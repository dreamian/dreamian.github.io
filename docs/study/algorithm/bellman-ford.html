Bellman-Ford 알고리즘

Published

June 2, 2026

1 알고리즘

Bellman-Ford는 음수 간선을 허용하고, \(s\)에서 도달 가능한 음수 사이클의 존재 여부까지 판별하는 단일 출발점 최단 경로 알고리즘이다.

BELLMAN-FORD(G, w, s)
1  INITIALIZE-SINGLE-SOURCE(G, s)
2  for i = 1 to |G.V| - 1
3      for each edge (u,v) ∈ G.E
4          RELAX(u, v, w)
5  for each edge (u,v) ∈ G.E          // 음수 사이클 검출
6      if v.d > u.d + w(u,v)
7          return FALSE
8  return TRUE

구조는 \(|V|-1\)번의 패스(pass)(각 패스마다 모든 간선을 relax)와 마지막 검출 루프로 이루어진다.

수행 시간: 초기화 \(O(V)\), 메인 이중 루프 \(O(VE)\), 검출 루프 \(O(E)\) → 전체 \(O(VE)\).

2 정확성: 도달 가능 정점 (Lemma 24.2)

NoteLemma 24.2

\(s\)에서 도달 가능한 음수 사이클이 없으면, 라인 2–4의 \(|V|-1\)번 패스 후 도달 가능한 모든 \(v\)에 대해 \(v.d=\delta(s,v)\)이다.

증명. \(s\to v\) 최단 경로 \(p=\langle v_0,\dots,v_k\rangle\)를 잡으면, 최단 경로는 simple이므로 \(k\le|V|-1\)이다. 각 패스가 모든 간선을 relax하므로 \(i\)번째 패스에서 간선 \((v_{i-1},v_i)\)가 (다른 간선들과 함께) 반드시 relax된다. 따라서 경로 순서대로 relax되고, 경로-완화 성질에 의해 \(v_k.d=\delta(s,v_k)\). \(\blacksquare\)

2.1 핵심: “패스 순서”와 “경로 정점 순서”는 달라도 된다

증명의 가장 헷갈리는 지점은 “간선 \((v_{i-1},v_i)\)가 \(i\)번째 iteration에서 relax된다”는 문장이다. 루프가 두 겹임을 분리하면 명확해진다.

2  for i = 1 to |V|-1          ← (A) 바깥 루프: "패스"
3      for each edge (u,v)∈E   ← (B) 안쪽 루프: 모든 간선을 어떤 고정 순서로 훑음

“\(i\)-th iteration”은 바깥 루프 (A)의 \(i\)번째 패스를 가리키며, 안쪽 (B)의 간선 순서가 아니다. 한 패스는 \(E\)의 모든 간선을 한 번씩 relax한다. 따라서 “간선 \((v_{i-1},v_i)\)가 \(i\)번째 패스에서 relax된다”는 거의 자명한 진술이다 — 그 간선도 \(E\)의 한 원소이므로 \(i\)번째 패스 도중 언젠가 반드시 풀린다. 패스 안에서 몇 번째로 풀리는지는 주장하지 않는다.

Important안쪽 순서가 어긋나도 괜찮은 이유

안쪽 (B)의 간선 순서가 경로 순서와 정반대일 수도 있다. 그러나 경로-완화 성질이 요구하는 것은 경로 간선들끼리의 상대적 순서뿐이고, 그 사이에 다른 relax가 아무리 끼어들어도 무방하다.

그 상대 순서는 패스가 순차적이라는 사실이 보장한다. 패스 1 전체가 패스 2 전체보다 앞서 일어나므로, “패스 1의 \((v_0,v_1)\)”은 설령 패스 1의 맨 마지막에 풀리고 “패스 2의 \((v_1,v_2)\)”가 패스 2의 맨 처음에 풀리더라도 무조건 먼저 일어난다. 즉 전체 relax 시퀀스 속에는

\[ \underbrace{(v_0,v_1)}_{\text{패스 1}},\ \dots,\ \underbrace{(v_1,v_2)}_{\text{패스 2}},\ \dots,\ \underbrace{(v_{k-1},v_k)}_{\text{패스 }k} \]

라는 올바른 순서의 부분수열이 (다른 relax들에 섞인 채) 항상 박혀 있다. 경로-완화 성질은 정확히 이것을 요구한다.

2.2 최악의 경우로 확인

\(s=v_0\to v_1\to v_2\to v_3\)(\(k=3\))인 최단 경로에서, 안쪽 순서가 가장 적대적으로 경로 역순 \((v_2,v_3)\to(v_1,v_2)\to(v_0,v_1)\)로 푼다고 하자.

패스 효과
1 \((v_0,v_1)\)만 효과: \(v_1.d=\delta(s,v_1)\) 확정
2 \((v_1,v_2)\) 효과: \(v_2.d=\delta(s,v_2)\) 확정
3 \((v_2,v_3)\) 효과: \(v_3.d=\delta(s,v_3)\) 확정

적대적 순서에서도 패스마다 확정된 정점의 경계(frontier)가 정확히 하나씩 전진한다. 그래서 \(k\)개 간선 경로는 늦어도 \(k\)번째 패스 끝에 도착점이 확정되며, \(k\le|V|-1\)이므로 \(|V|-1\)번 패스면 어떤 도달 가능 정점이든 확정된다. (반대로 안쪽 순서가 경로 순서와 같다면 단 한 패스에 모두 확정될 수도 있으나, 그런 행운을 가정할 수 없으므로 최악의 경우로 증명한다.)

3 Corollary 24.3

NoteCorollary 24.3

음수 사이클이 없으면, 각 \(v\)에 대해 \(s\to v\) 경로가 존재하는 것과 종료 시 \(v.d<\infty\)인 것은 동치이다.

4 전체 정확성 (Theorem 24.4)

NoteTheorem 24.4
  • \(s\)에서 도달 가능한 음수 사이클이 없으면: 알고리즘은 TRUE를 반환하고, 모든 \(v\)에 대해 \(v.d=\delta(s,v)\)이며, \(G_\pi\)는 최단 경로 트리이다.
  • \(s\)에서 도달 가능한 음수 사이클이 있으면: 알고리즘은 FALSE를 반환한다.

4.1 음수 사이클이 없는 경우

도달 가능 정점은 Lemma 24.2로 \(v.d=\delta\)가 확정되고, 도달 불가능 정점은 무경로 성질로 \(v.d=\infty=\delta\)가 유지된다. 둘을 합치면 모든 \(v\)에 대해 \(v.d=\delta(s,v)\)이고, 선행자-부분그래프 성질로 \(G_\pi\)는 최단 경로 트리이다.

TRUE 반환 이유: 종료 시 모든 간선 \((u,v)\)에 대해

\[ v.d=\delta(s,v)\ \underset{\text{24.10}}{\le}\ \delta(s,u)+w(u,v)=u.d+w(u,v) \]

이므로 라인 6의 검사가 한 번도 FALSE를 띄우지 않는다.

4.2 음수 사이클이 있는 경우 (귀류법)

도달 가능한 음수 사이클 \(c=\langle v_0,\dots,v_k\rangle\)(\(v_0=v_k\))에서

\[ \sum_{i=1}^k w(v_{i-1},v_i)<0. \tag{24.1} \]

알고리즘이 TRUE를 반환한다고 가정하면 라인 6 검사를 모두 통과했으므로, 사이클의 모든 간선에 대해

\[ v_i.d \le v_{i-1}.d + w(v_{i-1},v_i),\quad i=1,\dots,k. \]

사이클을 한 바퀴 합산하면

\[ \sum_{i=1}^k v_i.d \;\le\; \sum_{i=1}^k v_{i-1}.d \;+\; \sum_{i=1}^k w(v_{i-1},v_i). \]

\(v_0=v_k\)이므로 두 합 \(\sum_{i=1}^k v_i.d\)와 \(\sum_{i=1}^k v_{i-1}.d\)는 같은 정점 집합을 정확히 한 번씩 더한 것이라 동일하다. 또 Corollary 24.3에 의해 (사이클이 도달 가능하므로) 모든 \(v_i.d\)가 유한하여 양변에서 안전하게 소거할 수 있다. 남는 것은

\[ 0 \;\le\; \sum_{i=1}^k w(v_{i-1},v_i), \]

인데 이는 (24.1)에 모순이다. 따라서 가정이 틀렸고 알고리즘은 FALSE를 반환한다. \(\blacksquare\)

Tip이 귀류법의 두 전제

정점 항 \(\sum v_i.d\)와 \(\sum v_{i-1}.d\)의 소거가 가능한 것은 (a) 사이클이라 \(v_0=v_k\), (b) \(v_i.d\)가 모두 유한, 이 두 조건 덕분이다. 시험에서 이 두 조건을 명시하는 것이 좋다.

5 조기 종료 최적화

어떤 한 패스 동안 단 하나의 \(v.d\)도 갱신되지 않으면 즉시 종료해도 된다. \(|V|-1\)은 최악의 경우를 위한 상한이며 항상 채워야 하는 횟수가 아니다.

5.1 조기 종료가 옳은 이유

RELAX는 현재 \(d\) 값들의 결정론적 함수이다. 한 패스에서 아무 갱신도 없었다면 패스 끝 상태가 시작 때와 완전히 동일하므로, 다음 패스도 똑같은 상태에 똑같은 연산을 적용해 아무것도 바꾸지 못한다. 귀납적으로 이후 모든 패스가 무변화이며, 현재 \(d\) 값들이 최종 고정점(fixed point)이다.

5.2 그 고정점이 정답(\(=\delta\))이라는 보장

무변화 패스는 곧 모든 간선에서 \(v.d\le u.d+w(u,v)\)가 성립한다는 증명서이다. 이 조건이 갖춰지면 도달 가능한 \(v\)에 대해 \(v.d=\delta(s,v)\)가 따라온다. \(s\to v\) 최단 경로 \(s=v_0\to\dots\to v_k=v\)를 따라

\[ v_i.d \le v_{i-1}.d + w(v_{i-1},v_i)=\delta(s,v_{i-1})+w(v_{i-1},v_i)=\delta(s,v_i) \]

를 차례로 적용하면 \(v_i.d\le\delta(s,v_i)\)이고, 상한 성질 \(v_i.d\ge\delta(s,v_i)\)와 합치면 \(v_i.d=\delta(s,v_i)\)이다. 또한 무변화 패스가 나왔다는 사실 자체가 도달 가능한 음수 사이클이 없음을 증명한다(음수 사이클이 도달 가능하면 \(d\)가 영원히 줄어들어 고정점에 닿지 못하므로). 따라서 조기 종료 시 바로 TRUE를 반환해도 된다.

5.3 \(|V|-1\)은 최악의 경우 여전히 필요하다

조기 종료 가능성과 “\(|V|-1\) 상한을 줄일 수 있다”는 다른 얘기이다. 일자형 경로 \(s\to v_1\to\dots\to v_{|V|-1}\)에서 안쪽 간선 순서가 경로 역순이면, frontier가 패스당 하나씩만 전진해 정확히 \(|V|-1\)번의 갱신 패스가 필요하다. 이 경우 조기 종료가 발동하지 않는다.

  • 인스턴스별로는 갱신 없는 패스가 나오는 즉시 종료 가능(보통 훨씬 빨리 끝남).
  • 최악의 경우 보장으로는 \(|V|-1\)이 줄지 않음(어떤 그래프든 \(|V|-1\)번이면 충분하다는 안전판).

5.4 구현

for i = 1 to |V|-1
    changed = FALSE
    for each edge (u,v) ∈ E
        if v.d > u.d + w(u,v)
            v.d = u.d + w(u,v); v.π = u
            changed = TRUE
    if not changed
        return TRUE          // 고정점 도달, 음수 사이클 없음
for each edge (u,v) ∈ E      // |V|-1 패스로도 안 끝났을 때 음수 사이클 판별
    if v.d > u.d + w(u,v)
        return FALSE
return TRUE
Warning주의

조기 종료 판정은 반드시 한 패스를 완주한 뒤 내려야 한다. 패스 중간에 “아직 갱신 없네”라며 끊으면 안 된다 — 아직 안 본 간선이 갱신을 일으킬 수 있다. 올바른 종료 조건은 “전체 간선을 다 봤는데 아무것도 안 바뀜”이다.

6 논리 사슬 요약

\[ \text{삼각부등식 + 상한 성질}\Rightarrow\text{수렴 성질}\Rightarrow\text{경로-완화 성질} \Rightarrow\text{Lemma 24.2}\Rightarrow\text{정확성} \]

Bellman-Ford의 “각 간선 \(|V|-1\)번 relax” 설계는 결국 “임의의 최단 경로(\(\le|V|-1\) 간선)의 간선들이 순서대로 풀리는 것을 보장”하려는 것이며, 그 정당성이 경로-완화 성질 한 줄에 응축되어 있다.
