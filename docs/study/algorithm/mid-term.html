1 Incremental Algorithm

1.1 Insertion Sort

1.1.1 Pseudo Code

\[ \begin{aligned} &\text{INSERTION-SORT}(A) \\ &1\quad \mathbf{for}\ j = 2\ \mathbf{to}\ A.\mathrm{length} \\ &2\qquad \mathtt{key} = A[j] \\ &3\qquad \text{// Insert } A[j] \text{ into the sorted sequence } A[1 \ldots j-1] \\ &4\qquad i = j - 1 \\ &5\qquad \mathbf{while}\ i > 0 \ \mathbf{and}\ A[i] > \mathtt{key} \\ &6\qquad\qquad A[i+1] = A[i] \\ &7\qquad\qquad i = i - 1 \\ &8\qquad A[i+1] = \mathtt{key} \end{aligned} \]

1.1.2 알고리즘의 Correctness 증명

1.1.2.1 Loop Invariant

for 반복문의 각 반복이 시작될 때마다, 부분배열 A[1..j-1]은 원래 그 원소들로 이루어진 정렬된 배열이다.
이 invariant는 incremental algorithm의 철학과 정확히 일치한다. 즉, 이전 단계까지의 해가 올바르다고 가정하고, 그 위에 새로운 원소를 추가해서 더 큰 해를 만드는 것이다.

1.1.2.2 Initialization

첫 번째 반복이 시작될 때 j = 2이다. 이때 A[1..j-1] = A[1]인데, 원소가 하나뿐인 배열은 항상 정렬되어 있다. 따라서 loop invariant는 처음부터 성립한다.

1.1.2.3 Maintenance

반복이 시작될 때 A[1..j-1]이 정렬되어 있다고 가정하자. 알고리즘은 key = A[j]를 이 정렬된 구간 안의 적절한 위치에 삽입한다. 삽입 과정에서는 key보다 큰 원소들만 오른쪽으로 밀린다. 그 후 key가 정확한 위치에 놓인다. 그러면 결과적으로 A[1..j]가 정렬된다. 즉, 한 단계가 끝난 뒤에도 다음 단계에서 필요한 정렬 조건이 계속 유지된다.

1.1.2.4 Termination

반복문이 끝나면 j = A.length + 1이다. 그때 loop invariant에 의해 A[1..A.length]가 정렬되어 있으므로, 전체 배열이 올바르게 정렬된 것이다. 이로써 Insertion Sort의 correctness가 증명된다.

2 Divide & Conquer

2.1 Merge Sort

2.1.1 Pseudo Code

\[ \begin{aligned} &\text{MERGE}(A,p,q,r) \\ &1\ \ n_1 = q-p+1 \\ &2\ \ n_2 = r-q \\ &3\ \ \text{let } L[1\dots n_1+1] \text{ and } R[1\dots n_2+1] \text{ be new arrays} \\ &4\ \ \textbf{for } i = 1 \textbf{ to } n_1 \\ &5\ \quad L[i] = A[p+i-1] \\ &6\ \ \textbf{for } j = 1 \textbf{ to } n_2 \\ &7\ \quad R[j] = A[q+j] \\ &8\ \ L[n_1+1] = \infty \\ &9\ \ R[n_2+1] = \infty \\ &10\ i = 1 \\ &11\ j = 1 \\ &12\ \textbf{for } k = p \textbf{ to } r \\ &13\ \quad \textbf{if } L[i] \le R[j] \\ &14\ \qquad A[k] = L[i] \\ &15\ \qquad i = i + 1 \\ &16\ \quad \textbf{else } A[k] = R[j] \\ &17\ \qquad j = j + 1 \\ \\ &\text{MERGE-SORT}(A,p,r) \\ &1\ \textbf{if}\ p < r \\ &2\ \quad q = \lfloor (p+r)/2 \rfloor \\ &3\ \quad \text{MERGE-SORT}(A,p,q) \\ &4\ \quad \text{MERGE-SORT}(A,q+1,r) \\ &5\ \quad \text{MERGE}(A,p,q,r) \end{aligned} \]

2.1.2 알고리즘의 Correctness 증명

ImportantLoop Invariant

for-loop (12–17번 줄)의 각 반복이 시작될 때마다,

  • 부분배열 \(A[p \dots k-1]\) 는 \(L[1 \dots n_1+1]\) 와 \(R[1 \dots n_2+1]\) 에 있는 원소들 중 가장 작은 \((k-p)\)개의 원소를 오름차순으로 담고 있다.
  • 또한 \(L[i]\) 와 \(R[j]\) 는 각각 아직 \(A\)로 복사되지 않은 원소들 중 가장 작은 원소이다.

이 불변식이 유지되면, 반복이 끝났을 때 전체 병합 결과가 정확하게 정렬되어 있음을 보일 수 있다.

2.1.2.1 Initialization

반복문이 시작되기 전, \(k=p\) 이므로 부분배열 \(A[p \dots k-1]\) 는 비어 있다.

비어 있는 배열은 “가장 작은 0개의 원소를 정렬된 상태로 담고 있다”라고 볼 수 있으므로 초기 조건은 성립한다. 또한 \(i=1\), \(j=1\) 이므로 \(L[i]\), \(R[j]\) 는 각 배열에서 아직 복사되지 않은 가장 작은 후보이다.

2.1.2.2 Maintenance

반복 시작 시 loop invariant가 참이라고 가정하자.

Tip경우 1: \(L[i] \le R[j]\)

이때 \(L[i]\) 는 아직 복사되지 않은 원소들 중 가장 작은 값이다. 따라서 \(A[k]\) 에 \(L[i]\) 를 넣으면,

  • \(A[p \dots k]\) 는 가장 작은 \((k-p+1)\)개의 원소를 담게 되고
  • 오름차순 정렬 상태도 유지된다.

그 후 \(i\) 를 1 증가시키면 다음 반복에서도 불변식이 다시 성립한다.

Tip경우 2: \(L[i] > R[j]\)

이 경우에는 \(R[j]\) 가 가장 작은 미복사 원소이므로 \(A[k]\) 에 \(R[j]\) 를 넣고 \(j\) 를 증가시키면 된다. 같은 논리로 loop invariant는 유지된다.

2.1.2.3 Termination

반복문이 끝나면 \(k=r+1\) 이다.

따라서 loop invariant에 의해 \(A[p \dots k-1] = A[p \dots r]\) 는 \(L\) 과 \(R\) 의 원소들 중 가장 작은 \((r-p+1)\)개를 오름차순으로 담고 있다.

원래 우리가 병합하려던 실제 원소 개수는 정확히 \((r-p+1)\)개이므로, 결국 \(A[p \dots r]\) 는 정렬된 상태가 된다. 마지막에 남는 두 개의 가장 큰 값은 sentinel인 \(\infty\) 이므로 실제 정렬 결과에는 포함되지 않는다.

2.1.3 시간복잡도 분석

Merge Sort의 실행 시간을 divide, conquer, combine 관점에서 분석해보자.

NoteDivide

중간 인덱스 \(q\) 를 계산하는 데 걸리는 시간은 \(\Theta(1)\) 이다.

NoteConquer

크기가 \(n/2\) 인 두 부분 문제를 재귀적으로 해결하므로 비용은

\[ 2T(n/2) \]

이다.

NoteCombine

정렬된 두 부분 배열을 합치는 MERGE 과정은 전체 원소를 한 번씩 보므로

\[ \Theta(n) \]

시간이 걸린다.

따라서 전체 점화식은 다음과 같다.

\[ \begin{aligned} &T(1) = 1 \\ &T(n) = 2T(\frac {n}{2}) + n \end{aligned} \]

이 점화식을 풀면 Merge Sort의 시간 복잡도는

\[ \begin{aligned} &T(n) = 2T\left(\frac{n}{2}\right) + n \\ &T(n) = 2^2T\left(\frac{n}{2^2}\right) + 2n \\ &T(n) = 2^3T\left(\frac{n}{2^3}\right) + 3n \\ &\vdots \\ &T(n) = 2^kT\left(\frac{n}{2^k}\right) + kn, \quad k \in \{1, 2, \dots, \log_2 n\} \\ \\ &\text{when } k = \log_2 n, \\ &T(n) = 2^{\log_2 n}T(1) + (\log_2 n)n \\ &T(n) = n \cdot 1 + n \log_2 n \\ &T(n) = n(1 + \log_2 n) \\ \\ &\therefore T(n) = \Theta(n \log n) \end{aligned} \]
