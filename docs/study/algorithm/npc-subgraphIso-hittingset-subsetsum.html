NP-완전성 증명: SUBGRAPH-ISOMORPHISM · HITTING-SET · SUBSET-SUM

Published

June 7, 2026

1 들어가며: 환원으로 NP-완전을 보이는 표준 절차

어떤 결정 문제 \(L\)이 NP-완전임을 보이려면 두 가지를 증명한다.

  1. \(L \in \mathrm{NP}\): 인증서(certificate)가 주어졌을 때, 그것이 올바른 해임을 입력 크기의 다항 시간에 검증할 수 있다.
  2. \(L\)이 NP-hard: 이미 NP-완전임이 알려진 문제 \(L'\)에 대해 \(L' \le_P L\) (다항 시간 환원)을 보인다.

특히 (2)의 환원 방향이 결정적이다. \(L' \le_P L\)은 “\(L\)이 적어도 \(L'\)만큼 어렵다”를 뜻한다. 방향을 거꾸로 잡으면 의도와 정반대의 명제를 증명하게 되므로, 항상 알려진 어려운 문제 → 새 문제 방향으로 인스턴스를 변환해야 한다.

환원 증명은 보통 세 부분으로 구성된다.

  • 구성(construction): \(L'\)의 인스턴스를 \(L\)의 인스턴스로 변환하는 규칙.
  • 다항 시간성: 그 변환이 다항 시간에 수행됨.
  • 정당성(iff): 원래 인스턴스가 yes ⟺ 변환된 인스턴스가 yes. 이때 (\(\to\))와 (\(\leftarrow\)) 두 방향을 분리하여 각각 명시한다.

2 예비 개념: 그래프 동형사상(Isomorphism)

2.1 전단사 함수(Bijection)

함수 \(f : A \to B\)에 대해:

  • 단사(injective): \(a_1 \neq a_2 \Rightarrow f(a_1) \neq f(a_2)\). 출력이 겹치지 않는다.
  • 전사(surjective): \(B\)의 모든 원소가 어떤 입력의 상(image)이다. 빠지는 출력이 없다.
  • 전단사(bijection): 단사이면서 전사. 즉 \(A\)와 \(B\)의 원소가 빠짐없이·겹침없이 1:1로 짝지어진다. 이때 역함수 \(f^{-1}\)이 항상 존재하며, \(|A| = |B|\)가 필요조건이다.

2.2 그래프 동형사상

그래프 \(G\)와 \(H\)의 동형사상(isomorphism) 은 정점 집합 사이의 전단사 \[ f : V(G) \to V(H) \] 로서, \(G\)의 임의의 두 정점 \(u, v\)에 대해 \[ (u, v)\ \text{가 } G\text{에서 인접} \iff (f(u), f(v))\ \text{가 } H\text{에서 인접} \] 를 만족하는 것이다.

핵심 두 조건

  • 전단사 조건: 정점을 빠짐없이 1:1 대응시킨다. “정점에 붙은 이름표를 갈아끼우는 규칙”으로 볼 수 있다.
  • 인접 보존(iff) 조건: 간선의 유무 패턴이 양방향으로 정확히 보존된다. \(\to\)만 요구하면 간선을 추가한 그래프까지 허용되어 버리므로, \(\leftrightarrow\)를 통해 “연결 구조가 완전히 동일”함을 강제한다.

직관적으로 \(H\)가 \(G\)와 동형이라는 것은, \(H\)는 \(G\)의 정점 이름표만 바꿔 붙인 것일 뿐이며 “누가 누구와 연결되어 있는가”라는 연결 구조 자체는 동일하다는 뜻이다. 이후 SUBGRAPH-ISOMORPHISM 정의의 기본 벽돌이 된다.

3 SUBGRAPH-ISOMORPHISM

3.1 문제 정의

  • 입력: 무방향 그래프 \(G_1 = (V_1, E_1)\), \(G_2 = (V_2, E_2)\)
  • 질문: \(G_1\)이 \(G_2\)의 어떤 부분그래프(subgraph)와 동형인가?

즉, \(V' \subseteq V_2\), \(E' \subseteq E_2\) 인 \(G' = (V', E')\) 가 존재하여 \(|V'| = |V_1|\), \(|E'| = |E_1|\) 이고, 정점 사이의 일대일 대응 \(f\) 가 \((u,v) \in E' \iff (f(u), f(v)) \in E_1\) 을 만족하는가?

3.2 \(\text{SUBGRAPH-ISOMORPHISM} \in \mathrm{NP}\)

인증서: 부분그래프 \(G' = (V', E')\) 와 \(G'\)의 정점과 \(G_1\)의 정점 사이의 대응 함수 \(f\).

검증 알고리즘: 다음을 확인한다.

  • \(V' \subseteq V_2\), \(E' \subseteq E_2\) (부분그래프 여부)
  • \(|V'| = |V_1|\), \(|E'| = |E_1|\) (크기 일치)
  • 모든 \((u,v) \in E'\)에 대해 \((f(u), f(v)) \in E_1\) (동형 여부)

이 검사는 다항 시간에 수행 가능하므로 \(\text{SUBGRAPH-ISOMORPHISM} \in \mathrm{NP}\). \(\blacksquare\)

3.3 NP-hardness: \(\text{CLIQUE} \le_P \text{SUBGRAPH-ISOMORPHISM}\)

환원 방향: 이미 NP-완전인 CLIQUE를 SUBGRAPH-ISOMORPHISM으로 변환한다. 따라서 SUBGRAPH-ISOMORPHISM이 적어도 CLIQUE만큼 어렵다(NP-hard).

3.3.1 구성

CLIQUE 인스턴스 \(\langle G = (V, E),\ k \rangle\) 를 입력받아 다음을 생성한다. \[ G_1 := K_k \ (\text{크기 } k \text{의 complete graph}), \qquad G_2 := G. \]

유의 — \(G_1\)이 complete graph인 이유. \(G_1\)은 주어진 그래프가 아니라 환원 함수가 의도적으로 생성하는 인스턴스다. clique의 정의(“\(k\)개의 정점이 서로 모두 인접”)가 곧 complete graph \(K_k\)이므로, “\(G\) 안에 size \(k\) clique 존재”를 “\(K_k\) 패턴이 \(G\) 안에 박혀 있는가”로 번역하기 위해 \(G_1 = K_k\)로 설정한다.

크기 \(k\)의 complete graph 생성은 다항 시간에 가능하므로 환원은 다항 시간이다.

3.3.2 정당성

주장: \(G\)가 size \(k\) clique를 가진다 \(\iff\) \(G_1\)이 \(G_2\)의 부분그래프와 동형이다.

(\(\to\)) CLIQUE \(\Rightarrow\) SUBGRAPH-ISOMORPHISM. \(G_2(=G)\)가 size \(k\) clique를 가진다고 하자. 그 clique를 이루는 \(k\)개의 정점은 서로 모두 인접하므로, 그들이 유도하는 부분그래프는 정확히 \(K_k\) 이다. \(G_1 = K_k\) 이므로 \(G_1\)은 \(G_2\)의 한 부분그래프와 동형이다.

(\(\leftarrow\)) SUBGRAPH-ISOMORPHISM \(\Rightarrow\) CLIQUE. \(G_1\)이 \(G_2\)의 어떤 부분그래프와 동형이라고 하자. \(G_1 = K_k\), 즉 \(k\)개의 정점이 서로 모두 인접한 구조다. 동형사상은 인접 관계를 양방향(iff) 으로 보존하므로, \(G_2\) 안에서 대응되는 \(k\)개의 정점도 서로 모두 인접해야 한다. 따라서 \(G_2(=G)\)는 size \(k\) clique를 가진다.

여기서 동형사상의 iff(인접 양방향 보존) 가 (\(\leftarrow\))에서 결정적으로 쓰인다. 한쪽 방향만 보존한다면 \(K_k\)가 박혀 있어도 대응 정점들이 “서로 모두” 인접한다고 보장할 수 없어 clique 결론이 무너진다. \(G_1 = K_k\)라는 설계와 동형사상의 양방향 정의가 짝을 이루어야 증명이 닫힌다.

양방향이 성립하므로 환원이 정당하다. \(\blacksquare\)

4 HITTING-SET

4.1 문제 정의

집합 \(T\) 와, \(T\)의 부분집합들로 이루어진 컬렉션 \(S = \{S_1, S_2, \dots, S_n\}\) 이 주어진다. hitting set \(H \subseteq T\) 는 컬렉션의 모든 집합을 적어도 한 원소로 “찌르는(intersect)” 집합이다. 즉 모든 \(i\)에 대해 \(H \cap S_i \neq \emptyset\).

  • 예: \(T = \{1,2,3,4,5\}\), \(S = \{\{1,2\}, \{1,3\}, \{3,4,5\}\}\) 이면 \(H = \{1,3\}\) 이 hitting set.
  • 최적화 문제: 최소 크기의 hitting set을 구하라.
  • 결정 문제: \(T\), \(S\), 정수 \(k\) 가 주어질 때 \(|H| = k\) 인 hitting set이 존재하는가?

4.2 \(\text{HITTING-SET} \in \mathrm{NP}\)

인증서: hitting set 후보 \(H\).

검증 알고리즘: \(|H| = k\) 인지 확인하고, 모든 \(i = 1, \dots, n\) 에 대해 \(H \cap S_i \neq \emptyset\) 인지 확인한다.

시간 복잡도 \(O(|S|\,|H|\,|T|)\) — 세 인자의 출처:

for each S_i in S:          # 컬렉션의 모든 부분집합 순회 → |S| = n 회
    for each h in H:        # H의 각 원소 → |H| 회
        if h ∈ S_i: ...     # S_i 안에서 멤버십 검사 → 최악 |T| 회
  • \(|S|\): “모든 \(S_i\)를 확인”하는 외부 루프(컬렉션의 집합 개수 \(n\)).
  • \(|H| \cdot |T|\): 한 개의 교집합 판정 “\(H \cap S_i \neq \emptyset\)?” 의 비용. \(H\)의 원소 각각(\(|H|\)개)을 \(S_i\)에서 찾되, \(S_i \subseteq T\) 이므로 \(|S_i| \le |T|\) 라서 멤버십 1회가 최악 \(|T|\).

흔한 오해 — “각 \(S_i\)에 대해 \(S\)만 보면 된다”는 직관은 외부 루프 \(|S|\)만 떠올리고, 각 순회 안에서 일어나는 교집합 비교 (\(|H|\cdot|T|\)) 비용을 놓친 것이다. \(T\)는 바로 이 교집합 판정 비용에서 들어온다.

이 바운드는 타이트한 최적값이 아니라 다항임을 보이기 위한 느슨한 상한이다(해시를 쓰면 \(|T|\) 항 제거 가능). 세 양 모두 입력 크기에 다항으로 bound되므로 검증이 다항 시간이고, 따라서 \(\text{HITTING-SET} \in \mathrm{NP}\). \(\blacksquare\)

4.3 NP-hardness: \(\text{VERTEX-COVER} \le_P \text{HITTING-SET}\)

환원 방향: NP-완전인 VERTEX-COVER를 HITTING-SET으로 변환한다.

4.3.1 구성

VERTEX-COVER 인스턴스 \(\langle G = (V, E),\ k \rangle\) 를 입력받아: \[ T := V, \qquad S := \{\, \{u, v\} : (u, v) \in E \,\}. \] 즉 각 간선을 그 두 끝점으로 이루어진 2-원소 집합으로 만들어 컬렉션에 넣는다. 출력은 \(\langle T, S, k\rangle\).

이 변환은 \(O(|V| + |E|)\), 즉 다항 시간이다.

4.3.2 정당성

주장: \(G\)가 size \(k\) vertex cover \(C\) 를 가진다 \(\iff\) size \(k\) hitting set \(H\) 가 존재한다.

(\(\to\)) VERTEX-COVER \(\Rightarrow\) HITTING-SET. size \(k\) vertex cover \(C\) 가 있다고 하자. 정의상 모든 간선 \((u,v)\) 에 대해 \(u \in C\) 또는 \(v \in C\) 이다. 컬렉션의 집합은 정확히 \(\{u, v\}\) 형태이므로, \(H := C\) 로 두면 모든 \(\{u,v\} \in S\) 가 \(H\) 와 교차한다. 따라서 \(H\) 는 size \(k\) hitting set이다.

(\(\leftarrow\)) HITTING-SET \(\Rightarrow\) VERTEX-COVER. size \(k\) hitting set \(H\) 가 있다고 하자. \(H\) 는 모든 \(\{u,v\}\) 와 교차하므로 각 간선의 적어도 한 끝점을 포함한다. \(C := H\) 로 두면 모든 간선이 cover되어 size \(k\) vertex cover가 된다.

두 방향이 성립하므로 환원이 정당하다. \(\blacksquare\)

5 SUBSET-SUM

5.1 문제 정의

  • 입력: 양의 정수들의 유한집합 \(S\) 와 목표 정수 \(t > 0\)
  • 질문: 원소 합이 정확히 \(t\) 인 부분집합 \(S' \subseteq S\) 가 존재하는가?
  • 예: \(S = \{1,2,7,14,49,98,343,686,2409,2793\}\), \(t = 451\) 이면 \(S' = \{1,2,7,98,343\}\).

5.2 \(\text{SUBSET-SUM} \in \mathrm{NP}\)

인증서: 부분집합 \(S'\). 검증: \(\sum_{s \in S'} s = t\) 인지 더해서 확인한다. 다항 시간에 가능하므로 \(\text{SUBSET-SUM} \in \mathrm{NP}\). \(\blacksquare\)

5.3 NP-hardness: \(\text{3-CNF-SAT} \le_P \text{SUBSET-SUM}\)

환원 방향: NP-완전인 3-CNF-SAT를 SUBSET-SUM으로 변환한다.

5.3.1 입력에 거는 단순화 가정 (WLOG)

3-CNF 식 \(\phi\) (변수 \(x_1, \dots, x_n\), 절 \(C_1, \dots, C_k\))에 대해:

  1. 어떤 절도 한 변수와 그 부정을 동시에 포함하지 않는다.
  2. 각 변수는 적어도 하나의 절에 등장한다.

가정 1의 의미와 정당성. 절은 리터럴들의 OR이고, 리터럴은 \(x_i\) 또는 \(\neg x_i\) 이다. 가정 1은 한 절에 \(x_i\) 와 \(\neg x_i\) 가 함께 들어가지 않는다는 뜻이다(예: \((x_1 \lor \neg x_1 \lor x_2)\) 금지). 그런데 \(x_i \lor \neg x_i\) 는 항진식이라 그런 절은 어떤 배정에서도 무조건 참이다. 충족 가능성에 아무 제약도 주지 못하므로 다항 시간 전처리로 제거해도 되며, 따라서 일반성을 잃지 않는다. 또한 이 가정 덕분에 절의 (최대 3개) 리터럴이 서로 다른 변수에서 나와, 아래 자릿수 논증에서 “절 자리 기여 합 = 1~3, 충족 시 최소 1”이 깨끗하게 성립한다.

5.3.2 구성 (자릿수 인코딩)

각 수를 \(n + k\) 자리 십진수로 만들고, 자리를 다음과 같이 배정한다.

  • 변수 자리: 가장 중요한 \(n\) 자리 (\(x_1, \dots, x_n\)).
  • 절 자리: 가장 덜 중요한 \(k\) 자리 (\(C_1, \dots, C_k\)).

변수 수: 각 변수 \(x_i\) 마다 두 수 \(v_i\)(= \(x_i\) 참), \(v_i'\)(= \(x_i\) 거짓).

  • \(v_i, v_i'\) 모두 자신의 \(x_i\) 변수 자리에 1.
  • 리터럴 \(x_i\) 가 \(C_j\) 에 등장하면 \(v_i\) 의 \(C_j\) 자리에 1.
  • 리터럴 \(\neg x_i\) 가 \(C_j\) 에 등장하면 \(v_i'\) 의 \(C_j\) 자리에 1.

여유분(slack) 수: 각 절 \(C_j\) 마다 두 수 \(s_j\)(해당 자리에 1), \(s_j'\)(해당 자리에 2). 절 자리 합을 목표 4로 메꾸는 용도이며, 한 절당 slack 최대 기여는 \(1 + 2 = 3\).

목표값 \(t\): 각 변수 자리에 1, 각 절 자리에 4.

5.3.3 예시 식과 변환표

\[ \phi = C_1 \wedge C_2 \wedge C_3 \wedge C_4,\quad \begin{aligned} &C_1 = (x_1 \lor \neg x_2 \lor \neg x_3) \\ &C_2 = (\neg x_1 \lor \neg x_2 \lor \neg x_3) \\ &C_3 = (\neg x_1 \lor \neg x_2 \lor x_3) \\ &C_4 = (x_1 \lor x_2 \lor x_3) \end{aligned} \]

\(x_1\) \(x_2\) \(x_3\) \(C_1\) \(C_2\) \(C_3\) \(C_4\)
\(v_1\) 1 0 0 1 0 0 1
\(v_1'\) 1 0 0 0 1 1 0
\(v_2\) 0 1 0 0 0 0 1
\(v_2'\) 0 1 0 1 1 1 0
\(v_3\) 0 0 1 0 0 1 1
\(v_3'\) 0 0 1 1 1 0 0
\(s_1\) 0 0 0 1 0 0 0
\(s_1'\) 0 0 0 2 0 0 0
\(s_2\) 0 0 0 0 1 0 0
\(s_2'\) 0 0 0 0 2 0 0
\(s_3\) 0 0 0 0 0 1 0
\(s_3'\) 0 0 0 0 0 2 0
\(s_4\) 0 0 0 0 0 0 1
\(s_4'\) 0 0 0 0 0 0 2
\(t\) 1 1 1 4 4 4 4

이 변환은 다항 시간에 수행된다. 또한 한 자리의 최대 합은 절 자리에서 리터럴 3 + slack 3 = 6 \(< 10\) 이라 받아올림(carry)이 발생하지 않으므로, 각 자리를 독립된 제약으로 취급할 수 있다.

5.3.4 두 자리가 강제하는 제약 (구성의 핵심)

  • 변수 자리(목표 1): \(x_i\) 자리에 1을 줄 수 있는 수는 \(\{v_i, v_i'\}\) 뿐이고 목표가 1이므로, \(S'\)는 정확히 하나를 골라야 한다. \(v_i\) 선택 \(\Leftrightarrow x_i = 1\), \(v_i'\) 선택 \(\Leftrightarrow x_i = 0\). → 모순 없는 진리 배정 하나를 강제.
  • 절 자리(목표 4): 기여 출처는 (i) 선택된 리터럴 수 \(v\)들(0~3, 충족 시 최소 1)과 (ii) slack(\(s_j, s_j'\), 합 0~3). slack 최댓값이 3이므로, 리터럴 기여가 0(절 불충족)이면 4에 도달 불가. 모든 절이 충족될 때만 합이 \(t\) 가 된다.

5.3.5 정당성

주장: \(\phi\) 가 충족 가능 \(\iff\) 합이 정확히 \(t\) 인 \(S' \subseteq S\) 가 존재한다.

(\(\to\)) 3-CNF-SAT \(\Rightarrow\) SUBSET-SUM. \(\phi\) 의 충족 배정이 있다고 하자. \(x_i = 1\) 이면 \(v_i\) 를, \(x_i = 0\) 이면 \(v_i'\) 를 \(S'\) 에 넣는다. 그러면 각 변수 자리 합은 정확히 1(목표 일치). 각 절은 충족되므로 그 절 자리의 리터럴 기여 합은 1, 2, 또는 3 중 하나(최소 1)이고, 부족분을 slack \(\{s_j, s_j'\}\) 의 적절한 부분집합으로 채워 4를 맞춘다. 모든 자리가 목표와 일치하므로 \(S'\) 의 합은 \(t\) 이다.

예시 배정 \(\langle x_1{=}0, x_2{=}0, x_3{=}1\rangle\): \(S' = \{v_1', v_2', v_3\}\) 선택 시 절 자리 리터럴 기여는 \(C_1{:}1,\ C_2{:}2,\ C_3{:}3,\ C_4{:}1\). 부족분을 채워 \[ S' = \{v_1', v_2', v_3,\ s_1, s_1',\ s_2',\ s_3,\ s_4, s_4'\}, \qquad \textstyle\sum S' = 1114444 = t. \]

(\(\leftarrow\)) SUBSET-SUM \(\Rightarrow\) 3-CNF-SAT. 합이 \(t\) 인 \(S' \subseteq S\) 가 있다고 하자. 변수 자리 제약(받아올림 없음)에 의해 각 \(i\) 에 대해 \(v_i, v_i'\) 중 정확히 하나가 \(S'\) 에 있다. \(v_i \in S'\) 이면 \(x_i = 1\), \(v_i' \in S'\) 이면 \(x_i = 0\) 으로 배정한다. 각 절 자리의 목표는 4인데 slack은 최대 3까지만 기여하므로, 적어도 1은 선택된 리터럴 \(v\) 로부터 와야 한다. 즉 모든 절 \(C_j\) 에 그 절을 참으로 만드는 리터럴이 최소 하나 존재하여, 이 배정은 모든 절을 충족한다.

두 방향이 성립하므로 환원이 정당하다. \(\blacksquare\)

증명 작성 시 유의점

  • 항상 환원 방향을 먼저 명시한다(알려진 어려운 문제 → 새 문제).
  • iff 증명은 (\(\to\))와 (\(\leftarrow\))를 분리하여 각각 이름 붙여 서술하고, 종료를 명확히 표시한다.
  • 각 단계의 부등식·등식에는 근거를 named justification으로 붙인다(예: “받아올림 없음에 의해”, “slack 최댓값 3에 의해”).
  • SUBSET-SUM에서 “절 자리 목표 4 vs slack 최대 3”이라는 수치적 간극이 충족성을 강제하는 장치임을 강조한다.
