그래프 기초 및 BFS 정확성 증명

Published

May 18, 2026

1 그래프 기본 정의

1.1 그래프 G = (V, E)

방향 그래프(directed graph)는 정점 집합 V와 간선 집합 E \subseteq V \times V로 구성된다. 비방향 그래프(undirected graph)에서 간선 (u,v)는 순서 없는 쌍이다.

1.2 그래프 표현

그래프를 표현하는 두 가지 표준 방법이 있다.

인접 리스트 (Adjacency List): 각 정점 u \in V에 대해, u에 인접한 모든 정점들의 리스트 \text{Adj}[u]를 저장한다. 공간 복잡도 \Theta(V + E).

인접 행렬 (Adjacency Matrix): |V| \times |V| 크기의 행렬 A에서, a_{ij} = 1 iff (i,j) \in E. 공간 복잡도 \Theta(V^2).

표현 방식 공간 간선 존재 확인 인접 정점 순회
인접 리스트 \Theta(V+E) O(\text{degree}) O(\text{degree})
인접 행렬 \Theta(V^2) O(1) O(V)

1.3 Path (경로)

그래프 G에서 path는 정점의 수열 \langle v_1, v_2, \ldots, v_N \rangle으로, 모든 1 \leq i < N에 대해 (v_i, v_{i+1}) \in E를 만족한다. 경로의 길이(length)는 간선의 수 N-1이다.

1.4 Simple Path (단순 경로)

Simple path는 모든 정점이 서로 다른(distinct) 경로이다. 단, 첫 번째 정점과 마지막 정점이 같은 것은 허용한다.

이 정의에 따라 두 가지 케이스가 분리된다.

  • v_1 \neq v_N이고 \forall i \neq j, \; v_i \neq v_j — 일반적인 simple path
  • v_1 = v_N이고 v_1, v_2, \ldots, v_{N-1}은 모두 서로 다름 — simple cycle

후자의 케이스를 허용함으로써, cycle을 별도 객체로 정의하지 않고 simple path의 특수 케이스로 포섭할 수 있다.

1.5 Cycle (순환)

방향 그래프에서 cycle은 길이가 최소 1인 경로로, v_1 = v_N을 만족한다.

길이 \geq 1 조건은 정점 하나만 있고 이동이 없는 trivial한 경우(length = 0)를 배제하는 장치이다.

  • Self-loop (v_1 \to v_1): 길이 1인 cycle. \checkmark
  • v_1 \to v_2 \to v_1: 방향 그래프에서는 e_1 = (v_1, v_2)와 e_2 = (v_2, v_1)이 서로 다른 간선이므로 유효한 cycle. \checkmark

1.6 관련 정의 요약

DAG (Directed Acyclic Graph): cycle이 없는 방향 그래프.

Connected: 비방향 그래프에서 모든 정점 쌍 사이에 경로가 존재.

Strongly Connected: 방향 그래프에서 모든 정점 쌍 (u,v)에 대해 u \rightsquigarrow v와 v \rightsquigarrow u 모두 존재.

Complete Graph: 모든 정점 쌍 사이에 간선이 존재하는 그래프.

2 BFS 알고리즘

2.1 개요 및 핵심 특성

BFS(Breadth-First Search)는 소스 정점 s로부터 그래프의 간선을 체계적으로 탐색하여, s에서 도달 가능한 모든 정점을 발견하는 알고리즘이다.

핵심 특성은 frontier를 균등하게 확장(uniformly across the breadth)하는 것이다. 거리 k의 모든 정점을 발견한 후에야 거리 k+1의 정점들을 발견한다.

2.2 정점 상태와 Frontier

색깔 의미 위치
White 미발견 (undiscovered) Queue 밖
Gray 발견됨, 인접 정점 탐색 미완료 Queue 안 = Frontier
Black 발견됨, 인접 정점 탐색 완료 Queue 밖, 집합 S에 포함

Frontier = Gray 정점들의 집합 = Queue Q. 이 등식은 Loop Invariant로 보장된다.

2.3 최단경로 거리 정의

\delta(s,v) = \begin{cases} \min\{\text{path } s \to v \text{의 간선 수}\} & \text{if } v \text{ is reachable from } s \\ \infty & \text{otherwise} \end{cases}

2.4 BFS 의사코드

BFS(G, s)
 1.  for each vertex u ∈ G.V - {s}
 2.      u.color = WHITE
 3.      u.d = ∞
 4.      u.π = NIL
 5.  s.color = GRAY
 6.  s.d = 0
 7.  s.π = NIL
 8.  Q = ∅
 9.  ENQUEUE(Q, s)
10.  while Q ≠ ∅
11.      u = DEQUEUE(Q)
12.      for each v ∈ G.Adj[u]
13.          if v.color == WHITE
14.              v.color = GRAY
15.              v.d = u.d + 1
16.              v.π = u
17.              ENQUEUE(Q, v)
18.      u.color = BLACK

2.5 Loop Invariant

Line 10의 조건 검사 시점에서, Queue Q는 정확히 Gray 정점들의 집합으로 구성된다. Q = \{v \in V \mid v.\text{color} = \text{GRAY}\}

2.5.1 Initialization

루프 진입 전, source s만 GRAY로 색칠되고 (line 5) Q에 enqueue된다 (line 9). 나머지 모든 정점은 WHITE이므로, Q = \{s\} = \{v \mid v.\text{color} = \text{GRAY}\}가 성립한다.

2.5.2 Maintenance

한 iteration은 line 11의 dequeue로 시작하여 line 18의 BLACK 변색으로 종료된다. iteration 시작 시 Q = \{v \mid v.\text{color} = \text{GRAY}\}가 성립한다고 가정하고, iteration 종료 후(line 18 실행 직후)에도 이 등호가 유지됨을 양방향으로 보인다.

(\subseteq) Q에 있으면 GRAY다:

  • enqueue는 오직 line 14에서 GRAY로 변색한 직후(line 17)에만 발생한다.
  • 따라서 이 iteration 종료 시점에서 Q 안의 정점은 모두 GRAY이다.

(\supseteq) GRAY면 Q에 있다:

  • GRAY가 되는 경우는 오직 line 14뿐이며, 즉시 line 17에서 enqueue된다.
  • GRAY에서 벗어나는 경우는 오직 line 18(BLACK)뿐이며, 이는 line 11에서 dequeue된 이후에만 발생한다.
  • 따라서 이 iteration 종료 시점에서 GRAY인 정점은 반드시 Q 안에 존재한다.

두 방향이 모두 성립하므로, Q = \{v \mid v.\text{color} = \text{GRAY}\}가 유지된다. \square

2.5.3 Termination

Q = \emptyset이 되어 루프가 종료될 때, invariant에 의해 GRAY인 정점이 존재하지 않는다. 즉, s로부터 도달 가능한 모든 정점은 BLACK (처리 완료) 또는 WHITE (도달 불가)이다. 각 정점은 최대 한 번만 enqueue/dequeue되므로, queue 연산에 O(|V|), 인접 리스트 순회에 O(|E|)가 소요되어 전체 시간 복잡도는 T(n) = O(|V| + |E|)이다.

이 invariant가 보장하는 세 가지 사실:

  1. 탐색 경계가 Queue 하나로 완전히 표현된다: Frontier = Q (등호).
  2. 중복 처리 불가능: 코드 상 if v.color == WHITE 조건 체크에 의해 이미 발견된 정점은 다시 enqueue되지 않으며, 그 결과로 Queue에는 항상 Gray 정점만 존재한다는 invariant가 유지된다.
  3. Layer 단위 탐색 보장: FIFO + invariant에 의해, 거리 k인 정점들이 전부 처리된 후 거리 k+1인 정점들이 처리된다.

2.6 시간 복잡도

각 정점은 최대 한 번 enqueue/dequeue되므로 queue 연산에 O(|V|). 각 정점의 인접 리스트는 해당 정점이 dequeue될 때 한 번만 순회되므로 인접 리스트 총 탐색에 O(|E|).

T(n) = O(|V| + |E|)

3 BFS 정확성 증명을 위한 Lemma / Corollary 체계

3.1 Lemma 22.1 — 삼각부등식 (그래프 버전)

ImportantLemma 22.1

G = (V,E)를 방향 또는 비방향 그래프, s \in V를 임의의 정점이라 하자. 임의의 간선 (u,v) \in E에 대해:

\delta(s,v) \leq \delta(s,u) + 1

3.1.1 증명

Case 1 — u가 s로부터 reachable: u에 도달 가능하고 (u,v) \in E이므로 v도 도달 가능하다. 경로 s \rightsquigarrow u \to v의 길이는 \delta(s,u) + 1이다. \delta(s,v)는 s에서 v로의 모든 경로 중 최솟값이므로 \delta(s,v) \leq \delta(s,u) + 1. \square

Case 2 — u가 s로부터 unreachable: \delta(s,u) = \infty이므로 부등식 우변이 \infty가 되어 trivially 성립. \square

3.1.2 역할

이후 Lemma 22.2의 증명에서 핵심 도구로 사용된다.

3.2 Lemma 22.2 — Upper-bound Property (BFS 버전)

ImportantLemma 22.2

G = (V,E)에서 BFS를 소스 정점 s에서 실행할 때, BFS 실행 중 모든 시점에서 다음이 성립한다:

v.d \geq \delta(s,v) \quad \forall v \in V

3.2.1 핵심 의미

BFS가 계산하는 v.d 값은 실제 최단거리보다 절대 작아질 수 없다. v.d는 항상 \delta(s,v)의 상한(upper bound)이다.

3.2.2 역할

Theorem 22.5 증명에서, “v.d \neq \delta(s,v)이면 v.d > \delta(s,v)”를 이끌어내는 근거이다. 등호가 불가능한 상황에서 v.d \geq \delta(s,v)만으로 부등호 방향이 유일하게 결정된다.

3.2.3 증명

귀납법의 대상: ENQUEUE 연산의 횟수 k

Base case (k = 0):

BFS 초기화 시점에서,

  • s.d = 0 = \delta(s, s)이므로 s.d \geq \delta(s,s) 성립.
  • 나머지 모든 v \in V \setminus \{s\}에 대해 v.d = \infty \geq \delta(s,v) 성립.

Inductive step:

귀납 가정: 지금까지 수행된 모든 ENQUEUE에 대해 v.d \geq \delta(s,v)가 성립한다고 가정한다.

정점 u를 처리하는 도중 WHITE 정점 v가 발견되어 enqueue되는 경우를 고려한다.

v.d = u.d + 1 \geq \delta(s,u) + 1 \geq \delta(s,v)

  • v.d = u.d + 1: line 15에 의해.
  • u.d + 1 \geq \delta(s,u) + 1: 귀납 가정에 의해 u.d \geq \delta(s,u).
  • \delta(s,u) + 1 \geq \delta(s,v): Lemma 22.1 (\delta(s,v) \leq \delta(s,u) + 1)에 의해.

따라서 v.d \geq \delta(s,v)가 성립한다. \square

3.3 Lemma 22.3 — Queue 내 d-값 단조성

ImportantLemma 22.3

BFS 실행 중 Queue Q에 정점 \langle v_1, v_2, \ldots, v_r \rangle이 들어있다고 하자 (v_1이 head, v_r이 tail). 이때:

v_r.d \leq v_1.d + 1 \quad \text{그리고} \quad v_i.d \leq v_{i+1}.d \quad (i = 1, 2, \ldots, r-1)

3.3.1 의미

Queue 내의 d 값은 단조 비감소(non-decreasing)이며, 최대 차이가 1을 넘지 않는다. 즉, Queue에는 항상 최대 두 개의 서로 다른 d 값(연속된 layer k와 k+1)만 존재한다.

3.3.2 증명 (귀납법)

Queue 연산 횟수에 대한 귀납법으로 증명한다.

Inductive Hypothesis: v_r.d \leq v_1.d + 1 \quad \text{그리고} \quad v_i.d \leq v_{i+1}.d \quad (i = 1, 2, \ldots, r-1) Basis: $Queue에 s만 있을 때, s.d = 0이므로 자명하게 성립.$ Inductive Step: dequeue와 enqueue 각각에 대해 성질이 유지됨을 보인다.

  • Dequeue: v_1을 제거하면 v_2가 새 head. v_1.d \leq v_2.d이므로, v_r.d \leq v_1.d + 1 \leq v_2.d + 1. 나머지 부등식도 유지. \checkmark
  • Enqueue: 새 정점 v_{r+1}은 현재 처리 중인 정점 u의 인접 정점이므로 v_{r+1}.d = u.d + 1. u가 dequeue된 head이므로 u.d \leq v_r.d. 따라서 v_{r+1}.d = u.d + 1 \leq v_r.d + 1 \leq v_1.d + 1 + 1. v_r.d \leq v_{r+1}.d도 성립. \checkmark

\square

3.4 Corollary 22.4 — Dequeue 순서에 따른 d-값 비감소

ImportantCorollary 22.4

BFS 실행 중 정점 v_i와 v_j가 enqueue되었고, v_i가 v_j보다 먼저 enqueue되었다면, v_j가 enqueue되는 시점에:

v_i.d \leq v_j.d

3.4.1 증명

Lemma 22.3에서 Queue 내부의 d 값이 단조 비감소라는 사실과, 각 정점이 유한한 d 값을 BFS 실행 중 최대 한 번만 받는다는 사실로부터 즉시 따라온다. \square

3.4.2 역할

Theorem 22.5 증명에서 Black/Gray case의 핵심 도구이다:

  • Black case: v가 u보다 먼저 dequeue됨 → v.d \leq u.d
  • Gray case: v를 enqueue시킨 w가 u보다 먼저 dequeue됨 → w.d \leq u.d

4 Theorem 22.5 — BFS의 정확성 (핵심 정리)

WarningTheorem 22.5 (Correctness of BFS)

G = (V,E)에서 소스 정점 s \in V로부터 BFS를 실행하면, BFS는 s에서 도달 가능한 모든 정점 v \in V를 발견하며, 종료 시:

v.d = \delta(s,v) \quad \forall v \in V

또한 v \neq s이고 v가 s에서 도달 가능하면, s에서 v.\pi까지의 최단경로에 간선 (v.\pi, v)를 이어 붙인 것이 s에서 v까지의 최단경로 중 하나이다.

4.1 증명 (귀류법 — Proof by Contradiction)

4.1.1 Step 1 — 귀류법 가정 및 반례 정점 설정

어떤 정점이 incorrect한 d 값을 받는다고 가정한다. 그러한 정점들 중 \delta(s,v)가 최소인 것을 v로 선택한다.

v = \arg\min\{\delta(s,x) \mid x.d \neq \delta(s,x)\}

이 선택의 의미: v보다 s에 더 가까운 정점들은 전부 정확한 d 값을 받았다.

4.1.2 Step 2 — v.d > \delta(s,v) 확립

v.d \neq \delta(s,v)이고 Lemma 22.2에 의해 v.d \geq \delta(s,v)이므로:

v.d > \delta(s,v)

4.1.3 Step 3 — v의 reachability 확인

v가 unreachable이면 \delta(s,v) = \infty이고 v.d \geq \infty이므로 v.d = \infty = \delta(s,v) → incorrect라는 가정에 모순. 따라서 v는 반드시 s에서 reachable하다.

4.1.4 Step 4 — 전임자 u 설정

s에서 v로의 최단경로에서 v 바로 직전 정점을 u라 하면:

\delta(s,v) = \delta(s,u) + 1

4.1.5 Step 5 — u.d = \delta(s,u) (선택 방식에 의한 보장)

\delta(s,u) = \delta(s,v) - 1 < \delta(s,v)이므로, u는 “v보다 \delta가 작은 정점”이다. v를 incorrect 정점 중 \delta 최솟값으로 골랐으므로, u는 incorrect 정점 목록에 포함될 수 없다.

u.d = \delta(s,u)

4.1.6 Step 6 — 모순 목표 설정

v.d > \delta(s,v) = \delta(s,u) + 1 = u.d + 1

\boxed{v.d > u.d + 1}

4.1.7 Step 7 — u dequeue 시점 Case 분석

u가 Queue에서 dequeue될 때, 인접 정점 v의 색깔은 White, Black, Gray 중 하나이다.

4.1.7.1 Case 1: v가 White

BFS 알고리즘 line 15에 의해 v.d = u.d + 1 → v.d > u.d + 1에 직접 모순. \bot

4.1.7.2 Case 2: v가 Black

v가 Black이면 v는 이미 u보다 먼저 dequeue됨. Corollary 22.4에 의해 v.d \leq u.d.

v.d \leq u.d < u.d + 1

→ v.d > u.d + 1에 모순. \bot

주의: v가 Black이라는 것은 “u를 통해 발견됐다”는 뜻이 아니라, 다른 더 짧은 경로로 이미 먼저 발견되고 처리됐다는 뜻이다.

4.1.7.3 Case 3: v가 Gray

v가 Gray이면, 어떤 정점 w가 dequeue될 때 v가 Gray로 칠해진 것이므로:

v.d = w.d + 1

w는 u보다 먼저 dequeue되었으므로, Corollary 22.4에 의해 w.d \leq u.d.

v.d = w.d + 1 \leq u.d + 1

→ v.d > u.d + 1에 모순. \bot

4.1.8 결론

\text{White} \Rightarrow v.d = u.d+1 \quad \bot \qquad \text{Black} \Rightarrow v.d \leq u.d \quad \bot \qquad \text{Gray} \Rightarrow v.d \leq u.d+1 \quad \bot

모든 case에서 v.d > u.d+1에 모순이 발생하므로, 처음의 가정이 거짓이다.

\boxed{v.d = \delta(s,v) \quad \forall v \in V} \qquad \square

4.2 증명 완결부

4.2.1 Reachable한 정점은 반드시 발견됨

Reachable한 정점 v가 발견되지 않았다면 v.d = \infty이다. 그런데 \delta(s,v) < \infty이므로 v.d = \infty > \delta(s,v). 이는 v.d = \delta(s,v)에 모순. 따라서 reachable한 모든 정점은 반드시 BFS에 의해 발견된다.

4.2.2 Predecessor chain = 최단경로

v.\pi = u이면 BFS가 u를 dequeue할 때 v를 발견한 것이므로 v.d = u.d + 1. 이미 v.d = \delta(s,v), u.d = \delta(s,u)이므로:

\delta(s,v) = \delta(s,u) + 1

따라서 s에서 v.\pi까지의 최단경로에 간선 (v.\pi, v)를 이어 붙이면 s에서 v까지의 최단경로가 된다.

4.3 증명 구조도

증명 전략: Lemma 22.2 (하한) + Case Analysis (상한) → 등호

Lemma 22.2: v.d ≥ δ(s,v)  ← 하한 방향 (별도 증명)
                ↓
Case Analysis:  v.d ≤ u.d+1 = δ(s,v)  ← 상한 방향
                ↓
결합: v.d ≥ δ(s,v) ∧ v.d ≤ δ(s,v)  →  v.d = δ(s,v)

증명 의존관계:

Lemma 22.1 (삼각부등식)
    ↓
Lemma 22.2 (Upper-bound Property)
    ↓                                      Lemma 22.3 (Queue 단조성)
    ↓                                          ↓
    ↓                                      Corollary 22.4 (dequeue 순서 → d 비감소)
    ↓                                          ↓
    └──────────── Theorem 22.5 ────────────────┘

5 Lemma 22.6 — BFS Predecessor Subgraph는 BFS Tree

ImportantLemma 22.6

방향 또는 비방향 그래프 G = (V,E)에서 BFS를 적용하면, predecessor subgraph G_\pi = (V_\pi, E_\pi)는 BFS Tree(너비 우선 트리)를 형성한다.

5.0.1 증명

  1. BFS는 v.\pi = u를 (u,v) \in E이고 \delta(s,v) < \infty인 경우에만 설정하므로, V_\pi는 s에서 도달 가능한 정점들로 구성된다.
  2. G_\pi가 tree이므로 (Theorem B.2), s에서 각 v \in V_\pi로의 유일한 경로가 존재한다.
  3. Theorem 22.5를 귀납적으로 적용하면, 이 유일한 경로 각각이 최단경로임이 보장된다.

\square

6 시험 대비 — 핵심 증명 패턴 정리

6.1 귀류법 + 최솟값 선택 패턴

Theorem 22.5의 핵심 기법은 알고리즘 정확성 증명에서 반복적으로 등장하는 패턴이다:

  1. 가정: 알고리즘이 틀린 답을 내는 정점이 존재한다.
  2. 최솟값 선택: 그런 정점 중 특정 기준(여기서는 \delta)으로 최솟값을 골라 v로 설정.
  3. 선택의 효과: v보다 기준값이 작은 모든 정점은 자동으로 correct → 전임자 u의 정확성 확보.
  4. 모순 도출: 확보된 전임자 정보를 이용해 모든 case에서 모순을 보임.
  5. 결론: 가정 기각.

이 패턴은 Dijkstra 정확성 증명에서도 동일하게 적용된다.

6.2 Lemma → Corollary → Theorem 의존 구조 암기

시험에서 증명 문제가 출제될 경우, 각 Lemma/Corollary를 참조(cite)하며 사용해야 한다. 증명 작성 시 반드시 다음 순서를 따른다:

  1. 사용하는 Lemma/Corollary를 명시적으로 선언 (e.g., “By Lemma 22.2, …”)
  2. 해당 Lemma의 조건이 현재 상황에서 충족됨을 확인
  3. 결론을 적용

6.3 Upper-bound / Lower-bound 결합 패턴

v.d = \delta(s,v)를 증명하는 구조는 두 방향의 부등식을 결합하는 것이다:

\underbrace{v.d \geq \delta(s,v)}_{\text{Lemma 22.2 (별도 증명)}} + \underbrace{v.d \leq \delta(s,v)}_{\text{Case Analysis (귀류법)}} = v.d = \delta(s,v)

이 “두 부등식 결합” 패턴은 CLRS 전체에서 등호 증명의 표준 기법이다.

6.4 Corollary 22.4 활용 패턴

BFS Queue에서 먼저 처리된 정점의 d 값이 나중에 처리된 정점보다 작거나 같다는 것은, Black/Gray case에서 모순을 도출하는 핵심 도구이다. 이 Corollary 없이는 Theorem 22.5의 case analysis가 완성되지 않는다.
