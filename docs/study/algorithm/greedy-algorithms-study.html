April 19, 2026

1 Activity Selection Problem

1.1 문제 정의

하나의 공유 자원을 두고 경쟁하는 \(n\)개의 활동 집합 \(S = \{a_1, a_2, \ldots, a_n\}\)이 있을 때, 서로 겹치지 않는(mutually compatible) 활동의 최대 개수를 선택하는 최적화 문제다.

  • 각 활동 \(a_i\)는 시작 시각 \(s_i\)와 종료 시각 \(f_i\) (\(0 \le s_i < f_i < \infty\))를 가진다.
  • 활동 \(a_i\)가 선택되면 반개구간 \([s_i, f_i)\)를 점유한다.
  • \(a_i\)와 \(a_j\)가 compatible: \(f_i \le s_j\) 또는 \(f_j \le s_i\).
Note핵심 가정

활동들은 finish time 기준 오름차순으로 정렬되어 있다고 가정한다: \[f_1 \le f_2 \le \cdots \le f_n\]

1.2 Dynamic Programming 접근 — \(\Theta(n^3)\)

1.2.1 부분 문제 정의: \(S_{ij}\)

\[S_{ij} = \{ a_k \in S : f_i \le s_k < f_k \le s_j \}\]

\(S_{ij}\)는 \(a_i\)가 끝난 이후에 시작하고, \(a_j\)가 시작하기 전에 끝나는 활동들의 집합이다.

경계 조건을 위한 가상 활동 추가:

  • \(a_0\): \(f_0 = 0\) (시작 더미)
  • \(a_{n+1}\): \(s_{n+1} = \infty\) (종료 더미)
  • 전체 문제 = \(S_{0,\, n+1}\)에서의 최대 compatible 집합
  • \(i \ge j\)이면 \(S_{ij} = \emptyset\) (정렬 가정으로부터 자명)

1.2.2 Optimal Substructure 증명 (Cut-and-Paste)

ImportantOptimal Substructure

\(A_{ij}\)를 \(S_{ij}\)의 최적해라 하고 \(a_k \in A_{ij}\)라 하자. 그러면 \(A_{ij}\)는 두 하위 문제 \(S_{ik}\), \(S_{kj}\)의 최적해도 반드시 포함한다.

증명 (Cut-and-Paste):

  1. \(A_{ij}\)를 \(S_{ij}\)의 최적해, \(a_k \in A_{ij}\)로 정의한다.
  2. \(A_{ik} = A_{ij} \cap S_{ik}\), \(A_{kj} = A_{ij} \cap S_{kj}\)로 정의하면: \[A_{ij} = A_{ik} \cup \{a_k\} \cup A_{kj}, \quad |A_{ij}| = |A_{ik}| + |A_{kj}| + 1\]
  3. 귀류법: \(S_{kj}\)에서 \(|A_{kj}|\)보다 큰 compatible 집합 \(A'_{kj}\)가 존재한다고 가정하자.
  4. \(A_{ik} \cup \{a_k\} \cup A'_{kj}\)는 \(S_{ij}\)에서 크기 \(|A_{ij}|\)보다 큰 compatible 집합이 된다 (Cut: \(A_{kj}\) 제거, Paste: \(A'_{kj}\) 삽입).
  5. 이는 \(A_{ij}\)가 최적이라는 가정에 모순. ∴ \(A_{kj}\)는 \(S_{kj}\)의 최적해. ∎ (대칭 논거로 \(A_{ik}\)도 \(S_{ik}\)의 최적해)

1.2.3 DP 점화식

\(c[i,j]\) = \(S_{ij}\) 내의 최대 크기 compatible 집합의 크기:

\[c[i,j] = \begin{cases} 0 & \text{if } S_{ij} = \emptyset \\ \displaystyle\max_{a_k \in S_{ij}} \{ c[i,k] + c[k,j] + 1 \} & \text{if } S_{ij} \ne \emptyset \end{cases}\]

1.2.4 복잡도 분석 — 왜 \(\Theta(n^3)\)인가?

복잡도를 결정하는 세 가지 요소:

① 부분 문제의 수 — \(\Theta(n^2)\)

인덱스 쌍 \((i, j)\)의 개수다. \(0 \le i < j \le n+1\)이므로 \(\binom{n+2}{2} = \Theta(n^2)\)개의 부분 문제가 존재한다.

② 각 부분 문제당 탐색 범위 — \(O(n)\)

\(c[i,j]\)를 계산할 때, \(S_{ij}\)에 속하는 모든 \(a_k\)에 대해 탐색한다. 최악의 경우 \(|S_{ij}| = j - i - 1 = O(n)\)개의 후보 \(k\)를 시도한다.

③ 각 \(k\) 후보에 대한 계산 — \(O(1)\)

\(c[i,k] + c[k,j] + 1\)은 이미 계산된 값의 조회이므로 상수 시간이다.

\[\therefore \quad \Theta(n^2) \times \Theta(n) \times \Theta(1) = \Theta(n^3)\]

1.3 Greedy 접근 — \(\Theta(n)\)

1.3.1 Greedy 선택의 핵심 아이디어

DP에서는 최적 선택을 위해 하위 문제 결과를 먼저 보고 나서 \(k\)를 결정한다. Greedy는 반대로 먼저 선택하고 남은 하나의 하위 문제만 해결한다.

Greedy 전략: 항상 finish time이 가장 이른 활동 \(a_m\)을 선택한다.

\(a_1\)을 선택하면:

  • \(f_1\)이 모든 활동 중 가장 이르므로, \(f < f_1\)인 활동은 존재하지 않는다.
  • 왼쪽 하위 문제 \(S_{01}\)은 자동으로 공집합이 된다.
  • 남는 하위 문제는 \(S_1\) 하나뿐이다.
  • DP의 이중 인덱스 \(S_{ij}\) → 단일 인덱스 \(S_k\)로 문제 공간이 축소된다.

1.3.2 Theorem 16.1 — Greedy Choice Property

ImportantTheorem 16.1

비어있지 않은 임의의 부분 문제 \(S_k\)에서, finish time이 가장 이른 활동 \(a_m\)은 반드시 \(S_k\)의 어떤 최대 크기 최적해에 포함된다.

증명 (Cut-and-Paste):

  1. \(A_k\)를 \(S_k\)의 최적해라 하고, \(a_j\)를 \(A_k\)에서 finish time이 가장 이른 활동이라 하자.
  2. Case 1: \(a_j = a_m\) → 이미 \(a_m\)이 최적해에 있으므로 증명 완료. ✓
  3. Case 2: \(a_j \ne a_m\) → \(f_m \le f_j\) (\(a_m\)은 전체에서 가장 이른 finish time)
    • Cut: \(A_k\)에서 \(a_j\)를 제거한다.
    • Paste: \(a_m\)을 삽입하여 \(A'_k = (A_k - \{a_j\}) \cup \{a_m\}\)을 구성한다.
    • \(f_m \le f_j\)이므로, \(A_k\)에서 \(a_j\)와 compatible했던 모든 활동은 \(a_m\)과도 compatible.
    • \(A'_k\)의 활동들은 여전히 disjoint → \(|A'_k| = |A_k|\).
    • \(A'_k\)는 \(a_m\)을 포함하는 최대 크기 해. ∎

1.3.3 DP → Greedy 전환의 의미

Note부분 문제 공간의 축소
DP Greedy
부분 문제 형태 \(S_{ij}\) (양쪽 경계 가변) \(S_k\) (왼쪽 경계 고정)
부분 문제 수 \(\Theta(n^2)\) \(\Theta(n)\)
각 문제당 탐색 \(O(n)\)개의 \(k\) 후보 탐색 항상 하나의 \(a_m\) 선택
전체 복잡도 \(\Theta(n^3)\) \(\Theta(n)\)

Greedy 선택이 성립하면 하위 문제가 1개로 고정되므로, DP의 “어떤 \(k\)를 선택할 것인가”라는 탐색 자체가 불필요해진다. 이것이 \(\Theta(n^3) \to \Theta(n)\) 개선의 본질이다.

1.3.4 RECURSIVE-ACTIVITY-SELECTOR

RECURSIVE-ACTIVITY-SELECTOR(s, f, k, n)
1  m = k + 1
2  while m ≤ n and s[m] < f[k]    // a_k 이후에 시작하는 첫 활동 탐색
3      m = m + 1
4  if m ≤ n
5      return {a_m} ∪ RECURSIVE-ACTIVITY-SELECTOR(s, f, m, n)
6  else
7      return ∅
  • 초기 호출: RECURSIVE-ACTIVITY-SELECTOR(s, f, 0, n) (가상 활동 \(a_0\), \(f_0 = 0\))
  • 시간 복잡도: \(\Theta(n)\) — 각 활동이 정확히 한 번만 검사된다.
  • Greedy 선택 후 남는 하위 문제가 항상 하나이므로 꼬리 재귀 → 반복문으로 변환 가능.

1.3.5 실행 예시

활동 테이블 (finish time 기준 정렬):

\(k\) \(s_k\) \(f_k\)
0 — 0 (dummy)
1 1 4
2 3 5
3 0 6
4 5 7
5 3 8
6 5 9
7 6 10
8 8 11
9 8 12
10 2 13
11 12 14

실행 흐름:

  • \(k=0\), \(m=1\): \(s[1]=1 \ge f[0]=0\) → \(a_1\) 선택
  • \(k=1\), \(m=4\): \(s[2]=3 < 4\), \(s[3]=0 < 4\) skip → \(s[4]=5 \ge 4\) → \(a_4\) 선택
  • \(k=4\), \(m=8\): \(s[5..7] < 7\) skip → \(s[8]=8 \ge 7\) → \(a_8\) 선택
  • \(k=8\), \(m=11\): \(s[9..10] < 11\) skip → \(s[11]=12 \ge 11\) → \(a_{11}\) 선택

결과: \(\{a_1, a_4, a_8, a_{11}\}\) — 크기 4, 최적해 ✓

2 Greedy vs DP — 설계 원칙

2.1 Greedy 알고리즘 설계 3단계

TipSteps of Designing Greedy Algorithms (CLRS)
  1. Optimal Substructure 파악: 최적해가 하위 문제의 최적해를 포함함을 증명 (Cut-and-Paste).
  2. Greedy Choice가 항상 안전함을 증명: 탐욕적 선택을 포함하는 최적해가 존재함을 보임 (Cut-and-Paste).
  3. Optimal Substructure 재확인: Greedy 선택 + 하위 문제 최적해 = 전체 최적해임을 확인.

2.2 DP와 Greedy의 근본적 차이

측면 Dynamic Programming Greedy
선택 시점 하위 문제를 먼저 풀고 선택 선택 먼저, 이후 하위 문제 해결
진행 방향 Bottom-up (작은 것 → 큰 것) Top-down (큰 것 먼저 결정)
의존성 선택이 하위 문제 결과에 의존 선택이 미래 하위 문제에 독립
남는 하위 문제 수 다수 항상 1개
Warning중요한 구분

탐욕적 선택은 “지금까지의 선택”에는 의존할 수 있지만, 미래 하위 문제의 해에는 절대 의존하지 않는다. 이것이 Greedy의 본질이다.

3 Knapsack — Greedy가 실패하는 사례

3.1 0-1 Knapsack

각 물건을 통째로만 선택하거나 포기한다.

\[c[i, w] = \begin{cases} 0 & \text{if } i=0 \text{ or } w=0 \\ c[i-1, w] & \text{if } w_i > w \\ \max\bigl(v_i + c[i-1,\, w-w_i],\; c[i-1,\, w]\bigr) & \text{if } i>0 \text{ and } w \ge w_i \end{cases}\]

DP-KNAPSACK(n, W)
1  for w = 0 to W
2      C[0, w] = 0
3  for i = 1 to n
4      for w = 0 to W
5          if w[i] ≤ w
6              C[i, w] = max{C[i-1, w], v[i] + C[i-1, w-w[i]]}
7          else
8              C[i, w] = C[i-1, w]
9  return C[n, W]

복잡도: \(\Theta(nW)\) (pseudo-polynomial)

3.2 Fractional Knapsack

물건을 분할하여 일부만 선택 가능하다.

Greedy 전략: 단위 무게당 가치 \(v_i/w_i\)가 가장 높은 물건부터 최대한 채운다.

복잡도: \(O(n \lg n)\) (정렬 후 탐욕적 선택)

3.3 예제: 왜 0-1 Knapsack에서 Greedy가 실패하는가?

물건: 물건 1 (\(w=10\), \(v=\$60\), \(v/w=6\)), 물건 2 (\(w=20\), \(v=\$100\), \(v/w=5\)), 물건 3 (\(w=30\), \(v=\$120\), \(v/w=4\)). 가방 용량: \(W=50\).

전략 선택 총 가치
Greedy (단위가치 순) — 0-1 물건 1 + 물건 2 = 30lb $160
최적 DP 물건 1 + 물건 2 = 30lb $220
Fractional Greedy 물건 1 + 물건 2 + 물건 3의 \(\frac{20}{30}\) $240
WarningGreedy 실패의 원인

0-1 Knapsack에서는 물건을 통째로만 선택해야 하므로, 큰 물건을 선택하면 남은 공간이 낭비될 수 있다. 선택과 잔여 공간 활용이 서로 의존적이어서 Greedy Choice Property가 깨진다.

두 문제 모두 Optimal Substructure는 성립하지만, Greedy Choice Property는 Fractional에서만 성립한다.

3.4 DP 테이블 트레이스

물건: \((w_1=1, v_1=60)\), \((w_2=2, v_2=100)\), \((w_3=3, v_3=120)\). 용량: \(W=5\).

\(i \backslash w\) 0 1 2 3 4 5
0 0 0 0 0 0 0
1 (\(w=1\), \(v=60\)) 0 60 60 60 60 60
2 (\(w=2\), \(v=100\)) 0 60 100 160 160 160
3 (\(w=3\), \(v=120\)) 0 60 100 160 180 220

최종 답: \(c[3,5] = \$220\)

4 Huffman Codes

4.1 문제 배경

알파벳 \(C\)의 각 문자 \(c\)는 출현 빈도 \(c.\text{freq}\)를 가진다. 목표는 전체 파일의 인코딩 비트 수를 최소화하는 prefix-free binary code를 설계하는 것이다.

예제 (100자 파일, 6종 문자):

문자 빈도 고정 길이 (3비트) 가변 길이 (Huffman)
a 45 000 0
b 13 001 101
c 12 010 100
d 16 011 111
e 9 100 1101
f 5 101 1100
  • 고정 길이: \(100 \times 3 = 300\)비트
  • 가변 길이: \(45{\cdot}1 + 13{\cdot}3 + 12{\cdot}3 + 16{\cdot}3 + 9{\cdot}4 + 5{\cdot}4 = 224\)비트 (약 25% 절감)

4.2 Prefix-free Code와 Binary Trie

어떤 코드워드도 다른 코드워드의 prefix가 되지 않는 코드

  • 각 잎(leaf): 문자
  • 루트 → 잎의 경로: 해당 문자의 코드워드
  • 왼쪽 간선 = 0, 오른쪽 간선 = 1
NoteFull Binary Tree 성질

최적 코드는 항상 full binary tree(모든 내부 노드가 두 자식을 가짐)로 표현된다.

\(|C| = n\)일 때: 잎 \(n\)개, 내부 노드 \(n-1\)개.

4.3 비용 함수 \(B(T)\)

\[B(T) = \sum_{c \in C} c.\text{freq} \cdot d_T(c)\]

\(d_T(c)\): 트리 \(T\)에서 문자 \(c\) 잎의 깊이 (= 코드 길이). 목표: \(B(T)\) 최소화.

4.4 HUFFMAN 알고리즘

Greedy 선택: 항상 빈도가 가장 낮은 두 노드를 결합하여 새 내부 노드를 만든다.

HUFFMAN(C)
1  n = |C|
2  Q = C                          // min-priority queue (빈도 기준)
3  for i = 1 to n-1
4      allocate new node z
5      z.left  = x = EXTRACT-MIN(Q)
6      z.right = y = EXTRACT-MIN(Q)
7      z.freq = x.freq + y.freq
8      INSERT(Q, z)
9  return EXTRACT-MIN(Q)          // 트리의 루트 반환

복잡도: BUILD-MIN-HEAP \(O(n)\) + 루프 \((n-1)\)번 × 힙 연산 \(O(\lg n)\) = \(O(n \lg n)\)

4.5 알고리즘 실행 트레이스

초기 min-heap: \([\text{f:5},\ \text{e:9},\ \text{c:12},\ \text{b:13},\ \text{d:16},\ \text{a:45}]\)

단계 결합 새 노드 힙 상태
1 f(5) + e(9) 14 [c:12, b:13, 14, d:16, a:45]
2 c(12) + b(13) 25 [14, d:16, 25, a:45]
3 14 + d(16) 30 [25, 30, a:45]
4 25 + 30 55 [a:45, 55]
5 a(45) + 55 100 [100] → root

최종 코드 및 비용 검증:

\[B(T) = 45{\cdot}1 + 12{\cdot}3 + 13{\cdot}3 + 16{\cdot}3 + 5{\cdot}4 + 9{\cdot}4 = 224 \text{비트} \checkmark\]

4.6 정당성 증명

4.6.1 Lemma 16.2 — Greedy Choice Property

ImportantLemma 16.2

알파벳 \(C\)에서 빈도가 가장 낮은 두 문자 \(x\), \(y\)가 존재한다면, \(C\)의 최적 prefix-free 코드 트리에서 \(x\)와 \(y\)는 최대 깊이의 형제 잎으로 배치된 최적 트리가 존재한다.

증명 (Cut-and-Paste):

  1. \(T\): 임의의 최적 트리. \(T\)에서 최대 깊이를 가진 형제 잎 쌍 \(a\), \(b\)를 찾자. WLOG \(f[a] \le f[b]\), \(f[x] \le f[y]\)로 가정.
  2. \(f[x] \le f[a]\), \(f[y] \le f[b]\) (\(x\), \(y\)가 최소 빈도이므로).
  3. Paste 1 — \(T\)에서 \(a\)와 \(x\)를 교환하여 \(T'\) 구성: \[B(T) - B(T') = (f[a] - f[x])(d_T(a) - d_T(x)) \ge 0\] 두 인수 모두 \(\ge 0\) (\(f[a] \ge f[x]\)이고 \(d_T(a) \ge d_T(x)\)) → \(B(T') \le B(T)\)
  4. Paste 2 — \(T'\)에서 \(b\)와 \(y\)를 교환하여 \(T''\) 구성: \[B(T') - B(T'') = (f[b] - f[y])(d_{T'}(b) - d_{T'}(y)) \ge 0\] → \(B(T'') \le B(T') \le B(T)\)
  5. \(T\)가 최적이므로 \(B(T) \le B(T'')\). 두 조건 합쳐 \(B(T) = B(T'')\). \(T''\)는 \(x\), \(y\)가 최대 깊이의 형제인 최적해. ∎
Tip직관

“가장 빈도가 낮은 두 문자를 트리의 어떤 위치에 배치하더라도, 맨 아래 형제 위치로 교환해도 비용이 나빠지지 않는다.” → 최소 빈도 두 개를 먼저 합치는 Greedy 선택이 항상 안전.

4.6.2 Lemma 16.3 — Optimal Substructure

ImportantLemma 16.3

\(x\), \(y\)를 \(C\)에서 최소 빈도인 두 문자라 하자. \(f[z] = f[x] + f[y]\)인 새 문자 \(z\)를 도입하고, \(C' = C - \{x, y\} \cup \{z\}\)로 정의하자.

\(T'\)이 \(C'\)의 최적 prefix-free 코드 트리이면, \(T'\)에서 \(z\)의 잎을 \(x\), \(y\)를 자식으로 갖는 내부 노드로 확장한 트리 \(T\)는 \(C\)의 최적 prefix-free 코드 트리이다.

핵심 비용 관계식 유도:

\(c \in C - \{x, y\}\)에 대해 \(d_T(c) = d_{T'}(c)\). \(x\), \(y\)에 대해 \(d_T(x) = d_T(y) = d_{T'}(z) + 1\). 따라서:

\[f[x] \cdot d_T(x) + f[y] \cdot d_T(y) = (f[x]+f[y])(d_{T'}(z)+1) = f[z] \cdot d_{T'}(z) + f[x] + f[y]\]

\[\therefore \quad \boxed{B(T) = B(T') + f[x] + f[y]}\]

귀류법 증명:

  1. \(T\)가 \(C\)의 최적이 아니라고 가정 → \(B(T'') < B(T)\)인 \(C\)의 최적 트리 \(T''\) 존재.
  2. Lemma 16.2에 의해 WLOG \(T''\)에서 \(x\), \(y\)는 형제 잎이다.
  3. Cut: \(T''\)에서 \(x\), \(y\)의 공통 부모를 빈도 \(f[z]\)인 잎 \(z\)로 수축하여 \(T'''\) 구성: \[B(T''') = B(T'') - f[x] - f[y]\]
  4. \(B(T'') < B(T) = B(T') + f[x] + f[y]\) 이므로: \[B(T''') < B(T')\]
  5. 이는 \(T'\)이 \(C'\)의 최적이라는 가정에 모순 ∎
