Floyd-Warshall과 Johnson 알고리즘

Published

June 5, 2026

1 문제 설정

방향 그래프 \(G = (V, E)\)와 가중치 함수 \(w : E \to \mathbb{R}\)이 주어졌을 때, 모든 정점 쌍 \(i, j \in V\)에 대해 최단경로 무게 \(\delta(i, j)\)를 구하는 문제를 전 쌍 최단경로(All-Pairs Shortest Paths, APSP) 문제라 한다.

  • 정점은 \(1, 2, \ldots, n\) (\(n = |V|\))으로 번호 매긴다.
  • 그래프는 인접 행렬 \(W = (w_{ij})\)로 표현한다: \[ w_{ij} = \begin{cases} 0 & i = j \\ w(i, j) & i \neq j,\ (i,j) \in E \\ \infty & i \neq j,\ (i,j) \notin E \end{cases} \]
  • 출력은 \(n \times n\) 행렬 \(D = (d_{ij})\)이며 \(d_{ij} = \delta(i, j)\)이다.
Important공통 전제: 음의 가중치 사이클 없음

이 장의 모든 알고리즘은 음의 가중치 사이클이 없다고 가정한다. 음의 사이클이 있으면 그 사이클을 무한히 돌수록 무게가 감소하여 \(\delta(i, j) = -\infty\)가 되므로 최단경로 자체가 정의되지 않는다. 음의 간선은 허용된다. (Johnson 알고리즘은 추가로 음의 사이클을 탐지까지 한다.)

1.1 예측자 행렬

경로 복원을 위해 예측자 행렬 \(\Pi = (\pi_{ij})\)를 함께 관리한다. \(\pi_{ij}\)는 \(i \rightsquigarrow j\) 최단경로 상에서 \(j\)의 직전 정점이며, \(i = j\)이거나 경로가 없으면 \(\text{NIL}\)이다. \(\Pi\)의 \(i\)번째 행이 유도하는 부분그래프는 근(root)이 \(i\)인 최단경로 트리가 된다.

2 두 DP 접근의 조망과 핵심 차이

APSP는 서로 다른 두 가지 DP 설계로 풀 수 있다. 둘 다 동일한 최적 부분구조(Lemma 24.1)에 기대지만, 부분문제를 무엇으로 매개변수화하느냐가 다르며, 바로 이 선택이 복잡도를 결정한다.

행렬곱 기반 (25.1) Floyd-Warshall (25.2)
부분문제 \(\ell_{ij}^{(m)}\): 간선 수 \(\le m\)인 \(i\to j\) 최단 무게 \(d_{ij}^{(k)}\): 경유지가 \(\{1,\dots,k\}\)인 \(i\to j\) 최단 무게
DP 진행 축 경로 길이(간선 수) \(m\) 허용 중간 정점 집합 크기 \(k\)
분해 지점 경로의 마지막 간선 가장 큰 번호의 중간 정점 \(k\)
점화식 \(\ell_{ij}^{(m)} = \min_{1\le k\le n}\{\ell_{ik}^{(m-1)} + w_{kj}\}\) \(d_{ij}^{(k)} = \min(d_{ij}^{(k-1)},\, d_{ik}^{(k-1)}+d_{kj}^{(k-1)})\)
정답 \(L^{(n-1)} = (\delta(i,j))\) \(D^{(n)} = (\delta(i,j))\)
복잡도 \(\Theta(n^4)\), repeated squaring으로 \(\Theta(n^3\lg n)\) \(\Theta(n^3)\)

2.1 왜 복잡도가 갈리는가

복잡도를 셀 단위로 분해하면 다음과 같다.

\[ \text{총 시간} = (\text{축의 단계 수}) \times (\text{셀 개수 } n^2) \times (\text{셀당 작업량}) \]

단계 수 셀당 작업 총합
행렬곱 (naive) \(m = 1 \ldots n{-}1\), 즉 \(\Theta(n)\) \(\min\) over \(k\), 즉 \(\Theta(n)\) \(\Theta(n^4)\)
Floyd-Warshall \(k = 1 \ldots n\), 즉 \(\Theta(n)\) 이진 \(\min\), 즉 \(\Theta(1)\) \(\Theta(n^3)\)

두 방식 모두 축은 \(n\)번 돈다. 결정적 차이는 셀당 작업량이다.

  • 행렬곱은 “마지막 간선”에서 자르는데, \(j\)의 직전 정점 후보가 \(n\)개이므로 셀마다 \(n\)중 \(\min\)을 치른다 \(\Rightarrow n^4\).
  • Floyd-Warshall은 분해 지점이 지정된 정점 \(k\)이므로, 셀마다 “\(k\)를 쓰거나/안 쓰거나”의 이진 선택만 한다 \(\Rightarrow n^3\).
TipRepeated squaring이 줄이는 것은 ’단계 수’뿐

행렬곱 점화식 \(\ell_{ij}^{(m)} = \min_k\{\ell_{ik}^{(m-1)} + w_{kj}\}\)은 \((\min, +)\) 반환(tropical semiring) 위의 행렬 곱셈이다. 원소 결합 연산 \(+\)가 \(\min\)으로, \(\times\)가 \(+\)로 대응된다.

이 곱은 결합법칙이 성립하고, \(m \ge n{-}1\)이면 행렬이 고정점에 도달(\(L^{(m)} = L^{(n-1)}\))한다. 따라서 한 간선씩 늘리는 대신 경로 길이를 두 배씩 늘리면(\(W \to W^{(2)} \to W^{(4)} \to \cdots\)) \(\lceil \lg(n{-}1)\rceil\)번의 제곱으로 충분하다 \(\Rightarrow \Theta(n^3 \lg n)\).

그러나 줄어든 것은 단계 수(\(n \to \lg n\))뿐이고, 한 번의 행렬 곱은 여전히 \(\Theta(n^3)\)(셀마다 \(n\)중 \(\min\))이다. 마지막 간선의 후보가 본질적으로 \(n\)개이므로 그 \(O(n)\)을 없앨 수 없다. 반면 Floyd-Warshall은 분해 지점을 지정함으로써 그 \(O(n)\) 자체를 \(O(1)\)로 제거했고, 따라서 \(\lg n\) 인자 없이 \(n^3\)이다.

3 Floyd-Warshall 알고리즘

3.1 중간 정점과 \(\{1,\ldots,k\}\) 매개변수화

경로 \(p = \langle v_1, \ldots, v_l\rangle\)의 중간 정점(intermediate vertex)은 양 끝점을 제외한 \(\{v_2, \ldots, v_{l-1}\}\)이다.

핵심 부분문제 정의: \[ d_{ij}^{(k)} = \text{중간 정점이 모두 } \{1,\ldots,k\}\text{에 속하는 } i \rightsquigarrow j \text{ 최단경로의 무게} \]

Note오해 방지: 무엇이 제한되는가

\(\{1,\ldots,k\}\)는 경로의 끝점 후보가 아니다. 끝점 \(i, j\)는 여전히 전체 \(V\) 어디든 될 수 있다. 제한되는 것은 오직 경유지(중간 정점)다. 즉 \(d_{ij}^{(k)}\)는 “\(i\)에서 \(j\)로 가되, 경유지로는 \(1\)번부터 \(k\)번 정점까지만 써도 되는 최단경로 무게”다.

\(k\)는 DP의 진행 축이며, “허용된 경유지 범위”를 0부터 \(n\)까지 한 칸씩 키우는 손잡이로 이해하면 직관이 분명해진다.

\(k\) 허용 경유지 \(d_{ij}^{(k)}\)의 의미
\(0\) \(\varnothing\) 경유지 없음 = 직접 간선뿐. \(d_{ij}^{(0)} = w_{ij}\)
\(1\) \(\{1\}\) 정점 1만 경유 가능
\(\vdots\) \(\vdots\) \(\vdots\)
\(n\) \(V\) 전체 모든 정점 경유 가능 = 진짜 최단경로. \(d_{ij}^{(n)} = \delta(i,j)\)

3.2 최적 부분구조와 점화식 유도

\(\{1,\ldots,k\}\)를 경유지로 허용한 최단경로 \(p\) (\(i \rightsquigarrow j\))에 대해, \(k\)가 \(p\)의 중간 정점인지 여부로 경우를 나눈다.

Case 1 — \(k\)가 중간 정점이 아님. 그러면 \(p\)의 모든 중간 정점은 \(\{1,\ldots,k-1\}\)에 속하므로 \[ d_{ij}^{(k)} = d_{ij}^{(k-1)}. \]

Case 2 — \(k\)가 중간 정점임. \(p\)를 \(k\)에서 분할한다: \(i \overset{p_1}{\rightsquigarrow} k \overset{p_2}{\rightsquigarrow} j\).

ImportantLemma 24.1 (부분경로 최적성)의 Cut-and-Paste 적용

\(p_1\)이 \(i \rightsquigarrow k\)의 최단경로가 아니라고 가정하자. 그러면 더 짧은 \(p_1'\)이 존재하고, \(p_1'\)을 잘라 붙여(cut-and-paste) \(p_1' + p_2\)를 만들면 \[ w(p_1' + p_2) = w(p_1') + w(p_2) < w(p_1) + w(p_2) = w(p) \] 이 되어 \(p\)가 \(i \rightsquigarrow j\) 최단경로라는 가정에 모순이다. 따라서 \(p_1\)은 최단경로이며, \(p_2\)도 대칭적으로 동일하다.

\(p\)가 단순경로이므로 \(k\)는 한 번만 등장하고, \(p_1\)과 \(p_2\)의 중간 정점은 각각 \(\{1,\ldots,k-1\}\)에 속한다(\(k\)는 양쪽에서 끝점). 그러므로 \[ d_{ij}^{(k)} = d_{ik}^{(k-1)} + d_{kj}^{(k-1)}. \]

3.3 미묘한 지점: \(p_1\)과 \(p_2\)가 노드 \(x\)를 공유하는 경우

점화식의 둘째 항 \(d_{ik}^{(k-1)} + d_{kj}^{(k-1)}\)은 DP 표의 서로 다른 두 칸에서 따로 최적화된 두 반쪽을 이어 붙인다. 두 반쪽이 같은 정점 \(x\)를 지나지 말라는 보장이 없으므로, 이어 붙인 결과가 \(i \rightsquigarrow x \rightsquigarrow k \rightsquigarrow x \rightsquigarrow j\) 형태의 비단순 보행일 수 있다. 이때 \(x \to k \to x\) 사이클이 생기고 \(k\)는 그 사이클 위에 놓인다.

Warning왜 이 경우를 따져야 하는가

우리는 \(d_{ij}^{(k)}\)를 단순경로의 최단 무게로 정의했다. 점화식이 비단순 보행에 해당하는 값을 내놓을 수 있다면, 정의와 어긋나 점화식의 정당성이 위협받는다. 따라서 이 경우는 “쓰고 싶어서”가 아니라 점화식의 구멍을 막기 위해 반드시 검토해야 한다.

무해함의 증명. 사이클 \(x \to k \to x\)의 무게를 \(W_{\text{cycle}}\)이라 하자. 음의 사이클이 없으므로 \(W_{\text{cycle}} \ge 0\)이다. 따라서 그 사이클(즉 \(k\)를 경유하는 부분)을 잘라내면 \(i \rightsquigarrow x \rightsquigarrow j\)만 남고, 이는 \(k\)를 거치지 않으므로 경유지가 \(\{1,\ldots,k-1\}\)뿐이며 무게는 같거나 작다: \[ \underbrace{d_{ik}^{(k-1)} + d_{kj}^{(k-1)}}_{k\text{ 경유, } x\text{ 중복}} \;\ge\; \underbrace{d_{ij}^{(k-1)}}_{k\text{ 미경유}}. \] 점화식은 이 둘의 \(\min\)을 취하므로, 공유가 일어나는 상황에서는 자동으로 “\(k\) 미경유” 항을 택한다. 비단순 보행에 해당하는 값은 결코 답으로 채택되지 않는다.

Tip이 논증이 알려주는 것

두 반쪽이 노드를 공유한다는 것은 “\(k\)를 거치는 게 손해(불필요한 사이클)”라는 신호이며, 음의 사이클이 없으므로 \(\min\)이 알아서 걸러낸다. 그래서 점화식을 쓸 때 “\(p_1, p_2\)가 \(k\) 외에는 서로소”라고 안심하고 가정할 수 있다. 음의 사이클이 있었다면(\(W_{\text{cycle}} < 0\)) 이 분해가 무너진다 — Floyd-Warshall이 음의 사이클을 전제에서 배제하는 이유가 바로 이 분해의 정당성에 직결되어 있다.

3.4 점화식, 의사코드, 복잡도

\[ d_{ij}^{(k)} = \begin{cases} w_{ij} & k = 0 \\[4pt] \min\!\big(d_{ij}^{(k-1)},\; d_{ik}^{(k-1)} + d_{kj}^{(k-1)}\big) & k \ge 1 \end{cases} \]

FLOYD-WARSHALL(W)
1  n = W.rows
2  D⁽⁰⁾ = W
3  for k = 1 to n
4      let D⁽ᵏ⁾ = (dᵢⱼ⁽ᵏ⁾) be a new n×n matrix
5      for i = 1 to n
6          for j = 1 to n
7              dᵢⱼ⁽ᵏ⁾ = min( dᵢⱼ⁽ᵏ⁻¹⁾ , dᵢₖ⁽ᵏ⁻¹⁾ + dₖⱼ⁽ᵏ⁻¹⁾ )
8  return D⁽ⁿ⁾

3중 루프, 7행이 \(O(1)\)이므로 전체 시간은 \(\Theta(n^3)\), 공간은 명시 행렬을 쓰면 \(\Theta(n^3)\)이지만 아래 in-place 갱신으로 \(\Theta(n^2)\)로 줄일 수 있다.

3.5 in-place 갱신의 정당성

\(D^{(k)}\)를 매번 새로 만들 필요 없이 \(n \times n\) 행렬 하나를 제자리에서 갱신해도 정답이 나온다. 7행에서 참조하는 \(d_{ik}\)와 \(d_{kj}\)는 \(k\)번 행·열에 속하는데, 해당 반복에서 이 값들은 변하지 않기 때문이다: \[ d_{ik}^{(k)} = \min\big(d_{ik}^{(k-1)},\ d_{ik}^{(k-1)} + d_{kk}^{(k-1)}\big) = d_{ik}^{(k-1)} \quad (d_{kk}^{(k-1)} \ge 0), \] 마찬가지로 \(d_{kj}^{(k)} = d_{kj}^{(k-1)}\). 따라서 제자리 갱신이 이미 덮어쓴 \(k\)행·열 값을 참조해도 옳은 값(\(k{-}1\) 단계 값과 동일)을 읽는다. (음의 사이클이 없어 \(d_{kk} \ge 0\)이라는 점이 여기서도 쓰인다.)

3.6 예측자 행렬 갱신

기저 (\(k = 0\)): \[ \pi_{ij}^{(0)} = \begin{cases} \text{NIL} & i = j \text{ 또는 } w_{ij} = \infty \\ i & i \neq j \text{ 그리고 } w_{ij} < \infty \end{cases} \]

귀납 (\(k \ge 1\)): \(\min\)이 어느 쪽을 택했는지에 따라 예측자를 물려받는다. \[ \pi_{ij}^{(k)} = \begin{cases} \pi_{ij}^{(k-1)} & d_{ij}^{(k-1)} \le d_{ik}^{(k-1)} + d_{kj}^{(k-1)} \\[4pt] \pi_{kj}^{(k-1)} & d_{ij}^{(k-1)} > d_{ik}^{(k-1)} + d_{kj}^{(k-1)} \end{cases} \]

직관: \(k\)를 경유하기로 했다면 \(j\)의 직전 정점은 “\(k\)에서 \(j\)로 가는 경로”에서의 직전 정점과 같으므로 \(\pi_{kj}^{(k-1)}\)을 따른다.

4 Johnson 알고리즘

4.1 동기: Reweighting

음의 간선이 없다면 각 정점에서 Dijkstra를 \(|V|\)회 돌리는 것이 가장 빠르다. 문제는 음의 간선이 있으면 Dijkstra가 작동하지 않는다는 점이다. Johnson의 아이디어는 음의 간선을 비음수로 재가중(reweight)하되 최단경로 구조는 보존하여 Dijkstra를 쓸 수 있게 만드는 것이다.

요구 성질 두 가지:

  1. 경로 보존: 모든 쌍 \(u, v\)에 대해, \(p\)가 \(w\) 하 최단경로 \(\iff\) \(\hat{w}\) 하 최단경로.
  2. 비음수성: 모든 간선에서 \(\hat{w}(u, v) \ge 0\) (Dijkstra 적용 가능).

4.2 Lemma 25.1: Reweighting이 최단경로를 보존함

각 정점에 함수 \(h : V \to \mathbb{R}\)를 주고 \[ \hat{w}(u, v) = w(u, v) + h(u) - h(v) \] 로 정의한다.

ImportantLemma 25.1

임의의 경로 \(p = \langle v_0, v_1, \ldots, v_k\rangle\)에 대해 다음이 성립한다.

(a) 무게의 텔레스코핑. \[ \hat{w}(p) = \sum_{i=1}^{k}\big(w(v_{i-1},v_i) + h(v_{i-1}) - h(v_i)\big) = w(p) + h(v_0) - h(v_k). \] 중간 \(h\) 항들이 연쇄적으로 상쇄되므로, 보정항 \(h(v_0) - h(v_k)\)는 경로의 양 끝점에만 의존하고 같은 끝점을 잇는 모든 경로에 동일하게 더해진다.

(b) 경로 보존 (귀류법). \(w(p) = \delta(v_0, v_k)\)라 하고 \(\hat{w}(p) = \hat{\delta}(v_0, v_k)\)임을 보인다. 어떤 \(p'\)이 \(\hat{w}(p') < \hat{w}(p)\)라 가정하면, \[ w(p') + h(v_0) - h(v_k) < w(p) + h(v_0) - h(v_k) \] 에서 양변의 \(h(v_0) - h(v_k)\)를 소거하여 \(w(p') < w(p)\)를 얻는데, 이는 \(p\)가 \(w\) 하 최단경로라는 가정에 모순이다. 역방향도 대칭적이다.

(c) 음의 사이클 보존. 사이클 \(c\)(\(v_0 = v_k\))에서는 \(h(v_0) - h(v_k) = 0\)이므로 \(\hat{w}(c) = w(c)\). 따라서 음의 사이클의 존재 여부가 재가중으로 바뀌지 않는다.

4.3 비음수성 보장: \(h(v) = \delta(s, v)\)

성질 1(경로 보존)은 어떤 \(h\)를 써도 성립한다. 이제 성질 2(\(\hat{w} \ge 0\))를 만족하는 \(h\)를 구성한다.

구성.

  • 새 정점 \(s\)를 추가: \(V' = V \cup \{s\}\).
  • \(s\)에서 모든 정점으로 무게 0 간선 추가: \(w(s, v) = 0\). (\(s\)로 들어오는 간선은 없으므로 \(s\)는 어떤 최단경로의 중간 정점도 되지 않아 원래 구조를 해치지 않는다.)
  • \(G'\)에서 Bellman-Ford로 \(h(v) = \delta(s, v)\)를 계산한다.
Important비음수성 증명 (삼각부등식)

\(h(v) = \delta(s, v)\)이므로 Lemma 24.10 (삼각부등식)에 의해 모든 간선 \((u, v) \in E'\)에서 \[ \delta(s, v) \le \delta(s, u) + w(u, v), \quad\text{즉}\quad h(v) \le h(u) + w(u, v). \] 정리하면 \[ \hat{w}(u, v) = w(u, v) + h(u) - h(v) \ge 0. \qquad \blacksquare \]

Bellman-Ford가 음의 사이클을 보고하면 \(G'\)(따라서 \(G\))에 음의 사이클이 있다는 뜻이므로 그대로 보고하고 종료한다.

4.4 의사코드와 복잡도

JOHNSON(G, w)
1  G' 구성: V' = V ∪ {s}, E' = E ∪ {(s,v) : v ∈ V}, w(s,v) = 0
2  if BELLMAN-FORD(G', w, s) == FALSE
3      print "음의 가중치 사이클이 존재함"
4  else
5      for each v ∈ G'.V
6          h(v) = δ(s, v)                      # Bellman-Ford 결과
7      for each edge (u, v) ∈ G'.E
8          ŵ(u, v) = w(u, v) + h(u) − h(v)
9      let D = (d_uv) be a new n×n matrix
10     for each vertex u ∈ G.V
11         run DIJKSTRA(G, ŵ, u) to compute δ̂(u, v) for all v
12         for each vertex v ∈ G.V
13             d_uv = δ̂(u, v) + h(v) − h(u)    # 원래 무게로 복원
14     return D

13행의 복원은 텔레스코핑 관계 \(\hat{\delta}(u, v) = \delta(u, v) + h(u) - h(v)\)를 역으로 풀어 \(\delta(u, v) = \hat{\delta}(u, v) + h(v) - h(u)\)를 얻는 것이다. (8행의 \(+h(u)-h(v)\)와 13행의 \(+h(v)-h(u)\)가 정확히 상쇄됨에 유의.)

복잡도. Bellman-Ford \(O(|V||E|)\) + Dijkstra(피보나치 힙) \(|V|\)회 \(= |V| \cdot O(|V|\lg|V| + |E|)\). 후자가 지배하여 전체 \[ O(|V|^2 \lg|V| + |V||E|). \] Sparse graph(\(|E| = O(|V|)\))에서는 \(O(|V|^2 \lg|V|)\)로, Floyd-Warshall의 \(\Theta(|V|^3)\)보다 빠르다.

두 증명적 하이라이트로 정리한다.

  • Floyd-Warshall은 “중간 정점 집합 \(\{1,\ldots,k\}\)”라는 DP 차원 위에서 Lemma 24.1(부분경로 최적성)을 cut-and-paste로 적용하며, 분해 지점을 정점 \(k\)로 지정함으로써 셀당 작업을 \(O(1)\)로 만든다. 공유 노드 \(x\)로 인한 비단순 보행은 음의 사이클 부재 덕에 \(\min\)이 무해하게 걸러낸다.
  • Johnson은 텔레스코핑으로 보정항을 양 끝점에만 가둔 뒤 귀류법으로 최단성을 보존하고, \(h(v) = \delta(s, v)\)와 삼각부등식으로 비음수성을 끌어낸다.
