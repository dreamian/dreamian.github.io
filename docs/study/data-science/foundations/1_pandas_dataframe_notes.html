Key Points of Pandas DataFrame Processing

Boolean indexing · apply · String processing · explode · groupby/transform

Published

July 17, 2026

import pandas as pd
import numpy as np

url = 'https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv'
df_titanic = pd.read_csv(url)
df_titanic.head(3)

1 Missing Value Detection and Boolean Indexing

1.1 notna() / isna()

notna() returns a Boolean Series where True if each element is not missing (NaN), and isna() if it is not. A Boolean Series functions as a “row filter” itself.

df_titanic['Embarked'].isna().sum()   # True의 합 = 결측 개수

1.2 .loc in Series — 1 argument

Since the Series is one-dimensional, only one row selector is entered into .loc.

x = df_titanic['Embarked']
x.loc[x.notna()].unique()             # 결측 제거 후 유일값

1.3 .loc[행, 열] in DataFrame — 2 arguments

Since DataFrames are 2-dimensional, row selectors and column selectors are specified simultaneously with a comma.

df_titanic.loc[df_titanic['Cabin'].notna(), 'Cabin'].head()

The return type varies depending on the form of the column selector.

Column Selector Yes Return
Single string .loc[cond, 'Cabin'] Series
List .loc[cond, ['Name', 'Sex']] DataFrame
Label Slice .loc[cond, 'Pclass':'Cabin'] DataFrame (Ends Included)
Omit or : .loc[cond] All columns
ImportantValue assignment must be .loc[행, 열] = 값

Chained indexing in the form of df['col'][cond] = 값 is a common cause of bugs where assignments can be applied to copies and the original is not changed. Specifying coordinates with a single .loc call is the standard pattern.

df2 = df_titanic.copy()
df2.loc[df2['Embarked'].isna(), 'Embarked'] = df2['Embarked'].mode()[0]
df2['Embarked'].isna().sum()

Compound conditions are combined as & and |, but each condition is enclosed in parentheses (because & has higher precedence than comparison operators).

df_titanic.loc[
    (df_titanic['Sex'] == 'female') & (df_titanic['Pclass'] == 1),
    'Survived'
].mean()

2 apply — Column-by-column iteration

If you use apply(func) in a DataFrame, the default value is axis=0, and each column is passed sequentially to the function as a Series. Logically, this is equivalent to iterating through columns with a for loop, but it automatically combines the results into a single object.

df_titanic[['Survived', 'Pclass', 'Sex', 'Embarked']].apply(
    lambda x: x.loc[x.notna()].unique().tolist()
)

If the function returns a scalar, the result is a Series; if it returns an object like a list, it becomes a “Series whose values are lists”.

Tipapply + pd.Series = one column into multiple columns

When applying apply to a Series and Lambda returns pd.Series, pandas uses that index as a column name and assembles the result into a DataFrame.

df_titanic.loc[df_titanic['Cabin'].notna(), 'Cabin'].str.split(' ')\
    .explode()\
    .apply(
        lambda x: pd.Series((x[:1], x[1:]), index=['Cabin_Type', 'Cabin_No'])
    ).head()

Using x[:1] instead of x[0] returns an empty string without IndexError, making slicing more defensive.

Also keep in mind that if there is a vectorized alternative, that is concise and faster.

# apply 버전:  .apply(lambda x: x.isna().sum())
df_titanic[['Age', 'Cabin', 'Embarked']].isna().sum()   # 벡터화 버전

3 .str Accessor — String Batch Processing

.str vectorizes and applies string methods to each string element of the Series. When extracting elements from the result (a Series of lists) of split, append .str[i].

# "성, 호칭. 이름" 형식에서 호칭만 추출
title = df_titanic['Name'].str.split(', ').str[1].str.split('.').str[0]
title.value_counts().head()
Warning.str.split / .str.rsplit’s n is a keyword-only argument

Pure Python strings accept positional arguments like 'A/5 21171'.rsplit(' ', 1), but the pandas .str accessor signature is rsplit(pat=None, *, n=-1, expand=False), which accepts arguments following * as keywords only.

s.str.rsplit(' ', 1)     # TypeError!
s.str.rsplit(' ', n=1)   # OK

The “3 were given” in the error message is because self is automatically passed as the first positional argument. The reason apply(lambda x: x.rsplit(' ', 1)) works is that x inside the lambda is an individual Python string rather than a Series.

Since rsplit(' ', n=1) divides only once from the right, the last piece (number) is preserved even in values like 'STON/O 2. 3101282', which have a space in the prefix.

4 explode — Reconstruction of observation units

Standard aggregate operations cannot be used when multiple values are grouped in a single cell (“C23 C25 C27”). explode expands each element of the list into a separate row to create “one cell = one value”.

cabin_exploded = df_titanic.loc[df_titanic['Cabin'].notna(), 'Cabin']\
    .str.split(' ')\
    .explode()
cabin_exploded.loc[[27]]    # 인덱스 27: 객실 3개 → 행 3개

Two key properties:

  1. Indexes are duplicated — the original row from which each expanded value came is preserved.
  2. Length increases — The unit of observation changes from “passenger” to “cabin”.

5 groupby Deepening

5.1 level=0 — Group by index

When the basis of groupby is in the index rather than the column, use the level argument. level=0 refers to the first layer of the index, and if it is a single index, it means “group as the index itself.” This is a typical combination that restores the index preserved by explode as the group key.

cabins_per_passenger = cabin_exploded.groupby(level=0).size()
cabins_per_passenger.value_counts()   # 객실 개수별 승객 수

size() counts the number of rows in the group, and count() counts the number of non-missing values.

5.2 agg vs transform

It is the same group operation, but the method of returning the result is different.

Calculation Return Type Unit of Observation
agg (median() etc.) Statistics by group Rows equal to number of groups Group
transform Statistics by group Same length/index as original Original row

transform operates in three steps: split → grouped calculation → broadcast ( returning the value of its own group to each row). Conceptually, it is an operation that maps the conditional statistic \(E[Y \mid \text{그룹}]\) to each observation.

df3 = df_titanic.copy()

# 호칭별 나이 중앙값을 각 승객에게 대응시킨 891행 Series
age_median_by_title = df3.groupby(title)['Age'].transform('median')

# .loc 대입은 인덱스 정렬 기반 → 원본과 인덱스가 같아야 결측 위치에 정확히 들어간다
df3.loc[df3['Age'].isna(), 'Age'] = age_median_by_title

print(df3['Age'].isna().sum())
print(round(df_titanic['Age'].mean(), 3), '→', round(df3['Age'].mean(), 3))

If the result of agg (a short Series where the index is a name) is passed to the right side, NaN is assigned to everything because the indices do not match. The reason transform is needed is this sorting compatibility.

Typical usage: Group-specific missing data replacement, within-group standardization (x - x.mean()) / x.std(), weight relative to group sum x / x.sum().
