확률론의 기초 (Foundations of Probability Theory) I

Random Signal Theory — 확률, 확률변수, 분포, 기댓값, 확률벡터

Published

July 2, 2026

1 표본공간과 사건

1.1 표본공간 (Sample Space)

표본공간 \(\Omega\)는 어떤 실험(experiment)에서 나올 수 있는 모든 가능한 결과(outcome) \(\omega_i\)의 집합이다.

  • 주사위 던지기: \(\Omega = \{1, 2, 3, 4, 5, 6\}\)
  • 동전 던지기: \(\Omega = \{H, T\}\)
Important

확률론의 모든 개념은 표본공간 위에서 정의된다. 문제를 풀 때 표본공간을 올바르게 설정하는 것이 항상 첫 단계다.

1.2 사건 (Event)

사건은 표본공간의 부분집합으로, 특정 성질을 공유하는 결과들을 모아 놓은 것이다. 불 대수(Boolean algebra)의 법칙에 따라 결합·비교할 수 있다.

  • 예: 주사위에서 “짝수가 나온다”는 사건 \(A = \{2, 4, 6\}\)
Tip직관

사건은 실험에 대한 예/아니오 질문으로 생각할 수 있다: “결과가 이 집합에 속했는가?”

2 집합 연산 법칙

두 사건 \(A\), \(B\)에 대해 다음 연산들이 정의된다. 아래 예제는 공통적으로 \(\Omega = \{1,\dots,6\}\), \(A = \{2,4,6\}\) (짝수), \(B = \{2,3,5\}\) (소수)를 사용한다.

2.1 합집합 (Union)

\[A \cup B = \{\omega : \omega \in A \text{ or } \omega \in B\}\]

\(A\) 또는 \(B\) 중 적어도 하나가 일어나는 사건.

  • 예: \(A \cup B = \{2, 3, 4, 5, 6\}\)

2.2 교집합 (Intersection)

\[A \cap B = \{\omega : \omega \in A \text{ and } \omega \in B\}\]

\(A\)와 \(B\)가 동시에 일어나는 사건.

  • 예: 짝수이면서 소수인 수는 2뿐이므로 \(A \cap B = \{2\}\)

2.3 여집합 (Complement)

\[\bar{A} = \{\omega : \omega \notin A\}\]

표본공간 안에 있으면서 \(A\)에 속하지 않는 모든 결과.

  • 예: \(A = \{2,4,6\}\)이면 \(\bar{A} = \{1, 3, 5\}\)

2.4 드모르간 법칙 (De Morgan’s Law)

\[\overline{A \cup B} = \bar{A} \cap \bar{B}\]

합집합의 여집합은 여집합들의 교집합과 같다.

예제로 검증하기:

단계 계산 결과
1 \(A \cup B\) \(\{2,3,4,5,6\}\)
2 \(\overline{A \cup B}\) \(\{1\}\)
3 \(\bar{A}\) (짝수가 아닌 수) \(\{1,3,5\}\)
4 \(\bar{B}\) (소수가 아닌 수) \(\{1,4,6\}\)
5 \(\bar{A} \cap \bar{B}\) \(\{1\}\)

2단계와 5단계의 결과가 \(\{1\}\)로 일치하므로 드모르간 법칙이 성립함을 확인할 수 있다.

2.5 공집합과 상호배타

  • 공집합(null set) \(\emptyset\): 전체 표본공간의 여집합, 즉 불가능한 사건. 예: 동전 던지기 실험에서 “주사위를 굴려 7이 나온다”는 사건은 절대 일어날 수 없으므로 \(\emptyset\).
  • 상호배타적(mutually exclusive) 사건: \(A \cap B = \emptyset\)이면 두 사건은 동시에 일어날 수 없다. 예: 한 번의 주사위 굴림에서 \(A = \{\text{짝수}\}\), \(B = \{\text{홀수}\}\)는 겹칠 수 없으므로 \(A \cap B = \emptyset\).

2.6 벤 다이어그램 (Venn Diagram)

사각형이 표본공간 \(\Omega\)를, 그 안의 원들이 사건 \(A\), \(B\)를 나타내는 그림이다. 합·교·여집합 같은 집합 연산을 시각적으로 이해하는 데 유용하다.

  • 교집합: 두 원이 겹치는 부분 → \(A \cap B = \{2\}\)
  • 합집합: 두 원을 합친 전체 영역 → \(A \cup B = \{2,3,4,5,6\}\)
  • 여집합: 원 \(A\) 바깥이면서 사각형 안쪽 영역 → \(\bar{A} = \{1,3,5\}\)

3 확률의 공리 (Axioms of Probability)

  1. 비음수성: \(\Pr[A_i] \geq 0\) — 확률은 절대 음수가 될 수 없다.
  2. 정규화: \(\Pr[\Omega] = 1\) — 모든 확률 질량은 표본공간에 집중되어 있으며, 그 바깥에는 아무것도 없다.

이 두 규칙이 확률론 전체의 토대를 이룬다.

3.1 합집합 법칙 (Union Law)

Case 1 — 서로소인 경우 (\(A \cap B = \emptyset\)):

\[\Pr[A \cup B] = \Pr[A] + \Pr[B]\]

Case 2 — 겹치는 경우 (\(A \cap B \neq \emptyset\)):

\[\Pr[A \cup B] = \Pr[A] + \Pr[B] - \Pr[A \cap B]\]

Tip직관

겹치는 경우 \(\Pr[A] + \Pr[B]\)를 그대로 더하면 교집합 부분이 두 번 세어지므로, \(\Pr[A \cap B]\)를 한 번 빼주어야 한다.

4 조건부 확률 (Conditional Probability)

\(\Pr[B] \neq 0\)인 두 사건 \(A\), \(B\)에 대해:

\[\Pr[A \mid B] = \frac{\Pr[A \cap B]}{\Pr[B]}\]

의미: \(B\)가 일어났다는 것을 알았을 때, \(B\) 안에서 \(A\)가 일어날 확률을 측정하는 것이다.

Tip직관

\(B\)를 새로운 표본공간으로 생각하라. \(\Omega\) 전체가 아니라 \(B\)로 “확대(zoom in)”해서, \(B\)를 현재의 우주(universe)로 취급하는 관점이 조건부 확률을 이해하는 가장 쉬운 방법이다.

5 통계적 독립 (Statistical Independence)

\(B\)의 발생이 \(A\)의 확률을 바꾸지 않으면 \(A\)와 \(B\)는 독립이다:

\[\Pr[A \mid B] = \Pr[A]\]

즉, \(B\)가 일어났다는 사실을 알아도 \(A\)에 대한 추가 정보를 전혀 주지 못한다.

5.1 곱셈 규칙 유도

조건부 확률의 정의에서 출발하여:

\[\Pr[A \mid B] = \frac{\Pr[A \cap B]}{\Pr[B]} = \Pr[A] \;\;\Longrightarrow\;\; \Pr[A \cap B] = \Pr[A] \cdot \Pr[B]\]

양변에 \(\Pr[B]\)를 곱하면 독립 사건의 곱셈 규칙이 얻어진다.

Important핵심

“\(A\)와 \(B\)가 독립이다” \(\iff\) “\(\Pr[A \cap B] = \Pr[A]\Pr[B]\)”

이 동치 관계는 이후 계속 반복해서 사용되는 근본적 사실이다.

6 베이즈 규칙 (Bayes’ Rule)

조건부 확률의 정의를 양방향으로 쓰면:

\[\Pr[A \mid B] = \frac{\Pr[A \cap B]}{\Pr[B]}, \qquad \Pr[B \mid A] = \frac{\Pr[A \cap B]}{\Pr[A]}\]

두 식 모두 \(\Pr[A \cap B]\)를 포함하므로 같다고 놓으면:

\[\Pr[A \mid B] \cdot \Pr[B] = \Pr[B \mid A] \cdot \Pr[A]\]

\(\Pr[B \mid A]\)에 대해 정리하면 베이즈 규칙:

\[\Pr[B \mid A] = \frac{\Pr[A \mid B] \cdot \Pr[B]}{\Pr[A]}\]

의미: 조건부 확률의 방향을 역전(invert)시킬 수 있게 해준다. 실용적으로는 \(A\)를 관측한 후 \(B\)에 대한 믿음(belief)을 갱신하는 방법을 알려준다.

7 확률변수 (Random Variables)

7.1 정의

확률변수 \(X\)는 표본공간의 각 결과에 실수(또는 복소수)를 할당하는 함수다:

\[X : \Omega \mapsto \mathbb{R}\]

각 결과 \(\omega \in \Omega\)는 숫자 \(X(\omega)\)로 사상(map)된다. 추상적인 사건을 계산 가능한 숫자와 연결해 주는 다리 역할을 한다.

  • 예 1 (주사위): \(\Omega = \{1,\dots,6\}\), \(X(\omega) = \omega\) — 윗면의 값을 그대로 기록.
  • 예 2 (동전): \(\Omega = \{H, T\}\), \(X(H) = 1\), \(X(T) = 0\) — 범주형 결과를 숫자로 코딩.

7.2 분류

종류 조건 예 사용하는 도구
이산(discrete) \(\Omega\)가 이산적 주사위 눈 (정수값) PMF (probability mass function)
연속(continuous) \(\Omega\)가 연속적 버스 대기 시간, \(\Omega = [0, \infty)\) PDF (probability density function)

8 누적분포함수 (CDF)

8.1 정의

\[P_X(x) \overset{\text{def}}{=} \Pr[X \leq x]\]

확률변수가 임계값 \(x\)를 넘지 않을 확률을 알려준다.

8.2 CDF는 비감소 함수 — 증명

목표: \(x_1 \leq x_2\)이면 \(P_X(x_2) \geq P_X(x_1)\)임을 보인다.

Step 1. \(x_1 \leq x_2\)를 고정하고 두 사건을 정의한다:

\[A = \{\omega : X(\omega) \leq x_1\}, \qquad B = \{\omega : x_1 < X(\omega) \leq x_2\}\]

\(A\)는 “이미 갖고 있던 부분”, \(B\)는 임계값을 늘리며 “추가되는 띠(band)”로 생각할 수 있다.

Step 2. 집합 구조 관찰: \(A\)와 \(B\)는 전혀 겹치지 않고(\(A \cap B = \emptyset\)), 붙이면 정확히 \(A \cup B = \{\omega: X(\omega) \leq x_2\}\)가 된다.

Step 3. 서로소 사건의 가법성:

\[\Pr[A \cup B] = \Pr[A] + \Pr[B]\]

Step 4. 정의를 대입하면:

\[P_X(x_2) = P_X(x_1) + \Pr[x_1 < X \leq x_2]\]

임계값을 \(x_1\)에서 \(x_2\)로 옮기면, 새 CDF 값은 기존 값에 그 사이 구간의 확률 질량(“새로 얻은 조각”)을 더한 것이다.

결론: \(\Pr[x_1 < X \leq x_2] \geq 0\)이므로 \(P_X(x_2) \geq P_X(x_1)\). 임계값을 오른쪽으로 밀면 CDF는 올라가거나 평평하게 유지될 뿐, 절대 내려가지 않는다. \(\blacksquare\)

9 확률밀도함수 (PDF)

9.1 정의: CDF와의 관계

\[P_X(x) = \int_{-\infty}^{x} p_X(\alpha)\, d\alpha, \qquad p_X(x) = \frac{d}{dx} P_X(x)\]

  • 적분하면 누적 질량(CDF), 미분하면 국소 증가율(PDF)이 나온다.
  • \(p_X(x)\)는 확률 질량이 실수축 위에 어떻게 분포되어 있는지를 기술한다.
Tip직관: 군중 밀도(crowd density)

\(p_X(x)\)를 수직선 위의 군중 밀도로 상상하라.

  • \(p_X(x)\)가 큰 곳: 결과들이 그 근처에 몰려 있음 → 그 지점을 지날 때 CDF가 가파르게 올라간다.
  • \(p_X(x)\)가 작은 곳: 결과가 드묾 → CDF가 천천히 전진한다.

즉, PDF의 봉우리와 골짜기만 봐도 CDF가 어디서 급등하고 어디서 평평해질지 예측할 수 있다.

9.2 가우시안 PDF와 CDF

\[p_X(x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left( -\frac{(x-\mu)^2}{2\sigma^2} \right)\]

  • \(\mu\) (평균): 종 모양의 중심 위치. \(\mu\)를 바꾸면 모양은 그대로 좌우로만 이동한다.
  • \(\sigma^2\) (분산): 퍼짐 정도. 작으면 좁고 높은 봉우리(값들이 촘촘히 모임), 크면 넓고 낮은 종(값들이 더 분산됨).
  • 대응하는 CDF는 부드러운 S자 곡선이며 \(x = \mu\)에서 0.5를 지난다(대칭점). \(\sigma^2\)이 클수록 S자가 완만하게, 작을수록 가파르게 꺾인다.
  • 모든 PDF의 총 면적은 1이므로, 모든 CDF는 \(x \to \infty\)에서 반드시 1로 수렴한다.

10 확률변수의 변환 (Function of a Random Variable)

10.1 문제 설정

시스템이 \(X\)를 \(Y = f(X)\)로 변환한다고 하자 (제곱, 스케일링, 로그 등). 입력의 분포로부터 출력의 분포 \(P_Y(y)\), \(p_Y(y)\)를 구하고 싶다. 기본 다리는:

\[p_Y(y) = \frac{d}{dy} P_Y(y)\]

전략: \(f\)가 순증가인 경우와 순감소인 경우를 따로 다룬 뒤, 하나의 공식으로 통합한다.

10.2 Case I: \(f\)가 순증가

증가 함수는 순서를 보존하므로 \(f(X) \leq y \iff X \leq f^{-1}(y)\). 따라서:

\[P_Y(y) = \Pr[X \leq f^{-1}(y)] = P_X\big(f^{-1}(y)\big)\]

연쇄법칙으로 미분:

\[p_Y(y) = \frac{d f^{-1}(y)}{dy}\; p_X\big(f^{-1}(y)\big)\]

증가하는 경우 \(\dfrac{d f^{-1}(y)}{dy} = \dfrac{1}{f'(x)}\Big|_{x = f^{-1}(y)} > 0\)이므로 부호가 이미 올바르다:

\[p_Y(y) = \frac{1}{f'\!\big(f^{-1}(y)\big)}\; p_X\big(f^{-1}(y)\big) \quad (\text{증가하는 } f)\]

10.3 Case II: \(f\)가 순감소

순서가 뒤집히므로 \(f(X) \leq y \iff X \geq f^{-1}(y)\). 따라서:

\[P_Y(y) = \Pr[X \geq f^{-1}(y)] = 1 - P_X\big(f^{-1}(y)\big)\]

미분하면 (\(1 - P_X\)의 미분에서 음수 하나, 역함수의 기울기가 또 음수):

\[p_Y(y) = -\frac{d f^{-1}(y)}{dy}\; p_X\big(f^{-1}(y)\big)\]

감소하는 경우 \(\dfrac{d f^{-1}(y)}{dy} < 0\)이므로 두 음수가 상쇄되어 밀도는 (당연히 그래야 하듯) 양수가 된다:

\[p_Y(y) = \frac{1}{\big|f'\!\big(f^{-1}(y)\big)\big|}\; p_X\big(f^{-1}(y)\big) \quad (\text{감소하는 } f)\]

10.4 통합 공식 (변수변환 공식)

\[\boxed{\; p_Y(y) = p_X\big(f^{-1}(y)\big) \left| \frac{d}{dy} f^{-1}(y) \right| \;}\]

절댓값 덕분에 증가/감소 두 경우 모두 이 한 줄로 처리된다. 이것이 1차원 변수변환(change of variables) 공식이다.

Tip기하학적 해석
  1. \(y\)축의 점 \(y\)를 \(x = f^{-1}(y)\)로 되돌려(pull back) 원래 밀도 \(p_X(x)\)를 읽는다.
  2. 국소적인 늘림/압축 비율 \(\left|\frac{d}{dy}f^{-1}(y)\right| = \frac{1}{|f'(x)|}\)로 스케일링한다.
  • \(f'\)가 크면(가파른 기울기): 많은 \(x\)값이 좁은 \(y\)구간으로 압축 → 그 지점의 밀도가 커진다.
  • \(f'\)가 작으면(완만한 기울기): \(x\)값들이 넓은 \(y\)구간으로 퍼짐 → 밀도가 작아진다.

\(f\)를 역산할 수만 있으면, 어떤 방향이든 같은 공식으로 \(p_Y\)를 계산할 수 있다.

10.5 예제: 지수분포 입력에 \(Y = X^2\)

주어진 것: \(p_X(x) = e^{-x}\, u(x)\), 단위계단함수 \(u(x) = 1\ (x \geq 0),\ 0\) (otherwise).

변환: \(Y = f(X) = X^2\). \(x \geq 0\) 위에서 순증가이므로 역산이 간단하다.

Step 1 — 역함수와 기울기:

\[y = x^2 \;\Rightarrow\; x = f^{-1}(y) = \sqrt{y} \;\; (y \geq 0), \qquad \frac{d}{dy} f^{-1}(y) = \frac{1}{2\sqrt{y}}\]

Step 2 — 지지집합(support): \(x \geq 0 \Rightarrow y = x^2 \geq 0\)이므로 \(y < 0\)에서 \(p_Y(y) = 0\).

Step 3 — 공식에 대입:

\[p_Y(y) = p_X(\sqrt{y}) \left|\frac{1}{2\sqrt{y}}\right| = e^{-\sqrt{y}}\, u(\sqrt{y}) \cdot \frac{1}{2\sqrt{y}}\]

\(y \geq 0\)에서 \(u(\sqrt{y}) = 1\)이므로:

\[p_Y(y) = \frac{1}{2\sqrt{y}}\, e^{-\sqrt{y}}, \;\; y > 0; \qquad p_Y(y) = 0, \;\; y \leq 0\]

Step 4 — 정규화 확인 (\(y = x^2\), \(dy = 2x\,dx\) 치환):

\[\int_0^\infty \frac{1}{2\sqrt{y}} e^{-\sqrt{y}}\, dy = \int_0^\infty \frac{1}{2x} e^{-x} (2x)\, dx = \int_0^\infty e^{-x}\, dx = 1 \;\checkmark\]

해석: 제곱은 큰 \(x\)를 작은 \(x\)보다 더 강하게 압축한다. Jacobian 인자 \(\frac{1}{2\sqrt{y}}\)가 없다면 질량이 잘못 배분될 것이며, 이 인자가 국소적인 압축을 정확히 보상해 준다.

11 기댓값 (Expected Value)

11.1 정의

확률변수 \(X\)의 함수 \(f(\cdot)\)에 대한 기댓값:

\[E[f(X)] = \int_{-\infty}^{\infty} f(x)\, p_X(x)\, dx\]

의미: \(X\)의 확률 법칙으로 가중된 \(f(X)\)의 가중 평균. \(f(X)\)를 여러 번 관측한다면 얻게 될 평균값으로 생각하면 된다.

11.2 주요 통계량

\(f(X)\) 이름 표기
\(X\) 평균(mean) — \(X\)가 균형을 이루는 중심점 \(m_X = E[X]\)
\(X^2\) 평균 제곱값 (“power”) — 큰 크기를 더 강하게 반영 \(E[X^2]\)
\((X - m_X)^2\) 분산(variance) — 평균 주변의 퍼짐 \(\sigma_X^2\)

분산의 두 가지 표현:

\[\sigma_X^2 = E[(X - m_X)^2] = E[X^2] - \big(E[X]\big)^2\]

표준편차: \(\sigma_X = \sqrt{\sigma_X^2}\). 이 값들은 \(X\)의 값들이 \(m_X\) 주변에 얼마나 촘촘히/느슨하게 모여 있는지를 알려준다.

11.3 모멘트 (Moments)

  • \(n\)차 모멘트: \(f(X) = X^n\)일 때 \(\mu'_n = E[X^n]\) — 분포 모양의 다양한 측면을 요약.
  • \(n\)차 중심 모멘트: \(f(X) = (X - m_X)^n\)일 때 \(\mu_n = E[(X - m_X)^n]\) — 0이 아니라 평균 \(m_X\) 주변의 요동을 강조.
\(n\) 중심 모멘트의 의미
1 평균
2 분산
3 왜도(skewness) — 모양의 비대칭성
4 첨도(kurtosis) — 뾰족함 / 두꺼운 꼬리

12 특성함수 (Characteristic Function)

12.1 정의

\[\Phi_X(jv) = E[e^{jvX}] = \int_{-\infty}^{\infty} p_X(x)\, e^{jvx}\, dx\]

핵심 관찰: 이는 정확히 PDF \(p_X(x)\)의 푸리에 변환(Fourier transform)이다.

이 연결이 단순한 형식 이상의 의미를 갖는 이유:

  • 특성함수는 분포를 유일하게 결정한다.
  • 독립 확률변수들의 합을 다룰 때 PDF끼리의 합성곱(convolution)이 특성함수끼리의 곱셈으로 바뀌어 계산이 훨씬 간단해진다.
  • 원점에서의 미분으로 모멘트에 접근할 수 있다 (아래 참조).

12.2 특성함수로부터 모멘트 추출

\[\boxed{\; E[X^n] = j^{-n}\, \frac{d^n}{dv^n} \Phi_X(jv) \Big|_{v=0} \;}\]

\(\Phi_X(jv)\)를 \(n\)번 미분한 뒤 \(v = 0\)을 대입하면 \(n\)차 모멘트가 나온다.

Warning주의할 두 가지
  1. 미분값은 반드시 \(v = 0\)에서 평가한다.
  2. \(j^{-n}\) 인자를 잊지 말 것 — 특히 \(n\)이 홀수일 때 스케일과 부호를 맞춰 준다.

12.3 예제: \(n = 2\) (2차 모멘트)

Step 1 — 정의에서 출발:

\[\Phi_X(jv) = \int_{-\infty}^{\infty} p_X(x)\, e^{jvx}\, dx\]

Step 2 — 1차 미분 (미분이 적분 안으로 들어가 \(jx\) 인자를 끌어내림):

\[\frac{d}{dv}\Phi_X(jv) = \int_{-\infty}^{\infty} p_X(x)\, (jx)\, e^{jvx}\, dx\]

Step 3 — 2차 미분 (\(jx\)가 하나 더 나와 \((jx)^2\)):

\[\frac{d^2}{dv^2}\Phi_X(jv) = \int_{-\infty}^{\infty} p_X(x)\, (jx)^2\, e^{jvx}\, dx\]

Step 4 — \(v = 0\) 대입 (\(e^{jvx} \to 1\)):

\[\frac{d^2}{dv^2}\Phi_X(jv)\Big|_{v=0} = \int p_X(x)\, (jx)^2\, dx = -\int x^2\, p_X(x)\, dx\]

Step 5 — 공식 적용 (\(j^{-2} = -1\)):

\[E[X^2] = j^{-2} \cdot \left( -\int x^2 p_X(x)\, dx \right) = \int_{-\infty}^{\infty} x^2\, p_X(x)\, dx \;\checkmark\]

특성함수를 원점에서 미분하는 것만으로 모멘트를 하나씩 벗겨낼 수 있다 — 이론적 트릭이 아니라 많은 문제에서 실제로 유용한 계산법이다.

13 모멘트 생성 함수 (MGF)

13.1 정의

특성함수가 순허수 매개변수 \(jv\)를 썼다면, MGF는 실변수 \(s\)를 사용한다:

\[\Phi_X(s) \overset{\text{def}}{=} E[e^{sX}] = \int_{-\infty}^{\infty} p_X(x)\, e^{sx}\, dx\]

  • 이는 본질적으로 PDF의 라플라스 변환(Laplace transform)이다. 라플라스 변환의 이동 규칙, 선형성 등 친숙한 성질이 그대로 적용된다.
  • 존재 조건: \(s = 0\)을 포함하는 어떤 열린 구간에서 적분이 수렴해야 한다. 그러면 MGF는 분포를 유일하게 결정한다.

13.2 MGF로부터 모멘트 추출

\[E[X^n] = \frac{d^n}{ds^n} \Phi_X(s) \Big|_{s=0}\]

  • \(n = 1\): \(E[X] = \Phi_X'(0)\) (평균)
  • \(n = 2\): \(E[X^2] = \Phi_X''(0)\) (2차 모멘트)
Tip왜 성립하는가 — 테일러 전개

\[e^{sX} = 1 + sX + \frac{s^2}{2!}X^2 + \cdots\] 항별로 기댓값을 취하면: \[\Phi_X(s) = 1 + s\,E[X] + \frac{s^2}{2!}E[X^2] + \cdots\] 즉, 멱급수에서 \(\dfrac{s^n}{n!}\)의 계수가 정확히 \(E[X^n]\)이다. 그래서 \(s = 0\)에서 미분하면 \(n\)차 모멘트가 튀어나온다.

14 결합 분포 확률변수 (Jointly Distributed R.V.s)

14.1 결합 CDF와 결합 PDF

같은 표본공간 위에 두 확률변수를 정의할 수 있다: \(X: \Omega \mapsto \mathbb{R}\), \(Y: \Omega \mapsto \mathbb{R}\). 둘이 함께 2차원 결과를 기술한다.

결합 CDF:

\[P_{X,Y}(x, y) \overset{\text{def}}{=} \Pr[X \leq x,\; Y \leq y]\]

두 변수가 모두 각자의 임계값 아래로 떨어질 확률.

결합 PDF (결합 CDF가 충분히 매끄러울 때):

\[p_{X,Y}(x, y) = \frac{\partial^2}{\partial x\, \partial y} P_{X,Y}(x, y)\]

평면 위의 국소적인 확률 밀도를 준다.

14.2 주변 분포 (Marginals)

결합 PDF에서 다른 변수를 적분해 없애면(integrate out) 개별 분포가 복원된다:

\[p_X(x) = \int_{-\infty}^{\infty} p_{X,Y}(x, y)\, dy, \qquad p_Y(y) = \int_{-\infty}^{\infty} p_{X,Y}(x, y)\, dx\]

14.3 조건부 PDF와 독립

조건부 PDF (\(p_Y(y) \neq 0\)일 때):

\[p_{X|Y}(x \mid y) = \frac{p_{X,Y}(x, y)}{p_Y(y)}\]

\(Y\)의 값을 알았을 때 \(X\)가 어떻게 행동하는지를 알려준다.

독립이면 결합 PDF가 인수분해된다:

\[p_{X,Y}(x, y) = p_X(x)\, p_Y(y) \;\iff\; p_{X|Y}(x \mid y) = p_X(x)\]

즉, \(Y\)를 알아도 \(X\)의 분포는 변하지 않는다.

15 공분산과 상관계수

15.1 공분산 (Covariance)

\(X\)와 \(Y\)가 함께 변하는 정도를 측정한다:

\[\text{cov}[X, Y] = E[(X - m_X)(Y - m_Y)] = E[XY] - E[X]\,E[Y]\]

15.2 상관계수 (Correlation Coefficient)

공분산을 표준화한 것:

\[\rho_{X,Y} = \frac{\text{cov}[X, Y]}{\sigma_X\, \sigma_Y}\]

항상 \(-1 \leq \rho_{X,Y} \leq 1\)이며, \(X\)와 \(Y\)가 선형적으로 얼마나 강하게 연관되어 있는지를 알려준다.

15.3 무상관 vs 독립

\(\rho_{X,Y} = 0\)이면 \(\text{cov}[X,Y] = 0\), 즉 \(E[XY] = E[X]E[Y]\). 이는 독립처럼 보이지만 조심해야 한다.

Important핵심

\[\text{독립} \;\Longrightarrow\; \text{무상관} \qquad \text{그러나} \qquad \text{무상관} \;\not\Longrightarrow\; \text{독립}\]

두 변수는 상관관계가 없으면서도 비선형적으로 종속일 수 있다.

반례: \(X \sim \text{Uniform}(-1, 1)\), \(Y = X^2\).

  • \(Y\)는 \(X\)에 의해 완전히 결정되므로 둘은 명백히 종속이다.
  • 그런데 분포의 대칭성으로 \(E[X] = 0\)이고, \(XY = X^3\)이므로:

\[E[XY] = E[X^3] = \int_{-1}^{1} x^3 \cdot \frac{1}{2}\, dx = 0\]

(\(x^3\)은 홀함수, 구간은 대칭이므로 적분이 0)

  • 따라서 \(\text{cov}[X, Y] = E[XY] - E[X]E[Y] = 0\) — 무상관.

\(Y\)가 \(X\)의 결정론적 함수임에도 공분산이 0이다. 무상관이 독립을 함의하지 않음을 보여주는 표준적인 예다.

16 조건부 기댓값 (Conditional Expectation)

16.1 정의

\(Y\)의 값을 알고 있을 때 \(X\)의 평균적 행동:

\[E[X \mid Y = y] = \int_{-\infty}^{\infty} x\, p_{X|Y}(x \mid y)\, dx\]

\(Y = y\)로 고정했을 때, 그 조건 아래에서 \(X\)의 평균값이다.

16.2 반복 기댓값의 법칙 (Law of Iterated Expectation)

\[E\big[E[X \mid Y]\big] = E[X]\]

해석 — 2단계 평균:

  1. 먼저 각 “슬라이스” \(Y = y\) 안에서 \(X\)의 평균을 구하고,
  2. 그 평균들을 \(Y\)의 모든 값에 걸쳐 다시 평균하면,

원래의 \(E[X]\)가 복원된다. 조건부 기댓값이 전체 기댓값 안에 어떻게 중첩(nest)되어 있는지를 보여준다.

17 복소 확률벡터와 공분산 행렬

17.1 켤레와 에르미트 전치

  • 복소수: \(z = a + jb\)의 켤레는 \(\bar{z} = a - jb\) (허수부의 부호만 반전).
  • 복소 벡터 \(\mathbf{x} \in \mathbb{C}^K\): 각 원소를 개별적으로 켤레 — \(\bar{\mathbf{x}} = [\bar{x}_1; \cdots; \bar{x}_K]\) (모양은 유지).
  • 켤레 전치 (에르미트 전치, Hermitian transpose): 켤레를 취한 뒤 전치:

\[\mathbf{x}^H = \bar{\mathbf{x}}^T, \qquad \mathbf{A}^H = \bar{\mathbf{A}}^T\]

Note표기 규약

에르미트 전치는 \(*\)가 아니라 일관되게 위첨자 \(H\)로 표기한다. 행렬 연산을 다룰 때 표현을 깔끔하고 모호하지 않게 유지하기 위함이다.

17.2 공분산 행렬 (Covariance Matrix)

복소 확률벡터 \(\mathbf{X}\)에 대해:

\[\mathbf{K}_X = E\big[ (\mathbf{X} - E[\mathbf{X}])(\mathbf{X} - E[\mathbf{X}])^H \big]\]

스칼라의 분산 개념을 벡터로 일반화한 것으로, 각 성분의 변동성과 성분들 간의 관계를 함께 담는다.

성질 1 — 에르미트 대칭:

\[\mathbf{K}_X = \mathbf{K}_X^H\]

행렬이 자기 자신의 켤레 전치와 같다. 이는 행렬의 구성 방식에서 자연스럽게 따라 나오며, \(\mathbf{X}\)의 분포와 무관하게 항상 성립한다.

성질 2 — 양의 준정부호(positive semidefinite): 임의의 \(\mathbf{a} \in \mathbb{C}^K\)에 대해:

\[\mathbf{a}^H \mathbf{K}_X\, \mathbf{a} = E\big[ |\mathbf{a}^H (\mathbf{X} - E[\mathbf{X}])|^2 \big] \geq 0\]

성질 3 — 양의 정부호(positive definite) 조건: \(\mathbf{X}\)의 어떤 성분도 분산이 0이 아니면(즉, 모든 성분이 실제로 요동하면) \(\mathbf{K}_X\)는 양의 정부호다.

Tip직관

이차형식 \(\mathbf{a}^H \mathbf{K}_X \mathbf{a}\)는 정확히 선형결합 \(\mathbf{a}^H \mathbf{X}\)의 분산이다. 가중치 벡터 \(\mathbf{a}\)를 확률벡터에 적용해 얻는 스칼라의 분산이 이 이차형식으로 주어지므로, 분산은 음수가 될 수 없다 → 준정부호성이 자명해진다.

18 확률벡터의 최댓값 분포

18.1 문제 설정

확률벡터 \(\mathbf{X} = (X_1, \ldots, X_L)^T\)의 최대 성분이라는 스칼라 확률변수에 관심을 갖는다:

\[\max \mathbf{X} = \max\{X_1, \ldots, X_L\}\]

18.2 최댓값의 CDF

임계값 \(\mu\)에 대해:

\[\Pr[\max \mathbf{X} < \mu] = P_{\mathbf{X}}(\mu, \ldots, \mu)\]

왜 이렇게 되는가: 최댓값이 \(\mu\)보다 작다는 것은 모든 성분 \(X_i\)가 \(\mu\)보다 작다는 것과 동치다:

\[\{\max \mathbf{X} < \mu\} \;\iff\; \{X_i < \mu,\; \forall i\}\]

즉, 결합 CDF를 모든 성분이 \(\mu\)인 점에서 평가하는 하나의 결합 사건이 최댓값의 행동 전체를 기술한다.

18.3 독립인 경우

\(X_1, \ldots, X_L\)이 독립이면, 모두 \(\mu\) 미만일 확률은 개별 확률들의 곱이 된다:

\[\Pr[\max \mathbf{X} < \mu] = \prod_{i=1}^{L} P_{X_i}(\mu)\]

PDF — 곱의 미분 규칙(product rule)을 적용:

\[p_{\max \mathbf{X}}(\mu) = \sum_{j=1}^{L} p_{X_j}(\mu) \prod_{i \neq j} P_{X_i}(\mu)\]

각 항은 “\(X_j\)가 \(\mu\) 근처의 값을 치고(\(p_{X_j}\)), 나머지 전부는 \(\mu\) 아래에 머무는(\(P_{X_i}\))” 경우에 대응한다.

가장 간단한 경우 (\(L = 2\)):

\[p_{\max \mathbf{X}}(\mu) = \frac{d}{d\mu}\Big( P_{X_1}(\mu) P_{X_2}(\mu) \Big) = p_{X_1}(\mu)\, P_{X_2}(\mu) + p_{X_2}(\mu)\, P_{X_1}(\mu)\]

두 변수 중 어느 쪽이든 최댓값에 기여할 수 있음이 두 항으로 나타난다.

18.4 i.i.d.인 경우

성분들이 독립이면서 동일한 분포(같은 CDF \(P_X(\mu)\), 같은 PDF \(p_X(\mu)\))를 따르면 식이 크게 단순해진다:

\[\Pr[\max \mathbf{X} < \mu] = \big( P_X(\mu) \big)^L\]

미분하면:

\[\boxed{\; p_{\max \mathbf{X}}(\mu) = L\, p_X(\mu)\, \big( P_X(\mu) \big)^{L-1} \;}\]

Tip직관

변수의 개수 \(L\)이 커질수록 최댓값의 분포는 오른쪽으로 이동한다. 표본이 많을수록 높은 값을 볼 가능성이 커지므로, 최댓값의 밀도는 큰 \(\mu\) 쪽으로 점점 집중된다. (무선 통신에서 다중 사용자 다이버시티 등의 분석에 직접 쓰이는 결과다.)

19 핵심 공식 요약

개념 공식
드모르간 법칙 \(\overline{A \cup B} = \bar{A} \cap \bar{B}\)
합집합 법칙 \(\Pr[A \cup B] = \Pr[A] + \Pr[B] - \Pr[A \cap B]\)
조건부 확률 \(\Pr[A \mid B] = \dfrac{\Pr[A \cap B]}{\Pr[B]}\)
독립 \(\Pr[A \cap B] = \Pr[A]\Pr[B]\)
베이즈 규칙 \(\Pr[B \mid A] = \dfrac{\Pr[A \mid B]\Pr[B]}{\Pr[A]}\)
CDF ↔︎ PDF \(P_X(x) = \int_{-\infty}^x p_X(\alpha)d\alpha\), \(\;p_X = \frac{d}{dx}P_X\)
변수변환 \(p_Y(y) = p_X(f^{-1}(y))\left|\frac{d}{dy}f^{-1}(y)\right|\)
분산 \(\sigma_X^2 = E[X^2] - (E[X])^2\)
특성함수 모멘트 \(E[X^n] = j^{-n}\frac{d^n}{dv^n}\Phi_X(jv)\big|_{v=0}\)
MGF 모멘트 \(E[X^n] = \frac{d^n}{ds^n}\Phi_X(s)\big|_{s=0}\)
공분산 \(\text{cov}[X,Y] = E[XY] - E[X]E[Y]\)
반복 기댓값 \(E[E[X \mid Y]] = E[X]\)
공분산 행렬 \(\mathbf{K}_X = E[(\mathbf{X}-E[\mathbf{X}])(\mathbf{X}-E[\mathbf{X}])^H]\), 에르미트·PSD
i.i.d. 최댓값 \(p_{\max}(\mu) = L\,p_X(\mu)(P_X(\mu))^{L-1}\)
