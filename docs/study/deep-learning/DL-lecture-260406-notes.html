Important이 노트의 핵심 한 줄 요약

신경망의 손실 곡면(solution space)은 ill-conditioned이고, saddle point와 cliff로 가득하며, 우리가 쓰는 gradient조차 noisy하다. 그래서 전역 최적해를 찾는 것은 포기하고, 충분히 좋은 local minimum을 찾기 위해 Momentum·좋은 초기화·learning rate scheduling 같은 실용적 장치들을 동원한다. 이것이 1차 미분 기반 딥러닝 최적화의 본질이다.

2 출발점 복습: ERM과 GD vs. SGD

진짜 목표는 데이터 생성 분포 \(p_{\text{data}}\)에 대한 risk 최소화다.

\[ J^*(\theta) = \min_{\theta}\; \mathbb{E}_{(x,y)\sim p_{\text{data}}}\!\left[\, L\big(f(x;\theta),\, y\big) \right] \]

그러나 전체 세계의 데이터를 가질 수 없으므로 훈련 집합의 경험 분포 \(\hat{p}_{\text{data}}\)에 대한 empirical risk를 대신 최소화한다 (ERM, Empirical Risk Minimization).

\[ J(\theta) = \mathbb{E}_{(x,y)\sim \hat{p}_{\text{data}}}\!\left[ L\big(f(x;\theta), y\big)\right] = \frac{1}{m}\sum_{i=1}^{m} L\big(f(x^{(i)};\theta),\, y^{(i)}\big) \]

Gradient Descent (GD) Stochastic GD (SGD)
gradient 계산 단위 전체 데이터 \(m\)개 mini-batch \(k\)개
gradient 품질 안정적, noise 적음 불안정, noisy
중요한 gradient 서로 상쇄될 수 있음 보존될 가능성 있음
계산/메모리 비용 큼 (전체 로드 필요) 작음 → 실용적 표준

NoteSGD를 옹호하는 두 가지 추가 논거
  1. Solution space에는 local minima가 많다. loss function이 convex여도, solution space의 모양은 loss가 아니라 데이터 분포가 결정한다. GD는 확신을 갖고 local minimum으로 직진하지만, SGD의 randomness는 random walk처럼 빠져나올 기회를 준다.
  2. 병렬화가 쉽다. 여러 batch를 여러 머신에서 계산해 합산할 수 있다.

3 Newton’s method: 이론적으로는 최적, 실전에서는 폐기

3.1 아이디어: 2차 Taylor 근사

손실 \(f(x)\)를 2차까지 Taylor 전개하고 고차항을 버리면, 최적 step을 닫힌 형태로 구할 수 있다.

\[ f(x) \approx f(x_0) + (x - x_0)^\top g + \frac{1}{2}(x - x_0)^\top H (x - x_0) \]

  • \(g\): 1차 미분 (gradient)
  • \(H\): 2차 미분 행렬 (Hessian)

이를 \(x\)에 대해 미분해 0으로 놓으면 update가 나온다.

\[ x^{\ast} = x_0 - H^{-1} g \]

즉 step size를 따로 튜닝할 필요 없이 곡률 정보가 최적 보폭을 알려준다. convex objective라면 적은 iteration으로 전역 최적점에 도달한다.

3.2 왜 딥러닝에서는 안 쓰는가

WarningNewton’s method가 실패하는 세 가지 이유
  1. 계산 비용: 파라미터가 \(n\)개면 Hessian은 \(n \times n\). 수억~수천억 파라미터에서 계산·저장·역행렬은 불가능에 가깝다.
  2. 곡면이 매끄럽지 않다: 매우 복잡한 손실 곡면에서는 2차 근사 자체가 의미 있는 step을 주지 못한다. 비싸게 계산해도 최적 보폭이 아니다.
  3. Saddle point에 끌려간다: Newton’s method는 gradient가 0인 critical point를 향한다. 그런데 고차원 곡면의 critical point 대부분은 saddle point다(아래 Section 4.3 참고). Hessian의 고유값 부호가 섞여 있으면 그 극점은 minimum일 수도, maximum일 수도, saddle일 수도 있다.

critical point의 분류는 Hessian 고유값 부호로 결정된다.

Hessian 고유값 critical point의 종류
모두 양수 (positive definite) local minimum
모두 음수 (negative definite) local maximum
양수·음수 혼재 saddle point

4 신경망 최적화의 8가지 도전과제

4.1 1. Ill-conditioning

Condition number는 행렬 \(A\)의 가장 큰 고유값과 가장 작은 고유값의 비율이다.

\[ \kappa(A) = \max_{i,j}\left|\frac{\lambda_i}{\lambda_j}\right| = \frac{|\lambda_{\max}|}{|\lambda_{\min}|} \]

여기서 \(A\)로는 보통 feature 공간의 covariance matrix(또는 손실 곡면의 Hessian)를 생각한다. 고유값은 각 고유벡터 방향으로 데이터가 얼마나 퍼져 있는지를 말해준다.

  • \(\kappa \approx 1\): 데이터가 등방적(isotropic) 으로 퍼짐 → 어느 방향이든 비슷한 step size가 통함 → 최적화 쉬움
  • \(\kappa \gg 1\) (예: \(10^4\)): 어떤 방향은 넓게, 어떤 방향은 빽빽하게 분포 → step size가 극도로 민감해짐

step size가 민감해지는 메커니즘:

  1. 빽빽한(곡률이 큰) 방향 기준으로 step이 크면 → minimum을 건너뛰고 진동(oscillation)
  2. 퍼진(곡률이 작은) 방향 기준으로 step이 작으면 → minimum에 도달하기 전에 멈춤

하나의 learning rate로 두 방향을 동시에 만족시킬 수 없는 상황이 ill-conditioning이다.

Important고차원일수록 ill-conditioning은 기본값

차원이 높아질수록 고유값 조합의 가짓수가 많아져 \(\lambda_{\max}/\lambda_{\min}\) 비율이 커질 가능성이 높다. 실제 데이터는 대부분 고차원이므로, 실전의 solution space는 거의 항상 ill-conditioned라고 가정하는 것이 안전하다.

4.2 2. Local minima — 수렴 판단이 어렵다

깊은 신경망은 수렴하지 않을 수 있다. 그 이유들:

  • local minimum이 아예 없을 수도 있다. 전역 minimum 하나에 나머지는 plateau(평탄 지대)의 연속이라면, 최적화는 멈출 기준점 없이 떠돌다 멈춘다.
  • “stuck” 상태: loss가 줄지 않는데도 파라미터는 계속 움직이는 상태. 원인 후보는 ① 나쁜 conditioning, ② 과도한 gradient noise (SGD), ③ overfitting (특히 작은 훈련 데이터), ④ 그 외 미지의 원인.
  • critical point에 도달하기 전에 멈추는 것이 보통이다. learning rate를 점점 줄이는 scheduling을 쓰는데, local minimum에 들어가기 전에 learning rate가 너무 작아지면 중간 지점에서 학습이 끝나버린다. 이는 실전에서 매우 자주 일어난다.
Warning훈련 loss 곡선만으로는 “잘 수렴했는지” 알 수 없다

loss 값과 최적화 궤적을 들여다봐도 지금 멈춘 곳이 좋은 minimum인지 판단할 수 없다. 학습이 좋았는지는 결국 test/validation 데이터로 평가했을 때에만 드러난다. 훈련 중에는 알기 어렵다.

4.3 3. Saddle point, plateau — 흔한가? 불행히도 그렇다

동전 던지기 논증: Hessian의 고유값 하나하나에 대해 동전을 던진다고 하자.

  • 앞면 → 그 고유값은 양수
  • 뒷면 → 음수

local minimum이 되려면 모든 고유값이 양수(전부 앞면)여야 한다. 차원 \(n\)이 커질수록 전부 앞면이 나올 확률은 \(\sim (1/2)^n\)으로 지수적으로 희박해진다. 어떤 방향은 minimum이고 어떤 방향은 maximum인 saddle point가 critical point의 압도적 다수가 된다.

Random matrix theory의 보정: 사실 이 동전은 공정하지 않고 편향(weighted) 되어 있다. 손실 값 \(J\)가 낮은 지점일수록 앞면(양수 고유값)이 나올 확률이 높다. 따라서:

  • 낮은 \(J\)를 가진 critical point → local minimum일 가능성이 높다
  • 높은 \(J\)를 가진 critical point → 대부분 saddle point
Tip실용적 함의

“local minimum에 갇히면 어쩌지”라는 걱정은 생각보다 덜 치명적이다. 도달 가능한 local minimum들은 어차피 손실이 낮은 곳에 몰려 있기 때문이다. 진짜 문제는 높은 손실 영역에 널려 있는 saddle point들이고, Newton류 방법은 바로 이것들에 끌려간다 — 1차 방법(+noise)을 선호하는 또 하나의 이유다.

Saddle point 근처의 거동: 한 방향에서는 minimum처럼 보여 수렴하는 듯하다가, 다른 방향의 gradient가 커지는 순간 다른 골짜기로 굴러떨어진다. 이때 loss가 갑자기 튀어 오르는(soaring) 현상을 관찰할 수 있다.

4.4 4. Cliff와 exploding gradient → gradient clipping

손실 곡면에는 cliff(절벽) — loss가 급락/급등하는 지점 — 가 존재한다. step size가 충분히 크면 절벽을 뛰어넘어 엉뚱하게 높은 loss 지역으로 떨어지고, 한 번의 iteration만에 loss가 크게 튀어 학습이 망가진 것처럼 보인다.

  • 단순 해법: learning rate를 줄인다 → 그러나 전체 학습이 느려진다. 원하지 않는 trade-off.
  • Heuristic 해법: gradient clipping. gradient의 norm이 임계값을 넘으면 잘라낸다.

\[ g \leftarrow g \cdot \min\!\left(1,\; \frac{\tau}{\lVert g \rVert}\right) \]

“gradient가 비정상적으로 크다 = 지금 매우 불규칙한 지형을 지나는 중”이라는 신호로 받아들이고, 보폭을 강제로 제한해 조심스럽게 내려가는 것이다. 출발은 어이없을 만큼 단순한 heuristic이었지만 실전 성능이 좋아 표준 기법이 되었다.

4.5 5. Long-term dependency (vanishing gradient)

hidden layer 수가 늘어날수록, 출력에서 입력 방향으로 backprop되는 gradient의 크기가 지수적으로 감소한다 (vanishing gradient). 출력층에서 만들어진 학습 신호가 여러 층을 거치며 희석되어, 입력에 가까운 층의 파라미터가 효과적으로 학습되지 않는다. 정보를 보존하거나 노이즈를 줄이는 별도 장치(skip connection, 정규화 등)가 필요해진다.

Note같은 이름, 다른 축: 시간 축의 long-term dependency

여기서 말하는 것은 하나의 MLP 안에서 입력층–출력층 사이의(깊이 축) 의존성이다. 시퀀스 데이터에서는 시간 축의 long-term dependency가 별도로 존재한다 — 긴 문단을 이해하려면 앞에 나온 단어·문장들의 의미를 기억하고 연결해야 한다.

현대 Transformer는 이 문맥 정보를 KV cache에 저장하는데, 시퀀스가 길어지면 GPU 메모리를 폭발적으로 소모한다. 압축하면 정보가 손실되는 것이 일반적이지만, 최근에는 손실 없이(혹은 거의 없이) 약 6배 압축하는 기법들이 나와 cache 효율을 크게 높이고 있다. 이 주제는 시퀀스 모델링에서 다시 다룬다.

4.6 6. Inexact gradient → surrogate loss

SGD가 쓰는 stochastic gradient는 참 gradient가 아니다. mini-batch라는 데이터 일부의 “맛”만 본, noise 섞인 추정치다. 이 noise는 최적화를 엉뚱한 곳으로 끌고 갈 수 있다.

해법: surrogate loss. 원래의 복잡한 손실 곡면 대신, ① 그것과 비슷하면서 ② 훨씬 매끄럽고 최적화하기 쉬운 대리 손실을 정의해 그 위에서 최적화한다.

  • surrogate의 minimum은 원래 minimum과 약간 다르지만, 적은 iteration으로 원래 해에 충분히 가까운 점에 안정적으로 도달한다.
  • 곡면 자체가 매끄러우므로 gradient가 noisy해도 결국 minimum 근처로 수렴한다.
Important열린 문제

“원래 곡면에 가깝고, 그 minimum이 원래 해와 가까운 surrogate loss를 어떻게 설계하는가”가 핵심 질문이다. 정답은 데이터셋과 목적함수에 따라 달라지며, 일반해는 없다. 좋은 surrogate를 찾으면 noisy gradient를 쓰더라도 최적화가 극적으로 쉬워진다. (분류에서 0-1 loss 대신 cross-entropy를 쓰는 것이 대표적인 surrogate loss의 예다.)

4.7 7. Local 구조와 global 구조의 불일치

1차원으로 단순화한 사고 실험: 어떤 파라미터 구간에서 loss가 국소적으로 증가하고 있다고 하자. gradient만 보는 입장에서 가능한 해석은 여러 가지다.

  1. “지금 있는 골짜기가 좋은 local minimum이고, 언덕을 넘으면 안 된다” → 여기서 멈춤
  2. “overfitting이 시작됐다” → 학습 중단
  3. “언덕 너머에 훨씬 깊은 minimum이 있다” → 용감하게 넘어가면 더 좋은 해

문제는 국소 관측(local observation)만으로는 셋을 구분할 수 없다는 것이다. local 정보가 global 구조에 대해 알려주는 바가 빈약(poor correspondence)하기 때문에, 학습 곡선을 모니터링하면서 내리는 결정(중단할까, 계속할까)이 본질적으로 어렵다.

4.8 8. 최적화의 이론적 한계

신경망 학습에서 우리는 함수의 정확한 minimum을 찾는 것을 포기한다. 곡면이 너무 복잡해서 사실상 불가능하기 때문이다. 대신 목표를 바꾼다:

loss 값을 충분히 줄여서 좋은 generalization 성능을 얻는다.

“어떤 최적화 알고리즘이 목적(전역 minimum 발견)을 달성할 수 있는가”에 대한 이론적 분석은 극히 어렵다. 따라서 현실적인 성능 bound를 유도하는 것 — 예컨대 surrogate 최적화 결과와 진짜 최적해 사이의 gap을 보장하는 이론적 도구 — 이 머신러닝 연구의 중요한 목표로 남아 있다. 이런 보장(guarantee)을 하나 만들어내면 복잡한 곡면 위의 학습에 대한 의미 있는 진전이 된다.

5 최적화 디버깅: 경로의 시각화

SGD가 실제로 무엇을 하고 있는지 — local minimum에 갇혔는지, saddle point에 머무는지, 전역 장애물 주변을 낭비하며 맴도는지, 울퉁불퉁한 협곡을 누비는지 — 알아내는 한 방법은 최적화 경로를 시각화하는 것이다.

고차원 공간의 직접 시각화는 불가능하므로 저차원 projection을 쓴다.

방법 내용 장단점
2D subspace 시각화 손실 곡면을 2차원 평면에 투영해 등고선/표면으로 관찰 정보량 많음 / 덜 보편적
1D subspace 시각화 learning curve (loss vs. iteration), interpolation plot 매우 쉬움, 표준 관행 / 오판 가능 (좋은 minimum인지 빠져나가야 할 골짜기인지 오도할 수 있음)

5.1 시각화에서 얻은 교훈

  1. 대부분의 문제에서, loss가 단조 감소하는 linear subspace가 존재한다. 겉보기에 미친 듯이 복잡한 곡면이라도, 그 밑에 깔린(latent) 부분공간은 단순하고 심지어 선형적일 수 있다.
  2. 일부 문제에서는 이 subspace와 SGD 경로 사이에 장애물이 있다. learning curve가 일시적으로 정체되거나 튀어 오르는 국소적 ups and downs는 무시하고, 충분한 기간 관찰하면 결국 감소 추세를 확인할 수 있는 경우가 많다.
  3. Factored linear model이 심층 신경망 학습의 정성적 측면을 많이 포착한다. 선형 모델 \(y = Wx + b\)의 \(W\)를 고유벡터·고유값 형태로 인수분해(factorize)하면, 복잡한 곡면 밑의 선형 subspace를 드러내고 최적화 과정을 분석하는 도구가 된다.
Tip이 절의 punchline

겉의 곡면은 복잡해 보여도, latent space는 단순할 수 있다. 거대한 모델일수록 곡면은 더 복잡해지는데도 학습이 되는 이유가 여기에 있다. 같은 철학으로, 좋은 surrogate loss를 찾으면 — 밑에 깔린 단순한 구조에 올라타는 것이므로 — 실전에서 매우 잘 작동한다. (데이터의 noise와 비포괄성 때문에 곡면에 잔물결이 생기는 것일 뿐, 본질적 구조는 단순한 경우가 많다.)

6 1차 미분 기반 최적화의 재료들

gradient 기반 방법에서 쓸 수 있는 미분의 차수:

차수 이름 비고
1차 gradient 표준
2차 Hessian 입력의 작은 변화에 민감; 극점이 min인지 max인지 판별해줌
3차 이상 higher-order gradient 실용 사례 없음

2차 정보는 “이 극점이 minimum인가(멈춰도 됨) maximum인가(더 내려가야 함)”를 알려주지만, 비용 문제로 딥러닝에서는 1차 기반이 표준이다. 1차 기반 최적화를 안정화(stabilize) 하는 세 가지 재료:

  1. Momentum — noisy한 stochastic gradient에 관성을 부여
  2. 파라미터 초기화 — 좋은 골짜기 근처에서 출발
  3. Learning rate scheduling — 딥러닝 라이브러리에서 “optimizer”라 불리는 것 (다음 노트)
Note“Optimizer”라는 이름의 함정

PyTorch/TensorFlow의 optimizer 모듈(SGD, AdaGrad, RMSProp, Adam, …)은 마치 서로 다른 최적화 알고리즘처럼 보이지만, 전부 본질은 stochastic gradient descent다. 차이는 오직 learning rate를 어떻게 schedule하느냐뿐이다. 같은 곡면에서 어떤 scheduler를 쓰느냐에 따라 빨리 수렴하기도, 늦게 수렴하기도, 아예 수렴하지 않기도 한다 — 학습 효율을 사실상 결정하는 요소라서 “optimizer”라는 거창한 이름이 붙었다.

6.1 Momentum

일상적 정의: 운동(또는 연속된 사건)에 의해 얻은 힘 — 물리의 운동량 \(M = m \cdot v\), 즉 관성(inertia).

머신러닝에서의 직관: 어느 지점에서 mini-batch 운이 나빠 stochastic gradient가 엉뚱한 방향을 가리킬 수 있다. 그러나 곡면의 내리막 방향이 한 step 만에 급변하는 일은 드물다. 그렇다면 현재의 noisy gradient에 100% 의존하지 말고, 지금까지 내려온 방향(역사)을 더 신뢰하자 — gradient에 관성을 주자.

Momentum 알고리즘 [Polyak, 1964]은 과거 gradient들의 지수적으로 감쇠하는 이동평균(exponentially decaying moving average) 을 누적하고 그 방향으로 계속 이동한다.

\[ \begin{aligned} v &\leftarrow \alpha\, v \;-\; \epsilon\, \nabla_\theta J(\theta) \\ \theta &\leftarrow \theta + v \end{aligned} \]

  • \(v\) (velocity): 파라미터가 parameter space를 통과하는 방향과 속력. 음의 gradient의 지수 감쇠 평균으로 정의된다.
  • \(\alpha \in [0,1)\): hyperparameter. 과거 gradient의 기여가 얼마나 빨리 감쇠하는지를 결정한다. 예컨대 \(\alpha = 0.8\)이면 누적된 과거 velocity에 80%, 새 gradient에 나머지 비중을 두는 셈 — 현재의 “엉터리(noisy)” gradient보다 역사를 더 신뢰한다.
  • 주의: \(\alpha\)는 momentum 사용 시 반드시 지정해야 하는 또 하나의 hyperparameter이며, 결과가 이 값에 꽤 민감하다. “관성을 얼마나 쓸 것인가”를 정하는 일이다.

6.2 Nesterov Momentum

표준(ordinary) momentum의 한 가지 비효율: gradient를 이전의(낡은) 파라미터 지점에서 계산한다. 그런데 velocity로 어차피 이동할 것이 확실하다면, 그 gradient는 계산되는 순간 이미 outdated다.

Nesterov momentum은 보정항(correction factor)을 추가한다 — velocity를 먼저 적용한 미래의(lookahead) 지점에서 gradient를 계산한다.

\[ \begin{aligned} v &\leftarrow \alpha\, v \;-\; \epsilon\, \nabla_\theta J(\theta + \alpha v) \\ \theta &\leftarrow \theta + v \end{aligned} \]

mini-batch가 들어올 때마다 파라미터가 라이브로 갱신되는 online 학습 상황에서, “다음 iteration에 실제로 평가될 공간”의 gradient를 미리 보는 것이므로 gradient가 덜 낡는다. 실전에서 보통 표준 momentum보다 성능이 좋아 기본 선택으로 쓰인다.

Ordinary Momentum Nesterov Momentum
gradient 평가 지점 현재 \(\theta\) lookahead \(\theta + \alpha v\)
해석 과거 평균 + 현재 기울기 과거 평균 + 미래 예측 지점의 기울기
실전 성능 기준 일반적으로 더 좋음

6.3 파라미터 초기화 전략 (bias 제외)

좋은 골짜기 안에서 출발하면 골짜기를 탈출할 걱정 자체가 없다 — 초기화는 머신러닝 최적화에서 가장 중요한 요소 중 하나다. 다만 단 하나의 silver bullet은 없고, 잘 작동한다고 알려진 heuristic들의 모음이 있다.

6.3.1 기본 선택지와 “크기(magnitude)” 문제

  • 어떤 분포에서 샘플링? Gaussian 분포 또는 일정 범위의 Uniform 분포가 표준.
  • 크기가 중요한가? 그렇다. 초기값의 magnitude는 ① 최적화 절차의 결과와 ② 네트워크의 generalization 능력 모두에 영향을 준다. 그러나 “크면 항상 좋다/작으면 항상 좋다” 같은 단일 경향은 없다 — 곡면(즉 데이터와 목적함수)에 따라 달라진다.
  • MLP에 대한 처방: 입력 \(m\)개, 출력 \(n\)개의 층이라면 다음 uniform 분포가 좋은 출발점을 준다고 알려져 있다.

\[ W_{ij} \sim U\!\left(-\frac{1}{\sqrt{m}},\; \frac{1}{\sqrt{m}}\right) \]

6.3.2 Xavier (Glorot) initialization [Glorot & Bengio, 2010]

또 다른 처방인 normalized initialization (통칭 Xavier init):

\[ W_{ij} \sim U\!\left(-\sqrt{\frac{6}{m+n}},\; \sqrt{\frac{6}{m+n}}\right) \]

핵심 설계 철학은 두 목표 사이의 타협(compromise) 이다.

  1. 모든 층이 같은 activation variance를 갖도록 초기화 (forward 신호 보존)
  2. 모든 층이 같은 gradient variance를 갖도록 초기화 (backward 신호 보존)
Important왜 variance 균형이 최적화를 살리는가 — 인과 사슬

층별 activation variance와 gradient variance가 일정 범위 안에 유지되면 → 어떤 층에서도 신호가 폭발/소멸하지 않고 → loss 곡면의 국소적 cliff·폭발이 억제되어 → 마치 매끄러운 surrogate loss를 최적화하는 것처럼 국소 굴곡을 건너뛰며 안정적으로 하강한다. variance를 범위 안에 regularize하는 것이 학습을 잘 constrain하는 셈이다.

가정과 그 한계: 이 유도는 “네트워크가 비선형성 없는 행렬 곱의 사슬로만 구성된다”는 가정 위에서 성립한다. 물론 실제 네트워크는 입력–출력 사이에 수많은 비선형 activation을 갖는다. 가정이 깨지는데도 실전에서 꽤 잘 작동하기 때문에 표준으로 쓰인다.

6.3.3 Gain factor — 비선형성에 대한 보정 [Saxe et al., 2013]

ReLU를 쓴다고 하자. activation의 절반가량이 음수라면 그 절반은 0으로 죽고, activation variance도 그 비율만큼 죽는다. Xavier가 맞춰 놓은 activation–gradient variance 균형이 무너지는 것이다.

보정: 죽은 만큼의 magnitude를 gain factor로 되살린다. ReLU라면 분산이 절반으로 죽으므로 \(\times 2\) (가중치 표준편차 기준 \(\times\sqrt{2}\)) 보정 — 일반적으로는 음수 activation이 발생하는 비율에 맞춘 배율을 곱한다. 이렇게 비선형성을 “시뮬레이션”해 variance 균형을 복원하면, 더 적은 iteration으로 좋은 local minimum에 도달한다. gain factor의 중요성은 이후 연구 [Sussillo, 2014]에서도 확인되었다. (ReLU용 gain을 정식화한 것이 He initialization 계열이다.)

6.3.4 Sparse initialization [Martens, 2010]

같은 시기에 제안된 또 다른 갈래: 파라미터의 다수를 0으로 초기화하는 방식도 좋은 초기점을 줄 수 있어 여러 응용에서 널리 쓰인다.

초기화 분포 설계 원리
Naive uniform \(U(-1/\sqrt{m}, 1/\sqrt{m})\) fan-in 기준 스케일링
Xavier (Glorot) \(U\!\big(-\sqrt{6/(m{+}n)}, \sqrt{6/(m{+}n)}\big)\) activation var ↔︎ gradient var 균형 (선형 가정)
Xavier + gain 위 \(\times\) gain 비선형성으로 죽는 variance 보정 (ReLU: gain \(=\sqrt{2}\))
Sparse init 다수를 0으로 유효 fan-in 제한

7 무선통신 관점의 직관

딥러닝 개념 무선통신 대응물 연결 고리
Condition number / ill-conditioning LMS 적응 필터의 수렴 속도가 입력 상관행렬 \(R\)의 eigenvalue spread \(\lambda_{\max}/\lambda_{\min}\)에 지배되는 것; MIMO 채널 행렬의 condition number 동일한 수학이다. eigenvalue spread가 크면 LMS의 단일 step size \(\mu\)가 빠른 모드와 느린 모드를 동시에 만족 못 함 — GD의 learning rate 민감성과 정확히 같은 현상

Gradient clipping 송신단 PAPR 제한 / 진폭 clipping 비정상적으로 큰 순간값을 임계로 잘라 시스템을 보호하는 heuristic이 실전 표준이 된 것까지 닮음
Vanishing gradient (깊이 축) 다중 hop 중계에서 hop마다 곱해지는 감쇠 이득 \(<1\)인 단이 연쇄되면 신호가 지수적으로 소멸 — amplify-and-forward(= skip connection류) 장치가 필요

8 Python 부록: 핵심 현상 재현

import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(0)

# ---------- 1. Ill-conditioning: condition number와 GD ----------
# f(x) = 0.5 x^T A x,  A = diag(1, kappa)
def gd_path(kappa, lr, steps=60, momentum=0.0, nesterov=False):
    A = np.diag([1.0, kappa])
    x = np.array([8.0, 1.0]); v = np.zeros(2)
    path = [x.copy()]
    for _ in range(steps):
        g_point = x + momentum * v if nesterov else x
        g = A @ g_point
        v = momentum * v - lr * g
        x = x + v
        path.append(x.copy())
    return np.array(path)

fig, axes = plt.subplots(1, 3, figsize=(15, 4))
for ax, kappa in zip(axes, [1, 10, 50]):
    A = np.diag([1.0, kappa])
    xs = np.linspace(-9, 9, 200); ys = np.linspace(-3, 3, 200)
    X, Y = np.meshgrid(xs, ys)
    Z = 0.5 * (A[0, 0] * X**2 + A[1, 1] * Y**2)
    ax.contour(X, Y, Z, levels=20, alpha=0.4)
    p = gd_path(kappa, lr=1.8 / kappa)   # 큰 고유값 기준으로 안전한 lr
    ax.plot(p[:, 0], p[:, 1], "o-", ms=3)
    ax.set_title(f"condition number = {kappa}")
plt.suptitle("kappa가 클수록: 가파른 축은 진동, 완만한 축은 정체")
plt.tight_layout(); plt.show()

# ---------- 2. Noisy gradient + Momentum = low-pass filter ----------
def sgd_1d(momentum=0.0, lr=0.05, noise=2.0, steps=300):
    x, v = 6.0, 0.0
    xs = []
    for _ in range(steps):
        g = 2 * x + noise * rng.standard_normal()   # f(x)=x^2 + gradient noise
        v = momentum * v - lr * g
        x = x + v
        xs.append(x)
    return np.array(xs)

plt.figure(figsize=(8, 4))
plt.plot(sgd_1d(momentum=0.0), label="SGD (no momentum)", alpha=0.7)
plt.plot(sgd_1d(momentum=0.9), label=r"SGD + momentum ($\alpha=0.9$)", lw=2)
plt.axhline(0, color="k", ls="--", lw=0.8)
plt.legend(); plt.title("Momentum = gradient noise의 저역통과 필터링")
plt.xlabel("iteration"); plt.ylabel("x"); plt.show()

# ---------- 3. Xavier init: 층을 지나며 activation variance 보존 ----------
def forward_variance(init, depth=30, width=512, act=np.tanh):
    x = rng.standard_normal((1000, width))
    var_hist = []
    for _ in range(depth):
        if init == "naive":
            W = rng.normal(0, 0.5, (width, width))           # 너무 큰 분산
        elif init == "small":
            W = rng.normal(0, 0.01, (width, width))          # 너무 작은 분산
        elif init == "xavier":
            limit = np.sqrt(6 / (width + width))
            W = rng.uniform(-limit, limit, (width, width))
        x = act(x @ W)
        var_hist.append(x.var())
    return var_hist

plt.figure(figsize=(8, 4))
for init in ["naive", "small", "xavier"]:
    plt.semilogy(forward_variance(init), label=init)
plt.legend(); plt.xlabel("layer depth"); plt.ylabel("activation variance (log)")
plt.title("Xavier init만 깊이에 걸쳐 variance를 보존 (폭발도 소멸도 없음)")
plt.show()

9 1분 치트시트

  • risk vs. empirical risk: 전자는 \(p_{\text{data}}\) 기대값(목표), 후자는 훈련셋 평균(ERM, 실제로 푸는 것). pure optimization과의 가장 큰 차이 = 목적이 proxy라는 점.
  • Newton’s method: \(x^* = x_0 - H^{-1}g\) (2차 Taylor). convex면 최적 step. 딥러닝에선 ① Hessian 비용 ② 복잡 곡면에서 무의미 ③ saddle point에 끌림 때문에 폐기.
  • Condition number \(\kappa = |\lambda_{\max}/\lambda_{\min}|\). 클수록 step size 튜닝 불가능 지대. 고차원 → 거의 항상 ill-conditioned.
  • Saddle point 동전 논증: minimum이려면 고유값 전부 양수 → 고차원에서 지수적으로 희박. random matrix theory: 낮은 \(J\)의 critical point는 minimum, 높은 \(J\)는 saddle.
  • Cliff → gradient clipping (norm 임계 절단). Vanishing gradient ← 깊이 축 long-term dependency.
  • Inexact gradient → 매끄러운 surrogate loss 설계가 해법이자 열린 문제.
  • Local↔︎global 불일치: 국소적으로 loss가 올라도 언덕 너머 더 좋은 minimum이 있을 수 있다 — loss 곡선만으론 판단 불가, 평가는 test로.
  • 이론적 태도: 전역 minimum은 포기, “충분히 낮은 loss → 좋은 generalization”이 목표.
  • 시각화 교훈: 복잡한 곡면 밑에 단조 감소하는 linear subspace가 존재; factored linear model이 정성적 거동을 포착.
  • Optimizer의 정체: 전부 SGD. 차이는 learning rate scheduling뿐.
  • Momentum: \(v \leftarrow \alpha v - \epsilon \nabla J\), \(\theta \leftarrow \theta + v\). 과거 gradient의 EMA = 관성. \(\alpha\)는 민감한 hyperparameter.
  • Nesterov: gradient를 lookahead 지점 \(\theta + \alpha v\)에서 계산 — 낡은 gradient 방지, 실전 기본값.
  • 초기화: 크기가 결과를 좌우. MLP: \(U(-1/\sqrt{m}, 1/\sqrt{m})\). Xavier: \(U(\pm\sqrt{6/(m{+}n)})\) — activation var ↔︎ gradient var 타협, 선형 가정이지만 실전 유효. ReLU 등 비선형엔 gain factor(ReLU: 분산 \(\times 2\)) 보정. sparse init도 한 갈래.
  • 다음 주제: learning rate scheduling — 고전적 방법과 AdaGrad / RMSProp / Adam.
