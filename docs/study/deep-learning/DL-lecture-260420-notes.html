CNN의 진화에서 시퀀스 모델링까지: 역사·아키텍처·RNN

ImageNet 시대의 CNN, ViT/gMLP, 그리고 동역학계로서의 RNN

Published

April 20, 2026

1 개요

이 노트는 두 개의 큰 흐름을 다룬다. 첫째는 CNN의 후반부로, 합성곱 연산의 확장(dilated/transposed convolution, separable/group convolution)과 ImageNet 시대를 연 아키텍처 계보(LeNet → AlexNet → GoogLeNet → ResNet), 그리고 CNN 이후의 패러다임인 Vision Transformer(ViT)와 gMLP를 정리한다. 둘째는 시퀀스 모델링으로, 가변 길이 데이터를 다루기 위한 동역학계(dynamical system) 관점에서 RNN을 유도하고, 장기 의존성 학습이 왜 어려운지를 고유값 분해로 설명한 뒤 게이팅(LSTM/GRU)·양방향·Seq2Seq로 확장한다.

두 주제를 관통하는 핵심 메시지는 다음 한 줄로 요약된다.

“데이터의 구조적 불변성(invariance)을 모델의 가중치 공유(weight sharing)로 인코딩하면, 적은 파라미터로 효율적인 표현 학습이 가능하다.”

CNN은 공간 정상성(spatial stationarity) 을, RNN은 시간 정상성(temporal stationarity) 을 가정한다. 둘 다 “같은 함수를 위치/시간에 걸쳐 반복 적용”한다는 점에서 본질적으로 같은 아이디어다.

Tip무선통신 관점에서의 큰 그림
  • CNN의 가중치 공유 = 공간 이동 불변(shift-invariant) 필터.
  • RNN = 외부 입력으로 구동되는 상태공간 모델(state-space model). 한 스텝 순환 연산은 사실상 IIR 필터(피드백 있는 무한 임펄스 응답) 이고, 슬라이딩 윈도(이동 평균)는 FIR 필터다.
  • 뒤에서 보겠지만 RNN의 그래디언트 소실/폭발은 이산시간 LTI 시스템의 안정성(극점의 단위원 내부/외부) 과 정확히 같은 수학이다.

2 CNN 후반부: 합성곱의 확장과 변형

2.1 Dilated(atrous) convolution

한 줄 요약: 커널 원소 사이를 일정 간격으로 “건너뛰며” 적용해, 파라미터 수를 늘리지 않고 수용 영역(receptive field) 을 키운다.

  • stride와 비슷하지만 다르다. stride는 출력을 띄엄띄엄 만들고, dilation은 커널 내부를 띄엄띄엄 배치한다.
  • 건너뛰는 점의 개수를 dilation rate \(d\) 라 한다. \(d=2\) 면 커널 원소 사이에 한 칸씩 빈 공간을 둔다.
  • 유효 커널 크기: \(k_{\text{eff}} = k + (k-1)(d-1)\). 즉 \(3\times3\) 커널을 \(d=2\) 로 쓰면 유효 크기는 \(5\times5\) 이지만 학습 파라미터는 여전히 9개다.

\[ y[i] = \sum_{m} x[i + d\cdot m]\, w[m] \]

2.2 Transposed convolution (a.k.a. deconvolution)

한 줄 요약: “deconvolution”이라는 이름은 오해의 소지가 있다. 역연산이 아니라 전치 합성곱(transposed convolution) 이며, 해상도를 키우는(upsampling) 데 쓴다.

  • 연산 자체는 합성곱과 동일하다(곱하고 더하기). 다만 입력-출력의 공간 크기 관계가 반대다.
  • 신호및시스템(430.306)에서 다루는 deconvolution(역합성곱)과는 의미가 다르다. 여기서는 합성곱 행렬 \(C\) 의 전치 \(C^\top\) 를 적용한다고 이해하면 정확하다.

\[ \underbrace{\mathbf{y} = C\,\mathbf{x}}_{\text{conv (downsample)}} \qquad\Longleftrightarrow\qquad \underbrace{\mathbf{z} = C^{\top}\mathbf{u}}_{\text{transposed conv (upsample)}} \]

어디에 쓰는가? 픽셀 단위 예측이 필요한 과제. 대표적으로 FCN(Fully Convolutional Network) 의 의미론적 분할(semantic segmentation)에서 다운샘플링된 특징맵을 원본 해상도로 복원할 때 사용한다.

Note무선통신 analogy — 전치 합성곱 = 보간(interpolation) 필터

전치 합성곱은 다운샘플링된 신호에 0을 끼워 넣고(zero-insertion / upsampling) 필터를 통과시키는 보간 필터뱅크와 구조가 동일하다. 합성곱이 데시메이션(decimation)이라면, 전치 합성곱은 인터폴레이션(interpolation)이다.

2.3 효율적 합성곱: separable / group convolution

한 줄 요약: 표준 합성곱을 더 작은 연산들의 곱으로 분해해 곱셈 횟수와 파라미터를 줄인다.

  • Separable convolution: \(k\times k\) 2D 커널을 \(k\times1\) 과 \(1\times k\) 의 연속 적용으로 분해(랭크-1 가정). 연산량이 \(O(k^2)\) 에서 \(O(2k)\) 로 감소.
    • depthwise-separable은 한 발 더 나아가 (채널별 공간 합성곱) + (1×1 점별 합성곱)으로 분해한다(MobileNet 계열의 핵심).
  • Group convolution: 입력 채널을 \(g\) 개 그룹으로 나누어 각 그룹 안에서만 합성곱. 병렬화에 유리하고 파라미터를 \(1/g\) 로 줄인다(AlexNet의 2-GPU 분할이 원조).
Note무선통신 analogy — separable filter = 분리가능 커널

2D 영상 처리의 분리가능 필터(예: 가우시안 블러를 행 필터·열 필터로 분해)와 정확히 같은 아이디어다. 랭크-1 근사가 성립하면 외적(outer product) 한 쌍으로 2D 필터를 표현할 수 있어 곱셈 비용이 급감한다.

2.4 구조적 출력과 입력 데이터 타입

CNN의 출력은 과제에 따라 다양한 형태를 가진다.

출력 형태 과제 예시
단일 레이블 이미지 분류 ImageNet 분류
픽셀별 레이블 의미론적 분할 FCN
그래프(2D 행렬) 관계/구조 예측 인접 행렬 표현

입력 데이터 타입도 영상에 국한되지 않는다.

  • 스펙트로그램: 오디오 파형을 시간-주파수 평면으로 변환하면 사실상 “이미지”가 되어 CNN으로 처리 가능.
  • AlphaGo 입력: 바둑판을 \(19\times19\) 격자에 여러 특징 평면 \([X_t, Y_t, X_{t-1}, Y_{t-1}, \dots, C]\) 으로 쌓아 CNN에 투입.
Tip무선통신 analogy — 파형을 이미지로

파형 \(\to\) 스펙트로그램(STFT) \(\to\) CNN 입력의 흐름은, 시간 영역 신호를 시간-주파수 표현으로 옮겨 2D 패턴 인식 문제로 바꾸는 것이다. 변조 분류(modulation classification)에서 I/Q 샘플을 스펙트로그램으로 변환해 CNN에 넣는 접근과 동일하다.

2.5 임의/비지도 필터, 그리고 생물학적 근거

  • CNN 필터는 보통 지도 신호로 학습하지만, 무작위 필터도 의외로 꽤 잘 작동한다(Jarrett 2009; Saxe 2011 등). 이는 합성곱 구조 자체가 좋은 귀납 편향(inductive bias)임을 시사한다.
  • 비지도 방식으로 필터를 학습하는 대표 예가 대조 학습(contrastive learning): 같은 이미지의 패치는 양성쌍, 다른 이미지의 패치는 음성쌍으로 둔다.
  • 신경과학적 근거: CNN 연산은 1차 시각피질(V1)의 처리와 닮았다. V1의 단순세포(simple cell)는 CNN의 선형 필터에, 복잡세포(complex cell)는 풀링 유닛에 대응한다. 학습된 CNN 필터가 V1의 Gabor 필터와 유사하게 나타난다는 점도 흥미롭다.

3 ImageNet 시대와 아키텍처 계보

3.1 ImageNet: 르네상스의 방아쇠

한 줄 요약: 대규모 라벨 데이터셋의 등장이 CNN 부흥의 결정적 계기였다.

  • 2009년 Fei-Fei Li가 Princeton에서 구축(WordNet에서 영감). 전체 1,400만 장 / 2.4만 카테고리.
  • 실제로 널리 쓰이는 챌린지 부분집합은 ImageNet-1K: 120만 장 / 1,000 카테고리. 대규모 이미지 분류의 표준 벤치마크.
  • 성능 추이: 2009년경 오류율 약 35%(정확도 ~64%)에서 2011년 약 27~28%까지 점진 개선. 여전히 큰 간극이 남아 있었다.

3.2 핵심 아키텍처 계보

LeNet (1998). Yann LeCun이 손글씨 숫자 인식을 위해 제안한 최초의 실용적 CNN.

AlexNet (2012). Krizhevsky et al., “ImageNet Classification with Deep Convolutional Neural Networks”, NIPS 2012.

  • 구조: 7층(합성곱 5 + 완전연결 2), LeNet과 유사하나 GPU로 1,000 카테고리를 학습.
  • 성능: 오류율 16% — 직전 해 대비 약 10%p 감소. 이 도약이 딥러닝 르네상스의 “암묵적 출발점”이 되었다.

GoogLeNet (2014). Google. 100층 이상, 고성능 GPU로 1주일 이상 학습. 이름의 중간 대문자 L은 LeNet에 대한 오마주다.

ResNet (2015). Microsoft Research Asia, Kaiming He et al., CVPR 2016.

  • 잔차 연결(residual / highway connection) 으로 152층~1,001층까지 쌓음. Yann LeCun이 “ultra deep”이라 평.
  • 핵심: 마지막 층에서 계산된 그래디언트가 중간층의 간섭 없이 앞쪽으로 그대로 전파되는 통로를 만들어 그래디언트 소실을 완화. (뒤의 Section 8 와 직접 연결되는 아이디어다.)
  • 결과: ImageNet-1K에서 인간 성능(오류율 약 5%)을 처음으로 돌파.
Warning’인간 초월’이라는 표현의 함정

ResNet이 ImageNet-1K에서 인간을 넘어선 이유 중 하나는, 이 데이터셋에 미세 분류(fine-grained) 견종 클래스가 많기 때문이다. 인간은 골든리트리버와 비슷한 다른 견종을 구분하기 어렵지만, 모델은 텍스처·얼굴·형태의 미세 차이에 집중할 수 있다.

따라서 “딥러닝이 객체 인식에서 인간을 넘어섰다”는 일반화는 오해의 소지가 있다. 각 벤치마크는 고유의 편향과 선호를 가진다. “특정 벤치마크에서, 특정 다른 알고리즘 대비” 우수하다는 좁은 진술로 받아들여야 한다.

4 CNN 다음: Transformer, ViT, gMLP

4.1 Transformer와 Vision Transformer

한 줄 요약: NLP에서 출발한 Transformer(Vaswani et al., “Attention Is All You Need”, 2017)를 영상에 적용한 것이 ViT(Dosovitskiy et al., “An Image is Worth 16×16 Words”, ICLR 2021)다.

  • 핵심 발상: 이미지를 패치(patch)의 시퀀스로 본다. 각 패치를 “단어”처럼 토큰화하고, 토큰 간 문맥 정보를 어텐션으로 인코딩한다.
  • ViT는 CNN을 “이기기 위한” 것이 아니라 다른 종류의 연산으로 같은 정보를 인코딩하는 접근이다.

4.2 ViT vs CNN: 층수와 병렬성의 trade-off

한 줄 요약: ViT는 층수가 훨씬 적지만(예: ~32층) 한 층의 연산이 더 복잡하다. 적은 층수는 병렬화·에너지 효율에서 이점이 된다.

핵심 논리는 다음과 같다.

  1. ResNet은 152층까지 쌓는 반면, ViT-L은 약 32층으로 유사한 성능을 낸다.
  2. 한 층 안에 어텐션을 포함한 복잡한 연산(여러 CNN층에 상당)이 들어 있어 “공짜 점심”은 없다 — 층당 계산 비용은 크다.
  3. 그러나 층은 순차적(cascade) 이다. 다음 층 연산은 이전 층이 끝나야 시작된다. 따라서 층수가 적을수록 깊이 방향 직렬 의존이 줄어 병렬화에 유리하다.
  4. 결과적으로 GPU가 많을수록 ViT는 시간 효율이 좋고, 층수 감소로 전체 에너지 소비도 줄어드는 경향.

\[ \text{총 지연} \;\approx\; \underbrace{L}_{\text{직렬(층수)}}\times \underbrace{(\text{층당 계산}/P)}_{\text{병렬화 가능}},\qquad P=\text{병렬 자원} \]

층당 계산은 \(P\) 로 나눠 줄일 수 있지만, 층수 \(L\) 은 직렬이라 나눌 수 없다. 그래서 \(L\) 을 줄이는 것이 지연 단축의 핵심이다.

Note무선통신 analogy — 직렬 vs 병렬 처리

다단(multi-stage) 수신기에서 각 단을 더 무겁게 만들되 단 수를 줄이는 것과 같다. 단 수(직렬 깊이)는 파이프라인 지연을 결정하고, 단 내부 연산은 다수의 처리 코어로 병렬화 가능하다. 처리량(throughput) 대비 지연(latency) 최적화의 전형적 trade-off다.

4.3 gMLP와 멀티모달리티

  • gMLP (Liu et al., “Pay Attention to MLPs”, NeurIPS 2021): ViT의 이점이 어텐션 자체가 아니라 채널별 투영 + 공간 게이팅(spatial gating) + 정규화·활성 구조에서 온다고 주장. 더 단순한 구조로 비슷한 성능을 보였으나, 아직 어텐션만큼 널리 쓰이지는 않는다.
  • 멀티모달리티: 입력을 토큰으로 바꾸기만 하면 텍스트·영상·오디오(스펙트로그램)에 동일한 Transformer 구조를 쓸 수 있다. 이 균질성(homogeneity) 덕분에 NVIDIA는 Transformer 연산을 하드웨어(Transformer Engine)로 구현해 시간·에너지 효율을 끌어올렸다.

4.4 CNN 요약

ImportantCNN 핵심 정리
  • CNN은 2D 정보를 효율적으로 인코딩한다. MLP가 모든 위치를 독립적으로 학습하는 것과 달리, CNN은 공간 정상성을 이용해 가중치를 공유한다 → 적은 파라미터, 적은 학습 샘플로 학습 가능.
  • 구성요소: 합성곱층(정상성 가정) + 풀링층(국소적 노이즈/잉여 정보 폐기) + MLP(최종 의미 추출/분류).
  • 합성곱층이 입력을 컴팩트한 표현으로 압축하면, 그 위의 MLP가 회귀/분류를 담당한다.
  • 현재 많은 2D 인코딩 과제에서 ViT가 CNN을 대체하고 있다(계산 효율·병렬성·멀티모달리티 때문). 다만 일부 응용에서는 CNN형 구조가 여전히 우위를 가진다.

5.1 세 가지 대표 응용

컴퓨터 비전 이미지/비디오 분석 YOLO(객체 탐지)

세 분야 모두 결국 시퀀스 모델링을 필요로 한다. 텍스트는 단어의 나열, 음성은 파형의 나열, 비디오는 프레임의 나열이다.

5.2 스냅샷 데이터 vs 시퀀스 데이터

지금까지 다룬 것은 길이가 정해진 “스냅샷” 데이터(이미지, 그래프, 객체)였다. 이제 다룰 것은 가변 길이를 갖는 데이터다.

  • 언어(텍스트), 주가(시간), 비디오, 오디오
  • 핵심 차이: 입력 길이를 미리 알 수 없다 → 가변 길이를 다룰 인코딩이 필요.

5.3 핵심 도전: 장기 의존성

시퀀스 모델링의 두 가지 근본 난제:

  1. 가변 길이 처리. 길이가 매번 달라지므로 같은 모델로 다양한 길이를 받아야 한다.
  2. 시간에 걸친 기억(장기 의존성). 더 큰 난제다. 결론에 도달할 때까지 과거 문맥을 유지해야 하는데, 신경망은 시계열 기억에 약하다.

왜 어려운가? 여러 단계를 거쳐 전파되는 그래디언트가 대부분 소실(vanish) 되거나 드물게 폭발(explode) 하기 때문이다(폭발은 드물지만 최적화에 큰 손상을 준다).

Note비디오 이해의 한계 — 구체적 예

5분짜리 비디오에서 소년이 공을 차는 장면이 5초 정도 등장한다고 하자. “이 소년은 무엇을 하고 있나?”라고 물으면 모델은 “공을 들고 있다”거나 “드리블한다”는 식의 부정확한 답을 내기 쉽다. 5분 × 30 fps = 약 9,000 프레임을 시간적으로 통합해 핵심 순간을 기억해야 하는데, 현재 모델은 이런 시간적 통합을 잘 전파하지 못한다. 비디오 이해는 여전히 열린 연구 주제다.

Tip현대적 우회 — KV 캐시와 긴 문맥

“시간에 걸쳐 기억”을 제대로 못 하니, 대신 모든 과거 토큰을 입력으로 저장해 버리는 우회책이 쓰인다.

  • LLM은 사용자 입력 외에 긴 시스템 프롬프트까지 함께 처리한다(예: “공격적 표현 금지” 등).
  • 과거 토큰을 KV 캐시(key-value cache) 로 저장해 재사용. 처리 가능한 문맥이 2만 토큰에서 12.8만 토큰 이상으로 확장되었다.
  • 이는 본질적으로 “시간 기억을 포기하고 입력으로 저장”하는 전략이다. 최근에는 이 토큰들을 압축하는 연구(예: Google의 Titans 계열)가 활발하다.
  • 진짜 좋은 시간 기억 아키텍처를 만든다면 — 그것은 큰 미해결 문제다.

6 동역학계로서의 RNN

6.1 고전적 동역학계

한 줄 요약: RNN은 “상태가 시간에 따라 진화하는 시스템”을 신경망으로 구현한 것이다.

외부 입력 없는 가장 단순한 동역학계:

\[ s^{(t)} = f\!\left(s^{(t-1)};\, \theta\right) \]

  • \(s^{(t)}\): 시각 \(t\) 에서의 시스템 상태(state).
  • 초기 상태가 주어지면 시스템은 자기 자신을 입력으로 받아 상태를 갱신한다.
  • 시간으로 펼치면(unfold) \(s^{(t)} = f(f(\cdots f(s^{(0)})\cdots))\) 의 함수 합성이 된다.

6.2 외부 입력으로 구동되는 시스템

외부 신호 \(x^{(t)}\) 가 시스템을 구동하면:

\[ s^{(t)} = f\!\left(s^{(t-1)},\, x^{(t)};\, \theta\right) \]

이제 상태 \(s^{(t)}\) 는 과거 전체 시퀀스의 정보를 담는다. 이 상태를 은닉 상태(hidden state) \(h^{(t)}\) 라 이름 붙여 구현한 것이 바로 RNN이다.

\[ \boxed{\,h^{(t)} = f\!\left(h^{(t-1)},\, x^{(t)};\, \theta\right)\,} \]

Note왜 ‘은닉(hidden)’ 상태인가

사용자는 입력 \(x\) 를 주고 출력만 받는다. 상태 \(h\) 는 시스템 내부에 있어 사용자에게 직접 보이지 않으므로 “은닉” 상태라 부른다. 표기도 상태(state)의 \(s\) 가 아니라 hidden의 \(h^{(t)}\) 를 쓴다.

6.3 RNN의 정의와 입출력

  • 입력: 현재 시각 데이터 \(x^{(t)}\) 와 과거 은닉 상태 \(h^{(t-1)}\).
  • 출력: 현재 시각 모델 출력 \(o^{(t)}\) 와 다음 시각으로 넘길 은닉 상태 \(h^{(t)}\).

6.4 One-step RNN: 필터 관점

세 가지 연산을 비교하면 RNN의 정체가 드러난다.

연산 식 성격
비순환(memoryless) \(f(x_t)=w x_t + b\) 기억 없음
슬라이딩 윈도(이동 평균) \(f(x_t,x_{t-1})=w_1 x_t + w_2 x_{t-1} + b\) FIR (유한 기억)
한 스텝 순환 \(f(x_t,x_{t-1})=w_1 x_t + w_2\,f(x_{t-1},x_{t-2}) + b\) IIR (피드백, 무한 기억)

바닐라 RNN 셀은 보통 다음과 같이 쓴다(활성 함수는 \(\tanh\)).

\[ h^{(t)} = \tanh\!\left(W_{hh}\,h^{(t-1)} + W_{xh}\,x^{(t)} + b\right), \qquad o^{(t)} = W_{ho}\,h^{(t)} + c \]

Tip무선통신 analogy — RNN = IIR 필터/상태공간 모델
  • 비순환 → 메모리리스(memoryless) 채널.
  • 이동 평균 → FIR 필터: 출력이 과거 유한 개 입력의 가중합. 항상 안정.
  • 한 스텝 순환 → IIR 필터: 출력에 자기 피드백이 있어 임펄스 응답이 무한히 이어진다. 이 피드백 때문에 안정성(고유값/극점 위치) 이 문제가 된다 — 이것이 바로 그래디언트 소실/폭발의 근원이다(Section 8).
  • RNN의 은닉 상태 \(h^{(t)}\) 는 칼만 필터의 상태 추정치, 혹은 채널의 누적 상태와 같은 역할을 한다.

6.5 순환 구조의 두 가지 이점과 그 가정

  1. 가변 길이 무관성: 시퀀스 길이와 상관없이 학습된 모델의 입력 크기는 항상 같다(\(x^{(t)}\) 하나). \(n-1\) 이든 \(n+\delta\) 든 같은 RNN을 반복 적용.
  2. 파라미터 공유: 매 시각 같은 전이 함수 \(f\) 와 같은 파라미터 \(\theta\) 를 사용한다. 이는 CNN의 공간 정상성에 대응하는 시간 정상성(temporal stationarity) 가정이다.
Warning시간 정상성은 강한 가정이다

같은 함수를 모든 시각에 적용한다는 것은, 시퀀스가 시간적으로 정상(stationary)이라는 가정을 깐다. 그러나 한 문장이 말하는 바와 다음 문장이 말하는 바는 다를 수 있다 — 즉 데이터 생성 분포가 시간에 따라 바뀐다(non-stationary). 그런데도 같은 전이 함수를 쓰므로 가정 위배가 생긴다. 이것이 바닐라 RNN이 긴 시퀀스의 단어를 잘 인코딩하지 못하는 한 이유다.

무선통신 관점: WSS(wide-sense stationary) 가정으로 LTI 필터를 설계했는데 실제 채널이 시변(time-varying)인 상황과 같다. 정상성이 깨지면 단일 시불변 필터로는 부족하다.

7 RNN의 세 가지 유형

순환 구조로 다양한 RNN을 설계할 수 있다.

7.1 Type 1: 은닉-은닉 순환

매 시각 출력을 내고, 은닉 유닛 사이에 순환 연결을 갖는다. 가장 표준적인 형태.

\[ \begin{aligned} h^{(t)} &= \tanh\!\left(W_{hh}h^{(t-1)} + W_{xh}x^{(t)} + b\right)\\ o^{(t)} &= W_{ho}h^{(t)} + c \end{aligned} \]

매 시각 출력과 은닉 상태를 모두 내보내며, 은닉 상태가 시간에 걸쳐 전파된다. 매 시각 결과가 필요하면 이 유형을 쓴다.

7.2 Type 2: 출력→은닉 순환 (Teacher forcing)

출력은 매 시각 내지만, 순환 연결이 출력에서 다음 은닉 유닛으로만 간다(은닉-은닉 직접 연결 없음).

  • 장점: 학습 병렬화가 쉽다. 은닉 상태를 직렬로 기다릴 필요 없이, 각 시각의 출력에 대한 손실을 거의 즉시 계산할 수 있어 시각별 학습을 병렬화한 뒤 가중치를 집계할 수 있다.
  • 단점: 은닉-은닉 직접 연결이 없어 과거 정보를 더 많이 잊는다(less powerful). 출력에서 추정한 은닉 상태는 부정확하므로 정확도가 Type 1보다 낮다. (계산상의 이득이 정확도 손실로 번역된다.)

훈련 vs 추론의 비대칭:

\[ \underbrace{\text{Training: } h^{(t)} \leftarrow y^{(t)}\ (\text{정답 라벨})}_{\text{병렬화 용이}} \qquad \underbrace{\text{Inference: } h^{(t)} \leftarrow o^{(t)}\ (\text{모델 출력로 근사})}_{\text{정답 미지}} \]

  • 훈련 시: 정답 출력 \(y^{(t)}\) 를 다음 은닉 상태의 입력으로 먹인다(teacher forcing). 정답이 주어지므로 시각별로 분리해 병렬 학습 가능.
  • 추론 시: 정답을 모르므로 모델 출력 \(o^{(t)}\) 로 근사해 다시 모델에 먹인다.
Note무선통신 analogy — 판정 귀환 등화기(DFE)

추론 시 자신의 출력을 되먹이는 구조는 판정 귀환 등화기(Decision-Feedback Equalizer) 와 닮았다. 훈련 시엔 정답(파일럿/훈련 시퀀스)을 되먹이지만, 운용 시엔 자신의 판정값을 되먹인다. 판정 오류가 누적·전파될 수 있다는 단점까지 동일하다.

7.3 Type 3: 시퀀스 전체 → 단일 출력

은닉-은닉 순환 연결을 가지되, 전체 시퀀스를 다 읽고 마지막에 단일 출력만 낸다. 나머지 구조는 Type 1과 유사.

  • 시퀀스 모델링의 표준 선택. 예: 질의응답(QA). “현재 미국 대통령은 누구인가?”라는 질문의 모든 단어를 인코딩하고, 중간 출력 없이 문장 끝에서 답을 낸다.
  • 마지막에 정답 라벨과 손실을 계산하고 시간 역전파(BPTT)로 학습.
  • 단, 은닉 상태 정보를 끝까지 전파해야 하므로 정보가 자주 손실된다 → 외부 메모리/게이팅의 동기가 된다(Section 9.1).

8 장기 의존성 학습은 왜 어려운가

8.1 함수 합성과 비선형성의 증폭

한 줄 요약: 단순한 비선형 함수라도 여러 번 합성하면 극도로 비선형이 된다.

매우 단순한 비선형 함수 \(f\) 를 한 번 적용하면 완만한 곡선이지만, 두 번·세 번·…·열 번 합성(\(f\circ f\circ\cdots\circ f\))할수록 중간에 굴곡(ridge)이 급격히 늘어난다. 10단어 문장이면 \(f\) 를 10번, 300단어 문단이면 300번 합성한다. 그 결과 RNN이 인코딩하는 함수는 엄청나게 복잡하고 비틀린(torsion) 함수가 되어 최적화가 어렵다.

\[ h^{(t)} = \underbrace{f\circ f \circ \cdots \circ f}_{t\text{ 번}}\,(h^{(0)}) \]

8.2 고유값 분해와 단위원

선형 근사(또는 활성 함수를 무시한 핵심부)에서 시각 \(t-1\) 과 \(t\) 사이의 전이를 \(h^{(t)} \approx W\,h^{(t-1)}\) 로 보면,

\[ h^{(t)} = W^{t}\,h^{(0)}. \]

\(W\) 를 고유값 분해 \(W = Q\,\Lambda\,Q^{-1}\) 하면,

\[ W^{t} = Q\,\Lambda^{t}\,Q^{-1}, \qquad \Lambda^{t} = \operatorname{diag}(\lambda_1^t, \dots, \lambda_n^t). \]

따라서 고유값의 크기가 거동을 지배한다.

\[ \boxed{\;|\lambda_i| < 1 \;\Rightarrow\; \lambda_i^t \to 0\ (\text{소실}) \qquad |\lambda_i| > 1 \;\Rightarrow\; |\lambda_i^t| \to \infty\ (\text{폭발})\;} \]

300번 합성하면, 1보다 살짝 작은 값은 0으로 급격히 수렴하고(그래디언트 소실), 1보다 살짝 큰 값은 폭주한다(그래디언트 폭발). 그래서 손실 표면(loss surface)이 절벽처럼 급강하/급상승해 최적화가 불안정해진다. 여기에 MLP를 층으로 더 쌓으면(deep RNN) 한 스텝에서 이미 소실된 그래디언트가 더욱 악화되어, 깊은 RNN은 사실상 쓸모없어진다.

Important무선통신 analogy — 이산시간 LTI 시스템의 안정성 (정확히 같은 수학)

이것은 이산시간 LTI 시스템의 BIBO 안정성 과 글자 그대로 같은 결과다.

  • 상태 전이 행렬 \(W\) 의 고유값 = 시스템의 극점(pole).
  • 모든 극점이 단위원 내부(\(|\lambda|<1\)): 임펄스 응답이 지수적으로 감쇠 → 안정, 그러나 먼 과거의 영향이 사라짐(= 그래디언트 소실).
  • 극점이 단위원 밖(\(|\lambda|>1\)): 응답이 발산 → 불안정(= 그래디언트 폭발).
  • 경계(\(|\lambda|=1\))에서만 장기 기억과 안정성이 양립하는데, 이 경계를 정확히 유지하기는 매우 어렵다.

즉 “장기 기억”을 원한다는 것은 시스템을 안정성의 칼날(\(|\lambda|\approx 1\)) 위에 세우려는 것과 같다. 게이팅(Section 9.1)은 이 극점을 1 근처로 데이터에 따라 적응적으로 옮기는 메커니즘으로 이해할 수 있다.

또 다른 한계는 메모리 용량이다. 보통 하나 또는 소수의 셀/게이트만으로 과거 전체를 단일 벡터에 압축하려 하므로, 긴 시계열 정보를 모두 담기에 부족하다.

장기 의존성을 다루는 다섯 갈래의 아이디어.

  2. 누설 유닛(leaky units)
  3. 게이팅(LSTM, GRU)
  4. 최적화 트릭(그래디언트 클리핑 등)
  5. 명시적 메모리

9.1 게이팅: 핵심 아이디어

한 줄 요약: 과거에서 현재(혹은 미래)로 가는 “고속도로”를 만들고, 현재 입력과 과거 메모리를 가중 혼합한다.

\[ f(x) = a\cdot x \;\longrightarrow\; f(x) = a\cdot x + (1-a)\cdot m, \qquad a\in[0,1],\ m=\text{memory} \]

\(a\) 는 0~1 사이의 게이트 값이다. 현재 입력 \(x\) 와 과거 메모리 \(m\) 을 \(a\) 의 비율로 섞는다. 이 단순한 혼합 한 줄이 게이팅의 정수다.

Tip무선통신 analogy — 망각 인자(forgetting factor)/1차 IIR 저역통과

\(m_t = a\,x_t + (1-a)\,m_{t-1}\) 은 지수 이동 평균(EMA) 이자 1차 IIR 저역통과 필터이며, RLS(재귀 최소제곱)의 망각 인자(forgetting factor) 와 같은 형태다. 극점이 \(1-a\) 에 놓이므로 \(a\) 를 작게 하면 극점이 1에 가까워져(긴 기억), 크게 하면 빠른 망각(짧은 기억)이 된다. 게이팅은 이 망각 인자를 데이터·시각마다 적응적으로 학습하는 것이다.

9.2 Gating 1: LSTM

Long Short-Term Memory (Hochreiter & Schmidhuber, 1997). 셀 상태 \(c_t\) 라는 별도의 “고속도로”를 두고, 세 개의 게이트로 정보 흐름을 제어한다.

\[ \begin{aligned} f_t &= \sigma(W_f[h_{t-1}, x_t] + b_f) &&\text{(forget gate)}\\ i_t &= \sigma(W_i[h_{t-1}, x_t] + b_i) &&\text{(input gate)}\\ o_t &= \sigma(W_o[h_{t-1}, x_t] + b_o) &&\text{(output gate)}\\ \tilde{c}_t &= \tanh(W_c[h_{t-1}, x_t] + b_c) &&\text{(candidate)}\\ c_t &= f_t \odot c_{t-1} + i_t \odot \tilde{c}_t &&\text{(cell update)}\\ h_t &= o_t \odot \tanh(c_t) &&\text{(hidden output)} \end{aligned} \]

핵심은 셀 상태 갱신 \(c_t = f_t\odot c_{t-1} + i_t\odot\tilde c_t\) 다. forget gate \(f_t\approx 1\) 이면 과거 셀 상태가 거의 그대로 전달되어 그래디언트가 보존된다(= 극점을 1 근처로 적응 배치). 이는 ResNet의 잔차 연결(Section 3.2)과 같은 정신이다.

9.3 Gating 2: GRU

Gated Recurrent Unit (Cho et al., 2014). LSTM과 거의 같은 아이디어를 더 단순하게 구현. 셀 상태와 은닉 상태를 합치고 게이트를 둘로 줄였다.

\[ \begin{aligned} z_t &= \sigma(W_z[h_{t-1}, x_t]) &&\text{(update gate)}\\ r_t &= \sigma(W_r[h_{t-1}, x_t]) &&\text{(reset gate)}\\ \tilde{h}_t &= \tanh\!\left(W[r_t \odot h_{t-1}, x_t]\right) &&\text{(candidate)}\\ h_t &= (1-z_t)\odot h_{t-1} + z_t\odot \tilde{h}_t &&\text{(혼합)} \end{aligned} \]

마지막 줄이 바로 Section 9.1 의 혼합 공식 \(a\cdot x + (1-a)\cdot m\) 의 벡터판이다.

GRU는 “LSTM이 과파라미터화되었다”는 관찰에서, 더 적은 파라미터로 비슷한 성능을 달성하려는 시도였고 성공했다.

  • Idea 1 — 시간 skip connection: 비전의 DenseNet처럼 먼 시각으로 직접 연결을 추가.
  • Idea 2 — 누설 유닛(leaky units): \(h_t = (1-\alpha)h_{t-1} + \alpha\,\sigma(W_{rec}h_{t-1} + W_{in}x_t)\). (leaky-ReLU와는 무관하다.) 위의 1차 IIR 적분기와 같은 형태.
  • Idea 3 — 게이팅: LSTM/GRU (위에서 다룸).
  • Idea 4 — 최적화 트릭: 그래디언트 클리핑(폭발 대응) + 정보 흐름을 장려하는 정규화(소실 대응).
  • Idea 5 — 명시적 메모리: Memory Networks(Weston et al., ICLR 2015) 등 외부 메모리 모듈.

10 문맥(Context) 인코딩

장기 의존성과 더불어 시퀀스 인코딩의 또 다른 핵심 난제는 문맥(context) 이다.

10.1 Buffalo 예시

영어 문장 “Buffalo buffalo Buffalo buffalo buffalo buffalo Buffalo buffalo”는 모든 단어가 같은 철자지만(지명/동물/동사), 문맥에 따라 품사와 의미가 달라지는 문법적으로 올바른 문장이다. 같은 토큰이라도 주변 문맥이 의미를 결정한다는 점을 극명하게 보여준다.

10.2 문맥 조건부 RNN과 양방향 RNN

  • 문맥 조건부 RNN (단일 입력): 과거 출력을 보는 것이 미래 예측에 도움이 된다는 발상. 미래로부터의 역방향 연결을 둔다.
  • 문맥 조건부 RNN (시퀀스 입력): 이전 시각의 은닉 상태 출력과 이전 시각의 출력을 둘 다 다음 은닉 상태의 입력으로 사용(teacher forcing과 달리 은닉 상태 연결을 유지).
  • 양방향 RNN(Bi-directional RNN): “앞뒤로 읽으면 기억에 도움이 된다.” 순방향 은닉 상태와 별도로 역방향으로 진행하는 은닉 상태를 도입해, 각 시각의 표현이 과거와 미래 문맥을 모두 본다.

\[ \overrightarrow{h}_t = f(\overrightarrow{h}_{t-1}, x_t),\qquad \overleftarrow{h}_t = f(\overleftarrow{h}_{t+1}, x_t),\qquad y_t = g\!\left(\overrightarrow{h}_t, \overleftarrow{h}_t\right) \]

Note무선통신 analogy — 필터링 vs 평활화(smoothing)

단방향 RNN은 과거만 쓰는 인과적(causal) 필터 = 칼만 필터링. 양방향 RNN은 미래 관측까지 쓰는 비인과적 평활화 = 칼만 스무딩(smoothing). 오프라인에서 전체 수열을 보고 추정하면(스무딩) 인과적 추정(필터링)보다 정확해지지만, 실시간 처리에는 쓸 수 없다. 양방향 RNN이 전체 시퀀스를 받아야만 동작하는 것과 정확히 같은 trade-off다.

12 확장 구조: Deep RNN과 Recursive NN

12.1 Deep RNN

은닉층을 여러 겹 쌓은 RNN. 표현력은 늘지만, Section 8 에서 보았듯 한 스텝에서 이미 약해진 그래디언트가 깊이까지 더해져 학습이 더 어려워진다.

12.2 Recursive Neural Networks

한 줄 요약: 사슬(chain)이 아니라 트리(tree) 구조의 계산 그래프를 쓰는 RNN의 일반화.

  • 시퀀스를 선형으로 처리하는 대신, 트리로 묶어 처리.
  • 길이 \(\tau\) 에 대해 탐색/전파 깊이가 \(\tau\) 에서 \(\log(\tau)\) 로 줄어든다 → 장기 의존성을 더 짧은 경로로 연결할 수 있어(원리상) 유리.
  • 응용: 장면 파싱(scene parsing) — 각 은닉 노드가 장면 속 객체에 대응(Socher et al., ICML 2011).
Note무선통신 analogy — 트리 구조의 깊이 단축

순차 처리의 \(O(\tau)\) 깊이를 트리로 \(O(\log\tau)\) 로 줄이는 것은, 직렬 누산을 트리형(binary-tree) 리덕션으로 바꿔 임계 경로(critical path)를 단축하는 것과 같다. FFT가 \(O(N^2)\) DFT를 \(O(N\log N)\) 으로 줄이는 분할정복의 정신과 통한다.

Important이 노트의 핵심

CNN 측

  • ImageNet(2009)이 CNN 부흥의 방아쇠. AlexNet(2012)→GoogLeNet(2014)→ResNet(2015)으로 깊이가 폭증했고, ResNet의 잔차 연결이 그래디언트 소실을 완화하며 인간 성능을 돌파.
  • CNN 이후: ViT(이미지=패치 시퀀스), gMLP. ViT는 층수가 적어 병렬화·에너지에서 유리. 토큰화로 멀티모달리티 달성.

시퀀스 모델 측

  • RNN = 외부 입력으로 구동되는 상태공간 모델, \(h^{(t)} = f(h^{(t-1)}, x^{(t)};\theta)\). 한 스텝 순환은 IIR 필터.
  • 두 이점: 가변 길이 무관성, 파라미터 공유(=시간 정상성, 단 강한 가정).
  • 세 유형: Type 1(은닉-은닉), Type 2(teacher forcing, 병렬↑/기억↓), Type 3(끝에서 단일 출력, 표준).
  • 장기 의존성이 어려운 이유 = 고유값 분해: \(|\lambda|<1\) 소실, \(|\lambda|>1\) 폭발. 이산 LTI 안정성(극점의 단위원 위치) 과 같은 수학.
  • 해결: 게이팅(LSTM/GRU = 적응적 망각 인자), skip connection, 누설 유닛, 그래디언트 클리핑, 명시적 메모리.
  • 문맥 인코딩: 양방향 RNN(=평활화), Seq2Seq(인코더 문맥 \(C\) = 의미 요약/충분통계량).

14.3 C. 게이팅(망각 인자)으로서의 EMA

Code 
import numpy as np

# m_t = a * x_t + (1 - a) * m_{t-1}   (1차 IIR 저역통과 = 적응적 망각)
a = 0.3
m, xs = 0.0, np.ones(10)   # 계단 입력
traj = []
for t in range(10):
    m = a * xs[t] + (1 - a) * m
    traj.append(round(m, 4))

print("EMA(forgetting factor) trajectory:")
print(traj)
print("steady state ->", traj[-1], "(approaches 1)")

14.4 D. RNN 유형 비교(개념 스케치)

Code 
# 의사코드 수준의 개념 비교 (실제 학습 루프는 아님)
def type1_step(h, x, params):
    h = tanh(params.Whh @ h + params.Wxh @ x)   # hidden -> hidden
    o = params.Who @ h
    return h, o

def type2_step(h, x, prev_out, params, training, y=None):
    feedback = y if training else prev_out       # teacher forcing vs 자기 출력
    h = tanh(params.Wfh @ feedback + params.Wxh @ x)  # output -> hidden
    o = params.Who @ h
    return h, o

# Type 3: 전체 시퀀스를 돌린 뒤 마지막 h로만 출력
def type3_run(xs, h, params):
    for x in xs:
        h = tanh(params.Whh @ h + params.Wxh @ x)
    return params.Who @ h                         # 끝에서 단일 출력
