1 들어가며: 오늘의 큰 그림

오늘 다루는 내용은 두 개의 축으로 나뉜다.

  1. Transformer를 더 싸게 만들기 — Self-attention의 \(\mathcal{O}(n^2)\) 비용을 줄이려는 시도들. 그 대표 주자가 상태공간모델(State Space Model, SSM) 계열의 Mamba다.
  2. 여러 종류의 데이터를 한 공간에서 다루기 — 텍스트·이미지·오디오를 하나의 임베딩 공간으로 묶는 멀티모달(multimodal) 모델. 그 핵심 도구가 CLIP과 후속 모델(SigLIP, SigLIP 2)이다.

이 둘은 사실 같은 질문의 두 얼굴이다. 첫째 축은 “긴 문맥을 어떻게 효율적으로 인코딩할까”, 둘째 축은 “이질적인 정보를 어떻게 같은 좌표계로 정렬할까”. 무선통신을 전공하는 입장에서 보면, 전자는 필터의 복잡도-성능 트레이드오프, 후자는 정합 필터링(matched filtering)과 다이버시티 결합(diversity combining) 문제로 자연스럽게 번역된다. 각 절 끝의 “무선통신으로 보기” 박스에서 이 대응을 명시한다.

2 복습: Transformer의 한계

2.1 무엇이 좋았나

Self-attention은 윈도(window) 안의 모든 토큰 쌍을 직접 연결해 문맥 정보를 밀도 높게 인코딩한다. RNN처럼 정보를 한 개의 은닉 상태로 압축해 순차 전달하지 않으므로, 장거리 의존성(long-range dependency)을 한 번에 본다.

2.2 두 가지 본질적 한계

중요한계 1 — 윈도 밖은 보지 못한다

Attention은 고려 대상 윈도 내부의 토큰만 연결한다. 윈도 밖 문맥은 원칙적으로 인코딩 불가능하다.

중요한계 2 — 비용이 윈도 크기의 제곱

윈도 크기를 \(n\)이라 하면, 모든 쿼리-키 쌍에 대해 점수를 계산하므로 시간·메모리 복잡도가 \[ \mathcal{O}(n^2 d) \] 이다. 윈도를 키우면 더 많은 문맥을 담을 수 있지만(\(\Rightarrow\) 더 좋은 정합·정확도), 비용이 제곱으로 폭증한다.

2.2.1 왜 하필 제곱인가 (3단계 인과사슬)

  1. 입력 \(X \in \mathbb{R}^{n \times d}\)에서 \(Q = XW_Q,\; K = XW_K,\; V = XW_V\) 를 만든다.
  2. 점수 행렬 \(S = QK^\top \in \mathbb{R}^{n \times n}\) 을 만드는 순간, 원소 수가 \(n^2\) 이다 \(\Rightarrow\) 이 한 줄이 제곱 복잡도의 근원이다.
  3. \(\text{softmax}(S/\sqrt{d})\,V\) 도 같은 \(n^2\) 규모의 연산을 거친다. 따라서 윈도를 2배로 늘리면 비용은 4배가 된다.

업계는 두 갈래로 대응한다. (a) 더 비싼 하드웨어(H100, H200, B100/B200 …)로 큰 윈도를 그냥 감당하거나, (b) 알고리즘적으로 비용 자체를 낮추는 효율 Transformer. 효율화 흐름은 \(\mathcal{O}(n^2) \to \mathcal{O}(n\log n) \to \mathcal{O}(n)\) 으로 복잡도를 끌어내리려 한다. Mamba가 후자의 대표 사례다.

힌트무선통신으로 보기 — 직접 합성곱 vs FFT

\(\mathcal{O}(n^2)\)를 \(\mathcal{O}(n\log n)\) 또는 \(\mathcal{O}(n)\)로 낮추려는 노력은, 직접 시간영역 합성곱(\(\mathcal{O}(n^2)\))을 FFT 기반 주파수영역 곱(\(\mathcal{O}(n\log n)\))으로 대체하는 통신 신호처리의 고전적 전략과 동일한 동기를 가진다. “정확도는 유지하되 복잡도 차수를 낮춘다”는 목표가 같다.

3 Mamba와 상태공간모델(SSM)

3.1 한눈에

Mamba는 검은맘바(빠르고 치명적인 뱀)에서 이름을 따온, 시퀀스 인코딩용 효율 모델이다. 기반은 구조화 상태공간 시퀀스 모델(S4, Structured State Space Sequence model) 이며, 이를 단순화한 S5를 거쳐 선택적(selective) 버전인 S6를 채택한다.

3.2 핵심 아이디어 두 가지

3.2.1 (1) 선택적 메커니즘 (S6)

  • 작은 고정 크기 윈도를 유지하되, 그 안에 관련성 높은 토큰만 남긴다.
  • “관련성”은 RNN의 게이팅(gating) 메커니즘과 유사한 방식으로 측정한다. 즉, 입력에 따라 어떤 정보를 기억하고 어떤 정보를 버릴지 동적으로 결정한다.
노트디테일이 전부다

아이디어 자체(“중요한 토큰만 남긴다”)는 단순하지만, 무엇을 중요하다고 볼지(중요도 점수 함수) 와 어떻게 선택할지가 성능을 좌우한다. 이 부분이 원 논문의 핵심 기여다(Gu & Dao, Mamba: Linear-Time Sequence Modeling with Selective State Spaces, 2023).

3.2.2 (2) 하드웨어 인지 병렬 스캔 (Hardware-aware parallel scan)

선형 순환 \(h_t = A h_{t-1} + B x_t\) 는 본질적으로 순차적이지만, 결합법칙이 성립하는 스캔(scan/prefix-sum) 연산으로 재구성해 GPU에서 병렬화할 수 있다. Mamba는 이 스캔을 GPU 메모리 계층(SRAM/HBM)에 맞춰 구현해 추론 속도를 끌어올린다.

경고실무 메모

이 하드웨어 인지 커널은 아직 NVIDIA 하드웨어에 기본 내장되어 있지 않아, Mamba의 잠재적 효율 이득이 완전히 실현되지는 않았다. 커스텀 커널/하드웨어 최적화는 여전히 열려 있는 연구·엔지니어링 기회다.

3.3 Mamba의 변종들

3.3.1 설계 철학의 한 줄 요약

  • Mamba: 계산 효율(빠름)에 강하다. 단, 표현력 자체가 더 뛰어난 것은 아니다.
  • Transformer: 강한 문맥 인코딩으로 장거리 의존성에 강하다.

하이브리드(예: MambaVision)의 직관은 다음과 같다. 초기 레이어는 다소 정보를 흘려보내도 괜찮으므로 효율적인 Mamba로 처리하고, 후기 레이어는 더 정교한 추론이 필요하므로 self-attention을 써서 정확도를 끌어올린다. 효율과 정확도의 균형점을 레이어 배치로 조율하는 셈이다. TransMamba는 그 배치를 더 부드럽고 선택적으로 만든다.

3.3.2 표현력에 대한 이론적 결과

회로 복잡도(circuit complexity) 관점에서, Mamba가 Transformer보다 더 큰 표현력을 갖지는 않는다는 정리들이 제시되었다(Chen et al., 2025). 즉 Mamba의 가치는 표현력 우위가 아니라 동일·유사 표현력을 더 싼 비용에 얻는 데 있다.

힌트무선통신으로 보기 — SSM = 선형 시스템 / IIR 필터 / 칼만 필터

SSM의 핵심 점화식 \[ h_t = A h_{t-1} + B x_t,\qquad y_t = C h_t \;(+\, D x_t) \] 은 이산시간 선형 상태공간 시스템 그 자체다. 즉 Mamba의 백본은 무한 임펄스 응답(IIR) 필터 혹은 (잡음을 더하면) 칼만 필터의 상태방정식과 동형이다.

  • \(A\)의 고유값 크기가 \(|\lambda|<1\)이면 시스템이 안정하고 과거 정보가 지수적으로 감쇠한다(\(\Rightarrow\) 유한한 유효 메모리 길이).
  • “선택적(S6)”이란 곧 \(A,B,C\)를 입력에 따라 시변(time-varying) 으로 만든 것 — 통신의 적응형 필터(adaptive filter, 예: LMS/RLS) 와 같은 발상이다. 채널 상태에 따라 탭 계수를 바꾸듯, 토큰 내용에 따라 상태 전이를 바꾼다.
  • 순차 순환을 prefix-scan으로 병렬화하는 트릭은, 선형 점화식을 블록 단위로 묶어 병렬 처리하는 신호처리의 parallel prefix 기법과 동일하다.

4 멀티모달 모델: 개요

4.1 “모달리티”란 무엇인가

노트정의 — mode와 modality
  • Mode(최빈값): 확률분포의 봉우리(peak), 즉 밀도가 (국소) 최대가 되는 지점.
  • Multimodal 분포: 봉우리가 여러 개인 분포.
  • 이를 데이터로 확장하면, 멀티모달 데이터란 서로 다른 동질적(homogeneous) 정보 덩어리(=각 모달리티)가 여러 개 섞여 하나의 결정/임베딩 공간에 들어온 것을 뜻한다.

과거에는 데이터 종류마다 저장 매체가 달라(오디오=테이프, 영상=비디오테이프 …) 멀티미디어(multimedia) 라 불렀다. 지금은 모든 신호가 디지털(0/1)로 변환되어 같은 반도체 저장소에 담기므로, “매체”가 아니라 “양상”을 강조해 멀티모달이라 부른다. 모달리티에는 시각·청각·촉각·미각·후각, 더 나아가 주의·기억·선호 같은 추상적 “감각”까지 포함될 수 있다.

가장 중요한 두 모달리티는 텍스트와 비전이다. 인간이 매일 쓰는 정보이기 때문이다(오디오는 상당 부분 해결, 영상+텍스트가 남은 난제).

4.2 멀티모달 생성 모델의 발전 (맥락)

노트영상 생성의 본질적 제약 = 윈도(토큰 수)

긴 영상을 매끄럽고 시간적으로 일관되게(temporally consistent) 생성하기 어려운 이유는 다시 윈도(토큰 수) 한계 때문이다. 그래서 현재의 상업적 활용은 “2~3초짜리 고품질 컷”에 집중된다. 실제 촬영 비용(장비·인력·장소)을 상회하지 않는 한, 이 짧은 컷 생성이 경제적으로 정당화된다.

5 CLIP과 그 변종: 텍스트-비전 공동 임베딩

5.1 CLIP의 핵심 아이디어

CLIP(Contrastive Language–Image Pre-training, Radford & Kim et al., OpenAI, ICML 2021)은 가장 널리 쓰이는 공동 임베딩(co-embedding) 방법이다. 컴퓨터 비전과 자연어처리 사이의 간극을 메워, 이미지와 텍스트를 같은 임베딩 공간에 매핑한다. 일단 이 매핑을 학습하면, 별도 미세조정 없이 제로샷 분류(zero-shot classification) 같은 작업이 가능하다.

5.1.1 대조 사전학습 (Contrastive pre-training)

미니배치에 \(N\)개의 (이미지, 텍스트) 쌍이 있다고 하자. 이미지 인코더가 \(\{I_i\}\), 텍스트 인코더가 \(\{T_j\}\) 임베딩을 만든다. 모든 쌍의 유사도로 \(N \times N\) 행렬을 만들고,

  • 대각 원소(\(i=j\), 올바른 쌍) → 확률 1에 가깝게,
  • 비대각 원소(\(i \neq j\), 틀린 쌍) → 확률 0에 가깝게

만들도록 미니배치 전체에 softmax를 걸어 두 인코더를 함께 역전파한다.

코드 
flowchart LR
  TXT["텍스트<br/>'Pepper the aussie pup'"] --> TE["Text Encoder"]
  IMG["이미지"] --> IE["Image Encoder"]
  TE --> M["유사도 행렬 N×N<br/>(I_i · T_j)"]
  IE --> M
  M --> L["대각=양성, 비대각=음성<br/>Softmax 대조손실"]

유사도는 보통 코사인 유사도(임베딩을 \(\ell_2\) 정규화한 내적)로 잰다. 대칭 InfoNCE 손실은 \[ \mathcal{L}_{\text{CLIP}} = \tfrac{1}{2}\Big( \underbrace{-\tfrac{1}{N}\sum_{i}\log\frac{e^{\langle I_i,T_i\rangle/\tau}}{\sum_j e^{\langle I_i,T_j\rangle/\tau}}}_{\text{image}\to\text{text}} + \underbrace{-\tfrac{1}{N}\sum_{j}\log\frac{e^{\langle I_j,T_j\rangle/\tau}}{\sum_i e^{\langle I_i,T_j\rangle/\tau}}}_{\text{text}\to\text{image}} \Big), \] 여기서 \(\tau\)는 온도(temperature)다. 이는 “올바른 쌍에 대한 원-핫 분류”와 정확히 같은 형태이며, 따라서 교차엔트로피 최소화로 환원된다.

5.1.2 데이터는 어디서? — alt-text의 재발견

이 거대한 (이미지, 문구) 쌍은 HTML의 alt 텍스트에서 대규모로 수집됐다. 인터넷 초창기, 이미지 로딩이 느려서 이미지를 묘사하는 대체 텍스트(alt-text)를 함께 두던 관행이, 훗날 CLIP 학습의 공짜 약지도(weak supervision) 신호가 됐다. 웹의 방대한 alt-text 덕분에 이미지-문구 쌍을 대량 확보할 수 있었다.

5.2 SigLIP: softmax 대신 sigmoid

SigLIP(Zhai et al., Google DeepMind Zurich, ICML 2021)은 메모리 효율과 확장성 측면에서 CLIP을 개선한다. 아이디어 자체는 단순하다. 미니배치 전체에 softmax를 거는 대신, 각 쌍마다 독립적으로 sigmoid를 적용한다.

쌍 \((i,j)\)의 레이블을 \(z_{ij}\in\{+1,-1\}\) (대각=+1, 비대각=−1)이라 하면, \[ \mathcal{L}_{\text{SigLIP}} = -\frac{1}{N^2}\sum_{i}\sum_{j} \log \sigma\!\big(z_{ij}\,(t\,\langle I_i,T_j\rangle + b)\big), \] 여기서 \(t\)(스케일), \(b\)(바이어스)는 학습 파라미터, \(\sigma\)는 sigmoid다.

5.2.1 왜 sigmoid가 유리한가 (3단계)

  1. softmax는 분모에 미니배치 전체의 상대 정보가 필요하다 \(\Rightarrow\) 매 스텝 전 쌍의 정규화 항을 모아야 한다(동기화 비용).
  2. sigmoid는 각 쌍을 독립적으로 평가한다 \(\Rightarrow\) 쌍별 손실을 병렬·분산으로 계산 가능하다.
  3. 따라서 장치 간 all-gather 없이, 한 시점에 작은 블록만 메모리에 적재하면 된다 \(\Rightarrow\) 메모리 사용량↓, 확장성↑.
노트효율적 손실 구현 (parallelism)

원 논문은 글로벌 배치를 여러 장치에 쪼갠 뒤, 텍스트 표현을 장치 간에 순환(swap) 시키며 부분 손실을 누적한다. 어느 순간에도 작은 부분 블록만 메모리에 올라가고, 모든 이미지-텍스트 쌍이 한 번씩 상호작용한 뒤 장치 간 합으로 마무리한다. all-gather가 필요 없다는 점이 핵심이다.

5.2.2 CLIP vs SigLIP

대조학습은 SigLIP에서도 암묵적으로 이뤄진다. 양성 쌍을 1로, 음성 쌍을 0(−1 레이블)로 맞추는 sigmoid 적합 자체가 곧 “대비”이기 때문이다. 여러 데이터셋에서 SigLIP은 CLIP보다 정확도가 높으면서 병렬화 이점까지 가진다.

5.3 SigLIP 2: 더 풍부한 지도신호

SigLIP 2(Tschannen et al., Google DeepMind, 2025)는 두 가지를 더한다.

5.3.1 (1) LocCa — 위치 인지 캡셔닝

기존 CLIP/SigLIP의 alt-text는 이미지를 전체 수준으로만 묘사한다. LocCa(Wan et al., NeurIPS 2024)는 더 미세한(fine-grained) 지도신호를 준다.

  • Cap (Captioning): 이미지 전체 캡션.
  • ARef (Automatic Referring expression): 주어진 설명 → 그 설명이 가리키는 바운딩박스 위치 찾기.
  • GCap (Grounded Captioning): 주어진 바운딩박스 → 그 영역의 캡션 생성.

즉 “puffin standing on a cliff edge” 같은 묘사를 이미지의 특정 박스 좌표와 연결한다. 이런 위치 기반 약지도 덕분에 오늘날 LLM/VLM이 이미지의 작은 부분까지 이해할 수 있게 된다.

5.3.2 (2) 느린 학습자(이미지 인코더)를 위한 자기증류

노트왜 이미지 인코더가 “느린 학습자”인가
  • 텍스트: 고도로 추상화된 고수준 의미를 담는다 → 정보가 압축적·풍부.
  • 이미지: 픽셀 단위의 구체적 실현(realization). 의미 관점에서는 잡음이 많고, 선택적으로 취해야 할 정보가 섞여 있다.

그래서 이미지 인코더는 텍스트 인코더보다 학습이 느리고, 잡음에 휘둘리기 쉽다.

해결책은 컴퓨터 비전의 slow-fast / teacher-student 발상이다. 지수이동평균(EMA, Exponential Moving Average) 으로 천천히 갱신되는 가중치를 교사(teacher) 로 두고, \[ \theta^{\text{EMA}}_t = \alpha\,\theta^{\text{EMA}}_{t-1} + (1-\alpha)\,\theta_t,\qquad \alpha \approx 0.8\text{~}0.99, \] 학생 인코더가 이 안정적 교사로부터 자기증류(self-distillation)/마스크 예측(SILC/TIPS 류 손실)을 통해 더 빠르고 안정적으로 수렴하도록 한다. 결과적으로 이미지 인코더가 더 미세하고 견고한 표현을 학습한다.

5.3.3 CLIP vs SigLIP vs SigLIP 2

5.4 CLIP + 생성 모델 = 텍스트→이미지

CLIP류 공동 임베딩을 확산모델(diffusion model) 같은 이미지 생성기와 결합하면, 긴 텍스트 → 대응 이미지/영상 생성이 가능하다. 직관적으로: 이미지 인코더 자리를 이미지 생성기로 바꾸고 텍스트 인코더를 CLIP 방식으로 학습하면, 텍스트가 주어졌을 때 그에 대응하는 이미지를 뱉는 생성기를 얻는다. 오늘날의 텍스트-이미지 시스템(DALL·E류 등)의 기본 골격이 이것이다.

힌트무선통신으로 보기 — 코사인 유사도 = 정합 필터, SigLIP 손실 = 검출 이론
  • CLIP의 코사인 유사도 \(\langle I,T\rangle / (\|I\|\|T\|)\)는 정규화 상관(normalized correlation), 곧 정합 필터(matched filter) 출력이다. 정합 필터가 수신 신호와 기준 파형의 정렬도를 최대화하듯, CLIP은 올바른 (이미지,텍스트) 쌍의 정렬도를 최대화한다. 빔포밍의 조향 벡터(steering vector) 정렬과도 같은 그림이다.
  • softmax(CLIP) vs sigmoid(SigLIP) 는 검출 이론의 두 관점에 대응한다. softmax는 “\(N\)개 가설 중 하나를 고르는 다중가설 검출”(상호 정규화 필요), sigmoid는 “각 쌍이 양성/음성인지 독립 이진 검출”이다. 후자는 각 검출기를 병렬로 돌릴 수 있어 구현이 가볍다 — 셀룰러 다중사용자 검출에서 결합검출(joint detection) 대신 사용자별 독립검출을 쓰면 복잡도가 떨어지는 것과 같다.
  • 온도 \(\tau\)와 스케일 \(t\)는 로짓의 SNR을 조절하는 이득으로 볼 수 있다. 너무 크면 과확신, 너무 작으면 분별력 상실.

6.1.1 행동주의 시대 — 맥거크 효과 (McGurk Effect, 1976)

동일한 음성을 들려주면서 입모양 영상만 바꾸면, 들리는 소리가 달라진다(예: 청각 “ba” + 시각 “ga” → “da”로 지각). 눈을 감으면 실제 소리대로, 뜨면 시각이 청각을 덮어쓴다. 이는 멀티모달 간섭(interference) 의 사례다. 보통 다중모달 정보는 도움이 되지만, 충돌하면 오히려 오지각을 낳는다. (전화 영어가 어려운 이유: 시각 정보 없이 부분 정보만 쓰기 때문.)

6.1.2 계산주의 시대 — AVSR과 SNR

오디오-비주얼 음성인식(AVSR)에서, 시각 정보를 더하면 훨씬 낮은 음향 SNR에서도 같은 단어오류율(WER) 을 달성한다. 정성적으로:

  • 오디오 단독: 일정 WER을 얻으려면 비교적 높은 SNR(예: ~10) 필요.
  • 오디오+비주얼: 시각 신호가 보조하므로, 거의 0에 가까운 SNR에서도 유사 WER 달성 가능.
힌트무선통신으로 보기 — 멀티모달 융합 = 다이버시티 결합(diversity combining)

이건 비유가 아니라 거의 동일한 수학이다. 시각이라는 독립적(준독립) 관측 가지(branch) 를 추가해 유효 SNR을 끌어올리는 것은, 수신 다이버시티에서 최대비결합(MRC, Maximal Ratio Combining) 이 가지별 SNR을 합산해 어레이 이득을 얻는 것과 정확히 같은 원리다.

  • \(L\)개 독립 모달리티 ≈ \(L\)차 다이버시티 → 한 채널이 깊은 페이딩(=잡음/모호성)에 빠져도 다른 채널이 보완.
  • AVSR이 “0 dB 근처에서도 동작”하는 것은 곧 다이버시티 이득으로 요구 SNR이 크게 내려간 것.

따라서 멀티모달 융합 설계는 통신의 결합 규칙(combining rule) 설계 문제로 번역된다: 어떤 가중치로 가지를 합칠 것인가(=fusion).

6.2 딥러닝 시대의 5대 핵심 과제

노트5 Core Challenges
  1. Representation(표현) — 상보성·중복성을 활용해 멀티모달 데이터를 표현/요약.
  2. Alignment(정렬) — 둘 이상 모달리티의 (하위)요소 간 직접 대응 찾기.
  3. Fusion(융합) — 여러 모달리티 정보를 합쳐 예측 수행.
  4. Translation(변환) — 한 모달리티를 다른 모달리티로 변환(열린/주관적일 수 있음).
  5. Co-Learning(공동학습) — 모달리티 간 지식(표현·예측모델) 전이.

6.2.1 과제 1: Representation — Joint vs Coordinated

딥러닝은 대체로 joint 표현으로 간다. 표현을 스스로 학습한다는 딥러닝의 장점 덕분에, 모달리티별 입력을 단순 결합·연산해 하나의 공동 임베딩으로 녹여내면 정렬이 자동으로 이뤄진다.

6.2.2 Joint 표현의 마법 — 벡터 공간 산술

잘 학습된 joint 멀티모달 공간에서는, 의미가 비슷한 이미지·텍스트·오디오가 서로 가까이 놓인다. 더 나아가 벡터 산술이 성립한다(Kiros et al., 2014). \[ \text{image}(\text{파란 차}) - \mathbf{v}_{\text{blue}} + \mathbf{v}_{\text{red}} \;\approx\; \text{image}(\text{빨간 차}) \] 즉 “파란 차” 임베딩에서 blue 벡터를 빼고 red 벡터를 더한 위치 근방을 조회하면 빨간 차 이미지들이 나온다. 문장 속 한 단어를 다른 단어로 바꾸는 것이 임베딩 공간에서의 벡터 덧셈/뺄셈으로 대응되며, 그 결과 임베딩 근방의 이미지가 바뀐다(“Iron Man을 그려줘” → “고양이를 그려줘”).

6.2.3 과제 2~5 요약

  • Alignment(정렬): 조정 표현을 택하면 모달리티 간 요소 대응을 명시적으로 풀어야 한다(어려움). Joint 표현은 이를 학습 과정에 흡수.
  • Fusion(융합): 여러 모달리티를 합쳐 하나의 예측을 낸다(위 AVSR/다이버시티 결합 참조).
  • Translation(변환): 한 모달리티 → 다른 모달리티(예: 영상→소리, 텍스트→이미지). 관계가 열려 있고 주관적일 수 있어 정답이 하나가 아니다.
  • Co-Learning(공동학습): 한 모달리티의 지식을 다른 모달리티로 전이(예: 위의 slow-fast 증류). 정렬(alignment)과 깊게 연결된다.

7 강의 말미 추가 논의: CNN의 한계 → Attention → Gating

수업 끝에서, 왜 단순 합성곱으로는 부족하고 attention이 필요한가를 다시 짚었다. 멀티모달·Transformer의 동기를 보강하는 내용이라 함께 정리한다.

7.1 VQA에서 드러나는 CNN의 한계

“이 이미지에 새가 몇 마리 있나?”(시각적 질의응답, VQA)를 생각하자. CNN은 공간적 정상성(spatial stationarity) 과 국소성(locality) 을 가정한다. 즉 각 필터 응답은 위치와 무관하게 같은 의미를 가지며, 강한 응답만 남기고 나머지는 잡음 취급(max pooling)한다.

경고왜 세기(counting)에서 실패하나 (인과사슬)
  1. CNN은 위치 불변 특징을 추출하도록 설계 → “새다움” 은 잘 잡는다.
  2. 그러나 max pooling은 가장 강한 응답 하나를 다음 층으로 보낸다 → 개수 정보가 소실.
  3. “세 마리”는 각 위치가 서로 다른 의미(다른 개체)를 가져야 하는데, 정상성 가정과 정면충돌 → 세기 실패.

같은 종의 새가 화면의 좌하단과 우상단에 있을 때, “같은 종인가?”는 장거리 관계와 위치별로 다르게 행동하는 정보를 요구한다. CNN은 이런 장거리·문맥의존 관계에 약하다. (이론상 locally-connected net이 대안이나 파라미터가 폭증하고 CNN의 이점을 잃어, 실용적이지 않다.)

7.2 Attention = 입력에 의존해 변하는 가중치

중요핵심 직관

일반적인 가중치 \(W\)는 입력과 무관하게 고정(데이터로 학습되지만 추론 시 불변)이다. Attention 가중치 \(a\) 는 입력 자신을 입력으로 받아 가중치를 바꾸고, 그 바뀐 가중치를 다시 입력에 적용한다. \[ \text{고정: } y = Wx \qquad\text{vs}\qquad \text{Attention: } y = a(x)\,x \] 덕분에 같은 입력이라도 문맥에 따라 다른 역할·의미로 인코딩된다.

이 “입력으로부터 가중치를 계산한다”는 아이디어를 구현하기 위해 쿼리(Query)·키(Key)·값(Value) 개념을 도입한다(반드시 세 요소여야 하는 건 아니지만 Transformer의 표준 구현). 다음 강의에서 QKV로 attention을 완성하고, 그 뒤 중간고사를 본다(Transformer는 고수준 개념 위주로 출제).

7.3 게이팅(gating) 복습 — 기억의 문제

순환 구조에서 시간에 따른 기억은 게이팅으로 다룬다. 현재 입력과 과거 메모리의 이동평균을 가중합한다. \[ f(x) = g(x)\odot x + \big(1-g(x)\big)\odot m,\qquad g(x)\in(0,1), \] 여기서 \(m\)은 메모리(과거 누적), \(g\)는 게이트. 대표 구현이 LSTM(Long Short-Term Memory)과 GRU(Gated Recurrent Unit)다. GRU는 LSTM을 단순화(파라미터↓)하면서도 유사 성능을 낸다.

노트한 줄 메모

“시간에 따른 기억(remembering over time)”은 여전히 완전히 풀리지 않은 큰 도전 과제다. Mamba의 선택적 메커니즘도 결국 무엇을 기억하고 버릴지를 게이팅으로 정하는, 같은 문제에 대한 새로운 답이다.

힌트무선통신으로 보기 — 게이트 = 1차 IIR 평활기 / 적응 이득

\(f = g\odot x + (1-g)\odot m\) 은 지수가중이동평균(EWMA), 곧 1차 IIR 저역통과 필터다. 게이트 \(g\)가 시변이면 적응형 평활기가 된다. 채널 추정에서 잡음 억제를 위해 적응 망각인자(forgetting factor)를 두는 것과 동일한 구조다.

10 부록 B: 실습 코드 (NumPy)

대조손실(CLIP/SigLIP), 코사인 유사도, 선형 SSM 스캔, 벡터 산술을 순수 NumPy로 구현한다. 개념 검증용 토이 코드다.

코드 
import numpy as np
rng = np.random.default_rng(0)

def l2norm(X, axis=-1, eps=1e-8):
    """행 벡터를 단위 노름으로 정규화 → 내적이 코사인 유사도가 됨"""
    return X / (np.linalg.norm(X, axis=axis, keepdims=True) + eps)

def log_softmax(z, axis=-1):
    z = z - z.max(axis=axis, keepdims=True)          # 수치 안정화
    return z - np.log(np.exp(z).sum(axis=axis, keepdims=True))

def log_sigmoid(x):
    return -np.logaddexp(0.0, -x)                     # 안정적 log σ(x)

10.1 CLIP 대칭 대조손실 (InfoNCE)

코드 
N, d = 8, 16
I = l2norm(rng.standard_normal((N, d)))               # 이미지 임베딩
T = l2norm(rng.standard_normal((N, d)))               # 텍스트 임베딩
T = l2norm(0.6 * I + 0.4 * T)                         # 대각(짝)에 상관 주입

def clip_loss(I, T, temperature=0.07):
    logits = (I @ T.T) / temperature                  # (N,N) 코사인 유사도/τ
    labels = np.arange(N)                             # 정답 = 대각
    lp_i = log_softmax(logits, axis=1)                # image→text
    lp_t = log_softmax(logits, axis=0)                # text→image
    return 0.5 * (-lp_i[labels, labels].mean()
                  - lp_t[labels, labels].mean())

print("CLIP loss:", round(float(clip_loss(I, T)), 4))

10.2 SigLIP 쌍별 sigmoid 손실

코드 
def siglip_loss(I, T, t=10.0, b=-10.0):
    sims = I @ T.T                                    # (N,N)
    labels = -np.ones((N, N)); np.fill_diagonal(labels, 1.0)  # 대각 +1, 그 외 -1
    logits = labels * (t * sims + b)
    return -log_sigmoid(logits).mean()                # 쌍별 독립 → 병렬화 가능

print("SigLIP loss:", round(float(siglip_loss(I, T)), 4))

sims = I @ T.T
print("대각 평균 유사도:", round(float(np.diag(sims).mean()), 4))
print("비대각 평균 유사도:",
      round(float((sims.sum() - np.trace(sims)) / (N*N - N)), 4))

10.3 선형 SSM 스캔 (\(\mathcal{O}(n)\) 순차 점화식)

코드 
def ssm_scan(x, A, B, C):
    """h_t = A h_{t-1} + B x_t,  y_t = C h_t  (IIR/칼만 상태식과 동형)"""
    n = A.shape[0]; h = np.zeros(n); ys = []
    for xt in x:
        h = A @ h + B * xt
        ys.append(C @ h)
    return np.array(ys)

A = np.diag([0.9, 0.5])        # |eig|<1 → 안정, 과거가 지수 감쇠
B = np.array([1.0, 1.0]); C = np.array([1.0, -1.0])
x = rng.standard_normal(6)
print("SSM 출력:", np.round(ssm_scan(x, A, B, C), 4))

# 복습: Transformer의 한계 {#sec-recap}

## 무엇이 좋았나

Self-attention은 **윈도(window)** 안의 모든 토큰 쌍을 직접 연결해 문맥 정보를 밀도 높게 인코딩한다. RNN처럼 정보를 한 개의 은닉 상태로 압축해 순차 전달하지 않으므로, 장거리 의존성(long-range dependency)을 한 번에 본다.

## 두 가지 본질적 한계

::: {.callout-important}
## 한계 1 — 윈도 밖은 보지 못한다
Attention은 **고려 대상 윈도 내부**의 토큰만 연결한다. 윈도 밖 문맥은 원칙적으로 인코딩 불가능하다.
:::

::: {.callout-important}
## 한계 2 — 비용이 윈도 크기의 제곱
윈도 크기를 $n$이라 하면, 모든 쿼리-키 쌍에 대해 점수를 계산하므로 시간·메모리 복잡도가
$$
\mathcal{O}(n^2 d)
$$
이다. 윈도를 키우면 더 많은 문맥을 담을 수 있지만($\Rightarrow$ 더 좋은 정합·정확도), 비용이 *제곱으로* 폭증한다.
:::

### 왜 하필 제곱인가 (3단계 인과사슬)

1. 입력 $X \in \mathbb{R}^{n \times d}$에서 $Q = XW_Q,\; K = XW_K,\; V = XW_V$ 를 만든다.
2. 점수 행렬 $S = QK^\top \in \mathbb{R}^{n \times n}$ 을 만드는 순간, **원소 수가 $n^2$** 이다 $\Rightarrow$ 이 한 줄이 제곱 복잡도의 근원이다.
3. $\text{softmax}(S/\sqrt{d})\,V$ 도 같은 $n^2$ 규모의 연산을 거친다. 따라서 윈도를 2배로 늘리면 비용은 4배가 된다.

업계는 두 갈래로 대응한다. (a) **더 비싼 하드웨어**(H100, H200, B100/B200 …)로 큰 윈도를 그냥 감당하거나, (b) **알고리즘적으로 비용 자체를 낮추는** 효율 Transformer. 효율화 흐름은 $\mathcal{O}(n^2) \to \mathcal{O}(n\log n) \to \mathcal{O}(n)$ 으로 복잡도를 끌어내리려 한다. Mamba가 후자의 대표 사례다.

::: {.callout-tip}
## 무선통신으로 보기 — 직접 합성곱 vs FFT
$\mathcal{O}(n^2)$를 $\mathcal{O}(n\log n)$ 또는 $\mathcal{O}(n)$로 낮추려는 노력은, **직접 시간영역 합성곱($\mathcal{O}(n^2)$)을 FFT 기반 주파수영역 곱($\mathcal{O}(n\log n)$)으로 대체**하는 통신 신호처리의 고전적 전략과 동일한 동기를 가진다. "정확도는 유지하되 복잡도 차수를 낮춘다"는 목표가 같다.
:::

# Mamba와 상태공간모델(SSM) {#sec-mamba}

## 한눈에

Mamba는 **검은맘바**(빠르고 치명적인 뱀)에서 이름을 따온, **시퀀스 인코딩용 효율 모델**이다. 기반은 **구조화 상태공간 시퀀스 모델(S4, Structured State Space Sequence model)** 이며, 이를 단순화한 **S5**를 거쳐 **선택적(selective)** 버전인 **S6**를 채택한다.

```{mermaid}
flowchart LR
  S4["S4<br/>(2021, 구조화 SSM)"] --> S5["S5<br/>(단순화)"]
  S5 --> S6["S6<br/>(Selective)"]
  S6 --> M["Mamba<br/>(2023)"]
```

## 핵심 아이디어 두 가지

### (1) 선택적 메커니즘 (S6)

- **작은 고정 크기 윈도**를 유지하되, 그 안에 **관련성 높은 토큰만** 남긴다.
- "관련성"은 RNN의 **게이팅(gating) 메커니즘과 유사한 방식**으로 측정한다. 즉, 입력에 따라 어떤 정보를 기억하고 어떤 정보를 버릴지 동적으로 결정한다.

::: {.callout-note}
## 디테일이 전부다
아이디어 자체("중요한 토큰만 남긴다")는 단순하지만, **무엇을 중요하다고 볼지(중요도 점수 함수)** 와 **어떻게 선택할지**가 성능을 좌우한다. 이 부분이 원 논문의 핵심 기여다(Gu & Dao, *Mamba: Linear-Time Sequence Modeling with Selective State Spaces*, 2023).
:::

### (2) 하드웨어 인지 병렬 스캔 (Hardware-aware parallel scan)

선형 순환 $h_t = A h_{t-1} + B x_t$ 는 본질적으로 순차적이지만, **결합법칙이 성립하는 스캔(scan/prefix-sum) 연산**으로 재구성해 GPU에서 병렬화할 수 있다. Mamba는 이 스캔을 GPU 메모리 계층(SRAM/HBM)에 맞춰 구현해 추론 속도를 끌어올린다.

::: {.callout-warning}
## 실무 메모
이 하드웨어 인지 커널은 아직 NVIDIA 하드웨어에 *기본 내장*되어 있지 않아, Mamba의 잠재적 효율 이득이 완전히 실현되지는 않았다. 커스텀 커널/하드웨어 최적화는 여전히 열려 있는 연구·엔지니어링 기회다.
:::

### 설계 철학의 한 줄 요약

- **Mamba**: 계산 효율(빠름)에 강하다. 단, **표현력 자체가 더 뛰어난 것은 아니다.**
- **Transformer**: 강한 문맥 인코딩으로 장거리 의존성에 강하다.

하이브리드(예: MambaVision)의 직관은 다음과 같다. *초기 레이어*는 다소 정보를 흘려보내도 괜찮으므로 효율적인 Mamba로 처리하고, *후기 레이어*는 더 정교한 추론이 필요하므로 self-attention을 써서 정확도를 끌어올린다. 효율과 정확도의 균형점을 레이어 배치로 조율하는 셈이다. TransMamba는 그 배치를 더 부드럽고 선택적으로 만든다.

### 표현력에 대한 이론적 결과

회로 복잡도(circuit complexity) 관점에서, **Mamba가 Transformer보다 더 큰 표현력을 갖지는 않는다**는 정리들이 제시되었다(Chen et al., 2025). 즉 Mamba의 가치는 *표현력 우위*가 아니라 *동일·유사 표현력을 더 싼 비용에* 얻는 데 있다.

::: {.callout-tip}
## 무선통신으로 보기 — SSM = 선형 시스템 / IIR 필터 / 칼만 필터
SSM의 핵심 점화식
$$
h_t = A h_{t-1} + B x_t,\qquad y_t = C h_t \;(+\, D x_t)
$$
은 **이산시간 선형 상태공간 시스템** 그 자체다. 즉 Mamba의 백본은 **무한 임펄스 응답(IIR) 필터** 혹은 (잡음을 더하면) **칼만 필터**의 상태방정식과 동형이다.

- $A$의 고유값 크기가 $|\lambda|<1$이면 시스템이 **안정**하고 과거 정보가 지수적으로 감쇠한다($\Rightarrow$ 유한한 유효 메모리 길이).
- "선택적(S6)"이란 곧 $A,B,C$를 **입력에 따라 시변(time-varying)** 으로 만든 것 — 통신의 **적응형 필터(adaptive filter, 예: LMS/RLS)** 와 같은 발상이다. 채널 상태에 따라 탭 계수를 바꾸듯, 토큰 내용에 따라 상태 전이를 바꾼다.
- 순차 순환을 **prefix-scan**으로 병렬화하는 트릭은, 선형 점화식을 블록 단위로 묶어 병렬 처리하는 신호처리의 **parallel prefix** 기법과 동일하다.
:::

# CLIP과 그 변종: 텍스트-비전 공동 임베딩 {#sec-clip}

## CLIP의 핵심 아이디어

**CLIP**(Contrastive Language–Image Pre-training, Radford & Kim et al., OpenAI, ICML 2021)은 가장 널리 쓰이는 **공동 임베딩(co-embedding)** 방법이다. 컴퓨터 비전과 자연어처리 사이의 간극을 메워, **이미지와 텍스트를 같은 임베딩 공간**에 매핑한다. 일단 이 매핑을 학습하면, 별도 미세조정 없이 **제로샷 분류(zero-shot classification)** 같은 작업이 가능하다.

### 대조 사전학습 (Contrastive pre-training)

미니배치에 $N$개의 (이미지, 텍스트) 쌍이 있다고 하자. 이미지 인코더가 $\{I_i\}$, 텍스트 인코더가 $\{T_j\}$ 임베딩을 만든다. 모든 쌍의 유사도로 $N \times N$ 행렬을 만들고,

- **대각 원소**($i=j$, 올바른 쌍) → 확률 1에 가깝게,
- **비대각 원소**($i \neq j$, 틀린 쌍) → 확률 0에 가깝게

만들도록 **미니배치 전체에 softmax**를 걸어 두 인코더를 함께 역전파한다.

```{mermaid}
flowchart LR
  TXT["텍스트<br/>'Pepper the aussie pup'"] --> TE["Text Encoder"]
  IMG["이미지"] --> IE["Image Encoder"]
  TE --> M["유사도 행렬 N×N<br/>(I_i · T_j)"]
  IE --> M
  M --> L["대각=양성, 비대각=음성<br/>Softmax 대조손실"]
```

유사도는 보통 **코사인 유사도**(임베딩을 $\ell_2$ 정규화한 내적)로 잰다. 대칭 InfoNCE 손실은
$$
\mathcal{L}_{\text{CLIP}}
= \tfrac{1}{2}\Big(
\underbrace{-\tfrac{1}{N}\sum_{i}\log\frac{e^{\langle I_i,T_i\rangle/\tau}}{\sum_j e^{\langle I_i,T_j\rangle/\tau}}}_{\text{image}\to\text{text}}
+
\underbrace{-\tfrac{1}{N}\sum_{j}\log\frac{e^{\langle I_j,T_j\rangle/\tau}}{\sum_i e^{\langle I_i,T_j\rangle/\tau}}}_{\text{text}\to\text{image}}
\Big),
$$
여기서 $\tau$는 온도(temperature)다. 이는 "올바른 쌍에 대한 **원-핫 분류**"와 정확히 같은 형태이며, 따라서 교차엔트로피 최소화로 환원된다.

### 데이터는 어디서? — alt-text의 재발견

이 거대한 (이미지, 문구) 쌍은 **HTML의 `alt` 텍스트**에서 대규모로 수집됐다. 인터넷 초창기, 이미지 로딩이 느려서 이미지를 묘사하는 대체 텍스트(alt-text)를 함께 두던 관행이, 훗날 CLIP 학습의 **공짜 약지도(weak supervision) 신호**가 됐다. 웹의 방대한 alt-text 덕분에 이미지-문구 쌍을 대량 확보할 수 있었다.

## SigLIP: softmax 대신 sigmoid

**SigLIP**(Zhai et al., Google DeepMind Zurich, ICML 2021)은 **메모리 효율과 확장성** 측면에서 CLIP을 개선한다. 아이디어 자체는 단순하다. 미니배치 전체에 softmax를 거는 대신, **각 쌍마다 독립적으로 sigmoid**를 적용한다.

쌍 $(i,j)$의 레이블을 $z_{ij}\in\{+1,-1\}$ (대각=+1, 비대각=−1)이라 하면,
$$
\mathcal{L}_{\text{SigLIP}}
= -\frac{1}{N^2}\sum_{i}\sum_{j}
\log \sigma\!\big(z_{ij}\,(t\,\langle I_i,T_j\rangle + b)\big),
$$
여기서 $t$(스케일), $b$(바이어스)는 학습 파라미터, $\sigma$는 sigmoid다.

### 왜 sigmoid가 유리한가 (3단계)

1. softmax는 분모에 **미니배치 전체의 상대 정보**가 필요하다 $\Rightarrow$ 매 스텝 전 쌍의 정규화 항을 모아야 한다(동기화 비용).
2. sigmoid는 **각 쌍을 독립적으로** 평가한다 $\Rightarrow$ 쌍별 손실을 **병렬·분산**으로 계산 가능하다.
3. 따라서 장치 간 all-gather 없이, 한 시점에 **작은 블록만 메모리에 적재**하면 된다 $\Rightarrow$ 메모리 사용량↓, 확장성↑.

::: {.callout-note}
## 효율적 손실 구현 (parallelism)
원 논문은 글로벌 배치를 여러 장치에 쪼갠 뒤, **텍스트 표현을 장치 간에 순환(swap)** 시키며 부분 손실을 누적한다. 어느 순간에도 **작은 부분 블록만** 메모리에 올라가고, 모든 이미지-텍스트 쌍이 한 번씩 상호작용한 뒤 장치 간 합으로 마무리한다. all-gather가 필요 없다는 점이 핵심이다.
:::

### CLIP vs SigLIP

| 특성 | CLIP | SigLIP |
|---|---|---|
| 손실 함수 | softmax 기반 대조손실 | sigmoid (쌍별) |
| 손실 계산 단위 | 미니배치 내 **전 쌍** 비교 | **각 쌍** 독립 |
| 메모리 사용 | 높음 | 낮음 |
| 정확도 | 양호 | CLIP 대비 향상 |

: CLIP vs SigLIP {#tbl-clip-siglip}

대조학습은 SigLIP에서도 **암묵적으로** 이뤄진다. 양성 쌍을 1로, 음성 쌍을 0(−1 레이블)로 맞추는 sigmoid 적합 자체가 곧 "대비"이기 때문이다. 여러 데이터셋에서 SigLIP은 CLIP보다 정확도가 높으면서 병렬화 이점까지 가진다.

## SigLIP 2: 더 풍부한 지도신호

SigLIP 2(Tschannen et al., Google DeepMind, 2025)는 두 가지를 더한다.

### (1) LocCa — 위치 인지 캡셔닝

기존 CLIP/SigLIP의 alt-text는 이미지를 **전체 수준**으로만 묘사한다. LocCa(Wan et al., NeurIPS 2024)는 **더 미세한(fine-grained)** 지도신호를 준다.

- **Cap (Captioning)**: 이미지 전체 캡션.
- **ARef (Automatic Referring expression)**: *주어진 설명* → *그 설명이 가리키는 바운딩박스 위치* 찾기.
- **GCap (Grounded Captioning)**: *주어진 바운딩박스* → *그 영역의 캡션* 생성.

즉 "puffin standing on a cliff edge" 같은 묘사를 이미지의 **특정 박스 좌표**와 연결한다. 이런 위치 기반 약지도 덕분에 오늘날 LLM/VLM이 이미지의 작은 부분까지 이해할 수 있게 된다.

### (2) 느린 학습자(이미지 인코더)를 위한 자기증류

::: {.callout-note}
## 왜 이미지 인코더가 "느린 학습자"인가
- **텍스트**: 고도로 추상화된 **고수준 의미**를 담는다 → 정보가 압축적·풍부.
- **이미지**: 픽셀 단위의 **구체적 실현(realization)**. 의미 관점에서는 잡음이 많고, 선택적으로 취해야 할 정보가 섞여 있다.

그래서 이미지 인코더는 텍스트 인코더보다 학습이 느리고, 잡음에 휘둘리기 쉽다.
:::

해결책은 컴퓨터 비전의 **slow-fast / teacher-student** 발상이다. **지수이동평균(EMA, Exponential Moving Average)** 으로 천천히 갱신되는 가중치를 **교사(teacher)** 로 두고,
$$
\theta^{\text{EMA}}_t = \alpha\,\theta^{\text{EMA}}_{t-1} + (1-\alpha)\,\theta_t,\qquad \alpha \approx 0.8\text{~}0.99,
$$
학생 인코더가 이 안정적 교사로부터 **자기증류(self-distillation)/마스크 예측**(SILC/TIPS 류 손실)을 통해 더 빠르고 안정적으로 수렴하도록 한다. 결과적으로 이미지 인코더가 더 미세하고 견고한 표현을 학습한다.

### CLIP vs SigLIP vs SigLIP 2

| 특성 | CLIP | SigLIP | SigLIP 2 |
|---|---|---|---|
| 손실 | softmax 대조 | sigmoid | sigmoid + **LocCa** |
| 과제 | 이미지-텍스트 매칭 | 이미지-텍스트 매칭 | 캡셔닝·증류 포함 |
| 손실 단위 | 전 쌍 비교 | 각 쌍 | 각 쌍 |
| 메모리 | 높음 | 낮음 | 낮음 |
| 정확도 | 양호 | CLIP↑ | 다양한 과제에서 SigLIP↑ |

: CLIP vs SigLIP vs SigLIP 2 {#tbl-siglip2}

## CLIP + 생성 모델 = 텍스트→이미지

CLIP류 공동 임베딩을 **확산모델(diffusion model)** 같은 이미지 생성기와 결합하면, **긴 텍스트 → 대응 이미지/영상** 생성이 가능하다. 직관적으로: 이미지 인코더 자리를 **이미지 생성기**로 바꾸고 텍스트 인코더를 CLIP 방식으로 학습하면, 텍스트가 주어졌을 때 그에 대응하는 이미지를 뱉는 생성기를 얻는다. 오늘날의 텍스트-이미지 시스템(DALL·E류 등)의 기본 골격이 이것이다.

::: {.callout-tip}
## 무선통신으로 보기 — 코사인 유사도 = 정합 필터, SigLIP 손실 = 검출 이론
- **CLIP의 코사인 유사도** $\langle I,T\rangle / (\|I\|\|T\|)$는 **정규화 상관(normalized correlation)**, 곧 **정합 필터(matched filter)** 출력이다. 정합 필터가 수신 신호와 기준 파형의 정렬도를 최대화하듯, CLIP은 올바른 (이미지,텍스트) 쌍의 정렬도를 최대화한다. 빔포밍의 **조향 벡터(steering vector) 정렬**과도 같은 그림이다.
- **softmax(CLIP) vs sigmoid(SigLIP)** 는 검출 이론의 두 관점에 대응한다. softmax는 "$N$개 가설 중 하나를 고르는 **다중가설 검출**"(상호 정규화 필요), sigmoid는 "각 쌍이 양성/음성인지 **독립 이진 검출**"이다. 후자는 각 검출기를 병렬로 돌릴 수 있어 구현이 가볍다 — 셀룰러 다중사용자 검출에서 결합검출(joint detection) 대신 사용자별 독립검출을 쓰면 복잡도가 떨어지는 것과 같다.
- 온도 $\tau$와 스케일 $t$는 **로짓의 SNR을 조절하는 이득**으로 볼 수 있다. 너무 크면 과확신, 너무 작으면 분별력 상실.
:::


### 행동주의 시대 — 맥거크 효과 (McGurk Effect, 1976)

동일한 음성을 들려주면서 입모양 영상만 바꾸면, **들리는 소리가 달라진다**(예: 청각 "ba" + 시각 "ga" → "da"로 지각). 눈을 감으면 실제 소리대로, 뜨면 시각이 청각을 **덮어쓴다**. 이는 **멀티모달 간섭(interference)** 의 사례다. 보통 다중모달 정보는 도움이 되지만, 충돌하면 오히려 오지각을 낳는다. (전화 영어가 어려운 이유: 시각 정보 없이 부분 정보만 쓰기 때문.)

### 계산주의 시대 — AVSR과 SNR

오디오-비주얼 음성인식(AVSR)에서, **시각 정보를 더하면 훨씬 낮은 음향 SNR에서도 같은 단어오류율(WER)** 을 달성한다. 정성적으로:

- 오디오 단독: 일정 WER을 얻으려면 비교적 **높은 SNR**(예: ~10) 필요.
- 오디오+비주얼: 시각 신호가 보조하므로, **거의 0에 가까운 SNR**에서도 유사 WER 달성 가능.

::: {.callout-tip}
## 무선통신으로 보기 — 멀티모달 융합 = 다이버시티 결합(diversity combining)
이건 비유가 아니라 **거의 동일한 수학**이다. 시각이라는 **독립적(준독립) 관측 가지(branch)** 를 추가해 유효 SNR을 끌어올리는 것은, 수신 다이버시티에서 **최대비결합(MRC, Maximal Ratio Combining)** 이 가지별 SNR을 합산해 어레이 이득을 얻는 것과 정확히 같은 원리다.

- $L$개 독립 모달리티 ≈ $L$차 다이버시티 → 한 채널이 깊은 페이딩(=잡음/모호성)에 빠져도 다른 채널이 보완.
- AVSR이 "0 dB 근처에서도 동작"하는 것은 곧 **다이버시티 이득**으로 요구 SNR이 크게 내려간 것.

따라서 멀티모달 융합 설계는 통신의 **결합 규칙(combining rule)** 설계 문제로 번역된다: 어떤 가중치로 가지를 합칠 것인가(=fusion).
:::

## 딥러닝 시대의 5대 핵심 과제

::: {.callout-note}
## 5 Core Challenges
1. **Representation(표현)** — 상보성·중복성을 활용해 멀티모달 데이터를 표현/요약.
2. **Alignment(정렬)** — 둘 이상 모달리티의 (하위)요소 간 직접 대응 찾기.
3. **Fusion(융합)** — 여러 모달리티 정보를 합쳐 예측 수행.
4. **Translation(변환)** — 한 모달리티를 다른 모달리티로 변환(열린/주관적일 수 있음).
5. **Co-Learning(공동학습)** — 모달리티 간 지식(표현·예측모델) 전이.
:::

### 과제 1: Representation — Joint vs Coordinated

| 방식 | 정의 | 장점 | 단점 |
|---|---|---|---|
| **Joint(공동) 표현** | 모든 모달리티를 **하나의** 공유 공간으로 | 정렬이 학습 시점에 **암묵적으로 내장** → 추후 정렬 걱정↓ | 그 공간을 학습하기가 어려움 |
| **Coordinated(조정) 표현** | 모달리티별 **개별** 공간 + 사후 정렬 | 각 모달리티 고유 특성을 잘 반영 | **정렬이라는 어려운 문제**를 뒤로 미룸 |

: 표현 방식 비교 {#tbl-repr}

딥러닝은 대체로 **joint 표현**으로 간다. 표현을 **스스로 학습**한다는 딥러닝의 장점 덕분에, 모달리티별 입력을 단순 결합·연산해 하나의 공동 임베딩으로 녹여내면 정렬이 자동으로 이뤄진다.

### Joint 표현의 마법 — 벡터 공간 산술

잘 학습된 joint 멀티모달 공간에서는, 의미가 비슷한 이미지·텍스트·오디오가 **서로 가까이** 놓인다. 더 나아가 **벡터 산술**이 성립한다(Kiros et al., 2014).
$$
\text{image}(\text{파란 차}) - \mathbf{v}_{\text{blue}} + \mathbf{v}_{\text{red}} \;\approx\; \text{image}(\text{빨간 차})
$$
즉 "파란 차" 임베딩에서 *blue* 벡터를 빼고 *red* 벡터를 더한 위치 근방을 조회하면 **빨간 차** 이미지들이 나온다. 문장 속 한 단어를 다른 단어로 바꾸는 것이 임베딩 공간에서의 벡터 덧셈/뺄셈으로 대응되며, 그 결과 임베딩 근방의 이미지가 바뀐다("Iron Man을 그려줘" → "고양이를 그려줘").

### 과제 2~5 요약

- **Alignment(정렬)**: 조정 표현을 택하면 모달리티 간 요소 대응을 *명시적으로* 풀어야 한다(어려움). Joint 표현은 이를 학습 과정에 흡수.
- **Fusion(융합)**: 여러 모달리티를 합쳐 하나의 예측을 낸다(위 AVSR/다이버시티 결합 참조).
- **Translation(변환)**: 한 모달리티 → 다른 모달리티(예: 영상→소리, 텍스트→이미지). 관계가 **열려 있고 주관적**일 수 있어 정답이 하나가 아니다.
- **Co-Learning(공동학습)**: 한 모달리티의 지식을 다른 모달리티로 전이(예: 위의 slow-fast 증류). 정렬(alignment)과 깊게 연결된다.

# 강의 말미 추가 논의: CNN의 한계 → Attention → Gating {#sec-extra}

수업 끝에서, *왜 단순 합성곱으로는 부족하고 attention이 필요한가*를 다시 짚었다. 멀티모달·Transformer의 동기를 보강하는 내용이라 함께 정리한다.

## VQA에서 드러나는 CNN의 한계

"이 이미지에 새가 몇 마리 있나?"(시각적 질의응답, VQA)를 생각하자. CNN은 **공간적 정상성(spatial stationarity)** 과 **국소성(locality)** 을 가정한다. 즉 *각 필터 응답은 위치와 무관하게 같은 의미*를 가지며, 강한 응답만 남기고 나머지는 잡음 취급(max pooling)한다.

::: {.callout-warning}
## 왜 세기(counting)에서 실패하나 (인과사슬)
1. CNN은 위치 불변 특징을 추출하도록 설계 → **"새다움"** 은 잘 잡는다.
2. 그러나 max pooling은 **가장 강한 응답 하나**를 다음 층으로 보낸다 → 개수 정보가 소실.
3. "세 마리"는 *각 위치가 서로 다른 의미*(다른 개체)를 가져야 하는데, 정상성 가정과 정면충돌 → **세기 실패**.
:::

같은 종의 새가 화면의 좌하단과 우상단에 있을 때, "같은 종인가?"는 **장거리 관계**와 **위치별로 다르게 행동하는 정보**를 요구한다. CNN은 이런 장거리·문맥의존 관계에 약하다. (이론상 locally-connected net이 대안이나 파라미터가 폭증하고 CNN의 이점을 잃어, 실용적이지 않다.)

## Attention = 입력에 의존해 *변하는* 가중치

::: {.callout-important}
## 핵심 직관
일반적인 가중치 $W$는 입력과 무관하게 **고정**(데이터로 학습되지만 추론 시 불변)이다. **Attention 가중치 $a$** 는 **입력 자신을 입력으로 받아** 가중치를 바꾸고, 그 바뀐 가중치를 다시 입력에 적용한다.
$$
\text{고정: } y = Wx \qquad\text{vs}\qquad \text{Attention: } y = a(x)\,x
$$
덕분에 *같은 입력*이라도 **문맥에 따라 다른 역할·의미**로 인코딩된다.
:::

이 "입력으로부터 가중치를 계산한다"는 아이디어를 구현하기 위해 **쿼리(Query)·키(Key)·값(Value)** 개념을 도입한다(반드시 세 요소여야 하는 건 아니지만 Transformer의 표준 구현). 다음 강의에서 QKV로 attention을 완성하고, 그 뒤 중간고사를 본다(Transformer는 **고수준 개념** 위주로 출제).

## 게이팅(gating) 복습 — 기억의 문제

순환 구조에서 **시간에 따른 기억**은 게이팅으로 다룬다. 현재 입력과 과거 메모리의 이동평균을 가중합한다.
$$
f(x) = g(x)\odot x + \big(1-g(x)\big)\odot m,\qquad g(x)\in(0,1),
$$
여기서 $m$은 메모리(과거 누적), $g$는 게이트. 대표 구현이 **LSTM**(Long Short-Term Memory)과 **GRU**(Gated Recurrent Unit)다. GRU는 LSTM을 단순화(파라미터↓)하면서도 유사 성능을 낸다.

::: {.callout-note}
## 한 줄 메모
"시간에 따른 기억(remembering over time)"은 여전히 완전히 풀리지 않은 큰 도전 과제다. Mamba의 선택적 메커니즘도 결국 *무엇을 기억하고 버릴지*를 게이팅으로 정하는, 같은 문제에 대한 새로운 답이다.
:::

::: {.callout-tip}
## 무선통신으로 보기 — 게이트 = 1차 IIR 평활기 / 적응 이득
$f = g\odot x + (1-g)\odot m$ 은 **지수가중이동평균(EWMA)**, 곧 **1차 IIR 저역통과 필터**다. 게이트 $g$가 시변이면 **적응형 평활기**가 된다. 채널 추정에서 잡음 억제를 위해 적응 망각인자(forgetting factor)를 두는 것과 동일한 구조다.
:::

# 부록 B: 실습 코드 (NumPy) {#sec-appendix-code}

대조손실(CLIP/SigLIP), 코사인 유사도, 선형 SSM 스캔, 벡터 산술을 순수 NumPy로 구현한다. 개념 검증용 토이 코드다.

```{python}
import numpy as np
rng = np.random.default_rng(0)

def l2norm(X, axis=-1, eps=1e-8):
    """행 벡터를 단위 노름으로 정규화 → 내적이 코사인 유사도가 됨"""
    return X / (np.linalg.norm(X, axis=axis, keepdims=True) + eps)

def log_softmax(z, axis=-1):
    z = z - z.max(axis=axis, keepdims=True)          # 수치 안정화
    return z - np.log(np.exp(z).sum(axis=axis, keepdims=True))

def log_sigmoid(x):
    return -np.logaddexp(0.0, -x)                     # 안정적 log σ(x)
```

## CLIP 대칭 대조손실 (InfoNCE)

```{python}
N, d = 8, 16
I = l2norm(rng.standard_normal((N, d)))               # 이미지 임베딩
T = l2norm(rng.standard_normal((N, d)))               # 텍스트 임베딩
T = l2norm(0.6 * I + 0.4 * T)                         # 대각(짝)에 상관 주입

def clip_loss(I, T, temperature=0.07):
    logits = (I @ T.T) / temperature                  # (N,N) 코사인 유사도/τ
    labels = np.arange(N)                             # 정답 = 대각
    lp_i = log_softmax(logits, axis=1)                # image→text
    lp_t = log_softmax(logits, axis=0)                # text→image
    return 0.5 * (-lp_i[labels, labels].mean()
                  - lp_t[labels, labels].mean())

print("CLIP loss:", round(float(clip_loss(I, T)), 4))
```

## SigLIP 쌍별 sigmoid 손실

```{python}
def siglip_loss(I, T, t=10.0, b=-10.0):
    sims = I @ T.T                                    # (N,N)
    labels = -np.ones((N, N)); np.fill_diagonal(labels, 1.0)  # 대각 +1, 그 외 -1
    logits = labels * (t * sims + b)
    return -log_sigmoid(logits).mean()                # 쌍별 독립 → 병렬화 가능

print("SigLIP loss:", round(float(siglip_loss(I, T)), 4))

sims = I @ T.T
print("대각 평균 유사도:", round(float(np.diag(sims).mean()), 4))
print("비대각 평균 유사도:",
      round(float((sims.sum() - np.trace(sims)) / (N*N - N)), 4))
```

## 선형 SSM 스캔 ($\mathcal{O}(n)$ 순차 점화식)

```{python}
def ssm_scan(x, A, B, C):
    """h_t = A h_{t-1} + B x_t,  y_t = C h_t  (IIR/칼만 상태식과 동형)"""
    n = A.shape[0]; h = np.zeros(n); ys = []
    for xt in x:
        h = A @ h + B * xt
        ys.append(C @ h)
    return np.array(ys)

A = np.diag([0.9, 0.5])        # |eig|<1 → 안정, 과거가 지수 감쇠
B = np.array([1.0, 1.0]); C = np.array([1.0, -1.0])
x = rng.standard_normal(6)
print("SSM 출력:", np.round(ssm_scan(x, A, B, C), 4))
```

## 멀티모달 벡터 공간 산술 (토이)

```{python}
vocab = {w: l2norm(rng.standard_normal(d)) for w in ["blue", "red", "car"]}
```
