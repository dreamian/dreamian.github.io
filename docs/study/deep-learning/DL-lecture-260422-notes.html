1 한 장 요약

노트핵심 한 줄

시퀀스 모델링의 두 가지 근본 난제는 (1) 장기 의존성(long-term dependency)과 (2) 문맥 인코딩(context encoding)이다. RNN 계열(바닐라 → LSTM/GRU → Seq2Seq)은 이 둘을 순차적·고정 가중치로 풀려는 시도이고, 트랜스포머는 입력에 따라 가중치를 바꾸는 어텐션으로 같은 문제를 더 잘 푸는 대안이다.

바닐라 RNN 은닉상태 재귀 \(h_t=f(h_{t-1},x_t)\) 약함(소실/폭발) 암묵적·제한적 어려움
LSTM / GRU 게이팅으로 메모리 보존 중간 암묵적 어려움

2 시퀀스 모델링이란 무엇인가

2.1 직접적인 답

지금까지 다룬 데이터는 길이가 고정된 ‘스냅샷’ 이었다 — 이미지(숫자, 객체), 그래프 등. 반면 길이가 가변적인 데이터를 학습하려는 것이 시퀀스 모델링이다. 대표 예시:

  • 언어(텍스트) — 단어/문자의 가변 길이 나열
  • 시계열(주식) — 시간축 위의 값
  • 비디오 — 프레임의 시퀀스
  • 오디오 — 파형/스펙트로그램

주요 응용은 컴퓨터 비전(영상 분석, e.g. YOLO), 자연어 처리(텍스트 분석, e.g. GPT), 음성 인식(e.g. 음성 비서)이며, 시퀀스 모델링은 특히 NLP에서 핵심이다.

힌트무선통신 관점 비유

시퀀스 모델링은 가변 길이의 심볼 스트림을 처리하는 수신기와 같다. 패킷마다 길이가 다르고, 한 심볼의 의미가 앞뒤 심볼(채널 상태, 프리앰블)에 따라 달라진다. “현재 심볼”만 보는 무기억(memoryless) 검출기로는 ISI(심볼 간 간섭)가 있는 채널을 복조할 수 없듯, 시퀀스 모델도 과거 상태를 들고 다녀야 한다.

3 RNN: 동역학계로서의 시퀀스 인코더

3.1 직접적인 답

RNN은 상태를 시간에 따라 재귀적으로 갱신하는 동역학계다. 같은 함수 \(f\)와 같은 파라미터 \(\theta\)를 매 시점 재사용하여, 가변 길이 입력을 고정 크기 상태로 압축한다.

3.2 수학적 전개

외부 신호가 없는 동역학계의 고전적 형태:

\[ s^{(t)} = f\!\left(s^{(t-1)};\, \theta\right) \]

외부 입력 \(x^{(t)}\) 가 들어오면:

\[ s^{(t)} = f\!\left(s^{(t-1)},\, x^{(t)};\, \theta\right) \]

이때 상태 \(s^{(t)}\) 는 과거 시퀀스 전체의 정보를 담는다. 이 상태를 은닉 상태(hidden state) \(h^{(t)}\) 로 부르면 그것이 곧 RNN이다:

\[ \boxed{\,h^{(t)} = f\!\left(h^{(t-1)},\, x^{(t)};\, \theta\right)\,} \]

  • 입력: 현재 시점 데이터 \(x^{(t)}\) 와 과거 은닉상태 \(h^{(t-1)}\)
  • 출력: 현재 시점 모델 출력과 다음 시점으로 전달할 은닉상태

한 스텝(one-step) RNN을 비재귀 형태와 대비하면 그 본질이 드러난다:

\[ \begin{aligned} \text{비재귀:}\quad & f(x_t) = w x_t + b\\ \text{슬라이딩 윈도(이동평균):}\quad & f(x_t, x_{t-1}) = w_1 x_t + w_2 x_{t-1} + b\\ \text{한 스텝 재귀:}\quad & f(x_t, x_{t-1}) = w_1 x_t + w_2\, f(x_{t-1}, x_{t-2}) + b \end{aligned} \]

재귀 항 \(f(x_{t-1},x_{t-2})\) 이 과거를 무한히 거슬러 올라가게 만든다.

  2. 매 시점 같은 전이함수 \(f\) 와 같은 파라미터를 재사용할 수 있다(파라미터 공유).

유형 구조 특징
Type 1 매 시점 출력 + 은닉상태 간 재귀 연결 가장 일반적·표현력 높음
Type 2 매 시점 출력 + 출력→다음 은닉상태 연결 (Teacher forcing) 병렬화 쉬움 / 은닉상태 연결이 없어 과거를 더 잘 잊음

중요Teacher forcing (Type 2)의 정밀한 정의
  • 학습 시: 정답 출력 \(y^{(t)}\) (train set에서 추출)을 다음 시점 은닉상태 \(h^{(t+1)}\) 의 입력으로 먹인다.
  • 추론 시: 정답을 모르므로 모델 출력 \(o^{(t)}\) 로 \(y^{(t)}\) 를 근사하여 되먹인다.

4 장기 의존성 문제: 왜 RNN으로는 부족한가

4.1 직접적인 답

단순 비선형 함수를 여러 번 합성하면 합성 함수는 극도로 비선형해진다. RNN의 시간 전개가 정확히 이 합성이며, 그 결과 그래디언트가 소실(대부분)되거나 폭발(드물지만 치명적)하여 먼 과거의 정보를 학습에 반영하기 어렵다.

4.2 수학적 전개 (고유값 분해 관점)

선형 근사된 RNN 전이 \(h^{(t)} = W^\top h^{(t-1)}\) 를 보자. \(W\) 를 고유값 분해 \(W = Q\,\Lambda\, Q^{-1}\) 하면:

\[ h^{(t)} = \left(W^\top\right)^{t} h^{(0)} = Q\, \Lambda^{t}\, Q^{-1} h^{(0)} \]

여기서 \(\Lambda^{t} = \mathrm{diag}(\lambda_1^t, \dots, \lambda_n^t)\) 이므로,

\[ \boxed{\;|\lambda_i| < 1 \Rightarrow \lambda_i^{t}\to 0 \ (\text{소실}), \qquad |\lambda_i| > 1 \Rightarrow \lambda_i^{t}\to \infty \ (\text{폭발})\;} \]

즉 시간 깊이 \(t\) 에 대해 기여가 지수적으로 감쇠/증폭된다. 정확히 \(|\lambda_i|=1\) 인 경계만이 정보를 보존하지만, 학습 중 이를 유지하기는 사실상 불가능하다.

힌트무선통신 관점 비유

이것은 다중 홉 중계(multi-hop relay)에서의 누적 채널 이득과 같다. 각 홉의 이득을 \(\lambda\) 라 하면 \(t\) 홉 뒤 신호는 \(\lambda^t\). \(|\lambda|<1\) 이면 신호가 잡음 아래로 가라앉고(\(\to\) 정보 소실), \(|\lambda|>1\) 이면 비선형 증폭으로 클리핑·발산한다(\(\to\) 폭발). 안정 전송을 위해 AGC(자동이득제어)로 이득을 1 근처로 묶듯, RNN도 스펙트럴 반경을 1 근처로 제어해야 한다.

4.3 핵심 처방: 게이팅(Gating)

과거↔︎현재(혹은 미래)를 직접 잇는 연결을 만들자.

대표 구현이 게이팅이다. 단순 곱 \(f(x)=a\cdot x,\ a\in[0,1]\) 를 다음으로 바꾼다:

\[ f(x) = a\cdot x + (1-a)\cdot m \]

여기서 \(m\) 은 메모리. 이는 모멘텀/이동평균과 같은 직관 — 현재 입력과 과거 메모리를 가중 혼합하여 정보를 오래 유지한다. 대표 구현 두 가지: LSTM(1997)과 GRU(2014).

5 LSTM: Long Short-Term Memory

5.1 직접적인 답

LSTM은 명시적 메모리 셀 \(c_t\) 와 세 개의 게이트(망각·입력·출력) + 게이트 게이트로, 셀 내용을 얼마나 잊고, 얼마나 새로 쓰고, 얼마나 내보낼지를 부드럽게(softly) 조절해 장기 정보를 유지한다.

5.2 수학적 전개

입력으로 직전 은닉상태 \(h_{t-1}\) 와 현재 입력 \(x_t\) 를 결합한다. 게이트는 모두 시그모이드 \(\sigma(\cdot)\in(0,1)\), 후보는 \(\tanh\):

\[ \begin{aligned} f_t &= \sigma\!\left(W_f\,[h_{t-1}, x_t] + b_f\right) && \text{(망각 gate)}\\ i_t &= \sigma\!\left(W_i\,[h_{t-1}, x_t] + b_i\right) && \text{(입력 gate)}\\ o_t &= \sigma\!\left(W_o\,[h_{t-1}, x_t] + b_o\right) && \text{(출력 gate)}\\ g_t &= \tanh\!\left(W_g\,[h_{t-1}, x_t] + b_g\right) && \text{(gate gate / 후보 메모리)}\\[4pt] c_t &= f_t \odot c_{t-1} + i_t \odot g_t && \text{(셀 상태 갱신)}\\ h_t &= o_t \odot \tanh(c_t) && \text{(은닉상태 출력)} \end{aligned} \]

각 게이트의 역할:

  • \(f_t\)(망각): 이전 셀 내용 \(c_{t-1}\) 을 얼마나 유지할지 — 셀의 self-loop 연결을 부드럽게 조절(throttling).
  • \(i_t\)(입력): 현재 정보를 셀에 얼마나 쓸지.
  • \(g_t\)(게이트 게이트): 셀에 쓸 후보 내용 자체.
  • \(o_t\)(출력): 셀 내용을 출력/은닉상태로 얼마나 내보낼지.
중요LSTM은 두 개의 흐름을 갖는다

바닐라 RNN이 은닉상태 \(h\) 하나만 시간에 따라 전파하는 반면, LSTM은 셀 상태 \(c\)(전용 메모리) 와 은닉상태 \(h\) 두 개를 함께 전파한다. 핵심은 셀 상태 경로가 망각 게이트에 의한 곱셈 + 입력의 덧셈으로만 갱신되어, 그래디언트가 거의 1에 가까운 경로로 흐를 수 있다는 점(\(c_{t-1}\to c_t\) 의 야코비안이 \(\mathrm{diag}(f_t)\))이다. 이것이 장기 정보를 살리는 메커니즘이다.

5.3 기하/직관

망각 게이트가 1에 가까우면 셀 상태는 거의 그대로 흘러가는 ‘컨베이어 벨트’ 가 된다. 정보를 통째로 보관하는 게 아니라 게이트로 가공·저장하므로, 바닐라 RNN보다 길게 기억하지만 여전히 무한히 기억하지는 못한다. (날고기 대신 소시지를 먹는 셈 — 가공되어 원래 맛은 일부 손실된다.)

힌트무선통신 관점 비유

셀 상태 \(c_t\) 는 누설 적분기(leaky integrator) 기반의 채널 추정기/추적 필터다. 망각 게이트 \(f_t\) 는 잊음 인자(forgetting factor) \(\lambda\) 를 가진 RLS(재귀 최소자승)의 적응형 버전: 채널이 정적이면 \(f_t\to1\) 로 오래 평균내고, 급변하면 \(f_t\downarrow\) 로 과거를 빨리 버린다. 입력 게이트는 새 관측의 신뢰도(칼만 이득)에 해당한다.

6 GRU: Gated Recurrent Unit

6.1 직접적인 답

GRU는 LSTM과 거의 같은 아이디어를 더 단순하게 구현한 게이팅 유닛으로, 게이트가 3개(업데이트·리셋·후보)이고 별도 셀 상태가 없다. LSTM 대비 적은 파라미터로 대등한 성능을 낸다.

6.2 수학적 전개

\[ \begin{aligned} r_t &= \sigma\!\left(W_r\,[h_{t-1}, x_t] + b_r\right) && \text{(reset gate)}\\ z_t &= \sigma\!\left(W_z\,[h_{t-1}, x_t] + b_z\right) && \text{(update gate)}\\ \tilde{h}_t &= \tanh\!\left(W_h\,[\,r_t \odot h_{t-1},\, x_t\,] + b_h\right) && \text{(후보 상태)}\\[4pt] h_t &= (1 - z_t)\odot h_{t-1} + z_t \odot \tilde{h}_t && \text{(상태 갱신)} \end{aligned} \]

  • reset gate \(r_t\): 이전 상태를 후보 계산에 얼마나 반영할지(리셋 정도).
  • update gate \(z_t\): 과거 상태와 새 후보를 혼합하는 비율 — LSTM의 망각+입력 게이트를 하나로 합친 형태.

마지막 식이 정확히 게이팅 처방 \(f(x)=z\cdot(\text{새것}) + (1-z)\cdot(\text{메모리})\) 의 형태임에 주목.

6.3 LSTM vs GRU 비교

항목 LSTM GRU
게이트 수 4 (forget, input, output, gate) 3 (reset, update, candidate)
메모리 경로 셀 상태 \(c\) + 은닉 \(h\) (2개) 은닉 \(h\) (1개)
제안 연도 1997 2014
파라미터 기준 더 적음
성능 기준 대등(on par)
효용 — 과적합 위험↓, 학습 데이터·연산 비용↓
경고’파라미터 절반’에 대한 정밀한 주의

게이트별 가중치 행렬만 세면 LSTM 4개 vs GRU 3개로 \(3/4\) 이다. 흔히 인용되는 “약 1/2”은 셀 상태 경로 제거와 실무적 단순화까지 포함한 느슨한 어림수이며, 엄밀한 게이트 가중치 비율은 \(3/4\) 에 가깝다. 어느 쪽이든 결론은 동일하다: GRU가 더 적은 파라미터로 대등한 성능을 낸다.

7 장기 의존성을 위한 다른 해법들

게이팅 외에도 과거 정보를 멀리까지 나르는 다섯 가지 아이디어가 있다.

아이디어 1 — 시간축 스킵 연결(Skip connection through time). 가공된 셀 내용에만 의존하지 말고, 과거에서 현재로 직접 연결을 추가한다. 비전의 DenseNet/ResNet의 공간적 스킵 연결을 시간축으로 옮긴 발상으로, 게이트 효과 없이 메모리를 더 오래 보존한다.

아이디어 2 — 누설 유닛(Leaky units). 이동평균 형태로 천천히 움직이는 입력을 유지한다(\(W_{rec}\): 재귀 가중치, \(W_{in}\): 입력 가중치):

\[ \mu^{(t)} = \alpha\,\mu^{(t-1)} + (1-\alpha)\,(\cdot) \]

경고‘Leaky unit’ ≠ ‘Leaky ReLU’

이름은 비슷하나 완전히 다르다. Leaky ReLU는 음수 입력도 일부 통과시키는 활성함수다. Leaky unit은 시간에 따라 정보를 천천히 누설·적분하는 상태 갱신 메커니즘이다. 동기·역할 모두 다르다.

아이디어 3 — 게이팅(LSTM/GRU). 위에서 다룸.

아이디어 4 — 최적화 트릭. - 그래디언트 클리핑 → 폭발 그래디언트 대응(국소적으로 왜곡된 손실 영역에서 스텝 크기 제한). - 정보 흐름을 장려하는 정규화 → 소실 그래디언트 대응.

아이디어 5 — 명시적 메모리(Explicit memory). Memory Network처럼 과거 모든 시점 정보를 저장소에 그대로 보관하고, 필요 시 가중합으로 읽어 현재 입력에 더한다. “기억하려 애쓰지 말고 그냥 다 들고 있자”는 발상.

노트현대적 연장선: KV 캐시와 긴 컨텍스트

이 아이디어가 오늘날 KV 캐시와 대형 입력 토큰(긴 컨텍스트) 으로 이어진다. 최신 LLM이 수십~수백 K 토큰을 입력으로 받는 것은, 압축 기억의 어려움을 회피하고 모든 이력을 입력으로 제공하는 전략이다. 메모리 아키텍처는 현재도 활발한 연구 주제다.

8 두 번째 난제: 문맥(Context) 인코딩

8.1 직접적인 답

어떤 정보를 해석하려면 문맥을 봐야 한다. 같은 단어라도 문맥에 따라 역할·의미가 달라지므로, 고정 가중치로는 같은 단어를 매번 같은 벡터로 변환해버려 서로 다른 의미를 인코딩할 수 없다.

8.2 고전적 예시: “Buffalo buffalo …”

영어로 문법적으로 올바른 문장:

Buffalo buffalo Buffalo buffalo buffalo buffalo Buffalo buffalo.

여기서 Buffalo는 (1) 뉴욕주의 도시명, (2) 동물 ‘버펄로(아메리카 들소)’, (3) 동사 ’겁주다/괴롭히다’의 세 역할을 오간다. 문맥 없이는 어떤 buffalo가 명사인지 동사인지 알 수 없다. 한국어의 동음이의도 같은 문제다 — “감다”는 (눈을 감다) / (실을 감다) / (머리를 감다) 처럼 같은 표기가 문맥에 따라 전혀 다른 역할을 한다.

8.3 왜 고정 가중치로는 안 되는가

word2vec 같은 결정론적 함수는 같은 단어를 항상 같은 벡터로 보낸다. 거기에 고정 가중치 \(W\) 를 곱하면 결과도 항상 같다. 그렇다면 같은 단어의 다른 역할을 어떻게 구분하나?

  • 확률적 함수를 쓰면? 가중치가 매번 바뀌지만 제어 불가능하다 — 어떤 의미를 낼지 통제할 수 없다.
  • 해답: 입력 자체에 의존해 가중치를 바꾸자 → 어텐션, 그리고 그것을 쌓은 트랜스포머.
힌트무선통신 관점 비유

고정 가중치 = 고정 등화기(fixed equalizer). 채널(문맥)이 바뀌면 무력하다. 어텐션 = 적응형 등화기(adaptive equalizer): 수신 심볼(입력) 자체로부터 탭 계수를 매번 추정해 적용한다. 같은 송신 심볼이라도 채널 상태에 맞춰 다르게 복조하는 것과 같다.

9 문맥 조건부 RNN과 양방향 RNN

9.1 문맥 조건부 RNN (Type 4)

아이디어: 과거 출력을 보면 미래 예측이 나아진다. 단일 입력을 문맥으로 삼아 순차 예측하며, 미래로부터의 역방향 연결을 둔다.

시퀀스 입력에 대해 문맥을 인코딩하려면, 이전 시점의 은닉상태 출력과 이전 시점의 출력을 둘 다 현재 은닉상태의 입력으로 쓴다.

중요Type 2(teacher forcing)와의 결정적 차이

Type 2는 계산 효율(병렬화) 을 위해 출력 연결로 체인을 끊는다. 반면 문맥 조건부 RNN은 더 나은 출력을 위해 은닉상태 연결까지 함께 사용한다 — 그래서 병렬화는 포기하지만(직렬 캐스케이드) 문맥을 더 잘 나른다. 즉 같은 듯 보여도 목적이 정반대다.

9.2 양방향 RNN (Type 5)

아이디어: 앞→뒤, 뒤→앞으로 두 번 읽으면 각 단어의 문맥을 더 잘 잡는다. 정방향 은닉상태와 역방향으로 가는 또 하나의 은닉상태를 도입한다. 각 은닉상태에 전용 가중치가 필요해 파라미터는 늘지만, 시점별 문맥은 풍부해진다.

    subgraph fwd["정방향"]
      f1["→h₁"] --> f2["→h₂"] --> f3["→h₃"]
    end
    subgraph bwd["역방향"]
      b3["←h₃"] --> b2["←h₂"] --> b1["←h₁"]
    end
    f1 & b1 --> y1["y₁"]
    f2 & b2 --> y2["y₂"]
    f3 & b3 --> y3["y₃"]

10 Seq2Seq: 인코더-디코더 모델 (Type 6)

10.1 직접적인 답

Seq2Seq는 두 개의 RNN(인코더·디코더) 으로 이뤄진 범용 시퀀스 모델링 아키텍처다. 인코더(Type 3)가 입력 전체를 읽어 고정 크기 문맥 벡터 \(C\) 로 요약하고, 디코더가 \(C\) 를 받아 출력 시퀀스를 생성한다.

10.2 구조와 학습

  • 인코더(Type 3): 입력을 끝까지 읽어 의미 요약(semantic summary)인 문맥 변수 \(C\) 를 만든다.
  • 디코더(Type 4류): \(C\) 와 현재 시점 입력을 받아 매 시점 출력을 낸다. \(C\) 는 모든 출력 시점에 영향을 준다.
코드 
flowchart LR
    x1 --> E1["인코더"] --> E2["인코더"] --> E3["인코더"] --> C(("C\n문맥벡터"))
    C --> D1["디코더"] --> y1["y₁"]
    C --> D2["디코더"] --> y2["y₂"]
    D1 --> D2 --> D3["디코더"] --> y3["y₃"]
    C --> D3

학습: 기계 번역(예: 프랑스어→영어)이라면, 인코더에 원문을, 디코더 출력의 정답(gold standard)을 목표로 하여 손실을 줄인다. 손실의 그래디언트가 디코더 → 문맥 → 인코더 로 시간을 거슬러 역전파된다. 경로가 길어 그래디언트 소실·망각에 취약하다.

추론: 정답을 모르므로 디코더가 시작 토큰(<sos>)부터 시작해 자기 출력을 다음 입력으로 되먹이며 한 토큰씩 생성한다.

10.3 응용

  • QA 시스템: 입력=질문, 출력=답변
  • 대화 시스템(챗봇): 입력=사용자 발화, 출력=응답
  • 기계 번역: 입력=언어 A, 출력=언어 B
노트병목(bottleneck)의 통찰

가변 길이 입력 전체를 하나의 고정 크기 \(C\) 로 압축하는 것이 Seq2Seq의 우아함이자 약점이다. 긴 문장일수록 \(C\) 의 정보 병목이 심해진다 — 이 한계가 훗날 어텐션(디코더가 인코더의 모든 은닉상태를 직접 참조)을 낳는 직접적 동기가 된다.

힌트무선통신 관점 비유

인코더 = 소스 부호화기가 메시지를 고정 길이 코드워드 \(C\) 로 압축하는 것. 디코더 = 그 코드워드로부터 메시지를 복원하는 복호기. \(C\) 의 차원이 곧 레이트-왜곡(rate-distortion) 의 레이트이며, 너무 짧으면 긴 시퀀스를 담지 못해 왜곡이 커진다.

11 Deep RNN과 Recursive Neural Network

11.1 Deep RNN

Seq2Seq 내부의 \(f\) 를 단일 행렬곱이 아니라 다층 MLP(또는 CNN/디퓨전 등)로 바꾸면 표현력이 커진다. 깊은 연산을 재귀 안에 넣은 것을 Deep RNN이라 한다.

11.2 Recursive Neural Network

RNN의 또 다른 일반화로, 체인 구조가 아니라 트리(tree) 구조의 계산 그래프를 쓴다.

  • 탐색 복잡도 \(\tau \to \log(\tau)\) 로 감소(트리이므로).
  • 같은 아키텍처를 재귀적으로 호출하되, 시점/노드마다 다른 역할을 하길 기대한다.
  • 응용: 장면 파싱(scene parsing) — 각 은닉 노드가 장면 속 객체에 대응, 이미지를 의미 단위로 분해·합성하는 트리를 구성.
경고용어 주의 (RNN의 두 가지)

약어 RNN은 보통 Recurrent Neural Network(체인 구조)에 예약되어 있다. Recursive Neural Network(트리 구조)는 그 일반화로, 이론적으론 작동하나 각 노드가 다른 역할을 학습해야 해 실무 구현이 까다롭다(용량 한계 등으로 잘 안 됨).

12 시퀀스 모델링 요약 그리고 트랜스포머로의 다리

노트여기까지의 정리
  • 시퀀스 모델링의 두 핵심 난제: 장기 의존성 + 문맥 인코딩.
  • RNN(및 LSTM/GRU/Seq2Seq)은 둘 다를 다루는 해법이지만 충분하지 않다 — 고정 가중치라 문맥 구분이 어렵고, 직렬이라 병렬화가 안 되며, 장기 의존성도 완전치 않다.
  • 트랜스포머는 RNN의 대안으로, 문맥 인코딩이라는 어려운 문제를 입력 의존 동적 가중치로 정면 돌파한다.

13 트랜스포머: 변신하는 가중치

13.1 직접적인 답

트랜스포머는 단어마다·문맥마다 가중치를 바꾸는 Seq2Seq 모델이다. 같은 단어라도 이웃(문맥)을 보고 그때그때 다른 임베딩으로 변환해, 역할·의미를 구분해낸다. 이름 ’Transformer’는 입력에 따라 모습을 바꾸는(변신하는) 가중치에서 왔다.

각 단어의 임베딩은 이웃 단어(문맥) 를 봐야 의미가 정해진다. 그래서 Buffalo buffalo의 두 buffalo가 각각 도시/들소로 다른 임베딩을 갖게 된다.

14 핵심 1: 토큰(Tokens)

14.1 직접적인 답

토큰은 뉴런들의 벡터, 즉 정보를 캡슐화한 묶음이다. 트랜스포머는 개별 뉴런이 아니라 토큰 단위로 연산한다.

14.2 토큰화(Tokenization)

입력을 청크로 잘라 각 청크를 벡터로 사영한다. 토큰을 어떻게 정의하느냐(토큰화 방식)가 성능을 좌우한다 — 일종의 입력 엔지니어링.

입력 유형 토큰화 방식
이미지 패치(patch) 단위로 분할 후 벡터화 (ViT)
언어 문자 / 음절 / 단어 / Byte-Pair Encoding 등
오디오 시간 구간 분할, 또는 파형→스펙트로그램→패치
노트언어 토큰화의 실증적 결론

문자·음절·BPE·단어 등 다양한 단위를 시도한 결과, 어느 단위든 본질적 우열이 크지 않았다. 그래서 가장 단순하고 토큰 수가 적은 단어 단위가 널리 쓰인다. 토큰화 단계에서 비선형성을 넣지 않고, 그 역할을 트랜스포머 인코딩으로 미룬다 — 토큰화는 단순하게, 비선형 인코딩은 트랜스포머가.

토큰 집합에 대한 연산은 토큰들의 선형 결합 + 토큰별 비선형성(token-wise nonlinearity) 으로 구성된다. (GNN의 “노드 속성/특징 기술자”도 사실상 토큰이다.)

15 핵심 2: 어텐션(Attention)

15.1 직접적인 답

어텐션은 입력을 보고 가중치를 동적으로 정하는 가중합(weighting) 방식이다. 고정 가중치와 달리, 입력 자체를 입력으로 받아 가중치를 바꾼 뒤 그 가중치를 입력에 적용한다. 그래서 같은 입력이라도 문맥에 따라 다른 역할/의미를 인코딩할 수 있다.

15.2 동기: CNN의 한계 (VQA 예시)

“이 이미지에 새가 몇 마리 있나?” 같은 시각 질의응답(VQA) 을 보자. CNN은 공간 정상성(spatial stationarity)·국소성(locality) 가정 위에 세워져, 각 필터가 위치 무관하게 같은 패턴에 반응한다. 그러나:

  • 개수 세기는 위치마다 다른 의미(첫 번째 새 vs 두 번째 새)를 요구한다 — max-pooling은 가장 강한 반응만 다음 층에 넘겨 개수를 잃는다.
  • 장거리 관계(이미지 양 끝의 두 새가 같은 종인가?)는 국소 필터로 포착하기 어렵다.
  • 선택적 집중(이 영역만 보고 답하라)이 필요한데 CNN은 모든 위치를 동등 처리한다.

즉 CNN의 국소성·정상성은 장거리 관계와 문맥 의존적 처리에 부적합하다.

15.4 Query–Key–Value로 구현하기

“입력을 받아 가중치를 계산”하는 아이디어를 쿼리 \(Q\), 키 \(K\), 값 \(V\) 세 요소로 구현한다. (이 세 요소가 트랜스포머에 완전히 녹아들었으며, 반드시 이 형태일 필요는 없지만 표준이 되었다.)

힌트무선통신 관점 비유

어텐션은 빔포밍(beamforming)/공간 정합 필터다. 고정 가중치는 고정 빔(특정 방향만 수신)인 반면, 어텐션은 수신 신호(입력)로부터 채널을 추정해 빔 가중치를 매번 적응시킨다. 쿼리=원하는 방향, 키=각 안테나가 본 방향, 값=그 방향의 신호 — 쿼리와 키의 정합도(상관)가 높은 값에 더 큰 가중을 준다. 이는 정합 필터(matched filter)가 신호와의 상관으로 가중하는 것과 같은 원리다.

16 셀프 어텐션의 수식

16.1 직접적인 답

셀프 어텐션은 쿼리-키의 정합도로 정한 가중치로 값들을 가중평균하여, 각 패치/토큰의 표현을 이웃을 고려해 정련(refine)한다.

16.2 Scaled Dot-Product Attention

입력 토큰 행렬 \(X \in \mathbb{R}^{n\times d}\) 로부터 세 사영을 만든다:

\[ Q = X W_Q,\qquad K = X W_K,\qquad V = X W_V \]

어텐션 출력:

\[ \boxed{\;\mathrm{Attention}(Q,K,V) = \underbrace{\mathrm{softmax}\!\left(\frac{Q K^\top}{\sqrt{d_k}}\right)}_{A:\ \text{어텐션 행렬}\ (n\times n)} V\;} \]

  • \(QK^\top\): 모든 토큰 쌍의 유사도(내적) — 토큰 \(i\) 의 쿼리와 토큰 \(j\) 의 키가 얼마나 맞는가.
  • \(\sqrt{d_k}\) 스케일링: \(d_k\) 가 크면 내적의 분산이 \(d_k\) 에 비례해 커져 softmax가 포화(그래디언트 소실)된다. 분산을 1로 정규화하기 위함.
  • \(\mathrm{softmax}\): 각 행을 확률분포로 — 토큰 \(i\) 가 다른 토큰들에 분배하는 주의(attention) 가중치.
  • \(A V\): 그 가중치로 값들을 동적 풀링(query 기반).

이것이 “쿼리에 기반한 동적 풀링 연산”이며, 이웃 패치를 고려해 패치의 의미 표현을 정련한다. (DINO 같은 자기지도 ViT에서, 특정 패치가 ’dog’로 라벨될 때 관련 패치들이 함께 부각되는 시각화가 그 예.)

16.3 Masked Attention

때로 어떤 토큰이 어떤 토큰에 주의할지 제한하고 싶다. 어텐션 행렬을 마스킹해 구현한다:

\[ A_{ij} = \begin{cases} \mathrm{softmax}\ \text{값} & \text{허용}\\ 0\ (\text{스코어}=-\infty) & \text{금지} \end{cases} \]

디코더에서 주로 쓰며, 미래 토큰이 아니라 과거 토큰에만 주의하도록 상삼각을 막는다(causal mask). 멀티모달 입력에서 선택적 데이터 인코딩에도 활용된다.

16.4 Multi-Head Self-Attention (MHSA)

단일 \(Q,K,V\) 사영 한 벌로는 데이터의 모든 측면을 인코딩하기 부족하다. 여러 벌의 어텐션을 병렬로 두자:

\[ \begin{aligned} \mathrm{head}_h &= \mathrm{Attention}(X W_Q^h,\, X W_K^h,\, X W_V^h)\\ \mathrm{MHSA}(X) &= \mathrm{Concat}(\mathrm{head}_1,\dots,\mathrm{head}_H)\, W_O \end{aligned} \]

각 헤드가 자기만의 \(Q,K,V\) 함수를 갖고 병렬 실행된 뒤 출력 토큰 벡터들을 결합한다. 언어의 문맥 인코딩(여러 종류의 관계를 동시에 포착)에 특히 유용하다.

힌트무선통신 관점 비유

멀티헤드 = MIMO의 다중 공간 스트림. 단일 헤드(단일 빔)는 한 종류의 관계만 잡지만, 여러 헤드는 서로 다른 부공간(subspace)으로 신호를 분리·병렬 수신한다. 각 헤드가 다른 안테나 가중치(다른 \(Q,K,V\))로 다른 방향/관계를 보고, 마지막에 결합(combining)한다.

17 핵심 3: 포지셔널 인코딩(Positional Encoding)

17.1 직접적인 답

셀프 어텐션은 순열 등변(permutation equivariant) 이라 토큰 순서를 모른다. 위치 정보를 주입하기 위해, 위치마다 다른 코드 값을 입력에 더한다.

17.2 왜 필요한가: 순열 등변성

어텐션 \(A=\mathrm{softmax}(QK^\top/\sqrt{d_k})\) 는 토큰을 집합처럼 다룬다. 입력 순서를 바꾸면 출력도 같은 순서로 바뀔 뿐(등변), 순서 자체는 구분하지 못한다. 그러나 “철수가 영희를 보았다”와 “영희가 철수를 보았다”는 다르다 — 순서가 의미를 바꾼다.

17.3 구현: 위치별 코드 더하기

서로 다른 위치의 패치는 서로 다른 입력을 갖도록, 위치 \(pos\) 와 차원 \(i\) 에 대해 코드를 더한다(사인/코사인 형태):

\[ \begin{aligned} PE_{(pos,\,2i)} &= \sin\!\left(\frac{pos}{10000^{\,2i/d}}\right)\\ PE_{(pos,\,2i+1)} &= \cos\!\left(\frac{pos}{10000^{\,2i/d}}\right) \end{aligned} \]

그런 다음 \(\tilde{x}_{pos} = x_{pos} + PE_{pos}\). 이로써 모델이 순열 불변이 아니게 되어 순서를 인식한다.

힌트무선통신 관점 비유

포지셔널 인코딩은 직교 주파수 톤으로 만든 위치 파일럿(pilot) 과 같다. OFDM이 부반송파(주파수)로 심볼을 구분하듯, 사인/코사인의 서로 다른 주파수 성분이 각 위치에 고유한 ’지문’을 부여한다. 기하급수적 주파수 스펙트럼(\(10000^{2i/d}\)) 덕분에 가까운 위치는 비슷하고 먼 위치는 뚜렷이 구분되는 위상 패턴이 생긴다.

19 응용: 언어 모델과 자기회귀 트랜스포머

19.1 언어 모델(LM)

LM은 이전 단어 시퀀스가 주어졌을 때 다음 단어를 예측하는 확률 모델이다(고정 크기 윈도 가정). 규모가 크면 LLM(GPT 등).

\[ p(w_1,\dots,w_T) = \prod_{t=1}^{T} p\!\left(w_t \mid w_{1:t-1}\right) \]

19.2 자기회귀(Autoregressive) 트랜스포머와 GPT

causal attention(미래 토큰 마스킹)으로 학습하면, 각 위치는 과거만 보고 다음 토큰을 예측한다. 이 구조로 트랜스포머를 학습시킨 것이 GPT(Generative Pretrained Transformer) 다. 작은 구현 예로 minGPT(karpathy)가 있다.

노트학습 = 거대한 teacher forcing

자기회귀 LM 학습은 모든 위치에서 “다음 토큰 맞히기”를 병렬로 수행하는 것 — Type 2 RNN의 teacher forcing을 마스크드 셀프 어텐션으로 병렬화한 것이다. RNN과 달리 시점 간 직렬 의존이 없어 한 번에 전 위치를 계산한다(트랜스포머의 핵심 이점).

20 트랜스포머의 한계

  1. 윈도 밖 문맥은 인코딩하지 못한다. 컨텍스트 윈도가 곧 시야의 한계.
  2. 계산 복잡도 \(O(n^2)\) — \(n\) 은 윈도 크기. 모든 토큰 쌍의 어텐션 행렬 때문.

\[ \text{어텐션 행렬}\ A \in \mathbb{R}^{n\times n} \ \Rightarrow\ \text{시간·메모리}\ O(n^2 d) \]

이를 줄이려는 연구가 많다(Efficient Transformers). 계산 효율적 대안으로 Mamba(상태공간 모델) 등이 제시된다.

힌트무선통신 관점 비유

\(O(n^2)\) 어텐션은 완전 연결 네트워크의 모든 노드 쌍 채널 추정과 같다. \(n\) 이 커지면 파일럿/연산 오버헤드가 제곱으로 폭증한다. Efficient Transformer/희소 어텐션은 클러스터링·국소화로 의미 있는 링크만 추정하는 것에 대응한다.

노트이 노트의 결론
  • 시퀀스 모델링의 두 난제: 장기 의존성, 문맥 인코딩.

import numpy as np
np.random.seed(0)

def rnn_state_norms(W, T=40, h0=None):
    n = W.shape[0]
    h = np.ones(n) if h0 is None else h0
    norms = []
    for _ in range(T):
        h = W @ h
        norms.append(np.linalg.norm(h))
    return np.array(norms)

# |lambda| < 1 -> 소실
W_decay = np.array([[0.9, 0.1], [0.0, 0.5]])
print("eig(W_decay) =", np.round(np.linalg.eigvals(W_decay), 3))
nd = rnn_state_norms(W_decay)
print(f"||h|| : {nd[0]:.3f} -> {nd[-1]:.4f}  (소실)")

# |lambda| > 1 -> 폭발
W_explode = np.array([[1.2, 0.0], [0.0, 1.05]])

22.2 B. LSTM 셀 forward

코드 
import numpy as np
np.random.seed(1)
sigmoid = lambda x: 1.0 / (1.0 + np.exp(-x))

def lstm_step(x, h, c, P):
    z = np.concatenate([h, x])
    f = sigmoid(P['Wf'] @ z + P['bf'])   # 망각
    i = sigmoid(P['Wi'] @ z + P['bi'])   # 입력
    o = sigmoid(P['Wo'] @ z + P['bo'])   # 출력
    g = np.tanh (P['Wg'] @ z + P['bg'])  # gate gate
    c = f * c + i * g                    # 셀 상태
    h = o * np.tanh(c)                   # 은닉상태
    return h, c

H, X = 3, 2
mk = lambda a, b: np.random.randn(a, b) * 0.1
P = {k: mk(H, H + X) for k in ['Wf', 'Wi', 'Wo', 'Wg']}
P.update({k: np.zeros(H) for k in ['bf', 'bi', 'bo', 'bg']})

h, c = np.zeros(H), np.zeros(H)
for t in range(5):
    h, c = lstm_step(np.random.randn(X), h, c, P)
print("LSTM h =", np.round(h, 3))

22.3 C. GRU 셀 forward + 파라미터 수 비교

코드 
import numpy as np
np.random.seed(2)
sigmoid = lambda x: 1.0 / (1.0 + np.exp(-x))

def gru_step(x, h, P):
    z_in = np.concatenate([h, x])
    r = sigmoid(P['Wr'] @ z_in + P['br'])         # reset
    u = sigmoid(P['Wu'] @ z_in + P['bu'])         # update
    hh = np.tanh(P['Wh'] @ np.concatenate([r * h, x]) + P['bh'])  # 후보
    return (1 - u) * h + u * hh                   # 갱신

H, X = 3, 2
mk = lambda a, b: np.random.randn(a, b) * 0.1
Pg = {k: mk(H, H + X) for k in ['Wr', 'Wu', 'Wh']}
Pg.update({k: np.zeros(H) for k in ['br', 'bu', 'bh']})

h = np.zeros(H)
for t in range(5):
    h = gru_step(np.random.randn(X), h, Pg)

n_lstm = 4 * (H * (H + X) + H)
n_gru  = 3 * (H * (H + X) + H)
print(f"게이트 가중치 비율 GRU/LSTM = {n_gru / n_lstm:.2f}")  # ~0.75

22.4 D. Scaled Dot-Product Attention (+ causal mask)

import numpy as np
np.random.seed(3)

def softmax(x, axis=-1):
    x = x - x.max(axis=axis, keepdims=True)
    e = np.exp(x)
    return e / e.sum(axis=axis, keepdims=True)

def attention(Q, K, V, causal=False):
    d_k = Q.shape[-1]
    scores = Q @ K.T / np.sqrt(d_k)
    if causal:
        n = Q.shape[0]
        mask = np.tril(np.ones((n, n), dtype=bool))
        scores = np.where(mask, scores, -1e9)
    A = softmax(scores, axis=-1)
    return A @ V, A

n, d = 4, 8
Q, K, V = (np.random.randn(n, d) for _ in range(3))

out, A = attention(Q, K, V)
print("어텐션 행 합 = 1 :", np.allclose(A.sum(1), 1.0))

out_c, A_c = attention(Q, K, V, causal=True)
print("causal 상삼각 ~ 0 :", np.allclose(np.triu(A_c, 1), 0.0, atol=1e-6))

# 시퀀스 모델링이란 무엇인가 {#sec-seq-intro}

## 직접적인 답

지금까지 다룬 데이터는 길이가 **고정된 '스냅샷'** 이었다 — 이미지(숫자, 객체), 그래프 등. 반면 길이가 **가변적인** 데이터를 학습하려는 것이 시퀀스 모델링이다. 대표 예시:

- **언어(텍스트)** — 단어/문자의 가변 길이 나열
- **시계열(주식)** — 시간축 위의 값
- **비디오** — 프레임의 시퀀스
- **오디오** — 파형/스펙트로그램

주요 응용은 컴퓨터 비전(영상 분석, e.g. YOLO), 자연어 처리(텍스트 분석, e.g. GPT), 음성 인식(e.g. 음성 비서)이며, 시퀀스 모델링은 특히 NLP에서 핵심이다.

::: {.callout-tip title="무선통신 관점 비유"}
시퀀스 모델링은 **가변 길이의 심볼 스트림을 처리하는 수신기**와 같다. 패킷마다 길이가 다르고, 한 심볼의 의미가 앞뒤 심볼(채널 상태, 프리앰블)에 따라 달라진다. "현재 심볼"만 보는 무기억(memoryless) 검출기로는 ISI(심볼 간 간섭)가 있는 채널을 복조할 수 없듯, 시퀀스 모델도 과거 상태를 들고 다녀야 한다.
:::

# RNN: 동역학계로서의 시퀀스 인코더 {#sec-rnn-basic}

## 직접적인 답

RNN은 **상태를 시간에 따라 재귀적으로 갱신하는 동역학계**다. 같은 함수 $f$와 같은 파라미터 $\theta$를 매 시점 재사용하여, 가변 길이 입력을 고정 크기 상태로 압축한다.

## 수학적 전개

외부 신호가 없는 동역학계의 고전적 형태:

$$
s^{(t)} = f\!\left(s^{(t-1)};\, \theta\right)
$$

외부 입력 $x^{(t)}$ 가 들어오면:

$$
s^{(t)} = f\!\left(s^{(t-1)},\, x^{(t)};\, \theta\right)
$$

이때 상태 $s^{(t)}$ 는 **과거 시퀀스 전체의 정보를 담는다.** 이 상태를 은닉 상태(hidden state) $h^{(t)}$ 로 부르면 그것이 곧 RNN이다:

$$
\boxed{\,h^{(t)} = f\!\left(h^{(t-1)},\, x^{(t)};\, \theta\right)\,}
$$

- **입력:** 현재 시점 데이터 $x^{(t)}$ 와 과거 은닉상태 $h^{(t-1)}$
- **출력:** 현재 시점 모델 출력과 다음 시점으로 전달할 은닉상태

한 스텝(one-step) RNN을 비재귀 형태와 대비하면 그 본질이 드러난다:

$$
\begin{aligned}
\text{비재귀:}\quad & f(x_t) = w x_t + b\\
\text{슬라이딩 윈도(이동평균):}\quad & f(x_t, x_{t-1}) = w_1 x_t + w_2 x_{t-1} + b\\
\text{한 스텝 재귀:}\quad & f(x_t, x_{t-1}) = w_1 x_t + w_2\, f(x_{t-1}, x_{t-2}) + b
\end{aligned}
$$

재귀 항 $f(x_{t-1},x_{t-2})$ 이 과거를 무한히 거슬러 올라가게 만든다.

## 재귀 구조의 두 가지 이득

::: {.callout-note title="왜 재귀가 좋은가"}
1. **시퀀스 길이와 무관하게 입력 크기가 항상 동일하다.** 학습된 모델이 임의 길이를 처리한다.
2. **매 시점 같은 전이함수 $f$ 와 같은 파라미터를 재사용**할 수 있다(파라미터 공유).
:::

```{mermaid}
flowchart LR
    x1["x⁽¹⁾"] --> h1["h⁽¹⁾"]
    x2["x⁽²⁾"] --> h2["h⁽²⁾"]
    x3["x⁽³⁾"] --> h3["h⁽³⁾"]
    h0["h⁽⁰⁾"] --> h1 --> h2 --> h3 --> hT["..."]
    h1 --> o1["o⁽¹⁾"]
    h2 --> o2["o⁽²⁾"]
    h3 --> o3["o⁽³⁾"]
```

## RNN의 세 가지 유형 {#sec-rnn-types}

| 유형 | 구조 | 특징 |
|---|---|---|
| **Type 1** | 매 시점 출력 + **은닉상태 간** 재귀 연결 | 가장 일반적·표현력 높음 |
| **Type 2** | 매 시점 출력 + **출력→다음 은닉상태** 연결 (Teacher forcing) | 병렬화 쉬움 / 은닉상태 연결이 없어 과거를 더 잘 잊음 |
| **Type 3** | 은닉상태 재귀 + 시퀀스 전체를 읽고 **끝에서 단일 출력** | 분류/요약형 |

::: {.callout-important title="Teacher forcing (Type 2)의 정밀한 정의"}
- **학습 시:** 정답 출력 $y^{(t)}$ (train set에서 추출)을 다음 시점 은닉상태 $h^{(t+1)}$ 의 입력으로 먹인다.
- **추론 시:** 정답을 모르므로 모델 출력 $o^{(t)}$ 로 $y^{(t)}$ 를 근사하여 되먹인다.

학습-추론 분포 불일치(exposure bias)가 생기는 원인이 바로 여기다. 장점은 출력 의존성을 끊어 **시점별로 분리 학습 → 병렬화**가 가능하다는 점이다.
:::

# 장기 의존성 문제: 왜 RNN으로는 부족한가 {#sec-longterm}

## 직접적인 답

단순 비선형 함수를 여러 번 합성하면 합성 함수는 **극도로 비선형**해진다. RNN의 시간 전개가 정확히 이 합성이며, 그 결과 **그래디언트가 소실(대부분)되거나 폭발(드물지만 치명적)**하여 먼 과거의 정보를 학습에 반영하기 어렵다.

## 수학적 전개 (고유값 분해 관점)

선형 근사된 RNN 전이 $h^{(t)} = W^\top h^{(t-1)}$ 를 보자. $W$ 를 고유값 분해 $W = Q\,\Lambda\, Q^{-1}$ 하면:

$$
h^{(t)} = \left(W^\top\right)^{t} h^{(0)} = Q\, \Lambda^{t}\, Q^{-1} h^{(0)}
$$

여기서 $\Lambda^{t} = \mathrm{diag}(\lambda_1^t, \dots, \lambda_n^t)$ 이므로,

$$
\boxed{\;|\lambda_i| < 1 \Rightarrow \lambda_i^{t}\to 0 \ (\text{소실}), \qquad |\lambda_i| > 1 \Rightarrow \lambda_i^{t}\to \infty \ (\text{폭발})\;}
$$

즉 **시간 깊이 $t$ 에 대해 기여가 지수적으로 감쇠/증폭**된다. 정확히 $|\lambda_i|=1$ 인 경계만이 정보를 보존하지만, 학습 중 이를 유지하기는 사실상 불가능하다.

::: {.callout-tip title="무선통신 관점 비유"}
이것은 **다중 홉 중계(multi-hop relay)에서의 누적 채널 이득**과 같다. 각 홉의 이득을 $\lambda$ 라 하면 $t$ 홉 뒤 신호는 $\lambda^t$. $|\lambda|<1$ 이면 신호가 잡음 아래로 가라앉고($\to$ 정보 소실), $|\lambda|>1$ 이면 비선형 증폭으로 클리핑·발산한다($\to$ 폭발). 안정 전송을 위해 AGC(자동이득제어)로 이득을 1 근처로 묶듯, RNN도 스펙트럴 반경을 1 근처로 제어해야 한다.
:::

## 핵심 처방: 게이팅(Gating)

> 과거↔현재(혹은 미래)를 직접 잇는 연결을 만들자.

대표 구현이 **게이팅**이다. 단순 곱 $f(x)=a\cdot x,\ a\in[0,1]$ 를 다음으로 바꾼다:

$$
f(x) = a\cdot x + (1-a)\cdot m
$$

여기서 $m$ 은 **메모리**. 이는 모멘텀/이동평균과 같은 직관 — 현재 입력과 과거 메모리를 가중 혼합하여 정보를 오래 유지한다. 대표 구현 두 가지: **LSTM**(1997)과 **GRU**(2014).

# LSTM: Long Short-Term Memory {#sec-lstm}

## 직접적인 답

LSTM은 **명시적 메모리 셀 $c_t$ 와 세 개의 게이트(망각·입력·출력) + 게이트 게이트**로, 셀 내용을 *얼마나 잊고, 얼마나 새로 쓰고, 얼마나 내보낼지*를 부드럽게(softly) 조절해 장기 정보를 유지한다.

## 수학적 전개

입력으로 직전 은닉상태 $h_{t-1}$ 와 현재 입력 $x_t$ 를 결합한다. 게이트는 모두 시그모이드 $\sigma(\cdot)\in(0,1)$, 후보는 $\tanh$:

$$
\begin{aligned}
f_t &= \sigma\!\left(W_f\,[h_{t-1}, x_t] + b_f\right) && \text{(망각 gate)}\\
i_t &= \sigma\!\left(W_i\,[h_{t-1}, x_t] + b_i\right) && \text{(입력 gate)}\\
o_t &= \sigma\!\left(W_o\,[h_{t-1}, x_t] + b_o\right) && \text{(출력 gate)}\\
g_t &= \tanh\!\left(W_g\,[h_{t-1}, x_t] + b_g\right) && \text{(gate gate / 후보 메모리)}\\[4pt]
c_t &= f_t \odot c_{t-1} + i_t \odot g_t && \text{(셀 상태 갱신)}\\
h_t &= o_t \odot \tanh(c_t) && \text{(은닉상태 출력)}
\end{aligned}
$$

각 게이트의 역할:

- $f_t$(**망각**): 이전 셀 내용 $c_{t-1}$ 을 얼마나 유지할지 — 셀의 self-loop 연결을 부드럽게 조절(throttling).
- $i_t$(**입력**): 현재 정보를 셀에 얼마나 쓸지.
- $g_t$(**게이트 게이트**): 셀에 쓸 후보 내용 자체.
- $o_t$(**출력**): 셀 내용을 출력/은닉상태로 얼마나 내보낼지.

::: {.callout-important title="LSTM은 두 개의 흐름을 갖는다"}
바닐라 RNN이 은닉상태 $h$ **하나만** 시간에 따라 전파하는 반면, LSTM은 **셀 상태 $c$(전용 메모리)** 와 **은닉상태 $h$** **두 개**를 함께 전파한다. 핵심은 셀 상태 경로가 망각 게이트에 의한 곱셈 + 입력의 덧셈으로만 갱신되어, **그래디언트가 거의 1에 가까운 경로로 흐를 수 있다**는 점($c_{t-1}\to c_t$ 의 야코비안이 $\mathrm{diag}(f_t)$)이다. 이것이 장기 정보를 살리는 메커니즘이다.
:::

## 기하/직관

망각 게이트가 1에 가까우면 셀 상태는 거의 그대로 흘러가는 **'컨베이어 벨트'** 가 된다. 정보를 통째로 보관하는 게 아니라 게이트로 가공·저장하므로, 바닐라 RNN보다 길게 기억하지만 **여전히 무한히 기억하지는 못한다.** (날고기 대신 소시지를 먹는 셈 — 가공되어 원래 맛은 일부 손실된다.)

::: {.callout-tip title="무선통신 관점 비유"}
셀 상태 $c_t$ 는 **누설 적분기(leaky integrator) 기반의 채널 추정기/추적 필터**다. 망각 게이트 $f_t$ 는 잊음 인자(forgetting factor) $\lambda$ 를 가진 RLS(재귀 최소자승)의 적응형 버전: 채널이 정적이면 $f_t\to1$ 로 오래 평균내고, 급변하면 $f_t\downarrow$ 로 과거를 빨리 버린다. 입력 게이트는 새 관측의 신뢰도(칼만 이득)에 해당한다.
:::

# GRU: Gated Recurrent Unit {#sec-gru}

## 직접적인 답

GRU는 LSTM과 **거의 같은 아이디어를 더 단순하게** 구현한 게이팅 유닛으로, 게이트가 3개(업데이트·리셋·후보)이고 **별도 셀 상태가 없다.** LSTM 대비 적은 파라미터로 대등한 성능을 낸다.

## 수학적 전개

$$
\begin{aligned}
r_t &= \sigma\!\left(W_r\,[h_{t-1}, x_t] + b_r\right) && \text{(reset gate)}\\
z_t &= \sigma\!\left(W_z\,[h_{t-1}, x_t] + b_z\right) && \text{(update gate)}\\
\tilde{h}_t &= \tanh\!\left(W_h\,[\,r_t \odot h_{t-1},\, x_t\,] + b_h\right) && \text{(후보 상태)}\\[4pt]
h_t &= (1 - z_t)\odot h_{t-1} + z_t \odot \tilde{h}_t && \text{(상태 갱신)}
\end{aligned}
$$

- **reset gate $r_t$**: 이전 상태를 후보 계산에 얼마나 반영할지(리셋 정도).
- **update gate $z_t$**: 과거 상태와 새 후보를 혼합하는 비율 — LSTM의 망각+입력 게이트를 하나로 합친 형태.

마지막 식이 정확히 게이팅 처방 $f(x)=z\cdot(\text{새것}) + (1-z)\cdot(\text{메모리})$ 의 형태임에 주목.

## LSTM vs GRU 비교

| 항목 | LSTM | GRU |
|---|---|---|
| 게이트 수 | 4 (forget, input, output, gate) | 3 (reset, update, candidate) |
| 메모리 경로 | 셀 상태 $c$ + 은닉 $h$ (2개) | 은닉 $h$ (1개) |
| 제안 연도 | 1997 | 2014 |
| 파라미터 | 기준 | 더 적음 |
| 성능 | 기준 | 대등(on par) |
| 효용 | — | 과적합 위험↓, 학습 데이터·연산 비용↓ |

::: {.callout-warning title="'파라미터 절반'에 대한 정밀한 주의"}
게이트별 가중치 행렬만 세면 LSTM 4개 vs GRU 3개로 **$3/4$** 이다. 흔히 인용되는 "약 1/2"은 셀 상태 경로 제거와 실무적 단순화까지 포함한 **느슨한 어림수**이며, 엄밀한 게이트 가중치 비율은 $3/4$ 에 가깝다. 어느 쪽이든 결론은 동일하다: GRU가 더 적은 파라미터로 대등한 성능을 낸다.
:::

# 장기 의존성을 위한 다른 해법들 {#sec-other-longterm}

게이팅 외에도 과거 정보를 멀리까지 나르는 다섯 가지 아이디어가 있다.

**아이디어 1 — 시간축 스킵 연결(Skip connection through time).**
가공된 셀 내용에만 의존하지 말고, 과거에서 현재로 **직접 연결**을 추가한다. 비전의 DenseNet/ResNet의 공간적 스킵 연결을 시간축으로 옮긴 발상으로, 게이트 효과 없이 메모리를 더 오래 보존한다.

**아이디어 2 — 누설 유닛(Leaky units).**
이동평균 형태로 천천히 움직이는 입력을 유지한다($W_{rec}$: 재귀 가중치, $W_{in}$: 입력 가중치):

$$
\mu^{(t)} = \alpha\,\mu^{(t-1)} + (1-\alpha)\,(\cdot)
$$

::: {.callout-warning title="'Leaky unit' ≠ 'Leaky ReLU'"}
이름은 비슷하나 완전히 다르다. **Leaky ReLU**는 음수 입력도 일부 통과시키는 *활성함수*다. **Leaky unit**은 시간에 따라 정보를 천천히 누설·적분하는 *상태 갱신* 메커니즘이다. 동기·역할 모두 다르다.
:::

**아이디어 3 — 게이팅(LSTM/GRU).** 위에서 다룸.

**아이디어 4 — 최적화 트릭.**
- **그래디언트 클리핑** → 폭발 그래디언트 대응(국소적으로 왜곡된 손실 영역에서 스텝 크기 제한).
- **정보 흐름을 장려하는 정규화** → 소실 그래디언트 대응.

**아이디어 5 — 명시적 메모리(Explicit memory).**
Memory Network처럼 과거 모든 시점 정보를 **저장소에 그대로 보관**하고, 필요 시 가중합으로 읽어 현재 입력에 더한다. "기억하려 애쓰지 말고 그냥 다 들고 있자"는 발상.

::: {.callout-note title="현대적 연장선: KV 캐시와 긴 컨텍스트"}
이 아이디어가 오늘날 **KV 캐시**와 **대형 입력 토큰(긴 컨텍스트)** 으로 이어진다. 최신 LLM이 수십~수백 K 토큰을 입력으로 받는 것은, 압축 기억의 어려움을 회피하고 **모든 이력을 입력으로 제공**하는 전략이다. 메모리 아키텍처는 현재도 활발한 연구 주제다.
:::

# 두 번째 난제: 문맥(Context) 인코딩 {#sec-context}

## 직접적인 답

어떤 정보를 해석하려면 **문맥**을 봐야 한다. 같은 단어라도 문맥에 따라 역할·의미가 달라지므로, **고정 가중치**로는 같은 단어를 매번 같은 벡터로 변환해버려 서로 다른 의미를 인코딩할 수 없다.

## 고전적 예시: "Buffalo buffalo …"

영어로 문법적으로 올바른 문장:

> Buffalo buffalo Buffalo buffalo buffalo buffalo Buffalo buffalo.

여기서 `Buffalo`는 (1) 뉴욕주의 도시명, (2) 동물 '버펄로(아메리카 들소)', (3) 동사 '겁주다/괴롭히다'의 세 역할을 오간다. 문맥 없이는 어떤 `buffalo`가 명사인지 동사인지 알 수 없다. 한국어의 동음이의도 같은 문제다 — "감다"는 (눈을 **감다**) / (실을 **감다**) / (머리를 **감다**) 처럼 같은 표기가 문맥에 따라 전혀 다른 역할을 한다.

## 왜 고정 가중치로는 안 되는가

word2vec 같은 결정론적 함수는 같은 단어를 항상 같은 벡터로 보낸다. 거기에 **고정 가중치 $W$** 를 곱하면 결과도 항상 같다. 그렇다면 같은 단어의 *다른 역할*을 어떻게 구분하나?

- **확률적 함수**를 쓰면? 가중치가 매번 바뀌지만 **제어 불가능**하다 — 어떤 의미를 낼지 통제할 수 없다.
- **해답:** 입력 자체에 의존해 가중치를 바꾸자 → **어텐션**, 그리고 그것을 쌓은 **트랜스포머**.

::: {.callout-tip title="무선통신 관점 비유"}
고정 가중치 = **고정 등화기(fixed equalizer)**. 채널(문맥)이 바뀌면 무력하다. 어텐션 = **적응형 등화기(adaptive equalizer)**: 수신 심볼(입력) 자체로부터 탭 계수를 매번 추정해 적용한다. 같은 송신 심볼이라도 채널 상태에 맞춰 다르게 복조하는 것과 같다.
:::

# 문맥 조건부 RNN과 양방향 RNN {#sec-context-rnn}

## 문맥 조건부 RNN (Type 4)

**아이디어:** 과거 출력을 보면 미래 예측이 나아진다. 단일 입력을 문맥으로 삼아 순차 예측하며, **미래로부터의 역방향 연결**을 둔다.

시퀀스 입력에 대해 문맥을 인코딩하려면, **이전 시점의 은닉상태 출력**과 **이전 시점의 출력**을 *둘 다* 현재 은닉상태의 입력으로 쓴다.

::: {.callout-important title="Type 2(teacher forcing)와의 결정적 차이"}
Type 2는 **계산 효율(병렬화)** 을 위해 출력 연결로 체인을 끊는다. 반면 문맥 조건부 RNN은 **더 나은 출력**을 위해 *은닉상태 연결까지 함께* 사용한다 — 그래서 병렬화는 포기하지만(직렬 캐스케이드) 문맥을 더 잘 나른다. 즉 같은 듯 보여도 *목적*이 정반대다.
:::

## 양방향 RNN (Type 5)

**아이디어:** 앞→뒤, 뒤→앞으로 두 번 읽으면 각 단어의 문맥을 더 잘 잡는다. 정방향 은닉상태와 **역방향으로 가는 또 하나의 은닉상태**를 도입한다. 각 은닉상태에 전용 가중치가 필요해 파라미터는 늘지만, 시점별 문맥은 풍부해진다.

```{mermaid}
flowchart LR
    subgraph fwd["정방향"]
      f1["→h₁"] --> f2["→h₂"] --> f3["→h₃"]
    end
    subgraph bwd["역방향"]
      b3["←h₃"] --> b2["←h₂"] --> b1["←h₁"]
    end
    f1 & b1 --> y1["y₁"]
    f2 & b2 --> y2["y₂"]
    f3 & b3 --> y3["y₃"]
```

# Seq2Seq: 인코더-디코더 모델 (Type 6) {#sec-seq2seq}

## 직접적인 답

Seq2Seq는 **두 개의 RNN(인코더·디코더)** 으로 이뤄진 범용 시퀀스 모델링 아키텍처다. 인코더(Type 3)가 입력 전체를 읽어 **고정 크기 문맥 벡터 $C$** 로 요약하고, 디코더가 $C$ 를 받아 출력 시퀀스를 생성한다.

## 구조와 학습

- **인코더(Type 3):** 입력을 끝까지 읽어 의미 요약(semantic summary)인 문맥 변수 $C$ 를 만든다.
- **디코더(Type 4류):** $C$ 와 현재 시점 입력을 받아 매 시점 출력을 낸다. $C$ 는 **모든 출력 시점에 영향**을 준다.

```{mermaid}
flowchart LR
    x1 --> E1["인코더"] --> E2["인코더"] --> E3["인코더"] --> C(("C\n문맥벡터"))
    C --> D1["디코더"] --> y1["y₁"]
    C --> D2["디코더"] --> y2["y₂"]
    D1 --> D2 --> D3["디코더"] --> y3["y₃"]
    C --> D3
```

**학습:** 기계 번역(예: 프랑스어→영어)이라면, 인코더에 원문을, 디코더 출력의 정답(gold standard)을 목표로 하여 손실을 줄인다. 손실의 그래디언트가 **디코더 → 문맥 → 인코더** 로 시간을 거슬러 역전파된다. 경로가 길어 그래디언트 소실·망각에 취약하다.

**추론:** 정답을 모르므로 디코더가 시작 토큰(`<sos>`)부터 시작해 자기 출력을 다음 입력으로 되먹이며 한 토큰씩 생성한다.

## 응용

- **QA 시스템:** 입력=질문, 출력=답변
- **대화 시스템(챗봇):** 입력=사용자 발화, 출력=응답
- **기계 번역:** 입력=언어 A, 출력=언어 B

::: {.callout-note title="병목(bottleneck)의 통찰"}
가변 길이 입력 전체를 **하나의 고정 크기 $C$** 로 압축하는 것이 Seq2Seq의 우아함이자 약점이다. 긴 문장일수록 $C$ 의 정보 병목이 심해진다 — 이 한계가 훗날 어텐션(디코더가 인코더의 *모든* 은닉상태를 직접 참조)을 낳는 직접적 동기가 된다.
:::

::: {.callout-tip title="무선통신 관점 비유"}
인코더 = **소스 부호화기**가 메시지를 고정 길이 코드워드 $C$ 로 압축하는 것. 디코더 = 그 코드워드로부터 메시지를 복원하는 복호기. $C$ 의 차원이 곧 **레이트-왜곡(rate-distortion)** 의 레이트이며, 너무 짧으면 긴 시퀀스를 담지 못해 왜곡이 커진다.
:::

# Deep RNN과 Recursive Neural Network {#sec-deep-recursive}

## Deep RNN

Seq2Seq 내부의 $f$ 를 단일 행렬곱이 아니라 **다층 MLP**(또는 CNN/디퓨전 등)로 바꾸면 표현력이 커진다. 깊은 연산을 재귀 안에 넣은 것을 Deep RNN이라 한다.

## Recursive Neural Network

RNN의 또 다른 일반화로, **체인 구조가 아니라 트리(tree) 구조**의 계산 그래프를 쓴다.

- 탐색 복잡도 $\tau \to \log(\tau)$ 로 감소(트리이므로).
- 같은 아키텍처를 **재귀적으로** 호출하되, 시점/노드마다 *다른 역할*을 하길 기대한다.
- 응용: **장면 파싱(scene parsing)** — 각 은닉 노드가 장면 속 객체에 대응, 이미지를 의미 단위로 분해·합성하는 트리를 구성.

::: {.callout-warning title="용어 주의 (RNN의 두 가지)"}
약어 **RNN**은 보통 **Recurrent** Neural Network(체인 구조)에 예약되어 있다. **Recursive** Neural Network(트리 구조)는 그 일반화로, 이론적으론 작동하나 각 노드가 다른 역할을 학습해야 해 실무 구현이 까다롭다(용량 한계 등으로 잘 안 됨).
:::

# 시퀀스 모델링 요약 그리고 트랜스포머로의 다리 {#sec-bridge}

::: {.callout-note title="여기까지의 정리"}
- 시퀀스 모델링의 **두 핵심 난제: 장기 의존성 + 문맥 인코딩.**
- RNN(및 LSTM/GRU/Seq2Seq)은 둘 다를 다루는 해법이지만 **충분하지 않다** — 고정 가중치라 문맥 구분이 어렵고, 직렬이라 병렬화가 안 되며, 장기 의존성도 완전치 않다.
- **트랜스포머**는 RNN의 대안으로, 문맥 인코딩이라는 어려운 문제를 *입력 의존 동적 가중치*로 정면 돌파한다.
:::

# 트랜스포머: 변신하는 가중치 {#sec-transformer-intro}

## 직접적인 답

트랜스포머는 **단어마다·문맥마다 가중치를 바꾸는 Seq2Seq 모델**이다. 같은 단어라도 이웃(문맥)을 보고 *그때그때 다른* 임베딩으로 변환해, 역할·의미를 구분해낸다. 이름 'Transformer'는 입력에 따라 모습을 바꾸는(변신하는) 가중치에서 왔다.

각 단어의 임베딩은 **이웃 단어(문맥)** 를 봐야 의미가 정해진다. 그래서 `Buffalo buffalo`의 두 buffalo가 각각 도시/들소로 다른 임베딩을 갖게 된다.

## 세 가지 핵심 아이디어

```{mermaid}
flowchart TB
    T["Transformer"] --> A["1. 토큰 (Tokens)"]
    T --> B["2. 어텐션 (Attention)"]
    T --> C["3. 포지셔널 인코딩 (Positional Encoding)"]
```

---

# 핵심 1: 토큰(Tokens) {#sec-tokens}

## 직접적인 답

토큰은 **뉴런들의 벡터**, 즉 정보를 캡슐화한 묶음이다. 트랜스포머는 개별 뉴런이 아니라 **토큰 단위**로 연산한다.

## 토큰화(Tokenization)

입력을 청크로 잘라 각 청크를 벡터로 사영한다. 토큰을 어떻게 정의하느냐(토큰화 방식)가 성능을 좌우한다 — 일종의 입력 엔지니어링.

| 입력 유형 | 토큰화 방식 |
|---|---|
| 이미지 | **패치(patch)** 단위로 분할 후 벡터화 (ViT) |
| 언어 | 문자 / 음절 / 단어 / Byte-Pair Encoding 등 |
| 오디오 | 시간 구간 분할, 또는 파형→스펙트로그램→패치 |

::: {.callout-note title="언어 토큰화의 실증적 결론"}
문자·음절·BPE·단어 등 다양한 단위를 시도한 결과, **어느 단위든 본질적 우열이 크지 않았다.** 그래서 가장 단순하고 토큰 수가 적은 **단어 단위**가 널리 쓰인다. 토큰화 단계에서 비선형성을 넣지 않고, 그 역할을 트랜스포머 인코딩으로 미룬다 — 토큰화는 단순하게, 비선형 인코딩은 트랜스포머가.
:::

토큰 집합에 대한 연산은 **토큰들의 선형 결합** + **토큰별 비선형성(token-wise nonlinearity)** 으로 구성된다. (GNN의 "노드 속성/특징 기술자"도 사실상 토큰이다.)

# 핵심 2: 어텐션(Attention) {#sec-attention}

## 직접적인 답

어텐션은 **입력을 보고 가중치를 동적으로 정하는 가중합(weighting) 방식**이다. 고정 가중치와 달리, 입력 자체를 입력으로 받아 가중치를 바꾼 뒤 그 가중치를 입력에 적용한다. 그래서 같은 입력이라도 문맥에 따라 다른 역할/의미를 인코딩할 수 있다.

## 동기: CNN의 한계 (VQA 예시)

"이 이미지에 새가 몇 마리 있나?" 같은 **시각 질의응답(VQA)** 을 보자. CNN은 **공간 정상성(spatial stationarity)·국소성(locality)** 가정 위에 세워져, 각 필터가 위치 무관하게 같은 패턴에 반응한다. 그러나:

- **개수 세기**는 위치마다 *다른* 의미(첫 번째 새 vs 두 번째 새)를 요구한다 — max-pooling은 가장 강한 반응만 다음 층에 넘겨 개수를 잃는다.
- **장거리 관계**(이미지 양 끝의 두 새가 같은 종인가?)는 국소 필터로 포착하기 어렵다.
- **선택적 집중**(이 영역만 보고 답하라)이 필요한데 CNN은 모든 위치를 동등 처리한다.

즉 CNN의 국소성·정상성은 장거리 관계와 문맥 의존적 처리에 부적합하다.

## 고정 가중치 vs 셀프 어텐션

| | 고정 가중치 | (셀프) 어텐션 |
|---|---|---|
| 가중치 | 입력과 무관하게 **고정** | **입력에 따라 변함** (트리거 = 입력) |
| 학습 대상 | $W$ (데이터로 학습, 고정) | 어텐션 함수 $a(\cdot)$ — 데이터로 학습되지만 **입력을 받아 입력에 적용** |
| 문맥 처리 | 불가 | 가능 |

## Query–Key–Value로 구현하기

"입력을 받아 가중치를 계산"하는 아이디어를 **쿼리 $Q$, 키 $K$, 값 $V$** 세 요소로 구현한다. (이 세 요소가 트랜스포머에 완전히 녹아들었으며, 반드시 이 형태일 필요는 없지만 표준이 되었다.)

::: {.callout-tip title="무선통신 관점 비유"}
어텐션은 **빔포밍(beamforming)/공간 정합 필터**다. 고정 가중치는 고정 빔(특정 방향만 수신)인 반면, 어텐션은 **수신 신호(입력)로부터 채널을 추정해 빔 가중치를 매번 적응**시킨다. 쿼리=원하는 방향, 키=각 안테나가 본 방향, 값=그 방향의 신호 — 쿼리와 키의 정합도(상관)가 높은 값에 더 큰 가중을 준다. 이는 정합 필터(matched filter)가 신호와의 상관으로 가중하는 것과 같은 원리다.
:::

# 셀프 어텐션의 수식 {#sec-self-attention}

## 직접적인 답

셀프 어텐션은 **쿼리-키의 정합도로 정한 가중치로 값들을 가중평균**하여, 각 패치/토큰의 표현을 *이웃을 고려해* 정련(refine)한다.

## Scaled Dot-Product Attention

입력 토큰 행렬 $X \in \mathbb{R}^{n\times d}$ 로부터 세 사영을 만든다:

$$
Q = X W_Q,\qquad K = X W_K,\qquad V = X W_V
$$

어텐션 출력:

$$
\boxed{\;\mathrm{Attention}(Q,K,V) = \underbrace{\mathrm{softmax}\!\left(\frac{Q K^\top}{\sqrt{d_k}}\right)}_{A:\ \text{어텐션 행렬}\ (n\times n)} V\;}
$$

- $QK^\top$: 모든 토큰 쌍의 **유사도(내적)** — 토큰 $i$ 의 쿼리와 토큰 $j$ 의 키가 얼마나 맞는가.
- $\sqrt{d_k}$ **스케일링**: $d_k$ 가 크면 내적의 분산이 $d_k$ 에 비례해 커져 softmax가 포화(그래디언트 소실)된다. 분산을 1로 정규화하기 위함.
- $\mathrm{softmax}$: 각 행을 확률분포로 — 토큰 $i$ 가 다른 토큰들에 분배하는 주의(attention) 가중치.
- $A V$: 그 가중치로 값들을 **동적 풀링(query 기반)**.

이것이 "쿼리에 기반한 동적 풀링 연산"이며, **이웃 패치를 고려해 패치의 의미 표현을 정련**한다. (DINO 같은 자기지도 ViT에서, 특정 패치가 'dog'로 라벨될 때 관련 패치들이 함께 부각되는 시각화가 그 예.)

## Masked Attention

때로 어떤 토큰이 어떤 토큰에 주의할지 **제한**하고 싶다. 어텐션 행렬을 **마스킹**해 구현한다:

$$
A_{ij} =
\begin{cases}
\mathrm{softmax}\ \text{값} & \text{허용}\\
0\ (\text{스코어}=-\infty) & \text{금지}
\end{cases}
$$

**디코더**에서 주로 쓰며, **미래 토큰이 아니라 과거 토큰에만 주의**하도록 상삼각을 막는다(causal mask). 멀티모달 입력에서 선택적 데이터 인코딩에도 활용된다.

## Multi-Head Self-Attention (MHSA)

단일 $Q,K,V$ 사영 한 벌로는 데이터의 모든 측면을 인코딩하기 부족하다. **여러 벌의 어텐션을 병렬로** 두자:

$$
\begin{aligned}
\mathrm{head}_h &= \mathrm{Attention}(X W_Q^h,\, X W_K^h,\, X W_V^h)\\
\mathrm{MHSA}(X) &= \mathrm{Concat}(\mathrm{head}_1,\dots,\mathrm{head}_H)\, W_O
\end{aligned}
$$

각 헤드가 자기만의 $Q,K,V$ 함수를 갖고 병렬 실행된 뒤 출력 토큰 벡터들을 결합한다. 언어의 문맥 인코딩(여러 종류의 관계를 동시에 포착)에 특히 유용하다.

::: {.callout-tip title="무선통신 관점 비유"}
멀티헤드 = **MIMO의 다중 공간 스트림**. 단일 헤드(단일 빔)는 한 종류의 관계만 잡지만, 여러 헤드는 서로 다른 부공간(subspace)으로 신호를 분리·병렬 수신한다. 각 헤드가 다른 안테나 가중치(다른 $Q,K,V$)로 다른 방향/관계를 보고, 마지막에 결합(combining)한다.
:::

# 핵심 3: 포지셔널 인코딩(Positional Encoding) {#sec-positional}

## 직접적인 답

셀프 어텐션은 **순열 등변(permutation equivariant)** 이라 토큰 순서를 모른다. 위치 정보를 주입하기 위해, **위치마다 다른 코드 값을 입력에 더한다.**

## 왜 필요한가: 순열 등변성

어텐션 $A=\mathrm{softmax}(QK^\top/\sqrt{d_k})$ 는 토큰을 집합처럼 다룬다. 입력 순서를 바꾸면 출력도 같은 순서로 바뀔 뿐(등변), 순서 자체는 구분하지 못한다. 그러나 "철수가 영희를 보았다"와 "영희가 철수를 보았다"는 다르다 — 순서가 의미를 바꾼다.

## 구현: 위치별 코드 더하기

서로 다른 위치의 패치는 서로 다른 입력을 갖도록, 위치 $pos$ 와 차원 $i$ 에 대해 코드를 더한다(사인/코사인 형태):

$$
\begin{aligned}
PE_{(pos,\,2i)} &= \sin\!\left(\frac{pos}{10000^{\,2i/d}}\right)\\
PE_{(pos,\,2i+1)} &= \cos\!\left(\frac{pos}{10000^{\,2i/d}}\right)
\end{aligned}
$$

그런 다음 $\tilde{x}_{pos} = x_{pos} + PE_{pos}$. 이로써 모델이 **순열 불변이 아니게** 되어 순서를 인식한다.

::: {.callout-tip title="무선통신 관점 비유"}
포지셔널 인코딩은 **직교 주파수 톤으로 만든 위치 파일럿(pilot)** 과 같다. OFDM이 부반송파(주파수)로 심볼을 구분하듯, 사인/코사인의 서로 다른 주파수 성분이 각 위치에 고유한 '지문'을 부여한다. 기하급수적 주파수 스펙트럼($10000^{2i/d}$) 덕분에 가까운 위치는 비슷하고 먼 위치는 뚜렷이 구분되는 위상 패턴이 생긴다.
:::

세 핵심을 조립하면 인코더-디코더 트랜스포머가 된다. 인코더가 입력을 문맥화하고, 디코더가 (causal mask로) 자기회귀적으로 출력을 생성한다.

```{mermaid}
flowchart TB
    subgraph ENC["인코더 (×N)"]
      ie["입력 임베딩 + PE"] --> mha["Multi-Head Self-Attention"]
      mha --> an1["Add & Norm"]
      an1 --> ff1["FeedForward"]
      ff1 --> an2["Add & Norm"]
    end
    subgraph DEC["디코더 (×N)"]

      an3 --> cross["Cross-Attention (Q=디코더, K,V=인코더)"]
      cross --> an4["Add & Norm"]
      an4 --> ff2["FeedForward"]

    an2 -. "K, V" .-> cross
```

- **Add & Norm:** 잔차 연결(skip)로 그래디언트 흐름 보존 + LayerNorm으로 안정화.
- **Cross-Attention:** 디코더의 쿼리가 인코더 출력(키·값)에 주의 — Seq2Seq의 문맥 벡터 $C$ 를 *모든 인코더 위치에 대한 동적 참조*로 일반화한 것.

# 응용: 언어 모델과 자기회귀 트랜스포머 {#sec-application}

## 언어 모델(LM)

LM은 **이전 단어 시퀀스가 주어졌을 때 다음 단어를 예측하는 확률 모델**이다(고정 크기 윈도 가정). 규모가 크면 **LLM**(GPT 등).

$$
p(w_1,\dots,w_T) = \prod_{t=1}^{T} p\!\left(w_t \mid w_{1:t-1}\right)
$$

## 자기회귀(Autoregressive) 트랜스포머와 GPT

**causal attention**(미래 토큰 마스킹)으로 학습하면, 각 위치는 과거만 보고 다음 토큰을 예측한다. 이 구조로 트랜스포머를 학습시킨 것이 **GPT(Generative Pretrained Transformer)** 다. 작은 구현 예로 `minGPT`(karpathy)가 있다.

::: {.callout-note title="학습 = 거대한 teacher forcing"}
자기회귀 LM 학습은 모든 위치에서 "다음 토큰 맞히기"를 병렬로 수행하는 것 — Type 2 RNN의 teacher forcing을 마스크드 셀프 어텐션으로 *병렬화*한 것이다. RNN과 달리 시점 간 직렬 의존이 없어 한 번에 전 위치를 계산한다(트랜스포머의 핵심 이점).
:::

# 트랜스포머의 한계 {#sec-limitations}

1. **윈도 밖 문맥은 인코딩하지 못한다.** 컨텍스트 윈도가 곧 시야의 한계.
2. **계산 복잡도 $O(n^2)$** — $n$ 은 윈도 크기. 모든 토큰 쌍의 어텐션 행렬 때문.

$$
\text{어텐션 행렬}\ A \in \mathbb{R}^{n\times n} \ \Rightarrow\ \text{시간·메모리}\ O(n^2 d)
$$

이를 줄이려는 연구가 많다(Efficient Transformers). 계산 효율적 대안으로 **Mamba**(상태공간 모델) 등이 제시된다.

::: {.callout-tip title="무선통신 관점 비유"}
$O(n^2)$ 어텐션은 **완전 연결 네트워크의 모든 노드 쌍 채널 추정**과 같다. $n$ 이 커지면 파일럿/연산 오버헤드가 제곱으로 폭증한다. Efficient Transformer/희소 어텐션은 **클러스터링·국소화로 의미 있는 링크만 추정**하는 것에 대응한다.
:::

## A. 바닐라 RNN과 고유값에 의한 소실/폭발

```{python}
import numpy as np
np.random.seed(0)

def rnn_state_norms(W, T=40, h0=None):
    n = W.shape[0]
    h = np.ones(n) if h0 is None else h0
    norms = []
    for _ in range(T):
        h = W @ h
        norms.append(np.linalg.norm(h))
    return np.array(norms)

# |lambda| < 1 -> 소실
W_decay = np.array([[0.9, 0.1], [0.0, 0.5]])
print("eig(W_decay) =", np.round(np.linalg.eigvals(W_decay), 3))
nd = rnn_state_norms(W_decay)
print(f"||h|| : {nd[0]:.3f} -> {nd[-1]:.4f}  (소실)")

# |lambda| > 1 -> 폭발
W_explode = np.array([[1.2, 0.0], [0.0, 1.05]])
ne = rnn_state_norms(W_explode)
print(f"||h|| : {ne[0]:.3f} -> {ne[-1]:.1f}  (폭발)")
```

## B. LSTM 셀 forward

```{python}
import numpy as np
np.random.seed(1)
sigmoid = lambda x: 1.0 / (1.0 + np.exp(-x))

def lstm_step(x, h, c, P):
    z = np.concatenate([h, x])
    f = sigmoid(P['Wf'] @ z + P['bf'])   # 망각
    i = sigmoid(P['Wi'] @ z + P['bi'])   # 입력
    o = sigmoid(P['Wo'] @ z + P['bo'])   # 출력
    g = np.tanh (P['Wg'] @ z + P['bg'])  # gate gate
    c = f * c + i * g                    # 셀 상태
    h = o * np.tanh(c)                   # 은닉상태
    return h, c

H, X = 3, 2
mk = lambda a, b: np.random.randn(a, b) * 0.1
P = {k: mk(H, H + X) for k in ['Wf', 'Wi', 'Wo', 'Wg']}
P.update({k: np.zeros(H) for k in ['bf', 'bi', 'bo', 'bg']})

h, c = np.zeros(H), np.zeros(H)
for t in range(5):
    h, c = lstm_step(np.random.randn(X), h, c, P)
print("LSTM h =", np.round(h, 3))
```

## C. GRU 셀 forward + 파라미터 수 비교

```{python}
import numpy as np
np.random.seed(2)
sigmoid = lambda x: 1.0 / (1.0 + np.exp(-x))

def gru_step(x, h, P):
    z_in = np.concatenate([h, x])
    r = sigmoid(P['Wr'] @ z_in + P['br'])         # reset
    u = sigmoid(P['Wu'] @ z_in + P['bu'])         # update
    hh = np.tanh(P['Wh'] @ np.concatenate([r * h, x]) + P['bh'])  # 후보
    return (1 - u) * h + u * hh                   # 갱신

H, X = 3, 2
mk = lambda a, b: np.random.randn(a, b) * 0.1
Pg = {k: mk(H, H + X) for k in ['Wr', 'Wu', 'Wh']}
Pg.update({k: np.zeros(H) for k in ['br', 'bu', 'bh']})

h = np.zeros(H)
for t in range(5):
    h = gru_step(np.random.randn(X), h, Pg)
print("GRU h =", np.round(h, 3))

n_lstm = 4 * (H * (H + X) + H)
n_gru  = 3 * (H * (H + X) + H)
print(f"게이트 가중치 비율 GRU/LSTM = {n_gru / n_lstm:.2f}")  # ~0.75
```

## D. Scaled Dot-Product Attention (+ causal mask)

```{python}
import numpy as np
np.random.seed(3)

def softmax(x, axis=-1):
    x = x - x.max(axis=axis, keepdims=True)
    e = np.exp(x)
    return e / e.sum(axis=axis, keepdims=True)

def attention(Q, K, V, causal=False):
    d_k = Q.shape[-1]
    scores = Q @ K.T / np.sqrt(d_k)
    if causal:
        n = Q.shape[0]
        mask = np.tril(np.ones((n, n), dtype=bool))
        scores = np.where(mask, scores, -1e9)
    A = softmax(scores, axis=-1)
    return A @ V, A

n, d = 4, 8
Q, K, V = (np.random.randn(n, d) for _ in range(3))

out, A = attention(Q, K, V)
print("어텐션 행 합 = 1 :", np.allclose(A.sum(1), 1.0))

out_c, A_c = attention(Q, K, V, causal=True)
print("causal 상삼각 ~ 0 :", np.allclose(np.triu(A_c, 1), 0.0, atol=1e-6))
```

```{python}
import numpy as np

def positional_encoding(L, d):
    pos = np.arange(L)[:, None]
    i = np.arange(d)[None, :]
    angle = pos / np.power(10000.0, (2 * (i // 2)) / d)
    pe = np.zeros((L, d))
    pe[:, 0::2] = np.sin(angle[:, 0::2])
    pe[:, 1::2] = np.cos(angle[:, 1::2])
    return pe

pe = positional_encoding(50, 16)
print("PE shape =", pe.shape, "| 값 범위 =", round(pe.min(), 2), "~", round(pe.max(), 2))
# 서로 다른 위치는 서로 다른 코드를 가짐 (행벡터가 모두 구별됨)
print("위치 0 vs 1 코드가 다른가 :", not np.allclose(pe[0], pe[1]))
```
