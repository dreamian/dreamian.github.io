1 개요

이 노트는 MLP(Multi-Layer Perceptron)에 대한 수학적·구조적 통합 정리이다. 크게 다음 다섯 축으로 구성된다.

2 인공 뉴런과 퍼셉트론 — 용어의 정확한 구분

2.1 계층적 정의

생물학적 뉴런 (영감의 원천)
    ↓ 추상화
인공 뉴런(Artificial Neuron) = 수학적 계산 단위 [일반 개념]
    ↓ 특수화
퍼셉트론(Perceptron) = 활성화 함수가 step function인 뉴런 [특수 사례]

2.2 인공 뉴런 (Artificial Neuron)

입력 벡터를 받아 하나의 스칼라 출력을 내는 계산 단위:

z = \mathbf{w}^\top \mathbf{x} + b, \qquad a = f(z)

  • z: pre-activation (선형 결합)
  • a: activation (활성화 출력)
  • f(\cdot): 활성화 함수 — 이것이 무엇이냐에 따라 뉴런의 종류가 결정됨

2.3 퍼셉트론 (Perceptron)

활성화 함수가 계단 함수(step function) 또는 부호 함수(sign function)인 뉴런:

f(z) = \begin{cases} 1 & z > 0 \\ 0 & z \leq 0 \end{cases}

항목 뉴런(Neuron) 퍼셉트론(Perceptron)
개념 범위 일반 특수
활성화 함수 f 임의 step/sign 고정
출력 연속값 가능 이진값 \{0,1\}
역전파 가능? ✓ (f가 미분 가능할 때) ✗ (불연속)
등장 시기 — Rosenblatt, 1958
Important왜 현대 딥러닝은 “퍼셉트론”이라고 부르지 않는가?

역전파를 위해서는 \partial \mathcal{L}/\partial w를 계산해야 한다. Step function은 거의 모든 곳에서 미분값이 0(또는 불연속)이라 gradient가 흐르지 않는다. 그래서 현대에는 ReLU, sigmoid, tanh 같은 미분 가능한 활성화 함수를 쓰는 뉴런을 사용하고, 이를 쌓은 구조를 MLP 또는 신경망(neural network)이라 부른다. 이름은 퍼셉트론이지만 엄밀히 말하면 MLP의 뉴런들은 퍼셉트론이 아니다 — 역사적 명칭이 굳어진 것이다.

2.4 무선통신 직관

MLP 개념 무선통신 대응
뉴런(가중합) Matched filter
활성화 함수(step) Threshold detector (hard decision)
Sigmoid 뉴런 Soft decision detector

3 단일 퍼셉트론의 한계와 XOR 문제

3.1 Linearly Separable vs Non-Separable

단일 퍼셉트론은 하나의 hyperplane으로 두 클래스를 분리한다. 따라서 AND, OR 같은 linearly separable 문제는 풀 수 있지만, XOR처럼 linearly non-separable 한 문제는 원리적으로 불가능하다.

XOR의 진리표: (0,0)\to 0,\quad (0,1)\to 1,\quad (1,0)\to 1,\quad (1,1)\to 0 2D 평면에서 직선 하나로 두 클래스를 가를 수 없다.

3.2 XOR을 푸는 두 퍼셉트론 — 논리적 분해

XOR은 다음과 같이 논리적으로 분해된다:

y = x_1 \oplus x_2 = (x_1 \wedge \neg x_2) \vee (x_2 \wedge \neg x_1)

이를 임계값 함수로 인코딩:

v_1 = \mathbb{1}[-1.5 + 2x_1 - x_2 > 0] = (x_1 \wedge \neg x_2) v_2 = \mathbb{1}[-1.5 + 2x_2 - x_1 > 0] = (x_2 \wedge \neg x_1) y = \mathbb{1}[-0.5 + v_1 + v_2 > 0] = v_1 \vee v_2

3.3 v_1 = x_1 \wedge \neg x_2의 가중치/편향 설계 검증

x_1 x_2 -1.5 + 2x_1 - x_2 > 0? 기대
0 0 -1.5 ✗ 0 ✓
1 0 +0.5 ✓ 1 ✓
0 1 -2.5 ✗ 0 ✓
1 1 -0.5 ✗ 0 ✓

가중치 설계의 의미를 한 줄씩 읽으면:

  • +2 \cdot x_1: x_1=1일 때 충분히 크게 활성화
  • -1 \cdot x_2: x_2=1이면 negation 역할로 억제
  • 편향 -1.5: threshold를 올려 x_2=1이거나 둘 다 0인 경우를 차단

3.4 “퍼셉트론 두 개를 쌓는다”의 의미

은닉층 \{v_1, v_2\} 추가 = 층(layer)을 직렬로 쌓는다는 뜻이다.

입력층      은닉층        출력층
x₁  ─→  [v₁]
x₂  ─→  [v₂]  ─→  [y]

은닉층은 입력 공간을 비선형 변환해 선형 분리 가능한 공간으로 매핑하는 역할을 한다.

3.5 무선통신 직관

OFDM 수신기에서 단순 matched filter 하나로 multipath 간섭을 완전히 제거하지 못하듯, 단일 퍼셉트론(선형 필터)으로는 XOR 같은 비선형 패턴을 분리할 수 없다. 은닉층 추가 = 등화기(equalizer)를 직렬로 쌓아 비선형 채널을 단계적으로 보상하는 구조와 동일하다.

4 Hidden Layer의 구조적 이해

4.1 함수 합성으로서의 MLP

은닉층 1개를 가진 MLP의 출력은 다음과 같다:

\text{out}(\mathbf{x}) = g\!\Bigl(w_0 + \sum_{k=1}^{K} w_k \cdot \underbrace{g\bigl(w_0^{(k)} + \sum_i w_i^{(k)} x_i\bigr)}_{\text{k번째 은닉 뉴런 출력}}\Bigr)

재귀처럼 보이지만 정확히는 2단 함수 합성이다. 안쪽 g(\cdot)가 먼저 계산되고, 그 결과를 바깥쪽 g(\cdot)가 받는 구조.

4.2 활성화 함수의 개수

위치 개수 역할
은닉층 뉴런 각각 K개 안쪽 g
출력층 뉴런 1개 바깥쪽 g
합계 K+1개

수식에 활성화 함수가 1개처럼 보이지만, 전개하면 총 K+1번 적용된다.

4.3 Loss가 Non-Convex가 되는 이유

단일 뉴런에서:

\text{out}(\mathbf{x}) = g(\mathbf{w}^\top \mathbf{x} + b)

g가 sigmoid 또는 ReLU 같은 convex 함수라면, \mathbf{w}에 대한 loss가 convex일 수 있다. 그러나 은닉층 도입 후:

\mathcal{L}(\mathbf{W}^{(1)}, \mathbf{W}^{(2)}) = \text{Loss}\bigl(\mathbf{W}^{(2)}\, g(\mathbf{W}^{(1)}\mathbf{x})\bigr)

다음 두 가지가 convexity를 깨뜨린다.

원인 1 — 가중치 행렬의 비선형 합성

\mathbf{W}^{(2)}와 g(\mathbf{W}^{(1)}\mathbf{x})의 곱은 일반적으로 convex 보존 안 됨.

원인 2 — 대칭성(Symmetry)에 의한 다수의 동등한 해

은닉층 뉴런의 순서를 바꿔도 같은 함수를 표현한다:

[\mathbf{w}_1, \mathbf{w}_2, \mathbf{w}_3] \;\equiv\; [\mathbf{w}_2, \mathbf{w}_1, \mathbf{w}_3] \;\equiv\; \cdots

은닉층 뉴런이 n개면 n!개의 동등한 해가 존재한다. 이들은 같은 loss 값을 가지며 서로 다른 위치의 극솟값으로 나타난다.

NoteConvergence guarantee — 퍼셉트론 vs MLP

퍼셉트론: \mathcal{L}(\mathbf{w}) = \sum_i \max(0, -y_i \mathbf{w}^\top \mathbf{x}_i) → convex → global minimum 도달 보장 (어디서 시작하든 gradient가 항상 최저점을 향한다.)

MLP: non-convex → local minimum, saddle point, plateau에 갇힐 수 있음. 어디서 시작하느냐에 따라 다른 극솟값에 도달할 수 있다.

흥미롭게도 실제로는 SGD가 놀라울 정도로 잘 작동한다. 이는 (i) 고차원에서는 saddle point가 local minimum보다 훨씬 흔하고, (ii) 좋은 초기화와 momentum 기법이 saddle을 빠져나오게 도와주며, (iii) over-parameterized 영역에서는 거의 모든 local minimum이 비슷한 generalization 성능을 갖기 때문이다.

4.4 8-3-8 Autoencoder의 시사점

8차원 one-hot 입력 → 3개 hidden unit → 8차원 복원하는 네트워크가 2^3 = 8가지 패턴을 자동으로 인코딩한다. 이는 무선통신의 CSI feedback compression과 본질적으로 같다 — 고차원 채널 정보를 저차원 latent space로 압축한 뒤 복원하는 것. 실제 CsiNet, CRNet 같은 모델이 이 원리에 직접 기반한다.

5 Universal Approximation Theorem과 그 실용적 한계

5.1 정리 (Cybenko 1989, Hornik 1991)

단일 hidden layer를 가진 feed-forward 네트워크가 충분한 수의 뉴런을 가질 때, \mathbb{R}^n의 compact subset 위에서 임의의 연속 함수를 원하는 정밀도로 근사할 수 있다.

활성화 함수 g에 대해 mild한 조건이 필요하다 (non-constant, bounded, monotonically-increasing continuous 등).

5.2 두 가지 함정

함정 1 — “충분한 뉴런”이 얼마나 필요한지 모른다.

어떤 함수는 single hidden layer로 근사하려면 뉴런이 지수적으로 많이 필요할 수 있다. 반면 deep network로는 polynomial 수의 뉴런으로 충분할 수 있다. 이것이 depth의 가치이다.

Montufar et al. (2014)의 결과: k개의 hidden layer, 각 n개의 ReLU unit을 가진 네트워크는 최대

\left(\frac{n}{d}\right)^{(k-1)d} \cdot \binom{n}{d}

개의 linear region을 표현할 수 있다 (d = 입력 차원). 깊이가 1 증가할 때마다 표현 가능한 영역이 지수적으로 늘어난다.

함정 2 — 찾을 수 있다는 보장이 없다.

그런 weight가 “존재한다”는 것과, gradient descent로 “찾을 수 있다”는 것은 다른 문제다. Non-convex optimization이므로 global optimum 도달은 보장되지 않는다.

TipShannon의 정리와의 닮은꼴

UAT는 Shannon의 채널 부호화 정리와 유사하다 — “이론적 채널 용량에 도달하는 코드가 존재한다”는 것. 존재성은 보장하지만, 실제로 그런 코드를 설계하고 디코딩하는 방법은 별개의 문제다.

Random codebook이 capacity를 달성한다는 사실과, 실용적 LDPC/Turbo 부호의 발견 사이에는 50년의 간극이 있었다. 딥러닝에서도 표현 가능성(expressibility)과 학습 가능성(learnability) 사이에 실용적 간극이 존재한다.

5.3 표현 가능성 ≠ 학습 가능성 ≠ 일반화 가능성

세 개념을 분리해 이해해야 한다.

개념 의미 책임
Expressibility 그런 함수가 표현될 수 있는가? UAT가 답
Learnability gradient descent로 찾을 수 있는가? 최적화 이론
Generalizability 학습된 함수가 새 데이터에 통하는가? 통계적 학습 이론

깊은 네트워크가 강력한 이유는 이 세 가지를 동시에 만족시키기 때문이다.

6 Forward Propagation과 Backpropagation

6.1 Forward Propagation — Inference

각 층 l의 k번째 뉴런:

V_k^{(l)} = g\!\left(\sum_i w_{ki}^{(l)} U_i^{(l-1)} + b_k^{(l)}\right)

여기서 U_i^{(l-1)}는 이전 층 출력이다. 입력 → 출력 방향으로 순차적으로 계산.

6.2 Backpropagation — Learning

6.2.1 핵심 아이디어

학습 목표는 loss J를 최소화하는 weight를 찾는 것. 모든 weight에 대한 gradient \partial J/\partial w가 필요한데, 이를 한 번에 계산할 수 없다. 대신 chain rule로 layer별 gradient를 곱해나간다:

\frac{\partial z}{\partial x} = \frac{\partial z}{\partial y} \cdot \frac{\partial y}{\partial x}

6.2.2 Computational Graph 예제

f(x, y, z) = (x+y)\cdot z, with x=-2, y=5, z=-4.

Forward pass: q = x + y = 3, \quad f = q \cdot z = -12

Backward pass:

Step 1: \partial f / \partial f = 1

Step 2 (곱셈 노드): \frac{\partial f}{\partial q} = z = -4, \qquad \frac{\partial f}{\partial z} = q = 3

Step 3 (덧셈 노드): \frac{\partial q}{\partial x} = 1, \qquad \frac{\partial q}{\partial y} = 1

Step 4 (chain rule 적용): \frac{\partial f}{\partial x} = -4 \cdot 1 = -4, \qquad \frac{\partial f}{\partial y} = -4 \cdot 1 = -4, \qquad \frac{\partial f}{\partial z} = 3

노드별 gradient flow의 직관:

  • 덧셈 게이트는 upstream gradient를 그대로 분배(distribute)
  • 곱셈 게이트는 상대방의 값을 교환(swap) 후 곱함

6.2.3 왜 효율적인가? — Dynamic Programming의 원리

만약 chain rule을 “전개(expand)”해서 계산하면 같은 중간 결과를 여러 번 다시 계산하게 된다. 이는 계산량을 지수적으로 폭발시킨다. Backpropagation은 forward pass에서 계산한 값을 저장해두고 backward pass에서 재사용한다 — 정확히 dynamic programming의 원리다.

Forward:   x=-2, y=5  →  q=3  →  f=-12
                          ↑ 저장      ↑ 저장
Backward:  ∂f/∂f=1  →  ∂f/∂q=z=-4  →  ∂f/∂x = ∂f/∂q · ∂q/∂x = -4
                                          ∂f/∂y = ∂f/∂q · ∂q/∂y = -4
                          ∂f/∂z=q=3

6.2.4 실제 MLP의 Computational Graph

실제 학습에서는 cross-entropy loss + weight decay를 포함한 전체 그래프를 구성한다:

J = J_\text{MLE} + \lambda\bigl(\|\mathbf{W}^{(1)}\|_F^2 + \|\mathbf{W}^{(2)}\|_F^2\bigr)

왼쪽 경로 — Forward Pass (예측 계산):

\mathbf{X}, \mathbf{W}^{(1)} \xrightarrow{\text{matmul}} \mathbf{U}^{(1)} \xrightarrow{\text{ReLU}} \mathbf{H} \xrightarrow{\text{matmul} \mathbf{W}^{(2)}} \mathbf{U}^{(2)} \xrightarrow{\text{CE}} J_\text{MLE}

오른쪽 경로 — Weight Decay (정규화 계산):

\mathbf{W}^{(1)} \xrightarrow{\text{sqr}} \mathbf{U}^{(3)} \xrightarrow{\text{sum}} u^{(4)} = \|\mathbf{W}^{(1)}\|_F^2 \mathbf{W}^{(2)} \xrightarrow{\text{sqr}} \mathbf{U}^{(5)} \xrightarrow{\text{sum}} u^{(6)} = \|\mathbf{W}^{(2)}\|_F^2

합산 후 스케일링: u^{(8)} = \lambda(u^{(4)} + u^{(6)}).

각 노드는 자신에게 들어온 upstream gradient를 받아 local gradient와 곱해 내려보낸다. PyTorch의 .backward()가 하는 일이 정확히 이것이다.

Tip무선통신 직관 — Signal Flow Graph

이 computational graph는 신호 흐름도(signal flow graph)와 동일한 구조다. Forward pass = 신호 전파, Backward pass = 오차 역전파. 적응 등화기(adaptive equalizer)에서 LMS 알고리즘이 error signal을 필터 weight 방향으로 역전파하는 것과 같은 원리다.

6.3 Symbolic vs Numeric vs Automatic Differentiation

세 가지 미분 방식의 비교:

방식 입력 출력 장점 단점
Symbolic 수식 수식 닫힌 형태 도함수 Expression swell (지수적 증가)
Numeric 수식 + 점 수치값 구현 단순 N개 parameter에 대해 N번 forward pass 필요, 오차
Automatic (AD) 수식 + 점 수치값 (정확) 효율적, 정확 구현 복잡

Numeric differentiation은 gradient checking (backprop 구현 검증)에 유용하다:

\frac{\partial f}{\partial x_i} \approx \frac{f(\ldots, x_i + h, \ldots) - f(\ldots, x_i - h, \ldots)}{2h}

AD는 reverse-mode를 사용하여 scalar output에 대한 vector input의 gradient를 한 번의 forward + backward pass로 계산한다. 이것이 PyTorch, JAX의 핵심.

7 Cross Entropy와 KL Divergence

7.1 정의

Shannon Entropy: \quad H(p) = -\sum_x p(x) \log p(x)

Cross Entropy: \quad H(p, q) = -\sum_x p(x) \log q(x)

KL Divergence: \quad D_{KL}(p \| q) = \sum_x p(x) \log \dfrac{p(x)}{q(x)}

7.2 핵심 분해 공식 — 수학적 유도

KL divergence를 전개:

D_{KL}(p \| q) = \sum_x p(x) \bigl[\log p(x) - \log q(x)\bigr] = \sum_x p(x) \log p(x) - \sum_x p(x) \log q(x) = -H(p) + H(p, q)

따라서:

\boxed{H(p,q) = H(p) + D_{KL}(p \| q)}

7.3 의미적 분해

\underbrace{H(p,q)}_{\text{Cross-Entropy}} = \underbrace{H(p)}_{\text{어쩔 수 없는 불확실성}} + \underbrace{D_{KL}(p \| q)}_{\text{모델의 무지함}}

항 의미 제어 가능?
H(p) 실제 분포 자체의 본질적 불확실성 ❌ (데이터에 의해 고정)
D_{KL}(p\|q) q가 p로부터 얼마나 벗어났는가 ✅ (학습으로 감소)
H(p,q) 둘의 합 ✅ (간접적으로 감소)

핵심 부등식:

H(p,q) \geq H(p), \quad \text{등호 } \iff q = p

7.4 정보이론적 해석 — 코딩 비용

기호 의미
H(p) 실제 분포 p를 알 때 최적 코드의 평균 길이 (Shannon source coding)
H(p,q) 틀린 분포 q로 설계한 코드를 실제 p에 적용할 때 평균 길이
D_{KL}(p\|q) 잘못된 모델로 인한 여분의 비트 수

\underbrace{H(p,q)}_{\text{실제 전송 비용}} = \underbrace{H(p)}_{\text{최소 이론 비용}} + \underbrace{D_{KL}(p\|q)}_{\text{모델 오류 낭비}}

7.5 분류 문제에서 H(p) = 0의 의미

분류 문제에서 정답 레이블은 one-hot vector다:

p = [0, \ldots, 1, \ldots, 0]

Shannon entropy 계산: H(p) = -\sum_k p(k)\log p(k) = -(1\cdot\log 1 + 0\cdot\log 0 + \cdots) = 0 (여기서 0 \log 0 \overset{\text{정의}}{=} \lim_{x\to 0} x\log x = 0.)

이것은 “정답이 확정적이라 본질적 불확실성이 없다”는 뜻이며, 분해 공식에 대입하면:

H(p, q) = D_{KL}(p \| q) = -\log q(y^*)

정답 클래스 y^*의 log-probability 하나만 남는다.

7.6 MLE = CE 최소화 = KL 최소화

데이터셋 \mathcal{D} = \{x^{(1)}, \ldots, x^{(N)}\}이 실제 분포 p_\text{data}에서 i.i.d. 샘플링되었다고 하자.

MLE 목적함수:

\theta^*_\text{MLE} = \arg\max_\theta \sum_{i=1}^N \log q_\theta(x^{(i)})

N으로 나눈 후 대수의 법칙 적용 (N \to \infty):

\frac{1}{N}\sum_{i=1}^N \log q_\theta(x^{(i)}) \xrightarrow{} \mathbb{E}_{x \sim p_\text{data}}\bigl[\log q_\theta(x)\bigr] = -H(p_\text{data}, q_\theta)

따라서:

\theta^*_\text{MLE} = \arg\min_\theta H(p_\text{data}, q_\theta)

분해 공식을 적용하면:

\arg\min_\theta H(p_\text{data}, q_\theta) = \arg\min_\theta \bigl[\underbrace{H(p_\text{data})}_{\theta\text{와 무관}} + D_{KL}(p_\text{data} \| q_\theta)\bigr] = \arg\min_\theta D_{KL}(p_\text{data} \| q_\theta)

전체 등가 관계:

\boxed{\underbrace{\max_\theta \sum_i \log q_\theta(x^{(i)})}_{\text{MLE}} \;\equiv\; \underbrace{\min_\theta H(p_\text{data}, q_\theta)}_{\text{CE 최소화}} \;\equiv\; \underbrace{\min_\theta D_{KL}(p_\text{data} \| q_\theta)}_{\text{KL 최소화}}}

7.7 왜 D_{KL}(p \| q)이지 D_{KL}(q \| p)가 아닌가?

D_{KL}(p\|q) = \sum_x p(x) \log \frac{p(x)}{q(x)}

p가 ground truth, q가 모델이므로 기댓값은 p 아래에서 취한다. 이는 p(x) > 0인 곳에서 q(x)도 충분히 커야 함을 강제한다 — 즉 정답 클래스에 높은 확률을 부여하도록 강제하는 것.

방향 행동 양식 직관
D_{KL}(p\|q) (Forward) mode-covering / zero-avoiding 정답을 놓치지 않으려 함
D_{KL}(q\|p) (Reverse) mode-seeking / zero-forcing 한 모드에 집중

D_{KL}(q\|p)는 p(x)=0인 오답 클래스에서 q(x)=0이 되도록 강제하지만, 정답 확률을 직접적으로 높이지는 않는다. 이 차이가 generative model에서도 중요한 선택지가 된다 (VAE는 reverse KL).

7.8 CE vs MSE의 Gradient — 왜 분류에 CE를 쓰는가

7.8.1 MSE의 경우 (sigmoid 출력 + MSE loss)

\text{MSE} = \tfrac{1}{2}(y - \sigma(z))^2, \qquad \frac{\partial \text{MSE}}{\partial w} = (\sigma(z) - y) \cdot \sigma'(z) \cdot x

\sigma'(z) 항이 곱해진다. Sigmoid가 saturation 영역에 들어가면 \sigma'(z) \to 0이 되어 예측이 틀려도 gradient가 사라진다. 이것이 sigmoid + MSE의 학습 정체 문제.

7.8.2 CE의 경우

\text{CE} = -\bigl[y\log\sigma(z) + (1-y)\log(1-\sigma(z))\bigr]

체인 룰을 적용하면:

\frac{\partial \text{CE}}{\partial z} = -\frac{y}{\sigma(z)}\sigma'(z) + \frac{1-y}{1-\sigma(z)}\sigma'(z)

\sigma'(z) = \sigma(z)(1-\sigma(z))를 대입:

= -y(1-\sigma(z)) + (1-y)\sigma(z) = \sigma(z) - y

따라서:

\boxed{\frac{\partial \text{CE}}{\partial w} = (\sigma(z) - y) \cdot x}

\sigma'(z) 항이 완전히 소거된다. 예측이 틀릴수록 gradient가 크게 유지되어 빠른 학습이 가능.

ImportantCE의 두 가지 정당성
  1. 수치적 정당성: \sigma' 소거로 vanishing gradient 회피
  2. 통계적 정당성: Bernoulli/Multinoulli 분포에 대한 MLE와 동치 — 확률 모델 관점에서 “올바른” loss

7.9 Softmax + CE Gradient 유도

Softmax 출력: q_i = \dfrac{e^{z_i}}{\sum_j e^{z_j}}, Cross entropy: L = -\sum_i p_i \log q_i.

z_i에 대한 gradient:

\frac{\partial L}{\partial z_i} = q_i - p_i

  • 정답 클래스 k: \partial L/\partial z_k = q_k - 1 (예측이 1에 가까울수록 → 0)
  • 오답 클래스 i \neq k: \partial L/\partial z_i = q_i (예측이 0에 가까울수록 → 0)

이 단순한 형태의 의미:

  • 계산 효율성: 복잡한 log·exp 미분 없이 뺄셈 한 번
  • 수치 안정성: log와 exp가 상쇄되어 saturation 문제가 해결됨
  • 직관적 해석: “틀린 만큼 업데이트한다”

7.10 무선통신 직관

정보이론 무선통신 대응
p_\text{data} 실제 채널 분포 (불가지)
q_\theta 채널 모델 (AWGN, Rayleigh 가정)
H(p) Shannon capacity의 본질적 한계
D_{KL}(p\|q) 잘못된 채널 가정으로 인한 용량 손실
MLE 수신 신호로부터 채널 파라미터 추정

LMS adaptive filter의 weight update \mathbf{w} \leftarrow \mathbf{w} + \mu \cdot e(n) \cdot \mathbf{x}(n)에서 error signal e(n) = (\text{desired} - \text{predicted})인 것이 softmax + CE gradient (q - p)와 정확히 같은 구조다.

또한 MLD(Maximum Likelihood Detection)에서 수신 신호 r을 보고 \arg\max_s P(r|s)를 찾는 것 = CE loss 최소화와 본질적으로 동일하다.

8 Output Units — 출력층의 설계

신경망의 출력층은 풀려는 문제의 확률 분포에 맞게 설계해야 한다.

8.1 Linear Units

\hat{y} = \mathbf{W}^\top \mathbf{h} + \mathbf{b}

Gaussian 출력 분포를 가정: p(y|x) = \mathcal{N}(y; \hat{y}, \mathbf{I}). 회귀 문제에 적합. 이때 negative log-likelihood가 정확히 MSE가 된다 (상수 항 무시).

8.2 Sigmoid Units

\hat{y} = \sigma(\mathbf{w}^\top \mathbf{h} + b), \quad z = \mathbf{w}^\top \mathbf{h} + b \text{ (logit)}

Bernoulli 출력 분포를 가정. 이진 분류에 사용. z를 logit이라 부르며, 이는 log-odds \log[p/(1-p)]의 의미를 갖는다.

여러 sigmoid 출력을 동시에 사용하면 multi-label classification (각 라벨이 독립적). 확률 합이 1로 정규화되지 않으므로 un-normalized distribution.

8.3 Softmax Units

\text{softmax}(\mathbf{z})_i = \frac{e^{z_i}}{\sum_j e^{z_j}}

Multinoulli (categorical) 분포의 출력. 다중 클래스 분류의 표준.

8.3.1 Softmax는 단순 정규화가 아니다

[10, 20]을 비교하면:

  • L1 정규화: \bigl[\tfrac{10}{30}, \tfrac{20}{30}\bigr] = [0.33, 0.67]
  • Softmax: \bigl[e^{10}/(e^{10}+e^{20}),\ e^{20}/(e^{10}+e^{20})\bigr] \approx [0.00005, 0.99995]

차이의 절댓값이 클수록 최댓값 쪽으로 극적으로 편중된다. 이는 MIMO beam selection에서 SNR 차이가 클수록 최적 빔 선택 확률이 1에 수렴하는 것과 같다.

8.3.2 Numerical Stability — Log-Sum-Exp Trick

z_i가 크면 e^{z_i}가 overflow를 일으킨다. 그래서:

\text{softmax}(\mathbf{z})_i = \frac{e^{z_i - \max_j z_j}}{\sum_k e^{z_k - \max_j z_j}}

모든 z_i에서 \max z_j를 빼도 결과는 동일하다 (분자/분모 약분). 이를 통해 지수가 음수가 되어 overflow 방지.

8.4 Gumbel-Softmax — 미분 가능한 샘플링

Categorical 분포에서 샘플링하려면 argmax를 취해야 하는데, argmax는 미분 불가능하므로 backprop이 불가능하다.

Gumbel-Softmax로 해결:

y_i = \frac{\exp\bigl((z_i + g_i)/\tau\bigr)}{\sum_{j=1}^k \exp\bigl((z_j + g_j)/\tau\bigr)}

g_i는 Gumbel noise (PDF: f(x) = e^{-(x + e^{-x})}).

Gumbel-Max trick: \arg\max_i (z_i + g_i)가 정확히 softmax 분포에서의 샘플링과 동일. Gumbel-Softmax는 이 argmax를 softmax로 연속 완화한다.

온도 \tau 행동
\tau \to 0 one-hot에 가까움 (hard)
\tau \to \infty uniform에 가까움 (soft)

VAE의 reparameterization trick과 같은 철학 — 이산 선택을 미분 가능하게 만들기.

9 Activation Functions

9.1 Sigmoid

\sigma(z) = \frac{1}{1 + e^{-z}}, \qquad \sigma'(z) = \sigma(z)(1 - \sigma(z))

성질 값
출력 범위 (0, 1)
미분 최댓값 0.25 (at z = 0)
Zero-centered ❌

문제: 양 끝에서 saturation → gradient → 0.

9.2 Hyperbolic Tangent (Tanh)

\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}} = 2\sigma(2z) - 1

미분:

\frac{d}{dz}\tanh(z) = 1 - \tanh^2(z), \qquad \max = 1 \text{ (at } z = 0\text{)}

성질 값
출력 범위 (-1, 1)
미분 최댓값 1.0
Zero-centered ✅

9.2.1 Sigmoid 대비 장점: Zero-centered가 왜 중요한가

Sigmoid 출력은 항상 양수이므로, 가중치 gradient가 모두 같은 부호가 된다:

\frac{\partial \mathcal{L}}{\partial w_i^{(l)}} = \frac{\partial \mathcal{L}}{\partial a^{(l)}} \cdot \underbrace{x_i^{(l-1)}}_{>0 \text{ 항상 (sigmoid)}}

→ 가중치 업데이트가 지그재그 방향으로만 가능. tanh는 출력이 양/음 모두 가능 → gradient 방향이 자유.

이는 무선통신의 BPSK 변조 (양극성 \{-1, +1\}) vs unipolar 신호 (0, 1)의 차이와 같다. 양극성이 DC 성분 없어 전력 효율 높듯, tanh도 zero-centered로 gradient 흐름이 균형 잡힌다.

9.3 ReLU (Rectified Linear Unit)

\text{ReLU}(z) = \max(0, z), \qquad \text{ReLU}'(z) = \begin{cases} 1 & z > 0 \\ 0 & z \leq 0 \end{cases}

전자공학의 반파 정류기(half-wave rectifier)에서 차용한 용어.

9.3.1 ReLU의 4가지 이점

1. Vanishing Gradient 해결. 양수 구간에서 gradient = 1. 깊은 네트워크에서 모든 뉴런이 활성화된 경우:

\prod_{l=1}^L \text{ReLU}'(z^{(l)}) = 1

Sigmoid는 \leq 0.25^L로 감쇠. 10층이면 0.25^{10} \approx 9.5\times 10^{-7}.

2. 계산 효율. Sigmoid/tanh는 e^x 계산 필요. ReLU는 단순 비교 한 번. GPU에서 큰 차이.

3. Sparse Activation (희소 활성화). 음수 입력을 받은 뉴런은 출력이 정확히 0. 평균적으로 절반의 뉴런이 비활성화. 각 입력마다 다른 “서브네트워크”가 활성화되는 효과 — 뇌의 sparse coding과 닮음.

4. Catastrophic forgetting 완화. 음수 입력에 대해 뉴런을 완전히 비활성화하므로, 특정 task 관련 뉴런만 활성화되고 나머지는 보존되는 효과.

9.3.2 ReLU의 단점: Dying ReLU

w가 매우 음수가 되면 z = w^\top x + b \ll 0이 되어 ReLU 출력이 항상 0. 이 뉴런은 gradient도 0이라 영원히 업데이트 안 됨.

9.4 ReLU 계열의 통합 공식

ReLU 패밀리는 하나의 공식으로 표현된다:

h_i = \max(0, z_i) + \alpha_i \min(0, z_i)

\alpha_i 함수 이름 특성
0 ReLU 음수 영역 완전 차단
-1 Absolute value (h = \|z\|) 대칭 출력
0.01 Leaky ReLU 음수 영역에 작은 gradient
학습됨 Parametric ReLU (PReLU) \alpha를 데이터로부터 학습

9.4.1 Absolute Value Rectifier — 종이 접기 비유

|z|는 음수를 양수로 접어서 출력. 대칭축을 기준으로 왼쪽과 오른쪽이 동일한 출력 \Rightarrow 공간을 물리적으로 반으로 접는 효과.

| z | (접기):              ReLU (자르기):
       /\                       /
      /  \                     /
     /    \                   /
    /      \              ───/

레이어를 쌓을수록 접는 횟수가 늘고, 패턴이 지수적으로 반복된다 → 같은 파라미터로 표현 가능한 영역이 지수적으로 늘어남 (Montufar 정리의 직관).

9.5 활성화 함수 비교

성질 Sigmoid tanh ReLU
출력 범위 (0, 1) (-1, 1) [0, \infty)
Zero-centered ❌ ✅ ❌
최대 gradient 0.25 1.0 1

9.5.1 RNN/LSTM에서 tanh가 살아남는 이유

ReLU는 unbounded 출력 (0, \infty)이라 RNN에서 exploding gradient 위험. tanh는 |\tanh(x)| \leq 1 항상 → 시퀀스가 길어져도 값이 폭발하지 않는다. LSTM의 cell state·hidden state가 tanh를 쓰는 이유.

9.6 Vanishing Gradient — 무선 신호와의 비유

Sigmoid 미분 ≤ 0.25 → 10층이면 gradient \sim 10^{-6}. 이는 통신의 path loss와 유사하다 — 신호가 여러 relay를 거칠 때마다 감쇠. ReLU는 이상적인 증폭기(amplifier)처럼 양의 신호를 감쇠 없이 전달한다.

10 Regularization — 9가지 기법

10.1 일반 형식

Hard constraint: \min_\theta \frac{1}{n}\sum_{i=1}^n l(\theta, x_i, y_i) \quad \text{s.t.} \quad R(\theta) \leq c

Lagrangian으로 변환 → soft constraint: \min_\theta \frac{1}{n}\sum_{i=1}^n l(\theta, x_i, y_i) + \lambda^* R(\theta)

KKT 조건에 의해 적절한 \lambda^*가 존재할 때 두 문제의 해가 일치한다.

10.2 L2 Regularization의 Bayesian 해석

L2 penalty (weight decay): \min_\theta \frac{1}{n}\sum_{i=1}^n l(\theta, x_i, y_i) + \lambda \|\theta\|_2^2

이는 Gaussian prior p(\theta) = \mathcal{N}(0, \sigma^2 \mathbf{I})에 대한 MAP 추정과 동치다.

10.2.1 수학적 유도

MAP 추정: \max_\theta \log p(\theta|\text{data}) = \max_\theta \underbrace{\log p(\text{data}|\theta)}_{\text{likelihood}} + \underbrace{\log p(\theta)}_{\text{prior}}

Gaussian prior: \log \mathcal{N}(\theta; 0, \sigma^2 \mathbf{I}) = -\frac{1}{2\sigma^2}\|\theta\|_2^2 + \text{const}

Maximization을 minimization으로 바꾸면: \min_\theta -\log p(\text{data}|\theta) + \frac{1}{2\sigma^2}\|\theta\|_2^2

\lambda = \frac{1}{2\sigma^2}로 놓으면 weight decay와 정확히 일치. \sigma가 작을수록 (prior가 0에 집중) \lambda가 크다 → 강한 regularization.

10.2.2 “L2는 weight가 0 근처일 것이라는 믿음”인가?

그렇다. 그리고 그 가정이 합리적인 이유:

1. Occam’s Razor. Weight가 크면 입력의 작은 변화에도 출력이 크게 변한다 → 함수가 거칠어짐. 작은 weight = 매끄러운 함수.

2. MMSE 채널 추정과의 동치. 채널의 사전 통계 (correlation matrix, power delay profile)을 활용하는 MMSE estimator가 LS estimator보다 적은 pilot으로 좋은 성능을 내는 이유와 같다.

3. 데이터-사전지식의 균형. MAP 분해를 보면: \min_\theta \frac{1}{n}\sum_i l(\theta, x_i, y_i) + \frac{1}{2\sigma^2}\|\theta\|_2^2

데이터량 n 지배 항 결과
큼 likelihood MLE에 수렴 (prior 무시)
작음 prior regularizer가 결정

데이터가 늘어나면 MAP → MLE로 수렴한다는 일반 성질의 정량화.

10.2.3 L1 vs L2

Regularizer 대응 prior 효과
\|\theta\|_1 Laplace prior Sparsity (정확히 0인 weight)
\|\theta\|_2^2 Gaussian prior Shrinkage (작지만 0이 아닌 weight)
\|\theta\|_0 \log p \propto \mathbb{1}[\theta_i \neq 0] Sparsity 강제 (combinatorial, NP-hard)

L1은 L0의 convex relaxation. 무선통신의 compressed sensing에서 sparse 채널 추정에 직접 사용되는 원리.

10.3 9가지 Regularization 기법

10.3.1 1. Dataset Augmentation

원본 데이터에 변환을 적용해 training set을 인위적으로 확장:

  • Affine distortion (회전, 스케일링, shear)
  • Noise injection
  • Elastic deformation
  • Horizontal flip
  • Random translation
  • Hue shift

이는 모델에 “이 변환들에 invariant해야 한다”는 inductive bias를 주입하는 셈.

10.3.2 2. Adversarial Examples & Adversarial Training

Adversarial example은 사람이 인지 못하는 미세한 perturbation으로 모델이 완전히 다른 예측을 하게 만드는 입력:

x_\text{adv} = x + \epsilon \cdot \text{sign}(\nabla_x J(\theta, x, y))

FGSM (Fast Gradient Sign Method). 1차 테일러 전개로 정당화: J(x + \delta) \approx J(x) + \delta^\top \nabla_x J

\|\delta\|_\infty \leq \epsilon 제약 하에 이를 최대화하는 \delta^* = \epsilon \cdot \text{sign}(\nabla_x J).

유명한 예: panda 이미지에 \epsilon = 0.007 노이즈 → 모델은 99.3% 신뢰도로 gibbon 분류.

Adversarial Training: \min_\theta \mathbb{E}\!\left[\max_{\|\delta\| \leq \epsilon} J(\theta, x+\delta, y)\right]

모델이 입력 근방에서 robust한 표현을 학습하게 만든다. 주목적은 보안이지만 부수적으로 generic regularization 효과.

Tip무선통신 직관

Adversarial perturbation은 재밍(jamming) 신호와 유사하다 — gradient 기반 최적화로 수신 SNR을 최소화하는 방향으로 간섭 주입. FGSM도 모델 loss를 최대화하는 방향으로 노이즈 주입.

10.3.3 3. Label Smoothing

Hard one-hot label을 부드럽게: y_k^\text{smooth} = (1-\epsilon) y_k + \frac{\epsilon}{K}

모델이 정답에 대해 100% 확신하지 않도록 함 → over-confidence 방지, calibration 개선.

10.3.4 4. Semi-Supervised Learning

Labeled data와 unlabeled data를 함께 사용. 공통 representation을 학습해 unlabeled data의 구조를 활용 → 사실상 데이터 분포에 대한 prior로 작동.

10.3.5 5. Multi-Task Learning

여러 task를 공유 representation으로 동시에 학습.

이전 task A와 새 task B의 파라미터 차이에 penalty: \mathcal{L}_B = \mathcal{L}_\text{task\_B} + \lambda \|\mathbf{B} - \mathbf{A}\|_F^2

이는 L2의 일반화다 — 일반 L2가 \|w - 0\|_2^2로 0에 가깝게 했다면, 여기서는 A에 가깝게.

TipMIMO 채널 추정과의 비유

이전 시간 슬롯 채널 \hat{\mathbf{H}}_{t-1}을 prior로 현재 채널 \mathbf{H}_t 추정: \min_{\mathbf{H}_t} \|\mathbf{y} - \mathbf{H}_t \mathbf{x}\|^2 + \lambda \|\mathbf{H}_t - \hat{\mathbf{H}}_{t-1}\|_F^2

“채널이 급격히 변하지 않는다”는 prior를 regularization으로 표현 — 정확히 같은 구조.

10.3.6 6. Early Stopping

Training error는 계속 줄지만 validation error가 다시 늘기 시작하는 시점에서 학습 중단.

이는 implicit regularization으로 작용 — 적절히 일찍 멈추면 weight가 너무 커지기 전에 멈추므로 L2와 비슷한 효과.

10.3.7 7. Parameter Sharing / Tying

동일한 weight를 여러 위치에서 공유 (CNN의 convolution이 대표). 파라미터 수를 줄이고, 자연스러운 invariance (translation invariance) 도입.

10.3.8 8. Bagging (Bootstrap Aggregating)

여러 모델을 다른 데이터 샘플(bootstrap)로 학습 후 예측 평균. Variance를 줄여 generalization 향상. Random Forest의 핵심 원리.

10.3.9 9. Dropout

Training 시 각 뉴런을 확률 p로 랜덤 비활성화: \tilde{h}_i = m_i \cdot h_i, \qquad m_i \sim \text{Bernoulli}(1-p)

Inference 시에는 모든 뉴런을 사용하되 출력에 (1-p) 곱.

이는 앙상블 학습의 근사로 해석 가능 — 2^n개 sub-network의 평균을 single forward pass로 근사. 또한 뉴런 간 co-adaptation 방지.

12 핵심 정리

12.1 표현 가능성과 학습 가능성의 분리

UAT는 표현 가능성을 보장한다. 깊이는 학습 가능성과 일반화에 결정적이다. 세 개념을 분리해 사고할 것.

12.2 두 가지 핵심 등가 관계

  1. \;MLE = CE 최소화 = KL Divergence 최소화 (분류 모델 학습의 통일된 관점)
  2. \;L2 regularization = Weight decay = Gaussian prior에 대한 MAP (정규화의 통계적 정당화)

12.3 학습 메커니즘의 4단 구조

  1. Forward pass — 예측 계산
  2. Loss 평가 — 예측과 정답의 거리
  3. Backward pass — chain rule로 gradient 전파
  4. Weight update — gradient descent의 변형

12.4 활성화 함수의 진화

  • Step → 미분 불가
  • Sigmoid → vanishing gradient
  • Tanh → zero-centered, 여전히 vanishing
  • ReLU → vanishing 해결, dying 문제
  • ReLU 패밀리 (Leaky, PReLU) → dying 완화

12.5 Regularization의 통일적 관점

기법 통합 해석
L2 / L1 Bayesian prior
Data augmentation Invariance prior
Multi-task 공유 표현 prior
Early stopping Implicit regularization
Dropout Ensemble averaging
Adversarial training Robustness in input neighborhood

서로 다른 기법이지만, 모두 모델 복잡도를 효과적으로 제한하거나 데이터 분포에 대한 사전 정보를 주입하는 동일한 목표를 갖는다.
