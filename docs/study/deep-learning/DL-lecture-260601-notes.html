1 한눈에 보는 전체 그림

힌트핵심 한 줄 요약

강화학습(RL)은 MDP라는 수학적 골격 위에서, 보상의 기대 누적값을 최대화하는 정책 \(\pi\) 를 찾는 문제다. 정책을 직접 \(\theta\) 로 매개변수화하면 정책 경사 정리가 학습의 기본 방정식이 되고, 여기서 분산을 줄이고(baseline·advantage·actor-critic) 갱신 폭을 통제하는(TRPO·PPO·GRPO) 방향으로 알고리즘이 발전한다.

오늘 다루는 알고리즘들은 모두 하나의 계보 위에 있다. 출발점은 정책 경사를 그대로 쓰는 REINFORCE이고, 그것의 분산을 줄이려고 Actor-Critic이 나오며, 갱신이 너무 커서 학습이 불안정해지는 문제를 신뢰 영역으로 묶는 TRPO가 등장하고, 그 복잡한 2차 최적화를 단순한 클리핑으로 근사한 것이 PPO, 그리고 PPO에서 critic(가치망)을 통째로 들어내고 advantage를 그룹 통계로 대체한 것이 GRPO다.

노트무선통신 전공자를 위한 진입점

RL의 핵심 수식들은 신호처리에서 익숙한 도구들과 정확히 같은 모양을 한다. 할인 누적 보상은 망각 인자(forgetting factor)를 가진 IIR 누적, 벨만 재귀는 재귀 필터(RLS) 갱신, baseline 차감은 DC 제거 / 제어 변량(control variate), GRPO의 정규화는 CFAR/AGC 정규화, TRPO·PPO의 갱신 제약은 NLMS의 정규화된 스텝 크기 제어에 대응한다. 각 절 끝의 무선통신 대응 박스에서 짝을 맞춰 둔다.

2 강화학습의 4요소와 문제 정의

2.1 직접 답: RL이 푸는 것

RL은 환경과 상호작용하며 수치 보상 신호를 받는 에이전트가, 미래 보상의 기대 누적을 최대화하도록 행동 선택 규칙(정책) 을 학습하는 문제다.

2.2 네 가지 구성요소

요소 기호 정의 역할
정책(Policy) \(\pi(a\mid s)\) 상태에서 행동으로의 매핑(확률) 에이전트의 행동 자체를 정의
보상(Reward) \(r\) 매 시점 환경이 주는 단일 숫자 최대화 대상이 되는 신호
가치함수(Value) \(v_\pi, q_\pi\) 미래 보상의 기대 누적 어떤 행동이 좋은지 추정하는 도구
모델(Model, 선택) \(p(s',r\mid s,a)\) 환경 동역학의 모사 환경의 프록시(없어도 학습 가능)
중요

보상은 환경에서 오는 외생 신호이고, 가치함수는 에이전트가 만든 프록시라는 점이 핵심이다. 정책은 가치함수를 길잡이 삼아 갱신되며, 모델은 있으면(model-based) 환경을 시뮬레이션해 표본 효율을 높이지만 없어도(model-free) 학습된다. 오늘 다루는 알고리즘은 전부 model-free 계열이다.

“강화(reinforcement)”라는 이름은, 좋은 상태–행동 쌍이 반복적 상호작용을 통해 점점 강화되어 또렷해진다는 데서 왔다. 역사적으로 RL은 제어 이론(optimal control)에서 출발했고, Bellman이 동역학계의 상태와 가치함수(최적 반환 함수)를 도입하면서 벨만 방정식과 그 풀이로서의 동적 계획법이 등장했다. 이를 이산·확률 버전으로 일반화한 것이 MDP다.

3 마르코프 결정 과정(MDP)

3.1 직접 답: 왜 MDP인가

학습 가능한 에이전트를 정의하려면 에이전트와 환경의 행동을 규정하는 수학적 골격이 필요하다. 마르코프 성질을 가정하면, 다음 상태·보상의 확률이 바로 직전 상태와 행동에만 의존하므로 분석이 결정적으로 단순해진다.

3.2 정의와 마르코프 성질

시점 \(t\in\{0,1,2,\dots\}\), 상태 \(s\in S\), 행동 \(a\in A(s)\), 보상 \(r\in R\) 에 대해 환경 동역학은

\[ p(s', r \mid s, a) = \Pr\big(S_{t+1}=s',\, R_{t+1}=r \mid S_t=s,\, A_t=a\big). \]

여기서 우변이 \(S_t, A_t\) 하나에만 조건부라는 것이 마르코프 성질이다. 즉 전체 과거 \((S_0,A_0,\dots,S_{t-1},A_{t-1})\) 가 아니라 현재 한 시점만 보면 미래의 통계가 결정된다.

노트에피소드 = 데이터 한 점

시점 1부터 \(T\)까지의 상호작용 한 묶음 \((R_1, R_2, \dots, R_T)\) 를 에피소드라 하며, 이것이 학습의 데이터 한 점이다. 자연스럽게 끝이 나뉘면 episodic task, 하나의 긴 흐름이면 continuing task다.

3.3 할인 반환(discounted return)과 목표

\[ G_t = \sum_{k=t+1}^{T} \gamma^{\,k-t-1} R_k = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots, \qquad 0 \le \gamma \le 1. \]

미래 보상일수록 불확실성이 크므로 할인 인자 \(\gamma\) 로 가중을 줄인다. 여기서 곧바로 재귀 형태가 나온다:

\[ \boxed{\,G_t = R_{t+1} + \gamma\, G_{t+1}\,} \]

학습의 목표는 정책에 대한 기대 반환의 최대화다:

\[ \max_{\pi}\; \mathbb{E}_\pi[G_t]. \]

힌트무선통신 대응 — 망각 인자를 가진 IIR 누적

\(G_t = R_{t+1} + \gamma G_{t+1}\) 은 망각 인자 \(\lambda\) 를 가진 1차 IIR/지수가중 누적과 같은 구조다. \(\gamma\) 가 1에 가까울수록 먼 미래까지 기억(긴 시정수)하고, 0에 가까울수록 근시안적(짧은 시정수)이 된다. RLS의 forgetting factor가 과거 오차를 얼마나 오래 반영할지 정하는 것과 정확히 같은 역할이다.

4 가치함수와 최적 정책

4.1 두 가지 가치함수

\[ v_\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s], \qquad q_\pi(s,a) = \mathbb{E}_\pi[G_t \mid S_t = s,\, A_t = a]. \]

상태가치 \(v_\pi\) 는 상태만, 행동가치 \(q_\pi\) 는 상태와 행동 둘 다를 입력으로 받는다. 둘 다 정확히 구하기는 매우 어려워 근사한다.

4.2 최적 정책

\[ v_*(s) = \max_\pi v_\pi(s), \qquad q_*(s,a) = \max_\pi q_\pi(s,a). \]

최적 정책은 보통 행동가치 \(q_*\) 로 얻는다. \(q\) 는 행동을 입력으로 받으므로 어떤 행동이 그 상태에서 가치를 높이는지 직접 비교할 수 있는 반면, \(v\) 는 행동의 효과를 직접 담지 못하기 때문이다. 결정론적 정책에서는

\[ \pi_*(s) = \operatorname*{arg\,max}_a q_*(s,a). \]

중요

\(v\) 로 최적화하는 것처럼 보이지만 내부적으로는 \(q\) 를 쓴다. 뒤의 벨만 방정식에서 \(v_\pi(s)=\sum_a \pi(a\mid s)\,q_\pi(s,a)\) 로 둘이 연결되기 때문에, 표면상 \(v\) 최적화가 실제로는 \(q\) 비교로 환원된다.

5 벨만 방정식: 재귀 관계

5.1 직접 답: 무엇이 재귀인가

벨만 방정식은 현재 시점의 가치함수를 다음 시점의 가치함수로 표현하는 재귀식이다. 이 재귀가 있어야 정책반복을 반복적 갱신으로 돌릴 수 있다.

5.2 \(v_\pi\) 와 \(q_\pi\) 의 연결

상태가치를 행동에 대해 주변화(marginalize)하면:

\[ v_\pi(s) = \sum_{a\in A(s)} \pi(a\mid s)\, q_\pi(s,a) \;\le\; \max_a q_\pi(s,a). \]

부등식은 “기댓값은 최댓값을 넘지 못한다”는 사실이며, 정책개선의 상한을 준다.

5.3 \(q_\pi\) 의 재귀 전개

반환의 재귀 \(G_t = R_{t+1} + \gamma G_{t+1}\) 를 행동가치 정의에 넣는다. 핵심 단계는 기댓값 안에서 \(G_{t+1}\) 을 \(v_\pi(S_{t+1})\) 로 바꿀 수 있다는 점이다(둘은 밖에서는 다르지만 조건부 기댓값으로는 같다):

\[ \mathbb{E}_\pi[v_\pi(S_{t+1}) \mid S_t=s, a] = \mathbb{E}_\pi[G_{t+1}\mid S_t=s, a]. \]

따라서

\[ q_\pi(s,a) = \mathbb{E}_\pi\big[R_{t+1}+\gamma G_{t+1}\mid s,a\big] = \sum_{s',r} p(s',r\mid s,a)\,\big[\,r + \gamma\, v_\pi(s')\,\big]. \]

이를 \(v_\pi\) 식에 대입하면 벨만 기대 방정식이 완성된다:

\[ \boxed{\; v_\pi(s) = \underbrace{\sum_{a}\pi(a\mid s)}_{\text{에이전트가 하는 일(정책)}} \underbrace{\sum_{s',r} p(s',r\mid s,a)}_{\text{환경의 반응(전이·보상)}} \big[\,r + \gamma\, v_\pi(s')\,\big] \;} \]

노트

구조 해석(3단 인과 사슬): 정책이 행동 분포를 결정 → 환경이 전이·보상으로 반응 → 즉시 보상 \(r\) 과 다음 상태의 미래가치 \(\gamma v_\pi(s')\) 가 합쳐져 현재가치가 된다. 분리 가능한 두 항(정책 항 / 환경 항)으로 나뉘는 점이 뒤의 정책 경사 정리에서 결정적으로 쓰인다 — 환경 항은 \(\theta\) 와 무관해 미분에서 빠진다.

힌트무선통신 대응 — 재귀 필터(RLS) 갱신

\(v_\pi(s) = \mathbb{E}[\,r + \gamma v_\pi(s')\,]\) 는 “현재 추정 = 새 관측 + 할인된 다음 추정” 형태로, RLS·칼만 필터의 예측–갱신 재귀와 같은 골격이다. \(\gamma\) 가 상태 전이 게인 역할을 하는 안정한 1차 재귀로 보면 직관이 선다.

6 정책반복과 GPI

6.1 정책개선 정리

현재 정책 \(\pi\) 의 행동가치로 탐욕적 새 정책을 정의하면

\[ \pi'(s) = \operatorname*{arg\,max}_a q_\pi(s,a) \quad\Longrightarrow\quad v_\pi(s) \le v_{\pi'}(s). \]

즉 “현재 가치함수를 최대화하는 행동”으로 정책을 바꾸면 가치가 결코 나빠지지 않는다.

6.2 일반화 정책반복(GPI)

flowchart LR
    P["정책 π"] -->|"평가<br/>(가치 추정)"| V["가치함수 v_π"]
    V -->|"개선<br/>(탐욕적 갱신)"| P

평가(가치 추정)와 개선(정책 갱신)을 번갈아 반복하면 최적 정책 \(\pi_*\) 와 최적 가치 \(v_*\) 로 수렴한다. 두 과정이 서로를 끌어올리는 협력적 반복이다.

경고GPI의 한계 → 정책 경사로 넘어가는 동기

GPI는 \(\arg\max\) 라는 미분 불가능한 탐욕 연산을 쓴다. 게다가 탐욕 갱신은 정책 분포를 급격히 바꿀 수 있어, 한 스텝에 에이전트 행동이 돌변하고 학습 곡선이 출렁인다. 신경망으로 미분 가능하게 학습하려면, \(\arg\max\) 대신 정책을 \(\theta\) 로 매개변수화하고 경사로 천천히 갱신해야 한다. 이것이 정책 경사법의 출발 동기다.

7 정책 경사법(PGM)과 정책 경사 정리

7.1 직접 답: 정책 경사 정리

정책을 \(\pi(a\mid s;\theta)\) 로 두고 목적함수를 시작 상태의 상태가치 \(J(\theta)=v_{\pi_\theta}(s_0)\) 로 정의하면, (\(\gamma=1\) 가정) 그 경사는

\[ \boxed{\;\nabla J(\theta) \;\propto\; \sum_s \mu(s) \sum_a q_\pi(s,a)\, \nabla \pi(a\mid s,\theta)\;} \]

여기서 \(\mu(s)\) 는 정책이 유도하는 상태 분포(상태 \(s\) 에 머무는 평균 시간 비율)다.

7.2 정리의 의미

목적함수의 경사는 세 요소의 곱으로 분해된다: 상태 분포 \(\mu(s)\), 행동가치 \(q_\pi(s,a)\), 그리고 정책 자체의 경사 \(\nabla\pi\). 핵심은 미분이 정책 항에만 걸리고, 환경의 전이확률 \(p(s'\mid s,a)\) 는 \(\theta\) 와 무관해 사라진다는 점이다.

노트증명 골격(개요)
  1. \(\nabla v_\pi(s)\) 에 정의 \(v_\pi(s)=\sum_a \pi(a\mid s)q_\pi(s,a)\) 를 넣고 곱의 미분을 적용한다: \(\nabla(\pi\,q) = (\nabla\pi)q + \pi(\nabla q)\).
  2. \(\nabla q_\pi(s,a)\) 안에서 보상·전이확률은 \(\theta\) 무관 상수이므로 미분이 다음 상태의 \(\nabla v_\pi(s')\) 로 재귀적으로 넘어간다.
  3. 이 재귀를 반복 전개하면, \(\nabla v_\pi(s)\) 가 “\(s\) 에서 \(x\) 로 \(k\) 스텝에 도달할 확률 \(\Pr(s\to x,k,\pi)\) 의 합 \(\times\ \nabla\pi(\cdot\mid x)\, q_\pi(x,\cdot)\)” 형태로 정리된다.
  4. \(\sum_k \Pr(s\to x,k,\pi)\) 를 정규화하면 그것이 바로 상태 분포 \(\mu(x)\) — “한 에피소드에서 상태 \(s\) 에 머무는 평균 시간 수”의 의미를 갖는다. 이를 대입해 비례식이 닫힌다.
힌트무선통신 대응 — 미분 가능한 부분만 적응

환경 전이는 우리가 통제 못 하는 채널(고정 확률)이고, 정책만 우리가 적응시키는 가중치다. 채널은 미분에서 빠지고 가중치 갱신항만 남는 구조는, 채널을 고정한 채 등화기(equalizer) 계수만 적응시키는 적응 필터와 같은 분리 구도다.

8 REINFORCE: 몬테카를로 정책 경사

8.1 로그-미분 트릭과 갱신식

정책 경사 정리를 기댓값으로 다시 쓰면

\[ \nabla J(\theta) = \mathbb{E}_\pi\!\Big[\sum_a q_\pi(s,a)\,\nabla\pi(a\mid s,\theta)\Big]. \]

여기에 로그-미분(score function) 트릭 \(\nabla_\theta \ln f = \dfrac{\nabla_\theta f}{f}\) 을 적용하면 표본화 가능한 형태가 된다:

\[ \boxed{\;\theta_{t+1} = \theta_t + \alpha\, G_t\, \nabla \ln \pi(A_t\mid S_t, \theta_t)\;} \]

반환 \(G_t\) 가 큰(좋은) 궤적이 나온 행동의 로그확률을 끌어올리는 방향으로 갱신한다.

8.2 알고리즘

노트REINFORCE 절차
  • 함수형 \(\pi(a\mid s;\theta)\)(보통 신경망), 초기 \(\theta\), 스텝 크기 \(\alpha\) 를 정한다.
  • 반복: 현재 정책으로 에피소드 하나를 무작위 생성 → 각 시점의 \(G_t\) 계산 → \(\theta \leftarrow \theta + \alpha G_t \nabla\ln\pi(A_t\mid S_t,\theta)\) 로 모든 시점 갱신 → 새 에피소드로 반복.
  • 표본 궤적으로 경사를 추정하므로 Monte Carlo 정책 경사 제어라 부른다.
경고REINFORCE의 약점

에피소드를 끝까지 무작위로 굴려 \(G_t\) 를 만들기 때문에 표본 분산이 매우 크다. 학습이 불안정하고(큰 정책 갱신), 표본 효율·강건성이 떨어진다. 학습 곡선이 출렁이고 에이전트가 엉뚱한 행동(넘어지기, 헛디딤)을 자주 보이는 이유다. 이 분산을 줄이는 것이 다음 단계들의 일관된 동기다.

힌트무선통신 대응 — 잡음 큰 경사 추정

\(G_t\) 는 한 번의 무작위 실현으로 얻은 추정이라 분산이 큰 노이즈 섞인 경사다. 단일 스냅샷으로 채널을 추정하면 분산이 큰 것과 같으며, 다음 절의 baseline 차감은 추정량의 분산을 줄이는 전처리에 해당한다.

9 분산 감소: Baseline · Advantage · Actor-Critic

9.1 Baseline은 편향 없이 분산만 줄인다

기댓값에 상태에만 의존하는 baseline \(b(S_t)\) 를 빼도 경사의 기댓값은 변하지 않는다(불편):

\[ \nabla J(\theta) = \mathbb{E}_\pi\big[(G_t - b(S_t))\,\nabla\ln\pi(A_t\mid S_t,\theta)\big]. \]

이유는 \(\mathbb{E}_\pi[\,b(S_t)\nabla\ln\pi\,]=b(S_t)\sum_a \nabla\pi = b(S_t)\nabla\!\sum_a\pi = 0\) 이기 때문이다(\(\sum_a\pi=1\)).

9.2 Advantage 함수

자연스러운 baseline은 상태가치 \(v_\pi(S_t)\) 다. 한 스텝 전개로 \(G_t\) 를 끝까지 굴리지 않고 근사하면 TD 오차가 나오고, 이것이 곧 advantage다:

\[ \delta_t = R_{t+1} + \gamma\, v_\pi(S_{t+1}) - v_\pi(S_t) \;\approx\; G_t - v_\pi(S_t) \;=\; A_\pi(S_t, A_t), \qquad \nabla J(\theta) = \mathbb{E}_\pi[\delta_t\,\nabla\ln\pi]. \]

advantage는 “그 행동이 그 상태의 평균보다 얼마나 더 좋은가”를 재며, 절대 보상의 큰 출렁임을 평균 대비 상대값으로 바꿔 분산을 줄인다.

9.3 Actor-Critic

구성 역할 수식
Actor(정책망) 어떤 행동을 할지 결정 \(\pi_\theta(s)\)
Critic(가치망) 그 행동의 질을 추정 \(Q(s,a)\) 또는 \(v(s)\), \(\delta_t\)
노트

critic은 actor를 직접 지휘하지 않고 보조한다. 초기에는 정책이 미숙하니 critic도 noisy해 거의 통제하지 못하지만, 반복이 진행되며 정책이 좋아지면 critic의 피드백도 정확해지고, 그러면 actor의 갱신을 더 잘 제약해 빠르고 안정적으로 수렴시킨다. 다만 이는 간접적 정규화일 뿐, 한 스텝에 정책이 급변하지 않는다는 보장은 없다. 그 보장을 직접 거는 것이 다음의 신뢰 영역 방법이다.

힌트무선통신 대응 — DC 제거 / 제어 변량

baseline 차감은 추정 전에 평균(DC)을 빼 분산을 줄이는 control variate 기법이다. 신호의 평균을 제거한 뒤 변동분만 추정하면 추정 분산이 작아지는 것과 같으며, 본문 검증에서 분산이 약 7배(21.8→3.1) 줄어든 것이 이 효과다.

10 신뢰 영역 방법(TRPO)

10.1 직접 답: 무엇을 제약하나

한 스텝만에도 actor 파라미터가 급변해 학습이 무너질 수 있다. 해법은 새 정책이 이전 정책에서 너무 멀어지지 않도록 KL 발산으로 갱신 영역을 묶는 것이다:

\[ D_{\mathrm{KL}}\big(\pi_{\theta_{\text{old}}} \,\|\, \pi_\theta\big) \le \epsilon. \]

10.2 대리 목적함수와 확률 비율

\(\nabla\ln\pi\) 항을 확률 비율로 근사한다(\(\theta_{\text{old}}\) 에서 1차 전개하면 같은 경사를 준다):

\[ r_t(\theta) = \frac{\pi_\theta(a_t\mid s_t)}{\pi_{\theta_{\text{old}}}(a_t\mid s_t)}. \]

TRPO는 제약 하에서 대리 목적

\[ \max_\theta\; \mathbb{E}_t\big[r_t(\theta)\,\hat{A}_t\big] \quad \text{s.t.}\quad D_{\mathrm{KL}}\le \delta \]

를 최대화한다. 비제약 형태로는 KL 페널티 \(-\beta D_{\mathrm{KL}}\) 를 목적에 더한다.

경고TRPO의 한계

KL 제약을 정확히 다루려면 KL의 2차 근사(헤시안 포함)가 필요한 복잡한 2차 방법이고, KL 페널티 계수 \(\beta\) 를 모든 문제에 통하는 고정값으로 잡기 어렵다. 계산이 무겁다는 이 약점이 PPO로 가는 동기다.

힌트무선통신 대응 — 정규화된 스텝 크기 제어(NLMS)

KL 제약은 적응 갱신의 발산을 막으려고 스텝 크기를 정규화/제한하는 NLMS의 사상과 같다. 입력 에너지가 클 때 스텝을 줄여 안정성을 지키듯, 정책이 멀리 튀려 하면 KL 제약이 갱신을 끌어당겨 “신뢰할 수 있는” 영역 안에 둔다.

11 근위 정책 최적화(PPO)

11.1 직접 답: 클리핑 한 줄

PPO는 TRPO의 복잡한 KL 계산을, 확률 비율을 \([1-\epsilon,\,1+\epsilon]\) 로 자르는(clip) 단순 연산으로 대체한다:

\[ \boxed{\; L^{\text{CLIP}}(\theta) = \mathbb{E}_t\Big[\min\big(r_t(\theta)\,\hat{A}_t,\;\operatorname{clip}(r_t(\theta),\,1-\epsilon,\,1+\epsilon)\,\hat{A}_t\big)\Big] \;} \]

11.2 클리핑의 동작

\(r_t\) 가 1에서 멀어지는(=정책이 많이 바뀌는) 갱신을 벌점화한다. 본문 수치 검증의 결과로 동작을 읽으면:

상황 \(r_t\) 작음 \(r_t=1\) \(r_t\) 큼
\(\hat A>0\) (좋은 행동) 그대로 반영 1.0 \(1+\epsilon\) 에서 상한 (과한 증폭 차단)
\(\hat A<0\) (나쁜 행동) \(1-\epsilon\) 에서 하한 \(-1.0\) 그대로 벌점(억제)

즉 좋은 행동을 지나치게 밀어붙이거나 나쁜 행동을 과하게 끌어내려 정책이 튀는 것을 양쪽에서 막는다. 클리핑 대신 KL 페널티 변형 \(L - \beta D_{\mathrm{KL}}\) 도 쓸 수 있어, PPO는 KL 페널티 방식을 포함하는 일반 틀로 볼 수 있다.

노트PPO의 장점
  • 여러 epoch의 확률적 경사 상승으로 같은 데이터를 재활용 → 표본 효율↑
  • 신뢰 영역 방법의 안정성·신뢰성을 유지
  • 구현이 단순(1차 방법, 비율+클립만 계산; KL 헤시안 불필요)

이 단순함 덕분에 PPO는 RLHF의 표준 도구가 되었고, GPT → InstructGPT → ChatGPT 계열의 지시 미세조정에 핵심으로 쓰였다.

경고

한계도 분명하다. 지역 최적해에 갇힐 수 있고, 클리핑이 누적되며 새 정책이 결국 이전 정책에서 너무 멀어질 가능성이 남는다.

힌트무선통신 대응 — 피드백 루프의 리미터/경사 클리핑

\(r_t\) 를 \([1-\epsilon,1+\epsilon]\) 로 자르는 것은 피드백 루프의 진폭 리미터·경사 클리핑과 같다. 루프 게인이 과도해 발진하지 않도록 출력을 포화시키는 보호 장치이며, 복잡한 안정도 해석 없이도 안정성을 확보하는 실용적 방식이라는 점까지 닮았다.

12 그룹 상대 정책 최적화(GRPO)

12.1 직접 답: critic 제거 + 그룹 정규화

PPO에서 advantage 계산(GAE)은 baseline을 위해 별도 critic(가치망) 을 학습해야 해 비싸다. GRPO는 critic을 통째로 버리고, advantage를 그룹 내 보상의 상대 위치로 대체한다:

\[ \boxed{\;\hat{A}^{\text{GRPO}}_t = \frac{R - \mu_g}{\sigma_g + \delta}\;} \]

\(R\): 해당 출력의 보상, \(\mu_g\): 그룹 평균 보상, \(\sigma_g\): 그룹 표준편차, \(\delta\): 분모가 0이 되지 않게 하는 작은 상수.

12.2 아이디어

같은 프롬프트에 대해 여러 출력(그룹/배치)을 만들고, 각 출력의 보상을 그룹 평균 대비 상대값으로 정규화해 advantage로 쓴다. 미래 보상의 누적 추정도, critic도 필요 없이 현재 보상의 그룹 통계만으로 advantage를 만든다. PPO와 목적함수의 클리핑·(선택적) KL 항은 거의 동일하고, advantage 정의만 다르다.

12.3 PPO vs GRPO

항목 PPO GRPO

노트

힌트무선통신 대응 — CFAR / AGC 정규화

\(\hat A=\dfrac{R-\mu_g}{\sigma_g+\delta}\) 는 레이더의 CFAR 검출과 같은 발상이다. 시험 셀의 전력을 주변 셀로 추정한 잡음 통계(평균·표준편차)로 나눠 절대 스케일에 무관한 검출 통계를 만들듯, GRPO는 한 출력의 보상을 그룹의 평균·표준편차로 정규화해 보상 스케일에 둔감한 advantage를 만든다. AGC가 신호 레벨을 그룹 통계로 정규화하는 것과도 같으며, 별도 기준 추정기(critic) 없이 이웃/배치 통계만으로 정규화한다는 점이 정확히 대응한다.

import numpy as np
rng = np.random.default_rng(0)

# softmax 정책: pi(a) = softmax(theta)_a, grad_theta log pi(a) = e_a - pi
theta = rng.normal(size=4)
pi = np.exp(theta) / np.exp(theta).sum()
grad_logpi = np.eye(4) - pi[None, :]            # 행 a = grad log pi(a)

# (1) score function 항등식: E_{a~pi}[ grad log pi ] = 0
E_score = (pi[:, None] * grad_logpi).sum(0)
print("E[grad log pi]      :", np.round(E_score, 12))   # ~ 0

# (2) 상수 baseline b 는 경사를 편향시키지 않음: E[ b * grad log pi ] = 0
b = 3.7
print("E[b * grad log pi]  :", np.round((pi[:, None] * b * grad_logpi).sum(0), 12))

15.2 Baseline의 분산 감소 효과

# 반환 G ~ N(5, 2), 행동을 pi에서 샘플 → G*score 대 (G - mean)*score 의 분산 비교
N = 100_000
G = rng.normal(5.0, 2.0, size=N)
a = rng.integers(0, 4, size=N)
score = grad_logpi[a]                            # (N, 4)

est_no = G[:, None] * score                       # baseline 없음
est_bl = (G - G.mean())[:, None] * score          # baseline = 평균

print("trace Var (no baseline):", round(np.cov(est_no.T).trace(), 3))
print("trace Var (w/ baseline):", round(np.cov(est_bl.T).trace(), 3))
# baseline 차감으로 분산이 크게 감소 (약 7배)

15.3 GRPO 그룹 상대 advantage

# 그룹 내 이진 보상 → (R - mu)/(sigma + delta) 로 정규화
R = np.array([0., 1., 1., 0., 1., 0., 0., 1.])
mu, sd = R.mean(), R.std()
A_grpo = (R - mu) / (sd + 1e-8)
print("GRPO advantage:", np.round(A_grpo, 3))

15.4 PPO 클리핑 대리 목적

def ppo_clip(r, A, eps=0.2):
    """L^CLIP = min( r*A , clip(r,1-eps,1+eps)*A )"""
    return np.minimum(r * A, np.clip(r, 1 - eps, 1 + eps) * A)

ratios = np.array([0.5, 0.9, 1.0, 1.1, 1.5])
print("A>0 (좋은 행동) r:", ratios, "-> L:", np.round(ppo_clip(ratios, +1.0), 3))
print("A<0 (나쁜 행동) r:", ratios, "-> L:", np.round(ppo_clip(ratios, -1.0), 3))
# A>0: r가 1+eps=1.2 위로 가면 상한에서 포화 (과한 증폭 차단)
# A<0: r가 1-eps=0.8 아래로 가면 하한에서 포화

15.5 작은 REINFORCE 학습 데모(2상태 밴딧 유사)

# 단순 2행동 문제: 행동 1의 기대보상이 더 높음 → 정책이 행동 1로 수렴하는지 확인
rng = np.random.default_rng(1)
theta = np.zeros(2)                 # softmax 로짓
alpha = 0.1
true_reward = np.array([0.2, 0.8])  # 행동별 기대 보상

def softmax(z):
    z = z - z.max()
    e = np.exp(z)
    return e / e.sum()

for step in range(2000):
    p = softmax(theta)
    a = rng.choice(2, p=p)                          # 현재 정책에서 행동 샘플
    G = rng.normal(true_reward[a], 0.1)             # 보상(반환) 샘플
    grad_logpi = (np.eye(2)[a] - p)                 # grad log pi(a)
    theta += alpha * G * grad_logpi                 # REINFORCE 갱신

print("최종 정책 분포:", np.round(softmax(theta), 3))  # 행동 1 확률이 1에 근접

# 한눈에 보는 전체 그림 {#sec-overview}

::: {.callout-tip}
## 핵심 한 줄 요약
강화학습(RL)은 **MDP**라는 수학적 골격 위에서, 보상의 기대 누적값을 최대화하는 **정책 $\pi$** 를 찾는 문제다.
정책을 직접 $\theta$ 로 매개변수화하면 **정책 경사 정리**가 학습의 기본 방정식이 되고,
여기서 **분산을 줄이고**(baseline·advantage·actor-critic) **갱신 폭을 통제하는**(TRPO·PPO·GRPO) 방향으로 알고리즘이 발전한다.
:::

오늘 다루는 알고리즘들은 모두 하나의 계보 위에 있다. 출발점은 정책 경사를 그대로 쓰는 **REINFORCE**이고, 그것의 분산을 줄이려고 **Actor-Critic**이 나오며, 갱신이 너무 커서 학습이 불안정해지는 문제를 신뢰 영역으로 묶는 **TRPO**가 등장하고, 그 복잡한 2차 최적화를 단순한 클리핑으로 근사한 것이 **PPO**, 그리고 PPO에서 critic(가치망)을 통째로 들어내고 advantage를 그룹 통계로 대체한 것이 **GRPO**다.

# 강화학습의 4요소와 문제 정의 {#sec-elements}

## 직접 답: RL이 푸는 것 {#sec-elements-answer}

RL은 환경과 상호작용하며 **수치 보상 신호**를 받는 에이전트가, 미래 보상의 기대 누적을 최대화하도록 **행동 선택 규칙(정책)** 을 학습하는 문제다.

## 네 가지 구성요소 {#sec-elements-four}

| 요소 | 기호 | 정의 | 역할 |
|---|---|---|---|
| 정책(Policy) | $\pi(a\mid s)$ | 상태에서 행동으로의 매핑(확률) | 에이전트의 **행동 자체**를 정의 |
| 보상(Reward) | $r$ | 매 시점 환경이 주는 단일 숫자 | 최대화 **대상이 되는 신호** |
| 가치함수(Value) | $v_\pi, q_\pi$ | 미래 보상의 기대 누적 | 어떤 행동이 좋은지 **추정하는 도구** |
| 모델(Model, 선택) | $p(s',r\mid s,a)$ | 환경 동역학의 모사 | 환경의 **프록시**(없어도 학습 가능) |

::: {.callout-important}
보상은 **환경에서 오는 외생 신호**이고, 가치함수는 **에이전트가 만든 프록시**라는 점이 핵심이다. 정책은 가치함수를 길잡이 삼아 갱신되며, 모델은 있으면(model-based) 환경을 시뮬레이션해 표본 효율을 높이지만 없어도(model-free) 학습된다. 오늘 다루는 알고리즘은 전부 **model-free** 계열이다.
:::

"강화(reinforcement)"라는 이름은, 좋은 상태–행동 쌍이 반복적 상호작용을 통해 점점 **강화되어** 또렷해진다는 데서 왔다. 역사적으로 RL은 제어 이론(optimal control)에서 출발했고, Bellman이 동역학계의 상태와 가치함수(최적 반환 함수)를 도입하면서 **벨만 방정식**과 그 풀이로서의 **동적 계획법**이 등장했다. 이를 이산·확률 버전으로 일반화한 것이 **MDP**다.

# 마르코프 결정 과정(MDP) {#sec-mdp}

## 직접 답: 왜 MDP인가 {#sec-mdp-answer}

학습 가능한 에이전트를 정의하려면 에이전트와 환경의 행동을 규정하는 수학적 골격이 필요하다. **마르코프 성질**을 가정하면, 다음 상태·보상의 확률이 **바로 직전 상태와 행동에만** 의존하므로 분석이 결정적으로 단순해진다.

## 정의와 마르코프 성질 {#sec-mdp-def}

시점 $t\in\{0,1,2,\dots\}$, 상태 $s\in S$, 행동 $a\in A(s)$, 보상 $r\in R$ 에 대해 환경 동역학은

$$
p(s', r \mid s, a) = \Pr\big(S_{t+1}=s',\, R_{t+1}=r \mid S_t=s,\, A_t=a\big).
$$

여기서 우변이 $S_t, A_t$ **하나에만** 조건부라는 것이 마르코프 성질이다. 즉 전체 과거 $(S_0,A_0,\dots,S_{t-1},A_{t-1})$ 가 아니라 현재 한 시점만 보면 미래의 통계가 결정된다.

::: {.callout-note}
## 에피소드 = 데이터 한 점
시점 1부터 $T$까지의 상호작용 한 묶음 $(R_1, R_2, \dots, R_T)$ 를 **에피소드**라 하며, 이것이 학습의 데이터 한 점이다. 자연스럽게 끝이 나뉘면 *episodic task*, 하나의 긴 흐름이면 *continuing task*다.
:::

## 할인 반환(discounted return)과 목표 {#sec-mdp-return}

$$
G_t = \sum_{k=t+1}^{T} \gamma^{\,k-t-1} R_k
    = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots,
\qquad 0 \le \gamma \le 1.
$$

미래 보상일수록 불확실성이 크므로 할인 인자 $\gamma$ 로 가중을 줄인다. 여기서 곧바로 **재귀 형태**가 나온다:

$$
\boxed{\,G_t = R_{t+1} + \gamma\, G_{t+1}\,}
$$

학습의 목표는 정책에 대한 기대 반환의 최대화다:

$$
\max_{\pi}\; \mathbb{E}_\pi[G_t].
$$

::: {.callout-tip}
## 무선통신 대응 — 망각 인자를 가진 IIR 누적
$G_t = R_{t+1} + \gamma G_{t+1}$ 은 망각 인자 $\lambda$ 를 가진 1차 IIR/지수가중 누적과 같은 구조다. $\gamma$ 가 1에 가까울수록 먼 미래까지 기억(긴 시정수)하고, 0에 가까울수록 근시안적(짧은 시정수)이 된다. RLS의 forgetting factor가 과거 오차를 얼마나 오래 반영할지 정하는 것과 정확히 같은 역할이다.
:::

# 가치함수와 최적 정책 {#sec-value}

## 두 가지 가치함수 {#sec-value-two}

$$
v_\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s],
\qquad
q_\pi(s,a) = \mathbb{E}_\pi[G_t \mid S_t = s,\, A_t = a].
$$

상태가치 $v_\pi$ 는 **상태만**, 행동가치 $q_\pi$ 는 **상태와 행동 둘 다**를 입력으로 받는다. 둘 다 정확히 구하기는 매우 어려워 근사한다.

## 최적 정책 {#sec-value-optimal}

$$
v_*(s) = \max_\pi v_\pi(s),
\qquad
q_*(s,a) = \max_\pi q_\pi(s,a).
$$

최적 정책은 보통 **행동가치** $q_*$ 로 얻는다. $q$ 는 행동을 입력으로 받으므로 어떤 행동이 그 상태에서 가치를 높이는지 직접 비교할 수 있는 반면, $v$ 는 행동의 효과를 직접 담지 못하기 때문이다. 결정론적 정책에서는

$$
\pi_*(s) = \operatorname*{arg\,max}_a q_*(s,a).
$$

::: {.callout-important}
**$v$ 로 최적화하는 것처럼 보이지만 내부적으로는 $q$ 를 쓴다.** 뒤의 벨만 방정식에서 $v_\pi(s)=\sum_a \pi(a\mid s)\,q_\pi(s,a)$ 로 둘이 연결되기 때문에, 표면상 $v$ 최적화가 실제로는 $q$ 비교로 환원된다.
:::

# 벨만 방정식: 재귀 관계 {#sec-bellman}

## 직접 답: 무엇이 재귀인가 {#sec-bellman-answer}

벨만 방정식은 **현재 시점의 가치함수**를 **다음 시점의 가치함수**로 표현하는 재귀식이다. 이 재귀가 있어야 정책반복을 반복적 갱신으로 돌릴 수 있다.

## $v_\pi$ 와 $q_\pi$ 의 연결 {#sec-bellman-link}

상태가치를 행동에 대해 주변화(marginalize)하면:

$$
v_\pi(s) = \sum_{a\in A(s)} \pi(a\mid s)\, q_\pi(s,a)
        \;\le\; \max_a q_\pi(s,a).
$$

부등식은 "기댓값은 최댓값을 넘지 못한다"는 사실이며, 정책개선의 상한을 준다.

## $q_\pi$ 의 재귀 전개 {#sec-bellman-q}

반환의 재귀 $G_t = R_{t+1} + \gamma G_{t+1}$ 를 행동가치 정의에 넣는다. 핵심 단계는 **기댓값 안에서** $G_{t+1}$ 을 $v_\pi(S_{t+1})$ 로 바꿀 수 있다는 점이다(둘은 밖에서는 다르지만 조건부 기댓값으로는 같다):

$$
\mathbb{E}_\pi[v_\pi(S_{t+1}) \mid S_t=s, a] = \mathbb{E}_\pi[G_{t+1}\mid S_t=s, a].
$$

따라서

$$
q_\pi(s,a) = \mathbb{E}_\pi\big[R_{t+1}+\gamma G_{t+1}\mid s,a\big]
           = \sum_{s',r} p(s',r\mid s,a)\,\big[\,r + \gamma\, v_\pi(s')\,\big].
$$

이를 $v_\pi$ 식에 대입하면 **벨만 기대 방정식**이 완성된다:

$$
\boxed{\;
v_\pi(s) = \underbrace{\sum_{a}\pi(a\mid s)}_{\text{에이전트가 하는 일(정책)}}
           \underbrace{\sum_{s',r} p(s',r\mid s,a)}_{\text{환경의 반응(전이·보상)}}
           \big[\,r + \gamma\, v_\pi(s')\,\big]
\;}
$$

::: {.callout-note}
**구조 해석(3단 인과 사슬):** 정책이 행동 분포를 결정 → 환경이 전이·보상으로 반응 → 즉시 보상 $r$ 과 다음 상태의 미래가치 $\gamma v_\pi(s')$ 가 합쳐져 현재가치가 된다. 분리 가능한 두 항(정책 항 / 환경 항)으로 나뉘는 점이 뒤의 정책 경사 정리에서 결정적으로 쓰인다 — 환경 항은 $\theta$ 와 무관해 미분에서 빠진다.
:::

::: {.callout-tip}
## 무선통신 대응 — 재귀 필터(RLS) 갱신
$v_\pi(s) = \mathbb{E}[\,r + \gamma v_\pi(s')\,]$ 는 "현재 추정 = 새 관측 + 할인된 다음 추정" 형태로, RLS·칼만 필터의 예측–갱신 재귀와 같은 골격이다. $\gamma$ 가 상태 전이 게인 역할을 하는 안정한 1차 재귀로 보면 직관이 선다.
:::

# 정책반복과 GPI {#sec-gpi}

## 정책개선 정리 {#sec-gpi-pit}

현재 정책 $\pi$ 의 행동가치로 탐욕적 새 정책을 정의하면

$$
\pi'(s) = \operatorname*{arg\,max}_a q_\pi(s,a)
\quad\Longrightarrow\quad
v_\pi(s) \le v_{\pi'}(s).
$$

즉 "현재 가치함수를 최대화하는 행동"으로 정책을 바꾸면 가치가 결코 나빠지지 않는다.

## 일반화 정책반복(GPI) {#sec-gpi-loop}

```{mermaid}
flowchart LR
    P["정책 π"] -->|"평가<br/>(가치 추정)"| V["가치함수 v_π"]
    V -->|"개선<br/>(탐욕적 갱신)"| P
```

평가(가치 추정)와 개선(정책 갱신)을 번갈아 반복하면 최적 정책 $\pi_*$ 와 최적 가치 $v_*$ 로 수렴한다. 두 과정이 서로를 끌어올리는 **협력적 반복**이다.

::: {.callout-warning}
## GPI의 한계 → 정책 경사로 넘어가는 동기
GPI는 $\arg\max$ 라는 **미분 불가능**한 탐욕 연산을 쓴다. 게다가 탐욕 갱신은 정책 분포를 **급격히** 바꿀 수 있어, 한 스텝에 에이전트 행동이 돌변하고 학습 곡선이 출렁인다. 신경망으로 미분 가능하게 학습하려면, $\arg\max$ 대신 **정책을 $\theta$ 로 매개변수화하고 경사로 천천히 갱신**해야 한다. 이것이 정책 경사법의 출발 동기다.
:::

# 정책 경사법(PGM)과 정책 경사 정리 {#sec-pg}

## 직접 답: 정책 경사 정리 {#sec-pg-answer}

정책을 $\pi(a\mid s;\theta)$ 로 두고 목적함수를 시작 상태의 상태가치 $J(\theta)=v_{\pi_\theta}(s_0)$ 로 정의하면, ($\gamma=1$ 가정) 그 경사는

$$
\boxed{\;\nabla J(\theta) \;\propto\; \sum_s \mu(s) \sum_a q_\pi(s,a)\, \nabla \pi(a\mid s,\theta)\;}
$$

여기서 $\mu(s)$ 는 정책이 유도하는 **상태 분포**(상태 $s$ 에 머무는 평균 시간 비율)다.

## 정리의 의미 {#sec-pg-meaning}

목적함수의 경사는 세 요소의 곱으로 분해된다: 상태 분포 $\mu(s)$, 행동가치 $q_\pi(s,a)$, 그리고 **정책 자체의 경사** $\nabla\pi$. 핵심은 미분이 **정책 항에만** 걸리고, 환경의 전이확률 $p(s'\mid s,a)$ 는 $\theta$ 와 무관해 사라진다는 점이다.

::: {.callout-note}
## 증명 골격(개요)
1. $\nabla v_\pi(s)$ 에 정의 $v_\pi(s)=\sum_a \pi(a\mid s)q_\pi(s,a)$ 를 넣고 **곱의 미분**을 적용한다: $\nabla(\pi\,q) = (\nabla\pi)q + \pi(\nabla q)$.
2. $\nabla q_\pi(s,a)$ 안에서 보상·전이확률은 $\theta$ 무관 상수이므로 미분이 다음 상태의 $\nabla v_\pi(s')$ 로 **재귀적으로** 넘어간다.
3. 이 재귀를 반복 전개하면, $\nabla v_\pi(s)$ 가 "$s$ 에서 $x$ 로 $k$ 스텝에 도달할 확률 $\Pr(s\to x,k,\pi)$ 의 합 $\times\ \nabla\pi(\cdot\mid x)\, q_\pi(x,\cdot)$" 형태로 정리된다.
4. $\sum_k \Pr(s\to x,k,\pi)$ 를 정규화하면 그것이 바로 상태 분포 $\mu(x)$ — "한 에피소드에서 상태 $s$ 에 머무는 평균 시간 수"의 의미를 갖는다. 이를 대입해 비례식이 닫힌다.
:::

::: {.callout-tip}
## 무선통신 대응 — 미분 가능한 부분만 적응
환경 전이는 우리가 통제 못 하는 채널(고정 확률)이고, 정책만 우리가 적응시키는 가중치다. 채널은 미분에서 빠지고 가중치 갱신항만 남는 구조는, 채널을 고정한 채 등화기(equalizer) 계수만 적응시키는 적응 필터와 같은 분리 구도다.
:::

# REINFORCE: 몬테카를로 정책 경사 {#sec-reinforce}

## 로그-미분 트릭과 갱신식 {#sec-reinforce-trick}

정책 경사 정리를 기댓값으로 다시 쓰면

$$
\nabla J(\theta) = \mathbb{E}_\pi\!\Big[\sum_a q_\pi(s,a)\,\nabla\pi(a\mid s,\theta)\Big].
$$

여기에 **로그-미분(score function) 트릭** $\nabla_\theta \ln f = \dfrac{\nabla_\theta f}{f}$ 을 적용하면 표본화 가능한 형태가 된다:

$$
\boxed{\;\theta_{t+1} = \theta_t + \alpha\, G_t\, \nabla \ln \pi(A_t\mid S_t, \theta_t)\;}
$$

반환 $G_t$ 가 큰(좋은) 궤적이 나온 행동의 로그확률을 끌어올리는 방향으로 갱신한다.

## 알고리즘 {#sec-reinforce-algo}

::: {.callout-note}
## REINFORCE 절차
- 함수형 $\pi(a\mid s;\theta)$(보통 신경망), 초기 $\theta$, 스텝 크기 $\alpha$ 를 정한다.
- 반복: 현재 정책으로 **에피소드 하나를 무작위 생성** → 각 시점의 $G_t$ 계산 → $\theta \leftarrow \theta + \alpha G_t \nabla\ln\pi(A_t\mid S_t,\theta)$ 로 모든 시점 갱신 → 새 에피소드로 반복.
- 표본 궤적으로 경사를 추정하므로 **Monte Carlo 정책 경사 제어**라 부른다.
:::

::: {.callout-warning}
## REINFORCE의 약점
에피소드를 끝까지 무작위로 굴려 $G_t$ 를 만들기 때문에 **표본 분산이 매우 크다**. 학습이 불안정하고(큰 정책 갱신), 표본 효율·강건성이 떨어진다. 학습 곡선이 출렁이고 에이전트가 엉뚱한 행동(넘어지기, 헛디딤)을 자주 보이는 이유다. 이 분산을 줄이는 것이 다음 단계들의 일관된 동기다.
:::

::: {.callout-tip}
## 무선통신 대응 — 잡음 큰 경사 추정
$G_t$ 는 한 번의 무작위 실현으로 얻은 추정이라 분산이 큰 노이즈 섞인 경사다. 단일 스냅샷으로 채널을 추정하면 분산이 큰 것과 같으며, 다음 절의 baseline 차감은 추정량의 분산을 줄이는 전처리에 해당한다.
:::

# 분산 감소: Baseline · Advantage · Actor-Critic {#sec-ac}

## Baseline은 편향 없이 분산만 줄인다 {#sec-ac-baseline}

기댓값에 **상태에만 의존하는** baseline $b(S_t)$ 를 빼도 경사의 기댓값은 변하지 않는다(불편):

$$
\nabla J(\theta) = \mathbb{E}_\pi\big[(G_t - b(S_t))\,\nabla\ln\pi(A_t\mid S_t,\theta)\big].
$$

이유는 $\mathbb{E}_\pi[\,b(S_t)\nabla\ln\pi\,]=b(S_t)\sum_a \nabla\pi = b(S_t)\nabla\!\sum_a\pi = 0$ 이기 때문이다($\sum_a\pi=1$).

## Advantage 함수 {#sec-ac-adv}

자연스러운 baseline은 상태가치 $v_\pi(S_t)$ 다. 한 스텝 전개로 $G_t$ 를 끝까지 굴리지 않고 근사하면 **TD 오차**가 나오고, 이것이 곧 advantage다:

$$
\delta_t = R_{t+1} + \gamma\, v_\pi(S_{t+1}) - v_\pi(S_t)
\;\approx\; G_t - v_\pi(S_t) \;=\; A_\pi(S_t, A_t),
\qquad
\nabla J(\theta) = \mathbb{E}_\pi[\delta_t\,\nabla\ln\pi].
$$

advantage는 "그 행동이 그 상태의 평균보다 얼마나 더 좋은가"를 재며, 절대 보상의 큰 출렁임을 평균 대비 상대값으로 바꿔 분산을 줄인다.

## Actor-Critic {#sec-ac-actor-critic}

| 구성 | 역할 | 수식 |
|---|---|---|
| Actor(정책망) | 어떤 행동을 할지 결정 | $\pi_\theta(s)$ |
| Critic(가치망) | 그 행동의 질을 추정 | $Q(s,a)$ 또는 $v(s)$, $\delta_t$ |

::: {.callout-note}
**critic은 actor를 직접 지휘하지 않고 보조한다.** 초기에는 정책이 미숙하니 critic도 noisy해 거의 통제하지 못하지만, 반복이 진행되며 정책이 좋아지면 critic의 피드백도 정확해지고, 그러면 actor의 갱신을 더 잘 제약해 빠르고 안정적으로 수렴시킨다. 다만 이는 **간접적 정규화**일 뿐, 한 스텝에 정책이 급변하지 않는다는 **보장은 없다**. 그 보장을 직접 거는 것이 다음의 신뢰 영역 방법이다.
:::

::: {.callout-tip}
## 무선통신 대응 — DC 제거 / 제어 변량
baseline 차감은 추정 전에 평균(DC)을 빼 분산을 줄이는 control variate 기법이다. 신호의 평균을 제거한 뒤 변동분만 추정하면 추정 분산이 작아지는 것과 같으며, 본문 검증에서 분산이 약 7배(21.8→3.1) 줄어든 것이 이 효과다.
:::

# 신뢰 영역 방법(TRPO) {#sec-trpo}

## 직접 답: 무엇을 제약하나 {#sec-trpo-answer}

한 스텝만에도 actor 파라미터가 급변해 학습이 무너질 수 있다. 해법은 **새 정책이 이전 정책에서 너무 멀어지지 않도록** KL 발산으로 갱신 영역을 묶는 것이다:

$$
D_{\mathrm{KL}}\big(\pi_{\theta_{\text{old}}} \,\|\, \pi_\theta\big) \le \epsilon.
$$

## 대리 목적함수와 확률 비율 {#sec-trpo-surrogate}

$\nabla\ln\pi$ 항을 **확률 비율**로 근사한다($\theta_{\text{old}}$ 에서 1차 전개하면 같은 경사를 준다):

$$
r_t(\theta) = \frac{\pi_\theta(a_t\mid s_t)}{\pi_{\theta_{\text{old}}}(a_t\mid s_t)}.
$$

TRPO는 제약 하에서 대리 목적

$$
\max_\theta\; \mathbb{E}_t\big[r_t(\theta)\,\hat{A}_t\big]
\quad \text{s.t.}\quad D_{\mathrm{KL}}\le \delta
$$

를 최대화한다. 비제약 형태로는 KL 페널티 $-\beta D_{\mathrm{KL}}$ 를 목적에 더한다.

::: {.callout-warning}
## TRPO의 한계
KL 제약을 정확히 다루려면 KL의 2차 근사(헤시안 포함)가 필요한 **복잡한 2차 방법**이고, KL 페널티 계수 $\beta$ 를 모든 문제에 통하는 고정값으로 잡기 어렵다. 계산이 무겁다는 이 약점이 PPO로 가는 동기다.
:::

::: {.callout-tip}
## 무선통신 대응 — 정규화된 스텝 크기 제어(NLMS)
KL 제약은 적응 갱신의 발산을 막으려고 스텝 크기를 정규화/제한하는 NLMS의 사상과 같다. 입력 에너지가 클 때 스텝을 줄여 안정성을 지키듯, 정책이 멀리 튀려 하면 KL 제약이 갱신을 끌어당겨 "신뢰할 수 있는" 영역 안에 둔다.
:::

# 근위 정책 최적화(PPO) {#sec-ppo}

## 직접 답: 클리핑 한 줄 {#sec-ppo-answer}

PPO는 TRPO의 복잡한 KL 계산을, 확률 비율을 $[1-\epsilon,\,1+\epsilon]$ 로 **자르는(clip)** 단순 연산으로 대체한다:

$$
\boxed{\;
L^{\text{CLIP}}(\theta) = \mathbb{E}_t\Big[\min\big(r_t(\theta)\,\hat{A}_t,\;\operatorname{clip}(r_t(\theta),\,1-\epsilon,\,1+\epsilon)\,\hat{A}_t\big)\Big]
\;}
$$

## 클리핑의 동작 {#sec-ppo-clip}

$r_t$ 가 1에서 멀어지는(=정책이 많이 바뀌는) 갱신을 벌점화한다. 본문 수치 검증의 결과로 동작을 읽으면:

| 상황 | $r_t$ 작음 | $r_t=1$ | $r_t$ 큼 |
|---|---|---|---|
| $\hat A>0$ (좋은 행동) | 그대로 반영 | 1.0 | **$1+\epsilon$ 에서 상한** (과한 증폭 차단) |
| $\hat A<0$ (나쁜 행동) | **$1-\epsilon$ 에서 하한** | $-1.0$ | 그대로 벌점(억제) |

즉 좋은 행동을 지나치게 밀어붙이거나 나쁜 행동을 과하게 끌어내려 정책이 튀는 것을 양쪽에서 막는다. 클리핑 대신 KL 페널티 변형 $L - \beta D_{\mathrm{KL}}$ 도 쓸 수 있어, PPO는 KL 페널티 방식을 포함하는 일반 틀로 볼 수 있다.

::: {.callout-note}
## PPO의 장점
- 여러 epoch의 확률적 경사 상승으로 같은 데이터를 재활용 → 표본 효율↑
- 신뢰 영역 방법의 안정성·신뢰성을 유지
- 구현이 단순(1차 방법, 비율+클립만 계산; KL 헤시안 불필요)

이 단순함 덕분에 PPO는 **RLHF**의 표준 도구가 되었고, GPT → InstructGPT → ChatGPT 계열의 지시 미세조정에 핵심으로 쓰였다.
:::

::: {.callout-warning}
한계도 분명하다. 지역 최적해에 갇힐 수 있고, 클리핑이 누적되며 새 정책이 결국 이전 정책에서 **너무 멀어질** 가능성이 남는다.
:::

::: {.callout-tip}
## 무선통신 대응 — 피드백 루프의 리미터/경사 클리핑
$r_t$ 를 $[1-\epsilon,1+\epsilon]$ 로 자르는 것은 피드백 루프의 진폭 리미터·경사 클리핑과 같다. 루프 게인이 과도해 발진하지 않도록 출력을 포화시키는 보호 장치이며, 복잡한 안정도 해석 없이도 안정성을 확보하는 실용적 방식이라는 점까지 닮았다.
:::

# 그룹 상대 정책 최적화(GRPO) {#sec-grpo}

## 직접 답: critic 제거 + 그룹 정규화 {#sec-grpo-answer}

PPO에서 advantage 계산(GAE)은 baseline을 위해 별도 **critic(가치망)** 을 학습해야 해 비싸다. GRPO는 critic을 통째로 버리고, advantage를 **그룹 내 보상의 상대 위치**로 대체한다:

$$
\boxed{\;\hat{A}^{\text{GRPO}}_t = \frac{R - \mu_g}{\sigma_g + \delta}\;}
$$

$R$: 해당 출력의 보상, $\mu_g$: 그룹 평균 보상, $\sigma_g$: 그룹 표준편차, $\delta$: 분모가 0이 되지 않게 하는 작은 상수.

## 아이디어 {#sec-grpo-idea}

같은 프롬프트에 대해 여러 출력(그룹/배치)을 만들고, 각 출력의 보상을 **그룹 평균 대비 상대값**으로 정규화해 advantage로 쓴다. 미래 보상의 누적 추정도, critic도 필요 없이 **현재 보상의 그룹 통계**만으로 advantage를 만든다. PPO와 목적함수의 클리핑·(선택적) KL 항은 거의 동일하고, **advantage 정의만 다르다**.

## PPO vs GRPO {#sec-grpo-compare}

| 항목 | PPO | GRPO |
|---|---|---|
| 핵심 구조 | 정책 경사(Actor-Critic) | 정책 경사(**Critic-Free**) |
| Advantage | $\hat A_t = R_t - V(s_t)$ (GAE) | $\hat A_t = \dfrac{R-\mu_g}{\sigma_g+\delta}$ |
| 가치망(critic) | **필요** (별도 $V(s)$ 학습) | **불필요** (그룹 통계로 대체) |
| advantage 초점 | critic 예측 상태가치 대비 행동의 가치 | 현재 배치 평균 결과 $\mu_g$ 대비 결과의 가치 |
| 장점 | 정밀한 가치 추정 → 낮은 분산·안정 | **메모리·계산 효율**(critic 제거) |
| 적합 영역 | 정밀 가치·저분산이 필요한 일반 RL | **대규모 LLM RLHF** (메모리 병목, 희소·이진 보상) |

::: {.callout-note}
advantage가 PPO보다 정밀하진 않지만 계산 효율이 크고, 반복이 진행되면 대개 PPO와 비슷하거나 그 중간 수준으로 수렴한다. **DeepSeek-Math/V3** 등 최신 LLM 학습에서 핵심적으로 쓰였고, 메모리가 병목이고 보상이 희소·이진인 LLM 환경에 잘 맞는다.
:::

::: {.callout-tip}
## 무선통신 대응 — CFAR / AGC 정규화
$\hat A=\dfrac{R-\mu_g}{\sigma_g+\delta}$ 는 레이더의 **CFAR** 검출과 같은 발상이다. 시험 셀의 전력을 주변 셀로 추정한 잡음 통계(평균·표준편차)로 나눠 절대 스케일에 무관한 검출 통계를 만들듯, GRPO는 한 출력의 보상을 그룹의 평균·표준편차로 정규화해 보상 스케일에 둔감한 advantage를 만든다. AGC가 신호 레벨을 그룹 통계로 정규화하는 것과도 같으며, 별도 기준 추정기(critic) 없이 **이웃/배치 통계만으로** 정규화한다는 점이 정확히 대응한다.
:::

# RL 분류 체계 {#sec-taxonomy}

오늘 다룬 알고리즘들이 전체 지도에서 어디에 있는지 정리한다.

```{mermaid}
flowchart TD
    RL["RL 알고리즘"] --> MF["Model-Free<br/>(환경 프록시 없음)"]
    RL --> MB["Model-Based<br/>(환경 프록시 있음)"]
    MF --> PO["Policy Optimization<br/>(정책 최적화)"]
    MF --> QL["Q-Learning"]
    PO --> PG["REINFORCE / PGM"]
    PO --> ACx["A2C / A3C (Actor-Critic)"]
    PO --> TR["TRPO → PPO → GRPO"]
    QL --> DQN["Q-learning / DQN"]
```

| 구분 | 정의 | 예 |
|---|---|---|
| Model-free | 환경 프록시 없이 표본만으로 학습 | REINFORCE, PPO, GRPO, DQN |
| Model-based | 환경 프록시로 시뮬레이션 활용 | (본 노트 범위 밖) |
| On-policy | **현재 정책**이 만든 데이터로 평가·개선 | REINFORCE, **PPO**, GRPO |
| Off-policy | **다른 정책**이 만든 데이터로 평가·개선 | Q-learning, **DQN** |

::: {.callout-note}
오늘의 TRPO·PPO·GRPO는 모두 **Model-free → Policy Optimization → On-policy** 가지에 속한다. 이들이 현대 LLM 정렬(RLHF, PEFT 등)의 기반이 된다.
:::

# 핵심 요약 {#sec-summary}

::: {.callout-important}
## 한 페이지 정리
- **RL = MDP 위에서 기대 누적 보상을 최대화하는 정책 학습.** 4요소: 정책·보상·가치함수·(선택)모델.
- **벨만 방정식**이 현재가치를 다음가치로 잇는 재귀를 주고, 이를 반복하는 것이 **GPI**.
- GPI의 $\arg\max$ 가 미분 불가능·급변이라, 정책을 $\theta$ 로 두고 경사로 갱신하는 **정책 경사 정리**로 전환.
- **REINFORCE**는 그 직접 구현이나 **분산이 큼** → baseline·**advantage**·**Actor-Critic**으로 분산 감소.
- 갱신이 급변하는 불안정 → **TRPO**(KL 제약, 2차·복잡) → **PPO**(클리핑, 1차·단순) → **GRPO**(critic 제거, 그룹 정규화).
- PPO·GRPO는 **RLHF의 핵심**이며, GRPO는 메모리 병목의 **대규모 LLM**에 특히 적합.
:::

핵심 변천을 한 표로:

| 알고리즘 | 핵심 아이디어 | 무엇을 추가/제거 |
|---|---|---|
| REINFORCE | Monte Carlo 정책 경사 | (기준선) — |
| Actor-Critic | baseline=critic으로 분산↓ | **critic 추가** |
| TRPO | KL 제약으로 갱신 폭 통제 | **신뢰 영역 제약 추가** |
| PPO | 클리핑으로 제약 근사 | **2차 KL 계산 제거** |
| GRPO | 그룹 통계로 advantage | **critic 제거** |

## 로그-미분 항등식과 baseline 불편성 {#sec-appendix-score}

```{python}
#| label: score-baseline
import numpy as np
rng = np.random.default_rng(0)

# softmax 정책: pi(a) = softmax(theta)_a, grad_theta log pi(a) = e_a - pi
theta = rng.normal(size=4)
pi = np.exp(theta) / np.exp(theta).sum()
grad_logpi = np.eye(4) - pi[None, :]            # 행 a = grad log pi(a)

# (1) score function 항등식: E_{a~pi}[ grad log pi ] = 0
E_score = (pi[:, None] * grad_logpi).sum(0)
print("E[grad log pi]      :", np.round(E_score, 12))   # ~ 0

# (2) 상수 baseline b 는 경사를 편향시키지 않음: E[ b * grad log pi ] = 0
b = 3.7
print("E[b * grad log pi]  :", np.round((pi[:, None] * b * grad_logpi).sum(0), 12))
```

## Baseline의 분산 감소 효과 {#sec-appendix-var}

```{python}
#| label: variance-reduction
# 반환 G ~ N(5, 2), 행동을 pi에서 샘플 → G*score 대 (G - mean)*score 의 분산 비교
N = 100_000
G = rng.normal(5.0, 2.0, size=N)
a = rng.integers(0, 4, size=N)
score = grad_logpi[a]                            # (N, 4)

est_no = G[:, None] * score                       # baseline 없음
est_bl = (G - G.mean())[:, None] * score          # baseline = 평균

print("trace Var (no baseline):", round(np.cov(est_no.T).trace(), 3))
print("trace Var (w/ baseline):", round(np.cov(est_bl.T).trace(), 3))
# baseline 차감으로 분산이 크게 감소 (약 7배)
```

#| label: grpo-advantage
# 그룹 내 이진 보상 → (R - mu)/(sigma + delta) 로 정규화
R = np.array([0., 1., 1., 0., 1., 0., 0., 1.])
mu, sd = R.mean(), R.std()
A_grpo = (R - mu) / (sd + 1e-8)
print("GRPO advantage:", np.round(A_grpo, 3))
print("mean ~ 0:", round(A_grpo.mean(), 6), "| std ~ 1:", round(A_grpo.std(), 4))

## PPO 클리핑 대리 목적 {#sec-appendix-ppo}

```{python}
#| label: ppo-clip
def ppo_clip(r, A, eps=0.2):
    """L^CLIP = min( r*A , clip(r,1-eps,1+eps)*A )"""
    return np.minimum(r * A, np.clip(r, 1 - eps, 1 + eps) * A)

ratios = np.array([0.5, 0.9, 1.0, 1.1, 1.5])
print("A>0 (좋은 행동) r:", ratios, "-> L:", np.round(ppo_clip(ratios, +1.0), 3))
print("A<0 (나쁜 행동) r:", ratios, "-> L:", np.round(ppo_clip(ratios, -1.0), 3))
# A>0: r가 1+eps=1.2 위로 가면 상한에서 포화 (과한 증폭 차단)
# A<0: r가 1-eps=0.8 아래로 가면 하한에서 포화
```

## 작은 REINFORCE 학습 데모(2상태 밴딧 유사) {#sec-appendix-reinforce}

```{python}
#| label: reinforce-demo
# 단순 2행동 문제: 행동 1의 기대보상이 더 높음 → 정책이 행동 1로 수렴하는지 확인
rng = np.random.default_rng(1)
theta = np.zeros(2)                 # softmax 로짓
alpha = 0.1
true_reward = np.array([0.2, 0.8])  # 행동별 기대 보상

def softmax(z):
    z = z - z.max()
    e = np.exp(z)
    return e / e.sum()

for step in range(2000):
    p = softmax(theta)
    a = rng.choice(2, p=p)                          # 현재 정책에서 행동 샘플
    G = rng.normal(true_reward[a], 0.1)             # 보상(반환) 샘플
    grad_logpi = (np.eye(2)[a] - p)                 # grad log pi(a)
    theta += alpha * G * grad_logpi                 # REINFORCE 갱신

print("최종 정책 분포:", np.round(softmax(theta), 3))  # 행동 1 확률이 1에 근접
```
