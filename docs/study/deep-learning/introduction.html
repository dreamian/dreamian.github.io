2 AI / ML / Deep Learning의 관계

2.1 계층 구조

인공지능 (AI)
 └─ 머신러닝 (Machine Learning)
      └─ 딥러닝 (Deep Learning)  ← 이 강의의 주제

Goodfellow 교재 Fig 1.4에 따르면, 딥러닝은 표현 학습(Representation Learning) 의 한 종류이고, 표현 학습은 머신러닝의 한 종류이며, 머신러닝은 AI에 접근하는 여러 방법 중 하나이다. 지식 기반 시스템(Knowledge Base) 같은 비ML 방식도 AI에 포함된다.

2.2 머신러닝의 핵심 아이디어

전통적 프로그래밍과 머신러닝의 구조적 차이:

패러다임 입력 출력
전통 프로그래밍 Data + Program Output
머신러닝 Data + Output(레이블) Program(모델)

수학적으로, 데이터 쌍 \(\{(x_i, y_i)\}_{i=1}^N\)으로부터 미지의 입력 \(x^*\)에 대해 \(y^*\)를 예측하는 함수 \(f\)를 찾는 것이다.

\[f: \mathcal{X} \to \mathcal{Y}\]

2.3 ML 문제의 두 가지 분류 축

\[\text{Classification of ML problems} \neq \text{Categorization of ML problems}\]

두 용어가 모두 “분류”로 번역되어 혼동될 수 있으나, 기준 축이 다르다.

2.3.1 Classification of ML problems — 출력 유형 기준

“모델이 무엇을 예측하는가?”라는 질문에 따른 분류이다.

태스크 출력 주요 학습 방식
Classification 이산 레이블 \(y \in \{1,\ldots,K\}\) Usually supervised
Regression 연속값 \(y \in \mathbb{R}\) Usually supervised
Similarity 유사/비유사 쌍 Usually supervised
Clustering 군집 구조 Usually unsupervised
Embedding 벡터 \(z \in \mathbb{R}^d\) Usually unsupervised
Reinforcement Learning 행동 정책 \(\pi\) RL

2.3.2 Categorization of ML problems — 학습 방식 기준

“모델이 어떻게 학습하는가?”라는 질문에 따른 분류이다.

방식 레이블 사용 특징
Supervised 전부 사용 정확, 레이블 비용 高
Unsupervised 없음 저렴, 구조 발견
Semi-supervised 일부 사용 실용적 절충
Active learning 선택적 사용 효율적 레이블링
Reinforcement 간접적 사용 에이전트 행동 최적화
Important핵심 구분

두 분류는 독립된 두 축이다. 같은 Classification 태스크라도 supervised / unsupervised / semi-supervised 모두로 학습할 수 있다. 또한 “Classification of ML problems”에서 “Classification”은 메타 레벨의 분류 행위를 의미하고, 그 결과물 중 하나가 “Classification 태스크”이므로 동어 반복처럼 보이는 순환 구조가 있다.

3 핵심 개념: Embedding, Manifold, Latent Space, Epoch

딥러닝의 핵심 개념 네 가지이다. 이 개념들은 독립적이지 않고 아래와 같이 연결된다.

고차원 Raw Data  →  Embedding  →  Manifold 위의 구조 발견
                                          ↓
                                  Latent Space (저차원 표현)
                                          ↓
                              Epoch 반복으로 점점 정교해짐

3.1 Embedding (임베딩)

3.1.1 수학적 정의

“Object \(X\)가 \(Y\)에 embedding될 때, embedding은 단사(injective) 이고 구조 보존(structure-preserving) 인 함수 \(f: X \to Y\)로 주어진다.”

딥러닝에서는 다음과 같이 구체화한다.

\[f_\theta: \mathbb{R}^D \to \mathbb{R}^d, \quad d \ll D\]

두 가지 조건이 중요하다.

① Injective (단사):

\[x_1 \neq x_2 \implies f(x_1) \neq f(x_2)\]

정보의 구분 가능성(discriminability)이 보존된다.

② Structure-preserving (구조 보존):

\[d_{\text{원공간}}(x_1, x_2) \approx d_{\text{임베딩}}(f(x_1), f(x_2))\]

원래 공간의 관계가 임베딩 공간에서도 유지된다. 대표적인 예로 Word2Vec의 관계 보존이 있다.

\[\vec{\text{king}} - \vec{\text{man}} + \vec{\text{woman}} \approx \vec{\text{queen}}\]

3.1.2 임베딩의 종류

종류 입력 임베딩 공간 예시
Word Embedding \(\mathbb{R}^{|V|}\) (one-hot) \(\mathbb{R}^{300}\) Word2Vec
Image Embedding \(\mathbb{R}^{H \times W \times 3}\) \(\mathbb{R}^{512}\) CNN feature
Neural Network 입력층 각 은닉층 모든 딥러닝
Tip무선네트워크 관점

CSI(Channel State Information) 피드백에서 고차원 채널 행렬 \(\mathbf{H} \in \mathbb{C}^{N_r \times N_t}\)를 저차원 코드워드로 압축하는 것이 정확히 임베딩이다. CsiNet 같은 딥러닝 기반 CSI 압축이 이 원리를 활용한다.

3.2 Manifold (매니폴드)

3.2.1 수학적 정의

“수학에서 \(n\)-차원 매니폴드는 각 점의 근방이 \(n\)-차원 유클리드 공간 \(\mathbb{R}^n\)과 위상동형(homeomorphic) 인 위상 공간이다.”

쉽게 말하면, 어느 한 점을 충분히 가까이서 보면(locally), 평평한 유클리드 공간처럼 보이는 공간이다.

슬라이드의 지구 위에 서있는 사람 이미지가 이 직관을 잘 전달한다. 지구는 3차원 공간에 존재하는 구이지만, 그 표면은 2차원이다. 위도/경도 2개의 좌표만으로 지구 표면의 위치를 완전히 기술할 수 있다.

전체적으로(Globally):  구부러진 표면  (지구)
가까이서(Locally):     평평한 평면  (내 발 앞 땅)

3.2.2 Manifold Hypothesis

딥러닝이 작동하는 이론적 근거 중 하나이다.

실제 데이터는 고차원 공간에 균등하게 분포하는 것이 아니라, 훨씬 낮은 차원의 매니폴드 위에 집중되어 있다.

수학적으로:

\[p_{\text{data}}(x) \text{ is concentrated near a manifold } \mathcal{M} \subset \mathbb{R}^D\]

\[\dim(\mathcal{M}) = d \ll D\]

예시: 28×28 = 784차원 이미지 공간에서 “자연스러운 손글씨 이미지”는 이 784차원 공간의 극히 일부(저차원 매니폴드)에만 존재한다.

3.2.3 차원의 저주와의 관계

Goodfellow Ch. 5.11에서 다루는 차원의 저주(Curse of Dimensionality) 가 매니폴드 가설로 극복된다.

입력 차원 \(d\), 각 축에서 \(v\)개의 값을 구분한다면 필요한 영역의 수는 \(O(v^d)\)로 차원에 지수적으로 증가한다. 딥러닝은 Manifold Hypothesis를 활용하여 실제 데이터가 고차원 공간 안의 저차원 매니폴드 위에 집중되어 있다는 사실을 학습한다.

Autoencoder는 이 매니폴드를 학습하는 대표적 모델이다.

\[\text{Encoder: } \mathbb{R}^D \xrightarrow{f_\phi} \mathbb{R}^d, \quad \text{Decoder: } \mathbb{R}^d \xrightarrow{g_\theta} \mathbb{R}^D\]

\[\min_{\phi, \theta} \mathbb{E}_{x \sim p_{\text{data}}} \|x - g_\theta(f_\phi(x))\|^2\]

3.3 Latent Space (잠재 공간)

3.3.1 직관

인형사가 몇 개의 실만으로 인형의 복잡한 움직임 전체를 제어한다. 보이는 것(인형 움직임, 고차원)은 보이지 않는 것(실의 당김, 저차원)에 의해 결정된다. 보이지 않는 실들의 공간이 바로 Latent Space이다.

3.3.2 수학적 정의

\[\underbrace{x}_{\text{관측 가능}} = g(\underbrace{z}_{\text{잠재 변수}}) + \epsilon\]

\(z \in \mathbb{R}^d\)는 데이터를 생성하는 숨겨진 원인들이고, \(g: \mathbb{R}^d \to \mathbb{R}^D\)는 이를 관측 가능한 형태로 변환한다.

3.3.3 Subspace vs Latent Space

Subspace Latent Space
기원 선형대수학 확률론 / 생성 모델
구조 선형 비선형도 허용
예시 PCA의 주성분 공간 VAE의 \(z\) 공간

PCA (선형 서브스페이스):

\[z = W^\top x, \quad W \in \mathbb{R}^{D \times d} \text{ (직교 기저)}\]

VAE (비선형 잠재 공간):

\[q_\phi(z \mid x) \approx \mathcal{N}(\mu_\phi(x),\, \sigma^2_\phi(x))\]

잘 학습된 Latent Space에서 두 점 \(z_1\), \(z_2\) 사이를 선형 보간하면 의미 있는 중간 데이터가 생성된다(continuity).

3.4 Epoch (에폭)

3.4.1 정의

지질 시대 층위 그림이 직관을 준다. 각 지질 시대가 명확한 시작과 끝이 있는 완결된 시간 단위이듯, 훈련 Epoch도 전체 데이터셋을 한 번 완전히 통과하는 완결된 단위이다.

용어 정의
\(N\) 전체 훈련 데이터 수
\(b\) 배치 크기
Iteration 1번의 파라미터 업데이트
Epoch \(\lceil N/b \rceil\)번 Iteration = 전체 데이터 1회 순환

SGD 업데이트 규칙:

\[\theta \leftarrow \theta - \eta \cdot \nabla_\theta \mathcal{L}(\theta;\, B_t)\]

1 Epoch = 위 업데이트를 \(N/b\)번 수행하는 것이다.

3.4.2 Epoch 수와 학습 상태

너무 적은 Epoch  →  Underfitting  (학습 부족)
적당한 Epoch    →  Generalization (목표 상태)
너무 많은 Epoch  →  Overfitting   (훈련 데이터 암기)
                          ↑
                   Early Stopping으로 방지

4 데이터 분할: Train / Validation / Test

4.1 세 집합의 역할

전체 데이터셋
  ├── Training Set    →  파라미터 θ 학습 (역전파)
  ├── Validation Set  →  하이퍼파라미터 λ 튜닝
  └── Test Set        →  최종 성능 단 한 번 측정

4.2 파라미터 vs 하이퍼파라미터

구분 정의 예시 최적화 방법
Parameter 데이터로부터 학습 가중치 \(W\), 편향 \(b\) Gradient Descent
Hyperparameter 학습 알고리즘 제어 학습률 \(\eta\), 레이어 수 Validation Set으로 탐색

4.3 왜 Validation Set이 필요한가?

Goodfellow Ch. 5.3에서 핵심을 명시한다. 모델의 용량(capacity)을 제어하는 하이퍼파라미터를 훈련 데이터로 학습하면, 알고리즘은 항상 최대 가능 용량을 선택하게 되고 이는 과적합(Overfitting)으로 직결된다.

\[\lambda^* = \arg\min_{\lambda \in \Lambda}\, \mathcal{L}_{\text{val}}\bigl(\theta^*(\lambda)\bigr)\]

WarningTest Set 오염 금지

Validation을 통한 하이퍼파라미터 튜닝 과정에서 Test Set을 반복적으로 보면, Test Set이 사실상 두 번째 Validation Set이 되어버린다. 최종 성능 추정치가 낙관적으로 편향(optimistic bias)된다. “It’s a crime!” — 강의 슬라이드

4.4 하이퍼파라미터 자동화: HPO

Validation Set을 통한 하이퍼파라미터 튜닝은 완전히 자동화 가능하며, 실제로 대부분의 현대 ML 파이프라인에서 자동화되어 있다.

방법 원리 특징
Grid Search 격자 탐색 조합 폭발 문제
Random Search 무작위 샘플링 Grid보다 효율적 (Bergstra & Bengio, 2012)
Bayesian Optimization Surrogate model + EI 현재 가장 널리 사용
Gradient-based (DARTS) Implicit differentiation 아키텍처 탐색에 사용

Bayesian Optimization의 핵심:

\[\lambda_{\text{next}} = \arg\max_\lambda \text{EI}(\lambda), \quad \text{EI}(\lambda) = \mathbb{E}\!\left[\max(0,\, f(\lambda) - f(\lambda^+))\right]\]

4.4.1 K-Fold Cross-Validation

데이터가 부족할 때 사용하는 방법이다.

\[E_{\text{CV}} = \frac{1}{K} \sum_{k=1}^K E_k\]

데이터를 \(K\)등분하여 매번 1개는 validation, 나머지 \(K-1\)개는 training으로 사용한다.

5 Generalization과 LLM

5.1 머신러닝의 궁극적 목표

훈련 데이터로부터 학습하여, 한 번도 본 적 없는 입력에 대해 올바른 출력을 예측하는 능력

\[\text{목표: } E_{\text{train}} \approx E_{\text{test}}\]

“모든 것을 암기하지만 추론 못하는 학생”보다 “조금 암기하지만 많이 추론하는 학생”이 더 현명하다.

5.2 LLM은 Generalization을 달성했는가?

결론: 부분적으로 Yes, 하지만 기존 이론으로는 설명이 불완전하다.

5.2.1 고전 이론과의 충돌

통계학습 이론의 일반화 오차 bound:

\[E_{\text{test}} \leq E_{\text{train}} + O\!\left(\sqrt{\frac{\text{model complexity}}{N}}\right)\]

이에 따르면 모델이 클수록 일반화가 나빠져야 한다. 그러나 GPT-4(수천억 파라미터)는 뛰어난 일반화를 보인다. → Double Descent 현상

5.2.2 LLM의 한계

한계 설명
Hallucination 훈련 분포 밖에서 틀린 정보를 자신 있게 생성
Distribution Shift 훈련 시점 이후 정보에 적응 불가
Reasoning 한계 복잡한 수학적 추론에서 체계적 실패
Shortcut Learning 진짜 개념이 아닌 통계적 패턴 학습

6 ML vs Deep Learning

6.1 핵심 차이: Feature Engineering

전통적 ML 딥러닝
특징 추출 인간이 직접 설계 데이터로부터 자동 학습

6.2 딥러닝의 계층적 표현 학습

Goodfellow Ch. 1에 따르면, 딥러닝은 단순한 표현들의 조합으로 복잡한 표현을 구성한다.

\[\text{Raw Data} \xrightarrow{\text{Layer 1: edges}} \xrightarrow{\text{Layer 2: contours}} \xrightarrow{\text{Layer 3: parts}} \xrightarrow{\text{Layer 4: objects}} \text{Output}\]

NoteRepresentation Learning (표현 학습)

전통적 ML은 인간이 직접 feature를 설계(hand-crafted feature)한다.

\[\text{Raw Data} \xrightarrow{\text{인간이 설계}} \text{벡터} \xrightarrow{\text{ML}} \text{출력}\]

딥러닝은 이 과정을 데이터로부터 자동으로 학습한다.

\[\text{Raw Data} \xrightarrow{\text{Layer 1}} \xrightarrow{\text{Layer 2}} \cdots \xrightarrow{\text{Layer }L} \text{출력}\]

6.3 전통적 ML이 실패하는 이유: Local Smoothness 가정

Goodfellow Ch. 5.11에 따르면, 전통적 ML은 국소 평활성(Local Smoothness) 가정에 의존한다. 새로운 입력의 출력을 가장 가까운 훈련 포인트의 출력으로 추정하는 것이다.

고차원 공간에서는 “가까운” 훈련 데이터가 충분히 존재하지 않아(차원의 저주) 이 가정이 깨진다. 딥러닝은 계층적 표현 학습으로 이를 극복한다.

7 Double Descent

7.1 고전 이론: Bias-Variance Tradeoff

Goodfellow Ch. 5.4에서 다루는 핵심 공식:

\[\text{MSE}(\hat{\theta}) = \text{Bias}(\hat{\theta})^2 + \text{Var}(\hat{\theta})\]

모델 복잡도(capacity)가 증가할 때 Bias는 감소하고 Variance는 증가하여, Test Error는 U자 곡선을 그린다고 고전 이론은 예측한다.

7.2 Double Descent의 발견

2019년 Belkin et al.이 발표한 현상. 모델을 훈련 데이터를 완벽히 맞출 수 있는 수준(Interpolation Threshold)을 넘어서까지 키우면 Test Error가 다시 감소한다.

Test Error
  │╲
  │ ╲                    ← Double Descent
  │  ╲      /╲          /
  │   ╲    /  ╲        /  (두 번째 감소)
  │    ╲  /    ╲______/
  │     \/
  │  Classical  Modern
  │  Optimal    Optimal
  └────┬──────────────── 모델 복잡도 N
       ↑
  Interpolation Threshold
  (Train Error → 0이 되는 지점)

7.3 세 개의 Regime

Regime 조건 특성
① Classical \(N_{\text{params}} \ll N_{\text{data}}\) Bias 지배, 전통적 U자 곡선
② Critical \(N_{\text{params}} \approx N_{\text{data}}\) Test Error 최대 (위험 구간)
③ Modern \(N_{\text{params}} \gg N_{\text{data}}\) Train Error = 0, Test Error 재감소

7.4 Modern Regime에서 일반화가 되는 이유

7.4.1 Implicit Regularization of SGD

SGD는 훈련 데이터를 만족하는 무한히 많은 해 중에서 최소 놈(minimum norm) 해를 암묵적으로 선호한다.

선형 모델에서 훈련 데이터를 만족하는 해의 집합:

\[\{\theta : X\theta = y\}\]

SGD(Gradient Flow)는 이 집합 중 \(\|\theta\|_2\)가 최소인 해, 즉 Moore-Penrose pseudoinverse 해로 수렴하는 경향이 있다.

\[\theta^* = X^\top(XX^\top)^{-1}y\]

7.4.2 부드러운 보간 (Smooth Interpolation)

파라미터가 훨씬 많으면 훈련 포인트들 사이를 부드럽게 통과하는 함수를 찾을 수 있다. Critical Zone에서는 함수가 날카롭게 구부러져야 하지만, Modern Regime에서는 여유 자유도가 부드러운 해를 유도한다.

NoteEpoch-wise Double Descent

같은 모델을 오래 훈련할수록 나타나는 현상도 있다. 초기에는 유용한 패턴을 학습(1차 하강), 이후 노이즈를 암기(상승), 충분히 오래 훈련하면 다시 의미 있는 패턴으로 수렴(2차 하강). Early Stopping이 항상 최선이 아닌 이유이기도 하다.

Tip무선네트워크 관점

이는 채널 추정에서 훈련된 모델이 SNR 범위를 벗어나면 성능이 급격히 떨어지는 distribution shift 문제와 같은 맥락이다. 또한 Compressed Sensing에서 \(M < N\)인 underdetermined system을 \(\ell_1\) norm 최소화로 sparse한 해를 찾는 것처럼, SGD도 암묵적 sparsity를 유도한다.

8 AGI와 ASI

8.1 AI의 세 수준

수준 정의 현재 상태
ANI (Narrow AI) 특정 태스크에서만 뛰어남 ✅ 실재 (GPT-5, AlphaGo 등)
AGI (General AI) 인간 수준의 범용 지능 ❌ 아직 미달성
ASI (Super AI) 인간을 모든 면에서 초월 ❌ 이론적 개념 
지능 수준 축
────────────────────────────────────────────────►
      ANI                AGI               ASI
 [현재 우리 위치]      [미달성]           [이론적]
  특정 태스크만         인간 수준의        인간을 모든
  잘 하는 AI           범용 지능          면에서 초월

8.2 AGI의 핵심 특성

① 도메인 전이 학습: 서로 다른 분포 \(p_1(x,y)\), \(p_2(x,y)\) 간 표현 공유

\[f_{\text{AGI}}: \mathcal{X}_{\text{any}} \to \mathcal{Y}_{\text{any}}\]

② 자율적 목표 설정: 스스로 하위 목표를 정의하고 추구

③ Few-shot / Zero-shot 일반화: 본 적 없는 태스크를 몇 가지 예시만으로 수행

④ 지속적 학습: Catastrophic Forgetting 없이 새 지식 습득

⑤ 메타인지: “내가 무엇을 모르는지” 인식

8.3 ASI와 Intelligence Explosion

ASI의 핵심 시나리오는 재귀적 자기개선(Recursive Self-improvement) 이다.

AGI 달성
    ↓
AI가 자기 자신을 개선하는 코드 작성
    ↓
더 똑똑해진 AI가 또 자기 자신을 개선
    ↓  (기하급수적 폭발)
인간의 이해를 완전히 초월한 수준

지능 향상 속도가 현재 지능에 비례하면:

\[\frac{dI}{dt} \propto I(t) \implies I(t) = I_0 e^{\alpha t}\]

이를 Intelligence Singularity 또는 기술적 특이점이라 부른다.

8.4 AGI vs ASI 핵심 비교

AGI ASI
기준선 인간과 동등 (Human-level) 인간을 압도적으로 초월
자기개선 제한적 재귀적 자기개선 가능
현재 상태 미달성 순전히 이론적
핵심 위험 통제 문제 존재론적 위험
Important현재 LLM의 위치

GPT-5, Claude 등 현재 LLM은 모두 ANI이다. 다만 ANI들 중에서 가장 넓은 범위의 태스크를 커버하는 것이다. 2026년 기준, 어떤 시스템도 진정한 AGI를 달성하지 못했다.

10 핵심 정리

  • 딥러닝은 깊은 신경망을 사용하는 머신러닝 방법론이다.
  • ML의 궁극적 목표는 Generalization — 새로운 데이터에 대한 예측 능력이다.
  • 데이터는 Train / Validation / Test로 분리하며, 각 역할이 엄격히 구분된다.
  • 하이퍼파라미터 튜닝은 Validation Set을 통해 자동화 가능하다.
  • Double Descent는 고전 Bias-Variance 이론을 넘어서는 현대적 현상이다.
  • 현재 AI는 모두 ANI이며, AGI/ASI는 아직 달성되지 않았다.
