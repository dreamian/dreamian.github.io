1 오늘의 큰 그림

오늘 다루는 내용은 크게 두 축으로 나뉜다.

  1. 멀티모달(Multimodal) 학습 — 서로 다른 형태(modality)의 데이터(이미지·텍스트·오디오 등)를 하나의 시스템에서 다루는 방법론. Transformer의 효율적 대안(Mamba)을 짧게 짚은 뒤, 멀티모달의 5대 핵심 과제와 대표 기법인 CLIP/SigLIP을 본다.
  2. 생성 모델(Generative model) I — 데이터의 분포 p(X) 자체를 학습하려는 모델. 오토인코더(AE)에서 출발해, VAE(변분 추론 + ELBO + reparameterization)와 GAN(minimax 게임)을 다룬다.

두 축을 관통하는 한 문장: “고차원 데이터를 저차원 잠재 표현(latent representation)으로 압축하고, 그 잠재 공간을 우리가 통제 가능한 분포로 만들면, 표현·정렬·융합·생성이 모두 쉬워진다.”

힌트무선통신 전공자를 위한 한 줄 매핑
  • 잠재 표현 = 소스 코딩(source coding) 의 압축 표현
  • 잠재 분포를 \mathcal N(0,I)로 강제 = 가우시안 코드북(codebook) 설계
  • 대조 학습(CLIP) = 정합 필터(matched filter) / 상관 검출
  • GAN의 minimax = 재머(jammer)가 존재하는 2인 영합 게임(zero-sum game) 에서의 worst-case 강건 설계

2 Transformer의 한계와 효율적 대안: Mamba

2.1 Transformer의 두 가지 한계

Self-attention은 강력하지만 두 가지 구조적 약점이 있다.

  1. 윈도우(window) 밖 문맥을 인코딩하기 어렵다. 어텐션은 정해진 컨텍스트 길이 안에서만 직접 상호작용한다.
  2. 계산 복잡도가 O(n^2) 이다(n은 시퀀스/윈도우 길이). 길이가 길어지면 메모리·연산이 제곱으로 폭증한다.

이를 줄이려는 연구가 “Efficient Transformers”라는 큰 흐름을 이룬다(Tay et al., 2022).

2.2 Mamba: 선택적 상태공간 모델 (S6)

Mamba(Gu & Dao, 2023)는 시퀀스를 상태공간 모델(State Space Model, SSM) 로 보고 선형 시간에 처리한다. 핵심 아이디어는 두 가지다.

  1. Selective mechanism (S6) — 작은 윈도우를 유지하되, 그 안에서 관련 있는 토큰만 선택적으로 남긴다. 관련도(relevance)를 측정하는 방식이 RNN의 게이팅(gating) 과 유사하다.
  2. Hardware-aware parallel scan — 순차적 재귀를 GPU에서 병렬 스캔으로 계산해 속도를 확보한다.
특징 Transformer Mamba
복잡도 O(n^2) O(n) (선형)
장점 강한 문맥 인코딩(장거리 의존성) 계산 효율, 긴 윈도우(256k+)
약점 연산 비용 표현력은 Transformer를 넘지 못함 [Chen et al., 2025]
노트하이브리드가 대세
  • Jamba: Transformer + Mamba를 Mixture-of-Experts(MoE) 형태로 혼합.
  • MambaVision: 초기 층은 Mamba(효율), 후기 층은 self-attention(장거리 의존성).
  • TransMamba: 층/토큰 단위로 둘 중 하나를 선택.

회로 복잡도(circuit complexity) 관점에서 Mamba가 Transformer보다 표현력이 더 좋지는 않다. 즉 Mamba는 “더 똑똑한” 모델이 아니라 “더 싼” 모델이다.

힌트무선통신 관점

선택적 SSM은 본질적으로 재귀적 상태 추정기다. 상태 h_t = A h_{t-1} + B x_t, 출력 y_t = C h_t 형태는 칼만 필터(Kalman filter) / 선형 동적 시스템과 같은 골격이다. 게이팅으로 과거를 얼마나 잊을지 정하는 것은 RLS(Recursive Least Squares)의 forgetting factor \lambda를 적응적으로 조절하는 것과 직접 대응된다.

3 멀티모달 학습의 5대 핵심 과제

Modality(양태) = “mode”, 즉 데이터가 들어오는 형식(시각·청각·언어 등). 멀티모달 = 여러 양태를 함께 다루는 인식.

딥러닝 시대(2010~)의 멀티모달 ML은 다음 5개 과제로 정리된다 (Baltrušaitis, Ahuja & Morency, TPAMI 2019).

3.1 과제 1 — 표현 (Representation)

정의: 멀티모달 데이터를, 양태 간 상보성(complementarity) 과 중복성(redundancy) 을 활용하도록 요약·표현하는 법.

표현 학습은 두 갈래로 나뉜다.

방식 설명 난이도 남는 과제
Joint representation (공동 표현) 모든 양태를 하나의 공간에 임베딩 학습이 어려움 (없음 — 일단 학습되면 이후가 편함)
Coordinated representation (조율 표현) 양태별 별도 공간을 학습 후 정렬 상대적으로 쉬움 두 공간을 어떻게 정렬할지

핵심 통찰: 조율 표현이 보통 더 쉽다. 공동 표현은 어려운 문제를 한 번에 풀려 하고, 조율 표현은 어려움을 “정렬(alignment) 단계”로 미루기 때문이다.

3.1.1 멀티모달 벡터 산술 (Vector arithmetic)

잘 학습된 공동 임베딩 공간에서는 의미가 벡터 연산으로 나타난다.

\text{vec}(\text{이미지: 파란 책}) - \text{vec}(\text{파랑}) + \text{vec}(\text{빨강}) \approx \text{vec}(\text{빨간 책})

비행기 이미지에서 “하늘”을 빼고 “바다”를 더하면 가장 가까운 이웃이 배(boat) 이미지가 된다. 의미적으로 유사한 데이터가 공간상 가까운 영역에 모여 있기 때문이다. (Word2Vec의 king - man + woman ≈ queen의 멀티모달 버전.)

3.2 과제 2 — 정렬 (Alignment)

정의: 두 개 이상의 양태에서 (하위)요소들 사이의 직접적 대응관계를 찾는 것.

종류 설명
Explicit alignment 한 양태의 요소를 다른 양태의 요소에 1:1로 직접 매핑
Implicit alignment 명시적 대응을 만들지 않고, 매핑을 수행하는 학습된 함수에 맡김
경고

여기서의 alignment는 LLM의 alignment(인간 가치 정렬) 와 전혀 다른 개념이다. 혼동 주의.

3.3 과제 3 — 융합 (Fusion)

정의: 예측을 위해 두 개 이상 양태의 정보를 합치는 것. (AI의 본질은 결국 무언가를 예측하는 것이므로, 여러 입력을 하나로 모아 예측해야 한다.)

  • Early fusion: 모델에 넣기 전에 합친다. 가장 간단한 방법은 두 특징 벡터를 concatenate.
  • Late fusion: 양태별로 각자의 모델을 통과시킨 뒤, 출력 단에서 합친다.
  • Model-based(중간) fusion: 모델 내부에서 융합되도록 설계(신경망, 그래프 모델 등). End-to-end로 학습.

3.4 과제 4 — 변환 (Translation)

정의: 데이터를 한 양태에서 다른 양태로 바꾸는 것. 대응관계가 종종 open-ended/주관적이다.

  • 이미지 → 텍스트: Captioning(캡션 생성)
  • 텍스트 → 이미지: Image generation
  • 텍스트 → 비디오: Video generation
종류 설명 예시/한계
Example-based 양태 간 데이터 매핑을 예시로 직접 구축 사전식 1:1 매핑. 언어 번역(영↔︎불)처럼 어순·의미가 비슷하면 잘 됨. 영↔︎중처럼 단어가 1:1로 안 맞으면 어려움
Model-driven 매핑 예시들로 변환 모델을 학습 후 사용 현대 번역기 대부분. 주로 신경망 사용

3.5 과제 5 — 공동학습 (Co-Learning)

정의: 양태 간에 지식(표현·예측력)을 전이하는 학습 프레임워크.

오늘날의 현실: 위 4개 과제는 사실상 모두 하나의 거대한 신경망으로 흡수되었다. “표현/정렬/융합/변환을 따로 고민하지 말고, 모델을 충분히 키워라(scale up)”가 현재의 주류 패러다임이다.

중요효율성이 곧 경쟁력

하지만 scaling은 돈·전력 측면에서 매우 비싸다. 더 적은 데이터·전력으로 지식을 더 잘 전이하는 효율적 방법을 찾으면, 작은 기술로 거대 테크 기업을 이길 수 있는 큰 함의가 생긴다. (연구 방향으로서의 메시지.)

힌트무선통신 관점

융합(fusion)은 다이버시티 결합(diversity combining) 과 정확히 대응한다.

  • Early fusion (concatenate) ↔︎ 안테나 신호를 합치기 전에 결합 → MRC(Maximal-Ratio Combining) 처럼 raw 신호 단에서 결합
  • Late fusion ↔︎ 각 안테나에서 독립 검출 후 결합 → selection / soft combining

서로 다른 양태가 가진 상보성·중복성은 곧 공간 다이버시티(spatial diversity) 의 상보성·중복성이다.

4 텍스트–비전 공동 임베딩: CLIP과 SigLIP

4.1 CLIP (OpenAI, 2021)

CLIP(Contrastive Language–Image Pre-training)은 가장 널리 쓰이는 멀티모달 공동 임베딩 기법이다.

  • 이미지 인코더(ViT/CNN)와 텍스트 인코더(Transformer)가 각각 임베딩을 만든다.
  • 대조 학습(contrastive learning) 으로 “맞는 (이미지, 텍스트) 쌍”의 임베딩은 가깝게, “틀린 쌍”은 멀게 만든다.
  • 결과적으로 zero-shot 분류(태스크별 fine-tuning 없이 분류)가 가능해진다.

4.1.1 대조 사전학습(Contrastive pre-training)의 메커니즘

미니배치 N개의 (이미지, 텍스트) 쌍에서 모든 쌍의 내적(유사도) 행렬을 만든다. 대각선(I_i\cdot T_i)이 정답(positive), 나머지가 오답(negative)이다.

이미지 임베딩 I_i, 텍스트 임베딩 T_j (L2 정규화됨), 온도 \tau에 대해 로짓 \ell_{ij} = I_i^\top T_j / \tau. 손실은 행 방향(이미지→텍스트)과 열 방향(텍스트→이미지) 교차 엔트로피의 평균이다.

\mathcal{L}_{\text{CLIP}} = \frac{1}{2N}\sum_{i=1}^{N} \Bigg[ \underbrace{-\log\frac{e^{\ell_{ii}}}{\sum_{j} e^{\ell_{ij}}}}_{\text{이미지}\to\text{텍스트}} \;+\; \underbrace{-\log\frac{e^{\ell_{ii}}}{\sum_{j} e^{\ell_{ji}}}}_{\text{텍스트}\to\text{이미지}} \Bigg]

핵심: softmax가 미니배치 전체에 대해 걸린다. 즉 한 이미지에 대해 “배치 안 모든 텍스트 중 정답 고르기”라는 N지선다 분류 문제다.

4.2 SigLIP (Google DeepMind, 2021)

CLIP의 softmax는 배치 전체의 정규화가 필요해 메모리/통신 비용이 크다. SigLIP은 이를 각 쌍마다 독립적인 sigmoid(이진 분류) 로 바꾼다.

y_{ij} = +1 (정답 쌍, i=j) / -1 (오답 쌍), 스케일 t, 바이어스 b에 대해:

\mathcal{L}_{\text{SigLIP}} = -\frac{1}{N}\sum_{i=1}^{N}\sum_{j=1}^{N} \log \sigma\!\big(y_{ij}\,(t\, I_i^\top T_j + b)\big), \qquad \sigma(u)=\frac{1}{1+e^{-u}}

각 쌍이 독립적인 이진 결정이라 배치 전체 정규화가 필요 없다 → 병렬화·메모리 효율↑, 큰 배치로 확장 용이.

랜덤 벡터를 CLIP 임베딩에 매핑하고 그 임베딩을 확산 모델의 조건으로 주면, 텍스트로부터 이미지/비디오를 생성할 수 있다. DALL·E 3, Make-A-Video, Phenaki, Sora, Runway Gen-4.5가 이 계열의 멀티모달 생성 모델이다.

힌트무선통신 관점 — 대조 학습 = 검출 이론

CLIP의 softmax-over-batch는 코드북에서의 ML 검출(Maximum-Likelihood detection) 과 같다. 수신 신호(이미지 임베딩)와 가장 상관이 높은 코드워드(정답 텍스트)를 N개 후보 중에서 고른다 — 이것이 바로 정합 필터 뱅크(matched-filter bank) + argmax.

SigLIP의 sigmoid-per-pair는 각 쌍에 대한 개별 이진 가설검정(에너지/상관 검출) 이다. 즉, - CLIP = 결합 ML 검출 (전역 정규화 필요, 최적이지만 비쌈) - SigLIP = 쌍별 독립 검출 (분리 가능, 확장성 우수)

내적 I_i^\top T_j가 곧 상관(correlation) 이고, \tau/온도는 검출 임계의 sharpness를 조절하는 SNR 스케일과 같다.

5 생성 모델 개요 & 오토인코더 복습

5.1 오토인코더(Autoencoder, AE)

AE의 목표: 입력 x를 모델에 넣어 자기 자신을 복원(reconstruct) 하기.

경고“그냥 복사하면 되지 않나?” 라는 함정

입력을 그대로 출력하면 복원 오차 0짜리 완벽한 해다. 그런데 왜 굳이 인코더–디코더를 쓰는가?

답: 잠재 표현 z의 차원이 입력보다 작기 때문이다. (입력 7차원 → 잠재 4차원 같은 식.) 좁은 통로로 정보를 통과시키며 노이즈는 버리고 핵심 정보만 남겨야 복원이 가능하다. 이 강제된 좁은 통로가 바로 정보 병목(information bottleneck) 이다.

  • Encoder: 입력에서 핵심 정보를 추출(압축).
  • Decoder: 핵심 정보로부터 입력을 재생성.
  • 더 깊게 쌓으면(deep AE) 더 정교한 정보를 단계적으로 압축/복원할 수 있다.
힌트무선통신 관점 — 정보 병목 = 율-왜곡(Rate–Distortion)

정보 병목은 손실 압축(lossy source coding) 그 자체다. 잠재 차원 = 비트율(rate) R, 복원 오차 = 왜곡(distortion) D. AE는 주어진 율 예산 안에서 왜곡을 최소화하는 율-왜곡 최적화 문제를 신경망으로 푼다. 잠재 차원이라는 “노브(knob)”가 적을수록 잠재 공간을 더 정밀하게 통제할 수 있다.

5.2 왜 지금 AE가 중요한가: LeCun의 케이크 비유

Yann LeCun(Meta FAIR, NYU)은 학습 시 기계가 받는 정보량을 케이크에 빗댔다.

6 VAE (Variational Auto-Encoder)

오늘의 메인. AE에 “잠재 공간이 가우시안 분포를 따라야 한다”는 추가 제약을 거는 것이 VAE다.

6.1 한 줄 요약

VAE = AE + “잠재 표현 z가 \mathcal N(0,I)를 따르도록 강제하는 정규화”. 이로써 잠재 공간을 완전히 통제할 수 있고(→ 매끄러운 생성·보간), 직접 계산 불가능한 p(x)를 변분 추론(variational inference) 으로 우회해 학습한다.

6.2 생성 모델로서의 목표

데이터 X=\{x_1,\dots,x_n\}이 주어졌을 때, 이를 설명하는 분포 p(X)를 찾고 싶다. 그런데 p(X)를 직접 모델링하기는 어렵다. 그래서 잠재 변수 z를 도입한다.

p(x) = \sum_{z} p(x\mid z)\,p(z) \quad\xrightarrow{\text{연속}}\quad p(x) = \int p(x\mid z)\,p(z)\,dz

여기서 사전분포(prior) p(z)=\mathcal N(0,I)로 고정한다. 해석: “먼저 z를 가우시안에서 뽑고(z\sim p(z)), 그로부터 x를 생성한다(x\sim p(x\mid z)).”

6.2.1 왜 하필 가우시안 잠재인가?

  1. 해석적으로 다루기 쉽다(analytically tractable). 가우시안은 미분·적분·샘플링이 모두 잘 정의되고, KL 등도 닫힌 형태(closed form)로 나온다.
  2. 샘플링이 쉽다. 거의 모든 하드웨어/라이브러리에 가우시안 샘플러가 있다.
  3. 표현력이 충분하다. 자연의 많은 현상이 가우시안을 따른다(중심극한정리). 그러니 잠재 공간을 가우시안으로 가정해도 무리가 없고, 자연 현상을 통제된 방식으로 모델링할 수 있다.

6.3 적분이 다루기 어렵다 (intractability)

문제: p(x)=\int p(x\mid z)p(z)\,dz에서 p(x\mid z)는 디코더(비선형 신경망) 라 적분이 닫힌 형태로 안 나온다.

노트“어려운 적분”을 만났을 때 — 두 갈래

(가) 몬테카를로 샘플링(Monte Carlo). 적분 = “넓이 구하기”. 이상한 모양의 영역 넓이를, 사각형 안에 화살을 무수히 던져 영역 안에 들어간 비율로 근사한다(다트 게임). 즉 \int f \approx \frac{1}{M}\sum_m f(z_m). 문제: 이미지/오디오/텍스트의 잠재 공간은 너무 고차원이라 샘플로 적분을 근사하기가 사실상 불가능(차원의 저주).

(나) 변분 추론(Variational Inference). 더 샘플 효율적인 대안. → VAE가 택한 길.

6.4 변분 추론과 ELBO 유도

6.4.1 핵심 항등식

임의의 분포 q(z)에 대해(\int q(z)dz=1 이용), 베이즈 정리 p(x)=\frac{p(x,z)}{p(z\mid x)}를 써서:

\begin{aligned} \log p(x) &= \log p(x)\cdot 1 = \log p(x)\int q(z)\,dz = \int q(z)\log p(x)\,dz\\ &= \int q(z)\log \frac{p(x,z)}{p(z\mid x)}\,dz \qquad (\because \text{Bayes})\\ &= \int q(z)\big(\log p(x,z) - \log p(z\mid x)\big)\,dz\\ &= \mathbb{E}_{z\sim q}\big[\log p(x,z) - \log p(z\mid x)\big] \end{aligned}

6.4.2 변분족(variational family) 도입 → ELBO + KL

이제 q를 파라미터화한 q_\phi(z)로 둔다(이것이 인코더, 추론 네트워크). \frac{q_\phi(z)}{q_\phi(z)}=1을 끼워 넣고 전개하면:

\begin{aligned} \log p(x) &= \int q_\phi(z)\log\frac{p(x,z)}{p(z\mid x)}\,dz = \int q_\phi(z)\log\!\left[\frac{p(x,z)}{q_\phi(z)}\cdot\frac{q_\phi(z)}{p(z\mid x)}\right]dz\\ &= \underbrace{\mathbb{E}_{q}\big[\log p(x,z) - \log q_\phi(z)\big]}_{\textbf{ELBO}\;(\text{Evidence Lower BOund})} \;+\; \underbrace{\mathrm{KL}\!\big[\,q_\phi(z)\,\|\,p(z\mid x)\,\big]}_{\ge\,0} \end{aligned}

중요왜 이 분해가 결정적인가
  • \log p(x)는 \phi에 대해 상수(우리가 손댈 수 없는 진짜 값, “evidence”).
  • KL은 항상 \ge 0 (KL의 비음수성). 따라서 \log p(x) \ge \text{ELBO} → “Evidence Lower Bound”.
  • 우리가 진짜 줄이고 싶은 것은 \mathrm{KL}[q_\phi(z)\|p(z\mid x)] (내 근사 사후분포와 진짜 사후분포의 거리)인데, 진짜 사후분포 p(z\mid x)를 모르므로 KL을 직접 못 줄인다.
  • 대신 좌변이 상수이므로, ELBO를 최대화 = KL을 최소화. ELBO는 계산 가능하다. → ELBO를 최대화하자!

6.4.3 ELBO 전개 → 복원 항 + 정규화 항

p(x,z)=p(x\mid z)p(z)를 대입:

\begin{aligned} \text{ELBO} &= \mathbb{E}_{q}\big[\log p(x,z) - \log q_\phi(z)\big] = \mathbb{E}_{q}\big[\log p(x\mid z) + \log p(z) - \log q_\phi(z)\big]\\ &= \mathbb{E}_{q}\big[\log p(x\mid z)\big] + \mathbb{E}_{q}\big[\log p(z) - \log q_\phi(z)\big]\\ &= \mathbb{E}_{q}\big[\log p(x\mid z)\big] - \mathbb{E}_{q}\big[\log q_\phi(z) - \log p(z)\big]\\ &= \underbrace{\mathbb{E}_{q}\big[\log p(x\mid z)\big]}_{\textbf{복원(Reconstruction)}} \;-\; \underbrace{\mathrm{KL}\!\big(q_\phi(z)\,\|\,p(z)\big)}_{\textbf{정규화(Regularization)}} \end{aligned}

항 의미 역할
복원항 \mathbb{E}_q[\log p(x\mid z)] z로부터 x를 얼마나 잘 복원하는가 (디코더 품질) 데이터 충실도
정규화항 \mathrm{KL}(q_\phi(z)\|p(z)) 잠재 z가 prior \mathcal N(0,I)를 얼마나 잘 따르는가 잠재 공간 통제

ELBO 최대화는 이 둘의 균형을 맞춘다: “z로 x를 잘 복원하되, z의 분포는 \mathcal N(0,I)에 가깝게.”

6.5 VAE의 손실 함수와 reparameterization trick

ELBO는 최대화 대상이므로, 부호를 뒤집어 손실(최소화) 로 쓴다. (디코더 p_\theta(x\mid z), 인코더 q_\phi(z\mid x))

\boxed{\; \mathcal{L}_{\text{VAE}}(\theta,\phi) = \underbrace{-\,\mathbb{E}_{q_\phi}\!\big[\log p_\theta(x\mid z)\big]}_{\approx\ \text{MSE/CE 복원 손실}} \;+\; \underbrace{\mathrm{KL}\!\big(q_\phi(z\mid x)\,\|\,p(z)\big)}_{\text{닫힌 형태 (가우시안)}} \;}

노트표기 주의 (정밀성)
  • 본 노트는 표준(Kingma & Welling) 표기를 따른다: 인코더/추론망 q_\phi의 파라미터를 \phi, 디코더/생성망 p_\theta의 파라미터를 \theta로 둔다.
  • 일부 자료는 인코더에 \theta, 디코더에 \phi를 붙이기도 하므로(역할이 바뀐 표기), 어떤 망을 가리키는지를 기준으로 읽어야 혼동이 없다. 중요한 것은 기호가 아니라 “추론망 vs 생성망”이라는 역할 구분이다.

복원항은 x와 \hat x의 차이로 정의되므로, 가정에 따라 MSE 손실(가우시안 likelihood) 또는 교차 엔트로피(베르누이 likelihood)가 된다. KL항은 두 가우시안 사이라 닫힌 형태로 떨어진다(아래 부록 식).

6.5.1 문제: 샘플링은 미분 불가능

학습하려면 \hat x \to z \to x로 역전파해야 하는데, z\sim q_\phi(z\mid x)는 확률적 샘플링이라 그래디언트가 통과하지 못한다.

6.5.2 해법: Reparameterization trick

확률성을 입력 쪽의 외생 잡음 \epsilon 으로 빼낸다.

\boxed{\;z = \mu_\phi(x) + \sigma_\phi(x)\odot \epsilon,\qquad \epsilon\sim\mathcal N(0,I)\;}

이제 z는 \mu_\phi,\sigma_\phi(신경망 출력)의 결정론적 함수 + 고정 잡음이다. 평균 \mu는 인코더에, 분산 \sigma도 인코더에 의존하는 미분 가능한 식이 되어, \epsilon만 무작위로 두고 \phi,\theta에 대해 정상적으로 역전파할 수 있다.

6.6 VAE의 결과와 장점

  • AE보다 덜 흐릿한(less blurry) 샘플을 생성한다.
  • 잠재 공간이 통제 가능(controllable) 하다. 10차원 가우시안 잠재라면 각 차원이 의미(semantic)에 대응할 수 있다. 예: 1번 차원을 -\infty\to+\infty로 sweep하면 여성→남성으로, 2번 차원을 sweep하면 머리 스타일이 바뀌는 식의 disentangled 생성·보간(interpolation) 이 가능.
  • 잠재 공간이 분석 가능해, 어떤 데이터가 더 필요한지 등 학습 과정을 진단할 수 있다(AE의 불투명한 잠재 공간과 대비).
힌트무선통신 관점 — VAE의 세 가지 매핑
  1. Reparameterization trick = AWGN 모델. z=\mu+\sigma\epsilon은 정확히 신호 + 가우시안 잡음 모델이다. 결정론적 신호 성분(\mu)에 스케일된 백색 잡음(\sigma\epsilon)을 더한 것. 무선에서 늘 쓰는 y = s + n,\ n\sim\mathcal N(0,\sigma^2)와 동형. 덕분에 “기댓값에 대한 그래디언트(pathwise derivative)”를 잡을 수 있다.
  2. 가우시안 잠재 prior = 가우시안 입력 코드북. AWGN 채널의 용량 달성 입력 분포가 가우시안인 것과 같은 맥락 — 가우시안은 “최대 엔트로피/최적 표현”의 자연스러운 선택.
  3. ELBO = 다루기 힘든 likelihood의 하한. 직접 못 구하는 marginal likelihood를 계산 가능한 하한으로 대체해 최적화하는 전략은, 검출/추정에서 다루기 힘든 우도를 변분 하한·EM으로 푸는 것과 동일한 발상이다. KL 정규화는 잠재의 “전력(분산)을 \mathcal N(0,I)로 제한”하는 전력 제약처럼 작동한다.

7 GAN (Generative Adversarial Network)

Goodfellow et al., NeurIPS 2014. VAE의 구조를 빌리되, MSE 대신 적대적 손실(adversarial loss) 을 쓴다.

7.1 동기: MSE의 흐릿함을 넘어서

VAE/AE의 MSE 복원은 평균적으로 안전한 픽셀값을 택해 흐릿한(blurry) 결과를 낳기 쉽다. GAN은 adversarial loss 를 추가해 디테일이 살아있는 선명한 이미지를 만든다.

7.2 구성: 생성자 G와 판별자 D

  • Generator G(z): 랜덤 벡터 z → 이미지. (좋은 G = 생성 이미지가 진짜처럼 보임)
  • Discriminator D(x): 이미지 → “진짜일 확률”. (좋은 D = 진짜/가짜를 잘 구분)
  • 경쟁을 통한 학습: G는 D를 속이려 하고, D는 안 속으려 한다. 서로 적대적으로 공격하며 함께 강해진다.

7.3 Minimax 정식화

\boxed{\; \min_{G}\max_{D}\; \mathbb{E}_{x\sim q_{\text{data}}(x)}\big[\log D(x)\big] \;+\; \mathbb{E}_{z\sim p(z)}\big[\log\big(1 - D(G(z))\big)\big] \;}

물리적 의미: \log(\text{$x$가 진짜일 확률}) + \log(1-\text{$G(z)$가 진짜일 확률}).

  • 이 값이 커질수록 D가 좋다 → D에 대해 최대화.
  • 이 값이 작아질수록 G가 좋다(D를 잘 속임) → G에 대해 최소화.
  • 이런 문제를 Minimax 문제, 즉 영합(zero-sum) 비협조 게임이라 한다.
노트심화 — 최적 판별자와 JS 발산

G를 고정했을 때 최적 판별자는 D^*(x) = \frac{q_{\text{data}}(x)}{q_{\text{data}}(x) + p_g(x)}. 이를 대입하면 목적함수는 V(G,D^*) = -\log 4 + 2\cdot \mathrm{JSD}\big(q_{\text{data}}\,\|\,p_g\big) 가 된다(\mathrm{JSD} = Jensen–Shannon divergence). 즉 G를 최소화한다는 것은 생성 분포 p_g를 진짜 분포 q_{\text{data}}에 JS 발산 기준으로 일치시키는 것이다. 전역 최적은 p_g = q_{\text{data}}일 때이며 그때 V=-\log 4. (부록 코드에서 수치로 검증.)

7.4 학습 절차 (세 단계 업데이트)

7.5 학습의 어려움

GAN 학습은 악명 높게 어렵다.

문제 증상
Non-convergence (비수렴) 파라미터가 진동·불안정하며 수렴하지 않음
Mode collapse (모드 붕괴) G가 비슷한 샘플만 양산(다양성 상실)
Diminished gradient (그래디언트 소실) D가 너무 강해져 G의 그래디언트가 사라지고 학습 정체
  • D와 G의 불균형이 위 문제를 일으킨다. 하이퍼파라미터 선택이 “예술의 경지(work of art)”.
  • 안정화 변형: LSGAN, WGAN, WGAN-GP, BEGAN 등.
  • 근본적 대안으로 확산 모델(diffusion) 등장: 학습은 느리지만 안정적이고 품질이 뛰어남.

7.6 GAN은 왜 효과적인가: Hard negative

D는 G에게 매우 까다로운 음성 샘플(hard negative) 을 끊임없이 제공한다. 결정 경계 근처의 “거의 진짜 같은 가짜”를 만들어 G를 압박하므로, 단순 MSE보다 훨씬 강한 학습 신호가 된다.

경고적대적 예제(Adversarial Example) ≠ 적대적 학습(Adversarial Learning)

혼동 주의. 적대적 예제는 입력에 미세한 섭동을 가해 신경망이 엉뚱한 출력을 내게 만드는 것이다.

  • 예: 정지 표지판에 미세한 패턴을 더하면 자율주행 AI가 “서행”으로 오인 → 위험.
  • 예: 고양이 이미지에 사람 눈엔 안 보이는 텍스처를 넣으면 CNN이 “데스크톱 컴퓨터”라고 높은 확률로 단언.

이는 신경망이 입력의 작은 변화에 극도로 민감(취약) 하다는 증거다. GAN의 “adversarial”은 이 현상과 단어만 공유할 뿐, 두 네트워크가 경쟁한다는 다른 철학을 가진다.

힌트무선통신 관점 — GAN = 재밍 게임, 적대적 예제 = 정밀 간섭
  • Minimax = 재머(jammer) 대 송수신기의 영합 게임. D(수신기)는 진짜/가짜를 구분(검출)하려 하고, G(재머)는 검출을 회피할 신호를 합성한다. 평형(Nash equilibrium)은 worst-case 강건 설계의 saddle point와 같다.
  • 적대적 예제 = 결정 경계에 정렬된 저전력 간섭. 아주 작은 섭동(\|\delta\| 작음)으로 검출기를 오작동시키는 것은, 결정 경계 법선 방향에 맞춘 최소 전력 교란 신호와 같다. 신경망의 민감도는 곧 분류기의 나쁜 조건수(ill-conditioning) — 입력의 미세 변화가 출력에서 증폭된다.
  • Hard negative = 경계 근처의 고-난이도 샘플. 검출 이론의 “임계 SNR 부근 시험 신호”처럼, 가장 정보량 많은 학습 신호를 제공한다.

9.1 가우시안 KL의 닫힌 형태 (VAE 정규화항)

q=\mathcal N(\mu,\sigma^2), p=\mathcal N(0,1)일 때, \mathrm{KL}(q\|p) = \frac{1}{2}\sum_{j}\big(\mu_j^2 + \sigma_j^2 - \log\sigma_j^2 - 1\big). 

import numpy as np
rng = np.random.default_rng(0)

def gaussian_kl_closed(mu, var):
    # KL( N(mu, var) || N(0, I) ), per-dimension diagonal Gaussian
    return 0.5 * np.sum(mu**2 + var - np.log(var) - 1)

# Monte Carlo 검증
mu, sig = 0.7, 1.3
closed = gaussian_kl_closed(np.array([mu]), np.array([sig**2]))
z = rng.normal(mu, sig, size=2_000_000)
logq = -0.5*np.log(2*np.pi*sig**2) - (z-mu)**2/(2*sig**2)
logp = -0.5*np.log(2*np.pi)        - z**2/2
mc = np.mean(logq - logp)
print(f"KL closed-form = {closed:.5f}   Monte Carlo = {mc:.5f}")
KL closed-form = 0.32764   Monte Carlo = 0.32833

9.2 Reparameterization trick + VAE 손실 (forward)

def reparameterize(mu, logvar, eps=None):
    # z = mu + sigma * eps,  sigma = exp(0.5*logvar)
    std = np.exp(0.5*logvar)
    if eps is None:
        eps = rng.normal(size=mu.shape)
    return mu + std*eps                       # AWGN 모델: 신호 mu + 잡음 std*eps

def vae_loss(x, x_hat, mu, logvar):
    recon = np.mean(np.sum((x - x_hat)**2, axis=1))      # MSE 복원항
    kl    = np.mean(0.5*np.sum(np.exp(logvar) + mu**2 - 1 - logvar, axis=1))
    return recon + kl, recon, kl

# 더미 예시 (배치 4, 잠재 3, 입력 5)
mu     = rng.normal(size=(4,3))
logvar = rng.normal(size=(4,3))*0.1
z      = reparameterize(mu, logvar)
x      = rng.normal(size=(4,5))
x_hat  = rng.normal(size=(4,5))               # 실제로는 decoder(z)
total, recon, kl = vae_loss(x, x_hat, mu, logvar)
print(f"z.shape={z.shape}  total={total:.4f}  recon={recon:.4f}  kl={kl:.4f}")
z.shape=(4, 3)  total=20.7320  recon=19.6970  kl=1.0350

9.3 CLIP 대칭 대조 손실

def clip_loss(I, T, tau=1.0):
    I = I/np.linalg.norm(I, axis=1, keepdims=True)
    T = T/np.linalg.norm(T, axis=1, keepdims=True)
    logits = I @ T.T / tau                    # 상관(correlation) 행렬, 대각이 정답
    N = len(I)
    def ce_rows(L):
        L = L - L.max(1, keepdims=True)
        logp = L - np.log(np.exp(L).sum(1, keepdims=True))
        return -logp[np.arange(N), np.arange(N)].mean()
    return 0.5*(ce_rows(logits) + ce_rows(logits.T))   # 이미지→텍스트 + 텍스트→이미지

N, d = 8, 16
base = rng.normal(size=(N, d))
aligned = clip_loss(base, base + 0.01*rng.normal(size=(N, d)))
random_ = clip_loss(rng.normal(size=(N, d)), rng.normal(size=(N, d)))
print(f"정렬된 쌍 loss = {aligned:.4f}   무작위 쌍 loss = {random_:.4f}   (log N = {np.log(N):.4f})")
정렬된 쌍 loss = 1.2974   무작위 쌍 loss = 2.0121   (log N = 2.0794)

9.4 SigLIP 시그모이드 손실

def sigmoid(u): return 1/(1+np.exp(-u))

def siglip_loss(I, T, t=10.0, b=-10.0):
    I = I/np.linalg.norm(I, axis=1, keepdims=True)
    T = T/np.linalg.norm(T, axis=1, keepdims=True)
    S = I @ T.T                                # 상관 행렬
    N = len(I)
    Y = -np.ones((N, N)); np.fill_diagonal(Y, 1.0)   # 대각=+1(정답), 나머지=-1
    logits = Y*(t*S + b)
    return -np.mean(np.log(sigmoid(logits) + 1e-12)) # 쌍별 독립 이진 결정

print(f"SigLIP loss = {siglip_loss(base, base):.4f} (완전 정렬)")
SigLIP loss = 0.0871 (완전 정렬)

9.5 GAN: 최적 판별자와 JS 발산 항등식 검증

본문의 V(G,D^*) = -\log 4 + 2\,\mathrm{JSD}(q_{\text{data}}\|p_g)를 이산 분포로 확인한다.

p = np.array([0.1, 0.2, 0.3, 0.4])   # q_data
q = np.array([0.4, 0.3, 0.2, 0.1])   # p_g
D_star = p/(p+q)                                         # 최적 판별자
V = np.sum(p*np.log(D_star)) + np.sum(q*np.log(1-D_star))
m = 0.5*(p+q)
KL = lambda a,b: np.sum(a*np.log(a/b))
JSD = 0.5*KL(p,m) + 0.5*KL(q,m)
print(f"V(G, D*)            = {V:.5f}")
print(f"-log4 + 2*JSD       = {-np.log(4) + 2*JSD:.5f}")
print(f"전역최적(p_g=q_data)일 때 V = -log4 = {-np.log(4):.5f}")
V(G, D*)            = -1.17341
-log4 + 2*JSD       = -1.17341

# 오늘의 큰 그림 {#sec-overview}

오늘 다루는 내용은 크게 두 축으로 나뉜다.

1. **멀티모달(Multimodal) 학습** — 서로 다른 형태(modality)의 데이터(이미지·텍스트·오디오 등)를 하나의 시스템에서 다루는 방법론. Transformer의 효율적 대안(Mamba)을 짧게 짚은 뒤, 멀티모달의 5대 핵심 과제와 대표 기법인 CLIP/SigLIP을 본다.
2. **생성 모델(Generative model) I** — 데이터의 분포 $p(X)$ 자체를 학습하려는 모델. 오토인코더(AE)에서 출발해, **VAE**(변분 추론 + ELBO + reparameterization)와 **GAN**(minimax 게임)을 다룬다.

두 축을 관통하는 한 문장: **"고차원 데이터를 저차원 잠재 표현(latent representation)으로 압축하고, 그 잠재 공간을 우리가 통제 가능한 분포로 만들면, 표현·정렬·융합·생성이 모두 쉬워진다."**

::: {.callout-tip}
## 무선통신 전공자를 위한 한 줄 매핑
- 잠재 표현 = **소스 코딩(source coding)** 의 압축 표현
- 잠재 분포를 $\mathcal N(0,I)$로 강제 = **가우시안 코드북(codebook)** 설계
- 대조 학습(CLIP) = **정합 필터(matched filter) / 상관 검출**
- GAN의 minimax = **재머(jammer)가 존재하는 2인 영합 게임(zero-sum game)** 에서의 worst-case 강건 설계
:::

# Transformer의 한계와 효율적 대안: Mamba {#sec-mamba}

## Transformer의 두 가지 한계

Self-attention은 강력하지만 두 가지 구조적 약점이 있다.

1. **윈도우(window) 밖 문맥을 인코딩하기 어렵다.** 어텐션은 정해진 컨텍스트 길이 안에서만 직접 상호작용한다.
2. **계산 복잡도가 $O(n^2)$** 이다($n$은 시퀀스/윈도우 길이). 길이가 길어지면 메모리·연산이 제곱으로 폭증한다.

이를 줄이려는 연구가 "Efficient Transformers"라는 큰 흐름을 이룬다(Tay et al., 2022).

## Mamba: 선택적 상태공간 모델 (S6)

**Mamba**(Gu & Dao, 2023)는 시퀀스를 **상태공간 모델(State Space Model, SSM)** 로 보고 선형 시간에 처리한다. 핵심 아이디어는 두 가지다.

1. **Selective mechanism (S6)** — 작은 윈도우를 유지하되, 그 안에서 *관련 있는 토큰만* 선택적으로 남긴다. 관련도(relevance)를 측정하는 방식이 RNN의 **게이팅(gating)** 과 유사하다.
2. **Hardware-aware parallel scan** — 순차적 재귀를 GPU에서 병렬 스캔으로 계산해 속도를 확보한다.

| 특징 | Transformer | Mamba |
|---|---|---|
| 복잡도 | $O(n^2)$ | $O(n)$ (선형) |
| 장점 | 강한 문맥 인코딩(장거리 의존성) | 계산 효율, 긴 윈도우(256k+) |
| 약점 | 연산 비용 | 표현력은 Transformer를 넘지 못함 [Chen et al., 2025] |

::: {.callout-note}
## 하이브리드가 대세
- **Jamba**: Transformer + Mamba를 Mixture-of-Experts(MoE) 형태로 혼합.
- **MambaVision**: 초기 층은 Mamba(효율), 후기 층은 self-attention(장거리 의존성).
- **TransMamba**: 층/토큰 단위로 둘 중 하나를 선택.

회로 복잡도(circuit complexity) 관점에서 **Mamba가 Transformer보다 표현력이 더 좋지는 않다.** 즉 Mamba는 "더 똑똑한" 모델이 아니라 "더 싼" 모델이다.
:::

::: {.callout-tip}
## 무선통신 관점
선택적 SSM은 본질적으로 **재귀적 상태 추정기**다. 상태 $h_t = A h_{t-1} + B x_t$, 출력 $y_t = C h_t$ 형태는 **칼만 필터(Kalman filter)** / 선형 동적 시스템과 같은 골격이다. 게이팅으로 과거를 얼마나 잊을지 정하는 것은 **RLS(Recursive Least Squares)의 forgetting factor** $\lambda$를 적응적으로 조절하는 것과 직접 대응된다.
:::

# 멀티모달 학습의 5대 핵심 과제 {#sec-mm-challenges}

딥러닝 시대(2010~)의 멀티모달 ML은 다음 5개 과제로 정리된다 (Baltrušaitis, Ahuja & Morency, TPAMI 2019).


## 과제 1 — 표현 (Representation)

**정의:** 멀티모달 데이터를, 양태 간 **상보성(complementarity)** 과 **중복성(redundancy)** 을 활용하도록 요약·표현하는 법.

표현 학습은 두 갈래로 나뉜다.

| 방식 | 설명 | 난이도 | 남는 과제 |
|---|---|---|---|
| **Joint representation** (공동 표현) | 모든 양태를 **하나의 공간**에 임베딩 | 학습이 **어려움** | (없음 — 일단 학습되면 이후가 편함) |
| **Coordinated representation** (조율 표현) | 양태별 **별도 공간**을 학습 후 정렬 | 상대적으로 **쉬움** | 두 공간을 어떻게 **정렬**할지 |

핵심 통찰: **조율 표현이 보통 더 쉽다.** 공동 표현은 어려운 문제를 한 번에 풀려 하고, 조율 표현은 어려움을 "정렬(alignment) 단계"로 미루기 때문이다.

### 멀티모달 벡터 산술 (Vector arithmetic)

잘 학습된 공동 임베딩 공간에서는 의미가 벡터 연산으로 나타난다.

$$
\text{vec}(\text{이미지: 파란 책}) - \text{vec}(\text{파랑}) + \text{vec}(\text{빨강}) \approx \text{vec}(\text{빨간 책})
$$

비행기 이미지에서 "하늘"을 빼고 "바다"를 더하면 가장 가까운 이웃이 **배(boat)** 이미지가 된다. 의미적으로 유사한 데이터가 공간상 가까운 영역에 모여 있기 때문이다. (Word2Vec의 `king - man + woman ≈ queen`의 멀티모달 버전.)

## 과제 2 — 정렬 (Alignment)

**정의:** 두 개 이상의 양태에서 (하위)요소들 사이의 **직접적 대응관계**를 찾는 것.

| 종류 | 설명 |
|---|---|
| **Explicit alignment** | 한 양태의 요소를 다른 양태의 요소에 **1:1로 직접 매핑** |
| **Implicit alignment** | 명시적 대응을 만들지 않고, 매핑을 수행하는 **학습된 함수**에 맡김 |

::: {.callout-warning}
여기서의 alignment는 **LLM의 alignment(인간 가치 정렬)** 와 전혀 다른 개념이다. 혼동 주의.
:::

## 과제 3 — 융합 (Fusion)

**정의:** 예측을 위해 두 개 이상 양태의 정보를 **합치는** 것. (AI의 본질은 결국 무언가를 예측하는 것이므로, 여러 입력을 하나로 모아 예측해야 한다.)

```{mermaid}
flowchart TB
    subgraph EF["Early Fusion (model-agnostic)"]
      a1[모달 A] --> cc[Concatenate]
      a2[모달 B] --> cc
      cc --> m1[Model] --> o1[예측]
    end
    subgraph LF["Late Fusion (model-agnostic)"]
      b1[모달 A] --> mA[Model A] --> mm[Merge]
      b2[모달 B] --> mB[Model B] --> mm
      mm --> o2[예측]
    end
    subgraph IF["Intermediate / model-based"]
      c1[모달 A] --> mid[하나의 모델 내부에서 융합<br/>예: 신경망, 그래프 모델]
      c2[모달 B] --> mid --> o3[예측]
    end
```

- **Early fusion**: 모델에 넣기 *전에* 합친다. 가장 간단한 방법은 두 특징 벡터를 **concatenate**.
- **Late fusion**: 양태별로 각자의 모델을 통과시킨 뒤, *출력 단*에서 합친다.
- **Model-based(중간) fusion**: 모델 *내부에서* 융합되도록 설계(신경망, 그래프 모델 등). End-to-end로 학습.

## 과제 4 — 변환 (Translation)

**정의:** 데이터를 한 양태에서 다른 양태로 **바꾸는** 것. 대응관계가 종종 open-ended/주관적이다.

- 이미지 → 텍스트: **Captioning(캡션 생성)**
- 텍스트 → 이미지: **Image generation**
- 텍스트 → 비디오: **Video generation**

| 종류 | 설명 | 예시/한계 |
|---|---|---|
| **Example-based** | 양태 간 데이터 매핑을 예시로 직접 구축 | 사전식 1:1 매핑. 언어 번역(영↔불)처럼 어순·의미가 비슷하면 잘 됨. 영↔중처럼 단어가 1:1로 안 맞으면 어려움 |
| **Model-driven** | 매핑 예시들로 **변환 모델**을 학습 후 사용 | 현대 번역기 대부분. 주로 신경망 사용 |

## 과제 5 — 공동학습 (Co-Learning)

**정의:** 양태 간에 **지식(표현·예측력)을 전이**하는 학습 프레임워크.

> **오늘날의 현실:** 위 4개 과제는 사실상 모두 **하나의 거대한 신경망**으로 흡수되었다. "표현/정렬/융합/변환을 따로 고민하지 말고, 모델을 충분히 키워라(scale up)"가 현재의 주류 패러다임이다.

::: {.callout-important}
## 효율성이 곧 경쟁력
하지만 scaling은 **돈·전력 측면에서 매우 비싸다.** 더 적은 데이터·전력으로 지식을 더 잘 전이하는 **효율적** 방법을 찾으면, 작은 기술로 거대 테크 기업을 이길 수 있는 큰 함의가 생긴다. (연구 방향으로서의 메시지.)
:::

::: {.callout-tip}
## 무선통신 관점
융합(fusion)은 **다이버시티 결합(diversity combining)** 과 정확히 대응한다.

- *Early fusion (concatenate)* ↔ 안테나 신호를 합치기 전에 결합 → **MRC(Maximal-Ratio Combining)** 처럼 raw 신호 단에서 결합
- *Late fusion* ↔ 각 안테나에서 독립 검출 후 결합 → **selection / soft combining**

서로 다른 양태가 가진 상보성·중복성은 곧 **공간 다이버시티(spatial diversity)** 의 상보성·중복성이다.
:::

# 텍스트–비전 공동 임베딩: CLIP과 SigLIP {#sec-clip}

## CLIP (OpenAI, 2021)

CLIP(Contrastive Language–Image Pre-training)은 가장 널리 쓰이는 멀티모달 공동 임베딩 기법이다.

- **이미지 인코더**(ViT/CNN)와 **텍스트 인코더**(Transformer)가 각각 임베딩을 만든다.
- **대조 학습(contrastive learning)** 으로 "맞는 (이미지, 텍스트) 쌍"의 임베딩은 가깝게, "틀린 쌍"은 멀게 만든다.
- 결과적으로 **zero-shot 분류**(태스크별 fine-tuning 없이 분류)가 가능해진다.

### 대조 사전학습(Contrastive pre-training)의 메커니즘

미니배치 $N$개의 (이미지, 텍스트) 쌍에서 모든 쌍의 내적(유사도) 행렬을 만든다. 대각선($I_i\cdot T_i$)이 정답(positive), 나머지가 오답(negative)이다.

이미지 임베딩 $I_i$, 텍스트 임베딩 $T_j$ (L2 정규화됨), 온도 $\tau$에 대해 로짓 $\ell_{ij} = I_i^\top T_j / \tau$. 손실은 **행 방향(이미지→텍스트)과 열 방향(텍스트→이미지) 교차 엔트로피의 평균**이다.

$$
\mathcal{L}_{\text{CLIP}}
= \frac{1}{2N}\sum_{i=1}^{N}
\Bigg[
\underbrace{-\log\frac{e^{\ell_{ii}}}{\sum_{j} e^{\ell_{ij}}}}_{\text{이미지}\to\text{텍스트}}
\;+\;
\underbrace{-\log\frac{e^{\ell_{ii}}}{\sum_{j} e^{\ell_{ji}}}}_{\text{텍스트}\to\text{이미지}}
\Bigg]
$$

핵심: **softmax가 미니배치 전체에 대해 걸린다.** 즉 한 이미지에 대해 "배치 안 모든 텍스트 중 정답 고르기"라는 $N$지선다 분류 문제다.

## SigLIP (Google DeepMind, 2021)

CLIP의 softmax는 **배치 전체의 정규화**가 필요해 메모리/통신 비용이 크다. SigLIP은 이를 **각 쌍마다 독립적인 sigmoid(이진 분류)** 로 바꾼다.

$y_{ij} = +1$ (정답 쌍, $i=j$) / $-1$ (오답 쌍), 스케일 $t$, 바이어스 $b$에 대해:

$$
\mathcal{L}_{\text{SigLIP}}
= -\frac{1}{N}\sum_{i=1}^{N}\sum_{j=1}^{N}
\log \sigma\!\big(y_{ij}\,(t\, I_i^\top T_j + b)\big),
\qquad \sigma(u)=\frac{1}{1+e^{-u}}
$$

각 쌍이 **독립적인 이진 결정**이라 배치 전체 정규화가 필요 없다 → 병렬화·메모리 효율↑, 큰 배치로 확장 용이.

### 비교표

| 특징 | CLIP | SigLIP | SigLIP 2 |
|---|---|---|---|
| 손실 함수 | Softmax 기반 대조 손실 | Sigmoid (쌍별) | LocCa(위치 인지 캡셔닝) 추가 |
| 손실 계산 단위 | 배치 내 **모든 쌍** 비교 | **각 쌍** 독립 | 각 쌍 독립 |
| 태스크 | Image–Text matching | Image–Text matching | Captioning, Distillation |
| 메모리 | 높음 | 낮음 | 낮음 |
| 정확도 | 양호 | CLIP보다 개선 | 여러 태스크에서 SigLIP보다 개선 |

::: {.callout-note}
## CLIP + 확산 모델 = 생성으로 가는 다리
랜덤 벡터를 CLIP 임베딩에 매핑하고 그 임베딩을 **확산 모델**의 조건으로 주면, 텍스트로부터 이미지/비디오를 생성할 수 있다. DALL·E 3, Make-A-Video, Phenaki, Sora, Runway Gen-4.5가 이 계열의 멀티모달 생성 모델이다.
:::

::: {.callout-tip}
## 무선통신 관점 — 대조 학습 = 검출 이론
CLIP의 softmax-over-batch는 **코드북에서의 ML 검출(Maximum-Likelihood detection)** 과 같다. 수신 신호(이미지 임베딩)와 가장 상관이 높은 코드워드(정답 텍스트)를 $N$개 후보 중에서 고른다 — 이것이 바로 **정합 필터 뱅크(matched-filter bank) + argmax**.

SigLIP의 sigmoid-per-pair는 각 쌍에 대한 **개별 이진 가설검정(에너지/상관 검출)** 이다. 즉,
- **CLIP** = 결합 ML 검출 (전역 정규화 필요, 최적이지만 비쌈)
- **SigLIP** = 쌍별 독립 검출 (분리 가능, 확장성 우수)

내적 $I_i^\top T_j$가 곧 **상관(correlation)** 이고, $\tau$/온도는 **검출 임계의 sharpness**를 조절하는 SNR 스케일과 같다.
:::

# 생성 모델 개요 & 오토인코더 복습 {#sec-ae}

## 오토인코더(Autoencoder, AE)

AE의 목표: 입력 $x$를 모델에 넣어 **자기 자신을 복원(reconstruct)** 하기.

```{mermaid}
flowchart LR
    x[입력 x] --> E[Encoder] --> z[잠재 z<br/>저차원] --> D[Decoder] --> xh[복원 x̂]
```

::: {.callout-warning}
## "그냥 복사하면 되지 않나?" 라는 함정
입력을 그대로 출력하면 복원 오차 0짜리 완벽한 해다. 그런데 왜 굳이 인코더–디코더를 쓰는가?

**답: 잠재 표현 $z$의 차원이 입력보다 작기 때문이다.** (입력 7차원 → 잠재 4차원 같은 식.) 좁은 통로로 정보를 통과시키며 **노이즈는 버리고 핵심 정보만** 남겨야 복원이 가능하다. 이 강제된 좁은 통로가 바로 **정보 병목(information bottleneck)** 이다.
:::

- **Encoder**: 입력에서 핵심 정보를 추출(압축).
- **Decoder**: 핵심 정보로부터 입력을 재생성.
- 더 깊게 쌓으면(deep AE) 더 정교한 정보를 단계적으로 압축/복원할 수 있다.

::: {.callout-tip}
## 무선통신 관점 — 정보 병목 = 율-왜곡(Rate–Distortion)
정보 병목은 **손실 압축(lossy source coding)** 그 자체다. 잠재 차원 = **비트율(rate) $R$**, 복원 오차 = **왜곡(distortion) $D$**. AE는 주어진 율 예산 안에서 왜곡을 최소화하는 율-왜곡 최적화 문제를 신경망으로 푼다. 잠재 차원이라는 "노브(knob)"가 적을수록 잠재 공간을 더 정밀하게 통제할 수 있다.
:::

## 왜 지금 AE가 중요한가: LeCun의 케이크 비유

Yann LeCun(Meta FAIR, NYU)은 학습 시 기계가 받는 **정보량**을 케이크에 빗댔다.

```{mermaid}
flowchart TB
    cherry["🍒 체리 (꼭대기)<br/>= 강화학습 (RL)<br/>아주 적은 정보"] --> icing
    icing["🎂 아이싱<br/>= 지도학습 (Supervised)<br/>피상적 정보"] --> bread
    bread["🍰 빵 (본체, 대부분)<br/>= 자기지도학습 (Self-supervised)<br/>대부분의 정보"]
```

| 학습 방식 | 케이크 부위 | 신호의 양/질 | 이유 |
|---|---|---|---|
| **강화학습(RL)** | 체리 | 매우 약함, 확률적 | 보상이 **미래에, 띄엄띄엄** 주어짐. 현재 시점 보상은 기대값으로 예측해야 하고 분산이 큼 |
| **지도학습** | 아이싱 | 피상적(sparse) | "이 이미지=케이크"라는 라벨은 **색·배경·모양 등은 전혀 알려주지 않음** |
| **자기지도학습(SSL)** | 빵(본체) | 가장 풍부 | 입력 전체를 복원하려면 **모든 디테일**을 학습해야 함. 라벨도 불필요 |

::: {.callout-note}
SSL이 강력한 이유: (1) 데이터의 거의 모든 정보를 추출, (2) 인간 라벨 불필요 → 데이터 확보 쉬움. **유일한 어려움은 "좋은 pretext task(자기지도 과제)를 설계하는 것"** 이다. AE의 "입력 복원"이 가장 기본적인 pretext task다.
:::

::: {.callout-tip}
## 무선통신 관점 — 약한 보상 = 낮은 SNR 피드백
RL의 보상 신호가 "약하고 확률적"이라는 것은 **매우 낮은 SNR로 띄엄띄엄 도착하는 피드백 채널**과 같다. 추정 분산이 크므로 학습이 느리고 불안정하다. 반면 SSL은 입력 전체가 정답이므로 **고-SNR full-feedback** 상황이다.
:::

# VAE (Variational Auto-Encoder) {#sec-vae}

> 오늘의 메인. AE에 "잠재 공간이 가우시안 분포를 따라야 한다"는 **추가 제약**을 거는 것이 VAE다.

## 한 줄 요약

VAE = **AE + "잠재 표현 $z$가 $\mathcal N(0,I)$를 따르도록 강제하는 정규화"**. 이로써 잠재 공간을 완전히 통제할 수 있고(→ 매끄러운 생성·보간), 직접 계산 불가능한 $p(x)$를 **변분 추론(variational inference)** 으로 우회해 학습한다.

## 생성 모델로서의 목표

데이터 $X=\{x_1,\dots,x_n\}$이 주어졌을 때, 이를 설명하는 분포 $p(X)$를 찾고 싶다. 그런데 $p(X)$를 직접 모델링하기는 어렵다. 그래서 **잠재 변수 $z$를 도입**한다.

$$
p(x) = \sum_{z} p(x\mid z)\,p(z)
\quad\xrightarrow{\text{연속}}\quad
p(x) = \int p(x\mid z)\,p(z)\,dz
$$

여기서 **사전분포(prior)** $p(z)=\mathcal N(0,I)$로 고정한다. 해석: "먼저 $z$를 가우시안에서 뽑고($z\sim p(z)$), 그로부터 $x$를 생성한다($x\sim p(x\mid z)$)."

### 왜 하필 가우시안 잠재인가?

1. **해석적으로 다루기 쉽다(analytically tractable).** 가우시안은 미분·적분·샘플링이 모두 잘 정의되고, KL 등도 닫힌 형태(closed form)로 나온다.
2. **샘플링이 쉽다.** 거의 모든 하드웨어/라이브러리에 가우시안 샘플러가 있다.
3. **표현력이 충분하다.** 자연의 많은 현상이 가우시안을 따른다(중심극한정리). 그러니 잠재 공간을 가우시안으로 가정해도 무리가 없고, 자연 현상을 통제된 방식으로 모델링할 수 있다.

## 적분이 다루기 어렵다 (intractability)

문제: $p(x)=\int p(x\mid z)p(z)\,dz$에서 $p(x\mid z)$는 **디코더(비선형 신경망)** 라 적분이 닫힌 형태로 안 나온다.

::: {.callout-note}
## "어려운 적분"을 만났을 때 — 두 갈래
**(가) 몬테카를로 샘플링(Monte Carlo).** 적분 = "넓이 구하기". 이상한 모양의 영역 넓이를, 사각형 안에 화살을 무수히 던져 영역 안에 들어간 비율로 근사한다(다트 게임). 즉 $\int f \approx \frac{1}{M}\sum_m f(z_m)$.
**문제:** 이미지/오디오/텍스트의 잠재 공간은 **너무 고차원**이라 샘플로 적분을 근사하기가 사실상 불가능(차원의 저주).

**(나) 변분 추론(Variational Inference).** 더 샘플 효율적인 대안. → VAE가 택한 길.
:::

## 변분 추론과 ELBO 유도

### 핵심 항등식

임의의 분포 $q(z)$에 대해($\int q(z)dz=1$ 이용), 베이즈 정리 $p(x)=\frac{p(x,z)}{p(z\mid x)}$를 써서:

$$
\begin{aligned}
\log p(x) &= \log p(x)\cdot 1 = \log p(x)\int q(z)\,dz = \int q(z)\log p(x)\,dz\\
&= \int q(z)\log \frac{p(x,z)}{p(z\mid x)}\,dz \qquad (\because \text{Bayes})\\
&= \int q(z)\big(\log p(x,z) - \log p(z\mid x)\big)\,dz\\
&= \mathbb{E}_{z\sim q}\big[\log p(x,z) - \log p(z\mid x)\big]
\end{aligned}
$$

### 변분족(variational family) 도입 → ELBO + KL

이제 $q$를 파라미터화한 $q_\phi(z)$로 둔다(이것이 **인코더**, 추론 네트워크). $\frac{q_\phi(z)}{q_\phi(z)}=1$을 끼워 넣고 전개하면:

$$
\begin{aligned}
\log p(x)
&= \int q_\phi(z)\log\frac{p(x,z)}{p(z\mid x)}\,dz
= \int q_\phi(z)\log\!\left[\frac{p(x,z)}{q_\phi(z)}\cdot\frac{q_\phi(z)}{p(z\mid x)}\right]dz\\
&= \underbrace{\mathbb{E}_{q}\big[\log p(x,z) - \log q_\phi(z)\big]}_{\textbf{ELBO}\;(\text{Evidence Lower BOund})}
\;+\;
\underbrace{\mathrm{KL}\!\big[\,q_\phi(z)\,\|\,p(z\mid x)\,\big]}_{\ge\,0}
\end{aligned}
$$

::: {.callout-important}
## 왜 이 분해가 결정적인가
- $\log p(x)$는 $\phi$에 대해 **상수**(우리가 손댈 수 없는 진짜 값, "evidence").
- KL은 **항상 $\ge 0$** (KL의 비음수성). 따라서 $\log p(x) \ge \text{ELBO}$ → "Evidence **Lower** Bound".
- 우리가 진짜 줄이고 싶은 것은 $\mathrm{KL}[q_\phi(z)\|p(z\mid x)]$ (내 근사 사후분포와 진짜 사후분포의 거리)인데, **진짜 사후분포 $p(z\mid x)$를 모르므로 KL을 직접 못 줄인다.**
- 대신 좌변이 상수이므로, **ELBO를 최대화 = KL을 최소화.** ELBO는 계산 가능하다. → **ELBO를 최대화하자!**
:::

### ELBO 전개 → 복원 항 + 정규화 항

$p(x,z)=p(x\mid z)p(z)$를 대입:

$$
\begin{aligned}
\text{ELBO}
&= \mathbb{E}_{q}\big[\log p(x,z) - \log q_\phi(z)\big]
= \mathbb{E}_{q}\big[\log p(x\mid z) + \log p(z) - \log q_\phi(z)\big]\\
&= \mathbb{E}_{q}\big[\log p(x\mid z)\big] + \mathbb{E}_{q}\big[\log p(z) - \log q_\phi(z)\big]\\
&= \mathbb{E}_{q}\big[\log p(x\mid z)\big] - \mathbb{E}_{q}\big[\log q_\phi(z) - \log p(z)\big]\\
&= \underbrace{\mathbb{E}_{q}\big[\log p(x\mid z)\big]}_{\textbf{복원(Reconstruction)}}
\;-\;
\underbrace{\mathrm{KL}\!\big(q_\phi(z)\,\|\,p(z)\big)}_{\textbf{정규화(Regularization)}}
\end{aligned}
$$

| 항 | 의미 | 역할 |
|---|---|---|
| **복원항** $\mathbb{E}_q[\log p(x\mid z)]$ | $z$로부터 $x$를 얼마나 잘 복원하는가 (디코더 품질) | 데이터 충실도 |
| **정규화항** $\mathrm{KL}(q_\phi(z)\|p(z))$ | 잠재 $z$가 prior $\mathcal N(0,I)$를 얼마나 잘 따르는가 | 잠재 공간 통제 |

ELBO 최대화는 이 둘의 **균형**을 맞춘다: "$z$로 $x$를 잘 복원하되, $z$의 분포는 $\mathcal N(0,I)$에 가깝게."

## VAE의 손실 함수와 reparameterization trick

ELBO는 **최대화** 대상이므로, 부호를 뒤집어 **손실(최소화)** 로 쓴다. (디코더 $p_\theta(x\mid z)$, 인코더 $q_\phi(z\mid x)$)

$$
\boxed{\;
\mathcal{L}_{\text{VAE}}(\theta,\phi)
= \underbrace{-\,\mathbb{E}_{q_\phi}\!\big[\log p_\theta(x\mid z)\big]}_{\approx\ \text{MSE/CE 복원 손실}}
\;+\;
\underbrace{\mathrm{KL}\!\big(q_\phi(z\mid x)\,\|\,p(z)\big)}_{\text{닫힌 형태 (가우시안)}}
\;}
$$

::: {.callout-note}
## 표기 주의 (정밀성)
- 본 노트는 **표준(Kingma & Welling) 표기**를 따른다: 인코더/추론망 $q_\phi$의 파라미터를 $\phi$, 디코더/생성망 $p_\theta$의 파라미터를 $\theta$로 둔다.
- 일부 자료는 인코더에 $\theta$, 디코더에 $\phi$를 붙이기도 하므로(역할이 바뀐 표기), 어떤 망을 가리키는지를 기준으로 읽어야 혼동이 없다. **중요한 것은 기호가 아니라 "추론망 vs 생성망"이라는 역할 구분**이다.
:::

복원항은 $x$와 $\hat x$의 차이로 정의되므로, 가정에 따라 **MSE 손실**(가우시안 likelihood) 또는 **교차 엔트로피**(베르누이 likelihood)가 된다. KL항은 두 가우시안 사이라 **닫힌 형태**로 떨어진다(아래 부록 식).

### 문제: 샘플링은 미분 불가능

학습하려면 $\hat x \to z \to x$로 역전파해야 하는데, $z\sim q_\phi(z\mid x)$는 **확률적 샘플링**이라 그래디언트가 통과하지 못한다.

### 해법: Reparameterization trick

확률성을 **입력 쪽의 외생 잡음 $\epsilon$** 으로 빼낸다.

$$
\boxed{\;z = \mu_\phi(x) + \sigma_\phi(x)\odot \epsilon,\qquad \epsilon\sim\mathcal N(0,I)\;}
$$

이제 $z$는 $\mu_\phi,\sigma_\phi$(신경망 출력)의 **결정론적 함수** + 고정 잡음이다. 평균 $\mu$는 인코더에, 분산 $\sigma$도 인코더에 의존하는 미분 가능한 식이 되어, $\epsilon$만 무작위로 두고 **$\phi,\theta$에 대해 정상적으로 역전파**할 수 있다.

```{mermaid}
flowchart LR
    x[x] --> E[Encoder q_φ]
    E --> mu[μ_φ x]
    E --> sig[σ_φ x]
    eps["ε ~ N0,I"] --> z
    mu --> z["z = μ + σ⊙ε"]
    sig --> z
    z --> D[Decoder p_θ] --> xh[x̂]
    xh -. L_MSE .-> x
    z -. L_KL .-> prior["N0,I"]
```

## VAE의 결과와 장점

- AE보다 **덜 흐릿한(less blurry)** 샘플을 생성한다.
- **잠재 공간이 통제 가능(controllable)** 하다. 10차원 가우시안 잠재라면 각 차원이 의미(semantic)에 대응할 수 있다. 예: 1번 차원을 $-\infty\to+\infty$로 sweep하면 여성→남성으로, 2번 차원을 sweep하면 머리 스타일이 바뀌는 식의 **disentangled 생성·보간(interpolation)** 이 가능.
- 잠재 공간이 분석 가능해, **어떤 데이터가 더 필요한지** 등 학습 과정을 진단할 수 있다(AE의 불투명한 잠재 공간과 대비).

::: {.callout-tip}
## 무선통신 관점 — VAE의 세 가지 매핑
1. **Reparameterization trick = AWGN 모델.** $z=\mu+\sigma\epsilon$은 정확히 **신호 + 가우시안 잡음** 모델이다. 결정론적 신호 성분($\mu$)에 스케일된 백색 잡음($\sigma\epsilon$)을 더한 것. 무선에서 늘 쓰는 $y = s + n,\ n\sim\mathcal N(0,\sigma^2)$와 동형. 덕분에 "기댓값에 대한 그래디언트(pathwise derivative)"를 잡을 수 있다.
2. **가우시안 잠재 prior = 가우시안 입력 코드북.** AWGN 채널의 용량 달성 입력 분포가 가우시안인 것과 같은 맥락 — 가우시안은 "최대 엔트로피/최적 표현"의 자연스러운 선택.
3. **ELBO = 다루기 힘든 likelihood의 하한.** 직접 못 구하는 marginal likelihood를 **계산 가능한 하한으로 대체해 최적화**하는 전략은, 검출/추정에서 다루기 힘든 우도를 **변분 하한·EM**으로 푸는 것과 동일한 발상이다. KL 정규화는 잠재의 "전력(분산)을 $\mathcal N(0,I)$로 제한"하는 **전력 제약**처럼 작동한다.
:::

# GAN (Generative Adversarial Network) {#sec-gan}

> Goodfellow et al., NeurIPS 2014. VAE의 구조를 빌리되, **MSE 대신 적대적 손실(adversarial loss)** 을 쓴다.

## 동기: MSE의 흐릿함을 넘어서

VAE/AE의 MSE 복원은 평균적으로 안전한 픽셀값을 택해 **흐릿한(blurry)** 결과를 낳기 쉽다. GAN은 **adversarial loss** 를 추가해 디테일이 살아있는 **선명한** 이미지를 만든다.

## 구성: 생성자 G와 판별자 D

```{mermaid}
flowchart LR
    z["랜덤 벡터 z ~ p(z)"] --> G[Generator G]
    G --> fake["가짜 이미지 G(z)"]
    real["진짜 이미지 x"] --> D
    fake --> D[Discriminator D]
    D --> out["Real or Fake?<br/>D(·) ∈ (0,1)"]
```

- **Generator $G(z)$**: 랜덤 벡터 $z$ → 이미지. (좋은 $G$ = 생성 이미지가 진짜처럼 보임)
- **Discriminator $D(x)$**: 이미지 → "진짜일 확률". (좋은 $D$ = 진짜/가짜를 잘 구분)
- **경쟁을 통한 학습**: G는 D를 속이려 하고, D는 안 속으려 한다. 서로 적대적으로 공격하며 함께 강해진다.

## Minimax 정식화

$$
\boxed{\;
\min_{G}\max_{D}\;
\mathbb{E}_{x\sim q_{\text{data}}(x)}\big[\log D(x)\big]
\;+\;
\mathbb{E}_{z\sim p(z)}\big[\log\big(1 - D(G(z))\big)\big]
\;}
$$

물리적 의미: $\log(\text{$x$가 진짜일 확률}) + \log(1-\text{$G(z)$가 진짜일 확률})$.

- 이 값이 **커질수록 $D$가 좋다** → $D$에 대해 **최대화**.
- 이 값이 **작아질수록 $G$가 좋다**(D를 잘 속임) → $G$에 대해 **최소화**.
- 이런 문제를 **Minimax 문제**, 즉 **영합(zero-sum) 비협조 게임**이라 한다.

::: {.callout-note}
## 심화 — 최적 판별자와 JS 발산
$G$를 고정했을 때 최적 판별자는
$$
D^*(x) = \frac{q_{\text{data}}(x)}{q_{\text{data}}(x) + p_g(x)}.
$$
이를 대입하면 목적함수는
$$
V(G,D^*) = -\log 4 + 2\cdot \mathrm{JSD}\big(q_{\text{data}}\,\|\,p_g\big)
$$
가 된다($\mathrm{JSD}$ = Jensen–Shannon divergence). 즉 **G를 최소화한다는 것은 생성 분포 $p_g$를 진짜 분포 $q_{\text{data}}$에 JS 발산 기준으로 일치시키는 것**이다. 전역 최적은 $p_g = q_{\text{data}}$일 때이며 그때 $V=-\log 4$. (부록 코드에서 수치로 검증.)
:::

## 학습 절차 (세 단계 업데이트)

```{mermaid}
flowchart TB
    s1["① D를 진짜로 학습:<br/>진짜 데이터에 'real' 출력하도록 D 갱신"]
    s2["② D를 가짜로 학습:<br/>가짜 데이터에 'fake' 출력하도록 D 갱신"]
    s3["③ G를 학습:<br/>가짜 데이터에 D가 'real'이라 말하도록 G 갱신"]
    s1 --> s2 --> s3 --> s1
```

## 학습의 어려움

GAN 학습은 악명 높게 어렵다.

| 문제 | 증상 |
|---|---|
| **Non-convergence** (비수렴) | 파라미터가 진동·불안정하며 수렴하지 않음 |
| **Mode collapse** (모드 붕괴) | G가 비슷한 샘플만 양산(다양성 상실) |
| **Diminished gradient** (그래디언트 소실) | D가 너무 강해져 G의 그래디언트가 사라지고 학습 정체 |

- D와 G의 **불균형**이 위 문제를 일으킨다. 하이퍼파라미터 선택이 "예술의 경지(work of art)".
- 안정화 변형: **LSGAN, WGAN, WGAN-GP, BEGAN** 등.
- 근본적 대안으로 **확산 모델(diffusion)** 등장: 학습은 느리지만 **안정적**이고 품질이 뛰어남.

## GAN은 왜 효과적인가: Hard negative

D는 G에게 **매우 까다로운 음성 샘플(hard negative)** 을 끊임없이 제공한다. 결정 경계 근처의 "거의 진짜 같은 가짜"를 만들어 G를 압박하므로, 단순 MSE보다 훨씬 강한 학습 신호가 된다.

::: {.callout-warning}
## 적대적 예제(Adversarial Example) ≠ 적대적 학습(Adversarial Learning)
혼동 주의. **적대적 예제**는 입력에 미세한 섭동을 가해 신경망이 엉뚱한 출력을 내게 만드는 것이다.

- 예: 정지 표지판에 미세한 패턴을 더하면 자율주행 AI가 "서행"으로 오인 → 위험.
- 예: 고양이 이미지에 사람 눈엔 안 보이는 텍스처를 넣으면 CNN이 "데스크톱 컴퓨터"라고 높은 확률로 단언.

이는 **신경망이 입력의 작은 변화에 극도로 민감(취약)** 하다는 증거다. GAN의 "adversarial"은 이 *현상*과 단어만 공유할 뿐, **두 네트워크가 경쟁한다**는 다른 철학을 가진다.
:::

::: {.callout-tip}
## 무선통신 관점 — GAN = 재밍 게임, 적대적 예제 = 정밀 간섭
- **Minimax = 재머(jammer) 대 송수신기의 영합 게임.** D(수신기)는 진짜/가짜를 구분(검출)하려 하고, G(재머)는 검출을 회피할 신호를 합성한다. 평형(Nash equilibrium)은 worst-case 강건 설계의 saddle point와 같다.
- **적대적 예제 = 결정 경계에 정렬된 저전력 간섭.** 아주 작은 섭동($\|\delta\|$ 작음)으로 검출기를 오작동시키는 것은, 결정 경계 법선 방향에 맞춘 **최소 전력 교란 신호**와 같다. 신경망의 민감도는 곧 분류기의 **나쁜 조건수(ill-conditioning)** — 입력의 미세 변화가 출력에서 증폭된다.
- **Hard negative = 경계 근처의 고-난이도 샘플.** 검출 이론의 "임계 SNR 부근 시험 신호"처럼, 가장 정보량 많은 학습 신호를 제공한다.
:::

# 정리 {#sec-summary}

| 주제 | 핵심 한 줄 |
|---|---|
| **Mamba** | 선형 시간 SSM. Transformer보다 싸지만 더 강하진 않음. 하이브리드가 대세 |
| **멀티모달 5과제** | 표현·정렬·융합·변환·공동학습 — 오늘날 하나의 큰 신경망으로 흡수, 효율이 경쟁력 |

| **AE** | 정보 병목으로 핵심만 압축·복원. 가장 기본적인 자기지도 과제 |
| **VAE** | AE + 가우시안 잠재 정규화. ELBO 최대화 = 복원 + KL 정규화. reparameterization으로 역전파 |
| **GAN** | G vs D의 minimax 영합 게임 = JS 발산 최소화. 선명하지만 불안정 → 확산 모델로 이어짐 |

## 가우시안 KL의 닫힌 형태 (VAE 정규화항) {#sec-app-kl}

$q=\mathcal N(\mu,\sigma^2)$, $p=\mathcal N(0,1)$일 때,
$$
\mathrm{KL}(q\|p) = \frac{1}{2}\sum_{j}\big(\mu_j^2 + \sigma_j^2 - \log\sigma_j^2 - 1\big).
$$

```{python}
#| label: kl-closed-form
#| code-fold: false
import numpy as np
rng = np.random.default_rng(0)

def gaussian_kl_closed(mu, var):
    # KL( N(mu, var) || N(0, I) ), per-dimension diagonal Gaussian
    return 0.5 * np.sum(mu**2 + var - np.log(var) - 1)

# Monte Carlo 검증
mu, sig = 0.7, 1.3
closed = gaussian_kl_closed(np.array([mu]), np.array([sig**2]))
z = rng.normal(mu, sig, size=2_000_000)
logq = -0.5*np.log(2*np.pi*sig**2) - (z-mu)**2/(2*sig**2)
logp = -0.5*np.log(2*np.pi)        - z**2/2
mc = np.mean(logq - logp)
print(f"KL closed-form = {closed:.5f}   Monte Carlo = {mc:.5f}")
```

## Reparameterization trick + VAE 손실 (forward) {#sec-app-vae}

```{python}
#| label: vae-loss
#| code-fold: false
def reparameterize(mu, logvar, eps=None):
    # z = mu + sigma * eps,  sigma = exp(0.5*logvar)
    std = np.exp(0.5*logvar)
    if eps is None:
        eps = rng.normal(size=mu.shape)
    return mu + std*eps                       # AWGN 모델: 신호 mu + 잡음 std*eps

def vae_loss(x, x_hat, mu, logvar):
    recon = np.mean(np.sum((x - x_hat)**2, axis=1))      # MSE 복원항
    kl    = np.mean(0.5*np.sum(np.exp(logvar) + mu**2 - 1 - logvar, axis=1))
    return recon + kl, recon, kl

# 더미 예시 (배치 4, 잠재 3, 입력 5)
mu     = rng.normal(size=(4,3))
logvar = rng.normal(size=(4,3))*0.1
z      = reparameterize(mu, logvar)
x      = rng.normal(size=(4,5))
x_hat  = rng.normal(size=(4,5))               # 실제로는 decoder(z)
total, recon, kl = vae_loss(x, x_hat, mu, logvar)
print(f"z.shape={z.shape}  total={total:.4f}  recon={recon:.4f}  kl={kl:.4f}")
```

## CLIP 대칭 대조 손실 {#sec-app-clip}

```{python}
#| label: clip-loss
#| code-fold: false
def clip_loss(I, T, tau=1.0):
    I = I/np.linalg.norm(I, axis=1, keepdims=True)
    T = T/np.linalg.norm(T, axis=1, keepdims=True)
    logits = I @ T.T / tau                    # 상관(correlation) 행렬, 대각이 정답
    N = len(I)
    def ce_rows(L):
        L = L - L.max(1, keepdims=True)
        logp = L - np.log(np.exp(L).sum(1, keepdims=True))
        return -logp[np.arange(N), np.arange(N)].mean()
    return 0.5*(ce_rows(logits) + ce_rows(logits.T))   # 이미지→텍스트 + 텍스트→이미지

N, d = 8, 16
base = rng.normal(size=(N, d))
aligned = clip_loss(base, base + 0.01*rng.normal(size=(N, d)))
random_ = clip_loss(rng.normal(size=(N, d)), rng.normal(size=(N, d)))
print(f"정렬된 쌍 loss = {aligned:.4f}   무작위 쌍 loss = {random_:.4f}   (log N = {np.log(N):.4f})")
```

## SigLIP 시그모이드 손실 {#sec-app-siglip}

```{python}
#| label: siglip-loss
#| code-fold: false
def sigmoid(u): return 1/(1+np.exp(-u))

def siglip_loss(I, T, t=10.0, b=-10.0):
    I = I/np.linalg.norm(I, axis=1, keepdims=True)
    T = T/np.linalg.norm(T, axis=1, keepdims=True)
    S = I @ T.T                                # 상관 행렬
    N = len(I)
    Y = -np.ones((N, N)); np.fill_diagonal(Y, 1.0)   # 대각=+1(정답), 나머지=-1
    logits = Y*(t*S + b)
    return -np.mean(np.log(sigmoid(logits) + 1e-12)) # 쌍별 독립 이진 결정

print(f"SigLIP loss = {siglip_loss(base, base):.4f} (완전 정렬)")
```

## GAN: 최적 판별자와 JS 발산 항등식 검증 {#sec-app-gan}

본문의 $V(G,D^*) = -\log 4 + 2\,\mathrm{JSD}(q_{\text{data}}\|p_g)$를 이산 분포로 확인한다.

```{python}
#| label: gan-jsd
#| code-fold: false
p = np.array([0.1, 0.2, 0.3, 0.4])   # q_data
q = np.array([0.4, 0.3, 0.2, 0.1])   # p_g
D_star = p/(p+q)                                         # 최적 판별자
V = np.sum(p*np.log(D_star)) + np.sum(q*np.log(1-D_star))
m = 0.5*(p+q)
KL = lambda a,b: np.sum(a*np.log(a/b))
JSD = 0.5*KL(p,m) + 0.5*KL(q,m)
print(f"V(G, D*)            = {V:.5f}")
print(f"-log4 + 2*JSD       = {-np.log(4) + 2*JSD:.5f}")
print(f"전역최적(p_g=q_data)일 때 V = -log4 = {-np.log(4):.5f}")
```
