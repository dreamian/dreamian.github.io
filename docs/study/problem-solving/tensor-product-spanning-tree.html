1. 문제

방향 그래프 \(G\) 와, 정점 \(1 \to 2 \to \cdots \to i\) 로 이어지는 방향 경로 \(P_i\) 가 주어진다. 두 그래프의 텐서 곱 \(G \times P_i\) 는 정점 집합이 \(V(G) \times V(P_i)\) 이고, \((u_1, k_1)\) 과 \((u_2, k_2)\) 사이에 간선이 있으려면 \(G\) 에 \(u_1 \to u_2\) 가 있고 동시에 경로에 \(k_1 \to k_2\) 가 있어야 한다.

경로의 간선은 \(k \to k{+}1\) 뿐이므로, 결과를 무향 그래프로 보면 다음과 같이 단순해진다.

Note층 그래프 해석

\(G\) 를 \(i\) 개의 층으로 쌓는다. \(G\) 의 간선 \(u \to v\) (가중치 \(w\)) 는 인접한 모든 층 쌍에 대해 무향 간선

\[(u, k) - (v, k{+}1), \quad k = 0, 1, \dots, i{-}2\]

를 만든다. 특히 self-loop \(u \to u\) 는 같은 정점을 위아래 층으로 잇는 수직 연결선 \((u,k)-(u,k{+}1)\) 이 된다. 같은 층 안의 간선은 존재하지 않는다.

질의 \(i = 1, \dots, Q\) 에 대해 \(G \times P_{i+1}\) 의 최소 스패닝 트리(MST) 가중치를 출력한다. 즉 층 수 \(L = i+1\) 이 \(2\) 부터 \(Q+1\) 까지 움직인다. 제약은 \(N, Q \le 10^5\), \(M \le 2 \times 10^5\), 간선 가중치 \(1 \le w \le 30\) 이며, 질의되는 모든 \(L\) 에서 그래프는 연결임이 보장된다.

층마다 정점이 \(N\) 개씩 늘어 \(L\) 이 커지면 정점 수가 \(N \cdot L\) 까지 가므로, 각 \(L\) 마다 Kruskal 을 새로 돌리는 것은 불가능하다. 핵심은 가중치가 30 이하의 작은 정수라는 점과 층을 늘려도 연결성은 단조 증가한다는 구조다.

2. MST 을 컴포넌트 수의 합으로 (Abel 합)

가중치가 \(1\) 부터 \(30\) 까지의 정수이므로, 임계값별 컴포넌트 수로 MST 무게를 분해할 수 있다. 고정된 \(L\) 에 대해

\[C_L(w) = (\text{가중치} \le w \text{ 인 간선만 사용했을 때의 연결 컴포넌트 수})\]

로 두자. 전체 정점 수를 \(V = N L\) 이라 하면, Kruskal 에서 가중치 \(\le w\) 인 간선을 모두 처리한 뒤 남는 트리의 간선 수는 \(V - C_L(w)\) 이다. 따라서 MST 에서 가중치가 정확히 \(w\) 인 간선의 개수를 \(n_w\) 라 하면

\[S(w) := \sum_{w' \le w} n_{w'} = V - C_L(w)\]

가 성립한다. 이제 MST 무게에 Abel 합(부분합)을 적용한다.

\[ \text{MST}(L) = \sum_{w=1}^{30} w\, n_w = 30\, S(30) - S(0) - \sum_{w=1}^{29} S(w). \]

연결이 보장되므로 \(S(30) = V - 1\), 간선이 없을 때 \(S(0) = V - C_L(0) = 0\) 이다. 대입하면

\[ \text{MST}(L) = 30(V-1) - \sum_{w=1}^{29}\bigl(V - C_L(w)\bigr) = V - 30 + \sum_{w=1}^{29} C_L(w). \]

\(C_L(0) = V\) 이므로 최종적으로 다음 깔끔한 형태를 얻는다.

Important핵심 항등식

\[\boxed{\;\text{MST}(L) = \sum_{w=0}^{29} C_L(w) \;-\; 30\;}\]

이 식은 그래프가 연결이기만 하면(\(C_L(30) = 1\)) 항상 성립한다. 최대 가중치가 30 미만이어도 그 이상의 \(w\) 에서는 \(C_L(w) = 1\) 이 되어 자동으로 들어맞는다.

이로써 문제는 각 임계값 \(w\) 에 대해, 모든 층 \(L\) 의 컴포넌트 수 \(C_L(w)\) 를 구하라로 환원된다. 임계값은 \(0 \dots 29\) 의 30 가지뿐이다.

예제로 확인

예제 그래프(\(N=4\), 간선 8개, 최대 가중치 4)에서 임계값별 컴포넌트 수 표는 다음과 같다. 최대 가중치가 4 이므로 \(w \ge 4\) 에서는 전체 그래프가 되어 \(C_L(w) = 1\) 로 고정된다.

\(L\) \(C_L(0)\) \(C_L(1)\) \(C_L(2)\) \(C_L(3)\) 합 \(-4\) = MST
2 8 7 4 1 16
3 12 10 4 1 23
4 16 13 4 1 30
5 20 16 4 1 37

(\(w \ge 4\) 의 26개 항이 모두 1 이므로 \(\sum_{w=0}^{29} C_L(w) - 30 = \bigl[C_L(0)+\cdots+C_L(3)\bigr] + 26 - 30\) 으로 줄어 표의 마지막 열이 된다.) 출력 16 23 30 37 과 일치한다.

여기서 한 가지 패턴이 눈에 띈다. \(L\) 이 1 늘 때 MST 증가량이 \(7\) 로 일정하다. \(C_L(2)\) 와 \(C_L(3)\) 은 이미 \(L=2\) 부터 변하지 않고, \(C_L(0)\) 은 항상 \(+4\), \(C_L(1)\) 은 \(+3\) 씩 늘기 때문이다. 이 등차 수렴은 뒤에서 알고리즘을 가속하는 열쇠가 된다.

3. 한 임계값에서 모든 층의 컴포넌트 수: 슬라이딩 2층 Union-Find

이제 가중치 조건을 떼어 간선을 무가중으로 보고, 한 임계값에서 \(C_L(w)\) 를 \(L = 2, \dots, L_{\max}\) 에 대해 한 번의 스윕으로 구한다.

층 그래프는 인접한 두 층 사이에만 간선이 있다. 따라서 바닥 층부터 위로 올라가며 연속한 두 층 \(\{k, k{+}1\}\) 만 보는 슬라이딩 윈도우 union-find 를 유지할 수 있다. 윈도우를 \(\{k{-}1, k\}\) 에서 \(\{k, k{+}1\}\) 로 올릴 때, 층 \(k{-}1\) 에만 속하고 층 \(k\) 에 닿지 않는 컴포넌트는 더 이상 위로 자랄 수 없으므로 영구히 확정된다. 이런 닫힌 컴포넌트를 누적 카운터에 더하고, 층 \(k\) 에 닿는 컴포넌트만 다음 윈도우로 이어 보낸다.

Note컴포넌트 수의 분해

\(L\) 층 그래프의 컴포넌트 수는

\[C_L(w) = \underbrace{|P_L|}_{\text{상단 분할의 살아있는 클래스 수}} \;+\; \underbrace{\text{(아래로 빠져나가 확정된 컴포넌트 수의 누적)}}_{\text{닫힌 컴포넌트}}\]

로 나뉜다. 위로 향하는 간선이 하나도 없는 클래스(자신을 출발점으로 하는 간선이 없는 정점들로 이루어진 클래스)는 더 자라지 못하고 매 층 확정되어 빠진다.

손으로 따라가는 작은 예제

가장 단순한 비자명 사례로 감을 잡자. \(N = 2\), 간선은 \(0 \to 1\) 하나뿐(가중치 1). self-loop 가 없다.

직접 세어 보면 \(C_L(1)\) 은:

  • \(L=2\): 정점 \((0,0),(1,0),(0,1),(1,1)\), 간선 \((0,0)-(1,1)\) 하나. 컴포넌트는 \(\{(0,0),(1,1)\}, \{(1,0)\}, \{(0,1)\}\) → \(C_2 = 3\).
  • \(L=3\): 간선 \((0,0)-(1,1)\), \((0,1)-(1,2)\). 컴포넌트 4개 → \(C_3 = 4\).
  • \(L=4\): \(C_4 = 5\). 일반적으로 \(C_L = L + 1\).

알고리즘의 변수로 추적하면(size_p = 현재 상단에서 살아있는 클래스 수 = \(n -\) 누적 병합 수, iso_s = 아래로 빠진 닫힌 컴포넌트 누적):

\(L\) size_p iso_s \(C_L\) = 합
2 2 1 3
3 2 2 4
4 2 3 5

정점 0 은 출발 간선 \(0 \to 1\) 이 있어 위로 자라는 클래스, 정점 1 은 출발 간선이 없어 매 층 확정되어 빠지는 클래스다. 그래서 상단의 살아있는 클래스가 항상 2개, 닫힌 컴포넌트가 매 층 1개씩 쌓여 \(C_L = 2 + (L-1) = L + 1\) 이 된다. 손으로 센 값과 정확히 맞는다.

4. carry pointer 와 예약 병합 (구현)

윈도우를 올릴 때마다 union-find 를 통째로 새로 만들면 느리다. 대신 컴포넌트마다 위층으로 뻗는 대표 이웃을 가리키는 carry pointer nxt_[ra] 를 둔다. 이것이 reset 없이 연결성을 다음 층으로 이어 주는 장치다.

Tip같은 출발점에서 갈라진 이웃은 다음 층에서 만난다

정점 \(x\) 의 출발 간선이 여러 개라면, 그 이웃들은 모두 같은 하단 클래스 \(\{x\}\) 를 공유하므로 다음 층에서 서로 병합되어야 한다. 이를 layer 버킷에 schedule_(첫 이웃, 다른 이웃, 2) 로 예약해 둔다. 두 클래스가 층 \(L\) 에서 병합되면 그들의 carry target 도 층 \(L{+}1\) 에서 만나야 하므로 schedule_(nxt_[ra], nxt_[rb], L+1) 로 연쇄 예약한다.

각 병합은 평생 한 번만 일어나고(총 \(N-1\) 회 이하), union-by-size 로 작은 쪽을 큰 쪽에 붙이므로 전체 작업량이 거의 선형이다. 위층으로 향하는 간선이 없어진 클래스(nxt_ == -1)의 개수 empty_classes 는 병합 때마다 \(O(1)\) 로 갱신해 매 층의 iso 값을 만든다.

Importantsource 와 target 의 역할 분리

처음 시도에서, 한 라운드 안에서 정점이 갖는 하단 층의 source 역할과 상단 층의 target 역할을 단일 union-find 로 섞어 처리하다가 target 리스트가 오염되는 버그를 만났다. 해결책은 위의 nxt_ 포인터 전파다. source 정점과 target 정점을 같은 구조 안에서 라운드 도중에 합치지 않으므로 두 역할이 항상 분리된다.

5. 등차 수렴과 외삽

3절 예제에서 본 것처럼, 예약된 병합이 모두 소진되면(l >= max_sched_) 그 이후로는 매 층 같은 증가량(iso_prev)만 더해진다. 상단 분할이 더 이상 거칠어지지 않고 안정 상태에 도달했기 때문이다. 이때부터는 루프를 돌 필요 없이 남은 층을 일정한 증가분으로 외삽해 채운다.

\[C_L(w) = C_{L^\*}(w) + (L - L^\*) \cdot \text{iso}_{\text{prev}}, \quad L \ge L^\*.\]

이 단축이 없으면, 두 평행 사슬이 양 끝에서만 만나는 적대적 입력에서 안정화까지 \(\Theta(N)\) 층이 걸려 임계값마다 \(O(N^2)\) 가 될 수 있다. 외삽 덕분에 \(Q\) 가 커도 임계값당 거의 선형을 유지한다.

6. 복잡도와 검증

임계값 30개마다 CSR 재구성 \(O(N+M)\) 과 슬라이딩 union-find \(O((N+M+Q)\,\alpha)\) 가 들어, 테스트케이스당

\[O\bigl(30 \cdot (N+M+Q)\,\alpha(N)\bigr)\]

이고 메모리는 \(O(N+M+Q)\) 다. 모든 상태는 전역 배열과 반복문으로 처리되므로 1MB 스택 제한에 안전하다.

Note교차 검증 결과
  • 무작위 스트레스 2000건 + 다중 테스트케이스 200건 + 중간 규모(\(N=100, Q=200\)): 전수 Kruskal brute force 와 전부 일치.
  • 계측 버전으로 run_threshold_(w) 가 모든 \(L\) 에 대해 \(C_L(w)\) 를 정확히 만드는지 임계값별 200건 추가 확인.
  • 최대 제약(\(N = Q = 10^5\), \(M = 2 \times 10^5\), 두 평행 사슬 적대 입력)에서 약 0.14초.
Warning테스트케이스 사이 상태 초기화

par_ / sz_ / nxt_ 는 run_threshold_ 진입 시 매번 초기화하고, 답 누적 배열 ans_ 는 테스트케이스마다 0 으로 되돌린다. layer 버킷 bucket_head_ 는 슬라이딩 도중 소비하며 \(-1\) 로 복원해, 다음 임계값에서 깨끗한 상태로 시작하도록 한다. 이 리셋을 빠뜨리면 다중 테스트케이스에서 조용히 틀린다.

7. 디버깅에서 배운 점

  • source/target 역할 분리가 이 풀이의 정확성 핵심이었다. 한 라운드 안에서 정점의 두 역할을 union-find 로 섞으면 carry 정보가 오염된다.
  • scanf 의 형식 지정자 불일치(%d vs %lld)는 조용한 미정의 동작을 낳는다. 누적 답은 \(L \cdot N\) 규모까지 커질 수 있으므로 long long + %lld 로 받는다.
  • 단조성 전제 확인이 중요하다. 슬라이딩 윈도우가 성립하려면 “층을 늘릴 때 연결성이 단조 증가”한다는 구조가 깔려 있어야 한다.
  • 적대적 입력(두 평행 사슬)을 미리 상정해 두지 않으면, 평균적으로 빠른 안정화에만 의존하다가 최악 \(O(N^2)\) 에 걸린다. 외삽으로 안정 상태를 명시적으로 단축해 막았다.

Codes

#include <stdio.h>

#define MAXN 100005
#define MAXM 200005
#define MAXL 100005
#define MAXS 300010

int eu_[MAXM], ev_[MAXM], ew_[MAXM];
int par_[MAXN], sz_[MAXN], nxt_[MAXN];
int deg_[MAXN], head_[MAXN + 1], pos_[MAXN], adj_[MAXM];
int sa_[MAXS], sb_[MAXS], snext_[MAXS];
int bucket_head_[MAXL + 2];
long long ans_[MAXL + 2];

int n_, q_, m_, lmax_;
int sc_, max_sched_;

int find_(int x) {
    while (par_[x] != x) { par_[x] = par_[par_[x]]; x = par_[x]; }
    return x;
}

void schedule_(int a, int b, int l) {
    if (l > lmax_) return;
    sa_[sc_] = a; sb_[sc_] = b; snext_[sc_] = bucket_head_[l]; bucket_head_[l] = sc_; sc_++;
    if (l > max_sched_) max_sched_ = l;
}

void run_threshold_(int w) {
    int i, x, l;
    for (i = 0; i < n_; i++) deg_[i] = 0;
    for (i = 0; i < m_; i++) if (ew_[i] <= w) deg_[eu_[i]]++;
    head_[0] = 0;
    for (i = 0; i < n_; i++) head_[i + 1] = head_[i] + deg_[i];
    for (i = 0; i < n_; i++) pos_[i] = head_[i];
    for (i = 0; i < m_; i++) if (ew_[i] <= w) { adj_[pos_[eu_[i]]] = ev_[i]; pos_[eu_[i]]++; }

    for (i = 0; i < n_; i++) { par_[i] = i; sz_[i] = 1; }
    sc_ = 0; max_sched_ = 0;

    for (x = 0; x < n_; x++) {
        if (head_[x] == head_[x + 1]) { nxt_[x] = -1; continue; }
        nxt_[x] = adj_[head_[x]];
        for (i = head_[x] + 1; i < head_[x + 1]; i++) schedule_(adj_[head_[x]], adj_[i], 2);
    }

    int empty_classes = 0;
    for (x = 0; x < n_; x++) if (nxt_[x] == -1) empty_classes++;

    long long total_merges = 0, iso_s = 0, iso_prev = empty_classes, size_p;
    int e;

    for (l = 2; l <= lmax_; l++) {
        iso_s += iso_prev;
        for (e = bucket_head_[l]; e != -1; e = snext_[e]) {
            int ra = find_(sa_[e]), rb = find_(sb_[e]);
            if (ra == rb) continue;
            int na = nxt_[ra], nb = nxt_[rb];
            int ea = (na == -1), eb = (nb == -1);
            if (sz_[ra] < sz_[rb]) { int t = ra; ra = rb; rb = t; }
            par_[rb] = ra; sz_[ra] += sz_[rb];
            nxt_[ra] = (na != -1) ? na : nb;
            if (na != -1 && nb != -1) schedule_(na, nb, l + 1);
            if (ea || eb) empty_classes--;
            total_merges++;
        }
        bucket_head_[l] = -1;
        size_p = (long long)n_ - total_merges;
        ans_[l] += size_p + iso_s;
        iso_prev = empty_classes;
        if (l >= max_sched_) {
            int ll;
            for (ll = l + 1; ll <= lmax_; ll++) { iso_s += iso_prev; ans_[ll] += size_p + iso_s; }
            break;
        }
    }
}

int main() {
    int tc, i, w, l;
    for (i = 0; i < MAXL + 2; i++) bucket_head_[i] = -1;
    scanf("%d", &tc);
    while (tc--) {
        scanf("%d %d %d", &n_, &q_, &m_);
        lmax_ = q_ + 1;
        for (i = 0; i < m_; i++) {
            scanf("%d %d %d", &eu_[i], &ev_[i], &ew_[i]);
            eu_[i]--; ev_[i]--;
        }
        for (l = 0; l <= lmax_ + 1; l++) ans_[l] = 0;
        for (w = 0; w < 30; w++) run_threshold_(w);
        for (l = 2; l <= lmax_; l++) {
            printf("%lld", ans_[l] - 30);
            if (l < lmax_) printf(" ");
        }
        printf("\n");
    }
    return 0;
}
