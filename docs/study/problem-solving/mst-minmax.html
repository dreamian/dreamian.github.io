완전 그래프 K_N에서 간선 가중치의 배정 순서에 따라 달라지는 MST 비용의 최솟값과 최댓값을 구하는 문제
Published

April 16, 2026

1 문제 요약

\(N\)개의 정점을 가진 완전 그래프 \(K_N\)이 주어진다. 이 그래프에는 \(M = \dfrac{N(N-1)}{2}\)개의 간선이 존재한다.

각 간선에 양의 정수 가중치를 배정해야 하는데, 사용할 가중치 목록 \(C_1, C_2, \ldots, C_M\)은 주어지지만 어느 간선에 어떤 값을 배정할지는 자유롭게 결정할 수 있다.

이때 얻을 수 있는 MST(최소 스패닝 트리) 비용의 최솟값과 최댓값을 구하라.

2 핵심 관찰: 정렬 후 분석

가중치 배열을 오름차순으로 정렬한다.

\[c_0 \le c_1 \le c_2 \le \cdots \le c_{M-1}\]

이제 최솟값과 최댓값을 각각 유도한다.

3 최솟값 (Min MST)

Note

주장: Min MST = \(\displaystyle\sum_{i=0}^{N-2} c_i\) (정렬된 배열에서 가장 작은 \(N-1\)개의 합)

달성 가능성: 가장 작은 \(N-1\)개의 가중치를 임의의 스패닝 트리(예: star 또는 path)에 배정하면, Kruskal 알고리즘은 이 \(N-1\)개를 순서대로 선택하며, 나머지 간선들은 모두 이보다 크거나 같으므로 cycle을 형성하는 것으로 처리된다.

하한: MST는 반드시 \(N-1\)개의 간선을 포함해야 하므로, 그 합은 정렬된 가중치 중 가장 작은 \(N-1\)개의 합보다 작을 수 없다.

따라서 Min MST = \(c_0 + c_1 + \cdots + c_{N-2}\).

4 최댓값 (Max MST)

이 부분이 문제의 핵심이다. MST를 최대화하려면 Kruskal이 최대한 큰 가중치를 선택하도록, 작은 가중치들을 cycle 생성에 “낭비”시켜야 한다.

4.1 삼각수(Triangular Number) 인덱스

Important

주장: Max MST = \(\displaystyle\sum_{i=0}^{N-2} c_{T(i)}\), 단 \(T(i) = \dfrac{i(i+1)}{2}\) (삼각수)

즉, 정렬된 배열에서 인덱스 \(0, 1, 3, 6, 10, \ldots\)에 위치한 값들의 합이다.

4.2 왜 삼각수 인덱스인가?

Kruskal 알고리즘이 \(k\)번째 MST 간선 (1-indexed)을 선택하는 시점을 분석한다.

핵심 아이디어: \(k\)번째 MST 간선을 고르기 직전에, 정렬된 배열에서 앞쪽의 간선들을 최대한 많이 “cycle 생성”으로 소모시키면 \(k\)번째 MST 간선의 인덱스를 늦출 수 있다.

구체적으로, 처음 \(k-1\)개의 MST 간선이 어떤 \(k\)개의 정점 \(\{v_1, \ldots, v_k\}\) 위에 스패닝 트리를 형성하도록 가중치를 배정한다고 하자.

이 \(k\)개의 정점 사이에는 완전 그래프 \(K_k\)의 간선이 총 \(T(k-1) = \dfrac{(k-1)k}{2}\)개 존재하며, 그 중:

  • \(k-1\)개: 이미 추가된 MST 간선 (스패닝 트리의 간선)
  • \(T(k-1) - (k-1) = \dfrac{(k-1)(k-2)}{2}\)개: 같은 컴포넌트 내부 간선으로 cycle 생성 → skip됨

따라서 \(k\)번째 MST 간선이 처리되기 전까지 총: \[\underbrace{(k-1)}_{\text{MST 간선}} + \underbrace{\frac{(k-1)(k-2)}{2}}_{\text{skip된 간선}} = T(k-1)\] 개의 간선이 소모되므로, \(k\)번째 MST 간선은 정렬 배열의 인덱스 \(T(k-1)\)에 위치한다 (0-indexed: \((k-1)\)번째 MST 간선은 인덱스 \(T(k-1)\)).

MST 간선 순서 (0-indexed) 삼각수 \(T(i)\) 이유
\(i=0\) \(T(0) = 0\) 첫 번째 간선, skip 없음
\(i=1\) \(T(1) = 1\) 1개 간선(K₂)이 소모됨
\(i=2\) \(T(2) = 3\) 3개 간선(K₃)이 소모됨
\(i=3\) \(T(3) = 6\) 6개 간선(K₄)이 소모됨
\(\vdots\) \(\vdots\) \(\vdots\)
\(i=k\) \(T(k) = \dfrac{k(k+1)}{2}\) \(T(k)\)개 간선(K_{k+1})이 소모됨

4.3 N=4 예시 검증

\(c_0 \le c_1 \le c_2 \le c_3 \le c_4 \le c_5\)로 정렬된 6개 가중치에서, Max MST = \(c_0 + c_1 + c_3\).

다음과 같이 배정한다:

간선 가중치
(3, 4) \(c_0\)
(2, 4) \(c_1\)
(2, 3) \(c_2\)
(1, 4) \(c_3\)
(1, 3) \(c_4\)
(1, 2) \(c_5\)

Kruskal 수행:

  1. \(c_0\): 간선 (3,4) 추가 → {3,4}, {1}, {2}
  2. \(c_1\): 간선 (2,4) 추가 → {2,3,4}, {1}
  3. \(c_2\): 간선 (2,3) → cycle (2,3 모두 {2,3,4} 내) → skip
  4. \(c_3\): 간선 (1,4) 추가 → {1,2,3,4} (완성)

MST = \(c_0 + c_1 + c_3\) ✓

\(c_2\)가 cycle로 소모되어 \(c_3\)가 세 번째 MST 간선이 된다.

Tip

\(c_0 + c_1 + c_4\)는 달성 불가능한가?

\(c_2\)와 \(c_3\)를 동시에 cycle로 소모하려면, 두 간선 모두 이미 연결된 컴포넌트 내에 있어야 한다. 앞의 분석에서 \(c_0, c_1\)이 star 형태({1,2,3} 컴포넌트)를 이루면 \(c_2\)는 cycle로 소모 가능하지만, 그 시점에 {1,2,3} 내부 간선이 모두 소진되어 \(c_3\)는 반드시 singleton {4}를 연결하는 MST 간선이 된다. 따라서 \(c_4\)를 MST에 포함시키는 것은 불가능하다.

5 시간 복잡도

단계 복잡도
정렬 (삽입 정렬) \(O(M^2)\)
Min/Max 합산 \(O(N)\)
전체 \(O(M^2) = O(N^4)\)

\(N \le 100\)이면 \(M \le 4950\)이므로 \(M^2 \approx 2.4 \times 10^7\)으로 충분히 빠르다.

Note

삽입 정렬 대신 std::sort를 사용하면 \(O(M \log M)\)으로 개선되나, 제약 조건상 필요 없다.

6 Codes

#include <stdio.h>

int main(void)
{
    int t;
    scanf("%d", &t);
    while (t--)
    {
        int n;
        long long int _min_val = 0;
        long long int _max_val = 0;
        scanf("%d", &n);
        int m = (n * (n - 1)) >> 1;
        int* edges = new int[m];

        for (int i = 0; i < m; ++i)
        {
            scanf("%d", &edges[i]);
        }

        // 삽입 정렬 (오름차순)
        for (int j = 1; j < m; ++j)
        {
            auto key = edges[j];
            int i = j - 1;
            while (i >= 0 && edges[i] > key)
            {
                edges[i + 1] = edges[i];
                --i;
            }
            edges[i + 1] = key;
        }

        for (int i = 0; i < n - 1; ++i)
        {
            _min_val += edges[i];                  // Min MST: 가장 작은 N-1개
            _max_val += edges[(i * (i + 1)) / 2];  // Max MST: 삼각수 인덱스
        }

        printf("%lld %lld\n", _min_val, _max_val);
        delete[] edges;
    }
}
