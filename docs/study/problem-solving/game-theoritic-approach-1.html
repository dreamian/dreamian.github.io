Game Theory: Winning Strategies and Implementation

Published

April 15, 2026

1. 문제 개요 (Game Definition)

두 플레이어가 숫자 \(N\)을 가지고 게임을 합니다. 자신의 차례에 \(N\)의 약수 \(C\) (\(1 < C < N\))를 선택하여 \(N\)에서 뺍니다. 더 이상 뺄 수 있는 약수가 없는 사람이 패배합니다.

Tip핵심 인사이트

이 게임은 “상대를 패배 상태로 보내는 선택이 하나라도 존재하면 이긴다”는 구조입니다.

2. 필승 전략 (Winning Strategy)

✔️ Case 1: N이 홀수

  • 홀수의 약수는 항상 홀수
  • 홀수 - 홀수 = 짝수
  • 상대에게 항상 짝수를 넘김

👉 결과: 패배 (B)

✔️ Case 2: N = 2^k (2의 거듭제곱)

  • k가 홀수 → 패배 (B)
  • k가 짝수 → 승리 (A)

✔️ Case 3: 그 외 짝수

  • 반드시 홀수 약수 존재
  • 그걸 빼서 상대에게 홀수 넘김

👉 결과: 승리 (A)

3. DP 관점 (Recurrence)

dp[i] = True (이김) if

6. 최종 공식

\[ f(N) = \begin{cases} B & \text{if } N \equiv 1 \pmod 2 \\ B & \text{if } N = 2^k \text{ and } k \equiv 1 \pmod 2 \\ A & \text{otherwise} \end{cases} \]
