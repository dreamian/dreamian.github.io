원점에서 k번 이동 시 직사각형 장애물을 고려한 도달 가능 격자점 수를 O(1)로 구하는 풀이
Published

April 15, 2025

1 문제 요약

무한한 2차원 격자 위의 원점 \((0, 0)\)에서 출발한다. 격자 위에는 직사각형 장애물 \([x_1, x_2] \times [y_1, y_2]\)가 놓여 있어, 이 영역 안의 격자점은 방문할 수 없다. 최대 \(k\)번 상하좌우 이동하여 도달 가능한 격자점의 수(원점 포함)를 구하라.

제약 조건:

  • \(-10^6 \le x_1 \le 0 \le x_2 \le 10^6\)
  • \(1 \le y_1 \le y_2 \le 10^6\)
  • \(0 \le k \le 10^9\)

장애물이 반드시 원점의 위쪽(\(y_1 > 0\))에 있고, \(x\)축 방향으로 원점을 포함(\(x_1 \le 0 \le x_2\))한다는 점이 핵심이다.

2 핵심 관찰

2.1 장애물 없는 경우: 맨해튼 다이아몬드

장애물이 없다면 원점에서 \(k\)번 이내 이동으로 도달 가능한 점의 집합은

\[D_k = \{(x, y) : |x| + |y| \le k\}\]

이며, 그 크기는

\[|D_k| = 2k^2 + 2k + 1\]

이다. 이는 \(|y| = 0, 1, \ldots, k\)일 때 각 \(y\)에서 \(x\)가 \(-(k-|y|)\)부터 \(k-|y|\)까지이므로 \(\sum_{d=0}^{k}(2(k-d)+1) = 2k^2+2k+1\)로 확인된다.

2.2 장애물의 “그림자”

원점에서 위로 올라가면 반드시 장애물을 만나므로, 열 \(x \in [x_1, x_2]\)에서 \(y \ge y_1\)인 다이아몬드 내부 점들은 직접 도달 불가하다. 이 영역을 장애물의 그림자(shadow)라 부르자.

열 \(x\)에서 그림자 내 점의 수는

\[\max(0,\; k - |x| - y_1 + 1)\]

이다 (다이아몬드 경계까지의 점 중 \(y \ge y_1\)인 것).

2.3 우회를 통한 복원

그림자 중 \(y > y_2\)인 점, 즉 장애물 위쪽의 점은 좌측 또는 우측으로 장애물을 돌아가면 도달 가능할 수 있다.

Tip우회 거리 공식

점 \((x, y)\) (\(x_1 \le x \le x_2\), \(y > y_2\))로의 최단 우회 거리:

  • 좌측 우회: \((x_1 - 1, y_1)\) 근방을 경유. 거리 \(d_L = x - 2x_1 + 2 + y\).
  • 우측 우회: \((x_2 + 1, y_1)\) 근방을 경유. 거리 \(d_R = 2x_2 - x + 2 + y\).

이는 맨해튼 거리에서 “반드시 \(x = x_1 - 1\) (또는 \(x = x_2 + 1\))을 거쳐야 한다”는 제약을 걸면, 최적 경유점의 \(y\)좌표가 \(0\)과 \(y\) 사이 어디든 무방하므로 \(y\)축 비용이 그냥 \(y\)가 되는 것으로부터 유도된다.

3 풀이 구조: 포함-배제

전체 답을 다음과 같이 분해한다.

\[\text{answer} = \underbrace{|D_k|}_{\text{전체}} - \underbrace{S}_{\text{그림자}} + \underbrace{R}_{\text{복원}}\]

3.1 그림자 계산 (\(S\))

열 \(x\)의 그림자 크기를 \(f(|x|) = \max(0, k - |x| - y_1 + 1)\)로 쓰면, 열 대칭성을 이용하여 \(|x|\) 기준으로 그룹화한다.

\(c = \min(-x_1, x_2)\), \(w = \max(-x_1, x_2)\)로 놓으면:

  • \(|x| = 0\): 열 하나 (좌우 공통). 기여 \(f(0)\).
  • \(1 \le |x| \le c\): 열 \(x\)와 \(-x\) 모두 장애물 범위에 포함. 기여 \(2 \sum_{d=1}^{c} f(d)\).
  • \(c < |x| \le w\): 한쪽만 장애물 범위에 포함. 기여 \(\sum_{d=c+1}^{w} f(d)\).

\(f(d)\)는 \(d\)에 대해 선형이므로 각 구간 합은 등차급수 공식으로 \(O(1)\)에 계산된다.

Note코드에서의 exclude(from, to)

\(M = k - y_1 + 1\)로 놓으면 \(f(d) = \max(0, M - d)\)이다. to를 \(\min(\text{to}, M)\)으로 클램핑한 뒤, 등차급수

\[\sum_{d=\text{from}}^{\text{to'}} (M - d) = \frac{n \cdot (2M - \text{from} - \text{to'})}{2}\]

를 반환한다 (\(n = \text{to'} - \text{from} + 1\)).

3.2 복원 계산 (\(R\))

장애물 꼭짓점 \((x_1 - 1, y_2 + 1)\)까지의 거리를 좌측 소비량, \((x_2 + 1, y_2 + 1)\)까지의 거리를 우측 소비량이라 정의하자.

\[\text{consumed}_L = (-x_1 + 1) + (y_2 + 1), \quad \text{consumed}_R = (x_2 + 1) + (y_2 + 1)\]

남은 예산(잔여 자원):

\[\ell = \max(0,\; k - \text{consumed}_L), \quad r = \max(0,\; k - \text{consumed}_R)\]

\((x_1 - 1, y_2 + 1)\)에 도달한 후 잔여 \(\ell\)스텝으로 오른쪽·위쪽으로 이동하면, 열 \(x\)에서 복원 가능한 점의 수는

\[g_L(x) = \max(0,\; \ell - (x - x_1))\]

이며, 우측 우회 시에는

\[g_R(x) = \max(0,\; r - (x_2 - x))\]

이다. 양쪽 모두로 도달 가능한 점은 중복 제거가 필요하다.

Important중복 제거: 분할점(mid) 기법

열 \(x\)에서 \(\max(g_L(x), g_R(x))\)를 취하면 중복이 생기므로, \(g_L(x) \ge g_R(x)\)인 구간과 반대 구간을 분할점 \(\text{mid}\)에서 나누어 각 구간에서 해당 쪽만 합산한다.

\(g_L(x) = g_R(x)\)를 풀면:

\[\ell - (x - x_1) = r - (x_2 - x) \implies x = \frac{\ell - r + x_1 + x_2}{2}\]

이 분할점 왼쪽에서는 좌측 우회가 유리하고, 오른쪽에서는 우측 우회가 유리하다.

각 영역 내에서 \(g_L\) 또는 \(g_R\)은 \(x\)에 대한 선형 함수이므로 다시 등차급수로 \(O(1)\) 계산이 가능하다.

4 시간 복잡도 분석

모든 연산이 상수 시간의 산술로 구성되므로 테스트 케이스당 \(O(1)\)이다.

  • 공간: \(O(1)\) (변수만 사용)
  • \(k\)가 최대 \(10^9\)이지만 이동 시뮬레이션 없이 닫힌 공식으로 처리
  • long long 사용 필수: \(2k^2\)가 최대 \(2 \times 10^{18}\)
Warning오버플로 주의

\(k = 10^9\)일 때 \(2k^2 + 2k + 1 \approx 2 \times 10^{18}\)으로, int는 물론 부호 없는 32비트 정수로도 부족하다. 모든 중간 연산에서 long long이 필요하다.

5 예제 추적

테스트 1: \(x_1 = -5,\; x_2 = 5,\; y_1 = 5,\; y_2 = 5,\; k = 3\).

  • \(|D_3| = 2 \cdot 9 + 6 + 1 = 25\)
  • \(y_1 = 5 > k = 3\)이므로 그림자 없음, 복원도 없음
  • 답: \(25\) ✓

테스트 2: \(x_1 = -5,\; x_2 = 5,\; y_1 = 5,\; y_2 = 5,\; k = 15\).

  • \(|D_{15}| = 2 \cdot 225 + 30 + 1 = 481\)
  • 그림자: \(c = 5\), \(w = 5\)이므로 exclude(0,0) + \(2 \times\) exclude(1,5) + exclude(6,5) (빈 구간)
    • exclude(0,0): \(M = 15 - 5 + 1 = 11\), 값 \(= 11\)
    • exclude(1,5): \(n=5\), 합 \(= 5 \cdot (22 - 1 - 5)/2 = 5 \cdot 8 = 40\)
    • 그림자 합: \(11 + 2 \times 40 = 91\)
  • 복원: \(\text{consumed}_L = 6 + 6 = 12\), \(\ell = 3\); \(\text{consumed}_R = 6 + 6 = 12\), \(r = 3\)
    • 대칭이므로 \(\text{mid} = 0\)
    • 좌측 (\(x = -5\) ~ \(0\)): 유효 범위 \(x = -5\) ~ \(\min(0, -5+3-1) = -3\). 합 \(= 3+2+1 = 6\)
    • 우측 (\(x = 1\) ~ \(5\)): 유효 범위 \(x = \max(1, 5-3+1)=3\) ~ \(5\). 합 \(= 1+2+3 = 6\)
    • 복원 합: \(12\)
  • 답: \(481 - 91 + 12 = 402\) ✓

6 PS 스킬 포인트

이 문제에서 배울 수 있는 핵심 기법을 정리한다.

기하학적 관찰의 대수적 전환. 다이아몬드 영역의 점 개수, 그림자 영역 등을 모두 닫힌 공식으로 환산하는 과정이 핵심이다. BFS나 시뮬레이션이 아닌 수식으로 풀 수 있다는 직관은 \(k\)의 범위(\(10^9\))가 강력하게 암시한다.

대칭성 활용. \(|x|\) 기준으로 열을 그룹화하여, 좌우 대칭인 열은 2배, 비대칭 열은 1배로 처리한다. 이렇게 하면 \(O(|x_2 - x_1|)\) 반복 대신 \(O(1)\)에 처리할 수 있다.

우회 비용의 선형성. 장애물 모서리를 경유하는 최단 경로 비용이 목표 열 \(x\)에 대해 선형이라는 관찰이 등차급수 합산을 가능하게 한다.

분할점을 이용한 중복 제거. 좌측 우회와 우측 우회의 유효 범위가 겹칠 때, \(\max\)를 취하는 대신 두 함수가 같아지는 점에서 영역을 분할하면 깔끔하게 처리된다.

7 Codes

#include <stdio.h>

using ll = long long int;

ll x1, x2, y1, y2, k;

ll _MIN(ll a, ll b)
{
    return (a < b) ? a : b;
}

ll _MAX(ll a, ll b)
{
    return (a > b) ? a : b;
}

ll all()
{
    return 2*k*k + 2 * k + 1;
}

ll exclude(ll from, ll to)
{
    if(y1 > k) return 0;
    if(from > to) return 0;

    to = _MIN(to, k - y1 + 1);
    if(from > to) return 0;

    auto n = to - from + 1;

    return (n * (2*(k - y1 + 1) - from - to)) >> 1;
}

ll include()
{
    if(y2 + 1 > k) return 0;

    ll l_rsc = 0, r_rsc = 0;

    if(y2 + 1 - k < x1)
    {
        auto consumed = (-x1 + 1) + (y2 + 1);
        l_rsc = _MAX(0, k - consumed);
    }
    if(x2 < k - y2 - 1)
    {
        auto consumed = (x2 + 1) + (y2 + 1);
        r_rsc = _MAX(0, k - consumed);
    }

    ll ret = 0;

    ll sum_x = l_rsc - r_rsc + x1 + x2;
    ll mid = (sum_x >= 0) ? (sum_x / 2) : ((sum_x - 1) / 2);

    ll left_to = _MIN(x2, mid);
    if (x1 <= left_to && l_rsc > 0)
    {
        ll effective_to = _MIN(left_to, l_rsc + x1 - 1);
        if (x1 <= effective_to)
        {
            ll n = effective_to - x1 + 1;
            ll first = l_rsc - x1 + x1;
            ll last = l_rsc - effective_to + x1;
            ret += (n * (first + last)) >> 1;
        }
    }

    ll right_from = _MAX(x1, mid + 1);
    if (right_from <= x2 && r_rsc > 0)
    {
        ll effective_from = _MAX(right_from, x2 - r_rsc + 1);
        if (effective_from <= x2)
        {
            ll n = x2 - effective_from + 1;
            ll first = r_rsc + effective_from - x2;
            ll last = r_rsc + x2 - x2;
            ret += (n * (first + last)) >> 1;
        }
    }

    return ret;
}

int main(void)
{
    int t;
    scanf("%d", &t);
    while(t--)
    {
        scanf("%lld%lld%lld%lld%lld", &x1, &x2, &y1, &y2, &k);

        ll common_range = _MIN(-x1, x2);
        ll outer_range = _MAX(-x1, x2);

        printf("%lld\n",
            all()
            - exclude(0, 0)
            - 2 * exclude(1, common_range)
            - exclude(common_range + 1, outer_range)
            + include()
        );
    }
}
