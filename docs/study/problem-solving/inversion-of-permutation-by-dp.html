길이 N인 순열의 역위 개수를 K로 나눈 나머지별 순열 개수를 DP와 q-factorial로 구하는 문제. 핵심은 mod K DP로 배열 크기를 O(K)로 줄이는 아이디어이다.
Published

April 3, 2026

길이 \(N\)인 순열에서 역위(inversion)의 수를 \(K\)로 나눈 나머지가 \(m\)인 순열의 개수를 구하는 문제이다. 결과는 \(1{,}000{,}000{,}007\)로 나눈 나머지로 출력하며, \(1 \leq N \leq 10^6\), \(1 \leq K \leq 10^2\) 조건이 주어진다.

1 역위(Inversion)란?

순열 \(A_1, A_2, \ldots, A_N\)에서 \(i < j\)이고 \(A_i > A_j\)인 쌍 \((i, j)\)의 수를 역위 개수라 한다.

예시: \([3, 1, 2]\)의 역위 = \(\{(3,1),\,(3,2)\}\) → 2개

최대 역위 수는 완전 역순 배열 \([N, N-1, \ldots, 1]\)일 때이며:

\[\text{최대 역위 수} = \frac{N(N-1)}{2}\]

2 Q-Factorial과 생성함수

역위 개수의 생성함수는 q-factorial로 표현된다.

\[F_N(q) = \prod_{k=1}^{N}(1 + q + q^2 + \cdots + q^{k-1})\]

여기서 \(q^j\)의 계수는 역위가 정확히 \(j\)개인 길이 \(N\) 순열의 수이다.

Note직관

원소 \(k\)를 기존 \(k-1\)개 원소 사이에 삽입할 때, 삽입 위치에 따라 새로 생기는 역위 수가 \(p \in \{0, 1, \ldots, k-1\}\)로 결정된다. 이것이 \(q^p\) 기여로 나타나며, 각 단계가 독립적이므로 전체 생성함수는 곱으로 표현된다.

2.1 N = 3 예시

\[F_3(q) = 1 \cdot (1+q) \cdot (1+q+q^2) = 1 + 2q + 2q^2 + q^3\]

역위 수 순열 개수
0 [1,2,3] 1
1 [1,3,2], [2,1,3] 2
2 [2,3,1], [3,1,2] 2
3 [3,2,1] 1

합계 = \(1+2+2+1 = 3! = 6\) ✓

3 DP 설계

3.1 상태 정의

\[dp_k[r] = \text{1부터 } k \text{까지의 수로 만든 순열 중 역위 수} \equiv r \pmod{K} \text{인 것의 수}\]

배열 크기가 항상 \(K \leq 100\)으로 고정되므로, \(N\)이 \(10^6\)이어도 메모리 문제가 없다.

3.2 점화식

\[dp_k[r] = \sum_{p=0}^{\min(k,\,K)-1} dp_{k-1}[(r - p + K) \bmod K]\]

  • \(p\): 원소 \(k\) 삽입 시 새로 생기는 역위 수
  • \(k \geq K\)이면 윈도우 크기를 \(K\)로 고정 (mod 특성상 모든 나머지를 커버)
Important경계 조건

\(p\)의 범위는 \(r\)과 무관하게 항상 \(\{0, 1, \ldots, \min(k,K)-1\}\)이다. \((r-p)\)가 음수가 되는 경우는 mod \(K\) 연산으로 자동 처리된다.

3.3 초기 조건

\[dp_1[0] = 1, \quad dp_1[r] = 0 \; (r \neq 0)\]

3.4 DP 추적: N = 3, K = 3

step = 2 (\(p \in \{0, 1\}\)):

\(r\) 계산 결과
0 \(dp_1[0] + dp_1[2]\) 1
1 \(dp_1[1] + dp_1[0]\) 1
2 \(dp_1[2] + dp_1[1]\) 0

step = 3 (\(p \in \{0, 1, 2\}\)):

\(r\) 계산 결과
0 \(dp_2[0] + dp_2[2] + dp_2[1]\) 2
1 \(dp_2[1] + dp_2[0] + dp_2[2]\) 2
2 \(dp_2[2] + dp_2[1] + dp_2[0]\) 2

→ 균등: \([2, 2, 2]\) = \(3!/3 = 2\) ✓

4 N ≥ K일 때 균등성

\(k = K\) 단계에서 \(p \in \{0, \ldots, K-1\}\)이 모든 나머지를 정확히 한 번씩 커버하므로:

\[dp_K[r] = \sum_{j=0}^{K-1} dp_{K-1}[j] = (K-1)! \quad \text{(모든 } r \text{에 대해 동일)}\]

Tip핵심 아이디어

step \(K\) 이후 단계는 균등 상태를 유지하므로, \(\min(N, K)\)단계만 DP를 실행하고 나머지는 팩토리얼 곱셈으로 일괄 처리한다.

\[\text{최종값} = dp_{\min(N,K)}[r] \times \frac{N!}{\,(\min(N,K))!\,}\]

경우 steps 곱하는 값 결과
\(N < K\) \(N\) \(N!/N! = 1\) \(dp[r]\) 그대로
\(N \geq K\) \(K\) \(N!/K!\) \(N!/K\)

5 복잡도 분석

항목 값
DP 배열 크기 \(O(K) \leq 100\)
루프 단계 수 \(\min(N, K) \leq 100\)
단계당 연산 \(O(K^2)\)
전체 DP 복잡도 \(O(K^2)\) (N에 무관)
팩토리얼 전처리 \(O(N)\)

#include <stdio.h>
using ull = unsigned long long int;
const ull MOD = 1'000'000'007;

ull prev_DP[100];
ull curr_DP[100];
ull fact[1'000'001];

ull power(ull b, ull e, ull m) {
    ull r = 1;
    b %= m;
    for (; e > 0; e >>= 1) {
        if (e & 1) { r = r * b % m; }
        b = b * b % m;
    }
    return r;
}

int main(void)
{
    fact[0] = 1;
    for (int i = 1; i <= 1'000'000; ++i) {
        fact[i] = fact[i-1] * i % MOD;
    }

    int t;
    scanf("%d", &t);
    while (t--) {
        ull n, k;
        scanf("%llu %llu", &n, &k);

        for (int i = 0; i < k; ++i) {
            prev_DP[i] = curr_DP[i] = 0;
        }
        prev_DP[0] = 1;

        ull steps = (n < k) ? n : k;
        for (ull step = 2; step <= steps; ++step) {
            for (int i = 0; i < k; ++i) {
                curr_DP[i] = 0;
            }
            int wsize = (int)step;  // step <= k 보장
            for (int r = 0; r < k; ++r) {
                for (int p = 0; p < wsize; ++p) {
                    int idx = ((r - p) % (int)k + (int)k) % (int)k;
                    curr_DP[r] = (curr_DP[r] + prev_DP[idx]) % MOD;
                }
            }
            for (int i = 0; i < k; ++i) {
                prev_DP[i] = curr_DP[i];
            }
        }

        // 나머지 단계 (steps+1 ~ N) 일괄 처리
        ull mult = fact[n] * power(fact[steps], MOD - 2, MOD) % MOD;
        for (int i = 0; i < k; ++i) {
            printf("%llu ", prev_DP[i] * mult % MOD);
        }
        printf("\n");
    }
}
