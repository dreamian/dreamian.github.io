3 0. Starting point

3.1 Can the Bellman equation be directly obtained as the solution to the optimization problem?

First question to consider. Which property of \(T\) did all the methods (VI, PI) used to solve \(v=Tv\) so far rely on? What does it become if that property is written as a “constraint” instead of “repetition”?

Answer. VI and PI rely on the contraction property of \(T\) and the Banach fixed-point theorem. This time, without repeatedly applying \(T\), the Bellman equation is relaxed to the inequality constraint \(v\ge Tv\) and the linear objective function is minimized. The property used here is monotonicity in addition to contraction.

TipSignificance
  • If converted to an optimization problem, mature optimization solvers (interior-point, simplex) can be used as is.
  • Optimization tools such as duality, feature approximation, and sample-based constraints can be introduced into MDPs.
  • At the end of this chapter, the same framework leads to improving policies with data without a model → Section 10.2

4 I. Optimization Formalization

4.1 Why is the optimal solution to \(\min_v c^\top v\) st \(v\ge Tv\) (\(c>0\)) uniquely \(v^*\)?

\[ \min_{v\in\mathbb{R}^n}\ c^\top v\qquad\text{s.t.}\qquad v\ge Tv\quad(\text{원소별}). \]

The first question to think of.

  1. Let \(v_{\rm opt}\) be the optimal solution. This satisfies the constraint \(v_{\rm opt}\ge Tv_{\rm opt}\). Where do we go if we continue to apply \(T\) to both sides?
  2. Where is \(v^*\) located in this problem (is it feasible)?
  3. What are the directions of the inequalities derived from the two facts?

Answer. It is three lines.

  1. \(v_{\rm opt}\ge Tv_{\rm opt}\ge T^2v_{\rm opt}\ge\cdots\to v^*\), therefore \(v_{\rm opt}\ge v^*\).
  2. Since \(v^*=Tv^*\), \(v^*\) is feasible, and therefore \(c^\top v^*\ge c^\top v_{\rm opt}\).
  3. 1 and \(c>0\) \(c^\top v_{\rm opt}\ge c^\top v^*\). For the two inequalities to hold simultaneously, \(v_{\rm opt}=v^*\).

↓ Down: Section 4.1.1 Proof · Section 4.1.2 Tool ↑ Up: Section 3.1

4.1.1 Proof: Three inequalities one by one

NoteProof

We take \(v_{\rm opt}\) as the arbitrary optimal solution.

(i) \(v_{\rm opt}\ge v^*\). \[ \begin{aligned} v_{\rm opt}&\ge Tv_{\rm opt} &&(\text{제약})\\ Tv_{\rm opt}&\ge T^2v_{\rm opt} &&(\text{윗줄 양변에 }T\text{, 단조성})\\ &\ \ \vdots\\ v_{\rm opt}&\ge T^kv_{\rm opt}\ \ \forall k &&(\text{이어 붙이기})\\ v_{\rm opt}&\ge\lim_{k\to\infty}T^kv_{\rm opt}=v^* &&(\text{Banach: 임의 초기값에서 }T^k\cdot\to v^*,\ \text{원소별 부등식은 극한에서 유지}) \end{aligned} \]

(ii) \(c^\top v^*\ge c^\top v_{\rm opt}\). Since \(v^*=Tv^*\), \(v^*\ge Tv^*\) satisfies the equality. That is, \(v^*\) is feasible. \(v_{\rm opt}\) is the point where \(c^\top v\) is the smallest among the feasible points, so \(c^\top v_{\rm opt}\le c^\top v^*\).

(iii) \(v_{\rm opt}=v^*\). From (i), it is \(d:=v_{\rm opt}-v^*\ge0\). Rewriting (ii), it is \(c^\top d\le0\). However, \[ c^\top d=\sum_sc(s)\,d(s),\qquad c(s)>0,\ d(s)\ge0 \] Since , each term is nasal, and for the sum to be less than or equal to \(0\), all terms must be \(0\). Since \(c(s)>0\), it is \(d(s)=0\), i.e., \(v_{\rm opt}=v^*\).

Since \(v_{\rm opt}\) was chosen arbitrarily, the optimal solution is unique and is \(v^*\).

NoteAddendum: Existence of the optimal solution

The argument in (i) does not use the fact that \(v_{\rm opt}\) is the optimal solution. It only uses constraints. Therefore, for all feasible \(v\), \(v\ge v^*\) and \(c^\top v\ge c^\top v^*\). Since \(v^*\) itself is feasible, \(v^*\) actually achieves the minimum value. In other words, existence and uniqueness come together.

This is the same as the comparison lemma “\(v\ge Tv\Rightarrow v\ge v^*\)”.

TipSignificance
  • \(c>0\) is used only in (iii). If there is even one element \(c(s)=0\), the objective value does not change even if that element’s \(d(s)\) is positive, so uniqueness is broken.
  • Remember that minimization is in the direction of “pressing the Bellman equation from above.” Every point in the feasible set \(\{v\ge Tv\}\) is greater than \(v^*\), and the “bottom edge” of that set is \(v^*\).
  • If you want to write the problem as a maximization problem (\(\max\), \(v\le Tv\)), you must also reverse the direction of the inequality. Every point in \(\{v\le Tv\}\) is smaller than \(v^*\). If you mix the two directions (e.g., \(\min\) and \(v\le Tv\)), the objective function becomes unbounded below.

↓ Down: Section 4.1.2 ↑ Up: Section 4.1

4.1.2 Three tools used in the proof

Answer.

  • Monotonicity: \(v\le w\Rightarrow Tv\le Tw\). Since \(p\ge0\), it follows that \(\sum_{s'}p\,v\le\sum_{s'}p\,w\), and the inequality that holds for each \(a\) holds even when taking \(\max_a\).
  • Limit of iteration: Since \(T\) is a contraction of \(\gamma\), \(T^kv\to v^*\) from any starting point (Banach’s fixed point theorem). This leads to the fact that \(v^*\) is the only fixed point of \(T\).
  • Positive weighted sum: \(c>0\), \(d\ge0\), \(c^\top d=0\Rightarrow d=0\).
TipSignificance

The same three tools are reused in the policy evaluation LP (Section 5.1.3), Q-LP (Section 9.1), and upper limit of approximation LP (Section 7.1.1). The only thing that changes is the operator (\(T\), \(T^\pi\), \(T_Q\)).

5 II. Conversion to LP

5.1 How does this optimization problem become a linear program?

The first question to think of.

  1. Which is the problem, the objective function \(c^\top v\) or the constraint \(v\ge Tv\)?
  2. If the constraints are expanded by state, where exactly does the nonlinearity come from?
  3. What is the proposition equivalent to “\(x\ge\max_a y_a\)” written without max?

Answer. The objective function is linear. The problem is \(v(s)\ge\max_a[\cdots]\) and \(\max\). However, this constraint is equivalent to “\(a\) for all \(v(s)\ge[\cdots]\)”. When written this way, both sides of each constraint become affine for \(v\). \[ \boxed{\ \min_{v\in\mathbb{R}^n}\ c^\top v\quad\text{s.t.}\quad v(s)\ge r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\,v(s')\quad\forall(s,a)\in S\times A\ } \] The number of variables remains \(n\), and the number of constraints has increased from \(n\) to \(nm\).

TipSignificance
  • LP is the simplest class of optimization problems, and solvers are a mature technology.
  • The cost is the number of constraints. In a large-scale MDP, \(nm\) constraints become a burden. The two directions to reduce this burden are dual(Section 6.1) and approximation(Section 7.1).
  • To summarize, it is an LP version of the same problem as the original, at the cost of increasing the number of constraints. The solution is still \(v^*\).

5.1.1 “\(x\ge\max_ay_a\) ⇔ Two directions of \(x\ge y_a\) for all \(a\)”

NoteProof

(\(\Rightarrow\)) For all \(a\)Z \(y_a\le\max_by_b\le x\).

(\(\Leftarrow\)) If \(a\) for all \(y_a\le x\), then \(x\) is an upper bound of \(\{y_a\}\). Since the maximum value of a finite set is the smallest of the upper bounds, \(\max_ay_a\le x\).

If we set \(x=v(s)\), \(y_a=r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\,v(s')\) and write for all \(s\), it becomes the LP of Section 5.1.

TipSignificance: Conditions under which this equivalence holds
  • This solution works only when max is on the larger side (right side) of the inequality and the inequality is “\(\ge\max\)”. “\(\le\max\)” becomes an existential statement “for some \(a\)” and cannot be used as the intersection of linear constraints.
  • It is also important to note that max is outside the sum. The same method does not apply to the Bellman equation for Q where max is inside the sum → Section 9.1.1

5.1.2 What is the role of \(c\)

First question to consider. \(c\) has only the condition that “all elements are positive.” If you were designing the problem yourself, how would you determine \(c\)? Does changing \(c\) change the solution?

Answer. \(c(s)\) is the weight assigned to the \(s\)-th element of the value. If \(c(s)\) is increased, the search proceeds in the direction of further lowering \(v(s)\). If prior knowledge about the optimal value (which state has a lower value) exists, it can be reflected; otherwise, it is set to \(c=\mathbf{1}\).

TipSignificance: Different from exact LPs and approximate LPs
  • Exact LP: According to Section 4.1.1, if \(c>0\) is the case, the optimal solution is always \(v^*\). \(c\) does not change the solution. It only affects the solver’s search path and numerical efficiency.
  • Approximation LP: If \(v^*\) cannot be expressed exactly, \(c\) replaces the solution. In this case, \(c\) becomes the weight of the state-specific approximation error → Section 7.1.1
  • In dual: \(c\) acts as the initial state distribution. Since it is \(c>0\), positive mass is entered into all states, so the policy can be restored in all states → Section 6.1.3, Section 6.1.4

5.1.3 Why are there only \(n\) constraints on policy evaluation LP?

\[ \min_{v\in\mathbb{R}^n}\ c^\top v\quad\text{s.t.}\quad v\ge T^\pi v \ \Longleftrightarrow\ \min_{v}\ c^\top v\quad\text{s.t.}\quad v(s)\ge r(s,\pi(s))+\gamma\sum_{s'}p(s'\mid s,\pi(s))\,v(s')\quad\forall s. \]

Answer. There is no max in \(T^\pi\). Therefore, the constraint is linear from the start, and one per state, \(n\), is sufficient. The solution is \(v^\pi\). The proof can be done by replacing \(T\) with \(T^\pi\) in Section 4.1.1. This is because \(T^\pi\) is also monotonic and \(\gamma\)-reduction, and the only fixed point is \(v^\pi\).

TipSignificance
  • It is efficient because it is a small LP in which the behavioral dimension \(m\) has disappeared. It serves as the basis for using LP in the evaluation phase of PI.
  • In the optimal solution, all constraints hold as equals (\(v^\pi=T^\pi v^\pi\)). That is, this LP is another method for finding the solution to the system of linear equations \((I-\gamma P^\pi)v=R^\pi\).

6 III. Duality

6.1 What is the dual LP, and why can it be computationally preferred?

The first question to think of.

  1. One dual variable is assigned to each constraint. How many primal constraints are there, and what indices do they have?
  2. When minimizing the Lagrangian for ZZZPH0013200ZZZ \(v\), when does a finite value other than \(-\infty\) occur?
  3. What does that “condition making it finite” become of the dual?

Answer. Since there is one primal constraint for every \((s,a)\), there are \(\lambda(s,a)\ge0\), that is, \(n\times m\). If we organize the Lagrangian by the coefficients of \(v(s')\), it is \(\min_vL=-\infty\) when at least one coefficient is not \(0\). Therefore, “coefficient \(=0\)” becomes the equality constraint of the dual, and the remaining term becomes the objective function of the dual. \[ \boxed{\ \max_{\lambda\ge0}\ \sum_{s,a}\lambda(s,a)\,r(s,a)\quad\text{s.t.}\quad c(s')+\gamma\sum_{s,a}\lambda(s,a)\,p(s'\mid s,a)-\sum_a\lambda(s',a)=0\quad\forall s'\in S\ } \]

TipSignificance
  • dual is also an LP. Both the objective function and the constraints are linear with respect to \(\lambda\).
  • There is no duality gap. If both the primal and dual are feasible, the LP satisfies strong duality. For the primal, \(v^*\) is feasible, and for the dual, the occupancy measure of an arbitrary policy is feasible (Section 6.1.3). Therefore, the dual optimal value is \(=c^\top v^*\).
  • Sizes are swapped: variable \(n\to nm\), constraint \(nm\to n\) (equation). In LP, dual may be preferred because having fewer constraints is usually computationally advantageous.

6.1.1 From Lagrangian to Dual Function: Reordering the Sum

NoteInduction

Step 1: Change the constraint to the form \(g\le0\). The primal constraint is \[g_{s,a}(v):=r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\,v(s')-v(s)\ \le\ 0.\]

Step 2: Lagrangian. The Lagrangian of \(\min f\) st \(g\le0\) is \(f+\sum\lambda g\), \(\lambda\ge0\). \[ L(v,\lambda)=\underbrace{\sum_sc(s)\,v(s)}_{\text{(a)}}+\underbrace{\sum_{s,a}\lambda(s,a)\,r(s,a)}_{\text{(b)}}+\underbrace{\gamma\sum_{s,a}\lambda(s,a)\sum_{s'}p(s'\mid s,a)\,v(s')}_{\text{(c)}}-\underbrace{\sum_{s,a}\lambda(s,a)\,v(s)}_{\text{(d)}}. \]

Step 3: Collect all \(v\) terms into the coefficients of \(v(s')\).

  • (a): Renames only the indices of the junction. \(\sum_{s'}c(s')\,v(s')\).
  • (c): Since it is a finite sum, the order is changed. \(\sum_{s'}v(s')\cdot\gamma\sum_{s,a}\lambda(s,a)\,p(s'\mid s,a)\).
  • (d): \(\sum_s v(s)\sum_a\lambda(s,a)\) Groups and renames to \(s'\). \(\sum_{s'}v(s')\sum_a\lambda(s',a)\).

Therefore \[ L(v,\lambda)=\sum_{s,a}\lambda(s,a)\,r(s,a)+\sum_{s'}v(s')\underbrace{\Big[c(s')+\gamma\sum_{s,a}\lambda(s,a)\,p(s'\mid s,a)-\sum_a\lambda(s',a)\Big]}_{=:\,\kappa_\lambda(s')}. \]

Step 4: Minimize for \(v\). \(L\) is affine for \(v\). For any \(s'\), if \(\kappa_\lambda(s')\ne0\), send to \(v(s')\to\mp\infty\) and \(L\to-\infty\). Therefore \[ g(\lambda):=\min_vL(v,\lambda)=\begin{cases}\sum_{s,a}\lambda(s,a)\,r(s,a), & \kappa_\lambda(s')=0\ \ \forall s',\\ -\infty, & \text{그 외}.\end{cases} \]

Step 5: dual. Since \(\max_{\lambda\ge0}g(\lambda)\) becomes \(-\infty\)Z, \(\lambda\) is not useful for maximization, if we set \(\kappa_\lambda=0\) as a constraint, it becomes the dual LP of Section 6.1.

TipSignificance
  • What has changed in (c) is the perspective of counting “where starts to go to \(s'\)”. The flow out of \(s\) was recounted as the flow entering \(s'\). This shift in perspective is the starting point of the flow-preserving interpretation (Section 6.1.3).
  • In (d), the coefficient of \(v(s)\) is the sum of \(\lambda\) of all actions applied to \(s\). Therefore, there is one dual constraint per state, resulting in \(n\).

6.1.2 ✍ weak duality: primal objective value ≥ dual objective value

Guide Question:

  1. We define primal feasible \(v\) and dual feasible \(\lambda\). Why does the inequality remain when multiplying the constraint \(r(s,a)\le v(s)-\gamma\sum_{s'}p\,v(s')\) by \(\lambda(s,a)\ge0\)?
  2. Add for all \((s,a)\), and then group the right-hand side into the form \(\sum_{s'}v(s')[\cdots]\), what are the square brackets? (This is the same operation as step 3 of Section 6.1.1.)
  3. What does the square bracket change to when the dual constraint is applied?
NoteSolution

\[ \begin{aligned} \sum_{s,a}\lambda(s,a)\,r(s,a) &\le\sum_{s,a}\lambda(s,a)\Big[v(s)-\gamma\sum_{s'}p(s'\mid s,a)\,v(s')\Big] &&(\lambda\ge0,\ \text{primal 제약})\\ &=\sum_{s'}v(s')\Big[\sum_a\lambda(s',a)-\gamma\sum_{s,a}\lambda(s,a)\,p(s'\mid s,a)\Big] &&(\text{합의 순서 바꾸기})\\ &=\sum_{s'}c(s')\,v(s') &&(\text{dual 제약}). \end{aligned} \] equality holds only when the primal constraint is equality for all \((s,a)\) such that \(\lambda(s,a)>0\). This is the complementary slack condition → Section 6.1.4

6.1.3 Why is the dual constraint flow-preserving, and what does \(\lambda\) count?

Guide Question:

  1. dual constraint is rewritten as \(\sum_a\lambda(s',a)=c(s')+\gamma\sum_{s,a}p(s'\mid s,a)\,\lambda(s,a)\). What do the left side, the first term on the right side, and the second term on the right side each count, respectively?
  2. Given a stationary policy \(\pi\) and an (unnormalized) initial mass \(c\), let \(d_t(s,a):=\Pr^\pi(s_t=s,a_t=a)\). What is the one-step recursion that writes \(\sum_ad_{t+1}(s',a)\) to \(d_t\)?
  3. Let \(\lambda:=\sum_{t\ge0}\gamma^td_t\). What is the result when you multiply the recursion by \(\gamma^{t+1}\) and add them?
  4. What is \(\sum_{s,a}\lambda(s,a)\,r(s,a)\) in this case?
NoteSolution

1. The left side represents the total (discounted) amount remaining at \(s'\), the first term on the right side represents the mass placed at \(s'\) from the beginning, and the second term represents the amount flowing into \(s'\), one step after the other state, multiplied by the discount. “Amount remaining = Initial amount + Discounted inflow”.

2. The next state is determined by the transition, and the next action by the policy. \[\sum_ad_{t+1}(s',a)=\Pr(s_{t+1}=s')=\sum_{s,a}p(s'\mid s,a)\,d_t(s,a).\]

3. \(t=0\) Remove the term. \[ \sum_a\lambda(s',a)=\underbrace{\sum_ad_0(s',a)}_{=c(s')}+\sum_{t\ge0}\gamma^{t+1}\sum_ad_{t+1}(s',a) =c(s')+\gamma\sum_{s,a}p(s'\mid s,a)\underbrace{\sum_{t\ge0}\gamma^td_t(s,a)}_{=\lambda(s,a)}. \] That is, the discount share measure of all stationary policies is dual feasible.

4. \(\sum_{s,a}\lambda r=\sum_t\gamma^t\,\mathbb{E}^\pi_c[r(s_t,a_t)]=\sum_sc(s)\,v^\pi(s)=c^\top v^\pi\). Therefore, the dual is read as the problem of “maximizing the discounted cumulative reward \(c^\top v^\pi\) starting from the initial mass \(c\) with respect to the policy”. The optimal value is \(\max_\pi c^\top v^\pi=c^\top v^*\), which is equal to the primal optimal value.

Verification. Adding all dual constraints for \(s'\) gives \(\sum_{s,a}\lambda(s,a)=\sum_sc(s)/(1-\gamma)\). This is the total mass of the discounted sum.

TipSignificance
  • primal examines the same problem in the value space (which \(v\) satisfies the Bellman inequality), while dual examines it in the visit frequency space (how often a policy visits a state-behavior).
  • Since \(c>0\), \(\sum_a\lambda(s',a)\ge c(s')>0\). All states have positive mass, so policies can be defined in all states → Section 6.1.4

6.1.4 Complementary slack: How to extract a policy from a dual solution

Answer. For the primal optimal solution \(v^*\) and the dual optimal solution \(\lambda^*\), the following holds. \[ \lambda^*(s,a)>0\ \Longrightarrow\ v^*(s)=r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\,v^*(s'). \] , that is, the mass-based behavior of \(\lambda^*\) is a greedy behavior toward \(v^*\). Therefore, \[ \pi^*(a\mid s)=\frac{\lambda^*(s,a)}{\sum_b\lambda^*(s,b)} \] is the optimal policy. Since the denominator is greater than or equal to \(c(s)>0\), it is always defined.

NoteBasis

In the chain of inequalities Section 6.1.2, substituting \(\lambda^*\) and \(v^*\) results in a duality gap of \(0\), so the first line must be equal. The difference in the first line is \(\sum_{s,a}\lambda^*(s,a)\cdot(\text{제약의 여유})\), and since each term is non-negative, all terms are \(0\). If it were \(\lambda^*(s,a)>0\), the constraint margin would be \(0\).

TipSignificance

Solving primal yields \(v^*\), and for the policy, we must solve argmax again (model needed). If we solve dual, the policy is already contained within the solution. Verify this in the manual calculation example Section 11.2.

7 IV. Approximation LP

7.1 What decreases and what remains when approximating with a linear architecture

First question to consider. Whether primal or dual, the size is proportional to \(n\) and \(m\). If \(n\) is very large, what can be made small?

Answer. Constrain the value function to a linear combination of the given features. \[ v_\theta(s)=\sum_{k=1}^K\phi_k(s)\,\theta_k=\phi(s)^\top\theta,\qquad v_\theta=\Phi\theta,\quad\Phi=[\phi_1\ \cdots\ \phi_K]\in\mathbb{R}^{n\times K}\ (s\text{번째 행이 }\phi(s)^\top). \] Assign \(v=\Phi\theta\) to the LP of Section 5.1. \[ \boxed{\ \min_{\theta\in\mathbb{R}^K}\ c^\top\Phi\theta\quad\text{s.t.}\quad(\Phi\theta)(s)\ge r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\,(\Phi\theta)(s')\quad\forall(s,a)\ } \] Since \(\Phi\) is fixed, both the objective function and the constraints are linear with respect to \(\theta\). It is still an LP.

  • (+) Decision variable: \(n\to K\).
  • (−) Constraint number: \(nm\) as is.
  • If (−) \(v^*\notin\{\Phi\theta\}\), it loses optimality.
TipSignificance: Note the direction of the inequality sign
  • The direction paired with \(\min\) is \(\Phi\theta\ge T\Phi\theta\). As seen in the significance of Section 4.1.1, mixing \(\min\) and \(\le\) results in the objective function becoming unbounded below.
  • In literature using the cost minimization convention (ZZZPH0013268ZZZ, \(J\), \(\min_\mu\)), the form \(\max c^\top\Phi r\) st \(\Phi r\le T\Phi r\) is obtained. When switching between reward maximization and cost minimization, the objective \(\min/\max\) and the constraint \(\ge/\le\) are inverted together.
  • Problems where the number of constraints remains are handled using constraint sampling. The error limit of approximate solutions is also analyzed within this framework.

↓ Down: Section 7.1.1 ↑ Up: Section 5.1

7.1.1 Why is the approximate solution above \(v^*\), and what does \(c\) weigh?

Answer. Since the feasible \(\Phi\theta\) satisfies \(\Phi\theta\ge T\Phi\theta\), it is \(\Phi\theta\ge v^*\) by (i) of Section 4.1.1. Then \[ c^\top\Phi\theta=c^\top v^*+c^\top(\Phi\theta-v^*)=c^\top v^*+\sum_sc(s)\,\big|\Phi\theta(s)-v^*(s)\big|. \] Since \(c^\top v^*\) is a constant, the approximation LP minimizes the \(c\)-weighted \(\ell_1\) error \(\|\Phi\theta-v^*\|_{1,c}\) within the feasible set.

NoteDoes a feasible \(\theta\) exist?

constant feature \(\mathbf{1}\) needs to be in the column space of \(\Phi\). If we set it to \(\Phi\theta=\kappa\mathbf{1}\), the constraint is \(\kappa\ge r(s,a)+\gamma\kappa\), i.e., \(\kappa\ge\max_{s,a}r(s,a)/(1-\gamma)\). Such a \(\kappa\) always exists.

TipSignificance
  • In the exact LP, \(c\) did not change the solution(Section 5.1.2). In the approximate LP, \(c\) becomes a weight that determines “which state’s error to reduce further” and changes the solution.
  • The approximate solution is always the upper bound of \(v^*\). This means that when estimating policy performance with approximate values, it tends to be skewed toward overestimation.

8 V. Q-function

8.1 What is the Q-function, and what is its relationship to \(v^*\)?

\[ Q^*(s,a):=\max_\pi Q^\pi(s,a)=\max_\pi\mathbb{E}^\pi\Big[\sum_{t\ge0}\gamma^tr(s_t,a_t)\ \Big|\ s_0=s,\ a_0=a\Big]. \]

The first question to think of. The difference between \(v^*(s)\) and \(Q^*(s,a)\) is “what is fixed.” What must be added to \(v^*(s)\) to obtain \(Q^*(s,\cdot)\)?

Answer. \(Q^*(s,a)\) is the maximum expected cumulative reward after fixing the first action at \(a\). Since \(v^*(s)\) requires even the first action to be chosen optimally, \[ v^*(s)=\max_aQ^*(s,a),\qquad\pi^*(s)\in\arg\max_aQ^*(s,a). \] In the infinite discount setting, the starting point is not important, so it was set to start at \(t=0\).

NoteThe basis of \(v^*=\max_aQ^*\)

If you use ZZZPH0013286ZZZ Section 8.1.2 to see \(Q^*(s,a)=r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\,v^*(s')\) \[\max_aQ^*(s,a)=\max_a\Big[r(s,a)+\gamma\sum_{s'}p\,v^*(s')\Big]=(Tv^*)(s)=v^*(s).\] The last equality sign is because \(v^*\) is a solution to the Bellman equation.

8.1.1 What is the advantage of knowing \(Q^*\) compared to knowing only \(v^*\)?

First question to consider. If you write the equations for extracting the optimal policy for the two cases side by side, which side contains \(r\) and \(p\)?

Answer. \[ \begin{aligned} v^*\text{를 알 때}:&\quad\pi^*(s)\in\arg\max_a\Big[r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\,v^*(s')\Big] &&\leftarrow\ r,\ p\ \text{필요}\\ Q^*\text{를 알 때}:&\quad\pi^*(s)\in\arg\max_aQ^*(s,a) &&\leftarrow\ \text{모델 불필요} \end{aligned} \] \(Q^*\) is a table where the entire set of brackets is pre-calculated for each \((s,a)\). Therefore, it contains more information, and a model is not needed when retrieving policies.

TipSignificance
  • Even if ZZZPH0013294ZZZ is trained perfectly on \(v^*\) in a model-free configuration, a model is still needed to create a policy. Therefore, most RL algorithms train on \(Q\). The name Q-learning also comes from this.
  • The cost is that the size of the learning target increases from \(n\) to \(nm\).

8.1.2 How is the Bellman equation for Q derived?

\[ Q^*(s,a)=\underbrace{r(s,a)}_{\text{즉각 보상}}+\gamma\sum_{s'}p(s'\mid s,a)\underbrace{v^*(s')}_{\text{다음 상태의 최적 가치}} =r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\max_{a'}Q^*(s',a'). \]

First question to consider. If \((s,a)\) is currently fixed, the immediate reward is determined. Where does the remaining optimization go?

NoteInduction

If you set it to \(G_1:=\sum_{t\ge1}\gamma^{t-1}r(s_t,a_t)\), it is \(\sum_{t\ge0}\gamma^tr_t=r(s_0,a_0)+\gamma G_1\).

(≤) \[ \begin{aligned} Q^\pi(s,a)&=r(s,a)+\gamma\,\mathbb{E}^\pi[G_1\mid s_0=s,a_0=a]\\ &=r(s,a)+\gamma\,\mathbb{E}\big[\mathbb{E}^\pi[G_1\mid s_0,a_0,s_1]\ \big|\ s_0=s,a_0=a\big] &&(\text{tower})\\ &=r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\,\mathbb{E}^\pi[G_1\mid s_0,a_0,s_1=s'] &&(s_1\text{의 분포는 }p(\cdot\mid s,a))\\ &\le r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\,v^*(s') &&(s'\text{부터의 누적 보상} \le v^*(s')). \end{aligned} \] Since this holds for all \(\pi\), it also holds for \(\max_\pi\).

(≥) We consider a policy where the first move is \(a\), and thereafter follows the stationary optimal policy \(\pi^*\). Due to Markov properties and stationarity, the value of the tail starting from \(s_1=s'\) is \(v^{\pi^*}(s')=v^*(s')\). Since this is an acceptable policy, \[Q^*(s,a)\ge r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\,v^*(s').\]

Combining the two directions yields the first equality, and substituting \(v^*=\max_{a'}Q^*\) yields the second equality.

Define the right side of this expression as an operator. \[ (T_QQ)(s,a):=r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\max_{a'}Q(s',a'),\qquad Q^*=T_QQ^*. \]

TipSignificance: The formula and structure are different from \(v\)
  • \(T\): max is outside the sum. Select the current action \(a\).
  • \(T_Q\): max is not sum. For every next state \(s'\), select the next action \(a'\) separately.

Due to this difference, the linearization of the Q-LP is not as simple as in the case of \(v\) → Section 9.1.1

↓ Down: Section 8.1.3 ↑ Up: Section 8.1

8.1.3 Why is \(T_Q\) monotonous and \(\gamma\) a contraction?

NoteProof

Monotonic. If \(Q\le Q'\), then for each \(s'\)Z, \(\max_{a'}Q(s',a')\le\max_{a'}Q'(s',a')\), and the weighted sum of \(p\ge0\) preserves order. Therefore, \(T_QQ\le T_QQ'\).

Abbreviation. \[ \begin{aligned} |(T_QQ)(s,a)-(T_QQ')(s,a)| &=\gamma\Big|\sum_{s'}p(s'\mid s,a)\Big(\max_{a'}Q(s',a')-\max_{a'}Q'(s',a')\Big)\Big|\\ &\le\gamma\sum_{s'}p(s'\mid s,a)\,\max_{a'}|Q(s',a')-Q'(s',a')| &&(\text{max 차이 부등식})\\ &\le\gamma\|Q-Q'\|_\infty\sum_{s'}p(s'\mid s,a)=\gamma\|Q-Q'\|_\infty. \end{aligned} \] It ends by taking the max for \((s,a)\).

max difference inequality: For all \(a\), \(x_a\le y_a+|x_a-y_a|\le\max_by_b+\max_b|x_b-y_b|\). Take \(\max_a\) on the left side, and swap \(x\) and \(y\) once more.

TipSignificance

Since it possesses the same two properties as \(T\), the argument in Section 4.1.1 is transferred directly to Q-LP (Section 9.1). The same property is used in the convergence proof of Q-learning.

9 VI. Q-LP

9.1 What is Q-function LP and why is it inefficient

\[ \min_{Q\in\mathbb{R}^{n\times m}}\ \sum_{s,a}c(s,a)\,Q(s,a)\quad\text{s.t.}\quad Q\ge T_QQ,\qquad c>0. \]

The first question to think of.

  1. In the proof that the solution to is \(Q^*\), which part of Section 4.1.1 needs to be changed?
  2. To remove max, for which indices should “all” be added this time? Then, how many constraints are there?

Answer.

  1. We just need to replace \(T\) with \(T_Q\). Since \(T_Q\) is also monotonic and contracted, and the unique fixed point is \(Q^*\) (Section 8.1.3), the unique optimal solution with the same three lines is \(Q^*\).
  2. Since max is bound to the next action \(a'\), increase the constraint for \(a'\) as well. \[ Q(s,a)\ge r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\,Q(s',a')\qquad\forall(s,a,a'). \] There are \(n\times m\times m=nm^2\) constraints. It is rare to use this LP directly when finding the optimal Q.
TipSignificance

\(v\)-LP had variables \(n\) and constraints \(nm\). Q-LP had variables \(nm\) and constraints \(nm^2\). Since it amounts to solving the same information into a larger problem, there is no advantage for calculating optimal value. Q-LP is useful when the policy is fixed and the max disappears. → Section 10.1

↓ Down: Section 9.1.1 ↑ Up: Section 8.1

9.1.1 Fixed \(a'\) Is linearization equivalent to the original constraint?

First question to consider. The equivalence of Section 5.1.1 was when max was outside the sum. Under the linearization constraints above, can \(a'\) depend on \(s'\)?

Answer. They are not equivalent. Under the above constraint, \(a'\) is a single action common to all \(s'\). Therefore, the entire above constraint is \[ Q(s,a)\ge r(s,a)+\gamma\max_{a'}\sum_{s'}p(s'\mid s,a)\,Q(s',a') \] is equivalent to |||. However, generally \[ \max_{a'}\sum_{s'}p(s'\mid s,a)\,Q(s',a')\ \le\ \sum_{s'}p(s'\mid s,a)\max_{a'}Q(s',a') \] Since (on the right, the best \(a'\) is selected separately for each \(s'\)), the linearized constraint is loose compared to \(Q\ge T_QQ\). As the feasible set grows, the optimal objective value can become smaller than that of \(Q^*\), and the solution differs from \(Q^*\).

NoteExact linearization: auxiliary variables

Set an auxiliary variable \(u\in\mathbb{R}^n\) to represent the value of the next state. \[ \min_{Q,u}\ \sum_{s,a}c(s,a)\,Q(s,a)\quad\text{s.t.}\quad \begin{cases} Q(s,a)\ge r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\,u(s') & \forall(s,a)\\ u(s')\ge Q(s',a') & \forall(s',a') \end{cases} \] - If (\(\Rightarrow\)) \((Q,u)\) is feasible, then \(u(s')\ge\max_{a'}Q(s',a')\), and since \(p\ge0\), \(Q\ge r+\gamma\sum p\,u\ge T_QQ\). - (\(\Leftarrow\)) If \(Q\ge T_QQ\), then setting it to \(u(s'):=\max_{a'}Q(s',a')\) feasible.

Since the feasible set for \(Q\) is the same as the original, the solution is \(Q^*\). There are \(nm+nm=2nm\) constraints.

Numerical verification. For 200 randomly generated \(n=3\), \(m=2\), and \(\gamma=0.9\) MDPs, the auxiliary variable LPs all returned \(Q^*\) exactly. The fixed \(a'\) LP returned a solution different from \(Q^*\) (in one example, all elements were 0.04–0.06 smaller than \(Q^*\), and the maximum error out of 200 was approximately 2.7).

TipSignificance

The trick that “to get rid of a max, increase the constraint for every indices it is bound by” is only accurate when the max is outside the sum. To accurately linearize a max inside the sum, one must express “\(a'\) chosen for every \(s'\),” and the cleanest way is to keep that max value separately as a variable \(u(s')\). This \(u\) is effectively \(v\).

10 VII. Q-based policy iteration

10.1 To what extent can Q-based PI be performed without a model?

The first question to think of.

  1. If policy \(\pi\) is fixed, what does the max of \(T_Q\) change to? Then, how many constraints are there in the Q-LP?
  2. In the enhancement step \(\pi_{k+1}(s)\in\arg\max_a[r+\gamma\sum p\,v^{\pi_k}]\) of the existing PI, what is the entire bracket equal to?

Answer.

  • Evaluation: Since \(\pi(s')\) is placed in the max position, the constraint is linear, and there is one \((s,a)\) and \(nm\) solutions. The solution is \(Q^\pi\). \[ \min_{Q}\ \sum_{s,a}c(s,a)\,Q(s,a)\quad\text{s.t.}\quad Q(s,a)\ge r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\,Q(s',\pi(s'))\quad\forall(s,a). \]
  • Enhancement: \(\pi(s)\in\arg\max_aQ(s,a)\). No model needed.
NoteReason why the enhancement stage is Model Free

The Bellman equation of \(Q^{\pi_k}\) is \[ Q^{\pi_k}(s,a)=r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\,Q^{\pi_k}(s',\pi_k(s'))=r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\,v^{\pi_k}(s'). \] This is because the final equality sign is \(v^{\pi_k}(s')=Q^{\pi_k}(s',\pi_k(s'))\) (act according to policy in the next state). In other words, the brackets of the existing enhancement stage are exactly \(Q^{\pi_k}(s,a)\). If \(Q^{\pi_k}\) has already been calculated, there is no need to recreate those brackets, and only \(\arg\max_aQ^{\pi_k}(s,a)\) needs to be done.

TipSignificance
  • The PI structure alternating between evaluation and enhancement remains the same. Monotonic enhancement and convergence arguments are also transferred as they are.
  • Now, the only place where a model remains is \(\sum_{s'}p(s'\mid s,a)\,Q(s',\pi(s'))\) in the evaluation LP. If only this is changed to data, the entire thing becomes model-free → Section 10.2

10.2 Data-Driven PI: How to Eliminate Expectations in the Evaluation Phase

First question to consider. On the right-hand side of the evaluation LP constraint, the work done by \(p\) is the “expected value for the next state.” If we do not know \(p\) but can we sample the next state?

Answer. Collect transition samples \((s,a,r,s')\) from each \((s,a)\). These four elements constitute one unit of a transition sample in RL. Let \(D_{s,a}\) be the collection of the next states observed from \((s,a)\), and replace the expected value with the sample mean. \[ \sum_{s'}p(s'\mid s,a)\,Q(s',\pi(s'))\ \approx\ \frac1{|D_{s,a}|}\sum_{s'\in D_{s,a}}Q(s',\pi(s')). \] The algorithm repeats the following two steps.

  • Evaluation (Data-based): \[\min_{Q}\ \sum_{s,a}c(s,a)\,Q(s,a)\quad\text{s.t.}\quad Q(s,a)\ge\hat r(s,a)+\gamma\,\frac1{|D_{s,a}|}\sum_{s'\in D_{s,a}}Q(s',\pi(s'))\quad\forall(s,a)\] (\(\hat r(s,a)\): Average of observed rewards. If the reward is deterministic, that value.)
  • Enhance: \(\pi(s)\in\arg\max_aQ(s,a)\).

Since neither step uses \(p\), it is model free.

NoteWhy is normalization of necessary for \(1/|D|\)

For the sample mean to approximate the expected value, the sum of the weights must be 1. If only \(\sum_{s'\in D}\) is used without \(1/|D|\), the right-hand side grows proportionally to the number of samples. Then, the “effective discount rate” of \(\gamma\sum_{s'\in D}\) becomes \(\gamma|D|\), which can exceed 1, and the conciseness of the operator is broken, resulting in no solution or a meaningless solution.

NoteWhat is the solution to this LP?

If we set the empirical transition probability \(\hat p(s'\mid s,a):=\#\{s'\text{가 }D_{s,a}\text{에 나타난 횟수}\}/|D_{s,a}|\) \[\frac1{|D_{s,a}|}\sum_{s'\in D_{s,a}}Q(s',\pi(s'))=\sum_{s'}\hat p(s'\mid s,a)\,Q(s',\pi(s')).\] Since \(\hat p(\cdot\mid s,a)\) is a probability distribution, the data-driven evaluation LP is the policy evaluation LP of the empirical MDP \((\hat p,\hat r)\) itself. The solution is \(Q^\pi_{\hat p}\) in that MDP. As the sample size of each \((s,a)\) increases, by the law of large numbers it becomes \(\hat p\to p\), and since \(Q^\pi\) is continuous in finite dimensions to \(p\), it becomes \(Q^\pi_{\hat p}\to Q^\pi\).

TipSignificance
  • It is the first algorithm to perform both evaluation and improvement without a model. The trade-off is that samples are required from every \((s,a)\), and the LP size is proportional to \(nm\). It is sufficient for small problems.
  • The idea of “replacing expected values with samples” is the starting point for the next steps (probabilistic approximation, TD, Q-learning). In that case, instead of collecting samples and solving LP again, the estimate is updated little by little whenever a sample comes in.

11.2 Manual calculation example: primal, dual, and complementary slacks all at once

Settings. \(S=\{0,1\}\), \(A=\{\text{stay},\text{move}\}\), \(\gamma=0.9\), \(c=(1,1)\). Transition is deterministic.

\((s,a)\) \(r\) Next status
\((0,\text{stay})\) 1 0
\((0,\text{move})\) 0 1
\((1,\text{stay})\) 2 1
\((1,\text{move})\) 0 0

✍ Try solving this first.

  1. Write the four constraints of primal LP, and find \(v^*\) using the Bellman equation.
  2. Write the two equation constraints of dual LP.
  3. Determine which \(\lambda\) is 0 using complementary margins, and solve the remainders.
  4. Check if the two target values are the same.
NoteSolution

1. primal. \[ \begin{aligned} v(0)&\ge1+0.9\,v(0), & v(0)&\ge0+0.9\,v(1),\\ v(1)&\ge2+0.9\,v(1), & v(1)&\ge0+0.9\,v(0). \end{aligned} \] Bellman Equation: In State 1, repeating stay results in \(2/(1-0.9)=20\). Moving results in \(0.9\,v(0)\), but since \(v(0)\le20\), staying is better. \(v^*(1)=20\). In State 0, staying results in \(1/(0.1)=10\), and moving results in \(0.9\times20=18\). \(v^*(0)=18\).

\(v^*=(18,20)\), \(c^\top v^*=38\). The constraints for which equality holds are \((0,\text{move})\) and \((1,\text{stay})\).

2. dual constraint (\(\sum_a\lambda(s',a)=c(s')+\gamma\cdot\text{유입}\)): \[ \begin{aligned} s'=0:&\quad\lambda(0,\text{st})+\lambda(0,\text{mv})=1+0.9\big[\lambda(0,\text{st})+\lambda(1,\text{mv})\big],\\ s'=1:&\quad\lambda(1,\text{st})+\lambda(1,\text{mv})=1+0.9\big[\lambda(0,\text{mv})+\lambda(1,\text{st})\big]. \end{aligned} \]

3. Complementary Lack. For non-equality constraints \((0,\text{stay})\) and \((1,\text{move})\), it must be \(\lambda=0\). The remaining expression is \[ \lambda(0,\text{mv})=1,\qquad\lambda(1,\text{st})=1+0.9\,(1+\lambda(1,\text{st}))\ \Rightarrow\ 0.1\,\lambda(1,\text{st})=1.9\ \Rightarrow\ \lambda(1,\text{st})=19. \]

4. Objective value. dual: \(\sum\lambda r=19\times2=38\). primal: \(38\). Equal.

Verification. Total mass \(1+19=20=\sum_sc(s)/(1-\gamma)=2/0.1\).

Restore policy. Since \(\lambda(0,\cdot)=(0,1)\), move from state 0; since \(\lambda(1,\cdot)=(19,0)\), stay from state 1. Same as greedy policy.

Analysis of the occupancy measure. Mass 1, starting in state 0, immediately moves to state 1 (0.9 after discounting), combines with the 1 that was in state 1 from the beginning, and stays at every step. The total discount amount of state 1 is \((1+0.9)/(1-0.9)=19\).

(The above values are also confirmed with the LP solver as primal \(v=(18,20)\), dual \(\lambda=(0,1,19,0)\), and target value 38.)
