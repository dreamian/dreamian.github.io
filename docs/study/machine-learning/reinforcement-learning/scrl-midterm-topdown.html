3 0. Starting point

3.1 What is an MDP problem, and why is it difficult to solve directly?

Answer. The goal is \(\max_\pi\mathbb{E}^\pi\big[\sum_{t\ge0}\gamma^tr(s_t,a_t)\big]\). The optimization variable \(\pi\) is a function that goes from a state to an action (distribution). Therefore, it is not clear what the gradient of this objective function with respect to \(\pi\) is, and conventional numerical optimization cannot be applied directly. The solution is dynamic programming (DP). It breaks down a single difficult problem into several easier problems called state-specific action optimizations.

TipSignificance: Why optimize policies rather than action sequences?

Since transitions are probabilistic, the next state cannot be known in advance. A pre-optimized sequence of actions is no longer optimal if it reaches a state different from what was expected. The policy contains responses in advance for all reachable states.

TipSignificance: Why it cannot be solved with supervised learning

Reward \(r(s,a)\) measures only the immediate gain of the current state and action, and cannot measure future gain. Therefore, a label stating “the correct action in this state is this” does not exist.

TipSignificance: The fact that behavior has long-term effects, and that it involves sacrificing immediate rewards

The current action changes the trajectory of the states that will be traversed in the future. Therefore, even if the immediate reward is small, if the long-term gain is large, that action should be chosen. The Bellman equation is the exact mathematical expression of this statement. The optimal action is the action that maximizes “immediate reward + γ × optimal value of the next state.”

Sub-question.

  • What is \(v^\pi(s)\)? The expected value of the cumulative reward obtained when starting from state \(s\) and continuing to follow \(\pi\).
  • What is \(v^*(s)\)? It is the maximum expected cumulative reward that can be obtained with any policy starting from state \(s\), i.e., the best performance of that MDP.
  • Why is it said that “the MDP is solved if \(v^*\) is found”? This is because with only \(v^*\), the optimal policy can be immediately created using the state-specific argmax. → Section 6.5
  • What if we evaluate policy using Monte Carlo? It is an unbiased estimator, but the variance is large, and it must be repeated separately for each starting state. Therefore, we use DP that splits the value function into two parts → Section 10.2

4 I. Finite horizon MDP

4.1 Why does backward induction accurately produce \(v_t^*\) and \(\pi_t^*\)

Answer. It is because the two facts combine.

  1. \(v_t^*\) satisfies the Bellman recursive \(v_t^*(s)=\max_a\big[r_t(s,a)+\sum_{s'}p(s'\mid s,a)\,v_{t+1}^*(s')\big]\) (optimality principle), and the endpoint \(v_T^*=r_T\) is fixed. Therefore, it is uniquely determined in reverse order of \(t=T-1,\dots,0\).
  2. The deterministic Markov policy created with the argmax of each step is optimal.

The algorithm is as follows. \[ v_T^*:=r_T;\quad t=T-1{:}-1{:}0:\ \ v_t^*(s):=\max_a[\cdots],\ \ \pi_t^*(s)\in\arg\max_a[\cdots]\ \ \forall s. \]

TipSignificance
  • \(v_t^*\) and \(\pi_t^*\) are updated together in the same loop because they both only need the information for \(t+1\).
  • Hidden Complexity: At every time step, for every state, the action maximization must be solved. In large-scale problems, this is the bottleneck.
  • In finite MDPs, the optimality is not lost even when only the deterministic Markov policy is considered.

4.2 What are \(v_T^\pi(s)\) and \(v_T^*(s)\)?

Answer. Both are \(r_T(s)\).

NoteProof

When substituting \(t=T\) into \(v_t^\pi(s):=\mathbb{E}^\pi\big[\sum_{\tau=t}^{T-1}r_\tau(s_\tau,a_\tau)+r_T(s_T)\ \big|\ s_t=s\big]\), the sum \(\sum_{\tau=T}^{T-1}\) is empty. What remains is \(r_T(s_T)\), and since the condition is \(s_T=s\), it is \(v_T^\pi(s)=r_T(s)\).

Since the policy only includes \(\pi_0,\dots,\pi_{T-1}\), the value at time \(T\) does not depend on any policy. Therefore, it is \(v_T^*(s)=\max_\pi v_T^\pi(s)=r_T(s)\).

TipSignificance
  • Reason why the terminal term is \(r_T(s_T)\) instead of \(r_T(s_T,a_T)\): The trajectory of interest extends up to \(s_T\). The behavior at time \(T\) is out of interest because it only affects \(s_{T+1}\).
  • Two characteristics of a finite horizon emerge here: (1) the value function depends on time. (2) there is a terminal condition. This terminal condition is the starting point for reverse calculation. An infinite horizon lacks both.

4.3 Why does the policy evaluation recursion hold?

Proposition. For a stochastic Markov policy \(\pi=(\pi_0,\dots,\pi_{T-1})\), \(v_T^\pi=r_T\) and \[ v_t^\pi(s)=\sum_a\pi_t(a\mid s)\Big[r_t(s,a)+\sum_{s'}p(s'\mid s,a)\,v_{t+1}^\pi(s')\Big]. \]

Answer. This is because the value function is split into “current reward + cumulative reward from the next time point”, and the tower rule and Markov properties are applied to the second term in turn.

NoteProof

If you set it to \(G_t:=\sum_{\tau=t}^{T-1}r_\tau(s_\tau,a_\tau)+r_T(s_T)\), it is \(G_t=r_t(s_t,a_t)+G_{t+1}\).

  1. Linearity: \(v_t^\pi(s)=\mathbb{E}^\pi[r_t(s_t,a_t)\mid s_t=s]+\mathbb{E}^\pi[G_{t+1}\mid s_t=s]\).
  2. tower: \(\mathbb{E}^\pi[G_{t+1}\mid s_t=s]=\mathbb{E}^\pi\big[\mathbb{E}^\pi[G_{t+1}\mid h_{t+1}]\mid s_t=s\big]\), \(h_{t+1}=(s_0,a_0,\dots,s_t,a_t,s_{t+1})\).
  3. Markov: \(\mathbb{E}^\pi[G_{t+1}\mid h_{t+1}]=v_{t+1}^\pi(s_{t+1})\).
  4. Joint Distribution Expansion: When \(s_t=s\), the distribution of \((a_t,s_{t+1})\) is \(\pi_t(a\mid s)\,p(s'\mid s,a)\). The first term is \(\sum_a\pi_t(a\mid s)\,r_t(s,a)\), and the second term is \(\sum_a\pi_t(a\mid s)\sum_{s'}p(s'\mid s,a)\,v_{t+1}^\pi(s')\).
TipSignificance
  • The calculation order is reverse, from \(T\) to \(0\). You must finish all states of a current point in time to move to the previous point in time.
  • If it is a deterministic policy, \(\pi_t(\cdot\mid s)\) will converge at one point, becoming \(r_t(s,\pi_t(s))+\sum_{s'}p(s'\mid s,\pi_t(s))\,v_{t+1}^\pi(s')\).
  • In stochastic policies, the action distribution must be multiplied not only by the immediate reward but also by the next value term.

4.3.1 Where are the tower rule and Markov properties used respectively

Answer.

  • Tower rule: If \(\mathcal{G}_1\subset\mathcal{G}_2\), then \(\mathbb{E}[X\mid\mathcal{G}_1]=\mathbb{E}[\mathbb{E}[X\mid\mathcal{G}_2]\mid\mathcal{G}_1]\). Used only in the step of applying an additional layer of conditions.
  • Markov property: Makes the inner conditional expectation \(\mathbb{E}[G_{t+1}\mid h_{t+1}]\) a function of only \(s_{t+1}\)Z, i.e., \(v_{t+1}^\pi(s_{t+1})\), independent of the past. To achieve this, the transition must be Markov and the policy \(\pi_{t+1},\dots\) must also be Markov.
TipSignificance

In the answer, the two justifications are written on different lines. If the policy is history-dependent, the 3-step process is broken. In an infinite horizon, stationarity is additionally required here → Section 5.2

4.4 Optimality Principle: Why \(v_t^*\) satisfies Bellman recursion

Proposition. \(v_t^*(s)=\max_a\big[r_t(s,a)+\sum_{s'}p(s'\mid s,a)\,v_{t+1}^*(s')\big]\), \(v_T^*=r_T\).

Answer. If we separate (≤) and (≥), they become an equality sign.

  • (≤): Press down on the value after the next point in time as the optimal value.
  • (≥): Fixing the current action at any value and setting the subsequent actions to optimal results in an acceptable policy.
NoteProof (≤)

\[ \begin{aligned} v_t^*(s)&=\max_\pi\mathbb{E}^\pi\big[r_t(s_t,a_t)+G_{t+1}\mid s_t=s\big]\\ &=\max_\pi\mathbb{E}^\pi\big[r_t+\mathbb{E}^\pi[G_{t+1}\mid h_{t+1}]\mid s_t=s\big] &&\text{(tower)}\\ &=\max_\pi\mathbb{E}^\pi\big[r_t+v^\pi_{t+1}(s_{t+1})\mid s_t=s\big] &&\text{(Markov)}\\ &\le\max_\pi\mathbb{E}^\pi\big[r_t+v^*_{t+1}(s_{t+1})\mid s_t=s\big] &&(v^\pi_{t+1}\le v^*_{t+1},\ \text{기댓값의 단조성})\\ &=\max_\pi\sum_a\pi_t(a\mid s)\Big[r_t(s,a)+\sum_{s'}p(s'\mid s,a)\,v^*_{t+1}(s')\Big]\\ &=\max_a\Big[r_t(s,a)+\sum_{s'}p(s'\mid s,a)\,v^*_{t+1}(s')\Big] &&(\text{볼록결합} \le \max,\ \text{Dirac에서 등호}) \end{aligned} \]

NoteProof (≥): Two arguments

Argument (a), random policy + Dirac distribution. From the policy evaluation recursion(Section 4.3) for any \(\pi\) \[v_t^*(s)\ge v_t^\pi(s)=\sum_a\pi_t(a\mid s)\Big[r_t(s,a)+\sum_{s'}p\,v_{t+1}^\pi(s')\Big].\] On the right side, \(\pi_{t+1},\dots,\pi_{T-1}\) is random, so it can be replaced with the tail of the optimal policy. Then, \(v_{t+1}^*\) is placed in the position of \(v_{t+1}^\pi\). Now, since \(\pi_t(\cdot\mid s)\) is also random, applying a Dirac distribution with mass concentrated on each action yields an inequality for all \(a\), and the process concludes by taking \(\max_a\).

Argument (b), Allow Policy. A policy that takes action \(a\) at time \(t\) and follows the optimal policy from \(t+1\) is an allow policy. Its value is \(r_t(s,a)+\sum_{s'}p\,v^*_{t+1}(s')\), so this value cannot exceed \(v_t^*(s)\). Since this holds for all \(a\), we take \(\max_a\).

Both arguments use the existence of an optimal policy. If existence is not guaranteed, the same argument is made using an ε-optimal policy, but the ε error must be managed.

TipSignificance
  • Optimization for policies (functions \(T\)) has been changed to optimization for a single action in each \((t,s)\). The cost is that the maximization must be solved for every state.
  • The Bellman formula has four uses: optimal value calculation, verification of which policy is optimal, efficient computational procedures, and structural analysis of the optimal policy.

4.5 Why is the deterministic Markov policy built with argmax optimal?

Proposition. If \(\pi_t^*(s)\in\arg\max_a\big[r_t(s,a)+\sum_{s'}p\,v_{t+1}^*(s')\big]\), then in all \(t\)Z, \(v_t^{\pi^*}=v_t^*\).

Answer. (≤) is derived directly from the definition. (≥) appears to be reverse induction starting from \(t=T\).

NoteProof

(≤): \(v^*\) by definition of \(v_t^{\pi^*}\le v_t^*\).

(≥) Induction.

  • Base: \(t=T\) to \(v_T^{\pi^*}=r_T=v_T^*\).
  • Inductive Step: Assume \(v_{t+1}^{\pi^*}\ge v_{t+1}^*\).
    1. Since the transition probability has non-negative weights, \(\sum_{s'}p(s'\mid s,\pi_t^*(s))\,v_{t+1}^{\pi^*}(s')\ge\sum_{s'}p(s'\mid s,\pi_t^*(s))\,v_{t+1}^*(s')\).
    2. By the definition of argmax, for all \(a\), \(r_t(s,\pi_t^*(s))+\sum p(\cdot\mid s,\pi_t^*(s))\,v_{t+1}^*\ge r_t(s,a)+\sum p(\cdot\mid s,a)\,v_{t+1}^*\).
    3. Combining 1 and 2, for all \(a\), \(r_t(s,\pi_t^*(s))+\sum p(\cdot\mid s,\pi^*_t(s))\,v^{\pi^*}_{t+1}\ge r_t(s,a)+\sum p(\cdot\mid s,a)\,v^*_{t+1}\).
    4. The left side is \(v_t^{\pi^*}(s)\) by policy evaluation recursion (Section 4.3). Taking \(\max_a\) on the right side, it becomes \(v_t^*(s)\) by the Optimality Principle (Section 4.4).
TipSignificance

In a finite MDP, a deterministic Markov policy alone is sufficient. However, the decision rule may vary from time to time. The finite horizon policy must answer \(\pi_t^*\) for each time step.

4.6 How to construct a stochastic optimal policy, and why can there be multiple optimal policies

Proposition. If \(\bar\pi_t(a\mid s)>0\Rightarrow a\in A_t^*(s):=\arg\max_a[\cdots]\), then \(\bar\pi\) is optimal.

Answer. argmax If there are multiple elements in a set, the values inside the parentheses are all the same for those actions. Therefore, no matter how the probabilities are divided among them, the same value is obtained. There may be multiple optimal policies, but the optimal value \(v^*\) is unique by definition.

NoteProof

It appears to be reverse induction. It is \(v_T^{\bar\pi}=r_T=v_T^*\). Assuming \(v_{t+1}^{\bar\pi}=v_{t+1}^*\), by policy evaluation recursion \[v_t^{\bar\pi}(s)=\sum_a\bar\pi_t(a\mid s)\Big[r_t(s,a)+\sum_{s'}p\,v_{t+1}^*(s')\Big].\] For \(a\) in the support set, the parentheses are the same as \(v_t^*(s)\). Therefore, it is \(v_t^{\bar\pi}(s)=v_t^*(s)\sum_a\bar\pi_t(a\mid s)=v_t^*(s)\).

4.7 Finite horizon Why γ is not required in the Bellman equation

Answer. Since the reward can be time-dependent, defining it as \(r_t(s,a):=\gamma^tr(s,a)\) absorbs the discount into \(r_t\). Conversely, using \(\gamma\) in the Bellman equation without separately defining \(r_t\) is a source of confusion.

4.8 What Changes When Extended to Continuous States and Actions

Answer. Given the system model \(s_{t+1}=f(s_t,a_t,w_t)\) and the distribution \(w\)Z, \(p_w\), the following holds. \[p(s'\mid s,a)=p_w(w)\,\mathbf{1}\{s'=f(s,a,w)\},\qquad v_t(s)=\sup_a\Big[r(s,a)+\int v_{t+1}(f(s,a,w))\,p_w(dw)\Big].\] The Bellman equation can be used without explicitly calculating the transition probability. However, three problems arise.

  1. argmax may not exist. In this case, use the ε-optimal policy.
  2. Maximizing continuous actions itself is difficult.
  3. Since updates cannot be made across the entire state space, discretization is necessary. If there are \(N\) points per axis, it becomes \(d\) points in \(N^d\) dimensions, resulting in the curse of dimension.
TipSignificance

This limitation is the motivation for moving on to function approximation (weight learning) and deep RL. DP breaks down difficult problems into many easy problems, but the number of those easy problems increases exponentially.

4.9 How to derive transition probability in descriptive questions

Answer. Write the dynamics \(s'=g(s,a,W)\) and divide the region where \(s'\) can be into cases. There are three cases: interior, boundary (saturating max/min), and impossible (probability 0). Finally, check if \((s,a)\) is \(\sum_{s'}p=1\).

NoteExample: Inventory Management \(s_{t+1}=\max{s_t+a_t-D_t,0}\), \(p_j=\Pr(D=j)\)

The default settings are \(S=\{0,\dots,M\}\) and \(A_s=\{0,\dots,M-s\}\). The upper limit of \(A_s\) is due to storage capacity.

Transition probabilities are divided into three cases.

  • \(s+a<s'\le M\): Since the next stock cannot be greater than the stock after ordering, \(p(s'\mid s,a)=0\).
  • \(0<s'\le s+a\): Since the demand must be exactly \(D=s+a-s'\), \(p(s'\mid s,a)=p_{s+a-s'}\).
  • \(s'=0\): Excess demand is lost and cannot be sold. Since we add up all cases where demand is greater than inventory, \(p(0\mid s,a)=\sum_{j\ge s+a}p_j\).
TipSignificance: A space that must be entered in the answer
  • \(S\), \(A\)(or \(A_s\)), \(p(s'\mid s,a)\) (including boundaries), \(r_t(s,a)\) or \(c_t(s,a)\).
  • Termination \(r_T\): If not specified, write “\(r_T\equiv0\)” with the basis.
  • Objective function: \(\min\mathbb{E}[\sum c]\Leftrightarrow\max\mathbb{E}[\sum(-c)]\).
  • The sequence of events within a period (decision → cost incurrence → stochastic change) is directly reflected in the cost formula and transfer formula.

5 II. Infinite Discount MDP: Policy Evaluation

5.1 How is \(v^\pi\) calculated?

Answer. There are two methods.

  1. Inverse Matrix: \(v^\pi=(I-\gamma P^\pi)^{-1}R^\pi\).
  2. Fixed Point Repeat: \(v_{k+1}=T^\pi v_k\), \(v_k\to v^\pi\).

Both come from decomposition formula \(v^\pi=R^\pi+\gamma P^\pi v^\pi\).

TipSignificance

The inverse matrix of is \(O(n^3)\), and since it has a large memory capacity, it is suitable for small-scale problems. For large-scale problems, iteration is used. The justification for iteration comes from the contraction of \(T^\pi\) and Banach’s theorem.

Hidden complexity of iteration: All states must be updated in a single iteration. However, since the policy is fixed, there is no maximization of actions.

5.2 Why does the infinite horizon decomposition formula hold, and why is there no time index?

Proposition. \(v^\pi(s)=\sum_a\pi(a\mid s)\big[r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\,v^\pi(s')\big]\).

Answer. A tower like a finite horizon → Stationarity is added to the Markov argument. If \(r\), \(p\), and \(\pi\) are all time-invariant, then the process starting at \(t+1\) has the same distribution as the process starting at \(0\). Therefore, it becomes the function \(v^\pi\), where the value of the next state is the same.

NoteProof

\[ \begin{aligned} v^\pi(s)&=\mathbb{E}^\pi\Big[r(s_t,a_t)+\gamma\sum_{\tau\ge t+1}\gamma^{\tau-t-1}r(s_\tau,a_\tau)\ \Big|\ s_t=s\Big]\\ &=\mathbb{E}^\pi\Big[r(s_t,a_t)+\gamma\,\mathbb{E}^\pi\Big[\sum_{\tau\ge t+1}\gamma^{\tau-t-1}r_\tau\ \Big|\ s_{t+1}\Big]\ \Big|\ s_t=s\Big]&&(\text{tower, Markov})\\ &=\mathbb{E}^\pi\big[r(s_t,a_t)+\gamma\,v^\pi(s_{t+1})\mid s_t=s\big]&&(\text{stationarity})\\ &=\sum_a\pi(a\mid s)\Big[r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\,v^\pi(s')\Big]. \end{aligned} \]

TipSignificance

In the finite horizon, since the right side was \(t+1\) and the left side was \(t\), reverse calculation was possible. In the infinite horizon, there is the same function \(v^\pi\) on both sides. Therefore, reverse calculation is impossible, and this expression must be solved as an equation (or fixed-point problem).

5.3 What are the elements of the vector \(v^\pi=R^\pi+\gamma P^\pi v^\pi\)

5.4 Why is \(I-\gamma P^\pi\) always reversible?

Answer. The eigenvalue of \(P^\pi\) is \(\gamma<1\), and its absolute value is 1 or less. Therefore, the eigenvalue of \(I-\gamma P^\pi\), \(1-\gamma\mu\), cannot be 0.

NoteProof

Step 1: \(|\mu|\le1\). Let \(P^\pi x=\mu x\) and \(x\ne0\), and select \(i\), which is \(|x_i|=\|x\|_\infty\). Then \[|\mu|\,|x_i|=\Big|\sum_jP^\pi_{ij}x_j\Big|\le\sum_jP^\pi_{ij}|x_j|\le\|x\|_\infty\sum_jP^\pi_{ij}=\|x\|_\infty\] is used. Non-negative and row 1 were used. Therefore, \(|\mu|\le1\).

Step 2: Reversibility. If \((I-\gamma P^\pi)x=0\), then \(P^\pi x=\gamma^{-1}x\). However, the eigenvalue \(\gamma^{-1}>1\) contradicts Step 1. Therefore, \(x=0\) and \(I-\gamma P^\pi\) are reversible.

Step 3: Series Representation. Since \(\|\gamma P^\pi\|_\infty=\gamma<1\), the Neumann series converges. \[(I-\gamma P^\pi)^{-1}=\sum_{t\ge0}(\gamma P^\pi)^t.\]

TipSignificance
  • In \(v^\pi=\sum_t(\gamma P^\pi)^tR^\pi\), the \(t\) term is the “discounted value of the expected reward after \(t\) steps.” Therefore, it exactly matches the definition of the value function.
  • If \(\gamma=1\), then \(P^\pi\mathbf{1}=\mathbf{1}\), so \(I-P^\pi\) is a singular matrix.
  • Since each term is nasal, it is \((I-\gamma P^\pi)^{-1}\ge0\) → Section 6.3.3

6 III. Infinite Discount MDP: Optimality

6.1 The Bellman equation \(v=Tv\) has a unique solution, and that solution is \(v^*\).

\[(Tv)(s)=\max_a\Big[r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\,v(s')\Big].\]

6.2.3 What is the Banach Fixed Point Theorem?

Proposition. On a complete normed space (here, \((\mathbb{R}^n,\|\cdot\|_\infty)\)), if \(T\) is a \(\gamma\)-reduction, then the following two conditions hold.

  1. \(T\) has a unique fixed point \(v^\star\): \(v^\star=Tv^\star\).
  2. If we define \(v_0\) as \(v_{k+1}=Tv_k\), then it is \(v_k\to v^\star\).

Answer. If we show that the repeating sequence in (2) is a Cauchy sequence, the limit exists. Since that limit is a fixed point, the existence of the fixed point follows. Uniqueness is expressed in a single line of reduced inequality.

6.2.4 How are each proposition of Banach’s theorem proven?

Noteconvergence, and the existence part of (1)

① Consecutive difference. \(\|v_{k+1}-v_k\|=\|Tv_k-Tv_{k-1}\|\le\gamma\|v_k-v_{k-1}\|\le\cdots\le\gamma^k\|v_1-v_0\|\).

② Cauchy. \(m>n\), with telescopic sum and triangle inequality \[\|v_m-v_n\|\le\sum_{k=n}^{m-1}\|v_{k+1}-v_k\|\le\sum_{k=n}^{\infty}\gamma^k\|v_1-v_0\|=\frac{\gamma^n}{1-\gamma}\|v_1-v_0\|\xrightarrow{n\to\infty}0.\]

③ Existence of the limit. Since the space is complete, the Cauchy sequence has the limit \(v^\star\).

④ The limit is a fixed point. \[\|Tv^\star-v^\star\|\le\|Tv^\star-Tv_k\|+\|v_{k+1}-v^\star\|\le\gamma\|v^\star-v_k\|+\|v_{k+1}-v^\star\|\to0.\]

NoteUniqueness

If \(v^\star\) and \(\tilde v\) are both fixed points \[\|v^\star-\tilde v\|=\|Tv^\star-T\tilde v\|\le\gamma\|v^\star-\tilde v\|\] Since , it is \((1-\gamma)\|v^\star-\tilde v\|\le0\). Since \(1-\gamma>0\), it is \(v^\star=\tilde v\).

NoteConvergence rate

\(\|v_k-v^\star\|=\|Tv_{k-1}-Tv^\star\|\le\gamma\|v_{k-1}-v^\star\|\le\cdots\le\gamma^k\|v_0-v^\star\|\). It is geometric convergence.

6.3.1 Comparison Lemma: \(v\ge Tv\Rightarrow v\ge v^*\), \(v\le Tv\Rightarrow v\le v^*\)

Answer.

  • (≥ side): If we fix an arbitrary policy \(\pi\) and repeatedly substitute \(v\ge Tv\ge T^\pi v\) into itself, we get \(v\ge v^\pi\). Since this holds for all \(\pi\), we get \(v\ge v^*\).
  • (≤ side): Applying a greedy policy to \(v\) results in \(v\le Tv=T^{\pi_v}v\). Repeating monotonically results in \(v\le v^{\pi_v}\le v^*\).
NoteProof (v ≥ Tv ⇒ v ≥ v*)

For any stationary \(\pi\), by the definition of \(T\), \(Tv\ge T^\pi v=R^\pi+\gamma P^\pi v\). Therefore \[v\ge R^\pi+\gamma P^\pi v\ge R^\pi+\gamma P^\pi(R^\pi+\gamma P^\pi v)\ge\cdots\ge\sum_{t=0}^{n-1}(\gamma P^\pi)^tR^\pi+(\gamma P^\pi)^nv.\] The inequality holds even when multiplying by \(\gamma P^\pi\ge0\) at each step (Section 6.3.3). Since \(\|(\gamma P^\pi)^nv\|_\infty\le\gamma^n\|v\|_\infty\to0\), \(n\to\infty\), we have \(v\ge\sum_t(\gamma P^\pi)^tR^\pi=v^\pi\) (Section 5.4). Taking \(\max_\pi\) on both sides gives \(v\ge v^*\).

Refinement. For the abnormal Markov policy \((\pi_0,\pi_1,\dots)\), if \(Tv\ge T^{\pi_t}v\) is used at each step, \(v\ge T^{\pi_0}\cdots T^{\pi_{n-1}}v\to v^{(\pi_0,\pi_1,\dots)}\) is obtained through the same iteration.

NoteProof (v ≤ Tv ⇒ v ≤ v*)

If we set it to \(\pi_v(s)\in\arg\max_a[r(s,a)+\gamma\sum p\,v]\), then it is \(Tv=T^{\pi_v}v\)(Section 6.5.1). Then it is \(v\le T^{\pi_v}v\), and if we repeat with the monotonality of \(T^{\pi_v}\), \[v\le(T^{\pi_v})^nv\xrightarrow{n\to\infty}v^{\pi_v}\le v^*.\] The limit comes from the contraction (Section 5.5) of \(T^{\pi_v}\), and the final inequality comes from the definition of \(v^*\). (If this direction is proven using the “fixed point of \(T^nv\to\) \(T\),” it amounts to a circular argument, as it implies that the fixed point is already \(v^*\).)

6.5 Why is the greedy policy optimal for \(v^*\) and why is stationary sufficient?

Proposition. If \(S\) and \(A\) are finite, then a deterministic stationary optimal policy exists. The following is an example. \[\pi^*(s)\in\arg\max_a\Big[r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\,v^*(s')\Big]\]

  • \(T^{\pi^*}v^*=Tv^*\): This is because \(\pi^*\) is greedy with respect to \(v^*\)(Section 6.5.1).
  • \(Tv^*=v^*\): \(v^*\) is a solution to the Bellman equation(Section 6.1).
  • \(v^*=v^{\pi^*}\): \(T^{\pi^*}\) is a contraction, so the fixed point is unique, and it is \(v^{\pi^*}\)(Section 5.5).

7.2 Why does VI: \(v_{k+1}=Tv_k\) converge, and what is the cost?

Answer. By Banach’s theorem (2) and Section 6.1, it is \(v_k\to v^*\). The convergence rate is \(\|v_k-v^*\|\le\gamma^k\|v_0-v^*\|\).

TipSignificance
  • The policy evaluation iteration and template are the same. The only difference is that \(T\) is used instead of \(T^\pi\).
  • So in every iteration, action maximization is added in every state.
  • Difference from finite horizon: Since there is no terminal condition, neither the starting point nor the number of iterations is fixed. It runs until convergence, and the number of iterations depends on the initialization. Since the shape of the optimal value is not intuitive, it is usually initialized to 0 or a random vector.

7.3 PI: Why \(v^{\pi_k}\le v^{\pi_{k+1}}\)?

PI repeats two steps.

  • Policy Evaluation: \(v^{\pi_k}=T^{\pi_k}v^{\pi_k}\).
  • Policy Improvement: \(\pi_{k+1}(s)\in\arg\max_a\big[r+\gamma\sum p\,v^{\pi_k}\big]\).

Answer. If the operator of the new policy is applied once to the old value, it is greater than the old value. If this is repeated infinitely due to monotonicity, the limit is the new value.

NoteProof

Combine three facts.

    1. Evaluation step: \(v^{\pi_k}=T^{\pi_k}v^{\pi_k}\).
    1. Enhancement step: Since \(\pi_{k+1}\) is greedy for \(v^{\pi_k}\), \(T^{\pi_{k+1}}v^{\pi_k}=Tv^{\pi_k}\) (Section 6.5.1).
    1. Definition of \(T\): \(T^{\pi_k}v^{\pi_k}\le Tv^{\pi_k}\).

Therefore, it is \(v^{\pi_k}=T^{\pi_k}v^{\pi_k}\le Tv^{\pi_k}=T^{\pi_{k+1}}v^{\pi_k}\).

By repeatedly applying the monotonicity of \(T^{\pi_{k+1}}\) to both sides, \(v^{\pi_k}\le(T^{\pi_{k+1}})^\ell v^{\pi_k}\) holds for all \(\ell\). By the contraction of \(T^{\pi_{k+1}}\) (Section 5.5), the right-hand side converges to \(v^{\pi_{k+1}}\) at \(\ell\to\infty\).

TipSignificance

“Improvement” is justified as the performance of the policy, that is, the element-wise increase of the value function. The key is the interpretation of step (b). \(v^{\pi_k}\) is placed on the right side of the Bellman equation as if it were the optimal value, and its argmax is taken out as the policy.

7.4 Why does PI converge to the optimal policy?

Answer. It leads to five steps.

  1. The value sequence is monotonically non-decreasing(Section 7.3).
  2. Value is bounded(Section 7.4.1).
  3. By the monotonic convergence theorem, the limit \(\bar v\) exists.
  4. If we denote the greedy policy for \(\bar v\) as \(\bar\pi\), then \(v^{\bar\pi}=Tv^{\bar\pi}\) holds.
  5. Therefore, it is \(v^{\bar\pi}=v^*\) by Section 6.1.
NoteProof

If you set it to \(\bar\pi(s)\in\arg\max_a[r+\gamma\sum p\,\bar v]\) \[v^{\bar\pi}=T^{\bar\pi}v^{\bar\pi}=T^{\bar\pi}\bar v=T\bar v=Tv^{\bar\pi}.\]

  • The first equal sign is the definition of policy evaluation.
  • The second and fourth equal signs are written as \(\bar v=v^{\bar\pi}\).
  • The third equality is a greedy equation.

Basis for \(\bar v=v^{\bar\pi}\). There are only \(m^n\) deterministic stationary policies. Therefore, PI reaches the point \(\pi_{k+1}=\pi_k\) within a finite number of moves, at which point it becomes \(\bar v=v^{\pi_k}\) and \(\bar\pi=\pi_k\). To achieve this, a tie-breaking rule is required: if the current action is at argmax, keep it. Otherwise, cycle between equally optimal policies.

8.3 How is this problem an LP?

Answer. The constraint \(v(s)\ge\max_a[\cdots]\) is nonlinear due to the max. However, this is equivalent to “\(a\)Z for all \(v(s)\ge r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\,v(s')\)”. When written this way, both sides are affine for \(v\), so it becomes an LP.

  • LP is quickly solved by mature solvers such as interior-point and simplex.
  • In large-scale problems, the number of constraints is a burden.

8.4 What is the role of \(c\)

Answer. \(c_i\) is the weight assigned to the \(i\)-th element of the value. If \(c_i\) is increased, the search proceeds in the direction of further decreasing \(v_i\). If there is no prior knowledge of the optimal value, it is set to \(c=\mathbf{1}\).

In an exact LP, as long as it is \(c>0\), the solution is always the same as \(v^*\)(Section 8.2). That is, \(c\) does not change the solution but only affects numerical efficiency. \(c\) changes the solution when \(v^*\) cannot be accurately represented as in an approximate LP, at which time \(c\) becomes the weight of the state-specific approximation error.

8.7 What is the Q-function, and which Bellman equation does it satisfy?

Answer. Two definitions and two relational expressions.

  • Definition: \(Q^*(s,a)=\max_\pi\mathbb{E}^\pi[\sum\gamma^tr\mid s_0=s,a_0=a]\). This is the maximum expected value of the cumulative reward obtained after fixing the current action at \(a\).
  • Relation: \(v^*(s)=\max_aQ^*(s,a)\).
  • Bellman equation: \[Q^*(s,a)=r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\,v^*(s')=r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\max_{a'}Q^*(s',a').\]
  • operator \(T_Q\) is monotonic and contracted, and is \(Q^*=T_QQ^*\).
TipSignificance: Its structure is different from the Bellman formula of v.
  • \(v\) Formula: max is outside the sum (choose the current action).
  • \(Q\) Formula: max is in the sum (choose the next action of the next state).

8.7.1 Why does RL learn \(Q\) instead of \(v\)?

Answer. You just need to compare the formulas that extract the policy.

  • From \(v^*\): \(\pi^*(s)\in\arg\max_a[r+\gamma\sum p\,v^*]\). Models \(p\) and \(r\) are required.
  • From \(Q^*\): \(\pi^*(s)\in\arg\max_aQ^*(s,a)\). No model needed.

Even if we diligently train \(v^*\) in a model-free manner, a model is still needed when creating a policy. Therefore, we train \(Q\), which contains more information. The cost is that the training target has grown from \(n\) to \(nm\), requiring a larger sample size.

8.7.3 To what extent is Q-based PI model-free?

Answer.

9 VI. Probabilistic Approximation (SA)

9.1 How to Solve Fixed-Point Equations Without a Model

Answer. Let’s assume that even if we cannot accurately calculate \(Hx\) from \(Hx=x\), we can observe the noisy value \(Hx_k+w_k\). Then write the following iteration. \[x_{k+1}=(1-\alpha_k)x_k+\alpha_k(Hx_k+w_k)\] If the step size and noise satisfy appropriate conditions, the influence of the noise disappears in the long term, resulting in \(x_k\to x^*\).

TipSignificance

This is the theoretical framework of value-based RL algorithms. Both TD and Q-learning have the same structure: “Bellman fixed-point equation + noisy right-hand side formed from a single sample”.

9.2 Why VI·PI cannot be used directly in RL settings

Answer. In the definition of VI’s \(T\), the transition probability \(p\) is included in both the evaluation (\(P^\pi\)) and enhancement (\(\sum p\,v\)) of PI. In RL, \(p\) (and sometimes \(r\) as well) is unknown, and there are only transition samples obtained through trial and error.

TipSignificance and Pitfalls
  • Stochastic transitions themselves are not the problem. VI accurately handles stochastic transitions as expected values. The problem is that there is no model to calculate those expected values.
  • Two limitations of DP: knowledge of the model, scalability (curse of dimensionality).
  • Reasons why RL is useful: Flexibility (no model required), Adaptability (does not rely on a fixed model), Scalability (aims for approximate solutions from the start).
  • Reasons why RL is difficult: Limited knowledge, exploration–exploitation, limited expressiveness.
  • Characteristics of RL: No leader, delayed feedback, data is not iid, actions change subsequent data, exploration–exploitation trade-off.

9.3 SA form: \(\alpha\) and what is the meaning of the step direction?

Answer. The form for each coordinate is as follows. \[x_{k+1}(i)=(1-\alpha_k(i))\,x_k(i)+\alpha_k(i)\big[(Hx_k)(i)+w_k(i)\big]\] \(\alpha\) is the learning rate or innovation rate, giving weights of \(1-\alpha\) to the old estimate and \(\alpha\) to the new estimate. Summarizing, since it is \(x_{k+1}(i)=x_k(i)+\alpha_k(i)\big[(Hx_k)(i)-x_k(i)+w_k(i)\big]\), the step direction is \((Hx_k)(i)-x_k(i)+w_k(i)\). Assumption: For each \(i\), there are infinitely many \(k\) which is \(\alpha_k(i)>0\).

9.4 Is Robbins–Monro a special case of SA?

Answer. View the Bellman equation as \(x=\mathbb{E}[f(x,\xi)]\). Using the mean of \(N\) samples at every step makes calculations and data inefficient. Instead, using only one sample is Robbins–Monroe. \[x_{k+1}=(1-\alpha_k)x_k+\alpha_kf(x_k,\hat\xi).\] If we map SA, it is as follows. \[Hx_k=\mathbb{E}[f(x_k,\xi)],\qquad w_k=f(x_k,\hat\xi)-\mathbb{E}[f(x_k,\xi)].\]

TipSignificance
  • The noise \(w_k\) has an average of 0. Therefore, the first condition of the noise condition (conditional average 0) is naturally satisfied.
  • TD(0), TD(λ), and Q-learning are all of this form. For each algorithm, you only need to specify “what is \(f\) and what is \(\hat\xi\)”.

9.6 What is the noise condition, and what does the convergence theorem mean?

Answer. Let \(\mathcal{F}_k\) be the history up to step \(k\) (\(x_0,\dots,x_k\), \(w_0,\dots,w_{k-1}\), step size). There are two noise conditions.

  1. Conditional average 0: \(\mathbb{E}[w_k(i)\mid\mathcal{F}_k]=0\).
  2. Conditional variance limit: \(\mathbb{E}[w_k(i)^2\mid\mathcal{F}_k]\le C_0+C_1\|x_k\|^2\).

There are two convergence theorems.

  • Theorem 1 (Reduction): step size condition + noise condition + \(H\) reduction ⇒ probability 1 \(x_k\to x^*\).
  • Theorem 2 (Monotonic): Under three assumptions, if \(x_k\) is bounded with probability 1, then \(x_k\to x^*\) has probability 1. The three assumptions are as follows.
    • \(H\) is a monoton.
    • The fixed point is unique.
    • For all \(\eta>0\) \(Hx-\eta\mathbf{1}\le H(x-\eta\mathbf{1})\le H(x+\eta\mathbf{1})\le Hx+\eta\mathbf{1}\).
TipSignificance
  • For each algorithm, the order of verifying assumptions is more important than the proof of the theorem itself. The order is as follows: \(H\) specification → fixed point of the goal \(H\) → contraction of \(H\) → definition of \(w\) and conditional mean 0 → second moment limit → step size and visit condition. The convergence proofs of both TD(λ) and Q-learning follow this order.
  • Intuition: The noise must be conditionally unbiased and the variance appropriately bounded for the influence of the noise not to persist within the iterations.

10.2 Monte Carlo Policy Evaluation: What Are the Strengths and Limitations?

Answer. Generate \(M\) trajectories of length \(T\) that are negligible for \(\gamma^T\).   • Limit: Large variance. Since \(c\) can only be calculated after the trajectory ends, it is model-free but not online.

10.3 How does TD(0) come out?

Answer. Replace the expected value of the policy evaluation equation \(v^\pi(s_t)=\mathbb{E}\big[r(s_t,\pi(s_t))+\gamma v^\pi(s_{t+1})\big]\) with the next observed state (Robbins–Monro). \[v(s_t)\leftarrow(1-\alpha_t)\,v(s_t)+\alpha_t\big(r_t+\gamma v(s_{t+1})\big)=v(s_t)+\alpha_t\underbrace{\big(r_t+\gamma v(s_{t+1})-v(s_t)\big)}_{d_t\ (\text{temporal difference})}.\]

TipSignificance

  • It is completely incremental. Since only one visited state is updated, a lookup table is required, and the entire learning process is slow.
  • Lightest. Only one transition sample \((s_t,a_t,r_t,s_{t+1})\) is needed.

  • In episode types with a termination state, set the subsequent term to 0: target value \(r_t+\gamma(1-\text{done})\,v(s_{t+1})\).

11.1 Q-learning is a model-free, off-policy algorithm that converges to \(Q^*\) under conditions.

  • Limit 2, Scalability: Since updates are performed one step at a time, learning becomes very slow even with a slight increase in the number of state-behavior pairs. Function approximation is required.

11.2 Why is \(T_Q\) monotonous and contracted?

Proposition. \((T_QQ)(s,a)=r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\max_{a'}Q(s',a')\) is monotonic and for \(\|\cdot\|_\infty\)Z, \(\gamma\)-contraction.

11.3 How to transition from model-based Q-VI to Q-learning update expressions

Answer. If the model is known, the Q-VI is \(Q_{k+1}=T_QQ_k\), and in each iteration, update all \((s,a)\) and write \(p\). If the model is not known, replace \(T_Q\)’s \(\sum_{s'}p\max Q\) with the observed \(s_{t+1}\) (Robbins–Monro). \[Q(s_t,a_t)\leftarrow(1-\alpha)\,Q(s_t,a_t)+\alpha\Big[r_t+\gamma\max_{a'}Q(s_{t+1},a')\Big].\]

TipSignificance
  • All that is needed is one transition sample \((s_t,a_t,r_t,s_{t+1})\), so it is online.
  • It is completely incremental because it updates only one cell at a time.
  • All the ideas: \(1-\alpha\) on the old estimate, and \(\alpha\) on the single-sample estimate on the Bellman right-hand side.

11.4 What is the procedure for calculating Q-learning by hand?

Answer. For each transition, follow the next order.

  1. Calculate the target value \(y=r+\gamma\max_{a'}Q(s',a')\) using the current table. If not yet terminated, the max term is 0.
  2. Update \(Q(s,a)\leftarrow Q(s,a)+\alpha\,(y-Q(s,a))\). Leave the other cells as they are.
  3. Rewrite the entire table. The next transition uses this updated table.
TipSignificance and Pitfalls
  • Within the same transition, the target value is calculated using the table prior to the update.
  • When directly solving \(Q^*\) in a deterministic environment, solve the Bellman equations \(Q^*(s,a)=r(s,a)+\gamma\max_{a'}Q^*(s',a')\) as a system. Solve by assuming that a certain action is optimal, and verify whether that assumption holds.

11.6 Why is Q-learning off-policy?

Answer. The target value \(\max_{a'}\) determines the learning target (greedy policy). On the other hand, the actual action taken when creating the sample can be selected using a random policy. Since the policy to be learned and the policy for creating the action can be different, it is off-policy.

TipSignificance

It has high flexibility. Updates are valid even when reusing already collected samples (experience replay).

11.7 How Should Actions Be Chosen: The Problem of Greed and Exploration

Answer. If Q is nearly optimal, the greedy policy is optimal. However, Q is inaccurate during the early stages of learning. If only greedy is used at this point, some \((s,a)\) states will not be visited at all. Even if all states are visited, some beneficial actions may never be attempted. This breaks the assumption of “infinite visits to every pair,” and convergence to the optimal Q is not guaranteed. Therefore, we search by sacrificing some of the immediate greedy gain.

TipSignificance: Search method
  • ε-greedy: Greedy behavior with probability \(1-\epsilon\), random behavior with probability \(\epsilon\). It is the most widely used because it is simple and easy to schedule. It is not used because it is efficient.
  • Segment Switching: Alternates between a search segment (random) and a greedy segment.
  • Boltzmann: \(\Pr(a\mid s)=\frac{\exp(Q(s,a)/T)}{\sum_{a'}\exp(Q(s,a')/T)}\), \(T>0\) are temperatures. If \(T\to0\), it is greedy; if \(T\to\infty\), it is uniform.
  • ε Schedule: Starts with a large ε and reduces it. Since there is no information at the beginning, it focuses on exploration to improve the quality of value.
  • The root of the exploration–exploitation trade-off is a lack of knowledge regarding system dynamics and compensation structures.
