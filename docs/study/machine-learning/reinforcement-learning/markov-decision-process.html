1 Model and Policy: Fix before proof

1.1 Common Assumptions and Notation

The theorem in this article assumes a finite set of states \(S\), a non-empty finite set of actions \(A_s\), complete state observations, and expected cumulative reward maximization. All action sums and maximums are taken for \(a\in A_s\). Rewards are real and bounded.

Symbol Meaning
\(s_t,a_t\) State of time \(t\) and selected action
\(p_t(s'\mid s,a)\) Distribution of the next state; non-negative and \(\sum_{s'}p_t(s'\mid s,a)=1\)
\(r_t(s,a)\) Rewards for this period or their conditional average
\(h_t=(s_0,a_0,\ldots,s_t)\) History to date
\(\pi_t(a\mid h_t)\) Probability of action selection in general policy
\(\mu_0\) Initial state distribution
\(\mathbb P^\pi,\mathbb E^\pi\) Policy-induced path distribution and its expected value
\(P^\pi,R^\pi\) Transition matrix and reward vector averaged by normal Markov policy
\(\|v\|_\infty=\max_s|v(s)|\) Maximum absolute value norm; \(v\le w\) is a component inequality

The Markov nature of the model is the following condition.

\[ \mathbb P^\pi(s_{t+1}=s'\mid h_t,a_t=a) =p_t(s'\mid s_t,a). \]

In other words, if you know the current state and behavior, older records are not needed to predict the next state. Whether policies use the past is a separate issue.

If \(\rho_t(s,a,s')\) the reward also depends on the next state, then based on the expected total reward

\[ r_t(s,a)=\sum_{s'}p_t(s'\mid s,a)\rho_t(s,a,s') \]

can be written by averaging it as |||. \(\rho_t(s,a,s')\) is the reward for this period, and \(v_{t+1}(s')\), which appears later, is the total reward from the next point in time.

1.2 Distinction between decision rules and policies

Decision rules are guidelines to use at a given point in time, and a policy is a sequence of those rules. Deterministic rules specify a single action, while probabilistic rules specify the distribution of actions.

Class Input Output
MD Current Status \(s_t\) \(d_t(s_t)\in A_{s_t}\)
MR Current Status \(s_t\) \(\pi_t(\cdot\mid s_t)\)
HD History \(h_t\) \(d_t(h_t)\in A_{s_t}\)
HR History \(h_t\) \(\pi_t(\cdot\mid h_t)\)

Deterministic choice is a probabilistic choice in which an action is assigned a probability of 1. Therefore, MD is included in MR and HD respectively, and MR and HD are included in HR. There is no general inclusion relationship between MR and HD.

A stationary Markov policy uses the same rule \(\pi(a\mid s)\) at every point in time. A stationary deterministic policy can also choose a different action if the state changes.

WarningMarkov policy and normal policy are different

\(\pi_t(a\mid s)\) uses only the current state, so it is a Markov policy, but it can vary depending on the time point. In a finite horizon, even for the same state, the optimal action can differ depending on the remaining time. Stationarity does not automatically follow.

The pre-fixed sequence of actions \((a_0,a_1,\ldots)\) is a special policy that does not react to observed states. Therefore, in settings using a common set of actions, the value of policy optimization is not smaller than the value of fixed sequence of actions optimization. Choosing only the current highest reward is also generally not optimal, because actions change the distribution of the next state.

The reason for optimizing the policy. The reward is the immediate gain of the current choice, not the correct label itself, which is the optimal action. Therefore, it cannot be directly transformed into a supervised learning problem that maximizes only the immediate reward. Once a policy is derived, the action to be taken in a given state is specified, even if a state different from the expectation occurs.

The difficulty of policy optimization lies in the fact that the actions determined for each state influence each other through future transitions. Even in finite models with a common set of actions, there are \(|A|^{|S|}\) policies that are not ZZZ deterministic. Dynamic programming (DP) solves this problem using value functions. It does not generalize to mean that “policies are functions and therefore cannot be differentiated under any circumstances.”

2 The stochastic process created by the policy

2.1 Path probability and Markovity

The probability of the finite path \((s_0,a_0,\ldots,a_{N-1},s_N)\) is the chain rule

\[ \mathbb P^\pi(s_0,a_0,\ldots,s_N) =\mu_0(s_0)\prod_{t=0}^{N-1} \pi_t(a_t\mid h_t)p_t(s_{t+1}\mid s_t,a_t). \]

This formula is the probability of a finite path. We apply this formula to each finite-length path event even over an infinite horizon. We do not inadvertently equate the infinite product with the probability of an individual infinite path.

Proposition. If a Markov policy is used, the sequence of states is a Markov process.

Proof. If you sum the actions

\[ \mathbb P^\pi(s_{t+1}=s'\mid h_t) =\sum_a\pi_t(a\mid s_t)p_t(s'\mid s_t,a). \]

The right-hand side depends only on \(t,s_t\), not the entire past. Since the equation remains the same even if only the past of the state is given as a condition, the state column is Markov. If both the model and the policy are time-invariant, the transition matrix is also time-independent. \(\square\)

Intuition: If the environment moves based only on the current state and behavior, and policies also act based only on the current state, the past cannot provide additional information for the future.

WarningWhen the denominator of the conditional probability is 0

When calculating conditional probability as a ratio of probabilities, the probability of the conditional event must be positive. If the entire conditional distribution is set to zero because the denominator is zero, it does not become a probability distribution. To define the value of an unvisited state, define it as a new problem starting from that state. It is not necessary to visit that state in the original initial distribution.

Since history-dependent policies can alter the distribution of behavior based on the past, the Markovity of the state sequence cannot be concluded solely from the Markovity of the model. However, this does not mean that all history policies necessarily produce non-Markov state sequences.

3 One-period MDP: The starting point of all proofs

Perform one action at time 0 and receive a terminal reward \(g(s_1)\) at time 1. Let’s define.

\[ w(s,a)=r_0(s,a)+\sum_{s'}p_0(s'\mid s,a)g(s'). \]

3.1 Summary: Deterministic choice is sufficient

The optimal value in state \(s\) is \(\max_aw(s,a)\), and selecting the one action that gives the maximum value is optimal.

Proof. For a random action distribution \(q\)

\[ \sum_aq(a)w(s,a) \le\sum_aq(a)\max_bw(s,b) =\max_bw(s,b). \]

In a finite and non-empty \(A_s\), there exists an action that achieves a maximum value. If that action is given a probability of 1, the upper bound is achieved. \(\square\)

Equality condition: All actions that are \(q(a)>0\) must yield the maximum value. Randomizing among the best actions is harmless, but it does not produce a better value either.

Proof Structure: First, find the upper bound for an arbitrary policy, and then construct a policy that achieves that upper bound. Subsequently, the proof of finite-infinite horizon optimality also follows this structure.

Adding the constant \(c\) to the total terminal reward increases all \(w(s,a)\) by \(c\). This is because the sum of the transition probabilities is 1. Therefore, the optimal action does not change. What is important for comparing actions is the difference in value between terminal states.

4 Finite Horizon MDP: Inverse Induction

4.1 Objective function and boundary conditions

The decision point is \(0,\ldots,N-1\), and at \(N\), no action is taken and only the terminal reward \(g(s_N)\) is received. This section deals with finite horizons without discounting.

\[ J_s(\pi)=\mathbb E_s^\pi\left[ \sum_{t=0}^{N-1}r_t(s_t,a_t)+g(s_N)\right]. \]

The remaining value of the Markov policy is

\[ v_t^\pi(s)=\mathbb E_{t,s}^\pi\left[ \sum_{k=t}^{N-1}r_k(s_k,a_k)+g(s_N)\right]. \]

Here, \(\mathbb E_{t,s}^\pi\) means that the state at time point \(t\) is set to \(s\), and the policy is applied thereafter. Policy evaluation is also calculated using a one-step decomposition.

\[ \begin{aligned} v_N^\pi(s)&=g(s),\\ v_t^\pi(s)&=\sum_a\pi_t(a\mid s) \left[r_t(s,a)+\sum_{s'}p_t(s'\mid s,a)v_{t+1}^\pi(s')\right]. \end{aligned} \]

4.2 Summary: Bellman Recursion and Optimal Policy

Define the candidate value \(V_t\) from the back as follows.

\[ \begin{aligned} V_N(s)&=g(s),\\ Q_t(s,a)&=r_t(s,a)+\sum_{s'}p_t(s'\mid s,a)V_{t+1}(s'),\\ V_t(s)&=\max_a Q_t(s,a),\\ d_t^*(s)&\in\arg\max_a Q_t(s,a). \end{aligned} \]

Then \(\pi^*=(d_0^*,\ldots,d_{N-1}^*)\) is optimal even when compared to all HR policies. Each \(V_t(s)\) is the optimal remaining value possible at that point in time and state.

4.2.1 Proof: Inductively derives the upper bound and attainment together

1. Basic Phase \(t=N\). Since there are no more actions, the remaining reward for any policy is \(g(s_N)=V_N(s_N)\).

2. Induction to the Upper Bound. Fix an arbitrary HR policy and use \(U_t^\pi(h_t)\) as the expected remaining reward after history \(h_t\). From \(t+1\)

\[ U_{t+1}^\pi(h_t,a,s')\le V_{t+1}(s') \]

Let’s assume . Using iterative expectation and the Markov nature of the model

\[ \begin{aligned} U_t^\pi(h_t) &=\sum_a\pi_t(a\mid h_t) \left[r_t(s_t,a)+\sum_{s'}p_t(s'\mid s_t,a) U_{t+1}^\pi(h_t,a,s')\right]\\ &\le\sum_a\pi_t(a\mid h_t)Q_t(s_t,a)\\ &\le\max_aQ_t(s_t,a)=V_t(s_t). \end{aligned} \]

The first inequality is the assumption of induction and non-negative probability, and the second inequality is mean ≤ maximum. In a history where the reach probability is 0, the same recursion can be used by defining \(U_t^\pi\) with a specified follow-up policy and transition instead of the ratio of conditional probabilities.

3. Induction on Achieving the Upper Limit. Let us assume that if \(d_{t+1}^*,\ldots,d_{N-1}^*\) is used after time \(t+1\), \(V_{t+1}\) is achieved. If \(d_t^*(s)\) is chosen at time \(t\),

\[ v_t^{\pi^*}(s) =r_t(s,d_t^*(s))+ \sum_{s'}p_t(s'\mid s,d_t^*(s))V_{t+1}(s') =V_t(s). \]

Therefore, the same policy \(\pi^*\) achieves the upper bound for all points in time and states. \(\square\)

TipThe core of the proof

“Starting from the terminal condition, we constrain the residual value of any history-dependent policy to \(V_t(s_t)\) above. Since the state-specific argmax rule inductively achieves its upper bound, a deterministic Markov policy is sufficient.”

Intuition: Solve the last problem and use the answer as the terminal value from the immediately previous time step. Even if the past is different, if the current state and remaining time are the same, the optimal strategy to be used going forward can be shared.

4.3 Verification using two-state example

Let’s apply finite horizon and end compensation 0 to the following two state models.

The terminal reward is 0. If \(W_k(s)\) is used as the optimal value when \(k\) decisions remain, it is \(W_0=0\) and \(W_k(s_2)=-k\).

Even within the same \(s_1\), the optimal action changes depending on the number of remaining decisions. However, this does not mean that a finite horizon optimal policy is always abnormal. There are special problems where a normal policy is also optimal.

5 Discount Infinite Horizons: Policy Evaluation

From now on, the model \(p,r\) is time-invariant and \(0<\gamma<1\). The policy evaluation formula \(\pi\) is a normal Markov policy.

5.1 Definition of Return and Value

\[ G_t=\sum_{k=0}^{\infty}\gamma^k r(s_{t+k},a_{t+k}), \qquad v^\pi(s)=\mathbb E_s^\pi[G_0], \qquad J(\pi)=\sum_s\mu_0(s)v^\pi(s). \]

\(|r(s,a)|\le R_{\max}\) so

\[ |G_t|\le\frac{R_{\max}}{1-\gamma}. \]

Therefore, the return converges absolutely and is integrable. The exchange of the expectation value and the infinite sum can also be justified by this upper bound. In the time-invariant model and stationary policy, since the future distribution observed from the same state is independent of the starting time, the \(v^\pi\) \(t\) subscript is not needed.

5.2 Monte Carlo Policy Evaluation

Fix the policy and create multiple trajectories from the same starting state, then calculate the average of each cumulative reward.

If you can observe an independent full return \(G^{(1)},\ldots,G^{(m)}\) starting from the same state

\[ \hat v_m=\frac1m\sum_{i=1}^mG^{(i)},\qquad \mathbb E[\hat v_m]=v^\pi(s),\qquad \operatorname{Var}(\hat v_m)=\frac{\operatorname{Var}(G)}m. \]

Linearity of the expected value is used for unbiasedness, and sample independence is used for the variance formula. If the infinite horizon is cut at the \(T\) step and replaced with \(G_T=\sum_{t=0}^{T-1}\gamma^tr_t\), the sample mean is unbiased at \(\mathbb E[G_T]\), but is generally biased at \(v^\pi\).

\[ |\mathbb E[G_T]-v^\pi(s)| \le\frac{\gamma^T R_{\max}}{1-\gamma}. \]

Averaging many trajectories and observing each trajectory for a long time reduce other errors. There is no theorem that MC variance is always large. However, large variance can occur due to the randomness of long trajectories.

5.3 Summary: Bellman Policy Evaluation Equation

\[ v^\pi(s)=\sum_a\pi(a\mid s) \left[r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)v^\pi(s')\right]. \]

Proof Flow.

  1. Decomposes the return into \(G_t=r(s_t,a_t)+\gamma G_{t+1}\).
  2. Apply iterative expectation to \(a_t,s_{t+1}\).
  3. Using a Markov model and Markov policy, remove previous states and actions from future conditions.
  4. Due to the time invariance of the model and policy, the remaining value at the next time step is written as \(v^\pi(s_{t+1})\).

If you connect this as an expression

\[ \begin{aligned} v^\pi(s) &=\mathbb E^\pi[r(s_t,a_t)+\gamma G_{t+1}\mid s_t=s]\\ &=\sum_a\pi(a\mid s)\sum_{s'}p(s'\mid s,a) \left[r(s,a)+\gamma v^\pi(s')\right]. \end{aligned} \]

If you use \(\sum_{s'}p(s'\mid s,a)=1\) in the compensation term, it is the desired expression. \(\square\)

Note: The past is not erased solely by iteration expectation. To remove the past, Markovity of the model and policy is required, and to erase time indices, stationarity is also required.

5.4 Matrix Representation and the Existence of Inverse Matrices

\[ R^\pi(s)=\sum_a\pi(a\mid s)r(s,a),\qquad P^\pi(s,s')=\sum_a\pi(a\mid s)p(s'\mid s,a). \]

Then it is \(v^\pi=R^\pi+\gamma P^\pi v^\pi\). Since \(P^\pi\) is a non-negative matrix where the sum of each row is 1, it is \(\|P^\pi u\|_\infty\le\|u\|_\infty\). Therefore, the matrix series converges and

\[ (I-\gamma P^\pi)^{-1}=\sum_{k=0}^{\infty}\gamma^k(P^\pi)^k, \qquad v^\pi=(I-\gamma P^\pi)^{-1}R^\pi. \]

The inverse matrix expression is not a simple formal transposition. Multiplying the partial sum of the series by \(I-\gamma P^\pi\) results in \(I-\gamma^{m+1}(P^\pi)^{m+1}\), and since the last term goes to 0, it is confirmed to be the inverse matrix.

Example Verification: If \(\gamma=0.9\) is applied to the previous two state models, it is \(v^\pi(s_2)=-10\) in all policies. If \(s_1\) is always used with \(a_{11}\)

\[ v^\pi(s_1)=5+0.9\left[\tfrac12v^\pi(s_1)-5\right] \quad\Longrightarrow\quad v^\pi(s_1)=\frac{10}{11}. \]

If you always use \(a_{12}\), it is \(v^\pi(s_1)=10+0.9(-10)=1\).

6 Bellman Operator and Proof Tool

For any value candidate \(v\)

\[ \begin{aligned} q_v(s,a)&=r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)v(s'),\\ (\mathcal T^\pi v)(s)&=\sum_a\pi(a\mid s)q_v(s,a),\\ (\mathcal T v)(s)&=\max_a q_v(s,a). \end{aligned} \]

\(\mathcal T^\pi\) takes the average as the policy, and \(\mathcal T\) takes the maximum among the actions. The former is generally an affine mapping, and is not called a linear mapping because of the reward term.

6.1 Monotonicity · Constant Shift · Greed Policy

Properties Formula Reason
Monotonicity \(v\le w\Rightarrow\mathcal T v\le\mathcal T w\) Non-negative probability; max preserves order
Constant shift \(\mathcal T(v+c\mathbf1)=\mathcal T v+\gamma c\mathbf1\) Sum of transition probabilities 1
Upper bound of mean \(\mathcal T^\pi v\le\mathcal T v\) Mean ≤ Maximum
Greedy Policy \(d_v(s)\in\arg\max_aq_v(s,a)\Rightarrow\mathcal T^{d_v}v=\mathcal T v\) Directly select maximum action

Monotonicity and constant shift hold for \(\mathcal T^\pi\) as well. The last equation holds for \(v\) used to select the policy, but is not guaranteed for any other \(w\).

6.2 Summary: The two operators are \(\gamma\)-contraction

Policy evaluation operator. If you cancel out the reward term and limit the weighted average of the probabilities

\[ \|\mathcal T^\pi v-\mathcal T^\pi w\|_\infty =\|\gamma P^\pi(v-w)\|_\infty \le\gamma\|v-w\|_\infty. \]

Optimal operator. First, for two finite sequences

\[ |\max_ax_a-\max_ay_a|\le\max_a|x_a-y_a| \]

Verify that . If we select \(a_x\in\arg\max_ax_a\), it becomes \(\max x-\max y\le x_{a_x}-y_{a_x}\le\max|x-y|\), and by swapping \(x,y\), we also obtain the opposite direction. Therefore

\[ \begin{aligned} |\mathcal T v(s)-\mathcal T w(s)| &\le\max_a\left|\gamma\sum_{s'}p(s'\mid s,a)(v(s')-w(s'))\right|\\ &\le\gamma\|v-w\|_\infty. \end{aligned} \]

Taking the maximum value for the state yields contractility. \(\square\)

6.3 Banach Fixed Point Theorem: Necessary Parts and Proof

In a complete metric space, if \(T\) is a contraction with coefficient \(\gamma<1\), then a unique fixed point exists, and \(x_{k+1}=Tx_k\) converges from any starting point to that fixed point.

Existence: Since \(d(x_{k+1},x_k)\le\gamma^k d(x_1,x_0)\), when \(m>n\)

\[ d(x_m,x_n)\le\sum_{k=n}^{m-1}\gamma^k d(x_1,x_0) \le\frac{\gamma^n}{1-\gamma}d(x_1,x_0)\longrightarrow0. \]

It is \(x_k\to x^*\) due to completeness, and \(Tx^*=x^*\) due to the continuity of contraction events.

Uniqueness: If there are two fixed points \(x^*,y^*\), then \(d(x^*,y^*)\le\gamma d(x^*,y^*)\), so the two are equal.

Error: If contractility is repeated \(d(x_k,x^*)\le\gamma^k d(x_0,x^*)\). \(\square\)

Here, since \((\mathbb R^{|S|},\|\cdot\|_\infty)\) is complete, it can be applied. Therefore, \(\mathcal T^\pi\) and \(\mathcal T\) each have a unique fixed point. By the policy evaluation formula, the fixed point of the former is \(v^\pi\). The fact that the latter fixed point is the optimal value still needs to be proven.

7 Bellman Optimality and Optimal Policy

Intuition: The optimal value \(v^*(s)\) is the best performance achievable in the current state. The Bellman formula compares the “current reward + the discounted optimal value of the next state.” Optimization for the entire policy is represented by the maximization of the current action, but the computational burden of having to perform this maximization in all states remains.

7.1 Summary: The fixed point is the optimal value

For all HR policies, the value starting from the state at time point 0 \(s\) is defined as \(v^\pi(s)\), and

\[ v^*(s)=\sup_{\pi\in\Pi^{HR}}v^\pi(s) \]

Let . Then \(v^*\) is the only fixed point of \(\mathcal T\), and a single deterministic steady-state Markov policy achieves this in all states. Therefore, the above \(\sup\) can be written as \(\max\).

7.1.1 Proof Step 1: Achievable Candidate Configurations

Let \(\hat v\) be the fixed point obtained through contractility. In each state

\[ d^*(s)\in\arg\max_a q_{\hat v}(s,a) \]

If you select , it becomes \(\mathcal T^{d^*}\hat v=\mathcal T\hat v=\hat v\). Since the fixed point of the policy evaluation operator is unique,

\[ \hat v=v^{d^*}. \]

In other words, the candidate can be achieved through actual policies.

7.1.2 Proof Step 2: Upper bound for an arbitrary policy

Since \(\hat v=\mathcal T\hat v\), for all \((s,a)\)

\[ r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\hat v(s')\le\hat v(s). \]

Averaging behaviors with an arbitrary HR policy and applying iterative expectations

\[ \mathbb E^\pi[r(s_t,a_t)+\gamma\hat v(s_{t+1})\mid h_t] \le\hat v(s_t). \]

Multiplying both sides by \(\gamma^t\) and taking the expected value, then adding it for \(t=0,\ldots,n-1\), the intermediate value terms are canceled out.

\[ \mathbb E_s^\pi\left[ \sum_{t=0}^{n-1}\gamma^t r(s_t,a_t)+\gamma^n\hat v(s_n) \right]\le\hat v(s). \]

In finite state space, \(\hat v\) is bounded, so \(|\gamma^n\mathbb E_s^\pi[\hat v(s_n)]|\le\gamma^n\|\hat v\|_\infty\to0\). Since the complementary series can also pass the limit through the bounded supreme bound, it is \(v^\pi(s)\le\hat v(s)\).

7.1.3 Proof Step 3: Conclusion

For all policies, it is \(v^\pi\le\hat v\), and \(d^*\) achieves \(\hat v\). Therefore, it is \(v^*=\hat v=v^{d^*}\) and

\[ v^*(s)=\max_a\left[r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)v^*(s')\right]. \]

The same \(d^*\) is optimal in all states. \(\square\)

WarningOrder to avoid circular reasoning

When proving that “the optimal value is a Bellman fixed point,” do not write it as if it were already a definition. Write it in the order of existence of a candidate due to contractility → Greedy policy achieves the candidate → Upper bound of all policies → Candidate is the optimal value. Do not conclude the optimality of all HR policies based on a proof that compares only normal policies.

7.2 Exact conditions of stochastic optimal policy

Let \(q^*(s,a)=q_{v^*}(s,a)\), \(A^*(s)=\arg\max_aq^*(s,a)\). The necessary and sufficient condition for the normal Markov policy \(\pi\) to be optimal in all states is

\[ \pi(a\mid s)>0\quad\Longrightarrow\quad a\in A^*(s). \]

Sufficientity: Since we average only the maximum actions \(\mathcal T^\pi v^*=v^*\). Due to fixed-point uniqueness \(v^\pi=v^*\).

Necessity: If \(v^\pi=v^*\), then \(\mathcal T^\pi v^*=v^*\). Therefore, in each state

\[ 0=v^*(s)-\sum_a\pi(a\mid s)q^*(s,a) =\sum_a\pi(a\mid s)\big[v^*(s)-q^*(s,a)\big]. \]

Since all terms are non-negative, the difference between actions with positive probabilities must be 0. \(\square\)

Deterministic policies are also included in the probabilistic policy class. The absence of ties does not mean that there are no optimal policies within the probabilistic policy class, but rather that non-degenerate randomization is impossible. Furthermore, the above condition applies to optimality in all states. When maximizing only \(J(\pi)\) of a specific initial distribution, the selection of unreached states does not need to be optimal.

7.3 Fixed point repetition

\[ v_{k+1}=\mathcal T v_k \quad\Longrightarrow\quad \|v_k-v^*\|_\infty\le\gamma^k\|v_0-v^*\|_\infty. \]

That is, the fixed-point iteration converges to the optimal value. In policy evaluation, \(\mathcal T\) is iterated over instead of \(\mathcal T^\pi\).

8 Commonly Mistaken Assumptions

9.4 Problem 4. Bellman Policy Evaluation Formula

Derive the Bellman evaluation formula for a stationary Markov policy from the return definition of . Indicate separately where iterative expectation, Markovity, and stationarity are used. Also, explain why \(I-\gamma P^\pi\) is invertible.

TipHint

Start from \(G_t=r_t+\gamma G_{t+1}\). Distinguish between past elimination and time index elimination. The inverse matrix can be verified as the product of a convergent matrix series and partial sums.

NoteSOLUTION

Assuming a time-invariant model and a steady-state Markov policy \(\pi\), \(0<\gamma<1\), \(|r|\le R_{\max}\). The return is \(R_{\max}/(1-\gamma)\), which is integrable with the absolute value restricted.

Return Decomposition and Iteration Expected Value: Since \(G_t=r(s_t,a_t)+\gamma G_{t+1}\)

\[ v^\pi(s)=\sum_a\pi(a\mid s)\sum_{s'}p(s'\mid s,a) \left[r(s,a)+\gamma\mathbb E^\pi[G_{t+1}\mid s_t=s,a_t=a,s_{t+1}=s']\right]. \]

Markovity: Since both the model and the policy are Markov, \(s_t,a_t\) is not needed when predicting the future after \(s_{t+1}\). Stationality: Since the model and the policy are time-invariant, the expected return viewed from the state \(s'\) at time point \(t+1\) is the same function \(v^\pi(s')\). Therefore,

\[ v^\pi(s)=\sum_a\pi(a\mid s)\left[r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)v^\pi(s')\right]. \]

When the probability of the conditional event is 0, the above equation is interpreted as a new process starting from that state. In matrix notation, it is \(v^\pi=R^\pi+\gamma P^\pi v^\pi\).

Existence of Inverse: Since \(P^\pi\) is a row probability matrix, at the derived maximum norm, \(\|(P^\pi)^k\|_\infty=1\). Accordingly, \(S_m=\sum_{k=0}^m\gamma^k(P^\pi)^k\) converges to some matrix \(S\). Multiplying from both sides

\[ (I-\gamma P^\pi)S_m=S_m(I-\gamma P^\pi) =I-\gamma^{m+1}(P^\pi)^{m+1}\longrightarrow I. \]

Therefore, \(S=(I-\gamma P^\pi)^{-1}\) and \(v^\pi=(I-\gamma P^\pi)^{-1}R^\pi\). This confirms not only the transposition of the terms but also the existence of the inverse matrix. \(\square\)

9.5 Problem 5. Contractility of Optimal Operators and Fixed Points

Prove starting from \(|\max x-\max y|\le\max|x-y|\), then show the contractility of \(\mathcal T\). Write down the completeness of the application space, and prove the fixed point uniqueness and the error boundary of the iteration.

TipHint

Compare the difference of maximum values in the same operation, but obtain both-way inequalities. Let \(D\) be the distance between two fixed points, then \(D\le\gamma D\). If existence is also required, the Cauchy property and completeness of iteration sequences must be used.

NoteSOLUTION

1. max inequality. If you choose \(a_x\in\arg\max_ax_a\)

\[ \max_ax_a-\max_ay_a\le x_{a_x}-y_{a_x}\le\max_a|x_a-y_a|. \]

By changing \(x,y\) to obtain the opposite direction, it is \(|\max x-\max y|\le\max|x-y|\).

2. Contractility of the Bellman Operator. Due to the above inequality, the non-negative nature of transition probabilities, and the fact that the sum is 1

\[ \begin{aligned} |\mathcal T v(s)-\mathcal T w(s)| &\le\max_a\left|\gamma\sum_{s'}p(s'\mid s,a)[v(s')-w(s')]\right|\\ &\le\gamma\|v-w\|_\infty. \end{aligned} \]

Taking the maximum value for each state gives \(\|\mathcal T v-\mathcal T w\|_\infty\le\gamma\|v-w\|_\infty\). The application space is a finite-dimensional normed space \((\mathbb R^{|S|},\|\cdot\|_\infty)\) and is complete.

3. Fixed point exists. If we set it to \(v_{k+1}=\mathcal T v_k\), then it becomes \(\|v_{k+1}-v_k\|_\infty\le\gamma^k\|v_1-v_0\|_\infty\). Therefore, for \(m>n\)

\[ \|v_m-v_n\|_\infty\le\frac{\gamma^n}{1-\gamma}\|v_1-v_0\|_\infty\longrightarrow0. \]

It is \(v_k\to\hat v\) with completeness, and \(\mathcal T\hat v=\hat v\) with continuity of contraction events.

4. Uniqueness and Error. If there is another fixed point \(w\), then \(\|w-\hat v\|_\infty\le\gamma\|w-\hat v\|_\infty\). Since \(\gamma<1\), it is \(w=\hat v\). Also

\[ \|v_k-\hat v\|_\infty\le\gamma^k\|v_0-\hat v\|_\infty. \]

Up to this point are the results for the fixed point. That this fixed point is the optimal value is verified by comparing it with the policy in the next problem. \(\square\)

9.6 Problem 6. From Fixed Point to Optimal Policy

TipHint

NoteSOLUTION

Assumes a finite set of states and actions, bounded rewards, a time-invariant model, and \(0<\gamma<1\).

1. Achievement of the Greed Policy. Definition of \(d\) and from \(\hat v=\mathcal T\hat v\)

\[ \mathcal T^d\hat v=\mathcal T\hat v=\hat v. \]

\[ r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\hat v(s')\le\hat v(s) \]

Gives . Averaging behavior with an arbitrary HR policy \(\pi\)

\[ \mathbb E^\pi[r(s_t,a_t)+\gamma\hat v(s_{t+1})\mid h_t]\le\hat v(s_t). \]

is.
