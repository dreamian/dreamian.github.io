1 Big picture

NoteOne-sentence summary

The finite interval MDP is a difficult problem that requires optimizing \(T\) functions (decision rules) simultaneously, but since the terminal condition \(v_T = r_T\) is known, the optimal value and optimal policy can be accurately obtained by solving the Bellman equations one time step at a time from the back (backward induction).

The core flow is as follows.

  1. Problem Formula: \(\max_\pi \mathbb{E}^\pi\big[\sum_{t=0}^{T-1} r_t(s_t,a_t) + r_T(s_T)\big]\)
  2. Policy Evaluation: Define the value function \(v^\pi_t\) and decompose it into “Immediate Reward + Next State Value” → Backward Calculation
  3. Optimization: Proof that the optimal value function \(v^*_t\) is a solution to the Bellman equation (Optimality Principle)
  4. Policy Construction: Bellman Proving induction that the deterministic Markov policy constructed from the argmax on the right-hand side is optimal
  5. Algorithm: Calculate \(v^*_t\) and \(\pi^*_t\) simultaneously in a single loop using DP (backward induction).
  6. Extensions and Limitations: Continuous Control → \(\sup\)/Integral, Absence of argmax, Curse of Dimensionality → Connected to Approximation (Deep RL)

Philosophical Significance of the Bellman Equation: Optimal decision-making in the present is an action that balances the two by considering not only immediate gains but also long-term benefits to maximize their sum.

2 MDP Components Review

2.1 Sequential Decision Making and Uncertainty

  • Instead of performing an action once and finishing, decisions are made sequentially.
  • Since there is uncertainty in the system, instead of a method that predetermines the sequence of actions (open-loop), it is optimized in the form of a policy (state → action rule) so that the correct action can be taken even if an unexpected state is reached.
  • Immediate rewards measure only the gains of the current state or action and cannot measure long-term gains. Therefore, supervised learning cannot be applied directly, and it becomes a separate problem known as reinforcement learning.

2.2 Component

Element Notation Meaning
Status \(s_t \in S\) System status (location, speed, inventory, etc.)
Behavior \(a_t \in A\) Adjustable input (acceleration, order quantity, etc.)
Reward \(r_t(s,a)\) Immediate gain. Future gain not measured
Transition Probability \(p(s'\mid s,a) := \Pr(s_{t+1}=s'\mid s_t=s,a_t=a)\) Stochastic Dynamics. \(\sum_{s'}p(s'\mid s,a)=1\)
  • Reward design is important. In complex problems, reward tuning is as difficult as policy learning (reward engineering). Although LLMs can assist with reward design, manual tuning may still be necessary to precisely match desired system specifications.
  • In finite intervals, transition probabilities and rewards may depend on time (non-stationary). Therefore, a subscript \(t\) is attached, as in \(r_t\).

2.3 Decision Rules vs. Policy

  • Decision Rule \(\pi_t: S\to A\) — A mapping that sends a state to an action at a single point in time (snapshot)
  • Policy \(\pi = (\pi_0, \pi_1, \dots, \pi_{T-1})\) — A collection of decision rules from all points in time
  • Type: deterministic / stochastic(randomized), Markov / history-dependent
  • Stationary Policy: \(t\) has the same policy for all \(\pi_t\)
ImportantWhy distinguish decision rules and policies in finite intervals

This is because, in finite intervals, using different decision rules at each time step is actually optimal. On the other hand, in an infinite interval discounting MDP, using the same decision rule every time is optimal (stationary policy), so the two are not strictly distinguished and are simply referred to as “policies.”

2.3.1 Why is the same decision rule sufficient for infinite intervals?

This is because there is no clock. In an infinite interval, the remaining time is always infinite, so the problem in state \(s\) at time \(t\) and the problem in state \(s\) at time 0 are identical. The same problem yields the same answer.

\[ v^*_t(s) = \sup_\pi \mathbb{E}^\pi\Big[\sum_{\tau=t}^\infty \gamma^{\tau-t} r(s_\tau,a_\tau)\,\Big|\, s_t=s\Big] = v^*_0(s) =: v^*(s) \]

(when \(p, r, \gamma\) is time-invariant.) Therefore, both sides of the Bellman equation become the same function (fixed-point problem), and

\[ v^*(s) = \max_a\Big[r(s,a) + \gamma\sum_{s'}p(s'\mid s,a)v^*(s')\Big],\qquad \pi^*(s)\in\arg\max_a[\cdots] \]

Since \(t\) does not appear in argmax, the same \(\pi^*\) can be used at every time step. For the proof of optimality, since there is no terminal condition, uniqueness of fixed points of the contraction mapping is used instead of induction: \(T^{\pi^*}v^* = Tv^* = v^*\) and since the unique fixed point of \(T^{\pi^*}\) is \(v^{\pi^*}\), \(v^{\pi^*}=v^*\).

Example where policy changes at different times over a finite interval (Investment vs. Consumption)

  • State 1: Consume → Reward 1, Maintain State 1 / Invest → Reward 0, Move to State 2
  • State 2: Reward 5 per step (Absorption State), \(r_T\equiv 0\)
\(t\) \(v_t(1)\) \(v_t(2)\) Optimal action for state 1
\(T\) 0 0 –
\(T-1\) \(\max\{1+0,\,0+0\}=1\) 5 Consumption
\(T-2\) \(\max\{1+1,\,0+5\}=5\) 10 Investment
\(T-3\) \(\max\{1+5,\,0+10\}=10\) 15 Investment

Just before the deadline, consumption is optimal because there is no time to recover an investment. The remaining time \(T-t\) creates a time dependency on the decision rule. (This time dependency does not disappear even if a discount of \(r_t=\gamma^t r\) is applied. Since \(\gamma^t\) is multiplied commonly to all action candidates at time point \(t\), this factor itself does not change argmax, and the cause of the change in the decision rule is still the remaining time. Of course, since the value of \(\gamma\) changes the relative weight of future rewards, a different policy than in a problem without a discount may be optimal.)

3 Definition of Finite-Horizon MDP

NoteDefinition

The finite interval MDP is the tuple \(\langle T, S, A, p, r\rangle\). The newly appearing element is horizon length \(T\).

MDP Problem:

\[ \max_{\pi\in\Pi}\ \mathbb{E}^\pi\Big[\sum_{t=0}^{T-1} r_t(s_t,a_t) + r_T(s_T)\Big] \]

3.1 Difference from infinite interval

  • Time does not flow infinitely and stops at \(T\).
  • Reward and transition probabilities can depend on time.

3.2 Why is terminal compensation \(r_T(s_T)\) instead of \(r_T(s_T,a_T)\)?

The action to be taken at time \(T\) is not of interest. If \(s_0\) is taken, \(a_0\) becomes \(s_1\), and by repeating this, if \(s_{T-1}\) is taken, \(a_{T-1}\) reaches \(s_T\). If an action is taken at \(T\), \(s_{T+1}\) becomes \(s_T\), but interest is limited to exactly \(s_T\). Therefore, the last term does not consider the effect of the action. This is the first characteristic of a finite horizon.

3.3 Number of entries: \(T\) vs \(T+1\)

The terms of the objective function are \(T+1\): stage reward \(T\) (\(t=0,\dots,T-1\), action present) + terminal reward 1 (\(t=T\), action absent).

You can remember it as a fence post structure.

  • State \(s_0, s_1, \dots, s_T\) → Point → \(T+1\) Items
  • Action \(a_0, \dots, a_{T-1}\) → Interval between states (transition) → \(T\) items
  • Policy \(\pi=(\pi_0,\dots,\pi_{T-1})\) → \(T\) decision rules
  • e.g.: If \(T=3\), then \(r_0(s_0,a_0)+r_1(s_1,a_1)+r_2(s_2,a_2)+r_3(s_3)\)

3.4 Why is it difficult to solve (Difficult to solve — Why?)

The optimization target is not a number, but \(T\) functions, and the number of candidates explodes combinatorially.

When \(|S|=n\), \(|A|=m\), even if only deterministic Markov policies are counted

\[ |\Pi_{\text{det-Markov}}| = (m^n)^T = m^{nT} \]

Policy Enumeration \(m^{nT}\) Number of \(Q\) values of DP \(T\cdot n\cdot m\)
\(n=m=2,\ T=3\) 64 12
\(n=10,\ m=5,\ T=10\) \(\approx 8\times10^{69}\) 500

Also, \(\pi_0,\dots,\pi_{T-1}\) is coupled. Changing \(\pi_0\) alters the distribution of \(s_1\), which changes the importance of \(\pi_1\) in each state. Therefore, they cannot be optimized separately for each term.

DP breaks this combination from the back: Since \(v^*_{t+1}\) serves as summary information indicating that “the rest has already been handled best,” at time step \(t\), only one action needs to be chosen. This is possible because (i) the reward is the sum of terms per time step, and (ii) due to Markov properties. (The actual computational complexity of DP, including the sum of the next state, is \(\mathcal{O}(Tn^2m)\).)

TipBlock Check (Expand to check answer)

Q1. How is this different from the infinite interval problem?

A. Time stops at \(T\), and reward/transition probabilities can depend on time.

Q2. Why is the last term \(r_T(s_T)\) instead of \(r_T(s_T,a_T)\)?

A. The action at time point \(T\) only affects \(s_{T+1}\), because interest extends exactly up to \(s_T\).

Q3. Why is this problem difficult to solve?

A. This is because the optimization targets are \(T\) functions \((\pi_0,\dots,\pi_{T-1})\), and since they are coupled to each other through state distributions, they cannot be optimized separately.

4 Example: Stochastic Inventory Control

This is a finite-horizon MDP widely used in logistics and industrial engineering.

Element Meaning
\(s_t\) Inventory quantity of \(t\) at time
\(a_t\) Order quantity of \(t\) at time
\(D_t\) Probabilistic demand at time \(t\), \(p_j := \Pr(D_t=j)\) (assuming estimated from past data)

System Equation (Excess demand is lost):

\[ s_{t+1} = \max\{s_t + a_t - D_t,\ 0\} \]

Since \(D_t\) is a random variable, it is a probabilistic system injected with randomness.

4.1 State·Behavior·Reward

  • \(S = \{0,1,\dots,M\}\) (\(M\): Storage capacity)
  • \(A_s = \{0,1,\dots,M-s\}\) — The set of actions depends on the state. If ordered further, there is no place to store it. Thanks to this constraint, \(s+a\le M\) is guaranteed.
  • \(r_t(s,a) = \underbrace{F(s+a)}_{\text{수익}} - \underbrace{O(a)}_{\text{주문비}} - \underbrace{h(s+a)}_{\text{보관비}}\) — Rewards can be set in various ways and are not the core of this example.
TipReference

It is natural for actual profit to be proportional to the sales volume \(\min\{s+a, D\}\), and thus \(D\) comes into the reward. At this point, if \(\mathbb{E}_D[\text{수익}]\) is calculated in advance and inserted into \(F\), the MDP form is maintained where \(r_t\) is a function unique to \((s,a)\).

4.2 Three cases of transition probability

Case \(p(s'\mid s,a)\) Reason
\(s+a < s' \le M\) \(0\) The next stock cannot be greater than the current stock after an order (impossible)
\(0 < s' \le s+a\) \(p_{s+a-s'}\) The left term of \(\max\) is activated → exactly one is determined as \(D = s+a-s'\)
The right-hand side (0) of \(s' = 0\) \(\sum_{j\ge s+a} p_j\)

The key point is that \(\max\{\cdot,0\}\) is a many-to-one event. If it is \(s'>0\), the probability is taken as is because it is one-to-one, and if it is \(s'=0\), multiple \(D\) come together as one, so the sum is taken. The reason the equality sign is included in \(j\ge s+a\) is that the stock becomes exactly 0 even when it is \(D=s+a\).

Numerical example: \(M=3\), \(s=1\), \(a=2\) (\(s+a=3\)), \(p_0=0.1,\ p_1=0.3,\ p_2=0.4,\ \Pr(D\ge3)=0.2\)

\(D\) \(s'=\max\{3-D,0\}\) Probability
0 3 0.1 (\(=p_0\))
1 2 0.3 (\(=p_1\))
2 1 0.4 (\(=p_2\))
\(\ge 3\) 0 0.2 (\(=\sum_{j\ge3}p_j\))

4.3 General Principle

When encountering a stochastic dynamics system \(s_{t+1}=f(s_t,a_t,w_t)\), transition probabilities can be mechanically constructed.

\[ p(s'\mid s,a) = \sum_{w:\ f(s,a,w)=s'} p_w(w) \]

The inventory problem applies to the cases \(f=\max\{s+a-D,0\}\) and \(w=D\), and these three cases are the result of expanding this sum. This perspective leads to the subsequent extension of continuous control.

TipBlock Check (Expand to check answer)

Q1. Why is the transition probability 0 when \(s+a<s'\le M\)?

A. This is an impossible event because the next stock cannot be greater than the current stock \(s+a\) after the order.

Q2. Why is the sum \(\sum_{j\ge s+a}p_j\) taken only when \(s'=0\)?

A. This is because \(\max\{\cdot,0\}\) is a many-to-one event that sends all cases where demand \(D\ge s+a\) is one \(s'=0\). \(D=s+a\) also includes an equality sign because the inventory becomes exactly 0.

Q3. Why does the behavior set depend on the state as \(A_s=\{0,\dots,M-s\}\)?

A. This is because if you order more than that, you will exceed the storage capacity \(M\) and there will be no place to store it.

5 Value Function

Instead of optimizing immediately, we first deal with policy evaluation, which calculates the expected cumulative reward of the given policy \(\pi=(\pi_0,\dots,\pi_{T-1})\).

NoteDefinition (Value Function)

\[ v^\pi_t(s) := \mathbb{E}^\pi\Big[\sum_{\tau=t}^{T-1} r_\tau(s_\tau,a_\tau) + r_T(s_T)\ \Big|\ s_t = s\Big] \] is the expected cumulative reward (return) when executing policy \(\pi\) starting from state \(s\) at time \(t\).

  • return = cumulative reward.
  • Relationship with the original objective function: For the initial distribution \(\mu\), \(\mathbb{E}^\pi[\cdots] = \sum_s \mu(s)\,v^\pi_0(s)\).
  • \(v^\pi_t\) depends only on \((\pi_t,\dots,\pi_{T-1})\).

5.1 Difference from infinite interval

  1. The starting point is important. In an infinite interval, the value function had no time dependency because “the horizon is infinite, so it does not matter when it starts.” In a finite interval, even in the same state, the value differs depending on the remaining time, so \(v^\pi_t\) is a different function at each time point.
  2. There is a terminal condition.

5.2 Q) \(v^\pi_T(s)\) is?

\[ v^\pi_T(s) = r_T(s) \]

Since the start is \(T\), \(\sum_{\tau=T}^{T-1}\) is an empty sum (0), and the only remaining thing is \(r_T(s_T)\) because the condition is \(s_T=s\).

ImportantTwo characteristics of a finite interval value function
  1. The value function is time-dependent. (2) It has terminal conditions and its value is equal to the terminal compensation function.

5.3 Relationship between definition (sum form) and recursion

The definition is in the form of a sum, and the recursion is an expression derived by breaking down the definition one step at a time. This structure is equivalent to an infinite interval.

Definition (Sum form) Recursion
Infinite interval \(v^\pi(s)=\mathbb{E}^\pi[\sum_{\tau=t}^\infty\gamma^{\tau-t}r\mid s_t=s]\) \(v^\pi = R^\pi + \gamma P^\pi v^\pi\) (Fixed point problem)
Finite interval \(v^\pi_t(s)=\mathbb{E}^\pi[\sum_{\tau=t}^{T-1}r_\tau + r_T\mid s_t=s]\) \(v^\pi_t = \cdots v^\pi_{t+1}\) (backward calculation)

In the finite interval, the left side \(v^\pi_t\) and the right side \(v^\pi_{t+1}\) are different functions, so there is no self-referencing. Starting from \(v^\pi_T=r_T\), the process is completed by calculating each step once. In the infinite interval, \(v^\pi\) is present on both sides, so the linear equation \((I-\gamma P^\pi)v^\pi=R^\pi\) must be solved or converged iteratively.

TipBlock Check (Expand to check answer)

Q1. What is the meaning of \(v^\pi_t(s)\) in words without a definition?

A. Expected value of future cumulative reward (return) when starting from state \(t\) at time \(s\) and following policy \(\pi\).

Q2. What is \(v^\pi_T(s)\)? What is the reason?

A. \(r_T(s)\). The sum \(\sum_{\tau=T}^{T-1}\) is empty, the remainder is \(r_T(s_T)\), and the condition is set to \(s_T=s\).

Q3. What are the two characteristics of a finite interval value function compared to an infinite interval value function?

A. (1) Depends on the starting time. (2) Has a terminal condition, and its value is equal to the terminal compensation function.

6 Optimal Policy and Optimal Value Function

6.1 Optimal Policy

\[ v^{\pi^*}_0(s) \ge v^\pi_0(s)\qquad \forall s,\ \forall\pi \]

It is a policy that is of greater than or equal value to any other policy, regardless of the starting state. It can be considered the solution to the previous optimization problem.

6.2 ε-optimal policy

An optimal policy does not always exist (it always exists for finite \(S\) and \(A\)). When it does not exist, using an ε-optimal policy poses no practical problem.

\[ v^{\pi^*_\epsilon}_0(s) + \epsilon > v^\pi_0(s)\qquad\forall s,\ \forall\pi \]

  • Meaning: If you add ε, it beats all policies ⇔ Within ε of the optimal value. It is a policy that arbitrarily approaches the optimal performance.
  • ε must hold for all \(s\).

Example without optimal policy: \(T=1\), \(A=[0,1)\), \(r(a)=a\). No matter which \(a\) is chosen, there is no maximum value because there is a larger \(a'<1\). \(\sup=1\) is unattainable. If we set it to \(a_\epsilon = 1-\epsilon/2\), it becomes \(a_\epsilon+\epsilon = 1+\epsilon/2 > a\) (\(\forall a\)), so it is ε-optimal.

Situations where the optimal policy disappears: the action space is not closed, rewards and transitions are discontinuous at boundaries, and the argmax selection problem is measurable in a continuous space.

6.2.1 sup and max

  • \(\max\): The largest element of the set (may not exist)
  • \(\sup\) (supremum, least upper bound): ① an upper bound of every element, and ② for any \(\epsilon>0\), there exists an element greater than \(M-\epsilon\). If finite, it always exists.
  • Example: In \([0,1)\), \(\max\) does not exist but \(\sup=1\). If \(\max\) exists, then \(\sup=\max\).
  • ② is the basis for the existence of the ε-optimal policy. The question of the existence of the optimal policy ultimately boils down to “\(\sup\) is achieved”.
  • Pair: \(\inf\)(infimum) is a generalization of \(\min\). It appears in cost minimization problems.

6.3 Optimum value function

NoteDefinition (Optimal Value Function)

\[ v^*_t(s) := \max_{\pi\in\Pi} v^\pi_t(s) = \max_{\pi\in\Pi}\ \mathbb{E}^\pi\Big[\sum_{\tau=t}^{T-1} r_\tau(s_\tau,a_\tau) + r_T(s_T)\ \Big|\ s_t=s\Big] \]

WarningNotation caution

The consensus start must be \(\tau=t\). If written as \(\tau=0\), (i) \(v^*_T=r_T\) is broken, (ii) the past reward \(r_0,\dots,r_{t-1}\) is not determined solely by the \(s_t=s\) condition (it is an inverse conditional probability dependent on the initial distribution), and (iii) actions after time point \(t\) cannot change the past, so there is no reason to include them in the optimization target.

  • The maximum value of the cumulative reward expectation that maximizes the policy at each time point.
  • \(\max_\pi\) is effectively the maximization of the remaining time decision rule \((\pi_t,\dots,\pi_{T-1})\).
  • \(v^*_0\) represents the best possible performance. If the initial state is input, it is the maximum expected cumulative reward that the MDP can obtain in that state.
  • If an optimal policy exists, by definition \(v^{\pi^*}_0 = v^*_0\).

6.3.1 Q) \(v^*_T(s)\) is?

\[ v^*_T(s) = r_T(s) \]

No action is taken at the last point in time \(T\). Since the policy only includes up to \(\pi_{T-1}\), the last state is fixed even if \(\max_\pi\) is attached, so this term is not affected by any policy.

ImportantOrganize

Whether for policy evaluation or the optimal value function, the terminal condition is given by the terminal compensation function.

6.3.2 Subtle point

The definition of takes \((t,s)\) for each \(\max_\pi\) separately. Therefore, it is not self-evident that “a single \(\pi^*\) is simultaneously optimal in all \((t,s)\),” and showing this is the deterministic Markov policy optimality theorem that follows.

7 Finite Interval Policy Evaluation (Policy Evaluation)

7.1 Idea: Immediate reward + Expected value of the next state

\[ v^\pi_t(s) = \mathbb{E}^\pi\big[\underbrace{r_t(s_t,a_t)}_{\text{immediate reward}} + \underbrace{v^\pi_{t+1}(s_{t+1})}_{\text{value of next state}}\ \big|\ s_t=s\big] \]

The timing is important. The current reward is that of time point \(t\), and for the next state value to be accurately decomposed, the value function of time point \(t+1\) must be used. The condition applies at time point \(t\).

\[ v^\pi_t(s) = \begin{cases} r_t(s,\pi_t(s)) + \displaystyle\sum_{s'} p(s'\mid s,\pi_t(s))\,v^\pi_{t+1}(s') & \text{deterministic}\\[2ex] \displaystyle\sum_a \pi_t(a\mid s)\Big(r_t(s,a) + \sum_{s'}p(s'\mid s,a)\,v^\pi_{t+1}(s')\Big) & \text{stochastic} \end{cases} \]

  • deterministic: There is no randomness in the behavior, so it is determined as \(a=\pi_t(s)\). The expected value falls only on \(s_{t+1}\), and the distribution is \(p(\cdot\mid s,\pi_t(s))\).
  • stochastic: Since the behavior is also given by a distribution, we must take the expected value by multiplying by the behavior distribution one more time in addition to the randomness of the next state. It is important not to forget this part.

7.1.1 The reason why there is no action sum in the deterministic equation

The action term has not disappeared; rather, the sum has collapsed into a single term. Since the deterministic policy is the Dirac delta \(\pi_t(a\mid s)=\mathbf{1}\{a=\pi_t(s)\}\), substituting it into the stochastic equation leaves only the \(a=\pi_t(s)\) term. What has disappeared is the average of actions \(\sum_a\pi_t(a\mid s)\), and the action is substituted as \(\pi_t(s)\) in the place of \(a\).

Derivation: Conditional decomposition into \(a_t\) using the Total Probability Law \[ \mathbb{E}[\cdot\mid s_t=s] = \sum_a \underbrace{\Pr(a_t=a\mid s_t=s)}_{\pi_t(a\mid s)}\ \mathbb{E}[\cdot\mid s_t=s, a_t=a] \]

Numerical example (\(t=1\), \(s=1\), \(v_2=(2,1)\)): \(Q(1,1)=3.5\), \(Q(1,2)=2.7\)

Policy Value
Deterministic \(\pi_1(1)=1\) \(3.5\)
Dirac delta notation \(1\cdot3.5 + 0\cdot2.7 = 3.5\)
Stochastic \((0.6, 0.4)\) \(0.6\cdot3.5+0.4\cdot2.7 = 3.18\)

The value of the probabilistic policy is the weighted average (convex combination) of the \(Q\) values.

7.2 Proof of recursion

Prove the above recursion for the stochastic Markov policy \(\pi=(\pi_0,\dots,\pi_{T-1})\). The deterministic policy is a special case where \(\pi_t(\cdot\mid s)\) is the Dirac delta.

NoteClaim

\[ v^\pi_t(s)=\sum_{a\in A}\pi_t(a\mid s)\Big[r_t(s,a)+\sum_{s'\in S}p(s'\mid s,a)\,v^\pi_{t+1}(s')\Big],\qquad v^\pi_T(s)=r_T(s) \]

Proof. If we set \(G_{t+1}:=\sum_{\tau=t+1}^{T-1}r_\tau(s_\tau,a_\tau)+r_T(s_T)\), by the linearity of the definition and expectation

\[ v^\pi_t(s)=\mathbb{E}^\pi\big[r_t(s_t,a_t)\mid s_t=s\big]+\mathbb{E}^\pi\big[G_{t+1}\mid s_t=s\big]. \]

  1. First term. Given \(s_t=s\), the distribution of \(a_t\) is \(\pi_t(\cdot\mid s)\), therefore \[ \mathbb{E}^\pi[r_t(s_t,a_t)\mid s_t=s]=\sum_a\pi_t(a\mid s)\,r_t(s,a). \]
  2. Second term, tower rule. If you apply a condition one more time to \((s_t,a_t,s_{t+1})\) \[ \mathbb{E}^\pi[G_{t+1}\mid s_t=s]=\mathbb{E}^\pi\Big[\mathbb{E}^\pi[G_{t+1}\mid s_t,a_t,s_{t+1}]\ \Big|\ s_t=s\Big]. \]
  3. Markov property. Since transition probabilities depend only on the current state and action and the policy is also Markov, given \(s_{t+1}\), the distribution of the subsequent trajectory is independent of \((s_t,a_t)\). Therefore, the inner expectation is the value from time \(t+1\), starting from \(s_{t+1}\). \[ \mathbb{E}^\pi[G_{t+1}\mid s_t,a_t,s_{t+1}]=v^\pi_{t+1}(s_{t+1}). \]
  4. Outer Expectation Expansion. Since the probability of \((a_t,s_{t+1})=(a,s')\) when \(s_t=s\) is \(\pi_t(a\mid s)\,p(s'\mid s,a)\), \[ \mathbb{E}^\pi[G_{t+1}\mid s_t=s]=\sum_a\pi_t(a\mid s)\sum_{s'}p(s'\mid s,a)\,v^\pi_{t+1}(s'). \]
  5. Adding 1 and 4 and grouping them into \(\sum_a\pi_t(a\mid s)\) results in the claim expression. The terminal condition \(v^\pi_T=r_T\) was shown in Section 5. \(\blacksquare\)
WarningEasy to miss
  • Step 3 is the key to this proof. The policy must be Markov for the inner expectation to be a function of only \(s_{t+1}\). If it is a history-dependent policy, the traversed path must also be included as an argument.
  • If it is a probabilistic policy at step 4, the action distribution \(\pi_t(a\mid s)\) is multiplied to both terms. It is common to make the mistake of multiplying it only to the reward and omitting it in the next state term.

7.3 Algorithm: backward calculation

  1. How do you calculate \(v^\pi_t\)? → Reverse time. This is because we know the value of the last point in time, \(T\).
초기화:  v_T^π(s) := r_T(s)   ∀s
for t = T−1 : −1 : 0
    v_t^π(s) := Σ_a π_t(a|s) ( r_t(s,a) + Σ_{s'} p(s'|s,a) v_{t+1}^π(s') )   ∀s
  • T−1 : −1 : 0 = “Starting from \(T-1\), decreasing by \(-1\) to \(0\) (inclusive)”. If it is \(T=3\), it becomes \(t=2,1,0\), exactly \(T\) times.
  • In Python, it is range(T-1, -1, -1) (\(-1\) because the end value is not included). If you write it as range(T-1, 0, -1), \(t=0\) is omitted.

WarningPrecautions

To move from one point in time to the previous point in time, calculations must be completed for all states. The point in time \(T-1\) must be calculated in all states to ensure the necessary information for point \(T-2\) is available. The computational burden increases as the number of states increases.

8 Bellman Equation and Optimality Principle

8.1 Bellman equation

\[ v_t(s) = \max_{a\in A}\Big(r_t(s,a) + \sum_{s'}p(s'\mid s,a)\,v_{t+1}(s')\Big)\quad\forall s,\qquad v_T(s)=r_T(s) \]

  • Reward at time \(t\), the next state uses the value at time \(t+1\).
  • The characteristic of a finite interval is that it has a terminal condition attached.

Uses of the Bellman Equation (An equation studied for over 70 years):

  1. By finding the solution for , the optimal value function is obtained.
  2. Verify which policy is optimal.
  3. efficiently calculates the optimal value function and the optimal policy.
  4. Analyzes the structural properties of the optimal policy and value functions.

8.2 Principle of Optimality

NoteTheorem (Bellman equation)

The optimal value function \(v^*_t\) is a solution to the Bellman equation. \[ v^*_t(s) = \max_{a_t\in A}\mathbb{E}\big[\underbrace{r_t(s_t,a_t)}_{\text{immediate}} + \underbrace{v^*_{t+1}(s_{t+1})}_{\text{optimal value of next state}}\ \big|\ s_t=s\big] = \max_{a\in A}\Big(r_t(s,a) + \sum_{s'}p(s'\mid s,a)\,v^*_{t+1}(s')\Big),\quad v^*_T=r_T \]

WarningDiscount rate γ is not used

\(\gamma\) is not attached to the finite interval Bellman equation. This is because the discount rate can be included within the compensation definition since time-dependent compensation is being used. \[ r_t(s,a) := \gamma^t r(s,a) \] If you want to use discounting over a finite interval, you can do it like this.

Key Meaning: The original problem was optimization for policies (\(T\) functions), but it has now changed to optimization for a single current action — “what action to take at time \(t\), state \(s\)” —.

8.2.1 Why is \(\pi(a\mid s)\) not in the formula?

In policy evaluation, \(\pi\) is given, so the average (\(\sum_a\pi_t(a\mid s)\)) is calculated using that probability. In optimization, \(\pi\) is the target to find, so \(\max_a\) is selected instead of the average. Originally, maximization takes place on the action distribution \(q\), but

\[ \max_{q\in\Delta(A)}\sum_a q(a)\,Q^*_t(s,a) = \max_{a\in A} Q^*_t(s,a) \]

This is because maximizing a linear function over simplex for \(q\) results in a solution at the vertex (Dirac delta). Additionally, since the optimal choice of the future policy is absorbed within \(v^*_{t+1}\), the future policy does not appear in the equation either.

8.3 Proof of the Optimality Principle

Symbol: \(Q^*_t(s,a) := r_t(s,a) + \sum_{s'}p(s'\mid s,a)\,v^*_{t+1}(s')\) — “Expected value when doing \(a\) now and doing the best thereafter”. The proof goal is \(v^*_t(s)=\max_a Q^*_t(s,a)\).

Intuition: If the action at time \(t\) is fixed, the value is split into (now reward) + (later value), and the subsequent policy can be chosen independently of the current action. Therefore, it is advantageous to do the best possible thing after the first action, and thus the value of the first action becomes \(Q^*_t(s,a)\).

8.3.1 (≤) direction

For any \(\pi\):

\[ \begin{aligned} v^\pi_t(s) &= \mathbb{E}^\pi\Big[r_t(s_t,a_t) + \sum_{\tau=t+1}^{T-1} r_\tau(s_\tau,a_\tau) + r_T(s_T)\ \Big|\ s_t=s\Big]\\ &\overset{(1)}{=} \mathbb{E}^\pi\Big[r_t(s_t,a_t) + \mathbb{E}^\pi\Big[\sum_{\tau=t+1}^{T-1}r_\tau + r_T\ \Big|\ s_{t+1}\Big]\ \Big|\ s_t=s\Big]\\ &\overset{(2)}{=} \mathbb{E}^\pi\big[r_t(s_t,a_t) + v^\pi_{t+1}(s_{t+1})\mid s_t=s\big]\\ &\overset{(3)}{\le} \mathbb{E}^\pi\big[r_t(s_t,a_t) + v^*_{t+1}(s_{t+1})\mid s_t=s\big]\\ &\overset{(4)}{=} \sum_a \pi_t(a\mid s)\,Q^*_t(s,a)\ \overset{(5)}{\le}\ \max_a Q^*_t(s,a) \end{aligned} \]

  • (1) tower rule: Decomposition into two-step expectations passing through \(s_{t+1}\).
  • (2) Inside is “value from point \(t+1\) starting from \(s_{t+1}\)” \(= v^\pi_{t+1}(s_{t+1})\). Up to here is the equals sign.
  • (3) \(v^\pi_{t+1}\le v^*_{t+1}\) (The following may not be optimal).
    1. and (3) are parts where two steps are combined into one line and are easy to write. Originally, an equal sign appears as \(v^\pi_{t+1}\), and \(v^*_{t+1}\ge v^\pi_{t+1}\) is written there.
  • (5) Weighted average ≤ maximum value.
  • Since \(\pi\) is arbitrary, taking \(\max_\pi\) on the left side gives \(v^*_t(s)\le\max_a Q^*_t(s,a)\).
WarningNotation caution

The value inside the sum of the first line of the decomposition is \(r_\tau(s_\tau,a_\tau)\) (not \(r_t\)). \(r_t(s_t,a_t)\) outside the sum is the reward at the current time point, so \(t\) is correct, while the value inside the sum is the reward at the moving time point, so it must be \(\tau\). This is not apparent in time-invariant rewards because the values are the same, but the result differs in time-dependent rewards such as \(r_t=\gamma^t r\).

8.3.2 (≥) direction

For any \(\pi\), it is \(v^*_t\ge v^\pi_t\), and if we expand \(v^\pi_t\) in the same way (tower rule) (since \(\pi\) can be randomized, we also multiply by the action probability)

\[ v^*_t(s) \ge \sum_a \pi_t(a\mid s)\Big(r_t(s,a)+\sum_{s'}p(s'\mid s,a)\,v^\pi_{t+1}(s')\Big) \]

  1. The inequality holds for any \(\pi\), where \((\pi_{t+1},\dots,\pi_{T-1})\) on the right-hand side is involved starting from \(t+1\). Even if that part is replaced with the optimal one (\(v^\pi_{t+1}\to v^*_{t+1}\)), the inequality holds. This step is possible because the optimal policy exists, and if it does not exist, it would be much more difficult to prove using the ε-optimal policy and the ε-argument.
  2. Now, all that remains is the action distribution at time \(t\). Since this holds for any distribution, we take all Dirac deltas (distribution with mass concentrated on the first action, distribution with mass concentrated on the second action, …). Then

\[ v^*_t(s) \ge \max_a\Big(r_t(s,a)+\sum_{s'}p(s'\mid s,a)\,v^*_{t+1}(s')\Big) \]

Since both directions hold, the equality sign.

Constructive Interpretation: For any \(a\), if we create \(\pi^a\) such that “at time \(t\), \(a\), and thereafter the optimal policy”, then \(v^{\pi^a}_t(s)=Q^*_t(s,a)\le v^*_t(s)\). Since this holds for all \(a\), \(v^*_t(s)\ge\max_a Q^*_t(s,a)\).

9 Optimality of Deterministic Markov Policy

9.1 Fundamental Question

Under what conditions is it optimal to use deterministic Markov decision rules at each time point?

Answer: Finite MDP(\(S\), \(A\) finite) — more precisely, when the maximizer(argmax) on the right-hand side of the Bellman equation exists. Finiteness is a sufficient condition to guarantee the existence of argmax.

  • Why Determinism Is Sufficient: The value of the probabilistic decision rule \(q\) is \(\sum_a q(a)Q^*_t(s,a)\le\max_a Q^*_t(s,a)\). Randomization offers no benefit as it is merely a convex combination of \(Q\) values. Equality applies only when \(q\) places mass only on the argmax set. (e.g., \(t=1\), shuffling action 2 from state 1 with probability \(q\) results in \(3.5-0.8q\), a strictly loss.)
  • Why Markov is Enough: Once you reach \(s_{t+1}\), future rewards depend solely on your current state and future actions. How you got there does not affect \(v^*_{t+1}(s_{t+1})\) (the past is sunk).

Cases where conditions are broken: absence of a maximizer (continuous action space), when the objective function is not a sum of expectations (risk-sensitive objective, constrained MDP), when the state is not fully observable (POMDP), when there is an adversary (mixed strategies in games).

9.2 Basic assumption: Why is it a finite MDP?

This is to show a mathematically clean result. If it is not a finite set, there is no guarantee that argmax exists, and then we have to deal with the ε-optimal policy (arbitrary precision approximation), which leads to focusing on technical details rather than the idea.

9.3 Cleanup

NoteTheorem (Optimality of Deterministic Markov Policies)

\[ \pi^*_t(s)\in\arg\max_{a\in A}\Big(r_t(s,a)+\sum_{s'}p(s'\mid s,a)\,v^*_{t+1}(s')\Big)\qquad\forall s\in S \] The deterministic Markov policy \(\pi^*\) defined by is the optimal policy, and for all \(t\) it is \(v^{\pi^*}_t = v^*_t\).

Conclusion: In finite MDPs, the optimal policy can be found by considering only deterministic Markov policies.

  • deterministic: Maps one state to one action. Markov: Uses only current state information.
  • “Optimal” means that no matter when it starts or what state it starts in, \(\pi^*\) always delivers maximum performance.
  • \(\in\) Symbol: Used for set membership because there can be multiple (ties) maximization actions.
  • While deterministic policies are sufficient, there are cases where randomized policies are advantageous from a learning perspective (discussed in reinforcement learning).

9.3.1 What this theorem means

  1. There is a way to make it. Even if you do not optimize \(T\) functions at once, an optimal policy is assembled by selecting argmax for each cell from the back.
  2. Optimal for all \((t,s)\). The latter part of the optimal policy \((\pi^*_t,\dots,\pi^*_{T-1})\) is also optimal for the remaining problem (the remainder of the optimal path is also optimal).
  3. A policy is a reaction rule. Even if things do not go according to plan due to uncertainty, applying \(\pi^*_t\) again from the destination state restores it to optimality.

Why one step argmax is the overall optimal: This is because argmax contains not only \(r_t\) but also \(v^*_{t+1}\). Since \(v^*_{t+1}\) represents the “value when the subsequent steps are optimized,” the current choice is the best under the assumption that “the subsequent steps are optimized.” And since \(\pi^*\) is defined in the same way at all subsequent points in time, the assumption becomes reality. (e.g., \(t=T-2\) in the investment-consumption problem; looking only at the current reward in state 1, it is consumption, but since \(Q^*(1,\text{소비})=2 < Q^*(1,\text{투자})=5\), \(\pi^*\) is an investment.)

What is not said: that the optimal policy is unique (multiple if tied), that the action is the same at every time step, that argmax needs to be done at only one time step (it must be argmax at all times steps), and that the predetermined order of actions is optimal.

9.4 Proof (Mathematical Induction)

① \(v^{\pi^*}_t \le v^*_t\) — Definition of the optimal value function. No policy can exceed the optimal value.

② \(v^{\pi^*}_t \ge v^*_t\) by induction. Where do we start? Since we know the terminal condition, we start from \(T\).

  • Base \(t=T\): For any policy, the terminal value function is equal to the terminal reward and the optimal value is also equal. \(v^{\pi^*}_T = r_T = v^*_T\) (equality).
  • Inductive Assumption: \(v^{\pi^*}_{t+1}\ge v^*_{t+1}\) (in all \(s'\)).

First inequality (using inductive hypothesis) \[ \sum_{s'}p(s'\mid s,\pi^*_t(s))\,v^{\pi^*}_{t+1}(s') \ \ge\ \sum_{s'}p(s'\mid s,\pi^*_t(s))\,v^*_{t+1}(s') \tag{1} \] Why? The transition probability is a weight greater than or equal to 0, and since \(v^{\pi^*}_{t+1}\ge v^*_{t+1}\) under the same weight.

Second inequality (using the definition of \(\pi^*\)) — Since \(\pi^*_t\) is defined as the argmax of the right-hand side of the Bellman inequality, for all \(a\in A\) \[ r_t(s,\pi^*_t(s))+\sum_{s'}p(s'\mid s,\pi^*_t(s))\,v^*_{t+1}(s') \ \ge\ r_t(s,a)+\sum_{s'}p(s'\mid s,a)\,v^*_{t+1}(s') \tag{2} \]

Combination: If we add \(r_t(s,\pi^*_t(s))\) to both sides of (1) and connect it to (2) (connection is possible because the middle term uses the same behavior \(\pi^*_t(s)\)), for all \(a\) \[ r_t(s,\pi^*_t(s))+\sum_{s'}p(s'\mid s,\pi^*_t(s))\,v^{\pi^*}_{t+1}(s') \ \ge\ r_t(s,a)+\sum_{s'}p(s'\mid s,a)\,v^*_{t+1}(s') \]

Maximize for action: \(a\) is not on the left side.

  • Left side = Time point \(\pi^*\) \(t\) Policy Evaluation Formula = \(v^{\pi^*}_t(s)\)
  • \(\max_a\) on the right side = Bellman Equation = \(v^*_t(s)\) (Optimality Principle)

Therefore, \(v^{\pi^*}_t(s)\ge v^*_t(s)\). If it holds in \(t+1\), it also holds in \(t\), and since it holds at the end, induction is complete. Combined with ①, \(v^{\pi^*}_t = v^*_t\).

9.4.1 View as a single-line chain

\[ \begin{aligned} v^{\pi^*}_t(s)&\overset{(a)}{=}r_t(s,\pi^*_t(s))+\sum_{s'}p(s'\mid s,\pi^*_t(s))\,v^{\pi^*}_{t+1}(s')\\ &\overset{(b)}{\ge}r_t(s,\pi^*_t(s))+\sum_{s'}p(s'\mid s,\pi^*_t(s))\,v^*_{t+1}(s')\\ &\overset{(c)}{=}\max_a\Big(r_t(s,a)+\sum_{s'}p(s'\mid s,a)\,v^*_{t+1}(s')\Big)\overset{(d)}{=}v^*_t(s) \end{aligned} \]

  1. Deterministic policy evaluation (b) Inductive assumption + non-negative weights (c) \(\pi^*\) is argmax (d) Optimality principle

9.4.2 Check Value (Two-State, \(t=1\), \(s=1\))

Step Expression Value
(1) \(0.5\cdot2+0.5\cdot1\ \ge\ 0.5\cdot2+0.5\cdot1\) \(1.5\ge1.5\)
(2), \(a=2\) \(2+1.5\ \ge\ 1+0.7\cdot2+0.3\cdot1\) \(3.5\ge2.7\)

9.4.3 Why is the inductive hypothesis necessary?

\(t=1\) is argmax, but \(t=2\) is a policy that was incorrectly chosen (\(\pi_1(1)=1\), \(\pi_2(2)=1\)): \(v^\pi_2(2)=0<1=v^*_2(2)\), and \(v^\pi_1(1)=2+0.5\cdot2+0.5\cdot0=3<3.5\). We must be greedy at every point in time. The greedy at one point in time combines with the greedy at subsequent points to become the overall optimal.

9.4.4 Points to note

  • Reason the conclusion is equal: Since (≤) already holds by definition, the inductive assumption can be set as equal from the beginning.
  • Roles of the two theorems: The Optimality Principle is a fact about the value (\(v^*\) is the Bellman solution), and this theorem is a fact about the achievability of a policy (the argmax policy achieves \(v^*\)).
  • The converse holds: If \((t,s)\) is \(v^\pi_t=v^*_t\) for all \(v^\pi_t=v^*_t\), then argmax must be selected from each cell. That is, selecting argmax ⇔ optimality. This is used for “policy optimality verification”.
  • The place where the finite set assumption is used is (c) (argmax exists). If we change to ε-argmax in continuous space, the error accumulates at each step to \(v^\pi_t\ge v^*_t-(T-t)\epsilon'\). To make the total error less than or equal to \(\epsilon\), the step \(\epsilon'=\epsilon/T\).

10 Stochastic Optimum Policy

  1. We confirmed that a deterministic optimal policy can be created. How is a stochastic optimal policy created?

Consider the case where there are multiple maximizers. Since optimal performance is maintained regardless of which one is chosen, if you assign probabilities to the optimal actions such that their sum is 1, it becomes a randomized optimal policy.

  • Example: There are three optimal actions \(a^*_1, a^*_2, a^*_3\)
    • deterministic: Assign one of them (e.g., \(a^*_1\)) as the policy output
    • randomized: probabilistically selects among actions of equal performance
  • argmax It is not optimal to place mass on actions outside the set.
  • The question of when randomization and when determinism are advantageous is covered in reinforcement learning (e.g., exploration in situations where the model is unknown).

10.1 Proof: A stochastic policy on the argmax set is optimal

Let \(A^*_t(s):=\arg\max_{a}\big[r_t(s,a)+\sum_{s'}p(s'\mid s,a)\,v^*_{t+1}(s')\big]\), and let \(Q^*_t(s,a)\) be the value inside the square brackets.

NoteClaim

If a stochastic Markov policy \(\bar\pi\) satisfies \(\bar\pi_t(a\mid s)>0\Rightarrow a\in A^*_t(s)\) for all \(t,s\), then \(v^{\bar\pi}_t=v^*_t\) for all \(t\).

Proof. Back induction for \(t\).

  • Base \(t=T\): \(v^{\bar\pi}_T=r_T=v^*_T\).
  • Inductive Step: Assume \(v^{\bar\pi}_{t+1}=v^*_{t+1}\). By policy evaluation recursion (Section 7.2) and the inductive assumption \[ v^{\bar\pi}_t(s)=\sum_a\bar\pi_t(a\mid s)\Big[r_t(s,a)+\sum_{s'}p(s'\mid s,a)\,v^*_{t+1}(s')\Big]=\sum_{a\in A^*_t(s)}\bar\pi_t(a\mid s)\,Q^*_t(s,a). \] If \(a\in A^*_t(s)\), then it is \(Q^*_t(s,a)=\max_{a'}Q^*_t(s,a')\) and \(\sum_{a\in A^*_t(s)}\bar\pi_t(a\mid s)=1\), therefore \[ v^{\bar\pi}_t(s)=\max_{a'}Q^*_t(s,a')=v^*_t(s) \] is. The last equal sign is the Optimality Principle (Section 8). \(\blacksquare\)

Conversely, if a positive probability \(q\) is given to \(a\) in \(Q^*_t(s,a)<\max_{a'}Q^*_t(s,a')\) from some \((t,s)\), the value of that cell is strictly reduced by the product of \(q\) and the difference. Example: Two-State \(t=1\), shuffling Action 2 from State 1 with probability \(q\) results in \(3.5-0.8q\).

TipRelationship with Deterministic Theorems

The deterministic theorem in this argument is the case where \(\bar\pi_t(\cdot\mid s)\) has a mass of 1 for one argmax element. The probabilistic version is equal sign induction, so the proof is actually shorter. This is because we already know from the Optimality Principle that \(v^*\) is a Bellman solution.

11 DP (Backward Induction) algorithm

Notealgorithm 
초기화:  v_T*(s) := r_T(s)   ∀s
for t = T−1 : −1 : 0
    v_t*(s) := max_a    ( r_t(s,a) + Σ_{s'} p(s'|s,a) v_{t+1}*(s') )   ∀s
    π_t*(s) ∈ argmax_a  ( r_t(s,a) + Σ_{s'} p(s'|s,a) v_{t+1}*(s') )   ∀s
  • Initialize to \(r_T\) at the end and solve the Bellman equation while decreasing the time one by one.
  • The maximization problem is solved for each state. When the state changes, the optimal action also changes. Optimization must be solved as many times as there are states rather than once at every time step, and this is the computational burden of large-scale problems.
  • \(v^*_t\) and \(\pi^*_t\) are calculated simultaneously in one loop. There is no need to calculate \(\pi^*\) separately after calculating \(v^*_t\) down to 0. This is because the information required for both is from the point \(t+1\), which has already been calculated in the previous iteration. In a single calculation of \(\max\), the maximum value should be stored as \(v^*_t\), and the maximization action as \(\pi^*_t\).
  • When proceeding to time 0, the optimal value and optimal policy for all states are obtained.

11.1 Properties and the reason

Properties Basis
Find the optimal value function at each time step The update equation is literally equal to the right-hand side of the Bellman equation, and each step is accurate (no error accumulation) through induction on \(t\) starting from the basis \(v_T=r_T=v^*_T\)
Find the optimal policy \(\pi^*\) is the argmax, and the Deterministic Markov Policy Optimality Theorem guarantees \(v^{\pi^*}=v^*\)
There can be multiple optimal policies Since argmax is a set, an option arises in case of a tie
ImportantThe optimal value function is unique, but there is no reason for the optimal policy to be unique.

Tie selection does not change \(v^*\), so it does not affect the argmax set of other cells. Therefore, it is independent per cell and \[ \#\{\text{최적 결정론적 Markov 정책}\} = \prod_{t=0}^{T-1}\prod_{s\in S}\big|\arg\max_a Q^*_t(s,a)\big| \] If there are no ties, it is 1 (unique). If there are ties, there are infinitely many optimal policies that are probabilistically mixed.

Tie Example: In Two-State, if only \(r(1,2)\) is changed to \(1\to2\), it results in \(t=2\), and in State 1, it is a tie with \(Q(1,1)=Q(1,2)=2\) → \(\pi_2(1)\in\{1,2\}\). Either way is optimal, and all \(q\in[0,1]\) that are \(\pi_2(1\mid1)=q\) are also optimal.

(Note: If the optimal policy is defined as \(t=0\) only as \(v^{\pi^*}_0\ge v^\pi_0\), the number of optimal policies increases because the action in the \((t,s)\) cell, which is not reached by any policy, does not matter. The product formula above counts the optimal policies in the strong sense, which are \(v^\pi_t=v^*_t\) across all cells.)

Q1. Why can \(v^*_t\) and \(\pi^*_t\) be calculated simultaneously in a single loop?

A. The only information needed for both is \(t+1\) at point \(v^*_{t+1}\), and this has already been calculated in the previous iteration. In a single \(\max\), the maximum value is stored as \(v^*_t\), and the maximization action is stored as \(\pi^*_t\).

Q2. Which is the only optimal value function and optimal policy?

A. The optimal value function is unique. There can be multiple optimal policies if argmax is tied.

A. At every time step, the action maximization problem must be solved for all states. If the state and action space is large, it does not expand well.

12.1 Model

\(T=3\), \(S=\{1,2\}\), \(A=\{1,2\}\), \(r_T\equiv0\)

\(s\) \(a\) \(r(s,a)\) \(p(1\mid s,a)\) \(p(2\mid s,a)\)
1 1 2 0.5 0.5
1 2 1 0.7 0.3
2 1 0 0.2 0.8
2 2 1 0.6 0.4
  • State 1 is a good state with a large reward, and State 2 is a bad state.
  • Action 2 increases the probability of going to state 1.
  • Question for each square: Should I claim the reward now, or increase the chance of reaching a good state?
  • Notation: \(\pi_2(1)=1\) is “Time 2, State 1, Action 1”.

12.2 Calculation Instructions

\(p(2\mid s,a) = 1-p(1\mid s,a)\) so

\[ Q_t(s,a) = r(s,a) + v_{t+1}(2) + p(1\mid s,a)\cdot\underbrace{\big(v_{t+1}(1)-v_{t+1}(2)\big)}_{\Delta_{t+1}} \]

Since \(v_{t+1}(2)\) is common and therefore excluded from the comparison, only the immediate reward difference and \(p(1\mid s,a)\) difference × \(\Delta_{t+1}\) need to be compared.

12.3 Step-by-step solution

\(t=3\): \(v_3(1)=v_3(2)=0\) (End-end compensation 0)

\(t=2\) (\(\Delta_3=0\) → No future value, compare only immediate rewards, convert to greedy):

  • State 1: \(\max\{2,\ 1\}=2\) → \(\pi_2(1)=1\)
  • State 2: \(\max\{0,\ 1\}=1\) → \(\pi_2(2)=2\)

The first term inside \(\max\) is the “immediate reward + subsequent cumulative reward expected value” when performing action 1 and action 2. At time 3, the reward is 0, so there is nothing to be gained regardless of which state is reached, and therefore the transition probability does not affect the choice.

\(t=1\) (\(v_2=(2,1)\), \(\Delta_2=1\)):

  • State 1: \(\max\{2+0.5\cdot2+0.5\cdot1,\ 1+0.7\cdot2+0.3\cdot1\} = \max\{3.5,\ 2.7\} = 3.5\) → \(\pi_1(1)=1\)
  • State 2: \(\max\{0+0.2\cdot2+0.8\cdot1,\ 1+0.6\cdot2+0.4\cdot1\} = \max\{1.2,\ 2.6\} = 2.6\) → \(\pi_1(2)=2\)

\(t=0\) (\(v_1=(3.5,2.6)\), \(\Delta_1=0.9\)):

  • State 1: \(\max\{2+0.5\cdot3.5+0.5\cdot2.6,\ 1+0.7\cdot3.5+0.3\cdot2.6\} = \max\{5.05,\ 4.23\} = 5.05\) → \(\pi_0(1)=1\)
  • State 2: \(\max\{0+0.2\cdot3.5+0.8\cdot2.6,\ 1+0.6\cdot3.5+0.4\cdot2.6\} = \max\{2.78,\ 4.14\} = 4.14\) → \(\pi_0(2)=2\)

12.4 Result Summary

12.5 Why is such a policy being introduced?

  • State 1 → Action 1: Switching to Action 2 reduces the reward by 1 and increases the probability of returning to State 1 by 0.2, resulting in \(0.2\Delta\). Since \(\Delta\le1\), what is gained < what is lost. (It must be \(\Delta>5\) for it to flip.)
  • State 2 → Action 2: Reward increases by 1 and the probability of going to State 1 increases by 0.4, so Benefit in both aspects.
  • In this example, the policy is the same regardless of the time point, but it is a coincidence of numbers (compared to the investment-consumption example).
  • There are no ties, so the optimal policy is unique.
TipIf there is terminal compensation, even the final decision looks to the future.

If \(r_T(1)=10\), \(r_T(2)=0\), then \(t=2\), in state 1 action 1 is \(2+0.5\cdot10=7\), and action 2 is \(1+0.7\cdot10=8\), so it flips to \(\pi_2(1)=2\). \(t=2\) was reduced to greedy because the terminal value was 0.

13 Extension to continuous control

DP can be used in physical systems where both the state and action spaces are continuous. However, there is a point to note.

13.1 System Model

\[ s_{t+1} = f(s_t, a_t, w_t),\qquad w_t \sim p_w(\cdot)\ \text{(알려져 있음)} \]

  • Example: Vehicle dynamics, electrochemical model approximation of Battery Management System (BMS)
  • Haves Markov properties: The next state depends only on the previous state, behavior, and uncertainty.
  • In inventory management, transition probabilities were explicitly derived for \(s\)=Inventory Quantity, \(a\)=Order Quantity, and \(w\)=Demand. In continuous control, we examine whether the optimal value and policy can be calculated directly without explicitly deriving transition probabilities.

The problem is identical: \(\max_\pi \mathbb{E}^\pi\big[\sum_{t=0}^{T-1}r(s_t,a_t)+r(s_T)\big]\)

13.2 Q) What is the transition probability?

\(p(s'\mid s,a)\) is the probability that the next state is \(s'\), and for it to be meaningful, it must be \(s'=f(s,a,w)\). By introducing an indicator function

\[ p(s'\mid s,a) = p_w(w)\,\mathbf{1}\{s'=f(s,a,w)\} \]

NoteStrictly speaking, if written

The above expression is an abbreviated notation for “collecting the probabilities of \(w\) that make \(s'=f(s,a,w)\)”. Since \(w\) remains as a free variable on the right side, in reality, we must collect for \(w\). \[ p(s'\mid s,a)=\sum_{w}p_w(w)\,\mathbf{1}\{s'=f(s,a,w)\}\quad(\text{이산 }w),\qquad \Pr(s_{t+1}\in B\mid s,a)=\int\mathbf{1}\{f(s,a,w)\in B\}\,p_w(dw)\quad(\text{연속}) \] The three cases of inventory management are the expanded form of this sum (Section 4). The Bellman equation of the form \(p_w\) below is this integral written for \(v_{t+1}\).

13.3 Q) What is the Bellman equation?

Since is continuous, the expected value is an integral rather than a sum, and we write \(\sup\) instead of \(\max\).

\[ v_t(s) = \sup_{a\in A}\Big[r(s,a) + \int_{s'\in S} v_{t+1}(s')\,p(ds'\mid s,a)\Big] \]

13.4 Q) If you write it again as \(p_w\)?

Since it survives only when \(s'=f(s,a,w)\), substitute \(f(s,a,w)\) for \(s'\)Z and integrate over \(w\).

\[ v_t(s) = \sup_{a\in A}\Big[r(s,a) + \int_w v_{t+1}\big(f(s,a,w)\big)\,p_w(dw)\Big] \]

The Bellman equation can be defined without directly writing transition probabilities.

13.5 Q) What is the optimal policy?

\[ \pi^*_t(s)\in\arg\max_{a\in A}\Big[r(s,a)+\int_w v_{t+1}(f(s,a,w))\,p_w(dw)\Big] \]

WarningThe existence of an optimal policy is not guaranteed

In continuous problems, argmax may not exist. In such cases, an ε-optimal policy is used. In fact, when solving continuous problems with reinforcement learning, errors larger than ε occur. Most, and virtually all, reinforcement learning algorithms fail to find an optimal policy, and the very purpose of reinforcement learning is to find a sufficiently good approximation policy.

13.6 DP algorithm for continuous control

초기화:  v_T*(s) := r_T(s)   ∀s
for t = T−1 : −1 : 0
    v_t*(s) := sup_a  [ r(s,a) + ∫ v_{t+1}*(f(s,a,w)) p_w(dw) ]   ∀s
    π_t*(s) ∈ argmax_a [ … ]      (maximizer가 존재하는 경우)

Property: Finds the optimal value function at each time step. An optimal policy may not exist, and if a maximizer exists, finds the optimal policy.

13.7 New problems arising in continuous control

  1. Maximum value may not exist.
  2. Optimization is difficult because the action space is wide. Although there are algorithms for cases such as when the objective function is concave, it is generally difficult to find a maximizing action.
  3. If the state space is continuous, initialization can be done in the form of a function, but updates must hold for all real numbers.

13.8 Dioxide and the Curse of Dimensions

If the state space is \([0,1]\), discretize. If discretized to \(N=3\) points, the optimal value and policy are calculated only at those three points, and discretization error is introduced (perfect information is not transmitted at every step).

Generalized: 1-dimensional \(3\) point → 2-dimensional \(3^2=9\) point → \(n\)-dimensional \(3^n\) point. Computational load and memory increase exponentially.

ImportantCurse of Dimensionality

DP breaks down difficult problems into many easy problems, but the number of these easy problems can become too large. If continuous control is simply discretized, this exponential increase is immediately felt. The location of the difficulty has shifted from an “explosion of policy numbers (\(m^{nT}\))” to an “explosion of state numbers.”

Solution Approach: Instead of discretization, define a function architecture of the value function (or policy) and learn and optimize its weights. Approximating the value function and policy with a neural network is deep reinforcement learning (deep RL).

A. No. In continuous problems, an error greater than ε occurs, and the purpose itself is a sufficiently good approximation policy.
