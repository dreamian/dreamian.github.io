3 0. Starting point

3.1 What kind of problem is reinforcement learning?

A question to consider first. In the MDPs discussed so far, \(p\) and \(r\) were given. What does the agent exchange with the environment, and what does it gain from that exchange?

Answer. Reinforcement learning is the problem of goal-oriented agents interacting with an uncertain environment. The agent sends out an action (decision), and the environment returns the next state and a reward (feedback). Through this interaction, the agent learns about the environment while simultaneously learning a better policy. In other words

\[ \text{interaction}\ \Longrightarrow\ \text{adaptation}. \]

TipSignificance
  • “Goal-oriented” means that there is an objective function (expected cumulative reward). This is the root of optimal control → Section 4.1
  • “Adaptation through interaction” is rooted in trial-and-error learning → Section 4.2
  • Most model-free methods do not explicitly estimate the environment’s model \(p\) in interactions. They directly update values or policies → Section 8.1

↓ Scroll Down: Section 3.1.1

3.1.1 If intelligent systems are viewed as Data → Information → Decision Making, what role does RL play?

Answer. Taking autonomous vehicles as an example, intelligence can be divided into two stages.

\[ \underbrace{\text{Data}\to\text{Information}}_{\text{센서 데이터에서 주변 차량·보행자 정보 추출}} \qquad \underbrace{\text{Information}\to\text{Decision}}_{\text{교통 상황에 맞는 주행 판단}} \]

Usually, the two parts are designed separately, but RL can be an algorithm that learns end-to-end from data to decision-making. Such a system must adapt to uncertainties such as other vehicles and people, weather, road construction, and passengers.

4 I. Combine with two roots

4.1 What does optimal control solve, and where does DP get stuck?

First question to consider. When applying VI·PI earlier, (i) what did you absolutely have to know, and (ii) what was the amount of computation proportional to?

Answer. Optimal control is the problem of designing a controller that maximizes the performance of a dynamic system over an entire time interval (finite or infinite). The key point is that the objective is the performance of the entire interval, not the performance at a single point in time. Although Bellman’s dynamic programming in the 1950s laid the foundation for this problem, DP has two limitations.

  1. Model Knowledge: You must fully understand \(p\) (and \(r\)) to apply the Bellman operator → Section 4.1.2
  2. Scalability: State space grows exponentially with respect to dimension (curse of dimension) → Section 4.1.1

RL is an attempt to solve these two problems of (stochastic) optimal control. It can be used without a model and finds a tractable approximate solution instead of the exact optimal solution.

TipSignificance: The goal determines the year

In the path problem from a starting point to a destination, if the goal is time reduction, one path becomes optimal, and if the goal is fuel minimization, the other path becomes optimal. In optimal control, “optimal” is meaningful only with respect to the objective function. This is the same reason why the reward design determines the outcome policy in RL.

4.1.1 If you write the Curse of Dimensions as a number

First question to consider. If the state consists of \(d\) components and each component is discretized into \(k\) steps, what is \(|S|\)? VI What is the cost of one step?

Answer. \[ |S|=k^d,\qquad \text{VI 1회 비용}=O\big(|S|^2|A|\big)=O\big(k^{2d}|A|\big),\qquad \text{결정적 stationary 정책 수}=|A|^{|S|}=|A|^{k^d}. \]

NoteBasis
  • VI 1 time: Calculate \(\sum_{s'}p(s'\mid s,a)v(s')\) for all \((s,a)\). Since \((s,a)\) is the sum of \(|S||A|\), each \(|S|\) term, \(|S|^2|A|\).
  • Number of Policies: Since one action is chosen independently for each state, \(|A|^{|S|}\). As MDP theory has shown that deterministic stationary policies are sufficient, the search space is finite, but its size is an exponent of \(|S|\).
  • Example: If \(d=10\) and \(k=10\), then \(|S|=10^{10}\). Just storing \(v\) requires \(10^{10}\) elements.
TipSignificance

As long as \(v\) or \(Q\) are treated exactly as a tabular, this cost cannot be avoided. Therefore, RL abandons exact solutions from the outset and reduces the representation using functional approximations (linear features, neural networks). The price for this is the difficulty of “limited representation” → Section 7.1.2

4.1.2 Where is model dependency hidden in VI·PI?

Answer. There are three places.

\[ \begin{aligned} \text{VI}:\quad& v_{k+1}=Tv_k &&\leftarrow\ T\text{ 안의 }\textstyle\sum_{s'}p(s'\mid s,a)v(s')\\ \text{PI 평가}:\quad& v^{\pi}=T^{\pi}v^{\pi}\ \Leftrightarrow\ (I-\gamma P^\pi)v^\pi=R^\pi &&\leftarrow\ P^\pi\\ \text{PI 향상}:\quad& \pi'(s)\in\arg\max_a\Big[r(s,a)+\gamma\textstyle\sum_{s'}p(s'\mid s,a)v^\pi(s')\Big] &&\leftarrow\ p \end{aligned} \]

TipSignificance
  • The enhancement step of PI becomes \(\pi'(s)\in\arg\max_aQ^\pi(s,a)\) when \(Q^\pi\) is used, and the model disappears. What remains is “how to calculate the expected value \(\sum_{s'}p(\cdot)\) without the model”.
  • The answer to this question is the next topic, stochastic approximation. We replace the expectation with the sample and gradually reduce the step size so that the noise in the sample disappears over time.

4.2 What does trial and error learning mean?

Answer. It has roots in psychology.

  • Thorndike (1911), Law of Effect: Among various responses to the same situation, responses accompanied by satisfaction have a stronger connection to the situation and appear more frequently when the situation arises again, while responses accompanied by discomfort have a weaker connection and appear less frequently.
  • Klopf (1972): Connected this idea to trial-and-error learning and related it to vast experimental data in animal learning psychology.
  • Sutton & Barto (1970–80s): Temporal-Difference (TD) learning is the algorithm developed from this.
TipSignificance: If you interpret the law of effect as a probabilistic policy

The statement “responses accompanied by satisfaction appear more readily” can be interpreted as an update that increases the probability of actions with higher rewards in a stochastic policy \(\pi(a\mid s)\). This aligns with the intuition of policy gradient. On the other hand, if interpreted as storing and updating the “strength of the connection between situation and response” numerically, it aligns with the intuition of the value-based method that updates \(Q(s,a)\) → Section 8.1

  • Since the 2010s, with the advancement of deep learning and computational resources, deep RL, which expresses values and policies using neural networks, has expanded to practical problems.

5 II. Five Characteristics of RL

5.1 What is the difference between RL and supervised learning?

Answer.

  1. No supervisor and only reward signals → Section 5.1.1
  2. Feedback is not immediate and is delayed → Section 5.1.2
  3. Time is important. It is a sequential decision and the data is not iid → Section 5.1.2
  4. Agent’s behavior affects data to be received later → Section 5.1.3
  5. There is a trade-off between exploration and exploitation → Section 5.1.4
TipSignificance

4 is the most fundamental. In supervised learning, the data distribution is fixed regardless of the learner. In RL, if the learner changes the policy, the data distribution changes. 5 is a direct consequence of 4. Since the learner must decide for themselves which data to look at, they must choose between an action that looks good now and an action that provides more information.

5.1.1 ✍ Why Rewards Cannot Serve as Correct Answer Labels

Guide Question:

  1. What do we need to know to provide the “correct action” as the label for supervised learning in the state \(s\)? If we write it as \(Q^*\)?
  2. What is the difference between \(r(s,a)\) and \(Q^*(s,a)\)? Does \(\arg\max_ar(s,a)=\arg\max_aQ^*(s,a)\) always hold?
  3. If \(\gamma=0\), then it is \(Q^*=r\). In that case, is RL supervised learning?
NoteSolution

1. The correct action is \(\pi^*(s)\in\arg\max_aQ^*(s,a)\). In other words, to be the label, you must know the long-term gain \(Q^*(s,a)\).

2. \[ Q^*(s,a)-r(s,a)=\gamma\sum_{s'}p(s'\mid s,a)\,v^*(s'). \] This difference depends on \(a\) (since the action changes the distribution of the next state). Therefore, the argmax of immediate reward and the argmax of long-term gain are generally different. A counterexample is found in Section 6.1.1’s example. Reward is not the correct label because it measures only immediate gain.

3. No. If it is \(\gamma=0\), the lag problem disappears, but only the reward for a single selected action is observed. Since the reward for unselected actions is not visible, “which action was the correct answer” is still not given (bandit feedback). In supervised learning, the correct answer is given for every input, but here, only the score for the chosen action is given. Therefore, even if it is \(\gamma=0\), the search problem (Section 5.1.4) remains.

TipSignificance

There are two reasons why rewards cannot serve as supervised learning labels: (i) temporal: rewards do not reflect long-term gains (when \(\gamma>0\)). (ii) counterfactual: the consequences of uneven behavior are not observed (even when \(\gamma=0\)). RL algorithms treat (i) as the Bellman equation and (ii) as search.

5.1.2 Why is feedback delayed, and why is the data not iid?

First question to consider. When following a stationary policy \(\pi\), write the state distribution at time \(t\) in terms of the initial distribution and transition.

Answer. \(P^\pi(s,s'):=\sum_a\pi(a\mid s)\,p(s'\mid s,a)\), if we let the state distribution be the row vector \(\mu_t\), \[ \mu_{t+1}=\mu_tP^\pi\quad\Longrightarrow\quad\mu_t=\mu_0(P^\pi)^t,\qquad (s_t,a_t)\sim\mu_t(s)\,\pi(a\mid s). \]

  • Not iid: \(s_{t+1}\) is not independent because it depends on \(s_t\), and it is not identically distributed because \(\mu_t\) varies according to \(t\).
  • Feedback is delayed: Action \(a_t\) changes the distribution of \(s_{t+1}\), and this propagates to \(\mu_{t+2},\mu_{t+3},\dots\). The result of \(a_t\) appears not just in \(r_t\), but across the entire subsequent reward system. The current choice changes the very paths that can be taken later.
TipSignificance
  • The convergence logic of supervised learning (iid sample mean) cannot be used as is. This is why a “conditional” mean \(0\) condition (conditional on past history \(\mathcal{F}_k\)) is applied to the noise in subsequent convergence analysis.
  • Reducing inter-sample correlations with experience replay in deep RL also targets the same problem.

↑ Go Up: Section 5.1

5.1.3 What exactly does it mean that behavior changes the data distribution?

Answer. In the equation Section 5.1.2, the distribution of data \((s_t,a_t,r_t,s_{t+1})\) is a function of the policy \(\pi\) through \(\mu_0(P^\pi)^t\)Z and \(\pi\). If the policy changes to \(\pi_k\to\pi_{k+1}\) during training, the distribution of the next collected data also changes.

TipSignificance
  • Supervised learning: Fixed data distribution → Model training. It is one-way.
  • RL: Policy → Data Distribution → Policy Update → Data Distribution … There is a feedback loop.

In an unfamiliar environment, whether to choose the path that seems best based on the information (or belief) currently available, or to choose an action that provides more information because one knows less, depends on the situation. There is generally no known method to optimally balance these two → Section 5.1.4

5.1.4 Why does the search-utilization trade-off occur, and what goes wrong without search

First question to consider. If we always choose the greedy action \(\arg\max_a\hat Q(s,a)\) for the current estimate \(\hat Q\), what happens to the estimate of the action that was once underestimated?

Answer. It is not updated. This is because new data does not arrive due to unevenness. Therefore, if the initial estimate is unfortunately wrong, it can remain in the suboptimal state forever.

NoteExample: Case where greedy fails with a probability of 0.3 or higher

Two actions, one state (bandit that is \(\gamma=0\)).

  • Action A: The reward is always \(0.5\).
  • Action B: The rewards are \(0.7\) with probabilities \(1\) and \(0.3\) with probabilities \(0\). Since the expected value is \(0.7\), B is optimal.

Try each action once, use the sample mean as the estimate, and then choose greedy.

  • If B’s first reward is \(0\) (probability \(0.3\)), then \(\hat Q(B)=0<0.5=\hat Q(A)\). After that, always choose A, A’s estimate remains \(0.5\), and B is not tried again. It stays on A forever.
  • Even if B’s first reward is \(1\), the same thing happens if B’s sample mean unfortunately drops below \(0.5\) afterwards.

Therefore, the probability of failure is at least \(0.3\). It does not decrease no matter how long data is collected.

TipSignificance
  • The cause of the trade-off is that the environment model (\(p\), \(r\)) is unknown. If the model were known, there would be no reason to search. Therefore, this is not a problem unique to RL, but a problem in all sequential decision-making problems where the model is unknown.
  • Choosing an action that provides more information, even if it means sacrificing a small immediate gain (greedy), can be advantageous in the long run. The simplest implementation is \(\varepsilon\)-greedy (\(1-\varepsilon\) probability greedy, \(\varepsilon\) probability random).
  • The Q-learning convergence theorem assumes that “all \((s,a)\) are visited infinitely often” to exclude the failure shown in this example.

6 III. Formalization

6.1 What are the components and policies of an RL problem?

Answer.

  • State \(s_t\in S\): State of the environment (system).
  • Action \(a_t\in A\): Determined by the agent and affects the state.
  • Reward \(r(s_t,a_t)\): Evaluates the benefits of the state and action.
  • Policy \(\pi\): A transition from state to action. It is the subject of optimization. \[ \text{결정적: }\ \pi(s_t)=a_t,\qquad \text{확률적: }\ \pi(a\mid s)=\Pr(a_t=a\mid s_t=s). \]

The goal of sequential decision-making is to select actions over time to maximize the expected cumulative reward.

TipSignificance: Why use probabilistic policies

Since the optimal policy of an MDP exists among deterministic and stationary policies, a stochastic policy is not necessary in terms of optimality alone. However, stochastic policies are useful in RL algorithms.

  • Search can be put into the policy itself(\(\varepsilon\)-greedy, Boltzmann) → Section 5.1.4
  • Since \(\pi_\theta(a\mid s)\) is differentiable with respect to \(\theta\), we can use the policy gradient. The argmax of the deterministic policy is not differentiable → Section 8.1

6.1.1 ✍ Why Behavior Has Long-Term Effects, and How Immediate Rewards Are Sacrificed

Guide Question:

  1. What does \(a_t\) change other than \(r_t\)? How does that lead to \(r_{t+1},r_{t+2},\dots\)?
  2. If we write “sacrificing immediate rewards” as an equation, what are the short-sighted choice \(\arg\max_ar(s,a)\) and the optimal choice, respectively?
  3. Compare the two choices in the MDP below.

Settings: \(S=\{0,1\}\), \(A=\{\text{stay},\text{move}\}\), \(\gamma=0.9\), Transition is deterministic.

\((s,a)\) \(r\) Next status
\((0,\text{stay})\) 1 0
\((0,\text{move})\) 0 1
\((1,\text{stay})\) 2 1
\((1,\text{move})\) 0 0
NoteSolution

1. \(a_t\) changes the distribution of \(s_{t+1}\) through \(p(\cdot\mid s_t,a_t)\). Since subsequent rewards depend on subsequent states, the effect of \(a_t\) propagates to all future rewards via \(\mu_{t+1},\mu_{t+2},\dots\), as shown in the equation Section 5.1.2.

2. \[ \text{근시안: }\ \arg\max_a\,r(s,a),\qquad \text{최적: }\ \arg\max_a\Big[\underbrace{r(s,a)}_{\text{즉각}}+\underbrace{\gamma\textstyle\sum_{s'}p(s'\mid s,a)\,v^*(s')}_{\text{장기}}\Big]=\arg\max_aQ^*(s,a). \] Even if the immediate term is small, the action is optimal if the long-term term is sufficiently large. The Bellman equation accurately provides this comparison.

3. Repeating stay in state 1 is \(2/(1-0.9)=20\). Since move is \(0.9\,v(0)\le0.9\times20\), stay is better. \(v^*(1)=20\).

In state 0: \[ Q^*(0,\text{stay})=\frac{1}{1-0.9}=10,\qquad Q^*(0,\text{move})=0+0.9\times20=18. \] The short-sighted choice is stay(\(r=1>0\)) and the value is \(10\). The optimal choice is move. We give up the immediate reward \(1\) and receive \(0\), but move to state 1, which has a higher reward, so the value becomes \(18\). \(v^*=(18,20)\).

TipSignificance

This example is also a counterexample to Section 5.1.1. In state 0, it is \(\arg\max_ar(0,a)=\text{stay}\) and \(\arg\max_aQ^*(0,a)=\text{move}\). If the reward is used as a label, incorrect behavior is learned.

6.1.2 Why are MDP problems difficult to solve?

\[ \max_{\pi\in\Pi}\ \mathbb{E}^\pi\Big[\sum_{t=0}^\infty\gamma^tr(s_t,a_t)\Big]. \]

First question to consider. Look at the decision variable, the calculation of the objective function, and the size of the search space, respectively.

Answer. It is triple-layered difficult.

  1. The decision variable is a function. The optimization target is not a number but a policy, that is, a \(S\to A\) (or \(S\to\Delta(A)\)) event. Even when narrowed down to deterministic stationary policies, there are \(|A|^{|S|}\) candidates → Section 4.1.1
  2. A model is required even to calculate a single objective function. The value of a single policy, \(\mathbb{E}^\pi[\cdot]\), is the expected value of the trajectory distribution over an infinite number of time points, and that distribution is defined as \(p\) and \(\pi\). To calculate this, \((I-\gamma P^\pi)v^\pi=R^\pi\) must be solved, and \(p\) is input into it → Section 4.1.2
  3. Scale. Even when solved exactly, the cost is a polynomial with respect to \(|S|\), and \(|S|\) itself is exponential with respect to the state dimension.
TipSignificance

MDP theory solved the difficulty of 1 using the Bellman equation and contraction mapping. Instead of directly exploring the policy space, it found fixed points in the value space. What remains are 2 (model) and 3 (scale), which are exactly the two limits of DP. RL treats 2 as samples and 3 as approximations.

7 IV. RL Problem

7.1 What is an RL problem, and how is it approached?

Answer.

  • Objective: Solve the MDP problem Section 6.1.2 when model \((p,r)\) is unknown.
  • Approach: Trial and error. The agent accumulates experience (data) through actions and gradually updates values or policies using that data. The basic unit of data is the transition sample \((s_t,a_t,r_t,s_{t+1})\).

↓ Down: Section 7.1.1 · Section 7.1.2 ↑ Up: Section 3.1

7.1.1 What is assumed not to be known

Answer. In most cases, it is assumed that only \(p\) is unknown. Since the reward function is designed by the user, it is often known.

However, mathematically, it is possible to handle cases where even \(r\) is unknown. It can be viewed as a black box (e.g., expert scoring) where inputting \((s_t,a_t)\) yields only the signal \(r_t\), and it can be assumed that the signal is contaminated with noise. \[ r_t=r(s_t,a_t)+\eta_t,\qquad\mathbb{E}[\eta_t\mid s_t,a_t]=0. \]

NoteReasoning: Why noisy compensation does not change the problem

The objective function is the expected value. \[ \mathbb{E}^\pi\Big[\sum_t\gamma^t r_t\Big]=\sum_t\gamma^t\,\mathbb{E}^\pi\big[\mathbb{E}[r(s_t,a_t)+\eta_t\mid s_t,a_t]\big]=\mathbb{E}^\pi\Big[\sum_t\gamma^tr(s_t,a_t)\Big]. \] Noise with a conditional mean of \(0\) disappears due to the tower property (assuming the reward is bounded and \(\gamma<1\) allows for an exchange between the sum and the expectation). Therefore, the optimal policy is the same. Noise only slows down learning and does not change the goal.

↑ Go Up: Section 7.1

7.1.2 Why RL is useful and why it is difficult

Answer.

Useful reason Difficult reason
Flexibility: Can be used without model information Limited Knowledge: No model information
Adaptability: Since it does not rely on a fixed model, it can continue to update even if the environment changes Exploration vs. Exploitation: It is unclear what to try → Section 5.1.4
Extensibility: Can be used for large-scale problems because it abandons exact solutions from the start and obtains tractable approximate solutions Bound Representation: It is unclear in what functional form the values and policies of complex problems should be approximated
TipSignificance: Each row of the table is a two-sided representation of the same property.
  • The fact that “there is no model” becomes flexibility on the first line and limited knowledge on the right. It is a double-edged sword.
  • Line 2: Since it does not rely on a fixed model, it can adapt, but that is precisely why you have to decide for yourself what to try.
  • Line 3: Since we chose an approximation, it can be used for large-scale problems, but if the form of the approximation is chosen incorrectly, it cannot even come close to the optimal.

8 V. Algorithm Classification

8.1 What criteria do RL algorithms use for division?

First question to consider. Is the object that the algorithm learns and holds (a) only the value function, (b) only the policy, or (c) both?

Answer. Divide into the relationship between two circles: the set using the value function and the set using the policy.

Classification Training Target Method of obtaining policy Representative
value-based Value function only (\(Q\)) \(\pi(s)\in\arg\max_aQ(s,a)\) (implicit) Q-learning
policy-based policy only (\(\pi_\theta\)) directly parameterize policy policy gradient
actor-critic Both evaluate actor(\(\pi_\theta\)) as critic(value) and update actor-critic
NoteThe reason why value-based learning ZZZPH0014255ZZZ learns \(Q\) instead of \(v\)

Let’s assume that \(v^*\) was trained without a model. To retrieve the policy \[ \pi^*(s)\in\arg\max_a\Big[r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\,v^*(s')\Big] \] From , \(p\) is needed again. If you train \(Q^*\), you can retrieve \(\pi^*(s)\in\arg\max_aQ^*(s,a)\) without a model. The cost is that the training target grows from \(|S|\) to \(|S||A|\).

TipSignificance
  • The subsequent order is value-based (stochastic approximation → TD → Q-learning) → policy-based (policy gradient) → actor-critic.
  • Apart from this classification, there is a model-based / model-free axis. Most model-free methods do not explicitly estimate \(p\) but directly update values or policies.
  • The reason why probabilistic policies are essential in policy-based systems lies in the significance of Section 6.1.
