2 Review: Finite-horizon DP

2.1 Discrete State·Behavior

After initializing \(v_T^*(s) := r_T(s)\), perform backward induction on \(t = T-1, \dots, 0\).

\[ v_t^*(s) := \max_{a\in A}\Big(r_t(s,a) + \sum_{s'} p(s'|s,a)\,v_{t+1}^*(s')\Big),\qquad \pi_t^*(s) \in \arg\max_{a\in A}\Big(\cdots\Big) \]

  • Find the optimal value function and the optimal policy at each time point exactly.
  • There can be multiple optimal policies. This is because there can be multiple argmaxes.
  • Hidden Complexity: For every state, there is a behavior maximization for every operation. If the state and behavior space is large, it does not scale up.

2.2 Extension to continuous control

About \(s_{t+1} = f(s_t, a_t, w_t)\), \(w_t \sim p_w\)

\[ v_t^*(s) := \sup_{a\in A}\Big[r(s,a) + \int_w v_{t+1}^*(f(s,a,w))\,p_w(dw)\Big]. \]

  • Use sup instead of max. An optimal policy may not exist (find the optimal policy only when a maximizer exists).
  • Action maximization is difficult, and since it cannot be evaluated across the entire continuous state space, discretization is involved, leading to scalability issues.

3 Infinite-horizon discounted MDP

3.1 Definition

NoteDefinition (Discounted MDP)

tuple \(\langle S, A, p, r, \gamma\rangle\)

  • \(S\): State set, \(A\): Behavior set
  • \(p(s'|s,a) := \Pr(s_{t+1}=s' \mid s_t=s, a_t=a)\): Probability that the next state is \(s'\) when the current state is \(s\) and the current action is \(a\).
  • \(r(s,a)\): Scalar reward function measuring the gain of the current state/action
  • \(\gamma \in (0,1)\): Discount rate determining how much future rewards will be discounted

3.2 Assumption

  1. Stationary reward and transition probability: \(r(s,a)\) and \(p(s'|s,a)\) do not change over time.
    • In the finite horizon, the reward \(r_t\) could be time-dependent, and the transition probability could also be set to be time-dependent.
    • In the infinite horizon, the function itself does not directly depend on time.
  2. Finite set of states and actions: \((s,a)\). Since the combinations are finite, the rewards are bounded. That is, for some constant \(M\), \(|r(s,a)| < M\), \(\forall s, a\).
  3. Discount: \(0 \le \gamma < 1\).

3.3 Result: Cumulative rewards are always boundless

\[ \Big|\sum_{t=0}^{\infty}\gamma^t r(s_t,a_t)\Big| \le \sum_{t=0}^{\infty}\gamma^t\,|r(s_t,a_t)| \le \sum_{t=0}^{\infty}\gamma^t M = \frac{M}{1-\gamma}. \]

By combining finite states and actions with discounting, any value falls within the same upper bound. It is a neat setup where there is no need to worry about the divergence of cumulative rewards.

4 Value function and stationary policy

4.1 Value function

NoteDefinition (Value function)

\[ v^\pi(s) := \mathbb{E}^\pi\Big[\sum_{\tau=t}^{\infty}\gamma^{\tau-t}\,r(s_\tau,a_\tau)\;\Big|\; s_t = s\Big] \] Expected value of cumulative reward when using policy \(\pi\) starting from state \(s\).

  • Practice until this meaning comes to mind automatically. Intuitive understanding is much more important than mathematical definition.
  • The starting point \(t\) is irrelevant. Since we add up to infinity and shift the discount weight by the starting point, the value is the same regardless of what \(t\) is.
  • If the value function is calculated, the policy evaluation is completed by simply inserting the initial state into the state position.

4.2 Stationary Policy

Generally, the policy is \(\pi := (\pi_0, \pi_1, \pi_2, \dots)\). \(\pi_t\) is the decision rule written at time \(t\), i.e., the state → action transition. In the finite horizon, different optimal decision rules actually emerged at each time step.

A policy being stationary means that the same decision rule is used at every point in time. \[ \pi_i = \pi_j \quad \forall i, j. \]

Since there is no need to distinguish between decision rules and policies, write it simply as follows.

  • Deterministic stationary: \(\pi(s_t) = a_t\)
  • Stochastic stationary: \(\pi(a_t|s_t)\) (Probability distribution of actions by state)
TipQ) If it is a stationary policy, does it perform the same action at every point in time?

No. Although the event is fixed, the input (state) changes at every time step, so the output (action) also changes. Most reinforcement learning algorithms assume a stationary policy. The fact that considering only a stationary policy is sufficient is justified by the existence of an optimal policy].

5 Policy Evaluation: Decomposition of the Value Function

5.1 Bellman expectation equation

Decompose the value function into (i) immediate reward and (ii) discounted next state value.

\[ v^\pi(s) = \mathbb{E}^\pi\big[\underbrace{r(s_t,a_t)}_{\text{즉각 보상}} + \gamma\,\underbrace{v^\pi(s_{t+1})}_{\text{다음 상태의 가치}} \;\big|\; s_t = s\big] = \sum_{a\in A}\pi(a|s)\Big(r(s,a) + \gamma\sum_{s'\in S}p(s'|s,a)\,v^\pi(s')\Big). \]

Since actions are involved in both rewards and transition probabilities, randomized policies take the expected value of actions as the outer sum.

5.2 Proof (tower rule)

\[ \begin{aligned} v^\pi(s) &= \mathbb{E}^\pi\Big[r(s_t,a_t) + \gamma\sum_{\tau=t+1}^{\infty}\gamma^{\tau-t-1}r(s_\tau,a_\tau)\;\Big|\; s_t=s\Big] \\ &= \mathbb{E}^\pi\Big[r(s_t,a_t) + \gamma\,\mathbb{E}^\pi\Big[\sum_{\tau=t+1}^{\infty}\gamma^{\tau-t-1}r(s_\tau,a_\tau)\;\Big|\; s_{t+1}\Big]\;\Big|\; s_t=s\Big] \\ &= \mathbb{E}^\pi\big[r(s_t,a_t) + \gamma\,v^\pi(s_{t+1}) \;\big|\; s_t=s\big] \\ &= \sum_{a}\pi(a|s)\Big[r(s,a) + \gamma\sum_{s'}p(s'|s,a)\,v^\pi(s')\Big]. \end{aligned} \]

  • Line 1: Separate the infinite sum into the \(t\) point term and the \(t+1\) term thereafter.
  • Row 2: Apply conditional expectation to \(s_{t+1}\) one more time (tower rule)
  • Line 3: By definition, the inner part is a value function \(v^\pi(s_{t+1})\) with an initial state of \(s_{t+1}\) (thanks to stationarity)
  • Row 4: The distribution of \(a_t\) is a weighted sum of the distributions of \(\pi\) and \(s_{t+1}\) with transition probabilities

Why use conditional expectation twice? Instead of calculating the total probability all at once, we calculate the expected reward by assuming the next state \(s_{t+1}\) is determined first, and then take the average over the uncertainty of \(s_{t+1}\) itself. This is the intuition behind the tower rule \(\mathbb E[X]=\mathbb E[\mathbb E[X\mid Y]]\). Here, the fact that future rewards can be expressed as a function \(s_{t+1}\) \(v^\pi(s_{t+1})\) is due to Markov properties and a time-independent stationary policy.

TipVerification Question: Why does \(\gamma\) remain only once in the sum?

This is because it was separated into \(\gamma^{\tau-t}=\gamma\cdot\gamma^{\tau-(t+1)}\) in the future reward section. The inner sum becomes \(v^\pi\) ‘starting from the next state’, leaving only one \(\gamma\) for starting one step late.

5.3 What is different from Finite Horizon?

  • There is no concept of time. Since stationary compensation and transitions are assumed, the equation is the same at every time point. The influence of time is hidden within the definition of the value function.
  • Therefore, the calculation method changes. In the finite horizon, since the left side is the value at time \(t\) and the right side is \(t+1\), it was possible to calculate one by one backward from the terminal condition. In the infinite horizon, since the same function \(v^\pi\) exists on both the left and right sides, it is impossible to calculate starting from the terminal point. → A method to “solve” the equation is required.

6 Vector form

If labeled as \(S = \{1,\dots,n\}\), \(A = \{1,\dots,m\}\), it can be written as follows.

Value Vector \[ v^\pi := (v^\pi(1), \dots, v^\pi(n)) \in \mathbb{R}^n \] Original state → value mapping, but since \(s\) can have \(n\) values, the outputs are listed and viewed as a \(n\) dimensional vector.

Expected Reward Vector \[ R^\pi := \Big(\sum_a\pi(a|1)\,r(1,a),\;\dots,\;\sum_a\pi(a|n)\,r(n,a)\Big) \in \mathbb{R}^n \] The element at \(i\) is the expected reward value when using policy \(\pi\) in state \(i\). If deterministic, it is \(R^\pi = (r(1,\pi(1)), \dots, r(n,\pi(n)))\).

Transition Probability Matrix \[ P^\pi_{ij} := \sum_a \pi(a|i)\,p(j|i,a), \qquad P^\pi \in \mathbb{R}^{n\times n} \] The element \((i,j)\) represents the probability that the next state is \(j\) when policy \(\pi\) is applied from state \(i\). If deterministic, it is \(P^\pi_{ij} = p(j|i,\pi(i))\).

Vector Equation \[ \boxed{\,v^\pi = R^\pi + \gamma P^\pi v^\pi\,} \] \(n\) equations are written in a single line, and calculating each element yields exactly the same as the previous equation.

Important\(P^\pi\) is row-stochastic

\(P^\pi_{ij} \ge 0\) and \[ \sum_j P^\pi_{ij} = \sum_a \pi(a|i)\underbrace{\sum_j p(j|i,a)}_{=1} = 1. \] Therefore, \(\|P^\pi\|_\infty = \max_i\sum_j|P^\pi_{ij}| = 1\) and \(P^\pi\mathbf{1} = \mathbf{1}\). Almost all proofs in this text start from this fact.

7 Existence and Uniqueness of Solutions and Inverse Matrix Representation

Since the vector equation is linear, if we simplify it \[ (I - \gamma P^\pi)\,v^\pi = R^\pi. \] The fact that a unique solution exists is equivalent to \(I - \gamma P^\pi\) being reversible.

Noteproposition
  1. The eigenvalues of \(P^\pi\) satisfy \(|\lambda| \le 1\).
  2. \(v = R^\pi + \gamma P^\pi v\) has a unique solution.
  3. That year is \(v^\pi = (I-\gamma P^\pi)^{-1}R^\pi = \sum_{t=0}^{\infty}(\gamma P^\pi)^t R^\pi\).
  4. This method is inefficient for large-scale problems.

The logical structure is as follows. \[ \text{(A)}\ |\lambda| \le 1 \;\Longrightarrow\; \text{(B)}\ I-\gamma P^\pi \text{의 고유값은 } 1-\gamma\lambda \;\Longrightarrow\; \text{(C)}\ 0 \text{은 고유값이 아님} \Rightarrow \text{가역} \]

7.1 (A) Reason why the eigenvalue is 1 or less

Intuition: Continuously multiplying transition probabilities means a continuous multiplication of probabilities. \(P^\pi v\) is the weighted average of the next state values from each state, and since the average cannot exceed the largest value, the magnitude of the vector does not increase. The eigenvalue is “how many times it becomes when multiplied,” so it is \(|\lambda|\le 1\).

Since eigenvalues can be complex numbers, the exact proposition is \(|\lambda| \le 1\).

Proof: Let \(P^\pi v = \lambda v\) and \(v \ne 0\) (\(v\in\mathbb{C}^n\)). If we take \(i^*\), which is \(|v_{i^*}| = \|v\|_\infty > 0\),

\[ |\lambda|\,|v_{i^*}| = \Big|\sum_j P^\pi_{i^*j}\,v_j\Big| \le \sum_j P^\pi_{i^*j}\,|v_j| \le \|v\|_\infty\sum_j P^\pi_{i^*j} = \|v\|_\infty. \]

  • First inequality: Triangle inequality
  • Second inequality: \(|v_j| \le \|v\|_\infty\), \(P^\pi_{i^*j} \ge 0\)
  • Last equal sign: row sum is 1

Since the left side is \(|\lambda|\,\|v\|_\infty\), \(|\lambda| \le 1\). \(\blacksquare\)

Also, since \(P^\pi\mathbf 1 = \mathbf 1\), \(\lambda = 1\) is always an eigenvalue. That is, the upper bound of 1 is actually achieved.

7.2 (B) Eigenvalue of \(I - \gamma P^\pi\)

If \((I-\gamma P^\pi)x = \mu x\) (\(x \ne 0\)), then \(\gamma P^\pi x = (1-\mu)x\), that is \[ P^\pi x = \frac{1-\mu}{\gamma}\,x. \] Therefore, \(\lambda := \frac{1-\mu}{\gamma}\) is the eigenvalue of \(P^\pi\), which is \(\mu = 1 - \gamma\lambda\). Since the same calculation holds for the reverse direction, the eigenvalue of \(I-\gamma P^\pi\) is exactly \(\{1-\gamma\lambda : \lambda \text{는 } P^\pi\text{의 고유값}\}\). (The eigenvectors remain unchanged.)

7.3 (C) Reversibility

The matrix is not invertible \(\iff\) \(Ax = 0\)Z exists \(x \ne 0\) \(\iff\) \(0\) as eigenvalues.

\[ \mu = 1 - \gamma\lambda = 0 \iff \lambda = \frac{1}{\gamma}. \]

If \(0<\gamma<1\), then \(1/\gamma > 1\), but by (A), there is no such eigenvalue. Therefore, \(I-\gamma P^\pi\) is always invertible. Writing it out in one step using the inverse triangle inequality \[ |1-\gamma\lambda| \ge 1 - \gamma|\lambda| \ge 1-\gamma > 0. \]

Condition for the eigenvalue to be 0 Is it possible
\(\gamma<1\) \(\lambda = 1/\gamma > 1\) Impossible
\(\gamma=1\) \(\lambda = 1\) Always available (\(P^\pi\mathbf 1 = \mathbf 1\))

Why \(\gamma < 1\) is important: It pushes \(1/\gamma\) out of the upper bound of eigenvalues 1. Since \(\gamma = 1\) is \((I-P^\pi)\mathbf 1 = 0\), \(I - P^\pi\) must be singular.

7.3.1 Method of appearing without eigenvalues (Norm logic)

If \((I-\gamma P^\pi)x = 0\), then it is \(x = \gamma P^\pi x\) and \(\|P^\pi x\|_\infty \le \|x\|_\infty\), therefore \[ \|x\|_\infty = \gamma\|P^\pi x\|_\infty \le \gamma\|x\|_\infty \;\Longrightarrow\; (1-\gamma)\|x\|_\infty \le 0 \;\Longrightarrow\; x = 0. \] Since the null space is trivial, it is invertible. This calculation is the same as the \(T^\pi\) abbreviated proof that follows.

7.4 Neumann series representation

is the matrix version of the scalar geometric series \(\frac{1}{1-x} = \sum_t x^t\) (\(|x|<1\)).

(a) Convergence. Since \((P^\pi)^t\) is also stochastic, it follows \(\|(\gamma P^\pi)^t\|_\infty = \gamma^t\) and \(\sum_t\gamma^t < \infty\), so it converges absolutely.

(b) The limit is the inverse matrix. For the partial sum \(S_n = \sum_{t=0}^{n-1}(\gamma P^\pi)^t\), by telescoping \[ (I-\gamma P^\pi)\,S_n = I - (\gamma P^\pi)^n \xrightarrow{n\to\infty} I. \] Therefore \(S = \lim S_n = (I-\gamma P^\pi)^{-1}\).

(c) Meaning. By Markov properties, it is \(\mathbb{E}^\pi[r(s_t,a_t)\mid s_0 = i] = ((P^\pi)^t R^\pi)_i\).

  • \(R^\pi\): Expected rewards you are currently receiving
  • \(P^\pi R^\pi\): Expected reward one step ahead
  • \((P^\pi)^t R^\pi\): \(t\) Expected rewards behind the step
  • \(\gamma^t\): Discount to present value

, that is, the series is the sum of the discounted expected rewards of time \(0, 1, 2, \dots\), and is the definition of \(v^\pi\) itself. The inverse matrix formula is a rewriting of the definition in matrix form, and it can be verified that it is consistent with the value function originally intended to be calculated.

7.5 Numerical Example

\(P = \begin{pmatrix}0.5 & 0.5\\ 0.2 & 0.8\end{pmatrix}\), \(\gamma = 0.9\).

  • Eigenvalues of \(P\): trace \(= 1.3\), det \(= 0.3\) → \(\lambda = 1,\ 0.3\)
  • Eigenvalues of \(I - 0.9P\): \(1 - 0.9 = 0.1\), \(1 - 0.27 = 0.73\) → Both are not 0
  • \((I-0.9P)^{-1} = \frac{1}{0.073}\begin{pmatrix}0.28 & 0.45\\ 0.18 & 0.55\end{pmatrix}\)
  • Verification: If \(R = \mathbf 1\), then \(v = \sum_t \gamma^t = 1/(1-\gamma) = 10\). Actually, the sum of each row is \(0.73/0.073 = 10\).

7.6 Why Inverse Matrices Are Not Often Used

The problem of interest usually has a very large number of states.

  • Operational amount: \(n\times n\) Solving linear systems \(O(n^3)\)
  • Memory: \(P^\pi\) stores \(O(n^2)\). If \(n = 10^6\), then \(10^{12}\) elements
  • Even if \(P^\pi\) is sparse, the inverse matrix is generally dense

→ We need a precise method rather than an approximation, but one that avoids the inverse matrix. This is the operator form and fixed-point iteration.

8 Operator Forms and Fixed Point Problems

\[ T^\pi v := R^\pi + \gamma P^\pi v, \qquad (T^\pi v)(s) = \sum_a \pi(a|s)\Big[r(s,a) + \gamma\sum_{s'}p(s'|s,a)\,v(s')\Big]. \]

The policy evaluation equation is \[ \boxed{\,v^\pi = T^\pi v^\pi\,} \] becomes a fixed point problem.

  • I have only rewritten the derived equation, and I have not yet explained how to solve it.
  • Since \(v^\pi\) exists on both the left and right sides, this is the perspective of viewing the entire right side as the output obtained by applying the mapping \(T^\pi\) to \(v^\pi\).
  • This formulation is the idea that forms the basis of value-based RL.
TipLet’s distinguish between \(T^\pi w\) and \(v^\pi\)
  • \((T^\pi w)(s)\) is the result of a one-step update, assuming the current step follows policy \(\pi\) and the value after the next state is input \(w\).
  • \(v^\pi\) is the actual expected cumulative reward when the policy \(\pi\) is used infinitely from the beginning.
  • Therefore, for any \(w\), it cannot be said that \(T^\pi w=v^\pi\). \(T^\pi v^\pi=v^\pi\) holds only when \(w=v^\pi\).

This distinction is key to not confusing the following \(T^{\pi_{k+1}}v^{\pi_k}\) (one new action + future value of existing policy) with policy evaluation \(v^{\pi_{k+1}}\).

9 Contraction Properties and Banach Fixed Point Theorem

9.1 Definition

NoteDefinition (γ-contraction)

The fact that the ||| operator \(T:\mathbb{R}^n\to\mathbb{R}^n\) is a γ-contraction with respect to \(\|\cdot\|\) is \[ \|Tv - Tv'\| \le \gamma\|v - v'\| \qquad \forall v, v' \in\mathbb{R}^n. \]

Intuition: The distance between any two points after passing them through an operator is reduced to \(\gamma\) times less than before. This contractility plays a very important role in reinforcement learning.

9.2 \(T^\pi\) is γ-contraction

Noteproposition

\(T^\pi\) is a γ-contraction with respect to \(\|\cdot\|_\infty\) for any stationary policy \(\pi\).

9.2.1 Intuition: The error is reduced through three steps

What \(T^\pi\) does is “my reward + γ × (average of next state values)”. We only need to track the difference (error between the two estimates \(v, v'\).

Step What happens Effect on error
① Add reward \(R^\pi\) Added equally to both \(v, v'\) Canceled out, no effect
② Average as \(P^\pi\) Probability-weighted average of the next state values Since the average cannot exceed the maximum value, it does not increase
③ Multiply by \(\gamma\) \(\gamma<1\) Reduced by a factor of γ

9.2.2 Induction

Step 1. The reward disappears. \[ T^\pi v - T^\pi v' = \gamma P^\pi(v - v') =: \gamma P^\pi d. \]

Step 2. Look only at one state \(s\). \((\gamma P^\pi d)(s) = \gamma\sum_j P^\pi_{sj}\,d(j)\) is the weighted average of \(d\).

Step 3. The average cannot exceed the maximum value. \[ \Big|\sum_j P^\pi_{sj}\,d(j)\Big| \le \sum_j P^\pi_{sj}\,|d(j)| \le \|d\|_\infty\underbrace{\sum_j P^\pi_{sj}}_{=1} = \|d\|_\infty. \]

Step 4. Attach γ and max for \(s\). \[ \|T^\pi v - T^\pi v'\|_\infty \le \gamma\|v - v'\|_\infty. \qquad\blacksquare \]

It is one line in matrix norms: \(\|\gamma P^\pi d\|_\infty \le \gamma\|P^\pi\|_\infty\|d\|_\infty = \gamma\|d\|_\infty\).

9.2.3 Numerical Example

\(P^\pi = \begin{pmatrix}0.5 & 0.5\\ 0.2 & 0.8\end{pmatrix}\), \(\gamma = 0.9\), \(v = (10, 0)\), \(v' = (0,0)\).

  • Input difference \(d = (10, 0)\), \(\|d\|_\infty = 10\)
  • Average \(P^\pi d = (5, 2)\)
  • \(\gamma P^\pi d = (4.5, 1.8)\) → Output difference \(4.5 \le 0.9\times 10 = 9\)

9.2.4 Supplement

  • Why sup-norm: \(\|d\|_\infty\) is the error of the state with the largest error, and the probability mean cannot increase the largest error. The norm for which \(\|P^\pi\|_\infty = 1\) holds is the \(\infty\)-norm. In the general \(P^\pi\), \(\|P^\pi\|_2\) can exceed 1, so the \(\|\cdot\|_2\) reduction is not guaranteed.
  • Constant γ is tight: If \(d = c\mathbf 1\), then \(P^\pi\mathbf 1 = \mathbf 1\), so equality holds.

9.3 Banach Fixed Point Theorem

NoteBanach fixed point theorem

If \(T:\mathbb{R}^n\to\mathbb{R}^n\) is a contraction concept

  1. \(T\) has the unique fixed point \(v^*\) (\(v^* = Tv^*\)).
  2. Starting from an arbitrary \(v_0\) and defined as \(v_{k+1} := Tv_k\), then \(v_k \to v^*\).

(\((\mathbb{R}^n, \|\cdot\|_\infty)\) is a fully equipped street space.)

Convergence Rate: If the fixed point is \(v^*\), \[ \|v_{k+1} - v^*\|_\infty = \|Tv_k - Tv^*\|_\infty \le \gamma\|v_k - v^*\|_\infty \;\Longrightarrow\; \|v_k - v^*\|_\infty \le \gamma^k\|v_0 - v^*\|_\infty \to 0. \] With each iteration, the distance from the fixed point decreases by a factor of γ, and converges exponentially regardless of where it starts.

Direct Proof of Uniqueness: If there are two fixed points, then \(\|v_1 - v_2\| = \|Tv_1 - Tv_2\| \le \gamma\|v_1 - v_2\|\), so \(\|v_1-v_2\| = 0\).

TipQ) Why is uniqueness important?

If there are multiple fixed points, when a fixed point is reached through iteration, it is impossible to know if it is the true \(v^\pi\) that was intended. Thanks to uniqueness, as long as convergence is achieved, it is guaranteed that the convergence point is \(v^\pi\). This is important not only theoretically but also practically.

Reasons why the fixed point can be called \(v^\pi\): (1) Since the Bellman expectation equation \(v^\pi=T^\pi v^\pi\) was derived from the definition of cumulative reward, \(v^\pi\) is actually the fixed point. (2) By Banach’s theorem, that fixed point is unique. Therefore, the fixed point found through iteration is not another candidate, but exactly \(v^\pi\)**.

Conclusion: The policy evaluation equation has a unique solution, and \(v^\pi\) can be obtained through fixed-point iteration.

Notealgorithm

  • Initialization: \(v_0 \in \mathbb{R}^n\) Random (if continuous, a random function)
  • Repeat until convergence: \(v_{k+1} := T^\pi v_k\)

\[ v_0 \xrightarrow{T^\pi} v_1 \xrightarrow{T^\pi} v_2 \xrightarrow{T^\pi}\cdots \to v^\pi \]

Hidden Complexity: Although written concisely in operator form, in reality, one iteration is completed only after updating all states. If it is a Deterministic policy \[ v_{k+1}(s) = r(s,\pi(s)) + \gamma\sum_{s'}p(s'|s,\pi(s))\,v_k(s') \qquad\forall s. \] However, there is no action maximization. This is because the action is fixed as \(\pi(s)\). Action maximization is added when calculating the optimal value.

10 Optimum Value Function and Bellman Operator

10.1 Optimum value function

The goal is to solve the following problem. \[ \max_{\pi\in\Pi}\;\mathbb{E}^\pi\Big[\sum_{t=0}^{\infty}\gamma^t r(s_t,a_t)\Big] \]

NoteDefinition (Optimal value function)

\[ v^*(s) := \max_{\pi\in\Pi} v^\pi(s) = \max_{\pi\in\Pi}\mathbb{E}^\pi\Big[\sum_{\tau=t}^{\infty}\gamma^{\tau-t}r(s_\tau,a_\tau)\;\Big|\; s_t = s\Big] \] The maximum expected value of cumulative rewards obtainable from the starting state \(s\). Since it is an infinite horizon, the starting point does not matter.

10.2 Bellman operator

Maximize the sum of the immediate reward and the expected cumulative reward from the next state, in accordance with the idea of dynamic programming.

Notedefinition (Bellman operator)

\[ Tv := \max_\pi\{R^\pi + \gamma P^\pi v\},\qquad (Tv)(s) := \max_\pi\sum_{a}\pi(a|s)\Big[r(s,a) + \gamma\sum_{s'}p(s'|s,a)\,v(s')\Big]. \] This can be rewritten as follows. \[ \boxed{\,(Tv)(s) = \max_{a\in A}\Big[r(s,a) + \gamma\sum_{s'}p(s'|s,a)\,v(s')\Big]\,} \]

(In some notations, the Bellman operator is written as \(T^*\). They are the same operator.)

10.3 Q) Why is the maximum for policy the same as the maximum for action?

\[ q_v(s,a) := r(s,a) + \gamma\sum_{s'}p(s'|s,a)\,v(s') \] If we let , then \((T^\pi v)(s) = \sum_a\pi(a|s)\,q_v(s,a)\) is the weighted average of \(q_v(s,\cdot)\). What needs to be proven is \[ \max_\pi\sum_a\pi(a|s)\,q_v(s,a) = \max_a q_v(s,a). \]

(≤) The average cannot exceed the maximum value. For any \(\pi\), since \(\pi(a|s) \ge 0\) \[ \sum_a\pi(a|s)\,q_v(s,a) \le \max_{a'}q_v(s,a')\sum_a\pi(a|s) = \max_{a'}q_v(s,a'). \] No policy can be found that gives a value greater than the maximum for the action.

(≥) A policy exists that achieves the upper bound. If we use the Dirac distribution \(\pi^\delta(a|s) = \mathbb{1}\{a = a^*(s)\}\) which concentrates the probability mass on \(a^*(s) \in\arg\max_a q_v(s,a)\), \[ \sum_a\pi^\delta(a|s)\,q_v(s,a) = q_v(s,a^*(s)) = \max_a q_v(s,a). \qquad\blacksquare \]

The Bellman operator is typically defined and written in a form that maximizes the action \(a\), and most literature follows this convention.

10.3.1 Meaning of vector max

\(\max_\pi\{R^\pi + \gamma P^\pi v\}\) is read as componentwise max.

  • The \(s\)-th element depends only on \(\pi(\cdot|s)\). A policy is a collection of distributions that can be determined independently for each state.
  • Therefore, state-specific maximizations do not interfer with each other.
  • \(\pi^\delta\) One achieves the maximum value simultaneously in all states.

Intuition: Randomly selecting is mixing the values of each action by probability. Since mixing cannot make the result better than the best action, randomness offers no benefit from an optimization perspective. This is the root of the idea that “deterministic optimal policies exist.”

10.4 Affine vs. Nonlinear: Why Inverse Matrices Work Only in Policy Evaluation

  • Policy Evaluation Operator: \(T^\pi v=R^\pi+\gamma P^\pi v\). It is affine with respect to \(v\) and is a linear operator in the strict sense only in the special case where the reward is \(R^\pi=0\). Nevertheless, it is called ‘linear’ in the sense that \(v^\pi=R^\pi+\gamma P^\pi v^\pi\) is a system of linear equations. Therefore, it can be solved as \((I-\gamma P^\pi)^{-1}R^\pi\).
  • Optimal Bellman Operator: \(Tv=\max_a\{r(s,a)+\gamma\sum_{s'}p(s'|s,a)v(s')\}\) is generally non-linear as it involves the maximum value for the action. Therefore, \(v^*\) cannot be directly obtained by moving to a single fixed matrix and taking the inverse.
TipThe single difference between ‘policy evaluation’ and ‘optimization’

If policy \(\pi\) is fixed, the values of the next states are probabilistically averaged. For optimization, a max is added to select the action itself to take that average. The two operators have the same dynamic programming structure, but the meaning of the fixed point is different.

11 The Abbreviation and Monotonicity of the Bellman Operator

Noteproposition

Bellman operator \(T\) is a γ-contraction with respect to \(\|\cdot\|_\infty\). \[ \|Tv - Tv'\|_\infty \le \gamma\|v - v'\|_\infty \qquad\forall v, v'. \] It is also monotone. \[ v \le v' \;\Longrightarrow\; Tv \le Tv'. \] (Inequalities are element-wise, entry-wise)

11.1 Proof of Abbreviation

In a method like \(T^\pi\), an additional step is added to process the max.

Auxiliary Inequality: \[ \Big|\max_a f(a) - \max_a g(a)\Big| \le \max_a|f(a) - g(a)|. \] If we take \(\max_a\) on both sides of \(f(a) \le g(a) + |f(a)-g(a)| \le \max g + \max|f-g|\), we get \(\max f - \max g \le \max|f-g|\). If we swap the roles of \(f, g\), the opposite side also appears.

If you use this \[ |(Tv)(s) - (Tv')(s)| \le \max_a|q_v(s,a) - q_{v'}(s,a)| = \gamma\max_a\Big|\sum_{s'}p(s'|s,a)(v-v')(s')\Big| \le \gamma\|v - v'\|_\infty. \] The last inequality is the weighted average argument. Take the maximum for \(s\) and you’re done. \(\blacksquare\)

11.2 Proof of Monotonicity

If \(v \le v'\), then \(p(s'|s,a) \ge 0\) in each \((s,a)\), so \[ q_v(s,a) = r(s,a) + \gamma\sum_{s'}p(s'|s,a)\,v(s') \le r(s,a) + \gamma\sum_{s'}p(s'|s,a)\,v'(s') = q_{v'}(s,a). \] Taking \(\max_a\) on both sides gives \((Tv)(s) \le (Tv')(s)\). \(\blacksquare\)

For the same reason, \(T^\pi\) is also monotonous (the elements of \(P^\pi\) are \(\ge 0\)).

12 Bellman Equation: Uniqueness and Optimality of Solutions

\[ \text{연산자 형태: } v = Tv, \qquad \text{방정식 형태: } v(s) = \max_{a\in A}\Big[r(s,a) + \gamma\sum_{s'}p(s'|s,a)\,v(s')\Big]. \]

12.1 Q1) Why does it have a unique solution?

Since \(T\) is a γ-contraction, by the first property of the Banach fixed point theorem, it has a unique fixed point. Therefore, \(v = Tv\) has exactly one solution.

12.2 Q2) Why is that year \(v^*\)

Banach’s theorem states only that “there is a unique fixed point.” The key to showing that it is \(v^*\) is the following proposition.

Noteproposition
  • \(v \ge Tv\) if \(v \ge v^*\)
  • \(v \le Tv\) if \(v \le v^*\)

Fact of use:

  • (F1) For all \(\pi\), \(Tv \ge R^\pi + \gamma P^\pi v\) (\(T\) is the maximum for \(\pi\))
  • (F2) Since the element of \(P^\pi\) is \(\ge 0\), \(x \le y \Rightarrow P^\pi x \le P^\pi y\) (preserving inequality direction)

12.2.1 (a) \(v \ge Tv \Rightarrow v \ge v^*\)

Fix an arbitrary \(\pi\). \(v \ge Tv \ge R^\pi + \gamma P^\pi v\) as (F1). If this is substituted recursively, the direction is maintained thanks to (F2). \[ v \ge R^\pi + \gamma P^\pi v \ge R^\pi + \gamma P^\pi(R^\pi + \gamma P^\pi v) \ge \cdots \ge \sum_{t=0}^{n-1}(\gamma P^\pi)^t R^\pi + (\gamma P^\pi)^n v. \] Since \(\|(\gamma P^\pi)^n v\|_\infty \le \gamma^n\|v\|_\infty \to 0\), in \(n\to\infty\) \[ v \ge \sum_{t=0}^{\infty}(\gamma P^\pi)^t R^\pi = v^\pi. \] Since this holds for all \(\pi\), maximizing both sides for \(\pi\) gives \(v \ge v^*\).

12.2.2 (b) \(v \le Tv \Rightarrow v \le v^*\)

The opposite direction appears in the same way as (a), but care must be taken regarding which policy is chosen. If an arbitrary \(\pi\) is used, combining \(v \le Tv\) and \(Tv \ge R^\pi + \gamma P^\pi v\) does not determine the relationship between \(v\) and \(R^\pi + \gamma P^\pi v\). Instead, a policy that achieves \(Tv\) is used.

If we take the greedy policy \(\pi_g(s) \in\arg\max_a q_v(s,a)\) for \(v\), we get \(Tv = T^{\pi_g}v = R^{\pi_g} + \gamma P^{\pi_g}v\). Therefore, it is \(v \le R^{\pi_g} + \gamma P^{\pi_g}v\), and with iterative substitution like (a) \[ v \le \sum_{t=0}^{n-1}(\gamma P^{\pi_g})^t R^{\pi_g} + (\gamma P^{\pi_g})^n v \xrightarrow{n\to\infty} v^{\pi_g} \le v^*. \qquad\blacksquare \]

Visible Usage Policy
(a) All policies are less than or equal to \(v\) Any \(\pi\)
(b) Some policy \(v\) more than greedy policy \(\pi_g\)

12.2.3 Conclusion

The fixed point \(\bar v = T\bar v\) satisfies both \(\bar v \ge T\bar v\) and \(\bar v \le T\bar v\) simultaneously, so it is \(\bar v \ge v^*\) and \(\bar v \le v^*\), i.e., \(\bar v = v^*\).

ImportantCleanup

The Bellman equation has a unique solution, and that solution corresponds to the optimal value function. \[ v^* = Tv^*. \] This is the fundamental theorem of optimal control and reinforcement learning.

Intuition

  • Uniqueness: \(T\) reduces the distance between two candidates, so if there are two solutions, the distance becomes 0 and they become the same.
  • Optimality: \(v \ge Tv\) indicates that “even with a one-step improvement, it cannot exceed \(v\),” meaning that \(v\) is the upper bound of the achievable value. \(v \le Tv\) indicates that “\(v\) is the lower bound of the actually achievable value.” The point where the two meet is \(v^*\).

14 Existence and Configuration of Optimal Policy

ImportantOrganize

If \(S\) and \(A\) are finite sets, an optimal policy exists, among which there is a deterministic and stationary one. Such an optimal policy is obtained as follows. \[ \pi^*(s) \in\arg\max_{a\in A}\Big[r(s,a) + \gamma\sum_{s'}p(s'|s,a)\,v^*(s')\Big] \qquad\forall s\in S. \]

  • The part that is more powerful than determinism is that it is stationary. You can use the same decision rule every time. This theorem explains why you can focus on stationary policies in an infinite-horizon discounted configuration.
  • Construction Method: After obtaining \(v^*\) through value iteration, the action that maximizes the sum of the immediate reward and the next state value is assigned as the policy output, just as the Bellman equation dictates. This is very similar to the Finite Horizon approach.

14.1 Proof

\[ T^{\pi^*}v^* = Tv^* = v^*. \]

  • First equality (by construction): Since \(\pi^*\) contains an action that maximizes what is inside the brackets, applying \(T^{\pi^*}\) is equivalent to applying \(T\). \[ (T^{\pi^*}v^*)(s) = q^*(s,\pi^*(s)) = \max_a q^*(s,a) = (Tv^*)(s). \]
  • Second Equals: \(v^*\) is the only fixed point of \(T\).
  • If we connect the beginning and the end, \(v^*\) is the fixed point of \(T^{\pi^*}\). Since \(T^{\pi^*}\) is also a contraction, it has a unique fixed point, which by definition is \(v^{\pi^*}\). Therefore \[ v^* = v^{\pi^*}. \]
  • If the policy evaluation result of a policy is equal to the optimal value, then that policy is optimal. \(\blacksquare\)

(\(T^{\pi^*}\) is the policy evaluation operator \(T^\pi\), with \(\pi^*\) substituted for \(\pi\), and \(T\) is the Bellman operator that maximizes the action. Do not confuse these two.)

14.2 Proof Method: Constructive Proof + Fixed Point Identification

“By construction”: This means that the property automatically holds because of the way it is defined. Since the property was intentionally included when constructing the object, there is no need to prove it separately. Here, “\(\pi^*\) was made into argmax” is the basis for the first equality.

  • Constructive Proof: To show that something “exists,” the object is directly constructed. Conversely, proof by contradiction or compactness arguments only demonstrate existence without physically holding the object. Since it is a constructive proof, one also obtains an algorithm stating “this is how it can be obtained.”
  • Identifying Fixed Points: Since \(v^\pi\) is the unique fixed point of \(T^\pi\), if we show that a vector is the fixed point of \(T^\pi\), then that vector is \(v^\pi\).

14.3 Points to note

  1. Where finiteness is used: argmax must not be empty to form \(\pi^*\). If \(A\) is finite, the max is always achieved. This corresponds exactly to the fact in continuous control that “without a maximizer, an optimal policy may not exist.”
  2. Simultaneously Optimal in All States: Since \(v^*(s) = \max_\pi v^\pi(s)\) is the maximum value for each state, the optimal policy may differ for each state. This proof shows that a single \(\pi^*\) is simultaneously optimal for all \(s\). This is because state-specific maximizations do not interfere with each other.
  3. Why it is not a circular argument: To create \(\pi^*\), \(v^*\) is required, and \(v^*\) appears to depend on a policy by definition. However, \(v^*\) is first determined without a policy as a fixed point of \(T\), and \(\pi^*\) is created on top of it.
  4. \(\pi_g\), which is the greedy policy \(v = v^*\) written in (b) of the Bellman equation, is \(\pi^*\).

15 Policy iteration

15.1 Idea

Value iteration updates information only in the value space to calculate the optimal value before moving on to the policy space. The ultimate goal is the optimal policy, but can’t we also utilize information from the policy space?

Policy iteration is a method that optimally converges values and policies simultaneously by alternately utilizing information from the value space and the policy space.

15.2 algorithm

NoteAlgorithm (Policy iteration)
  • Initialization: Random deterministic stationary policy \(\pi_0\) (Initialize policy, not value)
  • Repeat until convergence:
    1. Policy Evaluation: Solve the fixed-point problem \(v^{\pi_k} = T^{\pi_k}v^{\pi_k}\) to calculate \(v^{\pi_k}\)
    2. Policy improvement: \[ \pi_{k+1}(s) \in\arg\max_{a\in A}\Big[r(s,a) + \gamma\sum_{s'}p(s'|s,a)\,v^{\pi_k}(s')\Big] \]

The policy enhancement phase assumes that \(v^{\pi_k}\) is the optimal value and adopts the action that maximizes the current reward plus the expected cumulative reward when \(\pi_k\) is used as the new policy.

15.3 Comparison of computational amounts between VI and PI

Where action maximization is Iterative structure
VI Every iteration, all states \(v_{k+1} = Tv_k\)
PI Policy Improvement Phase Only Evaluation (Inner Iteration) + Improvement
  • If you use fixed-point iteration for PI policy evaluation, there will be a lot of iterations inside, and you will have to do it again for every policy.
  • However, there is no action maximization in the iteration of policy evaluation. When comparing the same state updates, a single sweep of policy evaluation is usually lighter than VI. Conversely, PI has the cost of performing policy evaluation multiple times, so the overall superiority of the algorithms cannot be determined.
  • The total computational cost depends on the implementation of policy evaluation (linear system solving or iteration), the number of states and actions, and initialization; therefore, depending on the problem, it is different which approach is faster. For PI, the speed difference is significant depending on whether the initial policy is close to the optimal policy, while for VI, it depends on whether the initial value is close to the optimal value.
  • It is a strong theoretical result that both converge to the optimal value and optimal policy.

16 Monotonal Enhancement Lemma

What does it mean mathematically that “the policy improves”? Policy performance is measured by the cumulative reward expectation \(v^\pi(s)\) across all starting states.

NoteLemma (Monotonic improvement)

For all \(k\) obtained from policy iteration \[ \boxed{v^{\pi_k}(s)\le v^{\pi_{k+1}}(s)\qquad\forall s\in S.} \] This does not mean that ‘policies change strictly,’ but rather that expected cumulative rewards do not worsen in all states. Since values can be the same due to ties, it is \(\le\), not \(<\).

16.1 First to distinguish in the proof: Current policy · New policy · Input value

\[ q_k(s,a)=r(s,a)+\gamma\sum_{s'}p(s'|s,a)v^{\pi_k}(s'). \]

\(q_k(s,a)\) is the expected value when assuming that only the first action from the current state is set to \(a\), and from the next state onwards, the existing policy \(\pi_k\) is followed.

Formula Action used in the first step Standard of value after the first step
\(T^{\pi_k}v^{\pi_k}\) Existing \(\pi_k\) Existing \(v^{\pi_k}\)
\(T^{\pi_{k+1}}v^{\pi_k}\) New \(\pi_{k+1}\) Still Existing \(v^{\pi_k}\)
\(Tv^{\pi_k}\) Maximize all \(a\) Existing \(v^{\pi_k}\)
\(v^{\pi_{k+1}}\) Use the new \(\pi_{k+1}\) forever The actual value of the new policy itself

It is important to note that the first three are a single Bellman update, and the last one is a fixed point for policy evaluation.

16.2 Step 1. Proof that ‘changing only the first step results in no loss’

(a) Policy evaluation — The value of the existing policy is the fixed point of the operator evaluating itself.

\[ \underbrace{v^{\pi_k}}_{\text{기존 정책의 실제 가치}} =\underbrace{T^{\pi_k}v^{\pi_k}}_{\text{기존 정책으로 한 스텝 평가}}. \]

(b) Policy improvement — The new policy selects the action that maximizes \(q_k(s,a)\). Therefore, when the input value is \(v^{\pi_k}\), the following equation holds.

\[ \begin{aligned} (T^{\pi_{k+1}}v^{\pi_k})(s) &=q_k(s,\pi_{k+1}(s)) \\ &=\max_a q_k(s,a) \\ &=(Tv^{\pi_k})(s). \end{aligned} \]

(c) Definition of Bellman operator — The value of an existing action cannot exceed the maximum value among those actions.

\[ T^{\pi_k}v^{\pi_k}\le Tv^{\pi_k}. \]

If you connect the three above in order

\[ \boxed{ v^{\pi_k} =T^{\pi_k}v^{\pi_k} \le Tv^{\pi_k} =T^{\pi_{k+1}}v^{\pi_k} }. \]

Intuition: This means that rather than acting in the existing way, it cannot be a loss to take the best action based on the existing \(v^{\pi_k}\), even if only once.

WarningThe most confusing equation

\(T^{\pi_{k+1}}v^{\pi_k}=Tv^{\pi_k}\) is true because the new policy was chosen greedily with respect to the existing value. However, \(T^{\pi_{k+1}}w=Tw\) is not true for any \(w\). In particular, \(v^{\pi_k}\) and \(v^{\pi_{k+1}}\) must not be swapped arbitrarily.

16.3 Step 2. Extend ‘One Step Improvement’ to ‘Use New Policy Permanently’

If we set it to \(u:=v^{\pi_k}\), \(F:=T^{\pi_{k+1}}\), we obtained \(u\le Fu\) from the front.

  1. Monotonicity: Applying the same operator \(F\) to \(u\le Fu\) results in \(Fu\le F^2u\). Repeat this process.
  2. Coordinateness: The value of continuously applying the operator \(F\) of the new fixed policy goes to the unique fixed point \(v^{\pi_{k+1}}\) of \(F\).
  3. Limits and Inequalities: The \(\le\) relationship that holds in each state also holds in the limit.

\[ \underbrace{v^{\pi_k}}_{u} \le \underbrace{T^{\pi_{k+1}}v^{\pi_k}}_{Fu} \le (T^{\pi_{k+1}})^2v^{\pi_k} \le \cdots \xrightarrow{\ell\to\infty} \underbrace{v^{\pi_{k+1}}}_{\text{새 정책의 실제 가치}}. \]

Therefore \[ \boxed{v^{\pi_k}\le v^{\pi_{k+1}}}\qquad\blacksquare \]

Roles assigned by property in the proof: (i) Maximization shows that there is no loss in the first step, (ii) Monotonicity preserves the direction of the inequality even when the operator is applied multiple times, and (iii) Reducibility guarantees that the limit of the iteration is the value of the new policy.

Tip3 lines of proof framework

\[ \begin{aligned} v^{\pi_k} &=T^{\pi_k}v^{\pi_k}\le Tv^{\pi_k}=T^{\pi_{k+1}}v^{\pi_k},\\ v^{\pi_k} &\le (T^{\pi_{k+1}})^\ell v^{\pi_k}\qquad(\text{monotonicity}),\\ v^{\pi_k} &\le \lim_{\ell\to\infty}(T^{\pi_{k+1}})^\ell v^{\pi_k}=v^{\pi_{k+1}}\quad(\text{contraction}). \end{aligned} \] If you can state the basis for the first equality/inequality/equality, the rest leads to monotonicity and conciseness.

17 Convergence of Policy Iteration

The proposition to be proven is divided into two parts.

  1. Value converges: \(v^{\pi_k}\to\bar v\).
  2. That convergence value is the optimal value: \(\bar v=v^*\), and the greedy policy derived from it is optimal.

Number 2 does not automatically hold true based on number 1 alone. This is because just because the value is stable does not mean it is optimal.

17.1 Monotone convergence theorem

NoteCleanup

A bounded and component-wise monotonically non-decreasing sequence of real vectors \(\{x_k\}\subset\mathbb R^n\) has component-wise finite limits. \[ x_0\le x_1\le\cdots,\quad \sup_k\|x_k\|_\infty<\infty \quad\Longrightarrow\quad x_k\to \bar x. \]

Why does this hold for vectors as well? If \(x_k=(x_k(1),\ldots,x_k(n))\), then it is a sequence of real numbers where each component is bounded above and monotonically non-decreasing over time. This is because the monotonic convergence theorem for real numbers can be applied to each component.

17.2 Summary: Policy iteration reaches the optimal policy

ImportantConvergence of Policy Iteration

In a discounted MDP with finite states and actions, \(0\le\gamma<1\), performing exact policy evaluation and greedy improvement causes \(v^{\pi_k}\) to converge to \(v^*\). For a finite set of deterministically stationary policies, the optimal value is reached with finite improvements. If the existing action is maintained in case of ties and stopped upon reaching the optimal state, the policy itself also stops at the optimal policy.

17.2.1 Step 1. Compensation is bounded → Values of all policies are also bounded

Since \(S,A\) is finite, for all \((s,a)\), we can choose \(M\), which is \(|r(s,a)|\le M\). By \(0\le\gamma<1\)

\[ \begin{aligned} |v^\pi(s)| &=\left|\mathbb E^\pi\!\left[\sum_{t=0}^\infty\gamma^t r(s_t,a_t)\mid s_0=s\right]\right|\\ &\le \mathbb E^\pi\!\left[\sum_{t=0}^\infty\gamma^t |r(s_t,a_t)|\mid s_0=s\right]\\ &\le \sum_{t=0}^\infty\gamma^t M=\frac{M}{1-\gamma}. \end{aligned} \]

Meaning: No matter how the policy changes, the value cannot grow beyond a certain upper limit.

17.2.2 Step 2. Monotonic enhancement + Bounded → Converges to some \(\bar v\)

We have already proven \(v^{\pi_k}\le v^{\pi_{k+1}}\) above. Therefore, by the monotonic convergence theorem

\[ \boxed{v^{\pi_0}\le v^{\pi_1}\le \cdots \to\bar v}. \]

Up to this point, we only knew of the existence of extremes, but did not verify optimality.

17.2.3 Step 3. Key Connection: Why does \(\bar v\) satisfy the Bellman optimality equation?

When policy improvement and monotonic improvement are used together, the following relationship holds.

\[ \begin{aligned} \underbrace{v^{\pi_k}}_{\text{기존 정책의 가치}} &=T^{\pi_k}v^{\pi_k}\\ &\le \underbrace{Tv^{\pi_k}}_{\text{기존 가치에 대한 최적 한 스텝}}\\ &=T^{\pi_{k+1}}v^{\pi_k}\\ &\le T^{\pi_{k+1}}v^{\pi_{k+1}}\\ &=\underbrace{v^{\pi_{k+1}}}_{\text{새 정책의 가치}}. \end{aligned} \]

Reason for each symbol:

  • First equal sign: Policy evaluation, \(v^{\pi_k}\) is the fixed point of \(T^{\pi_k}\).
  • First \(\le\): \(T\) maximizes the action, so it is not smaller than the fixed policy.
  • Second equality: Policy improvement, \(\pi_{k+1}\) is selected greedily with \(v^{\pi_k}\) as input.
  • Second \(\le\): Forward forging improvement \(v^{\pi_k}\le v^{\pi_{k+1}}\) and forging of \(T^{\pi_{k+1}}\).
  • End equal sign: Evaluation equation of the new policy.

In other words, the key inequality is

\[ \boxed{v^{\pi_k}\le Tv^{\pi_k}\le v^{\pi_{k+1}}.} \]

Why is this important? Both ends converge to \(\bar v\). The middle \(Tv^{\pi_k}\) also converges to \(\bar v\) by the Sandwich Theorem. Meanwhile, \(T\) is a contraction, so it is continuous. Therefore

\[ \begin{aligned} \lim_{k\to\infty}Tv^{\pi_k}&=\bar v &&(\text{샌드위치 정리}),\\ \lim_{k\to\infty}Tv^{\pi_k}&=T\!\left(\lim_{k\to\infty}v^{\pi_k}\right)=T\bar v &&(\text{$T$의 연속성}). \end{aligned} \]

If you compare the two expressions

\[ \boxed{\bar v=T\bar v.} \]

Since we previously showed that the Bellman optimality operator \(T\) has exactly one fixed point, and that it is \(v^*\),

\[ \boxed{\bar v=v^*.} \]

This is the core logic that bridges the gap between ‘simply converged’ and ‘converged to the optimal value’.

17.2.4 Step 4. Create the actual optimal policy from the converged value

Let’s construct a greedy policy \(\bar\pi\) using the limit \(\bar v\).

\[ \bar\pi(s)\in\arg\max_a\left[r(s,a)+\gamma\sum_{s'}p(s'|s,a)\bar v(s')\right]. \]

Because \(\bar\pi\) was configured like this, regarding \(\bar v\)

\[ \underbrace{T^{\bar\pi}\bar v}_{\text{greedy 행동으로 한 스텝}} =\underbrace{T\bar v}_{\text{행동 최대화}} =\underbrace{\bar v}_{\text{Step 3에서 구한 고정점}}. \]

Therefore, \(\bar v\) is also the fixed point of \(T^{\bar\pi}\). However, since the only fixed point of \(T^{\bar\pi}\) is \(v^{\bar\pi}\),

\[ \boxed{v^{\bar\pi}=\bar v=v^*.} \]

Therefore, \(\bar\pi\) is the optimal policy. \(\blacksquare\)

WarningPay attention to the order of the equation chain

If you compress this step into a single line \[ v^{\bar\pi}=T^{\bar\pi}\bar v=T^{\bar\pi}v^{\bar\pi}=Tv^{\bar\pi} \] I am tempted to write it like . However, the first equation \(v^{\bar\pi}=T^{\bar\pi}\bar v\) does not hold simply because \(\bar\pi\)Z was defined greedily. We must show \(\bar v=v^{\bar\pi}\) before it.

Therefore, when writing strictly, in Step 3 above, first prove \(\bar v=T\bar v\), and then \[ \boxed{T^{\bar\pi}\bar v=T\bar v=\bar v=v^{\bar\pi}} \] It is safer to understand it by changing the order to . The idea is the same, but it is arranged so that the basis for each equation is already secured in the previous step.

17.3 Why does it finish in a finite number of moves? (Using a finite policy set)

The proof up to this point has demonstrated the convergence and optimality of the value sequence. We can go a step further regarding the policy iteration of a finite MDP.

  1. If the number of states is \(n\) and there are at most \(m\) actions per state, then there are at most \(m^n\) deterministic stationary policies. Therefore, the number of possible \(v^\pi\) vectors is also finite.
  2. \(v^{\pi_k}\) takes only a finite set of values while being monotonically non-decreasing. Therefore, at some point, two continuous values become equal: \(v^{\pi_{K+1}}=v^{\pi_K}\).
  3. If both ends are the same in the sandwich relationship of Step 3 \[ v^{\pi_K}\le Tv^{\pi_K}\le v^{\pi_{K+1}}=v^{\pi_K} \quad\Rightarrow\quad v^{\pi_K}=Tv^{\pi_K}=v^*. \]
  4. Therefore, \(\pi_K\) is already the optimal policy, and it reaches the optimal value with a finite number of exact improvements. Even if there is a tie in the optimal actions, maintaining the existing action and stopping at the optimal state guarantees the convergence (stopping) of the policy itself.

Caution: If implemented to continuously switch to a different optimal action instead of the existing one in case of a tie, oscillation between different optimal policies may occur even in the state \(v^{\pi_k}=v^*\). Therefore, strictly speaking, value convergence and policy sequence convergence must be distinguished, and tie-breaking/termination conditions must be specified when referring to the cessation of a policy sequence.

17.4 Proof 6-Line Summary

  1. Limited rewards and discounts: \(|v^\pi(s)|\le M/(1-\gamma)\).
  2. Forging Enhancement: \(v^{\pi_k}\le v^{\pi_{k+1}}\).
  3. Monotonic convergence: \(v^{\pi_k}\to\bar v\).
  4. Enhancement definition + operator monotonality: \(v^{\pi_k}\le Tv^{\pi_k}\le v^{\pi_{k+1}}\).
  5. sandwich + \(T\) continuity: \(\bar v=T\bar v\); with fixed point uniqueness \(\bar v=v^*\).
  6. The greedy policy \(\bar\pi\) for \(\bar v\) satisfies \(T^{\bar\pi}\bar v=T\bar v=\bar v\), so it is \(v^{\bar\pi}=v^*\), which is the optimal policy.

18 Numerical Example: VI and PI Comparison

state \(\{1,2\}\), action \(\{a,b\}\), \(\gamma = 0.9\).

  • Action \(a\): Stay in the current state. Action \(b\): Change state.
  • Reward: \(r(2,a) = 1\), remainder 0.

Optimal Solution: If we continue writing \(a\) in State 2, we get \(v^*(2) = \frac{1}{1-0.9} = 10\); if we go from State 1 to State 2 with \(b\), we get \(v^*(1) = 0 + 0.9\times 10 = 9\). That is, \(v^* = (9, 10)\), \(\pi^* = (b, a)\).

  • \(v^{\pi_0} = (0,0) \le v^{\pi_1} = (0,10) \le v^{\pi_2} = (9,10) = v^*\): Check for forging improvement.
  • Repeating \(T^{\pi_1}\) from \(k=0\) results in \((0,0) \le (0,1) \le (0,1.9) \le (0,2.71) \le \cdots \to (0,10)\). One step gain (\(0\to1\)) accumulates to become the total gain (\(0\to10\)).

Since \(\|v_k - v^*\|_\infty \le 0.9^k\times 10\), the error decreases exponentially, but in this example, PI, which performed accurate policy evaluation, reached the optimal state with 3 policy evaluations, whereas VI converges asymptotically. However, since each policy evaluation of PI requires internal calculation, it cannot be concluded from this single example that the overall execution time of PI is faster.

TipQ) Which one should I use?

There is no single correct answer. You have to try both to know for sure. There is a significant performance difference depending on how well the initialization is performed. If the VI happens to be initialized near \(v^*\), it converges within a few iterations, and if the PI happens to be initialized near \(\pi^*\), the PI also converges quickly. However, since the optimal value or the shape of the optimal policy cannot be known in advance, it is difficult to perform good initialization.

  • In actor-critic, the actor plays the role of policy improvement, and the critic plays the role of policy evaluation. Actor-critic can be viewed as a model-free version of policy iteration (although there are differences in details and techniques).
  • Here, the ‘root’ refers to a connection at the idea level. This does not mean that each algorithm is the exact same mathematical procedure as VI·PI.
TipQ) Why can’t VI or PI be applied directly to RL?

VI and PI assume that model information, specifically the transition probabilities \(p(s'|s,a)\), is perfectly known. In RL, only state and reward samples are obtained through trial and error, and the transition probabilities are not directly known. Therefore, VI was transformed into Q-learning and PI into actor-critic by changing them to a model-free approach.
