From the Evolution of CNNs to Sequence Modeling: History, Architecture, and RNN

CNNs, ViT/gMLP, and RNNs as Dynamical Systems in the ImageNet Era

Published

April 20, 2026

1 Overview

This note covers two major currents. The first is the later part of CNN, summarizing the extensions of convolutional operations (dilated/transposed convolution, separable/group convolution), the lineage of architectures that ushered in the ImageNet era (LeNet → AlexNet → GoogLeNet → ResNet), and the post-CNN paradigms: Vision Transformer (ViT) and gMLP. The second is sequence modeling, deriving RNNs from the perspective of dynamical systems for handling variable-length data, explaining why long-term dependency learning is difficult using eigenvalue decomposition, and extending to gating (LSTM/GRU), bidirectional, and Seq2Seq.

The core message running through the two topics is summarized in the following single line.

“By encoding the structural invariance of the data into the model’s weight sharing, efficient representation learning is possible with fewer parameters.”

CNNs assume spatial stationarity, while RNNs assume temporal stationarity. Both are essentially the same idea in that they “repeatedly apply the same function over time/location.”

TipThe Big Picture from a Wireless Communication Perspective
  • CNN weight sharing = shift-invariant filter.
  • RNN = state-space model driven by external input. A one-step recursive operation is effectively an IIR filter (infinite impulse response with feedback), and a sliding window (moving average) is an FIR filter.
  • As we will see later, the vanishing/explosion of gradients in RNNs is exactly the same mathematics as the stability of discrete-time LTI systems (inside/outside the unit circle of poles).

2 CNN Latter Half: Expansion and Transformation of Convolution

2.1 Dilated(atrous) convolution

One-line summary: Applies by “skipping” kernel elements at regular intervals to increase the receptive field without increasing the number of parameters.

  • It is similar to stride but different. Stride creates output spaced out, while dilation spaced out inside the kernel.
  • The number of skipped points is called the dilation rate \(d\). If \(d=2\), a single empty space is placed between kernel elements.
  • Effective kernel size: \(k_{\text{eff}} = k + (k-1)(d-1)\). That is, if the \(3\times3\) kernel is written as \(d=2\), the effective size is \(5\times5\), but the training parameters are still 9.

\[ y[i] = \sum_{m} x[i + d\cdot m]\, w[m] \]

2.2 Transposed convolution (a.k.a. deconvolution)

One-line summary: The name “deconvolution” is misleading. It is not an inverse operation but a transposed convolution, and it is used to upsample the resolution.

  • The operation itself is identical to convolution (multiplication and addition). However, the spatial relationship between the input and output is reversed.
  • This has a different meaning from the deconvolution discussed in Signals and Systems (430.306). Here, it is accurate to understand that the transpose \(C^\top\) of the convolution matrix \(C\) is applied.

\[ \underbrace{\mathbf{y} = C\,\mathbf{x}}_{\text{conv (downsample)}} \qquad\Longleftrightarrow\qquad \underbrace{\mathbf{z} = C^{\top}\mathbf{u}}_{\text{transposed conv (upsample)}} \]

Where is it used? Tasks requiring pixel-level prediction. Typically, it is used to restore downsampled feature maps to their original resolution during semantic segmentation in FCN (Fully Convolutional Network).

NoteWireless communication analogy — Transformed convolution = Interpolation filter

The preconvolution has the same structure as an interpolation filter bank that inserts zeros (zero-insertion / upsampling) into a downsampled signal and passes it through a filter. If convolution is decimation, then preconvolution is interpolation.

2.3 Efficient Convolution: Separable / Group Convolution

One-line summary: Reduces the number of multiplications and parameters by breaking down standard convolution into the product of smaller operations.

  • Separable convolution: \(k\times k\) Decomposes a 2D kernel into successive applications of \(k\times1\) and \(1\times k\) (assuming rank-1). The computational load is reduced from \(O(k^2)\) to \(O(2k)\).
    • depthwise-separable goes a step further and decomposes into (channel-wise spatial convolution) + (1×1 point-wise convolution) (the core of the MobileNet family).
  • Group convolution: Divides input channels into \(g\) groups and performs convolution only within each group. Advantageous for parallelization and reduces parameters to \(1/g\) (AlexNet’s 2-GPU split is the origin).
NoteWireless communication analogy — separable filter = separable kernel

It is exactly the same idea as separable filters in 2D image processing (e.g., decomposing Gaussian blur into row and column filters). If rank-1 approximation holds, 2D filters can be represented by a pair of outer products, which drastically reduces multiplication costs.

  • AlphaGo Input: Stack a Go board \(19\times19\) grid with multiple feature planes \([X_t, Y_t, X_{t-1}, Y_{t-1}, \dots, C]\) and feed it into a CNN.

2.5 Random/Unsupervised Filters, and Biological Evidence

  • CNN filters are usually trained on supervised signals, but random filters also work surprisingly well (Jarrett 2009; Saxe 2011 et al.). This suggests that the convolutional structure itself is a good inductive bias.
  • A representative example of learning filters in an unsupervised manner is contrastive learning: patches from the same image are designated as positive pairs, and patches from different images are designated as negative pairs.
  • Neuroscientific Basis: CNN computation resembles processing in the primary visual cortex (V1). The simple cells of V1 correspond to the linear filters of the CNN, and the complex cells correspond to the pooling units. It is also interesting that the learned CNN filters appear similar to the Gabor filters of V1.

3 ImageNet Era and Architecture Genealogy

3.1 ImageNet: Renaissance Trigger

One-line summary: The emergence of large-scale labeled datasets was the decisive catalyst for the resurgence of CNNs.

  • Built by Fei-Fei Li at Princeton in 2009 (inspired by WordNet). Total 14 million images / 24,000 categories.
  • A widely used challenge subset in practice is ImageNet-1K: 1.2 million images / 1,000 categories. The standard benchmark for large-scale image classification.
  • Performance trend: Gradual improvement from an error rate of about 35% (accuracy ~64%) around 2009 to about 27–28% in 2011. A large gap still remained.

LeNet (1998). The first practical CNN proposed by Yann LeCun for handwritten digit recognition.

AlexNet (2012). Krizhevsky et al., “ImageNet Classification with Deep Convolutional Neural Networks”, NIPS 2012.

  • Structure: 7 layers (5 convolutional + 2 fully connected), similar to LeNet but trained on GPU with 1,000 categories.
  • Performance: Error rate 16% — A decrease of about 10 percentage points compared to the previous year. This leap became the “implicit starting point” of the deep learning renaissance.

GoogLeNet (2014). Google. Over 100 layers, trained for over a week on a high-performance GPU. The middle capital L of the name is an homage to LeNet.

ResNet (2015). Microsoft Research Asia, Kaiming He et al., CVPR 2016.

  • Stacked from floor 152 to 1,001 using residual / highway connection. Yann LeCun described it as “ultra deep”.
  • Key Point: Creates a path for the gradient calculated in the final layer to propagate forward as is without interference from intermediate layers, thereby mitigating gradient vanishing. (This idea is directly connected to the following Section 8.)
  • Result: Breaks human performance (error rate about 5%) on ImageNet-1K for the first time.
WarningThe Trap of the Expression ‘Transcending Humanity’

One of the reasons ResNet outperformed humans on ImageNet-1K is that this dataset contains many fine-grained dog breed classes. While humans find it difficult to distinguish between Golden Retrievers and other similar breeds, the model can focus on minute differences in texture, face, and shape.

Therefore, the generalization that “deep learning has surpassed humans in object recognition” is misleading. Each benchmark has its own inherent biases and preferences. It should be taken as a narrow statement indicating superiority “compared to other specific algorithms on a specific benchmark.”

4 Next CNN: Transformer, ViT, gMLP

4.1 Transformer and Vision Transformer

One-line summary: ViT (Dosovitskiy et al., “An Image is Worth 16×16 Words”, ICLR 2021) is the application of the Transformer (Vaswani et al., “Attention Is All You Need”, 2017), which originated in NLP, to images.

  • Core Concept: View the image as a sequence of patches. Tokenize each patch like a “word” and encode contextual information between tokens as attention.
  • ViT is not an approach intended to “beat” CNNs, but rather one that encodes the same information using a different type of operation.

4.2 ViT vs CNN: The trade-off between layers and parallelism

One-line summary: ViT has a much smaller number of layers (e.g., ~32 layers), but the computation of each layer is more complex. The smaller number of layers is an advantage in parallelization and energy efficiency.

The core logic is as follows.

  1. ResNet stacks up to 152 layers, whereas ViT-L achieves similar performance with about 32 layers.
  2. Since complex operations including attention (equivalent to multiple CNN layers) are packed into a single layer, there is no “free lunch” — the computational cost per layer is high.
  3. However, layers are cascade. The operation of the next layer does not begin until the previous layer is finished. Therefore, the fewer the number of layers, the less serial dependency there is in the depth direction, which is advantageous for parallelization.
  4. As a result, the more GPUs there are, the better the time efficiency of ViT, and the overall energy consumption tends to decrease due to the reduction in the number of layers.

\[ \text{총 지연} \;\approx\; \underbrace{L}_{\text{직렬(층수)}}\times \underbrace{(\text{층당 계산}/P)}_{\text{병렬화 가능}},\qquad P=\text{병렬 자원} \]

Calculation per floor can be reduced by dividing by \(P\), but the number of floors \(L\) cannot be divided because it is serial. Therefore, reducing \(L\) is the key to reducing latency.

NoteWireless communication analogy — Serial vs Parallel processing

This is equivalent to making each stage heavier in a multi-stage receiver while reducing the number of stages. The number of stages (serial depth) determines pipeline latency, and internal stage operations can be parallelized across multiple processing cores. This is a typical trade-off for latency optimization relative to throughput.

4.3 gMLP and Multimodality

  • gMLP (Liu et al., “Pay Attention to MLPs”, NeurIPS 2021): It is argued that the advantage of ViT comes not from attention itself, but from the channel-wise projection + spatial gating + normalization and activation structure. Although it showed similar performance with a simpler structure, it is not yet as widely used as attention.
  • Multimodality: By simply converting inputs into tokens, the same Transformer structure can be used for text, video, and audio (spectrograms). Thanks to this homogeneity, NVIDIA has implemented Transformer operations in hardware (Transformer Engine), thereby increasing time and energy efficiency.

4.4 CNN Summary

ImportantCNN Key Summary
  • CNNs efficiently encode 2D information. Unlike MLPs that learn every location independently, CNNs share weights using spatial stationarity → enabling training with fewer parameters and fewer training samples.
  • Components: Convolutional Layer (Stationality Assumption) + Pooling Layer (Discarding Local Noise/Redundant Information) + MLP (Final Semantic Extraction/Classification).
  • When the convolutional layer compresses the input into a compact representation, the MLP above it handles regression/classification.
  • Currently, in many 2D encoding tasks, Vit is replacing CNN (due to computational efficiency, parallelism, and multimodality). However, in some applications, CNN-type architecture still holds an advantage.

5 Sequence Modeling: Motivation and Challenge

5.1 Three representative applications

Field Project Representative Example
Computer Vision Image/Video Analysis YOLO (Object Detection)
Natural Language Processing Text Analysis GPT
Speech Recognition Human Speech Recognition Amazon Echo

All three fields ultimately require sequence modeling. Text is a sequence of words, speech is a sequence of waveforms, and video is a sequence of frames.

5.2 Snapshot data vs Sequence data

What we have covered so far is fixed-length “snapshot” data (images, graphs, objects). What we will now deal with is variable-length data.

  • Language (Text), Stock Price (Time), Video, Audio
  • Key difference: Input length cannot be known in advance → An encoding capable of handling variable lengths is required.

5.3 Key Challenge: Long-term Dependence

Two fundamental challenges in sequence modeling:

  1. Variable Length Handling. Since the length changes every time, the same model must be used to receive various lengths.
  2. Memory over time (long-term dependency). This is a bigger challenge. Past context must be maintained until a conclusion is reached, but neural networks are weak at time-series memory.

Why is it difficult? This is because gradients propagating through multiple steps are mostly vanished or rarely explode (explosions are rare but cause significant damage to optimization).

NoteLimitations of Video Understanding — Specific Examples

Let’s assume that in a 5-minute video, a scene of a boy kicking a ball appears for about 5 seconds. If asked, “What is this boy doing?”, the model is prone to giving inaccurate answers such as “he is holding the ball” or “he is dribbling.” It needs to temporally integrate 5 minutes × 30 fps = approximately 9,000 frames to remember key moments, but current models do not propagate this temporal integration well. Video comprehension remains an open research topic.

TipModern Bypass — KV Cache and Long Context

Since “remembering over time” is not done properly, a workaround is used instead to store all past tokens as input.

  • LLM handles long system prompts in addition to user input (e.g., “No aggressive expressions”, etc.).
  • Past tokens are stored in the key-value cache for reuse. Processable contexts have been expanded from 20,000 tokens to over 128,000 tokens.
  • This is essentially a strategy of “abandoning temporal memory and storing it as input.” Recently, research on compressing these tokens (e.g., Google’s Titans series) has been active.
  • If you create a really good time memory architecture — that is a big unsolved problem.

6 RNN as a Dynamical System

6.1 Classical dynamical system

One-line summary: An RNN is a neural network implementation of a “system whose state evolves over time.”

The simplest dynamical system without external input:

\[ s^{(t)} = f\!\left(s^{(t-1)};\, \theta\right) \]

  • \(s^{(t)}\): System state at time \(t\).
  • Given an initial state, the system takes itself as input and updates the state.
  • When unfolded in time, it becomes the function composition of \(s^{(t)} = f(f(\cdots f(s^{(0)})\cdots))\).

6.2 System driven by external input

When external signal \(x^{(t)}\) drives the system:

\[ s^{(t)} = f\!\left(s^{(t-1)},\, x^{(t)};\, \theta\right) \]

Now, the state \(s^{(t)}\) contains information of the entire past sequence. An RNN is implemented by naming this state the hidden state \(h^{(t)}\).

\[ \boxed{\,h^{(t)} = f\!\left(h^{(t-1)},\, x^{(t)};\, \theta\right)\,} \]

NoteWhy is it in a ‘hidden’ state?

The user provides input \(x\) and receives only the output. The state \(h\) is located inside the system and is not directly visible to the user, so it is called the “hidden” state. The notation also uses \(h^{(t)}\) for hidden, rather than \(s\) for state.

6.3 Definition of RNN and Input/Output

  • Input: Current time data \(x^{(t)}\) and past hidden state \(h^{(t-1)}\).
  • Output: Current time model output \(o^{(t)}\) and hidden state to pass to next time \(h^{(t)}\).

6.4 One-step RNN: Filter perspective

Comparing the three operations reveals the true nature of the RNN.

operation expression nature
Memoryless \(f(x_t)=w x_t + b\) No memory
Sliding Window (Moving Average) \(f(x_t,x_{t-1})=w_1 x_t + w_2 x_{t-1} + b\) FIR (Finite Memory)
One step cycle \(f(x_t,x_{t-1})=w_1 x_t + w_2\,f(x_{t-1},x_{t-2}) + b\) IIR (Feedback, Infinite Memory)

Vanilla RNN cells are usually written as follows (the activation function is \(\tanh\)).

\[ h^{(t)} = \tanh\!\left(W_{hh}\,h^{(t-1)} + W_{xh}\,x^{(t)} + b\right), \qquad o^{(t)} = W_{ho}\,h^{(t)} + c \]

TipWireless communication analogy — RNN = IIR filter/state-space model
  • Acyclic → Memoryless channel.
  • Moving Average → FIR Filter: The output is a weighted sum of a finite number of past inputs. Always stable.
  • One step cycle → IIR filter: There is self-feedback at the output, so the impulse response continues indefinitely. Due to this feedback, stability (eigenvalues/pole locations) becomes an issue — this is the very source of gradient vanishing/explosion (Section 8).
  • The hidden state of the RNN \(h^{(t)}\) acts as the state estimate of the Kalman filter, or the accumulated state of the channel.

6.5 Two advantages of circular structures and their assumptions

  1. Variable Length Independence: Regardless of sequence length, the input size of the trained model is always the same (\(x^{(t)}\)). The same RNN is applied repeatedly whether it is \(n-1\) or \(n+\delta\).
  2. Parameter sharing: At every time, the same parameters \(f\) and the same transition function \(\theta\) are used. This is the temporal stationarity assumption corresponding to the spatial stationarity of CNNs.
WarningTemporal stationarity is a strong assumption

Applying the same function to every time step assumes that the sequence is temporally stationary. However, what one sentence says may differ from what the next sentence says—that is, the data generation distribution changes over time (non-stationary). Since the same transition function is used despite this, a violation of assumption occurs. This is one reason why vanilla RNNs cannot encode long sequences of words well.

Wireless Communication Perspective: The LTI filter was designed under the assumption of WSS (wide-sense stationary), but this is equivalent to a situation where the actual channel is time-varying. If stationarity is broken, a single time-invariant filter is insufficient.

7 Three types of RNNs

Various RNNs can be designed using a recurrent structure.

7.1 Type 1: Hidden-hidden cycle

Outputs at every time and has circular connections between hidden units. The most standard form.

\[ \begin{aligned} h^{(t)} &= \tanh\!\left(W_{hh}h^{(t-1)} + W_{xh}x^{(t)} + b\right)\\ o^{(t)} &= W_{ho}h^{(t)} + c \end{aligned} \]

Outputs both the output and the hidden state at each time step, and the hidden state propagates over time. Use this type if you need a result at each time step.

7.2 Type 2: Output→Hidden forcing (Teacher forcing)

Output is generated at every time step, but circular connections go only from the output to the next hidden unit (no hidden-hidden direct connections).

  • Advantages: Training parallelization is easy. Without needing to wait for hidden states in series, the loss for the output at each time step can be calculated almost immediately, allowing for parallelization of time-by-time training and subsequent aggregation of weights.
  • Disadvantage: Due to the lack of direct hidden-hidden connections, it forgets more past information (less powerful). Since the hidden state estimated in the output is inaccurate, accuracy is lower than Type 1. (Computational gain translates into a loss of accuracy.)

Training vs. Inference Asymmetry:

\[ \underbrace{\text{Training: } h^{(t)} \leftarrow y^{(t)}\ (\text{정답 라벨})}_{\text{병렬화 용이}} \qquad \underbrace{\text{Inference: } h^{(t)} \leftarrow o^{(t)}\ (\text{모델 출력로 근사})}_{\text{정답 미지}} \]

  • During training: Feed the correct answer output \(y^{(t)}\) as input to the next hidden state (teacher forcing). Since the correct answer is provided, parallel learning is possible by separating by time.
  • During inference: Since the correct answer is unknown, approximate it with the model output \(o^{(t)}\) and feed it back into the model.
NoteRadio communication analogy — Decision return equalizer (DFE)

The structure of feeding back its own output during inference resembles the Decision-Feedback Equalizer. During training, it feeds back the correct answer (pilot/training sequence), but during operation, it feeds back its own judgment value. It even shares the same disadvantage that judgment errors can accumulate and propagate.

7.3 Type 3: Entire sequence → Single output

It has a hidden-hidden circular connection, but reads the entire sequence and produces only a single output at the end. The rest of the structure is similar to Type 1.

  • Standard choice for sequence modeling. Example: Question Answer (QA). Encode all words of the question “Who is the current President of the United States?” and provide the answer at the end of the sentence without intermediate output.
  • Finally, calculate the correct label and loss and train using Time Backpropagation Toward (BPTT).
  • However, since hidden state information must be propagated to the end, information is frequently lost → This becomes a motivation for external memory/gating (Section 9.1).

7.4 Comparison of three types

8 Why Long-Term Dependency Learning Is Difficult

8.1 Function Composition and Amplification of Nonlinearity

One-line summary: Even a simple non-linear function becomes extremely non-linear when composed multiple times.

When a very simple non-linear function \(f\) is applied once, it forms a smooth curve, but as it is synthesized two, three, …, ten times (\(f\circ f\circ\cdots\circ f\)), the ridges in the middle increase sharply. For a 10-word sentence, \(f\) is synthesized 10 times, and for a 300-word paragraph, it is synthesized 300 times. As a result, the function encoded by the RNN becomes an extremely complex and torsion-driven function, making optimization difficult.

\[ h^{(t)} = \underbrace{f\circ f \circ \cdots \circ f}_{t\text{ 번}}\,(h^{(0)}) \]

8.2 Eigenvalue Decomposition and Unit Element

In the linear approximation (or the core part ignoring the activation function), if we view the transition between time \(t-1\) and \(t\) as \(h^{(t)} \approx W\,h^{(t-1)}\),

\[ h^{(t)} = W^{t}\,h^{(0)}. \]

If we perform eigenvalue decomposition of \(W\) \(W = Q\,\Lambda\,Q^{-1}\),

\[ W^{t} = Q\,\Lambda^{t}\,Q^{-1}, \qquad \Lambda^{t} = \operatorname{diag}(\lambda_1^t, \dots, \lambda_n^t). \]

Therefore, the magnitude of the eigenvalue dominates the behavior.

\[ \boxed{\;|\lambda_i| < 1 \;\Rightarrow\; \lambda_i^t \to 0\ (\text{소실}) \qquad |\lambda_i| > 1 \;\Rightarrow\; |\lambda_i^t| \to \infty\ (\text{폭발})\;} \]

When synthesized 300 times, values slightly less than 1 rapidly converge to 0 (gradient vanishing), and values slightly greater than 1 run wild (gradient explosion). As a result, the loss surface drops/rises like a cliff, making optimization unstable. If MLPs are stacked further as layers (deep RNN), the gradients already vanished in a single step worsen, rendering the deep RNN virtually useless.

ImportantWireless communication analogy — Stability of discrete-time LTI systems (exactly the same mathematics)

This is literally the same result as BIBO stability of discrete-time LTI systems.

  • Eigenvalues of the state transition matrix \(W\) = poles of the system.
  • All poles are inside the unit circle(\(|\lambda|<1\)): Impulse response damps exponentially → stabilizes, but the influence of the distant past disappears (= gradient vanishing).
  • Poles are outside the unit circle(\(|\lambda|>1\)): Response diverges → instability (= gradient explosion).
  • Long-term memory and stability coexist only at the boundary (\(|\lambda|=1\)), but maintaining this boundary precisely is very difficult.

In other words, wanting “long-term memory” is like trying to place the system on the edge of stability (\(|\lambda|\approx 1\)). Gating (Section 9.1) can be understood as a mechanism that adaptively shifts this pole to near 1 depending on the data.

Another limitation is memory capacity. Since the entire past is typically compressed into a single vector using only one or a few cells/gates, it is insufficient to hold all long time-series information.

9 Solutions

Five ideas for dealing with long-term dependency.

  1. Time-spanning skip connection
  2. leaky units
  3. Gating(LSTM, GRU)
  4. Optimization Tricks(Gradient Clipping, etc.)
  5. Explicit Memory

9.1 Gating: Key Idea

One-line summary: Create a “highway” from the past to the present (or future), and weight blend the current input and past memory.

\[ f(x) = a\cdot x \;\longrightarrow\; f(x) = a\cdot x + (1-a)\cdot m, \qquad a\in[0,1],\ m=\text{memory} \]

\(a\) is a gate value between 0 and 1. The current input \(x\) and the past memory \(m\) are mixed in a ratio of \(a\). This single line of simple mixing is the gating integer.

TipWireless communication analogy — Forgetting factor/1st order IIR low-pass

\(m_t = a\,x_t + (1-a)\,m_{t-1}\) is the Exponential Moving Average (EMA) and 1st-order IIR low-pass filter, and has the same form as the forgetting factor of RLS (Recursive Least Squares). Since the poles lie at \(1-a\), making \(a\) smaller causes the poles to approach 1 (long memory), while making it larger results in rapid forgetting (short memory). Gating is the adaptive learning of this forgetting factor for each data point and time.

9.2 Gating 1: LSTM

Long Short-Term Memory (Hochreiter & Schmidhuber, 1997). There is a separate “highway” called cell state \(c_t\), and the flow of information is controlled by three gates.

\[ \begin{aligned} f_t &= \sigma(W_f[h_{t-1}, x_t] + b_f) &&\text{(forget gate)}\\ i_t &= \sigma(W_i[h_{t-1}, x_t] + b_i) &&\text{(input gate)}\\ o_t &= \sigma(W_o[h_{t-1}, x_t] + b_o) &&\text{(output gate)}\\ \tilde{c}_t &= \tanh(W_c[h_{t-1}, x_t] + b_c) &&\text{(candidate)}\\ c_t &= f_t \odot c_{t-1} + i_t \odot \tilde{c}_t &&\text{(cell update)}\\ h_t &= o_t \odot \tanh(c_t) &&\text{(hidden output)} \end{aligned} \]

The key is the cell state update \(c_t = f_t\odot c_{t-1} + i_t\odot\tilde c_t\). If it is the forget gate \(f_t\approx 1\), the past cell state is passed almost exactly as is, so the gradients are preserved (= poles are adaptively placed near 1). This is the same spirit as ResNet’s residual connection (Section 3.2).

9.3 Gating 2: GRU

Gated Recurrent Unit (Cho et al., 2014). A simpler implementation of almost the same idea as LSTM. The cell state and hidden state are combined and the gate is reduced to two.

\[ \begin{aligned} z_t &= \sigma(W_z[h_{t-1}, x_t]) &&\text{(update gate)}\\ r_t &= \sigma(W_r[h_{t-1}, x_t]) &&\text{(reset gate)}\\ \tilde{h}_t &= \tanh\!\left(W[r_t \odot h_{t-1}, x_t]\right) &&\text{(candidate)}\\ h_t &= (1-z_t)\odot h_{t-1} + z_t\odot \tilde{h}_t &&\text{(혼합)} \end{aligned} \]

The last line is the vector version of Section 9.1’s mixed formula \(a\cdot x + (1-a)\cdot m\).

9.4 LSTM vs GRU

LSTM GRU
Number of Gates 3 (forget/input/output) 2 (update/reset)
State Cell State \(c_t\) + Concealed \(h_t\) Concealed \(h_t\) Only
Parameters Many About 1/2
Performance Standard Equivalent to LSTM
Strengths Expressiveness Risk of Overfitting ↓ (Advantageous when data is small)

GRU was an attempt to achieve similar performance with fewer parameters based on the observation that “LSTM is overparameterized” and succeeded.

9.5 Other solutions

  • Idea 1 — Time skip connection: Add a direct connection to a distant view like Vision’s DenseNet.
  • Idea 2 — Leaky units: \(h_t = (1-\alpha)h_{t-1} + \alpha\,\sigma(W_{rec}h_{t-1} + W_{in}x_t)\). (Independent of leaky-ReLU.) Same form as the first-order IIR integrator above.
  • Idea 3 — Gating: LSTM/GRU (discussed above).
  • Idea 4 — Optimization Trick: Gradient Clipping (Explosive Correspondence) + Normalization Encouraging Information Flow (Vanishing Correspondence).
  • Idea 5 — Explicit Memory: External memory modules such as Memory Networks (Weston et al., ICLR 2015).

10 Context encoding

Along with long-term dependencies, another key challenge in sequence encoding is context.

10.1 Buffalo Example

The English sentence “Buffalo buffalo Buffalo buffalo buffalo buffalo Buffalo buffalo” is a grammatically correct sentence in which all words have the same spelling (place name/animal/verb), but their part of speech and meaning change depending on the context. It clearly demonstrates that even with the same token, the surrounding context determines the meaning.

10.2 Context-Conditional RNN and Bidirectional RNN

  • Context-Conditional RNN (Single Input): The idea that looking at past outputs helps predict the future. It establishes a backward connection from the future.
  • Context-Conditional RNN (Sequence Input): Uses the hidden state output from the previous time step and the output from the previous time step both as inputs for the next hidden state (unlike teacher forcing, it maintains the hidden state connection).
  • Bi-directional RNN: “Reading back and forth helps with memory.” By introducing a backward hidden state separate from the forward hidden state, the representation of each time step considers both past and future contexts.

\[ \overrightarrow{h}_t = f(\overrightarrow{h}_{t-1}, x_t),\qquad \overleftarrow{h}_t = f(\overleftarrow{h}_{t+1}, x_t),\qquad y_t = g\!\left(\overrightarrow{h}_t, \overleftarrow{h}_t\right) \]

NoteWireless communication analogy — Filtering vs. Smoothing

A unidirectional RNN is a causal filter that uses only the past = Kalman filtering. A bidirectional RNN is a non-causal smoothing that uses future observations as well = Kalman smoothing. Estimating by looking at the entire sequence offline (smoothing) becomes more accurate than causal estimation (filtering), but it cannot be used for real-time processing. This is exactly the same trade-off as the bidirectional RNN needing to receive the entire sequence to operate.

11 Seq2Seq model

One-line summary: A universal sequence transformation structure created by concatenating two RNNs (encoder + decoder).

Code 
flowchart LR
    subgraph Encoder
      e1["x⁽¹⁾"] --> e2["x⁽²⁾"] --> e3["x⁽³⁾"]
    end
    e3 --> C(("C\n(context)"))
    subgraph Decoder
      C --> d1["y⁽¹⁾"] --> d2["y⁽²⁾"] --> d3["y⁽³⁾"]
    end

  • The encoder reads the input sequence and creates a fixed-size context variable \(C\). \(C\) serves as the semantic summary of the input.
  • Decoder generates an output sequence from \(C\).
  • Training: Feed the correct answer output to the decoder for training (teacher forcing). Inference: The decoder generates one token at a time by feeding its own output back as the next input.

Application:

Assignment Input Output
QA System Question Answer
Conversational System (Chatbot) A’s Utterance B’s Utterance
Machine Translation Language A Language B
TipWireless communication analogy — Information bottlenecks and sufficient statistics

When an encoder compresses a variable-length input into a fixed size \(C\), it is equivalent to summarizing the original signal into a sufficient statistic or compressing it into source coding. If the dimensionality of \(C\) is small, an information bottleneck occurs, and the loss increases over long inputs — this limit later becomes the motivation for attention (directly referencing the entire encoder state).

12 Extended Structures: Deep RNN and Recursive NN

12.1 Deep RNN

RNN with multiple hidden layers. Expressiveness increases, but as seen in Section 8, the gradient that is already weakened in one step is added to the depth, making training more difficult.

12.2 Recursive Neural Networks

One-line summary: A generalization of RNNs that uses a tree structured computational graph instead of a chain.

  • Process sequences as a tree instead of linearly.
  • For length \(\tau\), the search/propagation depth is reduced from \(\tau\) to \(\log(\tau)\) → This is advantageous (in principle) as it allows long-term dependencies to be connected via shorter paths.
  • Application: Scene parsing — Each hidden node corresponds to an object in the scene (Socher et al., ICML 2011).
NoteWireless communication analogy — Reducing the depth of the tree structure

Reducing the \(O(\tau)\) depth of sequential processing to a \(O(\log\tau)\) tree is equivalent to shortening the critical path by replacing serial accumulation with binary-tree reduction. This aligns with the spirit of divide and conquer, where FFT reduces the \(O(N^2)\) DFT to \(O(N\log N)\).

13 Key Summary

ImportantThe core of this note

CNN

  • ImageNet (2009) was the trigger for the CNN revival. Depth exploded with AlexNet (2012) → GoogLeNet (2014) → ResNet (2015), and ResNet’s residual connections mitigated vanishing gradients, breaking human performance.
  • Post-CNN: ViT (Image = Patch Sequence), gMLP. ViT is advantageous in parallelization and energy efficiency due to its small number of layers. Multimodality is achieved through tokenization.

Sequence Model Side

  • RNN = state-space model driven by external input, \(h^{(t)} = f(h^{(t-1)}, x^{(t)};\theta)\). One step cycle is IIR filter.
  • Two advantages: variable length independence, parameter sharing (=time stationarity, but strong assumption).
  • Three types: Type 1 (hidden-hidden), Type 2 (teacher forcing, parallel↑/memory↓), Type 3 (single output at the end, standard).
  • Reason why long-term dependency is difficult = Eigenvalue decomposition: \(|\lambda|<1\) vanishing, \(|\lambda|>1\) explosion. Mathematics such as Discrete LTI stability (position of poles on the unit circle).
  • Solution: Gating (LSTM/GRU = Adaptive Forget Factor), skip connection, leak unit, gradient clipping, explicit memory.
  • Context encoding: Bidirectional RNN(=smoothing), Seq2Seq(encoder context \(C\) = semantic summary/sufficient statistics).

One-line summary: Time-based memory is still an unresolved problem. Building a truly good time-based memory architecture is the core challenge, and the Transformer is the next topic as an alternative.

14.1 A. Eigenvalue Size and Disappearance/Explosion

Code 
import numpy as np
np.random.seed(0)

def spectral_radius(W):
    return np.max(np.abs(np.linalg.eigvals(W)))

# 수축 행렬 (|lambda|<1) -> 소실 / 팽창 행렬 (|lambda|>1) -> 폭발
Wc = np.array([[0.9, 0.1], [0.0, 0.8]])
We = np.array([[1.2, 0.1], [0.0, 1.1]])

print(f"rho(Wc) = {spectral_radius(Wc):.3f}   rho(We) = {spectral_radius(We):.3f}")
print(f"{'t':>4} | {'||Wc^t||':>12} | {'||We^t||':>12}")
for t in [1, 5, 20, 50]:
    nc = np.linalg.norm(np.linalg.matrix_power(Wc, t))
    ne = np.linalg.norm(np.linalg.matrix_power(We, t))
    print(f"{t:>4} | {nc:>12.3e} | {ne:>12.3e}")

If the spectral radius is less than 1, \(\|W^t\|\) goes to 0, and if it is greater, it goes to infinity — this is the nature of gradient vanishing/explosion.

14.3 C. EMA as Gating (Forgetting Factor)

Code 
import numpy as np

# m_t = a * x_t + (1 - a) * m_{t-1}   (1차 IIR 저역통과 = 적응적 망각)
a = 0.3
m, xs = 0.0, np.ones(10)   # 계단 입력
traj = []
for t in range(10):
    m = a * xs[t] + (1 - a) * m
    traj.append(round(m, 4))

print("EMA(forgetting factor) trajectory:")
print(traj)
print("steady state ->", traj[-1], "(approaches 1)")

Small \(a\) creates long memory by setting the poles close to 1, and large \(a\) creates fast forgetting. The gates of the LSTM/GRU learn this \(a\) for every data and time.

14.4 D. RNN Type Comparison (Conceptual Sketch)

Code 
# 의사코드 수준의 개념 비교 (실제 학습 루프는 아님)
def type1_step(h, x, params):
    h = tanh(params.Whh @ h + params.Wxh @ x)   # hidden -> hidden
    o = params.Who @ h
    return h, o

def type2_step(h, x, prev_out, params, training, y=None):
    feedback = y if training else prev_out       # teacher forcing vs 자기 출력
    h = tanh(params.Wfh @ feedback + params.Wxh @ x)  # output -> hidden
    o = params.Who @ h
    return h, o

# Type 3: 전체 시퀀스를 돌린 뒤 마지막 h로만 출력
def type3_run(xs, h, params):
    for x in xs:
        h = tanh(params.Whh @ h + params.Wxh @ x)
    return params.Who @ h                         # 끝에서 단일 출력
