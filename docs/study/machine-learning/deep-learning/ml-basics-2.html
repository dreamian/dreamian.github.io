1 Linear Regression

1.1 Key Idea

The goal of linear regression is to learn the mapping from the input \(\mathbf{x}\) to the continuous target \(t(\mathbf{x})\). The core structure is the weighted sum of basis functions:

\[ \hat{f}(\mathbf{x}) = \sum_{i=1}^{K} w_i h_i(\mathbf{x}) \]

where \(H = \{h_1, \dots, h_K\}\) is a predetermined set of basis functions and \(\mathbf{w} = \{w_1, \dots, w_K\}\) is the parameter to be learned.

ImportantMeaning of “Linear”

Even if non-linear basis functions like \(h_i(x) = x^2\) are used, this is still linear regression. This is because “linear” refers to linearity with respect to the coefficients (parameters) \(w\), not linearity with respect to the input \(x\).

\[ \hat{y} = w_0 + w_1 x + w_2 x^2 \]

There is a non-linear transformation \(x^2\), but it is a linear regression because \(w_0, w_1, w_2\) is a linear equation.

1.2 Basis Function and Hypothesis Space

1.2.1 Hypothesis Space

Hypothesis space \(\mathcal{H}\) is the set of all possible functions that we assume “the correct answer will be in here.” In linear regression:

\[ \mathcal{H} = \left\{ f(\mathbf{x}) = \sum_{i=1}^{K} w_i h_i(\mathbf{x}) \;\middle|\; w_i \in \mathbb{R} \right\} \]

When the basis function \(\{h_1, \dots, h_K\}\) is fixed, all possible weight combinations form the hypothesis space. The basis function defines the “coordinate axes” of the hypothesis space, and the weights are the coordinate values in that coordinate system.

1.2.2 Relationship with Inductive Bias

The selection of the basis function itself is an inductive bias:

Basis function selection Inductive bias
\(\{h_1(x) = x,\; h_2(x) = 1\}\) “The answer will be a straight line”
\(\{h_1(x) = x^2,\; h_2(x) = x,\; h_3(x) = 1\}\) “The answer will be a quadratic curve”
\(\{\sin(nx),\; \cos(nx)\}\) “The answer is likely a periodic function”
TipWireless Communication Perspective

The choice of whether to use a delay spread-based basis, a Fourier basis, or a polynomial basis when estimating channels corresponds to this inductive bias. The selection of the basis function determines “how we view the structure of the world,” and this is the prior knowledge that humans inject prior to learning.

The reason deep learning is innovative is that it learns the basis functions themselves from the data. This is handled in the MLP (Multi-layer Perceptron).

1.3 Ordinary Least Squares (OLS)

Minimize the sum of squares of residuals:

\[ \text{total error} = \sum_i (y_i - \hat{y}_i)^2 = \sum_i \left( y_i - \sum_k w_k f_k(x_i) \right)^2 \]

This is the sum of the squared residual \(e_i = y_i - \hat{y}_i\) at each data point. The reason for using squaring is to prevent positive and negative residuals from canceling each other out and to apply a larger penalty to large errors.

1.4 Matrix Representation and Design Matrix

1.4.1 Structure of the Design Matrix

Design matrix \(\mathbf{H}\) is the \(N \times K\) matrix, and the elements are:

\[ H_{ji} = h_i(\mathbf{x}^j) \]

WarningEach row of the Design Matrix has a different value

The definition of the basis function is that \(h_i(\cdot)\) is fixed (the form of the function depends only on \(i\)), but since the input value substituted into the function differs for each \(\mathbf{x}^j\), the output value depends on all \((i, j)\).

Example: 1D input, parabola basis \(\{h_1(x) = x^2,\; h_2(x) = x,\; h_3(x) = 1\}\), if data \(x^1=2, x^2=3, x^3=5\):

\[ \mathbf{H} = \begin{bmatrix} h_1(x^1) & h_2(x^1) & h_3(x^1) \\ h_1(x^2) & h_2(x^2) & h_3(x^2) \\ h_1(x^3) & h_2(x^3) & h_3(x^3) \end{bmatrix} = \begin{bmatrix} 4 & 2 & 1 \\ 9 & 3 & 1 \\ 25 & 5 & 1 \end{bmatrix} \]

Just as in OFDM \(H_{ji}\) represents the contribution of the \(i\) tap to the \(j\) subcarrier, here \(H_{ji}\) represents the contribution of the \(i\) basis function to the \(j\) data.

1.4.2 Matrix-based optimization problem

If we define weight vector \(\mathbf{w}\) (\(K \times 1\)) and target vector \(\mathbf{t}\) (\(N \times 1\)):

\[ \mathbf{w}^* = \arg\min_{\mathbf{w}} (\mathbf{Hw} - \mathbf{t})^T(\mathbf{Hw} - \mathbf{t}) \]

\((\mathbf{Hw} - \mathbf{t})\) is the residual vector, and its inner product with itself is the sum of squared residuals.

1.5 Normal Equation Derivation (Detailed)

1.5.1 Step 0: Define Objective Function

\[ F(\mathbf{w}) = (\mathbf{Hw} - \mathbf{t})^T(\mathbf{Hw} - \mathbf{t}) \]

1.5.2 Step 1: Expansion

Apply the distributive law of transposition \((A - B)^T = A^T - B^T\):

\[ F(\mathbf{w}) = (\mathbf{w}^T\mathbf{H}^T - \mathbf{t}^T)(\mathbf{Hw} - \mathbf{t}) \]

Create 4 terms using the distributive property:

\[ = \mathbf{w}^T\mathbf{H}^T\mathbf{H}\mathbf{w} - \mathbf{w}^T\mathbf{H}^T\mathbf{t} - \mathbf{t}^T\mathbf{H}\mathbf{w} + \mathbf{t}^T\mathbf{t} \]

NoteTranspose property of a scalar

\(\mathbf{w}^T\mathbf{H}^T\mathbf{t}\) and \(\mathbf{t}^T\mathbf{H}\mathbf{w}\) are both scalars, and since the transpose of a scalar is itself:

\[\mathbf{w}^T\mathbf{H}^T\mathbf{t} = (\mathbf{t}^T\mathbf{H}\mathbf{w})^T = \mathbf{t}^T\mathbf{H}\mathbf{w}\]

Therefore, the two terms can be combined.

\[ F(\mathbf{w}) = \mathbf{w}^T\mathbf{H}^T\mathbf{H}\mathbf{w} - 2\mathbf{t}^T\mathbf{H}\mathbf{w} + \mathbf{t}^T\mathbf{t} \]

1.5.3 Step 2: Vector Differentiation Rule

Two matrix differentiation formulas needed:

Rule 1 (Scalar version: Vector expansion of \(\frac{d}{dw}(aw) = a\)):

\[ \frac{\partial}{\partial \mathbf{w}}(\mathbf{a}^T\mathbf{w}) = \mathbf{a} \]

Rule 2 (Scalar version: Vector expansion of \(\frac{d}{dw}(aw^2) = 2aw\), when \(\mathbf{A}\) is symmetric):

\[ \frac{\partial}{\partial \mathbf{w}}(\mathbf{w}^T\mathbf{A}\mathbf{w}) = 2\mathbf{A}\mathbf{w} \]

Here, \(\mathbf{H}^T\mathbf{H}\) is always symmetric: \((\mathbf{H}^T\mathbf{H})^T = \mathbf{H}^T(\mathbf{H}^T)^T = \mathbf{H}^T\mathbf{H}\)

1.5.4 Step 3: Apply differentiation

\[ \nabla_{\mathbf{w}} F(\mathbf{w}) = 2\mathbf{H}^T\mathbf{H}\mathbf{w} - 2\mathbf{H}^T\mathbf{t} + \mathbf{0} \]

\(\mathbf{t}^T\mathbf{t}\) is a constant independent of \(\mathbf{w}\), so its derivative is 0.

1.5.5 Step 4: Set to 0 and solve

\[ 2\mathbf{H}^T\mathbf{H}\mathbf{w} - 2\mathbf{H}^T\mathbf{t} = \mathbf{0} \]

\[ \mathbf{H}^T\mathbf{H}\mathbf{w} = \mathbf{H}^T\mathbf{t} \]

\[ \boxed{\mathbf{w}^* = (\mathbf{H}^T\mathbf{H})^{-1}\mathbf{H}^T\mathbf{t}} \]

ImportantInverse matrix existence condition

For \((\mathbf{H}^T\mathbf{H})^{-1}\) to exist, \(\mathbf{H}^T\mathbf{H}\) must be invertible. This holds when the columns of \(\mathbf{H}\) are linearly independent, that is, when the basis functions are independent of each other. If \(N < K\) (number of data points < number of basis functions), it is not invertible, so the solution is not unique. This is one of the reasons why regularization is necessary.

TipConnection with MIMO ZF receiver

This Normal Equation has exactly the same structure as a zero-forcing receiver in a MIMO system:

\[ \hat{\mathbf{x}} = (\mathbf{H}^H\mathbf{H})^{-1}\mathbf{H}^H\mathbf{y} \]

The only difference is that in the complex channel, the Hermitian transpose (\(H\)) is used instead of the transpose (\(T\)).

1.6 Connection between Least-Squares and MLE

1.6.1 Probabilistic Model Settings

The observation model is assumed as follows:

\[ t(\mathbf{x}) = \sum_i w_i h_i(\mathbf{x}) + e, \quad e \sim \mathcal{N}(0, \sigma^2) \]

Under this assumption, the likelihood of a single observation is:

\[ P(t \mid \mathbf{x}, \mathbf{w}, \sigma) = \frac{1}{\sigma\sqrt{2\pi}} \exp\left( -\frac{[t - \sum_i w_i h_i(\mathbf{x})]^2}{2\sigma^2} \right) \]

1.6.2 Maximize Log-Likelihood

The log-likelihood of the entire data under the iid assumption is:

\[ \ln P(\mathcal{D} \mid \mathbf{w}, \sigma) = \ln\left(\frac{1}{\sigma\sqrt{2\pi}}\right)^N + \sum_{j=1}^{N} \frac{-[t_j - \sum_i w_i h_i(x_j)]^2}{2\sigma^2} \]

Maximizing for \(\mathbf{w}\), since the first term is a \(\mathbf{w}\)-independent constant:

\[ \arg\max_{\mathbf{w}} \ln P(\mathcal{D} \mid \mathbf{w}, \sigma) = \arg\max_{\mathbf{w}} \sum_{j=1}^{N} \frac{-[t_j - \sum_i w_i h_i(x_j)]^2}{2\sigma^2} \]

If we convert the negative sign of the numerator and max to min, and remove the \(2\sigma^2\) constant:

\[ = \arg\min_{\mathbf{w}} \sum_{j=1}^{N} [t_j - \sum_i w_i h_i(x_j)]^2 \]

ImportantLeast-Squares = Gaussian Noise MLE

Under the assumption of Gaussian noise, least-squares linear regression is equivalent to MLE.

If the noise distribution changes, the corresponding loss function also changes:

  • Gaussian noise → L2 loss (MSE)
  • Laplace noise → L1 loss (MAE) → robust regression

2 Logistic Regression

2.1 Regression for classification

Although “regression” is in the name, Logistic regression is a classification model. The core idea: the regression output is passed through a logistic function (sigmoid) to convert it into a probability.

2.2 Logistic Function and Sigmoid

General logistic function:

\[ f(x) = \frac{L}{1 + e^{-k(x - x_0)}} \]

  • \(x_0\): mid-point
  • \(L\): Maximum value of the curve (height)
  • \(k\): Curve slope (steepness)

standard sigmoid (\(L=1, k=1, x_0=0\)):

\[ \sigma(x) = \frac{1}{1 + e^{-x}} \]

Note\(\sigma\) Note on notation

In the ML/DL field, the sigmoid function is conventionally denoted as \(\sigma(\cdot)\). This has a completely different meaning from the standard deviation of a Gaussian distribution, \(\sigma\).

  • \(\sigma(\cdot)\): sigmoid function
  • \(\sigma^2\): Variance of Gaussian noise (in linear regression MLE)

This is notational overloading that must be distinguished by context.

2.2.1 Advantageous properties of Sigmoid

  1. Output is in the \([0, 1]\) interval → Can be interpreted as probability
  2. Smooth & continuous → Differentiable (Suitable for gradient-based optimization)
  3. Mirror symmetric → \(\sigma(-x) = 1 - \sigma(x)\)
  4. Derivative is cheap: \(\sigma'(x) = \sigma(x)(1 - \sigma(x))\) — Differentiation can be calculated using only the output value

2.3 Generative Model vs. Discriminative Model

2.3.1 Generative Model

Learn the Joint distribution \(P(X, Y)\). Decomposing it using Bayes’ rule:

\[ P(X, Y) = P(X|Y) \cdot P(Y) \]

Model two things for each class \(Y\):

  • \(P(X|Y)\) (likelihood): “What does the data of this class look like”
  • \(P(Y)\) (prior): “How often this class appears”

Apply Bayes’ rule when classifying:

\[ P(Y|X) = \frac{P(X|Y) \cdot P(Y)}{P(X)} \]

Examples: Gaussian Naive Bayes, HMM, GMM

2.3.2 Discriminative Model

Directly train on \(P(Y|X)\). Do not model \(P(X|Y)\) or \(P(X)\).

Examples: Logistic Regression, SVM, Neural Network

2.3.3 Key Comparison

Generative Discriminative
Training Target \(P(X,Y)\) or \(P(X|Y), P(Y)\) \(P(Y|X)\) Direct
Data generation possible? Possible (Origin of name) Impossible
Number of parameters High (describes input distribution) Low
Classification Accuracy Falls behind discriminative when data is large Usually higher
Advantages Missing data processing, outlier detection Focus on classification, efficient
TipWireless communication analogy
  • Generative: For each transmitted symbol \(s_k\), fully describe the received signal distribution \(P(\mathbf{y}|s_k)\) using a channel model and perform MAP/ML detection.
  • Discriminative: Learns received signal → transmitted symbol mapping directly from data without a channel model (learned MIMO detector)

2.4 Probabilistic model of Logistic Regression

Logistic regression is a discriminative model that directly trains \(P(Y|\mathbf{X})\). In binary classification (\(y \in \{0, 1\}\)):

\[ P(Y=1 \mid \mathbf{x}, \mathbf{w}) = \sigma(\mathbf{w}^T \mathbf{x}) = \frac{1}{1 + e^{-\mathbf{w}^T\mathbf{x}}} \]

2.5 MCLE: Maximum Conditional Likelihood Estimation

2.5.1 Problem situation

Traditional MLE attempts to maximize joint likelihood:

\[ \hat{\mathbf{w}}_{MLE} = \arg\max_{\mathbf{w}} \prod_{j=1}^{n} P(x^j, y^j | \mathbf{w}) \]

However, since logistic regression is a discriminative model, it does not know \(P(X, Y | \mathbf{w})\) and only modeled \(P(Y|X, \mathbf{w})\). In other words, there is no usable tool.

2.5.2 Decomposition of Data Likelihood

Product rule of joint probability:

\[ P(x^j, y^j | \mathbf{w}) = P(x^j | y^j, \mathbf{w}) \cdot P(y^j | \mathbf{w}) \]

This comes from the definition of conditional probability \(P(A,B|C) = P(A|B,C) \cdot P(B|C)\). If we take the logarithm and sum it over all the data:

\[ \ln P(\mathcal{D}|\mathbf{w}) = \underbrace{\sum_j \ln P(x^j | y^j, \mathbf{w})}_{\text{(A): 입력 분포 모델링}} + \underbrace{\sum_j \ln P(y^j | \mathbf{w})}_{\text{(B): 클래스 prior}} \]

Noteiid assumption

In the decomposition above, to decompose the joint likelihood into the product, the iid assumption is required for the data pair \(\{(x^j, y^j)\}_{j=1}^N\). Under the independence assumption, it is decomposed into \(P(y^1, \dots, y^N | x^1, \dots, x^N, \mathbf{w}) = \prod_j P(y^j | x^j, \mathbf{w})\), and taking the logarithm changes the product into a sum.

2.5.3 MCLE Solution

We define likelihood based only on what we have. Use Conditional data likelihood as the objective function:

\[ \hat{\mathbf{w}}_{MCLE} = \arg\max_{\mathbf{w}} \prod_{j=1}^{N} P(y^j | x^j, \mathbf{w}) \]

If you take the log:

\[ l(\mathbf{w}) = \sum_{j=1}^{N} \ln P(y^j | x^j, \mathbf{w}) \]

Since \(P(y|x, \mathbf{w}) = \sigma(\mathbf{w}^T\mathbf{x})^y \cdot (1 - \sigma(\mathbf{w}^T\mathbf{x}))^{1-y}\):

\[ l(\mathbf{w}) = \sum_j \left[ y^j \ln \sigma(\mathbf{w}^T\mathbf{x}^j) + (1-y^j) \ln(1 - \sigma(\mathbf{w}^T\mathbf{x}^j)) \right] \]

This is the prototype of binary cross-entropy loss.

2.5.4 MCLE’s Philosophy: What is the benefit of only estimating \(P(Y|X)\)

Efficiency: The distribution \(X\) of the input \(P(X)\) is typically very high-dimensional and complex. In image classification, \(P(X)\) represents the “distribution of natural images,” and accurately modeling this is incredibly difficult. This information is not needed for classification. To distinguish between a cat and a dog, there is no need to know “what distribution the natural image follows.”

Accuracy: When training resources are limited, since parameters are not wasted on modeling \(P(X|Y)\) , but rather focused on \(P(Y|X)\), which is unnecessary for classification, classification performance tends to be better with the same amount of data.

2.5.5 Justification for MCLE replacing MLE

In the data log-likelihood decomposition above:

  • (A) \(P(X|Y, \mathbf{w})\): In logistic regression, \(\mathbf{w}\) is the parameter of the decision boundary. Since the distribution of the input data \(X\) is mostly not dependent on \(\mathbf{w}\), this term does not contribute to the optimization of \(\mathbf{w}\).

  • (B) \(P(Y|\mathbf{w})\): The prior probability of the class is usually independent of \(\mathbf{w}\), or is already given as a ratio in the data.

Therefore, (A) and (B) act as constant terms in the optimization for \(\mathbf{w}\) and:

\[ \arg\max_{\mathbf{w}} \ln P(\mathcal{D}|\mathbf{w}) \approx \arg\max_{\mathbf{w}} \sum_j \ln P(y^j | x^j, \mathbf{w}) \]

While Generative MLE may be theoretically better, performance actually deteriorates if \(P(X|Y)\) is mismodeled (model misspecification). The Discriminative approach avoids this risk.

2.6 Gradient Ascent Optimization

Regarding the optimization of \(l(\mathbf{w})\):

  • \(l(\mathbf{w})\) has a concave function for \(\mathbf{w}\) → a globally optimal solution exists
  • No closed-form solution (Key difference from linear regression!)
  • The concave function can be optimized relatively easily using gradient ascent.

Gradient and update rules:

\[ \nabla_{\mathbf{w}} l(\mathbf{w}) = \left[ \frac{\partial l}{\partial w_0}, \frac{\partial l}{\partial w_1}, \dots, \frac{\partial l}{\partial w_n} \right] \]

\[ w_i^{(t+1)} \leftarrow w_i^{(t)} + \eta \frac{\partial l(\mathbf{w})}{\partial w_i} \]

NoteAscent vs. Descent
  • maximize the objective function → gradient ascent (sign \(+\))
  • Minimize Loss → Gradient Descent (Sign \(-\))

The two are essentially the same algorithm, differing only in sign.

3 Support Vector Machine (SVM)

3.1 Geometric intuition

In binary classification, a linear classifier divides the space into hyperplanes:

\[ \mathbf{w} \cdot \mathbf{x} + w_0 = 0 \]

\(\mathbf{w}\) is the normal vector of the hyperplane, and \(w_0\) is the bias. The label is \(y^j \in \{+1, -1\}\).

3.2 distance from point to hyperplane

Signed distance from data point \(\mathbf{x}^j\) to hyperplane:

\[ d^j = \frac{\mathbf{w} \cdot \mathbf{x}^j + w_0}{\|\mathbf{w}\|_2} \]

Multiplying \(y^j\) results in a positive number for correctly classified points:

\[ y^j \cdot \frac{\mathbf{w} \cdot \mathbf{x}^j + w_0}{\|\mathbf{w}\|_2} > 0 \]

3.3 Margin Definition and Maximization

Margin = Distance to the nearest data point from the hyperplane:

\[ \text{margin} = \min_j \frac{y^j(\mathbf{w} \cdot \mathbf{x}^j + w_0)}{\|\mathbf{w}\|_2} \]

SVM maximizes this margin. If we fix it to \(\min_j y^j(\mathbf{w} \cdot \mathbf{x}^j + w_0) = \gamma\) using scaling degrees of freedom, the margin becomes \(\frac{\gamma}{\|\mathbf{w}\|_2}\), and margin maximization is \(\Leftrightarrow\) \(\|\mathbf{w}\|_2\) minimization.

3.4 Final optimization problem

\[ \min_{\mathbf{w}, w_0} \frac{1}{2}\|\mathbf{w}\|_2^2 \] \[ \text{s.t.} \quad \forall j, \quad y^j(\mathbf{w} \cdot \mathbf{x}^j + w_0) > \gamma \]

Meaning of each element:

Element Meaning
\(\frac{1}{2}\|\mathbf{w}\|_2^2\) \(\mathbf{w}\) Minimize size → Maximize margin. \(\frac{1}{2}\) is differentiation bias, squaring ensures convexity
\(y^j(\mathbf{w} \cdot \mathbf{x}^j + w_0)\) Functional margin. Positive for correct classification by multiplying \(y^j\)
\(> \gamma\) Not a simple classification (\(>0\)), but requires a margin of at least \(\gamma\)

Conventionally, if set to \(\gamma = 1\), it is the standard form:

\[ \min_{\mathbf{w}, w_0} \frac{1}{2}\|\mathbf{w}\|_2^2 \quad \text{s.t.} \quad \forall j, \; y^j(\mathbf{w} \cdot \mathbf{x}^j + w_0) \geq 1 \]

3.5 Support Vector

The points where equality holds under the constraint —that is, the data points \(y^j(\mathbf{w} \cdot \mathbf{x}^j + w_0) = \gamma\)— are support vectors. Only these points determine the location of the hyperplane, and the remaining points do not affect the result.

3.6 Connection with Lagrangian/KKT

This problem is a Quadratic Programming (QP) problem because it involves quadratic objectives + linear constraints. Lagrangian:

\[ \mathcal{L}(\mathbf{w}, w_0, \boldsymbol{\alpha}) = \frac{1}{2}\|\mathbf{w}\|^2 - \sum_j \alpha_j \left[ y^j(\mathbf{w} \cdot \mathbf{x}^j + w_0) - \gamma \right] \]

By the KKT condition, only the points \(\alpha_j > 0\) are support vectors, and the rest are \(\alpha_j = 0\).

TipWireless Communication Analogy: Constellation Design

Margin maximization in SVM follows the same philosophy as minimum distance maximization in telecommunications. Just as maximizing the minimum Euclidean distance between symbols in QAM constellation design minimizes BER, SVM reduces misclassification by maximizing the minimum distance between classes.

4 K-Nearest Neighbor (KNN) Classifier

4.1 algorithm

  1. Given a new data point, find the \(K\) neighbors closest to the training data
  2. Determine class by majority voting
  3. No separate parameter learning step (lazy learning)

The definition of “closeness” depends on the distance metric (Euclidean, Manhattan, etc.).

4.2 No Training Phase?

“No training” means there is no parameter optimization process:

  • “Training” Step: Save training data. End.
  • Prediction Step: When a new \(\mathbf{x}\) comes in, calculate the distance to all stored training data, and Find the closest \(K\) and vote by majority

Calling fit() in scikit-learn internally stores data and builds index structures (KD-tree, Ball-tree, etc.) for efficient searching. It is not parameter learning.

Attribute Value
Training time \(O(1)\) — Just save
Prediction Time \(O(N \cdot d)\) — Proportional to Data Size, Slow
Hyperparameter \(K\) Value or ball radius (tuned with validation)
TipWireless Communication Perspective

KNN is actively used in RF fingerprinting-based location estimation. It is natural to assume that locations with similar received signal patterns will have similar coordinates.

5 Decision Tree and Random Forest

5.1 Decision Tree

This is a method that recursively partitions data based on feature conditions. Each internal node checks the condition for a single feature, and the leaf node makes the final decision.

5.2 Limitations of Decision Trees

  • Easily overfitting on training data
  • High variance problem where the tree structure changes significantly even with slight changes in data

5.3 Random Forest

Create multiple decision trees and ensemble them. The key is two types of randomness that intentionally make each tree different:

Creates a different training set for each tree using bootstrap sampling from the original data . When \(N\) data points are sampled with replacement (\(N\)) of them, on average, only about 63.2% of the unique data is included.

Feature randomness: When splitting at each node, the optimal split is found only from randomly selected \(\sqrt{d}\) (classification) or \(d/3\) (regression) features, rather than from all \(d\) features.

5.4 Prediction method

  • Category: Majority vote on predictions for all trees
  • Regression: Average the predictions of all trees

5.5 Why it works well

Individual trees have high variance and low bias. Averaging trees created with different randomness reduces variance and maintains bias.

TipWireless Communication Analogy: Diversity Combining

Just as combining multiple independent fading channels increases overall confidence, combining independent trees increases prediction stability.

6 Overall Structure: Why deal with these algorithms together

These are all representative algorithmic paradigms of supervised learning and demonstrate the core axes of ML through their contrasting characteristics.

6.1 Commonalities

  • All supervised learning (trained with labeled data)
  • Learn mapping from all inputs \(\mathbf{x}\) to output \(y\)

6.2 Contrast Axis 1: Parametric vs. Non-parametric

Parametric Non-parametric
Linear/Logistic Regression, SVM KNN, Decision Tree
Even if data is discarded after training, prediction is possible with only \(\mathbf{w}\) The data itself is part of the model

6.3 Contrast Axis 2: Spectrum of learning methods

Algorithm Learning Method

Logistic Regression Iterative optimization (Gradient Ascent)
SVM Constrained optimization (QP)
KNN No Learning (Lazy Learning)
Decision Tree Greedy recursive partitioning

6.4 Contrast Axis 3: Regression → Classification Extension

that starts with linear regression, applies the sigmoid function to logistic regression, and extends to SVM by introducing the concept of margin. This lineage is the foundation of neural networks.

Linear regression and logistic regression are actually 1-layer neural networks. If you stack layers on top of them and add non-linear activation, they become MLPs (Multi-layer Perceptrons). This is the key point of the next chapter.
