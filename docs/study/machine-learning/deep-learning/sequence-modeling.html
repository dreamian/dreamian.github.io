Circular Structures and Long-Term Dependency Issues for Variable-Length Data
Published

1 What is sequence modeling?

The data discussed so far—images, graphs—were in the form of fixed-length snapshots. However, much real-world data has variable length.

Domain Example
Natural Language Processing Sentence, Document
Time series Stock price, sensor data
Video Video Frame
Voice Voice signal
NoteWireless Communication Perspective

Channel impulse response (CIR), CSI sequence, time-dependent fading process, OFDM symbol stream, etc., are all subjects of sequence modeling. Statistically, it is reduced to the problem of estimating and predicting a stochastic process.

1.1 Key Challenges

  1. Long-term dependency: How to preserve information from a distant point in time?
  2. Context encoding: Even the same word can have different meanings depending on the context (see sentences like “Buffalo buffalo Buffalo buffalo…”).

2 Dynamic Systems and the Starting Point of RNNs

2.1 Autoregressive dynamic system

The simplest form in which a state evolves without external input:

s^{(t)} = f(s^{(t-1)}; \theta)

If you unfold this along the time axis, all past states can be explicitly expressed.

2.2 Dynamic system with external signal

Given external input x^{(t)}:

s^{(t)} = f(s^{(t-1)}, x^{(t)}; \theta)

In this case, s^{(t)} becomes a compressed representation of information about the entire past sequence. If we call this state the hidden state h^{(t)} and implement it as a learnable function f, that is precisely the Recurrent Neural Network:

\boxed{\;h^{(t)} = f(h^{(t-1)}, x^{(t)}; \theta)\;}

TipStatistical Intuition

This can be viewed as a neural network generalization of the HMM (Hidden Markov Model). While HMMs assume discrete states and linear transition probabilities, RNNs learn continuous states and non-linear transitions.

3 Basic formulas and weight notation of RNN

3.1 Standard Vanilla RNN Formula

h_t = \tanh(W_{hh}\,h_{t-1} + W_{xh}\,x_t) y_t = W_{hy}\,h_t

3.2 Weight Matrix Naming Rules

The symbol W_{\square\square} is generally read as “W_{\text{from}\to\text{to}}” (however, notation conventions vary by source, so always check the definition).

Matrix Role Dimension
W_{xh} Input x_t → Hidden h_t Projection d_h \times d_x
W_{hh} Previous hidden h_{t-1} → Current hidden h_t d_h \times d_h
W_{hy} hidden h_t → Output y_t d_y \times d_h

3.3 Dimensional tracing example

When d_x=10, d_h=20, d_y=5:

x_t      : (10,)
W_xh @ x_t     = (20, 10) @ (10,)  = (20,)
W_hh @ h_{t-1} = (20, 20) @ (20,)  = (20,)
                                  ↓ + 
                              tanh → h_t : (20,)
W_hy @ h_t     = (5, 20) @ (20,)   = y_t : (5,)

3.4 Weight Sharing

W_{hh}, W_{xh}, W_{hy} is identical at all time steps.

h_1 = \tanh(\mathbf{W_{hh}}h_0 + \mathbf{W_{xh}}x_1) h_2 = \tanh(\mathbf{W_{hh}}h_1 + \mathbf{W_{xh}}x_2) h_3 = \tanh(\mathbf{W_{hh}}h_2 + \mathbf{W_{xh}}x_3)

This follows the same philosophy as CNN’s spatial weight sharing, fixing the number of parameters regardless of sequence length.

NoteWireless communication analogy: Accurate correspondence with Kalman filter

Linear Gaussian state-space model s_t = F\,s_{t-1} + G\,u_t + w_t

Kalman RNN
F (state transition matrix) W_{hh}
G (input matrix) W_{xh}
H (observation matrix) W_{hy}
Linear + Gaussian noise Nonlinear (\tanh), Deterministic

RNN can be interpreted as a non-linear, learnable generalization of the Kalman filter.

3.5 Caution when interpreting RNN diagrams

In many unfolded diagrams, only the hidden state h^{(t)} is drawn, and the output y^{(t)} is omitted. This is to emphasize the recurrence mechanism itself, whereas in reality, a separate output readout exists for each time step.

The output format varies depending on the task:

Task Output Format
Many-to-many (Translation, POS tagging) From all t to \hat{y}^{(t)}
Many-to-one (Sentiment Analysis) Only in the last T \hat{y}^{(T)}
One-to-many (image captioning) Output at every t after first input

4 Activation Function: Why Tanh?

4.1 Three Key Reasons

4.1.1 Bounded output: (-1, +1)

\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}} \in (-1, +1)

In RNNs, the hidden state is repeatedly applied along the time axis:

h^{(t)} = \tanh(W_h \cdot \tanh(W_h \cdot \tanh(\cdots)))

If the activation were unbounded (e.g., ReLU), the value could diverge exponentially in the direction of \|W_h\| > 1. The saturation property of Tanh acts as a soft limiter that prevents state divergence.

4.1.2 Zero-centered

Activation Output Range Zero-centered
Sigmoid (0, 1) ✗
tanh (-1, +1) ✓
ReLU [0, \infty) ✗

Since Sigmoid always produces a positive output, the gradient passed to the next layer always has the same sign, causing the zigzag update problem. Tanh can represent both positive and negative values, allowing the hidden state to naturally move in both directions.

4.1.3 Superiority over sigmoid in gradient propagation

\frac{d}{dz}\tanh(z) = 1 - \tanh^2(z) \in (0, 1]

In BPTT (Backpropagation Through Time), the hidden state gradient is

\frac{\partial h^{(t)}}{\partial h^{(k)}} = \prod_{\tau=k+1}^{t} W_h^\top \cdot \mathrm{diag}(1 - (h^{(\tau)})^2)

If we compare the maximum values of the derivatives here:

  • \tanh Maximum derivative: 1
  • Maximum value of sigmoid derivative: 0.25

→ vanishing occurs approximately 4 times slower with tanh than with sigmoid.

WarningStill, limits exist

In the saturation region, it becomes 1 - \tanh^2(z) \to 0, and vanishing still occurs. This is the direct motivation for the emergence of LSTM/GRU, and they do not completely discard tanh but add a separate gradient highway through a gate.

NoteWireless communication analogy

The saturation characteristics of Tanh are similar to the saturation curve of a Power Amplifier (PA). It exhibits linear behavior when the input is small, but non-linear behavior where the output clamps to \pm V_\text{sat} when the input is large, which is the same in both cases. If we view an RNN as a system with a feedback loop, Tanh is a natural limiter that prevents divergence.

5 Three Architecture Types of RNN

5.1 Type 1: Hidden-to-Hidden Recurrence

h^{(t)} = \tanh(W h^{(t-1)} + U x^{(t)} + b) o^{(t)} = V h^{(t)} + c

Output at every time step + connection between hidden states. Most common and powerful form.

  • Advantage: h^{(t)} can form a sufficient statistic for the entire past, so it has high expressive power.
  • Disadvantage: Essentially, sequential calculation is forced.

5.2 Type 2: Output-to-Hidden Recurrence (Teacher Forcing)

h^{(t)} = \tanh(W o^{(t-1)} + U x^{(t)} + b)

There is no direct connection between the hidden elements, and only the previous output o^{(t-1)} is passed to the next hidden element. Teacher Forcing is injecting the correct answer y^{(t-1)} instead of o^{(t-1)} during training.

5.2.1 Advantage: Parallelization possible during training

The reason parallelization is possible is due to data dependency decoupling.

Type 1 dependency chain:

h^{(1)} \to h^{(2)} \to h^{(3)} \to \cdots

To calculate → h^{(t)}, h^{(t-1)} must be completed first. No matter how many GPUs there are, the process must proceed sequentially one step at a time.

Dependency of Type 2 + Teacher Forcing:

h^{(t)} = \tanh(W \cdot \underbrace{y^{(t-1)}}_{\text{ground truth}} + U x^{(t)})

Since y^{(0)}, y^{(1)}, \ldots, y^{(T)} are all already given in the training data, all hidden states can be calculated simultaneously.

훈련 시 (병렬):
    h^(1), h^(2), h^(3), ..., h^(T)  ←─ 한 번에 계산
                                         (모든 y가 이미 알려짐)
Type 1 (h→h) Type 2 (o→h, Teacher Forcing)
Dependency h^{(t)} \leftarrow h^{(t-1)} h^{(t)} \leftarrow y^{(t-1)} (Answer)
Access to correct answer during training Meaningless Always retained
Parallelization Impossible Possible
Expressiveness High Low (history bottleneck)

5.2.2 Cons: Less Powerful + Exposure Bias

Since h^{(t)} is not directly connected to h^{(t-1)}Z and must pass through a low-dimensional bottleneck called o^{(t-1)}, history information is lost if the dimension of o is small.

In addition, the exposure bias problem occurs, where the distributions of training (using correct answers) and inference (using self-outputs) differ.

NoteWireless communication analogy: Pilot-aided Estimation

Teacher Forcing is essentially the same as pilot-aided channel estimation.

Wireless Communication Type 2 RNN
Insert Pilot symbol (transmitter sends known signal) Inject correct answer y^{(t)} during training
Channel estimation in Pilot section hidden state update
Demodulation with estimates in the data range Self-output during inference o^{(t)} Use recursion

The mismatch between training (using pilot) and inference (data interval) is exactly equal to the exposure bias.

5.3 Type 3: Sequence-to-One

Reads the entire sequence and generates only a single output at the end. Suitable for classification problems (sentiment analysis, document classification). The structure is similar to Type 1, but the output terminal is located only at the last point in time.

6 Long-term dependency problem: Eigendecomposition analysis

6.1 Why RNNs Collapse in Long Sequences

Let’s simplify by assuming a linear RNN: h^{(t)} = W h^{(t-1)}

→ h^{(t)} = W^t h^{(0)}

If we write W as the eigenfactory W = Q \Lambda Q^{-1}:

h^{(t)} = Q \Lambda^t Q^{-1} h^{(0)}

Looking at the behavior of \Lambda^t here:

Condition Result
\|\lambda_i\| < 1 \lambda_i^t \to 0 → Gradient Vanishing
\|\lambda_i\| > 1 \lambda_i^t \to \infty → Gradient Exploding
\|\lambda_i\| = 1 Stable (but very narrow range)

Since it is virtually impossible to keep it exactly on top of \|\lambda_i\| = 1, almost all RNNs go vanishing or exploding.

Even if nonlinear \tanh is added, vanishing worsens because the derivative becomes 0 at saturation.

TipWireless communication analogy: System stability

This is the same logic as the BIBO stability of an LTI system. If a pole is inside the unit circle, the response dampens (\to 0), and if it is outside, it diverges (\to \infty). The W_{hh} eigenvalues of an RNN play exactly the same role.

6.2 The Duality of Expressiveness

There is another perspective. Deep composition of non-linear functions results in highly expressive composite functions — but at the cost of a harsh gradient landscape. In other words, the trade-off between expressiveness and learnability is the fundamental problem inherent in RNN depth.

7 Gating: LSTM and GRU

7.1 The core idea of gating

f(x) = a \cdot x (a \in [0,1], simple damping)

f(x) = a \cdot x + (1-a) \cdot m

Let’s change it to . Here, m is memory, and a is gate (the value being learned).

→ It is possible to separate the memory path that passes the past as is and the path that fuses new information. This is the key solution to the long-term dependency problem.

7.2 LSTM: Long Short-Term Memory

LSTM has two types of states:

  • c_t (cell state): long-term memory
  • h_t (hidden state): short-term memory and output

7.2.1 4 Gates

f_t = \sigma(W_f [h_{t-1}, x_t] + b_f) \quad \text{(forget gate)} i_t = \sigma(W_i [h_{t-1}, x_t] + b_i) \quad \text{(input gate)} o_t = \sigma(W_o [h_{t-1}, x_t] + b_o) \quad \text{(output gate)} g_t = \tanh(W_g [h_{t-1}, x_t] + b_g) \quad \text{(candidate cell)}

7.2.2 Update Cell state and hidden state

c_t = f_t \odot c_{t-1} + i_t \odot g_t h_t = o_t \odot \tanh(c_t)

Here, \odot is the element-wise product.

ImportantKey Point: Cell state is a separate Gradient Highway

In c_t = f_t \odot c_{t-1} + i_t \odot g_t, when it becomes f_t \approx 1, c_{t-1} remains almost unchanged.

\frac{\partial c_t}{\partial c_{t-1}} \approx f_t

is not multiplication but can be selectively kept close to 1 by a forget gate. This is the core of LSTM that enables long-term gradient flow.

7.3 GRU: Gated Recurrent Unit

r_t = \sigma(W_r [h_{t-1}, x_t]) \quad \text{(reset gate)} z_t = \sigma(W_z [h_{t-1}, x_t]) \quad \text{(update gate)} \tilde{h}_t = \tanh(W [r_t \odot h_{t-1}, x_t]) \quad \text{(candidate hidden)} h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t

GRU does not have a separate cell state and handles both long and short-terms with a single h_t. The number of gates has also been reduced from 4 to 2.

7.4 LSTM vs GRU Precision Comparison

Item LSTM GRU
Memory Structure c_t, h_t Separated h_t Single
Number of Gates 4 (forget, input, output, candidate) 2 (reset, update)
Number of parameters (approx.) 4 \times d_h(d_h + d_x) 3 \times d_h(d_h + d_x)
Expressiveness (Theory) High Low
Training data requirement High Low
Inference Speed Slow Fast

7.4.1 Which one will you choose?

WarningThe misconception that “GRU is always good”

The original slide states “GRU is on par with LSTM,” but in reality, results vary depending on the task. General guidelines:

LSTM Preference: - Very long sequence (hundreds of steps or more) - Sufficient data - Fine-grained memory control required

GRU Preference: - Insufficient data (risk of overfitting) - Short or medium-length sequence - Real-time inference is important (edge devices)

NoteWireless communication analogy: HARQ buffer structure
Wireless Communication LSTM GRU
Memory Management HARQ soft buffer + combining buffer separation Integrated buffer
Advantages Precise separate management Simple, low overhead
Suitable Scenario Multiple Round Retransmissions (Long Dependency) Single Hop, Short Packet

LSTM’s c_t is equivalent to managing long-range channel memory separately, and GRU can view this as a form compressed into a single state.

8 Other approaches to dealing with long-term dependency

In addition to gating, there are various other attempts.

8.1 Skip connections through time

Time-axis version of ResNet/DenseNet. Directly connects distant time points.

h^{(t)} = f(h^{(t-1)}, x^{(t)}) + h^{(t-d)}

8.2 Leaky units

\mu^{(t)} \leftarrow \alpha\, \mu^{(t-1)} + (1-\alpha)\, v^{(t)}

Exponential Moving Average (EMA) form. If \alpha is close to 1, it is long-term information that changes slowly; if it is close to 0, it tracks rapid changes. It has the same structure as EMA-based channel estimation in wireless communication.

8.3 Optimization tricks

  • Gradient clipping: \|g\| > c when g \leftarrow \frac{c\, g}{\|g\|}. Exploding response.
  • Information flow regularization: Response to vanishing.

8.4 Explicit memory

Uses external memory storage like a Memory Network. A structure similar to human working memory.

9 Bidirectionality and Seq-to-Seq

9.1 Bidirectional RNN

When information from not only the previous point in time but also the subsequent point in time needs to be utilized (e.g., determining word meaning after viewing the entire sentence). Use a bidirectional hidden state:

\overrightarrow{h}^{(t)} = f(\overrightarrow{h}^{(t-1)}, x^{(t)}) \overleftarrow{h}^{(t)} = f(\overleftarrow{h}^{(t+1)}, x^{(t)}) y^{(t)} = g(\overrightarrow{h}^{(t)}, \overleftarrow{h}^{(t)})

NoteWireless communication analogy: Forward-Backward Smoothing

If the Kalman filter is a forward-only estimator, the Bidirectional RNN is a neural network version of the Rauch-Tung-Striebel (RTS) smoother. It is identical to the method of combining forward and backward estimates after viewing all observations to obtain a more accurate state estimate.

9.2 Seq-to-Seq (Encoder-Decoder)

A general-purpose structure that converts variable-length input to variable-length output.

입력 시퀀스 → [Encoder RNN] → context c → [Decoder RNN] → 출력 시퀀스
  • Encoder: Reads the entire input and compresses the last hidden state c into a semantic summary
  • Decoder: Generate output one token at a time starting from c

Application: - Machine translation (Input: English, Output: Korean) - Q&A - Chatbot

WarningSeq-to-Seq bottleneck

Since the entire input is compressed into a single fixed-size c, there is severe information loss for long inputs. This is the direct motivation for the emergence of the Attention mechanism and the subsequent Transformer.

10 Deep RNN and Recursive Neural Network

10.1 Deep RNN

Multiple RNN layers are stacked vertically to enhance expressiveness. Information flows from the lower hidden to the upper hidden at the same point in time.

10.2 Recursive Neural Network

Tree structure computation graph, not a chain structure.

  • For sequence length , the computation depth is \tau, not \tauZ but \log \tau
  • Suitable for natural tree structures (parse trees, scene graphs)
  • Long-term dependency is connected via the shorter path

11 Summary

  1. The two major challenges of sequence modeling — long-term dependency and context encoding — are the evaluation criteria for all sequence models.
  2. Vanilla RNN is an elegant idea involving weight sharing and hidden state compression, but as seen in the eigendecomposition analysis, it is inherently vulnerable to gradient vanishing/exploding.
  3. Tanh became the standard activation of RNNs with bounded and zero-centered characteristics and a large derivative compared to sigmoid, but it cannot completely prevent vanishing in the saturation region.
  4. The structural differences of Type 1/2/3 RNNs determine data dependency patterns, and Teacher Forcing (Type 2) enables training parallelization but causes exposure bias.
  5. Gating in LSTM/GRU creates a gradient highway to mitigate long-term dependency problems. LSTM separates long and short-term dependencies by cell state, while GRU pursues simplification and lightweighting. The choice between the two is a trade-off based on data, sequence length, and computational resources.
  6. Bidirectional RNN, Seq-to-Seq, Deep RNN, Recursive NN, etc. are variations of RNN that handle tasks suited to their respective inductive biases.
  7. However, the inherent sequentiality of RNNs acted as a limitation in the era of parallel computing, leading to the emergence of Attention and Transformer.
