Generative Models: VAE · GAN · Diffusion

From AE to DDPM/DDIM/LDM/ControlNet

Published

May 11, 2026

1 Big picture: Topographic map of the generated model

TipOne-line summary

While discriminative models only need to learn decision boundaries, generative models must learn the shape of the entire data distribution p(x). Therefore, generative models always come down to the single problem of “how to make p(x) tractable.” VAE, GAN, and Diffusion are three strategies that provide different answers to this problem.

A classifier p(y\mid x) only needs to precisely define the boundaries between classes. On the other hand, a generative model must model the distribution from which samples can be drawn, so it needs to know the entire landscape of the data. This is why, when training with the same data, generative models generally require more data and a higher training cost.

First, get a quick overview of the core ideas of the three models.

Model Method of handling p(x) Learning objective Stability Sample efficiency
VAE Bypass latent variable z: p(x)=\int p(x\mid z)p(z)\,dz, ELBO lower bound maximization Variational Inference (ELBO) Stable Moderate
GAN Generates samples only without specifying distribution, evaluates by discriminator Adversarial minimax Unstable High
Diffusion Learn the inverse process of noiseization Maximum Likelihood Estimation (MLE) approx. Stable Low (Requires a lot of data)

2 VAE Review: Latent Variables and ELBO

NoteDirect Answer

The loss of the VAE is the reconstruction error + latent distribution normalization (KL). This is equivalent to maximizing ELBO, which is the lower bound of the log-likelihood \log p(x), and the non-differentiable problem of latent variable sampling is solved using the reparameterization trick.

2.1 Why can’t I handle p(x) directly

Given the data X=\{x_1,\dots,x_N\}, it is difficult to directly model p(x). Therefore, we bypass this by introducing the known (easy to sample) prior distribution p(z)=\mathcal N(0,I).

p(x)=\int_z p(x\mid z)\,p(z)\,dz .

The problem is that this integral is still difficult to handle (z integral over the entire space). So, we replace the posterior distribution p(z\mid x) with a parameterized approximation distribution q_\phi(z). This is variational inference.

2.2 ELBO Induction

Starting from Bayes’ rule and \log p(x)=\log p(x)\cdot\int q_\phi(z)\,dz, if we organize:

\log p(x)=\underbrace{\mathbb E_{q_\phi}\!\big[\log p(x,z)-\log q_\phi(z)\big]}_{\textstyle \text{ELBO}} \;+\;\underbrace{\mathrm{KL}\!\big(q_\phi(z)\,\|\,p(z\mid x)\big)}_{\textstyle \ge 0}.

The left side \log p(x) is constant for \theta,\phi. Since the KL term is always \ge 0, increasing ELBO = making the approximate posterior q_\phi closer to the true posterior p(z\mid x).

If you expand ELBO one more time, two familiar terms appear.

\mathrm{ELBO}=\mathbb E_{q_\phi}\!\big[\log p(x\mid z)\big]-\mathrm{KL}\!\big(q_\phi(z)\,\|\,p(z)\big).

  • First term: reconstruction — How well decoder p(x\mid z) reconstructs x
  • Second term: Regularization — Force the distribution of the latent z to follow \mathcal N(0,I)

Therefore, the VAE loss is

\min_{\theta,\phi}\;\; -\,\mathbb E_{q_\phi}\!\big[\log p_\theta(x\mid z)\big]\;+\;\mathrm{KL}\!\big(q_\phi(z\mid x)\,\|\,p(z)\big).

2.3 Reparameterization Trick

The backpropagation path is \mathcal L \to z \to \phi, but if we sample z\sim q_\phi(z\mid x), the operation is not differentiable. We bypass this by separating randomness into external variables.

z=\mu_\phi(x)+\sigma_\phi(x)\odot\epsilon,\qquad \epsilon\sim\mathcal N(0,I).

Now, randomness exists only in \epsilon, and since the path passing through \mu_\phi,\sigma_\phi is deterministic, a gradient flows.

ImportantWireless Communication Analogy — Reparameterization = Received Signal Model

Let’s consider the received signal y=h\,x+n,\ n\sim\mathcal N(0,\sigma^2). If we separate the channel gain h (the deterministic part) and the noise n (the random part), derivatives with respect to system parameters flow only along the deterministic path, and randomness is isolated from the noise term. Reparameterization z=\mu+\sigma\epsilon is exactly this structure — it creates samples in the form of “mean (signal) + standard deviation (noise intensity) × standard normal”.

3 GAN: Adversarial Learning

3.1 Adversarial examples and adversarial training are different

WarningCaution: Confusion

Adversarial example: Adding subtle perturbations to the input to trick an already trained neural network. For instance, adding a patch invisible to the human eye to an image of a cat causes it to misclassify it as a “desktop computer” with high confidence. The objective is an attack.

Adversarial training (= GAN learning paradigm): Learning in which two networks compete to deceive/not deceive each other to improve together. The goal is to make the generator better.

Both share the word “adversarial,” but their purposes are diametrically opposed. (LeCun noted in 2016 that “the most interesting idea in ML over the last decade is adversarial learning.”)

3.2 Components: Generator G and Discriminator D

  • Generator G: Takes a d-dimensional random vector z (e.g., a sample from \mathcal N(0,I)) as input and outputs an image. The z space is the “latent space”, and G mimics the data generation distribution.
  • Discriminator D: Determines whether the input image is real (real-world data) or fake (created by G). Output D(x)\in[0,1] is the “probability that it is real”.

What makes a good generator? It is one that produces a high degree of “realistic appearance in the generated images.” However, humans cannot grade whether they look realistic every time. Therefore, a second network called a discriminator is introduced and used as an automated grader—this is the core idea of adversarial learning.

3.3 minimax objective function

\min_G\max_D\; V(D,G)=\mathbb E_{x\sim p_{\text{data}}}\big[\log D(x)\big] +\mathbb E_{z\sim p_z}\big[\log\!\big(1-D(G(z))\big)\big].

The physical meaning of is “log probability that x is real” + “log probability that G(z) is fake”. It must be read in terms of two variables.

  • D Perspective (Maximization): If x is true, then D(x)\to1, so the first term \log D(x)\to0 (maximum). If G(z) is false, then D(G(z))\to0, so the second term \log(1-0)\to0. In other words, if D does well, V becomes larger → D maximizes V.
  • G Perspective (Minimization): If G successfully deceives D, then D(G(z))\to1, which is the second term \log(1-1)\to-\infty. That is, if G performs well, V becomes smaller → G minimizes V.

It is a zero-sum non-cooperative game (minimax problem) where players pull in opposite directions.

Notelearning = block coordinate descent (alternating optimization)

The parameters of G and D are included together within the entire parameter set. Optimization is performed alternately by fixing one side and descending or ascending (gradient) on the other. This is block coordinate descent. Instead of descending all coordinates simultaneously, variable blocks are divided and descended alternately. (The maximization term is unified into descent simply by reversing its sign.)

Update written in three steps:

  1. D Update (Real): To make D say “Real” for real data. D(x_{\text{real}})\to1.
  2. D Update (Fake): To make D say “fake” for fake data. D(G(z))\to0.
  3. G Update: Update G so that D mistakes the fake for “real”. To become D(G(z))\to1.

At each step, the higher side is barely updated, while the lower side is updated significantly. When updating G, the gradient is backpropagated serially through D to G; therefore, by the time G is reached, the gradient has already decreased significantly, making it difficult to train G (connected to the three major challenges below).

3.4 Optimal Discriminator and JSD: Why is it p_g=p_{\text{data}} if it works well?

If we fix G, we can maximize V with respect to D. Differentiating the integral interior with respect to D(x) and setting it to zero gives the optimal discriminator:

D^\*(x)=\frac{p_{\text{data}}(x)}{p_{\text{data}}(x)+p_g(x)} .

Substituting this, the objective function is simplified to Jensen–Shannon divergence (JSD).

V(G,D^\*)=-\log 4+2\,\mathrm{JSD}\!\big(p_{\text{data}}\,\|\,p_g\big).

Since ZZZPH0009154ZZZ \mathrm{JSD}\ge0 and p_g=p_{\text{data}}, 0, the global optimum is p_g=p_{\text{data}}, and the value therein is -\log 4\approx-1.386. (This value was numerically verified using the appendix code.)

3.5 Why GANs are effective: hard negative

To accurately map the “mountain ranges” of a data generation distribution, samples near the borders/envelopes are decisive. In taxonomic literature, challenging negative samples near the boundaries are referred to as hard negatives (hard samples). Typically, such samples are difficult to collect externally.

However, the generator G naturally learns to create data near the decision boundary in order to effectively fool the discriminator D. In other words, adversarial competition produces hard negatives for free, with no additional cost. As a result, GANs are sample-efficient and clearly capture the boundaries of the distribution. (The original motivation for proposing GANs in 2014 was to address data deficiency.)

3.6 3 Major Practical Challenges

WarningWhy GAN training is notorious
  1. Non-convergence: Parameters oscillate or diverge and do not converge. D learns much more easily/faster than G (since it only needs to learn boundaries), resulting in a power imbalance. If D becomes excessively strong, the two models fail to improve together with each iteration and become unstable.
  2. Mode Collapse: A phenomenon where G repeatedly generates only a few easy samples, deceiving D and settling there. Failing to learn all the various peaks (modes) of the true distribution, it creates only a few sharp peaks → Loss of diversity.
  3. Diminished Gradient: If D performs too well, the gradient backpropagating to G disappears, so G learns nothing.

Numbers 2 and 3 essentially stem from the imbalance in learning difficulty/speed between D and G. Tuning hyperparameters (learning rate, batch size) is “artistically” difficult.

3.7 Stabilization variants

Hundreds of variations have emerged targeting the two problems above (mode collapse and non-convergence).

  • LSGAN (Least Squares GAN): Least Squares Loss
  • WGAN (Wasserstein GAN): Smoother loss with Wasserstein distance
  • WGAN-GP: WGAN + Gradient Penalty
  • BEGAN (Boundary Equilibrium GAN), DCGAN, CycleGAN, etc.

The fact that GANs can freely change their loss functions (e.g., Wasserstein, Hinge loss) is a strength, but it is also a weakness in that the high degree of freedom in tuning makes stabilization difficult.

ImportantWireless Communication Analogy — GAN = Spoofing Transmitter vs. Signal Detector Game

Let G be the spoofing transmitter and D be the signal detector. D is a Neyman–Pearson-type detector that determines whether the input is a “real signal” or a “synthetic signal,” and the optimal discriminator D^\*=\tfrac{p_{\text{data}}}{p_{\text{data}}+p_g} is exactly the same form as the likelihood ratio test of the two hypotheses. From this perspective:

  • Mode Collapse = The transmitter loses constellation diversity and repeatedly transmits only a few symbols
  • Gradient Vanishing = The gradient of the likelihood ratio disappears as the detector becomes saturated deep in the high-SNR region
  • minimax / zero-sum = Jammer vs. Receiver, or the game structure of worst-case detection

3.8 Connection between VAE and GAN

Since the input z of the generator is usually modeled as \mathcal N(0,I), the VAE decoder can be used directly as the GAN generator. By adding the decoder =G and the discriminator to the VAE encoder-decoder structure, it becomes a GAN. The two are similar structures that are interchangeable. The difference lies in the learning paradigm (VAE = Variational Inference/MLE family, GAN = Adversarial Learning).

4 Diffusion Model

4.1 GAN vs Diffusion: Why Switched

TipDirect Answer

GANs are fast and have good sample efficiency but are unstable (mode collapse/non-convergence). Diffusion is slow but stable and offers excellent quality. Key difference: Diffusion is trained using a well-understood optimization called Maximum Likelihood Estimation (MLE), and trains a single model without pitting two models against each other → the concept of mode collapse itself does not exist.

Diffusion (DDPM) GAN
Pros High-quality, sharp samples with vivid detail / MLE = Well-understood Optimization / Both Image & Audio High Quality (Image & Audio) / Relatively Fast Training / Various loss functions (Wasserstein, Hinge) available
Cons Slow and computationally expensive (T iterations) / Requires a lot of data Difficult to train / Sensitive to hyperparameters / Mode collapse
NoteProfessor’s Intuition — Building a “Probability Tower”

While GANs draw sharp boundaries using hard negatives, Diffusion creates mountain ranges of distribution in a different way. By providing data points from every location and training the noiseization process, it learns “how high to stack probabilities at each location.” In other words, it reconstructs the entire terrain, including not only boundaries but also the heights of the peaks. However, since it requires data from every location, a large amount of data must be collected.

NoteStability Analogy — Highly Volatility Stocks vs. Steady Rising Stocks

GANs can produce a great model overnight if you’re lucky, but if things go wrong, training all night will yield useless results that have completely collapsed (resulting in massive financial losses for large-scale training). Diffusion is slow, but it produces a model that improves steadily, little by little, every day — it offers peace of mind. This is why the industry has chosen Diffusion. (Today, most image and video generation is Diffusion-based.)

4.2 DDPM: Two processes

DDPM(Denoising Diffusion Probabilistic Model, 2020) consists of two processes.

4.2.1 Forward (diffusion) process — fixed

A Markov chain of latent variables, progressively adding Gaussian noise with a pre-scheduled variance \beta_t.

q(x_t\mid x_{t-1})=\mathcal N\!\big(x_t;\ \sqrt{1-\beta_t}\,x_{t-1},\ \beta_t I\big).

  • \beta_t: Noise Magnitude at time t
  • \alpha_t=1-\beta_t: Signal retention size, and \bar\alpha_t=\prod_{s=1}^{t}\alpha_s

By using Markovs and Gaussian composition, an arbitrary time t can be represented in a closed-form.

\boxed{\,x_t=\sqrt{\bar\alpha_t}\,x_0+\sqrt{1-\bar\alpha_t}\,\epsilon,\qquad \epsilon\sim\mathcal N(0,I)\,}

If we set \beta_t sufficiently small and increase T to take the continuous limit of \delta t\to0, it becomes a stabilistic differential equation (SDE).

dx=-\tfrac12\,\beta(t)\,x\,dt+\sqrt{\beta(t)}\,dW_t,\qquad (W_t:\text{Wiener 과정}).

Since the noise \epsilon at each t is random and uncontrollable, it is a stochastic differential equation.

4.2.2 Reverse (Denoising) Process — Learning Target

The inverse process according to Bayes’ rule is

q(x_{t-1}\mid x_t)=\frac{q(x_t\mid x_{t-1})\,q(x_{t-1})}{q(x_t)}

, but q(x_{t-1}), q(x_t) is unknown (bad news). Good news: If \beta_t\ll1, then it is true. There is a theorem that the inverse process q(x_{t-1}\mid x_t) is well approximated by a Gaussian. Therefore, we approximate it using a Gaussian parameterized by a neural network.

p_\theta(x_{t-1}\mid x_t)=\mathcal N\!\big(x_{t-1};\ \mu_\theta(x_t,t),\ \sigma_t^2 I\big).

What we will learn is the average of this Gaussian, \mu_\theta (=denoiser).

4.2.3 Training: Predict “noise” instead of the mean

By organizing the true mean in the closed form of Forward, \mu_\theta can be reparameterized into noise predictor \epsilon_\theta(x_t,t).

\mu_\theta(x_t,t)=\frac{1}{\sqrt{\alpha_t}}\!\left(x_t-\frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\,\epsilon_\theta(x_t,t)\right).

Then, learning becomes surprisingly simple. For each t, the real noise \epsilon is taken as the correct answer, and the neural network regresses to identify that noise.

\boxed{\;\mathcal L_{\text{simple}}=\mathbb E_{t,\,x_0,\,\epsilon}\Big[\ \big\|\,\epsilon-\epsilon_\theta\big(\sqrt{\bar\alpha_t}\,x_0+\sqrt{1-\bar\alpha_t}\,\epsilon,\ t\big)\big\|^2\ \Big]\;}

Algorithm:

  1. Time t extraction, correct noise \epsilon\sim\mathcal N(0,I) extraction
  2. x_t=\sqrt{\bar\alpha_t}\,x_0+\sqrt{1-\bar\alpha_t}\,\epsilon Calculation
  3. Slope descent to \nabla_\theta\|\epsilon-\epsilon_\theta(x_t,t)\|^2

4.2.4 Generation(Sampling)

Starting from x_T\sim\mathcal N(0,I), it goes down to t=T,\dots,1Z and denoises step by step to the learned \epsilon_\theta.

\hat x_0=\frac{1}{\sqrt{\bar\alpha_t}}\big(x_t-\sqrt{1-\bar\alpha_t}\,\epsilon_\theta(x_t,t)\big),\qquad x_{t-1}=\mu_\theta(x_t,\hat x_0)+\sigma_t z,\quad z\sim\mathcal N(0,I).

WarningNote regarding the number of steps

The standard implementation of DDPM typically uses a sequential inverse process of T\approx1000 steps (default in papers). This sequentiality is the root cause of the slowness. (Some sources cite much larger figures, but the exact value depends on the noise schedule and resolution.) The key point is that “hundreds to thousands of forward passes are required to obtain a single sample,” and DDIM reduces this to dozens of steps.

4.3 Three Perspectives: Variation · Score · Flow

Note

Diffusion is interpreted equivalently by three mathematical tools.

Perspective Root Representative Method
Variational view (VAE formula) Variational inference DDPM
Score-based view Energy-based models in statistical physics NCSN / score-SDE
Flow-based view Normalizing Flow Flow Matching

All three perspectives converge to continuous-time formulations, and flow matching, in particular, reduces the number of iterations, becoming the de facto standard for recent generation. This theorem focuses on the most basic variational perspective (DDPM).

4.4 DDIM: Non-Markov + Deterministic Sampling

TipWhy DDIM?

DDPM offers good quality but (1) sampling is slow, (2) control is difficult because it is a stochastic path, and (3) every sample requires a full inverse SDE. The goal of DDIM is: fewer steps + deterministic path + maintaining the same marginal distribution as DDPM.

DDIM reinterprets the forward process as a non-Markovian deterministic mapping. It becomes non-Markovian by making x_t depend not only on x_{t-1}* but also on x_0. The key point is that the implementation is the same as DDPM, but the mathematical interpretation is different — DDPM is based on SDE, while DDIM is based on ODE.

Generalized reverse sampling:

x_{t-1}=\sqrt{\bar\alpha_{t-1}}\,\hat x_0+\sqrt{1-\bar\alpha_{t-1}-\sigma_t^2}\;\epsilon_\theta(x_t,t)+\sigma_t z, \sigma_t=\eta\sqrt{\frac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t}}\sqrt{1-\frac{\bar\alpha_t}{\bar\alpha_{t-1}}},\qquad z\sim\mathcal N(0,I).

  • \eta=0\Rightarrow\sigma_t=0: Truly deterministic(no noise injection)
  • \eta=1: Identical to DDPM(Markov·Stochastic)
ImportantKey Benefit — Training remains the same, only sampling accelerated

The loss function of is exactly the same as DDPM. That is, a noise predictor \epsilon_\theta trained once can be used directly for DDIM sampling. Thanks to the deterministic process of \sigma_t=0, denoising is well-defined even at arbitrary time intervals, allowing for fast sampling with a significantly reduced number of steps.

4.5 LDM (Stable Diffusion): Latent Space Diffusion

Learning diffusion directly in pixel space incurs too high a memory cost. LDM compresses images into a low-dimensional latent and then learns diffusion in that latent space. As a text conditional large-scale model, the sweet spot of the downsampling rate is important.

  • LDM-1(Uncompressed): Training time is excessively long
  • LDM-32(Overcompression): Quality degradation due to information loss
  • LDM-4 / 8 / 16: Competitive performance — Moderate compression is optimal

4.6 ControlNet: Conditional fine-tuning of small amounts of data

Efficiently fine-tunes an unconditionally trained image diffusion model for image-conditional scenarios with a relatively small (<50K) input–output pairs.

  • Idea: Process condition images using the pre-trained noise prediction U-Net
  • Encoder: Copy and initialize pre-trained U-Net parameters, then fine-tune
  • Decoder: Combines encoded condition information + noise image, but injects control signals using zero convolution (stable incremental learning as the influence is 0 initially)
  • Training data \sim100\text{K} Scale — Approximately 1/50,000 of LAION-5B

Since condition information is introduced gradually rather than suddenly, it can be generally applied to any image condition (edge, pose, depth, etc.).

ImportantWireless Communication Analogy — Diffusion = Progressive AWGN and its inverse operation

The closed form of Forward, x_t=\sqrt{\bar\alpha_t}\,x_0+\sqrt{1-\bar\alpha_t}\,\epsilon, is literally the same as the fading + AWGN channel model with signal gain \sqrt{\bar\alpha_t} and noise power 1-\bar\alpha_t. As t increases, the SNR decreases monotonically, reaching SNR\to0 (pure noise) at t=T.

  • Training Noise Prediction \epsilon_\theta = Training MMSE Estimator for Noise Estimation
  • Reverse Process = Step-by-step denoising, i.e., a structure similar to Iterative Equalization/Continuous Interference Removal (SIC)
  • Deterministic path of DDIM(\eta=0) = Deterministic equalization path without noise reinjection
  • \beta_t Schedule = SNR Schedule Design

TipKey Message

6 Appendix: NumPy Validation Code

The code below numerically verifies the two key results of the text — (1) whether the repeated sampling and closed form of the DDPM forward give the same distribution, and (2) whether the objective function value of the GAN optimal discriminator is exactly -\log4 when p_g=p_{\text{data}}.

import numpy as np
rng = np.random.default_rng(0)

# ---- 노이즈 스케줄 (선형) ----
T = 200
betas  = np.linspace(1e-4, 0.02, T)
alphas = 1 - betas
abar   = np.cumprod(alphas)          # ᾱ_t = ∏ α_s

x0 = 3.0                              # 스칼라 "데이터"
t  = 150                             # 검사할 시각

# (a) 반복 샘플링: q(x_t | x_{t-1}) 를 t번
N = 200_000
xt = np.full(N, x0, dtype=float)
for s in range(t):
    eps = rng.standard_normal(N)
    xt = np.sqrt(alphas[s])*xt + np.sqrt(betas[s])*eps

# (b) 닫힌 형태: x_t = √ᾱ_t x0 + √(1-ᾱ_t) ε
eps = rng.standard_normal(N)
xt_cf = np.sqrt(abar[t-1])*x0 + np.sqrt(1-abar[t-1])*eps

print(f"반복 샘플링  : mean={xt.mean():.4f}, var={xt.var():.4f}")
print(f"닫힌 형태    : mean={xt_cf.mean():.4f}, var={xt_cf.var():.4f}")
print(f"이론값       : mean={np.sqrt(abar[t-1])*x0:.4f}, "
      f"var={1-abar[t-1]:.4f}")
import numpy as np

# 최적 판별자 D*(x) = p_data / (p_data + p_g)
# V(G,D*) = E_pd[log D*] + E_pg[log(1-D*)] = -log4 + 2·JSD(pd||pg)
xs = np.linspace(-8, 8, 4000); dx = xs[1]-xs[0]
gauss = lambda x, m, s: np.exp(-0.5*((x-m)/s)**2)/(s*np.sqrt(2*np.pi))

pd = gauss(xs, 0, 1)
for label, pg in [("p_g = p_data ", gauss(xs, 0.0, 1.0)),
                  ("p_g 이동됨    ", gauss(xs, 1.5, 1.0))]:
    Dstar = pd/(pd+pg+1e-12)
    V = (pd*np.log(Dstar+1e-12)).sum()*dx + (pg*np.log(1-Dstar+1e-12)).sum()*dx
    print(f"{label}: V(G,D*) = {V:.4f}   (-log4 = {-np.log(4):.4f})")
import numpy as np
# 재매개변수화: z = μ + σ⊙ε 가 N(μ, σ²) 를 주는지 확인
rng = np.random.default_rng(1)
mu, sigma = 2.0, 0.5
eps = rng.standard_normal(500_000)
z = mu + sigma*eps
print(f"z ~ N(μ,σ²) 기대: mean={mu}, var={sigma**2:.4f}")
print(f"표본          : mean={z.mean():.4f}, var={z.var():.4f}")
NoteInterpretation of execution results
  • DDPM: Repeated sampling · Closed form · Mean/variance of theoretical values match → Confirms that x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon is accurate.
  • GAN: When p_g=p_{\text{data}}, it falls exactly to V=-\log4, and if the distribution is off, it becomes larger (2\,\mathrm{JSD}\ge0).
  • Reparameterization: \mu+\sigma\epsilon reproduces the mean/variance of the target Gaussian → The distribution is preserved even when randomness is isolated in \epsilon.

# Big picture: Topographic map of the generated model {#sec-overview}

::: {.callout-tip}
## One-line summary
While **discriminative models** only need to learn decision boundaries, **generative models** must learn the *shape* of the entire data distribution $p(x)$. Therefore, generative models always come down to the single problem of "how to make $p(x)$ tractable." VAE, GAN, and Diffusion are three strategies that provide different answers to this problem.
:::

A classifier $p(y\mid x)$ only needs to precisely define the boundaries between classes. On the other hand, a generative model must model the distribution from which samples can be drawn, so it needs to know the entire landscape of the data. This is why, when training with the same data, **generative models generally require more data and a higher training cost**.

First, get a quick overview of the core ideas of the three models.

| Model | Method of handling $p(x)$ | Learning objective | Stability | Sample efficiency |
|---|---|---|---|---|
| **VAE** | Bypass latent variable $z$: $p(x)=\int p(x\mid z)p(z)\,dz$, ELBO lower bound maximization | Variational Inference (ELBO) | Stable | Moderate |
| **GAN** | Generates *samples only* without specifying distribution, evaluates by discriminator | Adversarial minimax | **Unstable** | **High** |
| **Diffusion** | Learn the inverse process of noiseization | Maximum Likelihood Estimation (MLE) approx. | Stable | Low (Requires a lot of data) |

```{mermaid}
flowchart LR
    AE["Auto-Encoder<br/>(결정적 압축)"] --> VAE["VAE<br/>잠재공간을 N(0,I)로<br/>확률화 + 디코더"]
    VAE -->|디코더 = 생성기| GAN["GAN<br/>생성기 G vs 판별자 D<br/>적대적 학습"]

    DIFF --> DDPM --> DDIM --> LDM --> ControlNet
```

# VAE Review: Latent Variables and ELBO {#sec-vae}

::: {.callout-note}
## Direct Answer
The loss of the VAE is the **reconstruction error + latent distribution normalization (KL)**. This is equivalent to maximizing **ELBO**, which is the lower bound of the log-likelihood $\log p(x)$, and the non-differentiable problem of latent variable sampling is solved using the **reparameterization trick**.
:::

## Why can't I handle $p(x)$ directly

Given the data $X=\{x_1,\dots,x_N\}$, it is difficult to directly model $p(x)$. Therefore, we bypass this by introducing the known (easy to sample) prior distribution $p(z)=\mathcal N(0,I)$.

$$
p(x)=\int_z p(x\mid z)\,p(z)\,dz .
$$

The problem is that this integral is still difficult to handle ($z$ integral over the entire space). So, we replace the posterior distribution $p(z\mid x)$ with a **parameterized approximation distribution** $q_\phi(z)$. This is **variational inference**.

## ELBO Induction

Starting from Bayes' rule and $\log p(x)=\log p(x)\cdot\int q_\phi(z)\,dz$, if we organize:

$$
\log p(x)=\underbrace{\mathbb E_{q_\phi}\!\big[\log p(x,z)-\log q_\phi(z)\big]}_{\textstyle \text{ELBO}}
\;+\;\underbrace{\mathrm{KL}\!\big(q_\phi(z)\,\|\,p(z\mid x)\big)}_{\textstyle \ge 0}.
$$

The left side $\log p(x)$ is constant for $\theta,\phi$. Since the KL term is always $\ge 0$, **increasing ELBO = making the approximate posterior $q_\phi$ closer to the true posterior $p(z\mid x)$**.

If you expand ELBO one more time, two familiar terms appear.

$$
\mathrm{ELBO}=\mathbb E_{q_\phi}\!\big[\log p(x\mid z)\big]-\mathrm{KL}\!\big(q_\phi(z)\,\|\,p(z)\big).
$$

- First term: **reconstruction** — How well decoder $p(x\mid z)$ reconstructs $x$
- Second term: **Regularization** — Force the distribution of the latent $z$ to follow $\mathcal N(0,I)$

Therefore, the VAE loss is

$$
\min_{\theta,\phi}\;\; -\,\mathbb E_{q_\phi}\!\big[\log p_\theta(x\mid z)\big]\;+\;\mathrm{KL}\!\big(q_\phi(z\mid x)\,\|\,p(z)\big).
$$

## Reparameterization Trick

The backpropagation path is $\mathcal L \to z \to \phi$, but if we *sample* $z\sim q_\phi(z\mid x)$, the operation is not differentiable. We bypass this by separating randomness into external variables.

$$
z=\mu_\phi(x)+\sigma_\phi(x)\odot\epsilon,\qquad \epsilon\sim\mathcal N(0,I).
$$

Now, randomness exists only in $\epsilon$, and since the path passing through $\mu_\phi,\sigma_\phi$ is deterministic, a gradient flows.

::: {.callout-important}
## Wireless Communication Analogy — Reparameterization = Received Signal Model
Let's consider the received signal $y=h\,x+n,\ n\sim\mathcal N(0,\sigma^2)$. If we **separate** the channel gain $h$ (the deterministic part) and the noise $n$ (the random part), derivatives with respect to system parameters flow only along the deterministic path, and randomness is isolated from the noise term. Reparameterization $z=\mu+\sigma\epsilon$ is exactly this structure — it creates samples in the form of "mean (signal) + standard deviation (noise intensity) × standard normal".
:::

# GAN: Adversarial Learning {#sec-gan}

## Adversarial examples and adversarial training are different

::: {.callout-warning}
## Caution: Confusion
**Adversarial example**: Adding subtle perturbations to the input to *trick* an already trained neural network. For instance, adding a patch invisible to the human eye to an image of a cat causes it to misclassify it as a "desktop computer" with high confidence. The objective is an *attack*.

**Adversarial training (= GAN learning paradigm)**: Learning in which two networks compete to *deceive/not deceive* each other to improve together. The goal is to *make the generator better*.

Both share the word "adversarial," but their purposes are diametrically opposed. (LeCun noted in 2016 that "the most interesting idea in ML over the last decade is adversarial learning.")
:::

## Components: Generator G and Discriminator D

- **Generator $G$**: Takes a $d$-dimensional random vector $z$ (e.g., a sample from $\mathcal N(0,I)$) as input and outputs an image. The $z$ space is the "latent space", and $G$ mimics the data generation distribution.
- **Discriminator $D$**: Determines whether the input image is **real (real-world data)** or **fake (created by $G$)**. Output $D(x)\in[0,1]$ is the "probability that it is real".

What makes a good generator? It is one that produces a high degree of "realistic appearance in the generated images." However, humans cannot grade *whether they look realistic* every time. Therefore, a second network called a **discriminator** is introduced and used as an automated grader—this is the core idea of adversarial learning.

```{mermaid}
flowchart LR
    Z["z ~ N(0,I)"] --> G["생성기 G"]
    G --> FAKE["가짜 이미지 G(z)"]
    REAL["진짜 이미지 x ~ p_data"] --> D
    FAKE --> D["판별자 D"]
    D --> OUT["D(·) ∈ [0,1]<br/>진짜일 확률"]
```

## minimax objective function

$$
\min_G\max_D\; V(D,G)=\mathbb E_{x\sim p_{\text{data}}}\big[\log D(x)\big]
+\mathbb E_{z\sim p_z}\big[\log\!\big(1-D(G(z))\big)\big].
$$

The physical meaning of is *"log probability that $x$ is real" + "log probability that $G(z)$ is fake"*. It must be read in terms of two variables.

- **$D$ Perspective (Maximization)**: If $x$ is true, then $D(x)\to1$, so the first term $\log D(x)\to0$ (maximum). If $G(z)$ is false, then $D(G(z))\to0$, so the second term $\log(1-0)\to0$. In other words, if $D$ does well, $V$ becomes larger → **$D$ maximizes $V$**.
- **$G$ Perspective (Minimization)**: If $G$ successfully deceives $D$, then $D(G(z))\to1$, which is the second term $\log(1-1)\to-\infty$. That is, if $G$ performs well, $V$ becomes smaller → **$G$ minimizes $V$**.

It is a **zero-sum non-cooperative game (minimax problem)** where players pull in opposite directions.

::: {.callout-note}
## learning = block coordinate descent (alternating optimization)
The parameters of $G$ and $D$ are included together within the entire parameter set. Optimization is performed **alternately** by fixing one side and descending or ascending (gradient) on the other. This is **block coordinate descent**. Instead of descending all coordinates simultaneously, variable blocks are divided and descended alternately. (The maximization term is unified into descent simply by reversing its sign.)
:::

Update written in three steps:

1. **D Update (Real)**: To make $D$ say "Real" for real data. $D(x_{\text{real}})\to1$.
2. **D Update (Fake)**: To make $D$ say "fake" for fake data. $D(G(z))\to0$.
3. **G Update**: Update $G$ so that $D$ mistakes the fake for "real". To become $D(G(z))\to1$.

At each step, the *higher side is barely updated, while the lower side is updated significantly*. When updating $G$, the gradient is backpropagated serially through $D$ to $G$; therefore, by the time $G$ is reached, the gradient has already decreased significantly, making it difficult to train $G$ (connected to the three major challenges below).

## Optimal Discriminator and JSD: Why is it $p_g=p_{\text{data}}$ if it works well? {#sec-gan-optimal}

If we fix $G$, we can maximize $V$ with respect to $D$. Differentiating the integral interior with respect to $D(x)$ and setting it to zero gives the **optimal discriminator**:

$$
D^\*(x)=\frac{p_{\text{data}}(x)}{p_{\text{data}}(x)+p_g(x)} .
$$

Substituting this, the objective function is simplified to **Jensen–Shannon divergence (JSD)**.

$$
V(G,D^\*)=-\log 4+2\,\mathrm{JSD}\!\big(p_{\text{data}}\,\|\,p_g\big).
$$

Since ZZZPH0009154ZZZ  $\mathrm{JSD}\ge0$ and $p_g=p_{\text{data}}$, $0$, the **global optimum is $p_g=p_{\text{data}}$, and the value therein is $-\log 4\approx-1.386$**. (This value was numerically verified using the appendix code.)

## Why GANs are effective: hard negative

To accurately map the "mountain ranges" of a data generation distribution, samples near the **borders/envelopes** are decisive. In taxonomic literature, challenging negative samples near the boundaries are referred to as **hard negatives (hard samples)**. Typically, such samples are difficult to collect externally.

However, the generator $G$ naturally learns to create data near the decision boundary in order to **effectively fool the discriminator $D$**. In other words, adversarial competition produces hard negatives *for free*, with no additional cost. As a result, GANs are sample-efficient and clearly capture the boundaries of the distribution. (The original motivation for proposing GANs in 2014 was to address data deficiency.)

## 3 Major Practical Challenges

::: {.callout-warning}
## Why GAN training is notorious
1. **Non-convergence**: Parameters oscillate or diverge and do not converge. $D$ learns *much more easily/faster* than $G$ (since it only needs to learn boundaries), resulting in a power imbalance. If $D$ becomes excessively strong, the two models fail to improve together with each iteration and become unstable.
2. **Mode Collapse**: A phenomenon where $G$ repeatedly generates *only a few easy samples*, deceiving $D$ and settling there. Failing to learn all the various peaks (modes) of the true distribution, it creates only a few sharp peaks → Loss of diversity.
3. **Diminished Gradient**: If $D$ performs too well, the gradient backpropagating to $G$ disappears, so $G$ learns nothing.

Numbers 2 and 3 essentially stem from the **imbalance in learning difficulty/speed between $D$ and $G$**. Tuning hyperparameters (learning rate, batch size) is "artistically" difficult.
:::

## Stabilization variants

Hundreds of variations have emerged targeting the two problems above (mode collapse and non-convergence).

- **LSGAN** (Least Squares GAN): Least Squares Loss
- **WGAN** (Wasserstein GAN): Smoother loss with Wasserstein distance
- **WGAN-GP**: WGAN + Gradient Penalty
- **BEGAN** (Boundary Equilibrium GAN), DCGAN, CycleGAN, etc.

The fact that GANs can freely change their loss functions (e.g., Wasserstein, Hinge loss) is a strength, but it is also a weakness in that *the high degree of freedom in tuning makes stabilization difficult*.

::: {.callout-important}
## Wireless Communication Analogy — GAN = Spoofing Transmitter vs. Signal Detector Game
Let $G$ be the **spoofing transmitter** and $D$ be the **signal detector**. $D$ is a Neyman–Pearson-type detector that determines whether the input is a "real signal" or a "synthetic signal," and the optimal discriminator $D^\*=\tfrac{p_{\text{data}}}{p_{\text{data}}+p_g}$ is exactly the same form as the **likelihood ratio test** of the two hypotheses. From this perspective:

- **Mode Collapse** = The transmitter loses constellation diversity and repeatedly transmits *only a few symbols*
- **Gradient Vanishing** = The gradient of the likelihood ratio disappears as the detector becomes saturated deep in the high-SNR region
- **minimax / zero-sum** = Jammer vs. Receiver, or the game structure of worst-case detection
:::

## Connection between VAE and GAN

Since the input $z$ of the generator is usually modeled as $\mathcal N(0,I)$, the **VAE decoder can be used directly as the GAN generator**. By adding the decoder $=G$ and the discriminator to the VAE encoder-decoder structure, it becomes a GAN. The two are similar structures that are interchangeable. The difference lies in the *learning paradigm* (VAE = Variational Inference/MLE family, GAN = Adversarial Learning).

# Diffusion Model {#sec-diffusion}

## GAN vs Diffusion: Why Switched

::: {.callout-tip}
## Direct Answer
GANs are fast and have good sample efficiency but are **unstable (mode collapse/non-convergence)**. Diffusion is **slow but stable** and offers excellent quality. Key difference: Diffusion is trained using a *well-understood* optimization called **Maximum Likelihood Estimation (MLE)**, and trains a **single model** without pitting two models against each other → the concept of mode collapse itself does not exist.
:::

| | **Diffusion (DDPM)** | **GAN** |
|---|---|---|
| Pros | High-quality, sharp samples with vivid detail / **MLE = Well-understood Optimization** / Both Image & Audio | High Quality (Image & Audio) / **Relatively Fast Training** / Various loss functions (Wasserstein, Hinge) available |
| Cons | **Slow and computationally expensive** ($T$ iterations) / Requires a lot of data | Difficult to train / **Sensitive to hyperparameters** / **Mode collapse** |

::: {.callout-note}
## Professor's Intuition — Building a "Probability Tower"
While GANs draw sharp *boundaries* using hard negatives, Diffusion creates mountain ranges of distribution in a different way. By providing data points from every location and **training the noiseization process**, it learns "how high to stack probabilities at each location." In other words, it reconstructs the entire terrain, including not only boundaries but also the *heights* of the peaks. However, since it requires data from every location, a large amount of data must be collected.
:::

::: {.callout-note}
## Stability Analogy — Highly Volatility Stocks vs. Steady Rising Stocks
GANs can produce a great model overnight if you're lucky, but if things go wrong, training all night will yield useless results that have completely collapsed (resulting in massive financial losses for large-scale training). Diffusion is slow, but it produces a model that **improves steadily, little by little, every day** — it offers peace of mind. This is why the industry has chosen Diffusion. (Today, most image and video generation is Diffusion-based.)
:::

## DDPM: Two processes

DDPM(Denoising Diffusion Probabilistic Model, 2020) consists of two processes.

```{mermaid}
flowchart LR
    X0["x₀ (깨끗한 데이터)"] -->|"q(xₜ|xₜ₋₁) 노이즈 추가"| XT["x_T ~ N(0,I) (순수 잡음)"]
    XT -->|"pθ(xₜ₋₁|xₜ) 학습된 디노이징"| X0b["x₀ (생성)"]
    X0 -. "Forward (고정)" .- XT
    XT -. "Reverse (생성/학습)" .- X0b
```

### Forward (diffusion) process — fixed

A Markov chain of latent variables, progressively adding Gaussian noise with a pre-scheduled variance $\beta_t$.

$$
q(x_t\mid x_{t-1})=\mathcal N\!\big(x_t;\ \sqrt{1-\beta_t}\,x_{t-1},\ \beta_t I\big).
$$

- $\beta_t$: **Noise Magnitude** at time $t$
- $\alpha_t=1-\beta_t$: **Signal retention size**, and $\bar\alpha_t=\prod_{s=1}^{t}\alpha_s$

By using Markovs and Gaussian composition, an arbitrary time $t$ can be represented in a **closed-form**.

$$
\boxed{\,x_t=\sqrt{\bar\alpha_t}\,x_0+\sqrt{1-\bar\alpha_t}\,\epsilon,\qquad \epsilon\sim\mathcal N(0,I)\,}
$$

If we set $\beta_t$ sufficiently small and increase $T$ to take the continuous limit of $\delta t\to0$, it becomes a **stabilistic differential equation (SDE)**.

$$
dx=-\tfrac12\,\beta(t)\,x\,dt+\sqrt{\beta(t)}\,dW_t,\qquad (W_t:\text{Wiener 과정}).
$$

Since the noise $\epsilon$ at each $t$ is random and uncontrollable, it is a *stochastic* differential equation.

### Reverse (Denoising) Process — Learning Target

The inverse process according to Bayes' rule is

$$
q(x_{t-1}\mid x_t)=\frac{q(x_t\mid x_{t-1})\,q(x_{t-1})}{q(x_t)}
$$

, but **$q(x_{t-1}), q(x_t)$ is unknown** (bad news). Good news: If $\beta_t\ll1$, then it is true. There is a theorem that the inverse process $q(x_{t-1}\mid x_t)$ is **well approximated by a Gaussian**. Therefore, we approximate it using a Gaussian parameterized by a neural network.

$$
p_\theta(x_{t-1}\mid x_t)=\mathcal N\!\big(x_{t-1};\ \mu_\theta(x_t,t),\ \sigma_t^2 I\big).
$$

What we will learn is the average of this Gaussian, $\mu_\theta$ (=denoiser).

### Training: Predict "noise" instead of the mean

By organizing the true mean in the closed form of Forward, $\mu_\theta$ can be reparameterized into **noise predictor $\epsilon_\theta(x_t,t)$**.

$$
\mu_\theta(x_t,t)=\frac{1}{\sqrt{\alpha_t}}\!\left(x_t-\frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\,\epsilon_\theta(x_t,t)\right).
$$

Then, learning becomes surprisingly simple. **For each $t$, the real noise $\epsilon$ is taken as the correct answer, and the neural network regresses to identify that noise.**

$$
\boxed{\;\mathcal L_{\text{simple}}=\mathbb E_{t,\,x_0,\,\epsilon}\Big[\ \big\|\,\epsilon-\epsilon_\theta\big(\sqrt{\bar\alpha_t}\,x_0+\sqrt{1-\bar\alpha_t}\,\epsilon,\ t\big)\big\|^2\ \Big]\;}
$$

Algorithm:

1. Time $t$ extraction, correct noise $\epsilon\sim\mathcal N(0,I)$ extraction
2. $x_t=\sqrt{\bar\alpha_t}\,x_0+\sqrt{1-\bar\alpha_t}\,\epsilon$ Calculation
3. Slope descent to $\nabla_\theta\|\epsilon-\epsilon_\theta(x_t,t)\|^2$

### Generation(Sampling)

Starting from $x_T\sim\mathcal N(0,I)$, it goes down to $t=T,\dots,1$Z and denoises step by step to the learned $\epsilon_\theta$.

$$
\hat x_0=\frac{1}{\sqrt{\bar\alpha_t}}\big(x_t-\sqrt{1-\bar\alpha_t}\,\epsilon_\theta(x_t,t)\big),\qquad
x_{t-1}=\mu_\theta(x_t,\hat x_0)+\sigma_t z,\quad z\sim\mathcal N(0,I).
$$

::: {.callout-warning}
## Note regarding the number of steps
The standard implementation of DDPM typically uses a *sequential* inverse process of $T\approx1000$ steps (default in papers). This sequentiality is the root cause of the slowness. (Some sources cite much larger figures, but the exact value depends on the noise schedule and resolution.) The key point is that "hundreds to thousands of forward passes are required to obtain a single sample," and DDIM reduces this to dozens of steps.
:::

## Three Perspectives: Variation · Score · Flow

::: {.callout-note}
Diffusion is interpreted equivalently by three mathematical tools.

| Perspective | Root | Representative Method |
|---|---|---|
| **Variational view** | (VAE formula) Variational inference | **DDPM** |
| **Score-based view** | Energy-based models in statistical physics | NCSN / score-SDE |
| **Flow-based view** | Normalizing Flow | **Flow Matching** |

All three perspectives converge to continuous-time formulations, and flow matching, in particular, reduces the number of iterations, becoming the de facto standard for recent generation. This theorem focuses on the most basic **variational perspective (DDPM)**.
:::

## DDIM: Non-Markov + Deterministic Sampling

::: {.callout-tip}
## Why DDIM?
DDPM offers good quality but (1) sampling is slow, (2) control is difficult because it is a stochastic path, and (3) every sample requires a full inverse SDE. The goal of DDIM is: **fewer steps + deterministic path + maintaining the same marginal distribution as DDPM**.
:::

DDIM reinterprets the forward process as a **non-Markovian deterministic mapping**. It becomes non-Markovian by making $x_t$ depend not only on $x_{t-1}$* but also on $x_0$. The key point is that **the implementation is the same as DDPM, but the mathematical interpretation is different** — DDPM is based on SDE, while DDIM is based on **ODE**.

Generalized reverse sampling:

$$
x_{t-1}=\sqrt{\bar\alpha_{t-1}}\,\hat x_0+\sqrt{1-\bar\alpha_{t-1}-\sigma_t^2}\;\epsilon_\theta(x_t,t)+\sigma_t z,
$$
$$
\sigma_t=\eta\sqrt{\frac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t}}\sqrt{1-\frac{\bar\alpha_t}{\bar\alpha_{t-1}}},\qquad z\sim\mathcal N(0,I).
$$

- $\eta=0\Rightarrow\sigma_t=0$: **Truly deterministic**(no noise injection)
- $\eta=1$: **Identical to DDPM**(Markov·Stochastic)

::: {.callout-important}
## Key Benefit — Training remains the same, only sampling accelerated
The loss function of is **exactly the same as DDPM**. That is, **a noise predictor $\epsilon_\theta$ trained once can be used directly for DDIM sampling**. Thanks to the deterministic process of $\sigma_t=0$, denoising is well-defined even at arbitrary time intervals, allowing for **fast sampling with a significantly reduced number of steps**.
:::

## LDM (Stable Diffusion): Latent Space Diffusion

Learning diffusion directly in pixel space incurs too high a memory cost. **LDM** compresses images into a low-dimensional **latent** and then learns diffusion *in that latent space*. As a text conditional large-scale model, the sweet spot of the downsampling rate is important.

- **LDM-1**(Uncompressed): Training time is excessively long
- **LDM-32**(Overcompression): Quality degradation due to information loss
- **LDM-4 / 8 / 16**: Competitive performance — Moderate compression is optimal

## ControlNet: Conditional fine-tuning of small amounts of data

Efficiently fine-tunes an unconditionally trained image diffusion model for image-conditional scenarios with a **relatively small (<50K) input–output pairs**.

- **Idea**: Process condition images using the pre-trained noise prediction U-Net
- **Encoder**: **Copy and initialize** pre-trained U-Net parameters, then fine-tune
- **Decoder**: Combines encoded condition information + noise image, but injects control signals using **zero convolution** (stable incremental learning as the influence is 0 initially)
- Training data $\sim100\text{K}$ Scale — Approximately 1/50,000 of LAION-5B

Since condition information is introduced *gradually* rather than suddenly, it can be generally applied to any image condition (edge, pose, depth, etc.).

::: {.callout-important}
## Wireless Communication Analogy — Diffusion = Progressive AWGN and its inverse operation
The closed form of Forward, $x_t=\sqrt{\bar\alpha_t}\,x_0+\sqrt{1-\bar\alpha_t}\,\epsilon$, is literally the same as the **fading + AWGN channel model with signal gain $\sqrt{\bar\alpha_t}$ and noise power $1-\bar\alpha_t$**. As $t$ increases, the SNR decreases monotonically, reaching SNR$\to0$ (pure noise) at $t=T$.

- **Training Noise Prediction $\epsilon_\theta$** = Training **MMSE Estimator** for Noise Estimation
- **Reverse Process** = Step-by-step denoising, i.e., a structure similar to **Iterative Equalization/Continuous Interference Removal (SIC)**
- **Deterministic path of DDIM($\eta=0$)** = *Deterministic equalization* path without noise reinjection
- $\beta_t$ Schedule = SNR Schedule Design
:::

# Comprehensive Comparison and Summary {#sec-summary}

| Axis | VAE | GAN | Diffusion (DDPM) |
|---|---|---|---|
| Learning Principles | Variational Inference (ELBO) | Adversarial Minimax | Maximum Likelihood Estimation (MLE) Approximation |
| Number of Models | Encoder+Decoder (Cooperative) | Generator+Discriminator (Competitive) | Single Noise Prediction |
| Stability | Stable | **Unstable**(Mode Collapse/Non-convergence/Vanishing) | Stable |
| Sampling Efficiency | Medium | **High**(hard negative) | Low(large amount of data) |
| Creation Rate | Fast (1 Pass) | Fast (1 Pass) | **Slow**($T$ Pass) → DDIM/LDM accelerates |
| Quality | Slightly blurry | Sharp but variety risk | **Sharp+Variety** |

::: {.callout-tip}
## Key Message
- VAE: Bypass $p(x)$ as a latent variable → Maximize ELBO(Reconstruction+KL), differentiate via reparameterization.
- GAN: Generates samples via *adversarial competition* without specifying a distribution. The optimal solution is $p_g=p_{\text{data}}$($-\log4$); it is efficient due to hard negatives, but *imbalance* is the source of instability.
- Diffusion: Trained the inverse process of noiseization using MLE. Single model, stable, high quality. DDPM (Basic) → DDIM (Accelerated/Deterministic) → LDM (Latent Space/Large Scale) → ControlNet (Conditional Control).
- Wireless Perspective: Reparameterization=Received Signal Decomposition, GAN=Spoofing vs. Detection Game, Diffusion=Inverse MMSE of Progressive AWGN.
:::

# Appendix: NumPy Validation Code {#sec-appendix}

The code below numerically verifies the two key results of the text — (1) whether the *repeated sampling* and *closed form* of the DDPM forward give the same distribution, and (2) whether the objective function value of the GAN optimal discriminator is exactly $-\log4$ when $p_g=p_{\text{data}}$.

```{python}
#| label: ddpm-forward-check
#| code-fold: false
import numpy as np
rng = np.random.default_rng(0)

# ---- 노이즈 스케줄 (선형) ----
T = 200
betas  = np.linspace(1e-4, 0.02, T)
alphas = 1 - betas
abar   = np.cumprod(alphas)          # ᾱ_t = ∏ α_s

x0 = 3.0                              # 스칼라 "데이터"
t  = 150                             # 검사할 시각

# (a) 반복 샘플링: q(x_t | x_{t-1}) 를 t번
N = 200_000
xt = np.full(N, x0, dtype=float)
for s in range(t):
    eps = rng.standard_normal(N)
    xt = np.sqrt(alphas[s])*xt + np.sqrt(betas[s])*eps

# (b) 닫힌 형태: x_t = √ᾱ_t x0 + √(1-ᾱ_t) ε
eps = rng.standard_normal(N)
xt_cf = np.sqrt(abar[t-1])*x0 + np.sqrt(1-abar[t-1])*eps

print(f"반복 샘플링  : mean={xt.mean():.4f}, var={xt.var():.4f}")
print(f"닫힌 형태    : mean={xt_cf.mean():.4f}, var={xt_cf.var():.4f}")
print(f"이론값       : mean={np.sqrt(abar[t-1])*x0:.4f}, "
      f"var={1-abar[t-1]:.4f}")
```

xs = np.linspace(-8, 8, 4000); dx = xs[1]-xs[0]
gauss = lambda x, m, s: np.exp(-0.5*((x-m)/s)**2)/(s*np.sqrt(2*np.pi))

pd = gauss(xs, 0, 1)
for label, pg in [("p_g = p_data ", gauss(xs, 0.0, 1.0)),
                  ("p_g 이동됨    ", gauss(xs, 1.5, 1.0))]:
    Dstar = pd/(pd+pg+1e-12)
    V = (pd*np.log(Dstar+1e-12)).sum()*dx + (pg*np.log(1-Dstar+1e-12)).sum()*dx
    print(f"{label}: V(G,D*) = {V:.4f}   (-log4 = {-np.log(4):.4f})")
