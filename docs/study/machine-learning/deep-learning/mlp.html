1 Overview

This note is the Mathematical and Structural Unification Theorem for Multi-Layer Perceptrons (MLPs). It is broadly composed of the following five axes.

  1. Conceptual Basis: Distinction between Neurons and Perceptrons, XOR Problem, Functional Composition Structure
  2. Theory of Expressiveness: The Universal Approximation Theorem and Its Practical Limitations
  3. Learning Mechanisms: Forward propagation, Backpropagation, Computational graph, Automatic differentiation
  4. Loss Function and Output Layer: Cross entropy, KL divergence, Equivalence with MLE, Softmax, Gumbel-Softmax
  5. Tools for Generalization: Activation functions, Vanishing gradient, 9 Regularization techniques, Bayesian interpretation

At the end of each section, the intuitive correspondence relationship of the wireless network domain is attached.

2 Artificial Neurons and Perceptrons — The Precise Distinction Between Terms

2.1 Hierarchical Definition

생물학적 뉴런 (영감의 원천)
    ↓ 추상화
인공 뉴런(Artificial Neuron) = 수학적 계산 단위 [일반 개념]
    ↓ 특수화
퍼셉트론(Perceptron) = 활성화 함수가 step function인 뉴런 [특수 사례]

2.2 Artificial Neuron

A computational unit that takes an input vector and produces a single scalar output:

z = \mathbf{w}^\top \mathbf{x} + b, \qquad a = f(z)

  • z: pre-activation (linear combination)
  • a: activation (activation output)
  • f(\cdot): Activation function — The type of neuron is determined by what this is

2.3 Perceptron

Neuron with an activation function of step function or sign function:

f(z) = \begin{cases} 1 & z > 0 \\ 0 & z \leq 0 \end{cases}

Item Neuron Perceptron
Concept Scope General Special
Activation function f Random Step/sign fixed
Output Consecutive values possible Binary value \{0,1\}
Backpropagation possible? ✓ (When f is differentiable) ✗ (Discontinuous)
Date of Appearance — Rosenblatt, 1958
ImportantWhy isn’t modern deep learning called “Perceptron”?

For backpropagation, \partial \mathcal{L}/\partial w must be calculated. Since the derivative of the step function is zero (or discontinuous) almost everywhere, the gradient does not flow. Therefore, in modern times, neurons using differentiable activation functions such as ReLU, sigmoid, and tanh are used, and a structure formed by stacking these is called an MLP or neural network. Although the name is perceptron, strictly speaking, the neurons in an MLP are not perceptrons—it is a historical designation that has become established.

2.4 Wireless Communication Intuition

MLP Concept Wireless Communication Support
Neuron(Weighted Sum) Matched filter
Activation function (step) Threshold detector (hard decision)
Sigmoid neurons Soft decision detector

3 Limitations of a Single Perceptron and the XOR Problem

3.1 Linearly Separable vs Non-Separable

A single perceptron separates two classes using a single hyperplane. Therefore, it can solve linearly separable problems like AND and OR, but it is in principle impossible to solve linearly non-separable problems like XOR.

Truth table of XOR: (0,0)\to 0,\quad (0,1)\to 1,\quad (1,0)\to 1,\quad (1,1)\to 0 In a 2D plane, a single straight line cannot separate two classes.

3.2 Two Perceptrons Solving XOR — Logical Decomposition

XOR is logically decomposed as follows:

y = x_1 \oplus x_2 = (x_1 \wedge \neg x_2) \vee (x_2 \wedge \neg x_1)

Encode this as a threshold function:

v_1 = \mathbb{1}[-1.5 + 2x_1 - x_2 > 0] = (x_1 \wedge \neg x_2) v_2 = \mathbb{1}[-1.5 + 2x_2 - x_1 > 0] = (x_2 \wedge \neg x_1) y = \mathbb{1}[-0.5 + v_1 + v_2 > 0] = v_1 \vee v_2

3.3 Verification of the weight/bias design of v_1 = x_1 \wedge \neg x_2

x_1 x_2 -1.5 + 2x_1 - x_2 > 0? expectations
0 0 -1.5 ✗ 0 ✓
1 0 +0.5 ✓ 1 ✓
0 1 -2.5 ✗ 0 ✓
1 1 -0.5 ✗ 0 ✓

If you read the meaning of the weight design line by line:

  • +2 \cdot x_1: Activate sufficiently large when x_1=1
  • -1 \cdot x_2: If x_2=1, suppress as a negation role
  • Bias -1.5: Raise threshold to block cases where x_2=1 or both are 0

3.4 Meaning of “Stacking two perceptrons”

hidden layer \{v_1, v_2\} added = means stacking layers in series.

입력층      은닉층        출력층
x₁  ─→  [v₁]
x₂  ─→  [v₂]  ─→  [y]

The hidden layer performs a non-linear transformation of the input space to map it into a linearly separable space.

3.5 Wireless Communication Intuition

Just as a single matched filter in an OFDM receiver cannot completely eliminate multipath interference, a single perceptron (linear filter) cannot separate non-linear patterns such as XOR. Adding a hidden layer is equivalent to a structure that compensates for non-linear channels stepwise by stacking equalizers in series.

4 Structural Understanding of Hidden Layers

4.1 MLP as Function Composition

The output of an MLP with one hidden layer is as follows:

\text{out}(\mathbf{x}) = g\!\Bigl(w_0 + \sum_{k=1}^{K} w_k \cdot \underbrace{g\bigl(w_0^{(k)} + \sum_i w_i^{(k)} x_i\bigr)}_{\text{k번째 은닉 뉴런 출력}}\Bigr)

It looks like recursion, but it is actually two-stage function composition. It is a structure where the inner g(\cdot) is calculated first, and the outer g(\cdot) receives the result.

4.2 Number of activation functions

Location Count Role
Each hidden layer neuron K Inside g
Output layer neuron 1 Outer g
Total K+1 items

Although it appears that there is only one activation function in the formula , when expanded, it is applied a total of K+1 times.

4.3 Reason why the loss becomes non-convex

In a single neuron:

\text{out}(\mathbf{x}) = g(\mathbf{w}^\top \mathbf{x} + b)

If g is a convex function like sigmoid or ReLU, the loss for \mathbf{w} can be convex. However, after introducing a hidden layer:

\mathcal{L}(\mathbf{W}^{(1)}, \mathbf{W}^{(2)}) = \text{Loss}\bigl(\mathbf{W}^{(2)}\, g(\mathbf{W}^{(1)}\mathbf{x})\bigr)

The following two things break convexity.

Cause 1 — Non-linear composition of weight matrices

The product of \mathbf{W}^{(2)} and g(\mathbf{W}^{(1)}\mathbf{x}) is generally not convex.

Cause 2 — Multiple equivalent solutions due to symmetry

Represents the same function even if the order of the hidden layer neurons is changed:

[\mathbf{w}_1, \mathbf{w}_2, \mathbf{w}_3] \;\equiv\; [\mathbf{w}_2, \mathbf{w}_1, \mathbf{w}_3] \;\equiv\; \cdots

If there are n neurons in the hidden layer, there are n! equivalent solutions. These have the same loss value and appear as local minimums at different locations.

NoteConvergence guarantee — Perceptron vs MLP

Perceptron: \mathcal{L}(\mathbf{w}) = \sum_i \max(0, -y_i \mathbf{w}^\top \mathbf{x}_i) → convex → guaranteed to reach global minimum (regardless of the starting point, the gradient always points toward the minimum point)

MLP: non-convex → can get stuck in a local minimum, saddle point, or plateau. Depending on where you start, you can reach different local minimums.

Interestingly, SGD actually works surprisingly well. This is because (i) saddle points are much more common than local minimums in high dimensions, (ii) good initialization and momentum techniques help to escape saddles, and (iii) in over-parameterized regions, almost all local minimums have similar generalization performance.

4.4 8-3-8 Implications of the Autoencoder

A network that reconstructs 8-dimensional one-hot input → 3 hidden units → 8-dimensional automatically encodes 2^3 = 8 patterns. This is essentially the same as CSI feedback compression in wireless communication — compressing high-dimensional channel information into a low-dimensional latent space and then reconstructing it. In fact, models like CsiNet and CRNet are directly based on this principle.

5 Universal Approximation Theorem and Its Practical Limitations

5.1 Summary (Cybenko 1989, Hornik 1991)

When a feed-forward network with a single hidden layer has a sufficient number of neurons, Any continuous function can be approximated to desired precision over a compact subset of \mathbb{R}^n.

A mild condition is required for the activation function g (non-constant, bounded, monotonically-increasing continuous, etc.).

5.2 Two traps

Trap 1 — You don’t know how many “sufficient neurons” are needed.

Some functions may require an exponentially large number of neurons to be approximated by a single hidden layer. On the other hand, a deep network may be sufficient with a polynomial number of neurons. This is the value of depth.

Results of Montufar et al. (2014): A network with k hidden layers, each with n ReLU units, is maximum

\left(\frac{n}{d}\right)^{(k-1)d} \cdot \binom{n}{d}

linear regions can be represented (d = input dimension). The representable region increases exponentially with every 1 increase in depth.

Trap 2 — There is no guarantee that it can be found.

The fact that such a weight “exists” is different from the fact that it “can be found” through gradient descent. Since it is a non-convex optimization, reaching the global optimum is not guaranteed.

TipSimilarities with Shannon’s Theorem

UAT is similar to Shannon’s channel coding theorem — that “there exists a code that reaches the theoretical channel capacity.” While existence is guaranteed, actually designing and decoding such a code is a separate matter.

There was a 50-year gap between the fact that random codebooks achieve capacity and the discovery of practical LDPC/Turbo codes. In deep learning as well, there is a practical gap between expressibility and learnability.

5.3 Expressability ≠ Learnability ≠ Generalizability

You must understand the three concepts separately.

Concept Meaning Responsibility
Expressibility Can such a function be expressed? UAT is the answer
Learnability Can it be found with gradient descent? Optimization Theory
Generalizability Does the learned function work on new data? Statistical Learning Theory

The reason deep networks are powerful is that they satisfy these three things simultaneously.

6 Forward Propagation and Backpropagation

6.1 Forward Propagation — Inference

The kth neuron of each layer l:

V_k^{(l)} = g\!\left(\sum_i w_{ki}^{(l)} U_i^{(l-1)} + b_k^{(l)}\right)

Here, U_i^{(l-1)} is the output of the previous layer. Calculate sequentially from input to output.

6.2 Backpropagation — Learning

6.2.1 Key Idea

The learning goal is to find the weights that minimize the loss J. We need the gradient \partial J/\partial w for all weights, but this cannot be calculated all at once. Instead, we multiply the gradients for each layer using the chain rule:

\frac{\partial z}{\partial x} = \frac{\partial z}{\partial y} \cdot \frac{\partial y}{\partial x}

6.2.2 Computational Graph Example

f(x, y, z) = (x+y)\cdot z, with x=-2, y=5, z=-4.

Forward pass: q = x + y = 3, \quad f = q \cdot z = -12

Backward pass:

Step 1: \partial f / \partial f = 1

Step 2 (Multiplication Node): \frac{\partial f}{\partial q} = z = -4, \qquad \frac{\partial f}{\partial z} = q = 3

Step 3 (Addition Node): \frac{\partial q}{\partial x} = 1, \qquad \frac{\partial q}{\partial y} = 1

Step 4 (Apply chain rule): \frac{\partial f}{\partial x} = -4 \cdot 1 = -4, \qquad \frac{\partial f}{\partial y} = -4 \cdot 1 = -4, \qquad \frac{\partial f}{\partial z} = 3

Intuition of gradient flow per node:

  • The addition gate distributes the upstream gradient as is
  • The multiplication gate swaps the other party’s value and then multiplies.

6.2.3 Why is it efficient? — Principles of Dynamic Programming

If you calculate by “expanding” the chain rule, the same intermediate result is calculated multiple times. This causes the amount of computation to explode exponentially. Backpropagation stores the values calculated in the forward pass and reuses them in the backward pass — this is precisely the principle of dynamic programming.

Forward:   x=-2, y=5  →  q=3  →  f=-12
                          ↑ 저장      ↑ 저장
Backward:  ∂f/∂f=1  →  ∂f/∂q=z=-4  →  ∂f/∂x = ∂f/∂q · ∂q/∂x = -4
                                          ∂f/∂y = ∂f/∂q · ∂q/∂y = -4
                          ∂f/∂z=q=3

6.2.4 Computational Graph of an Actual MLP

In actual training, construct the entire graph including cross-entropy loss + weight decay:

J = J_\text{MLE} + \lambda\bigl(\|\mathbf{W}^{(1)}\|_F^2 + \|\mathbf{W}^{(2)}\|_F^2\bigr)

Left Path — Forward Pass (Predictive Calculation):

\mathbf{X}, \mathbf{W}^{(1)} \xrightarrow{\text{matmul}} \mathbf{U}^{(1)} \xrightarrow{\text{ReLU}} \mathbf{H} \xrightarrow{\text{matmul} \mathbf{W}^{(2)}} \mathbf{U}^{(2)} \xrightarrow{\text{CE}} J_\text{MLE}

Right Path — Weight Decay (Normalization Calculation):

\mathbf{W}^{(1)} \xrightarrow{\text{sqr}} \mathbf{U}^{(3)} \xrightarrow{\text{sum}} u^{(4)} = \|\mathbf{W}^{(1)}\|_F^2 \mathbf{W}^{(2)} \xrightarrow{\text{sqr}} \mathbf{U}^{(5)} \xrightarrow{\text{sum}} u^{(6)} = \|\mathbf{W}^{(2)}\|_F^2

Scaling after summation: u^{(8)} = \lambda(u^{(4)} + u^{(6)}).

Each node receives the upstream gradient coming into it, multiplies it by the local gradient, and sends it down. This is exactly what PyTorch’s .backward() does.

TipWireless Communication Intuition — Signal Flow Graph

This computational graph has the same structure as a signal flow graph. Forward pass = signal propagation, Backward pass = error backpropagation. This is the same principle as the LMS algorithm in an adaptive equalizer backpropagating the error signal in the direction of the filter weights.

6.3 Symbolic vs Numeric vs Automatic Differentiation

Comparison of three differentiation methods:

Method Input Output Advantages Disadvantages
Symbolic Formula Formula Closed form derivative Expression swell (exponential growth)
Numeric Formula + point Numeric value Simple implementation N parameters require N forward pass, error
Automatic (AD) Formula + Point Numerical Value (Accurate) Efficient, Accurate Complex Implementation

Numeric differentiation is useful for gradient checking (backprop implementation verification):

\frac{\partial f}{\partial x_i} \approx \frac{f(\ldots, x_i + h, \ldots) - f(\ldots, x_i - h, \ldots)}{2h}

AD uses reverse mode to calculate the gradient of a vector input to a scalar output in a single forward + backward pass. This is the core of PyTorch and JAX.

7 Cross Entropy and KL Divergence

7.1 Definition

Shannon Entropy: \quad H(p) = -\sum_x p(x) \log p(x)

Cross Entropy: \quad H(p, q) = -\sum_x p(x) \log q(x)

KL Divergence: \quad D_{KL}(p \| q) = \sum_x p(x) \log \dfrac{p(x)}{q(x)}

7.2 Core Decomposition Formula — Mathematical Derivation

KL divergence expansion:

D_{KL}(p \| q) = \sum_x p(x) \bigl[\log p(x) - \log q(x)\bigr] = \sum_x p(x) \log p(x) - \sum_x p(x) \log q(x) = -H(p) + H(p, q)

Therefore:

\boxed{H(p,q) = H(p) + D_{KL}(p \| q)}

7.3 Semantic decomposition

\underbrace{H(p,q)}_{\text{Cross-Entropy}} = \underbrace{H(p)}_{\text{어쩔 수 없는 불확실성}} + \underbrace{D_{KL}(p \| q)}_{\text{모델의 무지함}}

Clause Meaning Controllable?
H(p) Intrinsic uncertainty of the actual distribution itself ❌ (Fixed by the data)
D_{KL}(p\|q) How much q deviates from p ✅ (Decreased through learning)
H(p,q) Sum of the two ✅ (Indirectly decreasing)

Key inequality:

H(p,q) \geq H(p), \quad \text{등호 } \iff q = p

7.4 Information-theoretic interpretation — Coding costs

Symbol Meaning
H(p) Average length of optimal code when actual distribution p is known (Shannon source coding)
H(p,q) Average length when applying code designed for the incorrect distribution q to the actual p
D_{KL}(p\|q) Extra bits due to incorrect model

\underbrace{H(p,q)}_{\text{실제 전송 비용}} = \underbrace{H(p)}_{\text{최소 이론 비용}} + \underbrace{D_{KL}(p\|q)}_{\text{모델 오류 낭비}}

7.5 Meaning of H(p) = 0 in classification problems

In classification problems, the correct label is a one-hot vector:

p = [0, \ldots, 1, \ldots, 0]

Shannon entropy calculation: H(p) = -\sum_k p(k)\log p(k) = -(1\cdot\log 1 + 0\cdot\log 0 + \cdots) = 0 (here 0 \log 0 \overset{\text{정의}}{=} \lim_{x\to 0} x\log x = 0.)

This means “the correct answer is definitive, so there is no inherent uncertainty,” and if substituted into the decomposition formula:

H(p, q) = D_{KL}(p \| q) = -\log q(y^*)

Only one log-probability remains for the correct answer class y^*.

7.6 MLE = CE Minimization = KL Minimization

Let’s assume that dataset \mathcal{D} = \{x^{(1)}, \ldots, x^{(N)}\} is iid sampled from the actual distribution p_\text{data}.

MLE Objective Function:

\theta^*_\text{MLE} = \arg\max_\theta \sum_{i=1}^N \log q_\theta(x^{(i)})

Divide by Divide by N and apply the Law of Large Numbers (N \to \infty):

\frac{1}{N}\sum_{i=1}^N \log q_\theta(x^{(i)}) \xrightarrow{} \mathbb{E}_{x \sim p_\text{data}}\bigl[\log q_\theta(x)\bigr] = -H(p_\text{data}, q_\theta)

Therefore:

\theta^*_\text{MLE} = \arg\min_\theta H(p_\text{data}, q_\theta)

Applying the decomposition formula:

\arg\min_\theta H(p_\text{data}, q_\theta) = \arg\min_\theta \bigl[\underbrace{H(p_\text{data})}_{\theta\text{와 무관}} + D_{KL}(p_\text{data} \| q_\theta)\bigr] = \arg\min_\theta D_{KL}(p_\text{data} \| q_\theta)

Total Equivalence Relation:

\boxed{\underbrace{\max_\theta \sum_i \log q_\theta(x^{(i)})}_{\text{MLE}} \;\equiv\; \underbrace{\min_\theta H(p_\text{data}, q_\theta)}_{\text{CE 최소화}} \;\equiv\; \underbrace{\min_\theta D_{KL}(p_\text{data} \| q_\theta)}_{\text{KL 최소화}}}

7.7 Why is it D_{KL}(p \| q)? Isn’t it D_{KL}(q \| p)?

D_{KL}(p\|q) = \sum_x p(x) \log \frac{p(x)}{q(x)}

Since p is the ground truth and q is the model, the expectation is taken below p. This forces that q(x) must also be sufficiently large where p(x) > 0 — that is, it forces to assign a high probability to the correct answer class.

Direction Behavioral Pattern Intuition
D_{KL}(p\|q) (Forward) mode-covering / zero-avoiding Trying not to miss the correct answer
D_{KL}(q\|p) (Reverse) mode-seeking / zero-forcing Focus on one mode

D_{KL}(q\|p) forces the incorrect class (p(x)=0) to become q(x)=0, but it does not directly increase the probability of the correct answer. This difference becomes an important choice in generative models as well (VAE is reverse KL).

7.8 Gradient of CE vs MSE — Why Use CE for Classification

7.8.1 For MSE (sigmoid output + MSE loss)

\text{MSE} = \tfrac{1}{2}(y - \sigma(z))^2, \qquad \frac{\partial \text{MSE}}{\partial w} = (\sigma(z) - y) \cdot \sigma'(z) \cdot x

The term \sigma'(z) is multiplied. When the Sigmoid enters the saturation region, it becomes \sigma'(z) \to 0 , causing the gradient to disappear even if the prediction is wrong. This is the learning stagnation problem of sigmoid + MSE.

7.8.2 In the case of CE

\text{CE} = -\bigl[y\log\sigma(z) + (1-y)\log(1-\sigma(z))\bigr]

Applying the chain rule:

\frac{\partial \text{CE}}{\partial z} = -\frac{y}{\sigma(z)}\sigma'(z) + \frac{1-y}{1-\sigma(z)}\sigma'(z)

Substitute \sigma'(z) = \sigma(z)(1-\sigma(z)):

= -y(1-\sigma(z)) + (1-y)\sigma(z) = \sigma(z) - y

Therefore:

\boxed{\frac{\partial \text{CE}}{\partial w} = (\sigma(z) - y) \cdot x}

The terms \sigma'(z) are completely canceled out. As the prediction is incorrect, the gradient remains large, enabling faster learning.

ImportantTwo justifications of CE
  1. Numerical Justification: Avoid vanishing gradient by eliminating \sigma'
  2. Statistical Justification: Equivalent to MLE for Bernoulli/Multinoulli distributions — “correct” loss from the perspective of probabilistic models

7.9 Softmax + CE Gradient Induction

Softmax output: q_i = \dfrac{e^{z_i}}{\sum_j e^{z_j}}, Cross entropy: L = -\sum_i p_i \log q_i.

gradient for z_i:

\frac{\partial L}{\partial z_i} = q_i - p_i

  • Correct Answer Class k: \partial L/\partial z_k = q_k - 1 (The closer the prediction is to 1 → 0)
  • Incorrect Answer Class i \neq k: \partial L/\partial z_i = q_i (The closer the prediction is to 0 → 0)

Meaning of this simple form:

  • Computational Efficiency: One subtraction without complex log·exp differentiation
  • Numerical Stability: log and exp cancel each other out, resolving the saturation issue
  • Intuitive Interpretation: “Update as much as you get wrong”

7.10 Wireless Communication Intuition

Information Theory Wireless Communication Correspondence
p_\text{data} Actual Channel Distribution (Unknown)
q_\theta Channel Model (AWGN, Rayleigh Assumption)
H(p) Intrinsic limitations of Shannon capacity
D_{KL}(p\|q) Capacity loss due to incorrect channel assumptions
MLE Channel parameter estimation from received signal

The error signal e(n) = (\text{desired} - \text{predicted}) from the weight update \mathbf{w} \leftarrow \mathbf{w} + \mu \cdot e(n) \cdot \mathbf{x}(n) of the LMS adaptive filter has exactly the same structure as the softmax + CE gradient (q - p).

Also, in MLD (Maximum Likelihood Detection), looking at the received signal r and finding \arg\max_s P(r|s) is essentially the same as minimizing the CE loss.

8 Output Units — Design of the Output Layer

The output layer of a neural network must be designed to match the probability distribution of the problem to be solved.

8.1 Linear Units

\hat{y} = \mathbf{W}^\top \mathbf{h} + \mathbf{b}

Assuming a Gaussian output distribution: p(y|x) = \mathcal{N}(y; \hat{y}, \mathbf{I}). Fit to a regression problem. In this case, the negative log-likelihood is exactly the MSE (ignoring the constant term).

8.2 Sigmoid Units

\hat{y} = \sigma(\mathbf{w}^\top \mathbf{h} + b), \quad z = \mathbf{w}^\top \mathbf{h} + b \text{ (logit)}

Assumes a Bernoulli output distribution. Used for binary classification. z is called the logit, which has the meaning of log-odds \log[p/(1-p)].

Using multiple sigmoid outputs simultaneously results in multi-label classification (each label is independent). Since the sum of probabilities is not normalized to 1, it is an un-normalized distribution.

8.3 Softmax Units

\text{softmax}(\mathbf{z})_i = \frac{e^{z_i}}{\sum_j e^{z_j}}

Output of Multinoulli (categorical) distribution. Standard for multi-class classification.

8.3.1 Softmax is not simple normalization

If we compare [10, 20]:

  • L1 Normalization: \bigl[\tfrac{10}{30}, \tfrac{20}{30}\bigr] = [0.33, 0.67]
  • Softmax: \bigl[e^{10}/(e^{10}+e^{20}),\ e^{20}/(e^{10}+e^{20})\bigr] \approx [0.00005, 0.99995]

The larger the absolute value of the difference, the more dramatically it is biased toward the maximum value. This is equivalent to the fact that in MIMO beam selection, the larger the SNR difference, the more the probability of optimal beam selection converges to 1.

8.3.2 Numerical Stability — Log-Sum-Exp Trick

If z_i is larger, e^{z_i} causes an overflow. Therefore:

\text{softmax}(\mathbf{z})_i = \frac{e^{z_i - \max_j z_j}}{\sum_k e^{z_k - \max_j z_j}}

Subtracting \max z_j from all z_i yields the same result (simplifying numerator and denominator). This prevents overflow by making the exponent negative.

8.4 Gumbel-Softmax — Differentiable Sampling

To sample from a categorical distribution, you must take argmax, but since argmax is not differentiable, backprop is impossible.

Solved with Gumbel-Softmax:

y_i = \frac{\exp\bigl((z_i + g_i)/\tau\bigr)}{\sum_{j=1}^k \exp\bigl((z_j + g_j)/\tau\bigr)}

g_i is Gumbel noise (PDF: f(x) = e^{-(x + e^{-x})}).

Gumbel-Max trick: \arg\max_i (z_i + g_i) is exactly the same as sampling from a softmax distribution. Gumbel-Softmax continuously relaxes this argmax to softmax.

Temperature \tau Behavior
\tau \to 0 Close to one-hot (hard)
\tau \to \infty Close to uniform (soft)

A philosophy similar to VAE’s reparameterization trick — making discrete choices differentiable.

9 Activation Functions

9.1 Sigmoid

\sigma(z) = \frac{1}{1 + e^{-z}}, \qquad \sigma'(z) = \sigma(z)(1 - \sigma(z))

property value
Output Range (0, 1)
Maximum derivative 0.25 (at z = 0)
Zero-centered ❌

Problem: saturation at both ends → gradient → 0.

9.2 Hyperbolic Tangent (Tanh)

\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}} = 2\sigma(2z) - 1

Differentiation:

\frac{d}{dz}\tanh(z) = 1 - \tanh^2(z), \qquad \max = 1 \text{ (at } z = 0\text{)}

property value
Output Range (-1, 1)
Maximum derivative 1.0
Zero-centered ✅

9.2.1 Advantages over Sigmoid: Why Zero-Centeredness Is Important

Since the Sigmoid output is always positive, the weight gradients all have the same sign:

\frac{\partial \mathcal{L}}{\partial w_i^{(l)}} = \frac{\partial \mathcal{L}}{\partial a^{(l)}} \cdot \underbrace{x_i^{(l-1)}}_{>0 \text{ 항상 (sigmoid)}}

→ Weight updates are only possible in a zigzag direction. tanh can have both positive and negative outputs → The gradient direction is free.

This is equivalent to the difference between BPSK modulation (bipolar \{-1, +1\}) and unipolar signal (0, 1) in wireless communication. Just as the bipolar signal has no DC component and thus high power efficiency, the tanh signal also balances the gradient flow with zero-centeredness.

9.3 ReLU (Rectified Linear Unit)

\text{ReLU}(z) = \max(0, z), \qquad \text{ReLU}'(z) = \begin{cases} 1 & z > 0 \\ 0 & z \leq 0 \end{cases}

A term borrowed from the half-wave rectifier in electronics.

9.3.1 4 Benefits of ReLU

1. Solving Vanishing Gradient. Gradient = 1 in positive intervals. Case where all neurons are activated in a deep network:

\prod_{l=1}^L \text{ReLU}'(z^{(l)}) = 1

Sigmoid attenuates as \leq 0.25^L. If it is 10 layers, it is 0.25^{10} \approx 9.5\times 10^{-7}.

2. Computational Efficiency. Sigmoid/tanh requires e^x calculation. ReLU performs a single simple comparison. Significant difference on GPUs.

3. Sparse Activation. Neurons receiving a negative input produce an output of exactly 0. On average, half of the neurons are deactivated. This creates the effect of activating a different “subnetwork” for each input — resembling the brain’s sparse coding.

4. Alleviation of Catastrophic Forgetting. Since neurons are completely deactivated in response to negative input, the effect is that only specific task-related neurons are activated while the rest are preserved.

9.3.2 Disadvantage of ReLU: Dying ReLU

If w becomes very negative, it becomes z = w^\top x + b \ll 0, so the ReLU output is always 0. Since the gradient of this neuron is also 0, it will never be updated.

9.4 Integrated formula for the ReLU family

The ReLU family is expressed by a single formula:

h_i = \max(0, z_i) + \alpha_i \min(0, z_i)

\alpha_i Function Name Attribute
0 ReLU Complete blocking of negative regions
-1 Absolute value (h = \|z\|) Symmetric output
0.01 Leaky ReLU Small gradient in the negative region
Trained Parametric ReLU (PReLU) Trained \alpha from data

9.4.1 Absolute Value Rectifier — Origami Analogy

|z| outputs negative numbers by folding them into positive numbers. The output is identical on the left and right sides relative to the axis of symmetry. \Rightarrow has the effect of physically folding space in half.

| z | (접기):              ReLU (자르기):
       /\                       /
      /  \                     /
     /    \                   /
    /      \              ───/

As layers are stacked, the number of folds increases, and the pattern repeats exponentially → The area that can be represented by the same parameters increases exponentially (intuition of Montufar’s theorem).

9.5 Activation function comparison

properties Sigmoid tanh ReLU

9.5.1 Why tanh survives in RNN/LSTM

ReLU has an unbounded output (0, \infty), so there is a risk of exploding gradient in RNNs. tanh |\tanh(x)| \leq 1 always → values do not explode even if the sequence becomes long. This is the reason why LSTM cell states and hidden states use tanh.

9.6 Vanishing Gradient — Analogy with Wireless Signals

Sigmoid derivative ≤ 0.25 → for 10 layers, gradient \sim 10^{-6}. This is similar to the path loss in communication — signal attenuation whenever it passes through multiple relays. Like an ideal amplifier, ReLU transmits positive signals without attenuation.

10 Regularization — 9 Techniques

10.1 General format

Hard constraint: \min_\theta \frac{1}{n}\sum_{i=1}^n l(\theta, x_i, y_i) \quad \text{s.t.} \quad R(\theta) \leq c

Convert to Lagrangian → soft constraint: \min_\theta \frac{1}{n}\sum_{i=1}^n l(\theta, x_i, y_i) + \lambda^* R(\theta)

The solutions to the two problems match when KKT conditions exist for the appropriate \lambda^*.

10.2 Bayesian interpretation of L2 Regularization

L2 penalty (weight decay): \min_\theta \frac{1}{n}\sum_{i=1}^n l(\theta, x_i, y_i) + \lambda \|\theta\|_2^2

This is equivalent to the MAP estimate for the Gaussian prior p(\theta) = \mathcal{N}(0, \sigma^2 \mathbf{I}).

10.2.1 Mathematical derivation

MAP Estimation: \max_\theta \log p(\theta|\text{data}) = \max_\theta \underbrace{\log p(\text{data}|\theta)}_{\text{likelihood}} + \underbrace{\log p(\theta)}_{\text{prior}}

Gaussian prior: \log \mathcal{N}(\theta; 0, \sigma^2 \mathbf{I}) = -\frac{1}{2\sigma^2}\|\theta\|_2^2 + \text{const}

If you change Maximization to minimization: \min_\theta -\log p(\text{data}|\theta) + \frac{1}{2\sigma^2}\|\theta\|_2^2

Setting it to \lambda = \frac{1}{2\sigma^2} exactly matches weight decay. The smaller \sigma is (priors concentrated at 0), the larger \lambda is → strong regularization.

10.2.2 “Is L2 the belief that the weight will be near 0”?

Yes. And the reason that assumption is reasonable:

1. Occam’s Razor. If the weight is large, the output changes significantly even with small changes in the input → the function becomes coarse. Small weight = smooth function.

2. Equivalence with MMSE channel estimation. This is the same reason why an MMSE estimator that utilizes the channel’s prior statistics (correlation matrix, power delay profile) achieves better performance with fewer pilots than an LS estimator.

3. Data-Prior Knowledge Balance. Looking at the MAP decomposition: \min_\theta \frac{1}{n}\sum_i l(\theta, x_i, y_i) + \frac{1}{2\sigma^2}\|\theta\|_2^2

Data Amount n Dominant Term Result
Large likelihood Converges to MLE (ignores prior)
Small prior Regularizer determined

Quantification of the general property that MAP → MLE converges as data increases.

10.2.3 L1 vs L2

Regularizer Correspondence prior Effect
\|\theta\|_1 Laplace prior Sparsity (weight exactly 0)
\|\theta\|_2^2 Gaussian prior Shrinkage (small but non-zero weight)
\|\theta\|_0 \log p \propto \mathbb{1}[\theta_i \neq 0] Sparsity forcing (combinatorial, NP-hard)

L1 is the convex relaxation of L0. A principle directly used for sparse channel estimation in compressed sensing in wireless communication.

10.3 9 Regularization Techniques

10.3.1 1. Dataset Augmentation

Artificially expand the training set by applying a transformation to the original data:

  • Affine distortion (rotation, scaling, shear)
  • Noise injection
  • Elastic deformation
  • Horizontal flip
  • Random translation
  • Hue shift

This amounts to injecting an inductive bias into the model, implying that it “must be invariant to these transformations.”

10.3.2 2. Adversarial Examples & Adversarial Training

Adversarial example is an input that causes a model to make a completely different prediction due to subtle perturbations imperceptible to humans:

x_\text{adv} = x + \epsilon \cdot \text{sign}(\nabla_x J(\theta, x, y))

FGSM (Fast Gradient Sign Method). Justified by a first-order Taylor expansion: J(x + \delta) \approx J(x) + \delta^\top \nabla_x J

\|\delta\|_\infty \leq \epsilon maximizing this under constraint \delta^* = \epsilon \cdot \text{sign}(\nabla_x J).

Famous example: \epsilon = 0.007 noise in a panda image → Model classifies gibbon with 99.3% confidence.

Adversarial Training: \min_\theta \mathbb{E}\!\left[\max_{\|\delta\| \leq \epsilon} J(\theta, x+\delta, y)\right]

Makes the model learn robust representations near the input. The primary purpose is security, but the secondary effect is generic regularization.

TipWireless Communication Intuition

Adversarial perturbation is similar to jamming signals — interference injection in the direction of minimizing the received SNR through gradient-based optimization. FGSM also injects noise in the direction of maximizing the model loss.

10.3.3 3. Label Smoothing

Soften hard one-hot label: y_k^\text{smooth} = (1-\epsilon) y_k + \frac{\epsilon}{K}

Prevents the model from being 100% confident in the correct answer → Prevents over-confidence, improves calibration.

10.3.4 4. Semi-Supervised Learning

Uses labeled and unlabeled data together. Learns a common representation to utilize the structure of unlabeled data → Effectively acts as a prior to the data distribution.

10.3.5 5. Multi-Task Learning

Simultaneously train multiple tasks using a shared representation.

penalty on parameter difference between previous task A and new task B: \mathcal{L}_B = \mathcal{L}_\text{task\_B} + \lambda \|\mathbf{B} - \mathbf{A}\|_F^2

This is a generalization of L2 — if general L2 was \|w - 0\|_2^2, making it close to 0, here it is close to A.

TipAnalogy with MIMO Channel Estimation

Estimate current channel \mathbf{H}_t with previous time slot channel \hat{\mathbf{H}}_{t-1} as prior: \min_{\mathbf{H}_t} \|\mathbf{y} - \mathbf{H}_t \mathbf{x}\|^2 + \lambda \|\mathbf{H}_t - \hat{\mathbf{H}}_{t-1}\|_F^2

Expressing the prior “channel does not change abruptly” as regularization — exactly the same structure.

10.3.6 6. Early Stopping

Training error continues to decrease, but training stops when validation error starts to increase again.

This acts as implicit regularization — if stopped appropriately early, it stops before the weight becomes too large, so it has a similar effect to L2.

10.3.7 7. Parameter Sharing / Tying

Share the same weight at multiple locations (represented by CNN convolution). Reduce the number of parameters and introduce natural invariance (translation invariance).

10.3.8 8. Bagging (Bootstrap Aggregating)

Average predictions after training multiple models on different data samples (bootstrap). Improves generalization by reducing variance. The core principle of Random Forest.

10.3.9 9. Dropout

Randomly deactivate each neuron with probability p during training: \tilde{h}_i = m_i \cdot h_i, \qquad m_i \sim \text{Bernoulli}(1-p)

Use all neurons for inference, but multiply the output by (1-p).

This can be interpreted as an approximation of ensemble learning — 2^n approximating the average of sub-networks with a single forward pass. Also prevents co-adaptation between neurons.

12 Key Summary

12.1 Separation of expressibility and learnability

UAT guarantees expressibility. Depth is critical to learnability and generalization. Think of the three concepts separately.

12.2 Two key equivalence relationships

  1. \;MLE = CE Minimization = KL Divergence Minimization (A unified perspective on classification model training)
  2. \;L2 regularization = Weight decay = MAP for Gaussian prior (Statistical justification of regularization)

12.3 4-stage structure of the learning mechanism

  1. Forward pass — Prediction calculation
  2. Loss Evaluation — Distance between Prediction and Correct Answer
  3. Backward pass — Gradient propagation using the chain rule
  4. Weight update — A variation of gradient descent

12.4 Evolution of Activation Functions

  • Step → Non-differentiable
  • Sigmoid → vanishing gradient
  • Tanh → zero-centered, still vanishing
  • ReLU → solves vanishing, dying problem
  • ReLU family (Leaky, PReLU) → dying relief

12.5 A Unified Perspective on Regularization

Technique Integrated Analysis
L2 / L1 Bayesian prior
Data augmentation Invariance prior
Multi-task Shared representation prior
Early stopping Implicit regularization
Dropout Ensemble averaging
Adversarial training Robustness in input neighborhood

Although they are different techniques, they all share the same goal of effectively limiting model complexity or injecting prior information about the data distribution.
