2 Relationship between AI / ML / Deep Learning

2.1 Hierarchy

인공지능 (AI)
 └─ 머신러닝 (Machine Learning)
      └─ 딥러닝 (Deep Learning)  ← 이 강의의 주제

According to Fig. 1.4 of the Goodfellow textbook, deep learning is a type of Representation Learning , representation learning is a type of machine learning, and machine learning is one of several methods of approaching AI . Non-ML methods, such as knowledge base systems, are also included in AI.

2.2 Core Ideas of Machine Learning

Structural Differences Between Traditional Programming and Machine Learning:

Paradigm Input Output
Traditional Programming Data + Program Output
Machine Learning Data + Output(Label) Program(Model)

Mathematically, it is to find a function \(f\) that predicts \(y^*\) for an unknown input \(x^*\) from the data pair \(\{(x_i, y_i)\}_{i=1}^N\).

\[f: \mathcal{X} \to \mathcal{Y}\]

2.3 Two classification axes of ML problems

\[\text{Classification of ML problems} \neq \text{Categorization of ML problems}\]

Both terms are translated as “classification” and may be confusing, but the reference axes are different.

2.3.1 Classification of ML problems — Based on output type

This is a classification based on the question “What does the model predict?”

Task Output Main Learning Method
Classification Discrete Label \(y \in \{1,\ldots,K\}\) Usually supervised
Regression Continuous value \(y \in \mathbb{R}\) Usually supervised
Similarity Similar/Dissimilar Pairs Usually supervised
Clustering Cluster Structure Usually unsupervised
Embedding Vector \(z \in \mathbb{R}^d\) Usually unsupervised
Reinforcement Learning Behavior Policy \(\pi\) RL

2.3.2 Categorization of ML problems — Based on learning method

This is a classification based on the question “How does the model learn?”

Method Label Usage Features
Supervised Use All Accurate, High Label Cost
Unsupervised None Cheap, structure found
Semi-supervised Partial use Practical compromise
Active learning Optional use Efficient labeling
Reinforcement Indirect Use Agent Behavior Optimization
ImportantKey distinction

The two classifications are two independent axes. Even for the same Classification task, training can be performed using supervised, unsupervised, or semi-supervised methods. Additionally, in “Classification of ML problems,” “Classification” refers to a meta-level classification behavior, and since one of the results is the “Classification task,” there is a circular structure that appears to be a tautology.

3 Key Concepts: Embedding, Manifold, Latent Space, Epoch

These are the four core concepts of deep learning. These concepts are not independent but are connected as follows.

고차원 Raw Data  →  Embedding  →  Manifold 위의 구조 발견
                                          ↓
                                  Latent Space (저차원 표현)
                                          ↓
                              Epoch 반복으로 점점 정교해짐

3.1 Embedding

3.1.1 Mathematical Definition

“When Object \(X\) is embedded in \(Y\), the embedding is given by the injective and structure-preserving function \(f: X \to Y\).”

In deep learning, it is specified as follows.

\[f_\theta: \mathbb{R}^D \to \mathbb{R}^d, \quad d \ll D\]

Two conditions are important.

① Injective:

\[x_1 \neq x_2 \implies f(x_1) \neq f(x_2)\]

Discriminability of information is preserved.

② Structure-preserving:

\[d_{\text{원공간}}(x_1, x_2) \approx d_{\text{임베딩}}(f(x_1), f(x_2))\]

Relationships in the original space are maintained in the embedding space as well. A representative example is the relationship preservation in Word2Vec.

\[\vec{\text{king}} - \vec{\text{man}} + \vec{\text{woman}} \approx \vec{\text{queen}}\]

3.1.2 Types of embeddings

Type Input Embedding Space Example
Word Embedding \(\mathbb{R}^{|V|}\) (one-hot) \(\mathbb{R}^{300}\) Word2Vec
Image Embedding \(\mathbb{R}^{H \times W \times 3}\) \(\mathbb{R}^{512}\) CNN feature
Neural Network Input Layer Each Hidden Layer All Deep Learning
TipWireless Network Perspective

Compressing a high-dimensional channel matrix \(\mathbf{H} \in \mathbb{C}^{N_r \times N_t}\) from CSI (Channel State Information) feedback into low-dimensional codewords is exactly what embedding is. Deep learning-based CSI compression, such as CsiNet, utilizes this principle.

3.2 Manifold

3.2.1 Mathematical Definition

“In mathematics, a \(n\)-dimensional manifold is a topological space in which the neighborhood of each point is homeomorphic to the \(n\)-dimensional Euclidean space \(\mathbb{R}^n\).”

Simply put, it is a space that looks like a flat Euclidean space when viewed from a sufficiently close distance (locally).

The image of a person standing on the Earth on the slide conveys this intuition well. The Earth is a sphere existing in three-dimensional space, but its surface is two-dimensional. A location on the Earth’s surface can be completely described using only two coordinates: latitude and longitude.

전체적으로(Globally):  구부러진 표면  (지구)
가까이서(Locally):     평평한 평면  (내 발 앞 땅)

3.2.2 Manifold Hypothesis

This is one of the theoretical grounds on which deep learning works.

Actual data is not evenly distributed in high-dimensional space, but, It is concentrated on a much lower-dimensional manifold.

Mathematically:

\[p_{\text{data}}(x) \text{ is concentrated near a manifold } \mathcal{M} \subset \mathbb{R}^D\]

\[\dim(\mathcal{M}) = d \ll D\]

Example: In a 28×28 = 784-dimensional image space, “natural handwriting images” exist only in a very small part (low-dimensional manifold) of this 784-dimensional space.

3.2.3 Relationship with the Curse of Dimensions

The Curse of Dimensionality discussed in Goodfellow Ch. 5.11 is overcome by the manifold hypothesis.

If the input dimension is \(d\) and Z\(v\) values are distinguished on each axis, the number of required regions increases exponentially with the dimension, reaching \(O(v^d)\). Deep learning utilizes the Manifold Hypothesis to learn the fact that real data is concentrated on a low-dimensional manifold within a high-dimensional space.

The Autoencoder is a representative model for learning this manifold.

\[\text{Encoder: } \mathbb{R}^D \xrightarrow{f_\phi} \mathbb{R}^d, \quad \text{Decoder: } \mathbb{R}^d \xrightarrow{g_\theta} \mathbb{R}^D\]

\[\min_{\phi, \theta} \mathbb{E}_{x \sim p_{\text{data}}} \|x - g_\theta(f_\phi(x))\|^2\]

3.3 Latent Space

3.3.1 Intuition

The puppeteer controls the entire complex movement of the puppet using only a few strings. What is visible (puppet movement, high dimension) is determined by what is invisible (string pulling, low dimension). The space of these invisible strings is precisely Latent Space.

3.3.2 Mathematical Definition

\[\underbrace{x}_{\text{관측 가능}} = g(\underbrace{z}_{\text{잠재 변수}}) + \epsilon\]

\(z \in \mathbb{R}^d\) are the hidden causes that generate data, and \(g: \mathbb{R}^d \to \mathbb{R}^D\) converts it into an observable form.

3.3.3 Subspace vs Latent Space

Subspace Latent Space
Origin Linear Algebra Probability Theory / Generative Models
Structure Linear Non-linearity allowed
Example Principal Component Space of PCA \(z\) Space of VAE

PCA (Linear Subspace):

\[z = W^\top x, \quad W \in \mathbb{R}^{D \times d} \text{ (직교 기저)}\]

VAE (Non-linear Latent Space):

\[q_\phi(z \mid x) \approx \mathcal{N}(\mu_\phi(x),\, \sigma^2_\phi(x))\]

Linear interpolation between two points \(z_1\) and \(z_2\) in a well-learned Latent Space generates meaningful intermediate data (continuity).

3.4 Epoch

3.4.1 Definition

The geological era stratigraphy provides intuition. Just as each geological era is a complete unit of time with a clear beginning and end, the training epoch is also a complete unit that completely traverses the entire dataset once.

Term Definition
\(N\) Total number of training data
\(b\) Batch Size
Iteration 1 parameter update
Epoch \(\lceil N/b \rceil\) Iteration = Cycle through the entire data once

SGD Update Rule:

\[\theta \leftarrow \theta - \eta \cdot \nabla_\theta \mathcal{L}(\theta;\, B_t)\]

1 Epoch = Performing the above update \(N/b\) times.

3.4.2 Epoch Number and Training State

너무 적은 Epoch  →  Underfitting  (학습 부족)
적당한 Epoch    →  Generalization (목표 상태)
너무 많은 Epoch  →  Overfitting   (훈련 데이터 암기)
                          ↑
                   Early Stopping으로 방지

4.2 Parameters vs Hyperparameters

Classification Definition Example Optimization Method
Parameter Learn from data Weights \(W\), Bias \(b\) Gradient Descent
Hyperparameter Control learning algorithm Learning rate \(\eta\), number of layers Explore with Validation Set

4.3 Why is a Validation Set necessary?

Goodfellow states the key point in Chapter 5.3. If hyperparameters controlling the model’s capacity are trained on the training data, the algorithm will always select the maximum possible capacity, which leads directly to overfitting.

\[\lambda^* = \arg\min_{\lambda \in \Lambda}\, \mathcal{L}_{\text{val}}\bigl(\theta^*(\lambda)\bigr)\]

WarningTest Set No Contamination

During the hyperparameter tuning process through validation, repeatedly examining the test set effectively turns it into a second validation set. The final performance estimate becomes optimistically biased. “It’s a crime!” — Lecture slides

4.4 Hyperparameter Automation: HPO

Hyperparameter tuning through the Validation Set is fully automatable and is actually automated in most modern ML pipelines.

Method Principle Characteristics
Grid Search Grid Search Combination Explosion Problem
Random Search Random Sampling More Efficient Than Grid (Bergstra & Bengio, 2012)
Bayesian Optimization Surrogate model + EI Currently most widely used
Gradient-based (DARTS) Implicit differentiation Used for architecture exploration

The Core of Bayesian Optimization:

\[\lambda_{\text{next}} = \arg\max_\lambda \text{EI}(\lambda), \quad \text{EI}(\lambda) = \mathbb{E}\!\left[\max(0,\, f(\lambda) - f(\lambda^+))\right]\]

4.4.1 K-Fold Cross-Validation

This is a method used when there is insufficient data.

\[E_{\text{CV}} = \frac{1}{K} \sum_{k=1}^K E_k\]

Divide the data into \(K\) parts, using 1 part for validation and the remaining \(K-1\) parts for training.

5 Generalization and LLM

5.1 The Ultimate Goal of Machine Learning

The ability to predict the correct output for unseen inputs by learning from training data

\[\text{목표: } E_{\text{train}} \approx E_{\text{test}}\]

who memorizes a little but reasons a lot is wiser than a student who memorizes everything but cannot reason .”

5.2 Did LLM achieve generalization?

Conclusion: Partially Yes, but the explanation is incomplete based on existing theories.

5.2.1 Conflict with Classical Theory

Generalization error of statistical learning theory bound:

\[E_{\text{test}} \leq E_{\text{train}} + O\!\left(\sqrt{\frac{\text{model complexity}}{N}}\right)\]

According to this, generalization should worsen as the model gets larger. However, GPT-4 (hundreds of billions of parameters) demonstrates excellent generalization. → Double Descent Phenomenon

5.2.2 Limitations of LLM

Limit Description
Hallucination Confidently generating incorrect information outside the training distribution
Distribution Shift Unable to adapt to information after the training point
Reasoning Limitations Systematic Failure in Complex Mathematical Reasoning
Shortcut Learning Learning statistical patterns, not real concepts

6.2 Hierarchical Representation Learning in Deep Learning

According to Goodfellow Ch. 1, deep learning constructs complex expressions from a combination of simple expressions.

\[\text{Raw Data} \xrightarrow{\text{Layer 1: edges}} \xrightarrow{\text{Layer 2: contours}} \xrightarrow{\text{Layer 3: parts}} \xrightarrow{\text{Layer 4: objects}} \text{Output}\]

NoteRepresentation Learning

Traditional ML designs features directly (hand-crafted features) by humans.

\[\text{Raw Data} \xrightarrow{\text{인간이 설계}} \text{벡터} \xrightarrow{\text{ML}} \text{출력}\]

Deep learning automatically learns this process from data.

\[\text{Raw Data} \xrightarrow{\text{Layer 1}} \xrightarrow{\text{Layer 2}} \cdots \xrightarrow{\text{Layer }L} \text{출력}\]

6.3 Why Traditional ML Fails: The Local Smoothness Assumption

According to Goodfellow Ch. 5.11, traditional ML relies on the local smoothness assumption. It estimates the output of a new input as the output of the nearest training point.

In high-dimensional space, this assumption is broken because there is not enough “near” training data (curse of dimensionality) . Deep learning overcomes this through hierarchical representation learning.

7 Double Descent

7.1 Classical Theory: Bias-Variance Tradeoff

Key formulas covered in Goodfellow Ch. 5.4:

\[\text{MSE}(\hat{\theta}) = \text{Bias}(\hat{\theta})^2 + \text{Var}(\hat{\theta})\]

Classical theory predicts that as model complexity (capacity) increases, bias decreases and variance increases, causing the test error to follow a U-shaped curve.

7.2 Discovery of Double Descent

A phenomenon reported by Belkin et al. in 2019. When the model is expanded beyond the level where it can perfectly fit the training data (Interpolation Threshold), the Test Error decreases again.

Test Error
  │╲
  │ ╲                    ← Double Descent
  │  ╲      /╲          /
  │   ╲    /  ╲        /  (두 번째 감소)
  │    ╲  /    ╲______/
  │     \/
  │  Classical  Modern
  │  Optimal    Optimal
  └────┬──────────────── 모델 복잡도 N
       ↑
  Interpolation Threshold
  (Train Error → 0이 되는 지점)

7.3 Three Regimes

Regime Condition Attribute
① Classical \(N_{\text{params}} \ll N_{\text{data}}\) Bias Dominance, Traditional U-curve
② Critical \(N_{\text{params}} \approx N_{\text{data}}\) Test Error Max (Critical Section)
③ Modern \(N_{\text{params}} \gg N_{\text{data}}\) Train Error = 0, Test Error re-reduced

7.4 Reasons why it becomes generalized in Modern Regimes

7.4.1 Implicit Regularization of SGD

SGD implicitly favors the minimum norm solution among the infinitely many solutions that satisfy the training data.

Set of solutions satisfying the training data in a linear model:

\[\{\theta : X\theta = y\}\]

tends to converge to the solution with the minimum of \(\|\theta\|_2\) in this set, i.e., the Moore-Penrose pseudoinverse solution.

\[\theta^* = X^\top(XX^\top)^{-1}y\]

7.4.2 Smooth Interpolation

With a much larger number of parameters, one can find a function that smoothly passes between training points. In the critical zone, the function must bend sharply, but in the Modern Regime, slack degrees of freedom lead to a smooth solution.

NoteEpoch-wise Double Descent

There is also a phenomenon that occurs the longer the same model is trained. Initially, it learns useful patterns (first-order descent), then memorizes noise (ascending), and after training long enough, it converges back to meaningful patterns (second-order descent). This is also the reason why Early Stopping is not always the best option.

TipWireless Network Perspective

in the same context as the distribution shift problem in channel estimation, where performance drops sharply when a trained model goes out of the SNR range . Also, just as Compressed Sensing finds a sparse solution for an underdetermined system \(M < N\) by minimizing the \(\ell_1\) norm, SGD also induces implicit sparsity.

8.3 ASI and Intelligence Explosion

The core scenario of ASI is Recursive Self-improvement.

AGI 달성
    ↓
AI가 자기 자신을 개선하는 코드 작성
    ↓
더 똑똑해진 AI가 또 자기 자신을 개선
    ↓  (기하급수적 폭발)
인간의 이해를 완전히 초월한 수준

If the rate of intelligence improvement is proportional to current intelligence:

\[\frac{dI}{dt} \propto I(t) \implies I(t) = I_0 e^{\alpha t}\]

This is called the Intelligence Singularity or Technological Singularity.

10 Key Summary

  • Deep learning is a machine learning methodology that uses deep neural networks.
  • The ultimate goal of ML is Generalization — the ability to predict on new data.
  • Data is separated into Train / Validation / Test, and each role is strictly distinguished.
  • Hyperparameter tuning can be automated through the Validation Set.
  • Double Descent is a modern phenomenon that goes beyond classical Bias-Variance theory.
  • Currently, all AI is ANI, and AGI/ASI has not yet been achieved.
