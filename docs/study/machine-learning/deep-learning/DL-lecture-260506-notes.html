Multimodal Models and Generative Models (I): VAE & GAN

Mamba · Multimodal Core Challenges · CLIP/SigLIP · Autoencoder · VAE · GAN

Published

May 4, 2026

1 Today’s Big Picture

The content covered today is broadly divided into two main axes.

  1. Multimodal Learning — A methodology for handling data of different modalities (images, text, audio, etc.) within a single system. After briefly examining an efficient alternative to the Transformer (Mamba), we will look at the five key challenges of multimodal learning and representative techniques such as CLIP and SigLIP.
  2. Generative model I — A model that attempts to learn the data distribution p(X) itself. Starting from autoencoders (AE), it covers VAE (variational inference + ELBO + reparameterization) and GAN (minimax game).

A single sentence connecting the two axes: “If we compress high-dimensional data into low-dimensional latent representations and transform that latent space into a distribution we can control, representation, alignment, fusion, and generation all become easier.”

TipOne-line mapping for wireless communication majors
  • Latent representation = Compressed representation of source coding
  • Force latent distribution to \mathcal N(0,I) = Gaussian codebook design
  • Comparative Learning (CLIP) = Matched Filter / Correlation Detection
  • GAN minimax = Worst-case robust design in 2-player zero-sum games with jammers

2 Transformer Limitations and Efficient Alternatives: Mamba

2.1 Two limitations of the Transformer

Self-attention is powerful but has two structural weaknesses.

  1. It is difficult to encode context outside the window. Attention interacts directly only within a fixed length of context.
  2. The computational complexity is O(n^2) (n is the sequence/window length). As the length increases, memory and computation increase exponentially.

Research aimed at reducing this forms a major trend known as “Efficient Transformers” (Tay et al., 2022).

2.2 Mamba: Optional state-space model (S6)

Mamba(Gu & Dao, 2023) views sequences as State Space Models (SSM) and processes them in linear time. The core idea is twofold.

  1. Selective mechanism (S6) — Maintain a small window, but selectively keep only relevant tokens within it. The method of measuring relevance is similar to the gating of an RNN.
  2. Hardware-aware parallel scan — Speed is achieved by computing sequential recursion as a parallel scan on the GPU.
Features Transformer Mamba
Complexity O(n^2) O(n) (Linear)
Advantages Strong context encoding (long-distance dependency) Computational efficiency, long window (256k+)
Weakness Computational Cost Expressiveness does not exceed Transformer [Chen et al., 2025]
NoteHybrid is the trend
  • Jamba: Mix Transformer + Mamba into a Mixture-of-Experts (MoE).
  • MambaVision: The initial layer is Mamba (efficiency), and the later layer is self-attention (long-range dependency).
  • TransMamba: Select one of the two based on layer/token.

From the perspective of circuit complexity, Mamba is not more expressive than Transformer. In other words, Mamba is not a “smarter” model, but a “cheaper” model.

TipWireless Communication Perspective

An optional SSM is essentially a recursive state estimator. The form of the state h_t = A h_{t-1} + B x_t and output y_t = C h_t is a framework similar to a Kalman filter / linear dynamic system. Determining how much of the past to forget through gating directly corresponds to adaptively adjusting the forgetting factor \lambda of an RLS (Recursive Least Squares).

3 5 Key Tasks of Multimodal Learning

Modality = “mode”, that is, the format in which data is received (visual, auditory, linguistic, etc.). Multimodal = Perception that deals with multiple modes together.

Multimodal ML in the deep learning era (2010~) is summarized into the following five tasks (Baltrušaitis, Ahuja & Morency, TPAMI 2019).

3.1 Assignment 1 — Representation

Definition: A method of summarizing and representing multimodal data by utilizing complementarity and redundancy between modalities.

Expression learning is divided into two branches.

Method Description Difficulty Remaining Tasks
Joint representation Embeds all modalities in a single space Learning is difficult (None — once trained, it is easy)
Coordinated representation Align after learning separate spaces for each modality Relatively easy How to align the two spaces

Key Insight: Tuning expressions are usually easier. This is because co-expressions attempt to solve difficult problems all at once, whereas tuning expressions defer the difficulty to an “alignment stage.”

3.1.1 Multimodal Vector Arithmetic (Vector arithmetic)

In a well-trained co-embedding space, semantics are represented as vector operations.

\text{vec}(\text{이미지: 파란 책}) - \text{vec}(\text{파랑}) + \text{vec}(\text{빨강}) \approx \text{vec}(\text{빨간 책})

If you remove “sky” and add “sea” from an airplane image, the nearest neighbor becomes a boat image. This is because semantically similar data is clustered in spatially close areas. (Multimodal version of Word2Vec’s king - man + woman ≈ queen.)

3.2 Assignment 2 — Alignment

Definition: Finding a direct correspondence between (sub)elements in two or more modes.

Type Description
Explicit alignment 1:1 direct mapping of elements of one modality to elements of another modality
Implicit alignment Instead of creating explicit correspondences, leave it to a learned function to perform the mapping
Warning

The alignment referred to here is a completely different concept from LLM alignment (human value alignment). Please be careful not to confuse them.

3.3 Assignment 3 — Fusion

Definition: The combination of information from two or more modalities for the purpose of prediction. (Since the essence of AI is ultimately to predict something, it must combine multiple inputs into one to make a prediction.)

  • Early fusion: Combine before feeding into the model. The simplest method is to concatenate the two feature vectors.
  • Late fusion: Pass each model through each modality, then combine them at the output stage.
  • Model-based (Intermediate) fusion: Designed to fuse internal within the model (neural networks, graph models, etc.). Trained end-to-end.

3.4 Assignment 4 — Translation

Definition: Changing data from one modality to another. The correspondence is often open-ended/subjective.

  • Image → Text: Captioning
  • Text → Image: Image generation
  • Text → Video: Video generation
Type Description Examples/Limitations
Example-based Directly constructed using data mapping between modalities as an example Lexicographical 1:1 mapping. Works well when word order and meaning are similar, like in language translation (English ↔︎ French). Difficult when words do not match 1:1, like in English ↔︎ Chinese
Model-driven Uses a transformation model trained with mapping examples Most modern translators. Primarily uses neural networks

3.5 Assignment 5 — Co-Learning

Definition: A learning framework that transfers knowledge (representation and predictive power) between modes.

Today’s Reality: The four tasks above have virtually all been absorbed into one massive neural network. The current mainstream paradigm is “scale up the model without worrying about representation/alignment/fusion/transformation separately.”

ImportantEfficiency is competitiveness

However, scaling is very expensive in terms of money and power. Finding a efficient method to transfer knowledge better with less data and power has significant implications for beating giant tech companies with small technology. (A message as a direction for research.)

TipWireless Communication Perspective

Fusion corresponds exactly to diversity combining.

  • Early fusion (concatenate) ↔︎ Combines antenna signals before combining → Combines at the raw signal stage like MRC (Maximal-Ratio Combining)
  • Late fusion ↔︎ Independent detection and combination at each antenna → selection / soft combining

The complementarity and redundancy of different modes are the complementarity and redundancy of spatial diversity.

4 Text–Vision Co-embedding: CLIP and SigLIP

4.1 CLIP (OpenAI, 2021)

CLIP (Contrastive Language–Image Pre-training) is the most widely used multimodal co-embedding technique.

  • Image encoder (ViT/CNN) and Text encoder (Transformer) each create embeddings.
  • Contrastive learning makes the embeddings of “correct (image, text) pairs” close and “incorrect pairs” far apart.
  • As a result, zero-shot classification (classification without task-specific fine-tuning) becomes possible.

4.1.1 Mechanism of Contrastive Pre-training

Creates an inner product (similarity) matrix for all pairs from the mini-batch N (image, text) pairs. The diagonal (I_i\cdot T_i) represents the correct answer (positive), and the rest represent the incorrect answer (negative).

Logit \ell_{ij} = I_i^\top T_j / \tau for image embedding I_i, text embedding T_j (L2 normalized), temperature \tau. The loss is the average of the row direction (image→text) and column direction (text→image) cross-entropy.

\mathcal{L}_{\text{CLIP}} = \frac{1}{2N}\sum_{i=1}^{N} \Bigg[ \underbrace{-\log\frac{e^{\ell_{ii}}}{\sum_{j} e^{\ell_{ij}}}}_{\text{이미지}\to\text{텍스트}} \;+\; \underbrace{-\log\frac{e^{\ell_{ii}}}{\sum_{j} e^{\ell_{ji}}}}_{\text{텍스트}\to\text{이미지}} \Bigg]

Key point: Softmax is applied to the entire mini-batch. In other words, for a single image, it is a N multiple-choice classification problem of “selecting the correct answer from all texts in the batch.”

4.2 SigLIP (Google DeepMind, 2021)

CLIP’s softmax requires normalization of the entire batch, resulting in high memory/communication costs. SigLIP replaces this with sigmoid (binary classification) independent of each pair.

y_{ij} = +1 (correct pair, i=j) / -1 (incorrect pair), for scale t, bias b:

\mathcal{L}_{\text{SigLIP}} = -\frac{1}{N}\sum_{i=1}^{N}\sum_{j=1}^{N} \log \sigma\!\big(y_{ij}\,(t\, I_i^\top T_j + b)\big), \qquad \sigma(u)=\frac{1}{1+e^{-u}}

Since each pair is an independent binary decision, batch-wide normalization is not required → Increased parallelization and memory efficiency, easy to scale to large batches.

NoteCLIP + Diffusion Model = Bridge to Generation

By mapping a random vector to a CLIP embedding and using that embedding as a condition for a diffusion model, images/videos can be generated from text. DALL·E 3, Make-A-Video, Phenaki, Sora, and Runway Gen-4.5 are multimodal generation models of this family.

TipWireless Communication Perspective — Contrast Learning = Detection Theory

CLIP’s softmax-over-batch is equivalent to Maximum-Likelihood detection (ML detection) in a codebook. It selects the codeword (correct text) most correlated with the received signal (image embedding) from N candidates — this is precisely the matched-filter bank + argmax.

SigLIP’s sigmoid-per-pair is an individual binary hypothesis test (energy/correlation detection) for each pair. That is, - CLIP = Combined ML Detection (Global normalization required, optimal but expensive) - SigLIP = Pairwise Independent Detection (Separable, Excellent Scalability)

The inner product I_i^\top T_j is the correlation, and \tau/temperature is the same as the SNR scale that controls the sharpness of the detection threshold.

5 Generative Model Overview & Autoencoder Review

5.1 Autoencoder(Autoencoder, AE)

AE Goal: Feed input x into the model to reconstruct itself.

WarningThe trap of “Can’t you just copy it?”

If we output the input exactly as is, it is a perfect solution with zero reconstruction error. So why bother using an encoder-decoder?

Answer: This is because the dimension of the latent representation z is smaller than the input. (For example, Input 7 dimensions → Latent 4 dimensions.) Reconstruction is possible only by passing information through a narrow channel, discarding noise and retaining only the core information. This forced narrow channel is precisely the information bottleneck.

  • Encoder: Extract key information from input (compress).
  • Decoder: Reconstruct input from core information.
  • By stacking more deeply (deep AE), more sophisticated information can be compressed/restored step by step.
TipWireless Communication Perspective — Information Bottleneck = Rate–Distortion

The information bottleneck is lossy source coding itself. Latent dimension = bit rate R, restoration error = distortion D. AE solves the rate-distortion optimization problem using neural networks to minimize distortion within a given rate budget. The fewer the “knobs” called latent dimensions, the more precisely the latent space can be controlled.

5.2 Why AE Matters Now: LeCun’s Cake Analogy

Yann LeCun (Meta FAIR, NYU) likened the amount of information a machine receives during learning to a cake.

Learning method Cake region Signal quantity/quality Reason
Reinforcement Learning (RL) Cherry Very weak, stochastic Rewards are given in the future, sporadically. The reward at the current time must be predicted as an expectation, and the variance is large
Supervised Learning Icing Sparse The label “This image = cake” does not tell you anything about color, background, shape, etc.
Self-supervised Learning (SSL) Bread (Main Body) Richest To reconstruct the entire input, all details must be learned. Labels are also unnecessary
Note

Reasons why SSL is powerful: (1) extracts almost all information from the data, (2) no human labeling required → easy data acquisition. **The only difficulty is “designing a good pretext task (self-supervised task)”. AE’s “input restoration” is the most basic pretext task.

TipWireless Communication Perspective — Weak Compensation = Low SNR Feedback

The fact that the reward signal in RL is “weak and stochastic” is equivalent to a feedback channel arriving sporadically with a very low SNR. Since the estimated variance is large, learning is slow and unstable. On the other hand, since the entire input is the correct answer in SSL, it is a high-SNR full-feedback situation.

6 VAE (Variational Auto-Encoder)

Today’s main. VAE is applying an additional constraint to AE that “the latent space must follow a Gaussian distribution.”

6.1 One-line summary

VAE = AE + “Normalization that forces the latent representation z to follow \mathcal N(0,I)”. This allows for complete control of the latent space (→ smooth generation and interpolation), and learns p(x), which cannot be directly computed, by bypassing it through variational inference.

6.2 Goal as a Generative Model

Given the data X=\{x_1,\dots,x_n\}, we want to find the distribution p(X) that explains it. However, it is difficult to model p(X) directly. Therefore, we introduce a latent variable z.

p(x) = \sum_{z} p(x\mid z)\,p(z) \quad\xrightarrow{\text{연속}}\quad p(x) = \int p(x\mid z)\,p(z)\,dz

Here, the prior distribution is fixed to p(z)=\mathcal N(0,I). Interpretation: “First, we draw z from the Gaussian (z\sim p(z)), and from that, we generate x (x\sim p(x\mid z)).”

6.2.1 Why Gaussian latent, of all things?

  1. Analytically tractable. For Gaussians, differentiation, integration, and sampling are all well-defined, and KL and others also appear in a closed form.
  2. Sampling is easy. Almost all hardware/libraries have a Gaussian sampler.
  3. It is sufficiently expressive. Many natural phenomena follow a Gaussian distribution (Central Limit Theorem). Therefore, it is not unreasonable to assume that the latent space is Gaussian, and natural phenomena can be modeled in a controlled manner.

6.3 Integration is difficult to handle (intractability)

Problem: In p(x)=\int p(x\mid z)p(z)\,dz, p(x\mid z) is a decoder (non-linear neural network), so the integral does not come out in a closed form.

NoteWhen you encounter “difficult integration” — Two branches

(a) Monte Carlo Sampling. Integration = “Calculating Area”. The area of a strangely shaped region is approximated by the proportion of arrows thrown infinitely into a rectangle that land within the region (Dart Game). That is, \int f \approx \frac{1}{M}\sum_m f(z_m). Problem: The latent space of images/audio/text is too high-dimensional to approximate an integral using samples (Curse of Dimensionality).

(b) Variational Inference. A more sample-efficient alternative. → The path chosen by VAE.

6.4 Variational Inference and ELBO Derivation

6.4.1 Key Identity

For any distribution q(z) (using \int q(z)dz=1), using Bayes’ theorem p(x)=\frac{p(x,z)}{p(z\mid x)}:

\begin{aligned} \log p(x) &= \log p(x)\cdot 1 = \log p(x)\int q(z)\,dz = \int q(z)\log p(x)\,dz\\ &= \int q(z)\log \frac{p(x,z)}{p(z\mid x)}\,dz \qquad (\because \text{Bayes})\\ &= \int q(z)\big(\log p(x,z) - \log p(z\mid x)\big)\,dz\\ &= \mathbb{E}_{z\sim q}\big[\log p(x,z) - \log p(z\mid x)\big] \end{aligned}

6.4.2 Introduction of variational family → ELBO + KL

Now, let q be parameterized to q_\phi(z) (this is the encoder, the inference network). If we insert \frac{q_\phi(z)}{q_\phi(z)}=1 and expand it:

\begin{aligned} \log p(x) &= \int q_\phi(z)\log\frac{p(x,z)}{p(z\mid x)}\,dz = \int q_\phi(z)\log\!\left[\frac{p(x,z)}{q_\phi(z)}\cdot\frac{q_\phi(z)}{p(z\mid x)}\right]dz\\ &= \underbrace{\mathbb{E}_{q}\big[\log p(x,z) - \log q_\phi(z)\big]}_{\textbf{ELBO}\;(\text{Evidence Lower BOund})} \;+\; \underbrace{\mathrm{KL}\!\big[\,q_\phi(z)\,\|\,p(z\mid x)\,\big]}_{\ge\,0} \end{aligned}

ImportantWhy is this decomposition decisive?
  • \log p(x) is a constant (a real value we cannot touch, “evidence”) for \phi.
  • KL is always \ge 0 (non-negativeness of KL). Therefore \log p(x) \ge \text{ELBO} → “Evidence Lower Bound”.
  • What we really want to reduce is \mathrm{KL}[q_\phi(z)\|p(z\mid x)] (the distance between my approximate posterior distribution and the true posterior distribution), but since we do not know the true posterior distribution p(z\mid x), we cannot directly reduce KL.
  • Since the left side is a constant instead of , maximizing ELBO = minimizing KL. ELBO is computable. → Let’s maximize ELBO!

6.4.3 ELBO Expansion → Restoration Term + Normalization Term

Substitute p(x,z)=p(x\mid z)p(z):

\begin{aligned} \text{ELBO} &= \mathbb{E}_{q}\big[\log p(x,z) - \log q_\phi(z)\big] = \mathbb{E}_{q}\big[\log p(x\mid z) + \log p(z) - \log q_\phi(z)\big]\\ &= \mathbb{E}_{q}\big[\log p(x\mid z)\big] + \mathbb{E}_{q}\big[\log p(z) - \log q_\phi(z)\big]\\ &= \mathbb{E}_{q}\big[\log p(x\mid z)\big] - \mathbb{E}_{q}\big[\log q_\phi(z) - \log p(z)\big]\\ &= \underbrace{\mathbb{E}_{q}\big[\log p(x\mid z)\big]}_{\textbf{복원(Reconstruction)}} \;-\; \underbrace{\mathrm{KL}\!\big(q_\phi(z)\,\|\,p(z)\big)}_{\textbf{정규화(Regularization)}} \end{aligned}

Term Meaning Role
Recovered Term \mathbb{E}_q[\log p(x\mid z)] How well x is recovered from z (Decoder Quality) Data Fidelity
Normalization Term \mathrm{KL}(q_\phi(z)\|p(z)) How well the latent z follows the prior \mathcal N(0,I) Latent Space Control

ELBO maximization balances these two: “zZ well reconstructs x, while the distribution of z is close to \mathcal N(0,I).”

6.5 VAE Loss Function and Reparameterization Trick

Since ELBO is the maximization target, the sign is flipped to write it as loss (minimization). (Decoder p_\theta(x\mid z), Encoder q_\phi(z\mid x))

\boxed{\; \mathcal{L}_{\text{VAE}}(\theta,\phi) = \underbrace{-\,\mathbb{E}_{q_\phi}\!\big[\log p_\theta(x\mid z)\big]}_{\approx\ \text{MSE/CE 복원 손실}} \;+\; \underbrace{\mathrm{KL}\!\big(q_\phi(z\mid x)\,\|\,p(z)\big)}_{\text{닫힌 형태 (가우시안)}} \;}

NoteNotation Caution (Precision)
  • This note follows standard (Kingma & Welling) notation: The parameters of the encoder/inference network q_\phi are set to \phi, and the parameters of the decoder/generation network p_\theta are set to \theta.
  • Some data may have \theta for the encoder and \phi for the decoder (notation with reversed roles), so you must read it based on which network it refers to to avoid confusion. What is important is not the symbol, but the distinction between the roles of “inference network vs. generative network”.

Since the restoration term is defined as the difference between x and \hat x, it becomes either MSE loss (Gaussian likelihood) or cross-entropy (Bernoulli likelihood) depending on the assumption. The KL term falls into a closed form as it is between the two Gaussians (equation in the appendix below).

6.5.1 Problem: Sampling is not differentiable

To train , backpropagation must be done to \hat x \to z \to x, but z\sim q_\phi(z\mid x) is stochastic sampling, so the gradient cannot pass through.

6.5.2 Solution: Reparameterization trick

The probability is subtracted as exogenous noise on the input side \epsilon.

\boxed{\;z = \mu_\phi(x) + \sigma_\phi(x)\odot \epsilon,\qquad \epsilon\sim\mathcal N(0,I)\;}

Now z is a deterministic function of \mu_\phi,\sigma_\phi (neural network output) + fixed noise. The mean \mu becomes a differentiable expression that depends on the encoder, and the variance \sigma also depends on the encoder, so we can randomize only \epsilon and backpropagate normally to \phi,\theta.

6.6 VAE Results and Advantages

  • Generates less blurry samples than AE.
  • The latent space is controllable. If it is a 10-dimensional Gaussian latent, each dimension can correspond to a semantic. For example, disentangled generation and interpolation is possible, such as sweeping dimension 1 as -\infty\to+\infty to change from female to male, or sweeping dimension 2 to change the hairstyle.
  • The latent space is analyzable, allowing for the diagnosis of the learning process, such as what additional data is needed (in contrast to the opaque latent space of AE).
TipWireless Communication Perspective — Three Mappings of VAE
  1. Reparameterization trick = AWGN model. z=\mu+\sigma\epsilon is exactly a signal + Gaussian noise model. It is the sum of scaled white noise (\sigma\epsilon) and the deterministic signal component (\mu). It is isomorphic to y = s + n,\ n\sim\mathcal N(0,\sigma^2), which is commonly used in radio. Thanks to this, it is possible to capture the “pathwise derivative” of the expected value.
  2. Gaussian latent prior = Gaussian input codebook. In the same context as the input distribution being Gaussian for achieving the capacity of an AWGN channel — Gaussian is the natural choice for “maximum entropy/optimal representation”.
  3. ELBO = Lower bound of unmanageable likelihood. The strategy of optimizing by replacing the marginal likelihood that cannot be directly calculated with a computable lower bound is based on the same idea as solving the unmanageable likelihood in detection/estimation using the variable lower bound·EM. KL regularization acts as a power constraint that “limits the power (variance) of the latent to \mathcal N(0,I)”.

7 GAN (Generative Adversarial Network)

Goodfellow et al., NeurIPS 2014. Borrows the structure of VAE, but uses adversarial loss instead of MSE.

7.1 Synchronization: Beyond the blur of MSE

MSE reconstruction in VAE/AE tends to produce blurry results by selecting average, safe pixel values. GANs add adversarial loss to create sharp images with preserved detail.

7.2 Composition: Generator G and Discriminator D

  • Generator G(z): Random vector z → Image. (Good G = Generated image looks real)
  • Discriminator D(x): Image → “Probability of being real”. (Good D = good at distinguishing between real and fake)
  • Learning through competition: G tries to deceive D, and D tries not to be deceived. They attack each other hostilely and become stronger together.

7.3 Minimax Officialization

\boxed{\; \min_{G}\max_{D}\; \mathbb{E}_{x\sim q_{\text{data}}(x)}\big[\log D(x)\big] \;+\; \mathbb{E}_{z\sim p(z)}\big[\log\big(1 - D(G(z))\big)\big] \;}

Physical meaning: \log(\text{$x$가 진짜일 확률}) + \log(1-\text{$G(z)$가 진짜일 확률}).

  • As this value increases, D is better → Maximize for D.
  • As this value becomes smaller, G is better (deceives D well) → minimize for G.
  • This type of problem is called a Minimax problem, or a zero-sum non-cooperative game.
NoteAdvanced — Optimal Discriminator and JS Divergence

When G is fixed, the optimal discriminator is D^*(x) = \frac{q_{\text{data}}(x)}{q_{\text{data}}(x) + p_g(x)}. If we substitute this, the objective function is V(G,D^*) = -\log 4 + 2\cdot \mathrm{JSD}\big(q_{\text{data}}\,\|\,p_g\big) (\mathrm{JSD} = Jensen–Shannon divergence). In other words, minimizing G means aligning the generating distribution p_g to the true distribution q_{\text{data}} based on the JS divergence. The global optimal is p_g = q_{\text{data}}, at which point it becomes V=-\log 4. (Numerically verified in the appendix code.)

7.5 Learning difficulties

GAN training is notoriously difficult.

Problem Symptoms
Non-convergence (Non-convergence) Parameters are oscillatory/unstable and do not converge
Mode collapse (Mode collapse) G mass-produces only similar samples (loss of diversity)
Diminished Gradient (Gradient Vanishing) D becomes too strong, causing G’s gradient to disappear and learning to stagnate
  • The imbalance between D and G causes the above problem. Hyperparameter selection is a “work of art”.
  • Stabilized variants: LSGAN, WGAN, WGAN-GP, BEGAN etc.
  • Diffusion Models Emerge as a Fundamental Alternative: Learning is slow, but stable and of excellent quality.

7.6 Why GANs Are Effective: Hard Negative

D constantly provides G with hard negatives. By creating “almost real fakes” near the decision boundary to pressure G, it becomes a much stronger learning signal than simple MSE.

WarningAdversarial Example ≠ Adversarial Learning

Caution: Confusion. Adversarial examples are created by applying small perturbations to the input to cause a neural network to produce an unexpected output.

  • Example: Adding fine patterns to stop signs causes autonomous driving AI to mistake them for “slow down” → Danger.
  • Example: If you insert a texture invisible to the human eye into a cat image, the CNN asserts with high probability that it is a “desktop computer.”

This is evidence that neural networks are extremely sensitive (vulnerable) to small changes in input. The “adversarial” of GANs shares only the word with this phenomenon, but holds a different philosophy that two networks compete.

TipWireless Communication Perspective — GAN = Jamming Game, Adversarial Example = Precision Interference
  • Minimax = A zero-sum game between a jammer and a transceiver. D (the receiver) attempts to distinguish (detect) real/fake signals, and G (the jammer) synthesizes signals to evade detection. Nash equilibrium is equivalent to the saddle point of a worst-case robust design.
  • Adversarial example = low-power interference aligned to the decision boundary. Misculating the detector with very small perturbations (\|\delta\| small) is equivalent to a minimum power disturbance signal aligned to the decision boundary normal direction. The sensitivity of a neural network is equivalent to the ill-conditioning of the classifier — minute changes in the input are amplified in the output.
  • Hard negative = High-difficulty sample near the boundary. Like the “test signal near the threshold SNR” in detection theory, it provides the most informative learning signal.

9.1 Closed form of Gaussian KL (VAE normalization term)

When q=\mathcal N(\mu,\sigma^2), p=\mathcal N(0,1), \mathrm{KL}(q\|p) = \frac{1}{2}\sum_{j}\big(\mu_j^2 + \sigma_j^2 - \log\sigma_j^2 - 1\big).

def gaussian_kl_closed(mu, var):
    # KL( N(mu, var) || N(0, I) ), per-dimension diagonal Gaussian
    return 0.5 * np.sum(mu**2 + var - np.log(var) - 1)

9.2 Reparameterization trick + VAE loss (forward)

def reparameterize(mu, logvar, eps=None):
    # z = mu + sigma * eps,  sigma = exp(0.5*logvar)
    std = np.exp(0.5*logvar)
    if eps is None:
        eps = rng.normal(size=mu.shape)
    return mu + std*eps                       # AWGN 모델: 신호 mu + 잡음 std*eps

def vae_loss(x, x_hat, mu, logvar):
    recon = np.mean(np.sum((x - x_hat)**2, axis=1))      # MSE 복원항
    kl    = np.mean(0.5*np.sum(np.exp(logvar) + mu**2 - 1 - logvar, axis=1))
    return recon + kl, recon, kl

9.3 CLIP Symmetric Contrast Loss

def clip_loss(I, T, tau=1.0):
    I = I/np.linalg.norm(I, axis=1, keepdims=True)
    T = T/np.linalg.norm(T, axis=1, keepdims=True)
    logits = I @ T.T / tau                    # 상관(correlation) 행렬, 대각이 정답
    N = len(I)
    def ce_rows(L):
        L = L - L.max(1, keepdims=True)
        logp = L - np.log(np.exp(L).sum(1, keepdims=True))
        return -logp[np.arange(N), np.arange(N)].mean()
    return 0.5*(ce_rows(logits) + ce_rows(logits.T))   # 이미지→텍스트 + 텍스트→이미지

N, d = 8, 16
base = rng.normal(size=(N, d))

9.4 SigLIP Sigmoid Loss

def sigmoid(u): return 1/(1+np.exp(-u))

def siglip_loss(I, T, t=10.0, b=-10.0):
    I = I/np.linalg.norm(I, axis=1, keepdims=True)
    T = T/np.linalg.norm(T, axis=1, keepdims=True)
    S = I @ T.T                                # 상관 행렬
    N = len(I)
    Y = -np.ones((N, N)); np.fill_diagonal(Y, 1.0)   # 대각=+1(정답), 나머지=-1
    logits = Y*(t*S + b)
    return -np.mean(np.log(sigmoid(logits) + 1e-12)) # 쌍별 독립 이진 결정

# Transformer Limitations and Efficient Alternatives: Mamba {#sec-mamba}

## Two limitations of the Transformer

Self-attention is powerful but has two structural weaknesses.

1. **It is difficult to encode context outside the window.** Attention interacts directly only within a fixed length of context.
2. **The computational complexity is $O(n^2)$** ($n$ is the sequence/window length). As the length increases, memory and computation increase exponentially.

Research aimed at reducing this forms a major trend known as "Efficient Transformers" (Tay et al., 2022).

## Mamba: Optional state-space model (S6)

**Mamba**(Gu & Dao, 2023) views sequences as **State Space Models (SSM)** and processes them in linear time. The core idea is twofold.

1. **Selective mechanism (S6)** — Maintain a small window, but selectively keep only *relevant tokens* within it. The method of measuring relevance is similar to the **gating** of an RNN.
2. **Hardware-aware parallel scan** — Speed is achieved by computing sequential recursion as a parallel scan on the GPU.

| Features | Transformer | Mamba |
|---|---|---|
| Complexity | $O(n^2)$ | $O(n)$ (Linear) |
| Advantages | Strong context encoding (long-distance dependency) | Computational efficiency, long window (256k+) |
| Weakness | Computational Cost | Expressiveness does not exceed Transformer [Chen et al., 2025] |

::: {.callout-note}
## Hybrid is the trend
- **Jamba**: Mix Transformer + Mamba into a Mixture-of-Experts (MoE).
- **MambaVision**: The initial layer is Mamba (efficiency), and the later layer is self-attention (long-range dependency).
- **TransMamba**: Select one of the two based on layer/token.

From the perspective of circuit complexity, **Mamba is not more expressive than Transformer.** In other words, Mamba is not a "smarter" model, but a "cheaper" model.
:::

::: {.callout-tip}
## Wireless Communication Perspective
An optional SSM is essentially a **recursive state estimator**. The form of the state $h_t = A h_{t-1} + B x_t$ and output $y_t = C h_t$ is a framework similar to a **Kalman filter** / linear dynamic system. Determining how much of the past to forget through gating directly corresponds to adaptively adjusting the **forgetting factor** $\lambda$ of an RLS (Recursive Least Squares).
:::

# 5 Key Tasks of Multimodal Learning {#sec-mm-challenges}

> Modality = "mode", that is, the format in which data is received (visual, auditory, linguistic, etc.). Multimodal = Perception that deals with multiple modes together.

Multimodal ML in the deep learning era (2010~) is summarized into the following five tasks (Baltrušaitis, Ahuja & Morency, TPAMI 2019).

```{mermaid}
flowchart LR
    A[Multimodal ML] --> R[1\. Representation<br/>표현]
    A --> AL[2\. Alignment<br/>정렬]
    A --> F[3\. Fusion<br/>융합]
    A --> T[4\. Translation<br/>변환]
    A --> C[5\. Co-Learning<br/>공동학습]
```

## Assignment 1 — Representation

**Definition:** A method of summarizing and representing multimodal data by utilizing **complementarity** and **redundancy** between modalities.

Expression learning is divided into two branches.

| Method | Description | Difficulty | Remaining Tasks |
|---|---|---|---|
| **Joint representation** | Embeds all modalities in a **single space** | Learning is **difficult** | (None — once trained, it is easy) |
| **Coordinated representation** | Align after learning **separate spaces** for each modality | Relatively **easy** | How to **align** the two spaces |

Key Insight: **Tuning expressions are usually easier.** This is because co-expressions attempt to solve difficult problems all at once, whereas tuning expressions defer the difficulty to an "alignment stage."

### Multimodal Vector Arithmetic (Vector arithmetic)

In a well-trained co-embedding space, semantics are represented as vector operations.

$$
\text{vec}(\text{이미지: 파란 책}) - \text{vec}(\text{파랑}) + \text{vec}(\text{빨강}) \approx \text{vec}(\text{빨간 책})
$$

If you remove "sky" and add "sea" from an airplane image, the nearest neighbor becomes a **boat** image. This is because semantically similar data is clustered in spatially close areas. (Multimodal version of Word2Vec's `king - man + woman ≈ queen`.)

## Assignment 2 — Alignment

**Definition:** Finding a **direct correspondence** between (sub)elements in two or more modes.

| Type | Description |
|---|---|
| **Explicit alignment** | **1:1 direct mapping** of elements of one modality to elements of another modality |
| **Implicit alignment** | Instead of creating explicit correspondences, leave it to a **learned function** to perform the mapping |

::: {.callout-warning}
The alignment referred to here is a completely different concept from **LLM alignment (human value alignment)**. Please be careful not to confuse them.
:::

## Assignment 3 — Fusion

**Definition:** The **combination** of information from two or more modalities for the purpose of prediction. (Since the essence of AI is ultimately to predict something, it must combine multiple inputs into one to make a prediction.)

```{mermaid}
flowchart TB
    subgraph EF["Early Fusion (model-agnostic)"]
      a1[모달 A] --> cc[Concatenate]
      a2[모달 B] --> cc
      cc --> m1[Model] --> o1[예측]
    end
    subgraph LF["Late Fusion (model-agnostic)"]
      b1[모달 A] --> mA[Model A] --> mm[Merge]
      b2[모달 B] --> mB[Model B] --> mm
      mm --> o2[예측]
    end
    subgraph IF["Intermediate / model-based"]
      c1[모달 A] --> mid[하나의 모델 내부에서 융합<br/>예: 신경망, 그래프 모델]
      c2[모달 B] --> mid --> o3[예측]
    end
```

- **Early fusion**: Combine *before* feeding into the model. The simplest method is to **concatenate** the two feature vectors.
- **Late fusion**: Pass each model through each modality, then combine them at the *output stage*.
- **Model-based (Intermediate) fusion**: Designed to fuse *internal* within the model (neural networks, graph models, etc.). Trained end-to-end.

## Assignment 4 — Translation

**Definition:** **Changing** data from one modality to another. The correspondence is often open-ended/subjective.

- Image → Text: **Captioning**
- Text → Image: **Image generation**
- Text → Video: **Video generation**

| Type | Description | Examples/Limitations |
|---|---|---|
| **Example-based** | Directly constructed using data mapping between modalities as an example | Lexicographical 1:1 mapping. Works well when word order and meaning are similar, like in language translation (English ↔ French). Difficult when words do not match 1:1, like in English ↔ Chinese |
| **Model-driven** | Uses a **transformation model** trained with mapping examples | Most modern translators. Primarily uses neural networks |

## Assignment 5 — Co-Learning

**Definition:** A learning framework that **transfers knowledge (representation and predictive power)** between modes.

> **Today's Reality:** The four tasks above have virtually all been absorbed into **one massive neural network**. The current mainstream paradigm is "scale up the model without worrying about representation/alignment/fusion/transformation separately."

::: {.callout-important}
## Efficiency is competitiveness
However, scaling is **very expensive in terms of money and power.** Finding a **efficient** method to transfer knowledge better with less data and power has significant implications for beating giant tech companies with small technology. (A message as a direction for research.)
:::

::: {.callout-tip}
## Wireless Communication Perspective
Fusion corresponds exactly to **diversity combining**.

- *Early fusion (concatenate)* ↔ Combines antenna signals before combining → Combines at the raw signal stage like **MRC (Maximal-Ratio Combining)**
- *Late fusion* ↔ Independent detection and combination at each antenna → **selection / soft combining**

The complementarity and redundancy of different modes are the complementarity and redundancy of **spatial diversity**.
:::

# Text–Vision Co-embedding: CLIP and SigLIP {#sec-clip}

## CLIP (OpenAI, 2021)

CLIP (Contrastive Language–Image Pre-training) is the most widely used multimodal co-embedding technique.

- **Image encoder** (ViT/CNN) and **Text encoder** (Transformer) each create embeddings.
- **Contrastive learning** makes the embeddings of "correct (image, text) pairs" close and "incorrect pairs" far apart.
- As a result, **zero-shot classification** (classification without task-specific fine-tuning) becomes possible.

### Mechanism of Contrastive Pre-training

Creates an inner product (similarity) matrix for all pairs from the mini-batch $N$ (image, text) pairs. The diagonal ($I_i\cdot T_i$) represents the correct answer (positive), and the rest represent the incorrect answer (negative).

Logit $\ell_{ij} = I_i^\top T_j / \tau$ for image embedding $I_i$, text embedding $T_j$ (L2 normalized), temperature $\tau$. The loss is the **average of the row direction (image→text) and column direction (text→image) cross-entropy**.

$$
\mathcal{L}_{\text{CLIP}}
= \frac{1}{2N}\sum_{i=1}^{N}
\Bigg[
\underbrace{-\log\frac{e^{\ell_{ii}}}{\sum_{j} e^{\ell_{ij}}}}_{\text{이미지}\to\text{텍스트}}
\;+\;
\underbrace{-\log\frac{e^{\ell_{ii}}}{\sum_{j} e^{\ell_{ji}}}}_{\text{텍스트}\to\text{이미지}}
\Bigg]
$$

Key point: **Softmax is applied to the entire mini-batch.** In other words, for a single image, it is a $N$ multiple-choice classification problem of "selecting the correct answer from all texts in the batch."

## SigLIP (Google DeepMind, 2021)

CLIP's softmax requires **normalization of the entire batch**, resulting in high memory/communication costs. SigLIP replaces this with **sigmoid (binary classification) independent of each pair**.

$y_{ij} = +1$ (correct pair, $i=j$) / $-1$ (incorrect pair), for scale $t$, bias $b$:

$$
\mathcal{L}_{\text{SigLIP}}
= -\frac{1}{N}\sum_{i=1}^{N}\sum_{j=1}^{N}
\log \sigma\!\big(y_{ij}\,(t\, I_i^\top T_j + b)\big),
\qquad \sigma(u)=\frac{1}{1+e^{-u}}
$$

Since each pair is an **independent binary decision**, batch-wide normalization is not required → Increased parallelization and memory efficiency, easy to scale to large batches.

### Comparison Table

| Features | CLIP | SigLIP | SigLIP 2 |
|---|---|---|---|
| Loss Function | Softmax-based Contrast Loss | Sigmoid (paired) | LocCa (Local Captioning) Added |
| Loss calculation unit | Compare **all pairs** in batch | **each pair** independent | each pair independent |
| task | Image–Text matching | Image–Text matching | Captioning, Distillation |
| Memory | High | Low | Low |
| Accuracy | Good | Improved over CLIP | Improved over SigLIP across multiple tasks |

::: {.callout-note}
## CLIP + Diffusion Model = Bridge to Generation
By mapping a random vector to a CLIP embedding and using that embedding as a condition for a **diffusion model**, images/videos can be generated from text. DALL·E 3, Make-A-Video, Phenaki, Sora, and Runway Gen-4.5 are multimodal generation models of this family.
:::

::: {.callout-tip}
## Wireless Communication Perspective — Contrast Learning = Detection Theory
CLIP's softmax-over-batch is equivalent to **Maximum-Likelihood detection (ML detection) in a codebook**. It selects the codeword (correct text) most correlated with the received signal (image embedding) from $N$ candidates — this is precisely the **matched-filter bank + argmax**.

SigLIP's sigmoid-per-pair is an **individual binary hypothesis test (energy/correlation detection)** for each pair. That is,
- **CLIP** = Combined ML Detection (Global normalization required, optimal but expensive)
- **SigLIP** = Pairwise Independent Detection (Separable, Excellent Scalability)

The inner product $I_i^\top T_j$ is the **correlation**, and $\tau$/temperature is the same as the SNR scale that controls the **sharpness of the detection threshold**.
:::

# Generative Model Overview & Autoencoder Review {#sec-ae}

## Autoencoder(Autoencoder, AE)

AE Goal: Feed input $x$ into the model to **reconstruct** itself.

```{mermaid}
flowchart LR
    x[입력 x] --> E[Encoder] --> z[잠재 z<br/>저차원] --> D[Decoder] --> xh[복원 x̂]
```

::: {.callout-warning}
## The trap of "Can't you just copy it?"
If we output the input exactly as is, it is a perfect solution with zero reconstruction error. So why bother using an encoder-decoder?

**Answer: This is because the dimension of the latent representation $z$ is smaller than the input.** (For example, Input 7 dimensions → Latent 4 dimensions.) Reconstruction is possible only by passing information through a narrow channel, **discarding noise and retaining only the core information**. This forced narrow channel is precisely the **information bottleneck**.
:::

- **Encoder**: Extract key information from input (compress).
- **Decoder**: Reconstruct input from core information.
- By stacking more deeply (deep AE), more sophisticated information can be compressed/restored step by step.

::: {.callout-tip}
## Wireless Communication Perspective — Information Bottleneck = Rate–Distortion
The information bottleneck is **lossy source coding** itself. Latent dimension = **bit rate $R$**, restoration error = **distortion $D$**. AE solves the rate-distortion optimization problem using neural networks to minimize distortion within a given rate budget. The fewer the "knobs" called latent dimensions, the more precisely the latent space can be controlled.
:::

## Why AE Matters Now: LeCun's Cake Analogy

Yann LeCun (Meta FAIR, NYU) likened the **amount of information** a machine receives during learning to a cake.

```{mermaid}
flowchart TB
    cherry["🍒 체리 (꼭대기)<br/>= 강화학습 (RL)<br/>아주 적은 정보"] --> icing
    icing["🎂 아이싱<br/>= 지도학습 (Supervised)<br/>피상적 정보"] --> bread
    bread["🍰 빵 (본체, 대부분)<br/>= 자기지도학습 (Self-supervised)<br/>대부분의 정보"]
```

| Learning method | Cake region | Signal quantity/quality | Reason |
|---|---|---|---|
| **Reinforcement Learning (RL)** | Cherry | Very weak, stochastic | Rewards are given **in the future, sporadically**. The reward at the current time must be predicted as an expectation, and the variance is large |
| **Supervised Learning** | Icing | Sparse | The label "This image = cake" **does not tell you anything about color, background, shape, etc.** |
| **Self-supervised Learning (SSL)** | Bread (Main Body) | Richest | To reconstruct the entire input, **all details** must be learned. Labels are also unnecessary |

::: {.callout-note}
Reasons why SSL is powerful: (1) extracts almost all information from the data, (2) no human labeling required → easy data acquisition. **The only difficulty is "designing a good pretext task (self-supervised task)". AE's "input restoration" is the most basic pretext task.
:::

::: {.callout-tip}
## Wireless Communication Perspective — Weak Compensation = Low SNR Feedback
The fact that the reward signal in RL is "weak and stochastic" is equivalent to a **feedback channel arriving sporadically with a very low SNR**. Since the estimated variance is large, learning is slow and unstable. On the other hand, since the entire input is the correct answer in SSL, it is a **high-SNR full-feedback** situation.
:::

# VAE (Variational Auto-Encoder) {#sec-vae}

> Today's main. VAE is applying an **additional constraint** to AE that "the latent space must follow a Gaussian distribution."

## One-line summary

VAE = **AE + "Normalization that forces the latent representation $z$ to follow $\mathcal N(0,I)$"**. This allows for complete control of the latent space (→ smooth generation and interpolation), and learns $p(x)$, which cannot be directly computed, by bypassing it through **variational inference**.

## Goal as a Generative Model

Given the data $X=\{x_1,\dots,x_n\}$, we want to find the distribution $p(X)$ that explains it. However, it is difficult to model $p(X)$ directly. Therefore, we **introduce a latent variable $z$.**

$$
p(x) = \sum_{z} p(x\mid z)\,p(z)
\quad\xrightarrow{\text{연속}}\quad
p(x) = \int p(x\mid z)\,p(z)\,dz
$$

Here, the **prior distribution** is fixed to $p(z)=\mathcal N(0,I)$. Interpretation: "First, we draw $z$ from the Gaussian ($z\sim p(z)$), and from that, we generate $x$ ($x\sim p(x\mid z)$)."

### Why Gaussian latent, of all things?

1. **Analytically tractable.** For Gaussians, differentiation, integration, and sampling are all well-defined, and KL and others also appear in a closed form.
2. **Sampling is easy.** Almost all hardware/libraries have a Gaussian sampler.
3. **It is sufficiently expressive.** Many natural phenomena follow a Gaussian distribution (Central Limit Theorem). Therefore, it is not unreasonable to assume that the latent space is Gaussian, and natural phenomena can be modeled in a controlled manner.

## Integration is difficult to handle (intractability)

Problem: In $p(x)=\int p(x\mid z)p(z)\,dz$, $p(x\mid z)$ is a **decoder (non-linear neural network**), so the integral does not come out in a closed form.

::: {.callout-note}
## When you encounter "difficult integration" — Two branches
**(a) Monte Carlo Sampling.** Integration = "Calculating Area". The area of a strangely shaped region is approximated by the proportion of arrows thrown infinitely into a rectangle that land within the region (Dart Game). That is, $\int f \approx \frac{1}{M}\sum_m f(z_m)$. 
**Problem:** The latent space of images/audio/text is **too high-dimensional** to approximate an integral using samples (Curse of Dimensionality).

**(b) Variational Inference.** A more sample-efficient alternative. → The path chosen by VAE.
:::

## Variational Inference and ELBO Derivation

### Key Identity

For any distribution $q(z)$ (using $\int q(z)dz=1$), using Bayes' theorem $p(x)=\frac{p(x,z)}{p(z\mid x)}$:

$$
\begin{aligned}
\log p(x) &= \log p(x)\cdot 1 = \log p(x)\int q(z)\,dz = \int q(z)\log p(x)\,dz\\
&= \int q(z)\log \frac{p(x,z)}{p(z\mid x)}\,dz \qquad (\because \text{Bayes})\\
&= \int q(z)\big(\log p(x,z) - \log p(z\mid x)\big)\,dz\\
&= \mathbb{E}_{z\sim q}\big[\log p(x,z) - \log p(z\mid x)\big]
\end{aligned}
$$

### Introduction of variational family → ELBO + KL

Now, let $q$ be parameterized to $q_\phi(z)$ (this is the **encoder**, the inference network). If we insert $\frac{q_\phi(z)}{q_\phi(z)}=1$ and expand it:

$$
\begin{aligned}
\log p(x)
&= \int q_\phi(z)\log\frac{p(x,z)}{p(z\mid x)}\,dz
= \int q_\phi(z)\log\!\left[\frac{p(x,z)}{q_\phi(z)}\cdot\frac{q_\phi(z)}{p(z\mid x)}\right]dz\\
&= \underbrace{\mathbb{E}_{q}\big[\log p(x,z) - \log q_\phi(z)\big]}_{\textbf{ELBO}\;(\text{Evidence Lower BOund})}
\;+\;
\underbrace{\mathrm{KL}\!\big[\,q_\phi(z)\,\|\,p(z\mid x)\,\big]}_{\ge\,0}
\end{aligned}
$$

::: {.callout-important}
## Why is this decomposition decisive?
- $\log p(x)$ is a **constant** (a real value we cannot touch, "evidence") for $\phi$.
- KL is **always $\ge 0$** (non-negativeness of KL). Therefore $\log p(x) \ge \text{ELBO}$ → "Evidence **Lower** Bound".
- What we really want to reduce is $\mathrm{KL}[q_\phi(z)\|p(z\mid x)]$ (the distance between my approximate posterior distribution and the true posterior distribution), but **since we do not know the true posterior distribution $p(z\mid x)$, we cannot directly reduce KL.**
- Since the left side is a constant instead of , **maximizing ELBO = minimizing KL.** ELBO is computable. → **Let's maximize ELBO!**
:::

### ELBO Expansion → Restoration Term + Normalization Term

Substitute $p(x,z)=p(x\mid z)p(z)$:

$$
\begin{aligned}
\text{ELBO}
&= \mathbb{E}_{q}\big[\log p(x,z) - \log q_\phi(z)\big]
= \mathbb{E}_{q}\big[\log p(x\mid z) + \log p(z) - \log q_\phi(z)\big]\\
&= \mathbb{E}_{q}\big[\log p(x\mid z)\big] + \mathbb{E}_{q}\big[\log p(z) - \log q_\phi(z)\big]\\
&= \mathbb{E}_{q}\big[\log p(x\mid z)\big] - \mathbb{E}_{q}\big[\log q_\phi(z) - \log p(z)\big]\\
&= \underbrace{\mathbb{E}_{q}\big[\log p(x\mid z)\big]}_{\textbf{복원(Reconstruction)}}
\;-\;
\underbrace{\mathrm{KL}\!\big(q_\phi(z)\,\|\,p(z)\big)}_{\textbf{정규화(Regularization)}}
\end{aligned}
$$

| Term | Meaning | Role |
|---|---|---|
| **Recovered Term** $\mathbb{E}_q[\log p(x\mid z)]$ | How well $x$ is recovered from $z$ (Decoder Quality) | Data Fidelity |
| **Normalization Term** $\mathrm{KL}(q_\phi(z)\|p(z))$ | How well the latent $z$ follows the prior $\mathcal N(0,I)$ | Latent Space Control |

ELBO maximization balances these two: "$z$Z well reconstructs $x$, while the distribution of $z$ is close to $\mathcal N(0,I)$."

## VAE Loss Function and Reparameterization Trick

Since ELBO is the **maximization** target, the sign is flipped to write it as **loss (minimization)**. (Decoder $p_\theta(x\mid z)$, Encoder $q_\phi(z\mid x)$)

$$
\boxed{\;
\mathcal{L}_{\text{VAE}}(\theta,\phi)
= \underbrace{-\,\mathbb{E}_{q_\phi}\!\big[\log p_\theta(x\mid z)\big]}_{\approx\ \text{MSE/CE 복원 손실}}
\;+\;
\underbrace{\mathrm{KL}\!\big(q_\phi(z\mid x)\,\|\,p(z)\big)}_{\text{닫힌 형태 (가우시안)}}
\;}
$$

::: {.callout-note}
## Notation Caution (Precision)
- This note follows **standard (Kingma & Welling) notation**: The parameters of the encoder/inference network $q_\phi$ are set to $\phi$, and the parameters of the decoder/generation network $p_\theta$ are set to $\theta$.
- Some data may have $\theta$ for the encoder and $\phi$ for the decoder (notation with reversed roles), so you must read it based on which network it refers to to avoid confusion. **What is important is not the symbol, but the distinction between the roles of "inference network vs. generative network"**.
:::

Since the restoration term is defined as the difference between $x$ and $\hat x$, it becomes either **MSE loss** (Gaussian likelihood) or **cross-entropy** (Bernoulli likelihood) depending on the assumption. The KL term falls into a **closed form** as it is between the two Gaussians (equation in the appendix below).

### Problem: Sampling is not differentiable

To train , backpropagation must be done to $\hat x \to z \to x$, but $z\sim q_\phi(z\mid x)$ is **stochastic sampling**, so the gradient cannot pass through.

### Solution: Reparameterization trick

The probability is subtracted as **exogenous noise on the input side $\epsilon$**.

$$
\boxed{\;z = \mu_\phi(x) + \sigma_\phi(x)\odot \epsilon,\qquad \epsilon\sim\mathcal N(0,I)\;}
$$

Now $z$ is a **deterministic function** of $\mu_\phi,\sigma_\phi$ (neural network output) + fixed noise. The mean $\mu$ becomes a differentiable expression that depends on the encoder, and the variance $\sigma$ also depends on the encoder, so we can randomize only $\epsilon$ and **backpropagate normally to $\phi,\theta$**.

```{mermaid}
flowchart LR
    x[x] --> E[Encoder q_φ]
    E --> mu[μ_φ x]
    E --> sig[σ_φ x]
    eps["ε ~ N0,I"] --> z
    mu --> z["z = μ + σ⊙ε"]
    sig --> z
    z --> D[Decoder p_θ] --> xh[x̂]
    xh -. L_MSE .-> x
    z -. L_KL .-> prior["N0,I"]
```

## VAE Results and Advantages

- Generates **less blurry** samples than AE.
- **The latent space is controllable**. If it is a 10-dimensional Gaussian latent, each dimension can correspond to a semantic. For example, **disentangled generation and interpolation** is possible, such as sweeping dimension 1 as $-\infty\to+\infty$ to change from female to male, or sweeping dimension 2 to change the hairstyle.
- The latent space is analyzable, allowing for the diagnosis of the learning process, such as **what additional data is needed** (in contrast to the opaque latent space of AE).

::: {.callout-tip}
## Wireless Communication Perspective — Three Mappings of VAE
1. **Reparameterization trick = AWGN model.** $z=\mu+\sigma\epsilon$ is exactly a **signal + Gaussian noise** model. It is the sum of scaled white noise ($\sigma\epsilon$) and the deterministic signal component ($\mu$). It is isomorphic to $y = s + n,\ n\sim\mathcal N(0,\sigma^2)$, which is commonly used in radio. Thanks to this, it is possible to capture the "pathwise derivative" of the expected value.
2. **Gaussian latent prior = Gaussian input codebook.** In the same context as the input distribution being Gaussian for achieving the capacity of an AWGN channel — Gaussian is the natural choice for "maximum entropy/optimal representation".
3. **ELBO = Lower bound of unmanageable likelihood.** The strategy of optimizing by **replacing the marginal likelihood that cannot be directly calculated with a computable lower bound** is based on the same idea as solving the unmanageable likelihood in detection/estimation using the **variable lower bound·EM**. KL regularization acts as a **power constraint** that "limits the power (variance) of the latent to $\mathcal N(0,I)$".
:::

# GAN (Generative Adversarial Network) {#sec-gan}

> Goodfellow et al., NeurIPS 2014. Borrows the structure of VAE, but uses **adversarial loss** instead of MSE.

## Synchronization: Beyond the blur of MSE

MSE reconstruction in VAE/AE tends to produce **blurry** results by selecting average, safe pixel values. GANs add **adversarial loss** to create **sharp** images with preserved detail.

## Composition: Generator G and Discriminator D

```{mermaid}
flowchart LR
    z["랜덤 벡터 z ~ p(z)"] --> G[Generator G]
    G --> fake["가짜 이미지 G(z)"]
    real["진짜 이미지 x"] --> D
    fake --> D[Discriminator D]
    D --> out["Real or Fake?<br/>D(·) ∈ (0,1)"]
```

- **Generator $G(z)$**: Random vector $z$ → Image. (Good $G$ = Generated image looks real)
- **Discriminator $D(x)$**: Image → "Probability of being real". (Good $D$ = good at distinguishing between real and fake)
- **Learning through competition**: G tries to deceive D, and D tries not to be deceived. They attack each other hostilely and become stronger together.

## Minimax Officialization

$$
\boxed{\;
\min_{G}\max_{D}\;
\mathbb{E}_{x\sim q_{\text{data}}(x)}\big[\log D(x)\big]
\;+\;
\mathbb{E}_{z\sim p(z)}\big[\log\big(1 - D(G(z))\big)\big]
\;}
$$

Physical meaning: $\log(\text{$x$가 진짜일 확률}) + \log(1-\text{$G(z)$가 진짜일 확률})$.

- As this value **increases, $D$ is better** → **Maximize** for $D$.
- As this value **becomes smaller, $G$ is better** (deceives D well) → **minimize** for $G$.
- This type of problem is called a **Minimax problem**, or a **zero-sum non-cooperative game**.

::: {.callout-note}
## Advanced — Optimal Discriminator and JS Divergence
When $G$ is fixed, the optimal discriminator is
$$
D^*(x) = \frac{q_{\text{data}}(x)}{q_{\text{data}}(x) + p_g(x)}.
$$
If we substitute this, the objective function is
$$
V(G,D^*) = -\log 4 + 2\cdot \mathrm{JSD}\big(q_{\text{data}}\,\|\,p_g\big)
$$
($\mathrm{JSD}$ = Jensen–Shannon divergence). In other words, **minimizing G means aligning the generating distribution $p_g$ to the true distribution $q_{\text{data}}$ based on the JS divergence**. The global optimal is $p_g = q_{\text{data}}$, at which point it becomes $V=-\log 4$. (Numerically verified in the appendix code.)
:::

## Learning Procedure (Three-step update)

```{mermaid}
flowchart TB
    s1["① D를 진짜로 학습:<br/>진짜 데이터에 'real' 출력하도록 D 갱신"]
    s2["② D를 가짜로 학습:<br/>가짜 데이터에 'fake' 출력하도록 D 갱신"]
    s3["③ G를 학습:<br/>가짜 데이터에 D가 'real'이라 말하도록 G 갱신"]
    s1 --> s2 --> s3 --> s1
```

## Learning difficulties

GAN training is notoriously difficult.

| Problem | Symptoms |
|---|---|
| **Non-convergence** (Non-convergence) | Parameters are oscillatory/unstable and do not converge |
| **Mode collapse** (Mode collapse) | G mass-produces only similar samples (loss of diversity) |
| **Diminished Gradient** (Gradient Vanishing) | D becomes too strong, causing G's gradient to disappear and learning to stagnate |

- The **imbalance** between D and G causes the above problem. Hyperparameter selection is a "work of art".
- Stabilized variants: **LSGAN, WGAN, WGAN-GP, BEGAN** etc.
- **Diffusion Models** Emerge as a Fundamental Alternative: Learning is slow, but **stable** and of excellent quality.

## Why GANs Are Effective: Hard Negative

D constantly provides G with **hard negatives**. By creating "almost real fakes" near the decision boundary to pressure G, it becomes a much stronger learning signal than simple MSE.

::: {.callout-warning}
## Adversarial Example ≠ Adversarial Learning
Caution: Confusion. **Adversarial examples** are created by applying small perturbations to the input to cause a neural network to produce an unexpected output.

- Example: Adding fine patterns to stop signs causes autonomous driving AI to mistake them for "slow down" → Danger.
- Example: If you insert a texture invisible to the human eye into a cat image, the CNN asserts with high probability that it is a "desktop computer."

This is evidence that **neural networks are extremely sensitive (vulnerable) to small changes in input**. The "adversarial" of GANs shares only the word with this *phenomenon*, but holds a different philosophy that **two networks compete**.
:::

::: {.callout-tip}
## Wireless Communication Perspective — GAN = Jamming Game, Adversarial Example = Precision Interference
- **Minimax = A zero-sum game between a jammer and a transceiver.** D (the receiver) attempts to distinguish (detect) real/fake signals, and G (the jammer) synthesizes signals to evade detection. Nash equilibrium is equivalent to the saddle point of a worst-case robust design.
- **Adversarial example = low-power interference aligned to the decision boundary.** Misculating the detector with very small perturbations ($\|\delta\|$ small) is equivalent to a **minimum power disturbance signal** aligned to the decision boundary normal direction. The sensitivity of a neural network is equivalent to the **ill-conditioning** of the classifier — minute changes in the input are amplified in the output.
- **Hard negative = High-difficulty sample near the boundary.** Like the "test signal near the threshold SNR" in detection theory, it provides the most informative learning signal.
:::

## Closed form of Gaussian KL (VAE normalization term) {#sec-app-kl}

When $q=\mathcal N(\mu,\sigma^2)$, $p=\mathcal N(0,1)$,
$$
\mathrm{KL}(q\|p) = \frac{1}{2}\sum_{j}\big(\mu_j^2 + \sigma_j^2 - \log\sigma_j^2 - 1\big).
$$

```{python}
#| label: kl-closed-form
#| code-fold: false
import numpy as np
rng = np.random.default_rng(0)

def gaussian_kl_closed(mu, var):
    # KL( N(mu, var) || N(0, I) ), per-dimension diagonal Gaussian
    return 0.5 * np.sum(mu**2 + var - np.log(var) - 1)

# Monte Carlo 검증
mu, sig = 0.7, 1.3
closed = gaussian_kl_closed(np.array([mu]), np.array([sig**2]))
z = rng.normal(mu, sig, size=2_000_000)
logq = -0.5*np.log(2*np.pi*sig**2) - (z-mu)**2/(2*sig**2)
logp = -0.5*np.log(2*np.pi)        - z**2/2
mc = np.mean(logq - logp)
print(f"KL closed-form = {closed:.5f}   Monte Carlo = {mc:.5f}")
```

## Reparameterization trick + VAE loss (forward) {#sec-app-vae}

```{python}
#| label: vae-loss
#| code-fold: false
def reparameterize(mu, logvar, eps=None):
    # z = mu + sigma * eps,  sigma = exp(0.5*logvar)
    std = np.exp(0.5*logvar)
    if eps is None:
        eps = rng.normal(size=mu.shape)
    return mu + std*eps                       # AWGN 모델: 신호 mu + 잡음 std*eps

def vae_loss(x, x_hat, mu, logvar):
    recon = np.mean(np.sum((x - x_hat)**2, axis=1))      # MSE 복원항
    kl    = np.mean(0.5*np.sum(np.exp(logvar) + mu**2 - 1 - logvar, axis=1))
    return recon + kl, recon, kl

# 더미 예시 (배치 4, 잠재 3, 입력 5)
mu     = rng.normal(size=(4,3))
logvar = rng.normal(size=(4,3))*0.1
z      = reparameterize(mu, logvar)
x      = rng.normal(size=(4,5))
x_hat  = rng.normal(size=(4,5))               # 실제로는 decoder(z)
total, recon, kl = vae_loss(x, x_hat, mu, logvar)
print(f"z.shape={z.shape}  total={total:.4f}  recon={recon:.4f}  kl={kl:.4f}")
```

## CLIP Symmetric Contrast Loss {#sec-app-clip}

```{python}
#| label: clip-loss
#| code-fold: false
def clip_loss(I, T, tau=1.0):
    I = I/np.linalg.norm(I, axis=1, keepdims=True)
    T = T/np.linalg.norm(T, axis=1, keepdims=True)
    logits = I @ T.T / tau                    # 상관(correlation) 행렬, 대각이 정답
    N = len(I)
    def ce_rows(L):
        L = L - L.max(1, keepdims=True)
        logp = L - np.log(np.exp(L).sum(1, keepdims=True))
        return -logp[np.arange(N), np.arange(N)].mean()
    return 0.5*(ce_rows(logits) + ce_rows(logits.T))   # 이미지→텍스트 + 텍스트→이미지

N, d = 8, 16
base = rng.normal(size=(N, d))
aligned = clip_loss(base, base + 0.01*rng.normal(size=(N, d)))
random_ = clip_loss(rng.normal(size=(N, d)), rng.normal(size=(N, d)))
print(f"정렬된 쌍 loss = {aligned:.4f}   무작위 쌍 loss = {random_:.4f}   (log N = {np.log(N):.4f})")
```

## SigLIP Sigmoid Loss {#sec-app-siglip}

```{python}
#| label: siglip-loss
#| code-fold: false
def sigmoid(u): return 1/(1+np.exp(-u))

def siglip_loss(I, T, t=10.0, b=-10.0):
    I = I/np.linalg.norm(I, axis=1, keepdims=True)
    T = T/np.linalg.norm(T, axis=1, keepdims=True)
    S = I @ T.T                                # 상관 행렬
    N = len(I)
    Y = -np.ones((N, N)); np.fill_diagonal(Y, 1.0)   # 대각=+1(정답), 나머지=-1
    logits = Y*(t*S + b)
    return -np.mean(np.log(sigmoid(logits) + 1e-12)) # 쌍별 독립 이진 결정

print(f"SigLIP loss = {siglip_loss(base, base):.4f} (완전 정렬)")
```
