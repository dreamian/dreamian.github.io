1 View at a glance

This note covers four key variations of the diffusion model.

Model One-line summary Key contributions Sources
DDPM Prototype of the Diffusion Model Gradually add noise (\(q\)) and return to the neural network (\(p_\theta\)) Ho et al., NeurIPS 2020
DDIM Generation Acceleration Version of DDPM Significantly Reduced Sampling Steps via Non-Markov + Deterministic Paths Song et al., ICLR 2021

Notemain stem

DDPM → DDIM is a series that samples the same model faster (philosophy A: efficiency), and LDM is a series that changes where to run the diffusion (philosophy B: latent space). ControlNet adds commercially important control to this.

2 Recap: Diffusion Model vs. GAN

One-line answer: GANs are fast but unstable (mode collapse), while diffusion models are slow but stable (MLE-based) and of excellent quality.

Diffusion Model (DDPM) GAN
Pros Sharpness and high quality, Well-understood optimization called MLE, for both image and audio Relatively fast training, various loss functions (Wasserstein, Hinge), requires less data
Disadvantages Slow and computationally intensive, requires a lot of data High training difficulty, hyperparameter sensitive, mode collapse
TipWhy Diffusion Instead of Hard-Negative in GANs?

GANs are adversarial games that pressure the discriminator by generating “hard negatives” near the decision boundary. On the other hand, diffusion models do not involve zero-sum games because they gradually build a probability tower at each position. Therefore, learning converges slowly but stably.

Diffusion models are broadly classified into three series based on their generation mechanisms (Review paper The Principles of Diffusion Models, arXiv 2025):

The three perspectives view the same goal of “gradually transforming a complete noise matrix into a clean image” through different mathematics, and this extends to continuous-time versions (SDE/ODE).

3 DDPM Details

DDPM consists of two processes.

  • Forward Spread (forward, fixed): Gradually adds noise to the input — no learning parameters.
  • Reverse noise removal (reverse, generation): Creates data by removing noise — Trained with a neural network.

3.1 Forward process (forward)

One-line answer: It is a Markov chain that adds Gaussian noise following a predefined distributed schedule \(\beta_t\).

Organize the notation.

  • \(\beta_t \in (0,1)\) : Noise magnitude at time \(t\) (pre-scheduled).
  • \(\alpha_t = 1-\beta_t\) : Signal retention rate of one step.
  • \(\bar\alpha_t = \prod_{s=1}^{t}(1-\beta_s) = \prod_{s=1}^{t}\alpha_s\) : Preserve accumulated signal up to time \(t\).

The one-step transition and its closed-form marginal distribution are as follows.

\[ q(x_t \mid x_{t-1}) = \mathcal{N}\!\big(x_t;\, \sqrt{\alpha_t}\,x_{t-1},\, \beta_t \mathbf{I}\big), \qquad \boxed{\;x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon,\quad \epsilon \sim \mathcal{N}(\mathbf{0},\mathbf{I})\;} \tag{1}\]

NoteWhy multiply \(\sqrt{\bar\alpha_t}\) in front of the signal — variance preservation

Since the overall signal magnitude should not increase as noise is added, the original signal is reduced by \(\sqrt{\bar\alpha_t}\) and noise is added by \(\sqrt{1-\bar\alpha_t}\) to keep \(\operatorname{Var}(x_t)\) equal to \(\operatorname{Var}(x_0)\). The fact that the sum of the squares of the two coefficients is \(\bar\alpha_t + (1-\bar\alpha_t)=1\) serves as proof of this (so-called variance-preserving). It is very convenient during training because it allows a direct jump to an arbitrary \(t\) (Food 1).

3.2 Continuous-time limit: SDE

\(\delta t \to 0\) When taking the limit, the forward process is written as a stochastic differential equation (SDE).

\[ dx = -\tfrac{1}{2}\beta(t)\,x\,dt + \sqrt{\beta(t)}\;dW_t \tag{2}\]

Here, \(W_t\) is the Wiener process, which models a Gaussian random sample at each time step. The drift term \(-\tfrac12\beta(t)x\) shrinks the signal to zero, and the diffusion term \(\sqrt{\beta(t)}\,dW_t\) injects noise. (Refer to the review paper for the derivation — this note uses only the result.)

TipWireless Communication Analogy — Forward Process = “Progressive Fading Channel”

\(x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon\) is exactly the same form as the channel model with AWGN added to a signal attenuated by the time-varying fading coefficient \(\sqrt{\bar\alpha_t}\). \(\bar\alpha_t\) is the channel gain that decreases monotonically over time, and \(1-\bar\alpha_t\) is the accumulated noise power. Variance-preserving is equivalent to AGC (Automatic Gain Control) that keeps the total power of the received signal constant. When the SNR drops to 0 at \(t\to T\), the received signal becomes pure noise \(x_T \sim \mathcal{N}(\mathbf{0},\mathbf{I})\).

3.3 Reverse process (reverse)

One-line answer: The true inverse process \(q(x_{t-1}\mid x_t)\) is unknown, but since \(\beta_t \ll 1\) is approximated as Gaussian, the average is learned using a neural network.

If you try to use inversion with Bayes’ rule

\[ q(x_{t-1}\mid x_t) = \frac{q(x_t \mid x_{t-1})\,q(x_{t-1})}{q(x_t)} \tag{3}\]

, but the marginal distribution \(q(x_{t-1}),\,q(x_t)\) on the right side is unknown for the entire data distribution (bad news). The good news is that if \(\beta_t\) is sufficiently small, the true posterior \(q(x_{t-1}\mid x_t)\) is also well approximated by a Gaussian. Therefore, we set it as a parameterized Gaussian as follows.

\[ p_\theta(x_{t-1}\mid x_t) = \mathcal{N}\!\big(x_{t-1};\, \mu_\theta(x_t,t),\, \sigma_t^2 \mathbf{I}\big) \tag{4}\]

ImportantStructure of cascaded approximation
  1. True inverse process \(q(x_{t-1}\mid x_t)\) → (β small) → Approximately as Gaussian
  2. The mean of that Gaussian \(\mu_\theta\) → Approximated by a neural network

The Gaussian is completely determined by knowing only the sufficient statistics of mean and variance. Since the variance \(\sigma_t^2\) is automatically determined by the schedule \(\beta_t\), the target of training is effectively just the mean \(\mu_\theta\).

3.4 \(\mu_\theta\) Learning: Noise Reparameterization

The posterior mean of the forward process is represented by \(x_0\) and noise \(\epsilon\). If we solve Food 1 for \(x_0\) and substitute, the mean takes the following neat form.

\[ \mu_\theta(x_t,t) = \frac{1}{\sqrt{\alpha_t}}\left(x_t - \frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\,\epsilon_\theta(x_t,t)\right) \tag{5}\]

In other words, instead of directly predicting the mean, we just need to train a neural network \(\epsilon\) that predicts the injected noise \(\epsilon_\theta(x_t,t)\). The core idea is:

  1. Select one time point \(t\) and sample the correct noise \(\epsilon \sim \mathcal{N}(\mathbf{0},\mathbf{I})\).
  2. Noise image generated with \(x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon\).
  3. Slope descent to \(\nabla_\theta \lVert \epsilon - \epsilon_\theta(x_t,t)\rVert^2\).
NoteWhy Noise Prediction — Backward Process Average = Forward Process Average

To make the inverse process the exact inverse of the forward process, the averages of the two processes must be equal: \(\mu_\theta^{\text{(rev)}}(x_t,t) = \tilde\mu^{\text{(fwd)}}(x_t,t)\). In the forward process, we know \(x_0,\epsilon\), so we can calculate this average accurately; in the inverse process, since we do not know it, we approximate it as \(\epsilon_\theta\). Since the average is a function of \(\epsilon\) (Food 5), average fitting = noise fitting.

3.5 Loss function

\[ \mathcal{L}_{\text{DDPM}} = \mathbb{E}_{t,\,x_0,\,\epsilon}\Big[\big\lVert \epsilon - \epsilon_\theta(x_t,t)\big\rVert^2\Big], \qquad x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon \tag{6}\]

It starts from the original variational lower bound (ELBO), but after reparameterization, it is reduced to the simple noise regression (MSE) as shown above. Unlike the zero-sum game of GANs, the loss value decreases monotonically and converges stably.

3.6 Learning/Sampling Algorithm

Training

  1. Data \(x_0 \sim q(x_0)\).
  2. \(t \sim \text{Uniform}\{1,\dots,T\}\) (Learnable at any time — thanks to Food 1).
  3. \(\epsilon \sim \mathcal{N}(\mathbf{0},\mathbf{I})\).
  4. Update to \(x_t = \sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon\), \(\;\nabla_\theta\lVert\epsilon-\epsilon_\theta(x_t,t)\rVert^2\), repeat until convergence.

Sampling (Sampling / Generation)

Starting from \(x_T \sim \mathcal{N}(\mathbf{0},\mathbf{I})\), about \(t=T,\dots,1\):

\[ \hat{x}_0 = \frac{1}{\sqrt{\bar\alpha_t}}\big(x_t - \sqrt{1-\bar\alpha_t}\,\epsilon_\theta(x_t,t)\big), \]

\[ \mu_\theta(x_t,\hat{x}_0) = \frac{\sqrt{\bar\alpha_{t-1}}\,\beta_t}{1-\bar\alpha_t}\,\hat{x}_0 + \frac{\sqrt{\alpha_t}\,(1-\bar\alpha_{t-1})}{1-\bar\alpha_t}\,x_t, \qquad x_{t-1} = \mu_\theta(x_t,\hat{x}_0) + \sigma_t\,z,\;\; z\sim\mathcal{N}(\mathbf{0},\mathbf{I}). \]

WarningInherent limitation of DDPM — cannot control \(\sigma_t\)

In DDPM, \(\sigma_t\) (usually \(\sigma_t^2 = \tilde\beta_t = \tfrac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t}\beta_t\)) is automatically calculated from schedule \(\beta_t\) and cannot be touched by the user. Since it is stochastic sampling that draws a new \(z\) at every step, the path cannot be controlled, and the entire inverse-SDE must run tens of thousands of steps to generate a single sample — this is the source of slowness.

3.7 Evaluation Metrics: FID

One-line answer: FID (Fréchet Inception Distance) measures the distance between the generated distribution and the actual distribution on the latent representation of an Inception neural network, and lower is better.

Images are passed through a pre-trained Inception network (Google’s GoogLeNet/Inception family) to obtain semantic latent vectors, and the difference in mean and covariance (assuming Gaussian distribution) between the set of real images and the set of generated images is measured. The closer the two distributions are (=the more the product looks “like a natural image”), the smaller the FID. Although it is an old network that is over five years old, it is still widely used as a standard comparison metric.

Method (CIFAR-10) FID ↓
Conditional GAN 14.73
StyleGAN2 + Auxiliary Techniques 2.67 (accompanied by difficulty in avoiding mode collapse)
DDPM 3.17 (Reached stably without game theory)

DDPM is simple and stable to train, yet demonstrates quality comparable to top-tier GANs. However, the inefficiency of generation speed remains a major weakness — DDIM addresses this.

4 DDIM: Deterministic Accelerated Sampling

4.1 Synchronous

One-line answer: DDIM reuses the same training results as DDPM, but reinterprets the forward process as non-Markov to enable deterministic, small-step sampling.

DDPM’s Weakness:

  • Slow sampling (tens of thousands of steps).
  • Stochastic path → Difficult to control · Inefficiency.
  • Full inverse-SDE required for every sample.

The goal of DDIM is “Fewer steps + Deterministic path + Marginal distribution identical to DDPM”. Key idea:

  1. Interpret the forward process as a non-Markov, deterministic event.
  2. Deriving the inverse process based on ODE (DDPM is SDE).
  3. Realization of non-probabilistic and efficient sampling.

4.2 Non-Markov forward process

DDPM assumes that \(q(x_{t-1}\mid x_t)\) depends only on \(x_t\) (Markov assumption). DDIM additionally conditions this with \(x_0\) information.

\[ q(x_{1:T}\mid x_0) = q(x_T\mid x_0)\prod_{t=2}^{T} q(x_{t-1}\mid x_t, x_0) \tag{7}\]

Each inversion is by Bayes’ rule

\[ q(x_t \mid x_{t-1}, x_0) = \frac{q(x_{t-1}\mid x_t, x_0)\,q(x_t\mid x_0)}{q(x_{t-1}\mid x_0)} \tag{8}\]

is derived from ||| and is non-Markov because \(x_t\) depends on both \(x_{t-1}\)Z and \(x_0\).

Tip\(x_0\) Why does the information reduce the number of steps?

The Markov assumption is the constraint that “only the immediate state is known.” Since DDIM utilizes additional information about the destination \(x_0\) during training, it can reach the same quality with fewer iterations. By analogy, it is the difference between moving one step at a time based only on the current position (DDPM) vs. knowing the destination and jumping along a straight path (DDIM).

Crucially, the marginal distribution of \(x_t\) remains identical to DDPM.

\[ q(x_t \mid x_0) = \mathcal{N}\!\big(\sqrt{\bar\alpha_t}\,x_0,\,(1-\bar\alpha_t)\mathbf{I}\big), \qquad x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon_t \tag{9}\]

Thanks to this neighborhood match, the noise predictor \(\epsilon_\theta\) trained in DDPM can be reused as is. The implementation is the same, only the mathematical interpretation differs (DDPM=SDE, DDIM=ODE).

4.3 Inverse process sampling and \(\eta\)

Following the average of the posterior \(q(x_{t-1}\mid x_t, x_0)\) yields a generalized update formula.

\[ \boxed{\;x_{t-1} = \sqrt{\bar\alpha_{t-1}}\,\hat{x}_0 + \sqrt{1-\bar\alpha_{t-1}-\sigma_t^2}\;\epsilon_\theta(x_t,t) + \sigma_t\,z,\quad z\sim\mathcal{N}(\mathbf{0},\mathbf{I})\;} \tag{10}\]

Here, the amount of probability is controlled by the hyperparameter \(\eta\).

\[ \sigma_t = \eta\,\sqrt{\frac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t}}\,\sqrt{1-\frac{\bar\alpha_t}{\bar\alpha_{t-1}}} \tag{11}\]

  • \(\eta = 0 \Rightarrow \sigma_t = 0\) : Completely deterministic(first term + second term only, noise \(z\) eliminated).
  • \(\eta = 1 \Rightarrow\) Exactly equivalent to DDPM (Markov forward reduction).
NoteVerification: When \(\eta{=}1\) \(\sigma_t^2 = \tilde\beta_t\)

If you substitute \(\beta_t = 1-\tfrac{\bar\alpha_t}{\bar\alpha_{t-1}}\) into Food 11 \[ \sigma_t^2\big|_{\eta=1} = \frac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t}\,\beta_t = \tilde\beta_t \] exactly matches the posterior variance of DDPM (the difference \(=0\) confirmed by symbolic calculation). Additionally, the forward margin Food 9 was confirmed to match the closed form via Monte Carlo (Section 9).

4.4 Loss Equality

Since the fact that the neural network predicts noise \(\epsilon_t\) remains the same even if the forward and inverse processes are swapped, the loss is the same as DDPM — for any \(\sigma_t\).

\[ \mathcal{L} = \mathbb{E}_{t,\,x_0,\,\epsilon}\big[\lVert \epsilon_t - \epsilon_\theta(x_t,t)\rVert^2\big] \tag{12}\]

That is, both DDPM and DDIM generation can be performed with \(\epsilon_\theta\), which has been trained once. You just need to leave the training code as is and add one \(\eta\) to the sampling.

4.5 DDPM vs. DDIM

Item DDPM DDIM
Forward Process Markov Non-Markov(at \(x_0\) Conditioning)
Inverse Process Formula SDE ODE
Variance \(\sigma_t\) Automatically determined by \(\beta_t\), uncontrollable Arbitrarily adjustable by \(\eta\)
\(\eta=0\) — Deterministic, prime step
\(\eta=1\) — Equivalent to DDPM
Sampling Rate Slow (e.g., 1000 steps) Fast (e.g., similar quality at 50 steps)
Training Same procedure/loss Reuse the same \(\epsilon_\theta\)
TipWireless Communication Analogy — DDIM = “Deterministic Equalizer”

The stochastic inverse process of DDPM is akin to random reconstruction, which draws a new noise realization for every symbol. DDIM reconstructs the signal using deterministic ODE integral = deterministic equalization/demodulation while maintaining the channel statistics (marginal distribution of the forward process) identically. \(\eta\) is a dial that controls the amount of residual probabilism, \(\eta=0\) corresponds to a deterministic equalizer without noise addition, and \(\eta=1\) corresponds to a simulation of the original stochastic channel. Since it is a deterministic path, it is reliably reconstructed even with a small number of large steps (subsampling), significantly reducing latency. However, large steps entail a slight loss of quality (approximation error).

WarningHonest Interpretation of Experimental Facts

In terms of FID, DDIM 50 steps may appear similar to or slightly better than DDPM 1000 steps. However, since FID is not a perfect indicator, the results of a few steps may appear somewhat inferior to the naked eye. A distinction must be made between “FID ≈ Equivalent” and “Perceptual Quality Equivalent”.

5 LDM: Potential Diffusion (Stable Diffusion)

One-line answer: Since diffusing in pixel space takes up too much memory, the image is compressed into a low-dimensional latent space and then diffusion is performed on it.

Training large-scale text-condition models directly in pixel space incurs massive computational and memory costs. LDM compresses images into low-dimensional latent representations using an autoencoder, performs the diffusion process in the latent space, and then restores them to pixel images using a decoder.

Sweet Spot of Compression Ratio: As a result of comparing quality while changing the downsampling scale,

Settings Result
LDM-1 (Almost no compression = pixel diffusion) Training time is significantly long
LDM-32 (Overcompression) Discarding too much information Quality degradation
LDM-4, 8, 16 Competitive Optimal Quality
NoteThe second advantage of LDM — Semantic control

Each dimension of the latent space captures semantics better than pixels (simple color values). Therefore, adjusting specific dimensions of the latent representation allows for better control over the meaning of generated images, such as “summer deer → winter deer.” This controllability leads to ControlNet (developed in 2023).

TipWireless Communication Analogy — LDM = “Transmit after source compression”

Pixel spatial spreading is equivalent to processing the entire original signal as is. Since LDM processes over a latent representation with redundancy removed through source coding (dimensional reduction), bandwidth and computational efficiency increase significantly. Overcompression (LDM-32) is equivalent to a situation in lossy compression where the bitrate is lowered too much, causing the restoration quality to deteriorate — it is a problem of finding the sweet spot of the rate-distortion trade-off.

6 U-Net structure

One-line answer: It is a “butterfly/hourglass” structure in which the encoder-decoder forms an information bottleneck and the useful information lost at the bottleneck is restored through skip connections between corresponding layers.

The noise predictors for LDM and ControlNet typically use U-Net (which can be implemented using CNN or Transformer). The input and output are high-dimensional, and the representation narrows towards the center.

  • Information Bottleneck: Removes unnecessary noise information through compression (same principle as an autoencoder). It takes the shape of a “butterfly” with the narrowest point in the middle, or an “hourglass” when rotated 90°.
  • Skip connection: Since bottlenecks can discard useful information along with noise, information is passed directly from the encoder layer → decoder layer of the same dimension to restore the details necessary for high-quality restoration. These paths form the shape of the letter U and are called U-Net.

It was originally proposed for medical image segmentation, but it is widely used in various fields due to its excellent information preservation capabilities.

TipWireless communication analogy — Skip connection = “Side information channel”

The bottleneck is lossy compression, and skip connection is equivalent to directly delivering details missing from compression to a separate side channel. It is a structure that achieves high-fidelity restoration by combining the main compression stream (main channel) and detail preservation (side channel).

7 ControlNet: Controllable Generation

One-line answer: It is a fractional shot editing technique that fine-tunes a pre-trained diffusion U-Net with small input-output pairs (\(<50\text{K}\)) and controls generation with condition images (sketch, edge, etc.).

Structural Idea — Process conditional images using a pre-trained noise prediction U-Net.

  • Encoder: Initialize by copying pre-trained U-Net parameters and fine-tune.
  • Decoder: Combines encoded condition information and noise image, but injects the condition (control signal) using zero convolution.

Procedure: Initially, realistic images are generated without condition information, and then condition information is gradually introduced (since the initial value of zero convolution is 0, the backbone is not damaged in the early stages of training). This idea is applicable to arbitrary image conditions.

NoteData Efficiency

The training dataset size is approximately \(100\text{K}\), which is about 50,000 times smaller than LAION-5B. Achieving strong controllability with a small number of pairs is a key value.

ImportantWhy is it commercially important?

In multimodal conditional generation, the ability to precisely control the generation when slightly changing the text prompt is critical. ControlNet offers high quality, controllability, and broad applicability simultaneously, making it highly commercially valuable (ICCV 2023 Best Paper).

TipWireless Communication Analogy — ControlNet = “Pilot/Control Channel Overlay”

It is equivalent to steering the beam/transmission by leaving the existing transmitting and receiving system (pre-trained backbone) as is and gradually adding a separate control/pilot channel (condition encoder + zero convolution). The zero initialization of the zero convolution corresponds to a strategy of gradually turning on the control channel at 0 power to adapt without disturbing the existing link.

8 Wrap-up and Next Preview

  • DDPM ↔︎ DDIM: Same series sharing the same \(\epsilon_\theta\). DDIM turns off probabilism with \(\eta\) and uses the ODE deterministic path to accelerate sampling.
  • LDM: A different philosophy that moves to latent space to gain efficiency + semantic control.
  • ControlNet: Grant commercial control to LDM.

Next Session — Data-Efficient Learning

In the objective function \(\mathcal{L} = \underbrace{\mathcal{L}_{\text{data}}}_{\text{데이터 적합}} + \underbrace{\Omega(\theta)}_{\text{정규화 = 귀납 편향}}\), the traditional approach when data is scarce is to design a better inductive bias (few-shot / zero-shot / continual). However, devising a new bias for every task is very wasteful.

NoteParadigm Shift: Inductive Bias → Foundation Model

An alternative is to pre-warm up the model with irrelevant but massive data instead of the data for the given task, and then fine-tune and generalize. A model that serves as the “starting point for good performance across multiple tasks” in this way is called a frontier model. It is expensive but offers powerful generalization — leading to the next topic (few/zero-shot, continual learning).

9 Appendix: Python/NumPy Verification

Verify the two key facts in the text with code: (1) the marginal distribution of the forward process Food 1, and (2) the variance of DDIM(\(\eta{=}1\)) matches the posterior variance of DDPM \(\tilde\beta_t\) (Food 11).

Code 
import numpy as np

np.random.seed(0)
betas  = np.linspace(1e-4, 0.02, 1000)
alphas = 1.0 - betas
abar   = np.cumprod(alphas)        # \bar\alpha_t

x0, T, N = 3.0, 500, 200_000
# 마르코프 전방을 직접 반복하여 x_T를 몬테카를로로 추정
x = np.full(N, x0, dtype=float)
for t in range(T):
    x = np.sqrt(alphas[t]) * x + np.sqrt(1 - alphas[t]) * np.random.randn(N)

print(f"MC      mean={x.mean():.4f}  var={x.var():.4f}")
print(f"closed  mean={np.sqrt(abar[T-1])*x0:.4f}  var={1-abar[T-1]:.4f}")
# closed form: x_t ~ N( sqrt(abar_t) x0, (1-abar_t) I )
Code 
import sympy as sp

abar_t, abar_tm1 = sp.symbols('abar_t abar_tm1', positive=True)
beta_t = 1 - abar_t/abar_tm1                          # \beta_t = 1 - \bar\alpha_t/\bar\alpha_{t-1}

sigma_ddim_sq = ((1-abar_tm1)/(1-abar_t)) * (1 - abar_t/abar_tm1)   # eta=1
beta_tilde    = (1-abar_tm1)/(1-abar_t) * beta_t                    # DDPM 사후 분산

print("sigma_DDIM(eta=1)^2 - beta_tilde =", sp.simplify(sigma_ddim_sq - beta_tilde))
# 0 이면 두 식이 항등적으로 동일
Code 
import numpy as np
# 신호 보존 sqrt(abar_t) 와 누적 잡음 sqrt(1-abar_t), 그리고 SNR = abar_t/(1-abar_t)
betas  = np.linspace(1e-4, 0.02, 1000)
abar   = np.cumprod(1 - betas)
for t in [0, 100, 300, 600, 999]:
    snr = abar[t] / (1 - abar[t])
    print(f"t={t:4d}  sqrt(abar)={np.sqrt(abar[t]):.3f}  "
          f"sqrt(1-abar)={np.sqrt(1-abar[t]):.3f}  SNR={snr:8.3f}")
# t가 커질수록 신호 보존↓, 잡음↑, SNR→0  (수신 신호가 순수 잡음으로 수렴)

| **DDPM** | Prototype of the Diffusion Model | Gradually add noise ($q$) and return to the neural network ($p_\theta$) | Ho et al., NeurIPS 2020 |
| **DDIM** | *Generation Acceleration* Version of DDPM | **Significantly Reduced Sampling Steps** via Non-Markov + Deterministic Paths | Song et al., ICLR 2021 |
| **LDM** | Efficient High Resolution·Multimodal | Diffusion in **Latent Space** (= Stable Diffusion) | Rombach et al., CVPR 2022 |

::: {.callout-note}
## main stem
**DDPM → DDIM** is a series that samples the same model *faster* (philosophy A: efficiency), and **LDM** is a series that changes *where* to run the diffusion (philosophy B: latent space). **ControlNet** adds *commercially important control* to this.
:::

## Recap: Diffusion Model vs. GAN {#sec-recap}

**One-line answer:** GANs are fast but unstable (mode collapse), while diffusion models are slow but stable (MLE-based) and of excellent quality.

| | Diffusion Model (DDPM) | GAN |
|---|---|---|
| **Pros** | Sharpness and high quality, **Well-understood optimization called MLE**, for both image and audio | Relatively **fast training**, various loss functions (Wasserstein, Hinge), requires less data |
| **Disadvantages** | **Slow and computationally intensive**, requires a lot of data | High training difficulty, hyperparameter sensitive, **mode collapse** |

::: {.callout-tip}
## Why Diffusion Instead of Hard-Negative in GANs?
GANs are *adversarial games* that pressure the discriminator by generating "hard negatives" near the decision boundary. On the other hand, diffusion models do not involve zero-sum games because they **gradually build a probability tower at each position**. Therefore, learning converges slowly but stably.
:::

Diffusion models are broadly classified into three series based on their generation mechanisms (Review paper *The Principles of Diffusion Models*, arXiv 2025):

```{mermaid}
flowchart TB
    A["확산 모델 (이산 노이징 ↔ 클린)"] --> B["VAE 기반 계열<br/>(DDPM 등)"]
    A --> C["에너지 기반 / 점수 기반<br/>(score-based, NCSN)"]
    A --> D["정규화 흐름 계열<br/>(normalizing flow)"]
    C -.확장.-> E["조건부 score network<br/>연속시간(SDE) 일반화"]
    D -.해석.-> F["적은 스텝으로<br/>노이즈→데이터 사상"]
```

The three perspectives view the same goal of "gradually transforming a complete noise matrix into a clean image" through different mathematics, and this extends to continuous-time versions (SDE/ODE).

## DDPM Details {#sec-ddpm}

DDPM consists of two processes.

- **Forward Spread (forward, fixed):** Gradually adds noise to the input — no learning parameters.
- **Reverse noise removal (reverse, generation):** Creates data by removing noise — **Trained with a neural network**.

```{mermaid}
flowchart LR
    x0["x₀ (데이터)"] -- "q(xₜ|xₜ₋₁) 고정" --> xt["xₜ"]
    xt -- "..." --> xT["x_T ~ N(0,I)"]
    xT -. "pθ(xₜ₋₁|xₜ) 학습" .-> xt2["xₜ₋₁"]
    xt2 -. "..." .-> x0b["x̂₀ (생성)"]
```

### Forward process (forward) {#sec-forward}

**One-line answer:** It is a Markov chain that adds Gaussian noise following a predefined distributed schedule $\beta_t$.

Organize the notation.

- $\beta_t \in (0,1)$ : **Noise magnitude** at time $t$ (pre-scheduled).
- $\alpha_t = 1-\beta_t$ : **Signal retention rate** of one step.
- $\bar\alpha_t = \prod_{s=1}^{t}(1-\beta_s) = \prod_{s=1}^{t}\alpha_s$ : **Preserve accumulated signal** up to time $t$.

The one-step transition and its closed-form marginal distribution are as follows.

$$
q(x_t \mid x_{t-1}) = \mathcal{N}\!\big(x_t;\, \sqrt{\alpha_t}\,x_{t-1},\, \beta_t \mathbf{I}\big),
\qquad
\boxed{\;x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon,\quad \epsilon \sim \mathcal{N}(\mathbf{0},\mathbf{I})\;}
$$ {#eq-forward}

::: {.callout-note}
## Why multiply $\sqrt{\bar\alpha_t}$ in front of the signal — variance preservation
Since the overall signal magnitude should not increase as noise is added, the original signal is reduced by $\sqrt{\bar\alpha_t}$ and noise is added by $\sqrt{1-\bar\alpha_t}$ to **keep $\operatorname{Var}(x_t)$ equal to $\operatorname{Var}(x_0)$**. The fact that the sum of the squares of the two coefficients is $\bar\alpha_t + (1-\bar\alpha_t)=1$ serves as proof of this (so-called variance-preserving). It is very convenient during training because it allows a direct jump to an arbitrary $t$ (@eq-forward).
:::

### Continuous-time limit: SDE {#sec-sde}

$\delta t \to 0$ When taking the limit, the forward process is written as a stochastic differential equation (SDE).

$$
dx = -\tfrac{1}{2}\beta(t)\,x\,dt + \sqrt{\beta(t)}\;dW_t
$$ {#eq-sde}

Here, $W_t$ is the **Wiener process**, which models a Gaussian random sample at each time step. The drift term $-\tfrac12\beta(t)x$ shrinks the signal to zero, and the diffusion term $\sqrt{\beta(t)}\,dW_t$ injects noise. (Refer to the review paper for the derivation — this note uses only the result.)

::: {.callout-tip}
## Wireless Communication Analogy — Forward Process = "Progressive Fading Channel"
$x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon$ is exactly the same form as the **channel model with AWGN added to a signal attenuated by the time-varying fading coefficient $\sqrt{\bar\alpha_t}$**. $\bar\alpha_t$ is the channel gain that decreases monotonically over time, and $1-\bar\alpha_t$ is the accumulated noise power. Variance-preserving is equivalent to **AGC (Automatic Gain Control) that keeps the total power of the received signal constant**. When the SNR drops to 0 at $t\to T$, the received signal becomes pure noise $x_T \sim \mathcal{N}(\mathbf{0},\mathbf{I})$.
:::

### Reverse process (reverse) {#sec-reverse}

**One-line answer:** The true inverse process $q(x_{t-1}\mid x_t)$ is unknown, but since $\beta_t \ll 1$ is approximated as Gaussian, the average is learned using a neural network.

If you try to use inversion with Bayes' rule

$$
q(x_{t-1}\mid x_t) = \frac{q(x_t \mid x_{t-1})\,q(x_{t-1})}{q(x_t)}
$$ {#eq-bayes}

, but the marginal distribution $q(x_{t-1}),\,q(x_t)$ on the right side is **unknown for the entire data distribution** (bad news). The good news is that if $\beta_t$ is sufficiently small, the true posterior $q(x_{t-1}\mid x_t)$ is also well approximated by a Gaussian. Therefore, we set it as a **parameterized Gaussian** as follows.

$$
p_\theta(x_{t-1}\mid x_t) = \mathcal{N}\!\big(x_{t-1};\, \mu_\theta(x_t,t),\, \sigma_t^2 \mathbf{I}\big)
$$ {#eq-reverse}

::: {.callout-important}
## Structure of cascaded approximation
1. **True inverse process** $q(x_{t-1}\mid x_t)$ → (β small) → Approximately as **Gaussian**
2. The mean of that Gaussian $\mu_\theta$ → Approximated by a **neural network**

The Gaussian is completely determined by knowing only the **sufficient statistics** of mean and variance. Since the variance $\sigma_t^2$ is automatically determined by the schedule $\beta_t$, the target of training is effectively just **the mean $\mu_\theta$**.
:::

### $\mu_\theta$ Learning: Noise Reparameterization {#sec-reparam}

The posterior mean of the forward process is represented by $x_0$ and noise $\epsilon$. If we solve @eq-forward for $x_0$ and substitute, the mean takes the following neat form.

$$
\mu_\theta(x_t,t) = \frac{1}{\sqrt{\alpha_t}}\left(x_t - \frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\,\epsilon_\theta(x_t,t)\right)
$$ {#eq-mu}

In other words, instead of directly predicting the mean, we just need to train a neural network $\epsilon$ that predicts the injected noise $\epsilon_\theta(x_t,t)$. The core idea is:

1. Select one time point $t$ and sample the correct noise $\epsilon \sim \mathcal{N}(\mathbf{0},\mathbf{I})$.
2. Noise image generated with $x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon$.
3. Slope descent to $\nabla_\theta \lVert \epsilon - \epsilon_\theta(x_t,t)\rVert^2$.

::: {.callout-note}
## Why Noise Prediction — Backward Process Average = Forward Process Average
To make the inverse process *the exact inverse of the forward process*, the averages of the two processes must be equal: $\mu_\theta^{\text{(rev)}}(x_t,t) = \tilde\mu^{\text{(fwd)}}(x_t,t)$. In the forward process, we know $x_0,\epsilon$, so we can calculate this average accurately; in the inverse process, since we do not know it, we approximate it as $\epsilon_\theta$. Since the average is a function of $\epsilon$ (@eq-mu), **average fitting = noise fitting**.
:::

### Loss function {#sec-loss}

$$
\mathcal{L}_{\text{DDPM}} = \mathbb{E}_{t,\,x_0,\,\epsilon}\Big[\big\lVert \epsilon - \epsilon_\theta(x_t,t)\big\rVert^2\Big],
\qquad x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon
$$ {#eq-loss}

It starts from the original variational lower bound (ELBO), but after reparameterization, it is reduced to the **simple noise regression (MSE)** as shown above. Unlike the zero-sum game of GANs, the loss value decreases monotonically and converges stably.

### Learning/Sampling Algorithm {#sec-algo}

**Training**

1. Data $x_0 \sim q(x_0)$.
2. $t \sim \text{Uniform}\{1,\dots,T\}$ (Learnable at any time — thanks to @eq-forward).
3. $\epsilon \sim \mathcal{N}(\mathbf{0},\mathbf{I})$.
4. Update to $x_t = \sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon$, $\;\nabla_\theta\lVert\epsilon-\epsilon_\theta(x_t,t)\rVert^2$, repeat until convergence.

**Sampling (Sampling / Generation)**

Starting from $x_T \sim \mathcal{N}(\mathbf{0},\mathbf{I})$, about $t=T,\dots,1$:

$$
\hat{x}_0 = \frac{1}{\sqrt{\bar\alpha_t}}\big(x_t - \sqrt{1-\bar\alpha_t}\,\epsilon_\theta(x_t,t)\big),
$$

$$
\mu_\theta(x_t,\hat{x}_0) = \frac{\sqrt{\bar\alpha_{t-1}}\,\beta_t}{1-\bar\alpha_t}\,\hat{x}_0 + \frac{\sqrt{\alpha_t}\,(1-\bar\alpha_{t-1})}{1-\bar\alpha_t}\,x_t,
\qquad
x_{t-1} = \mu_\theta(x_t,\hat{x}_0) + \sigma_t\,z,\;\; z\sim\mathcal{N}(\mathbf{0},\mathbf{I}).
$$

::: {.callout-warning}
## Inherent limitation of DDPM — cannot control $\sigma_t$
In DDPM, $\sigma_t$ (usually $\sigma_t^2 = \tilde\beta_t = \tfrac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t}\beta_t$) is **automatically calculated from schedule $\beta_t$** and cannot be touched by the user. Since it is **stochastic sampling** that draws a new $z$ at every step, the path cannot be controlled, and the entire inverse-SDE must run tens of thousands of steps to generate a single sample — this is the source of **slowness**.
:::

```{mermaid}
flowchart TB
    subgraph T["학습 (단순)"]
      t1["x₀ 샘플"] --> t2["t ~ Uniform"] --> t3["ε ~ N(0,I)"] --> t4["xₜ 합성"] --> t5["∇θ‖ε−εθ‖²"]
    end
    subgraph S["샘플링 (비쌈)"]
      s1["x_T ~ N(0,I)"] --> s2["t=T..1 반복"] --> s3["εθ(xₜ,t) 예측"] --> s4["x̂₀, μθ 계산"] --> s5["xₜ₋₁ = μθ + σₜz"] --> s2
    end
```

### Evaluation Metrics: FID {#sec-fid}

**One-line answer:** FID (Fréchet Inception Distance) measures the distance between the generated distribution and the actual distribution on the latent representation of an Inception neural network, and **lower is better**.

Images are passed through a pre-trained Inception network (Google's GoogLeNet/Inception family) to obtain semantic latent vectors, and the difference in mean and covariance (assuming Gaussian distribution) between the set of real images and the set of generated images is measured. The closer the two distributions are (=the more the product looks "like a natural image"), the smaller the FID. Although it is an old network that is over five years old, it is still widely used as a standard comparison metric.

| Method (CIFAR-10) | FID ↓ |
|---|---|
| Conditional GAN | 14.73 |
| StyleGAN2 + Auxiliary Techniques | 2.67 (accompanied by difficulty in avoiding mode collapse) |
| **DDPM** | **3.17** (Reached stably without game theory) |

DDPM is simple and stable to train, yet demonstrates **quality** comparable to top-tier GANs. However, the inefficiency of generation speed remains a major weakness — DDIM addresses this.

## DDIM: Deterministic Accelerated Sampling {#sec-ddim}

### Synchronous {#sec-ddim-motivation}

**One-line answer:** DDIM reuses the same training results as DDPM, but reinterprets the forward process as **non-Markov** to enable **deterministic, small-step** sampling.

DDPM's Weakness:

- Slow sampling (tens of thousands of steps).
- Stochastic path → Difficult to control · Inefficiency.
- Full inverse-SDE required for every sample.

The goal of DDIM is "**Fewer steps + Deterministic path + Marginal distribution identical to DDPM**". Key idea:

1. Interpret the forward process as a **non-Markov, deterministic event**.
2. Deriving the inverse process based on **ODE** (DDPM is SDE).
3. Realization of non-probabilistic and efficient sampling.

### Non-Markov forward process {#sec-ddim-forward}

DDPM assumes that $q(x_{t-1}\mid x_t)$ depends **only on $x_t$** (Markov assumption). DDIM additionally conditions this with $x_0$ information.

$$
q(x_{1:T}\mid x_0) = q(x_T\mid x_0)\prod_{t=2}^{T} q(x_{t-1}\mid x_t, x_0)
$$ {#eq-ddim-forward}

Each inversion is by Bayes' rule

$$
q(x_t \mid x_{t-1}, x_0) = \frac{q(x_{t-1}\mid x_t, x_0)\,q(x_t\mid x_0)}{q(x_{t-1}\mid x_0)}
$$ {#eq-ddim-bayes}

is derived from ||| and is non-Markov because $x_t$ depends on both $x_{t-1}$Z and $x_0$.

::: {.callout-tip}
## $x_0$ Why does the information reduce the number of steps?
The Markov assumption is the constraint that "only the immediate state is known." Since DDIM utilizes **additional information about the destination $x_0$** during training, it can reach the same quality with fewer iterations. By analogy, it is the difference between **moving one step at a time based only on the current position (DDPM)** vs. **knowing the destination and jumping along a straight path (DDIM)**.
:::

Crucially, the marginal distribution of $x_t$ remains **identical** to DDPM.

$$
q(x_t \mid x_0) = \mathcal{N}\!\big(\sqrt{\bar\alpha_t}\,x_0,\,(1-\bar\alpha_t)\mathbf{I}\big),
\qquad x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon_t
$$ {#eq-ddim-marginal}

Thanks to this neighborhood match, the noise predictor $\epsilon_\theta$ trained in DDPM can be reused as is. The implementation is the same, only the mathematical interpretation differs (DDPM=SDE, DDIM=ODE).

### Inverse process sampling and $\eta$ {#sec-ddim-sampling}

Following the average of the posterior $q(x_{t-1}\mid x_t, x_0)$ yields a generalized update formula.

$$
\boxed{\;x_{t-1} = \sqrt{\bar\alpha_{t-1}}\,\hat{x}_0 + \sqrt{1-\bar\alpha_{t-1}-\sigma_t^2}\;\epsilon_\theta(x_t,t) + \sigma_t\,z,\quad z\sim\mathcal{N}(\mathbf{0},\mathbf{I})\;}
$$ {#eq-ddim-sample}

Here, the amount of probability is controlled by the hyperparameter $\eta$.

$$
\sigma_t = \eta\,\sqrt{\frac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t}}\,\sqrt{1-\frac{\bar\alpha_t}{\bar\alpha_{t-1}}}
$$ {#eq-ddim-sigma}

- $\eta = 0 \Rightarrow \sigma_t = 0$ : **Completely deterministic**(first term + second term only, noise $z$ eliminated).
- $\eta = 1 \Rightarrow$ **Exactly equivalent to DDPM** (Markov forward reduction).

::: {.callout-note}
## Verification: When $\eta{=}1$ $\sigma_t^2 = \tilde\beta_t$
If you substitute $\beta_t = 1-\tfrac{\bar\alpha_t}{\bar\alpha_{t-1}}$ into @eq-ddim-sigma
$$
\sigma_t^2\big|_{\eta=1} = \frac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t}\,\beta_t = \tilde\beta_t
$$
**exactly** matches the posterior variance of DDPM (the difference $=0$ confirmed by symbolic calculation). Additionally, the forward margin @eq-ddim-marginal was confirmed to match the closed form via Monte Carlo (@sec-appendix).
:::

### Loss Equality {#sec-ddim-loss}

Since the fact that the neural network predicts noise $\epsilon_t$ remains the same even if the forward and inverse processes are swapped, the loss is the same as DDPM — **for any $\sigma_t$**.

$$
\mathcal{L} = \mathbb{E}_{t,\,x_0,\,\epsilon}\big[\lVert \epsilon_t - \epsilon_\theta(x_t,t)\rVert^2\big]
$$ {#eq-ddim-loss}

That is, **both DDPM and DDIM generation can be performed** with $\epsilon_\theta$, which has been trained once. You just need to leave the training code as is and add one $\eta$ to the sampling.

### DDPM vs. DDIM {#sec-ddim-vs}

| Item | DDPM | DDIM |
|---|---|---|
| Forward Process | Markov | **Non-Markov**(at $x_0$ Conditioning) |
| Inverse Process Formula | SDE | **ODE** |
| Variance $\sigma_t$ | Automatically determined by $\beta_t$, uncontrollable | Arbitrarily adjustable by $\eta$ |
| $\eta=0$ | — | **Deterministic**, prime step |
| $\eta=1$ | — | **Equivalent to DDPM** |
| Sampling Rate | Slow (e.g., 1000 steps) | Fast (e.g., similar quality at **50 steps**) |
| Training | Same procedure/loss | **Reuse the same $\epsilon_\theta$** |

::: {.callout-tip}
## Wireless Communication Analogy — DDIM = "Deterministic Equalizer"
The stochastic inverse process of DDPM is akin to **random reconstruction**, which draws a new noise realization for every symbol. DDIM reconstructs the signal using **deterministic ODE integral = deterministic equalization/demodulation** while maintaining the channel statistics (marginal distribution of the forward process) identically. $\eta$ is a dial that controls the amount of residual probabilism, $\eta=0$ corresponds to a **deterministic equalizer without noise addition**, and $\eta=1$ corresponds to a **simulation of the original stochastic channel**. Since it is a deterministic path, it is reliably reconstructed even with a **small number of large steps (subsampling)**, significantly reducing latency. However, large steps entail a slight loss of quality (approximation error).
:::

::: {.callout-warning}
## Honest Interpretation of Experimental Facts
In terms of FID, DDIM 50 steps may appear similar to or slightly better than DDPM 1000 steps. However, since FID is not a perfect indicator, **the results of a few steps may appear somewhat inferior to the naked eye**. A distinction must be made between "FID ≈ Equivalent" and "Perceptual Quality Equivalent".
:::

## LDM: Potential Diffusion (Stable Diffusion) {#sec-ldm}

**One-line answer:** Since diffusing in pixel space takes up too much memory, the image is compressed into a **low-dimensional latent space** and then diffusion is performed on it.

Training large-scale text-condition models directly in pixel space incurs massive computational and memory costs. LDM compresses images into low-dimensional latent representations using an autoencoder, performs the diffusion process in the **latent space**, and then restores them to pixel images using a decoder.

```{mermaid}
flowchart LR
    img["입력 이미지 (픽셀, 고차원)"] -- "인코더 E" --> z["잠재 z (저차원)"]
    z -- "잠재 공간 확산 (DDPM/DDIM)" --> z2["z' 생성"]
    z2 -- "디코더 D" --> out["출력 이미지"]
    txt["텍스트 조건"] -.크로스 어텐션.-> z2
```

**Sweet Spot of Compression Ratio:** As a result of comparing quality while changing the downsampling scale,

| Settings | Result |
|---|---|
| LDM-1 (Almost no compression = pixel diffusion) | Training time is **significantly long** |
| LDM-32 (Overcompression) | Discarding too much information **Quality degradation** |
| **LDM-4, 8, 16** | **Competitive Optimal Quality** |

::: {.callout-note}
## The second advantage of LDM — Semantic control
Each dimension of the latent space captures **semantics** better than pixels (simple color values). Therefore, adjusting specific dimensions of the latent representation allows for better control over the meaning of generated images, such as "summer deer → winter deer." This controllability leads to ControlNet (developed in 2023).
:::

::: {.callout-tip}
## Wireless Communication Analogy — LDM = "Transmit after source compression"
Pixel spatial spreading is equivalent to processing the entire original signal as is. Since LDM processes over a **latent representation with redundancy removed through source coding (dimensional reduction)**, **bandwidth and computational efficiency** increase significantly. Overcompression (LDM-32) is equivalent to a situation in lossy compression where the bitrate is lowered too much, causing the restoration quality to deteriorate — it is a problem of finding the **sweet spot of the rate-distortion trade-off**.
:::

## U-Net structure {#sec-unet}

**One-line answer:** It is a "butterfly/hourglass" structure in which the encoder-decoder forms an **information bottleneck** and the useful information lost at the bottleneck is restored through **skip connections** between corresponding layers.

The noise predictors for LDM and ControlNet typically use U-Net (which can be implemented using CNN or Transformer). The input and output are high-dimensional, and the representation narrows towards the center.

```{mermaid}
flowchart TB
    i1["입력 (고차원)"] --> e1["인코더 층1"] --> e2["인코더 층2"] --> b["병목<br/>(저차원 잠재)"]
    b --> d2["디코더 층2"] --> d1["디코더 층1"] --> o1["출력 (고차원)"]
    e1 -. "스킵 연결" .-> d1
    e2 -. "스킵 연결" .-> d2
```

- **Information Bottleneck:** Removes unnecessary noise information through compression (same principle as an autoencoder). It takes the shape of a "butterfly" with the narrowest point in the middle, or an "hourglass" when rotated 90°.
- **Skip connection:** Since bottlenecks can discard *useful information along with noise*, information is passed directly from the **encoder layer → decoder layer of the same dimension** to restore the details necessary for high-quality restoration. These paths form the shape of the letter **U** and are called U-Net.

It was originally proposed for **medical image segmentation**, but it is widely used in various fields due to its excellent information preservation capabilities.

::: {.callout-tip}
## Wireless communication analogy — Skip connection = "Side information channel"
The bottleneck is lossy compression, and skip connection is equivalent to **directly delivering details missing from compression to a separate side channel**. It is a structure that achieves **high-fidelity restoration** by combining the main compression stream (main channel) and detail preservation (side channel).
:::

## ControlNet: Controllable Generation {#sec-controlnet}

**One-line answer:** It is a fractional shot editing technique that fine-tunes a pre-trained diffusion U-Net with **small input-output pairs ($<50\text{K}$)** and controls generation with condition images (sketch, edge, etc.).

**Structural Idea** — Process conditional images using a pre-trained noise prediction U-Net.

- **Encoder:** Initialize by **copying** pre-trained U-Net parameters and fine-tune.
- **Decoder:** Combines encoded condition information and noise image, but injects the condition (control signal) using **zero convolution**.

```{mermaid}
flowchart LR
    cond["조건 이미지<br/>(스케치/엣지/깊이)"] --> enc["복사된 U-Net 인코더<br/>(미세조정)"]
    base["사전학습 확산 U-Net<br/>(고정 backbone)"] --> dec["디코더"]
    enc -- "zero convolution 주입" --> dec
    dec --> out["조건부 생성 이미지"]
```

**Procedure:** Initially, realistic images are generated without condition information, and then **condition information is gradually introduced** (since the initial value of zero convolution is 0, the backbone is not damaged in the early stages of training). This idea is applicable to arbitrary image conditions.

::: {.callout-note}
## Data Efficiency
The training dataset size is approximately $100\text{K}$, which is **about 50,000 times smaller** than LAION-5B. Achieving strong controllability with a small number of pairs is a key value.
:::

::: {.callout-important}
## Why is it commercially important?
In multimodal conditional generation, the ability to **precisely control the generation when slightly changing the text prompt** is critical. ControlNet offers high quality, controllability, and broad applicability simultaneously, making it highly commercially valuable (ICCV 2023 Best Paper).
:::

::: {.callout-tip}
## Wireless Communication Analogy — ControlNet = "Pilot/Control Channel Overlay"
It is equivalent to steering the beam/transmission by leaving the existing transmitting and receiving system (pre-trained backbone) as is and gradually adding a **separate control/pilot channel (condition encoder + zero convolution)**. The zero initialization of the zero convolution corresponds to a strategy of **gradually turning on the control channel at 0 power** to adapt without disturbing the existing link.
:::


- **DDPM ↔ DDIM**: *Same series* sharing the same $\epsilon_\theta$. DDIM turns off probabilism with $\eta$ and uses the ODE deterministic path to **accelerate sampling**.
- **LDM**: A *different philosophy* that moves to latent space to gain **efficiency + semantic control**.
- **ControlNet**: Grant **commercial control** to LDM.

**Next Session — Data-Efficient Learning**

In the objective function $\mathcal{L} = \underbrace{\mathcal{L}_{\text{data}}}_{\text{데이터 적합}} + \underbrace{\Omega(\theta)}_{\text{정규화 = 귀납 편향}}$, the traditional approach when data is scarce is to design a **better inductive bias** (few-shot / zero-shot / continual). However, devising a new bias for every task is very wasteful.

::: {.callout-note}
## Paradigm Shift: Inductive Bias → Foundation Model
An alternative is to **pre-warm up the model with irrelevant but massive data** instead of the data for the given task, and then fine-tune and generalize. A model that serves as the "starting point for good performance across multiple tasks" in this way is called a **frontier model**. It is expensive but offers powerful generalization — leading to the next topic (few/zero-shot, continual learning).
:::

## Appendix: Python/NumPy Verification {#sec-appendix}

Verify the two key facts in the text with code: (1) the marginal distribution of the forward process @eq-forward, and (2) the variance of DDIM($\eta{=}1$) matches the posterior variance of DDPM $\tilde\beta_t$ (@eq-ddim-sigma).

```{python}
#| label: forward-marginal-check
#| code-fold: show
import numpy as np

np.random.seed(0)
betas  = np.linspace(1e-4, 0.02, 1000)
alphas = 1.0 - betas
abar   = np.cumprod(alphas)        # \bar\alpha_t

x0, T, N = 3.0, 500, 200_000
# 마르코프 전방을 직접 반복하여 x_T를 몬테카를로로 추정
x = np.full(N, x0, dtype=float)
for t in range(T):
    x = np.sqrt(alphas[t]) * x + np.sqrt(1 - alphas[t]) * np.random.randn(N)

print(f"MC      mean={x.mean():.4f}  var={x.var():.4f}")
print(f"closed  mean={np.sqrt(abar[T-1])*x0:.4f}  var={1-abar[T-1]:.4f}")
# closed form: x_t ~ N( sqrt(abar_t) x0, (1-abar_t) I )
```

```{python}
#| label: ddim-ddpm-equivalence
#| code-fold: show
import sympy as sp

abar_t, abar_tm1 = sp.symbols('abar_t abar_tm1', positive=True)
beta_t = 1 - abar_t/abar_tm1                          # \beta_t = 1 - \bar\alpha_t/\bar\alpha_{t-1}

sigma_ddim_sq = ((1-abar_tm1)/(1-abar_t)) * (1 - abar_t/abar_tm1)   # eta=1
beta_tilde    = (1-abar_tm1)/(1-abar_t) * beta_t                    # DDPM 사후 분산

print("sigma_DDIM(eta=1)^2 - beta_tilde =", sp.simplify(sigma_ddim_sq - beta_tilde))
# 0 이면 두 식이 항등적으로 동일
```

```{python}
#| label: noise-schedule-snr
#| code-fold: show
import numpy as np
# 신호 보존 sqrt(abar_t) 와 누적 잡음 sqrt(1-abar_t), 그리고 SNR = abar_t/(1-abar_t)
betas  = np.linspace(1e-4, 0.02, 1000)
abar   = np.cumprod(1 - betas)
for t in [0, 100, 300, 600, 999]:
    snr = abar[t] / (1 - abar[t])
    print(f"t={t:4d}  sqrt(abar)={np.sqrt(abar[t]):.3f}  "
          f"sqrt(1-abar)={np.sqrt(1-abar[t]):.3f}  SNR={snr:8.3f}")
# t가 커질수록 신호 보존↓, 잡음↑, SNR→0  (수신 신호가 순수 잡음으로 수렴)
```

::: {.callout-note}
## Verification result
- Forward margin: Monte Carlo mean and variance match closed form $\mathcal{N}(\sqrt{\bar\alpha_t}x_0,\,(1-\bar\alpha_t)\mathbf{I})$.
- DDIM($\eta{=}1$) Variance $-\ \tilde\beta_t = 0$ (Identity). → DDIM is a **strict generalization** of DDPM.
- SNR $=\bar\alpha_t/(1-\bar\alpha_t)$ converges to 0 at $t\to T$ → $x_T$ is pure noise.
:::
