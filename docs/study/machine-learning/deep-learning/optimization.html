1 The Essence of Optimization Problems

1.1 Risk vs. Empirical Risk

Deep learning training is ultimately an optimization problem. The key is to find the parameters \theta to minimize the loss, but two levels must be strictly distinguished.

Ideal Goal — Risk (Expected Risk)

J^*(\theta) = \min_\theta \mathbb{E}_{(x,y) \sim p_{\text{data}}} \big[L(f(x;\theta), y)\big]

Here, p_{\text{data}} is the actual distribution that generates “all the data in the world.” Minimizing this value is the goal of true generalization.

Realistic Alternative — Empirical Risk

J(\theta) = \mathbb{E}_{(x,y) \sim \hat{p}_{\text{data}}} \big[L(f(x;\theta), y)\big] = \frac{1}{m} \sum_{i=1}^{m} L(f(x^{(i)};\theta), y^{(i)})

Here, \hat{p}_{\text{data}} is the empirical distribution generated by the training dataset. J(\theta) is merely a proxy for J^*(\theta).

TipWireless communication analogy

In channel estimation, we want to minimize the MMSE of the entire channel environment (all locations, all times), but in reality, we only have a finite sample measured with pilot symbols. J(\theta), created from training data, can be thought of as a pilot-based estimate, while J^*(\theta), from the real world, can be thought of as a real channel.

This is Empirical Risk Minimization (ERM).

1.2 Limitations of ERM and Surrogate Loss

By definition, ERM is designed to overfit the training set. However, even if overfitting is intended, it is often difficult to efficiently optimize the ERM itself. For this reason, surrogate loss is used in practice.

The most representative example is the classification problem. The real goal is to minimize the 0-1 loss, but since it is not differentiable, the cross-entropy loss is used as a surrogate. This is a function that is easy to estimate and has a similar optimal solution.

1.3 Difference from pure optimization

In pure optimization, the objective itself is the problem, but deep learning optimization is different. We do not want to reduce J(\theta), but rather J^*(\theta), yet we are in a situation where we can only use J(\theta) as a tool. This subtle difference creates the inherent difficulty of deep learning optimization.

3 Critical Points and Hessian

The critical point of the loss function J(\theta) is the point \nabla_\theta J = 0. Whether this point is an extremum or a saddle point is determined by the eigenvalues of the Hessian matrix H = \nabla^2 J.

Types of critical points viewed by Hessian eigenvalues
Condition Type of branch
All eigenvalues > 0 Local minimum
All eigenvalues < 0 Local maximum
Mixed positive/negative eigenvalues Saddle point

4 Newton’s Method

4.1 principle

If we expand J(\theta) around \theta_0, we get:

J(\theta) \approx J(\theta_0) + (\theta - \theta_0)^\top \nabla J + \frac{1}{2}(\theta - \theta_0)^\top H (\theta - \theta_0)

By differentiating with respect to \theta and setting it to 0, a single update step is obtained in a closed form:

\theta^* = \theta_0 - H^{-1} \nabla J(\theta_0)

4.2 Failure condition of Newton’s Method

If the Hessian is indefinite (containing a mix of positive and negative eigenvalues), the Newton step can converge to a saddle point. This situation is very common in the high-dimensional space of deep learning.

There are also practical problems.

  • If there are n parameters, H is the n \times n matrix — calculating the inverse matrix is virtually impossible with hundreds of millions of parameters.
  • Memory requirement O(n^2), computation amount O(n^3)
  • For this reason, deep learning relies on quasi-Newton methods (such as L-BFGS) or first-order methods

5 Gradient Descent (GD)

5.1 Batch Training Algorithm

W \leftarrow W - \lambda \cdot \frac{1}{m} \Delta W

Here, \Delta W = \sum_{i=1}^m \nabla_W \text{loss}^{(i)}(W), sum the gradients of all m samples.

5.2 Characteristic Analysis

GD trade-off
Characteristics Result
Use all data → Stable gradient Descent in the correct direction
No noise Some important gradients may be canceled out
Large datasets → Rapid increase in memory/computation costs Reduced practicality

The core problem is that the larger the dataset, the more the entire data must be traversed for a single update. This is not practical at the scale of modern deep learning datasets.

6 Stochastic Gradient Descent (SGD)

6.1 Mini-batch Training algorithm

By splitting the data into n mini-batches (each batch size k, total m = n \cdot k):

W_{l,j} \leftarrow W_{l,j} - \frac{\lambda}{k} \Delta W_{l,j}

Update immediately for each mini-batch.

6.3 Arguments in favor of SGD — Noise is actually an advantage

  1. Local minimum escape: GD definitely gets stuck in a local minimum, but the stochastic noise of SGD causes it to escape.
  2. Saddle point escape: Newton’s method attempts to converge to the saddle point, but SGD avoids this with noise.
  3. Easy to Parallel: Each mini-batch can be processed independently → Advantageous for distributed learning.
NoteImportant Insight

The structure of the solution space is determined by the data distribution, not the convexity of the loss function. Even when using a convex loss, the landscape created by the data can be non-convex.

7 8 Challenges of Deep Learning Optimization

7.1 Ill-conditioning

Hessian H occurs when the condition number \kappa is very large.

\kappa = \frac{\lambda_{\max}}{\lambda_{\min}} \gg 1

The ideal step is \theta \leftarrow \theta - H^{-1} \nabla J, but with ill-conditioning, the general gradient direction deviates significantly from the optimal direction, following a zigzag path, and convergence becomes extremely slow.

TipWireless Communication Intuition

If the channel matrix H is ill-conditioned (if some singular values are very small), noise is amplified even when calculating the pseudo-inverse H^+. For the same reason, gradient updates on the ill-conditioned Hessian are also very unstable.

7.2 Local Minima

The loss landscape of deep learning has numerous local minimums. There are various reasons why optimization fails to converge.

  • If the function has no local minimum → does not stop
  • If gradient noise is too large → diverge
  • Overfitting → Extreme values that fit only the training data
  • Deterministic: Stops before reaching the critical point in most cases

7.3 Saddle Points — Key Challenges

Let’s think of the sign of the Hessian eigenvalue at each parameter dimension as a coin toss.

  • heads = positive (local minimum direction)
  • tails = negative (local maximum direction)

The probability that all are heads (pure local minimums) in the dimension n is 2^{-n}. Since the n of deep learning ranges from millions to billions, there are overwhelmingly many saddle points.

Correction for Random Matrix Theory: The lower the loss value J, the higher the probability that the eigenvalue is positive. Therefore:

  • Low-J critical point → mostly local minimum (good solution)
  • High-J critical point → mostly saddle point (to avoid)

This theoretically supports the empirical observation in deep learning that “a good local minimum is good enough.”

7.4 Cliffs and Exploding Gradients

In deep or time-stretched networks like RNNs, when the same weight matrix is repeatedly multiplied, the gradient increases exponentially.

\nabla J \sim W^\top \cdot W^\top \cdots W^\top \cdot \delta

The solution is Gradient Clipping.

\hat{g} = \frac{g}{\|g\|} \cdot \tau \quad \text{if } \|g\| > \tau

Limits only the magnitude while maintaining the direction of the gradient.

7.5 Long-Term Dependencies (Vanishing Gradient)

As the hidden layer deepens, the Jacobian is cumulatively multiplied according to the chain rule.

\frac{\partial L}{\partial W^{(1)}} = \frac{\partial L}{\partial h^{(n)}} \cdot \prod_{k=1}^{n-1} \frac{\partial h^{(k+1)}}{\partial h^{(k)}}

If the Jacobian of each layer is less than 1, the product decreases exponentially → vanishing gradient. The gradient of the initial layer becomes virtually zero, making learning impossible.

7.6 Inexact Gradients

The mini-batch gradient of SGD is merely a stochastic estimate of the true gradient.

g_{\text{batch}} = \frac{1}{k} \sum_{i \in \text{batch}} \nabla_\theta L^{(i)} \approx \nabla_\theta J(\theta)

Optimization is more difficult because it is not an exact gradient. The solution is to use a surrogate loss instead of the actual loss.

7.7 Poor Local vs. Global Structure Correspondence

Occurs when local gradient information does not represent the global landscape. SGD must diagnose which of the following situations applies.

  • Is it trapped in a local minimum?
  • Are you wandering at the saddle point?
  • Are you wasting time navigating global obstacles?
  • Does it vibrate between multiple local bumps?
  • Does it move along the winding canyon?

This can be diagnosed through visualization.

  • 1D subspace visualization: loss landscape between two points
  • 2D subspace visualization: landscape in a plane spanned by two direction vectors

Empirical Lesson: In most problems, there exists a linear subspace with monotonically decreasing values. This is why SGD actually works well.

7.8 Theoretical Limits

Theoretical analysis of deep learning optimization is extremely difficult. What we actually want is:

  • Exact global minimum ❌
  • Sufficiently good generalization performance ✓

This subtle difference makes deep learning theoretically difficult.

10 Momentum

10.1 Why is it necessary?

Vanilla SGD has two structural problems.

Problem 1 — ill-conditioning (poor Hessian conditioning)

If the contours of the loss function are very long ellipses (shaped like narrow canyons), the gradient oscillates back and forth along the walls of the canyon in the narrow direction, while moving slowly in the deeper direction. This occurs when the condition number of the Hessian is large.

\kappa = \max_{i,j} \left|\frac{\lambda_i}{\lambda_j}\right|

Problem 2 — Variance of Stochastic Gradient

Since the mini-batch gradient is a noisy estimate of the true gradient, the direction fluctuates at every step.

10.2 Momentum Algorithm [Polyak, 1964]

The core idea is to accumulate past gradients using an exponentially decaying moving average to create velocity \mathbf{v}, and to move the actual parameters in the direction \mathbf{v}.

\mathbf{v} \leftarrow \alpha \mathbf{v} - \epsilon \nabla_\theta \left(\frac{1}{m}\sum_{i=1}^{m} L(f(\mathbf{x}^{(i)};\boldsymbol{\theta}), \mathbf{y}^{(i)})\right)

\boldsymbol{\theta} \leftarrow \boldsymbol{\theta} + \mathbf{v}

  • \alpha \in [0,1): momentum hyperparameter, determines the exponential decay rate of the previous gradient contribution
  • \epsilon: learning rate
  • If \alpha = 0, it is the same as vanilla SGD; \alpha = 0.9 or 0.99 are common.
TipWireless communication analogy

\alpha is a type of low-pass filter coefficient. Instead of using the noisy gradient of each step as is, it exponentially weights and averages past signals to suppress stochastic noise and amplify signals in a consistent direction. This is the same principle as how the MMSE estimator filters out noise.

Magnitude of the steady-state value of velocity: If the continuous gradient g is fixed, the velocity is

\mathbf{v}_\infty = \frac{\epsilon \|\mathbf{g}\|}{1-\alpha}

converges to |||. That is, it moves \frac{1}{1-\alpha} times faster than vanilla SGD. If it is \alpha = 0.9, it is 10 times faster, and if it is \alpha = 0.99, it is 100 times faster.

10.3 Nesterov Momentum

It is an improved version of Ordinary Momentum. The key difference is that it calculates the gradient not at the current position, but at the position where velocity is applied one step ahead.

Ordinary vs. Nesterov Momentum
Ordinary Momentum Nesterov Momentum
gradient calculation location \boldsymbol{\theta} \boldsymbol{\theta} + \alpha\mathbf{v}
Formula \mathbf{v} \leftarrow \alpha\mathbf{v} - \epsilon\nabla_\theta L(\boldsymbol{\theta}) \mathbf{v} \leftarrow \alpha\mathbf{v} - \epsilon\nabla_\theta L(\boldsymbol{\theta} + \alpha\mathbf{v})

The entire update rule is:

\mathbf{v} \leftarrow \alpha\mathbf{v} - \epsilon\nabla_\theta\left[\frac{1}{m}\sum_{i=1}^{m} L\left(f(\mathbf{x}^{(i)};\boldsymbol{\theta}+\alpha\mathbf{v}),\mathbf{y}^{(i)}\right)\right]

\boldsymbol{\theta} \leftarrow \boldsymbol{\theta} + \mathbf{v}

NoteWhy is it good?

Since we already know the direction of movement due to inertia is \alpha\mathbf{v}, we calculate the gradient at that position and add the correction factor. For convex functions, it has been theoretically proven that the convergence speed improves from O(1/T) to O(1/T^2).

11 Parameter Initialization Strategies

11.1 Why is initialization important?

Since deep learning optimization is non-convex, where you start significantly influences where you converge. In particular:

  • If the initial value is too large → activation saturates → gradient vanishing
  • If the initial value is too small → the signal does not propagate
  • All units have the same value → No symmetry breaking occurs

11.2 Reset Weight

11.2.1 Naive method

W_{i,j} \sim U\left(-\frac{1}{\sqrt{m}}, \frac{1}{\sqrt{m}}\right)

It is a scale inversely proportional to the fan-in m. The idea is to maintain a constant variance of the activation by reducing the contribution of each weight as the input increases.

11.2.2 Xavier / Glorot Initialization [Glorot and Bengio, 2010]

W_{i,j} \sim U\left(-\sqrt{\frac{6}{m+n}}, \sqrt{\frac{6}{m+n}}\right)

Here, m is the fan-in (number of inputs) and n is the fan-out (number of outputs).

The core idea is to achieve two goals simultaneously.

  1. Forward pass: Activation variance is kept equal across all layers
  2. Backward pass: Gradient variance of all layers is kept equal

The geometric mean of the scale that simultaneously satisfies these two conditions in a linear network (no activation) is \sqrt{\frac{2}{m+n}}, and if the range is set accordingly in a uniform distribution, the above equation is derived.

WarningLimitations of the assumption

Xavier’s derivation assumes a “matrix multiplication chain without non-linearity.” Since real networks contain non-linear activations such as ReLU and sigmoid, this is not a completely accurate assumption. Nevertheless, it works very well in practice.

11.2.3 He Initialization [He et al., 2015] — Version for ReLU

W \sim \mathcal{N}\left(0, \sqrt{\frac{2}{m}}\right)

Since ReLU makes half of the input (negative region) zero, the variance is multiplied by 2 to compensate for the reduction of the effective variance by half.

11.3 Bias Initialization

In most cases, even if you initialize to 0, the weights break symmetry. The exceptions are as follows.

  • Output unit bias: The value obtained by converting the marginal statistics (mean) of the training set output into the inverse of the activation function.
  • ReLU bias: Set to around 0.1 → Prevent ReLU saturation during initialization
  • Gate/switch unit (LSTM forget gate, etc.): Set close to 1 → Allow information to pass through initially

12 Adaptive Learning Rate Methods

The fundamental problem with Vanilla SGD is that it applies the same learning rate \epsilon to all parameters. However, in reality:

  • Some parameters have large gradients and are updated frequently → require smaller steps
  • Some parameters have small gradients and are updated infrequently → require larger steps

This is particularly pronounced in uneven gradient landscape problems, such as sparse features in NLP and specific frequency components of CSI feedback. A method to solve this is the adaptive learning rate.

12.1 AdaGrad [Duchi et al., 2011]

Adjust the learning rate by accumulating the sum of squares of past gradients \mathbf{r} for each parameter.

\mathbf{r} \leftarrow \mathbf{r} + \mathbf{g} \odot \mathbf{g}

\boldsymbol{\theta} \leftarrow \boldsymbol{\theta} - \frac{\epsilon}{\delta + \sqrt{\mathbf{r}}} \odot \mathbf{g}

  • \delta: Small constant for numerical stability (\sim 10^{-7})
  • \odot: element-wise product

Effect: Parameters with large and frequent gradients → \mathbf{r} increases → effective learning rate decreases. Conversely, sparse parameters maintain large steps.

WarningProblem

Since \mathbf{r} is monotonically increasing, the effective learning rate converges to 0 as training lengthens → training stops prematurely. For this reason, it does not work well in non-convex deep learning.

12.2 RMSProp [Hinton, 2012 — unpublished]

Solves the monotonically increasing problem of AdaGrad. Uses the exponential moving average instead of the sum of squares.

\mathbf{r} \leftarrow \rho\mathbf{r} + (1-\rho)\mathbf{g} \odot \mathbf{g}

\boldsymbol{\theta} \leftarrow \boldsymbol{\theta} - \frac{\epsilon}{\sqrt{\delta + \mathbf{r}}} \odot \mathbf{g}

  • \rho: decay factor (usually 0.9 or 0.99)

Intuition: It reflects only the magnitude of the recent gradient, so it forgets old information. It has a sliding window effect. It is superior to AdaGrad in non-stationary objectives.

RMSProp with Nesterov momentum version also exists.

\mathbf{r} \leftarrow \rho\mathbf{r} + (1-\rho)\nabla_\theta L(\boldsymbol{\theta}+\alpha\mathbf{v}) \odot \nabla_\theta L(\boldsymbol{\theta}+\alpha\mathbf{v})

12.3 Adam [Kingma and Ba, 2014]

It is currently the de facto standard optimizer for deep learning. It integrates RMSProp + Momentum and adds bias correction.

(1) 1st moment estimate (mean): \mathbf{s} \leftarrow \rho_1 \mathbf{s} + (1-\rho_1)\mathbf{g}

(2) 2nd moment estimation (uncentered variance): \mathbf{r} \leftarrow \rho_2 \mathbf{r} + (1-\rho_2)\mathbf{g} \odot \mathbf{g}

(3) Bias correction: \hat{\mathbf{s}} \leftarrow \frac{\mathbf{s}}{1-\rho_1^t}, \quad \hat{\mathbf{r}} \leftarrow \frac{\mathbf{r}}{1-\rho_2^t}

(4) Parameter update: \boldsymbol{\theta} \leftarrow \boldsymbol{\theta} - \epsilon \frac{\hat{\mathbf{s}}}{\sqrt{\hat{\mathbf{r}}} + \delta}

ImportantWhy is bias correction necessary?

It starts initially as \mathbf{s}_0 = 0, \mathbf{r}_0 = 0. In the first step, it is \mathbf{s}_1 = (1-\rho_1)\mathbf{g}_1, which is underestimated by a factor of (1-\rho_1) compared to the actual expected gradient value, \mathbf{g}_1. This is corrected by dividing by \frac{1}{1-\rho_1^t}. As t increases, it becomes \rho_1^t \to 0, so the effect of the correction disappears.

Recommended hyperparameter:

  • \rho_1 = 0.9 (momentum decay)
  • \rho_2 = 0.999 (RMSProp decay)
  • \epsilon = 10^{-3} (learning rate)
  • \delta = 10^{-8} (numerical stability)

12.4 Optimizer Comparison Summary

SGD          : θ ← θ - ε·g
Momentum     : θ ← θ + v,  v ← αv - ε·g
AdaGrad      : θ ← θ - ε/√r · g,  r 단조증가
RMSProp      : θ ← θ - ε/√r · g,  r 지수이동평균
Adam         : θ ← θ - ε·ŝ/√r̂,  both moments + bias correction
NoteWhich optimizer should be used?

According to the No Free Lunch Theorem, the optimal optimizer varies for each problem. Even in the extensive comparative study by Schaul et al. (2014), no clear superiority was determined. Generally, Adam is used as the default, and in vision tasks, momentum + SGD sometimes shows better generalization.

13 2nd derivative-based optimization

These are methods to overcome the reason why Newton’s method cannot be used directly (the cost of the Hessian inverse).

  • Conjugate gradient: Fletcher-Reeves, Polak-Ribiere
  • BFGS / L-BFGS: quasi-Newtonian method, incrementally updates the Hessian approximation

L-BFGS is used for medium-scale problems due to its memory efficiency, but it is still a heavy burden for large deep learning models.

14 Other optimization techniques

14.1 Coordinate Descent

is a method that optimizes each dimension of the vector input \mathbf{x} independently. It repeats the process of freezing other variables and optimizing only one variable. Optimizing a subset of dimensions together results in block coordinate descent.

It is valid only when dimensions are truly independent, so it is not suitable for general deep learning parameters. However, it is useful for problems where dimensions are clearly distinct (e.g., the color dimension and edge dimension of an image).

14.2 Polyak Averaging

In the optimization process, the average of visited points is used as the final parameter.

\bar{\theta} = \frac{1}{t}\sum_{i=1}^{t} \theta^{(i)}

In convex optimization, there is a strong guarantee of convergence. In non-convex neural networks, it is a heuristic but works well in practice. For non-convex problems, the running average (averaging only recent points) is commonly used.

15 Modern Techniques

15.1 Batch Normalization [Ioffe and Szegedy, 2015]

Strictly speaking, it is not an optimization algorithm but an adaptive reparameterization method, yet it has a significant impact on optimization.

Normalize the activation of each layer in mini-batch units.

\hat{x}^{(k)} = \frac{x^{(k)} - \mu_\mathcal{B}}{\sqrt{\sigma_\mathcal{B}^2 + \epsilon}}

y^{(k)} = \gamma^{(k)}\hat{x}^{(k)} + \beta^{(k)}

\gamma, \beta is a learnable scale/shift parameter. If it is \gamma = \sigma_\mathcal{B}, \beta = \mu_\mathcal{B}, the original activation can be restored, so there is no loss of expressiveness.

Why is this necessary? Looking at the second-order term \epsilon^2 g_i g_j \prod_{k=i}^{j-1} w_k of the neural network output, if \prod w_k is greater than 1, an exponentially large term is created, making it very difficult to select a learning rate. BN alleviates this problem by stabilizing the activation distribution of each layer.

Effect:

  • Allow higher learning rate
  • Less sensitive to initialization
  • Regularization effect (mini-batch noise acts as a kind of noise injection)

Test: Use \mu, \sigma, the running average accumulated during training.

15.2 Pretraining

Uses parameters pre-trained on large datasets or related tasks as initial values. Allows starting in a good area of the loss landscape.

Greedy supervised pretraining: When it is difficult to directly optimize a complex model, this is a method of training a simpler model on a simpler task and then gradually increasing the complexity.

MAML (Model-Agnostic Meta-Learning) [Finn et al., 2017]: meta-pretrains on multiple tasks to learn initial values that enable fast adaptation to new tasks.

15.3 Knowledge Distillation [Hinton et al., 2015]

Train a small student model using the soft prediction of a large teacher model as the target. Pass the “dark knowledge” contained in the teacher’s prediction distribution.

This topic is very important, so it will be covered in detail in a separate section.

15.4 Continuation Methods

Optimize by starting with an easy cost function J^{(0)} and moving to increasingly difficult cost functions J^{(k)}. The initial point is well-set to ensure that local optimization spends most of its time in the well-behaved region.

15.5 Curriculum Learning [Bengio et al., 2009]

It trains by starting with easy examples and gradually moving to more difficult ones. It can be viewed as a data version of the Continuation method. It accelerates convergence by making the optimization landscape smoother. It is particularly useful in weakly supervised tasks like reinforcement learning.

15.6 Better Architecture (ResNet)

Strictly speaking, it is an architectural design rather than an optimization algorithm, but it is a key element that aids in optimization. Residual connections (highway connections) preserve the gradients of later layers down to the initial layers, mitigating vanishing gradients.

16 Q&A: Further Exploration

16.1 Why are soft labels helpful for training?

This is the core mechanism of Knowledge Distillation and can be analyzed from three perspectives: Information Theory + Optimization Landscape + Generalization.

16.1.1 Hard Label vs. Soft Label

The hard label (one-hot) is y = [0, 0, 1, 0, 0, \ldots, 0], which assigns a probability of 1 only to the correct class. The only information given to the model is “what the correct answer is”.

Soft label (teacher’s softmax output) shows that the correct answer class has the highest value, as in q = [0.01, 0.05, 0.85, 0.06, 0.02, \ldots, 0.01], but there is also a meaningful probability distribution in the incorrect answer class.

16.1.2 Information Theory Perspective — “Dark Knowledge”

This is a concept named by Hinton et al. (2015). The output of Teacher implicitly encodes the inter-class similarity structure. For example, for the MNIST digit “8” image, teacher:

Teacher distribution contains dark knowledge
Class Soft Label
8 (Answer) 0.87
3 0.07
0 0.04
1 0.01
remainder \approx 0

If you printed , this contains the information that “8 is visually similar to 3 and somewhat similar to 0.”

When comparing entropy, the one-hot distribution is H(p) = 0 bits, but the soft label is H(q) > 0. This means that additional information is contained.

16.1.3 Gradient Perspective — Maintaining Learning Signals

Let’s directly compare the gradients of the cross-entropy loss.

Hard label: \frac{\partial \mathcal{L}_{\text{hard}}}{\partial z_c} = p_c - y_c

A meaningful gradient flows only for the correct class (c). For the incorrect class j \neq c: \frac{\partial \mathcal{L}_{\text{hard}}}{\partial z_j} = p_j \quad \text{(매우 작음)}

If the model is already highly confident in the correct answer (p_c \approx 1), the gradient converges to nearly 0 and the learning signal vanishes.

Soft label: \frac{\partial \mathcal{L}_{\text{soft}}}{\partial z_j} = p_j - q_j

Since the incorrect class is also q_j > 0, a continuous gradient is supplied to allow the model to learn the relative relationship between the incorrect classes.

16.1.4 Normalization Effect — Generalization of Label Smoothing

Label smoothing (Szegedy et al., 2016): y_{\text{smooth}} = (1-\epsilon) \cdot y_{\text{hard}} + \frac{\epsilon}{K}

Distributes \epsilon/K evenly across all incorrect answer classes. Soft labels refine this further: y_{\text{soft}} = (1-\lambda) \cdot y_{\text{hard}} + \lambda \cdot q_{\text{teacher}}

Smooths the distribution to reflect actual similarity, even unevenly among incorrect answer classes. Both suppress the model’s over-confident prediction.

16.1.5 The role of Temperature

In KD, temperature T is introduced to softmax: q_c^{(T)} = \frac{\exp(z_c/T)}{\sum_j \exp(z_j/T)}

Temperature distribution shape effect
Temperature T Effect
T = 1 Original softmax (sharper)
T \gg 1 Distribution approaches uniform (softer)
T \to \infty Perfectly uniform distribution

The higher the T used, the higher the probability of incorrect answer classes, and similarity information between classes becomes clearer. Hinton et al. recommend that both teacher and student use the same T.

16.1.6 Cleanup

Soft Label이 학습에 도움이 되는 이유:

1. 정보량 증가    → 클래스 간 유사도 구조(dark knowledge) 전달
2. Gradient 유지  → 정답에 confident해도 학습 신호가 소멸하지 않음
3. Landscape 개선 → Loss surface가 더 smooth, flat minimum 형성
4. 정규화 효과    → Over-confident prediction 억제, generalization 향상
TipWireless communication analogy

Training solely with hard labels is akin to performing channel estimation using only binary decisions (0/1). Soft labels convey confidence information, such as the Log-Likelihood Ratio (LLR), enabling the student model to make more accurate and robust estimates.

16.2 What exactly is “Loss Landscape”?

In a word, it is the “topographic map” generated by the loss function in the parameter space.

16.2.1 Intuitive understanding

If we simplify the model to have only two parameters \boldsymbol{\theta} = (\theta_1, \theta_2), the loss L(\theta_1, \theta_2) can be visualized in 3D space. Since actual deep learning models have millions to billions of parameters, direct visualization is impossible, but we can cut a 2D cross-section or conceptually imagine this terrain.

16.2.2 Major features of the landscape

Main structures of Loss landscape
Terrain Meaning Problem
Global minimum L is the lowest point in the whole hard to find
Local minimum Lower than surroundings but not the global minimum Can get stuck here
Saddle point Some directions are minimum, other directions are maximum Difficult to escape because gradient = 0
Flat region Flat region with gradient \approx 0 Training appears to have stopped
Sharp valley A canyon that is steep in one direction and gentle in the other ill-conditioning problem

16.2.3 What Optimization Techniques Do in Landscapes

Gradient descent is ultimately a search process of walking over this terrain. Each technique plays the following role on the terrain.

  • Momentum → Use inertia to escape the canyon
  • Adaptive LR → Adjust stride based on terrain slope
  • Good initialization → Select a good starting location
  • Batch normalization → Makes the terrain itself smoother
  • Soft label → Reshape terrain to make it smoother

16.2.4 Flat Minimum vs Sharp Minimum

The statement that “flat minimums provide good generalization” also stems from this context. If the range converges to a wide, flat valley, the loss does not change significantly even if the parameters fluctuate slightly, making it stable on test data. In contrast, with a sharp minimum, the loss increases explosively with even a slight deviation (Hochreiter and Schmidhuber, 1997; Keskar et al., 2017).

TipWireless communication analogy

The landscape of the cost function in channel estimation is a familiar concept. The MMSE estimator has a convex quadratic landscape, so it has only one global minimum and converges easily. On the other hand, ML estimation in non-linear channel models has a non-convex landscape, leading to local minimum problems — exactly the same situation as in deep learning.

17 Deep Learning Optimization from a Wireless Communication Perspective

Tip3-axis wireless communication support

From the perspective of wireless communication, the three axes of deep learning optimization can be corresponded as follows.

  • Initialization (Xavier/He) → pilot deployment: An incorrect pilot ruins all subsequent estimations.
  • Momentum → Filter Coefficients: Low-pass filtering of the noisy gradient. Same principle as noise suppression in the MMSE estimator.
  • Adaptive LR (Adam) → adaptive modulation: Adjusts the step size based on channel status (parameter stat).
