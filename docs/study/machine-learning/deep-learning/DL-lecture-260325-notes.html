Linear Regression, Logistic Regression, and Support Vector Machines

1 Overview

The core of a deep learning model is ultimately a linear model. Even though neural networks include non-linear activation functions, the operations of each layer are essentially linear transformations, with non-linearity added on top of them. Therefore, a deep understanding of linear regression serves as the starting point for understanding non-linear deep networks.

The overall structure of the content covered in this note is as follows.

Organize based on three key questions.

  1. How is the closed-form solution of linear regression derived, and why can it always be obtained? (Convexity)
  2. What is the relationship between the least squares method and maximum likelihood estimation (MLE)?
  3. Why is logistic “regression,” a regression model, the most representative classification model?

2 Linear Regression

2.1 Problem formulation

Given the observation pairs ZZZPH0006871ZZZ \(\langle \mathbf{x}_i, t_i \rangle\) and \(i = 1, \dots, N\), learn the mapping from the input \(\mathbf{x}\) to the target value \(t(\mathbf{x})\). The hypothesis space is restricted to a linear combination of the basis functions \(\{h_1, \dots, h_K\}\) and \(h_k(\mathbf{x}) \in \mathbb{R}\).

\[ \hat{y}_i = \sum_{k=1}^{K} w_k \, h_k(\mathbf{x}_i) \]

The learning target is the coefficient vector \(\mathbf{w} = (w_1, \dots, w_K)\). There are several options for the objective function (cross-entropy, KL divergence, etc.), but the most basic form is the Mean Squared Error (MSE), and the MSE-based linear regression problem is called the Ordinary Least Squares (OLS).

\[ \text{total error} = \sum_{i} (y_i - \hat{y}_i)^2 = \sum_{i} \Big( y_i - \sum_{k} w_k \, h_k(\mathbf{x}_i) \Big)^2 \]

Here, \(y_i - \hat{y}_i\) is called the residual. The goal is to minimize the sum of the squared vertical distances between the observed values and the model predicted values.

2.2 The precise meaning of “linear” — linearity of coefficients

ImportantThe standard for a linear model is not the input, but the parameters

If \(h_1(x) = x^2,\ h_2(x) = x,\ h_3(x) = 1\) is selected as the basis function, the relationship \(x\)–\(y\) becomes a parabola, but this model is still linear regression. This is because the model is linear with respect to parameter \(\mathbf{w}\).

\[ \hat{y} = w_1 x^2 + w_2 x + w_3 \quad \text{— } \mathbf{w} \text{에 대해 선형, } x \text{에 대해 비선형} \]

Regardless of the non-linear transformation ZZZPH0006877ZZZ the input undergoes \(h_k(\cdot)\), as long as linearity with respect to the optimization variable \(\mathbf{w}\) is maintained, all the theories of OLS (convexity, closed solutions) hold true. For a 2D input, any basis can be freely defined as \(\{h_1 = x_1^2,\ h_2 = x_2^2,\ h_3 = x_1 x_2, \dots\}\).

The basis function \(h_k\) acts as a feature transformation that moves data into a representation space. In traditional machine learning, this \(h_k\) was handcrafted and only \(\mathbf{w}\) was trained, but modern deep learning (CNN, Transformer) places learnable parameters within \(h_k\) as well to learn the representation itself from the data (representation learning). In this case, closed solutions no longer exist and dependence shifts to iterative optimization (gradient descent) — this is the fundamental reason why deep learning optimization is difficult.

2.3 Matrix Notation and Closed Solutions

Let’s rewrite the optimization problem in matrix form.

\[ \mathbf{w}^\ast = \arg\min_{\mathbf{w}} \sum_{j=1}^{N} \Big( t(\mathbf{x}_j) - \sum_{i=1}^{K} w_i \, h_i(\mathbf{x}_j) \Big)^2 \]

The \(j\)-th row of the design matrix \(\mathbf{H} \in \mathbb{R}^{N \times K}\) is \((h_1(\mathbf{x}_j), \dots, h_K(\mathbf{x}_j))\), \(\mathbf{t} \in \mathbb{R}^{N}\) is the observation output vector, and \(\mathbf{w} \in \mathbb{R}^{K}\) is the weight vector. Then

\[ \mathbf{w}^\ast = \arg\min_{\mathbf{w}} \underbrace{(\mathbf{H}\mathbf{w} - \mathbf{t})^{T} (\mathbf{H}\mathbf{w} - \mathbf{t})}_{\text{residual error } F(\mathbf{w})} \]

Derivation. \(F(\mathbf{w})\) is a quadratic expression in \(\mathbf{w}\). Expanded

\[ F(\mathbf{w}) = \mathbf{w}^T \mathbf{H}^T \mathbf{H} \mathbf{w} - 2\, \mathbf{t}^T \mathbf{H} \mathbf{w} + \mathbf{t}^T \mathbf{t} \]

If we set the gradient to 0 (Matrix derivative: \(\nabla_{\mathbf{w}}\, \mathbf{w}^T A \mathbf{w} = 2A\mathbf{w}\) for symmetric \(A\), \(\nabla_{\mathbf{w}}\, \mathbf{b}^T\mathbf{w} = \mathbf{b}\))

\[ \nabla_{\mathbf{w}} F = 2\,\mathbf{H}^T \mathbf{H} \mathbf{w} - 2\,\mathbf{H}^T \mathbf{t} = 0 \]

\[ \boxed{\ \mathbf{w}^\ast = (\mathbf{H}^T \mathbf{H})^{-1} \mathbf{H}^T \mathbf{t} = \mathbf{A}^{-1}\mathbf{b}\ } \qquad \mathbf{A} = \mathbf{H}^T\mathbf{H} \in \mathbb{R}^{K \times K},\quad \mathbf{b} = \mathbf{H}^T\mathbf{t} \in \mathbb{R}^{K} \]

\((\mathbf{H}^T\mathbf{H})^{-1}\mathbf{H}^T\) is the Moore–Penrose pseudo-inverse of \(\mathbf{H}\). \(\mathbf{A} = \mathbf{H}^T\mathbf{H}\) can be interpreted as the \(K \times K\) matrix containing the (denormalized) covariance structure of the transformed data.

NoteWhy Closed Solutions Are Guaranteed — Convexity

\(\mathbf{H}^T\mathbf{H}\) is a positive semidefinite function because for any \(\mathbf{v}\)Z, it is \(\mathbf{v}^T \mathbf{H}^T \mathbf{H} \mathbf{v} = \|\mathbf{H}\mathbf{v}\|^2 \ge 0\), and therefore \(F(\mathbf{w})\) is a convex function. Since the point where the gradient is zero is the global minimum of a convex quadratic function, the global optimum is obtained simply by differentiating and setting it to zero. In one-dimensional intuition, it is a downward-concave parabola of the form \(F(w) = aw^2 - 2bw + c,\ a \ge 0\).

For convexity, PSD matrices, and the rigorous derivation of matrix derivatives, refer to the quadratic forms and convexity chapters in the Mathematics for Machine Learning notes.

On the other hand, in actual deep learning, \(h_k\) itself is learned, so the objective function becomes non-convex over the entire \(\mathbf{w}\) (parameters of all layers), and must be explored through iterative optimization among numerous local minima.

TipComputation Perspective: \(A\mathbf{x} = \mathbf{b}\) and BLAS

Solving linear systems of the form \(\mathbf{A}\mathbf{w} = \mathbf{b}\) is the most common operation across engineering simulations, so the highly optimized library BLAS (Basic Linear Algebra Subprograms) has established itself as the standard. NVIDIA provides cuBLAS, which implements this for GPU parallel architectures, and these libraries are ultimately called at the bottom of PyTorch and TensorFlow. The performance of matrix operations in deep learning frameworks is essentially the performance of BLAS-family kernels.

2.4 Connection with MLE — Least squares is the MLE of the Gaussian noise model

Now, let’s look at the same problem again from a probabilistic perspective. Let’s model the prediction as a “linear function + Gaussian noise”.

\[ t(\mathbf{x}) = \sum_{i} w_i h_i(\mathbf{x}) + e, \qquad e \sim \mathcal{N}(0, \sigma^2) \]

Then the likelihood of a single observation is

\[ P(t \mid \mathbf{x}, \mathbf{w}, \sigma) = \frac{1}{\sigma\sqrt{2\pi}} \exp\!\left( \frac{-\big[t - \sum_i w_i h_i(\mathbf{x})\big]^2}{2\sigma^2} \right) \]

WarningDo not omit the product of the likelihoods of the entire iid dataset

The most common mistake in deriving the MLE is stopping with only the single-sample likelihood. If the dataset \(\mathcal{D} = \{(\mathbf{x}_j, t_j)\}_{j=1}^N\) is iid, the total likelihood must start as the product of \(N\) terms, take the logarithm, and then become the sum. In the experiment, if you start with a single term without \(\prod_{j=1}^N\), all subsequent expansions become meaningless.

Maximizing the log-likelihood of the entire data for \(\mathbf{w}\):

\[ \ln P(\mathcal{D} \mid \mathbf{w}, \sigma) = \ln \left( \frac{1}{\sigma\sqrt{2\pi}} \right)^{N} \prod_{j=1}^{N} \exp\!\left( \frac{-\big[t_j - \sum_i w_i h_i(\mathbf{x}_j)\big]^2}{2\sigma^2} \right) \]

Applying the properties of logarithms (product → sum, \(\ln e^z = z\)), the exponential function disappears and:

\[ \arg\max_{\mathbf{w}} \underbrace{\ln \left( \frac{1}{\sigma\sqrt{2\pi}} \right)^{N}}_{\mathbf{w}\text{와 무관한 상수}} + \sum_{j=1}^{N} \frac{-\big[t_j - \sum_i w_i h_i(\mathbf{x}_j)\big]^2}{2\sigma^2} \]

Since the constant term has no effect on \(\arg\max\), it is removed; and since the denominator \(2\sigma^2\) is also irrelevant to \(\mathbf{w}\), it is removed as well, and the max is flipped to min due to the negative sign.

\[ = \arg\max_{\mathbf{w}} \sum_{j=1}^{N} -\big[t_j - \textstyle\sum_i w_i h_i(\mathbf{x}_j)\big]^2 = \boxed{\ \arg\min_{\mathbf{w}} \sum_{j=1}^{N} \big[t_j - \textstyle\sum_i w_i h_i(\mathbf{x}_j)\big]^2\ } \]

This is exactly the OLS objective function. Conclusion:

Least-squares linear regression is equivalent to MLE under a Gaussian noise model.

To summarize the causal chain: ① Assume the noise is Gaussian → ② The likelihood takes the form of an exponential family, and the log-likelihood is proportional to the negative squared error → ③ Maximizing the likelihood = Minimizing the squared error. Linear regression is used so widely because many natural phenomena are well modeled as “signal + Gaussian noise.”

TipWireless Communication Perspective: ML Detection and LS Channel Estimation of AWGN Channels

This equivalence relation is a result already familiar in communication theory.

  • ML detection = minimum distance detection. ML detection of a transmitted symbol in AWGN channels \(r = s + n\) and \(n \sim \mathcal{N}(0, \sigma^2)\) is equivalent to selecting \(\arg\max_s P(r \mid s) = \arg\min_s \|r - s\|^2\), that is, the constellation point closest to the received signal. This has the exact same structure as the derivation “Gaussian assumption → MLE = LS” above.
  • LS Channel Estimation. The LS channel estimate \(\hat{\mathbf{h}}_{LS} = (\mathbf{X}^H\mathbf{X})^{-1}\mathbf{X}^H\mathbf{y}\) from the pilot matrix \(\mathbf{X}\) and the receiver \(\mathbf{y} = \mathbf{X}\mathbf{h} + \mathbf{n}\) is the same as the OLS closed solution \(\mathbf{w}^\ast = (\mathbf{H}^T\mathbf{H})^{-1}\mathbf{H}^T\mathbf{t}\). The design matrix \(\mathbf{H}\) corresponds to the pilot matrix, and the weights \(\mathbf{w}\) correspond to the channel coefficients.
  • The reason digital communication is possible. If we know that the channel noise is Gaussian, we can reconstruct the original signal virtually without error using ML estimation, even without knowing \(\sigma\). Knowledge of the statistical structure of the noise is the ability to reconstruct it — this is exactly the same principle as how assumptions about the noise model determine the objective function in machine learning.

The tool known as MLE itself has evolved deeply from communication/detection theory, and therefore machine learning and digital communication share the same mathematical foundation.

2.5 Why \(P(Y \mid X)\) — Benefits of Conditional Modeling

For supervised learning data \(\mathcal{D} = \{(\mathbf{x}, y)\}\), the principle likelihood is the joint distribution \(P(\mathbf{x}, y \mid \theta)\); however, since the input space \(\mathbf{x}\) (e.g., images) is usually ultra-high-dimensional, direct modeling is very difficult. Therefore, most classification problems are reduced to an easier version where \(\mathbf{x}\) is set as a given condition and only \(P(y \mid \mathbf{x}, \theta)\) is modeled.

The key difference lies in the difficulty of calculating the expected value. If \(\mathbf{x}\) is treated as a random variable, the integral (expected value) over an unknown high-dimensional distribution gets involved in the likelihood calculation, making it virtually impossible to compute. On the other hand, if \(\mathbf{x}\) is fixed as a condition, the design matrix \(\mathbf{H}\) becomes a deterministic constant, and since \(y\) is low-dimensional (a finite class in the case of classification), calculating the expected value becomes as simple as counting. It is not that the modeling format itself changes, but rather that computability leads to the choice of conditional formulation.

The philosophy of discriminant models is that if the goal is classification, one should not spend effort learning \(P(X \mid Y)\) but rather focus on \(P(Y \mid X)\) estimation, and logistic regression is a prime example. Generative models will be covered in detail later in VAE/GAN/Diffusion.

4 Logistic Regression

4.1 The paradox of “classifying” as “regression”

It seems contradictory at first glance that the name of the most popular discriminative classification model is logistic regression. The key to resolving this: the probability of a subject being regressed belonging to a class.

The model’s regression output is interpreted as the “probability that this sample belongs to that class,” and classification is performed by taking the maximum value of that probability. For example, if the regression probability for an image is Dog 0.8, Cat 0.7, and Flower 0.2, it is classified as a Dog. That is,

\[ \text{회귀 (확률 추정)} \;\xrightarrow{\;\arg\max\;}\; \text{분류 (결정)} \]

4.2 Logistic function

To regress the probability , a function is needed where the output is confined to \([0, 1]\). The general logistic function is

\[ f(x) = \frac{L}{1 + e^{-k(x - x_0)}} \]

  • \(x_0\): mid-point of the curve
  • \(L\): Curve height (upper limit)
  • \(k\): Curve steepness

The sigmoid function is a special case of \(L = 1,\ k = 1,\ x_0 = 0\).

\[ \sigma(x) = \frac{1}{1 + e^{-x}} \]

Properties that make the logistic function preferred for classifiers:

  1. Output is between 0–1 — Can be interpreted as a probability (not a strict probability, but the interval matches)
  2. Smooth and continuous — Since it is based on an exponential function, it can take derivatives infinitely, making it suitable for gradient-based optimization.
  3. Mirror Symmetry (\(\sigma(-x) = 1 - \sigma(x)\)) — Useful in some applications
  4. Very cheap to differentiate — See derivation below

Derivative derivation. By differentiation of composite functions

\[ \sigma'(x) = \frac{e^{-x}}{(1 + e^{-x})^2} = \frac{1}{1 + e^{-x}} \cdot \frac{e^{-x}}{1 + e^{-x}} = \sigma(x)\,\big(1 - \sigma(x)\big) \]

Since the derivative is obtained using only the pre-calculated function value \(\sigma(x)\), there is almost no additional cost in backpropagation.

4.3 Probabilistic Models and Linear Decision Boundaries

The probabilistic model of logistic regression in binary classification \(Y \in \{0, 1\}\) is

\[ P(Y = 0 \mid \mathbf{X}, \mathbf{w}) = \frac{1}{1 + \exp(w_0 + \sum_i w_i X_i)}, \qquad P(Y = 1 \mid \mathbf{X}, \mathbf{w}) = \frac{\exp(w_0 + \sum_i w_i X_i)}{1 + \exp(w_0 + \sum_i w_i X_i)} \]

(The signs of the exponents can be set differently according to convention — if the numerator and denominator are multiplied by \(\exp\) and simplified, the signs are absorbed to become equivalent expressions, so \(-\) The signed definition and the unsigned definition are the same model.)

Decision Boundary Derivation. Let’s assume we classify as \(P(Y=1 \mid \mathbf{X}) \gtrless P(Y=0 \mid \mathbf{X})\). If we take the ratio of the two probabilities, the common denominator cancels out, and

\[ \frac{P(Y = 1 \mid \mathbf{X}, \mathbf{w})}{P(Y = 0 \mid \mathbf{X}, \mathbf{w})} = \exp\Big( w_0 + \sum_i w_i X_i \Big) \gtrless 1 \]

Taking the logarithm of both sides (since \(\exp\) is monotonically increasing, keep the inequality direction):

\[ \boxed{\ w_0 + \sum_i w_i X_i \ \underset{0}{\overset{1}{\gtrless}}\ 0\ } \]

That is, the decision boundary is a linear (hyperplane) boundary of the input space. The essence of logistic regression is that while the probability output is non-linear (sigmoid), the decision rule itself is a linear classifier.

TipWireless Communication Perspective: log-odds are LLR

The \(\ln \frac{P(Y=1\mid \mathbf{x})}{P(Y=0 \mid \mathbf{x})} = w_0 + \sum_i w_i x_i\) derived above is an object similar to the LLR(Log-Likelihood Ratio) used daily in communication.

  • The soft decision of the channel decoder (LDPC, Turbo) calculates bit-by-bit LLR \(\ln \frac{P(b=1\mid r)}{P(b=0\mid r)}\) and makes a hard decision based on the sign — this is the same structure as logistic regression classifying based on the sign of log-odds.
  • Sigmoid is a transformation that converts LLR back into probabilities: \(P(b=1 \mid r) = \sigma(\text{LLR})\). Just as LLR \(= 2r/\sigma^2\) in BPSK over AWGN is a linear function of the received values, logistic regression can be viewed as a learner that models LLR as a linear function of the features.

4.4 Training: MCLE (Maximum Conditional Likelihood Estimation)

We train the parameters \(w_0, w_1, \dots, w_d\) on the \(d\)-dimensional features. Ideally, we would like to use the MLE of the joint likelihood \(P(\mathcal{D}_X, \mathcal{D}_Y \mid \mathbf{w})\), but our model only has \(P(Y \mid X)\). Therefore, we maximize the conditional data likelihood.

\[ l(\mathbf{w}) = \ln P(\mathcal{D}_Y \mid \mathcal{D}_X, \mathbf{w}) = \sum_{j=1}^{N} \ln P(y^j \mid x^j, \mathbf{w}) \]

(The symbol \(l\) represents the loss l, but here it is the objective function to be maximized.)

Derivation. Write the log-likelihood of the two classes in a single line using the indicator function \(\mathbf{1}(\cdot)\).

\[ l(\mathbf{w}) = \sum_j \Big[ \mathbf{1}(y^j = 1) \ln P(Y=1 \mid X^j, \mathbf{w}) + \mathbf{1}(y^j = 0) \ln P(Y=0 \mid X^j, \mathbf{w}) \Big] \]

Thanks to the label being \(\{0, 1\}\), it can be replaced with \(\mathbf{1}(y^j = 1) = y^j\) and \(\mathbf{1}(y^j = 0) = 1 - y^j\) (this trick does not work if the label is set to \(\{-1, +1\}\)).

\[ = \sum_j \Big[ y^j \ln P(Y=1 \mid X^j, \mathbf{w}) + (1 - y^j) \ln P(Y=0 \mid X^j, \mathbf{w}) \Big] \]

Substituting the definition of the probability model and simplifying:

\[ l(\mathbf{w}) = \sum_j \left[ y^j \Big( w_0 + \sum_i w_i x_i^j \Big) - \ln \Big( 1 + \exp\big( w_0 + \sum_i w_i x_i^j \big) \Big) \right] \]

NoteGood news and bad news
  • Good news: \(l(\mathbf{w})\) is the concave function of \(\mathbf{w}\) → The local optimum is the global optimum.
  • Bad news: There is no closed solution. Even if you try to solve \(\nabla l = 0\), the exponential terms are tangled and cannot be solved algebraically.
  • Good news again: Concave functions are easy to optimize. Since the global optimal point is unique, as you ascend the mountain (gradient ascent), you will inevitably reach near the summit.

(Note: The absence of a closed solution or the non-uniformity of the solution does not imply non-convexity — here, it is proven that the objective function is actually concave.)

4.5 Gradient Ascent

Maximization of the concave function is performed using gradient ascent that goes up in the direction of the gradient.

Gradient Derivation (3-step causal chain):

\[ \frac{\partial l(\mathbf{w})}{\partial w_i} = \sum_j \left[ \frac{\partial}{\partial w_i} y^j \Big( w_0 + \sum_i w_i x_i^j \Big) - \frac{\partial}{\partial w_i} \ln\Big( 1 + \exp\big(w_0 + \sum_i w_i x_i^j\big) \Big) \right] \]

① The first term is linear, so \(y^j x_i^j\). ② The second term follows the chain rule, so \(\dfrac{x_i^j \exp(w_0 + \sum_i w_i x_i^j)}{1 + \exp(w_0 + \sum_i w_i x_i^j)} = x_i^j \, P(Y=1 \mid x^j, \mathbf{w})\). ③ When factored by the common factor \(x_i^j\):

\[ \boxed{\ \frac{\partial l(\mathbf{w})}{\partial w_i} = \sum_j x_i^j \Big( y^j - P(Y^j = 1 \mid x^j, \mathbf{w}) \Big)\ } \]

The interpretation is beautiful: the gradient is the sum of (actual label − predicted probability) × input, i.e., a quantity weighted by the input to the prediction error. Since the label is 0/1 and the prediction probability is between 0 and 1, the error term \(y^j - P(\cdot)\) is confined to \([-1, 1]\), so all quantities naturally have a normalized scale.

Algorithm. Given a learning rate \(\eta > 0\), repeat until convergence:

\[ w_0^{(t+1)} \leftarrow w_0^{(t)} + \eta \sum_j \big[ y^j - P(Y^j = 1 \mid \mathbf{x}^j, \mathbf{w}) \big] \]

\[ w_i^{(t+1)} \leftarrow w_i^{(t)} + \eta \sum_j x_i^j \big[ y^j - P(Y^j = 1 \mid \mathbf{x}^j, \mathbf{w}) \big] \qquad (i = 1, \dots, n) \]

The outer loop runs on dimension \(i\), and the inner sum runs over the entire training sample \(j\). The termination conditions are ① reaching a fixed number of iterations, or ② the gradient (or the change in \(\mathbf{w}\)) becoming below a threshold—the latter is a method that guarantees a suboptimal point where it “no longer moves.”

NoteGeometric meaning of bias term \(w_0\)

\(w_0\) is a special weight that is not multiplied by the input \(x_i\), and it serves as the intercept of the linear model. Without \(w_0\), the decision hyperplane remains fixed at the origin and can only rotate; \(w_0\) is required to freely translate across the entire space. Although it is named “bias,” it is a distinct concept unrelated to the bias in the bias–variance tradeoff, so do not confuse them. In the update equation as well, it can be observed that \(w_0\) is updated solely by the error statistics, without the input \(x_i^j\).

WarningLearning Rate Scheduling — To avoid going over the top

The learning rate \(\eta\) problem is like determining the step size without knowing the terrain of the mountain (the curvature of the objective function). If the step size is too large near the summit (optimal point), an overshoot occurs where the model goes over the summit and falls to the opposite side. Therefore, learning rate scheduling, which reduces the step size as training progresses, determines the quality of convergence. What is called an “optimizer” in deep learning libraries (Adagrad, RMSProp, Adam, etc.) is essentially a combination of gradient descent/ascent and learning rate adjustment rules — the framework of the optimization algorithm is the same, but the rules regarding when and how much to reduce the learning rate differ. This is exactly the same structure as the LMS step size \(\mu\) in wireless communication adaptive filters determining the trade-off between convergence speed and steady-state error (misadjustment).

5 Support Vector Machine: Max Margin Classifier

5.1 Which linear classifier is the best

In linearly separable binary classification problems, there are infinitely many straight lines that perfectly separate the training data. Since they all have a learning error of 0, which one is better? The evaluation criterion is the goal of machine learning itself, namely generalization.

Intuition: Since points of each class are likely to be more distributed around visible samples, the boundary that maximizes the margin between the two classes is the safest for future samples. The Support Vector Machine (SVM) implements this intuition and is a model whose validity has been confirmed in intuition, theory, and practice.

5.2 Anatomy of a name

  • Machine = function (classifier). In machine learning, “machine” refers to a learned function.
  • Support Vector = A small number of data points that support (define) the decision boundary and margin. Since they are points in a vector space, they are vectors.

Key Insight: To define the boundary, only confusing samples close to the boundary are needed. The remaining distant points contribute nothing to the solution. The margin is defined by support vectors, and maximizing the margin itself becomes the objective function; expanding the formula results in a constrained linear (convex) optimization problem.

5.3 Limitations and Historical Position

  • Since SVM is a linear model, it cannot directly represent complex non-linear boundaries. Although non-linear boundaries can be implemented using kernel SVM, the computational cost is high, and at that level, there is no difference from using deep networks, so it has gradually been replaced by deep learning.
  • SVM was THE classifier of the pre-deep learning era (around 2010–2011). Remember that there was a time when neural networks were treated as “failed models” and SVMs dominated — dominant paradigms cycle.
  • Nevertheless, the key to remember: SVM is a linear classifier with a built-in margin concept and possesses a robust generalization theory. This margin/generalization idea extends to the regularization theory of neural networks as well.
TipWireless communication perspective: Margin = Minimum distance

The intuition of maximum margin is similar to the minimum distance design in digital modulation. Just as the probability of error due to noise decreases exponentially as the minimum Euclidean distance between symbols \(d_{\min}\) increases in constellation design (\(P_e \sim Q(d_{\min}/2\sigma)\)), the larger the margin of the classification boundary, the less likely it is for a new (noisy) sample to cross the boundary and be misclassified. Support vectors correspond to the “nearest constellation point pairs” that determine the boundaries of the decision region.

6 Next Topic Preview: KNN and Decision Trees

Unlike the linear model family (linear regression → logistic regression → SVM), the following two supervised learning algorithms are non-linear and non-parametric approaches.

  • K-Nearest Neighbor (KNN): Classification by majority voting of “close” samples. Two variations — ① the closest \(K\) samples ② neighbors within a radius \(r\) of a ball. The definition of “close” is determined by the distance metric. There is no training phase, and the hyperparameter is \(K\) or ball radius.
  • Decision Tree: Partitions space into a tree of feature questions. Extended to the ensemble version, Random Forest.

Logistic Regression Classification (Discriminative) Conditional Log-Likelihood (MCLE) Gradient Ascent (Concavity, No Closed Solution) Linear
SVM Classification (Discrimination) Margin Maximization Constraint Convex Optimization Linear (Non-linearized with Kernel)
  1. Linear regression is the foundation of modern ML models. The criterion for linearity is parameters, not inputs, and non-linear relationships can also be fitted as basis functions.
  2. OLS has a closed solution because its objective function is a convex quadratic, which is equivalent to MLE under the assumption of Gaussian noise. Since deep learning learns up to the representation (\(h_k\)), it leaves this world of closed solutions and enters the world of non-convex iterative optimization.
  3. Logistic regression is a discriminant model that classifies by regression of probabilities. The objective function of MCLE is concave, and it reaches a global optimality through gradient ascent. The gradient has a neat form as the sum of (error × input).
  4. SVM is a linear classifier with a built-in generalization principle called margin maximization, and was the standard in the pre-deep learning era.

8 Appendix: Python Implementation

Validate OLS closed solution and logistic regression gradient ascent in NumPy.

import numpy as np

rng = np.random.default_rng(42)

# ---- OLS: 닫힌 해 검증 ----
# 진짜 모델: y = 2*x^2 - 3*x + 1 + Gaussian noise
N = 200
x = rng.uniform(-2, 2, N)
t = 2 * x**2 - 3 * x + 1 + rng.normal(0, 0.5, N)

# 기저 함수: h1 = x^2, h2 = x, h3 = 1  (비선형 기저, 계수에 대해선 선형)
H = np.column_stack([x**2, x, np.ones(N)])     # N x K 설계 행렬

# w* = (H^T H)^{-1} H^T t   — 수치적으로는 solve가 inv보다 안정적
w_star = np.linalg.solve(H.T @ H, H.T @ t)
print("OLS closed-form w* =", np.round(w_star, 3), " (true: [2, -3, 1])")

# np.linalg.lstsq (내부적으로 LAPACK/BLAS 호출)와 일치 확인
w_lstsq, *_ = np.linalg.lstsq(H, t, rcond=None)
assert np.allclose(w_star, w_lstsq)
# ---- 로지스틱 회귀: gradient ascent ----
def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-z))

# 2D 가우시안 두 덩어리로 이진 분류 데이터 생성
N2 = 300
X0 = rng.normal([-1.5, -1.0], 1.0, (N2 // 2, 2))   # class 0
X1 = rng.normal([+1.5, +1.0], 1.0, (N2 // 2, 2))   # class 1
X = np.vstack([X0, X1])
y = np.r_[np.zeros(N2 // 2), np.ones(N2 // 2)]

Xb = np.column_stack([np.ones(N2), X])   # bias term w0 추가
w = np.zeros(3)
eta = 0.01

for step in range(2000):
    p1 = sigmoid(Xb @ w)                  # P(Y=1 | x, w)
    grad = Xb.T @ (y - p1)                # ∂l/∂w = Σ_j x^j (y^j - p1^j)
    w = w + eta * grad                    # ascent (오목 함수 최대화)
    if np.linalg.norm(eta * grad) < 1e-6: # 정지 조건: 파라미터 변화량
        break

acc = np.mean((sigmoid(Xb @ w) > 0.5) == y)
print(f"steps={step},  w = {np.round(w, 3)},  train acc = {acc:.3f}")

# 결정 경계가 선형(w0 + w1 x1 + w2 x2 = 0)임을 수치로 확인
print("decision boundary: "
      f"{w[0]:.2f} + {w[1]:.2f}*x1 + {w[2]:.2f}*x2 = 0")
# ---- "MLE = LS" 수치 검증 ----
# Gaussian 노이즈 모델의 음의 로그우도를 직접 최소화한 해가 OLS 해와 일치하는지
from scipy.optimize import minimize

sigma = 0.5
def neg_log_likelihood(w):
    r = t - H @ w
    # i.i.d. 곱 → 로그 합: N개 항 전체를 합산해야 함
    return 0.5 * np.sum(r**2) / sigma**2 + N * np.log(sigma * np.sqrt(2 * np.pi))

w_mle = minimize(neg_log_likelihood, np.zeros(3)).x
print("w_MLE =", np.round(w_mle, 3), " vs  w_OLS =", np.round(w_star, 3))
assert np.allclose(w_mle, w_star, atol=1e-4)
print("MLE (Gaussian noise) == OLS  ✓")
