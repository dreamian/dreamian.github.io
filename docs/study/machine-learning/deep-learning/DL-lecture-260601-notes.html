From Reinforcement Learning to PPO·GRPO: Policy Gradient-Based Optimization

Published

1 Full picture at a glance

TipKey One-Line Summary

Reinforcement learning (RL) is a problem of finding a policy \(\pi\) that maximizes the expected cumulative value of rewards on a mathematical framework called MDP. If the policy is directly parameterized as \(\theta\), the policy gradient theorem becomes the fundamental equation of learning, and from this, algorithms evolve in the direction of reducing variance (baseline, advantage, actor-critic) and controlling the update range (TRPO, PPO, GRPO).

The algorithms discussed today all lie on a single lineage. The starting point is REINFORCE, which uses the policy gradient as is; Actor-Critic emerged to reduce its variance; TRPO appeared to address the problem of learning becoming unstable due to overly large updates by binding the confidence domain; PPO approximated that complex second-order optimization with simple clipping; and GRPO is a version of PPO that completely removed the critic (value network) and replaced the advantage with group statistics.

2 The 4 Elements of Reinforcement Learning and Problem Definition

2.1 Direct Answer: What RL solves

RL is a problem in which an agent interacting with an environment and receiving a numerical reward signal learns action choice rules (policies) to maximize the accumulation of expected future rewards.

2.2 Four components

Element Symbol Definition Role
Policy \(\pi(a\mid s)\) Mapping from state to action (probability) Defines the agent’s action itself
Reward \(r\) A single number given by the environment at each time point The signal to be maximized **
Value Function (Value) \(v_\pi, q_\pi\) Accumulation of Expected Future Rewards Tool for Estimating Which Action Is Good
Model (Model, Optional) \(p(s',r\mid s,a)\) Simulation of Environment Dynamics Environment Proxy (Learning possible without)
Important

The key point is that the reward is an exogenous signal from the environment, and the value function is a proxy created by the agent. The policy is updated using the value function as a guide, and while the model simulates the environment to improve sampling efficiency if present (model-based), it learns even without one (model-free). All algorithms discussed today belong to the model-free family.

The name “reinforcement” comes from the fact that good state-behavior pairs become increasingly reinforced and distinct through repeated interactions. Historically, RL originated from optimal control theory, and with Bellman introducing the states of dynamical systems and value functions (optimal return functions), the Bellman equations and dynamic programming as their solution emerged. MDP is a generalization of this into a discrete, probabilistic version.

3 Markov Decision Process (MDP)

3.1 Direct Answer: Why MDP?

To define a learnable agent, a mathematical framework is required to define the behavior of the agent and the environment. Assuming the Markov property, the analysis becomes decisively simple because the probability of the next state and reward depends only on the immediately preceding state and action.

3.2 Definition and Markov properties

For time \(t\in\{0,1,2,\dots\}\), state \(s\in S\), action \(a\in A(s)\), and reward \(r\in R\), the environment dynamics are

\[ p(s', r \mid s, a) = \Pr\big(S_{t+1}=s',\, R_{t+1}=r \mid S_t=s,\, A_t=a\big). \]

Here, the Markov property is that the right-hand side is conditional on only one \(S_t, A_t\). In other words, the future statistics are determined by looking only at the present point in time, rather than the entire past \((S_0,A_0,\dots,S_{t-1},A_{t-1})\).

NoteEpisode = Data point

A set of interactions from time point 1 to \(T\) \((R_1, R_2, \dots, R_T)\) is called an episode, and this is a point of data for training. If the ends are naturally divided, it is an episodic task, and if it is a single long flow, it is a continuing task.

3.3 Discounted return and goal

\[ G_t = \sum_{k=t+1}^{T} \gamma^{\,k-t-1} R_k = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots, \qquad 0 \le \gamma \le 1. \]

Since uncertainty is greater for future rewards, the weight is reduced using the discount factor \(\gamma\). From here, the recursive form emerges immediately:

\[ \boxed{\,G_t = R_{t+1} + \gamma\, G_{t+1}\,} \]

The goal of learning is to maximize the expected return on the policy:

\[ \max_{\pi}\; \mathbb{E}_\pi[G_t]. \]

TipWireless communication compatibility — IIR accumulation with forget factor

\(G_t = R_{t+1} + \gamma G_{t+1}\) has the same structure as a first-order IIR/exponentially weighted accumulation with a forgetting factor \(\lambda\). The closer \(\gamma\) is to 1, the further into the future it remembers (long time constant), and the closer it is to 0, the more short-sighted it becomes (short time constant). This plays exactly the same role as the forgetting factor in RLS, which determines how long past errors are reflected.

4 Value function and optimal policy

4.1 Two value functions

\[ v_\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s], \qquad q_\pi(s,a) = \mathbb{E}_\pi[G_t \mid S_t = s,\, A_t = a]. \]

The state value \(v_\pi\) takes state only as input, while the action value \(q_\pi\) takes both state and action as input. Since it is very difficult to calculate both exactly, they are approximated.

4.2 Optimal Policy

\[ v_*(s) = \max_\pi v_\pi(s), \qquad q_*(s,a) = \max_\pi q_\pi(s,a). \]

The optimal policy is usually obtained using the action value \(q_*\). This is because \(q\) takes an action as input, allowing for a direct comparison of which action increases value in that state, whereas \(v\) cannot directly capture the effect of an action. In deterministic policies,

\[ \pi_*(s) = \operatorname*{arg\,max}_a q_*(s,a). \]

Important

It appears to optimize to \(v\), but internally it uses \(q\). Since the two are connected as \(v_\pi(s)=\sum_a \pi(a\mid s)\,q_\pi(s,a)\) in the Bellman equation that follows, the apparent optimization of \(v\) is actually reduced to a comparison of \(q\).

5 Bellman equation: recursive relation

5.1 Direct Answer: What is recursion?

The Bellman equation is a recursive formula that expresses the value function at the current time step in terms of the value function at the next time step. This recursion is necessary to convert policy iterations into iterative updates.

5.2 \(v_\pi\) and \(q_\pi\) connection

Marginalize state values with respect to behavior:

\[ v_\pi(s) = \sum_{a\in A(s)} \pi(a\mid s)\, q_\pi(s,a) \;\le\; \max_a q_\pi(s,a). \]

The inequality represents the fact that “the expected value cannot exceed the maximum value,” and sets an upper limit on policy improvement.

5.3 Recursive expansion of \(q_\pi\)

Insert the recursion \(G_t = R_{t+1} + \gamma G_{t+1}\) returning into the action value definition. The key step is that \(G_{t+1}\) can be replaced with \(v_\pi(S_{t+1})\) inside the expectation (the two are different outside but are the same in terms of conditional expectation):

\[ \mathbb{E}_\pi[v_\pi(S_{t+1}) \mid S_t=s, a] = \mathbb{E}_\pi[G_{t+1}\mid S_t=s, a]. \]

Therefore

\[ q_\pi(s,a) = \mathbb{E}_\pi\big[R_{t+1}+\gamma G_{t+1}\mid s,a\big] = \sum_{s',r} p(s',r\mid s,a)\,\big[\,r + \gamma\, v_\pi(s')\,\big]. \]

Substituting this into the \(v_\pi\) equation completes the Belleman expectation equation:

\[ \boxed{\; v_\pi(s) = \underbrace{\sum_{a}\pi(a\mid s)}_{\text{에이전트가 하는 일(정책)}} \underbrace{\sum_{s',r} p(s',r\mid s,a)}_{\text{환경의 반응(전이·보상)}} \big[\,r + \gamma\, v_\pi(s')\,\big] \;} \]

Note

Structural Analysis (3-step causal chain): Policy determines the behavior distribution → Environment responds with transitions and rewards → The immediate reward \(r\) and the future value of the next state \(\gamma v_\pi(s')\) combine to become the present value. The fact that it splits into two separable terms (policy term / environment term) is crucially used in the subsequent Policy Gradient Theorem — the environment term is independent of \(\theta\) and is excluded from differentiation.

TipWireless Communication Support — Recursive Filter (RLS) Update

\(v_\pi(s) = \mathbb{E}[\,r + \gamma v_\pi(s')\,]\) is in the form “current estimate = new observation + discounted next estimate,” and is a framework similar to the predict–update recursion of the RLS Kalman filter. It is intuitive if you view \(\gamma\) as a stable first-order recursion acting as the state transition gain.

6 Policy Repetition and GPI

6.1 Policy Improvement Summary

If we define the new greedy policy as the behavioral value of the current policy \(\pi\)

\[ \pi'(s) = \operatorname*{arg\,max}_a q_\pi(s,a) \quad\Longrightarrow\quad v_\pi(s) \le v_{\pi'}(s). \]

In other words, if you change the policy to “action that maximizes the current value function,” the value never deteriorates.

6.2 Generalized Policy Iteration (GPI)

flowchart LR
    P["정책 π"] -->|"평가<br/>(가치 추정)"| V["가치함수 v_π"]
    V -->|"개선<br/>(탐욕적 갱신)"| P

By alternately repeating evaluation (value estimation) and improvement (policy update), the optimal policy \(\pi_*\) and the optimal value \(v_*\) converge. The two processes are a cooperative iteration in which they lift each other.

WarningMotivation to transition from GPI limitations to policy gradient

GPI uses a non-differentiable greedy operation \(\arg\max\). Furthermore, greedy updates can abruptly change the policy distribution, causing agent behavior to change drastically in a single step and the learning curve to fluctuate. To train a neural network in a differentiable way, instead of \(\arg\max\), the policy must be parameterized as \(\theta\) and updated slowly using gradients. This is the motivation behind the policy gradient method.

7 Policy Gradient Modeling (PGM) and Policy Gradient Theorem

7.1 Direct Answer: Policy Gradient Theorem

If we set the policy to \(\pi(a\mid s;\theta)\) and define the objective function as the state value of the starting state \(J(\theta)=v_{\pi_\theta}(s_0)\), then (assuming \(\gamma=1\)) the gradient is

\[ \boxed{\;\nabla J(\theta) \;\propto\; \sum_s \mu(s) \sum_a q_\pi(s,a)\, \nabla \pi(a\mid s,\theta)\;} \]

where \(\mu(s)\) is the state distribution induced by the policy (average time ratio of staying in state \(s\)).

7.2 Meaning of theorem

The gradient of the objective function is decomposed into the product of three elements: the state distribution \(\mu(s)\), the action value \(q_\pi(s,a)\), and the gradient of the policy itself \(\nabla\pi\). The key point is that the derivative applies only to the policy term, and the environment transition probability \(p(s'\mid s,a)\) is independent of \(\theta\) and vanishes.

NoteProof Framework (Overview)
  1. Substitute the defined ZZZPH0010032ZZZ \(\nabla v_\pi(s)\) into \(v_\pi(s)=\sum_a \pi(a\mid s)q_\pi(s,a)\) and apply the product derivative: \(\nabla(\pi\,q) = (\nabla\pi)q + \pi(\nabla q)\).
  2. Since the reward/transition probability within \(\nabla q_\pi(s,a)\) is an independent constant \(\theta\), the derivative recursively passes to the next state \(\nabla v_\pi(s')\).
  3. If this recursion is expanded repeatedly, it is organized into the form \(\nabla v_\pi(s)\) \(s\) \(x\) \(x\) \(k\) \(\Pr(s\to x,k,\pi)\) \(\times\ \nabla\pi(\cdot\mid x)\, q_\pi(x,\cdot)\)“.
  4. Normalizing \(\sum_k \Pr(s\to x,k,\pi)\) gives the state distribution \(\mu(x)\) — “the average number of times spent in state \(s\) in one episode”. Substituting this closes the proportion.
TipWireless communication support — Adapt only the differentiable part

The environment transition is a channel (fixed probability) that we cannot control, and the policy is the weight that we adapt. The structure in which the channel is excluded from the derivative and only the weight update term remains is a separation configuration similar to an adaptive filter that adapts only the equalizer coefficients while keeping the channel fixed.

8 REINFORCE: Monte Carlo Policy Slope

8.1 Log-derivative trick and update formula

If we rewrite the policy gradient theorem in terms of expectation

\[ \nabla J(\theta) = \mathbb{E}_\pi\!\Big[\sum_a q_\pi(s,a)\,\nabla\pi(a\mid s,\theta)\Big]. \]

Applying the score function trick \(\nabla_\theta \ln f = \dfrac{\nabla_\theta f}{f}\) to this results in a sampleable form:

\[ \boxed{\;\theta_{t+1} = \theta_t + \alpha\, G_t\, \nabla \ln \pi(A_t\mid S_t, \theta_t)\;} \]

Return \(G_t\) updates in a direction that increases the log probability of the action that produced a large (good) trajectory.

8.2 algorithm

NoteREINFORCE procedure
  • Set the function \(\pi(a\mid s;\theta)\) (normal neural network), initial \(\theta\), and step size \(\alpha\).
  • Iteration: Randomly generate one episode with the current policy → Calculate \(G_t\) at each time point → Update all time points to \(\theta \leftarrow \theta + \alpha G_t \nabla\ln\pi(A_t\mid S_t,\theta)\) → Repeat with a new episode.
  • Since the gradient is estimated using sample trajectories, it is called Monte Carlo policy gradient control.
WarningWeakness of REINFORCE

Because the episodes are rolled randomly until the end to create \(G_t\), sample variance is very large. Learning is unstable (large policy updates), and sample efficiency and robustness are poor. This is why the learning curve fluctuates and the agent frequently exhibits erratic behavior (falling, stumbling). Reducing this variance is the consistent motivation for the next steps.

TipWireless communication support — Noise-heavy slope estimation

\(G_t\) is a noisy gradient with large variance, as it is an estimate obtained from a single random realization. Estimating a channel from a single snapshot is equivalent to having large variance, and the baseline subtraction in the next section corresponds to a preprocessing step that reduces the variance of the estimator.

9 Reduced Variance: Baseline · Advantage · Actor-Critic

9.1 Baseline reduces only variance without bias

The expected value of the gradient does not change even if the state-only dependent baseline \(b(S_t)\) is subtracted from the expected value (uncomfortable):

\[ \nabla J(\theta) = \mathbb{E}_\pi\big[(G_t - b(S_t))\,\nabla\ln\pi(A_t\mid S_t,\theta)\big]. \]

The reason is \(\mathbb{E}_\pi[\,b(S_t)\nabla\ln\pi\,]=b(S_t)\sum_a \nabla\pi = b(S_t)\nabla\!\sum_a\pi = 0\) (\(\sum_a\pi=1\)).

9.2 Advantage function

The natural baseline is the state value \(v_\pi(S_t)\). Approximating \(G_t\) with a one-step expansion without rolling it all the way results in a TD error, and this is precisely the advantage:

\[ \delta_t = R_{t+1} + \gamma\, v_\pi(S_{t+1}) - v_\pi(S_t) \;\approx\; G_t - v_\pi(S_t) \;=\; A_\pi(S_t, A_t), \qquad \nabla J(\theta) = \mathbb{E}_\pi[\delta_t\,\nabla\ln\pi]. \]

Advantage measures “how much better that action is than the average of that state” and reduces variance by converting large fluctuations in absolute rewards into relative values compared to the average.

9.3 Actor-Critic

Configuration Role Formula
Actor(Policy Network) Decide what action to take \(\pi_\theta(s)\)
Critic(Value Network) Estimate the quality of the behavior \(Q(s,a)\) or \(v(s)\), \(\delta_t\)
Note

The critic does not directly command the actor but assists them. Initially, since the policy is immature, the critic is noisy and offers almost no control; however, as iterations progress and the policy improves, the critic’s feedback becomes more accurate. This then better constrains the actor’s updates, leading to faster and more stable convergence. However, this is merely indirect normalization, and there is no guarantee that the policy will not change abruptly in a single step. The following confidence domain method is designed to directly provide that guarantee.

TipWireless communication support — DC removal / Control variable

Baseline subtraction is a control variate technique that reduces variance by subtracting the mean (DC) before estimation. It is equivalent to estimating only the variation after removing the mean of the signal, which reduces the estimated variance; this effect is evident in the approximately 7-fold reduction (21.8→3.1) in the text verification.

10 Confidence Region Method (TRPO)

10.1 Direct Answer: What does it restrict?

Even a single step can cause actor parameters to change rapidly, potentially leading to the breakdown of training. The solution is to bind the update domain using KL divergence to prevent the new policy from deviating too far from the previous one:

\[ D_{\mathrm{KL}}\big(\pi_{\theta_{\text{old}}} \,\|\, \pi_\theta\big) \le \epsilon. \]

10.2 Surrogate Objective Function and Probability Ratio

Approximate the \(\nabla\ln\pi\) term with a probability ratio (a first-order expansion from \(\theta_{\text{old}}\) gives the same slope):

\[ r_t(\theta) = \frac{\pi_\theta(a_t\mid s_t)}{\pi_{\theta_{\text{old}}}(a_t\mid s_t)}. \]

TRPO is for surrogate purposes under constraints

\[ \max_\theta\; \mathbb{E}_t\big[r_t(\theta)\,\hat{A}_t\big] \quad \text{s.t.}\quad D_{\mathrm{KL}}\le \delta \]

Maximize . In the unconstrained form, add the KL penalty \(-\beta D_{\mathrm{KL}}\) to the objective.

WarningLimitations of TRPO

To accurately handle KL constraints, it is a complex quadratic method that requires a second-order approximation of KL (including Hessian), and it is difficult to set the KL penalty coefficient \(\beta\) as a fixed value applicable to all problems. This weakness of being computationally heavy is the motivation for moving toward PPO.

TipWireless Communication Compatibility — Normalized Step Size Control (NLMS)

KL constraints are analogous to the NLMS concept of normalizing/limiting step sizes to prevent divergence in adaptive updates. Just as steps are reduced to maintain stability when input energy is high, KL constraints pull updates back when the policy is about to jump far, keeping them within a “trusted” area.

11 Proximate Policy Optimization (PPO)

11.1 Direct Answer: Clipped line

PPO replaces TRPO’s complex KL calculations with a simple operation that clips the probability ratios to \([1-\epsilon,\,1+\epsilon]\):

\[ \boxed{\; L^{\text{CLIP}}(\theta) = \mathbb{E}_t\Big[\min\big(r_t(\theta)\,\hat{A}_t,\;\operatorname{clip}(r_t(\theta),\,1-\epsilon,\,1+\epsilon)\,\hat{A}_t\big)\Big] \;} \]

11.2 Clipping behavior

\(r_t\) penalizes updates that deviate from 1 (=significant policy changes). Reading the behavior as a result of the body numerical validation:

Situation \(r_t\) Small \(r_t=1\) \(r_t\) Large
\(\hat A>0\) (Good behavior) Reflected as is 1.0 Upper limit at \(1+\epsilon\) (Block excessive amplification)
\(\hat A<0\) (Bad Behavior) Lower limit at \(1-\epsilon\) \(-1.0\) Penalty points as is (Suppression)

In other words, it prevents the policy from jumping out from both sides by pushing good behavior too hard or pulling bad behavior too hard. Since a KL penalty variation \(L - \beta D_{\mathrm{KL}}\) can also be used instead of clipping, PPO can be viewed as a general framework that includes the KL penalty method.

NoteAdvantages of PPO
  • Reusing the same data through stochastic gradient elevation over multiple epochs → Sample efficiency ↑
  • Maintain the stability and reliability of the confidence domain method
  • Simple implementation (first-order method, calculates only ratio + clip; KL Hessian unnecessary)

Thanks to this simplicity, PPO became the standard tool of RLHF and was used as a key tool for fine-tuning instructions in the GPT → InstructGPT → ChatGPT family.

Warning

There are also clear limitations. It can get stuck in a local optimum, and as clipping accumulates, there remains the possibility that the new policy will eventually become too far from the previous policy.

TipWireless Communication Support — Feedback Loop Limiter/Grid Clipping

Cutting \(r_t\) to \([1-\epsilon,1+\epsilon]\) is equivalent to the amplitude limiter and slope clipping of a feedback loop. It is a protection device that saturates the output to prevent the loop gain from becoming excessive and oscillating, and it is similar in that it is a practical method that ensures stability without complex stability analysis.

12 Group-Related Policy Optimization (GRPO)

12.1 Direct Answer: Remove critic + Group normalization

In PPO, advantage calculation (GAE) is expensive because it requires training a separate critic (value network) for the baseline. GRPO discards the critic entirely and replaces the advantage with the relative position of rewards within the group:

\[ \boxed{\;\hat{A}^{\text{GRPO}}_t = \frac{R - \mu_g}{\sigma_g + \delta}\;} \]

\(R\): Compensation for the corresponding output, \(\mu_g\): Group mean compensation, \(\sigma_g\): Group standard deviation, \(\delta\): A small constant that prevents the denominator from becoming zero.

12.2 Idea

For the same prompt, multiple outputs (groups/batches) are generated, and the reward of each output is normalized to its relative value relative to the group mean and used as the advantage. The advantage is calculated solely from the group statistics of the current reward, without the need for cumulative estimates of future rewards or critics. The clipping and (optional) KL terms of the objective function are nearly identical to the PPO, with only the definition of advantage being different.

12.3 PPO vs GRPO

Note

Although the advantage is not as precise as PPO, it offers greater computational efficiency, and as iterations progress, it generally converges to a level similar to or intermediate to PPO. It has been used as a core component in modern LLM training, such as DeepSeek-Math/V3, and is well-suited for LLM environments where memory is a bottleneck and rewards are sparse and binary.

TipWireless Communication Support — CFAR / AGC Normalization

\(\hat A=\dfrac{R-\mu_g}{\sigma_g+\delta}\) is based on the same concept as CFAR detection in radar. Just as the power of a test cell is divided by noise statistics (mean and standard deviation) estimated from surrounding cells to create detection statistics independent of absolute scale, GRPO normalizes the compensation of a single output by the mean and standard deviation of the group to create an advantage of being insensitive to the compensation scale. This is similar to how AGC normalizes signal levels by group statistics, and corresponds exactly in that it normalizes using neighbor/batch statistics without a separate critique.

# Full picture at a glance {#sec-overview}

::: {.callout-tip}
## Key One-Line Summary
Reinforcement learning (RL) is a problem of finding a **policy $\pi$** that maximizes the expected cumulative value of rewards on a mathematical framework called **MDP**. 
If the policy is directly parameterized as $\theta$, the **policy gradient theorem** becomes the fundamental equation of learning, and 
from this, algorithms evolve in the direction of **reducing variance** (baseline, advantage, actor-critic) and **controlling the update range** (TRPO, PPO, GRPO).
:::

The algorithms discussed today all lie on a single lineage. The starting point is **REINFORCE**, which uses the policy gradient as is; **Actor-Critic** emerged to reduce its variance; **TRPO** appeared to address the problem of learning becoming unstable due to overly large updates by binding the confidence domain; **PPO** approximated that complex second-order optimization with simple clipping; and **GRPO** is a version of PPO that completely removed the critic (value network) and replaced the advantage with group statistics.

# The 4 Elements of Reinforcement Learning and Problem Definition {#sec-elements}

## Direct Answer: What RL solves {#sec-elements-answer}

RL is a problem in which an agent interacting with an environment and receiving a **numerical reward signal** learns **action choice rules (policies)** to maximize the accumulation of expected future rewards.

## Four components {#sec-elements-four}

| Element | Symbol | Definition | Role |
|---|---|---|---|
| Policy | $\pi(a\mid s)$ | Mapping from state to action (probability) | Defines the agent's **action itself** |
| Reward | $r$ | A single number given by the environment at each time point | The signal to be maximized ** |
| Value Function (Value) | $v_\pi, q_\pi$ | Accumulation of Expected Future Rewards | **Tool for Estimating** Which Action Is Good |
| Model (Model, Optional) | $p(s',r\mid s,a)$ | Simulation of Environment Dynamics | Environment **Proxy** (Learning possible without) |

::: {.callout-important}
The key point is that the reward is an **exogenous signal from the environment**, and the value function is a **proxy created by the agent**. The policy is updated using the value function as a guide, and while the model simulates the environment to improve sampling efficiency if present (model-based), it learns even without one (model-free). All algorithms discussed today belong to the **model-free** family.
:::

The name "reinforcement" comes from the fact that good state-behavior pairs become increasingly **reinforced** and distinct through repeated interactions. Historically, RL originated from optimal control theory, and with Bellman introducing the states of dynamical systems and value functions (optimal return functions), the **Bellman equations** and **dynamic programming** as their solution emerged. **MDP** is a generalization of this into a discrete, probabilistic version.

# Markov Decision Process (MDP) {#sec-mdp}

## Direct Answer: Why MDP? {#sec-mdp-answer}

To define a learnable agent, a mathematical framework is required to define the behavior of the agent and the environment. Assuming the **Markov property**, the analysis becomes decisively simple because the probability of the next state and reward depends **only on the immediately preceding state and action**.

## Definition and Markov properties {#sec-mdp-def}

For time $t\in\{0,1,2,\dots\}$, state $s\in S$, action $a\in A(s)$, and reward $r\in R$, the environment dynamics are

$$
p(s', r \mid s, a) = \Pr\big(S_{t+1}=s',\, R_{t+1}=r \mid S_t=s,\, A_t=a\big).
$$

Here, the Markov property is that the right-hand side is conditional on **only** one $S_t, A_t$. In other words, the future statistics are determined by looking only at the present point in time, rather than the entire past $(S_0,A_0,\dots,S_{t-1},A_{t-1})$.

::: {.callout-note}
## Episode = Data point
A set of interactions from time point 1 to $T$ $(R_1, R_2, \dots, R_T)$ is called an **episode**, and this is a point of data for training. If the ends are naturally divided, it is an *episodic task*, and if it is a single long flow, it is a *continuing task*.
:::

## Discounted return and goal {#sec-mdp-return}

$$
G_t = \sum_{k=t+1}^{T} \gamma^{\,k-t-1} R_k
    = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots,
\qquad 0 \le \gamma \le 1.
$$

Since uncertainty is greater for future rewards, the weight is reduced using the discount factor $\gamma$. From here, the **recursive form** emerges immediately:

$$
\boxed{\,G_t = R_{t+1} + \gamma\, G_{t+1}\,}
$$

The goal of learning is to maximize the expected return on the policy:

$$
\max_{\pi}\; \mathbb{E}_\pi[G_t].
$$

::: {.callout-tip}
## Wireless communication compatibility — IIR accumulation with forget factor
$G_t = R_{t+1} + \gamma G_{t+1}$ has the same structure as a first-order IIR/exponentially weighted accumulation with a forgetting factor $\lambda$. The closer $\gamma$ is to 1, the further into the future it remembers (long time constant), and the closer it is to 0, the more short-sighted it becomes (short time constant). This plays exactly the same role as the forgetting factor in RLS, which determines how long past errors are reflected.
:::

# Value function and optimal policy {#sec-value}

## Two value functions {#sec-value-two}

$$
v_\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s],
\qquad
q_\pi(s,a) = \mathbb{E}_\pi[G_t \mid S_t = s,\, A_t = a].
$$

The state value $v_\pi$ takes **state only** as input, while the action value $q_\pi$ takes **both state and action** as input. Since it is very difficult to calculate both exactly, they are approximated.

## Optimal Policy {#sec-value-optimal}

$$
v_*(s) = \max_\pi v_\pi(s),
\qquad
q_*(s,a) = \max_\pi q_\pi(s,a).
$$

The optimal policy is usually obtained using the **action value** $q_*$. This is because $q$ takes an action as input, allowing for a direct comparison of which action increases value in that state, whereas $v$ cannot directly capture the effect of an action. In deterministic policies,

$$
\pi_*(s) = \operatorname*{arg\,max}_a q_*(s,a).
$$

::: {.callout-important}
**It appears to optimize to $v$, but internally it uses $q$.** Since the two are connected as $v_\pi(s)=\sum_a \pi(a\mid s)\,q_\pi(s,a)$ in the Bellman equation that follows, the apparent optimization of $v$ is actually reduced to a comparison of $q$.
:::

# Bellman equation: recursive relation {#sec-bellman}

## Direct Answer: What is recursion? {#sec-bellman-answer}

The Bellman equation is a recursive formula that expresses the **value function at the current time step** in terms of the **value function at the next time step**. This recursion is necessary to convert policy iterations into iterative updates.

## $v_\pi$ and $q_\pi$ connection {#sec-bellman-link}

Marginalize state values with respect to behavior:

$$
v_\pi(s) = \sum_{a\in A(s)} \pi(a\mid s)\, q_\pi(s,a)
        \;\le\; \max_a q_\pi(s,a).
$$

The inequality represents the fact that "the expected value cannot exceed the maximum value," and sets an upper limit on policy improvement.

## Recursive expansion of $q_\pi$ {#sec-bellman-q}

Insert the recursion $G_t = R_{t+1} + \gamma G_{t+1}$ returning into the action value definition. The key step is that $G_{t+1}$ can be replaced with $v_\pi(S_{t+1})$ **inside the expectation** (the two are different outside but are the same in terms of conditional expectation):

$$
\mathbb{E}_\pi[v_\pi(S_{t+1}) \mid S_t=s, a] = \mathbb{E}_\pi[G_{t+1}\mid S_t=s, a].
$$

Therefore

$$
q_\pi(s,a) = \mathbb{E}_\pi\big[R_{t+1}+\gamma G_{t+1}\mid s,a\big]
           = \sum_{s',r} p(s',r\mid s,a)\,\big[\,r + \gamma\, v_\pi(s')\,\big].
$$

Substituting this into the $v_\pi$ equation completes the **Belleman expectation equation**:

$$
\boxed{\;
v_\pi(s) = \underbrace{\sum_{a}\pi(a\mid s)}_{\text{에이전트가 하는 일(정책)}}
           \underbrace{\sum_{s',r} p(s',r\mid s,a)}_{\text{환경의 반응(전이·보상)}}
           \big[\,r + \gamma\, v_\pi(s')\,\big]
\;}
$$

::: {.callout-note}
**Structural Analysis (3-step causal chain):** Policy determines the behavior distribution → Environment responds with transitions and rewards → The immediate reward $r$ and the future value of the next state $\gamma v_\pi(s')$ combine to become the present value. The fact that it splits into two separable terms (policy term / environment term) is crucially used in the subsequent Policy Gradient Theorem — the environment term is independent of $\theta$ and is excluded from differentiation.
:::

::: {.callout-tip}
## Wireless Communication Support — Recursive Filter (RLS) Update
$v_\pi(s) = \mathbb{E}[\,r + \gamma v_\pi(s')\,]$ is in the form "current estimate = new observation + discounted next estimate," and is a framework similar to the predict–update recursion of the RLS Kalman filter. It is intuitive if you view $\gamma$ as a stable first-order recursion acting as the state transition gain.
:::

# Policy Repetition and GPI {#sec-gpi}

## Policy Improvement Summary {#sec-gpi-pit}

If we define the new greedy policy as the behavioral value of the current policy $\pi$

$$
\pi'(s) = \operatorname*{arg\,max}_a q_\pi(s,a)
\quad\Longrightarrow\quad
v_\pi(s) \le v_{\pi'}(s).
$$

In other words, if you change the policy to "action that maximizes the current value function," the value never deteriorates.

## Generalized Policy Iteration (GPI) {#sec-gpi-loop}

```{mermaid}
flowchart LR
    P["정책 π"] -->|"평가<br/>(가치 추정)"| V["가치함수 v_π"]
    V -->|"개선<br/>(탐욕적 갱신)"| P
```

By alternately repeating evaluation (value estimation) and improvement (policy update), the optimal policy $\pi_*$ and the optimal value $v_*$ converge. The two processes are a **cooperative iteration** in which they lift each other.

::: {.callout-warning}
## Motivation to transition from GPI limitations to policy gradient
GPI uses a **non-differentiable** greedy operation $\arg\max$. Furthermore, greedy updates can **abruptly** change the policy distribution, causing agent behavior to change drastically in a single step and the learning curve to fluctuate. To train a neural network in a differentiable way, instead of $\arg\max$, the **policy must be parameterized as $\theta$** and updated slowly using gradients. This is the motivation behind the policy gradient method.
:::

# Policy Gradient Modeling (PGM) and Policy Gradient Theorem {#sec-pg}

## Direct Answer: Policy Gradient Theorem {#sec-pg-answer}

If we set the policy to $\pi(a\mid s;\theta)$ and define the objective function as the state value of the starting state $J(\theta)=v_{\pi_\theta}(s_0)$, then (assuming $\gamma=1$) the gradient is

$$
\boxed{\;\nabla J(\theta) \;\propto\; \sum_s \mu(s) \sum_a q_\pi(s,a)\, \nabla \pi(a\mid s,\theta)\;}
$$

where $\mu(s)$ is the **state distribution** induced by the policy (average time ratio of staying in state $s$).

## Meaning of theorem {#sec-pg-meaning}

The gradient of the objective function is decomposed into the product of three elements: the state distribution $\mu(s)$, the action value $q_\pi(s,a)$, and the **gradient of the policy itself** $\nabla\pi$. The key point is that the derivative applies **only to the policy term**, and the environment transition probability $p(s'\mid s,a)$ is independent of $\theta$ and vanishes.

::: {.callout-note}
## Proof Framework (Overview)
1. Substitute the defined ZZZPH0010032ZZZ  $\nabla v_\pi(s)$ into $v_\pi(s)=\sum_a \pi(a\mid s)q_\pi(s,a)$ and apply the **product derivative**: $\nabla(\pi\,q) = (\nabla\pi)q + \pi(\nabla q)$.
2. Since the reward/transition probability within $\nabla q_\pi(s,a)$ is an independent constant $\theta$, the derivative **recursively** passes to the next state $\nabla v_\pi(s')$.
3. If this recursion is expanded repeatedly, it is organized into the form $\nabla v_\pi(s)$ $s$ $x$ $x$ $k$ $\Pr(s\to x,k,\pi)$ $\times\ \nabla\pi(\cdot\mid x)\, q_\pi(x,\cdot)$".
4. Normalizing $\sum_k \Pr(s\to x,k,\pi)$ gives the state distribution $\mu(x)$ — "the average number of times spent in state $s$ in one episode". Substituting this closes the proportion.
:::

::: {.callout-tip}
## Wireless communication support — Adapt only the differentiable part
The environment transition is a channel (fixed probability) that we cannot control, and the policy is the weight that we adapt. The structure in which the channel is excluded from the derivative and only the weight update term remains is a separation configuration similar to an adaptive filter that adapts only the equalizer coefficients while keeping the channel fixed.
:::

# REINFORCE: Monte Carlo Policy Slope {#sec-reinforce}

## Log-derivative trick and update formula {#sec-reinforce-trick}

If we rewrite the policy gradient theorem in terms of expectation

$$
\nabla J(\theta) = \mathbb{E}_\pi\!\Big[\sum_a q_\pi(s,a)\,\nabla\pi(a\mid s,\theta)\Big].
$$

Applying the **score function trick** $\nabla_\theta \ln f = \dfrac{\nabla_\theta f}{f}$ to this results in a sampleable form:

$$
\boxed{\;\theta_{t+1} = \theta_t + \alpha\, G_t\, \nabla \ln \pi(A_t\mid S_t, \theta_t)\;}
$$

Return $G_t$ updates in a direction that increases the log probability of the action that produced a large (good) trajectory.

## algorithm {#sec-reinforce-algo}

::: {.callout-note}
## REINFORCE procedure
- Set the function $\pi(a\mid s;\theta)$ (normal neural network), initial $\theta$, and step size $\alpha$.
- Iteration: **Randomly generate one episode** with the current policy → Calculate $G_t$ at each time point → Update all time points to $\theta \leftarrow \theta + \alpha G_t \nabla\ln\pi(A_t\mid S_t,\theta)$ → Repeat with a new episode.
- Since the gradient is estimated using sample trajectories, it is called **Monte Carlo policy gradient control**.
:::

::: {.callout-warning}
## Weakness of REINFORCE
Because the episodes are rolled randomly until the end to create $G_t$, **sample variance is very large**. Learning is unstable (large policy updates), and sample efficiency and robustness are poor. This is why the learning curve fluctuates and the agent frequently exhibits erratic behavior (falling, stumbling). Reducing this variance is the consistent motivation for the next steps.
:::

::: {.callout-tip}
## Wireless communication support — Noise-heavy slope estimation
$G_t$ is a noisy gradient with large variance, as it is an estimate obtained from a single random realization. Estimating a channel from a single snapshot is equivalent to having large variance, and the baseline subtraction in the next section corresponds to a preprocessing step that reduces the variance of the estimator.
:::

# Reduced Variance: Baseline · Advantage · Actor-Critic {#sec-ac}

## Baseline reduces only variance without bias {#sec-ac-baseline}

The expected value of the gradient does not change even if the **state-only dependent** baseline $b(S_t)$ is subtracted from the expected value (uncomfortable):

$$
\nabla J(\theta) = \mathbb{E}_\pi\big[(G_t - b(S_t))\,\nabla\ln\pi(A_t\mid S_t,\theta)\big].
$$

The reason is $\mathbb{E}_\pi[\,b(S_t)\nabla\ln\pi\,]=b(S_t)\sum_a \nabla\pi = b(S_t)\nabla\!\sum_a\pi = 0$ ($\sum_a\pi=1$).

## Advantage function {#sec-ac-adv}

The natural baseline is the state value $v_\pi(S_t)$. Approximating $G_t$ with a one-step expansion without rolling it all the way results in a **TD error**, and this is precisely the advantage:

$$
\delta_t = R_{t+1} + \gamma\, v_\pi(S_{t+1}) - v_\pi(S_t)
\;\approx\; G_t - v_\pi(S_t) \;=\; A_\pi(S_t, A_t),
\qquad
\nabla J(\theta) = \mathbb{E}_\pi[\delta_t\,\nabla\ln\pi].
$$

Advantage measures "how much better that action is than the average of that state" and reduces variance by converting large fluctuations in absolute rewards into relative values compared to the average.

## Actor-Critic {#sec-ac-actor-critic}

| Configuration | Role | Formula |
|---|---|---|
| Actor(Policy Network) | Decide what action to take | $\pi_\theta(s)$ |
| Critic(Value Network) | Estimate the quality of the behavior | $Q(s,a)$ or $v(s)$, $\delta_t$ |

::: {.callout-note}
**The critic does not directly command the actor but assists them.** Initially, since the policy is immature, the critic is noisy and offers almost no control; however, as iterations progress and the policy improves, the critic's feedback becomes more accurate. This then better constrains the actor's updates, leading to faster and more stable convergence. However, this is merely **indirect normalization**, and there is **no guarantee** that the policy will not change abruptly in a single step. The following confidence domain method is designed to directly provide that guarantee.
:::

::: {.callout-tip}
## Wireless communication support — DC removal / Control variable
Baseline subtraction is a control variate technique that reduces variance by subtracting the mean (DC) before estimation. It is equivalent to estimating only the variation after removing the mean of the signal, which reduces the estimated variance; this effect is evident in the approximately 7-fold reduction (21.8→3.1) in the text verification.
:::

# Confidence Region Method (TRPO) {#sec-trpo}

## Direct Answer: What does it restrict? {#sec-trpo-answer}

Even a single step can cause actor parameters to change rapidly, potentially leading to the breakdown of training. The solution is to bind the update domain using KL divergence to **prevent the new policy from deviating too far from the previous one**:

$$
D_{\mathrm{KL}}\big(\pi_{\theta_{\text{old}}} \,\|\, \pi_\theta\big) \le \epsilon.
$$

## Surrogate Objective Function and Probability Ratio {#sec-trpo-surrogate}

Approximate the $\nabla\ln\pi$ term with a **probability ratio** (a first-order expansion from $\theta_{\text{old}}$ gives the same slope):

$$
r_t(\theta) = \frac{\pi_\theta(a_t\mid s_t)}{\pi_{\theta_{\text{old}}}(a_t\mid s_t)}.
$$

TRPO is for surrogate purposes under constraints

$$
\max_\theta\; \mathbb{E}_t\big[r_t(\theta)\,\hat{A}_t\big]
\quad \text{s.t.}\quad D_{\mathrm{KL}}\le \delta
$$

Maximize . In the unconstrained form, add the KL penalty $-\beta D_{\mathrm{KL}}$ to the objective.

::: {.callout-warning}
## Limitations of TRPO
To accurately handle KL constraints, it is a **complex quadratic method** that requires a second-order approximation of KL (including Hessian), and it is difficult to set the KL penalty coefficient $\beta$ as a fixed value applicable to all problems. This weakness of being computationally heavy is the motivation for moving toward PPO.
:::

::: {.callout-tip}
## Wireless Communication Compatibility — Normalized Step Size Control (NLMS)
KL constraints are analogous to the NLMS concept of normalizing/limiting step sizes to prevent divergence in adaptive updates. Just as steps are reduced to maintain stability when input energy is high, KL constraints pull updates back when the policy is about to jump far, keeping them within a "trusted" area.
:::

# Proximate Policy Optimization (PPO) {#sec-ppo}

## Direct Answer: Clipped line {#sec-ppo-answer}

PPO replaces TRPO's complex KL calculations with a simple operation that **clips** the probability ratios to $[1-\epsilon,\,1+\epsilon]$:

$$
\boxed{\;
L^{\text{CLIP}}(\theta) = \mathbb{E}_t\Big[\min\big(r_t(\theta)\,\hat{A}_t,\;\operatorname{clip}(r_t(\theta),\,1-\epsilon,\,1+\epsilon)\,\hat{A}_t\big)\Big]
\;}
$$

## Clipping behavior {#sec-ppo-clip}

$r_t$ penalizes updates that deviate from 1 (=significant policy changes). Reading the behavior as a result of the body numerical validation:

| Situation | $r_t$ Small | $r_t=1$ | $r_t$ Large |
|---|---|---|---|
| $\hat A>0$ (Good behavior) | Reflected as is | 1.0 | **Upper limit at $1+\epsilon$** (Block excessive amplification) |
| $\hat A<0$ (Bad Behavior) | **Lower limit at $1-\epsilon$** | $-1.0$ | Penalty points as is (Suppression) |

In other words, it prevents the policy from jumping out from both sides by pushing good behavior too hard or pulling bad behavior too hard. Since a KL penalty variation $L - \beta D_{\mathrm{KL}}$ can also be used instead of clipping, PPO can be viewed as a general framework that includes the KL penalty method.

::: {.callout-note}
## Advantages of PPO
- Reusing the same data through stochastic gradient elevation over multiple epochs → Sample efficiency ↑
- Maintain the stability and reliability of the confidence domain method
- Simple implementation (first-order method, calculates only ratio + clip; KL Hessian unnecessary)

Thanks to this simplicity, PPO became the standard tool of **RLHF** and was used as a key tool for fine-tuning instructions in the GPT → InstructGPT → ChatGPT family.
:::

::: {.callout-warning}
There are also clear limitations. It can get stuck in a local optimum, and as clipping accumulates, there remains the possibility that the new policy will eventually become **too far** from the previous policy.
:::

::: {.callout-tip}
## Wireless Communication Support — Feedback Loop Limiter/Grid Clipping
Cutting $r_t$ to $[1-\epsilon,1+\epsilon]$ is equivalent to the amplitude limiter and slope clipping of a feedback loop. It is a protection device that saturates the output to prevent the loop gain from becoming excessive and oscillating, and it is similar in that it is a practical method that ensures stability without complex stability analysis.
:::

# Group-Related Policy Optimization (GRPO) {#sec-grpo}

## Direct Answer: Remove critic + Group normalization {#sec-grpo-answer}

In PPO, advantage calculation (GAE) is expensive because it requires training a separate **critic (value network)** for the baseline. GRPO discards the critic entirely and replaces the advantage with the **relative position of rewards within the group**:

$$
\boxed{\;\hat{A}^{\text{GRPO}}_t = \frac{R - \mu_g}{\sigma_g + \delta}\;}
$$

$R$: Compensation for the corresponding output, $\mu_g$: Group mean compensation, $\sigma_g$: Group standard deviation, $\delta$: A small constant that prevents the denominator from becoming zero.

## Idea {#sec-grpo-idea}

For the same prompt, multiple outputs (groups/batches) are generated, and the reward of each output is normalized to its **relative value relative to the group mean** and used as the advantage. The advantage is calculated solely from the **group statistics of the current reward**, without the need for cumulative estimates of future rewards or critics. The clipping and (optional) KL terms of the objective function are nearly identical to the PPO, with only the **definition of advantage** being different.

## PPO vs GRPO {#sec-grpo-compare}

| Item | PPO | GRPO |
|---|---|---|
| Core Structure | Policy Gradient (Actor-Critic) | Policy Gradient (**Critic-Free**) |
| Advantage | $\hat A_t = R_t - V(s_t)$ (GAE) | $\hat A_t = \dfrac{R-\mu_g}{\sigma_g+\delta}$ |
| Value Network (critic) | **Required** (Separate $V(s)$ training) | **Unnecessary** (Replaced by group statistics) |
| advantage focus | critic value of action versus predicted state value | value of result versus current batch average result $\mu_g$ |
| Advantages | Precise value estimation → Low variance & stability | **Memory & computational efficiency** (critic elimination) |
| Fitting Region | General RL requiring precision value and low variance | **Large-scale LLM RLHF** (Memory bottleneck, sparse/binary reward) |

::: {.callout-note}
Although the  advantage is not as precise as PPO, it offers greater computational efficiency, and as iterations progress, it generally converges to a level similar to or intermediate to PPO. It has been used as a core component in modern LLM training, such as **DeepSeek-Math/V3**, and is well-suited for LLM environments where memory is a bottleneck and rewards are sparse and binary.
:::

::: {.callout-tip}
## Wireless Communication Support — CFAR / AGC Normalization
$\hat A=\dfrac{R-\mu_g}{\sigma_g+\delta}$ is based on the same concept as **CFAR** detection in radar. Just as the power of a test cell is divided by noise statistics (mean and standard deviation) estimated from surrounding cells to create detection statistics independent of absolute scale, GRPO normalizes the compensation of a single output by the mean and standard deviation of the group to create an advantage of being insensitive to the compensation scale. This is similar to how AGC normalizes signal levels by group statistics, and corresponds exactly in that it normalizes using **neighbor/batch statistics** without a separate critique.
:::

# Key Summary {#sec-summary}

::: {.callout-important}
## One Page Cleanup
- **RL = Learning a policy that maximizes the expected cumulative reward over an MDP.** 4 elements: Policy, Reward, Value Function, (Choice) Model.
- The **Bellman equation** provides recursion connecting the present value to the next value, and repeating this is **GPI**.
- Since GPI's $\arg\max$ is non-differentiable and rapidly changing, switch to the **Policy Gradient Theorem** which updates the gradient with $\theta$.
- **REINFORCE** has a direct implementation or **large variance** → variance reduction through baseline, **advantage**, and **Actor-Critic**.
- Rapidly changing instability → **TRPO**(KL constraint, 2nd-order/complex) → **PPO**(Clipping, 1st-order/simple) → **GRPO**(critic removal, group normalization).
- PPO·GRPO is the **core of RLHF**, and GRPO is particularly suitable for **large-scale LLM** with memory bottlenecks.
:::

Key changes in a table:

| Algorithm | Core Idea | What to Add/Remove |
|---|---|---|
| REINFORCE | Monte Carlo Policy Gradient | (Baseline) — |
| Actor-Critic | Dispersion ↓ due to baseline=critic | **critic added** |
| TRPO | Control update width with KL constraint | **Added confidence zone constraint** |
| PPO | Constrained approximation by clipping | **Eliminate second-order KL calculation** |
| GRPO | advantage with group statistics | **remove criticism** |

## PPO Clipping Proxy Purpose {#sec-appendix-ppo}

```{python}
#| label: ppo-clip
def ppo_clip(r, A, eps=0.2):
    """L^CLIP = min( r*A , clip(r,1-eps,1+eps)*A )"""
    return np.minimum(r * A, np.clip(r, 1 - eps, 1 + eps) * A)

ratios = np.array([0.5, 0.9, 1.0, 1.1, 1.5])
print("A>0 (좋은 행동) r:", ratios, "-> L:", np.round(ppo_clip(ratios, +1.0), 3))
print("A<0 (나쁜 행동) r:", ratios, "-> L:", np.round(ppo_clip(ratios, -1.0), 3))
# A>0: r가 1+eps=1.2 위로 가면 상한에서 포화 (과한 증폭 차단)
# A<0: r가 1-eps=0.8 아래로 가면 하한에서 포화
```

## Small REINFORCE training demo (similar to 2-state bandit) {#sec-appendix-reinforce}

```{python}
#| label: reinforce-demo
# 단순 2행동 문제: 행동 1의 기대보상이 더 높음 → 정책이 행동 1로 수렴하는지 확인
rng = np.random.default_rng(1)
theta = np.zeros(2)                 # softmax 로짓
alpha = 0.1
true_reward = np.array([0.2, 0.8])  # 행동별 기대 보상

def softmax(z):
    z = z - z.max()
    e = np.exp(z)
    return e / e.sum()

for step in range(2000):
    p = softmax(theta)
    a = rng.choice(2, p=p)                          # 현재 정책에서 행동 샘플
    G = rng.normal(true_reward[a], 0.1)             # 보상(반환) 샘플
    grad_logpi = (np.eye(2)[a] - p)                 # grad log pi(a)
    theta += alpha * G * grad_logpi                 # REINFORCE 갱신

print("최종 정책 분포:", np.round(softmax(theta), 3))  # 행동 1 확률이 1에 근접
```
