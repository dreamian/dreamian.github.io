Large Language Models (LLMs)

Pre-learning, In-Context Learning, Instruction Tuning, RLHF

Published

May 20, 2026

1 Today’s Big Picture

The Large Language Model (LLM) can be summarized in a single sentence as follows.

“Almost every NLP problem in the world is reducible to next-token prediction, and training on this single task on a sufficiently large scale brings with it emergent abilities.”

This note breaks down how that one sentence is formed in the following order.

  1. Why Scale Determines Performance — Scaling Laws
  2. Why Build a Single Foundation Model — No-Free-Lunch and 80/20 Logic
  3. How all tasks are unified into next-token prediction
  4. How to Change Behavior Without Learning — In-Context Learning, CoT
  5. Alignment — Instruction finetuning, RLHF
NoteOne-line mapping from a wireless communication perspective

LLM is a massive predictive source coder. It predicts the next symbol most plausibly and minimizes its negative log-likelihood. Throughout this note, we continue to use the information-theoretic equivalence that “next token prediction = entropy minimization = compression.”

2 The Age of Scale: Scaling Laws

2.1 Direct answer first

Increasing the number of model parameters \(N\), the number of data tokens \(D\), and the training computation \(C\) causes the test loss to decrease smoothly according to a power law. This is the scaling laws of Kaplan et al. (2020).

2.2 Formula

When the other two resources are not bottlenecks for each of the three variables:

\[ L(N) \approx \left(\frac{N_c}{N}\right)^{\alpha_N},\qquad L(D) \approx \left(\frac{D_c}{D}\right)^{\alpha_D},\qquad L(C) \approx \left(\frac{C_c}{C}\right)^{\alpha_C} \]

Here, the exponents \(\alpha_N,\alpha_D,\alpha_C\) are all very small at the level of \(0.05\!\sim\!0.1\). Taking the logarithm of both sides,

\[ \log L = -\alpha_N \log N + \text{const} \]

That is, it becomes a straight line on the log–log axis.

Tip“A trick to make it look like a rule”

The reason this curve appears as a neat straight line is that (1) it is a power law, so it becomes linear in log–log, and (2) the scales on the graph axis are not evenly spaced. It is closer to a repeatedly observed empirical rule than a law of nature. It is similar in nature to Moore’s Law in semiconductors — rather than a “law,” it is the product of engineering efforts to match that trend.

2.3 Intuition

  • \(\alpha\) is small = diminishing returns are very gradual. Even if you increase resources tenfold, the loss only decreases by \(10^{-\alpha}\approx 0.8\sim0.9\) times, but the key point is that it continues to decrease without stopping.
  • If the data covers almost the entire world, the train loss becomes \(\approx\) test loss, and the generalization performance itself is determined by the scale.
NoteWireless Communication Analogy — Capacity–Resource Trade-off

The power law of the scaling law has the same shape as the rate–distortion curve. As more bits (resources) are used, distortion (loss) decreases monotonically, but marginal utility decreases. Also, if we view \(L\) as “residual uncertainty” and \(N,D,C\) as “input SNR/bandwidth,” the power exponent \(\alpha\) plays a role similar to the channel’s diversity order—it is the slope that determines how quickly the error drops relative to the resources.

2.4 Human vs. LLM: The Data Efficiency Gap

flowchart LR
    A["13세 인간<br/>&lt; 100M 단어"] -->|"~10^4배 격차"| B["대형 LLM<br/>1.4T+ 토큰"]
    A -.다중감각 입력.-> C["시각·청각·촉각·미각<br/>+ 상호작용"]
    B -.텍스트만.-> D["단어의 나열"]

While a 13-year-old human sees fewer than 100 million words in a lifetime, large models see trillions of tokens. Nevertheless, models induce hallucinations. Two interpretations of this gap:

  1. Absence of multisensory information. Humans redundantly learn the same concept through multimodal inputs such as visual, auditory, and tactile senses in addition to words → Motivation leading to VLM/VLA thereafter.
  2. Undiscovered inefficiency. The fact that \(10^4\) times more data is required for the same performance suggests that there is a fundamental inefficiency in the learning algorithm.
ImportantThe precise definition of Hallucination

LLMs do not lie with intention. The objective function of an LLM is merely to “output the most plausible next word under the learning distribution.” The output is incorrect only from a human perspective; it is not incorrect from the perspective of the model’s own statistical objective. Therefore, hallucinations are not “lying” but a natural byproduct of a statistical word predictor.

3 Why Only One Model: Foundation Model

3.1 Direct Answer

Training a single large-scale model costs tens of billions of won. To persuade a financial officer, an argument is needed that “This single model can solve numerous tasks”. A model that serves as the foundation for other models is called a foundation model.

3.2 Conflict with No-Free-Lunch, and its resolution

According to the No-Free-Lunch theorem, there is no single model that is simultaneously optimal for all tasks. If so, is the foundation model a contradiction? The logic for resolving it is as follows.

\[ \underbrace{\text{단일 사전학습 모델}}_{\sim 80\text{–}90\%\ \text{커버}} \;+\; \underbrace{\text{과제별 fine-tuning}}_{\text{나머지 }10\text{–}20\%} \;=\; \text{과제별 전문가 모델} \]

  • The core task (language modeling) is a general metatask shared by almost all subtasks of NLP → 80~90% is handled by a single model.
  • The final touch (maximum performance) is filled in with task-specific fine-tuning → Not contradictory to NFL.

4 All assignments are fill-in-the-blanks

4.1 Key Insights

Seemingly completely different NLP tasks are actually unified into a single format — fill-in-the-blank (predict next token)**.

TipWhy was this a revolution?

“Answering questions = predicting the next word”, “Action plan = predicting the next action token”, “Writing code = predicting the next code token”, “Diagnosis = predicting the prescription token that follows the symptom text”. Since almost all assessments measuring intelligence are ultimately “answering questions”, they are all reduced to a single next-token prediction.

4.2 Formula: Objective function of Language Modeling

The joint probability of the sentence \(x = (x_1,\dots,x_T)\) is decomposed into autoregressive using the chain rule.

\[ p_\theta(x) = \prod_{t=1}^{T} p_\theta(x_t \mid x_{<t}) \]

Learning is the minimization of negative log-likelihood (NLL) = cross-entropy.

\[ \mathcal{L}(\theta) = -\frac{1}{T}\sum_{t=1}^{T} \log p_\theta(x_t \mid x_{<t}) \]

softmax for vocabulary \(V\) at each step:

\[ p_\theta(x_t = v \mid x_{<t}) = \frac{\exp(z_v)}{\sum_{v'\in V}\exp(z_{v'})} \]

The evaluation metric perplexity is \(\mathrm{PPL} = \exp(\mathcal{L})\).

NoteReconfirmation of Cross-Entropy = KL = MLE

Minimizing \(\mathcal{L}\) is identical to minimizing the forward KL \(\mathrm{KL}(p_{\text{data}}\Vert p_\theta)\) between the data distribution \(p_{\text{data}}\) and the model \(p_\theta\), except for the sign and constant; this is precisely MLE. In other words, the essence of LLM pre-training is the equivalence chain we already know — MLE = forward-KL minimization = cross-entropy minimization — itself. Since it is forward KL, mean-seeking (zero-avoiding): probability mass must be applied to every mode the data takes, and this is the reason why it absorbs all diverse representations in massive data.

NoteWireless Communication Analogy — Predictive Encoding and Entropy Rate

Next-token prediction is exactly the same as predictive coding (DPCM/entropy coding) in communication. It predicts the next symbol of the source using a conditional distribution, and the mean of that NLL is an estimate of the source’s entropy rate \(H(\mathcal{X})\). The cross-entropy \(\ge H\) and the equality holds when \(p_\theta = p_{\text{data}}\) — that is, a perfect language model is equivalent to an optimal lossless compressor. Perplexity is the “effective branching factor,” which is the effective alphabet size indicating how many symbols are selected on average.

5 Learning Without Learning: In-Context Learning (ICL)

5.1 Direct Answer

In-Context Learning is a prompt engineering technique that modifies model behavior by inputting a task demonstration in natural language into a prompt, without updating any parameters (no gradient, no parameter update).

5.2 “How is that learning?”

If we view the operational definition of learning as a change in input–output mapping:

\[ \text{학습 전: } x \mapsto y_{\text{before}}, \qquad \text{학습 후: } x \mapsto y_{\text{after}}, \qquad y_{\text{before}} \neq y_{\text{after}} \]

In ICL, the weights \(\theta\) remain the same, but the output changes when the context (demonstration/system prompt) changes. Since the output changes for the same core input, it is called “learning.”

flowchart LR
    U["사용자 입력 x"] --> AUG["+ system prompt<br/>+ demonstrations(context)"]
    AUG --> LLM["LLM (θ 고정)"]
    LLM --> Y["출력 y (context에 의해 달라짐)"]
NoteWireless Communication Analogy — Pilot-based Adaptive Equalization

A demonstration example of ICL is like pilot symbols. The receiver (LLM) does not retrain the weights (hardware) but estimates the channel from the pilots in the preamble and adapts the detection rule on the fly. A few-shot example from the prompt allows the “current task channel” to be estimated, and the main question (data symbol) is decoded accordingly. The fact that the decision boundary changes but the circuit remains the same accurately captures the essence of ICL.

6 Emergent Ability

6.1 Definition

Emergent ability is the ability that suddenly appears when the model size exceeds a certain threshold, even without intentional training.

6.2 Evidence: Word unscrambling task

If you look at string restoration tasks such as cyclic-letter, anagram, random-insertion, and reversed-word in the GPT-3 family:

  • Most tasks: Gradual performance increase with scale (consistent with scaling law).
  • Random insertion: \(\sim\) Up to 6.7B, in the range of almost 0 → 6.7B → 13B → 175B, suddenly jumps to the 70% range.

This discontinuous jump is a typical sign of emergent ability.

NoteWireless Communication Metaphor — Waterfall Area

Let’s recall the BER–SNR curve of the LDPC/Turbo sign. Below the critical SNR, the error hardly decreases, but the moment it exceeds the threshold, the BER plummets like a waterfall. The sharp jump in emerging ability is a phase transition phenomenon similar to this waterfall transition. When the magnitude (SNR) exceeds the critical point, the ability (reliability) turns on non-linearly.

7 Chain-of-Thought (CoT) and Variants

7.1 Few-shot CoT

If intermediate reasoning steps are solved and presented as a demonstration instead of just showing the answer, the model mimics that reasoning chain and the accuracy rate increases (Wei et al., 2022).

Q: ... (문제)
A: 먼저 ...이므로 ... 따라서 ... = 11.  답은 11.    ← 중간 단계를 펼친 시연
Q: ... (새 문제)
A: (모델이 단계별로 따라 생성)

7.2 Zero-shot CoT: “Let’s think step by step”

Step-by-step reasoning is induced simply by adding the line “Let’s think step by step” to the prompt without even needing a demonstration (Kojima et al., 2022). Such a sentence is called a trigger prompt.

TipKey Implications

It is possible to gain +60%p with a single line of prompt, without a dataset, GPU, or parameter updates. Inference capability is already latent within the model; the trigger prompt merely draws it out. It is also possible to let the model explore the optimal trigger prompt on its own.

7.3 Self-Consistency CoT

The same question is asked multiple times to the same model. Since the model performs stochastic sampling, it produces slightly different inference paths \(r^{(m)}\) and answers \(a^{(m)}\) each time. The majority vote of those answers is selected as the final answer (“sample-and-marginalize”).

\[ \hat{a} = \arg\max_{a}\ \sum_{m=1}^{M} \mathbb{1}\!\left[a(y^{(m)}) = a\right] \;\approx\; \arg\max_{a}\ \sum_{r} p_\theta(a, r \mid x) \]

That is, the latent inference path \(r\) is marginalized in Monte Carlo to collect probability masses that reach the same answer even if the paths are different.

7.4 Tree of Thoughts (ToT)

Inference is executed as a tree rather than a linear chain. At each node, the model is asked “What is the confidence level for this answer?” to assign weights, and the tree is traversed to synthesize the final answer.

NoteWireless Communication Analogy — Diversity Combination

Self-consistency is repetition coding + majority combining, or more precisely, diversity combining (MRC/selection) of multiple independent paths. A single decoding (inference path) is susceptible to noise, but combining independent trials increases the effective SNR and averages out errors, thereby improving confidence. The confidence weighting in ToT corresponds to MRC (maximal-ratio combining), which weights based on the confidence of each path.

7.5 (Note) Jailbreaking / Trigger Prompt

By inserting specific trigger phrases (e.g., code header patterns), it is possible to induce an output close to the training data, thereby causing training-data retrieval. This phenomenon arises from the nature of next-token prediction reproducing the training distribution exactly, and is treated as a risk in terms of security and privacy.

8 Alignment I: Instruction Finetuning

8.1 Direct Answer

**If you fine-tune a pre-trained model by collecting (instruction, answer) pairs from various tasks, it generalizes zero-shot to tasks that were not in training (Wei et al., 2022, FLAN). This is a method of alignment.

8.2 structure

\[ \mathcal{D}_{\text{IFT}} = \big\{(\text{instruction}_i,\ \text{output}_i)\big\}_{i=1}^{K\ \text{tasks}} \]

Example) “Answer the following question: What is the boiling point of nitrogen? → −320.4 °F”. Even after fine-tuning with numerous tasks not directly related to the goal task to be solved, the performance of the target task improves — another emergent phenomenon.

Definition (Wei et al.): Instruction tuning is the process of fine-tuning an instruction model with a set of tasks described by instructions to improve the zero-shot performance of unseen tasks.

8.3 limit

  1. Tasks with no single correct answer. Open-ended generation, such as “Write a story about a puppy and its pet grasshopper,” has no unique correct answer, making the supervised learning signal ambiguous.
  2. Penalty all token errors equally. Language modeling uses token-level cross-entropy, which penalizes all incorrect tokens with the same weight. However, some tokens (“Yes/No”) are much more important than others → Mismatch between the objective function (LM) and the true goal (satisfying human preferences).

9 Alignment II: RLHF

9.1 Synchronous

To bridge the discrepancy above, human preference must be incorporated as an explicit signal. One can evaluate whether “this conversation was satisfactory” only after the entire conversation has concluded; this is not a token-based map but a delayed scalar reward. This structure is solved using reinforcement learning → RLHF (Reinforcement Learning from Human Feedback).

9.2 Pipeline

flowchart LR
    G["GPT-3<br/>(사전학습 LM)"] --> SFT["Instruction FT<br/>(InstructGPT의 SFT)"]
    SFT --> RM["보상모델 r_φ 학습<br/>(인간 선호 비교 데이터)"]
    RM --> RL["정책 최적화 (PPO)<br/>r_φ 최대 + KL 제약"]
    RL --> C["ChatGPT"]

9.3 Formula: KL-Normalized Reward Maximization

Policy \(\pi_\theta\) maximizes the expected reward of the reward model \(r_\phi\), but a KL penalty is applied so that it does not deviate too far from the reference policy \(\pi_{\text{ref}}\) (usually an SFT model).

\[ \max_{\theta}\ \mathbb{E}_{x\sim\mathcal{D},\, y\sim\pi_\theta(\cdot\mid x)} \Big[\, r_\phi(x, y) \;-\; \beta\, \mathrm{KL}\!\big(\pi_\theta(\cdot\mid x)\,\Vert\,\pi_{\text{ref}}(\cdot\mid x)\big) \Big] \]

NoteDirectionality of KL term (Connected to HW#4)

Here, KL is \(\mathrm{KL}(\pi_\theta \Vert \pi_{\text{ref}})\) — the policy being learned is the first argument. This is in the form of reverse KL, implying a mode-seeking / zero-forcing tendency: it strongly suppresses the policy from leaking into regions where the reference distribution is near zero (preventing reward hacking), but is not obligated to cover all modes of the reference. PPO/GRPO reliably optimizes this objective with clipped policy gradients.

NoteWireless Communication Analogy — Closed-loop Feedback Adaptation

RLHF is equivalent to closed-loop adaptive control. Pre-training is the open-loop transmitter, and human feedback is the feedback channel that updates the transmission strategy, such as the receiver’s ACK/quality report. The KL penalty acts as a power constraint or trust-region—limiting the update width to prevent the system from diverging. Just as closed-loop power control aligns the SINR to a target value, RLHF aligns the model output to human preference.

11.1 A.1 Next-token softmax and cross-entropy / perplexity

import numpy as np

def softmax(z):
    z = z - z.max()                      # 수치 안정화 (overflow 방지)
    e = np.exp(z)
    return e / e.sum()

# 어휘 크기 5에 대한 한 스텝 로짓과 정답 토큰
logits = np.array([2.0, 1.0, 0.5, -1.0, 0.2])
target = 0                                # 정답 토큰 인덱스

p = softmax(logits)
ce = -np.log(p[target])                   # 단일 스텝 cross-entropy (NLL)
print("p:", np.round(p, 4))
print("cross-entropy:", round(float(ce), 4))

# 시퀀스 평균 NLL과 perplexity
nlls = np.array([0.31, 1.20, 0.05, 2.10])  # 토큰별 NLL 예시
avg_nll = nlls.mean()
ppl = np.exp(avg_nll)                       # PPL = exp(평균 NLL) = 유효 분기계수
print("avg NLL:", round(float(avg_nll), 4), "| perplexity:", round(float(ppl), 4))

11.2 A.2 Check Forward-KL = cross-entropy − entropy

import numpy as np

p_data  = np.array([0.5, 0.3, 0.15, 0.05])   # 데이터 분포
p_model = np.array([0.4, 0.3, 0.2,  0.1])    # 모델 분포

H_data = -(p_data * np.log(p_data)).sum()                 # 데이터 엔트로피 (하한)
CE     = -(p_data * np.log(p_model)).sum()                # cross-entropy
KL_fwd =  (p_data * np.log(p_data / p_model)).sum()       # forward KL

print("H(data) :", round(float(H_data), 4))
print("CE      :", round(float(CE), 4))
print("KL_fwd  :", round(float(KL_fwd), 4))
print("CE - H  :", round(float(CE - H_data), 4), "(== KL_fwd 이어야 함)")
# 결론: cross-entropy 최소화 == forward KL 최소화 == MLE  (상수 H(data) 차이)

11.3 A.3 Self-consistency: Valid accuracy increases with majority vote

import numpy as np
rng = np.random.default_rng(0)

def single_pass_correct(p_correct):
    """한 번의 추론 경로가 정답일 확률 p_correct 인 베르누이 시도."""
    return rng.random() < p_correct

def self_consistency_accuracy(p_correct, M, trials=20000):
    """M개 경로 다수결의 정확도를 몬테카를로로 추정.
       오답은 여러 잘못된 답으로 분산된다고 단순 가정."""
    wins = 0
    for _ in range(trials):
        correct_votes = sum(single_pass_correct(p_correct) for _ in range(M))
        # 오답표는 (M - correct_votes)표가 서로 다른 답으로 흩어진다고 가정
        # => 정답표가 1표 이상이면서 최다이면 승리 (보수적 근사)
        wins += 1 if correct_votes * 2 > M else 0
    return wins / trials

p = 0.40                                  # 단일 경로 정확도 40%
for M in [1, 3, 5, 11, 21]:
    acc = self_consistency_accuracy(p, M)
    print(f"M={M:2d}: majority-vote accuracy ≈ {acc:.3f}")
# 직관: 단일 경로가 우연보다 낫기만 하면, 경로 수 M↑ 에 따라 정확도가 향상
#       (다이버시티 결합으로 유효 신뢰도 상승)

11.4 A.4 Log–log Linearity of Scaling Law

import numpy as np

# L(N) = (Nc / N)^alpha  형태의 멱법칙
Nc, alpha = 1e8, 0.076
N = np.array([1e6, 1e7, 1e8, 1e9, 1e10])
L = (Nc / N) ** alpha

logN, logL = np.log10(N), np.log10(L)
slope = (logL[-1] - logL[0]) / (logN[-1] - logN[0])   # log-log 기울기
print("log-log slope:", round(float(slope), 4), " (이론값 -alpha =", -alpha, ")")
# 결론: 멱법칙은 log-log 축에서 기울기 -alpha 의 직선으로 나타난다.
