Transformers

Tokens, Attention, and Positional Encoding

Deep Learning
Sequence Modeling
Attention
Published

April 28, 2026

Introduction

Since being proposed in Attention is All You Need by Vaswani et al. in 2017, the Transformer has become the standard backbone in almost every area of deep learning, ranging from NLP, vision, speech, and reinforcement learning . This document breaks down the Transformer into three core ideas — token, attention, and positional encoding — and organizes the information by answering the structural question of “why this structure is superior to RNN/CNN.”

TipWireless Communication Intuition One-Line Summary

Attention is adaptive beamforming, Positional Encoding is pilot symbols, and Multi-head is MIMO multi-beam. This correspondence is explained in detail throughout the text.

1 Two Intrinsic Difficulties of Sequence Modeling

Unlike fixed-length snapshot data such as images and graphs, sequence data (language, speech, video, time series) must solve the following two problems simultaneously.

Problem Description
Long-term dependency A distant token determines the meaning of the current token
Context Even the same token can have different meanings depending on the surrounding context

“Buffalo buffalo Buffalo buffalo buffalo buffalo Buffalo buffalo.” — A grammatically correct English sentence consisting of 8 identical words. The meaning is entirely Depends on context.

RNN attempted to solve these two problems through sequential updates of the hidden state, but - Vanishing gradient: Information from a distance is lost during the BPTT process - Sequential Processing: Cannot be parallelized, inefficient GPU utilization

The Transformer bypasses this limitation with attention that views the entire sequence at once.

2 First core idea: Token

2.1 From neuron to token

The basic unit of existing neural networks was the neuron, which has a scalar value. The Transformer elevates the unit by one level and treats vectors as the unit.

\text{Neuron: } x \in \mathbb{R}, \qquad \text{Token: } \mathbf{t} \in \mathbb{R}^{d}

A token is an “encapsulated bundle of information.” A single token contains all multidimensional attributes, such as meaning, location, and context.

NoteRelationship with GNN

a node feature or node attribute in Graph Neural Networks is a token in the Transformer world. They are essentially the same data structure.

2.2 How to tokenize input

Input Type Tokenization Method
Image Cropped into 16×16 patches and projected each patch as a vector (ViT)
Language Split into word/subword units and embedding
Audio Project spectrogram slice of a constant window as a vector

project each chunk onto a fixed-dimensional vector **.

2.3 Linear combination of tokens and .z notation

A linear combination of neurons is a scalar weighted sum:

x_\text{out} = \sum_{i=1}^N w_i \, x_{\text{in}_i}

Linear combinations of tokens are essentially the same, but the notation differs because the unit is a vector:

t_\text{out}.\mathbf{z} = \sum_{i=1}^N w_i \, t_{\text{in}_i}.\mathbf{z}

Important.z Meaning of the notation

.z is an indexing notation pointing to a specific element of a token vector. In other words, the above formula means “The z-th element of the output token is the weighted sum of the z-th elements of the input tokens”, which explicitly reveals that the same weight w_i is applied to all elements .

Rewritten in vector notation, it is simple: \mathbf{t}_\text{out} = \sum_{i=1}^N w_i \, \mathbf{t}_{\text{in}_i}

This element-wise identical weight structure exactly matches the weighted sum of the values in attention.

3 Second key idea: Attention

3.1 Limitations of CNN: Locality Bias

CNNs are built on the locality assumption. k \times k kernels always look only at adjacent pixels:

y_{ij} = \sum_{p=-k}^{k}\sum_{q=-k}^{k} w_{pq} \cdot x_{i+p,\, j+q}

This causes inherent difficulties in two tasks:

  • Global Counting: “How many birds are in the image?” — The entire patch must be integrated
  • Long-distance relationship: “Are the bird in the bottom left and the bird in the top right the same species?” — Two far apart area must be directly compared

To establish long-distance relationships, you must stack layers deeply to expand the receptive field, but information becomes diluted in this process.

TipWireless Communication Intuition

The locality of CNN is equivalent to local cooperation where only nearby antennas cooperate. On the other hand, attention is cooperative MIMO where the entire cell shares CSI — any two nodes directly exchange information without distance constraints.

3.2 Weight vs. Attention: Static vs. Dynamic

The structural core of Transformer excellence can be summarized in a single line:

ImportantCore

General weights are fixed after training, but attention weights are generated in real-time based on the input.

When compared using the formula:

\text{일반 Weight: } y = \sum_i \underbrace{w_i}_{\text{고정}} \cdot x_i \qquad \text{Attention: } y = \sum_i \underbrace{\alpha_i(\mathbf{x})}_{\text{입력의 함수}} \cdot v_i

w_i is a point in the parameter space \Theta, but \alpha_i is the output of the function produced by the parameters . This one-step meta-fication gives rise to all the superiority of the Transformer.

3.2.1 Three capabilities created by dynamic weights

3.2.1.1 Context-dependent representation

Even the same token must have different expressions depending on the context.

"배가 고프다"  → 배 = 복부
"배가 떠난다"  → 배 = 선박
"배를 먹었다"  → 배 = 과일

With a fixed weight, “pear” always produces the same output. Since Attention changes \alpha_j depending on surrounding tokens (“hungry”, “leaves”, “ate”), the representation itself changes. This is the essence of contextual embedding.

3.2.1.2 Adaptive receptive field

operates flexibly as follows depending on the data :

Situation Attention Behavior
Simple declarative Focus on adjacent tokens (effectively local)
long-range demonstrative pronoun long-range jump as antecedent
Counting task Reference all tokens evenly

Same model, same parameters, but behavior changes depending on the data.

3.2.1.3 Learned routing

The separation of Q, K, and V makes “who asks what to whom” learnable:

\underbrace{Q}_{\text{무엇을 찾나?}} \cdot \underbrace{K^\top}_{\text{무엇을 갖고 있나?}} \;\to\; \underbrace{\alpha}_{\text{누구한테 얼마나?}} \;\to\; \underbrace{\alpha V}_{\text{수집 결과}}

TipWireless Communication Intuition
  • Fixed weight = Fixed beamforming: Beam direction is predetermined
  • Attention = Adaptive Beamforming: Readjusts the beam direction at every moment based on the channel state (input).

Just as the beamforming weights \mathbf{w}^*(\mathbf{h}) are a function of the channel \mathbf{h}, the attention score \alpha_i(\mathbf{x}) is a function of the input \mathbf{x}.

3.3 Self-Attention: View as Matrix Operation

For the input token matrix \mathbf{T}_\text{in} \in \mathbb{R}^{N \times d} (N tokens, each dimension d):

\mathbf{Q} = \mathbf{T}_\text{in}\mathbf{W}_q^\top, \quad \mathbf{K} = \mathbf{T}_\text{in}\mathbf{W}_k^\top, \quad \mathbf{V} = \mathbf{T}_\text{in}\mathbf{W}_v^\top

Split each token into query/key/value vectors using three trainable projection matrices \mathbf{W}_q, \mathbf{W}_k, \mathbf{W}_v .

The attention matrix and output are:

\mathbf{A} = \text{softmax}\!\left(\frac{\mathbf{Q}\mathbf{K}^\top}{\sqrt{m}}\right), \qquad \mathbf{T}_\text{out} = \mathbf{A}\mathbf{V}

where m = d_k (dimension of the key vector).

NoteWhy divide into \sqrt{d_k}

If the variance of \mathbf{Q}\mathbf{K}^\top increases in proportion to d_k, the softmax shifts toward extreme values and the gradient disappears. Dividing by \sqrt{d_k} to keep the variance near 1 is the key to learning stability.

3.3.1 Meaning Interpretation

Self-attention is “an operation that refines its own representation by considering neighboring tokens”. It can be viewed as a process where a patch looks at its surrounding patches and re-determines “which part of the dog I am.”

Let’s look at a VQA (Visual Question Answering) example:

Query Where Attention Focuses
“How many animals?” All patches containing animals (uniformly distributed)
“What color is the impala?” Focus only on the Impala patch

Even with the same image, the attention distribution changes dynamically depending on the query. This is why attention is called “query-based dynamic pooling.”

3.4 Masked Attention

A variant that blocks a specific token from seeing other tokens:

\text{MaskedAttn}(\mathbf{Q},\mathbf{K},\mathbf{V}) = \text{softmax}\!\left(\frac{\mathbf{Q}\mathbf{K}^\top + \mathbf{M}}{\sqrt{d_k}}\right)\mathbf{V}

Mask \mathbf{M} inserts -\infty at the location to be blocked — after softmax it becomes 0 and is completely blocked.

Most common use: causal mask in decoders. Since looking at future tokens in autoregressive generation is cheating, all positions j > i are masked.

M_{ij} = \begin{cases} 0 & j \leq i \\ -\infty & j > i \end{cases}

3.5 Multi-Head Self-Attention (MHSA)

With a single (Q, K, V) projection, it is easy to learn only one relationship pattern. Therefore, multiple heads are operated in parallel:

\text{MultiHead}(Q,K,V) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h)\mathbf{W}^O

Each head has its own (\mathbf{W}_q^{(i)}, \mathbf{W}_k^{(i)}, \mathbf{W}_v^{(i)}) and calculates attention in a different subspace.

TipWireless Communication Intuition: MIMO Beamforming

The h heads are h independent beams. Each beam is beamformed in a different direction (subspace) to simultaneously capture various channel states. The reason why multi-head attention is more expressive than general attention is exactly the same as the reason why multi-beams have higher angular diversity than single beams .

It is also interesting in terms of interpretability — analyzing the learned heads reveals specialization where some heads establish grammatical relationships, others semantic relationships, and still others positional relationships .

4 Third Key Idea: Positional Encoding

4.1 The trap called Permutation Equivariance

Pure self-attention is permutation equivariant:

F_\theta(\text{permute}(\mathbf{T}_\text{in})) = \text{permute}(F_\theta(\mathbf{T}_\text{in}))

In other words, shuffling the token order simply shuffles the output in the same way, without any loss of information. Put another way, attention alone ignores order information.

This means that the result of shuffling the image patch and the original are encoded with the same expression , which is a fatal problem in languages where “I love you” and “I love you” have the same expression.

4.2 Solution: Directly inject location information into the input

Add a unique vector for each position pos:

\text{PE}_{(pos, 2i)} = \sin\!\left(\frac{pos}{10000^{2i/d_\text{model}}}\right), \quad \text{PE}_{(pos, 2i+1)} = \cos\!\left(\frac{pos}{10000^{2i/d_\text{model}}}\right)

Final input: \mathbf{x}_\text{input} = \mathbf{x}_\text{embed} + \text{PE}.

4.2.1 Advantages of Sinusoidal PE

  • Extrapolability: Provides reasonable positional representations even for long sequences never seen during training
  • Relative Position Encoding: \text{PE}_{pos+k} as a linear transformation of \text{PE}_{pos} Representable → Model easily learns relative distance
  • Scale Variety: Vibrating at different frequencies per dimension → From short distances to long distances Capturing various patterns
TipWireless Communication Intuition: Pilot Symbol

is essentially the same as the receiver in OFDM inserting pre-agreed pilot symbols into a specific subcarrier to estimate the channel .

  • Pilot = A pre-known pattern that differs for each location
  • PE = Deterministic sin/cos pattern that varies by location

Just as the receiver estimates the channel with a pilot, the Transformer estimates “where this token came from” with a PE.

5 Overall Architecture Summary

Now, combine the three ideas to complete the Encoder-Decoder structure of the original paper.

5.1 Data Flow

Inputs
  └→ Input Embedding + Positional Encoding
       └→ [Encoder Block × N]
            ├ Multi-Head Self-Attention → Add & Norm
            └ Feed Forward          → Add & Norm
            ⇒ Encoder Output (다른 모든 디코더 블록의 K, V 공급원)

Outputs (shifted right)
  └→ Output Embedding + Positional Encoding
       └→ [Decoder Block × N]
            ├ Masked MH Self-Attention   → Add & Norm
            ├ Cross-Attention (Q←dec, K,V←enc) → Add & Norm
            └ Feed Forward               → Add & Norm
            ⇒ Linear → Softmax → Output Probabilities

5.2 Meaning of Nx: Deep stacking

\mathbf{h}^{(l)} = \text{TransformerBlock}(\mathbf{h}^{(l-1)}), \quad l = 1, \ldots, N

The original paper was N=6, but modern LLMs have increased to N=96 (GPT-3) or higher. As the layers deepen, the representation becomes increasingly abstract:

Layer Representation being learned
Sub- (1~2) Lexical, Grammatical Patterns
Infix (3~5) Syntactic dependency, cross-reference
Upper (6~N) Semantics, Inference, Task-Specific Patterns

5.3 Add & Norm: Residual Linking and Normalization

Each sublayer is wrapped in the following form:

\mathbf{x}' = \text{LayerNorm}(\mathbf{x} + \text{SubLayer}(\mathbf{x}))

  • Residual connection (\mathbf{x} +): acting as a gradient highway Enables the learning of deep networks (ResNet principle). Also guarantees that original information is not lost.
  • Layer Normalization: Ensures training stability by normalizing at the token level. Unlike batch norm, it does not rely on inter-sample statistics, so it is suitable for variable-length sequences and RNN-like processing.

\text{LayerNorm}(\mathbf{x}) = \boldsymbol{\gamma} \odot \frac{\mathbf{x} - \mu}{\sigma + \epsilon} + \boldsymbol{\beta}

5.4 Feed Forward Network (FFN)

2-layer MLP applied independently to each token:

\text{FFN}(\mathbf{x}) = \max(0, \mathbf{x}\mathbf{W}_1 + \mathbf{b}_1)\mathbf{W}_2 + \mathbf{b}_2

Dimensional change: d_\text{model} \to d_{ff} \to d_\text{model} (usually d_{ff} = 4 d_\text{model}).

NoteDivision of roles between Attention and FFN
  • Attention: Information exchange between tokens — whose information to retrieve and how much
  • FFN: Non-linear transformation inside the token — how to process the imported information

The essence of a Transformer block is that these two are stacked alternately.

5.5 Cross-Attention: Legs of Encoder ↔︎ Decoder

The decoder’s second attention takes the query from the decoder, and the key/value from the encoder:

\mathbf{Q} = \mathbf{H}_\text{dec}\mathbf{W}_q, \quad \mathbf{K} = \mathbf{H}_\text{enc}\mathbf{W}_k, \quad \mathbf{V} = \mathbf{H}_\text{enc}\mathbf{W}_v

This single line determines “where in the input sequence the decoder will refer when generating output tokens.” In translation, the mechanism automatically learns a natural soft alignment, such as attending to the English word “love” when producing the corresponding target word.

5.6 Meaning of “Outputs (shifted right)”

Teacher forcing method learning:

Target:  <BOS>  나는  밥을  먹었다  <EOS>
입력:    <BOS>  나는  밥을  먹었다       (마지막 제외)
출력:    나는   밥을  먹었다  <EOS>      (첫 토큰 제외)

During training, the decoder predicts the next token by taking previous correct answer tokens as input. During inference, since there are no correct answers, it feeds back the previous predicted token (autoregressive).

6 MLP vs Transformer Comparison

Item MLP Transformer (vanilla)
Basic unit Neuron (Scalar) Token (Vector)
Inter-token operation linear (all inputs → all outputs) self-attention (learned dynamic routing)
In-token operation ReLU (neuron-wise) MLP (token-wise)
Weight nature Fixed after training Recalculated every time depending on input
Sequential processing Different weights per position Permutation equivariant + PE

Transformer can essentially be viewed as a structure that inserts attention instead of the linearity of an MLP. Attention bypasses the limitations of a static structure created by a linear transformation into a dynamic structure.

7 Application: Language Model and GPT

7.1 Definition of Language Model

Modeling the probability distribution of the next word given the previous words:

P(w_t \mid w_1, w_2, \ldots, w_{t-1})

Approximately fixed window assumption:

P(w_t \mid w_{t-n}, \ldots, w_{t-1})

As the scale increases, Large Language Model (LLM) — GPT, Claude, HyperCLOVA X, etc.

7.2 GPT: Decoder-only Transformer

GPT(Generative Pretrained Transformer) is a structure that uses only the decoder part of the original paper.

  • Remove Encoder, Remove Cross-attention
  • Use only causal masked self-attention
  • Pre-training with next token prediction

\mathcal{L} = -\sum_t \log P(w_t \mid w_{<t}; \theta)

The key finding of the GPT series is that training a massive corpus with this simple learning objective leads to emergent zero-shot/few-shot generalization ability.

NoteminGPT

Andrej Karpathy’s minGPT is an educational implementation of GPT in about 300 lines. It is useful for seeing how the concepts in the text map to code.

8 Limitations and Follow-up Research

8.1 Computational complexity

The time/space complexity of self-attention for sequence length n is:

O(n^2 \cdot d)

This is because it calculates the similarity of all token pairs. If the length is n=10{,}000, 100 million pairs are required.

8.2 Absence of external Windows information

Information outside the window (context length) is completely invisible. While RNNs can theoretically handle infinite lengths (though in practice they cannot due to vanishing), Transformers have hard constraints.

8.3 Direction of follow-up research

Classification Representative Technique Key Idea
Sparse Attention Longformer, BigBird Calculate only some token pairs
Linear Attention Performer, Linformer O(n) with kernel tricks
Long-context FlashAttention Practical acceleration with memory IO optimization
RNN-Transformer Hybrid Mamba (SSM) State-space model O(n) + Infinite Context

9 Summary

ImportantOne-page summary

Three Key Ideas

  1. Token: Elevate the basic unit of data from a scalar neuron to a vector token
  2. Attention: Between tokens using dynamic weights that are recalculated every time based on the input Routing information. QKV separation, scaled dot-product, multi-head, causal mask detailed design
  3. Positional Encoding: at each position to break permutation equivariance Add another deterministic signal to the input

The Core of Structural Superiority

General weights are fixed in the parameter space, but the attention score is a function of the input. w_i \in \Theta instead of \alpha_i = f_\Theta(\mathbf{x}). This one step of meta-ization, context-dependent representation, adaptive receptive field, produces all three superiorities known as learned routing.
