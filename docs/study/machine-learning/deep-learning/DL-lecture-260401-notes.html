Important5 Key Points Directly Related to the Exam
  1. CE vs MSE Gradient Comparison: \(\sigma'(z)\) is multiplied to the MSE gradient, but not to the CE gradient. Since \(\sigma'(z) \le 0.25\), MSE exacerbates the vanishing gradient — one must be able to write the differentiation process directly.
  2. Softmax is not simple normalization: Unlike L1 normalization, it is magnitude sensitive and amplifies the gap between the max and non-max values. Remember the numerical examples as well.
  3. Gumbel Softmax: Argmax is non-differentiable → End-to-end learning is possible using a reparameterization trick that adds Gumbel noise. The key property is that \(\text{argmax}(\text{logit} + \text{Gumbel noise})\) follows a softmax distribution.
  4. ReLU Generalized Formula Distinguish the 4 variations (ReLU / Absolute Value Static / Leaky / PReLU) based on the values from \(h_i = \max(0, z_i) + \alpha_i \min(0, z_i)\) to \(\alpha_i\).
  5. Bayesian Interpretation of Regularization: MAP \(= \log p(\theta) + \log p(\mathcal{D}|\theta)\) = Regularizer + MLE loss. L2 ↔︎ Gaussian prior, L1 ↔︎ Laplace prior.

2 Why Cross Entropy: Gradient Comparison with MSE

2.1 Problem Settings

Let’s consider a single sigmoid output unit.

\[ \hat{y} = \sigma(z), \qquad z = w^\top x + b, \qquad \sigma(z) = \frac{1}{1+e^{-z}} \]

Compare the gradients of two loss functions for the same model.

2.2 Slope of MSE

\[ L_{\text{MSE}} = \frac{1}{2}\left(y - \sigma(z)\right)^2 \]

Differentiating using the chain rule:

\[ \frac{\partial L_{\text{MSE}}}{\partial w} = \underbrace{(\sigma(z) - y)}_{\text{오차}} \cdot \underbrace{\sigma'(z)}_{\text{문제의 항}} \cdot \, x \]

2.3 Gradient of CE (Binary Classification)

\[ L_{\text{CE}} = -\left[ y \log \sigma(z) + (1-y)\log(1 - \sigma(z)) \right] \]

If we use \(\frac{d}{dz}\log\sigma(z) = 1 - \sigma(z)\), \(\sigma'(z) = \sigma(z)(1-\sigma(z))\), the \(\sigma'(z)\) term cancels out and disappears:

\[ \frac{\partial L_{\text{CE}}}{\partial w} = (\sigma(z) - y) \cdot x \]

WarningCausal Mechanism Chain (Essential Structure for Essay Answers)

Ending with “CE is good” will result in a deduction. You must write the entire following chain:

  1. The derivative of the sigmoid is \(\sigma'(z) = \sigma(z)(1-\sigma(z))\), the maximum value is at \(z=0\) and \(0.25\), and as \(|z|\) increases, it converges exponentially to 0 (saturation).
  2. Since \(\sigma'(z)\) remains as a multiplication factor in the MSE gradient, the gradient becomes almost 0 even if the error is large when the neuron is in the saturation region.
  3. When stacking layers, the local gradients of each layer are multiplied sequentially during backpropagation, so the factor \(\le 0.25\) is multiplied by the number of layers, and the gradient near the input layer becomes virtually zero (vanishing gradient).
  4. Therefore, parameters near the input layer are hardly updated from their initial values, so learning does not proceed.
  5. On the other hand, since the \(\sigma'(z)\) factor is eliminated for CE, the gradient is directly proportional to the error \((\sigma(z)-y)\); therefore, as predictions become incorrect, it receives a larger gradient, resulting in faster learning and mitigated vanishing.

2.4 Statistical Justification of CE: Equivalence with Bernoulli MLE

The pmf of the Bernoulli distribution is \(P(y) = q^y (1-q)^{1-y}\). The log-likelihood for the iid sample \(\{y_i\}_{i=1}^N\) is:

\[ \log \mathcal{L}(q) = \sum_{i=1}^{N} \left[ y_i \log q_i + (1-y_i)\log(1-q_i) \right] \]

Maximizing this is exactly the same as minimizing the CE. That is, CE minimization = Bernoulli maximum likelihood estimation in logistic regression.

NoteCaution regarding iid summation (prevention of floating-point pattern A)

Do not stop after writing only the single-sample form \(y\log q + (1-y)\log(1-q)\). In MLE derivation problems, you must first write the form aggregated over the entire data using \(\sum_{i=1}^N\) (log-likelihood) or \(\prod_{i=1}^N\) (likelihood).

2.5 Summary: Two reasons to prefer CE

Perspective Content
Practical Less slope vanishing due to the absence of the \(\sigma'(z)\) factor in the MSE slope
Theoretical Equivalent to the negative log-likelihood (NLL) of Bernoulli / Multinoulli distributions — Statistically principled loss

MSE is natural for regression (\(f^*(x) = \mathbb{E}[y|x]\), conditional mean prediction), while MAE learns a function to predict the conditional median. It is still widely used for simple problems.

3 Output Units

A unit that generates an output (probability or value) in the last layer. It corresponds 1:1 with the assumption of the output distribution.

Output Unit Formula Corresponding Output Distribution Application
Linear \(\hat{y} = W^\top h + b\) Gaussian: \(p(y|x) = \mathcal{N}(y; \hat{y}, I)\) regression
Sigmoid \(\hat{y} = \sigma(w^\top h + b)\) Bernoulli Binary Classification
Softmax \(\text{softmax}(z)_i = \dfrac{e^{z_i}}{\sum_j e^{z_j}}\) Multinoulli (Multi-class extension of Bernoulli) Multi-class

Here, \(z = w^\top h + b\) is called logit.

WarningThe Trap of Sigmoid Output

If a sigmoid is applied to each of the 10-dimensional outputs, each dimension takes on the value \([0,1]\), but the sum is not 1. In other words, it is not a probability distribution but “appears like unnormalized probability.” Normalizing it by taking the exponent results in softmax.

3.1 Softmax is more than normalization

The essence is revealed when compared to L1 normalization (values verified by direct calculation):

Input L1 Normalization Softmax
\([1, 2]\) \([0.333, 0.667]\) \([0.269, 0.731]\)
\([10, 20]\) \([0.333, 0.667]\) \([0.0000454, 0.99995]\)
  • L1 normalization preserves only ratios — \([1,2]\) and \([10,20]\) are the same.
  • Softmax is magnitude sensitive — the larger the absolute difference, the closer it amplifies the max to 1.
  • That is, softmax is an operation that takes the max softly: it is not a deterministic argmax, but amplifies the gap while maintaining it in a differentiable form.
  • Practical Benefit: The amplified probability gap leads to an amplified gradient, making learning easier.
TipWireless Communication Perspective: Soft Decision vs Hard Decision

The relationship between softmax and argmax is exactly the same as the relationship between a receiver’s soft decision vs. hard decision. Argmax is a hard decision that immediately confirms a symbol and discards information (reliability), whereas softmax is a soft decision that preserves the reliability of each candidate, similar to LLR. Just as passing LLR to the channel decoder improves performance, a differentiable softmax is required for backpropagation.

4 Gumbel Softmax: Makes argmax differentiable

4.1 Synchronous: End-to-end connection between two networks

Let’s assume that we want to connect the discrete output (softmax + argmax) of neural network A as the input to neural network B.

A representative application is the Robotics Foundation Model: Network A determines high-level actions (“Go to the door,” “Go to the refrigerator”), while Network B generates fine-grained actions (maintaining an appropriate distance to grasp the doorknob, turning the handle, pulling). To perform end-to-end learning of the entire model from input to output, all intermediate operations must be differentiable for backpropagation to pass.

The problem is:

  • softmax: infinitely differentiable ✓
  • argmax: Cannot be differentiated as it is an index selection operation ✗ — Backpropagation stops here

4.2 Solution: Add noise to convert to sampling

\[ \text{(기존)} \quad p_i = \frac{\exp(z_i)}{\sum_j \exp(z_j)}, \qquad y_i = \begin{cases} 1 & i = \text{argmax}_j\, p_j \\ 0 & \text{otherwise} \end{cases} \]

\[ \text{(Gumbel Softmax)} \quad y_i = \frac{\exp\!\left(\dfrac{z_i + g_i}{\tau}\right)}{\sum_{j=1}^{k} \exp\!\left(\dfrac{z_j + g_j}{\tau}\right)} \]

  • \(g_i\): Noise sampled from a Gumbel distribution
  • \(\tau\): Temperature hyperparameter — The smaller the value, the closer it is to one-hot; the larger the value, the closer it is to a uniform distribution.

4.3 Why the Gumbel distribution of all things?

The PDF of the Gumbel distribution is \(f(x) = e^{-(x + e^{-x})}\) (in the form of an exponent inside an exponent). Key property:

ImportantGumbel-Max Trick (Key Properties)

If Gumbel noise is added to the logit and then argmax is applied, the result follows the distribution identical to sampling from a softmax distribution:

\[ \text{argmax}_i (z_i + g_i) \sim \text{Categorical}\left(\text{softmax}(z)\right) \]

That is, the deterministic argmax is reinterpreted as sampling of a random variable, and if that sampling process is continuous with the softmax formula (\(y_i\) above), the whole becomes differentiable. This technique of making something non-differentiable differentiable is called the reparameterization trick, and this special case using the Gumbel distribution is called the Gumbel-Max trick.

4.4 Application

  • End-to-end training of a single model connecting two networks via cascade
  • Variational Autoencoder (VAE) control of discrete latent variables — VAE is the foundation of modern generative AI (GAN is also based on VAE architecture), and is more widely used in foundation models such as VLA (Vision-Language-Action) these days than when it was proposed in 2017 (Jang et al., Maddison et al., ICLR 2017).
TipWireless Communication Perspective: Modulators in Learnable Communication Systems

In end-to-end learned communication systems based on autoencoders, the transmitter’s constellation mapping is discrete selection and therefore non-differentiable. To directly minimize BER by combining the transmitter and receiver into a single neural network, this discrete selection must be relaxed to be differentiable, and the standard tool used for this is Gumbel Softmax. Additionally, the reparameterization trick plays the same role when making the quantization layer of CSI feedback compression (CsiNet family) learnable.

5 Activation Functions

5.1 Candidates

Function Formula Range Characteristics
Logistic Sigmoid \(\sigma(z)\) \((0,1)\) Smooth and infinitely differentiable, but severe vanishing gradient in \(\sigma' \le 0.25\)
Hyperbolic Tangent \(\tanh(z)\) \((-1,1)\) Similar to sigmoid but with different curvature; better accuracy depending on the application — the choice between the two is determined by application/experimentation, not intrinsic superiority
ReLU \(\max(0, z)\) \([0,\infty)\) The standard of modern deep learning; contributes to vanishing gradient mitigation and catastrophic forgetting mitigation

5.2 First Impressions and Twist on ReLU

ReLU is a “futilely simple” function that is linear in the positive range and kills negative values to zero. In a single layer, it appears to provide almost no non-linearity between input and output. However, when stacking multiple layers, the non-linearity between input and output becomes exponentially complex. It is preferred over sigmoid/tanh because it ensures sufficient expressiveness even with simple activation if the depth is sufficient, while simultaneously having the decisive advantage of minimal vanishing gradients.

5.3 Generalizations and Variations of ReLU

There are also applications where negative input information is important. Since vanilla ReLU kills all negative numbers, a generalized formula is:

\[ h_i = \max(0, z_i) + \alpha_i \min(0, z_i) \]

\(\alpha_i\) Result Remarks
\(0\) ReLU Completely block negatives
\(1\) Linear unit Activation vanished (no non-linearity)
\(-1\) Absolute value rectification: \(h_i = |z_i|\) Folding a negative number into a positive
\(0.01\) (small positive) Leaky ReLU “Leaks” negative information
Trainable Parameter PReLU (Parametric ReLU) \(\alpha\) Learn from itself as data — The philosophy of “Let’s learn everything we can”

Maxout is also a variation of the same spirit (taking the maximum of several linear functions).

5.4 Intuitive Justification: Space Folding

Using Absolute Value Rectification \(h = |z|\) causes the input space to fold in half. When simple (nearly linear) classification boundaries are learned in the folded space and then unfolded, they become much more complex boundaries in the original space.

  • Fold 1 → Double boundary complexity effect
  • \(n\) folds (= \(n\) hidden layer cascade) → exponentially complex classification boundary

In other words, since depth exponentially amplifies complexity even if the activation of each layer is simple, deep neural networks can encode very complex classification boundaries. This is the justification for “simple activation + deep structure”.

6 Gradient Vanishing

6.1 mechanism (causal chain)

  1. Backpropagation in deep neural networks is multiplying the local gradients of each layer by the chain rule.
  2. If the magnitude of the local gradient is in the \([0,1]\) interval (especially a value sufficiently smaller than 1), the magnitude of the gradient decreases exponentially with each passing layer.
  3. Even if the magnitude of the gradient at the output layer is sufficiently large, it becomes almost 0 by the time it reaches the input layer.
  4. If the gradient magnitude is close to 0, the update amount in \(w \leftarrow w - \eta \nabla_w L\) is close to 0.
  5. Therefore, parameters near the input layer hardly change from the initial state, and no matter how much training progresses, that layer cannot learn → learning efficiency becomes extremely low, so a mechanism to greatly increase the number of iterations or amplify the gradient is required, but amplification amplifies even the noise in the gradient.

6.2 Effects by activation function

Activation Local Gradient Result
Sigmoid Max \(0.25\) (at \(z=0\)), in the saturation region \(\approx 0\) \(0.25\) repeatedly multiplied → severe vanishing
ReLU Exactly in the positive range \(1\) \(1 \times 1 \times \cdots\) → The magnitude of the gradient in the output layer is transmitted alive to the input layer

This is the biggest reason why ReLU is preferred in deep networks.

TipWireless Communication Perspective: SNR Degradation of Multi-Hop Relays

The local gradient multiplication at each layer is equivalent to the channel gain multiplied at each hop in a multi-hop relay. If the gain at each hop is less than 1 (attenuation), the received signal weakens exponentially as the number of hops increases — this corresponds exactly to how an amplify-and-forward relay amplifies noise along with the signal, and how gradient boosting amplifies gradient noise. ReLU preserves the signal magnitude like a regenerative (decode-and-forward) relay with a gain of exactly 1.

7 Catastrophic Forgetting

7.1 Definition

Knowledge about a previously learned task (Task A) tends to be abruptly lost as information related to the current task (Task B) is integrated (McCloskey and Cohen, 1989)

7.2 Occurrence mechanism in mini-batch learning

  1. Train a fixed-size network in mini-batches: Update parameters with Batch 1 → Update with Batch 2 → ⋯
  2. Immediately after training Batch 1, the loss for Batch 1 is nearly 0 (well trained).
  3. However, the slopes of subsequent batches continue to overwrite the same set of parameters. There is no barrier/protector.
  4. Even parameters independent of a specific batch will change significantly when accumulated millions of times, as long as the slope is not exactly 0 (e.g., \(10^{-6}\)).
  5. When looking at Batch 1 as the epoch nears its end, the loss has risen again — information from the initial batch has been forgotten. In the case of a 5,000-unit mini-batch, information from the early batches of the epoch is almost forgotten by the time of the last mini-batch.

7.3 Why It Is “Cataclysmic” — Two Causes

Cause Explanation
Absence of Protection A fixed set of parameters is shared and overwritten by all data; there is no mechanism to say “Do not touch this parameter”
Insufficient Capacity If the amount of data > network capacity, old data must be deleted to insert new data. To put 2MB of data onto a 500KB storage device, the only option is to overwrite — only the last data inserted remains.

7.4 Relationship with multi-epoch learning

There is no winning theory yet regarding “why run multiple epochs?” One of the leading hypotheses is catastrophic forgetting: because reviewing the same data multiple times mitigates forgetting. In practice, it is empirically known that multiple epochs provide a better model.

7.5 Derived concept

  • Continual Learning: A scenario where data is viewed only once and passed through as a stream (review is impossible). It is an environment where forgetting is most severe and is a subfield of machine learning. The smaller the model (the less capacity it has), the more severe the problem.
  • Aspects of the Era of Large Models: Models with massive parameters, such as LLM/VLA, can “seep” information into the spare parameter space, making forgetting relatively less severe. In other words, the forgetting problem takes on a different aspect in the realm of large models.
TipWireless Communication Perspective: Time-varying Channel Tracking of Adaptive Filters

The LMS/RLS adaptive equalizer intentionally forgets past information using a forgetting factor \(\lambda\) to track time-varying channels. The catastrophic forgetting of neural networks is akin to a situation where data order is enforced without being able to control this forgetting factor. Furthermore, the logic that “if information amount > capacity, overwriting is unavoidable” can be interpreted as a stored version of Shannon’s theorem, which states that error-free transmission is impossible at transmission rates exceeding channel capacity.

8 Two questions in network design

8.1 Q1. How deep should it be?

In multi-digit transcription tasks, increasing the number of layers raises accuracy from 92% → 95% → 96%, but the rate of increase gradually slows down. The name of this phenomenon:

NoteDiminishing Returns

A phenomenon in which marginal gain decreases as inputs (number of layers, number of parameters) increase. Most phenomena in nature follow this pattern. (Equivalent to diminishing marginal utility in Korean)

8.2 Q2. How many parameters should there be?

Increasing the number of parameters can lead to performance actually declining beyond diminishing returns, or fluctuating without a consistent trend. Causes for each:

Phenomenon Cause
Performance degradation If parameters are excessive relative to the amount of data, overfitting — fits the training data but fails to generalize
Irregular fluctuations The test set is merely a sample of the world and therefore cannot perfectly represent the world → Ups and downs caused by local noise are a natural phenomenon

8.3 Conclusion

There is no general answer to the question of “how many layers and parameters are optimal.” It all depends on the application, the dataset, and the architecture. This non-obviousness is why machine learning engineers are needed.

9 Convergence of Backpropagation

9.1 From convex to non-convex

Model Solution Space Convergence Guarantee
Single-layer Perceptron + Logistic Regression Loss Convex Gradient Descent Guarantees Reaching Global Minimum
Perceptron layer 2 or higher (from the point where XOR solving is possible) Non-convex Gradient descent can get stuck at a local minimum

9.2 Determinants of the solution space

The solution space is determined by the combination of loss function definition × dataset. If the loss is changed from logistic regression to CE, or if the data changes from 100 to 1000, the solution space itself changes.

WarningTest Trap: “Multiple solutions = non-convex” is not true

The basis for non-convexity is the structural fact that “the objective function loses convexity due to multilayer composition,” not the observation that there are multiple solutions (convex functions can also have multiple sets of minimums). Furthermore, since it is virtually impossible to search the entire high-dimensional solution space, gradient descent operates based solely on local information and settles at a local minimum.

9.3 Results and History

  • The selection of the number of hidden units and layers is a hyperparameter — since there is no guarantee of convergence, human intervention is required to find a good local solution.
  • Neural networks lagged behind SVMs for over 10 years due to the lack of convergence guarantees: SVMs guaranteed convergence through convex optimization, had robust generalization theory (made stronger by kernel tricks), and did not require multiple epochs of training. However, SVMs were inherently shallow models with limited capacity (even with kernels), and high-capacity neural networks defeated SVMs in 2012 with AlexNet.
  • The reason for using convex optimization tools (gradient-based methods) even knowing that the objective function is non-convex: Because there is no mathematically guaranteed better alternative. Convex optimization techniques remain the most reliable tools for finding good local minima, even in non-convex spaces.
NoteAs a side note, a memorable metaphor

The problem of finding a good local solution is similar to many life decisions (e.g., finding a spouse) — since exploring the entire solution space is NP-hard, we look for a good local minimum within a constrained search space (my city, my school). And if we expand the search space, a better local solution almost certainly exists — the probability that the current solution is the global optimal is very low.

10 Regularization (Regularizer)

10.1 General form of the learning objective function

\[ \min_\theta \;\; \underbrace{L(\theta)}_{\text{Loss}} + \underbrace{\Omega(\theta)}_{\text{Regularizer}} \]

  • Loss: Target for minimization. Reliability decreases if data is insufficient (coin toss example — MLE is unstable if the sample size is small).
  • Regularizer \(\Omega\): As an inductive bias, it acts as guidance (prior information) to prevent overfitting under the premise that training data is always insufficient.
  • Design Principle: Normalization terms should be designed to minimize. If a quantity is meaningful only when maximized, invert the sign and insert \(-\Omega\).

10.2 Hard Constraint vs Soft Constraint

Hard constraint — Optimization with constraints:

\[ \min_\theta L(\theta) \quad \text{s.t.} \quad \theta \in \mathcal{H} \qquad \text{예: } \|\theta\|_2^2 \le r^2 \]

Since a solution is infeasible if it is outside the set, constraint satisfaction must be checked every time, and it is generally difficult to solve. Constraints can be applied to the parameter space rather than the function space (since neural networks are defined by parameters).

Soft constraint — Absorbed as penalty term:

\[ \min_\theta \; L(\theta) + \lambda \|\theta\|_2^2 \]

ImportantEquivalence of two forms (Lagrangian)

There exists a normalization parameter \(\lambda^* > 0\) such that hard-constraint optimization is equivalent to soft-constraint optimization — this is the Lagrange multiplier method. The difference: hard guarantees that the solution is inside the ball, whereas soft “guides to keep the size from becoming excessive” without such guarantee. The soft form is much easier to solve because it is an unconstrained optimization.

The name “penalty” implies that penalties are imposed to ensure the model does not have a large magnitude when optimization is finished. This principle of favoring simple models is Occam’s razor, and it is in the same context as what we saw in the 13th-order polynomial overfitting example — everything is connected.

10.3 L1, L0 Penalty and Sparsity

Sparse vector: A vector in which most of the components are zero (vs. dense vector: non-zero values in almost every dimension). “How many zeros must there be to be sparse” is somewhat subjective, like the distinction between a beautiful flower and a non-beautiful one.

Penalty Effect Bayesian Interpretation Optimization Difficulty
\(\ell_2\): \(\|\theta\|_2^2\) Size suppression (weight decay) MAP with Gaussian prior Easy (differentiable)
\(\ell_1\): \(\|\theta\|_1\) encourage sparsity — not guaranteed MAP with Laplace prior NP-hard but approximate exists → can be solved with gradient-based tools
\(\ell_0\): Number of non-zero components force scarcity — rarer year — NP-hard, combination optimization — virtually impossible to optimize directly
WarningTest Trap: encourage vs force

\(\ell_1\) only induced sparsity, not guaranteed it. \(\ell_0\) enforced sparsity, but it is difficult to solve because it is a combinatorial optimization. The reason \(\ell_1\) is the practice standard is that it is a tractable approximation of \(\ell_0\). (Caution regarding definition inversion — Real pattern C)

10.4 Bayesian perspective: Regularizer = Prior

Bayes’ Theorem:

\[ p(\theta \mid \{x_i, y_i\}) = \frac{p(\theta) \, p(\{x_i, y_i\} \mid \theta)}{p(\{x_i, y_i\})} \]

  • \(p(\theta)\): prior regarding the hypothesis (parameter) — an assumption about the model/parameter, which translates to a constraint on the parameter.
  • \(p(\{x_i,y_i\} \mid \theta)\): likelihood
  • Denominator: Normalization constant (partition function)

Taking the logarithm and using MAP makes the structure transparent:

\[ \max_\theta \; \log p(\theta \mid \{x_i, y_i\}) = \max_\theta \; \underbrace{\log p(\theta)}_{\text{Regularizer}} + \underbrace{\log p(\{x_i, y_i\} \mid \theta)}_{\text{MLE loss}} \]

That is, from a Bayesian perspective, the normalization term is the prior, and the loss term is the likelihood. The solution optimized together with the normalization term becomes the MAP solution.

TipWireless Communication Perspective: MMSE vs. Sparse Channel Estimation (Review and Integration)
  • \(\ell_2\) Normalization = Gaussian prior MAP ↔︎ MMSE Channel Estimation (Gaussian prior to channel coefficients; the prior suppresses noise amplification in LS estimation)
  • \(\ell_1\) Normalization = Laplace prior MAP ↔︎ Sparse Channel Estimation for mmWave/Massive MIMO (LASSO/OMP; prior indicating a small number of paths in the delay-angle domain)
  • \(\ell_0\) ↔︎ The problem of restoring accurate sparse support — even in compressed sensing, \(\ell_0\) is NP-hard, so it is exactly the same logic as using \(\ell_1\) Convex Relaxation (Basis Pursuit).
  • It is also the same that the role of the prior (normalization) becomes greater as the data (pilot) becomes scarce.

11 Regularization techniques for deep learning

Traditional normalization was a hand-crafted prior, but deep learning with an end-to-end philosophy prefers a data-driven normalization method.

11.1 Dataset Augmentation

The fundamental motivation behind normalization is to combat the lack of training data. The easiest but most expensive solution is to “collect more data”—but if budget is limited, create new, fake data that represents the data while retaining its semantics.

  • Image: Affine distortion, noise injection, axis deformation, flip, translation, color change — pixels change, but same class
  • Text: Word Variations — Ensuring sentence diversity through synonyms/variants like “trash can” ↔︎ “recycle bin”, “chair” ↔︎ “sofa”

11.2 Adversarial Examples

Neural networks are prone to having solutions that are overfitted to the training data, so the output can be manipulated by microscopic noise invisible to the human eye.

  • Classic example: panda image (57.7% confidence) + fine noise → 99.3% confidence misclassification as gibbon. This is because the noise pattern triggers an internal statistical/response corresponding to a different semantic.
  • Safety-related case: If a few stickers are attached to a STOP sign, the autonomous vehicle’s vision model mistakes it for a speed limit sign → it does not stop. An attack actually demonstrated in early neural network-based autonomous driving.

Utilization as defense and normalization — Two methods:

Method Content
Method 1: Noise in Input Generate adversarial examples and retrain with correct labels (“This is also a panda”) → The model becomes robust to adversarial perturbations (adversarial training; the primary purpose is security, but it also has the effect of general regularization)
Method 2: Noise on output target = Label Smoothing Smooth one-hot targets: \(1 \to 1-\epsilon\), \(\;0 \to \dfrac{\epsilon}{k-1}\) (\(\epsilon\): small value, \(k\): number of classes). Prevents overconfidence like “98% pandas, 2% gibbon” to induce less overfitted solutions (Szegedy et al., CVPR 2016)
WarningLabel Smoothing formula memorize

\(k\)-In class, the correct dimension is \(1-\epsilon\) and the incorrect dimension is \(\epsilon/(k-1)\). Verify that the sum is exactly \(1\): \((1-\epsilon) + (k-1)\cdot\frac{\epsilon}{k-1} = 1\).

TipWireless Communication Perspective: Minimum Power Target Jamming

Adversarial perturbation is similar to smart jamming, where an attacker who knows the receiver’s decision boundary pushes symbols beyond the boundary with minimum power — it is identical in that it is efficient to push only in a direction perpendicular to the boundary rather than using broadband noise (a waste of power). And label smoothing corresponds to techniques like LLR clipping, which gain robustness by limiting overconfidence.

11.3 Remaining Data-Driven Normalization Techniques (Detailed in the next note)

Semi-supervised learning (unlabeled data = normalized information), Multi-task learning, Early stopping, Parameter sharing/tying (\(\|B-A\|_2^2\) minimization), Bagging/Ensemble, Dropout, Tangent propagation. This is followed by optimization methodologies (Momentum, initialization, adaptive learning rate, BatchNorm, etc.).

13 1-Minute Cheat Sheet

  • CE slope \(=(\sigma(z)-y)x\), MSE slope \(=(\sigma(z)-y)\sigma'(z)x\). \(\sigma'_{\max}=0.25\).
  • CE Minimize ≡ Bernoulli Log-likelihood \(\sum_i [y_i\log q_i + (1-y_i)\log(1-q_i)]\) Maximize.
  • Sigmoid Multidimensional output sums are not 1 → Exponential normalization results in softmax.
  • Softmax is size sensitive: the results of \([1,2]\) and \([10,20]\) are different (L1 regularization is the same).
  • Gumbel-Max trick: \(\text{argmax}(z_i+g_i)\) ~ softmax distribution; a type of reparameterization trick; temperature \(\tau\).
  • \(h_i=\max(0,z_i)+\alpha_i\min(0,z_i)\): \(\alpha=0\) ReLU, \(-1\) Absolute Value, \(0.01\) Leaky, Learning PReLU.
  • Folding \(n\) times → Boundary complexity exponential increase.
  • Vanishing Gradient: Local Gradient (\(\in[0,1]\)) Chain Product → Input Layer Gradient \(\approx 0\); ReLU multiplies by 1.
  • Catastrophic forgetting: unprotected parameter sharing + insufficient capacity; multiple epochs are a mitigation (no definitive theory); extreme scenario = continual learning.
  • Depth/parameter: Diminishing returns; Over-parameters → Overfitting; Fluctuations in test accuracy are because the test set is also a sample.
  • Perceptron (convex, global solution guaranteed) vs MLP (non-convex, local solution); Solution space = Loss × Dataset; lagging behind SVM for over 10 years → 2012 AlexNet.
  • \(\min L + \Omega\); hard ↔︎ soft constraints are equivalent to \(\lambda^*\) (Lagrangian); \(\ell_1\) inductive/\(\ell_0\) enforced (NP-hard).
  • MAP \(= \log p(\theta) + \log p(\mathcal{D}|\theta)\) = prior(normalization) + MLE.
  • Label smoothing: \(1\to1-\epsilon\), \(0\to\epsilon/(k-1)\).

14.1 CE vs MSE Slope Comparison

import numpy as np
import matplotlib.pyplot as plt

z = np.linspace(-8, 8, 400)
sig = 1 / (1 + np.exp(-z))
y = 1.0  # 정답 라벨

grad_mse = np.abs((sig - y) * sig * (1 - sig))  # |∂L/∂z|, x=1 가정
grad_ce  = np.abs(sig - y)

fig, ax = plt.subplots(1, 2, figsize=(11, 4))
ax[0].plot(z, sig * (1 - sig))
ax[0].axhline(0.25, ls='--', c='gray')
ax[0].set_title(r"$\sigma'(z)$ — max 0.25 at z=0")
ax[0].set_xlabel("z")

ax[1].plot(z, grad_mse, label="|MSE grad|")
ax[1].plot(z, grad_ce, label="|CE grad|")
ax[1].set_title("y=1일 때 기울기 크기: 포화 영역(z≪0)에서 MSE는 죽는다")

plt.tight_layout(); plt.show()

14.2 Size Sensitivity of Softmax vs L1 Regularization

def softmax(x):
    e = np.exp(x - np.max(x))
    return e / e.sum()

for v in ([1., 2.], [10., 20.]):
    v = np.array(v)
    print(f"input={v},  L1={v/v.sum()},  softmax={softmax(v)}")

14.3 Empirical verification of the Gumbel-Max trick: The empirical distribution of argmax(logit+Gumbel) = softmax

rng = np.random.default_rng(0)
logits = np.array([2.0, 1.0, 0.5])
N = 200_000

g = rng.gumbel(size=(N, 3))                  # 표준 Gumbel 노이즈
samples = np.argmax(logits + g, axis=1)      # Gumbel-Max 샘플링
emp = np.bincount(samples, minlength=3) / N

print("softmax(logits) :", np.round(softmax(logits), 4))
print("empirical freq  :", np.round(emp, 4))

14.4 Variations of the ReLU generalized formula

def gen_relu(z, alpha):
    return np.maximum(0, z) + alpha * np.minimum(0, z)

14.6 Label Smoothing

def label_smooth(onehot, eps):
    k = len(onehot)
    return np.where(onehot == 1, 1 - eps, eps / (k - 1))

t = np.array([0, 0, 1, 0, 0])
print("original :", t)
sm_t = label_smooth(t, eps=0.1)
print("smoothed :", sm_t, "  sum =", sm_t.sum())
