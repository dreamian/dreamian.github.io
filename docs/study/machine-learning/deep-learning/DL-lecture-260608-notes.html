M2177.003100 — Deep Learning

Published

June 8, 2026

One-line Map: A well-prepared LLM is (1) aligned to human preferences (RLHF·Alignment), (2) efficiently adapted with few parameters (PEFT), (3) reduced illusions using external knowledge (RAG), (4) task completion using external tools/behaviors (Agents), and (5) planned/simulated by modeling the world itself (World Models). This note organizes these five axes using mathematical formulas, intuition, and wireless communication analogies.

1 RLHF — Reinforcement Learning from Human Feedback

1.1 Motivation: Why instruction finetuning alone is insufficient

Direct Answer. Instruction finetuning optimizes the language modeling objective function, but what we actually want is to satisfy human preferences. There is an objective mismatch between the two.

NoteRecap — Instruction Finetuning

When a pre-trained LLM is further fine-tuned by grouping various tasks into “instruction–answer” pairs, zero-shot performance is improved even on unseen tasks that were not directly used for training (Wei et al., Finetuned Language Models Are Zero-Shot Learners, ICLR 2022). Although formally called “fine-tuning,” in reality it is closer to a procedure of pre-training the model with a wide range of tasks to improve generalized response capabilities.

Two inherent limitations of instruction finetuning:

# Limit Description Example
1 Task with no correct answer Open-ended generation has no single correct answer or single metric → Cannot generate instruction–answer pairs themselves “Write a story about a puppy and its pet grasshopper”
2 Equal Punishment for Token Errors Language modeling loss punishes all token errors equally, but some errors are more fatal In “The current US president is ___“, errors in the name token are much more fatal than errors in particles or conjunctions

Key Insight: The objective of language modeling (\(\max \log p(\text{next token})\)) does not directly care about “user satisfaction.” It merely outputs the next token with high probability, and how much that response satisfies humans is not included in the objective function. → “Can’t we include human preference as an explicit objective?” is the starting point of RLHF.

1.2 3-stage structure of RLHF

Direct Answer. RLHF = Establish a starting point with SFT → Train a reward model with preference data → Fine-tune LLM to RL using that reward.

  • Step 1 — SFT Starting Point: Build a base model that produces a plausible response using instruction finetuning.
  • Step 2 — Feedback Collection: When the LLM generates two responses for a single prompt, a human evaluates which one is preferred using a Likert scale (strongly better ↔︎ slightly better) or ranking. (There is an anecdote that OpenAI hired a large number of linguistics and humanities majors, rather than engineering majors, and paid them high wages to perform labeling.)
  • Step 3 — Reward Model + RL: Train a reward model with preference data, and fine-tune the LLM using reinforcement learning with that reward as a signal.
TipHistorical Context — Learning to summarize (NeurIPS 2020)

In initial experiments (Stiennon et al.), for the same prompt, the vanilla LM output was mechanical, such as repeating the same words, but the output of the model injected with lightweight human feedback became natural, as if written by a human. After confirming this effect, a three-stage pipeline was established to advance the GPT-3 family from InstructGPT to ChatGPT.

1.3 Reward Model and Bradley–Terry Loss

Direct Answer. The reward model is trained with a loss that increases the difference between the two rewards so that the reward for the chosen response becomes greater than the reward for the rejected response.

Add a new final layer (preferred head) on top of the base model and minimize the following loss:

\[ L_{\text{RM}} \;=\; \log\!\Big(1 + e^{\,r_{\text{rejected}} - r_{\text{chosen}}}\Big). \]

This is identical to the Bradley–Terry / Logistic Preference Model. If set to \(\sigma(z)=\frac{1}{1+e^{-z}}\)

\[ L_{\text{RM}} = -\log \sigma\!\big(r_{\text{chosen}} - r_{\text{rejected}}\big), \]

That is, it is the negative log-likelihood (binary cross-entropy) of the “probability that ‘chosen’ beats ‘rejected’”. (In Appendix Section 8, the numerical equivalence of the two forms is verified using SymPy.)

NotePractical Details
  • Single 1 epoch training (intentional overfitting).
  • Human evaluation mutual agreement rate is typically at the 65–75% level — reward signals are inherently noisy. This leads to the need for KL normalization later on (Section 1.5).
  • Variations that add margin (difference in strength between options) to the loss are common.

1.4 RLHF + PPO-Clip from an RL Perspective

Direct Answer. LLM = Policy, Output Token String = Action, Reward Model = Environmental Reward. Optimize this with PPO-Clip.

RL Concept Correspondence in RLHF
Agent / Policy \(\pi_\theta\) LLM in Learning
Action Response generated by LLM (Token string)
Environment reward Output of reward model trained on human preferences
Episode One prompt → completion

Note: Whether RLHF is “deep” depends not on the framework, but on whether a neural network is used for the policy/value function. Both deep and shallow are possible with the same RL frame.

for each iteration:

    2. 보상 모델로 각 completion 의 reward 계산

It is not necessary to be limited to PPO — LLM can also be fine-tuned using other alignment techniques such as DPO.

1.5 Since rewards are unstable: KL normalization to base policy

Direct Answer. Since the reward signal is noisy, the learned policy is conservatively constrained by KL divergence so that it does not deviate too far from the original LM.

\[ \max_\theta \;\; \mathbb{E}\big[\, r(x) \,\big] \;-\; \beta\, D_{\mathrm{KL}}\!\big(\pi_{\text{RLHF}} \,\|\, \pi_{\text{base}}\big). \]

ImportantDo not confuse the two KLs (Frequently tested point)
Comparison Target Role
RLHF’s KL \(D_{\mathrm{KL}}(\pi_{\text{RLHF}} \,\|\, \pi_{\text{base}})\) Anchoring the training policy to the original base LM — to prevent the model from breaking
KL of PPO-Clip \(D_{\mathrm{KL}}(\pi_{\text{old}} \,\|\, \pi_{\text{new}})\) trust region between two consecutive policy iterations — update width limit

In other words, RLHF-KL is a normalization term that binds to the absolute standard (base), and PPO-KL is a step size constraint on the relative standard (previous policy). Additionally, PPO-Clip enforces a small confidence area for every gradient step, whereas the KL term of RLHF directly penalizes the distance from the base when multiple steps are aggregated for a single large update.

1.6 The name “Alignment”

The process of tailoring a model to user preferences using preference data is still learning by updating parameters, but it is now called by the new name alignment because the terms “fine-tuning/learning” are considered cliché. The essence is the same (a kind of marketing renaming).

NoteWireless Communication Analogy — Limited Feedback-Based Adaptation

RLHF resembles closed-loop control that adapts the transmission policy with limited feedback at the receiver. - Reward Model = Learned Quality Indicator (soft CSI) replacing channel quality. Human preference corresponds not to the exact CSI but to quantized preference feedback (which one is better) → therefore noisy (agreement rate 65–75%). - Bradley–Terry Logistic = a logistic link equivalent to the LLR(log-likelihood ratio) of soft-decision. - KL Normalization (→base) = Proximal/Confidence Region Update. This is isomorphic to the method used in adaptive power control to prevent divergence by limiting updates to the vicinity of the previous (or reference) operating point without taking a large step at once.

2 PEFT — Parameter-Efficient Fine-Tuning

2.1 Why PEFT?

Direct Answer. A technique for adapting a massive model by updating only a small number of parameters instead of updating the entire model.

Advantage Mechanism
Increased efficiency / Fast time-to-value Fast training and deployment due to fewer update parameters
Reduction in Catastrophic Forgetting Most existing weights frozen → Preservation of prior training knowledge
Reduced Risk of Overfitting Small Degrees of Freedom for Updates
Reduced Data Requirement Fewer Parameters → Less Data Is Sufficient
Improved Accessibility Adapt large models with fewer resources

Representative techniques: Adapters, LoRA, QLoRA, Prefix-/Prompt-/P-tuning. This note covers the first three.

2.2 Adapter

Direct Answer. Insert a small additional layer (adapter) between Transformer blocks, and train only the adapter and LayerNorm while freezing the existing weights (Houlsby et al., Google Research, ICML 2019).

  • feed-forward·multi-head attention weights are fixed.
  • The newly inserted adapter usually has a down-projection → non-linear → up-projection structure (bottleneck).
  • Since the output distribution changes, Add/retrain LayerNorm.

Consequently, by updating only a small number of layers, it blends previously learned knowledge with new data knowledge through LayerNorm recalibration to maintain accuracy on both sides.

2.3 LoRA — Low-Rank Adaptation

Direct Answer. Approximate the weight update amount \(\Delta W\) with the low-rank decomposition \(BA\), freeze the original weight \(W\), and train only \(A,B\) (Hu et al., Microsoft, ICLR 2022).

For linear layer \(W \in \mathbb{R}^{d\times d}\):

\[ h \;=\; W x \;+\; \underbrace{B A}_{\Delta W}\, x, \qquad A \in \mathbb{R}^{r \times d},\; B \in \mathbb{R}^{d \times r},\; r \ll d. \]

  • Number of Parameters: \(W\) is \(d^2\), \(BA\) is \(2dr\). Savings

\[ \frac{2dr}{d^2} = \frac{2r}{d}. \]

e.g., if \(d=4096,\ r=8\), then \(2dr/d^2 = 1/256\). In reality, LoRA often learns only less than 0.1% of the original parameters.

NoteWhy Low Rank Is Enough — Intuition

If the information required for adapting a task is not as complex as full-rank (i.e., has low intrinsic dimensionality), the update direction lies mostly in a low-dimensional subspace. Only that subspace needs to be trained \(BA\). This is in the same spirit as the low-rank approximation (taking only the upper singular values of SVD) of matrices.

When inferring , \(BA\) can be merged into \(W\) (\(W' = W + BA\)), making the inference latency 0 (however, there is a slight overhead if the adapter is kept disconnected).

2.4 QLoRA — Quantized LoRA

Direct Answer. Train the LoRA adapter with frozen base weights quantized to low precision (e.g., 4-bit) (Dettmers et al., UW, NeurIPS 2023 Oral).

  • Even if LoRA’s \(BA\) is less than 0.1% of the base, the absolute size can be large. Quantizing the base reduces memory and overhead while maintaining accuracy almost.
  • Summary: “Frozen heavy parts at low bits, learning light parts (adapters) as is” → Very compact adaptation.
NoteWireless Communication Analogy — Low-Rank Subspace Adaptation & Quantization Feedback
  • LoRA = reduced-rank / subspace adaptation. This is isomorphic to precoding using only upper singular modes (beams) when channels are low-rank in MIMO, or updating only fractional coordinates using subspace tracking in adaptive filters. Learning only the low-dimensional direction \(BA\) instead of the entire \(W\) = Correcting only the core direction with a bounded feedback codebook.
  • QLoRA = Equivalent to limited-feedback precision reduction, which reduces transmission and storage costs by quantizing adaptive information (core beams are frozen and quantized, only correction is precise).
TipSupplementary Note (math4ml / d2l)
  • Rigorous background of low-rank approximation, SVD, and eigendecomposition: Use the Linear Algebra section (eigendecomposition, singular values) of math4ml as the basis for LoRA intuition.
  • Transformer block structure involving Adapter/LoRA: Reinforces positional sense with d2l.ai’s Attention Mechanisms / Transformer chapter.

3 RAG — Retrieval-Augmented Generation

3.1 Motivation and Core Ideas

Direct Answer. LLM does not intend to lie, but rather probabilistically spits out plausible tokens and produces hallucinations. It reduces hallucinations by providing relevant external documents as a condition (Piktus et al., Facebook, NeurIPS 2020).

Flow:

3.2 MIPS and RAG-Sequence vs RAG-Token

Maximum Inner Product Search (MIPS). Finds the maximum value document by calculating the inner product (alignment similar to cosine similarity) between query embedding \(q\) and document embedding \(\{d_i\}\):

\[ i^\star = \arg\max_i \; \langle q, d_i \rangle . \]

marginalize seq-to-seq predictions for the top \(K\) documents:

Variant Action Cost/Attribute
RAG-Sequence Generates by viewing the entire sentence at once and selecting the most relevant documents Uses one document per sequence — cheaper
RAG-Token Re-locate and combine relevant documents for each token Different documents possible for each token — More expensive, more flexible

Which one is superior depends on the application. Although numerous advanced variations have emerged since 2020, it is recommended to make sure you understand MIPS at least and start from there to follow the literature.

NoteWireless Communication Analogy — Matched Filter / Correlation Receiver

MIPS “internal product maximization” = matched filter/correlated receiver. It is exactly the same operation as selecting the best-fit path/symbol by maximizing the correlation between the received signal and candidate waveforms (codes) (e.g., the strong-correlation path selection in a RAKE receiver). Grounding the response to the retrieved document corresponds to matching decoding with pilot-based channel estimation.

TipSupplementary Note (d2l)

The basics of embedding and attention-based similarity and seq-to-seq decoding can be reinforced in the Attention / Encoder–Decoder chapter of d2l.ai.

4 AI Agents (Agentic AI)

4.1 Definition and Toolformer

Direct Answer. Agent = A (usually LLM-based) model that calls external tools or plans to complete tasks. The key point is that the output is action tokens rather than word tokens.

  • The name (“AI Agents” vs “Agentic AI”) does not matter — the essence is performing high-precision tasks through tool calling and planning.
  • Actions can be physical movements or computer operations (web agents moving, clicking, or typing a mouse). Task = sequence of actions.

Toolformer (Schick et al., UW, NeurIPS 2023) — Initial representative example:

In other words, a self-supervised method that “adopts an API call as training data if the result reduces the loss of the next token”. Today, this tool control is handled more sophisticatedly and extended to web agents, robots, and the like.

NoteWireless Communication Analogy — Closed-loop Control and Control Signaling

The agent is a closed-loop controller that observes the state via external sensing (tools/web) and outputs an action. Action tokens correspond to control signaling at the physical layer, and the loop of observation → evaluation (loss) → action adoption has the same structure as an adaptive loop that adjusts modulation and power based on the channel state.

5 World Models

5.1 Initial definition (Ha & Schmidhuber, 2018)

Direct Answer. Proxy Model of the World. In RL, the “model” (environment simulator) of model-based methods is the world model.

  • The conceptual roots lie in the 1993 intuition of Scott McCloud—“Humans imagine in their brains and act as a result of that imagination.” Just as one rides a bicycle while visualizing it in their mind, they act as an output of imagination.
  • Ha & Schmidhuber (NeurIPS 2018) concretized this into a visual input + memory + controller structure: a compressed representation is obtained from perception, dynamics are predicted with memory (circular structure), and the controller produces a sequence of actions.

5.2 modern world model

Direct Answer. Learns an interactive world from perceptual information (visual, linguistic, audio, etc.) → Evolves into a model that generates images infinitely. Robot and policy models are trained on top of this.

Representative example:

Model Core
UniSim (2023) Universal Simulator — Generates various real-world scenes (navigation, manipulation, etc.) to create inputs for policy learning (Yang et al., Learning Interactive Real-World Simulators)
LWM (2025) Large World Model — autoregressive transformer over a multimodal token sequence
NVIDIA Cosmos (2025–2026) Pre-trained Multimodal Generative Model Suite

LWM (Liu, Yan, Zaharia, Abbeel, ICLR 2025) Structure:

  • Each video frame → Tokenized into 256 tokens using VQGAN.
  • Text → Processed with BPE(Byte-Pair Encoding) tokenizer.
    • By using BPE/byte-level encoding, various language variations can be represented using only a small number of characters instead of the vast vocabulary of word-level encoding.
  • Combine image and text tokens, feed them into a transformer, and autoregressively predict the next token.

NVIDIA Cosmos 3 types of modules:

  • Cosmos Predict: world model that predicts the next frame from a given sequence of frames → generates world behavior in the form of images.
  • Cosmos Reason: Inference/behavior model learning on Predict (VLA example).
  • Cosmos Transfer: Improves real-world application with sim-to-real domain transition.
  • Cosmos 2.5(October 2025) → Cosmos 3(June 2026): Based on mixture-of-transformers, it leverages open synthetic video data to enhance vision and inference and aims for better policy models and world simulations.
NoteWireless Communication Analogy — Channel Prediction / Digital Twin

The World model is equivalent to a channel predictor and a digital twin. “Next frame prediction” corresponds to “next channel state prediction,” and learning and planning policies based on the predicted future is isomorphic to predictive scheduling—looking ahead to future channels and allocating resources in advance. The key advantage of the model-based approach is that it learns by simulating within an internal model rather than directly manipulating the actual environment.

The underlying principle. All five techniques correct and extend a well-trained large model with additional signals (feedback, external knowledge, tools, world models, etc.), but conservatively (low-rank, KL, quantization, grounding) while adding new capabilities while preserving existing capabilities. From a wireless communication perspective, they are all bound together by a single abstraction: closed-loop adaptation under restricted feedback.

7 Appendix: Research Methodology Notes

Summarizes the key points of the research advice in the latter half of this session (highly valuable regardless of the exam scope).

7.1 Definition of Research and Publication

  • Research = re-search: The act of searching again, and again because the solution could not be found. Failure is ordinary, and the day of finding the solution is extra-ordinary. It is normal not to find something new every day, and one should actually be surprised when one does.
  • Publication ≠ “Report on what I have done”: Reporting new and surprising discoveries regarding a problem, rather than what was attempted. However, record for yourself what was attempted and what was learned (to prevent repeating the same mistakes). Do not list attempts in the body of the paper.
  • The message of a good paper: “To solve this problem, you must do this” (e.g., “To perform efficient and accurate object detection, you must do X”). A weak paper is one that says, “I tried this and it went up by 5%, so please accept it”.

7.2 Procedures and Principles

  1. Selecting an Interesting Topic — The more interesting a problem is to many people, the greater its value.
  2. Start on Prior Research — Do not reinvent the wheel. Read SOTA, identify what is wrong, and fix it. That is why you read other people’s papers.
  3. Collaboration — In the era of massive models (e.g., technical reports with over 100 authors), you must collaborate with the majority to make a significant impact. Become someone that others want to work with.

7.3 Big Idea vs. Incremental Idea

  • Incremental (safe) idea: Results are predictable and almost always publishable, but career impact is small (e.g., performance +some percent).
  • Risky Ideas: High risk, high return. Implementation is long and painful with no guaranteed results, but if successful, the impact is tens to hundreds of times. (Examples include CNN seeing the light of day after a long dormancy, and long-term investment in GPU computing.)
  • In the early stages of your PhD, practice with small ideas, but judge real research by whether it is a big idea worth 4–5 years to invest in. Aim for “creative, original (sometimes boldly) big problems.”

7.4 Review · Libertal’s Reality

  • Reviewers are short on time and look for reasons to reject (they superficially look only at numbers, figures, and conclusions). Therefore, writing in a way that “makes it impossible to find a reason to reject” is the essence of good thesis/liberal writing.
  • Naming is also part of the influence: Give good ideas memorable names (e.g., gating variants of the LSTM family).
NoteTechnical side note at the end of the episode — Gating

The core idea introduced to “remember the past” is gating. Weighted sum of current input and past memory as gate values: \[ f \;=\; g(x)\odot x \;+\;\big(1-g(x)\big)\odot m, \qquad g(x)\in(0,1), \] where \(m\) is memory (accumulated moving average of the past). Representative variations include LSTM and GRU, which achieves similar performance with fewer parameters. Long-range memory remains an unsolved challenge.

# (2) LoRA 파라미터 절감비 2r/d
def lora_ratio(d, r):
    full = d * d          # 원본 W 의 파라미터 수
    lora = 2 * d * r      # A(r x d) + B(d x r)

## 3-stage structure of RLHF {#sec-rlhf-3step}

**Direct Answer.** RLHF = Establish a starting point with SFT → Train a reward model with preference data → Fine-tune LLM to RL using that reward.


- **Step 1 — SFT Starting Point**: Build a base model that produces a plausible response using instruction finetuning.
- **Step 2 — Feedback Collection**: When the LLM generates **two responses** for a single prompt, a human evaluates **which one is preferred** using a Likert scale (strongly better ↔ slightly better) or ranking. (There is an anecdote that OpenAI hired a large number of linguistics and humanities majors, rather than engineering majors, and paid them high wages to perform labeling.)
- **Step 3 — Reward Model + RL**: Train a *reward model* with preference data, and fine-tune the LLM using reinforcement learning with that reward as a signal.

::: {.callout-tip title="Historical Context — Learning to summarize (NeurIPS 2020)"}
In initial experiments (Stiennon et al.), for the same prompt, the *vanilla LM* output was mechanical, such as repeating the same words, but the output of the **model injected with lightweight human feedback** became natural, as if written by a human. After confirming this effect, a three-stage pipeline was established to advance the GPT-3 family from InstructGPT to ChatGPT.
:::

## Reward Model and Bradley–Terry Loss {#sec-rlhf-rm}

**Direct Answer.** The reward model is trained with a loss that increases the difference between the two rewards so that the reward for the *chosen response* becomes greater than the reward for the *rejected response*.

Add a new final layer (preferred head) on top of the base model and minimize the following loss:

$$
L_{\text{RM}} \;=\; \log\!\Big(1 + e^{\,r_{\text{rejected}} - r_{\text{chosen}}}\Big).
$$

This is identical to the **Bradley–Terry / Logistic Preference Model**. If set to $\sigma(z)=\frac{1}{1+e^{-z}}$

$$
L_{\text{RM}} = -\log \sigma\!\big(r_{\text{chosen}} - r_{\text{rejected}}\big),
$$

That is, it is the negative log-likelihood (binary cross-entropy) of the "probability that 'chosen' beats 'rejected'". (In Appendix @sec-appendix, the *numerical equivalence* of the two forms is verified using SymPy.)

::: {.callout-note title="Practical Details"}
- **Single 1 epoch** training (intentional overfitting).
- Human evaluation *mutual agreement rate* is typically at the **65–75%** level — reward signals are inherently noisy. This leads to the need for KL normalization later on (@sec-rlhf-kl).
- Variations that add *margin* (difference in strength between options) to the loss are common.
:::

## RLHF + PPO-Clip from an RL Perspective {#sec-rlhf-ppo}

**Direct Answer.** LLM = *Policy*, Output Token String = *Action*, Reward Model = *Environmental Reward*. Optimize this with PPO-Clip.

| RL Concept | Correspondence in RLHF |
|---------|----------------|
| Agent / Policy $\pi_\theta$ | LLM in Learning |
| Action | Response generated by LLM (Token string) |
| Environment reward | Output of **reward model** trained on human preferences |
| Episode | One prompt → completion |

> **Note:** Whether RLHF is "deep" depends not on the *framework*, but on *whether a neural network is used for the policy/value function*. Both deep and shallow are possible with the same RL frame.

PPO-Clip pseudocode (repeating loop):

```text
for each iteration:
    1. 현재 정책 π_θ 로 completion 집합 수집  (← LLM 생성, "episode")
    2. 보상 모델로 각 completion 의 reward 계산
    3. advantage  Â  추정 (가치함수 V_φ 이용)
    4. PPO-Clip 목적함수로 정책 파라미터 θ 갱신
    5. 가치함수 φ 를 gradient descent 로 갱신
    repeat
```

It is not necessary to be limited to PPO — LLM can also be fine-tuned using other alignment techniques such as DPO.

## Since rewards are unstable: KL normalization to base policy {#sec-rlhf-kl}

**Direct Answer.** Since the reward signal is noisy, the learned policy is conservatively constrained by KL divergence so that it does not deviate too far from the original LM.

$$
\max_\theta \;\; \mathbb{E}\big[\, r(x) \,\big] \;-\; \beta\, D_{\mathrm{KL}}\!\big(\pi_{\text{RLHF}} \,\|\, \pi_{\text{base}}\big).
$$

::: {.callout-important title="Do not confuse the two KLs (Frequently tested point)"}
| | Comparison Target | Role |
|---|---|---|
| **RLHF's KL** | $D_{\mathrm{KL}}(\pi_{\text{RLHF}} \,\|\, \pi_{\text{base}})$ | *Anchoring* the training policy to the **original base LM** — to prevent the model from breaking |
| **KL of PPO-Clip** | $D_{\mathrm{KL}}(\pi_{\text{old}} \,\|\, \pi_{\text{new}})$ | **trust region between two consecutive policy iterations** — update width limit |

In other words, RLHF-KL is a normalization term that binds to the *absolute standard (base)*, and PPO-KL is a step size constraint on the *relative standard (previous policy)*. Additionally, PPO-Clip enforces a small confidence area for every gradient step, whereas the KL term of RLHF directly penalizes the distance from the base when multiple steps are aggregated for a single large update.
:::

## The name "Alignment" {#sec-rlhf-align}

The process of tailoring a model to user preferences using preference data is *still learning by updating parameters*, but it is now called by the new name **alignment** because the terms "fine-tuning/learning" are considered cliché. The essence is the same (a kind of marketing renaming).

::: {.callout-note title="Wireless Communication Analogy — Limited Feedback-Based Adaptation"}
RLHF resembles closed-loop control that adapts the transmission policy with limited feedback at the receiver.
- *Reward Model* = **Learned Quality Indicator (soft CSI)** replacing channel quality. Human preference corresponds not to the exact CSI but to *quantized preference feedback* (which one is better) → therefore noisy (agreement rate 65–75%).
- *Bradley–Terry Logistic* = a logistic link equivalent to the **LLR(log-likelihood ratio)** of soft-decision.
- *KL Normalization (→base)* = **Proximal/Confidence Region Update**. This is isomorphic to the method used in adaptive power control to prevent divergence by limiting updates to the vicinity of the previous (or reference) operating point without taking a large step at once.
:::

# PEFT — Parameter-Efficient Fine-Tuning

## Why PEFT? {#sec-peft-why}

**Direct Answer.** A technique for adapting a massive model by updating only a *small number of parameters* instead of updating the entire model.

| Advantage | Mechanism |
|------|----------|
| **Increased efficiency / Fast time-to-value** | Fast training and deployment due to fewer update parameters |
| **Reduction in Catastrophic Forgetting** | Most existing weights frozen → Preservation of prior training knowledge |
| **Reduced Risk of Overfitting** | Small Degrees of Freedom for Updates |
| **Reduced Data Requirement** | Fewer Parameters → Less Data Is Sufficient |
| **Improved Accessibility** | Adapt large models with fewer resources |

Representative techniques: **Adapters, LoRA, QLoRA**, Prefix-/Prompt-/P-tuning. This note covers the first three.

## Adapter {#sec-peft-adapter}

**Direct Answer.** Insert a *small additional layer (adapter)* between Transformer blocks, and train only the **adapter and LayerNorm** while freezing the existing weights (Houlsby et al., Google Research, ICML 2019).

- feed-forward·multi-head attention weights are **fixed**.
- The newly inserted adapter usually has a **down-projection → non-linear → up-projection** structure (bottleneck).
- Since the output distribution changes, **Add/retrain LayerNorm**.

Consequently, by updating only a small number of layers, it blends previously learned knowledge with new data knowledge through LayerNorm recalibration to maintain accuracy on both sides.

## LoRA — Low-Rank Adaptation {#sec-peft-lora}

**Direct Answer.** Approximate the weight update amount $\Delta W$ with the **low-rank decomposition $BA$**, freeze the original weight $W$, and train only $A,B$ (Hu et al., Microsoft, ICLR 2022).

For linear layer $W \in \mathbb{R}^{d\times d}$:

$$
h \;=\; W x \;+\; \underbrace{B A}_{\Delta W}\, x,
\qquad A \in \mathbb{R}^{r \times d},\; B \in \mathbb{R}^{d \times r},\; r \ll d.
$$

- **Number of Parameters**: $W$ is $d^2$, $BA$ is $2dr$. Savings

$$
\frac{2dr}{d^2} = \frac{2r}{d}.
$$

e.g., if $d=4096,\ r=8$, then $2dr/d^2 = 1/256$. In reality, LoRA often learns only **less than 0.1%** of the original parameters.

::: {.callout-note title="Why Low Rank Is Enough — Intuition"}
If the information required for adapting a task is not as complex as *full-rank* (i.e., has low intrinsic dimensionality), the update direction lies mostly in a low-dimensional subspace. Only that subspace needs to be trained $BA$. This is in the same spirit as the **low-rank approximation (taking only the upper singular values of SVD)** of matrices.
:::

When inferring , $BA$ can be merged into $W$ ($W' = W + BA$), making the **inference latency 0** (however, there is a slight overhead if the adapter is kept disconnected).

## QLoRA — Quantized LoRA {#sec-peft-qlora}

**Direct Answer.** Train the LoRA adapter with frozen base weights **quantized to low precision (e.g., 4-bit)** (Dettmers et al., UW, NeurIPS 2023 Oral).

- Even if LoRA's $BA$ is less than 0.1% of the base, the *absolute size* can be large. Quantizing the base reduces **memory and overhead** while maintaining accuracy almost.
- Summary: "Frozen heavy parts at low bits, learning light parts (adapters) as is" → Very compact adaptation.

::: {.callout-note title="Wireless Communication Analogy — Low-Rank Subspace Adaptation & Quantization Feedback"}
- **LoRA** = **reduced-rank / subspace adaptation**. This is isomorphic to precoding using only upper singular modes (beams) when channels are low-rank in MIMO, or updating only fractional coordinates using *subspace tracking* in adaptive filters. Learning only the low-dimensional direction $BA$ instead of the entire $W$ = Correcting only the core direction with a *bounded feedback codebook*.
- **QLoRA** = Equivalent to limited-feedback precision reduction, which reduces transmission and storage costs by **quantizing** adaptive information (core beams are frozen and quantized, only correction is precise).
:::

::: {.callout-tip title="Supplementary Note (math4ml / d2l)"}
- Rigorous background of low-rank approximation, SVD, and eigendecomposition: Use the *Linear Algebra* section (eigendecomposition, singular values) of math4ml as the basis for LoRA intuition.
- Transformer block structure involving Adapter/LoRA: Reinforces positional sense with d2l.ai's *Attention Mechanisms / Transformer* chapter.
:::

# RAG — Retrieval-Augmented Generation

## Motivation and Core Ideas {#sec-rag-idea}

**Direct Answer.** LLM does not *intend to lie*, but rather **probabilistically spits out plausible tokens and produces hallucinations**. It reduces hallucinations by providing relevant external documents as a *condition* (Piktus et al., Facebook, NeurIPS 2020).

Flow:

```{mermaid}
flowchart LR
    Q["쿼리<br/>(예: 한국 문화)"] --> E["쿼리 임베딩"]
    E --> S["MIPS<br/>최대 내적 검색"]
    DB["문서 임베딩 DB / 웹"] --> S
    S --> R["가장 관련 높은<br/>문서 선택"]
    R --> G["문서 + 쿼리로<br/>응답 생성(조건부)"]
    G --> O["환각 줄어든 출력"]
```

## MIPS and RAG-Sequence vs RAG-Token {#sec-rag-mips}

**Maximum Inner Product Search (MIPS).** Finds the maximum value document by calculating the **inner product (alignment similar to cosine similarity)** between query embedding $q$ and document embedding $\{d_i\}$:

$$
i^\star = \arg\max_i \; \langle q, d_i \rangle .
$$

**marginalize** seq-to-seq predictions for the top $K$ documents:

| Variant | Action | Cost/Attribute |
|------|------|----------|
| **RAG-Sequence** | Generates by viewing the *entire sentence* at once and selecting the most relevant documents | Uses **one document** per sequence — cheaper |
| **RAG-Token** | Re-locate and combine relevant documents for each token | **Different documents** possible for each token — More expensive, more flexible |

Which one is superior depends on the application. Although numerous advanced variations have emerged since 2020, it is recommended to **make sure you understand MIPS at least** and start from there to follow the literature.

::: {.callout-note title="Wireless Communication Analogy — Matched Filter / Correlation Receiver"}
**MIPS "internal product maximization" = matched filter/correlated receiver**. It is exactly the same operation as selecting the best-fit path/symbol by maximizing the correlation between the received signal and candidate waveforms (codes) (e.g., the strong-correlation path selection in a RAKE receiver). *Grounding* the response to the retrieved document corresponds to **matching decoding with pilot-based channel estimation**.
:::

::: {.callout-tip title="Supplementary Note (d2l)"}
The basics of embedding and attention-based similarity and seq-to-seq decoding can be reinforced in the *Attention / Encoder–Decoder* chapter of d2l.ai.
:::

# AI Agents (Agentic AI)

## Definition and Toolformer {#sec-agents-def}

**Direct Answer.** Agent = A (usually LLM-based) model that *calls external tools* or *plans* to complete tasks. The key point is that the output is **action tokens** rather than word tokens.

- The name ("AI Agents" vs "Agentic AI") does not matter — the essence is *performing high-precision tasks through tool calling and planning*.
- Actions can be physical movements or computer operations (web agents moving, clicking, or typing a mouse). Task = **sequence of actions**.

**Toolformer (Schick et al., UW, NeurIPS 2023)** — Initial representative example:

```{mermaid}
flowchart LR
    T["LLM 토큰 생성 중"] --> A["API 호출 토큰 삽입"]
    A --> X["API 실행 → 결과 수신"]
    X --> L["손실로 평가:<br/>다음 토큰 예측이<br/>개선되는가?"]
    L -->|"개선됨"| K["API 결과 채택"]
    L -->|"개선 안 됨"| D["폐기, 원래 출력 사용"]
```

In other words, a self-supervised method that **"adopts an API call as training data if the result reduces the loss of the next token"**. Today, this tool control is handled more sophisticatedly and extended to web agents, robots, and the like.

::: {.callout-note title="Wireless Communication Analogy — Closed-loop Control and Control Signaling"}
The agent is a **closed-loop controller that observes the state via external sensing (tools/web) and outputs an action**. Action tokens correspond to *control signaling* at the physical layer, and the loop of observation → evaluation (loss) → action adoption has the same structure as an adaptive loop that adjusts modulation and power based on the channel state.
:::

# World Models

## Initial definition (Ha & Schmidhuber, 2018) {#sec-wm-early}

**Direct Answer.** *Proxy Model of the World*. In RL, the "model" (environment simulator) of model-based methods is the world model.

- The conceptual roots lie in the 1993 intuition of Scott McCloud—"Humans *imagine* in their brains and act as a result of that imagination." Just as one rides a bicycle while visualizing it in their mind, they **act as an output of imagination**.
- Ha & Schmidhuber (NeurIPS 2018) concretized this into a **visual input + memory + controller** structure: a compressed representation is obtained from perception, dynamics are predicted with memory (circular structure), and the controller produces a sequence of actions.

## modern world model {#sec-wm-modern}

**Direct Answer.** Learns an *interactive world* from perceptual information (visual, linguistic, audio, etc.) → Evolves into a **model that generates images infinitely**. Robot and policy models are trained on top of this.

Representative example:

| Model | Core |
|------|------|
| **UniSim (2023)** | *Universal Simulator* — Generates various real-world scenes (navigation, manipulation, etc.) to create inputs for policy learning (Yang et al., *Learning Interactive Real-World Simulators*) |
| **LWM (2025)** | *Large World Model* — autoregressive transformer over a multimodal token sequence |
| **NVIDIA Cosmos (2025–2026)** | Pre-trained Multimodal Generative Model Suite |

**LWM (Liu, Yan, Zaharia, Abbeel, ICLR 2025)** Structure:

- Each **video frame → Tokenized into 256 tokens** using VQGAN.
- **Text → Processed with BPE(Byte-Pair Encoding)** tokenizer.
  - By using BPE/byte-level encoding, various language variations can be represented using only *a small number of characters* instead of the vast vocabulary of word-level encoding.
- Combine image and text tokens, feed them into a transformer, and **autoregressively predict the next token**.

**NVIDIA Cosmos** 3 types of modules:

```{mermaid}
flowchart LR
    P["Cosmos Predict<br/>(world model)<br/>다음 프레임 예측 → 세계 생성"] --> R["Cosmos Reason<br/>(VLA/추론 모델)<br/>Predict 위에서 학습"]
    P --> T["Cosmos Transfer<br/>(sim→real 도메인 전이)<br/>실세계 적용"]
```

- **Cosmos Predict**: world model that predicts the *next frame* from a given sequence of frames → generates world behavior in the form of images.
- **Cosmos Reason**: Inference/behavior model learning on Predict (VLA example).
- **Cosmos Transfer**: Improves real-world application with sim-to-real domain transition.
- *Cosmos 2.5*(October 2025) → *Cosmos 3*(June 2026): Based on mixture-of-transformers, it leverages open synthetic video data to enhance vision and inference and aims for better policy models and world simulations.

::: {.callout-note title="Wireless Communication Analogy — Channel Prediction / Digital Twin"}
The World model is equivalent to a **channel predictor and a digital twin**. "Next frame prediction" corresponds to "next channel state prediction," and learning and planning policies based on the predicted future is isomorphic to **predictive scheduling**—looking ahead to future channels and allocating resources in advance. The key advantage of the model-based approach is that it learns by *simulating* within an internal model rather than directly manipulating the actual environment.
:::

# Summary {#sec-summary}

| Axis | Problem | Solution | Key Formula/Mechanism |
|----|------|------|-------------------|
| **RLHF** | LM Objective ≠ Human Preference | Preference Reward + RL Fine-tuning | $L_{\text{RM}}=-\log\sigma(r_c-r_r)$, KL Normalization to Base |
| **PEFT** | Full fine-tuning is expensive and risk of forgetting | Update only a few parameters | Adapter; LoRA $W{+}BA$ ($2r/d$ savings); QLoRA(quantization base) |
| **RAG** | Hallucination | Grounding to external document | MIPS $\arg\max\langle q,d_i\rangle$; RAG-Seq vs RAG-Token |
| **Agents** | Limitations of Standalone LLM | Tool Invocation/Action | Toolformer(Adopt API result for loss improvement); Action Token |
| **World Models** | Environment Interaction Costs | Modeling/Simulating the World | UniSim/LWM(VQGAN+BPE+AR)/Cosmos(Predict·Transfer·Reason) |

> **The underlying principle.** All five techniques **correct and extend** a well-trained large model with additional signals (feedback, external knowledge, tools, world models, etc.), but **conservatively (low-rank, KL, quantization, grounding)** while adding new capabilities while preserving existing capabilities. From a wireless communication perspective, they are all bound together by a single abstraction: *closed-loop adaptation under restricted feedback*.

# Appendix: Research Methodology Notes {#sec-research}

Summarizes the key points of the research advice in the latter half of this session (highly valuable regardless of the exam scope).

## Definition of Research and Publication {#sec-research-def}

- **Research = re-search**: The act of searching *again, and again* because the solution could not be found. Failure is ordinary, and the *day of finding the solution is extra-ordinary*. It is normal not to find something new every day, and one should actually be surprised when one does.
- **Publication ≠ "Report on what I have done"**: Reporting **new and surprising discoveries regarding a problem**, rather than what was attempted. However, *record for yourself what was attempted and what was learned* (to prevent repeating the same mistakes). Do not list attempts in the body of the paper.
- The message of a good paper: *"To solve this problem, you must do this"* (e.g., "To perform efficient and accurate object detection, you must do X"). A weak paper is one that says, *"I tried this and it went up by 5%, so please accept it"*.

## Procedures and Principles {#sec-research-proc}

1. **Selecting an Interesting Topic** — The more interesting a problem is to many people, the greater its value.
2. **Start on Prior Research** — Do not reinvent the wheel. Read SOTA, identify what is wrong, and fix it. That is why you read other people's papers.
3. **Collaboration** — In the era of massive models (e.g., technical reports with over 100 authors), you must collaborate with the majority to make a significant impact. Become someone that others want to work with.

## Big Idea vs. Incremental Idea {#sec-research-bigidea}

- **Incremental (safe) idea**: Results are predictable and almost always publishable, but career impact is small (e.g., performance +some percent).
- **Risky Ideas**: High risk, high return. Implementation is long and painful with no guaranteed results, but if successful, the impact is *tens to hundreds of times*. (Examples include CNN seeing the light of day after a long dormancy, and long-term investment in GPU computing.)
- In the early stages of your PhD, *practice* with small ideas, but judge real research by whether it is a **big idea worth 4–5 years** to invest in. Aim for "creative, original (sometimes boldly) big problems."

## Review · Libertal's Reality {#sec-research-rebuttal}

- Reviewers are short on time and look for *reasons to reject* (they superficially look only at numbers, figures, and conclusions). Therefore, writing in a way that **"makes it impossible to find a reason to reject"** is the essence of good thesis/liberal writing.
- Naming is also part of the influence: Give good ideas memorable names (e.g., gating variants of the LSTM family).

::: {.callout-note title="Technical side note at the end of the episode — Gating"}
The core idea introduced to "remember the past" is **gating**. Weighted sum of current input and past memory as gate values:
$$
f \;=\; g(x)\odot x \;+\;\big(1-g(x)\big)\odot m, \qquad g(x)\in(0,1),
$$
where $m$ is memory (accumulated moving average of the past). Representative variations include **LSTM** and **GRU**, which achieves similar performance with fewer parameters. *Long-range memory* remains an unsolved challenge.
:::

```{python}
#| label: verify-lora-params
#| code-fold: show
# (2) LoRA 파라미터 절감비 2r/d
def lora_ratio(d, r):
    full = d * d          # 원본 W 의 파라미터 수

for d, r in [(4096, 8), (4096, 16), (1024, 4)]:
```

```{python}
#| label: verify-sigmoid-softmax
#| code-fold: show
import numpy as np
# (3) sigmoid(x) == 2-class softmax([x, 0])_0  (선호 모형의 로지스틱 링크)
def sigmoid(x): return 1.0 / (1.0 + np.exp(-x))
def softmax2_first(x):
    z = np.array([x, 0.0]); e = np.exp(z - z.max())
    return (e / e.sum())[0]

xs = np.linspace(-4, 4, 9)
diff = np.max(np.abs([sigmoid(x) - softmax2_first(x) for x in xs]))
print("max |sigmoid - 2class softmax| =", diff)   # ~1e-16
```

- (1) The two forms of the compensation model loss are *symbolically exactly 0* (perfectly equivalent).
- (2) LoRA savings amount is $2r/d$: e) $d=4096,\,r=8 \Rightarrow 1/256$.
- (3) Bradley–Terry logistic is equivalent to 2-class softmax — reaffirming that preference learning is binary cross-entropy.
