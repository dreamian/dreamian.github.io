Transformer: Token, Attention, Position Encoding

Attention as Dynamic Pooling — Weights that adapt to input beyond fixed weights

Published

April 27, 2026

1 View at a glance

TipKey line

A Transformer is a sequence-to-seq model that uses “input-dependent weights” instead of “fixed weights.” These weights do not directly weight the data, but are assigned to the similarity between data points.

The three pillars supporting the Transformer are as follows.

Component One-line definition Intuition
Token A vector (bundle of neurons) encapsulating information Elevating the minimum unit of processing from “neuron” to “bundle of vectors”
Attention Dynamic pooling that assigns learned weights to similarity Observes the input, changes the weights, and applies them back to the input
Positional Encoding Code that adds a positional address to a token Tells a model that does not know the order “which token it is”

Of these three, attention is the most important. The other two are more like auxiliary devices that make attention applicable to actual data.

2 Background: Why CNN/RNN Is Insufficient

2.1 Two challenges in sequence modeling

The data discussed so far has been “snapshots” (images, graphs) with fixed length. However, language, time series (stock prices), video, and audio are sequences with variable length. There are two key challenges in sequence encoding.

  1. Long-term dependency: It is difficult to remember information from a long time ago.
  2. Context: Even the same token can have different meanings depending on the surrounding context. (e.g., as in the sentence “Buffalo buffalo Buffalo buffalo …”, the same word can be interpreted as a noun, verb, or place name depending on the context.)

RNNs address these two difficult problems by propagating the hidden state from start to finish. The Transformer is an alternative to this and has now become the de facto standard.

2.2 CNN Limitations: Failure Cases Seen Through VQA

NoteVQA(Visual Question Answering) Example

Let’s think about questions like “How many birds are in this image?”, “Are the bird in the top right and the bird in the bottom left the same species?”, and “What is the color of the sky?”

CNN stands on two design assumptions.

  • Locality: The filter only considers adjacent areas.
  • Spatial stationarity: Applies the same filter equally across the entire image (parameter sharing).

Because of this assumption, CNN does not do the following well.

  • Counting: max-pooling passes only the position with the strongest reaction to the next layer. This conflicts with the task of counting different “birds” at each position.
  • Long-distance relationship comparison: Determining the relationship between two distant objects (“Top right vs. Bottom left”) is difficult with local filters.
  • Selective attention based on context: CNNs scan all spatial locations equally, but there are times when they need to pay attention to “only specific regions” depending on the question.

Locally-connected networks (CNNs that eliminate weight sharing) are advantageous for counting, but the number of parameters explodes, and they lose almost all the advantages of CNNs. Therefore, a different type of encoding method is needed — that is attention.

3 Token

3.1 New data structure

TipKey point

A token is not a “single neuron” but a “vector encapsulating information.” Transformers perform operations at the token level, not the neuron level.

  • It is essentially the same concept as the “node attribute” of GNN — the unit of information is a vector.
  • If you chop the input and project each piece onto a vector, it becomes a token.
Input Type Tokenization Method
Image Split into patches and project each patch as a vector (ViT)
Text Convert word/subword to embedding vector
Audio Convert time interval (frame) to vector

3.2 Once tokenized, all modalities are in the same architecture

This is a major practical advantage of Transformer. Regardless of modality, once tokenized, the same architecture can be used as is.

CNNs are closer to “one way of encoding” information, while MLPs are closer to “one way of mixing” information. Transformers shift the burden of modality integration to the “tokenization” stage by pushing inputs into a token space.

Tokens are updated through linear combinations between tokens and token-wise nonlinearity (i.e., position-wise MLP).

4 Attention

This is the heart of this text.

4.1 Fixed Weights vs. Attention

ImportantThe most important distinction
  • Ordinary weight: A fixed value regardless of the input. It is learned from the data, but remains the same regardless of the input during inference.
  • Attention: Weights are a function of the input. It receives input, changes the weight values, and applies the changed weights back to the input.

Looking at the formula, the output of a normal layer is ZZZPH0008507ZZZ , where \(y = Wx\) and Z\(W\) is a constant. For attention, like \(y = A(x)\,x\), the weights themselves are a function of \(x\) \(A(x)\). Only one step is added: “take the input as input, create weights, and apply those weights back to the input.”

4.2 Attention as dynamic pooling

Attention can be understood as dynamic/adaptive pooling based on queries.

  • Max/average pooling performs fixed operations (max/average) without considering the relationships between positions.
  • Attention dynamically determines pooling weights based on the relationship (similarity) between the query and the key.

In other words, it is “relationship-based pooling that is neither max, min, nor average”.

4.3 Query·Key·Value (Query, Key, Value)

Defines three roles.

  • Query (\(q\)): The target from which to obtain encoding (embedding). What I am “asking”.
  • Key (\(k\)): Other contextual information. The relative to measure similarity with the query.
  • Value (\(v\)): Information to actually retrieve and combine. Reflected in the output as a result of the operation.
NoteLanguage example: “I like ice cream”

If you want to obtain the embedding of “like”, “like” is the query, and all words in the sentence (“I”, “like”, “ice”, “cream”) are the keys. Measure the similarity between the query and each key, and then perform a weighted sum of the values based on that similarity.

NoteVQA Example (cross-attention)

The question sentence “What color is this impala?” serves as the query, and image patches serve as the key/value. Large weights are assigned to patches (impala regions) similar to the query, and clues to the answer are obtained from the values of those regions. When the query and the key originate from different sources, this is called cross-attention.

By simply defining “what to use as queries/keys/values” based on the problem settings (translation, VQA, video generation, etc.), various problems can be reduced to a single format.

4.4 Why is similarity cosine similarity?

Measure the similarity between query \(q\) and key \(k\) using the dot product. Let’s explain this using high school vectors.

\[ q \cdot k = \|q\|\,\|k\|\cos\theta \]

  • \(\|q\|,\|k\|\) is the magnitude, \(\theta\) is the angle between the two vectors.
  • If the two vectors are normalized to unit vectors (or if magnitude is ignored), the dot product is \(\cos\theta\) itself.

\[ \text{cosine similarity} = \frac{q\cdot k}{\|q\|\,\|k\|} = \cos\theta \]

Geometrically, \(\cos\theta\) is the length of the projection of one vector in the direction of another vector. That is:

  • \(\theta = 90°\) (Orthogonal) → \(\cos\theta = 0\): Irrelevant.
  • \(\theta = 0°\) (same direction) → \(\cos\theta = 1\): maximum similarity.
TipIntuition

Cosine similarity ignores magnitude and only looks at “how much the direction points in the same direction.” This is also called angular distance**. What attention asks is “whether the query and the key point in the same direction.”

4.5 Softmax: Amplifying the Difference

Apply softmax to the similarity score vector \(s = [s_1, \dots, s_n]\).

\[ a_j = \frac{\exp(s_j)}{\sum_{l} \exp(s_l)} \]

The role of the softmax is to amplify the difference between the maximum value and the remainder to create a weight distribution where the sum is 1 (smooth argmax). The \(a\) obtained in this way is the attention weight.

4.6 Value transformation matrix \(W_v\) and training target

Up until now, \(q, k\) has been used to determine similarity (=attention strength). Then, what is the value that will actually be combined? Instead of using the input token \(x\) as is, it is transformed once more into a trainable matrix \(W_v\). This grants degrees of freedom to rotate/scale the value space to suit the given task.

To summarize, what attention learns are three projection matrices \(W_q, W_k, W_v\).

\[ Q = X W_q,\quad K = X W_k,\quad V = X W_v \]

ImportantThe Essence of Attention

Attention is not “applying fixed weights to the information itself”, but “applying learned weights to the similarity between pieces of information”. Which similarity is important varies depending on the data and the task, and \(W_q, W_k, W_v\) learns this judgment.

4.7 Scaled Dot-Product Attention (Supplement)

The entire operation can be written as a single matrix as follows. (This normalization coefficient \(\sqrt{d_k}\) is omitted in the intuitive explanation above, but is included here as it invariably appears in actual implementations — refer to the Attention Scoring Functions section of d2l.ai.)

\[ \boxed{\ \text{Attention}(Q, K, V) = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right) V\ } \]

NoteWhy divide into \(\sqrt{d_k}\)

If each component of \(q, k\) is independent with a mean of 0 and a variance of 1, the variance of the inner product \(q\cdot k = \sum_{i=1}^{d_k} q_i k_i\) becomes \(d_k\). If \(d_k\) is large, the magnitude of the scores increases, causing the softmax to become oversaturated on one side, and the gradient becomes nearly 0 in that region. Dividing by the standard deviation \(\sqrt{d_k}\) returns the score variance to a level of 1, stabilizing the learning.

5 Self-Attention

TipKey line

It is self-attention if the query, key, and value all originate from the same source. Each token refines itself into a context-reflecting expression by using “itself as the query and everything around it (including itself) as the key/value.”

  • Example: When obtaining the embedding of an image patch, query that patch, and set all patches of the same image as key/value pairs.
  • Result: Each token has a semantic embedding that reflects neighbor token information.

5.1 Matrix Operations

For \(X \in \mathbb{R}^{n\times d}\) ( \(n\) token, dimension \(d\) ):

\[ Q=XW_q,\ K=XW_k,\ V=XW_v;\qquad \text{Out} = \mathrm{softmax}\!\left(\tfrac{QK^\top}{\sqrt{d_k}}\right)V \]

The order of operations for is the same as cross-attention, differing only in that \(Q,K,V\) comes from the same \(X\).

5.2 DINO: Visualization of Patch Value Refining

In the self-supervised learning model DINO (Caron et al., ICCV 2021), when attention scores are visualized with a small patch as a query, regions of semantically identical objects (numbers) appear bright, while irrelevant backgrounds appear dark. This demonstrates that self-attention groups patches by semantic unit.

6 Masked Attention (Masked / Causal Attention)

TipKey point line

Blocking parts of the attention matrix with zeros prevents a specific token from paying attention to another specific token. In decoders, this is used to block “future tokens” (causal attention).

6.1 Why Block the Future

Let’s consider machine translation (seq-to-seq). The encoder looks at the entire input sentence, but the decoder generates words one by one. At the point \(t\), the words after \(t+1\) have not yet been generated.

  • If attention is allowed on future tokens, the decoder will “peek” at the correct answer (future word) during training and refer to a non-existent token during inference.
  • As a result, the attention score of the future position becomes a meaningless value, and during backpropagation, the garbage gradient propagates up to \(W_q, W_k\), ruining the learning.

Solution: Make the score of the future position \(-\infty\) (actually a very large negative number) so that the weight becomes 0 after softmax.

\[ s_{ij} \leftarrow \begin{cases} s_{ij} & j \le i \quad(\text{과거·현재})\\[4pt] -\infty & j > i \quad(\text{미래, 마스킹}) \end{cases} \]

6.2 Other uses: Optional multimodal encoding

In addition to causality, masking can be used as a general mechanism to select which tokens to exclude from the context. For example, when generating a consistent sequence of images that corresponds to a text story, an attention mask can be designed to selectively encode only relevant tokens (Ahn et al., Story visualization by online text augmentation with context memory, ICCV 2023).

7 Multi-Head Self-Attention

TipKey point

A single \((W_q, W_k, W_v)\) pair captures only one aspect of the relationship. To see multiple aspects, place multiple pairs in parallel. This is the same motivation as training multiple filters in CNNs.

  • CNN: Learn multiple filters on a single image → Capture different spatial patterns.
  • Transformer: Multiple heads \(\{(W_q^{(h)}, W_k^{(h)}, W_v^{(h)})\}_{h=1}^{H}\) in parallel → Capture different relationship aspects.

Concatenate the outputs of each head and mix them into output projection \(W_o\).

\[ \text{head}_h = \text{Attention}(XW_q^{(h)}, XW_k^{(h)}, XW_v^{(h)}) \] \[ \text{MHA}(X) = \big[\text{head}_1; \dots; \text{head}_H\big]\,W_o \]

WarningHonest Limits

There is no explicit mechanism to prevent “knowledge duplication” or “information loss” between different heads. We merely implicitly assume** that the heads will learn different aspects on their own. Interaction between heads occurs only implicitly during the blending stage of the next layer. Removing attention causes a significant (but not fatal) drop in performance — we have many conjectures, but we do not know the exact reason.

In addition to multiple heads (parallel within heads), blocks are cascade. This is equivalent to stacking convolutional layers in a CNN.

8 MLP vs Transformer, and Permutation Iomovariance

The decisive difference between MLP and Transformer: Transformer’s attention is a function of the input (\(A(x)\)). The weights of an MLP are fixed regardless of the input.

8.1 Equivariance and Invariance

Concept Definition One-line Intuition
Invariance Output remains the same even if input changes Insensitive to change
Equivariance Output changes as much as the input changes Reflects change

Example: If the output rotates along with the input when rotated, it is rotationally equal; if the output remains unchanged, it is rotationally invariant.

8.2 The necessity of permutation equivariance and positional encoding

Importantproblem

Attention (and MLPs) are permutation equivariant. If the order of input tokens is shuffled, the output is shuffled in the same way, but the model does not know the original positions of the tokens.

In language and images, position/order determines meaning (“dog bites person” ≠ “person bites dog”). Therefore, position information must be explicitly injected into tokens. That is the position encoding in the following section.

9 Positional Encoding

TipKey point

Add a different “address vector” to the input token for each location. However, these addresses must be dense and of similar size to facilitate learning.

9.1 Why aren’t simple integer numbers allowed?

The simplest idea is to assign positions as integers \(0,1,2,\dots\). However, sparse codes with many zeros, like binary representations, are difficult to learn weights on (weights multiplied by zeros are effectively not learned). We need dense representations where every dimension has a meaningful value, and vectors that differ by position but are similar in size.

9.2 Sine wave position encoding (supplement)

The most widely used implementation is to use sine/cosine of different frequencies (Vaswani et al., 2017; d2l.ai Self-Attention and Positional Encoding section).

\[ PE_{(pos,\,2i)} = \sin\!\left(\frac{pos}{10000^{\,2i/d}}\right),\qquad PE_{(pos,\,2i+1)} = \cos\!\left(\frac{pos}{10000^{\,2i/d}}\right) \]

  • All component sizes are uniform as \([-1, 1]\) → Advantageous for weight learning.
  • Unique pattern (address) for each location → Location distinguishable.
  • Since it is a superposition of different frequencies, relative position information can also be expressed by a linear transformation.
NoteAnalogy: Military unit numbering

Even though the value itself may appear “unconventional” (e.g., Unit 6575), it is a code designed to have good properties from the perspective of learning weights. A sine wave PE is a location address that “appears meaningless to the human eye but is useful for machine learning.”

When position encoding is added, multi-head (masked) self-attention + feedforward effectively captures the context to generate appropriate output probabilities.

10 Overall Architecture Summary

Now let’s assemble the blocks. The encoder-decoder structure is as follows.

Core Flow:

  1. Encoder: Encodes the context of the entire input with (unmasked) self-attention.
  2. Decoder: First, look only at the tokens generated so far using masked self-attention, then mix with the encoder’s context (Key/Value) using cross-attention.
  3. Residual linking (Add), normalization (Norm), and positional feedforward stabilize and transform each step.
  4. The final output is the probability distribution of the next token, and this probability serves as a clue as to which token will be generated next.
NoteAdd & Norm — Why Residual Linking?

Residual connections of the form \(\text{LayerNorm}(x + \text{Sublayer}(x))\) are used for the same reason as in ResNet. Thanks to the identity path (+I), gradients are preserved even in deep layers, maintaining learnability.

11 Application

11.1 Language Model

A language model is an NLP task that predicts the probability of the next word given previous words. A common assumption is that “the probability of the next word depends only on previous words within a fixed-size window.” When the scale is very large, it is called a Large-scale Language Model (LLM) (GPT, Claude, HyperClova X, etc.).

Language modeling is, in fact, the meta-task of NLP. Training a good language model can yield numerous downstream tasks, such as sentiment analysis, Named Entity Recognition (NER), coreference resolution, and question answering. Therefore, people have continuously expanded their models.

11.2 Autoregressive Models and GPT

GPT = Generative Pretrained Transformer. The name contains “Transformer” (GPT is not General Purpose Text).

  • Autoregressive: Generate the next token using the previously generated token as input, and repeat this process.
  • Training: Train the entire encoder-decoder (or decoder-only) model to output one word at a time. Sampling (Inference) also generates one token at a time.
  • Causal attention: Since it does not look at future tokens, it aligns exactly with autoregressive generation.
WarningWeakness of Autoregression

Error Propagation: If an error is made once at the beginning, that error spreads to the entire sequence thereafter. As an alternative, methods to generate word chunks all at once (e.g., some models generate chunks using CNN/Diffusion) are also being studied. However, early LLMs (such as GPT-2/3) used the Transformer directly for autoregression.

NoteTouch it yourself: minGPT

A. Karpathy’s minGPT is a minimal GPT with causal attention fully implemented. Its source is very simple, which makes it suitable for training.

12 Limitations and Efficiency (Limitations)

Transformer has been the standard for almost 10 years (since its proposal in 2017), but it has limitations.

12.1 1) Cannot see outside the context window

Calculates \(W_q, W_k, W_v\) only within the key window (e.g., 128,000 tokens). Information outside the window is not propagated like an RNN and is therefore lost → Asking for information from a distance can increase hallucination.

  • Partial Mitigation: KV Cache. It stores and reuses the Key/Value pairs of important tokens to effectively maintain long contexts. However, this is a temporary solution and not a fundamental solution.
  • Since it must hold the KV cache, memory demand is high (one cause of GPU memory/bandwidth bottlenecks).

12.2 2) Computational complexity \(O(n^2)\)

For window size \(n\), the attention is \(O(n^2)\). Two operations proportional to the square of the window size are performed: once for the inner product of all query-key pairs in \(QK^\top\), and again when applying the attention weights to \(V\). As the window increases, the cost skyrockets.

12.3 Efficient Alternative

  • Efficient Transformer family(Tay et al., Efficient Transformers: A Survey, 2022): \(O(n^2)\) relaxation through sparse/low-rank approximation, etc.
  • Mamba and other State Space Model (SSM) families: Attempts to encode long contexts with lower complexity.
TipOpen problem

The current Transformer architecture is not the optimal structure that humans can imagine. Finding a deterministic function (architecture) that encodes long contexts more efficiently remains a major research topic that is still open.

13 Wireless communication perspective analogy

In the background of signal processing and wireless communication, attention is interpreted as a recombination of familiar concepts.

Transformer Concept Wireless Communication/Signal Processing Correspondence Description
Query/Key Inner Product \(q\cdot k\) Matched Filter/Correlator The correlation between the received signal and the template. The attention score is the correlation value.
Cosine Similarity Normalized Correlation Coefficient Compares only direction (waveform shape) after removing magnitude — Equivalent to normalized correlation in signal detection.
Softmax Weighted Sum Maximum Non-Coupling (MRC) type soft coupling Weighted coupling that gives greater weight to paths with high SNR/similarity.
Fixed Weights vs. Attention Fixed Beamforming vs. Adaptive Beamforming (MVDR/LCMV) Fixed beamformers use fixed weights independent of the input, while adaptive beamformers update weights based on received data — Attention is exactly the latter.
Multihead MIMO Spatial Multiplexing/Multibeam Different heads = Simultaneously form different spatial channels/beams.
Position Encoding (Sine Wave) OFDM Subcarrier/Pilot Indexing Orthogonally encodes “positions” using sine waves of different frequencies — the same format as OFDM indexing resources using subcarrier frequencies.
KV Cache Channel State/Latency Profile Memory Stores past states to maintain long time-axis dependencies.
\(O(n^2)\) Complexity Cost of computing the entire pairwise correlation matrix An operation on the scale of the correlation of all query-key pairs = covariance matrix.
TipOne-line summary metaphor

Attention ≈ Beamforming that adapts to data. A fixed beamformer (normal weights) uses the same weights regardless of where the signal comes from, but an adaptive beamformer (attention) looks at the received data (query/key) and redesigns the weights to form a beam in the desired direction (similar tokens).

15 Appendix: NumPy Implementation

The code below verifies the operation of attention, causal mask, multihead, and sine wave position encoding with a minimal implementation.

import numpy as np

def softmax(x, axis=-1):
    x = x - np.max(x, axis=axis, keepdims=True)
    e = np.exp(x)
    return e / np.sum(e, axis=axis, keepdims=True)

def scaled_dot_product_attention(Q, K, V, mask=None):
    """Attention(Q,K,V) = softmax(QK^T / sqrt(d_k)) V"""
    d_k = Q.shape[-1]
    scores = Q @ np.swapaxes(K, -1, -2) / np.sqrt(d_k)   # 쿼리-키 상관 (정합필터)
    if mask is not None:
        scores = np.where(mask, scores, -1e9)            # 마스킹 위치는 -inf
    A = softmax(scores, axis=-1)                         # 어텐션 가중치 (합=1)
    return A @ V, A
# 1) 셀프 어텐션
rng = np.random.default_rng(0)
n, d = 4, 8
X = rng.standard_normal((n, d))
Wq, Wk, Wv = (rng.standard_normal((d, d)) for _ in range(3))
Q, K, V = X @ Wq, X @ Wk, X @ Wv
out, A = scaled_dot_product_attention(Q, K, V)
assert np.allclose(A.sum(axis=1), 1.0)        # 각 행의 가중치 합 = 1

# 2) 인과(causal) 마스크: 하삼각만 허용 → 미래 차단
causal = np.tril(np.ones((n, n), dtype=bool))
out_c, A_c = scaled_dot_product_attention(Q, K, V, mask=causal)
assert np.allclose(A_c[np.triu_indices(n, 1)], 0, atol=1e-6)  # 미래 가중치 ~ 0
# 3) 멀티헤드 어텐션
class MultiHeadAttention:
    def __init__(self, d_model, h, seed=0):
        rng = np.random.default_rng(seed)
        self.h, self.dk = h, d_model // h
        self.Wq, self.Wk, self.Wv, self.Wo = (
            rng.standard_normal((d_model, d_model)) for _ in range(4))
    def _split(self, x):                 # (n, d) -> (h, n, dk)
        n, _ = x.shape
        return x.reshape(n, self.h, self.dk).transpose(1, 0, 2)
    def __call__(self, X, mask=None):
        Q, K, V = self._split(X @ self.Wq), self._split(X @ self.Wk), self._split(X @ self.Wv)
        out, _ = scaled_dot_product_attention(Q, K, V, mask)   # (h, n, dk)
        out = out.transpose(1, 0, 2).reshape(X.shape[0], -1)   # concat heads
        return out @ self.Wo

y = MultiHeadAttention(d_model=16, h=4)(rng.standard_normal((5, 16)))
assert y.shape == (5, 16)
# 4) 사인파 위치 인코딩
def positional_encoding(seq_len, d_model):
    pos = np.arange(seq_len)[:, None]
    i = np.arange(d_model)[None, :]
    angle = pos / np.power(10000, (2 * (i // 2)) / d_model)
    return np.where(i % 2 == 0, np.sin(angle), np.cos(angle))

PE = positional_encoding(seq_len=10, d_model=16)
assert PE.shape == (10, 16) and PE.min() >= -1 and PE.max() <= 1
print("모든 검증 통과")
