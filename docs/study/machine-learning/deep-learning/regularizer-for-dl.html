Regularization for Deep Learning

9 Regularization Techniques in Deep Learning — Mathematical Derivation and Intuition

Published

April 12, 2026

1 The Big Picture of Normalization

1.1 One-line summary

Regularization refers to “any modification aimed at reducing generalization error even if it increases training error.” Essentially, it is the act of injecting inductive bias into the model—that is, “our prior beliefs about aspects that cannot be determined by the data alone.”

1.2 Why it is necessary: Bias-Variance Decomposition

The expected squared error of the estimator \(\hat{f}_\mathcal{D}\) trained on finite data \(\mathcal{D}=\{(\bm{x}_i,y_i)\}_{i=1}^N\) is decomposed as follows.

\[ \underbrace{\mathbb{E}_{\mathcal{D}}\!\left[(\hat{f}_\mathcal{D}(\bm{x}) - f^*(\bm{x}))^2\right]}_{\text{기대 오차}} = \underbrace{\left(\mathbb{E}_\mathcal{D}[\hat{f}_\mathcal{D}(\bm{x})] - f^*(\bm{x})\right)^2}_{\text{Bias}^2} + \underbrace{\mathbb{E}_\mathcal{D}\!\left[(\hat{f}_\mathcal{D}(\bm{x}) - \mathbb{E}_\mathcal{D}[\hat{f}_\mathcal{D}(\bm{x})])^2\right]}_{\text{Variance}} \tag{1}\]

Deep neural networks have high capacity, making them prone to operating in variance-dominant regions. Regularization lowers the total sum of Food 1 by significantly reducing variance in exchange for accepting a small amount of bias.

NoteStatistical Inference Perspective

Normalization is isomorphic to the process of transforming an ill-posed inverse problem into a well-posed one. In wireless communication, when the number of paths to be estimated exceeds the number of antennas (under-determined), applying the prior knowledge that the channels are sparse as a \(\ell_1\) penalty to uniquely find the solution—this is compressed sensing, a classic example of normalization.

1.3 Three forms of normalization

The learning objective function generally takes the following form.

\[ \min_{\bm{\theta}} \; \underbrace{L(\bm{\theta};\mathcal{D})}_{\text{Loss: 최적화 대상}} + \underbrace{\Omega(\bm{\theta})}_{\text{Regularizer: 귀납적 편향}} \tag{2}\]

Hand-crafted normalization is unified into three perspectives.

Format Definition Representative Example
Hard constraint \(\min_{\bm{\theta}} L(\bm{\theta})\) st \(R(\bm{\theta}) \le c\) Weighted norm upper constraint
Soft constraint \(\min_{\bm{\theta}} L(\bm{\theta}) + \lambda R(\bm{\theta})\) \(\ell_2\) weight decay, \(\ell_1\)
Bayesian prior Posterior Probability Maximization (MAP) Introduction of prior \(p(\bm{\theta})\)

1.3.1 Equivalence of Hard Constraints and Soft Constraints

Hard constraint problem

\[ \bm{\theta}^* = \arg\min_{\bm{\theta}} L(\bm{\theta}) \quad \text{s.t.}\quad R(\bm{\theta}) \le c \]

If we apply the KKT condition for , for some \(\lambda^* > 0\)

\[ \bm{\theta}^* = \arg\min_{\bm{\theta}} \; L(\bm{\theta}) + \lambda^*\big(R(\bm{\theta}) - c\big) \]

holds. The constant \(-\lambda^* c\) is independent of \(\bm{\theta}\) and is therefore removed, so ultimately hard constraint = soft constraint. As \(c\) becomes smaller (stronger constraint), the corresponding \(\lambda^*\) becomes larger.

1.3.2 Normalization as a Bayesian prior: MAP = MLE + log prior

Bayes’ Theorem

\[ p(\bm{\theta}\mid\mathcal{D}) = \frac{p(\bm{\theta})\,p(\mathcal{D}\mid\bm{\theta})}{p(\mathcal{D})} \]

If we maximize the posterior probability (MAP) for , \(p(\mathcal{D})\) is independent of \(\bm{\theta}\), so

\[ \bm{\theta}_{\text{MAP}} = \arg\max_{\bm{\theta}} \underbrace{\log p(\mathcal{D}\mid\bm{\theta})}_{\text{MLE loss}} + \underbrace{\log p(\bm{\theta})}_{\text{Regularizer}} \tag{3}\]

ImportantAccurate Statement (Frequently Mistaken)
  • MAP = MLE + log-prior normalization term. MLE is a special case of MAP that assumes a uniform prior rather than “ignoring” the prior.
  • \(\ell_2\) Normalized \(\Leftrightarrow\) Gaussian prior \(p(\bm{\theta})=\mathcal{N}(\bm{0},\sigma^2 I)\) of MAP.
  • \(\ell_1\) Normalization \(\Leftrightarrow\) Derivation of MAP of Laplace prior \(\to\) sparsity.
  • \(\ell_0\) The penalty directly counts the number of non-zero elements, so it forces scarcity, but it is non-convex · NP-hard.

Now, building upon this framework, we will examine the 9 regularization techniques widely used in deep learning one by one. Note which term of Food 2 each technique modifies and how.

2 Dataset Augmentation

2.1 Core

Artificially increase the training data using a label-preserving transformation to make the model invariant to that transformation. “If you cannot obtain more real data, synthesize fake data.”

2.2 Formatting

For the transformation distribution \(T(\cdot\mid\bm{x})\) (e.g., rotation, translation, chromatic transformation), replace the loss with the expectation of the transformed input.

\[ \tilde{L}(\bm{\theta}) = \mathbb{E}_{(\bm{x},y)\sim\mathcal{D}}\;\mathbb{E}_{\tilde{\bm{x}}\sim T(\cdot\mid\bm{x})}\big[\ell\big(f_{\bm{\theta}}(\tilde{\bm{x}}),\,y\big)\big] \tag{4}\]

This has the effect of smoothing decision boundaries by “spreading” the data distribution along the transformation orbit.

TipNoise injection = \(\ell_2\) Normalization (for small Gaussians)

If we add small Gaussian noise \(\tilde{\bm{x}}=\bm{x}+\bm{\epsilon},\ \bm{\epsilon}\sim\mathcal{N}(\bm{0},\sigma^2 I)\) to the input and perform a second-order Taylor expansion of the regression loss, the expected value is approximately

\[ \mathbb{E}_{\bm{\epsilon}}[\ell] \approx \ell(\bm{x}) + \tfrac{\sigma^2}{2}\,\mathbb{E}\big[\|\nabla_{\bm{x}} f(\bm{x})\|^2\big] \]

, which acts as a penalty for the Jacobian norm (inducing flatness of the function). In other words, data augmentation is equivalent to adding an implicit normalization term.

2.3 Intuition and Caution

  • The transformation must be label invariant. Rotation augmentation is dangerous because rotating the handwritten ‘6’ by 180° results in ‘9’.
  • Domain knowledge determines good augmentation — this is why augmentation is called “manual inductive bias.”
NoteWireless communication analogy

This is equivalent to training the equalizer/receiver on multiple channel realizations. By sampling the fading channel using Monte-Carlo and training under various \(\bm{h}\) conditions, the receiver becomes robust to the entire channel distribution without overfitting to a specific channel. \(T\) in Equation Food 4 is the channel distribution \(p(\bm{h})\).

3 Adversarial Examples

3.1 Core

We intentionally create and train with adversarial perturbations that are almost identical to the human eye but trick the model. The primary purpose is robustness, but it also helps with generalization by making decision boundaries insensitive to changes in input.

3.2 Adversarial example generation: FGSM

If the loss \(J(\bm{\theta},\bm{x},y)\) is linearized first-order with respect to the input, the perturbation that maximizes the loss under the \(\ell_\infty\) constraint is the sign of the gradient (Fast Gradient Sign Method).

\[ \bm{x}_{\text{adv}} = \bm{x} + \epsilon \cdot \mathrm{sign}\big(\nabla_{\bm{x}} J(\bm{\theta},\bm{x},y)\big) \tag{5}\]

In high dimensions, even very small \(\epsilon\) perturbations accumulate across numerous dimensions and significantly shake the output (linearity hypothesis). A classic example illustrating this is when invisible perturbations are added to a panda image, causing it to be misclassified as a gibbon with 99% certainty.

3.3 Two learning strategies

  1. Injecting perturbation into input (Adversarial training): Add \(\bm{x}_{\text{adv}}\) from Food 5 to the training set. If written in minimax form

    \[ \min_{\bm{\theta}}\ \mathbb{E}_{(\bm{x},y)}\Big[\max_{\|\bm{\delta}\|\le\epsilon} J(\bm{\theta},\bm{x}+\bm{\delta},y)\Big] \]

— Robust optimization for the worst-case.

  1. Injecting noise into output target (Label smoothing): Smooths the one-hot target. For class count \(k\), small \(\epsilon\)

    \[ y_c^{\text{smooth}} = \begin{cases} 1-\epsilon & (\text{정답 클래스}) \\[4pt] \dfrac{\epsilon}{k-1} & (\text{나머지 클래스}) \end{cases} \tag{6}\]

Prevents softmax from running into infinite logits (prevents overconfidence) and mitigates gradient vanishing in high-confidence predictions.

NoteWireless communication analogy

minimax adversarial learning is exactly the same structure as a receiver design robust against jamming/worst-case interference. In the transmitter-jammer game, robust beamforming designed to guarantee performance even when the jammer pours power in the worst direction in the signal space corresponds to the internal max of Food 5.

4 Semi-Supervised Learning

4.1 Core

Combines labeled data (small amount) and unlabeled data (large amount). The distribution \(p(\bm{x})\) of the unlabeled data itself becomes normalization information, inducing the decision boundary to be placed in a low-density region rather than a dense region.

4.2 Formatting

The objective function is a combination of supervised terms and unsupervised (normalized) terms.

\[ L = \underbrace{\sum_{(\bm{x}_i,y_i)\in\mathcal{D}_L}\ell(f(\bm{x}_i),y_i)}_{\text{레이블 정보}} + \lambda\underbrace{\sum_{\bm{x}_j\in\mathcal{D}_U}\mathcal{R}(f,\bm{x}_j)}_{\text{분포 정보}} \]

Representative selection of non-guided item \(\mathcal{R}\):

  • Consistency Normalization (consistency): \(\mathcal{R}=\|f(\bm{x})-f(\tilde{\bm{x}})\|^2\), i.e., \(\bm{x}\), and its augmentation \(\tilde{\bm{x}}\) must have the same prediction (cluster assumption).
  • Entropy Minimization: \(\mathcal{R}=H(f(\bm{x}))\), to ensure the prediction is confident in one class — push the boundary into a low-density region.

4.3 Two scenarios

  • When labeled and unlabeled data are in the same representation domain: standard semi-map.
  • When it is a different representation domain: It aligns with transfer/self-supervised methods that learn shared representations.
NoteWireless communication analogy

It is isomorphic to semi-blind channel estimation. It roughly defines the channel using a small number of pilot symbols (=labels) and reduces the estimation variance by utilizing the statistics of a large number of data symbols (received signal distribution, stationarity, structures such as finite alphabets = non-label distribution information).

5 Multi-task Learning (MTL)

5.1 Core

Train multiple tasks simultaneously with a single model, but share the sub-representation \(\bm{h}^{\text{shared}}\). Each task acts as a data-dependent prior to the others, preventing the shared representation from overfitting to any single task.

5.2 structure

Code 
flowchart BT
    x["입력 x"] --> hs["h(shared): 공유 표현"]
    hs --> h1["h(1): 과제1 전용"]
    hs --> h2["h(2): 과제2 전용"]
    hs --> h3["h(3): 추가 인자"]
    h1 --> y1["y(1)"]
    h2 --> y2["y(2)"]

The objective function is the weighted sum of the losses per task.

\[ L_{\text{MTL}}(\bm{\theta}_{\text{shared}}, \{\bm{\theta}_t\}) = \sum_{t=1}^{T} \alpha_t\, L_t\big(\bm{\theta}_{\text{shared}}, \bm{\theta}_t;\ \mathcal{D}_t\big) \]

5.3 Why Normalization?

Since the shared parameter \(\bm{\theta}_{\text{shared}}\) must simultaneously satisfy the gradients of all tasks, the explorable hypothesis space is significantly narrowed. This acts as an implicit constraint imposed on the expression in Food 2 even without an explicit \(\Omega\). The effect is greater the more the assumption that tasks share a common generative factor holds true.

NoteWireless communication analogy

Joint Estimation — When a single receiver performs channel estimation, frequency offset compensation, and noise power estimation simultaneously based on a common statistic (shared representation), each estimation normalizes the other, thereby reducing the total estimation variance.

6 Early Stopping

6.1 Core

Stop training when the validation error no longer decreases. The most common, efficient, and almost free regularization. Since the longer training is done, the more the model overfits to the training set, the moment when generalization is optimal is used as a hyperparameter to control the “effective capacity”.

Code 
flowchart LR
    A["훈련 시작"] --> B["train↓ val↓<br/>(과소적합 탈출)"]
    B --> C["val 최저점<br/>= Early Stopping"]
    C --> D["train↓ val↑<br/>(과적합 시작)"]

6.2 Deep Insight: Early Stopping ≈ \(\ell_2\) Normalization

When gradient descent with a learning rate \(\epsilon\) is \(\tau\) step over the second-order approximated loss \(L(\bm{\theta})\approx L(\bm{\theta}^*) + \tfrac12(\bm{\theta}-\bm{\theta}^*)^\top H (\bm{\theta}-\bm{\theta}^*)\), each component shrinks as follows based on \(H=Q\Lambda Q^\top\) eigendecomposition.

\[ \theta^{(\tau)}_i = \big(1-(1-\epsilon\lambda_i)^{\tau}\big)\,\theta^*_i \]

Comparing this to the \(\ell_2\) normalized solution \(\theta^{\ell_2}_i = \frac{\lambda_i}{\lambda_i+\alpha}\theta^*_i\), in the small \(\epsilon\lambda_i\) approx.

\[ \boxed{\;\alpha \approx \frac{1}{\tau\epsilon}\;} \tag{7}\]

In other words, the fewer the step count \(\tau\) (=the earlier it stops), the greater the \(\ell_2\) regularization strength \(\alpha\). Early stopping learns the direction of large curvature (large \(\lambda_i\)) first and stops before the direction of small curvature is fully learned; this has exactly the same effect as weight decay suppressing the direction of small eigenvalues.

TipPractical advantages

If you were to manually explore \(\alpha\) of Food 7, you would have to retrain multiple times, but early stopping automatically selects the optimal regularization strength by following the validation curve in a single training iteration. So it is practically free.

NoteWireless communication analogy

It is similar to the iteration limit of iterative decoding (LDPC/Turbo). If it is run indefinitely, it can become unstable by being overly tailored to the realization of specific noise, so it is optimal to stop at the number of iterations where the verification BER is lowest.

7 Parameter Sharing / Tying

7.1 Core

Reduces degrees of freedom by forcing multiple parameters to be equal to or close to each other. For two similar tasks A and B, a penalty is applied to make \(\bm{w}^{(B)}\) closer to the already learned \(\bm{w}^{(A)}\).

7.2 Two variants

Soft tying (parameter tying): Adds a distance penalty to the loss.

\[ \Omega(\bm{w}^{(A)},\bm{w}^{(B)}) = \big\|\bm{w}^{(A)} - \bm{w}^{(B)}\big\|_2^2 \tag{8}\]

This is equivalent to the MAP of “\(\bm{w}^{(B)}\), where the prior mean is \(\bm{w}^{(A)}\)” (@see eq-map).

Hard sharing (parameter sharing): It forcibly shares identical parameters. CNN convolutional kernels are a prime example — by applying the same filter to every location in the image, it injects powerful prior knowledge of “translation invariance” and dramatically reduces the number of parameters and memory.

Soft tying Hard sharing
Format \(+\lambda\|\bm{w}^A-\bm{w}^B\|^2\) \(\bm{w}^A \equiv \bm{w}^B\)
Degrees of freedom Partially reduced Fully coupled
Representative Case Transfer Learning Fine-tuning CNN Kernel, RNN Time-shifting Sharing
NoteWireless communication analogy

This is equivalent to the time-invariant or stationarity assumption. Assuming that the channel is constant within a block and applying the same channel coefficient to all symbols is the same kind of statistical assumption as hard sharing, where CNNs share the same kernel at all locations.

8 Bagging (Bootstrap Aggregating)

8.1 Core

Multiple models are trained independently on different data subsets, and then the predictions are averaged (voted). The diversity of the dataset created by Bootstrap decorrelates errors between models, thereby directly reducing variance. A form of ensemble and model averaging.

8.2 Quantitative proof of variance reduction

Let \(k\) be the prediction error of the models, \(\epsilon_i\), let \(v=\mathbb{E}[\epsilon_i^2]\) be the variance of each error, and let \(c=\mathbb{E}[\epsilon_i\epsilon_j]\,(i\ne j)\) be the covariance between models. The variance of the mean prediction error \(\bar\epsilon=\tfrac1k\sum_i\epsilon_i\) is

\[ \mathbb{E}\!\left[\bar\epsilon^{\,2}\right] = \frac{1}{k^2}\,\mathbb{E}\!\left[\Big(\sum_i \epsilon_i\Big)^2\right] = \frac{1}{k}v + \frac{k-1}{k}c \tag{9}\]

When looking at the two extremes:

  • Perfectly Correlated(\(c=v\)): \(\mathbb{E}[\bar\epsilon^2]=v\) — Averaging does not decrease at all.
  • Completely uncorrelated (\(c=0\)): \(\mathbb{E}[\bar\epsilon^2]=\dfrac{v}{k}\) — Variance decreases inversely proportional to the number of models!

Therefore, the effectiveness of bagging depends on “making each model sufficiently strong while making them different (uncorrelated) from one another.”

ImportantThe effect of Bagging on bias

Food 9 only deals with variance. Since the bias shared by each model remains even after averaging, bagging is most effective for low-bias, high-variance models (e.g., deep decision trees, large neural networks).

NoteWireless Communication Analogy — The Most Accurate Correspondence

Food 9 is identical to the gain formula for diversity combining (e.g., MRC). When combining \(k\) receiving branches undergoing independent fading, the effective noise variance is reduced to \(1/k\) when the noise of the branches is uncorrelated (\(c=0\)), yielding a diversity order \(k\). The communication intuition that “the more independent branches, the better” is the ensemble intuition that “the more uncorrelated models, the better.”

9 Dropout: Another Type of Ensemble

9.1 Core

In every mini-batch, each unit is randomly removed with probability \(p\) for training. This is exponentially efficient bagging that trains \(2^n\) sub-networks simultaneously with shared weights in a single training session.

9.2 Training: Bernoulli mask

Multiply the mask ZZZPH0011658ZZZ for the hidden unit \(\bm{h}\) by \(\bm{m}\sim\text{Bernoulli}(1-p)\) (elementally independent).

\[ \tilde{\bm{h}} = \bm{m}\odot\bm{h}, \qquad m_j\in\{0,1\} \]

Different masks define different subnetworks, and all subnetworks share weights. This is the decisive difference from bagging — in bagging, models are independent, whereas in dropout, they share parameters.

9.3 Inference: Weight Scaling Inference Rule

During inference, the predictions of all subnetworks must be averaged (ensemble), but it is not possible to run all \(2^n\) units. Instead, it is approximated by the weight scaling rule. Since the unit was turned on with probability \(1-p\) during training, the weight (or activation) is multiplied by \((1-p)\) during inference to fit the expected input.

\[ \mathbb{E}_{\bm{m}}[\tilde{\bm{h}}] = (1-p)\,\bm{h} \]

This single forward propagation approximates the geometric mean ensemble of exponential subnetworks well (accurate for softmax output).

TipInverted Dropout (Practical Standard)

To avoid touching the inference, the surviving activations are usually pre-scaled by dividing them into \(1/(1-p)\) during training. Then, the inference can be used as is without scaling.

\[ \tilde{\bm{h}}_{\text{train}} = \frac{\bm{m}\odot\bm{h}}{1-p} \]

9.4 Why Generalization Improves

Each unit becomes unable to rely on the presence of specific peer units (co-adaptation), allowing each unit to learn robust features that are useful in themselves. This can also be interpreted as normalization that injects multiplicative noise into the input.

NoteWireless communication analogy

It is similar to random antenna selection or a distributed system robust to node failure. If trained to operate with only a random subset of antennas, it learns a robust coupling strategy that does not over-depend on a specific antenna.

10 Tangent Propagation

10.1 Core

is an explicit normalization that directly brings the directional derivative in a direction close to zero so that the output \(f(\bm{x})\) becomes locally invariant with respect to a “known variation direction”. Example: The output should not change when moving along a manifold formed by the same class examples.

10.2 Formatting

Let \(\bm{v}^{(i)}\) be the tangent vector of the class-invariant transformation in data \(\bm{x}\). If the gradient of the output is orthogonal to this tangent, it becomes insensitive to changes in direction. The normalization term is the sum of squares of the directional derivatives in the tangent direction.

\[ \Omega(f) = \sum_{i}\Big(\big(\nabla_{\bm{x}} f(\bm{x})\big)^\top \bm{v}^{(i)}\Big)^2 \tag{10}\]

Minimizing Food 10 \(\nabla_{\bm{x}} f \perp \bm{v}^{(i)}\), that is, the rate of change of output in the tangential direction disappears.

10.3 Relationship with data augmentation

Dataset Augmentation Tangent Propagation
Method Explicitly generate and learn modified inputs Implicitly penalize modification effects
Variation Size Large perturbations possible Very small (local) perturbations only
Cost Data growth Jacobian calculation

Essentially, both pursue the same goal (deformation invariance), but TP directly regulates infinitesimal deformations with first-order derivative information.

WarningTP’s Two Weaknesses
  1. Modeling only local deformation — Food 10 is a first-order approximation, so it cannot handle large deformations (dataset augmentation is superior in this respect).
  2. Poor compatibility with ReLU — When you need to make the gradient small, ReLU kills it to zero. Since TP assumes “shrunken” gradients, it works better with smooth activation than ReLU, which cuts off to zero.
NoteWireless communication analogy

This is equivalent to invariance design to known impairment. Making the receiver insensitive to “known deformation directions,” such as small carrier phase rotation or fine Doppler shift, is isomorphic to regulating the output sensitivity to that deformation direction to zero, as in Food 10.

11.3 Key Message

  1. All normalization can be understood within the big picture of Food 2 — Loss + Inductive Bias —.
  2. The three forms, Hard, Soft, and Bayesian-prior, are equivalent to each other through KKT and MAP (Food 3).
  3. Seemingly different techniques converge to the same effect: input noise, early stopping, and tangent prop all induce function flatness (Jacobian suppression) in some sense, and bagging and dropout are grouped into variance reduction ensemble.
  4. Wireless communication intuition — diversity coupling (=bagging), robust beamforming (=adversarial), semi-blind estimation (=semi-supervised), and stationarity assumption (=parameter sharing) — runs throughout this normalization.

12 Appendix: Executable Code

12.1 A. Bagging Variance Reduction (Food 9 numerical validation)

Code 
import numpy as np
rng = np.random.default_rng(0)

def ensemble_var(k, v=1.0, rho=0.0, trials=200_000):
    """k개 모델, 오차분산 v, 상관계수 rho일 때 평균오차의 분산을 추정."""
    c = rho * v
    # 공분산행렬 Sigma: 대각 v, 비대각 c
    Sigma = np.full((k, k), c) + np.eye(k) * (v - c)
    L = np.linalg.cholesky(Sigma)
    eps = rng.standard_normal((trials, k)) @ L.T   # 상관된 오차 샘플
    ebar = eps.mean(axis=1)
    return ebar.var()

for k in [1, 2, 4, 8, 16]:
    emp = ensemble_var(k, rho=0.0)
    theory = 1.0 / k            # c=0이면 v/k
    print(f"k={k:2d} | empirical={emp:.4f} | theory(v/k)={theory:.4f}")

It can be observed that the mean error variance decreases to \(1/k\) when is uncorrelated (\(\rho=0\)). Increasing \(\rho\) converges to \(\frac1k v+\frac{k-1}{k}c\) of Food 9.

12.2 B. Dropout Forward Propagation and Weight Scaling

Code 
import numpy as np
rng = np.random.default_rng(1)

def dropout_forward(h, p, training=True, inverted=True):
    """Bernoulli dropout. p = drop 확률."""
    if not training:
        return h if inverted else h * (1 - p)     # 표준 추론
    mask = (rng.random(h.shape) > p).astype(h.dtype)
    out = h * mask
    if inverted:
        out /= (1 - p)        # inverted dropout: 추론 무수정
    return out

h = np.ones(10_000)           # 모든 활성=1
p = 0.5
train_out = dropout_forward(h, p, training=True, inverted=True)
print(f"훈련 시 평균 활성(inverted) ≈ {train_out.mean():.3f}  (목표 1.0)")
print(f"실제 drop된 비율 ≈ {(train_out==0).mean():.3f}  (목표 {p})")

Inverted dropout preserves expected activity during training, so it does not require manipulation of inference.

12.3 C. Early Stopping ↔︎ \(\ell_2\) Equivalence (Food 7)

Code 
import numpy as np

# 이차 손실 L(theta) = 0.5 (theta-theta*)^T H (theta-theta*), H=diag(lams)
lams = np.array([5.0, 1.0, 0.1, 0.01])   # 곡률(고유값)
theta_star = np.ones_like(lams)
eps = 0.05                                # 학습률

def gd_solution(tau):
    # 성분별 closed-form: theta_tau = (1-(1-eps*lam)^tau) theta*
    return (1 - (1 - eps * lams) ** tau) * theta_star

def l2_solution(alpha):
    # theta = lam/(lam+alpha) theta*
    return lams / (lams + alpha) * theta_star

tau = 40
alpha_equiv = 1.0 / (tau * eps)          # 식 (early-l2)
print(f"tau={tau}, eps={eps}  ->  등가 alpha ≈ {alpha_equiv:.3f}\n")
print("성분 | early-stopping |  L2(alpha_equiv)")
for i, (a, b) in enumerate(zip(gd_solution(tau), l2_solution(alpha_equiv))):
    print(f"  {i}  |    {a:.4f}     |     {b:.4f}")

The direction of high curvature converges quickly to \(\theta^*\) (both close to 1), while the direction of low curvature is suppressed and stays at small values — early stopping and \(\ell_2\) normalization produce the same contraction.

12.4 D. FGSM Hostile Perturbation (Food 5)

Code 
import numpy as np

def fgsm(grad_x, eps):
    """입력 그래디언트로부터 FGSM 섭동을 만든다."""
    return eps * np.sign(grad_x)

x = np.array([0.2, -0.5, 0.9, -0.1])
grad = np.array([1.3, -0.4, 0.8, -2.1])   # dJ/dx (가정)
x_adv = x + fgsm(grad, eps=0.1)
print("원본 x      :", x)
print("적대적 x_adv:", np.round(x_adv, 3))
print("섭동 노름(∞):", np.abs(x_adv - x).max(), "= eps")

\(\ell_\infty\) under constraint, the perturbation that increases the loss the most is in the sign direction of the gradient, and its magnitude is exactly uniform \(\epsilon\).
