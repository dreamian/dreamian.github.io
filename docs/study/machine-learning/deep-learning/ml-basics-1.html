1 Bias-Variance Tradeoff

1.1 Hypothesis Class and Learning Bias

In machine learning, the selection of the hypothesis class (hypothesis space) creates a fundamental bias in the learning results. When attempting to fit data scattered on a 2D plane:

  • 1st-order polynomial (straight line): Since the model is simple, it cannot capture complex patterns → High bias, Low variance
  • 13th-order polynomial: Fits training data very accurately but predicts “fluctuating” on new data → low bias, high variance
NoteWhat is Hypothesis Class?

“Class” refers to the set of functions that a learning algorithm can select as a solution. This selection itself already introduces inductive bias into learning.

It is the same principle as when assuming a Rayleigh model for channel estimation in wireless communication, bias occurs in a Rician environment, and using an overly general model increases the variance of the estimate.

1.2 Intuitive Understanding of Bias and Variance

The best analogy for understanding Bias and Variance is dart throwing.

Assuming that multiple people train a model with different training datasets and produce predictions for the same test input \(x\):

  • Bias: How far the mean of the predicted values is from the correct answer → structural limitations of the model itself
  • Variance: How scattered the predicted values are from each other → the model’s sensitivity to the training data

Mathematically decomposing the expected error:

\[ E\left[(h_D(x) - y)^2\right] = \underbrace{\text{Bias}^2}_{\text{모델 구조의 한계}} + \underbrace{\text{Variance}}_{\text{데이터에 대한 민감도}} + \underbrace{\sigma^2}_{\text{irreducible noise}} \]

If you write each term clearly:

\[ \text{Bias}^2 = \left(E_D[h_D(x)] - \bar{y}(x)\right)^2 \]

\[ \text{Variance} = E_D\left[\left(h_D(x) - E_D[h_D(x)]\right)^2\right] \]

where \(\bar{y}(x) = E[y|x]\) is the Bayes optimal prediction for the given \(x\), and \(E_D[\cdot]\) is the expected value for all possible training datasets.

TipReasons why tradeoffs occur

Making the model more complex increases expressiveness and reduces bias, but it increases variance as it becomes responsive to small fluctuations in the data. Conversely, simplifying the model reduces variance, but increases bias due to a lack of expressiveness. Since Total Error = Bias² + Variance + Noise, the goal is to find the “sweet spot” that minimizes this sum.

Wireless Communication Analogy: In an MMSE channel estimator, increasing the filter order allows you to capture the channel’s frequency selectivity, which reduces bias, but it results in noise amplification (increase in variance). This is exactly the bias-variance tradeoff.

1.3 Training Error, True Error, Test Error

The three errors are at different levels of accessibility.

1.3.1 Training Error

This is the average loss on the given training data:

\[ \text{error}_{\text{train}}(\mathbf{w}) = \frac{1}{N_{\text{train}}} \sum_{j=1}^{N_{\text{train}}} \left( t(\mathbf{x}_j) - \sum_i w_i h_i(\mathbf{x}_j) \right)^2 \]

Meaning of each symbol here:

  • \(t(\mathbf{x}_j)\): Target value (Answer)
  • \(h_i(\mathbf{x})\): basis function — Defines how the input is transformed. For example, if it is polynomial regression, \(h_0(x)=1, h_1(x)=x, h_2(x)=x^2, \ldots\)
  • \(w_i\): Weights — Learning parameters that determine the contribution of each basis function
  • \(\sum_i w_i h_i(\mathbf{x}_j)\): Model’s predicted value

Learning is adjusting these \(w_i\) to find \(\mathbf{w}^*\) that minimizes the training error.

NoteWhy use Squared Error?
  1. Mathematical Convenience: Squared functions are differentiable everywhere and are convex since they are quadratic functions. The absolute value error (\(|t-\hat{y}|\)) is not differentiable at 0.
  2. Statistical Basis: If the noise is Gaussian, minimizing MSE is equivalent to MLE under Gaussian likelihood
  3. Bias-Variance Disassembly: A clean disassembly of \(E[(h_D(x)-y)^2] = \text{Bias}^2 + \text{Variance} + \text{Noise}\) is possible because it is an MSE.
  4. Penalty for Large Errors: If the error is double, the penalty is quadrupled → Prevents large mistakes

1.3.2 True Error (Prediction Error)

Expected error for all possible inputs:

\[ \text{error}_{\text{true}}(\mathbf{w}) = E_{\mathbf{x}} \left[ \left( t(\mathbf{x}) - \sum_i w_i h_i(\mathbf{x}) \right)^2 \right] = \int_{\mathbf{x}} \left( t(\mathbf{x}) - \sum_i w_i h_i(\mathbf{x}) \right)^2 p(\mathbf{x}) d\mathbf{x} \]

The integral cannot be calculated directly. This is because \(t(x)\) is unknown for all \(x\), and \(p(x)\) is also unknown. Therefore, it is approximated by the Monte Carlo integral.

1.3.3 The principle of Monte Carlo approximation

Key Idea: Replace integral with sample mean.

\[ E_{x \sim p}[g(x)] = \int g(x) p(x) dx \approx \frac{1}{M} \sum_{j=1}^{M} g(x_j), \quad x_j \sim p(x) \text{ i.i.d.} \]

The reason this holds is the Law of Large Numbers: If \(M \to \infty\), the sample mean converges to the expected value.

ImportantWhy shouldn’t training data be used as Monte Carlo samples?

Although the training data is also an iid sample drawn from \(p(\mathbf{x})\), because \(\mathbf{w}\) is optimized for that very data, the training error becomes an optimistically biased estimator of the true error:

\[E[\text{error}_{\text{train}}(\mathbf{w}^*)] \leq \text{error}_{\text{true}}(\mathbf{w}^*)\]

Optimistically biased = Biased to appear better than reality. It is like the situation where, after studying with past exam questions, evaluating your skills using the same questions results in a score higher than your actual ability.

1.3.4 Test Error (Generalization Error)

This is a Monte Carlo approximation using separate test data:

\[ \text{error}_{\text{test}}(\mathbf{w}) = \frac{1}{N_{\text{test}}} \sum_{j=1}^{N_{\text{test}}} \left( t(\mathbf{x}_j) - \sum_i w_i h_i(\mathbf{x}_j) \right)^2 \]

Since the test data was not involved in model training, the test error is the unbiased estimator of the true error:

\[E[\text{error}_{\text{test}}(\mathbf{w}^*)] = \text{error}_{\text{true}}(\mathbf{w}^*)\]

1.3.5 Summary of the relationship between the three errors

Comparison of three errors
Error Accessibility Role Bias
True Error Uncalculable (Theoretical Concept) Ultimate Minimization Goal —
Test Error Computable (separate data) Proxy evaluation of true error Unbiased
Training Error Computable (Training Data) Target for Optimization in Training Process Optimistic Bias

Practically speaking, the most important factor is Test Error. Since the true error is unknown and the training error is biased, the test error is the final criterion for judging model performance.

1.4 Relationship between Error and Model Complexity

1.4.1 When changing model complexity

  • Training error (blue curve): Complexity ↑ → Monotonically decreasing. This is because a 13th-degree polynomial can pass through every point in the training data.
  • True error (red curve): U-shaped. Initially improves due to reduced bias, then worsens due to increased variance.
  • Test error (Green curve): Estimates the true error, but variability is large due to the finite sample size.

1.4.2 When changing the number of data (fixed model complexity)

Reason for the increase in training error: When there is little data, it is easy to fit all points, but as the amount of data increases, “compromises” are required because more constraints must be satisfied with a fixed representational power.

Reason why Test/True error decreases: As the amount of data increases, noise is canceled out, leaving only the true patterns, allowing the model to learn the true structure better. This is the same principle as the variance of the estimator decreasing to \(\text{Var}(\bar{X}) = \sigma^2/N\).

Residual error (bias) at the point of convergence: This residual error, which does not become zero even when the amount of data increases infinitely, is the structural limitation (bias) of the model itself.

Reason why the decay pattern looks like exponential decay:

\[ \text{Test error} \approx \underbrace{\text{Bias}^2}_{\text{상수}} + \underbrace{\frac{c}{N}}_{\text{Variance}} \]

If \(N\) increases, \(c/N\) decreases and only \(\text{Bias}^2\) remains.

WarningIs having a lot of data always good?

Most are good, but not “absolutely.”

  1. Differences in Returns: Once Bias² is reached, performance improvement is minimal even with more data. At this point, changing the model is the answer.
  2. Data Quality: Mixing in noisy or incorrectly labeled data is actually harmful
  3. Double descent: There is a section where the test error temporarily increases near the interpolation threshold, where the number of data points is similar to the number of parameters.
  4. Distribution Mismatch: Adding data from a different distribution than the existing data confuses the model
  5. Computational Cost: Data 10x → Training time more than 10x

1.5 Formal definition of overfitting

hypothesis \(h\) is said to be overfitting, that there exists another hypothesis \(h'\) within the same hypothesis space \(H\):

\[\text{error}_{\text{train}}(h) < \text{error}_{\text{train}}(h') \quad \text{이면서 동시에} \quad \text{error}_{\text{true}}(h) > \text{error}_{\text{true}}(h')\]

It is the case that [] is better in training but worse in reality.

1.6 Benign Overfitting

This is a phenomenon recently discovered in deep learning where an overparameterized model has a training error of 0 (perfect interpolation) on noisy training data while maintaining a low generalization error.

NoteMeaning of Interpolation

In ML, “a model interpolates training data” means that the training error is exactly 0 across all training data. This implies that the model’s predictions perfectly match the target values of all training samples. It is the same concept as interpolation in wireless communication, which fills in channel values between pilot locations.

Interpolation threshold = The point where the number of model parameters equals the number of training data. Once this point is exceeded, the model gains sufficient degrees of freedom to perfectly interpolate the training data.

Three types of overfitting:

  • Benign: The model asymptotically converges to the optimal predictor
  • Tempered: Converges to a test risk level slightly higher than optimal but constant
  • Catastrophic: Overfitting in the traditional sense — Failure of generalization

2 Capacity and VC Dimension

2.1 Capacity (Capacity)

Capacity is the ability of a model to express a wide variety of functions. The way to adjust capacity is to select the hypothesis space.

In the underfitting zone (insufficient capacity), both training error and generalization error are high, while in the overfitting zone (excessive capacity), training error is low but generalization error increases. The point where the generalization gap is minimized is the optimal capacity.

2.2 VC Dimension

This is a concept proposed by Vladimir Vapnik and Alexey Chervonenkis in 1971.

VC dimension \(h\) is the maximum number of points that the classifier \(f\) can shatter. “Shatter” means that all possible label combinations (\(2^n\)) of those points can be perfectly classified.

Key Examples:

  • Linear Classifier: VC = \(d\) in dimension \(d + 1\)
  • Neural Network: VC ≈ Number of Parameters
  • 1-nearest neighbor: VC = \(\infty\)
NoteThe reason why the VC dimension of 1-NN is infinite

1-NN copies the label of the nearest point in the training data when a new input comes in. Since the point closest to the training data \(x_j\) is itself (distance=0), any label combination is classified 100% accurately on the training data. Whether there are \(n\) points or \(n=100,000\) points, shatter is always possible → VC dimension = \(\infty\).

However, if the VC dimension is infinite = the capacity is infinite = the risk of overfitting is infinite. Training error is always 0, but test error can be bad.

2.3 VC Bound

Vapnik’s Core Theorem: Probability \(1 - \eta\) Above,

\[ \text{TESTERR} \leq \text{TRAINERR} + \sqrt{\frac{h(\log(2R/h) + 1) - \log(\eta/4)}{R}} \]

where \(h\) is the VC dimension, \(R\) is the number of training samples, and \(\eta\) is the failure probability.

Interpretation of this inequality: “Test error can be up to ‘this much’ larger than the training error”

Behavior of the square root term (upper bound of the generalization gap):

  • \(h\) ↑ (Model complexity) → Increased penalty → Test error can be large even if training error is small
  • \(R\) ↑ (Large amount of data) → Decrease in penalty → Decrease in generalization gap
  • \(\eta\) ↓ (High probability guaranteed) → Bound loosens

The key ratio is \(h/R\), i.e., (model complexity)/(amount of data).

ImportantLimitations and Alternatives of VC Bound

VC bound is very conservative (loose), so while it is useful for qualitative understanding, it has limitations in quantitative prediction.

Practical Alternative:

  1. Cross-validation: Dividing data into \(k\) folds and performing alternating validation — the most common
  2. Direct measurement of generalization gap: Monitoring the size of \(\text{Test error} - \text{Training error}\)
  3. PAC-Bayes bound: \(\text{Test error} \leq \text{Train error} + \sqrt{\frac{D_{KL}(\text{posterior}\|\text{prior}) + \log(n/\delta)}{2n}}\)
  4. Experimental Evaluation: Reporting test error across multiple benchmarks is the main method of modern deep learning

3 Regularization and Inductive Bias

3.1 Inductive Bias

To improve generalization when training data is limited, introduce inductive bias:

  • Maximum conditional independence: Used in Naive Bayes
  • Maximum margin: Used in SVM
  • Minimum description length: Occam’s Razor principle
  • Minimum features: Remove useless features
  • Nearest neighbor: Label determined by majority vote of neighbors

3.2 Occam’s Razor

“Pluralitas non est ponenda sine necessitate” — Do not make things unnecessarily complicated.

Short hypotheses have a low probability of fitting the data by chance, while long hypotheses have a high probability of fitting by chance. However, there is a counterargument—that assuming the hypothesis space is small is itself a bias.

3.3 No Free Lunch Theorem

Wolpert & Macready (1997): Averaging over all possible data generation distributions, no classification algorithm is universally superior to another.

Therefore, the algorithm must be designed to work well for a specific task.

TipNFLT and AGI

NFLT does not directly deny AGI. The key condition is a “uniform mean over all possible distributions,” but the real world is not a uniform distribution due to structures such as physical laws and causal relationships. What NFLT teaches is that “learning is impossible without inductive bias.”

4 Maximum Likelihood Estimation (MLE)

4.1 The connection between Bayes’ Theorem, MLE, and KL Divergence

4.1.1 The Fundamental Meaning of Bayes’ Theorem

\[ \underbrace{P(\theta|\mathcal{D})}_{\text{Posterior}} = \frac{\overbrace{P(\mathcal{D}|\theta)}^{\text{Likelihood}} \cdot \overbrace{P(\theta)}^{\text{Prior}}}{\underbrace{P(\mathcal{D})}_{\text{Evidence}}} \]

  • Likelihood \(P(\mathcal{D}|\theta)\): How well does this model (\(\theta\)) explain this data?
  • Prior \(P(\theta)\): Existing knowledge about parameters before viewing data
  • Posterior \(P(\theta|\mathcal{D})\): Beliefs updated after viewing the data
  • Evidence \(P(\mathcal{D})\): Normalization constant

4.1.2 Meaning of Evidence \(P(\mathcal{D})\) — Marginalization

\[ P(\mathcal{D}) = \int P(\mathcal{D}, \theta) \, d\theta = \int P(\mathcal{D}|\theta) P(\theta) \, d\theta \]

This is the Law of Total Probability: “Since we don’t know what \(\theta\) is, we eliminate \(\theta\) by weighted summing all possible \(\theta\).”

If you grasp the intuition with discrete examples:

\[P(\mathcal{D}) = \sum_{\text{all } \theta} P(\mathcal{D}|\theta) \cdot P(\theta) = \text{모든 시나리오의 가중 평균}\]

TipWireless Communication Analogy: Average BER

\[P(\text{error}) = \int_0^\infty P(\text{error}|\gamma) \cdot p(\gamma) \, d\gamma\]

It is structurally equivalent to integrating “error probability × probability of that SNR being realized when SNR is \(\gamma\)” over all possible SNRs.

4.1.3 KL Divergence and MLE Equivalence Relation

If we set \(p_{\text{data}}\) as the true distribution of the data and \(p_{\text{model}}(x;\theta)\) as the model distribution:

\[ D_{KL}(p_{\text{data}} \| p_{\text{model}}) = E_{x \sim p_{\text{data}}}[\log p_{\text{data}}(x)] - E_{x \sim p_{\text{data}}}[\log p_{\text{model}}(x;\theta)] \]

Since the first term is a constant independent of \(\theta\):

\[ \arg\min_\theta D_{KL} = \arg\max_\theta E_{x \sim p_{\text{data}}}[\log p_{\text{model}}(x;\theta)] \approx \arg\max_\theta \sum_{i=1}^n \log p_{\text{model}}(x_i;\theta) \]

ImportantKey Conclusion

MLE is equivalent to minimizing the KL divergence between the model distribution and the data distribution.

4.2 Notation: \(P(y|x;\theta)\)

\[P(y \,|\, x;\, \theta)\]

  • \(|\) (conditioning bar): Conditional probability given \(x\). Both \(x\) and \(y\) are random variables
  • \(;\) (semicolon): \(\theta\) is not a random variable but a parameter (setting value) defining the distribution
NoteAren’t the semicolon and argmax a contradiction?

No. Changing \(\theta\) means changing “which distribution to choose”, not treating \(\theta\) as a random variable. For each \(\theta\) value, a probability distribution \(p(\cdot;\theta)\) is defined, and MLE selects the one among these distributions that best explains the data.

  • MLE: Views \(\theta\) as a parameter (semicolon \(;\)) → Frequentist perspective
  • MAP: View \(\theta\) as a random variable (vertical line \(|\)) → Bayesian perspective

4.3 \(\prod\) (uppercase pi) and iid

\[ \theta_{\text{ML}} = \arg\max_\theta p_{\text{model}}(\mathbb{X};\theta) = \arg\max_\theta \prod_{i=1}^{m} p_{\text{model}}(\mathbf{x}^{(i)};\theta) \]

  • Just as \(\sum\) is a repetition of addition, \(\prod\) is a repetition of multiplication.
  • Under the iid assumption, the joint probability is decomposed into the product of each probability
  • Applying logarithm changes the product to the sum: \(\log \prod = \sum \log\)
NoteRelationship between iid and log
  • Applying the logarithm itself is independent of iid. Since it is a monotonically increasing function, it is possible at any time.
  • What requires iid is the step of “decomposing the product into a sum”:
    • Independent: Allows using joint as multiplication
    • Identically distributed: Since each term has the same form, it can be optimized into a single \(\theta\).

4.4 MLE: Coin Toss Example

\(P(\text{Head}) = p\), \(P(\text{Tail}) = 1-p\), each flip is iid

When observing \(\alpha_H\) heads and \(\alpha_T\) tails:

\[ P(\mathcal{D}|p) = \binom{\alpha_H + \alpha_T}{\alpha_H} p^{\alpha_H}(1-p)^{\alpha_T} \]

NoteEach flip is Bernoulli, and the sum of the flips is Binomial

Individual flips follow a Bernoulli(p) distribution, and the number of heads follows a Binomial(n,p) distribution.

Maximize Log-likelihood:

\[ \arg\max_p \; \alpha_H \log p + \alpha_T \log(1-p) \]

Differentiate and set to 0:

\[ \frac{\alpha_H}{p} - \frac{\alpha_T}{1-p} = 0 \implies \hat{p}_{\text{MLE}} = \frac{\alpha_H}{\alpha_H + \alpha_T} = \frac{k}{n} \]

WarningOptimality Guarantee: Boundaries and Secondary Conditions

The derivative = 0 alone cannot guarantee the optimal solution. Complete argument:

  1. Check Boundary: From \(p=0, p=1\) to \(\log 0 = -\infty\) → Boundary cannot be maximum (except when \(\alpha_H > 0\) and \(\alpha_T > 0\))
  2. 2nd derivative: \(\frac{d^2\Phi}{dp^2} = -\frac{\alpha_H}{p^2} - \frac{\alpha_T}{(1-p)^2} < 0\) → concave function → critical point is global maximum

4.5 Conditional Log-Likelihood

In supervised learning:

\[ \theta_{\text{ML}} = \arg\max_\theta \sum_i \log P(y_i | x_i; \theta) \]

This is equivalent to minimizing the loss function in deep learning — minimizing negative log-likelihood = MLE.

5 Bayesian Learning and MAP

5.1 From MLE to MAP

Limitation of MLE: If you flip a coin 3 times and all 3 are heads, \(\hat{p} = 1\). However, there is prior knowledge that “coins are usually 50:50”.

ImportantMLE does not “ignore” the Prior, but “assumes it is Uniform”

\[\hat{\theta}_{\text{MAP}} = \arg\max_\theta P(\mathcal{D}|\theta) \cdot P(\theta)\]

If you set it to \(P(\theta) = c\) (uniform):

\[= \arg\max_\theta P(\mathcal{D}|\theta) \cdot c = \arg\max_\theta P(\mathcal{D}|\theta) = \hat{\theta}_{\text{MLE}}\]

MLE is a special case of MAP (uniform prior). Uniform prior = expression “all parameter values are lexicographically equivalent”.

5.2 Conjugate Prior

A prior for which the posterior belongs to the same distribution family when the likelihood and the prior are multiplied is called a conjugate prior.

5.2.1 Why is it necessary?

To find the posterior, we must calculate the evidence \(P(\mathcal{D}) = \int P(\mathcal{D}|\theta) P(\theta) d\theta\), but this integral is generally very difficult or impossible. Using a conjugate prior allows us to know the form of the posterior in advance, resulting in a closed form.

NoteWhat is a Closed Form?

is an expression that can precisely write the answer using a combination of a finite number of standard mathematical operations (arithmetic operations, exponents, logarithms, exponents, etc.). Substituting numbers yields the answer immediately, and no iterative calculations or numerical approximations are required.

  • Closed form: \(\hat{p} = \frac{\alpha_H + \beta_H - 1}{\alpha_H + \beta_H + \alpha_T + \beta_T - 2}\)
  • Not a closed form: Logistic regression MLE → Gradient descent required

5.2.2 Binomial + Beta: Representative Conjugate Pair

Likelihood: \(P(\mathcal{D}|p) \propto p^{\alpha_H}(1-p)^{\alpha_T}\)

Prior (Beta distribution): \(P(p) = \frac{p^{\beta_H - 1}(1-p)^{\beta_T - 1}}{B(\beta_H, \beta_T)} \sim \text{Beta}(\beta_H, \beta_T)\)

Here, \(B(\beta_H, \beta_T) = \int_0^1 p^{\beta_H-1}(1-p)^{\beta_T-1}dp\) is a normalization constant that adjusts the total area of the distribution to 1. Since it does not depend on \(p\), it can be ignored in argmax.

Posterior = Likelihood × Prior:

\[ P(p|\mathcal{D}) \propto p^{\alpha_H + \beta_H - 1}(1-p)^{\alpha_T + \beta_T - 1} \sim \text{Beta}(\alpha_H + \beta_H, \; \alpha_T + \beta_T) \]

Prior(Beta) → Data Observation → Posterior(Beta). The shape of the distribution is preserved and only the parameters are updated!

Why this works: Since both the Beta distribution and the Binomial likelihood are in the form of powers of \(p\), when multiplied, only the exponents are added according to the law of exponents (\(p^a \cdot p^b = p^{a+b}\)), and the form is preserved.

5.2.3 Intuition of the Beta Distribution: The Meaning of \(\beta_H\) and \(\beta_T\)

\(\beta_H, \beta_T\) can be considered as “a result virtually observed before seeing the data”:

Intuition of Beta distribution parameters
Distribution Meaning Form
Beta(1,1) No virtual observations Uniform distribution (nothing known)
Beta(2,2) Virtual observation 1 head, 1 tail Weak peak near \(p=0.5\)
Beta(5,5) 4 heads, 4 tails virtual observation Strong peak near \(p=0.5\)
Beta(30,20) Virtual observation on heads 29, tails 19 Very narrow peak near \(p=0.6\)

Key: \(\beta_H - 1\) is the number of virtual heads, \(\beta_T - 1\) is the number of virtual tails.

5.2.4 Major Conjugate Pair

Summary of Major Conjugate Pairs
Likelihood Conjugate Prior Posterior
Bernoulli/Binomial Beta Beta
Multinomial Dirichlet Dirichlet
Gaussian (mean unknown) Gaussian Gaussian
Gaussian (variance unknown) Inverse-Gamma Inverse-Gamma
Poisson Gamma Gamma

5.3 MAP Estimator

If you use Beta prior, the posterior is also Beta:

\[ P(p|\mathcal{D}) \sim \text{Beta}(\alpha_H + \beta_H, \; \alpha_T + \beta_T) \]

MAP takes the mode of the posterior. Applying the logarithm and differentiating in the same way as MLE:

\[ \hat{p}_{\text{MAP}} = \frac{\alpha_H + \beta_H - 1}{\alpha_H + \beta_H + \alpha_T + \beta_T - 2} \]

5.3.1 Check with numbers

Coin 3, 3 heads (\(\alpha_H=3, \alpha_T=0\)), Prior = Beta(2,2):

\[\hat{p}_{\text{MLE}} = \frac{3}{3} = 1.0 \quad \text{vs.} \quad \hat{p}_{\text{MAP}} = \frac{3+2-1}{3+2+0+2-2} = \frac{4}{5} = 0.8\]

5.3.2 The Core Intuition of MAP

\[ \hat{p}_{\text{MAP}} = \frac{\text{실제 앞면} + \text{가상 앞면}}{\text{실제 전체} + \text{가상 전체}} \]

MAP calculates the ratio by combining “virtual prior observations” and “actual observations”.

5.3.3 MAP → MLE convergence at \(N \to \infty\)

Coin 1000, 800 heads:

\[\hat{p}_{\text{MAP}} = \frac{800+2-1}{800+2+200+2-2} = \frac{801}{1002} \approx 0.7994 \approx 0.8 = \hat{p}_{\text{MLE}}\]

If there is enough data, the influence of the prior disappears and converges from MAP to MLE. This is because \(\beta\) is constant, whereas \(\alpha\) grows in proportion to \(N\).

TipMAP in wireless communication = MMSE channel estimation
  • LS Estimation = MLE: Channel estimation based solely on receive pilots. Relying only on data.
  • MMSE Estimation = MAP: Uses channel prior statistics (correlation matrix, power delay profile) as a prior

The reason MMSE is much better than LS when the number of pilots is small is precisely the regularization effect of the prior. As the number of pilots increases infinitely, MMSE converges to LS.

5.4 Regularization = MAP

L2 regularization (weight decay), almost always used in deep learning:

\[ \mathcal{L}(\theta) = \underbrace{\sum_i -\log P(y_i|x_i;\theta)}_{\text{negative log-likelihood}} + \underbrace{\lambda \|\theta\|^2}_{\text{regularization}} \]

is equivalent to the MAP using the Gaussian prior \(P(\theta) = \mathcal{N}(0, \sigma^2 I)\) (\(\lambda = \frac{1}{2\sigma^2}\)).

Correspondence between Regularization and MAP
Method Formula Meaning
Pure MLE \(\mathcal{L} = -\log P(\mathcal{D}|\theta)\) No Prior (uniform)
L2 Reg (MAP) \(\mathcal{L} = -\log P(\mathcal{D}|\theta) + \lambda\|\theta\|^2\) Gaussian prior
L1 Reg (MAP) \(\mathcal{L} = -\log P(\mathcal{D}|\theta) + \lambda\|\theta\|_1\) Laplace prior

Since there are almost no cases of learning without regularization, most practical learning is effectively MAP.

6.1 Vector notation (bold)

  • \(\mathbf{x}\), \(\mathbf{w}\) (bold): vector
  • \(x\), \(w\) (Regular text): Scalar

Distinction method for handwriting/board writing:

  • Underlined: \(\underline{x}\) — Most common, widely used in engineering
  • Arrow: \(\vec{x}\) — Common in physics but rarely used in ML
  • LaTeX: \mathbf{x} or \boldsymbol{x}

6.2 pronunciation

  • MLE: “M-L-E” (each letter separately)
  • MAP: “Map” (/mæp/, identical to the English word map)

7 Key Summary

  1. Bias-Variance Tradeoff is the fundamental tension between model complexity and generalization performance
  2. VC dimension is a quantitative measure of model complexity, but cross-validation is more useful in practice.
  3. No Free Lunch Theorem: Since there is no universally optimal algorithm, inductive bias is essential.
  4. MLE = Parameter estimation based solely on data = Minimization of KL divergence = MAP assuming a uniform prior
  5. MAP = Parameter estimation using prior knowledge = Probabilistic interpretation of regularization
  6. Conjugate prior is a mathematical convenience that allows the posterior to be obtained in a closed form
