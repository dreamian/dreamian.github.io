1 Introduction: Today’s Big Picture

The content covered today is divided into two axes.

  1. Making Transformers Cheaper — Attempts to reduce the \(\mathcal{O}(n^2)\) cost of Self-attention. The leading example is Mamba from the State Space Model (SSM) family.
  2. Handling various types of data in one space — a multimodal model that combines text, images, and audio into a single embedding space. The core tools for this are CLIP and subsequent models (SigLIP, SigLIP 2).

These two are actually two faces of the same question. The first axis is “How to efficiently encode long contexts?”, and the second axis is “How to align heterogeneous information into the same coordinate system?”. From the perspective of a wireless communications major, the former naturally translates to the filter complexity-performance trade-off, and the latter to the matched filtering and diversity combining problem. This correspondence is specified in the “View via Wireless Communication” box at the end of each section.

2 Review: The Limitations of the Transformer

2.1 What was good

Self-attention densely encodes contextual information by directly connecting all token pairs within a window. Unlike RNNs, which compress information into a single hidden state and transmit it sequentially, it examines long-range dependencies all at once.

2.2 Two essential limitations

ImportantLimit 1 — Cannot see outside the window

Attention concatenates only tokens within the consideration window. Context outside the window cannot be encoded in principle.

ImportantLimit 2 — Cost is the square of the window size

If the window size is \(n\), the time and memory complexity is because scores are calculated for all query-key pairs \[ \mathcal{O}(n^2 d) \] . Increasing the window size allows for more context (\(\Rightarrow\) better alignment and accuracy), but the cost increases exponentially.

2.2.1 Why Squares of All Things? (3-Step Causal Chain)

  1. Create \(Q = XW_Q,\; K = XW_K,\; V = XW_V\) from input \(X \in \mathbb{R}^{n \times d}\).
  2. The moment the score matrix \(S = QK^\top \in \mathbb{R}^{n \times n}\) is created, the number of elements is \(n^2\). This single line \(\Rightarrow\) is the source of squared complexity.
  3. \(\text{softmax}(S/\sqrt{d})\,V\) also undergoes operations of the same scale as \(n^2\). Therefore, if the window is doubled, the cost becomes four times higher.

The industry responds in two ways: (a) simply handling large Windows with more expensive hardware (H100, H200, B100/B200 …), or (b) an efficiency transformer that algorithmically lowers the cost itself. The efficiency trend seeks to reduce complexity through \(\mathcal{O}(n^2) \to \mathcal{O}(n\log n) \to \mathcal{O}(n)\). Mamba is a prime example of the latter.

TipView via Wireless Communication — Direct Convolution vs FFT

The effort to reduce \(\mathcal{O}(n^2)\) to \(\mathcal{O}(n\log n)\) or \(\mathcal{O}(n)\) shares the same motivation as the classic strategy in communications signal processing of replacing direct time-domain convolution (\(\mathcal{O}(n^2)\)) with FFT-based frequency-domain product (\(\mathcal{O}(n\log n)\)). The goal of “reducing the order of complexity while maintaining accuracy” is the same.

3 Mamba and State-Space Model (SSM)

3.1 At a glance

Mamba is an efficient model for sequence encoding named after the black mamba (a fast and deadly snake). It is based on the Structured State Space Sequence model (S4), which is simplified through S5 and adopts the selective version S6.

Code 
flowchart LR
  S4["S4<br/>(2021, 구조화 SSM)"] --> S5["S5<br/>(단순화)"]
  S5 --> S6["S6<br/>(Selective)"]
  S6 --> M["Mamba<br/>(2023)"]

3.2 Two key ideas

3.2.1 (1) Selective mechanism (S6)

  • Maintain a small, fixed-size window, but keep only the highly relevant tokens inside it.
  • “Relevance” is measured in a manner similar to the gating mechanism of RNNs. That is, it dynamically decides which information to remember and which to discard based on the input.
NoteDetails are everything

The idea itself (“keep only important tokens”) is simple, but what is considered important (importance score function) and how the selection is made determine performance. This is the core contribution of the original paper (Gu & Dao, Mamba: Linear-Time Sequence Modeling with Selective State Spaces, 2023).

3.2.2 (2) Hardware-aware parallel scan

Linear cycle \(h_t = A h_{t-1} + B x_t\) is essentially sequential, but it can be reconfigured into associative scan (prefix-sum) operations and parallelized on the GPU. Mamba implements this scan to match the GPU memory hierarchy (SRAM/HBM) to boost inference speed.

WarningWork Memo

Since this hardware-aware kernel is not yet natively embedded in NVIDIA hardware, the potential efficiency gains of Mamba have not been fully realized. Custom kernel/hardware optimization remains an open research and engineering opportunity.

3.3 Variants of Mamba

3.3.1 One-line summary of design philosophy

  • Mamba: Strong in computational efficiency (fast). However, it is not that the expressiveness itself is superior.
  • Transformer: Strong against long-distance dependencies due to strong context encoding.

The intuition of hybrids (e.g., MambaVision) is as follows: Initial layers can afford to let some information flow, so they are processed by efficient Mamba; Later layers require more sophisticated inference, so self-attention is used to boost accuracy. In essence, the balance between efficiency and accuracy is tuned through layer placement. TransMamba makes that placement smoother and more selective.

3.3.2 Theoretical results on expressiveness

Theorems have been proposed that, from the perspective of circuit complexity, Mamba does not have greater expressive power than Transformer (Chen et al., 2025). In other words, the value of Mamba lies not in expressive superiority, but in obtaining the same or similar expressive power at a lower cost.

TipView as Wireless Communication — SSM = Linear System / IIR Filter / Kalman Filter

The core recurrence relation of SSM \[ h_t = A h_{t-1} + B x_t,\qquad y_t = C h_t \;(+\, D x_t) \] is the discrete-time linear state-space system itself. That is, the backbone of Mamba is isomorphic to the state equations of an infinite impulse response (IIR) filter or (with noise added) a Kalman filter.

  • If the eigenvalue magnitude of \(A\) is \(|\lambda|<1\), the system is stable and past information decays exponentially (\(\Rightarrow\) finite effective memory length).
  • “Optional (S6)” means making \(A,B,C\) time-varying depending on the input — this is the same concept as adaptive filters (e.g., LMS/RLS) in communication. Just as tap counts change depending on the channel state, state transitions change depending on the token content.
  • The trick of parallelizing sequential recurrence relations using prefix-scan is identical to the parallel prefix technique in signal processing, which groups linear recurrence relations into blocks for parallel processing.

4 Multimodal Model: Overview

4.1 What is “Modality”

NoteDefinition — mode and modality
  • Mode: The peak of a probability distribution, i.e., the point where the density is (locally) maximum.
  • Multimodal distribution: A distribution with multiple peaks.
  • Extending this to data, multimodal data refers to a situation where multiple distinct homogeneous chunks of information (=each modality) are mixed together and entered into a single decision/embedding space.

In the past, storage media differed for each type of data (audio = tape, video = videotape, etc.), so it was called multimedia. Now, since all signals are converted to digital (0/1) and stored in the same semiconductor storage, the term is called multimodal, emphasizing the “mode” rather than the “medium.” Modality can include sight, hearing, touch, taste, and smell, and even extend to abstract “senses” such as attention, memory, and preference.

The two most important modalities are text and vision. This is because they are the information humans use every day (audio has been largely resolved, and video + text remains a difficult challenge).

4.2 Evolution of Multimodal Generative Models (Context)

NoteIntrinsic constraints of image generation = Window (number of tokens)

The reason it is difficult to generate long videos smoothly and temporally consistent is again due to window (token count) limitations. Therefore, current commercial applications focus on “high-quality cuts of 2 to 3 seconds.” As long as the cost does not exceed the actual filming costs (equipment, personnel, and location), generating these short cuts is economically justified.

5 CLIP and its variants: Text-Vision co-embedding

5.1 CLIP’s core idea

CLIP (Contrastive Language–Image Pre-training, Radford & Kim et al., OpenAI, ICML 2021) is the most widely used co-embedding method. It bridges the gap between computer vision and natural language processing by mapping images and text to the same embedding space. Once this mapping is trained, tasks such as zero-shot classification are possible without separate fine-tuning.

5.1.1 Contrastive pre-training

Let’s assume there are \(N\) (image, text) pairs in the minibatch. The image encoder creates \(\{I_i\}\) and the text encoder creates \(\{T_j\}\) embeddings. A \(N \times N\) matrix is created using the similarity of all pairs, and

  • Diagonal element(\(i=j\), correct pair) → Probability close to 1,
  • Non-diagonal element(\(i \neq j\), mismatch) → Probability close to 0

To create , apply softmax to the entire minibatch and backpropagate the two encoders together.

Code 
flowchart LR
  TXT["텍스트<br/>'Pepper the aussie pup'"] --> TE["Text Encoder"]
  IMG["이미지"] --> IE["Image Encoder"]
  TE --> M["유사도 행렬 N×N<br/>(I_i · T_j)"]
  IE --> M
  M --> L["대각=양성, 비대각=음성<br/>Softmax 대조손실"]

Similarity is usually measured by cosine similarity (the inner product of \(\ell_2\) normalized embeddings). The symmetric InfoNCE loss is \[ \mathcal{L}_{\text{CLIP}} = \tfrac{1}{2}\Big( \underbrace{-\tfrac{1}{N}\sum_{i}\log\frac{e^{\langle I_i,T_i\rangle/\tau}}{\sum_j e^{\langle I_i,T_j\rangle/\tau}}}_{\text{image}\to\text{text}} + \underbrace{-\tfrac{1}{N}\sum_{j}\log\frac{e^{\langle I_j,T_j\rangle/\tau}}{\sum_i e^{\langle I_i,T_j\rangle/\tau}}}_{\text{text}\to\text{image}} \Big), \] where \(\tau\) is the temperature. This is exactly the same form as “one-hot classification for correct pairs” and therefore reduces to cross-entropy minimization.

5.1.2 Where does the data come from? — The rediscovery of alt-text

This massive (image, text) pair was collected in large quantities from HTML text alt. In the early days of the Internet, the practice of including alternative text (alt-text) to describe images because image loading was slow later became a free weak supervision signal for CLIP learning. Thanks to the vast amount of alt-text on the web, it was possible to obtain a large number of image-text pairs.

5.2 SigLIP: sigmoid instead of softmax

SigLIP(Zhai et al., Google DeepMind Zurich, ICML 2021) improves CLIP in terms of memory efficiency and scalability. The idea itself is simple. Instead of applying softmax to the entire mini-batch, sigmoid is applied independently to each pair.

If the label of the pair ZZZPH0008748ZZZ \((i,j)\) is \(z_{ij}\in\{+1,-1\}\) (diagonal=+1, off-diagonal=−1), then \[ \mathcal{L}_{\text{SigLIP}} = -\frac{1}{N^2}\sum_{i}\sum_{j} \log \sigma\!\big(z_{ij}\,(t\,\langle I_i,T_j\rangle + b)\big), \] Here, \(t\) (scale), \(b\) (bias) are learning parameters, and \(\sigma\) is sigmoid.

5.2.1 Why sigmoid is advantageous (Step 3)

  1. softmax requires relative information of the entire mini-batch in the denominator \(\Rightarrow\) the normalization terms of the pairs from every step must be collected (synchronization cost).
  2. sigmoid evaluates each pair independently \(\Rightarrow\) pairwise loss can be calculated in parallel and variance.
  3. Therefore, without all-gathering between devices, only small blocks need to be loaded into memory at a time \(\Rightarrow\) Memory usage ↓, scalability ↑.
NoteEfficient Loss Implementation (parallelism)

The original paper splits the global batch across multiple devices and accumulates partial loss by swapping text representations between devices. At any given moment, only small partial blocks are loaded into memory, and after every image-text pair interacts once, it concludes with a sum across devices. The key point is that an all-gather is not required.

5.2.2 CLIP vs SigLIP

Contrast learning occurs implicitly in SigLIP as well. This is because the sigmoid fit itself, which sets positive pairs to 1 and negative pairs to 0 (-1 label), is the “contrast.” On various datasets, SigLIP offers higher accuracy than CLIP while also providing parallelization advantages.

5.3 SigLIP 2: Richer map signal

SigLIP 2(Tschannen et al., Google DeepMind, 2025) adds two things.

5.3.1 (1) LocCa — Location recognition captioning

The alt-text of the existing CLIP/SigLIP describes the image only at the whole level. LocCa (Wan et al., NeurIPS 2024) provides a fine-grained map signal.

  • Cap (Captioning): Captioning the entire image.
  • ARef (Automatic Referring expression): given description → Find the location of the bounding box that the description points to.
  • GCap (Grounded Captioning): Given bounding box → Generate caption for that area.

In other words, it links descriptions like “puffin standing on a cliff edge” to specific box coordinates of an image. Thanks to these location-based weak maps, modern LLM/VLM is able to understand even small parts of an image.

5.3.2 (2) Autodistillation for slow learners (image encoders)

NoteWhy Image Encoders Are “Slow Learners”
  • Text: Contains highly abstract high-level meaning → Information is compressed and rich.
  • Image: A pixel-level concrete realization. From a semantic perspective, it is noisy and contains information that must be selectively taken.

Therefore, image encoders learn slower than text encoders and are susceptible to noise.

The solution is the slow-fast / teacher-student concept of computer vision. By setting the weights, which are slowly updated by the Exponential Moving Average (EMA), as the teacher, \[ \theta^{\text{EMA}}_t = \alpha\,\theta^{\text{EMA}}_{t-1} + (1-\alpha)\,\theta_t,\qquad \alpha \approx 0.8\text{~}0.99, \] Allows the student encoder to converge faster and more stably from this stable teacher through self-distillation/mask prediction (SILC/TIPS-type loss). As a result, the image encoder learns a finer and more robust representation.

5.3.3 CLIP vs SigLIP vs SigLIP 2

5.4 CLIP + Generated Model = Text→Image

By combining CLIP-style co-embeddings with image generators such as diffusion models, it is possible to generate long text → corresponding images/videos. Intuitively: if you replace the image encoder with an image generator and train a text encoder using the CLIP method, you obtain a generator that outputs a corresponding image when given text. This is the basic framework of today’s text-image systems (such as DALL·E).

TipView via Wireless Communication — Cosine Similarity = Matched Filter, SigLIP Loss = Detection Theory
  • CLIP’s cosine similarity \(\langle I,T\rangle / (\|I\|\|T\|)\) is the normalized correlation, or the matched filter output. Just as a matched filter maximizes the alignment of the received signal and the reference waveform, CLIP maximizes the alignment of correct (image, text) pairs. This is analogous to the steering vector alignment in beamforming.
  • Softmax (CLIP) vs. Sigmoid (SigLIP) correspond to two perspectives in detection theory. Softmax is multi-hypothesis detection that selects one of \(N\) hypotheses (requires mutual normalization), while sigmoid is independent binary detection of whether each pair is positive or negative. The latter is lightweight in implementation because each detector can be run in parallel—similar to how using independent detection per user instead of joint detection in cellular multi-user detection reduces complexity.
  • Temperature \(\tau\) and Scale \(t\) can be viewed as the gain that controls the logit’s SNR. If it is too large, it leads to overconfidence; if it is too small, it leads to a loss of discernment.

6 The History of Multimodal ML and 5 Key Challenges

6.1 Overview of Three Eras

Code 
timeline
  title 멀티모달 연구의 세 시대

6.1.1 The Age of Behaviorism — The McGurk Effect (1976)

If you play the same audio but change only the lip-sync video, the heard sound changes (e.g., auditory “ba” + visual “ga” → perceived as “da”). When you close your eyes, you hear the actual sound, but when you open them, the visual overwrites the auditory. This is an example of multimodal interference. While multimodal information is usually helpful, conflicts can actually lead to misperception. (The reason phone English is difficult: because it uses only partial information without visual data.)

6.1.2 The Age of Computationalism — AVSR and SNR

In Audio-Visual Speech Recognition (AVSR), adding visual information achieves the same Word Error Rate (WER) even at much lower Acoustic SNR. Qualitatively:

  • Audio Only: Relatively high SNR (e.g., ~10) is required to achieve a certain WER.
  • Audio+Visual: Since visual signals assist, pseudo-WER can be achieved even at nearly 0 SNR.
TipView as wireless communication — Multimodal fusion = diversity combining

This is not a metaphor, but almost identical mathematics. Increasing the effective SNR by adding an independent (quasi-independent) observation branch called time is based on the exact same principle as Maximal Ratio Combining (MRC) in receive diversity, which obtains array gain by summing the branch-specific SNRs.

  • \(L\) independent modalities ≈ \(L\)-order diversity → Even if one channel falls into deep fading (=noise/ambiguity), the other channel compensates.
  • The fact that AVSR “operates even near 0 dB” means that the required SNR has been significantly lowered due to diversity gain.

Therefore, multimodal fusion design translates into the problem of designing combining rules in communication: with what weights should branches be merged (=fusion).

6.2 5 Key Challenges of the Deep Learning Era

Note5 Core Challenges
  1. Representation — Represents/summarizes multimodal data using complementarity and redundancy.
  2. Alignment — Find direct correspondences between (child) elements of two or more modalities.
  3. Fusion — Combines information from multiple modalities to perform prediction.
  4. Translation — Transforms one modality into another (can be open/subjective).
  5. Co-Learning — Transfer of knowledge (representation/prediction models) between modalities.

6.2.1 Task 1: Representation — Joint vs Coordinated

Deep learning generally moves toward joint representations. Thanks to the advantage of deep learning that it learns representations on its own, alignment is automatically achieved by simply combining and computing inputs by modality to integrate them into a single joint embedding.

6.2.2 The Magic of Joint Representations — Vector Space Arithmetic

In a well-trained joint multimodal space, images, texts, and audio with similar meanings are placed closely together. Furthermore, vector arithmetic holds (Kiros et al., 2014). \[ \text{image}(\text{파란 차}) - \mathbf{v}_{\text{blue}} + \mathbf{v}_{\text{red}} \;\approx\; \text{image}(\text{빨간 차}) \] That is, if you look up the vicinity of the location where blue vector is subtracted and red vector is added in the “blue car” embedding, red car images appear. Changing one word in a sentence to another corresponds to vector addition/subtraction in the embedding space, and as a result, the images in the vicinity of the embedding change (“Draw an Iron Man” → “Draw a cat”).

6.2.3 Assignment 2~5 Summary

  • Alignment: If you choose the alignment representation, you must explicitly solve the element correspondence between modalities (difficulty). The joint representation absorbs this into the learning process.
  • Fusion: Combines multiple modalities to produce a single prediction (see AVSR/Diversity Combination above).
  • Translation: One modality → another (e.g., video → sound, text → image). Since the relationship can be open and subjective, there is not a single correct answer.
  • Co-Learning: Transferring knowledge from one modality to another (e.g., the slow-fast distillation mentioned above). It is deeply connected to alignment.

7 Additional discussion at the end of the lecture: Limitations of CNN → Attention → Gating

At the end of the class, we revisited why simple convolution is insufficient and attention is necessary. Since this reinforces the motivation for multimodal and Transformer concepts, I am summarizing it here.

7.1 CNN’s Limitations Revealed in VQA

Let’s consider “How many birds are in this image?” (Visual Question Answering, VQA). CNNs assume spatial stationarity and locality. That is, each filter response has the same meaning regardless of location, and only strong responses are retained while the rest are treated as noise (max pooling).

WarningWhy Counting Fails (Causal Chain)
  1. CNN is designed to extract position-invariant features → It captures “novelty” well.
  2. However, max pooling sends the one strongest response to the next layer → count information is lost.
  3. “Three animals” implies that each position must have a different meaning (different individual), which conflicts head-on with the assumption of normality → failure to count.

When birds of the same species are located in the bottom-left and top-right corners of the screen, the question “Are they the same species?” requires long-distance relationships and information on behaviors that vary by location. CNNs are weak at such long-distance and context-dependent relationships. (Theoretically, locally-connected networks are an alternative, but they are not practical because the number of parameters explodes, causing them to lose the advantages of CNNs.)

7.2 Attention = Weights that change depending on the input

ImportantCore Intuition

The general weight \(W\) is fixed regardless of the input (learned from data but remains invariant during inference). The Attention weight \(a\) takes the input itself as input, changes the weight, and applies the changed weight back to the input. \[ \text{고정: } y = Wx \qquad\text{vs}\qquad \text{Attention: } y = a(x)\,x \] Thanks to , even the same input is encoded into different roles and meanings depending on the context.

To implement the idea of “calculating weights from inputs,” we introduce the Query, Key, Value concept (it does not necessarily have to be three elements, but this is the standard implementation of the Transformer). In the next lecture, we will complete attention using QKV, and then take the midterm exam (the Transformer exam will focus on high-level concepts).

7.3 Gating Review — A Matter of Memory

In cyclic structures, memory over time is handled by gating. It takes the weighted sum of the current input and the moving average of past memory. \[ f(x) = g(x)\odot x + \big(1-g(x)\big)\odot m,\qquad g(x)\in(0,1), \] Here, \(m\) represents memory (past accumulation), and \(g\) represents the gate. Representative implementations are LSTM (Long Short-Term Memory) and GRU (Gated Recurrent Unit). GRU achieves similar performance to LSTM while simplifying it (reducing parameters).

NoteOne-line memo

“Remembering over time” remains a major challenge that has not yet been fully solved. Mamba’s selective mechanism is also a new answer to the same problem, which ultimately determines what to remember and what to discard through gating.

TipView as wireless — Gate = 1st order IIR smoother / Adaptive gain

\(f = g\odot x + (1-g)\odot m\) is an Exponentially Weighted Moving Average (EWMA), which is a first-order IIR low-pass filter. If the gate \(g\) is time-varying, it becomes an adaptive smoother. This is the same structure as using an adaptive forgetting factor to suppress noise in channel estimation.

8 Summary and Next Lecture

NoteKey Summary
  • Efficiency: Mamba(SSM) is the representative trend aiming to reduce the \(\mathcal{O}(n^2)\) of the Transformer. It features an optional mechanism + hardware-aware scanning. However, it does not offer superior expressiveness, but its strength lies in efficiency. Hybrids (Jamba/MambaVision/TransMamba) balance efficiency and accuracy.
  • Multimodal: Bringing heterogeneous data into the same space. CLIP (softmax contrast) → SigLIP (sigmoid, parallel and memory efficient) → SigLIP 2 (LocCa localization map + EMA autodivision).
  • 5 Major Tasks: Representation, Alignment, Fusion, Transformation, and Joint Learning. Deep learning primarily moves toward joint representation, and as a result, vector space arithmetic is possible.
  • Overarching Theme: “How to efficiently handle long contexts and memories” and “How to align and fuse heterogeneous information” — both can be read as the complexity-performance trade-off and combination of diversity in communication.

import numpy as np
rng = np.random.default_rng(0)

def l2norm(X, axis=-1, eps=1e-8):
    """행 벡터를 단위 노름으로 정규화 → 내적이 코사인 유사도가 됨"""
    return X / (np.linalg.norm(X, axis=axis, keepdims=True) + eps)

def log_softmax(z, axis=-1):
    z = z - z.max(axis=axis, keepdims=True)          # 수치 안정화
    return z - np.log(np.exp(z).sum(axis=axis, keepdims=True))

def log_sigmoid(x):
    return -np.logaddexp(0.0, -x)                     # 안정적 log σ(x)

10.1 CLIP Symmetric Contrast Loss (InfoNCE)

Code 
N, d = 8, 16
I = l2norm(rng.standard_normal((N, d)))               # 이미지 임베딩
T = l2norm(rng.standard_normal((N, d)))               # 텍스트 임베딩
T = l2norm(0.6 * I + 0.4 * T)                         # 대각(짝)에 상관 주입

def clip_loss(I, T, temperature=0.07):
    logits = (I @ T.T) / temperature                  # (N,N) 코사인 유사도/τ
    labels = np.arange(N)                             # 정답 = 대각
    lp_i = log_softmax(logits, axis=1)                # image→text
    lp_t = log_softmax(logits, axis=0)                # text→image
    return 0.5 * (-lp_i[labels, labels].mean()
                  - lp_t[labels, labels].mean())

print("CLIP loss:", round(float(clip_loss(I, T)), 4))

10.2 SigLIP Pairwise sigmoid loss

Code 
def siglip_loss(I, T, t=10.0, b=-10.0):
    sims = I @ T.T                                    # (N,N)
    labels = -np.ones((N, N)); np.fill_diagonal(labels, 1.0)  # 대각 +1, 그 외 -1
    logits = labels * (t * sims + b)
    return -log_sigmoid(logits).mean()                # 쌍별 독립 → 병렬화 가능

print("SigLIP loss:", round(float(siglip_loss(I, T)), 4))

sims = I @ T.T
print("대각 평균 유사도:", round(float(np.diag(sims).mean()), 4))
print("비대각 평균 유사도:",
      round(float((sims.sum() - np.trace(sims)) / (N*N - N)), 4))

10.3 Linear SSM scan (\(\mathcal{O}(n)\) sequential recurrence relation)

Code 
def ssm_scan(x, A, B, C):
    """h_t = A h_{t-1} + B x_t,  y_t = C h_t  (IIR/칼만 상태식과 동형)"""
    n = A.shape[0]; h = np.zeros(n); ys = []
    for xt in x:
        h = A @ h + B * xt
        ys.append(C @ h)
    return np.array(ys)

A = np.diag([0.9, 0.5])        # |eig|<1 → 안정, 과거가 지수 감쇠
B = np.array([1.0, 1.0]); C = np.array([1.0, -1.0])
x = rng.standard_normal(6)
print("SSM 출력:", np.round(ssm_scan(x, A, B, C), 4))

# Introduction: Today's Big Picture {#sec-overview}

The content covered today is divided into two axes.

1. **Making Transformers Cheaper** — Attempts to reduce the $\mathcal{O}(n^2)$ cost of Self-attention. The leading example is **Mamba** from the **State Space Model (SSM)** family.

# Review: The Limitations of the Transformer {#sec-recap}

## What was good

Self-attention densely encodes contextual information by directly connecting all token pairs within a **window**. Unlike RNNs, which compress information into a single hidden state and transmit it sequentially, it examines long-range dependencies all at once.

## Two essential limitations

::: {.callout-important}
## Limit 1 — Cannot see outside the window
Attention concatenates only tokens within the **consideration window**. Context outside the window cannot be encoded in principle.
:::

::: {.callout-important}
## Limit 2 — Cost is the square of the window size
If the window size is $n$, the time and memory complexity is because scores are calculated for all query-key pairs
$$
\mathcal{O}(n^2 d)
$$
. Increasing the window size allows for more context ($\Rightarrow$ better alignment and accuracy), but the cost increases exponentially.
:::

### Why Squares of All Things? (3-Step Causal Chain)

1. Create $Q = XW_Q,\; K = XW_K,\; V = XW_V$ from input $X \in \mathbb{R}^{n \times d}$.
2. The moment the score matrix $S = QK^\top \in \mathbb{R}^{n \times n}$ is created, **the number of elements is $n^2$**. This single line $\Rightarrow$ is the source of squared complexity.
3. $\text{softmax}(S/\sqrt{d})\,V$ also undergoes operations of the same scale as $n^2$. Therefore, if the window is doubled, the cost becomes four times higher.

The industry responds in two ways: (a) simply handling large Windows with **more expensive hardware** (H100, H200, B100/B200 …), or (b) **an efficiency transformer that algorithmically lowers the cost itself**. The efficiency trend seeks to reduce complexity through $\mathcal{O}(n^2) \to \mathcal{O}(n\log n) \to \mathcal{O}(n)$. Mamba is a prime example of the latter.

::: {.callout-tip}
## View via Wireless Communication — Direct Convolution vs FFT
The effort to reduce $\mathcal{O}(n^2)$ to $\mathcal{O}(n\log n)$ or $\mathcal{O}(n)$ shares the same motivation as the classic strategy in communications signal processing of **replacing direct time-domain convolution ($\mathcal{O}(n^2)$) with FFT-based frequency-domain product ($\mathcal{O}(n\log n)$)**. The goal of "reducing the order of complexity while maintaining accuracy" is the same.
:::

# Mamba and State-Space Model (SSM) {#sec-mamba}

## At a glance

Mamba is an efficient model for sequence encoding named after the **black mamba** (a fast and deadly snake). It is based on the **Structured State Space Sequence model (S4)**, which is simplified through **S5** and adopts the **selective** version **S6**.

```{mermaid}
flowchart LR
  S4["S4<br/>(2021, 구조화 SSM)"] --> S5["S5<br/>(단순화)"]
  S5 --> S6["S6<br/>(Selective)"]
  S6 --> M["Mamba<br/>(2023)"]
```

## Two key ideas

### (1) Selective mechanism (S6)

- Maintain a small, fixed-size window, but keep only the highly relevant tokens inside it.
- "Relevance" is measured in a manner similar to the **gating mechanism** of RNNs. That is, it dynamically decides which information to remember and which to discard based on the input.

::: {.callout-note}
## Details are everything
The idea itself ("keep only important tokens") is simple, but **what is considered important (importance score function)** and **how the selection is made** determine performance. This is the core contribution of the original paper (Gu & Dao, *Mamba: Linear-Time Sequence Modeling with Selective State Spaces*, 2023).
:::

### (2) Hardware-aware parallel scan

Linear cycle $h_t = A h_{t-1} + B x_t$ is essentially sequential, but it can be reconfigured into **associative scan (prefix-sum) operations** and parallelized on the GPU. Mamba implements this scan to match the GPU memory hierarchy (SRAM/HBM) to boost inference speed.

::: {.callout-warning}
## Work Memo
Since this hardware-aware kernel is not yet *natively embedded* in NVIDIA hardware, the potential efficiency gains of Mamba have not been fully realized. Custom kernel/hardware optimization remains an open research and engineering opportunity.
:::

## Variants of Mamba

| Model | Structure | Key Features |
|---|---|---|
| **Vision Mamba (Vim)** | Pure Mamba | Non-dedicated Mamba |
| **Jamba** | Hybrid (Mamba+Transformer) | Mixes the two blocks in MoE form. Max **256k token** window |
| **MambaVision** | Hybrid | **Front end = Mamba**, **Back end = Transformer self-attention** |
| **TransMamba** | Hybrid (soft/selective) | **Dynamic selection** of Mamba or Transformer for each layer/token |

: Mamba Variant Comparison {#tbl-mamba}

### One-line summary of design philosophy

- **Mamba**: Strong in computational efficiency (fast). However, **it is not that the expressiveness itself is superior.**
- **Transformer**: Strong against long-distance dependencies due to strong context encoding.

The intuition of hybrids (e.g., MambaVision) is as follows: *Initial layers* can afford to let some information flow, so they are processed by efficient Mamba; *Later layers* require more sophisticated inference, so self-attention is used to boost accuracy. In essence, the balance between efficiency and accuracy is tuned through layer placement. TransMamba makes that placement smoother and more selective.

### Theoretical results on expressiveness

Theorems have been proposed that, from the perspective of circuit complexity, **Mamba does not have greater expressive power than Transformer** (Chen et al., 2025). In other words, the value of Mamba lies not in *expressive superiority*, but in *obtaining the same or similar expressive power at a lower cost*.

::: {.callout-tip}
## View as Wireless Communication — SSM = Linear System / IIR Filter / Kalman Filter
The core recurrence relation of SSM
$$
h_t = A h_{t-1} + B x_t,\qquad y_t = C h_t \;(+\, D x_t)
$$
is the **discrete-time linear state-space system** itself. That is, the backbone of Mamba is isomorphic to the state equations of an **infinite impulse response (IIR) filter** or (with noise added) a **Kalman filter**.

- If the eigenvalue magnitude of $A$ is $|\lambda|<1$, the system is **stable** and past information decays exponentially ($\Rightarrow$ finite effective memory length).
- "Optional (S6)" means making $A,B,C$ **time-varying** depending on the input — this is the same concept as **adaptive filters (e.g., LMS/RLS)** in communication. Just as tap counts change depending on the channel state, state transitions change depending on the token content.
- The trick of parallelizing sequential recurrence relations using **prefix-scan** is identical to the **parallel prefix** technique in signal processing, which groups linear recurrence relations into blocks for parallel processing.
:::

# Multimodal Model: Overview {#sec-mm-overview}

## What is "Modality"

::: {.callout-note}
## Definition — mode and modality
- **Mode**: The **peak** of a probability distribution, i.e., the point where the density is (locally) maximum.
- **Multimodal distribution**: A distribution with **multiple** peaks.
- Extending this to data, **multimodal data** refers to a situation where multiple distinct **homogeneous chunks of information** (=each modality) are mixed together and entered into a single decision/embedding space.
:::

In the past, storage media differed for each type of data (audio = tape, video = videotape, etc.), so it was called **multimedia**. Now, since all signals are converted to digital (0/1) and stored in the same semiconductor storage, the term is called **multimodal**, emphasizing the "mode" rather than the "medium." Modality can include sight, hearing, touch, taste, and smell, and even extend to abstract "senses" such as attention, memory, and preference.

The two most important modalities are **text** and **vision**. This is because they are the information humans use every day (audio has been largely resolved, and video + text remains a difficult challenge).

# CLIP and its variants: Text-Vision co-embedding {#sec-clip}

## CLIP's core idea

CLIP (Contrastive Language–Image Pre-training, Radford & Kim et al., OpenAI, ICML 2021) is the most widely used co-embedding method. It bridges the gap between computer vision and natural language processing by mapping images and text to the same embedding space. Once this mapping is trained, tasks such as zero-shot classification are possible without separate fine-tuning.

### Contrastive pre-training

Let's assume there are $N$ (image, text) pairs in the minibatch. The image encoder creates $\{I_i\}$ and the text encoder creates $\{T_j\}$ embeddings. A $N \times N$ matrix is created using the similarity of all pairs, and

- **Diagonal element**($i=j$, correct pair) → Probability close to 1,
- **Non-diagonal element**($i \neq j$, mismatch) → Probability close to 0

To create , apply **softmax** to the entire minibatch and backpropagate the two encoders together.

```{mermaid}
flowchart LR
  TXT["텍스트<br/>'Pepper the aussie pup'"] --> TE["Text Encoder"]
  IMG["이미지"] --> IE["Image Encoder"]
  TE --> M["유사도 행렬 N×N<br/>(I_i · T_j)"]
  IE --> M
  M --> L["대각=양성, 비대각=음성<br/>Softmax 대조손실"]
```

Similarity is usually measured by **cosine similarity** (the inner product of $\ell_2$ normalized embeddings). The symmetric InfoNCE loss is
$$
\mathcal{L}_{\text{CLIP}}
= \tfrac{1}{2}\Big(
\underbrace{-\tfrac{1}{N}\sum_{i}\log\frac{e^{\langle I_i,T_i\rangle/\tau}}{\sum_j e^{\langle I_i,T_j\rangle/\tau}}}_{\text{image}\to\text{text}}
+
\underbrace{-\tfrac{1}{N}\sum_{j}\log\frac{e^{\langle I_j,T_j\rangle/\tau}}{\sum_i e^{\langle I_i,T_j\rangle/\tau}}}_{\text{text}\to\text{image}}
\Big),
$$
where $\tau$ is the temperature. This is exactly the same form as "one-hot classification for correct pairs" and therefore reduces to cross-entropy minimization.

### Where does the data come from? — The rediscovery of alt-text

This massive (image, text) pair was collected in large quantities from **HTML text `alt`**. In the early days of the Internet, the practice of including alternative text (alt-text) to describe images because image loading was slow later became a **free weak supervision signal** for CLIP learning. Thanks to the vast amount of alt-text on the web, it was possible to obtain a large number of image-text pairs.

## SigLIP: sigmoid instead of softmax

**SigLIP**(Zhai et al., Google DeepMind Zurich, ICML 2021) improves CLIP in terms of **memory efficiency and scalability**. The idea itself is simple. Instead of applying softmax to the entire mini-batch, **sigmoid** is applied independently to each pair.

If the label of the pair ZZZPH0008748ZZZ  $(i,j)$ is $z_{ij}\in\{+1,-1\}$ (diagonal=+1, off-diagonal=−1), then
$$
\mathcal{L}_{\text{SigLIP}}
= -\frac{1}{N^2}\sum_{i}\sum_{j}
\log \sigma\!\big(z_{ij}\,(t\,\langle I_i,T_j\rangle + b)\big),
$$
Here, $t$ (scale), $b$ (bias) are learning parameters, and $\sigma$ is sigmoid.

### Why sigmoid is advantageous (Step 3)

1. softmax requires **relative information of the entire mini-batch** in the denominator $\Rightarrow$ the normalization terms of the pairs from every step must be collected (synchronization cost).
2. sigmoid evaluates **each pair independently** $\Rightarrow$ pairwise loss can be calculated in **parallel and variance**.
3. Therefore, without all-gathering between devices, only **small blocks need to be loaded into memory** at a time $\Rightarrow$ Memory usage ↓, scalability ↑.

::: {.callout-note}
## Efficient Loss Implementation (parallelism)
The original paper splits the global batch across multiple devices and accumulates partial loss by **swapping text representations** between devices. At any given moment, **only small partial blocks** are loaded into memory, and after every image-text pair interacts once, it concludes with a sum across devices. The key point is that an all-gather is not required.
:::

### CLIP vs SigLIP

| Characteristics | CLIP | SigLIP |
|---|---|---|
| Loss function | softmax-based contrast loss | sigmoid (paired) |
| Loss calculation unit | Compare **all pairs** within minibatch | **each pair** independent |
| Memory Usage | High | Low |
| Accuracy | Good | Improved compared to CLIP |

: CLIP vs SigLIP {#tbl-clip-siglip}

Contrast learning occurs **implicitly** in SigLIP as well. This is because the sigmoid fit itself, which sets positive pairs to 1 and negative pairs to 0 (-1 label), is the "contrast." On various datasets, SigLIP offers higher accuracy than CLIP while also providing parallelization advantages.

## SigLIP 2: Richer map signal

SigLIP 2(Tschannen et al., Google DeepMind, 2025) adds two things.

### (1) LocCa — Location recognition captioning

The alt-text of the existing CLIP/SigLIP describes the image only at the **whole level**. LocCa (Wan et al., NeurIPS 2024) provides a **fine-grained** map signal.

- **Cap (Captioning)**: Captioning the entire image.
- **ARef (Automatic Referring expression)**: *given description* → Find *the location of the bounding box that the description points to*.
- **GCap (Grounded Captioning)**: *Given bounding box* → *Generate caption for that area*.

In other words, it links descriptions like "puffin standing on a cliff edge" to **specific box coordinates** of an image. Thanks to these location-based weak maps, modern LLM/VLM is able to understand even small parts of an image.

### (2) Autodistillation for slow learners (image encoders)

::: {.callout-note}
## Why Image Encoders Are "Slow Learners"
- **Text**: Contains highly abstract **high-level meaning** → Information is compressed and rich.
- **Image**: A pixel-level **concrete realization**. From a semantic perspective, it is noisy and contains information that must be selectively taken.

Therefore, image encoders learn slower than text encoders and are susceptible to noise.
:::

The solution is the **slow-fast / teacher-student** concept of computer vision. By setting the weights, which are slowly updated by the **Exponential Moving Average (EMA)**, as the **teacher**,
$$
\theta^{\text{EMA}}_t = \alpha\,\theta^{\text{EMA}}_{t-1} + (1-\alpha)\,\theta_t,\qquad \alpha \approx 0.8\text{~}0.99,
$$
Allows the student encoder to converge faster and more stably from this stable teacher through **self-distillation/mask prediction** (SILC/TIPS-type loss). As a result, the image encoder learns a finer and more robust representation.

### CLIP vs SigLIP vs SigLIP 2

| Characteristics | CLIP | SigLIP | SigLIP 2 |
|---|---|---|---|
| Loss | softmax contrast | sigmoid | sigmoid + **LocCa** |
| Assignment | Image-Text Matching | Image-Text Matching | Captioning · Distillation Included |
| Loss Unit | Compare All Pairs | Each Pair | Each Pair |
| Memory | High | Low | Low |
| Accuracy | Good | CLIP↑ | SigLIP↑ on various tasks |

: CLIP vs SigLIP vs SigLIP 2 {#tbl-siglip2}

## CLIP + Generated Model = Text→Image

By combining CLIP-style co-embeddings with image generators such as **diffusion models**, it is possible to **generate long text → corresponding images/videos**. Intuitively: if you replace the image encoder with an **image generator** and train a text encoder using the CLIP method, you obtain a generator that outputs a corresponding image when given text. This is the basic framework of today's text-image systems (such as DALL·E).

::: {.callout-tip}
## View via Wireless Communication — Cosine Similarity = Matched Filter, SigLIP Loss = Detection Theory
- **CLIP's cosine similarity** $\langle I,T\rangle / (\|I\|\|T\|)$ is the **normalized correlation**, or the **matched filter** output. Just as a matched filter maximizes the alignment of the received signal and the reference waveform, CLIP maximizes the alignment of correct (image, text) pairs. This is analogous to the **steering vector alignment** in beamforming.
- **Softmax (CLIP) vs. Sigmoid (SigLIP)** correspond to two perspectives in detection theory. Softmax is **multi-hypothesis detection** that selects one of $N$ hypotheses (requires mutual normalization), while sigmoid is **independent binary detection** of whether each pair is positive or negative. The latter is lightweight in implementation because each detector can be run in parallel—similar to how using independent detection per user instead of joint detection in cellular multi-user detection reduces complexity.
- Temperature $\tau$ and Scale $t$ can be viewed as the **gain that controls the logit's SNR**. If it is too large, it leads to overconfidence; if it is too small, it leads to a loss of discernment.
:::

# The History of Multimodal ML and 5 Key Challenges {#sec-mm-core}

## Overview of Three Eras

```{mermaid}
timeline
  title 멀티모달 연구의 세 시대
  1970s : 행동주의(Behavioral) : 인간의 다중감각 처리 연구 (McGurk 1976)
  1980s-2000 : 계산주의(Computational) : AVSR 등 계산 모델로 모방
  2010-Now : 딥러닝(Deep Learning) : 표현을 스스로 학습
```

### The Age of Behaviorism — The McGurk Effect (1976)

If you play the same audio but change only the lip-sync video, the **heard sound changes** (e.g., auditory "ba" + visual "ga" → perceived as "da"). When you close your eyes, you hear the actual sound, but when you open them, the visual **overwrites** the auditory. This is an example of **multimodal interference**. While multimodal information is usually helpful, conflicts can actually lead to misperception. (The reason phone English is difficult: because it uses only partial information without visual data.)

### The Age of Computationalism — AVSR and SNR

In Audio-Visual Speech Recognition (AVSR), **adding visual information achieves the same Word Error Rate (WER)** even at much lower Acoustic SNR. Qualitatively:

- Audio Only: Relatively **high SNR** (e.g., ~10) is required to achieve a certain WER.
- Audio+Visual: Since visual signals assist, pseudo-WER can be achieved even at **nearly 0 SNR**.

::: {.callout-tip}
## View as wireless communication — Multimodal fusion = diversity combining
This is not a metaphor, but **almost identical mathematics**. Increasing the effective SNR by adding an **independent (quasi-independent) observation branch** called time is based on the exact same principle as **Maximal Ratio Combining (MRC)** in receive diversity, which obtains array gain by summing the branch-specific SNRs.

- $L$ independent modalities ≈ $L$-order diversity → Even if one channel falls into deep fading (=noise/ambiguity), the other channel compensates.
- The fact that AVSR "operates even near 0 dB" means that the required SNR has been significantly lowered due to **diversity gain**.

Therefore, multimodal fusion design translates into the problem of designing **combining rules** in communication: with what weights should branches be merged (=fusion).
:::

## 5 Key Challenges of the Deep Learning Era

::: {.callout-note}
## 5 Core Challenges
1. **Representation** — Represents/summarizes multimodal data using complementarity and redundancy.
2. **Alignment** — Find direct correspondences between (child) elements of two or more modalities.
3. **Fusion** — Combines information from multiple modalities to perform prediction.
4. **Translation** — Transforms one modality into another (can be open/subjective).
5. **Co-Learning** — Transfer of knowledge (representation/prediction models) between modalities.
:::

### Task 1: Representation — Joint vs Coordinated

| Method | Definition | Advantages | Disadvantages |
|---|---|---|---|
| **Joint Representation** | All modalities in a **single** shared space | Alignment is **implicitly embedded** at training time → Reduced concerns about future alignment | Difficult to train that space |
| **Coordinated Representation** | **Individual** Space per Modality + Post-alignment | Reflects the Unique Characteristics of Each Modality | Postpones the **Difficult Problem of Alignment** |

: Comparison of expression styles {#tbl-repr}

Deep learning generally moves toward **joint representations**. Thanks to the advantage of deep learning that it **learns** representations on its own, alignment is automatically achieved by simply combining and computing inputs by modality to integrate them into a single joint embedding.

### The Magic of Joint Representations — Vector Space Arithmetic

In a well-trained joint multimodal space, images, texts, and audio with similar meanings are placed **closely together**. Furthermore, **vector arithmetic** holds (Kiros et al., 2014).
$$
\text{image}(\text{파란 차}) - \mathbf{v}_{\text{blue}} + \mathbf{v}_{\text{red}} \;\approx\; \text{image}(\text{빨간 차})
$$
That is, if you look up the vicinity of the location where *blue* vector is subtracted and *red* vector is added in the "blue car" embedding, **red car** images appear. Changing one word in a sentence to another corresponds to vector addition/subtraction in the embedding space, and as a result, the images in the vicinity of the embedding change ("Draw an Iron Man" → "Draw a cat").

### Assignment 2~5 Summary

- **Alignment**: If you choose the alignment representation, you must *explicitly* solve the element correspondence between modalities (difficulty). The joint representation absorbs this into the learning process.
- **Fusion**: Combines multiple modalities to produce a single prediction (see AVSR/Diversity Combination above).
- **Translation**: One modality → another (e.g., video → sound, text → image). Since the relationship can be **open and subjective**, there is not a single correct answer.
- **Co-Learning**: Transferring knowledge from one modality to another (e.g., the slow-fast distillation mentioned above). It is deeply connected to alignment.

# Additional discussion at the end of the lecture: Limitations of CNN → Attention → Gating {#sec-extra}

At the end of the class, we revisited *why simple convolution is insufficient and attention is necessary*. Since this reinforces the motivation for multimodal and Transformer concepts, I am summarizing it here.

## CNN's Limitations Revealed in VQA

Let's consider "How many birds are in this image?" (Visual Question Answering, VQA). CNNs assume **spatial stationarity** and **locality**. That is, *each filter response has the same meaning regardless of location*, and only strong responses are retained while the rest are treated as noise (max pooling).

::: {.callout-warning}
## Why Counting Fails (Causal Chain)
1. CNN is designed to extract position-invariant features → It captures **"novelty"** well.
2. However, max pooling sends the **one strongest response** to the next layer → count information is lost.
3. "Three animals" implies that *each position must have a different meaning* (different individual), which conflicts head-on with the assumption of normality → **failure to count**.
:::

When birds of the same species are located in the bottom-left and top-right corners of the screen, the question "Are they the same species?" requires **long-distance relationships** and **information on behaviors that vary by location**. CNNs are weak at such long-distance and context-dependent relationships. (Theoretically, locally-connected networks are an alternative, but they are not practical because the number of parameters explodes, causing them to lose the advantages of CNNs.)

## Attention = Weights that *change* depending on the input

::: {.callout-important}
## Core Intuition
The general weight $W$ is **fixed** regardless of the input (learned from data but remains invariant during inference). The **Attention weight $a$** takes the **input itself** as input, changes the weight, and applies the changed weight back to the input.
$$
\text{고정: } y = Wx \qquad\text{vs}\qquad \text{Attention: } y = a(x)\,x
$$
Thanks to , even the *same input* is encoded into **different roles and meanings** depending on the context.
:::

To implement the idea of "calculating weights from inputs," we introduce the **Query, Key, Value** concept (it does not necessarily have to be three elements, but this is the standard implementation of the Transformer). In the next lecture, we will complete attention using QKV, and then take the midterm exam (the Transformer exam will focus on **high-level concepts**).

## Gating Review — A Matter of Memory

In cyclic structures, **memory over time** is handled by gating. It takes the weighted sum of the current input and the moving average of past memory.
$$
f(x) = g(x)\odot x + \big(1-g(x)\big)\odot m,\qquad g(x)\in(0,1),
$$
Here, $m$ represents memory (past accumulation), and $g$ represents the gate. Representative implementations are **LSTM** (Long Short-Term Memory) and **GRU** (Gated Recurrent Unit). GRU achieves similar performance to LSTM while simplifying it (reducing parameters).

::: {.callout-note}
## One-line memo
"Remembering over time" remains a major challenge that has not yet been fully solved. Mamba's selective mechanism is also a new answer to the same problem, which ultimately determines *what to remember and what to discard* through gating.
:::

::: {.callout-tip}
## View as wireless — Gate = 1st order IIR smoother / Adaptive gain
$f = g\odot x + (1-g)\odot m$ is an **Exponentially Weighted Moving Average (EWMA)**, which is a **first-order IIR low-pass filter**. If the gate $g$ is time-varying, it becomes an **adaptive smoother**. This is the same structure as using an adaptive forgetting factor to suppress noise in channel estimation.
:::

# Appendix B: Practice Code (NumPy) {#sec-appendix-code}

Implements contrast loss (CLIP/SigLIP), cosine similarity, linear SSM scan, and vector arithmetic in pure NumPy. This is toy code for concept verification.

```{python}
import numpy as np
rng = np.random.default_rng(0)

def l2norm(X, axis=-1, eps=1e-8):
    """행 벡터를 단위 노름으로 정규화 → 내적이 코사인 유사도가 됨"""
    return X / (np.linalg.norm(X, axis=axis, keepdims=True) + eps)

def log_softmax(z, axis=-1):
    z = z - z.max(axis=axis, keepdims=True)          # 수치 안정화
    return z - np.log(np.exp(z).sum(axis=axis, keepdims=True))

def log_sigmoid(x):
    return -np.logaddexp(0.0, -x)                     # 안정적 log σ(x)
```

## CLIP Symmetric Contrast Loss (InfoNCE)

```{python}
N, d = 8, 16
I = l2norm(rng.standard_normal((N, d)))               # 이미지 임베딩
T = l2norm(rng.standard_normal((N, d)))               # 텍스트 임베딩
T = l2norm(0.6 * I + 0.4 * T)                         # 대각(짝)에 상관 주입

def clip_loss(I, T, temperature=0.07):
    logits = (I @ T.T) / temperature                  # (N,N) 코사인 유사도/τ
    labels = np.arange(N)                             # 정답 = 대각
    lp_i = log_softmax(logits, axis=1)                # image→text
    lp_t = log_softmax(logits, axis=0)                # text→image
    return 0.5 * (-lp_i[labels, labels].mean()
                  - lp_t[labels, labels].mean())

print("CLIP loss:", round(float(clip_loss(I, T)), 4))
```

## SigLIP Pairwise sigmoid loss

```{python}
def siglip_loss(I, T, t=10.0, b=-10.0):
    sims = I @ T.T                                    # (N,N)
    labels = -np.ones((N, N)); np.fill_diagonal(labels, 1.0)  # 대각 +1, 그 외 -1
    logits = labels * (t * sims + b)
    return -log_sigmoid(logits).mean()                # 쌍별 독립 → 병렬화 가능

print("SigLIP loss:", round(float(siglip_loss(I, T)), 4))

sims = I @ T.T
print("대각 평균 유사도:", round(float(np.diag(sims).mean()), 4))
print("비대각 평균 유사도:",
      round(float((sims.sum() - np.trace(sims)) / (N*N - N)), 4))
```

## Linear SSM scan ($\mathcal{O}(n)$ sequential recurrence relation)

```{python}
def ssm_scan(x, A, B, C):
    """h_t = A h_{t-1} + B x_t,  y_t = C h_t  (IIR/칼만 상태식과 동형)"""
    n = A.shape[0]; h = np.zeros(n); ys = []
    for xt in x:
        h = A @ h + B * xt
        ys.append(C @ h)
    return np.array(ys)

A = np.diag([0.9, 0.5])        # |eig|<1 → 안정, 과거가 지수 감쇠
B = np.array([1.0, 1.0]); C = np.array([1.0, -1.0])
x = rng.standard_normal(6)
print("SSM 출력:", np.round(ssm_scan(x, A, B, C), 4))
```
