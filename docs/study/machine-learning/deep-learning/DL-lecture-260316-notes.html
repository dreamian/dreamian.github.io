1 Information Theory

1.1 Self-information (Self-information amount)

The self-information of event x with probability p(x) is

I(x) = -\log p(x).

  • Common event (p large) → small amount of information, rare event (p small) → large amount of information.
  • It is a quantity that is not derived from deep theory but is intuitively defined (Shannon).
  • Unit: If natural logarithm(\ln), nats, if \log_2, bits.
NoteIntuition

A measure of “how surprising (surprise)” it is. If something obvious happens, there is little information, and if something unlikely happens, there is a lot of information.

1.2 Entropy (Entropy)

Entropy is the expected value of magnetic information.

H(X) = \mathbb{E}_{x\sim p}\big[-\log p(x)\big] = -\sum_{x\in\mathcal{X}} p(x)\log p(x).

  • The etymology is the degree of disorder in thermodynamics. However, there is no concept of particles/matter here, and it measures only the randomness and disorder of a random variable.
  • More random variable → Higher entropy / Less random → Lower entropy.
  • notation is usually H or \mathbb{H}.

Differential entropy for continuous random variables, where the sum is changed to an integral:

h(X) = -\int_{\mathcal{X}} p(x)\log p(x)\,dx.

Tip“Why is it differential?”

If x is continuous, it is called differential entropy because the random variable can be differentiated. When it is discrete, it is just entropy.

1.3 KL Divergence (Coolback–Liveler Divergence)

“Distance similar” amount between two distributions p, q:

D_{KL}(p\,\|\,q) = \sum_{x} p(x)\log\frac{p(x)}{q(x)} = \mathbb{E}_{x\sim p}\!\left[\log\frac{p(x)}{q(x)}\right].

  • The name is Kullback–Leibler(two people’s names).
  • There is a direction. “Divergence from p to q” D_{KL}(p\,\|\,q) and “from q to p” D_{KL}(q\,\|\,p) are different.
  • notation uses two lines (\|) instead of an arrow (\to).
  • Property: D_{KL}(p\,\|\,q)\ge 0 (Gibbs inequality), equality only when p=q.
WarningCommonly Mistaken Points

KL is called “distance,” but it is not a true metric. It is asymmetric and does not satisfy the triangle inequality. If written in a different direction, it becomes a different quantity.

1.4 The 4 Axioms of the Metric (Distance Function)

Another name for the distance function d(\cdot,\cdot) is metric. For a function to be a distance, it must satisfy the following four axioms.

# Axiom Formula Meaning
1 Non-negativity d(s,d)\ge 0 Distance cannot be negative
2 Identity d(s,d)=0 \iff s=d If 0, the same point
3 Symmetry d(s,d)=d(d,s) Same whether going or coming
4 Triangle Inequality (triangle ineq.) d(s,d)\le d(s,m)+d(m,d) Direct is shorter than the intermediate route

Metric learning: Much of what we do in machine learning ultimately involves “learning the appropriate distance function (space) in a vector space.” We learn an embedding space that makes points that should be close close and points that should be far far apart.

Why KL is not a metric: It violates 3 (symmetry) and 4 (triangle inequality) among the axioms above. (Axioms 1 and 2 are satisfied.)

NoteReal-world examples of asymmetric “distance” (intuition enhancement)
  • Hiking Energy: Energy used to climb a mountain > Energy used to descend. Even if the route is the same, the “cost” varies depending on the direction.
  • Looking Beyond the Valley: When two people standing on the summits of two peaks look at each other, if there is a large lens/obstacle in between, their “visible distance” may differ.
  • Navigation (GPS): Due to one-way roads/traffic volume, S\to D shortest route and D\to S shortest route are different.

1.5 Symmetricing KL: Symmetric KL & Jensen–Shannon

Since KL is asymmetrical and inconvenient, I will create a symmetrical version.

Symmetric KL: D_{\text{SKL}}(p,q) = D_{KL}(p\,\|\,q) + D_{KL}(q\,\|\,p).

Jensen–Shannon divergence (JSD): Given the intermediate distribution m=\tfrac12(p+q) D_{\text{JS}}(p,q) = \tfrac12 D_{KL}(p\,\|\,m) + \tfrac12 D_{KL}(q\,\|\,m).

  • The value remains the same even if the order of p,q is changed → Symmetry.
  • In addition to this, there are various other symmetry methods (you can also define and name them yourself if you wish).

2 KL as Loss Function: Classification and Cross-Entropy

Important

KL divergence is the core of the most widely used loss function in classification. The model distribution q is trained on the ground truth distribution p (fixed).

2.1 Cross-Entropy Decomposition

cross-entropy for correct (one-hot) distribution p, predicted distribution q:

H(p,q) = -\sum_{x} p(x)\log q(x) = \mathbb{E}_{p}[-\log q].

Core Relationship:

\boxed{\,H(p,q) = H(p) + D_{KL}(p\,\|\,q)\,}

  • If p is fixed (correct answer), then H(p) is a constant.
  • Therefore, CE Minimization = KL Minimization = Maximum Likelihood (MLE).

2.2 Mean-seeking vs Mode-seeking (★ emphasis)

When minimizing KL with q as the training variable and p as fixed, the nature of the solution changes completely depending on the direction.

D_{KL}(p\,\|\,q) = \sum_x p(x)\big[\log p(x) - \log q(x)\big].

  • Where p(x)>0, if q(x)\to 0, then -\log q(x)\to +\infty → KL explodes.
  • Therefore, q attempts to cover all regions where p exists → a broad solution that covers multiple modes on average.

Conversely

D_{KL}(q\,\|\,p) = \sum_x q(x)\big[\log q(x) - \log p(x)\big].

  • p(x)\approx 0 where q(x)>0 explodes → q avoids the place where p is 0 q makes itself 0 (zero-forcing).
  • Therefore, q focuses on a single mode (peak).
Forward KL D_{KL}(p\,\|\,q) Reverse KL D_{KL}(q\,\|\,p)
nickname mean-seeking / mass-covering mode-seeking / peak-seeking
Behavior Covers the entire area of p Focused on a single peak
Mechanism zero-avoiding (p>0, but if q=0, it diverges) zero-forcing (p=0, but if q>0, it diverges)
Relationship with MLE MLE is forward KL D_{KL}(\hat p\,\|\,q_\theta) —
WarningTest Trap

“What is the KL direction used in MLE?” → D_{KL}(\hat{p}\,\|\,p_\theta) (forward). If written in reverse, a problem arises where it diverges when p_\theta has mass in the unobserved data region. (In other words, the reverse cannot penalize regions outside the data.)

2.3 (Supplement) Why Cross-Entropy is Popular

Two reasons why CE is preferred over MSE for classification loss:

1) Gradient vanishing is less. In sigmoid output q=\sigma(z)

  • MSE: \dfrac{\partial L}{\partial w} = (q-y)\,\underbrace{\sigma'(z)}_{\text{포화 시 } \to 0}\,x → Gradient vanishes when output saturates.
  • CE (binary): \dfrac{\partial L}{\partial w} = (q-y)\,x → \sigma'(z) The term disappears, resulting in less loss.

2) CE = Maximum log-likelihood of logistic regression (Bernoulli).

\text{Bernoulli: } P(y)=p^{y}(1-p)^{1-y},\quad \log L(\theta)=\sum_i\big[y_i\log p_i + (1-y_i)\log(1-p_i)\big].

The negative of this log-likelihood is the binary cross-entropy.

Interpretation of other cost functions (Reference):

Cost Function Optimal Forecast f^{*}(x)
Mean Squared Error (MSE) Conditional Mean \mathbb{E}[y\mid x]
Mean Absolute Error (MAE) Conditional Median

3 Optimization

3.1 argmin / argmax, and the definition of ML

  • \min_x f(x): function’s minimum value.
  • \arg\min_x f(x): The x value that creates that minimum value.

Example: f(x)=(x-2)^2+3 → \min = 3, \arg\min = 2.

Important

Machine learning is ultimately the task of solving \displaystyle \arg\min_{\theta} \mathcal{L}(\theta). The parameter values that minimize the loss are the “learned model (knowledge)”.

NoteParameter vs Argument (CS Terminology Summary)
  • Parameter: container for values — formal arguments used in the function definition.
  • Argument: The value actually passed when calling the function.

Example: In def D(s, d): ..., s, d is the parameter, and in D(2, 3), 2, 3 is the argument.

3.2 Objective Function Terminology Summary

Direction Function Name
minimize cost / loss / error / objective function
maximize reward / value / benefit / profit function

Notation convention:

  • \hat{x} : The solution to a problem.
  • x^{*} : Optimal solution — “The asterisk emphasizes the good/optimal”.
  • Like \displaystyle \min_{x} f(x,y,z), only the subscript variable is the control variable, and the rest are treated as constants.

3.3 Convex vs Concave

Convex Concave
Shape \cup (e.g., (x-2)^2+3) \cap (e.g., -(x-2)^2+3)
min/max Global min exists Global max exists
Important

Convex functions have a unique global minimum over the entire domain. However, most actual objective functions are non-convex (convex only locally), making it very difficult to find a global minimum.

3.4 Computational complexity perspective: Every problem is search

  • From a computer’s perspective, solving the problem involves searching all candidates using an evaluation function.
  • Therefore, the cost is proportional to the size of the solution space → If it cannot be solved in polynomial time, it is effectively unsolvable.
  • NP-hard / NP-complete: A set of problems that cannot be solved within a reasonable time (combinatorial explosion). Due to realistic time constraints, we are satisfied with a suboptimal solution.
  • Strategy: Restrict search space → Solves faster but is not guaranteed to be optimal (suboptimal).

3.5 Constrained Optimization

\min_x f(x)\quad \text{subject to (s.t.)}\quad g(x)=0.

  • Constraint expressions are attached after “subject to / such that(st)”.
  • If there are constraints, it is expensive because conditions must be checked at every optimization step → I want to solve it unconstrained.

Equality Constraint → Lagrange multiplier: \mathcal{L}(x,\lambda) = f(x) - \lambda\, g(x).

  • Absorb the constraint into the objective function using the auxiliary variable \lambda (Lagrange multiplier).
  • Constraints like g(x)=10 can always be converted to the form =0 as g'(x)=g(x)-10=0 (equality constraint).
  • Note that this provides an approximate solution and may not be an exact solution.

Inequality Constraint → KKT Condition: g(x)\le 0 \;\Rightarrow\; \textbf{Karush–Kuhn–Tucker (KKT)} \text{ 조건으로 변환}.

  • The names of three mathematicians: Karush, Kuhn, and Tucker.
  • We introduce the KKT multiplier (a generalization of Lagrange \lambda) to transform the inequality-constrained problem into an unconstrained problem.

Deeper: Convex Optimization (Stephen Boyd, Stanford) — Although convex shapes may look easy, it is a field deep enough to be a 1,000-page book.

3.6 Closed solution vs. Gradient descent

If it is convex like linear least squares, we set the slope to 0 to immediately obtain the closed form:

\min_w \|Xw-y\|_2^2 \;\Rightarrow\; \nabla_w = 0 \;\Rightarrow\; w^{*} = (X^\top X)^{-1}X^\top y.

If there is no closed solution or it is expensive, gradient descent:

x_{t+1} = x_t - \eta\,\nabla f(x_t).

  • The slope indicates the direction of the slope. If the slope is 0, the extreme point = (local) minimum/maximum.
  • \eta = step size / learning rate = how much to move at once.
WarningThe learning rate is “art”
  • \eta If too large: Wanders or diverges around the minimum point.
  • \eta If too small: Too slow.
  • Hint: Using the second derivative (Hessian) allows you to estimate the appropriate stride length (Newtonian method series) → x_{t+1}=x_t-[\nabla^2 f]^{-1}\nabla f. However, finding the optimal \eta in practice is still difficult.

4 Generalization

Important

The goal of machine learning = generalization. “If I had to remember just one word, it would be generalization.”

4.1 Definition of Overfitting

Intuitive Definition: Not generalizing to unseen data because of looking at too much of the training data.

Formal Definition: Assume that data originates from the data-generating distribution \mathcal{D}. Hypothesis space \mathcal{H}, hypothesis (=model) h\in\mathcal{H}.

  • Training error \hat{R}(h): Error on training set (calculable).
  • True error R(h): Error in the true distribution (smaller indicates better generalization).

Model h is overfit: some h'\in\mathcal{H} exists \hat{R}(h) < \hat{R}(h') \quad\text{이지만}\quad R(h) > R(h'). That is, the case where the learning error is lower but the true error is higher.

NoteWhy is it difficult to diagnose overfitting?

By definition, one would have to check all h' to determine if even one satisfies the above condition → In practice, this is impossible. Therefore, papers do not make a definitive statement; instead, they write, “I assume/estimate that my model is overfit.” (Decision signals will be discussed later.)

4.2 “Neural networks are the worst-case generalization models, so why use them?” (★ Emphasized discussion)

  • Neural networks are notorious for being models that overfit very well to the training set, that is, do not generalize well.
  • In the past, models like SVM (support vector machine), which were theoretically well-guaranteed for generalization, were used.
  • And yet, we use neural networks now. Why?

Key Answer: Generalization is too difficult, so virtually giving up, and instead

“Let’s gather a massive training set that is almost identical to reality and fit it perfectly.” → Appears like a generalization.

  • This is the essence of benign overfitting, and large data + large models = large-scale (LLM) approach.
  • Advantages of Neural Networks: Easy to scale (capacity can be easily increased by adding parameters → can store massive amounts of information).

4.3 Capacity & Bias–Variance Trade-off

Important

The Bias–Variance Trade-off is a central concept in machine learning. With this, you can understand overfitting, underfitting, and capacity all at once.

Status Meaning Result
High bias Model is too rigid/inflexible Does not capture enough information → underfitting
High variance Model is too flexible Fits even the variance of the training set → overfitting
  • Capacity: Amount of information/complexity the model can hold.
    • SVM: small capacity → fails if training set becomes larger than capacity.
    • Neural Networks: Capacity can be easily increased (by adding parameters), making them advantageous for large-scale applications.
