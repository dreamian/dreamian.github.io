2 Basic Definition of a Stochastic Process

2.1 A stochastic process as a function of two variables

Random / Stochastic Process \(X(\omega,t)\) is a rule that assigns a single time function to each outcome \(\omega\in\Omega\) in the sample space.

\[ X:\ \Omega\times\mathcal{T}\to\mathbb{R},\qquad (\omega,t)\mapsto X(\omega,t) \]

In other words, the stochastic process is a function of two variables, \(\omega\) and \(t\), and depending on which variable is fixed, it becomes a completely different object.

Fixing Obtained Name
\(\omega\) Fixed, \(t\) Varying Deterministic time function \(t\mapsto X(\omega,t)\) Sample function / realization
\(t\) Fixed, \(\omega\) Changing Random variable \(X(t)\), Distribution \(p_{X(t)}(x)\) Random variable at time \(t\)
Both fixed One real number Sample value
Both change Collection of sample functions Ensemble
ImportantThe sample function must be defined over the entire domain

Each sampling function \(t\mapsto X(\omega,t)\) must be defined across the entire time domain of interest. Constructions such as “for some \(\omega\), there is a value only at some time points” are not allowed.

2.2 Reading horizontally vs. reading vertically

The figure below shows the dual interpretation of a stochastic process at once.

  • Read Horizontally: Each curve is a sampling function corresponding to a different result \(\omega\). The waveform observed today and the waveform observed tomorrow may be different curves.
  • Reading Vertically: If a vertical line is drawn at a specific time \(t_0\), the set of points where the curves intersect that line becomes the samples of the random variable \(X(t_0)\), and the distribution is \(p_{X(t_0)}(x)\).

3 Stationarity

3.1 The precise meaning of joint distribution

Since the definition of stationarity involves the joint distribution, let us first clarify this concept. When two random variables \(X, Y\) are defined on the same sample space, the joint CDF is

\[ P_{X,Y}(x,y) \stackrel{\text{def}}{=} \Pr[X\le x,\ Y\le y] = \Pr\Big(\{\omega: X(\omega)\le x\}\cap\{\omega: Y(\omega)\le y\}\Big) \]

, and the joint PDF is (if it exists) \(p_{X,Y}(x,y)=\dfrac{\partial^2}{\partial x\,\partial y}P_{X,Y}(x,y)\). The \(N\) degree joint distribution of a stochastic process is an extension of this.

\[ P_{X(t_1),\dots,X(t_N)}(x_1,\dots,x_N) = \Pr\Big[X(t_1)\le x_1,\ \dots,\ X(t_N)\le x_N\Big] \]

WarningNot the intersection of random variables

The object to which the intersection is taken is not the random variable \(X_i\) itself, but the event \(\{X_i\le x_i\}\). And “distribution” refers to viewing the probability of that intersection event as a function of \((x_1,\dots,x_N)\). To summarize:

Joint Distribution = “Probability that events \(X_i\) generated from each \(\{X_i\le x_i\}\) occur simultaneously” expressed as a function of \((x_1,\dots,x_N)\)

3.2 Strict-Sense Stationarity (SSS)

NoteDefinition (SSS)

The fact that the stochastic process \(X(t)\) is strong stationary (SSS) means that the joint amplitude distribution is invariant under common time shifts.

\[ P_{X(t_1-\Delta),\dots,X(t_N-\Delta)}(x_1,\dots,x_N) = P_{X(t_1),\dots,X(t_N)}(x_1,\dots,x_N), \qquad \forall\,\Delta \]

This equation must hold for all three of the following:

  1. Random Order \(N\) (No matter how many times you select)
  2. Random set of times \(t_1,\dots,t_N\)
  3. Random movement \(\Delta\in\mathbb{R}\)

Intuitively, this means that the process appears statistically the same regardless of when the observation begins (where the clock’s origin is set).

TipQ. Does the SSS condition need to hold only in a specific \(\Delta\), or must it hold in all \(\Delta\)?

must hold for all \(\Delta\in\mathbb{R}\). That is exactly what the definition of \(\forall\Delta\) means.

If the joint distribution is invariant for only one specific \(\Delta_0\) (and its integer multiples), this is not “independent of the time origin” but a much weaker property that “statistics repeat with a period \(\Delta_0\),” and such a process is separately called a cyclostationary process. (e.g., a digital communication signal modulated with a symbol period \(T_s\))

Additionally, the \(\forall\Delta\) condition is simultaneously applied with the order \(N\) and the “randomness” of the time set. If either of these is restricted to a “specific case,” it is no longer SSS but becomes weakened stationarity. A typical example of weakening is the WSS shown below.

3.2.1 Things that follow from SSS

(1) \(N=1\): Linear distribution independent of time → Mean and variance are constant

Applying the SSS definition to \(N=1\) results in \(p_{X(t-\Delta)}(x)=p_{X(t)}(x)\), meaning the marginal distribution is the same for all times. Therefore

\[ m_X(t) = \mathbb{E}[X(t)] = \int_{-\infty}^{\infty} x\,p_{X(t)}(x)\,dx = \mu \quad(\text{상수}) \]

In a general stochastic process, the mean is also a function of \(t\), but in SSS, since the PDF itself is fixed, the mean is also fixed.

WarningThe converse does not hold

“Fixed PDF ⇒ Fixed Mean” is true, but “Fixed Mean ⇒ Fixed PDF” is false. For example, consider a process that follows a uniform distribution at some time and a Gaussian distribution at others, but has a mean that is always 0. Since the mean is fixed but the distribution varies from time to time, it is not SSS. This distinction serves as the motivation for introducing the concept of WSS separately.

(2) \(N=2\): Autocorrelation depends only on the time difference — Proven in the Autocorrelation Function section below.

3.3 Autocorrelation Function

NoteDefinition

\[ R_X(t_1,t_2) = \mathbb{E}\big[X(t_1)\,X(t_2)\big] = \int_{-\infty}^{\infty}\!\int_{-\infty}^{\infty} x_1x_2\,p_{X(t_1),X(t_2)}(x_1,x_2)\,dx_1\,dx_2 \]

In random variable theory, the expected value of the product of two random variables is called correlation. Here, we choose two times \(t_1,t_2\), but since they are ultimately two random variables derived from the same stochastic process, it is called autocorrelation, meaning “correlation with itself.” It measures how “moves together” (is similar) the amplitudes of the two times.

3.3.1 Why does the steady process depend only on the time difference \(\tau\)?

The key point is that the expected value is completely determined by the joint distribution alone. The right-hand side of the above definition depends only on \(p_{X(t_1),X(t_2)}\).

SSS definition(\(N=2\)) is for all \(\Delta\)

\[ p_{X(t_1-\Delta),\,X(t_2-\Delta)}(x_1,x_2) = p_{X(t_1),\,X(t_2)}(x_1,x_2) \]

It requires . Since it holds for all \(\Delta\), you may substitute a specific value \(\Delta=t_2\).

\[ p_{X(t_1-t_2),\,X(0)}(x_1,x_2) = p_{X(t_1),\,X(t_2)}(x_1,x_2) \]

Since the two joint distributions are the same, the expected value calculated from them is also the same.

\[ R_X(t_1,t_2) = \mathbb{E}[X(t_1)X(t_2)] = \mathbb{E}[X(t_1-t_2)\,X(0)] = R_X(t_1-t_2,\,0) \]

The right-hand side does not individually include \(t_1,t_2\), but only the difference \(\tau = t_1-t_2\). Therefore

\[ \boxed{R_X(t_1,t_2) = R_X(\tau),\qquad \tau = t_1 - t_2} \]

Intuitively, if the time origin does not affect the statistics, the only information remaining between two time points is “how far apart”. Since \((t_1,t_2)=(5,3)\) and \((105,103)\) are both \(\tau=2\), they must have the same correlation in a stationary process. This can also be written as follows.

\[ R_X(t_1,t_2) = R_X(t_1+\Delta,\ t_2+\Delta)\qquad \forall\Delta \]

TipWhat was actually used in this derivation is not the entire SSS

In the derivation above, only the time-shift invariance of the joint distribution \(N=2\) was used. That is, to obtain “\(R_X\) depends only on \(\tau\),” it is not necessary to go up to SSS (all orders), and second-order invariance is sufficient. This observation is the design principle of WSS.

3.3.2 The meaning of \(\tau\) and “Univariate vs. Multivariate”

TipQ. Is \(\tau\) a time shift, and does it mean \(R_X(\tau)=\mathbb{E}[X(t_1)X(t_1-\tau)]\)? Should I understand this as multivariate rather than univariate?

The beginning part is correct. If you substitute \(t_2=t_1-\tau\)

\[ R_X(\tau) = \mathbb{E}\big[X(t_1)\,X(t_1-\tau)\big] \]

It is . (If defined as \(\tau=t_2-t_1\), it becomes \(\mathbb{E}[X(t_1)X(t_1+\tau)]\), but as shown below, \(R_X\) in the real number WSS process is an even function, so it is the same regardless of how it is defined.)

The expression “multivariate” is accurate only when distinguishing between two perspectives.

Perspective Answer
Number of input variables for function \(R_X\) Normal process: \(R_X(t_1,t_2)\) is a 2-variable function. Normal process: \(\tau\) is reduced to a single 1-variable function
Probability structure required to calculate that value The joint (bivariate) distribution of the two random variables \(X(t_1), X(t_1-\tau)\) is required → In this sense, “multivariate” is correct

\(\mathbb{E}[X(t_1)X(t_1-\tau)]\) cannot be calculated from the marginal distributions of each time point alone (except for the special case where the two time points are independent). That is, “\(\tau\) is a single variable, but its value at \(\tau\) is the second joint moment of two random variables”.

3.3.3 Basic properties of the autocorrelation function

For the real number WSS process, the following holds.

(a) \(R_X(0)\) is average power

\[ R_X(0) = \mathbb{E}[X(t)^2] \ge 0 \]

(b) Even function: \(\tau\to-\tau\) merely swaps the roles of the two time points, so

\[ R_X(-\tau) = \mathbb{E}[X(t)X(t+\tau)] = \mathbb{E}[X(t+\tau)X(t)] = R_X(\tau) \]

(c) Maximum at the origin: Applying the Cauchy–Schwarz inequality \(\big(\mathbb{E}[UV]\big)^2\le\mathbb{E}[U^2]\,\mathbb{E}[V^2]\) to \(U=X(t),\ V=X(t-\tau)\)

\[ R_X(\tau)^2 \le \mathbb{E}[X(t)^2]\,\mathbb{E}[X(t-\tau)^2] = R_X(0)^2 \quad\Longrightarrow\quad |R_X(\tau)|\le R_X(0) \]

Therefore, the “typical \(R_X(\tau)\)” is depicted as having a maximum value at \(\tau=0\) and decreasing as \(|\tau|\) increases. It is an intuition that the correlation with itself is strongest, and memory fades as time moves further away.

3.4 Wide-Sense Stationarity (WSS)

NoteDefinition (WSS)

A stochastic process \(X(t)\) is called WSST (WSST) if it satisfies the following two conditions.

  1. Average is constant: \(\;m_X(t) = \mu\quad \forall t\)
  2. Autocorrelation depends only on time difference: \(\;\mathbb{E}[X(t_1)X(t_2)] = R_X(t_1-t_2)\)

While SSS requires time-shift invariance of the joint distribution of all orders, WSS requires invariance of only the first and second moments. For this reason, WSS is also called second-order stationarity. To illustrate Condition 2: The PDFs themselves at times \(t_1\) and \(t_2\) may differ, but if the two points are shifted by the same amount \(\Delta\), the correlation must be the same if the interval between the two points is the same.

TipQ. Why does \(\mathbb{E}[X(t_1)X(t_2)] = R_X(t_1-t_2)\) hold in WSS?

This equation is not a theorem to be proven, but the definition of WSS itself (condition 2). It means “a process satisfying this property is called WSS.”

Question Answer
Does it automatically hold in a general stochastic process? No. In general, \(R_X(t_1,t_2)\) is a true 2-variable function
Does it hold within WSS? Yes. That is condition 2 of the WSS definition
Why is it valid to introduce such a condition? Since this condition is automatically derived when assuming SSS (as in the previous section), it is an independent assumption that extracts only the part actually necessary for PSD calculation from the conclusions of SSS and elevates it to an independent assumption.

Therefore, the moment of changing \(\mathbb{E}[x(t_1)x(t_2)]\) to \(R_X(t_1-t_2)\) in the subsequent Wiener–Khinchin derivation is not the moment of writing an identity, but the moment of introducing the decisive assumption that “this process is assumed to be WSS.”

3.4.1 The relationship between SSS and WSS

\[ \text{SSS}\ \text{그리고}\ \mathbb{E}[X^2(t)]<\infty \;\Longrightarrow\; \text{WSS}, \qquad \text{WSS} \;\not\Longrightarrow\; \text{SSS} \]

  • SSS ⇒ WSS: As shown above, the mean constant in \(N=1\) and \(R_X\) in \(N=2\)Z depend only on \(\tau\). However, since \(R_X\) itself is defined only if the second moment is finite, the condition \(\mathbb{E}[X^2]<\infty\) is applied.
  • WSS ⇏ SSS: WSS imposes no constraints on joint distributions of degree 3 or higher. Counterexample (Discrete Time): If \(X[n]\) are independent of each other, and \(n\) is \(X[n]\sim\mathcal{N}(0,1)\) if it is even and \(X[n]\sim\mathrm{Unif}[-\sqrt{3},\sqrt{3}]\) if it is odd, then the mean is always \(0\) and the variance is always \(1\) and \(R_X[k]=\delta[k]\), so it is WSS. However, since the marginal distribution itself changes with time, it is not SSS.
  • Exception: In Gaussian processes, WSS ⇔ SSS — Proven in the Gaussian process section.

In practice, WSS is often assumed even if it is not strictly SSS. For example, although radio channels are strictly time-varying, models that approximate WSS over short intervals (such as the WSSUS channel model) are used as a standard.

3.5 Covariance function and variance

The covariance function of the WSS process with mean \(m_X\) is

\[ K_X(\tau) = \mathbb{E}\big[(X(t)-m_X)(X(t-\tau)-m_X)\big] \]

It is . If expanded

\[ K_X(\tau) = \mathbb{E}[X(t)X(t-\tau)] - m_X\mathbb{E}[X(t-\tau)] - m_X\mathbb{E}[X(t)] + m_X^2 = R_X(\tau) - m_X^2 \]

That is, \(K_X\) and \(R_X\) have only a difference of a constant due to the mean, and they are identical when the mean is 0. \(R_X\) is the non-centered second moment, and \(K_X\) is the centered second moment.

Variance is the 0-lag value of the covariance function.

\[ \sigma_X^2 = K_X(0) = R_X(0) - m_X^2 \]

That is, the variance is the “squared mean of the degree to which \(X(t)\) deviates from the mean,” and is merely the \(\tau=0\) value of the covariance function.

3.6 Examples satisfying SSS

Example 1: Stochastic Constant Process \(X(t)\equiv A\)

This is a process that takes the same random variable \(A\) as its value at all time points. For any \(N\), \(t_1,\dots,t_N\), \(\Delta\)

\[ \big(X(t_1-\Delta),\dots,X(t_N-\Delta)\big) = (A,\dots,A) = \big(X(t_1),\dots,X(t_N)\big) \]

Since , the joint distribution is trivially invariant. This is the simplest SSS example that holds regardless of the distribution of \(A\). The PSD for this process is calculated from.

Example 2: WSS Gaussian Process — Since the joint distribution of a Gaussian process is determined solely by the mean and covariance, if the mean and covariance are invariant to time shift (WSS), the entire joint distribution is invariant (SSS). This is proven in the Gaussian Process section. Gaussian white noise and exponentially correlated processes assumed to be Gaussian belong to this category.

NoteWhy Learn Normality
  1. Conceptual Reference Point: SSS provides a definition of “complete normality” and clarifies how much weaker the assumption of WSS used in practice is compared to it.
  2. Prerequisite for PSD Definition: PSD is defined as the Fourier transform of \(R_X(\tau)\), and this definition holds if \(R_X\) is a function of \(\tau\) (at least WSS).
  3. Common Premise of Subsequent Theories: Subsequent models, such as the sampling theorem of band-limited processes and the stationary Poisson process (\(\lambda\) constant), are also simplified based on the stationarity assumption.

4 Power Spectral Density

4.1 PSD of deterministic signals

The PSD of the deterministic signal \(x(t)\) is defined as the time average.

\[ S_x(f) = \lim_{T\to\infty}\frac{1}{2T}\big|X_T(f)\big|^2, \qquad X_T(f) = \int_{-T}^{T} x(t)\,e^{-j2\pi ft}\,dt \]

  • If \(x(t)\) spans an infinite amount of time, the total energy becomes infinite, so the Fourier transform can diverge.
  • So, we obtain the spectrum \(X_T(f)\) of the signal cut into the finite interval \([-T,T]\), and
  • After dividing \(|X_T(f)|^2\) (energy spectrum) by the observation interval length \(2T\) to convert it into power per unit time,
  • Send to \(T\to\infty\) to obtain the average power spectrum for the entire time.
TipQ. Is \(T\) a period? Can’t the integration range be \(0\sim T\)? Why is the denominator \(2T\)?

\(T\) is not a period. This definition makes no assumption whatsoever about periodic signals; rather, it is intended to handle non-periodic signals and stochastic processes. \(T\) is the half-window length of the observation interval, and the total length of the observation interval \([-T,T]\) is \(2T\). \(T\to\infty\) does not mean “the period goes infinitely,” but rather “the observation time is extended until it eventually reaches the average over the entire time axis”. (This confusion arises because the notation and appearance are similar to \(\frac{1}{T_0}\int_0^{T_0}\) used for one period \(T_0\) in Fourier series.)

The key principle is that the denominator equals the length of the integration interval. Only then will the result be an exact “per unit of time” amount.

Observation interval Interval length Normalization
\([-T,\,T]\) \(2T\) \(\dfrac{1}{2T}\lvert X_T(f)\rvert^2\)
\([0,\,T]\) \(T\) \(\dfrac{1}{T}\lvert X_T(f)\rvert^2\)

Even if we set it as \([0,T]\), it is a completely equivalent definition as long as normalization is maintained, and for the \(T\to\infty\) limit (for a normal signal), the starting point of the interval does not affect the result. Choosing an interval symmetric to the origin is for convenience of derivation. If we use the symmetric window \(w_T(t)=\mathbf{1}\{|t|\le T\}\), the integration region after the variable transformation below becomes a neat rhombus symmetric to the origin.

4.2 PSD of a stochastic process: Defined as expected value

The situation is different for the stochastic process \(X(t)\).

  • The waveform \(X(\omega,t)\) varies depending on the sampling function, and what we know is not the waveform but only the distribution. The sample observed today is a different curve from the sample observed tomorrow.
  • Therefore, there is no single Fourier transform that represents the entire stochastic process. Although it is possible to calculate \(X_T(f)\) for a single sample function, its value is a random variable that differs for each sample.

Therefore, PSD is defined by calculating the finite interval spectrum \(|X_T(f)|^2\) and taking the ensemble mean (expected value). It averages the results so that each sampling function contributes by its own probability.

\[ S_X(f) = \lim_{T\to\infty}\frac{1}{2T}\,\mathbb{E}\Big[\big|X_T(f)\big|^2\Big] \]

The result is the Wiener–Khinchin theorem.

\[ \boxed{S_X(f) = \int_{-\infty}^{\infty} R_X(\tau)\,e^{-j2\pi f\tau}\,d\tau} \]

In other words, the PSD of a stochastic process is the Fourier transform of the autocorrelation function. This is derived step-by-step below.

4.3 Derivation of the Wiener–Khinchin theorem

4.3.1 Step 1: Set up a finite window

Observe a time-limited version to avoid convergence issues.

\[ x_T(t) = x(t)\,w_T(t),\qquad w_T(t)=\begin{cases}1, & |t|\le T\\ 0, & \text{otherwise}\end{cases} \]

\[ X_T(f) = \int_{-\infty}^{\infty} x_T(t)\,e^{-j2\pi ft}\,dt = \int_{-T}^{T} x(t)\,e^{-j2\pi ft}\,dt \]

A finite amount of time is defined as follows.

\[ S_X^{(T)}(f) = \frac{1}{2T}\,\big|X_T(f)\big|^2 \]

4.3.2 Step 2: \(|X_T(f)|^2\) Expansion — Appearance of Complex Conjugates

The square of the absolute value of a complex number is the product of that number and its complex conjugate.

\[ |X_T(f)|^2 = X_T(f)\cdot X_T^*(f) \]

The first argument is the definition of \(X_T(f)\), and the integration variable is written as \(t_1\). The second argument (conjugate) is written as another integration variable \(t_2\). Since \(x(t)\) is a real number, taking the conjugate only changes the sign of the exponent.

\[ |X_T(f)|^2 = \underbrace{\left(\int_{-T}^{T} x(t_1)\,e^{-j2\pi ft_1}\,dt_1\right)}_{X_T(f)} \underbrace{\left(\int_{-T}^{T} x(t_2)\,e^{+j2\pi ft_2}\,dt_2\right)}_{X_T^*(f)} \]

NoteReason for separating integration variables into \(t_1\) and \(t_2\)

The two factors must each have independent integration variables so that they can be combined into a double integral in the next step, where the product of two time points \(x(t_1)x(t_2)\) appears and connects to the autocorrelation \(\mathbb{E}[x(t_1)x(t_2)]\). If only \(X_T(f)\) is used without a conjugate factor, the equality does not hold. The conjugate factor is the second integral.

4.3.3 Step 3: Convert the product of two integrals into a double integral

\[ |X_T(f)|^2 = \int_{-T}^{T}\!\int_{-T}^{T} x(t_1)\,x(t_2)\,e^{-j2\pi f(t_1-t_2)}\,dt_1\,dt_2 \]

TipQ. Is there a guarantee that the product of the individual integrals is equal to the product followed by the integral?

It always holds true. It is an identity derived solely from the linearity of integration, not an approximation.

The key point is that after integration, \(A\equiv\int x(t_1)e^{-j2\pi ft_1}dt_1\) and \(B\equiv\int x(t_2)e^{+j2\pi ft_2}dt_2\) are not functions of \(t_1, t_2\), but constants (with respect to the given \(f,T\)).

(i) Since \(B\) is a constant independent of \(t_1\), it can be substituted into the integral of \(A\). \[ A\cdot B = \int_{-T}^{T} x(t_1)e^{-j2\pi ft_1}\cdot B\;dt_1 \]

(ii) \(B\) is rewritten in its definition. \[ = \int_{-T}^{T} x(t_1)e^{-j2\pi ft_1}\left(\int_{-T}^{T}x(t_2)e^{+j2\pi ft_2}\,dt_2\right)dt_1 \]

(iii) From the perspective of the inner integral, \(x(t_1)e^{-j2\pi ft_1}\) is a constant, so it is placed inside. \[ = \int_{-T}^{T}\!\int_{-T}^{T} x(t_1)x(t_2)\,e^{-j2\pi f t_1}e^{+j2\pi f t_2}\,dt_2\,dt_1 \]

This result is strictly an iterated integral. Equating this to a double integral over a square region, and the justification for subsequent operations such as changing the order of integration or including \(\mathbb{E}[\cdot]\) in the integral, is guaranteed by the Fubini–Tonelli theorem.

\[ \iint |x(t_1)x(t_2)|\,dt_1\,dt_2<\infty \;\Longrightarrow\; \text{반복적분} = \text{이중적분},\ \text{순서 교환 가능} \]

If the integration interval \([-T,T]\) is finite and the signal is bounded, this absolute convergence condition is automatically satisfied.

4.3.4 Step 4: Take the expected value and introduce the WSS assumption

Since both expectation and integral are linear operations (by Fubini), they can be interchanged.

\[ \mathbb{E}\big[|X_T(f)|^2\big] = \int_{-T}^{T}\!\int_{-T}^{T} \mathbb{E}\big[x(t_1)x(t_2)\big]\,e^{-j2\pi f(t_1-t_2)}\,dt_1\,dt_2 \]

Here we introduce a deterministic assumption: the process is WSS. Then \(\mathbb{E}[x(t_1)x(t_2)]\) is the autocorrelation function, and it depends only on the difference \(t_1-t_2\), not on the absolute time.

\[ \mathbb{E}\big[|X_T(f)|^2\big] = \int_{-T}^{T}\!\int_{-T}^{T} R_X(t_1-t_2)\,e^{-j2\pi f(t_1-t_2)}\,dt_1\,dt_2 \]

Now that the entire integrand has become a single function \(t_1-t_2\), it is natural to treat this difference as a new variable.

4.3.5 Step 5: Variable Transformation \((t_1,t_2)\mapsto(\eta,\tau)\) and Jacobian

\[ \eta = \frac{t_1+t_2}{2}\ (\text{중심}),\qquad \tau = t_1-t_2\ (\text{차이}) \qquad\Longleftrightarrow\qquad t_1 = \eta+\frac{\tau}{2},\quad t_2 = \eta-\frac{\tau}{2} \]

The Jacobian determinant is

\[ J = \det\begin{bmatrix}\dfrac{\partial t_1}{\partial\eta} & \dfrac{\partial t_1}{\partial\tau}\\[6pt] \dfrac{\partial t_2}{\partial\eta} & \dfrac{\partial t_2}{\partial\tau}\end{bmatrix} = \det\begin{bmatrix}1 & 1/2\\ 1 & -1/2\end{bmatrix} = (1)\!\left(-\tfrac{1}{2}\right) - \left(\tfrac{1}{2}\right)\!(1) = -1 \]

and the area element is

\[ dt_1\,dt_2 = |J|\,d\eta\,d\tau = d\eta\,d\tau \]

TipQ. It should be \(J=-1\), so why is it \(dt_1dt_2 = d\eta\,d\tau\)? Isn’t the symbol missing?

It is not an omission, but because the original absolute value \(|J|\) is entered into the multivariable substitution integral formula.

  • \(dt_1dt_2\) and \(d\eta\,d\tau\) are area elements, and the area is always greater than or equal to 0 regardless of the coordinate system.
  • The sign of the determinant \(J\) indicates whether the transformation preserves (\(J>0\)) or flips (\(J<0\)) the orientation, and the size \(|J|\) indicates the scaling ratio of the area.
  • Since the area ratio is needed for integration, only \(|J|\) is used.

Here, \(J=-1\) is obtained because the winding direction of the axis is reversed, as \(\tau=t_1-t_2\) decreases as \(t_2\) increases. If defined as \(\tau=t_2-t_1\), \(J=+1\) is obtained. In either case, since it is \(|J|=1\), this transformation preserves the area, and \(dt_1dt_2=d\eta\,d\tau\) can be used as is.

4.3.6 Step 6: Integration Region — The square becomes a rhombus

The original integration region is a square \([-T,T]\times[-T,T]\). We move this to \((\eta,\tau)\).

① \(t_1\) Condition

\[ -T\le \eta+\frac{\tau}{2}\le T \quad\Longrightarrow\quad -T-\frac{\tau}{2}\le\eta\le T-\frac{\tau}{2} \]

② \(t_2\) Condition

\[ -T\le \eta-\frac{\tau}{2}\le T \quad\Longrightarrow\quad -T+\frac{\tau}{2}\le\eta\le T+\frac{\tau}{2} \]

③ Intersection of two conditions: Take the larger of the lower bounds and the smaller of the upper bounds.

\[ \max\!\left(-T-\tfrac{\tau}{2},\,-T+\tfrac{\tau}{2}\right) = -T+\frac{|\tau|}{2},\qquad \min\!\left(T-\tfrac{\tau}{2},\,T+\tfrac{\tau}{2}\right) = T-\frac{|\tau|}{2} \]

\[ \Longrightarrow\quad -\Big(T-\frac{|\tau|}{2}\Big)\le\eta\le T-\frac{|\tau|}{2} \quad\Longleftrightarrow\quad |\eta|+\frac{|\tau|}{2}\le T \]

④ Range of \(\tau\): \(\eta\) For the interval not to be empty, lower bound ≤ upper bound must be true.

\[ -T+\frac{|\tau|}{2}\le T-\frac{|\tau|}{2}\quad\Longrightarrow\quad |\tau|\le 2T \]

Therefore

\[ \mathbb{E}\big[|X_T(f)|^2\big] = \int_{-2T}^{2T}\int_{-(T-|\tau|/2)}^{\,T-|\tau|/2} R_X(\tau)\,e^{-j2\pi f\tau}\,d\eta\,d\tau \]

\(|\eta|+|\tau|/2\le T\) is a diamond in the \((\eta,\tau)\) plane. The transformation \((\eta,\tau)\) is equivalent to rotating a square \(45^\circ\) to make the diagonal the new axis, so the original square appears as a rhombus in the new coordinates. As \(\tau\) goes from \(0\) to \(\pm2T\), the allowable width \(\eta\) \(2T-|\tau|\) decreases linearly to become a vertex.

4.3.7 Step 7: Integrate for \(\eta\) — Introduction of trigonometric weights

Since the integrand \(R_X(\tau)e^{-j2\pi f\tau}\) does not depend on \(\eta\), the \(\eta\) integration is merely to find the “height (width)” of the rhombus.

\[ \int_{-(T-|\tau|/2)}^{\,T-|\tau|/2} d\eta = 2T-|\tau| \]

\[ \mathbb{E}\big[|X_T(f)|^2\big] = \int_{-2T}^{2T}\big(2T-|\tau|\big)\,R_X(\tau)\,e^{-j2\pi f\tau}\,d\tau \]

If you divide by \(2T\)

\[ \frac{1}{2T}\,\mathbb{E}\big[|X_T(f)|^2\big] = \int_{-2T}^{2T}\left(1-\frac{|\tau|}{2T}\right)R_X(\tau)\,e^{-j2\pi f\tau}\,d\tau \]

NoteMeaning of triangular weights \((1-|\tau|/2T)\)

Within an observation interval of length \(2T\), the number of pairs of points with a time difference \(\tau\)Z \((t_1,t_2)\) is highest at \(\tau=0\), and decreases linearly as \(|\tau|\) increases (width of the rhombus). That is, in finite observations, correlation of large lags is less reflected, and this effect is represented by triangular (Bartlett) weights.

4.3.8 8th step: \(T\to\infty\) extreme

If \(T\to\infty\), then at each \(\tau\) it becomes \((1-|\tau|/2T)\to1\) and the integration interval expands to \((-\infty,\infty)\).

\[ S_X(f) = \lim_{T\to\infty}\int_{-2T}^{2T}\left(1-\frac{|\tau|}{2T}\right)R_X(\tau)\,e^{-j2\pi f\tau}\,d\tau = \int_{-\infty}^{\infty} R_X(\tau)\,e^{-j2\pi f\tau}\,d\tau \]

(The exchange between limits and integrals is justified by the Governing Convergence Theorem if \(\int|R_X(\tau)|\,d\tau<\infty\). When \(R_X\) includes a delta function, as in white noise, it is understood in the sense of a generalized function.)

4.4 Wiener–Khinchin pairs and properties

\[ S_X(f) = \mathcal{F}\{R_X(\tau)\}(f),\qquad R_X(\tau) = \mathcal{F}^{-1}\{S_X(f)\}(\tau) = \int_{-\infty}^{\infty}S_X(f)\,e^{j2\pi f\tau}\,df \]

Time delay structure ⇔ frequency component are a Fourier pair with each other. From this, several properties emerge immediately.

  • Total Power: Substituting \(\tau=0\) into the inverse transform yields \(\;R_X(0)=\mathbb{E}[X^2(t)]=\displaystyle\int_{-\infty}^{\infty}S_X(f)\,df\). Integrating the PSD over the entire frequency range gives the average power.
  • Real-Even Function: Since \(R_X\) is a real-even function, \(S_X(f)=\displaystyle 2\int_0^\infty R_X(\tau)\cos(2\pi f\tau)\,d\tau\) is a real-even function and is an even function for \(f\).
  • Non-negative: \(S_X(f)\) is the limit of \(\frac{1}{2T}\mathbb{E}|X_T(f)|^2\ge0\), so it is \(S_X(f)\ge0\).

5 Example: Correlation Structure and Spectrum Duality

5.1 Extreme 1 — White Noise: \(R_X(\tau)=\sigma^2\delta(\tau)\)

\[ R_X(\tau) = \sigma^2\delta(\tau) \quad\xrightarrow{\ \mathcal{F}\ }\quad S_X(f) = \int_{-\infty}^{\infty}\sigma^2\delta(\tau)\,e^{-j2\pi f\tau}\,d\tau = \sigma^2\quad(\text{평탄}) \]

In communication, \(N_0/2\) is usually used instead of \(\sigma^2\): \(R_X(\tau)=\frac{N_0}{2}\delta(\tau)\), \(S_X(f)=\frac{N_0}{2}\) (both PSD).

Statistical Significance: From different perspectives

\[ \forall\,\tau\ne0:\quad R_X(\tau) = \mathbb{E}[X(t)X(t-\tau)] = 0 \]

In other words, if the two points in time differ even slightly, the correlation is 0. It is a no memory process, so even if you know the exact value at any given moment, you cannot predict the value a very short time later.

NotePhysical example: thermal noise

If you measure the voltage across a resistor with no power connected, it appears as zero on a large scale, but if you zoom in with an oscilloscope to the \(10^{-4}\,\text{V}\) level, it is not exactly zero. This is because the numerous electrons inside the conductor move randomly due to thermal energy, shifting to one side at one moment and to the opposite side the next. The average is zero, but the instantaneous value fluctuates between positive and negative.

  • Why White: Even if we know the noise at a single moment, we cannot predict the noise \(10^{-7}\) seconds later. Since it does not matter, it is \(R_X(\tau)\propto\delta(\tau)\), and the PSD is the same whether it is 100 MHz or several GHz. This is the reason why we cannot control or predict this noise.
  • Why Gaussian: Since the noise voltage is the sum of a very large number of electron motions, by the central limit theorem, the overall behavior appears as a Gaussian random variable with a mean of 0.
  • Origin of the Name: It is called “white” by likening it to light that appears white when all visible frequency components are evenly mixed. However, this is merely a metaphor for the name; the actual solar spectrum is in the form of blackbody radiation and is not strictly flat.
WarningThe point of idealization

Perfect white noise is \(R_X(0)=\int S_X(f)\,df=\infty\), meaning average power is infinite, so it is a mathematical idealization that cannot physically exist. Since actual thermal noise is flat at room temperature up to approximately \(kT/h\approx 6\,\text{THz}\), the white model is used to mean that it is flat over a much wider range than the band of interest (radio communication band). After passing through the receiver filter, the power becomes finite (see LTI section below).

5.2 Extreme 2 — Stochastic Constant Process: \(X(t)\equiv A\)

5.2.1 Autocorrelation

Since the same random variable \(A\) is at all times, no matter what the time is or what \(\tau\) is

\[ R_X(\tau) = \mathbb{E}[X(t)X(t-\tau)] = \mathbb{E}[A\cdot A] = \mathbb{E}[A^2] \]

TipQ. Why \(\mathbb{E}[A^2] = \sigma_A^2 + m_A^2\)?

Definition of variance \(\sigma_A^2 = \mathbb{E}[(A-m_A)^2]\) (where \(m_A=\mathbb{E}[A]\)) expands

\[ \sigma_A^2 = \mathbb{E}[A^2] - 2m_A\mathbb{E}[A] + m_A^2 = \mathbb{E}[A^2] - 2m_A^2 + m_A^2 = \mathbb{E}[A^2] - m_A^2 \]

Therefore \(\mathbb{E}[A^2]=\sigma_A^2+m_A^2\). That is, it is the identity second moment = variance + square of the mean. \(\mathbb{E}[A^2]\) has been rewritten using two more familiar statistics (mean, variance).

\[ R_X(\tau) = \sigma_A^2 + m_A^2\quad(\tau\text{와 무관한 상수}),\qquad m_A=0 \text{이면}\ R_X(\tau)=\sigma_A^2\ \ \forall\tau \]

Perfect correlation across all lags — This process has full memory. If you know the value at one moment, you know the values at all times.

5.2.2 PSD: The Fourier transform of a constant is a delta function

If you say \(m_A=0\)

\[ S_X(f) = \int_{-\infty}^{\infty}\sigma_A^2\,e^{-j2\pi f\tau}\,d\tau = \sigma_A^2\,\delta(f) \]

(Generally, if it is \(m_A\neq0\), it is \(S_X(f)=(\sigma_A^2+m_A^2)\,\delta(f)\).)

TipQ. Why does this integral become \(\delta(f)\)?

Since the integrand \(e^{-j2\pi f\tau}\) oscillates with a magnitude of 1 at \(|\tau|\to\infty\), this integral does not exist as an ordinary (absolutely convergent) integral. It must be understood in the sense of a limit (distribution).

Calculate first in a finite interval

\[ \int_{-T}^{T} e^{-j2\pi f\tau}\,d\tau = \left[\frac{e^{-j2\pi f\tau}}{-j2\pi f}\right]_{-T}^{T} = \frac{e^{-j2\pi fT}-e^{j2\pi fT}}{-j2\pi f} = \frac{-2j\sin(2\pi fT)}{-j2\pi f} = \frac{\sin(2\pi fT)}{\pi f} \]

If we view this function as a function of \(f\), it has the following properties in \(T\to\infty\).

  1. Area is always 1: \(\displaystyle\int_{-\infty}^{\infty}\frac{\sin(2\pi fT)}{\pi f}\,df = 1\) (Independent of \(T\), Dirichlet integral \(\int\frac{\sin ax}{x}dx=\pi\))
  2. Origin height diverges: Value at \(f\to0\) \(2T\to\infty\)
  3. Cancels in \(f\ne0\): \(\sin(2\pi fT)\) oscillates increasingly faster, so averaging over small intervals results in 0, which vanishes.

The width is fixed at 1, the depth goes to 0, and the height goes to infinity — this is exactly the defining property of Dirac delta.

\[ \lim_{T\to\infty}\frac{\sin(2\pi fT)}{\pi f} = \delta(f)\quad(\text{분포의 의미로}) \]

Verification via inverse transformation: \(R_X(0)=\int\sigma_A^2\delta(f)e^{j2\pi f\cdot0}df=\sigma_A^2\), which matches the original \(R_X(\tau)=\sigma_A^2\).

This result is consistent with the physical intuition that an unchanging signal has all its power in direct current (DC, \(f=0\)).

NoteNote: Normal but not ergodic

The process is SSS, but the time mean of a single sample function is \(\lim\frac{1}{2T}\int_{-T}^{T}X(\omega,t)\,dt = A(\omega)\), which is a random variable and is generally different from the ensemble mean \(m_A\). In other words, it is a prime example where it is impossible to determine ensemble statistics (ergodicity) by observing a single sample for a long time. Stationarity and ergodicity are distinct properties.

5.3 Compromise — Exponential Correlation and Lorentzian PSD

Consider exponential autocorrelation with mean 0 and correlation time \(\tau_c\).

\[ R_X(\tau) = \sigma^2\,e^{-|\tau|/\tau_c} \]

5.3.1 Step 1: Divide the interval due to absolute value and combine with cosine

\[ S_X(f) = \int_{-\infty}^{\infty}\sigma^2 e^{-|\tau|/\tau_c}\,e^{-j2\pi f\tau}\,d\tau = \underbrace{\int_{-\infty}^{0}\sigma^2 e^{\tau/\tau_c}e^{-j2\pi f\tau}\,d\tau}_{\tau<0:\ |\tau|=-\tau} + \underbrace{\int_{0}^{\infty}\sigma^2 e^{-\tau/\tau_c}e^{-j2\pi f\tau}\,d\tau}_{\tau\ge0:\ |\tau|=\tau} \]

If we substitute \(\tau\to-\tau\) into the first integral, the interval changes to \((0,\infty)\) and

\[ \int_{-\infty}^{0}\sigma^2 e^{\tau/\tau_c}e^{-j2\pi f\tau}\,d\tau = \int_{0}^{\infty}\sigma^2 e^{-\tau/\tau_c}e^{+j2\pi f\tau}\,d\tau \]

Therefore, by Euler’s formula \(e^{j\theta}+e^{-j\theta}=2\cos\theta\)

\[ S_X(f) = \sigma^2\int_0^\infty e^{-\tau/\tau_c}\Big(e^{j2\pi f\tau}+e^{-j2\pi f\tau}\Big)d\tau = 2\sigma^2\int_0^\infty e^{-\tau/\tau_c}\cos(2\pi f\tau)\,d\tau \]

This is an example of the general property that “The Fourier transform of an even function can be computed using the cosine transform”.

5.3.2 Step 2: Standard Integral

\[ \int_0^\infty e^{-a\tau}\cos(b\tau)\,d\tau = \frac{a}{a^2+b^2}\qquad(a>0) \]

Proof: Since \(\cos(b\tau)=\mathrm{Re}\{e^{jb\tau}\}\)

\[ \int_0^\infty e^{-a\tau}e^{jb\tau}\,d\tau = \int_0^\infty e^{-(a-jb)\tau}\,d\tau = \frac{1}{a-jb} \]

(Since \(a>0\), damping occurs at \(\tau\to\infty\)). If you take the real part

\[ \mathrm{Re}\left\{\frac{1}{a-jb}\right\} = \mathrm{Re}\left\{\frac{a+jb}{a^2+b^2}\right\} = \frac{a}{a^2+b^2} \]

5.3.3 Step 3: Substitution and Organization

If you substitute \(a=1/\tau_c\), \(b=2\pi f\) and multiply the numerator and denominator by \(\tau_c^2\)

\[ \int_0^\infty e^{-\tau/\tau_c}\cos(2\pi f\tau)\,d\tau = \frac{1/\tau_c}{(1/\tau_c)^2+(2\pi f)^2} = \frac{\tau_c}{1+(2\pi f\tau_c)^2} \]

\[ \boxed{S_X(f) = \frac{2\sigma^2\tau_c}{1+(2\pi f\tau_c)^2}}\qquad(\text{Lorentzian}) \]

Verification: Total power \(\int S_X(f)\,df = 2\sigma^2\tau_c\cdot\frac{1}{2\pi\tau_c}\cdot\pi = \sigma^2 = R_X(0)\) ✓. Half power (−3 dB) frequency is \(f_{3\text{dB}}=\dfrac{1}{2\pi\tau_c}\).

5.4 Duality Theorem

The three examples lie on the spectrum of time–frequency duality.

Process \(R_X(\tau)\) (Time Domain) \(S_X(f)\) (Frequency Domain) Memory
White Noise \(\sigma^2\delta(\tau)\) — Infinitely narrow \(\sigma^2\) — Infinitely wide (flat) None
Exponential Correlation \(\sigma^2e^{-\lvert\tau\rvert/\tau_c}\) — Width \(\sim\tau_c\) Lorentzian — Width \(\sim 1/\tau_c\) Finite
Probability constant \(\sigma_A^2\) — Infinitely wide (constant) \(\sigma_A^2\delta(f)\) — Infinitely narrow Perfect

As it spreads widely in the \(\tau\) region, it narrows in the \(f\) region. Exponential correlation is an intermediate step that approaches white noise at \(\tau_c\to0\) and a stochastic constant at \(\tau_c\to\infty\).

6 Stochastic process passing through the LTI system

6.1 LTI System Review

In a system with an impulse response of \(h(t)\)

  • Linear: The Principle of Superposition — \(a_1x_1+a_2x_2 \mapsto a_1y_1+a_2y_2\)
  • Time-invariant: The same input yields the same output (shifted by time) whether input is given today or tomorrow — the system’s impulse response does not change over time.

If , the output is the convolution of the input and the impulse response.

\[ y(t) = (h*x)(t) = \int_{-\infty}^{\infty}h(t-\alpha)\,x(\alpha)\,d\alpha \]

6.2 Problem Settings

Now, instead of the deterministic signal, we put the WSS stochastic process \(X(t)\) into a stable LTI filter.

\[ Y(t) = (h*X)(t) = \int_{-\infty}^{\infty}h(t-\alpha)\,X(\alpha)\,d\alpha \]

While \(h(t)\) is a deterministic function, \(X(t)\) is a stochastic process where only the distribution is known at each time step; therefore, the waveform of \(Y(t)\) itself cannot be obtained. Instead, we calculate the output statistics (mean, autocorrelation, PSD). The goal is…

\[ \boxed{S_Y(f) = |H(f)|^2\,S_X(f)},\qquad H(f)=\mathcal{F}\{h(t)\} \]

and this shows that the output is also WSS.

NoteIntuitive Approach

Looking at \(S_Y(f)\sim\mathbb{E}\big[|Y_T(f)|^2\big]/2T\) according to the definition of PSD, since convolution is a product in the frequency domain, it is \(Y(f)\approx H(f)X(f)\), and \(H(f)\) is deterministic and comes out of the expectation value. Then it becomes \(\mathbb{E}|Y|^2\approx|H|^2\,\mathbb{E}|X|^2\), and we immediately obtain \(S_Y=|H|^2S_X\). Due to the boundary effects of the finite window, this is not a rigorous derivation (the boundary effects disappear in \(T\to\infty\)), and below, we follow a rigorous path through autocorrelation. The key point is that it is the same calculation as for the deterministic signal, but with only the expectation value applied.

6.3 Output Average

By exchanging expectation and integral

\[ m_Y = \mathbb{E}[Y(t)] = \int h(t-\alpha)\,\mathbb{E}[X(\alpha)]\,d\alpha = m_X\int_{-\infty}^{\infty}h(s)\,ds = m_X\,H(0) \]

is a time-independent constant. (If the input mean is 0, the output mean is also 0.)

6.4 Derivation of output autocorrelation

Starting from the definition, apply the convolution form to \(Y(t)\) and \(Y(u)\).

\[ R_Y(t,u) = \mathbb{E}[Y(t)Y(u)] = \mathbb{E}\left[\int h(t-\alpha)X(\alpha)\,d\alpha\int h(u-\beta)X(\beta)\,d\beta\right] \]

Using the linearity of expectation (Tonelli/Fubini), \(\mathbb{E}\) is placed into the integral, and since the input is WSS, \(\mathbb{E}[X(\alpha)X(\beta)]=R_X(\alpha-\beta)\):

\[ R_Y(t,u) = \iint h(t-\alpha)\,h(u-\beta)\,R_X(\alpha-\beta)\,d\alpha\,d\beta \]

Separating lag by variable conversion: Set to \(\tau\triangleq t-u\)

\[ \omega\triangleq\beta-u,\qquad \xi\triangleq\alpha-\beta \quad\Longrightarrow\quad \beta = u+\omega,\quad \alpha = u+\omega+\xi \]

Each argument is

\[ h(t-\alpha) = h(\tau-\omega-\xi),\qquad h(u-\beta)=h(-\omega),\qquad R_X(\alpha-\beta)=R_X(\xi) \]

, and since the absolute value of the Jacobian of \((\alpha,\beta)\mapsto(\xi,\omega)\) is 1,

\[ R_Y(\tau) = \int_{-\infty}^{\infty}\!\int_{-\infty}^{\infty} h(\tau-\omega-\xi)\,h(-\omega)\,R_X(\xi)\,d\xi\,d\omega \]

Since no \(u\) remains on the right side, the output autocorrelation depends only on \(\tau\). Since the mean was also a constant, the output is WSS.

Grouping by \(G(\tau)\): If we first perform the integration of \(\omega\) for a fixed \(\xi\)

\[ G(\tau-\xi)\triangleq\int_{-\infty}^{\infty}h\big((\tau-\xi)-\omega\big)\,h(-\omega)\,d\omega \]

If you just change the variable name and use it from the origin

\[ G(\tau) = \int_{-\infty}^{\infty}h(\tau-\omega)\,h(-\omega)\,d\omega = \big(h * h(-t)\big)(\tau) \]

, that is, \(G\) is the convolution of \(h\) and the time-inverted \(h(-t)\). Using this, the output autocorrelation is the convolution over the lag \(\tau\).

\[ R_Y(\tau) = \int_{-\infty}^{\infty}G(\tau-\xi)\,R_X(\xi)\,d\xi = (G*R_X)(\tau) = \big(h*h(-t)\big)*R_X(\tau) \]

6.5 Frequency range: \(S_Y = |H|^2 S_X\)

We apply the convolution theorem (time convolution ⇔ frequency product) to Wiener–Khinchin(\(\mathcal{F}\{R\}=S\)). Since for the real \(h\), \(\mathcal{F}\{h(-t)\}=H^*(f)\)

\[ S_Y(f) = \mathcal{F}\{G*R_X\}(f) = \mathcal{F}\{G\}(f)\,\mathcal{F}\{R_X\}(f) = H(f)H^*(f)\,S_X(f) = |H(f)|^2S_X(f) \]

The LTI filter shapes the input PSD into the argument \(|H(f)|^2\). It is also worth noting that the phase information \(\angle H(f)\) has no effect on the PSD at all.

6.6 White noise input

If the input is \(R_X(\tau)=\frac{N_0}{2}\delta(\tau)\), \(S_X(f)=\frac{N_0}{2}\)

\[ R_Y(\tau) = \big(h*h(-t)\big)*R_X(\tau) = \frac{N_0}{2}\big(h*h(-t)\big)(\tau), \qquad S_Y(f) = \frac{N_0}{2}\,|H(f)|^2 \]

TipQ. Why did the convolution symbol in the middle, \(*\), disappear?

It has not disappeared; rather, since the convolution with the delta function is the identity operation, it was calculated immediately without integration. Let \(G=h*h(-t)\)

\[ (G*R_X)(\tau) = \int G(\tau-\xi)\,\frac{N_0}{2}\delta(\xi)\,d\xi = \frac{N_0}{2}\int G(\tau-\xi)\,\delta(\xi)\,d\xi \]

If we apply the sifting property of the delta function \(\int g(\xi)\delta(\xi)\,d\xi=g(0)\) to \(g(\xi)=G(\tau-\xi)\)

\[ = \frac{N_0}{2}\,G(\tau-0) = \frac{N_0}{2}\,G(\tau) \]

Just as multiplying by 1 in multiplication does not change anything, in convolution, \(\delta\) is the identity element (\(f*\delta=f\)). \(*\) within the remaining \(h*h(-t)\) remains as it is because it is a distinct convolution contained in the definition of \(G\) itself.

In other words, when flat white noise passes through a filter, the shape of the output PSD becomes exactly the shape of the filter \(|H(f)|^2\). The previously mentioned problem of the white noise having infinite power is resolved as \(|H(f)|^2\) passes through an integrable (band-limited) filter, resulting in \(\int\frac{N_0}{2}|H(f)|^2df<\infty\).

7 Wiener Process

7.1 Definition

The process of integrating the white noise ZZZPH0002092ZZZ (\(X(t)\), \(\mathbb{E}[X(t)]=0\), \(R_X(\tau)=\frac{N_0}{2}\delta(\tau)\)) is called the Wiener process.

\[ Y(t) = \int_0^t X(\alpha)\,d\alpha,\qquad t>0 \]

Intuition: Continuous-time random walk. The value at time \(t\) is the cumulative sum of infinitesimal random kicks received from white noise from the start to that time. Since the waveform of white noise can be infinitely numerous, taking one shape with some probability and that shape with others, \(Y(t)\) is also a stochastic process.

7.2 Average

Since both integrals and expectations are linear operators, they are interchangeable.

\[ \mathbb{E}[Y(t)] = \int_0^t\mathbb{E}[X(\alpha)]\,d\alpha = 0 \]

Since it is an accumulation of inputs with an average of 0, it is a centered process that does not drift to one side.

7.3 Derivation of Autocorrelation

About \(t,u>0\)

\[ R_Y(t,u) = \mathbb{E}[Y(t)Y(u)] = \mathbb{E}\left[\int_0^tX(\alpha)\,d\alpha\int_0^uX(\beta)\,d\beta\right] = \int_0^t\!\int_0^u\mathbb{E}[X(\alpha)X(\beta)]\,d\alpha\,d\beta \]

(For convenience, the order of integration is written as \(\alpha\in[0,t]\) and \(\beta\in[0,u]\).) If we substitute \(\mathbb{E}[X(\alpha)X(\beta)]=\frac{N_0}{2}\delta(\alpha-\beta)\)

\[ R_Y(t,u) = \frac{N_0}{2}\int_0^u\left(\int_0^t\delta(\alpha-\beta)\,d\alpha\right)d\beta = \frac{N_0}{2}\int_0^{\min(t,u)}1\,d\gamma = \boxed{\frac{N_0}{2}\min(t,u)} \]

TipQ. Why does the integration range change from \(0\) to \(\min(t,u)\)?

Calculate the inner integral first. The field property is originally \(\int_{-\infty}^{\infty}\delta(\alpha-\beta)\,d\alpha=1\), but here the integration interval is restricted to \([0,t]\). If the delta “peak” \(\alpha=\beta\) is inside the interval, it is 1, and if it is outside, it is 0.

\[ \int_0^t\delta(\alpha-\beta)\,d\alpha = \mathbf{1}\{\beta\in[0,t]\} \qquad(\text{지시함수}) \]

The outer integral counts the length of the part inside \([0,t]\) at the same time while \(\beta\) scans \([0,u]\).

\[ \int_0^u\mathbf{1}\{\beta\in[0,t]\}\,d\beta = \text{length}\big([0,u]\cap[0,t]\big) \]

Since both intervals start at 0, the intersection is always to the shorter endpoint.

  • \(t<u\): \([0,t]\cap[0,u]=[0,t]\)
  • \(t>u\): \([0,t]\cap[0,u]=[0,u]\)
  • In any case \([0,\min(t,u)]\), length \(\min(t,u)\)

Geometric Figure: \((\alpha,\beta)\) In the plane, the region of integration is a rectangle \([0,t]\times[0,u]\), and \(\delta(\alpha-\beta)\) has a value only on the diagonal \(\alpha=\beta\). Therefore, the double integral is the length of the part of the rectangle where the diagonal is contained (on an appropriate scale), and since the diagonal starting from the origin ends at the shorter side of the rectangle first, its length is \(\min(t,u)\). In this way, thanks to the field property, the double integral collapses into a much simpler single integral.

7.4 The Winner process is not a normal process

\[ R_Y(t,u) = \frac{N_0}{2}\min(t,u) \]

depends on the absolute time \(t,u\) and cannot be expressed solely by the difference \(\tau=t-u\). For example, if \((t,u)=(2,1)\), it becomes \(\frac{N_0}{2}\cdot1\), and if \((t,u)=(11,10)\), it becomes \(\frac{N_0}{2}\cdot10\); thus, the values are different even though \(\tau=1\) is the same. Therefore, the WSS condition is violated, and the Wiener process is non-stationary.

Especially if set to \(t=u\), the variance is

\[ \mathrm{Var}[Y(t)] = R_Y(t,t) = \frac{N_0}{2}\,t \]

increases linearly in proportion to time. Since random shocks continue to accumulate, the spread becomes increasingly larger. The normalized correlation coefficient is

\[ \rho(t,u) = \frac{R_Y(t,u)}{\sqrt{R_Y(t,t)R_Y(u,u)}} = \frac{\min(t,u)}{\sqrt{tu}} = \sqrt{\frac{\min(t,u)}{\max(t,u)}} \]

depends on the ratio of the two times.

WarningWhy is the previous “WSS input → LTI → WSS output” result not applied?

The reason the output is not WSS when inputting white noise of WSS into a linear operation called “integration” is that this operation does not satisfy the assumption in the previous section.

  1. Not time-invariant: \(\int_0^t\) has an integral starting point that is a fixed origin 0. Since the integral starting point does not move even when the input is shifted in time, it is not a time-invariant system. The fact that it “started at time 0” itself creates absolute time information.
  2. Not stable: The ideal integrator \(h(t)=u(t)\) is not BIBO stable with \(\int|h|dt=\infty\), and formally \(|H(f)|^2=\frac{1}{(2\pi f)^2}\) is not integrable near \(f=0\). Integrating \(\frac{N_0}{2}|H(f)|^2\) results in infinite power, which corresponds to the phenomenon where the variance increases infinitely with \(t\).

7.5 Independent Incremental and Gaussian Marginal Distribution

Independent increments: The increments in non-overlapping intervals are unrelated. For \(0<s<t\)

\[ \mathbb{E}\big[(Y(t)-Y(s))\,Y(s)\big] = R_Y(t,s)-R_Y(s,s) = \frac{N_0}{2}\big(\min(t,s)-s\big) = \frac{N_0}{2}(s-s) = 0 \]

Intuitively, \(Y(t)-Y(s)=\int_s^tX\) and \(Y(s)=\int_0^sX\) use only the non-overlapping intervals of white noise, because white noise is uncorrelated at different times. If \(X\) is Gaussian, then non-correlation is independence, so the increments are independent.

Gaussian Marginal Distribution: If \(X\) is Gaussian white noise, then it is \(Y(t)\sim\mathcal{N}\!\big(0,\ \tfrac{N_0}{2}t\big)\). This is directly connected to the Gaussian process in the next section.

8 Gaussian Process

8.1 Definition

NoteDefinition

The stochastic process \(X(t)\) is Gaussian for a random finite set of times \(t_1,\dots,t_N\) of which a probability vector

\[ \mathbf{X} = \big(X(t_1),X(t_2),\dots,X(t_N)\big) \]

This means that follows a multivariate Gaussian distribution.

You must pay attention to the weight of the condition “arbitrary”.

  • \(N=1\): No matter which time is selected, \(X(t_1)\) is (univariate) Gaussian
  • \(N=2\): If two times are selected, \(\big(X(t_1),X(t_2)\big)\) is a 2D Gaussian
  • Any \(N\), no matter which perspective is chosen, it is always a multivariate Gaussian
NoteSimilar in format to SSS but different conditions

The definitions of SSS and Gaussian processes are similar in form in that they are joint distribution conditions for “arbitrary \(N\), arbitrary time”. However

  • SSS: Is the joint distribution invariant to time shifts?
  • Gaussian: Does the joint distribution belong to the Gaussian distribution family?

By asking for , the two conditions are independent of each other. Being Gaussian does not mean it is normal, nor does being normal mean it is Gaussian.

8.2 Completely determined by mean and covariance alone

The multivariate Gaussian distribution is a special family of distributions that is completely determined by only the mean vector and the covariance matrix.

\[ p_{\mathbf{X}}(\mathbf{x}) = \frac{1}{(2\pi)^{N/2}\,|\mathbf{K}|^{1/2}}\exp\!\left(-\frac{1}{2}(\mathbf{x}-\mathbf{m})^{\mathsf T}\mathbf{K}^{-1}(\mathbf{x}-\mathbf{m})\right) \]

\[ \mathbf{m}_i = m_X(t_i),\qquad \mathbf{K}_{ij} = K_X(t_i,t_j) \]

Therefore, all statistical information of the Gaussian process is summarized by only two functions.

\[ m_X(t) = \mathbb{E}[X(t)],\qquad K_X(t_1,t_2) = \mathbb{E}\big[(X(t_1)-m_X(t_1))(X(t_2)-m_X(t_2))\big] \]

With just these two functions, you can calculate joint distributions of any order, from 3rd to 4th, … and so on. This is why the Gaussian process is “very important and widely used.”

8.3 WSS Gaussian process is SSS

Let the Gaussian process be WSS, i.e., \(m_X(t)=\mu\) and \(K_X(t_1,t_2)=K_X(t_1-t_2)\). If we shift all time points by \(\Delta\),

  • Mean vector: \(\big(m_X(t_i-\Delta)\big)_i = (\mu,\dots,\mu) = \big(m_X(t_i)\big)_i\) — Invariant
  • Covariance matrix: \(K_X\big((t_i-\Delta),(t_j-\Delta)\big) = K_X(t_i-t_j) = K_X(t_i,t_j)\) — Invariant

Since both factors determining the joint distribution are invariant, the entire joint distribution is invariant, i.e., it is SSS.

\[ \text{가우시안 과정에서:}\qquad \text{WSS}\;\Longleftrightarrow\;\text{SSS} \]

In general processes, WSS cannot constrain distributions of order 3 or higher, but since the entire distribution of a Gaussian is determined by only the first and second moments from the outset, second-order stationarity is lifted up to total stationarity. Due to this property, Gaussian white noise is SSS.

8.4 Closed for linear operations

The Gaussian process remains Gaussian even after undergoing the following linear operation.

  • Differentiation and Integration (where defined)
  • LTI Filtering
  • Sampling in discrete time
  • Sum with other (combined) Gaussian processes

The basis is the fact that “a linear combination of Gaussian random variables is Gaussian,” and integration and filtering are linear combinations in the sense of limits. Therefore

The output of a linear system driven by a Gaussian process is Gaussian.

Combined with the result from the previous section: When a WSS Gaussian input passes through a stable LTI filter, the output is WSS Gaussian = SSS, and its distribution is completely determined by \(m_Y=m_XH(0)\) and \(R_Y=(h*h(-t))*R_X\). This is why the noise in the receiver filter output can be treated as Gaussian.

8.5 Relationship with the Winner Process

The Wiener process is a representative example of a Gaussian process (Brownian motion). The reason is as follows:

  1. In \(Y(t)=\int_0^tX(\alpha)\,d\alpha\), integration is a linear operation.
  2. If input \(X(t)\) is Gaussian white noise, then \(\big(Y(t_1),\dots,Y(t_N)\big)\) at a finite number of times is a (limited) linear combination of Gaussian random variables.
  3. Therefore, \(\big(Y(t_1),\dots,Y(t_N)\big)\) satisfies the definition of a multivariate Gaussian-Gaussian process.

Practical Advantage: Since the Wiener process is Gaussian, all finite-dimensional joint distributions can be determined using only the two previously calculated means \(\mathbb{E}[Y(t)]=0\) and \(R_Y(t,u)=\frac{N_0}{2}\min(t,u)\). For example, the distribution of \(\big(Y(t_1),Y(t_2)\big)\) is

\[ \mathbf{m}=\begin{bmatrix}0\\0\end{bmatrix},\qquad \mathbf{K} = \frac{N_0}{2}\begin{bmatrix} t_1 & \min(t_1,t_2)\\ \min(t_1,t_2) & t_2\end{bmatrix} \]

is immediately determined as a bivariate Gaussian.
