2 Linear vector space

2.1 Definition and Vector Addition Axioms

The linear vector space \(\mathcal S\) is a structure in which two operations, vector addition and scalar multiplication, are given to a collection of elements (vectors) and satisfy the following axioms. Vectors are written as \(x,y,z\in\mathcal S\), and scalars are written as \(\mathbb F\) (usually \(\mathbb R\) or \(\mathbb C\)), an element of the field \(a,b\).

Vector Addition Axiom

  1. Closure: \(x,y\in\mathcal S\Rightarrow x+y\in\mathcal S\)
  2. Commutative property: \(x+y=y+x\)
  3. Associative property: \((x+y)+z=x+(y+z)\)
  4. Zero vector: For every \(x\), there exists \(0\in\mathcal S\) such that \(x+0=x\)
  5. Additive inverse: For every angle \(x\), there exists \((-x)\in\mathcal S\) such that \(x+(-x)=0\)

2.2 Scalar and Field

To write the axioms of scalar product, “what a scalar is” must first be determined. A scalar forms a field \(\mathbb F\). For addition and multiplication, the field

  • Associative law, Commutative law, Distributive law \(a(b+c)=ab+ac\)
  • Additive identity \(0\), Multiplicative identity \(1\)
  • Additive inverse of all elements, multiplicative inverse of all elements other than \(0\) \(a^{-1}\)

It is a structure that has . The last condition distinguishes the field from a ring and enables division.

The scalar product is a mapping

\[ \mathbb F\times\mathcal S\to\mathcal S,\qquad (a,x)\mapsto a\cdot x \]

. The fact that the result belongs back to \(\mathcal S\) is the closure of the scalar product.

NoteThe reason a sieve is needed

In the proof of the Cauchy–Schwarz inequality , the optimal coefficient \(a^\star=-\langle x,y\rangle/\|y\|^2\) is used, which is an operation of dividing by the scalar \(\|y\|^2\). Furthermore, by abstracting \(\mathbb F\), \(\mathbb R\) and \(\mathbb C\) can be handled at once, allowing complex baseband signals to also fit into the same framework.

2.3 Scalar product axiom

  1. Closure: \(a\in\mathbb F,\ x\in\mathcal S\Rightarrow a\cdot x\in\mathcal S\)
  2. Compatibility: \(a\cdot(b\cdot x)=(ab)\cdot x\)
  3. Identity element: \(1\cdot x=x\), \(0\cdot x=0\) (zero vector)
  4. Distributive law: \(a(x+y)=ax+ay\), \((a+b)x=ax+bx\)

2.4 Example: Column vector of length \(N\) \(\mathbb F^N\)

\[ \begin{bmatrix}x_1\\\vdots\\x_N\end{bmatrix}+\begin{bmatrix}y_1\\\vdots\\y_N\end{bmatrix}=\begin{bmatrix}x_1+y_1\\\vdots\\x_N+y_N\end{bmatrix},\qquad a\cdot\begin{bmatrix}x_1\\\vdots\\x_N\end{bmatrix}=\begin{bmatrix}ax_1\\\vdots\\ax_N\end{bmatrix} \]

Since it is a component-wise operation, the properties of the field are applied to each component as they are, and all axioms hold.

2.5 Example: \(L^2(T_i,T_f)\)

\[ L^2(T_i,T_f):=\Big\{x(t):\int_{T_i}^{T_f}|x(t)|^2\,dt<\infty\Big\} \]

is a set of finite energy signals. Operations are defined point by point.

\[ (x+y)(t):=x(t)+y(t),\qquad (ax)(t):=a\,x(t) \]

From this perspective, each function is a vector, and it can be viewed as a “vector with a continuous number of components” where time \(t\) acts as an index of the components. This is an infinite dimension example corresponding to the finite dimension \(\mathbb F^N\).

The statement “all vector space axioms are satisfied” means that if the axioms are verified one by one, they all pass. Verification is divided into two categories.

(1) Axioms inherited from point-by-point operations. Since the operation at each time point \(t\) is an operation between scalars \(x(t),y(t)\in\mathbb F\), the properties of the field are transferred as they are. For example, the commutative law is

\[ (x+y)(t)=x(t)+y(t)=y(t)+x(t)=(y+x)(t)\quad\forall t \]

. The associative and distributive laws, compatibility, and \(1\cdot x=x\) are also the same. The zero vector is the zero function \(0(t)\equiv0\), and the inverse is \((-x)(t):=-x(t)\).

(2) Axiom to be verified in practice: Closure. Sums or scalar multiplications must not extend to infinity of energy.

  • Scalar Bae: \[ \int|ax|^2\,dt=|a|^2\int|x|^2\,dt<\infty \]
  • Sum: From \((|u|-|v|)^2\ge0\)Z to \(2|u||v|\le|u|^2+|v|^2\) \[ |u+v|^2\le(|u|+|v|)^2\le2|u|^2+2|v|^2 \] If we apply to each \(t\) and integrate \[ \int|x+y|^2\,dt\le2\int|x|^2\,dt+2\int|y|^2\,dt<\infty \]

Since the zero function and \(-x\) also belong to \(L^2\), the existence conditions of (d) and (e) are satisfied within \(L^2\).

WarningStrict definition: Equivalence classes

The elements of \(L^2\) are strictly equivalence classes of functions that are the same almost everywhere (ae) and must be measurable functions. While no distinction is necessary when looking only at the vector space axioms, it is necessary for the positive definiteness of the inner product \(\langle x,x\rangle=0\Rightarrow x=0\). This is because a function that is not zero only on a set of measure zero \(\int|x|^2=0\) is different from the zero function.

3 Inner Space

3.1 Axiom of the inner product (1–3)

In real vector space, the inner product is a mapping \(\langle\cdot,\cdot\rangle:\mathcal S\times\mathcal S\to\mathbb R\) that maps scalars to two vectors to create the concepts of length, angle, and orthogonality.

  1. Symmetry: \(\langle x,y\rangle=\langle y,x\rangle\)
  2. Homogeneity in the first digit: \(\langle ax,y\rangle=a\langle x,y\rangle\)
  3. Additiveness in the first digit: \(\langle x+y,z\rangle=\langle x,z\rangle+\langle y,z\rangle\)

Combining 2) and 3) gives the linearity for the first digit \(\langle ax+by,z\rangle=a\langle x,z\rangle+b\langle y,z\rangle\).

3.1.1 The linearity of the second digit is derived

Writing only “first slot” is not because it does not hold in the second slot, but because it is derived from symmetry, so there is no need to write it as an axiom.

\[ \langle x,ay\rangle\overset{(1)}{=}\langle ay,x\rangle\overset{(2)}{=}a\langle y,x\rangle\overset{(1)}{=}a\langle x,y\rangle \]

\[ \langle x,y+z\rangle\overset{(1)}{=}\langle y+z,x\rangle\overset{(3)}{=}\langle y,x\rangle+\langle z,x\rangle\overset{(1)}{=}\langle x,y\rangle+\langle x,z\rangle \]

Therefore, the real inner product is a bilinear form that is linear in both digits. Since symmetry implies that linearity in one digit is sufficient for the other to follow, this follows the convention of writing the minimum number of axioms.

3.1.2 When this distinction actually becomes important

(a) Complex number field. If the symmetry changes to the conjugate symmetry \(\langle x,y\rangle=\overline{\langle y,x\rangle}\)

\[ \langle x,ay\rangle=\overline{\langle ay,x\rangle}=\overline{a\langle y,x\rangle}=\bar a\,\langle x,y\rangle \]

, so the second digit is sesquilinear. In this case, which digit is linear carries the actual content. Mathematics usually follows the convention of linearity in the first digit, while physics uses the convention of linearity in the second digit.

(b) Symmetry is not automatic. \(\langle x,y\rangle_K=x^TKy\) is linear in both digits for any matrix \(K\), but

\[ \langle y,x\rangle_K=y^TKx=(y^TKx)^T=x^TK^Ty \]

Since , it is symmetric only when \(K=K^T\). In kernel inner product, “symmetric” corresponds to Axiom 1), and “positive-definite” corresponds to Axiom 4).

3.3 There are various types of inner products.

Axioms 1) through 4) are not specific formulas but qualification conditions. Anything that satisfies these conditions is an inner product, and there are infinitely many such cases in the same space. In \(\mathbb R^N\), if \(K\) is a symmetric positive definite, then all \(\langle x,y\rangle_K=x^TKy\) are inner products.

예: \(K=\begin{pmatrix}2&1\\1&2\end{pmatrix}\) (고유값 \(3,1\)).

  • \(x=(1,0)\), \(y=(0,1)\): The standard inner product is \(0\) (orthogonal), but \(\langle x,y\rangle_K=1\ne0\) — is not orthogonal.
  • \(x=(1,0)\), \(y=(1,-2)\): The standard inner product is \(1\), but since \(Ky=(0,-3)^T\), \(\langle x,y\rangle_K=0\) — it is orthogonal.

A set in which length, angle, and orthogonality all depend on the choice of inner product \(\|x\|_K=1\) is an ellipse, not a circle. Therefore, strictly speaking, the pair of space and inner product \((\mathcal S,\langle\cdot,\cdot\rangle)\) is an inner product space.

3.4 \(L^2\) The inner product above: Standard inner product and kernel inner product

Standard inner product (time-wise agreement)

\[ \langle x,y\rangle=\int_{T_i}^{T_f}x(t)\,y(t)\,dt \]

Kernel Inner Product (Weighted/Correlation Matching)

\[ \langle x,y\rangle_K=\int_{T_i}^{T_f}\!\!\int_{T_i}^{T_f}x(t)\,K(t,u)\,y(u)\,dt\,du \]

If \(K\) is positive definite, then for \(x\ne0\), it is \(\langle x,x\rangle_K>0\). \(K\) provides weighted correlations between different time points. If the identity kernel \(K(t,u)=\delta(t-u)\), then

\[ \int\!\!\int x(t)\delta(t-u)y(u)\,dt\,du=\int x(t)y(t)\,dt \]

becomes the standard inner product.

3.6 Cauchy–Schwarz inequality

3.6.1 Real number case

Goal: \(|\langle x,y\rangle|\le\|x\|\,\|y\|\)

If \(y=0\), then it is obvious since both sides are 0. Let \(y\ne0\), and for all real numbers \(a\), a non-negative quadratic expression

\[ f(a):=\|x+ay\|^2\ge0 \]

Consider (this inequality itself is Axiom 4). Expanding using bilinearity and symmetry

\[ f(a)=\langle x+ay,x+ay\rangle=\|x\|^2+2a\langle x,y\rangle+a^2\|y\|^2 \]

It is . Both two-digit linearity and symmetry are used for the intersection term \(\langle x,ay\rangle+\langle ay,x\rangle\) to merge into \(2a\langle x,y\rangle\). If we find the minimum point by differentiation (or perfect squaring),

\[ f'(a)=2\langle x,y\rangle+2a\|y\|^2=0\ \Rightarrow\ a^\star=-\frac{\langle x,y\rangle}{\|y\|^2} \]

and if you substitute

\[ 0\le f(a^\star)=\|x\|^2-\frac{2\langle x,y\rangle^2}{\|y\|^2}+\frac{\langle x,y\rangle^2}{\|y\|^2}=\|x\|^2-\frac{\langle x,y\rangle^2}{\|y\|^2} \]

\[ \Longrightarrow\ \langle x,y\rangle^2\le\|x\|^2\|y\|^2\ \Longrightarrow\ |\langle x,y\rangle|\le\|x\|\,\|y\| \]

Equality condition. Since \(f(a^\star)=0\iff x+a^\star y=0\)

\[ \text{등호}\iff\exists\,c\in\mathbb R:\ x=cy \]

, that is, when \(x\) lies on the line generated by \(y\). This argument is equivalent to projecting \(x\) onto \(y\). \(-a^\star y\) is the projection of \(x\) in the direction of \(y\), and \(f(a^\star)\) is the squared length of the projected residual.

3.6.2 Complex number case

Assuming conjugate symmetry and first-digit linearity, \(a\) operates over all complex numbers (if \(a\) is restricted to real numbers, only the inequality for \(\mathrm{Re}\langle x,y\rangle\) is obtained).

Step 1: Expansion.

\[ f(a)=\langle x,x\rangle+\langle x,ay\rangle+\langle ay,x\rangle+\langle ay,ay\rangle \]

\(\langle x,ay\rangle=\bar a\langle x,y\rangle\), \(\langle ay,x\rangle=a\overline{\langle x,y\rangle}\), \(\langle ay,ay\rangle=|a|^2\|y\|^2\), and since the two middle terms are conjugates,

\[ f(a)=\|x\|^2+2\,\mathrm{Re}\big(\bar a\langle x,y\rangle\big)+|a|^2\|y\|^2 \]

In the second-digit linear convention, the intersection term is written as \(2\,\mathrm{Re}\big(a\langle x,y\rangle\big)\), and the final result is the same.

Step 2: Optimal \(a\). If set to \(\langle x,y\rangle=|\langle x,y\rangle|e^{i\varphi}\), \(a=re^{i\theta}\)

\[ \mathrm{Re}\big(\bar a\langle x,y\rangle\big)=r|\langle x,y\rangle|\cos(\varphi-\theta) \]

\(r\) When fixed, it is minimum at \(\theta=\varphi+\pi\) (phase exactly opposite), and then

\[ f=\|x\|^2-2r|\langle x,y\rangle|+r^2\|y\|^2 \]

is minimum at \(r^\star=|\langle x,y\rangle|/\|y\|^2\). Combined

\[ a^\star=-r^\star e^{i\varphi}=-\frac{\langle x,y\rangle}{\|y\|^2} \]

is the same expression as in the case of real numbers.

Step 3: Substitution. Since \(\bar a^\star\langle x,y\rangle=-|\langle x,y\rangle|^2/\|y\|^2\) and \(|a^\star|^2\|y\|^2=|\langle x,y\rangle|^2/\|y\|^2\)

\[ 0\le f(a^\star)=\|x\|^2-\frac{|\langle x,y\rangle|^2}{\|y\|^2}\ \Longrightarrow\ |\langle x,y\rangle|\le\|x\|\,\|y\| \]

Verify with perfect square. If set to \(c=\langle x,y\rangle/\|y\|^2\)

\[ f(a)=\|y\|^2|a+c|^2+\|x\|^2-\frac{|\langle x,y\rangle|^2}{\|y\|^2} \]

Since the first term is zero only at \(a=-c\), the minimum point is clear (can be verified without differentiating the complex variable).

Equality condition. Since \(x=cy\) and \(c=\langle x,y\rangle/\|y\|^2\in\mathbb C\)

\[ \text{등호}\iff\exists\,c\in\mathbb C:\ x=cy \]

TipConnection with matched filter

In the complex baseband, \(|\langle x,y\rangle|\le\|x\|\|y\|\) is the upper limit of the matched filter output. The equality applies when \(y\) is a complex scalar multiple of \(x\), meaning it allows for phase rotation and matches. This is the reason why asynchronous detection without phase is used for \(|\langle x,y\rangle|\).

3.7 Orthogonality and Angles

  • Orthogonal: \(\langle x,y\rangle=0\)
  • Cosine of Angle (\(x,y\ne0\)): \[ \cos(x,y)=\frac{\langle x,y\rangle}{\|x\|\,\|y\|} \] It does not change even if replaced with \(x\to ax\), \(y\to by\) (\(a,b>0\)) (only the sign changes for negative multiples).

Conclusion

  • \(|\cos(x,y)|\le1\) in Cauchy–Schwarz.
  • Orthogonal and not zero \(\cos=0\), angle \(\pm\pi/2\).
  • \(|\langle x,y\rangle|=\|x\|\|y\|\iff x\propto y\) then \(\cos=\pm1\), angle \(0\) or \(\pi\).
  • If \(x=0\) or \(y=0\), the angle is undefined, but since \(\langle x,y\rangle=0\), orthogonality holds.

In complex space, since \(\langle x,y\rangle/(\|x\|\|y\|)\) is a complex number with an absolute value of 1 or less, the angle is defined as \(|\langle x,y\rangle|/(\|x\|\|y\|)\) or \(\mathrm{Re}\langle x,y\rangle/(\|x\|\|y\|)\).

3.8 Gambling space

The distance in the gambling space is \(d(x,y)=\|x-y\|\) and satisfies the following.

  • (M1) Symmetry: \(d(x,y)=d(y,x)\)
  • (M2) Identity of the indistinguishable: \(d(x,y)=0\iff x=y\)
  • (M3) Triangle inequality: \(d(x,y)\le d(x,z)+d(z,y)\), in norm form \(\|x+y\|\le\|x\|+\|y\|\)

Proof of the triangle inequality of the inner product norm.

\[ \|x+y\|^2=\|x\|^2+2\langle x,y\rangle+\|y\|^2\le\|x\|^2+2\|x\|\|y\|+\|y\|^2=(\|x\|+\|y\|)^2 \]

Since the starting point of the Cauchy–Schwarz inequality was axiom 4), the order is 4) ⇒ Cauchy–Schwarz ⇒ triangle inequality.

\(p\)-norm (\(p\ge1\)):

\[ \|x\|_p=\Big(\sum_{n=1}^N|x_n|^p\Big)^{1/p},\qquad \|f\|_p=\Big(\int|f(x)|^p\,dx\Big)^{1/p} \]

Convergence: \(x_n\to x\iff\lim_{n\to\infty}\|x_n-x\|=0\)

3.8.1 Hierarchy of structure

\[ \text{내적 공간}\ \Rightarrow\ \text{노름 공간}\ \Rightarrow\ \text{거리 공간} \]

The inner product derives the norm, and the norm derives the distance. The converse does not hold. The derivation of the norm from the inner product is the parallelogram law

\[ \|x+y\|^2+\|x-y\|^2=2\|x\|^2+2\|y\|^2 \]

is equivalent to ||| (Jordan–von Neumann), and the \(p\)-norm satisfies this only when \(p=2\). Therefore, angle and orthogonality are defined only in \(p=2\).

The definition of an inner product space does not include completeness. An inner space in which every Cauchy sequence converges with respect to the derivation distance is called a Hilbert space, and \(L^2\) is a representative example.

4.3 Mixture Model

The target density is expressed as a convex combination of the reference density \(p_0\) and the deviation density \(p_d\).

\[ p(x)=(1-a)\,p_0(x)+a\,p_d(x),\qquad 0\le a\le1 \]

  • \(p_0\): Nominal density, \(p_d\): Deviation component (density valid in itself)
  • If \(a=0\), then it is \(p=p_0\), and \(a\) is a measure indicating the degree of deviation in the direction of \(p_d\).
  • Limit: Not all \(p\) can be expressed as any \(p_0\) and one \(p_d\).

4.3.1 Representation conditions

If you solve for \(p_d\)

\[ p_d(x)=\frac{p(x)-(1-a)\,p_0(x)}{a} \]

Since \(\int p_d=1\) is automatically satisfied, the remaining condition is \(p_d\ge0\), i.e.

\[ p(x)\ge(1-a)\,p_0(x)\quad\forall x \]

. \(p\) must cover \(p_0\)’s \((1-a)\) times over the entire interval. If we simplify at the point where it is \(p_0>0\)…

\[ 1-a\le\operatorname*{ess\,inf}_x\frac{p(x)}{p_0(x)}=:w^\star,\qquad a_{\min}=1-w^\star \]

. For \(p_0\) to be mixed into \(p\), the support of \(p_0\) must be within the support of \(p\).

4.3.2 Uniform vs Gaussian

If \(p=\frac1L\mathbf 1_{[0,L]}\), \(p_0=\mathcal N(\mu,\sigma^2)\), then outside \([0,L]\) are \(p=0\), \(p_0>0\), so the condition is \(0\ge(1-a)p_0(x)>0\), which is \(a=1\). If \(a=1\), then \(p=p_d\), which is a trivial expression unrelated to \(p_0\), then it is impossible for any \(p_d\) that is \(a<1\). When mixing a Gaussian with positive weights, the tails spread across the entire range, and those tails cannot be removed by adding a non-negative function.

If \(p_d\) is fixed in advance, the expressible \(p\) are only the points on the line segment connecting \(p_0\) and \(p_d\).

4.3.3 Connection with KL

Since the expressibility condition for is \(p_0/p\le\frac1{1-a}\),

\[ D(p_0\|p)=E_{p_0}\Big[\log\frac{p_0}{p}\Big]\le\log\frac1{1-a}<\infty \]

. In Uniform vs. Gaussian, there is a point \(p=0<p_0\), so \(D(p_0\|p)=\infty\); therefore, the unrepresentability of a mixture is the same fact as \(D(p_0\|p)=\infty\). The opposite direction, \(D(p\|p_0)\), is finite. The representability of a mixture also has directionality, just like KL.

4.4 Manifold perspective

The idea is not to force density into a linear space, but to view the set of allowable densities as a manifold. A manifold is locally flat, allowing for the definition of tangents and geodesics, but it can be curved overall. On this, distance is measured not by a linear norm, but by geodesic distance or information-geometric distance (Fisher–Rao, etc.).

4.4.1 Intuition: The ruler’s markings must be different at each position

The distance \(\|p-q\|\) in linear space depends only on the difference \(p-q\). The scale is the same everywhere. However, it is natural to measure the “degree of difference” between distributions by how easy it is to distinguish, and this varies depending on location.

Example 1: Same parameter difference, different difficulty of distinction. In \(\mathcal N(0,\sigma^2)\)

  • \(\sigma=0.01\) vs \(0.02\): Double the width — distinguished by a few samples.
  • \(\sigma=10\) vs \(10.01\): They are virtually the same distribution.

Although it is the same as \(|\Delta\sigma|=0.01\), the Fisher–Rao distance is \(\sigma\) direction Fisher information \(2/\sigma^2\)

\[ d=\int_{\sigma_1}^{\sigma_2}\frac{\sqrt2}{\sigma}\,d\sigma=\sqrt2\,\Big|\ln\frac{\sigma_2}{\sigma_1}\Big| \]

are approximately \(0.98\) and \(0.0014\), respectively. The scale is dense at the smallest point of \(\sigma\).

Example 2: Longitude on a map. The actual distance of 1° of longitude is approximately 111 km at the equator and approximately 55 km at 60° latitude. Since the actual distance varies depending on the location even with the same coordinate difference, a metric is required to correct the scale for each location. This analogy is accurate only in the sense that “the scale changes depending on the location,” and the actual geometry of the Gaussian family is hyperbolic geometry.

5.2 Jensen inequality

For the convex function \(f\) and probabilities \(p_k\ge0\), \(\sum p_k=1\)

\[ \sum_{k=1}^np_kf(X_k)\ge f\Big(\sum_{k=1}^np_kX_k\Big) \]

Basis (\(n=2\)). Definition of convexity \(f(\lambda u+(1-\lambda)v)\le\lambda f(u)+(1-\lambda)f(v)\) is itself.

Inductive step. Let \(n\) hold, and if we set \(p_{n+1}<1\)Z, we set \(\tilde p_k=\frac{p_k}{1-p_{n+1}}\), then it is \(\sum_{k=1}^n\tilde p_k=1\) (if \(p_{n+1}=1\), it is obvious).

\[ \sum_{k=1}^{n+1}p_kf(X_k)=(1-p_{n+1})\sum_{k=1}^n\tilde p_kf(X_k)+p_{n+1}f(X_{n+1}) \]

If we apply the inductive hypothesis to the first term,

\[ \ge(1-p_{n+1})\,f\Big(\sum_{k=1}^n\tilde p_kX_k\Big)+p_{n+1}f(X_{n+1}) \]

and if we apply 2-point Jensen to the two points \(\sum\tilde p_kX_k\) and \(X_{n+1}\)

\[ \ge f\Big((1-p_{n+1})\sum_{k=1}^n\tilde p_kX_k+p_{n+1}X_{n+1}\Big)=f\Big(\sum_{k=1}^{n+1}p_kX_k\Big) \]

The last equality is because \((1-p_{n+1})\tilde p_k=p_k\). The continuous form \(E[f(X)]\ge f(E[X])\) extends to the limit. If \(f\) is strictly convex, the equality holds only when \(X\) is (as) a constant.

5.3 Proof of the basic properties of KL

Set it to \(S_1=\{x:p_1(x)>0\}\), and treat the place of \(p_1=0\) as the convention \(0\log\frac0{\cdot}=0\).

5.3.1 \(D(p_1\|p_0)\ge0\)

Jensen’s Proof. \(f(u)=-\log u\) is convex because \(f''(u)=1/u^2>0\). If we set it to \(U=p_0(X)/p_1(X)\), then \(D=E_{p_1}[f(U)]\) and

\[ D(p_1\|p_0)\ge-\log E_{p_1}\Big[\frac{p_0(X)}{p_1(X)}\Big]=-\log\int_{S_1}p_0(x)\,dx\ge-\log1=0 \]

If the supports of the two densities are the same, it is \(\int_{S_1}p_0=1\), and generally it is \(\int_{S_1}p_0\le1\), but since \(-\log\) is a decreasing function, the direction of the inequality sign is maintained.

Gibbs Proof. From \(u>0\), since \(\log u\le u-1\) (the equality is \(u=1\)), \(-\log\frac{p_0}{p_1}\ge1-\frac{p_0}{p_1}\) and

\[ D\ge\int_{S_1}p_1\Big(1-\frac{p_0}{p_1}\Big)dx=1-\int_{S_1}p_0\,dx\ge0 \]

5.3.2 \(D=0\iff p_1=p_0\) a.e.

(\(\Leftarrow\)) \(\log(p_1/p_0)=0\) ae Therefore \(D=0\).

(\(\Rightarrow\)) Both inequalities in Gibbs’ proof must be equal. The first is \(p_0/p_1=1\) (\(p_1\)-ae), and the second is \(\int_{S_1}p_0=1\), that is, \(S_1\) outside of \(p_0=0\) ae. 5.3.3 support mismatch

5.3.4 Additiveness of independent components

\(p_0(\mathbf x)=\prod_\ell p_{0}(x_\ell)\), \(p_1(\mathbf x)=\prod_\ell p_{1}(x_\ell)\) if

\[ \log\frac{p_1(\mathbf x)}{p_0(\mathbf x)}=\sum_\ell\log\frac{p_1(x_\ell)}{p_0(x_\ell)} \]

\[ D(p_1\|p_0)=\sum_\ell D\big(p_1(x_\ell)\,\|\,p_0(x_\ell)\big) \]

In the case of Chernoff, since \(J_{\text{prod}}(s)=\prod_\ell J_\ell(s)\), \(\log J\) is additive, but since \(\min_s\sum_\ell\log J_\ell(s)\ge\sum_\ell\min_s\log J_\ell(s)\),

5.4.1 Curve \(p_s\)

About \(s\in[0,1]\)

\[ p_s(x)=\frac{p_0(x)^{1-s}\,p_1(x)^s}{J(s)},\qquad J(s)=\int p_0(x)^{1-s}p_1(x)^s\,dx \]

  • If written as \(\Lambda=\log(p_1/p_0)\), it is \(p_s=p_0\,e^{s\Lambda}/J(s)\) and \(J(s)=E_{p_0}[e^{s\Lambda}]\). It is an exponential family with sufficient statistics \(\Lambda\), natural parameters \(s\), and logarithmic partitioning functions \(\log J(s)\).

\[ (1-s)(x-\mu_0)^2+s(x-\mu_1)^2=(x-\mu_s)^2+s(1-s)\Delta^2,\qquad \mu_s=(1-s)\mu_0+s\mu_1 \]

\[ J(s)=e^{-s(1-s)\Delta^2/(2\sigma^2)},\qquad p_s=\mathcal N(\mu_s,\sigma^2) \]

This is the path where one peak moves from \(\mu_0\) to \(\mu_1\).

5.4.2 \(J(s)\le1\)

If we set it as \(U=p_1/p_0\), it becomes \(J(s)=E_{p_0}[U^s]\), and since \(u\mapsto u^s\) is concave at \(s\in(0,1)\),

\[ J(s)\le\big(E_{p_0}[U]\big)^s=\Big(\int_{p_0>0}p_1\,dx\Big)^s\le1 \]

The equality sign applies only when \(U\) is a constant in strict concavity, i.e., \(p_1=p_0\) ae.

5.4.3 \(\log J(s)\) is convex

\(\log J(s)\) is the leakage rate generating function of \(\Lambda\).

\[ \frac{d}{ds}\log J=E_{p_s}[\Lambda],\qquad \frac{d^2}{ds^2}\log J=\mathrm{Var}_{p_s}[\Lambda]\ge0 \]

(the derivation of the first equation is Section 5.5.3). Since \(\log J(0)=\log J(1)=0\) at the end point, the minimum value is always \(\le0\).

\[ C(p_1,p_0)=-\min_{0\le s\le1}\log J(s) \]

  • Equals: \(C=0\iff\) In all \(s\) \(\log J(s)=0\iff p_1=p_0\) ae
  • Symmetry: \(s\to1-s\) Since the role of \(p_0,p_1\) changes due to the substitution, \(C(p_1,p_0)=C(p_0,p_1)\).

5.4.5 Error Index

The error probability of the MAP test in a binary hypothesis test with prior probability \(\pi_0,\pi_1\) and iid samples \(n\) is

\[ P_e=\int\min\big(\pi_0p_0^{(n)},\pi_1p_1^{(n)}\big)\,d\mathbf x,\qquad p_i^{(n)}(\mathbf x)=\prod_{k=1}^np_i(x_k) \]

. Since \(a,b\ge0\) and \(s\in[0,1]\)Z, it is \(\min(a,b)\le a^{1-s}b^s\) (if \(a\le b\), then \(a=a^{1-s}a^s\le a^{1-s}b^s\)).

\[ P_e\le\pi_0^{1-s}\pi_1^s\int\big(p_0^{(n)}\big)^{1-s}\big(p_1^{(n)}\big)^s\,d\mathbf x=\pi_0^{1-s}\pi_1^s\,J(s)^n \]

and if we minimize from \(\pi_0^{1-s}\pi_1^s\le1\) to \(s\)

\[ P_e\le\exp\big(-n\,C(p_1,p_0)\big) \]

. The fact that this exponent is the best (\(-\frac1n\log P_e\to C\)) is Chernoff’s theorem. In equal probability BPSK, the exponent of \(P_e=Q\big(\frac{\Delta}{2\sigma}\big)\le\tfrac12e^{-\Delta^2/(8\sigma^2)}\) matches the above \(C\).

The exponent of the Neyman–Pearson setup, which places a constraint on one-sided error, is determined by KL (Stein’s Lemma), and the exponent of the Bayes setup, which is weighted by prior probability, is determined by Chernoff.

5.5 The relationship between KL and Chernoff

5.5.1 Claim

If we let \(s^\star=\arg\min_sJ(s)\) (since logarithms are increasing functions, this is equal to \(\arg\min_s\log J(s)\)), then

\[ C(p_0,p_1)=D(p_{s^\star}\|p_0)=D(p_{s^\star}\|p_1)=-\log J(s^\star) \]

The last equality sign is the definition, and the actual content is the two equality signs in the middle. The point \(p_{s^\star}\) on the curve is at the equi-KL point, which is the equidistant point from the two endpoints, and the common value is the Chernoff distance. The definition of \(C\) does not include KL, but the key point is that the conclusion is that its value is KL.

Points to note:

  • \(p_{s^\star}\) is the first argument of KL. It is generally different from \(D(p_0\|p_{s^\star})\) or \(D(p_0\|p_1)\).
  • \(s^\star=\tfrac12\) applies only in the symmetrical case.

The proof of is two steps: (i) calculate two KLs at any point on the curve, and (ii) find the first-order condition of \(\log J\) and substitute it. The two steps meet at the same quantity \(E_{p_s}[\Lambda]\).

5.5.2 Step 1: Two KLs on the curve

\[ D(p_s\|p_0)=\int\underbrace{p_s(x)}_{\text{가중치}}\log\frac{\overbrace{p_s(x)}^{\text{로그 안}}}{p_0(x)}\,dx \]

In , \(p_s\) plays a different role in the second digit, so it is processed separately.

(A) Ratio inside the log. Since \(p_0^{1-s}/p_0=p_0^{-s}\)

\[ \frac{p_s}{p_0}=\frac{p_0^{1-s}p_1^s}{J(s)\,p_0}=\frac1{J(s)}\Big(\frac{p_1}{p_0}\Big)^s \]

(B) Properties of logarithms.

\[ \log\frac{p_s}{p_0}=\log\Big(\frac{p_1}{p_0}\Big)^s-\log J(s) \]

(C) Multiply by weights and integrate. \(\log J(s)\) is a constant independent of \(x\), and since \(\int p_s=1\),

\[ \int p_s\log J(s)\,dx=\log J(s) \]

Therefore

\[ D(p_s\|p_0)=\int\frac{p_0^{1-s}p_1^s}{J(s)}\log\Big(\frac{p_1}{p_0}\Big)^s dx-\log J(s) \]

(D) Move exponents forward. From \(\log u^s=s\log u\)

\[ D(p_s\|p_0)=s\int p_s\log\frac{p_1}{p_0}\,dx-\log J(s)=s\,E_{p_s}[\Lambda]-\log J(s) \]

In the same way, \(\dfrac{p_s}{p_1}=\dfrac1{J(s)}\Big(\dfrac{p_1}{p_0}\Big)^{s-1}\), therefore

\[ D(p_s\|p_1)=(s-1)\,E_{p_s}[\Lambda]-\log J(s) \]

The two expressions are multiplied by the same expected value with only the coefficients \(s\) and \(s-1\)Z differing, and if you subtract

\[ D(p_s\|p_0)-D(p_s\|p_1)=E_{p_s}[\Lambda] \]

. The condition for the two KLs to be equal is \(E_{p_s}[\Lambda]=0\).

Check. If \(s=0\), it matches the definition as \(0-\log1=0=D(p_0\|p_0)\); if \(s=1\), it matches the definition as \(E_{p_1}[\Lambda]-\log1=D(p_1\|p_0)\).

5.5.3 Step 2: Differentiation of \(\log J(s)\)

(1) Differentiation of composite functions.

\[ \frac{d}{ds}\log J(s)=\frac{J'(s)}{J(s)} \]

(2) Differentiate into integral. (Under the conditions of the Dominant Convergence Theorem)

\[ J'(s)=\int\frac{\partial}{\partial s}\Big[p_0(x)^{1-s}p_1(x)^s\Big]dx \]

(3) Differentiation of the integrand. If \(x\) is fixed, \(p_0,p_1\) is a constant and

\[ p_0^{1-s}p_1^s=p_0\Big(\frac{p_1}{p_0}\Big)^s \]

is of the form \(a^s\). Since \(a^s=e^{s\ln a}\), it is \(\frac{d}{ds}a^s=a^s\ln a\) and

\[ \frac{\partial}{\partial s}\Big[p_0^{1-s}p_1^s\Big]=p_0^{1-s}p_1^s\,\ln\frac{p_1}{p_0} \]

Even after differentiation, the original expression remains and \(\ln(p_1/p_0)\) is multiplied by one.

(4)–(5) Combine and take the expected value.

\[ \frac{d}{ds}\ln J(s)=\frac1{J(s)}\int p_0^{1-s}p_1^s\ln\frac{p_1}{p_0}\,dx=\int p_s\ln\frac{p_1}{p_0}\,dx=E_{p_s}\Big[\ln\frac{p_1}{p_0}\Big] \]

Since it was divided by \(J(s)\), the weight becomes the normalized density \(p_s\), which is the expected value.

Identification with Step 1. Slope of \(\log J\) = Difference between two KLs.

5.5.3.1 base of the log

In the differentiation of exponential functions, \(\ln\) always appears regardless of the base, so the logarithm appearing in the above derivation is the natural logarithm. If defined as \(\log=\log_b\)

\[ \frac{d}{ds}\log_bJ(s)=\frac1{\ln b}\,E_{p_s}\Big[\ln\frac{p_1}{p_0}\Big]=E_{p_s}\Big[\log_b\frac{p_1}{p_0}\Big] \]

As , the factor \(\frac1{\ln b}\) is absorbed by \(\frac{\ln u}{\ln b}=\log_bu\). The expansion in Step 1 is base-independent because it uses only \(\log(ab)=\log a+\log b\) and \(\log u^s=s\log u\), and the condition “\(\frac{d}{ds}\log J=0\)” used in Step 3 is also not affected by positive constant multiples. Therefore, as long as the base is unified within the same expression, the conclusion is base-independent. If the base is 2, the unit is simply bits.

5.5.3.2 The minimum value is inside and the only reason

The first-order condition can be used only when \(s^\star\) is inside the interval. Second derivative

\[ J''(s)=\int p_0^{1-s}p_1^s\,\Lambda^2\,dx>0\quad(p_0\ne p_1) \]

In , \(J\) is strictly convex, and the slope at the endpoint is

\[ \frac{d}{ds}\log J\Big|_{s=0}=E_{p_0}[\Lambda]=-D(p_0\|p_1)<0,\qquad \frac{d}{ds}\log J\Big|_{s=1}=E_{p_1}[\Lambda]=D(p_1\|p_0)>0 \]

. Since the gradient is continuous, strictly increasing, and changes from negative to positive, there is exactly one zero in \((0,1)\), which is \(s^\star\). This is \(p_0\ne p_1\) and is the argument when the two KLs are finite, but the case where the support is different and KL is \(\infty\) is outside this argument.

5.5.4 Step 3: Substitution

From \(s^\star\), since it becomes \(E_{p_{s^\star}}[\Lambda]=0\), the first term of Step 1 disappears.

\[ D(p_{s^\star}\|p_0)=-\log J(s^\star),\qquad D(p_{s^\star}\|p_1)=-\log J(s^\star) \]

and \(C=-\min_s\log J(s)=-\log J(s^\star)\), therefore

\[ \boxed{\,C(p_0,p_1)=D(p_{s^\star}\|p_0)=D(p_{s^\star}\|p_1)=-\log J(s^\star)\,} \]

Step Key Formula Role
1 \(D(p_s\|p_0)-D(p_s\|p_1)=E_{p_s}[\Lambda]\) the difference between two KLs as an expected value
2 \(\frac{d}{ds}\log J=E_{p_s}[\Lambda]\) The same expected value is the slope of \(\log J\)
3 Slope at the optimal point \(=0\) The two KLs are equal and the value is \(-\log J(s^\star)\)

5.5.5 Verification: Gaussian equal variances

\(p_s=\mathcal N(\mu_0+s\Delta,\sigma^2)\) Therefore

\[ D(p_s\|p_0)=\frac{s^2\Delta^2}{2\sigma^2},\qquad D(p_s\|p_1)=\frac{(1-s)^2\Delta^2}{2\sigma^2} \]

The two values become the same at \(s^\star=\tfrac12\), and the common value is \(\frac{\Delta^2}{8\sigma^2}=C\). The difference is

\[ \frac{(2s-1)\Delta^2}{2\sigma^2}=\frac{d}{ds}\Big[-\frac{s(1-s)\Delta^2}{2\sigma^2}\Big] \]

is consistent with the identity in Step 1–2. On the expectation side as well, if we set \(x=\mu_s+\sigma z\), it becomes \((x-\mu_0)^2-(x-\mu_1)^2=(2s-1)\Delta^2+2\Delta\sigma z\), which is equal to \(E_{p_s}[\Lambda]=\frac{(2s-1)\Delta^2}{2\sigma^2}\).

5.5.7 Interpretation

The most plausible error path. For an error to occur, a sample from \(p_0\) must look like \(p_1\) or vice versa. In such a rare event, the experience distribution follows a \(q\), and the exponential cost of that probability is \(D(q\|\text{진짜 분포})\) (Sanov). The equilibrium point where both types of errors occur with the same exponential is \(p_{s^\star}\), where the two KLs are equal, and the common cost is \(C\). \(E_{p_{s^\star}}[\Lambda]=0\) means that “a sample from \(p_{s^\star}\) provides, on average, neither type of evidence.”

Legendre conversion. If you set it to \(\psi(s)=\log J(s)=\log E_{p_0}[e^{s\Lambda}]\), it becomes \(\psi'(s)=E_{p_s}[\Lambda]\) and

\[ D(p_s\|p_0)=s\,\psi'(s)-\psi(s) \]

is the Legendre transformation of \(\psi\). \(C=-\min_s\psi(s)=\psi^*(0)\) is the value of the rate function of Cramér’s theorem calculated from the origin, that is, the exponent of the “event where the sample mean of LLR is greater than 0”.
