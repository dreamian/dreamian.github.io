삼각형 막대기 (여사건 + 하키스틱 항등식)

combinatorics
math
Published

April 11, 2026

1. 문제 요약

길이 \(A\), \(B\), \(C\)인 세 막대기가 있다. 최대 \(K\)번의 연산(막대 하나를 골라 1cm 늘리기)을 수행한 뒤, 최종 길이 \((X, Y, Z)\)가 삼각형 조건을 만족하는 서로 다른 순서쌍의 수를 구한다.

  • 삼각형 조건: \(X+Y>Z\), \(Y+Z>X\), \(Z+X>Y\)
  • \(1 \le A, B, C \le 3 \times 10^5\), \(0 \le K \le 3 \times 10^5\)

2. 풀이

2.1 여사건 접근

직접 세는 대신, (전체 경우의 수) − (삼각형이 안 되는 경우의 수)를 구한다.

각 막대에 \(da, db, dc \ge 0\)만큼 늘린다고 하면 \(da + db + dc \le K\)이다.

삼각형이 안 되는 경우는 세 부등식

\[Z \ge X + Y, \quad X \ge Y + Z, \quad Y \ge X + Z\]

중 하나가 성립하는 경우인데, 이 세 조건은 동시에 2개 이상 성립할 수 없으므로 포함-배제 없이 단순 합산으로 뺄 수 있다.

2.2 전체 경우의 수와 하키스틱 항등식

\(da + db + dc \le K\)인 비음정수 해의 수를 구해야 한다.

Step 1. \(da + db + dc = s\) (정확히 \(s\)번 사용)인 비음정수 해의 수는 Stars and Bars에 의해

\[\binom{s + 2}{2}\]

Step 2. \(s\)를 \(0\)부터 \(K\)까지 합산한다.

\[\text{전체} = \sum_{s=0}^{K} \binom{s+2}{2}\]

여기서 하키스틱 항등식(Hockey Stick Identity)을 적용한다.

Tip하키스틱 항등식

\[\sum_{i=0}^{r} \binom{n+i}{n} = \binom{n+r+1}{n+1}\]

파스칼 삼각형에서 같은 대각선 방향으로 연속된 항을 더하면, 그 합이 바로 아래 옆 칸의 값과 같다. 이 경로의 모양이 하키 스틱처럼 생겨서 붙은 이름이다.

구체적 예시 (\(n=2\), \(r=3\)):

\(i\) \(\binom{2+i}{2}\) 값
0 \(\binom{2}{2}\) 1
1 \(\binom{3}{2}\) 3
2 \(\binom{4}{2}\) 6
3 \(\binom{5}{2}\) 10

합 \(= 1 + 3 + 6 + 10 = 20 = \binom{6}{3}\) ✓

일반적으로, \(\binom{2}{2} + \binom{3}{2} + \cdots + \binom{r+2}{2} = \binom{r+3}{3}\)이다.

따라서 \(n = 2\), \(r = K\)를 대입하면

\[\text{전체} = \binom{K+3}{3} = \frac{(K+1)(K+2)(K+3)}{6}\]

2.3 불가능 경우의 수

\(Z \ge X + Y\), 즉 \((C + dc) \ge (A + da) + (B + db)\)인 경우를 센다.

\(dc\)를 \(\text{KK}\)로 고정하면, 조건은

\[da + db \le \min\bigl(C - A - B + \text{KK},\; K - \text{KK}\bigr)\]

이고, 이 값을 \(m\)이라 하면 \(m \ge 0\)일 때 비음정수 해의 수는 \(\frac{(m+1)(m+2)}{2}\)이다.

\(\text{KK} = 0, 1, \ldots, K\)에 대해 합산하면 하나의 부등식에 대한 불가능 수가 나온다. 세 부등식 각각에 대해 같은 함수를 호출하여 모두 빼면 된다.

2.4 시간 복잡도

  • 전체 경우의 수: \(O(1)\)
  • 불가능 경우의 수: \(O(K)\) × 3
  • 총: \(O(K)\) per test case
Note

불가능 경우의 수 계산에도 하키스틱을 한 번 더 적용하면 \(O(1)\)로 줄일 수 있지만, 현재 제한에서는 \(O(K)\)로 충분하다.
