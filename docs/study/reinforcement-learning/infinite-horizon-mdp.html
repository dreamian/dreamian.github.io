1 전체 흐름 한눈에 보기

\[ \underbrace{\text{정책 평가}}_{v^\pi = T^\pi v^\pi\ (\text{선형})} \;\longrightarrow\; \underbrace{\text{최적 가치}}_{v^* = T v^*\ (\text{비선형})} \;\longrightarrow\; \underbrace{\text{최적 정책}}_{\pi^*(s)\in\arg\max_a[\cdots]} \;\longrightarrow\; \underbrace{\text{Policy iteration}}_{\text{평가} \leftrightarrow \text{향상}} \]

단계 핵심 질문 핵심 도구
정책 평가 주어진 \(\pi\)의 성능 \(v^\pi\)를 어떻게 계산하나? 벡터 형태, 역행렬, 연산자 \(T^\pi\), γ-축약, Banach
최적 가치 \(v^*\)는 어떻게 특징지어지고 계산되나? Bellman 연산자 \(T\), 축약성·단조성, value iteration

모든 증명의 뿌리는 결국 두 가지 사실로 모입니다.

Important모든 증명의 뿌리
  1. 가중평균은 최댓값을 넘지 못한다. \(P^\pi\)의 각 행과 \(\pi(\cdot|s)\)는 확률분포이므로, 이들을 곱하는 연산은 모두 가중평균이다.
  2. \(\gamma<1\)이 오차를 수축시킨다. 평균으로 커지지 않은 오차에 \(\gamma\)가 곱해져 실제로 줄어든다.

2 복습: Finite-horizon DP

2.1 이산 상태·행동

초기화 \(v_T^*(s) := r_T(s)\) 후, \(t = T-1, \dots, 0\)에 대해 backward induction을 수행한다.

\[ v_t^*(s) := \max_{a\in A}\Big(r_t(s,a) + \sum_{s'} p(s'|s,a)\,v_{t+1}^*(s')\Big),\qquad \pi_t^*(s) \in \arg\max_{a\in A}\Big(\cdots\Big) \]

  • 각 시점의 최적 가치 함수와 최적 정책을 정확히(exact) 구한다.
  • 최적 정책은 여러 개일 수 있다. argmax가 여러 개일 수 있기 때문이다.
  • 숨은 복잡도: 모든 상태에 대해, 매 연산마다 행동 최대화가 있다. 상태·행동 공간이 크면 확장(scale up)되지 않는다.

2.2 연속 제어로의 확장

\(s_{t+1} = f(s_t, a_t, w_t)\), \(w_t \sim p_w\)에 대해

\[ v_t^*(s) := \sup_{a\in A}\Big[r(s,a) + \int_w v_{t+1}^*(f(s,a,w))\,p_w(dw)\Big]. \]

  • max 대신 sup을 쓴다. 최적 정책이 존재하지 않을 수 있다(maximizer가 존재할 때만 최적 정책을 찾는다).
  • 행동 최대화가 어렵고, 연속 상태 공간 전체에서 평가할 수 없어 이산화가 들어가며 확장성 문제가 생긴다.

3 Infinite-horizon discounted MDP

3.1 정의

Note정의 (Discounted MDP)

튜플 \(\langle S, A, p, r, \gamma\rangle\)

  • \(S\): 상태 집합, \(A\): 행동 집합
  • \(p(s'|s,a) := \Pr(s_{t+1}=s' \mid s_t=s, a_t=a)\): 현재 상태 \(s\), 현재 행동 \(a\)일 때 다음 상태가 \(s'\)일 확률
  • \(r(s,a)\): 현재 상태·행동의 이득을 측정하는 스칼라 보상 함수
  • \(\gamma \in (0,1)\): 미래 보상을 얼마나 할인할지 정하는 할인율

3.2 가정

  1. Stationary한 보상과 전이 확률: \(r(s,a)\), \(p(s'|s,a)\)가 시간에 따라 변하지 않는다.
    • Finite horizon에서는 보상 \(r_t\)가 시간에 의존할 수 있었고, 전이 확률도 시간 의존으로 설정할 수 있었다.
    • Infinite horizon에서는 함수 자체가 시간에 직접 의존하지 않는다.
  2. 유한 상태·행동 집합: \((s,a)\) 조합이 유한하므로 보상이 유계이다. 즉 어떤 상수 \(M\)에 대해 \(|r(s,a)| < M\), \(\forall s, a\).
  3. 할인: \(0 \le \gamma < 1\).

3.3 결과: 누적 보상은 항상 유계

\[ \Big|\sum_{t=0}^{\infty}\gamma^t r(s_t,a_t)\Big| \le \sum_{t=0}^{\infty}\gamma^t\,|r(s_t,a_t)| \le \sum_{t=0}^{\infty}\gamma^t M = \frac{M}{1-\gamma}. \]

유한 상태·행동과 할인을 결합하면 어떤 가치든 같은 상한 안에 들어온다. 누적 보상의 발산을 걱정할 필요가 없는 깔끔한 설정이다.

4 가치 함수와 stationary 정책

4.1 가치 함수

Note정의 (Value function)

\[ v^\pi(s) := \mathbb{E}^\pi\Big[\sum_{\tau=t}^{\infty}\gamma^{\tau-t}\,r(s_\tau,a_\tau)\;\Big|\; s_t = s\Big] \] 상태 \(s\)에서 출발해 앞으로 정책 \(\pi\)를 썼을 때 얻을 누적 보상의 기댓값.

  • 이 의미가 자동으로 떠오르도록 연습할 것. 수학적 정의보다 직관적 이해가 훨씬 중요하다.
  • 시작 시점 \(t\)는 중요하지 않다. 무한대까지 더하고 할인 가중치도 시작 시점만큼 shift했으므로, \(t\)가 무엇이든 값이 같다.
  • 가치 함수를 계산해 두면, 상태 자리에 초기 상태만 넣어 주면 정책 평가가 끝난다.

4.2 Stationary 정책

일반적으로 정책은 \(\pi := (\pi_0, \pi_1, \pi_2, \dots)\)이다. \(\pi_t\)는 시간 \(t\)에 쓰는 결정 규칙, 즉 상태 → 행동 사상이다. Finite horizon에서는 실제로 시점마다 다른 최적 결정 규칙이 나왔다.

정책이 stationary하다는 것은 매 시점 같은 결정 규칙을 쓴다는 뜻이다. \[ \pi_i = \pi_j \quad \forall i, j. \]

결정 규칙과 정책을 구분할 필요가 없으므로 다음처럼 간단히 쓴다.

  • Deterministic stationary: \(\pi(s_t) = a_t\)
  • Stochastic stationary: \(\pi(a_t|s_t)\) (상태별 행동 확률 분포)
TipQ) Stationary 정책이면 매 시점 똑같은 행동을 하나?

아니다. 사상은 고정되어 있지만 매 시점 입력(상태)이 달라지므로 출력(행동)도 달라진다. 대부분의 강화학습 알고리즘이 stationary 정책을 가정한다. Stationary 정책만 고려해도 충분하다는 사실은 최적 정책의 존재에서 정당화된다.

5 정책 평가: 가치 함수의 분해

5.1 Bellman 기대 방정식

가치 함수를 (i) 즉각 보상과 (ii) 할인된 다음 상태의 가치로 분해한다.

\[ v^\pi(s) = \mathbb{E}^\pi\big[\underbrace{r(s_t,a_t)}_{\text{즉각 보상}} + \gamma\,\underbrace{v^\pi(s_{t+1})}_{\text{다음 상태의 가치}} \;\big|\; s_t = s\big] = \sum_{a\in A}\pi(a|s)\Big(r(s,a) + \gamma\sum_{s'\in S}p(s'|s,a)\,v^\pi(s')\Big). \]

보상에도 행동이 걸리고 전이 확률에도 행동이 걸리므로, randomized 정책에서는 행동에 대한 기댓값을 바깥 합(outer sum)으로 취한다.

5.2 증명 (tower rule)

\[ \begin{aligned} v^\pi(s) &= \mathbb{E}^\pi\Big[r(s_t,a_t) + \gamma\sum_{\tau=t+1}^{\infty}\gamma^{\tau-t-1}r(s_\tau,a_\tau)\;\Big|\; s_t=s\Big] \\ &= \mathbb{E}^\pi\Big[r(s_t,a_t) + \gamma\,\mathbb{E}^\pi\Big[\sum_{\tau=t+1}^{\infty}\gamma^{\tau-t-1}r(s_\tau,a_\tau)\;\Big|\; s_{t+1}\Big]\;\Big|\; s_t=s\Big] \\ &= \mathbb{E}^\pi\big[r(s_t,a_t) + \gamma\,v^\pi(s_{t+1}) \;\big|\; s_t=s\big] \\ &= \sum_{a}\pi(a|s)\Big[r(s,a) + \gamma\sum_{s'}p(s'|s,a)\,v^\pi(s')\Big]. \end{aligned} \]

  • 1행: 무한 합을 \(t\) 시점 항과 \(t+1\) 이후 항으로 분리
  • 2행: \(s_{t+1}\)에 대한 조건부 기댓값을 한 번 더 적용 (tower rule)
  • 3행: 안쪽은 정의상 초기 상태가 \(s_{t+1}\)인 가치 함수 \(v^\pi(s_{t+1})\) (stationarity 덕분)
  • 4행: \(a_t\)의 분포는 \(\pi\), \(s_{t+1}\)의 분포는 전이 확률로 가중합

5.3 Finite horizon과 무엇이 다른가

  • 시간에 대한 개념이 없다. Stationary 보상·전이를 가정했으므로 매 시점 같은 식이다. 시간의 영향은 가치 함수의 정의 안에 숨어 있다.
  • 그래서 계산 방식이 달라진다. Finite horizon에서는 좌변이 \(t\), 우변이 \(t+1\) 시점의 가치라 종단 조건에서 거꾸로 하나씩 계산할 수 있었다. Infinite horizon에서는 좌변과 우변에 같은 함수 \(v^\pi\)가 있어 종단 시점부터 계산하는 것이 불가능하다. → 방정식을 “푸는” 방법이 필요하다.

6 벡터 형태

\(S = \{1,\dots,n\}\), \(A = \{1,\dots,m\}\)으로 라벨링하면 다음과 같이 쓸 수 있다.

가치 벡터 \[ v^\pi := (v^\pi(1), \dots, v^\pi(n)) \in \mathbb{R}^n \] 원래 상태 → 가치 사상이지만 \(s\)가 가질 수 있는 값이 \(n\)개이므로 출력을 나열해 \(n\)차원 벡터로 본다.

기대 보상 벡터 \[ R^\pi := \Big(\sum_a\pi(a|1)\,r(1,a),\;\dots,\;\sum_a\pi(a|n)\,r(n,a)\Big) \in \mathbb{R}^n \] \(i\)번째 원소는 상태 \(i\)에서 정책 \(\pi\)를 썼을 때의 보상 기댓값이다. Deterministic이면 \(R^\pi = (r(1,\pi(1)), \dots, r(n,\pi(n)))\).

전이 확률 행렬 \[ P^\pi_{ij} := \sum_a \pi(a|i)\,p(j|i,a), \qquad P^\pi \in \mathbb{R}^{n\times n} \] \((i,j)\) 원소는 상태 \(i\)에서 정책 \(\pi\)를 썼을 때 다음 상태가 \(j\)일 확률이다. Deterministic이면 \(P^\pi_{ij} = p(j|i,\pi(i))\).

벡터 방정식 \[ \boxed{\,v^\pi = R^\pi + \gamma P^\pi v^\pi\,} \] \(n\)개의 방정식을 한 줄로 쓴 것이며, 각 원소를 계산하면 앞의 방정식과 완전히 동일하다.

Important\(P^\pi\)는 row-stochastic

\(P^\pi_{ij} \ge 0\)이고 \[ \sum_j P^\pi_{ij} = \sum_a \pi(a|i)\underbrace{\sum_j p(j|i,a)}_{=1} = 1. \] 따라서 \(\|P^\pi\|_\infty = \max_i\sum_j|P^\pi_{ij}| = 1\)이고, \(P^\pi\mathbf{1} = \mathbf{1}\)이다. 이 장의 거의 모든 증명이 이 사실에서 출발한다.

7 해의 존재·유일성과 역행렬 표현

벡터 방정식은 선형이므로 정리하면 \[ (I - \gamma P^\pi)\,v^\pi = R^\pi. \] 해가 유일하게 존재한다는 것은 \(I - \gamma P^\pi\)가 가역이라는 것과 동치이다.

Note명제
  1. \(P^\pi\)의 고유값은 \(|\lambda| \le 1\)을 만족한다.
  2. \(v = R^\pi + \gamma P^\pi v\)는 유일한 해를 가진다.
  3. 그 해는 \(v^\pi = (I-\gamma P^\pi)^{-1}R^\pi = \sum_{t=0}^{\infty}(\gamma P^\pi)^t R^\pi\)이다.
  4. 이 방법은 대규모 문제에서 비효율적이다.

논리 구조는 다음과 같다. \[ \text{(A)}\ |\lambda| \le 1 \;\Longrightarrow\; \text{(B)}\ I-\gamma P^\pi \text{의 고유값은 } 1-\gamma\lambda \;\Longrightarrow\; \text{(C)}\ 0 \text{은 고유값이 아님} \Rightarrow \text{가역} \]

7.1 (A) 고유값이 1 이하인 이유

직관: 전이 확률을 계속 곱한다는 것은 확률의 곱이 이어지는 것이다. \(P^\pi v\)는 각 상태에서 다음 상태 값들의 가중평균이고, 평균은 가장 큰 값을 넘을 수 없으므로 벡터의 크기가 커지지 않는다. 고유값은 “곱했을 때 몇 배가 되는가”이므로 \(|\lambda|\le 1\)이다.

고유값은 복소수일 수 있으므로 정확한 명제는 \(|\lambda| \le 1\)이다.

증명: \(P^\pi v = \lambda v\), \(v \ne 0\) (\(v\in\mathbb{C}^n\))이라 하자. \(|v_{i^*}| = \|v\|_\infty > 0\)인 \(i^*\)를 잡으면

\[ |\lambda|\,|v_{i^*}| = \Big|\sum_j P^\pi_{i^*j}\,v_j\Big| \le \sum_j P^\pi_{i^*j}\,|v_j| \le \|v\|_\infty\sum_j P^\pi_{i^*j} = \|v\|_\infty. \]

  • 첫 부등식: 삼각부등식
  • 둘째 부등식: \(|v_j| \le \|v\|_\infty\), \(P^\pi_{i^*j} \ge 0\)
  • 마지막 등호: 행의 합이 1

좌변이 \(|\lambda|\,\|v\|_\infty\)이므로 \(|\lambda| \le 1\). \(\blacksquare\)

또한 \(P^\pi\mathbf 1 = \mathbf 1\)이므로 \(\lambda = 1\)은 항상 고유값이다. 즉 상한 1은 실제로 달성된다.

7.2 (B) \(I - \gamma P^\pi\)의 고유값

\((I-\gamma P^\pi)x = \mu x\) (\(x \ne 0\))이면 \(\gamma P^\pi x = (1-\mu)x\), 즉 \[ P^\pi x = \frac{1-\mu}{\gamma}\,x. \] 따라서 \(\lambda := \frac{1-\mu}{\gamma}\)는 \(P^\pi\)의 고유값이고 \(\mu = 1 - \gamma\lambda\)이다. 역방향도 같은 계산으로 성립하므로, \(I-\gamma P^\pi\)의 고유값은 정확히 \(\{1-\gamma\lambda : \lambda \text{는 } P^\pi\text{의 고유값}\}\)이다. (고유벡터는 그대로 유지된다.)

7.3 (C) 가역성

행렬이 가역이 아니다 \(\iff\) \(Ax = 0\)인 \(x \ne 0\) 존재 \(\iff\) \(0\)이 고유값.

\[ \mu = 1 - \gamma\lambda = 0 \iff \lambda = \frac{1}{\gamma}. \]

\(0<\gamma<1\)이면 \(1/\gamma > 1\)인데 (A)에 의해 그런 고유값은 없다. 따라서 \(I-\gamma P^\pi\)는 항상 가역이다. 역삼각부등식으로 한 번에 쓰면 \[ |1-\gamma\lambda| \ge 1 - \gamma|\lambda| \ge 1-\gamma > 0. \]

고유값 0이 되는 조건 가능한가
\(\gamma<1\) \(\lambda = 1/\gamma > 1\) 불가능
\(\gamma=1\) \(\lambda = 1\) 항상 가능 (\(P^\pi\mathbf 1 = \mathbf 1\))

\(\gamma < 1\)이 중요한 이유: \(1/\gamma\)를 고유값의 상한 1 바깥으로 밀어낸다. \(\gamma = 1\)이면 \((I-P^\pi)\mathbf 1 = 0\)이므로 \(I - P^\pi\)는 반드시 특이(singular)이다.

7.3.1 고유값 없이 보이는 방법 (노름 논법)

\((I-\gamma P^\pi)x = 0\)이면 \(x = \gamma P^\pi x\)이고 \(\|P^\pi x\|_\infty \le \|x\|_\infty\)이므로 \[ \|x\|_\infty = \gamma\|P^\pi x\|_\infty \le \gamma\|x\|_\infty \;\Longrightarrow\; (1-\gamma)\|x\|_\infty \le 0 \;\Longrightarrow\; x = 0. \] 영공간이 자명하므로 가역이다. 이 계산은 뒤의 \(T^\pi\) 축약 증명과 같은 계산이다.

7.4 Neumann 급수 표현

스칼라 등비급수 \(\frac{1}{1-x} = \sum_t x^t\) (\(|x|<1\))의 행렬 버전이다.

(a) 수렴. \((P^\pi)^t\)도 stochastic이므로 \(\|(\gamma P^\pi)^t\|_\infty = \gamma^t\)이고, \(\sum_t\gamma^t < \infty\)이므로 절대수렴한다.

(b) 극한이 역행렬. 부분합 \(S_n = \sum_{t=0}^{n-1}(\gamma P^\pi)^t\)에 대해 telescoping으로 \[ (I-\gamma P^\pi)\,S_n = I - (\gamma P^\pi)^n \xrightarrow{n\to\infty} I. \] 따라서 \(S = \lim S_n = (I-\gamma P^\pi)^{-1}\).

(c) 의미. Markov 성질에 의해 \(\mathbb{E}^\pi[r(s_t,a_t)\mid s_0 = i] = ((P^\pi)^t R^\pi)_i\)이다.

  • \(R^\pi\): 지금 받는 기대 보상
  • \(P^\pi R^\pi\): 한 스텝 뒤의 기대 보상
  • \((P^\pi)^t R^\pi\): \(t\) 스텝 뒤의 기대 보상
  • \(\gamma^t\): 현재 가치로 할인

즉 급수는 시간 \(0, 1, 2, \dots\)의 기대 보상을 할인해 더한 것으로, \(v^\pi\)의 정의 그 자체이다. 역행렬 공식은 정의를 행렬로 다시 쓴 것이며, 원래 구하려던 가치 함수와 일관됨을 검산할 수 있다.

7.5 수치 예시

\(P = \begin{pmatrix}0.5 & 0.5\\ 0.2 & 0.8\end{pmatrix}\), \(\gamma = 0.9\).

  • \(P\)의 고유값: trace \(= 1.3\), det \(= 0.3\) → \(\lambda = 1,\ 0.3\)
  • \(I - 0.9P\)의 고유값: \(1 - 0.9 = 0.1\), \(1 - 0.27 = 0.73\) → 둘 다 0이 아님
  • \((I-0.9P)^{-1} = \frac{1}{0.073}\begin{pmatrix}0.28 & 0.45\\ 0.18 & 0.55\end{pmatrix}\)
  • 검산: \(R = \mathbf 1\)이면 \(v = \sum_t \gamma^t = 1/(1-\gamma) = 10\). 실제로 각 행의 합 \(0.73/0.073 = 10\).

7.6 왜 역행렬을 잘 쓰지 않는가

관심 있는 문제는 보통 상태가 매우 많다.

  • 연산량: \(n\times n\) 선형계 풀이에 \(O(n^3)\)
  • 메모리: \(P^\pi\) 저장에 \(O(n^2)\). \(n = 10^6\)이면 \(10^{12}\)개 원소
  • \(P^\pi\)가 희소해도 역행렬은 일반적으로 밀집

→ 근사가 아닌 정확한 방법을 원하되 역행렬을 피하는 방법이 필요하다. 이것이 연산자 형태와 고정점 반복이다.

8 연산자 형태와 고정점 문제

\[ T^\pi v := R^\pi + \gamma P^\pi v, \qquad (T^\pi v)(s) = \sum_a \pi(a|s)\Big[r(s,a) + \gamma\sum_{s'}p(s'|s,a)\,v(s')\Big]. \]

정책 평가 방정식은 \[ \boxed{\,v^\pi = T^\pi v^\pi\,} \] 라는 고정점(fixed point) 문제가 된다.

  • 유도한 방정식을 다시 쓰기만 한 것이고, 푸는 방법은 아직 말하지 않았다.
  • 좌변과 우변에 모두 \(v^\pi\)가 있으니, 우변 전체를 \(v^\pi\)에 사상 \(T^\pi\)를 적용한 출력으로 보는 관점이다.
  • 이 정식화는 value-based RL의 근간이 되는 아이디어이다.

9 축약 성질과 Banach 고정점 정리

9.1 정의

Note정의 (γ-contraction)

연산자 \(T:\mathbb{R}^n\to\mathbb{R}^n\)이 \(\|\cdot\|\)에 관해 γ-축약이라는 것은 \[ \|Tv - Tv'\| \le \gamma\|v - v'\| \qquad \forall v, v' \in\mathbb{R}^n. \]

직관: 임의의 두 점을 연산자에 통과시킨 뒤의 거리가 통과시키기 전보다 \(\gamma\)배 이하로 줄어든다. 이 수축성은 강화학습에서 매우 중요한 역할을 한다.

9.2 \(T^\pi\)는 γ-축약

Note명제

\(T^\pi\)는 임의의 stationary 정책 \(\pi\)에 대해 \(\|\cdot\|_\infty\)에 관해 γ-축약이다.

9.2.1 직관: 오차가 세 단계를 거치며 줄어든다

\(T^\pi\)가 하는 일은 “내 보상 + γ × (다음 상태 가치의 평균)”이다. 두 추정 \(v, v'\)의 차이(오차)만 추적하면 된다.

단계 일어나는 일 오차에 미치는 영향
① 보상 \(R^\pi\)를 더함 \(v, v'\) 둘 다에 똑같이 더해짐 상쇄되어 영향 없음
② \(P^\pi\)로 평균 다음 상태 가치들의 확률 가중평균 평균은 최댓값을 못 넘으므로 커지지 않음
③ \(\gamma\)를 곱함 \(\gamma<1\) γ배로 줄어듦

9.2.2 유도

Step 1. 보상이 사라진다. \[ T^\pi v - T^\pi v' = \gamma P^\pi(v - v') =: \gamma P^\pi d. \]

Step 2. 한 상태 \(s\)만 본다. \((\gamma P^\pi d)(s) = \gamma\sum_j P^\pi_{sj}\,d(j)\)는 \(d\)의 가중평균이다.

Step 3. 평균은 최댓값을 넘지 못한다. \[ \Big|\sum_j P^\pi_{sj}\,d(j)\Big| \le \sum_j P^\pi_{sj}\,|d(j)| \le \|d\|_\infty\underbrace{\sum_j P^\pi_{sj}}_{=1} = \|d\|_\infty. \]

Step 4. γ를 붙이고 \(s\)에 대해 최대. \[ \|T^\pi v - T^\pi v'\|_\infty \le \gamma\|v - v'\|_\infty. \qquad\blacksquare \]

행렬 노름으로는 한 줄이다: \(\|\gamma P^\pi d\|_\infty \le \gamma\|P^\pi\|_\infty\|d\|_\infty = \gamma\|d\|_\infty\).

9.2.3 수치 예시

\(P^\pi = \begin{pmatrix}0.5 & 0.5\\ 0.2 & 0.8\end{pmatrix}\), \(\gamma = 0.9\), \(v = (10, 0)\), \(v' = (0,0)\).

  • 입력 차이 \(d = (10, 0)\), \(\|d\|_\infty = 10\)
  • 평균 \(P^\pi d = (5, 2)\)
  • \(\gamma P^\pi d = (4.5, 1.8)\) → 출력 차이 \(4.5 \le 0.9\times 10 = 9\)

9.2.4 보충

  • 왜 sup-norm인가: \(\|d\|_\infty\)는 가장 오차가 큰 상태의 오차이고, 확률 평균은 가장 큰 오차를 키울 수 없다. \(\|P^\pi\|_\infty = 1\)이 성립하는 노름이 \(\infty\)-노름이다. 일반적인 \(P^\pi\)에서 \(\|P^\pi\|_2\)는 1을 넘을 수 있어 \(\|\cdot\|_2\) 축약은 보장되지 않는다.
  • 상수 γ는 tight: \(d = c\mathbf 1\)이면 \(P^\pi\mathbf 1 = \mathbf 1\)이므로 등호가 성립한다.

9.3 Banach 고정점 정리

Note정리 (Banach fixed point theorem)

\(T:\mathbb{R}^n\to\mathbb{R}^n\)이 축약 사상이면

  1. \(T\)는 유일한 고정점 \(v^*\)를 가진다 (\(v^* = Tv^*\)).
  2. 임의의 \(v_0\)에서 출발해 \(v_{k+1} := Tv_k\)로 정의하면 \(v_k \to v^*\).

(\((\mathbb{R}^n, \|\cdot\|_\infty)\)는 완비 거리공간이다.)

수렴 속도: 고정점을 \(v^*\)라 하면 \[ \|v_{k+1} - v^*\|_\infty = \|Tv_k - Tv^*\|_\infty \le \gamma\|v_k - v^*\|_\infty \;\Longrightarrow\; \|v_k - v^*\|_\infty \le \gamma^k\|v_0 - v^*\|_\infty \to 0. \] 한 번 반복할 때마다 고정점과의 거리가 γ배로 줄어, 어디서 시작하든 지수적으로 수렴한다.

유일성의 직접 증명: 고정점이 둘이면 \(\|v_1 - v_2\| = \|Tv_1 - Tv_2\| \le \gamma\|v_1 - v_2\|\)이므로 \(\|v_1-v_2\| = 0\).

TipQ) 유일성은 왜 중요한가?

고정점이 여러 개라면 반복으로 어떤 고정점에 도달했을 때 그것이 진짜 구하려던 \(v^\pi\)인지 알 수 없다. 유일성 덕분에 수렴만 시키면 그 수렴점이 \(v^\pi\)임을 보장받는다. 이론적으로뿐 아니라 실질적으로도 중요하다.

결론: 정책 평가 방정식은 유일한 해를 가지며, \(v^\pi\)는 고정점 반복으로 구할 수 있다.

9.4 정책 평가를 위한 value iteration

Note알고리즘
  • 입력: stationary 정책 \(\pi\)
  • 초기화: \(v_0 \in \mathbb{R}^n\) 임의 (연속 상태면 임의의 함수)
  • 수렴할 때까지 반복: \(v_{k+1} := T^\pi v_k\)

\[ v_0 \xrightarrow{T^\pi} v_1 \xrightarrow{T^\pi} v_2 \xrightarrow{T^\pi}\cdots \to v^\pi \]

숨은 복잡도: 연산자 형태로 간결하게 썼지만 실제로는 모든 상태에 대해 업데이트해야 한 번의 반복이 끝난다. Deterministic 정책이면 \[ v_{k+1}(s) = r(s,\pi(s)) + \gamma\sum_{s'}p(s'|s,\pi(s))\,v_k(s') \qquad\forall s. \] 다만 행동에 대한 최대화가 없다. 행동이 \(\pi(s)\)로 고정되어 있기 때문이다. 최적 가치를 계산할 때는 행동 최대화가 추가된다.

10 최적 가치 함수와 Bellman 연산자

10.1 최적 가치 함수

목표는 다음 문제를 푸는 것이다. \[ \max_{\pi\in\Pi}\;\mathbb{E}^\pi\Big[\sum_{t=0}^{\infty}\gamma^t r(s_t,a_t)\Big] \]

Note정의 (Optimal value function)

\[ v^*(s) := \max_{\pi\in\Pi} v^\pi(s) = \max_{\pi\in\Pi}\mathbb{E}^\pi\Big[\sum_{\tau=t}^{\infty}\gamma^{\tau-t}r(s_\tau,a_\tau)\;\Big|\; s_t = s\Big] \] 시작 상태 \(s\)에서 얻을 수 있는 누적 보상 기댓값의 최대치. Infinite horizon이므로 출발 시점은 중요하지 않다.

10.2 Bellman 연산자

Dynamic programming의 아이디어대로 즉각 보상과 다음 상태부터의 누적 보상 기댓값의 합을 최대화한다.

Note정의 (Bellman operator)

\[ Tv := \max_\pi\{R^\pi + \gamma P^\pi v\},\qquad (Tv)(s) := \max_\pi\sum_{a}\pi(a|s)\Big[r(s,a) + \gamma\sum_{s'}p(s'|s,a)\,v(s')\Big]. \] 이는 다음과 같이 다시 쓸 수 있다. \[ \boxed{\,(Tv)(s) = \max_{a\in A}\Big[r(s,a) + \gamma\sum_{s'}p(s'|s,a)\,v(s')\Big]\,} \]

(일부 표기에서 Bellman 연산자를 \(T^*\)로 쓰기도 한다. 같은 연산자이다.)

10.3 Q) 왜 정책에 대한 max가 행동에 대한 max와 같은가

\[ q_v(s,a) := r(s,a) + \gamma\sum_{s'}p(s'|s,a)\,v(s') \] 라 두면 \((T^\pi v)(s) = \sum_a\pi(a|s)\,q_v(s,a)\)는 \(q_v(s,\cdot)\)의 가중평균이다. 증명할 것은 \[ \max_\pi\sum_a\pi(a|s)\,q_v(s,a) = \max_a q_v(s,a). \]

(≤) 평균은 최댓값을 넘지 못한다. 임의의 \(\pi\)에 대해 \(\pi(a|s) \ge 0\)이므로 \[ \sum_a\pi(a|s)\,q_v(s,a) \le \max_{a'}q_v(s,a')\sum_a\pi(a|s) = \max_{a'}q_v(s,a'). \] 행동에 대한 최대치보다 더 큰 값을 주는 정책은 찾을 수 없다.

(≥) 상한을 달성하는 정책이 존재한다. \(a^*(s) \in\arg\max_a q_v(s,a)\)에 확률 질량을 몰아주는 Dirac 분포 \(\pi^\delta(a|s) = \mathbb{1}\{a = a^*(s)\}\)를 쓰면 \[ \sum_a\pi^\delta(a|s)\,q_v(s,a) = q_v(s,a^*(s)) = \max_a q_v(s,a). \qquad\blacksquare \]

보통 Bellman 연산자는 행동 \(a\)에 대해 최대화하는 형태로 정의해 쓰며, 대부분의 문헌이 이 관례를 따른다.

10.3.1 벡터 max의 의미

\(\max_\pi\{R^\pi + \gamma P^\pi v\}\)는 원소별(componentwise) max로 읽는다.

  • \(s\)번째 원소는 \(\pi(\cdot|s)\)에만 의존한다. 정책은 상태마다 독립적으로 정할 수 있는 분포의 모음이다.
  • 따라서 상태별 최대화는 서로 간섭하지 않는다.
  • \(\pi^\delta\) 하나가 모든 상태에서 동시에 최댓값을 달성한다.

직관: 랜덤하게 고르는 것은 각 행동의 값을 확률로 섞은 것이다. 섞어서 가장 좋은 행동보다 좋아질 수 없으므로, 최적화 관점에서 무작위성은 이득이 없다. 이것이 “deterministic 최적 정책이 존재한다”의 뿌리이다.

10.4 선형 vs 비선형

  • \(T^\pi v = R^\pi + \gamma P^\pi v\): 행렬 곱과 합만 있으므로 \(v\)에 대해 선형. → 역행렬 사용 가능.
  • \(T\): 행동에 대한 최대화가 있으므로 \(v\)에 대해 비선형. → 역행렬로 \(v^*\)를 계산할 수 없다.

선형성은 입력 \(v\)에 대해 판단한다.

11 Bellman 연산자의 축약성과 단조성

Note명제

Bellman 연산자 \(T\)는 \(\|\cdot\|_\infty\)에 관해 γ-축약이다. \[ \|Tv - Tv'\|_\infty \le \gamma\|v - v'\|_\infty \qquad\forall v, v'. \] 또한 단조(monotone)이다. \[ v \le v' \;\Longrightarrow\; Tv \le Tv'. \] (부등식은 원소별, entry-wise)

11.1 축약성 증명

\(T^\pi\)와 같은 방식에서 max를 처리하는 한 단계가 추가된다.

보조 부등식: \[ \Big|\max_a f(a) - \max_a g(a)\Big| \le \max_a|f(a) - g(a)|. \] \(f(a) \le g(a) + |f(a)-g(a)| \le \max g + \max|f-g|\)에서 양변에 \(\max_a\)를 취하면 \(\max f - \max g \le \max|f-g|\). \(f, g\) 역할을 바꾸면 반대쪽도 나온다.

이를 쓰면 \[ |(Tv)(s) - (Tv')(s)| \le \max_a|q_v(s,a) - q_{v'}(s,a)| = \gamma\max_a\Big|\sum_{s'}p(s'|s,a)(v-v')(s')\Big| \le \gamma\|v - v'\|_\infty. \] 마지막 부등식은 가중평균 논법이다. \(s\)에 대해 최대를 취하면 끝. \(\blacksquare\)

11.2 단조성 증명

\(v \le v'\)이면 각 \((s,a)\)에서 \(p(s'|s,a) \ge 0\)이므로 \[ q_v(s,a) = r(s,a) + \gamma\sum_{s'}p(s'|s,a)\,v(s') \le r(s,a) + \gamma\sum_{s'}p(s'|s,a)\,v'(s') = q_{v'}(s,a). \] 양변에 \(\max_a\)를 취하면 \((Tv)(s) \le (Tv')(s)\). \(\blacksquare\)

같은 이유로 \(T^\pi\)도 단조이다 (\(P^\pi\)의 원소가 \(\ge 0\)).

12 Bellman 방정식: 해의 유일성과 최적성

\[ \text{연산자 형태: } v = Tv, \qquad \text{방정식 형태: } v(s) = \max_{a\in A}\Big[r(s,a) + \gamma\sum_{s'}p(s'|s,a)\,v(s')\Big]. \]

12.1 Q1) 왜 유일한 해를 가지는가

\(T\)가 γ-축약이므로 Banach 고정점 정리의 첫 번째 성질에 의해 유일한 고정점을 가진다. 따라서 \(v = Tv\)는 해를 정확히 하나 가진다.

12.2 Q2) 왜 그 해가 \(v^*\)인가

Banach 정리는 “유일한 고정점이 있다”까지만 말해 준다. 그것이 \(v^*\)임을 보이는 열쇠는 다음 명제이다.

Note명제
  • \(v \ge Tv\)이면 \(v \ge v^*\)
  • \(v \le Tv\)이면 \(v \le v^*\)

사용하는 사실:

  • (F1) 모든 \(\pi\)에 대해 \(Tv \ge R^\pi + \gamma P^\pi v\) (\(T\)는 \(\pi\)에 대한 최대)
  • (F2) \(P^\pi\)의 원소가 \(\ge 0\)이므로 \(x \le y \Rightarrow P^\pi x \le P^\pi y\) (부등식 방향 보존)

12.2.1 (a) \(v \ge Tv \Rightarrow v \ge v^*\)

임의의 \(\pi\)를 고정한다. (F1)로 \(v \ge Tv \ge R^\pi + \gamma P^\pi v\). 이를 재귀적으로 대입하면 (F2) 덕분에 방향이 유지되어 \[ v \ge R^\pi + \gamma P^\pi v \ge R^\pi + \gamma P^\pi(R^\pi + \gamma P^\pi v) \ge \cdots \ge \sum_{t=0}^{n-1}(\gamma P^\pi)^t R^\pi + (\gamma P^\pi)^n v. \] \(\|(\gamma P^\pi)^n v\|_\infty \le \gamma^n\|v\|_\infty \to 0\)이므로 \(n\to\infty\)에서 \[ v \ge \sum_{t=0}^{\infty}(\gamma P^\pi)^t R^\pi = v^\pi. \] 모든 \(\pi\)에 대해 성립하므로 양변을 \(\pi\)에 대해 최대화하면 \(v \ge v^*\).

12.2.2 (b) \(v \le Tv \Rightarrow v \le v^*\)

“반대 방향도 같은 방식”이지만 한 가지 주의가 필요하다. 임의의 \(\pi\)를 쓰면 \(v \le Tv\)와 \(Tv \ge R^\pi + \gamma P^\pi v\)를 합쳐도 \(v\)와 \(R^\pi + \gamma P^\pi v\)의 관계가 정해지지 않는다. 대신 \(Tv\)를 달성하는 정책을 쓴다.

\(v\)에 대한 greedy 정책 \(\pi_g(s) \in\arg\max_a q_v(s,a)\)를 잡으면 \(Tv = T^{\pi_g}v = R^{\pi_g} + \gamma P^{\pi_g}v\). 따라서 \(v \le R^{\pi_g} + \gamma P^{\pi_g}v\)이고, (a)와 같은 반복 대입으로 \[ v \le \sum_{t=0}^{n-1}(\gamma P^{\pi_g})^t R^{\pi_g} + (\gamma P^{\pi_g})^n v \xrightarrow{n\to\infty} v^{\pi_g} \le v^*. \qquad\blacksquare \]

보이는 것 쓰는 정책
(a) 모든 정책이 \(v\) 이하 임의의 \(\pi\)
(b) 어떤 정책이 \(v\) 이상 greedy 정책 \(\pi_g\)

12.2.3 결론

고정점 \(\bar v = T\bar v\)는 \(\bar v \ge T\bar v\)와 \(\bar v \le T\bar v\)를 동시에 만족하므로 \(\bar v \ge v^*\)이고 \(\bar v \le v^*\), 즉 \(\bar v = v^*\).

Important정리

Bellman 방정식은 유일한 해를 가지며, 그 해는 최적 가치 함수와 일치한다. \[ v^* = Tv^*. \] 이는 최적 제어와 강화학습의 근간이 되는 정리이다.

직관

  • 유일성: \(T\)는 두 후보의 거리를 줄이므로, 두 해가 있으면 거리가 0이 되어 같아진다.
  • 최적성: \(v \ge Tv\)는 “한 스텝 개선해도 \(v\)를 못 넘는다”, 즉 \(v\)는 달성 가능한 값의 상한이다. \(v \le Tv\)는 “\(v\)는 실제로 달성 가능한 값의 하한”이다. 둘이 만나는 곳이 \(v^*\)이다.

13 Value iteration

Note알고리즘 (Value iteration)
  • 초기화: \(v_0 \in\mathbb{R}^n\) 임의
  • 수렴할 때까지 반복: \(v_{k+1} := Tv_k\)

그러면 \(v_k \to v^*\).

  • 정책 평가용 알고리즘과 템플릿이 같다. 유일한 차이는 \(T^\pi\) 대신 \(T\)를 적용한다는 것이다.
  • 숨은 복잡도: 매 \(k\), 모든 \(s\)에 대해 \[ v_{k+1}(s) = \max_a\Big[r(s,a) + \gamma\sum_{s'}p(s'|s,a)\,v_k(s')\Big] \] 를 풀어야 한다. 정책 평가에 비해 행동 최대화라는 추가 복잡도가 있다(상태별로 병렬화는 가능).
  • 행동 최대화를 하기 때문에 dynamic programming이 제대로 작동하고 최적 가치로 수렴한다.

13.1 Finite horizon과의 차이

Finite horizon Infinite horizon
시작점 종단 조건 \(v_T^* = r_T\)로 고정 어디서든 시작 가능 (임의의 \(v_0\))
반복 횟수 정확히 \(T\)번 (\(T-1 \to 0\)) 미리 정해지지 않음, 수렴할 때까지
결정 규칙 시점마다 다름 하나의 stationary 규칙

13.2 반복 횟수는 무엇에 의존하는가

초기화에 의존한다. 우연히 \(v_0\)를 \(v^*\) 근처로 잡았다면 매우 적은 반복으로 수렴하고, 멀리 잡았다면 많은 반복이 필요하다 (\(\|v_k - v^*\|_\infty \le \gamma^k\|v_0 - v^*\|_\infty\)).

그러나 최적 가치 함수의 모양(shape)은 직관적으로 알기 매우 어렵다. 강화학습이 느리게 발전했던 이유 중 하나이다. 그래서 보통 영벡터, 누적 보상의 대략적 추정치, 또는 그냥 임의의 벡터로 초기화한다.

14 최적 정책의 존재와 구성

Important정리

\(S\)와 \(A\)가 유한 집합이면 최적 정책이 존재하며, 그중 deterministic하고 stationary한 것이 있다. 그런 최적 정책은 다음과 같이 얻는다. \[ \pi^*(s) \in\arg\max_{a\in A}\Big[r(s,a) + \gamma\sum_{s'}p(s'|s,a)\,v^*(s')\Big] \qquad\forall s\in S. \]

  • Deterministic보다 더 강력한 부분은 stationary하다는 것이다. 매 시간 같은 결정 규칙을 써도 된다. Infinite-horizon discounted 설정에서 stationary 정책에 집중해도 되는 이유를 이 정리가 설명한다.
  • 구성 방법: value iteration으로 \(v^*\)를 구한 뒤, Bellman 방정식이 말하는 그대로 즉각 보상 + 다음 상태 가치의 합을 최대화하는 행동을 정책 출력으로 할당한다. Finite horizon의 방식과 매우 유사하다.

14.1 증명

\[ T^{\pi^*}v^* = Tv^* = v^*. \]

  • 첫 번째 등호 (by construction): \(\pi^*\)는 대괄호 안을 최대화하는 행동을 담고 있으므로, \(T^{\pi^*}\)를 적용하는 것은 \(T\)를 적용하는 것과 같다. \[ (T^{\pi^*}v^*)(s) = q^*(s,\pi^*(s)) = \max_a q^*(s,a) = (Tv^*)(s). \]
  • 두 번째 등호: \(v^*\)는 \(T\)의 유일한 고정점.
  • 처음과 끝을 이으면 \(v^*\)는 \(T^{\pi^*}\)의 고정점이다. \(T^{\pi^*}\)도 축약이므로 유일한 고정점을 가지며, 그것은 정의상 \(v^{\pi^*}\)이다. 따라서 \[ v^* = v^{\pi^*}. \]
  • 어떤 정책의 정책 평가 결과가 최적 가치와 같다면, 그 정책은 최적이다. \(\blacksquare\)

(\(T^{\pi^*}\)는 정책 평가 연산자 \(T^\pi\)의 \(\pi\) 자리에 \(\pi^*\)를 넣은 것이고, \(T\)는 행동을 최대화하는 Bellman 연산자이다. 이 둘을 혼동하지 말 것.)

14.2 증명법: 구성적 증명 + 고정점 식별

“By construction”: 정의한 방식 때문에 그 성질이 자동으로 성립한다는 뜻이다. 대상을 만들 때 성질을 일부러 집어넣었으므로 따로 증명할 필요가 없다. 여기서는 “\(\pi^*\)를 argmax로 만들었다”가 첫 번째 등호의 근거이다.

  • 구성적 증명(constructive proof): “존재한다”를 보이기 위해 대상을 직접 만들어 보인다. 반대로 귀류법이나 compactness 논법은 대상을 손에 쥐지 않고 존재만 보인다. 구성적 증명이므로 “이렇게 구하면 된다”는 알고리즘까지 얻는다.
  • 고정점 식별: \(v^\pi\)는 \(T^\pi\)의 유일한 고정점이므로, 어떤 벡터가 \(T^\pi\)의 고정점임을 보이면 그 벡터가 곧 \(v^\pi\)이다.

14.3 짚어둘 점

  1. 유한성이 쓰이는 곳: argmax가 공집합이 아니어야 \(\pi^*\)를 만들 수 있다. \(A\)가 유한하면 max가 항상 달성된다. 연속 제어에서 “maximizer가 없으면 최적 정책이 존재하지 않을 수 있다”는 사실과 정확히 대응한다.
  2. 모든 상태에서 동시에 최적: \(v^*(s) = \max_\pi v^\pi(s)\)는 상태마다의 최댓값이므로 상태마다 최적 정책이 다를 수도 있다. 이 증명은 하나의 \(\pi^*\)가 모든 \(s\)에서 동시에 최적임을 보인다. 상태별 최대화가 서로 간섭하지 않기 때문이다.
  3. 순환 논증이 아닌 이유: \(\pi^*\)를 만들려면 \(v^*\)가 필요하고, \(v^*\)는 정의상 정책에 의존하는 것처럼 보인다. 그러나 \(v^*\)는 \(T\)의 고정점으로 정책 없이 먼저 확정되고, 그 위에서 \(\pi^*\)를 만든다.
  4. Bellman 방정식 Q2의 (b)에서 쓴 greedy 정책 \(\pi_g\)를 \(v = v^*\)에 대해 잡은 것이 바로 \(\pi^*\)이다.

15 Policy iteration

15.1 아이디어

Value iteration은 가치 공간(value space)에서만 정보를 업데이트해 최적 가치를 계산한 뒤에야 정책 공간으로 넘어간다. 궁극적 목표는 최적 정책인데, 정책 공간(policy space)의 정보도 활용할 수 없을까?

→ 가치 공간과 정책 공간의 정보를 번갈아(alternating) 활용해 가치와 정책을 동시에 최적으로 수렴시키는 방법이 policy iteration이다.

15.2 알고리즘

Note알고리즘 (Policy iteration)
  • 초기화: 임의의 deterministic stationary 정책 \(\pi_0\) (가치가 아니라 정책을 초기화)
  • 수렴할 때까지 반복:
    1. 정책 평가 (policy evaluation): 고정점 문제 \(v^{\pi_k} = T^{\pi_k}v^{\pi_k}\)를 풀어 \(v^{\pi_k}\)를 계산
    2. 정책 향상 (policy improvement): \[ \pi_{k+1}(s) \in\arg\max_{a\in A}\Big[r(s,a) + \gamma\sum_{s'}p(s'|s,a)\,v^{\pi_k}(s')\Big] \]

정책 향상 단계는 \(v^{\pi_k}\)가 마치 최적 가치인 것처럼 가정하고, 현재 보상 + 앞으로 \(\pi_k\)를 썼을 때의 누적 보상 기댓값을 최대화하는 행동을 새 정책으로 삼는다.

15.3 VI와 PI의 계산량 비교

행동 최대화가 있는 곳 반복 구조
VI 매 반복, 모든 상태 \(v_{k+1} = Tv_k\)
PI 정책 향상 단계에만 평가(안쪽 반복) + 향상
  • PI의 정책 평가도 고정점 반복을 쓰면 안쪽에 반복이 많이 들어가고, 매 정책마다 다시 해야 한다.
  • 그러나 정책 평가의 반복에는 행동 최대화가 없다. VI 한 스텝과 정책 평가 반복 한 스텝은 구조적으로 같아 보여도 계산량에 큰 차이가 있고, 정책 평가 쪽이 훨씬 빠르다.
  • 전체 복잡도는 사실상 비슷하며, 문제에 따라 어느 쪽이 빠를지 다르다. PI는 초기 정책이 최적 정책 근처인지, VI는 초기 가치가 최적 가치 근처인지에 따라 속도 차이가 크다.
  • 둘 다 최적 가치·최적 정책으로 수렴한다는 것이 강력한 이론적 결과이다.

16 단조 향상 보조정리

“π_{k+1}이 π_k보다 좋다”의 의미는 정책의 성능이 좋아진다는 것이고, 성능은 가치 함수로 측정한다.

Note보조정리 (Monotonic improvement)

Policy iteration으로 얻은 \(\{\pi_k\}\)에 대해 \[ v^{\pi_k} \le v^{\pi_{k+1}} \qquad\forall k. \]

증명은 두 단계이다.

  1. 한 스텝만 새 정책을 써도 낫다: \(v^{\pi_k} \le T^{\pi_{k+1}}v^{\pi_k}\)
  2. 그 이득을 무한 스텝으로 늘린다: \(v^{\pi_k} \le (T^{\pi_{k+1}})^\ell v^{\pi_k} \to v^{\pi_{k+1}}\)

16.1 Step 1: 세 관계식

\(v^{\pi_k}\)를 고정하고 \[ q(s,a) := r(s,a) + \gamma\sum_{s'}p(s'|s,a)\,v^{\pi_k}(s') \] (“첫 행동은 \(a\), 그 뒤로는 \(\pi_k\)를 계속 쓰면 얻는 값”)로 두면 세 식이 모두 \(q\)로 통일된다.

(a) 정책 평가 단계: \(v^{\pi_k}\)는 \(T^{\pi_k}\)의 고정점. \[ v^{\pi_k}(s) = (T^{\pi_k}v^{\pi_k})(s) = \sum_a\pi_k(a|s)\,q(s,a) \]

(b) 정책 향상 단계: \(\pi_{k+1}(s) \in\arg\max_a q(s,a)\)이므로 \[ (T^{\pi_{k+1}}v^{\pi_k})(s) = q(s,\pi_{k+1}(s)) = \max_a q(s,a) = (Tv^{\pi_k})(s). \]

(c) Bellman 연산자의 정의: 고정된 정책에 대한 출력을 정책에 대해 최대화한 것이 \(T\)이므로 (가중평균 ≤ 최댓값) \[ T^{\pi_k}v^{\pi_k} \le Tv^{\pi_k}. \]

결합: \[ v^{\pi_k} \overset{(a)}{=} T^{\pi_k}v^{\pi_k} \overset{(c)}{\le} Tv^{\pi_k} \overset{(b)}{=} T^{\pi_{k+1}}v^{\pi_k}. \]

직관: 왼쪽은 “처음부터 계속 \(\pi_k\)를 쓰는 값”, 오른쪽은 “첫 스텝만 \(\pi_{k+1}\), 그 뒤는 \(\pi_k\)를 쓰는 값”이다. 첫 스텝에서 평균 대신 최선의 행동을 고르니 값이 줄 수 없다.

16.2 (b)가 헷갈리는 이유

\(T^{\pi_{k+1}}v^{\pi_k}\) 안에는 서로 다른 두 대상이 있다.

  • 연산자의 정책: \(\pi_{k+1}\)
  • 입력 벡터: \(v^{\pi_k}\) (\(v^{\pi_{k+1}}\)이 아님)

\(\pi_{k+1}\)은 \(v^{\pi_k}\)를 최적 가치인 것처럼 생각하고 Bellman 방정식의 우변에서 끄집어낸 정책, 즉 \(Tv^{\pi_k}\)의 argmax이다. 그래서 \(T^{\pi_{k+1}}\)에 \(v^{\pi_k}\)를 넣으면 매 상태에서 argmax 행동이 선택되어 \(Tv^{\pi_k}\)가 나온다.

Warning주의

(b)는 입력이 \(v^{\pi_k}\)일 때만 등식이다. 다른 벡터 \(w\)를 넣으면 \(T^{\pi_{k+1}}w \le Tw\)만 보장된다. 반대로 (c)는 일반 부등식 \(T^{\pi'}w \le Tw\)에서 \(\pi' = \pi_k\), \(w = v^{\pi_k}\)인 경우이다.

16.3 Step 2: 한 스텝에서 무한 스텝으로

\(u := v^{\pi_k}\), \(T' := T^{\pi_{k+1}}\)이라 하면 \(u \le T'u\). \(T'\)는 단조이므로 양변에 \(T'\)를 적용해도 방향이 유지된다. \[ u \le T'u \le T'^2 u \le \cdots \le T'^\ell u \qquad\forall\ell. \] \(T'\)는 γ-축약이므로 \(T'^\ell u \to v^{\pi_{k+1}}\) (Banach). 부등식은 극한에서도 유지되므로 \[ v^{\pi_k} \le \lim_{\ell\to\infty}(T^{\pi_{k+1}})^\ell v^{\pi_k} = v^{\pi_{k+1}}. \qquad\blacksquare \]

단계 내용 근거
(a) \(v^{\pi_k} = T^{\pi_k}v^{\pi_k}\) \(T^{\pi_k}\)의 고정점
(c) \(T^{\pi_k}v^{\pi_k} \le Tv^{\pi_k}\) 평균 ≤ 최댓값
(b) \(Tv^{\pi_k} = T^{\pi_{k+1}}v^{\pi_k}\) \(\pi_{k+1}\)이 \(v^{\pi_k}\)에 대한 argmax
사슬 \(v^{\pi_k} \le T'^\ell v^{\pi_k}\) \(T'\)의 단조성
극한 \(\to v^{\pi_{k+1}}\) \(T'\)의 축약성

17 Policy iteration의 수렴

17.1 단조 수렴 정리

Note정리 (Monotone convergence theorem)

\(\{x_k\}\)가 단조 비감소(monotonically non-decreasing)이고 유계(bounded)인 실수 벡터 수열이면 유한한 극한을 가진다.

17.2 수렴 정리와 증명

Important정리

Policy iteration으로 얻은 \(\{\pi_k\}\)는 최적 정책으로 수렴한다: \(\pi_k \to \pi^*\).

증명

  1. \(S, A\) 유한 → \(|r(s,a)| \le M\) → \(|v^\pi(s)| \le \frac{M}{1-\gamma}\). 가치는 유계이다.
  2. 단조 향상 보조정리 → \(v^{\pi_k} \le v^{\pi_{k+1}}\).
  3. 단조 수렴 정리 → \(\lim_{k\to\infty}v^{\pi_k} = \bar v\)가 존재한다.
  4. 정책 향상: \(\bar v\)로 향상한 정책을 \(\bar\pi\)라 하자. \[ \bar\pi(s) \in\arg\max_a\Big[r(s,a) + \gamma\sum_{s'}p(s'|s,a)\,\bar v(s')\Big]. \]
  5. 정책 평가: \[ v^{\bar\pi} = T^{\bar\pi}\bar v = T^{\bar\pi}v^{\bar\pi} = Tv^{\bar\pi}. \] \(v^{\bar\pi}\)가 \(T^{\bar\pi}\)의 고정점이라는 것과, \(\bar\pi\)가 greedy 정책이라 \(T^{\bar\pi}\) 적용이 \(T\) 적용과 같아진다는 것을 쓴다.
  6. 맨 왼쪽과 맨 오른쪽을 이으면 \(v^{\bar\pi} = Tv^{\bar\pi}\). Bellman 연산자의 고정점은 \(v^*\)로 유일하므로 \(v^{\bar\pi} = v^*\), 즉 \(\bar\pi\)는 최적 정책이다. \(\blacksquare\)

17.3 보충: 위 사슬의 빈틈과 엄밀한 마무리

5번의 사슬은 \(\bar v = v^{\bar\pi}\)를 암묵적으로 사용한다. 이는 유한성으로 메울 수 있다.

  • 유한 MDP에서 deterministic stationary 정책은 \(|A|^{|S|}\)개로 유한하다. 따라서 \(\{v^{\pi_k}\}\)는 유한 집합에서 값을 취한다.
  • 유한 집합에서 값을 취하는 단조 비감소 수열은 유한 번 이후 상수가 된다. 즉 어떤 \(K\)가 있어 \(v^{\pi_{K+1}} = v^{\pi_K}\).
  • 그러면 \[ v^{\pi_K} = v^{\pi_{K+1}} = T^{\pi_{K+1}}v^{\pi_{K+1}} = T^{\pi_{K+1}}v^{\pi_K} \overset{(b)}{=} Tv^{\pi_K}. \]
  • 따라서 \(v^{\pi_K}\)는 \(T\)의 고정점이고 \(v^{\pi_K} = v^*\). 이때 \(\pi_{K+1}\)은 \(v^*\)에 대한 greedy 정책이므로 최적 정책이다.

즉 PI는 유한 번 안에 최적 가치에 도달하고, 정책이 더 이상 바뀌지 않는 지점(\(\pi_{k+1} = \pi_k\))에서 \(\bar v = v^{\pi_k} = v^{\bar\pi}\)가 성립한다. (동점인 행동이 있으면 현재 행동을 유지하는 tie-breaking을 쓰면 정책 자체도 멈춘다.)

18 수치 예시: VI와 PI 비교

상태 \(\{1,2\}\), 행동 \(\{a,b\}\), \(\gamma = 0.9\).

  • 행동 \(a\): 현재 상태에 머문다. 행동 \(b\): 상태를 바꾼다.
  • 보상: \(r(2,a) = 1\), 나머지는 0.

최적 해: 상태 2에서 \(a\)를 계속 쓰면 \(v^*(2) = \frac{1}{1-0.9} = 10\), 상태 1에서는 \(b\)로 상태 2로 가서 \(v^*(1) = 0 + 0.9\times 10 = 9\). 즉 \(v^* = (9, 10)\), \(\pi^* = (b, a)\).

18.1 Policy iteration (\(\pi_0 = (a, b)\))

\(k\) \(\pi_k\) \(v^{\pi_k}\) \(q(1,a),\ q(1,b)\) \(q(2,a),\ q(2,b)\) \(\pi_{k+1}\)
0 \((a,b)\) \((0, 0)\) \(0,\ 0\) \(1,\ 0\) \((a, a)\) (동점은 유지)
1 \((a,a)\) \((0, 10)\) \(0,\ 9\) \(10,\ 0\) \((b, a)\)
2 \((b,a)\) \((9, 10)\) \(8.1,\ 9\) \(10,\ 8.1\) \((b, a)\) → 정지
  • \(v^{\pi_0} = (0,0) \le v^{\pi_1} = (0,10) \le v^{\pi_2} = (9,10) = v^*\): 단조 향상 확인.
  • \(k=0\)에서 \(T^{\pi_1}\)을 반복하면 \((0,0) \le (0,1) \le (0,1.9) \le (0,2.71) \le \cdots \to (0,10)\). 한 스텝 이득(\(0\to1\))이 쌓여 전체 이득(\(0\to10\))이 된다.

18.2 Value iteration (\(v_0 = (0,0)\))

\[ v_1 = (0, 1),\quad v_2 = (0.9, 1.9),\quad v_3 = (1.71, 2.71),\quad \dots \to (9, 10) \]

\(\|v_k - v^*\|_\infty \le 0.9^k\times 10\)이므로 오차가 지수적으로 줄지만, 이 예에서는 PI가 3번의 평가로 정확한 답에 도달한 반면 VI는 많은 반복이 필요하다.

TipQ) 둘 중 무엇을 써야 하나?

정답은 없다. 둘 다 써 봐야 안다. 초기화가 얼마나 좋은지에 따라 성능 차이가 크다. VI가 우연히 \(v^*\) 근처에서 초기화되면 몇 번 만에 수렴하고, PI가 우연히 \(\pi^*\) 근처에서 초기화되면 PI도 빨리 수렴한다. 그러나 최적 가치나 최적 정책의 모양을 미리 알 수 없으므로 초기화를 잘하기 어렵다.

20 강화학습 알고리즘과의 연결

두 알고리즘은 대부분의 RL 알고리즘의 뼈대이다.

계열 사용하는 것 예시 뿌리
Value-based 가치만 Q-learning, DQN Value iteration
Actor-critic 가치 + 정책 actor-critic, DDPG, SAC Policy iteration
Policy-based 정책만 Policy gradient —
  • Actor-critic에서 actor는 policy improvement, critic은 policy evaluation 역할을 한다. Actor-critic은 policy iteration을 model-free화한 것으로 볼 수 있다(디테일과 기법에는 차이가 있다).
TipQ) 왜 VI나 PI를 RL에 바로 적용할 수 없는가?

VI와 PI는 모델 정보, 즉 전이 확률 \(p(s'|s,a)\)를 완벽히 안다고 가정한다. RL에서는 시행착오(trial and error)로 상태·보상 샘플만 얻을 뿐 전이 확률을 직접 알지 못한다. 그래서 이들을 model-free 방식으로 바꾼 것이 VI → Q-learning, PI → actor-critic이다.
