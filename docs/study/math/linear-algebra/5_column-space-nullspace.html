Column Space and Nullspace

Where they live, what they collect, and how they connect

Published

November 8, 2026

1 Subspaces

A subspace of a vector space is a nonempty subset that stays inside itself under linear combinations:

  1. if \(x\) and \(y\) are in the subspace, so is \(x+y\);

  2. if \(x\) is in the subspace and \(c\) is any scalar, so is \(cx\).

Choosing \(c=0\) in (ii) shows that every subspace contains the zero vector. That gives the fastest test for failure: if \(0\) is missing, the set is not a subspace.

1.1 The smallest subspace is not the empty set

Set Subspace?
\(Z=\{0\}\), the one-point space yes, the smallest possible
\(\varnothing\), the empty set no, because a subspace must be nonempty

These are different objects. For example, two distinct parallel planes have an empty intersection, not the zero vector.

1.2 Typical failures in \(\mathbb{R}^3\)

  • Missing zero. The plane \(b_1 = 1\) does not contain \(0\).
  • Shifted plane. \(P: x+2y+z=6\) is not a subspace. \((6,0,0)\) and \((0,3,0)\) lie in \(P\), but their sum \((6,3,0)\) gives \(6+6=12\neq 6\). The parallel plane through the origin, \(P_0: x+2y+z=0\), is a subspace.
  • Union of subspaces. The set \(b_2b_3=0\) is the union of the planes \(b_2=0\) and \(b_3=0\). It contains \((0,1,0)\) and \((0,0,1)\) but not their sum \((0,1,1)\).

Planes through the origin, lines through the origin, \(Z\), and \(\mathbb{R}^3\) itself are the only subspaces of \(\mathbb{R}^3\).

1.3 \(\mathbb{R}^2\) is not a subspace of \(\mathbb{R}^3\)

The reason is not that the dimensions differ. A plane through the origin in \(\mathbb{R}^3\) is two-dimensional and is still a subspace of \(\mathbb{R}^3\).

The real reason comes before any closure test. A subspace must first be a subset. A vector \((x,y)\in\mathbb{R}^2\) has two components, so it is not an element of \(\mathbb{R}^3\) at all:

\[ \mathbb{R}^2 \not\subseteq \mathbb{R}^3. \]

The plane \(\{(x,y,0)\}\) looks like \(\mathbb{R}^2\) and is a subspace of \(\mathbb{R}^3\), but it is a different set.

1.4 Subspaces of matrix spaces

The “vectors” can be matrices. Let \(M\) be the space of all \(3\times 3\) matrices.

Skew-symmetric matrices (\(A^T=-A\)) form a subspace:

\[ (A+B)^T = A^T + B^T = -(A+B),\qquad (cA)^T = -(cA). \]

The diagonal entries are forced to zero (\(a_{ii}=-a_{ii}\)). The off-diagonal entries only come in pairs \(a_{ji}=-a_{ij}\):

\[ A=\begin{bmatrix}0&a&b\\-a&0&c\\-b&-c&0\end{bmatrix}. \]

Three free numbers \(a,b,c\) describe the whole subspace, but it is a subspace of \(M\), not \(\mathbb{R}^3\) itself.

Unsymmetric matrices (\(A^T\neq A\)) do not form a subspace. The zero matrix is symmetric, so \(0\) is missing. Also, if \(A\) is unsymmetric then so is \(A^T\), yet \(A+A^T\) is symmetric.

Matrices sharing a fixed null vector. For any fixed \(v\),

\[ S_v = \{A\in M : Av = 0\} \]

is a subspace, since \(Av=Bv=0\) implies \((A+B)v=0\) and \((cA)v=0\). The proof never uses the entries of \(v\). For \(v=0\) it gives all of \(M\). For several fixed vectors, \(S_{v_1}\cap\cdots\cap S_{v_k}\) is again a subspace, since an intersection of subspaces is a subspace.

The word fixed matters. “Has some nonzero null vector” means “singular”, and singular matrices do not form a subspace:

\[ \begin{bmatrix}1&0\\0&0\end{bmatrix}+\begin{bmatrix}0&0\\0&1\end{bmatrix}=I. \]

Each summand is singular, but with a different null vector, \((0,1)\) and \((1,0)\), and the sum is invertible. The test for a subspace is closure, not a shared property such as “singular”.

2 The Column Space

For an \(m\times n\) matrix \(A=[\,a_1\ \cdots\ a_n\,]\),

\[ Ax = x_1a_1 + x_2a_2 + \cdots + x_na_n . \]

The column space \(C(A)\) is the set of all linear combinations of the columns:

\[ C(A) = \{Ax : x\in\mathbb{R}^n\}. \]

Reading \(Ax=b\) by columns gives the central fact:

\(Ax=b\) is solvable \(\iff\) \(b\) is a combination of the columns \(\iff\) \(b\in C(A)\).

\(C(A)\) is a subspace. If \(Ax=b\) and \(Ax'=b'\), then \(A(x+x')=b+b'\) and \(A(cx)=cb\).

2.1 Two descriptions of the same subspace

A subspace can be described by generators (what spans it) or by constraints (which equations its vectors satisfy).

\[ A=\begin{bmatrix}1&4\\2&9\\-1&-4\end{bmatrix}:\qquad (4,9,-4) - 4(1,2,-1) = (0,1,0). \]

  • Generators: \(b = \alpha(1,2,-1)+\beta(0,1,0)\).
  • Constraint: \(b_1 + b_3 = 0\).

Both generators satisfy the constraint. A plane in \(\mathbb{R}^3\) needs one constraint, and a line needs two. For example, if every column is a multiple of \((1,2,-1)\), then

\[ C(A)=\{c(1,2,-1)\} = \{\,b : b_2 = 2b_1,\ b_3=-b_1\,\}. \]

“For which \(b\) is \(Ax=b\) solvable?” asks for the constraint form.

2.2 Adding a column

Appending a column \(b\) enlarges the column space unless \(b\) is already in \(C(A)\). Moreover,

\[ Ax=b \text{ solvable} \iff b\in C(A) \iff C([\,A\ \ b\,]) = C(A). \]

  • (\(\Rightarrow\)) If \(b\in C(A)\), then in any combination of the columns of \([\,A\ b\,]\) the vector \(b\) can be rewritten as a combination of the \(a_j\), so nothing new appears.
  • (\(\Leftarrow\)) If \(C([\,A\ b\,]) = C(A)\), then \(b\), being a column of \([\,A\ b\,]\), lies in \(C(A)\).

\[ \begin{bmatrix}1&0\\0&1\\0&0\end{bmatrix} \;\xrightarrow{\text{add }(0,0,1)}\; \text{larger: } \mathbb{R}^3, \qquad \xrightarrow{\text{add }(1,1,0)}\; \text{unchanged: the plane } b_3=0. \]

2.3 Column space of a product

Each column of \(AB\) is \(A\) times a column of \(B\), which is a combination of the columns of \(A\). Hence

\[ C(AB)\subseteq C(A). \]

Equality can fail. With \(A=I\) and \(B=\begin{bmatrix}1&0\\0&0\end{bmatrix}\), \(C(A)=\mathbb{R}^2\) but \(C(AB)\) is only the \(x\)-axis.

2.4 Quick facts

Statement Verdict Reason
The \(b\)’s not in \(C(A)\) form a subspace false \(0\in C(A)\), so \(0\) is missing
\(C(A)=\{0\}\) \(\Rightarrow\) \(A=0\) true a nonzero entry makes its column a nonzero vector in \(C(A)\)
\(C(2A)=C(A)\) true \((2A)x = A(2x)\)
\(C(A-I)=C(A)\) false \(A=I\): \(C(I)=\mathbb{R}^n\), \(C(0)=\{0\}\)
\(n\times n\) invertible \(\Rightarrow C(A)=\mathbb{R}^n\) true \(Ax=b\) is solvable for every \(b\)

3 The Nullspace

The nullspace of \(A\) is the set of solutions to \(Ax=0\):

\[ N(A) = \{x\in\mathbb{R}^n : Ax=0\}. \]

It is a subspace, since \(Ax=Ax'=0\) gives \(A(x+x')=0\) and \(A(cx)=0\). Both requirements fail when the right-hand side is not zero: the solutions of \(Ax=b\) with \(b\neq0\) never include \(x=0\). Only homogeneous equations produce subspaces, which is exactly why \(P\) fails and \(P_0\) succeeds.

A nonzero \(x\in N(A)\) is a linear relation among the columns:

\[ x_1a_1+\cdots+x_na_n = 0. \]

4 Why \(C(A)\subseteq\mathbb{R}^m\) but \(N(A)\subseteq\mathbb{R}^n\)

The host space is decided by how many components each vector has, not by how many vectors there are.

For \(A\) of size \(m\times n\) (\(m\) rows, \(n\) columns),

\[ \underbrace{A}_{m\times n}\;\underbrace{x}_{n\times 1} = \underbrace{b}_{m\times 1}. \]

  • \(x\) must have one component per column, so \(x\in\mathbb{R}^n\). It is the list of coefficients that multiply the \(n\) columns.
  • \(Ax\) has one component per row, so \(Ax\in\mathbb{R}^m\).

The two subspaces collect different things:

\[ N(A)=\{x : Ax=0\}\ \text{collects inputs } x \;\Rightarrow\; N(A)\subseteq\mathbb{R}^n, \qquad C(A)=\{Ax\}\ \text{collects outputs } b \;\Rightarrow\; C(A)\subseteq\mathbb{R}^m. \]

There are \(n\) columns, but each column has length \(m\). The length decides where \(C(A)\) lives; \(n\) only counts the generators.

Read as a linear system: \(m\) is the number of equations and \(n\) the number of unknowns. \(N(A)\) gathers values of the unknowns, and \(C(A)\) gathers right-hand sides.

4.1 Tall and wide examples

\[ A=\begin{bmatrix}1&0\\5&4\\2&4\end{bmatrix}\ (3\times2):\qquad \begin{bmatrix}1&0\\5&4\\2&4\end{bmatrix}\begin{bmatrix}u\\v\end{bmatrix} = u\begin{bmatrix}1\\5\\2\end{bmatrix}+v\begin{bmatrix}0\\4\\4\end{bmatrix}. \]

  • \(C(A)\subseteq\mathbb{R}^3\) is the plane spanned by the two columns.
  • \(N(A)\subseteq\mathbb{R}^2\). The first equation gives \(u=0\), then the second gives \(v=0\), so \(N(A)=\{(0,0)\}\).

\[ B=\begin{bmatrix}0&0&3\\1&2&3\end{bmatrix}\ (2\times3): \]

  • \(C(B)=\mathbb{R}^2\), because \((0,1)\) and \((3,3)\) already span the plane.
  • \(N(B)\subseteq\mathbb{R}^3\): \(3x_3=0\) and \(x_1+2x_2+3x_3=0\) give \(N(B)=\{c(-2,1,0)\}\), a line.

For the \(2\times3\) zero matrix, \(C=\{(0,0)\}=Z\subseteq\mathbb{R}^2\) and \(N=\mathbb{R}^3\).

A \(9\times12\) system that is solvable for every \(b\) has \(C(A)=\mathbb{R}^9\), because \(b\) has \(9\) components. The \(12\) belongs to \(x\).

4.2 Square matrices: the same \(\mathbb{R}^n\), different roles

When \(m=n\), both subspaces sit in \(\mathbb{R}^n\). Numerically it is the same space, but one subspace collects inputs and the other outputs, so no containment between them should be expected.

\[ A=\begin{bmatrix}1&-1\\0&0\end{bmatrix}:\qquad C(A)=\{(t,0)\}\ (x\text{-axis}),\qquad N(A)=\{c(1,1)\}. \]

Both are lines in \(\mathbb{R}^2\), but different lines. An element of \(C(A)\) is a vector \((x_1-x_2,\,0)\), not the scalar \(x_1-x_2\).

Keep the input side and the output side apart even when \(m=n\).

5 How the Two Subspaces Connect

Both subspaces look at the same equation \(Ax=b\) from opposite ends.

\(C(A)\) \(N(A)\)
lives in \(\mathbb{R}^m\) (right-hand sides) \(\mathbb{R}^n\) (unknowns)
collects attainable \(b\) solutions \(x\) of \(Ax=0\)
answers is \(Ax=b\) solvable? which \(x\) are sent to \(0\)?

The link is redundancy among the columns. Add a third column that is the sum of the first two:

\[ B=\begin{bmatrix}1&0&1\\5&4&9\\2&4&6\end{bmatrix},\qquad a_3=a_1+a_2. \]

  • \(C(B)=C(A)\): an extra column, but the same plane.
  • \(N(B)\) grows from \(\{0\}\) to the line \(\{c(1,1,-1)\}\), since \(1\cdot a_1+1\cdot a_2-1\cdot a_3=0\).

A column that does not enlarge \(C\) shows up as a nonzero vector in \(N\).

\(B\) is square, yet \((1,1,-1)\in N(B)\) is not in \(C(B)\). Solving \(u(1,5,2)+v(0,4,4)=(1,1,-1)\) forces \(u=1\), \(v=-1\), and then the third component is \(2-4=-2\neq-1\).

rank A = 2 -> N(A) = {0}: True
B (1,1,-1) = [0 0 0]
C(B) == C(A): True
(1,1,-1) in C(B): False
W (-2,1,0) = [0 0] | rank W = 2 -> C(W) = R^2
columns of T satisfy b1 + b3 = 0: [0 0]
