1 정규화의 큰 그림

1.1 한 줄 요약

정규화(Regularization)란 “훈련 오차를 늘리더라도 일반화 오차(generalization error)를 줄이려는 모든 수정”을 말한다. 본질적으로는 모델에 귀납적 편향(inductive bias), 즉 “데이터만으로는 결정할 수 없는 부분에 대한 우리의 사전 믿음”을 주입하는 행위다.

1.2 왜 필요한가: 편향-분산 분해

유한한 데이터 \(\mathcal{D}=\{(\bm{x}_i,y_i)\}_{i=1}^N\) 로 학습한 추정량 \(\hat{f}_\mathcal{D}\) 의 기대 제곱 오차는 다음처럼 분해된다.

\[ \underbrace{\mathbb{E}_{\mathcal{D}}\!\left[(\hat{f}_\mathcal{D}(\bm{x}) - f^*(\bm{x}))^2\right]}_{\text{기대 오차}} = \underbrace{\left(\mathbb{E}_\mathcal{D}[\hat{f}_\mathcal{D}(\bm{x})] - f^*(\bm{x})\right)^2}_{\text{Bias}^2} + \underbrace{\mathbb{E}_\mathcal{D}\!\left[(\hat{f}_\mathcal{D}(\bm{x}) - \mathbb{E}_\mathcal{D}[\hat{f}_\mathcal{D}(\bm{x})])^2\right]}_{\text{Variance}} \tag{1}\]

심층 신경망은 표현력(capacity)이 커서 분산이 지배적인 영역에서 동작하기 쉽다. 정규화는 약간의 편향을 받아들이는 대신 분산을 크게 깎아 식 1 의 총합을 낮춘다.

Note통계적 추론 관점

정규화는 ill-posed 역문제(inverse problem)를 well-posed로 바꾸는 작업과 동형이다. 무선통신에서 안테나 수보다 추정해야 할 경로(path)가 많을 때(under-determined), 채널이 희소(sparse)하다는 사전지식을 \(\ell_1\) 페널티로 넣어 해를 유일하게 만드는 것 — 이것이 바로 compressed sensing이며, 정규화의 전형적 사례다.

1.3 정규화의 세 가지 형식

학습 목적함수는 보편적으로 다음 형태를 갖는다.

\[ \min_{\bm{\theta}} \; \underbrace{L(\bm{\theta};\mathcal{D})}_{\text{Loss: 최적화 대상}} + \underbrace{\Omega(\bm{\theta})}_{\text{Regularizer: 귀납적 편향}} \tag{2}\]

손쉽게 만든(hand-crafted) 정규화는 세 가지 관점으로 통일된다.

형식 정의 대표 예
Hard constraint \(\min_{\bm{\theta}} L(\bm{\theta})\) s.t. \(R(\bm{\theta}) \le c\) 가중치 노름 상한 제약
Soft constraint \(\min_{\bm{\theta}} L(\bm{\theta}) + \lambda R(\bm{\theta})\) \(\ell_2\) weight decay, \(\ell_1\)
Bayesian prior 사후확률 최대화(MAP) prior \(p(\bm{\theta})\) 도입

1.3.1 Hard constraint와 Soft constraint의 등가성

하드 제약 문제

\[ \bm{\theta}^* = \arg\min_{\bm{\theta}} L(\bm{\theta}) \quad \text{s.t.}\quad R(\bm{\theta}) \le c \]

의 KKT 조건을 쓰면, 어떤 \(\lambda^* > 0\) 에 대해

\[ \bm{\theta}^* = \arg\min_{\bm{\theta}} \; L(\bm{\theta}) + \lambda^*\big(R(\bm{\theta}) - c\big) \]

가 성립한다. 상수 \(-\lambda^* c\) 는 \(\bm{\theta}\) 에 무관하므로 제거되고, 결국 하드 제약 = 소프트 제약이 된다. \(c\) 가 작을수록(강한 제약) 대응하는 \(\lambda^*\) 는 커진다.

1.3.2 Bayesian prior로서의 정규화: MAP = MLE + log prior

베이즈 정리

\[ p(\bm{\theta}\mid\mathcal{D}) = \frac{p(\bm{\theta})\,p(\mathcal{D}\mid\bm{\theta})}{p(\mathcal{D})} \]

에서 사후확률을 최대화(MAP)하면, \(p(\mathcal{D})\) 는 \(\bm{\theta}\) 와 무관하므로

\[ \bm{\theta}_{\text{MAP}} = \arg\max_{\bm{\theta}} \underbrace{\log p(\mathcal{D}\mid\bm{\theta})}_{\text{MLE loss}} + \underbrace{\log p(\bm{\theta})}_{\text{Regularizer}} \tag{3}\]

Important정확한 진술 (자주 틀리는 부분)
  • MAP = MLE + log-prior 정규화항. MLE는 prior를 “무시”하는 것이 아니라 균일 사전분포(uniform prior)를 가정한 MAP의 특수경우다.
  • \(\ell_2\) 정규화 \(\Leftrightarrow\) 가우시안 prior \(p(\bm{\theta})=\mathcal{N}(\bm{0},\sigma^2 I)\) 의 MAP.
  • \(\ell_1\) 정규화 \(\Leftrightarrow\) 라플라스(Laplace) prior의 MAP \(\to\) 희소성(sparsity) 유도.
  • \(\ell_0\) 페널티는 비영(non-zero) 원소 개수를 직접 세므로 희소성을 강제하지만 비볼록·NP-hard.

이제 이 틀 위에서, 심층학습에서 실제로 널리 쓰이는 9가지 정규화 기법을 하나씩 본다. 각 기법이 식 2 의 어느 항을 어떻게 건드리는지에 주목하라.

2 Dataset Augmentation

2.1 핵심

레이블을 보존하는 변환(label-preserving transformation)으로 훈련 데이터를 인위적으로 늘려, 모델이 그 변환에 대해 불변(invariant)하도록 만든다. “더 많은 진짜 데이터를 못 구한다면, 가짜를 합성하라.”

2.2 형식화

변환 분포 \(T(\cdot\mid\bm{x})\) (예: 회전, 이동, 색 변형)에 대해 손실을 변환된 입력의 기댓값으로 바꾼다.

\[ \tilde{L}(\bm{\theta}) = \mathbb{E}_{(\bm{x},y)\sim\mathcal{D}}\;\mathbb{E}_{\tilde{\bm{x}}\sim T(\cdot\mid\bm{x})}\big[\ell\big(f_{\bm{\theta}}(\tilde{\bm{x}}),\,y\big)\big] \tag{4}\]

이는 데이터 분포를 변환 궤도(orbit)를 따라 “퍼뜨려” 결정 경계를 매끄럽게 만드는 효과를 준다.

Tip노이즈 주입 = \(\ell_2\) 정규화 (소량 가우시안의 경우)

입력에 작은 가우시안 노이즈 \(\tilde{\bm{x}}=\bm{x}+\bm{\epsilon},\ \bm{\epsilon}\sim\mathcal{N}(\bm{0},\sigma^2 I)\) 를 더하고 회귀 손실을 2차 테일러 전개하면, 그 기댓값은 대략

\[ \mathbb{E}_{\bm{\epsilon}}[\ell] \approx \ell(\bm{x}) + \tfrac{\sigma^2}{2}\,\mathbb{E}\big[\|\nabla_{\bm{x}} f(\bm{x})\|^2\big] \]

가 되어, 자코비안 노름에 대한 페널티(함수의 평탄성 유도)로 작동한다. 즉 데이터 증강은 암묵적 정규화항을 추가하는 것과 같다.

2.3 직관과 주의점

  • 변환은 반드시 레이블 불변이어야 한다. 손글씨 ’6’을 180° 회전하면 ’9’가 되므로 회전 증강은 위험하다.
  • 도메인 지식이 곧 좋은 증강을 결정한다 — 이것이 증강을 “수작업 귀납 편향”이라 부르는 이유다.
Note무선통신 비유

이퀄라이저/수신기를 여러 채널 실현(channel realization)에 대해 훈련하는 것과 동일하다. 페이딩 채널을 Monte-Carlo로 샘플링해 다양한 \(\bm{h}\) 하에서 학습시키면, 수신기가 특정 채널에 과적합하지 않고 채널 분포 전체에 강인해진다. 식 식 4 의 \(T\) 가 곧 채널 분포 \(p(\bm{h})\) 다.

3 Adversarial Examples

3.1 핵심

사람 눈엔 거의 동일하지만 모델을 속이는 미세 섭동(adversarial perturbation)을 일부러 만들어 함께 학습시킨다. 주목적은 보안(robustness)이지만, 결정 경계를 입력 변화에 둔감하게 만들어 일반화에도 도움을 준다.

3.2 적대적 예제 생성: FGSM

손실 \(J(\bm{\theta},\bm{x},y)\) 를 입력에 대해 1차 선형화하면, \(\ell_\infty\) 제약 하에서 손실을 가장 키우는 섭동은 그래디언트의 부호다 (Fast Gradient Sign Method).

\[ \bm{x}_{\text{adv}} = \bm{x} + \epsilon \cdot \mathrm{sign}\big(\nabla_{\bm{x}} J(\bm{\theta},\bm{x},y)\big) \tag{5}\]

고차원에서는 아주 작은 \(\epsilon\) 의 섭동도 수많은 차원에 걸쳐 누적되어 출력을 크게 흔든다(선형성 가설). 판다 이미지에 사람 눈에 보이지 않는 섭동을 더해 긴팔원숭이로 99% 확신을 갖고 오분류하게 만드는 고전적 사례가 이를 잘 보여준다.

3.3 두 가지 학습 전략

  1. 입력에 섭동 주입 (Adversarial training): 식 5 의 \(\bm{x}_{\text{adv}}\) 를 훈련셋에 추가. minimax 형태로 쓰면

    \[ \min_{\bm{\theta}}\ \mathbb{E}_{(\bm{x},y)}\Big[\max_{\|\bm{\delta}\|\le\epsilon} J(\bm{\theta},\bm{x}+\bm{\delta},y)\Big] \]

    — 최악의 경우(worst-case)에 대한 강건 최적화다.

  2. 출력 타깃에 노이즈 주입 (Label smoothing): 원-핫 타깃을 부드럽게 만든다. 클래스 수 \(k\), 작은 \(\epsilon\) 에 대해

    \[ y_c^{\text{smooth}} = \begin{cases} 1-\epsilon & (\text{정답 클래스}) \\[4pt] \dfrac{\epsilon}{k-1} & (\text{나머지 클래스}) \end{cases} \tag{6}\]

    소프트맥스가 무한대 로짓으로 폭주하는 것을 막고(과신 방지), 확신이 큰 예측에서의 그래디언트 소실을 완화한다.

Note무선통신 비유

minimax 적대적 학습은 재밍(jamming)/최악 간섭에 강인한 수신기 설계와 정확히 같은 구조다. 송신기-재머의 게임에서, 재머가 신호공간 내 최악 방향으로 전력을 쏟을 때도 성능을 보장하도록 설계하는 robust beamforming이 식 5 의 내부 max에 대응한다.

4 Semi-Supervised Learning

4.1 핵심

레이블된 데이터(소량)와 레이블 없는 데이터(대량)를 결합한다. 레이블 없는 데이터의 분포 \(p(\bm{x})\) 자체가 정규화 정보가 되어, 결정 경계를 데이터가 조밀한 영역이 아닌 저밀도 영역(low-density region)에 놓이도록 유도한다.

4.2 형식화

목적함수는 지도 항과 비지도(정규화) 항의 결합이다.

\[ L = \underbrace{\sum_{(\bm{x}_i,y_i)\in\mathcal{D}_L}\ell(f(\bm{x}_i),y_i)}_{\text{레이블 정보}} + \lambda\underbrace{\sum_{\bm{x}_j\in\mathcal{D}_U}\mathcal{R}(f,\bm{x}_j)}_{\text{분포 정보}} \]

비지도 항 \(\mathcal{R}\) 의 대표적 선택:

  • 일관성 정규화(consistency): \(\mathcal{R}=\|f(\bm{x})-f(\tilde{\bm{x}})\|^2\), 즉 \(\bm{x}\) 와 그 증강 \(\tilde{\bm{x}}\) 의 예측이 같아야 함 (cluster assumption).
  • 엔트로피 최소화: \(\mathcal{R}=H(f(\bm{x}))\), 예측이 한 클래스로 확신을 갖도록 — 경계를 저밀도 영역으로 밀어냄.

4.3 두 가지 시나리오

  • 레이블·비레이블 데이터가 같은 표현 도메인일 때: 표준 준지도.
  • 다른 표현 도메인일 때: 공유 표현(shared representation)을 학습하는 전이/자기지도 방식과 맞닿는다.
Note무선통신 비유

반-블라인드(semi-blind) 채널 추정과 동형이다. 소수의 파일럿 심볼(=레이블)로 채널을 대략 잡고, 다수의 데이터 심볼의 통계(수신신호 분포, 정상성·유한 알파벳 같은 구조 = 비레이블 분포정보)를 활용해 추정 분산을 줄인다.

5 Multi-task Learning (MTL)

5.1 핵심

여러 과제를 하나의 모델로 동시에 학습하되, 하위 표현 \(\bm{h}^{\text{shared}}\) 를 공유한다. 각 과제가 서로에게 데이터 의존적 prior로 작용하여, 공유 표현이 어느 한 과제에 과적합되지 못하게 막는다.

5.2 구조

Code 
flowchart BT
    x["입력 x"] --> hs["h(shared): 공유 표현"]
    hs --> h1["h(1): 과제1 전용"]
    hs --> h2["h(2): 과제2 전용"]
    hs --> h3["h(3): 추가 인자"]
    h1 --> y1["y(1)"]
    h2 --> y2["y(2)"]

목적함수는 과제별 손실의 가중합이다.

\[ L_{\text{MTL}}(\bm{\theta}_{\text{shared}}, \{\bm{\theta}_t\}) = \sum_{t=1}^{T} \alpha_t\, L_t\big(\bm{\theta}_{\text{shared}}, \bm{\theta}_t;\ \mathcal{D}_t\big) \]

5.3 왜 정규화인가

공유 파라미터 \(\bm{\theta}_{\text{shared}}\) 는 모든 과제의 그래디언트를 동시에 만족해야 하므로, 탐색 가능한 가설공간이 크게 좁아진다. 이는 식 2 에서 명시적 \(\Omega\) 없이도 표현에 부과되는 암묵적 제약으로 작동한다. 과제들이 공통 잠재 인자(generative factor)를 공유한다는 가정이 성립할수록 효과가 크다.

Note무선통신 비유

결합 추정(joint estimation) — 채널 추정, 주파수 옵셋 보상, 잡음전력 추정을 하나의 수신기가 공통 통계량(공유 표현)을 토대로 동시에 수행하면, 각 추정이 서로를 정규화하여 전체 추정 분산이 줄어든다.

6 Early Stopping

6.1 핵심

검증 오차(validation error)가 더 이상 줄지 않는 시점에서 훈련을 멈춘다. 가장 흔하고 효율적이며 거의 공짜인 정규화. 훈련을 길게 할수록 모델은 훈련셋에 과적합되므로, 일반화가 최적인 순간을 “유효 표현력(effective capacity)”을 제어하는 하이퍼파라미터로 삼는 것이다.

Code 
flowchart LR
    A["훈련 시작"] --> B["train↓ val↓<br/>(과소적합 탈출)"]
    B --> C["val 최저점<br/>= Early Stopping"]
    C --> D["train↓ val↑<br/>(과적합 시작)"]

6.2 깊은 통찰: Early Stopping ≈ \(\ell_2\) 정규화

이차 근사된 손실 \(L(\bm{\theta})\approx L(\bm{\theta}^*) + \tfrac12(\bm{\theta}-\bm{\theta}^*)^\top H (\bm{\theta}-\bm{\theta}^*)\) 위에서 학습률 \(\epsilon\) 의 경사하강을 \(\tau\) 스텝 돌리면, \(H=Q\Lambda Q^\top\) 고유분해 기준으로 각 성분이 다음처럼 수축한다.

\[ \theta^{(\tau)}_i = \big(1-(1-\epsilon\lambda_i)^{\tau}\big)\,\theta^*_i \]

이를 \(\ell_2\) 정규화의 해 \(\theta^{\ell_2}_i = \frac{\lambda_i}{\lambda_i+\alpha}\theta^*_i\) 와 비교하면, 작은 \(\epsilon\lambda_i\) 근사에서

\[ \boxed{\;\alpha \approx \frac{1}{\tau\epsilon}\;} \tag{7}\]

즉 스텝 수 \(\tau\) 가 적을수록(=일찍 멈출수록) \(\ell_2\) 정규화 강도 \(\alpha\) 가 커진다. Early stopping은 곡률이 큰 방향(큰 \(\lambda_i\))을 먼저 학습하고 곡률이 작은 방향은 미처 학습하지 못한 채 멈추는데, 이것이 weight decay가 작은 고유값 방향을 억누르는 것과 정확히 같은 효과다.

Tip실용적 장점

식 7 의 \(\alpha\) 를 직접 탐색하려면 여러 번 재학습해야 하지만, early stopping은 한 번의 학습으로 검증곡선을 따라가며 최적 정규화 강도를 자동 선택한다. 그래서 사실상 공짜다.

Note무선통신 비유

반복 복호(iterative decoding, LDPC/Turbo)의 반복 횟수 제한과 닮았다. 반복을 무한정 돌리면 특정 노이즈 실현에 과도하게 맞춰져 오히려 불안정해질 수 있어, 검증 BER이 최저인 반복 횟수에서 멈추는 것이 최적이다.

7 Parameter Sharing / Tying

7.1 핵심

여러 파라미터가 서로 같거나 가깝도록 강제하여 자유도를 줄인다. 두 유사 과제 A, B에 대해, 이미 학습된 \(\bm{w}^{(A)}\) 에 \(\bm{w}^{(B)}\) 가 가까워지도록 페널티를 준다.

7.2 두 변종

Soft tying (parameter tying): 거리 페널티를 손실에 더한다.

\[ \Omega(\bm{w}^{(A)},\bm{w}^{(B)}) = \big\|\bm{w}^{(A)} - \bm{w}^{(B)}\big\|_2^2 \tag{8}\]

이는 “\(\bm{w}^{(B)}\) 의 prior 평균이 \(\bm{w}^{(A)}\) 인 가우시안”의 MAP과 같다(식 3 참조).

Hard sharing (parameter sharing): 아예 동일한 파라미터를 강제로 공유한다. CNN의 합성곱 커널이 대표적 — 같은 필터를 이미지 모든 위치에 적용함으로써 “통계가 위치에 불변(translation invariance)”이라는 강력한 사전지식을 주입하고, 파라미터 수와 메모리를 극적으로 줄인다.

Soft tying Hard sharing
형식 \(+\lambda\|\bm{w}^A-\bm{w}^B\|^2\) \(\bm{w}^A \equiv \bm{w}^B\)
자유도 부분적으로 감소 완전히 결합
대표 사례 전이학습 fine-tuning CNN 커널, RNN 시점 공유
Note무선통신 비유

시불변(time-invariant) 또는 정상성(stationarity) 가정과 같다. 채널이 한 블록 내에서 일정하다고 보고 모든 심볼에 같은 채널 계수를 적용하는 것은, CNN이 같은 커널을 모든 위치에 공유하는 hard sharing과 동일한 종류의 통계적 가정이다.

8 Bagging (Bootstrap Aggregating)

8.1 핵심

서로 다른 데이터 부분집합으로 여러 모델을 독립적으로 학습한 뒤, 예측을 평균(투표)한다. Bootstrap으로 만든 데이터셋의 다양성이 모델 간 오차를 비상관화하여 분산을 직접 줄인다. 앙상블(ensemble)·모델 평균(model averaging)의 한 형태.

8.2 분산 감소의 정량적 증명

\(k\) 개 모델의 예측 오차를 \(\epsilon_i\) 라 하고, 각 오차의 분산이 \(v=\mathbb{E}[\epsilon_i^2]\), 모델 간 공분산이 \(c=\mathbb{E}[\epsilon_i\epsilon_j]\,(i\ne j)\) 라 하자. 평균 예측의 오차 \(\bar\epsilon=\tfrac1k\sum_i\epsilon_i\) 의 분산은

\[ \mathbb{E}\!\left[\bar\epsilon^{\,2}\right] = \frac{1}{k^2}\,\mathbb{E}\!\left[\Big(\sum_i \epsilon_i\Big)^2\right] = \frac{1}{k}v + \frac{k-1}{k}c \tag{9}\]

두 극단을 보면:

  • 완전 상관(\(c=v\)): \(\mathbb{E}[\bar\epsilon^2]=v\) — 평균해도 전혀 줄지 않음.
  • 완전 무상관(\(c=0\)): \(\mathbb{E}[\bar\epsilon^2]=\dfrac{v}{k}\) — 모델 수에 반비례해 분산이 줄어듦!

따라서 bagging의 효과는 “각 모델을 충분히 강하게 만들면서도 서로 다르게(비상관) 만드는 것”에 달려 있다.

ImportantBagging이 편향에 미치는 영향

식 9 은 분산만 다룬다. 평균을 취해도 각 모델이 공유하는 편향은 그대로 남으므로, bagging은 저편향·고분산 모델(예: 깊은 결정트리, 큰 신경망)에 가장 효과적이다.

Note무선통신 비유 — 가장 정확한 대응

식 9 은 다이버시티 결합(diversity combining, 예: MRC)의 이득 공식과 동일하다. 독립 페이딩을 겪는 \(k\) 개의 수신 브랜치를 결합하면, 브랜치들의 잡음이 비상관(\(c=0\))일 때 유효 잡음 분산이 \(1/k\) 로 줄어들어 다이버시티 차수 \(k\) 를 얻는다. “독립 브랜치가 많을수록 좋다”는 통신의 직관이 곧 “비상관 모델이 많을수록 좋다”는 앙상블의 직관이다.

9 Dropout: Another Type of Ensemble

9.1 핵심

매 미니배치마다 각 유닛을 확률 \(p\) 로 무작위 제거하여 학습한다. 한 번의 학습으로 \(2^n\) 개의 부분 신경망(sub-network)을 가중치를 공유하며 동시에 훈련하는, 지수적으로 효율적인 bagging이다.

9.2 학습: Bernoulli 마스크

은닉 유닛 \(\bm{h}\) 에 대해 마스크 \(\bm{m}\sim\text{Bernoulli}(1-p)\) (원소별 독립)를 곱한다.

\[ \tilde{\bm{h}} = \bm{m}\odot\bm{h}, \qquad m_j\in\{0,1\} \]

서로 다른 마스크는 서로 다른 부분망을 정의하며, 모든 부분망이 가중치를 공유한다. 이것이 bagging과의 결정적 차이다 — bagging은 모델들이 독립이지만, dropout은 파라미터를 공유한다.

9.3 추론: Weight Scaling Inference Rule

추론 시 모든 부분망의 예측을 평균(앙상블)해야 하지만 \(2^n\) 개를 다 돌릴 수는 없다. 대신 가중치 스케일링 규칙으로 근사한다. 훈련 시 유닛이 확률 \(1-p\) 로 켜졌으므로, 추론 시 가중치(또는 활성)에 \((1-p)\) 를 곱해 기대 입력을 맞춘다.

\[ \mathbb{E}_{\bm{m}}[\tilde{\bm{h}}] = (1-p)\,\bm{h} \]

이 한 번의 순전파가 지수개 부분망의 기하평균 앙상블을 잘 근사한다(소프트맥스 출력의 경우 정확).

TipInverted Dropout (실무 표준)

추론을 건드리지 않으려고, 보통 훈련 시에 살아남은 활성을 \(1/(1-p)\) 로 미리 나눠 키운다. 그러면 추론은 스케일링 없이 그대로 쓰면 된다.

\[ \tilde{\bm{h}}_{\text{train}} = \frac{\bm{m}\odot\bm{h}}{1-p} \]

9.4 왜 일반화가 좋아지는가

각 유닛이 특정 동료 유닛의 존재에 의존(co-adaptation)할 수 없게 되어, 유닛마다 그 자체로 유용한 강건한 특징을 학습한다. 이는 입력에 곱셈적 잡음을 주입하는 정규화로도 해석된다.

Note무선통신 비유

무작위 안테나/부반송파 선택(random antenna selection) 또는 노드 고장에 강인한 분산 시스템과 같다. 임의의 안테나 부분집합만으로도 동작하도록 훈련하면, 특정 안테나에 과의존하지 않는 강건한 결합 전략을 학습하게 된다.

10 Tangent Propagation

10.1 핵심

출력 \(f(\bm{x})\) 가 “알려진 변형 방향”에 대해 국소적으로 불변(locally invariant)이 되도록, 그 방향으로의 방향도함수를 직접 0에 가깝게 만드는 명시적 정규화다. 예: 같은 클래스 예제들이 이루는 매니폴드(manifold)를 따라 움직여도 출력이 바뀌지 않아야 한다.

10.2 형식화

데이터 \(\bm{x}\) 에서 클래스 불변 변형의 접선 벡터(tangent vector)를 \(\bm{v}^{(i)}\) 라 하자. 출력의 그래디언트가 이 접선과 직교(orthogonal)하면 그 방향 변화에 둔감해진다. 정규화항은 접선 방향 방향도함수의 제곱합이다.

\[ \Omega(f) = \sum_{i}\Big(\big(\nabla_{\bm{x}} f(\bm{x})\big)^\top \bm{v}^{(i)}\Big)^2 \tag{10}\]

식 10 을 최소화하면 \(\nabla_{\bm{x}} f \perp \bm{v}^{(i)}\), 즉 접선 방향으로의 출력 변화율이 사라진다.

10.3 데이터 증강과의 관계

Dataset Augmentation Tangent Propagation
방식 변형된 입력을 명시적으로 생성·학습 변형 효과를 암묵적으로 페널티화
변형 크기 큰 섭동도 가능 아주 작은(국소적) 섭동만
비용 데이터 증가 자코비안 계산

본질적으로 둘은 같은 목표(변형 불변성)를 추구하지만, TP는 1차 미분 정보로 무한소 변형을 직접 규제한다.

WarningTP의 두 가지 약점
  1. 국소 변형만 모델링 — 식 10 은 1차 근사라 큰 변형은 못 다룬다(이 점은 dataset augmentation이 우월).
  2. ReLU와 궁합이 나쁨 — 그래디언트를 작게 만들어야 할 때 ReLU는 아예 0으로 죽여버린다. TP는 “줄어든(shrunk)” 그래디언트를 전제하므로, 0으로 끊기는 ReLU보다 매끄러운 활성과 잘 맞는다.
Note무선통신 비유

알려진 손상(impairment)에 대한 불변성 설계와 같다. 수신기가 작은 반송파 위상 회전이나 미세 Doppler 편이 같은 “알려진 변형 방향”에 둔감하도록 만드는 것은, 식 10 처럼 그 변형 방향으로의 출력 민감도를 0으로 규제하는 것과 동형이다.

11.3 핵심 메시지

  1. 모든 정규화는 식 2 의 큰 틀 — Loss + 귀납적 편향 — 안에서 이해할 수 있다.

  3. 겉보기에 다른 기법들이 동일한 효과로 수렴한다: 입력 노이즈·early stopping·tangent prop은 모두 어떤 의미에서 함수의 평탄성(자코비안 억제)을 유도하고, bagging·dropout은 분산 감소 앙상블로 묶인다.
  4. 무선통신의 직관 — 다이버시티 결합(=bagging), 강건 빔포밍(=adversarial), 반-블라인드 추정(=semi-supervised), 정상성 가정(=parameter sharing) — 이 정규화 전반을 관통한다.

12.1 A. Bagging 분산 감소 (식 9 수치 검증)

Code 
import numpy as np
rng = np.random.default_rng(0)

def ensemble_var(k, v=1.0, rho=0.0, trials=200_000):
    """k개 모델, 오차분산 v, 상관계수 rho일 때 평균오차의 분산을 추정."""
    c = rho * v
    # 공분산행렬 Sigma: 대각 v, 비대각 c
    Sigma = np.full((k, k), c) + np.eye(k) * (v - c)
    L = np.linalg.cholesky(Sigma)
    eps = rng.standard_normal((trials, k)) @ L.T   # 상관된 오차 샘플
    ebar = eps.mean(axis=1)
    return ebar.var()

for k in [1, 2, 4, 8, 16]:
    emp = ensemble_var(k, rho=0.0)
    theory = 1.0 / k            # c=0이면 v/k
    print(f"k={k:2d} | empirical={emp:.4f} | theory(v/k)={theory:.4f}")
k= 1 | empirical=1.0024 | theory(v/k)=1.0000
k= 2 | empirical=0.5001 | theory(v/k)=0.5000
k= 4 | empirical=0.2499 | theory(v/k)=0.2500
k= 8 | empirical=0.1253 | theory(v/k)=0.1250
k=16 | empirical=0.0624 | theory(v/k)=0.0625

비상관(\(\rho=0\))일 때 평균 오차 분산이 \(1/k\) 로 줄어드는 것을 확인할 수 있다. \(\rho\) 를 키우면 식 9 의 \(\frac1k v+\frac{k-1}{k}c\) 로 수렴한다.

12.2 B. Dropout 순전파와 가중치 스케일링

Code 
import numpy as np
rng = np.random.default_rng(1)

def dropout_forward(h, p, training=True, inverted=True):
    """Bernoulli dropout. p = drop 확률."""
    if not training:
        return h if inverted else h * (1 - p)     # 표준 추론
    mask = (rng.random(h.shape) > p).astype(h.dtype)
    out = h * mask
    if inverted:
        out /= (1 - p)        # inverted dropout: 추론 무수정
    return out

h = np.ones(10_000)           # 모든 활성=1
p = 0.5
train_out = dropout_forward(h, p, training=True, inverted=True)
print(f"훈련 시 평균 활성(inverted) ≈ {train_out.mean():.3f}  (목표 1.0)")
print(f"실제 drop된 비율 ≈ {(train_out==0).mean():.3f}  (목표 {p})")
훈련 시 평균 활성(inverted) ≈ 1.009  (목표 1.0)
실제 drop된 비율 ≈ 0.495  (목표 0.5)

inverted dropout은 훈련 시 기대 활성을 보존하므로 추론을 손대지 않아도 된다.

12.3 C. Early Stopping ↔︎ \(\ell_2\) 등가성 (식 7)

Code 
import numpy as np

# 이차 손실 L(theta) = 0.5 (theta-theta*)^T H (theta-theta*), H=diag(lams)
lams = np.array([5.0, 1.0, 0.1, 0.01])   # 곡률(고유값)
theta_star = np.ones_like(lams)
eps = 0.05                                # 학습률

def gd_solution(tau):
    # 성분별 closed-form: theta_tau = (1-(1-eps*lam)^tau) theta*
    return (1 - (1 - eps * lams) ** tau) * theta_star

def l2_solution(alpha):
    # theta = lam/(lam+alpha) theta*
    return lams / (lams + alpha) * theta_star

tau = 40
alpha_equiv = 1.0 / (tau * eps)          # 식 (early-l2)
print(f"tau={tau}, eps={eps}  ->  등가 alpha ≈ {alpha_equiv:.3f}\n")
print("성분 | early-stopping |  L2(alpha_equiv)")
for i, (a, b) in enumerate(zip(gd_solution(tau), l2_solution(alpha_equiv))):
    print(f"  {i}  |    {a:.4f}     |     {b:.4f}")
tau=40, eps=0.05  ->  등가 alpha ≈ 0.500

곡률이 큰 방향은 빠르게 \(\theta^*\) 로 수렴(둘 다 1에 가까움)하고, 곡률이 작은 방향은 억제되어 작은 값에 머문다 — early stopping과 \(\ell_2\) 정규화가 같은 수축을 만든다.

12.4 D. FGSM 적대적 섭동 (식 5)

Code 
import numpy as np

def fgsm(grad_x, eps):
    """입력 그래디언트로부터 FGSM 섭동을 만든다."""
    return eps * np.sign(grad_x)

x = np.array([0.2, -0.5, 0.9, -0.1])
grad = np.array([1.3, -0.4, 0.8, -2.1])   # dJ/dx (가정)
x_adv = x + fgsm(grad, eps=0.1)
print("원본 x      :", x)
print("적대적 x_adv:", np.round(x_adv, 3))
print("섭동 노름(∞):", np.abs(x_adv - x).max(), "= eps")
원본 x      : [ 0.2 -0.5  0.9 -0.1]
적대적 x_adv: [ 0.3 -0.6  1.  -0.2]
섭동 노름(∞): 0.10000000000000003 = eps

\(\ell_\infty\) 제약 하에서 손실을 가장 키우는 섭동은 그래디언트의 부호 방향이며, 그 크기는 정확히 \(\epsilon\) 으로 균일하다.
